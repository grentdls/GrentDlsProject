# 单位选中后的建造页面 UI 详细规则文档

## 一、设计目标

当玩家点击拥有建造能力的单位后，需要显示建造页面。

该页面用于快速选择建筑，并进入放置建筑流程。

当前优化目标：

```text
1. 建造列表更直观。
2. 每个建筑按钮显示建筑图片。
3. 建筑图片下方显示资源消耗：ICON + 数字。
4. 建造列表横向排布，可横向拖动。
5. 增加建筑分类栏。
6. 鼠标悬停 / 手机长按显示建筑详情页。
7. PC 和手机都要好点、好拖、好看、好识别。
8. 主界面不堆文字，详情信息进入详情卡。
```

最终体验：

```text
玩家选中工人 / 机器工人 / 自然工灵 / 妖族建造单位后，
右侧或底部弹出建造页面，
快速横向滑动选择建筑，
短按/点击进入建筑放置，
悬停/长按查看详情。
```

# 二、建造页面出现条件

## 2.1 哪些单位会显示建造页面

满足以下条件的单位，选中后显示建造页面入口：

```text
拥有建造能力
当前未死亡
当前未被控制
当前未处于不可操作状态
当前阵营允许建造
当前模式允许建造
```

示例单位：

| 阵营 | 建造单位 |
|---|---|
| 华夏 | 工兵 / 工匠 / 工人 |
| 妖族 | 苦役小妖 / 建巢妖仆 |
| 机械 | 机器工人 / 工程车 |
| 自然 | 工灵 / 灵木使 |
| 融合阵营 | 对应融合工人 / 占领核心授权单位 |

## 2.2 多单位选中时

如果多选中有建造能力单位：

```text
显示建造页面。
建造行为由最近的可用建造单位执行。
```

如果同时选中多个不同阵营建造单位：

```text
优先显示当前主控阵营的建造列表。
可通过小标签切换建造来源。
```

建议早期简化：

```text
只显示第一个主选中建造单位的建造列表。
```

## 2.3 非建造单位

非建造单位：

```text
不显示建造页面。
显示普通单位操作面板。
```

如果单位有特殊建造功能，例如自然融合单位临时造藤蔓屏障：

```text
显示小型“特殊建造”入口，不进入完整建造页。
```

# 三、建造页面整体布局

## 3.1 手机端布局

手机端推荐建造页面显示在：

```text
屏幕右侧偏下区域
靠近技能按钮上方或左侧
不遮挡资源栏
不遮挡小地图
不遮挡单位信息主面板
```

推荐结构：

```text
┌──────────────────────────────┐
│ 分类栏：全部 资源 军队 科技 防御 │
├──────────────────────────────┤
│ 横向建筑列表                  │
│ [建筑卡][建筑卡][建筑卡]  →拖动 │
└──────────────────────────────┘
```

手机端尺寸建议：

| 项目 | 建议 |
|---|---:|
| 面板宽度 | 屏幕宽度 88% |
| 面板高度 | 190~230 px |
| 分类栏高度 | 36~42 px |
| 建筑卡宽度 | 92~108 px |
| 建筑卡高度 | 130~150 px |
| 建筑图片 | 72~82 px |
| 拖动热区 | 整个列表区域 |

## 3.2 PC端布局

PC端推荐显示在：

```text
屏幕底部中间
或右下角单位操作面板上方
```

推荐结构：

```text
┌────────────────────────────────────────┐
│ 分类栏：全部 资源 军队 科技 防御 特殊    │
├────────────────────────────────────────┤
│ ← [建筑卡][建筑卡][建筑卡][建筑卡] →     │
└────────────────────────────────────────┘
```

PC端尺寸建议：

| 项目 | 建议 |
|---|---:|
| 面板宽度 | 720~980 px |
| 面板高度 | 190~230 px |
| 分类栏高度 | 34~40 px |
| 建筑卡宽度 | 104~120 px |
| 建筑卡高度 | 138~156 px |
| 建筑图片 | 78~88 px |
| 一屏显示数量 | 5~8 个 |

## 3.3 面板层级

建造页面层级：

```text
低于战斗警告
低于任务弹窗
高于普通单位面板
高于战场HUD
不遮挡顶部资源栏
```

# 四、建造页面展开与隐藏

## 4.1 展开规则

选中可建造单位后：

```text
建造页面从右侧或底部滑出。
```

推荐动效：

```text
0.18秒滑入
透明度 0 → 100%
缩放 96% → 100%
```

## 4.2 隐藏规则

以下情况隐藏建造页面：

```text
取消选择单位
选中非建造单位
打开其他全屏UI
进入放置建筑确认阶段后，可折叠为小条
单位死亡
玩家按返回键
手机系统返回键
```

## 4.3 返回键规则

手机端：

```text
按系统返回键：
如果建筑详情卡打开 → 先关闭详情卡
如果处于建筑放置模式 → 取消放置
如果建造页面打开 → 关闭建造页面
如果没有打开UI → 不处理或打开暂停菜单
```

PC端：

```text
ESC：
优先关闭详情卡
再取消建筑放置
再关闭建造页面
```

# 五、分类栏设计

## 5.1 分类目的

分类栏用于减少建筑列表长度，让玩家快速找到目标建筑。

分类必须清楚、数量不能过多。

## 5.2 推荐分类

基础分类：

```text
全部建造
资源建造
军队建造
科技建造
防御建造
特殊建造
```

可选分类：

```text
水域建造
空军建造
融合建造
终局建造
```

## 5.3 分类定义

### 全部建造

显示当前单位可建的全部建筑。

```text
所有已解锁建筑
所有未解锁但可预览建筑，可选
```

### 资源建造

资源相关建筑。

包括：

```text
采集点建筑
资源加工建筑
资源存储建筑
能量/电力/灵气/献祭相关经济建筑
```

示例：

| 阵营 | 建筑 |
|---|---|
| 华夏 | 灵矿坊、仙木场、太府钱庄 |
| 妖族 | 温兽巢，若作为采集单位生产建筑 |
| 机械 | 发电站、电容中继站、高压电塔 |
| 自然 | 灵泉之环，若作为经济/回复支援可归入特殊或资源 |

注意：

```text
如果建筑主要生产战斗单位，不放资源建造。
```

### 军队建造

生产战斗单位的建筑。

包括：

```text
兵营
兽巢
机场
重装工厂
元素生产建筑
船厂
飞行单位建筑
水军建筑
```

示例：

| 阵营 | 建筑 |
|---|---|
| 华夏 | 步兵营、骑兵营、水军营、飞行营 |
| 妖族 | 虫巢、凶兽巢、飞兽巢、水巢 |
| 机械 | 机场、重装工厂、机动机械场、船厂 |
| 自然 | 水灵源池、炽火灵炉、厚土灵坛、金魄铸庭、灵木育场 |

### 科技建造

研究科技、升级、改造、融合、吞噬相关建筑。

包括：

```text
科研建筑
科技树建筑
改造建筑
融合建筑
献祭/进化科技建筑
```

示例：

| 阵营 | 建筑 |
|---|---|
| 华夏 | 玄机观、神机工坊、演武台 |
| 妖族 | 妖血池、进化祭坑、妖魂科技建筑 |
| 机械 | 科研中心、改造车间、雷达站 |
| 自然 | 元素研习所、元素融合坛、天象祭台 |

### 防御建造

防御、城墙、塔、炮台、陷阱。

包括：

```text
箭塔
防空塔
炮塔
根须守卫
陷阱
城墙
雷达防御建筑
```

示例：

| 阵营 | 建筑 |
|---|---|
| 华夏 | 破云弩塔、镇霄灵塔 |
| 妖族 | 骨刺妖塔、妖瞳图腾 |
| 机械 | 防御炮台、导弹塔、雷达站可根据功能双分类 |
| 自然 | 根须守卫、元素防御塔 |

### 特殊建造

功能特殊、不适合放进前面分类的建筑。

包括：

```text
主城相关
终局建筑
融合阵营建筑
占领核心建筑
奇观建筑
传送建筑
大型战役建筑
```

示例：

```text
天象祭台
万兽祭环
超载核心
融合阵营专属建筑
```

## 5.4 分类显示规则

分类标签横向排布。

```text
[全部] [资源] [军队] [科技] [防御] [特殊]
```

手机端：

```text
分类栏也可以横向拖动。
当前分类高亮。
分类名称最多4个字。
```

推荐手机端简写：

```text
全部
资源
军队
科技
防御
特殊
```

PC端可显示完整：

```text
全部建造
资源建造
军队建造
科技建造
防御建造
特殊建造
```

## 5.5 分类角标

每个分类可显示数量角标：

```text

```

如果有新解锁建筑：

```text
分类右上角显示小红点
```

如果该分类无建筑：

```text
分类灰显
不可点击
```

# 六、建筑卡片设计

## 6.1 建筑卡片整体结构

每个建筑卡片显示：

```text
建筑图片
建筑名称
资源消耗列表
状态标记
```

推荐结构：

```text
┌──────────────┐
│   建筑图片    │
│              │
├──────────────┤
│ 建筑名称      │
│ 🪵120 🪙80    │
│ 🪨60  ⚙40     │
└──────────────┘
```

## 6.2 建筑图片

建筑图片要求：

```text
使用对应建筑的图标或小渲染图
保持独立透明背景
图片主体居中
显示建筑主要剪影
不同阵营风格清晰
```

尺寸：

| 平台 | 图片尺寸 |
|---|---:|
| 手机 | 72~82 px |
| PC | 78~88 px |

图片底板：

```text
圆角方形底
阵营色描边
轻微阴影
```

## 6.3 建筑名称

显示规则：

```text
最多 5 个汉字
超过显示缩略名
悬停/长按详情显示完整名
```

字体：

```text
12~14号
加粗
居中
```

## 6.4 资源消耗列表

建筑卡片下方显示资源消耗。

格式：

```text
ICON + 数字
```

最多显示 4 个资源。

示例：

```text
🪵120  🪙80
🪨60   ⚙40
```

如果资源种类超过 4 个：

```text
显示主要3个 + 更多图标
详情页显示完整消耗
```

## 6.5 资源不足表现

如果某个资源不足：

```text
该资源数字变红
建筑卡片整体降低亮度
按钮底部显示“资源不足”
```

不要整张卡完全灰掉，否则玩家看不清建筑。

推荐：

```text
图片保持70%亮度
资源不足项红色
确认按钮灰显
```

## 6.6 未解锁表现

未解锁建筑可以选择显示或隐藏。

推荐规则：

```text
默认显示未解锁建筑，但灰显。
让玩家知道后续能造什么。
```

未解锁卡片显示：

```text
锁图标
灰色遮罩
名称可读
消耗隐藏或变暗
底部显示前置条件
```

卡片示例：

```text
[锁] 机场
需要：军工扩展
```

## 6.7 已达上限表现

如果建筑有数量上限：

```text
显示数量：1 / 1
达到上限后卡片灰显
```

示例：

```text
天象祭台 0/1
```

达到上限：

```text
已达上限
```

## 6.8 正在建造数量

如果当前已排队或正在建造：

```text
卡片右上角显示小角标：建造中 x2
```

示例：

```text
高压电塔 x3
```

# 七、建筑卡片状态

## 7.1 状态类型

| 状态 | 表现 |
|---|---|
| 可建造 | 正常亮度，阵营色描边 |
| 资源不足 | 资源数字红色，卡片轻微变暗 |
| 条件不足 | 灰色遮罩，锁图标 |
| 地形限制 | 黄色地形图标 |
| 数量上限 | 灰色，显示已达上限 |
| 电力不足 | 蓝色电力警告 |
| 供给不足 | 紫色/灰色供给警告 |
| 新解锁 | 金色角标，新字 |
| 推荐建造 | 柔和脉冲描边 |

## 7.2 推荐建造规则

系统可根据局势推荐建筑。

推荐条件示例：

```text
没有资源建筑 → 推荐资源建筑
没有军队建筑 → 推荐军队建筑
敌方空军多 → 推荐防空建筑
电力不足 → 推荐发电站
融合人口未使用 → 推荐融合生产建筑
```

推荐表现：

```text
建筑卡片边框柔和呼吸
右上角显示“荐”
```

不推荐过强闪烁。

# 八、横向拖动列表规则

## 8.1 横向排布

建筑卡片横向排列。

```text
[卡1][卡2][卡3][卡4][卡5] →
```

列表可拖动。

## 8.2 手机拖动规则

手机端：

```text
手指在列表区域左右拖动 → 横向滚动
拖动距离超过 12px → 判定为拖动，不触发点击
快速滑动 → 惯性滚动
长按 0.35秒 → 显示详情，不进入拖动
长按后拖动超过20px → 关闭详情并进入拖动
```

防误触优先级：

```text
拖动 > 长按 > 点击
```

## 8.3 PC拖动规则

PC端支持：

```text
鼠标滚轮横向滚动，可按Shift+滚轮
鼠标拖拽列表横向移动
左右箭头按钮翻页
鼠标悬停卡片显示详情
```

推荐：

```text
鼠标滚轮默认滚动建造列表。
如果鼠标不在建造列表上，不影响镜头缩放。
```

## 8.4 滚动条表现

PC端可显示细滚动条。

手机端不显示传统滚动条，使用：

```text
底部小分页点
或细进度条
```

示例：

```text
━━━━━━━──
```

表示当前横向位置。

## 8.5 列表边缘提示

如果列表还能继续滑动：

```text
右侧显示渐隐遮罩
左侧显示渐隐遮罩
```

如果到头：

```text
遮罩消失
```

# 九、点击建筑卡片后的流程

## 9.1 PC流程

点击建筑卡片后进入建筑放置模式。

推荐支持中心虚影确认方案，和手机保持一致：

```text
点击建筑卡片
→ 建筑虚影出现在屏幕中心
→ 虚影右上角显示确认按钮
→ 虚影左上角显示取消按钮
→ 玩家移动镜头/鼠标调整位置
→ 点击确认建造
```

PC可选传统RTS方案：

```text
点击建筑卡片
→ 建筑虚影跟随鼠标
→ 左键确认
→ 右键取消
```

推荐设置项：

```text
建筑放置模式：中心虚影确认 / 传统鼠标放置
```

## 9.2 手机流程

手机端强烈建议使用中心虚影确认方案。

流程：

```text
点击建筑卡片
→ 建筑虚影出现在屏幕中心
→ 建造页面自动折叠成小条
→ 玩家拖动地图调整位置
→ 虚影随屏幕中心地面位置变化
→ 右上方确认建造
→ 左上方取消建造
```

虚影按钮：

```text
左上：取消
右上：确认
下方：旋转，可选
下方：详情，可选
```

## 9.3 资源不足点击

点击资源不足建筑：

```text
不进入放置模式
播放轻微错误音
资源不足项闪红
弹出小提示：黄金不足
```

## 9.4 条件不足点击

点击未解锁建筑：

```text
不进入放置模式
显示详情卡
自动定位到缺少条件区
```

示例：

```text
需要科技：军工扩展
需要建筑：科研中心
```

```text

建造时间

特殊功能

解锁条件
```

# 十一、建造页面视觉风格

## 11.1 通用风格

整体应保持：

```text
干净
低遮挡
图标大
文字少
资源清楚
卡片有层次
```

推荐视觉：

```text
半透明深色底板
阵营色描边
卡片微浮起
软阴影
圆角
简洁资源图标
```

## 11.2 面板背景

面板背景分三层：

```text
外层阴影
中层半透明底板
内层建筑卡片槽位
```

颜色建议：

```text
深色主底：#1E2430，透明度 88%
浅色纸张风：#E8D9B8，透明度 92%
```

根据当前整体 UI 风格选择。

## 11.3 卡片背景

卡片状态：

| 状态 | 背景 |
|---|---|
| 正常 | 深色略亮 |

| 可建造 | 阵营色细边框 |
| 推荐 | 阵营色呼吸边框 |
| 资源不足 | 暗化 + 红色资源 |
| 未解锁 | 灰色遮罩 + 锁 |
| 已达上限 | 灰色 + 上限标签 |

## 11.4 阵营主题

# 十二、可视性规则

## 12.1 建筑图片必须最大

建筑卡片中：

```text
建筑图片占卡片高度 55%~60%
资源占 25%
名称占 15%
```

不要让文字挤掉建筑图。

## 12.2 资源图标必须统一

资源图标要求：

```text
大小一致
颜色清楚
和资源栏一致
不足时变红
```

推荐资源图标：

```text
木材：木头
黄金：金币
石料：石块
金属：铁锭/齿轮
电力：闪电
融合人口：紫色双环
献祭值：血滴
元素：五行小图标
```

## 12.3 文字控制

建筑卡片文字：

```text
建筑名称最多1行
资源数字最多2行
不显示长描述
长描述进详情页
```

详情页文字：

```text
每条不超过18字
最多5条核心效果
超出用“更多”
```

# 十三、操控性规则

## 13.1 点击热区

手机端建筑卡点击热区必须大于视觉区域。

推荐：

```text
视觉卡片 96x140
实际热区 108x152
```

## 13.2 防误触

手机端判断：

```text
按下 < 0.25秒且移动 < 12px = 点击
按下 >= 0.35秒 = 详情
移动 >= 12px = 拖动列表
```

优先级：

```text
拖动 > 长按 > 点击
```

## 13.3 点击反馈

点击建筑卡：

```text
卡片缩放 1.0 → 0.94 → 1.0
播放轻微点击音
可建造时进入放置
不可建造时资源或条件闪烁
```

## 13.4 悬停反馈

PC悬停：

```text
卡片上浮 4px
边框提亮
建筑图片轻微放大 1.05
显示详情卡
```

# 十八、验收标准

## 18.1 基础功能

```text
选中有建造能力单位后显示建造页面。
选中非建造单位后不显示建造页面。
建造页面可正常展开和隐藏。
分类栏可以切换建筑分类。
建筑列表横向排布。
建筑列表可横向拖动。
建筑卡显示建筑图片。
建筑卡下方显示资源ICON+数字。
点击可建造建筑进入放置模式。
```

## 18.2 详情功能

```text
PC鼠标悬停建筑卡0.25秒显示详情页。
手机长按建筑卡0.35秒显示详情页。
详情页显示建筑图片、属性、消耗、功能、条件、限制。
详情页不会遮挡当前按钮太严重。
详情页可关闭。
```

## 18.3 状态表现

```text
资源不足项显示红色。
未解锁建筑显示锁。
已达上限建筑显示上限。
地形限制建筑显示地形警告。
机械建筑显示电力要求。
融合建筑显示供给要求。
推荐建筑有轻微高亮。
```

## 18.4 操控体验

```text
手机端拖动列表不会误触建造。
手机端长按详情不会误触点击。
PC端滚轮/拖拽列表顺畅。
点击反馈清楚。
进入放置模式后建造面板不遮挡主要视野。
返回键能正确关闭详情、取消放置、关闭建造页。
```

## 18.5 可视性

```text
建筑图片清楚。
资源消耗清楚。
分类文字清楚。
卡片状态能一眼区分。
详情页信息完整但不臃肿。
手机端不会遮挡主要操作区。
```

# 十九、最终硬规则

```text
1. 建造页面必须显示建筑图片。
2. 建筑图片下方必须显示资源 ICON + 数字。
3. 建造列表必须横向排布。
4. 建造列表必须支持横向拖动。
5. 建造页面必须有分类栏。
6. 基础分类至少包含：全部、资源、军队、科技、防御、特殊。
7. PC端鼠标悬停显示建筑详情。
8. 手机端长按显示建筑详情。
9. 点击建筑卡进入建筑放置流程。
10. 资源不足、条件不足、地形错误必须有清楚状态。
11. 手机端必须避免拖动和点击误触。
12. 进入建筑放置后，建造页面必须折叠或弱化，避免遮挡视野。
13. 详情页只放复杂信息，主卡片保持简洁。
14. 不同阵营建筑卡要有不同主题边框。
15. 融合建筑必须显示路线和供给限制。
```
