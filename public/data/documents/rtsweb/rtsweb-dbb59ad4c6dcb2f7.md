# 占领主城后的定向融合阵营系统 V2

## 一、这版修改重点

原方案把两个阵营组合成一套“对称融合阵营”，这是不对的。

正确规则应该是：

```text
谁占领谁，结果不同。
```

也就是：

```text
华夏占领妖族 ≠ 妖族占领华夏
机械占领自然 ≠ 自然占领机械
```

占领后的融合结果由两个信息决定：

```text
占领方阵营
被占领主城阵营
```

公式：

```text
融合路线 = 占领方文化/玩法主导 + 被占领阵营能力被吸收/驯化/改造/自然化
```

示例：

```text
华夏占领妖族：华夏驯化妖兽 → 饕餮骑兵、麒麟骑兵、镇妖弩车
妖族占领华夏：妖兽吸收华夏军制并化形 → 化形麒麟、化形饕餮、妖化军阵
```

# 二、新占领规则

## 2.1 主城击破即占领

取消“核心瘫痪20秒等待占领”的复杂流程。

新规则：

```text
谁最后一下击破敌方主城，谁立即占领该主城。
```

判定：

```text
造成主城最后一击的玩家/AI获得占领权。
```

多人/多AI混战：

```text
只看最后一击。
不看总伤害。
不看周围单位数量。
```

这样规则最清楚，玩家也容易理解。

---

## 2.2 主城被击破后的状态

敌方主城生命归零后，不直接消失。

流程：

```text
主城生命归零
→ 播放主城破防表现
→ 归属最后一击玩家
→ 进入占领保护期
→ 转化为占领核心
→ 解锁定向融合建筑菜单
```

---

## 2.3 占领保护期

占领后立刻进入保护期。

```text
保护期：10秒
```

保护期内：

```text
占领核心不可被攻击
占领核心不可被重新占领
占领核心不可生产单位
占领核心不可建造融合建筑
占领核心不可研究融合科技
```

保护期作用：

```text
给玩家看清楚占领结果
防止刚占领就被瞬间打掉
给UI弹窗和表现留时间
```

保护期结束后：

```text
占领核心恢复可攻击状态
融合建筑菜单解锁
融合科技树解锁第一层
```

---

## 2.4 占领核心基础规则

占领后的主城变成：

```text
占领核心
```

占领核心不是原阵营主城，也不是玩家原主城。

它是一个融合功能节点。

占领核心功能：

```text
提供融合建筑建造权限
提供融合人口上限
提供融合科技入口
提供占领区域建造范围
显示当前定向融合路线
```

## 2.6 占领核心被摧毁

如果占领核心被敌人摧毁：

```text
该占领路线失效
无法继续建造对应融合建筑
无法继续训练对应融合单位
正在研究的融合科技暂停并取消
已经生产出的融合单位保留
已经建好的融合建筑进入断供状态
```

断供状态：

```text
生产停止
科技停止
建筑技能禁用
防御建筑攻击速度 -50%
```

断供持续：

```text
60秒
```

60秒后：

```text
融合建筑变为废墟
```

# 三、占领表现规则

## 3.1 最后一击表现

主城被最后一击击破时：

```text
主城核心爆裂
原阵营旗帜破碎
最后一击单位头顶出现“占领者”标记
屏幕提示：你占领了敌方主城
```

如果是敌人占领：

```text
警告：敌方占领了我方主城！
```

---

## 3.2 10秒保护期表现

保护期内：

```text
主城外出现半透明护盾罩
护盾罩显示倒计时数字
地面出现占领方阵营纹路
原阵营元素/机械/妖气/军旗逐渐被占领方覆盖
```

头顶HUD：

```text
占领保护 10s
```

倒计时：

```text
10 → 9 → 8 ... → 0
```

---

## 3.3 转化完成表现

保护期结束：

```text
护盾破碎
占领核心完成转化
播放融合路线专属特效
解锁融合建筑菜单
```

示例：

华夏占领妖族：

```text
妖族主城被插上华夏军旗
妖兽骨架被锁链和符印束缚
出现镇妖符文和兽栏结构
```

妖族占领华夏：

```text
华夏主城被妖血和兽骨侵蚀
城墙长出妖纹
军旗变为妖化战旗
```

机械占领自然：

```text
自然主城被电缆和金属支架包裹
树根中嵌入能量核心
```

自然占领机械：

```text
机械主城被藤蔓、灵晶和五行纹路覆盖
电路变成灵脉流光
```

# 五、定向融合通用限制

## 5.1 不能获得敌方完整体系

占领敌方主城后不能完整复制敌方阵营。

例如：

```text
华夏占领妖族后，不能建完整妖族虫巢、凶兽巢、水巢。
只能建“镇妖骑军”路线建筑。
```

```text
妖族占领华夏后，不能建完整华夏步兵营、骑兵营、演武台。
只能建“化形妖军”路线建筑。
```

---

## 5.2 融合建筑上限

每个占领核心默认：

```text
最多建造4座融合建筑
```

科技提升：

```text
融合扩建 I：+2
融合扩建 II：+2
```

最大：

```text
8座
```

---

## 5.3 融合人口上限

默认：

```text
融合人口 = 当前总人口上限的20%
```

科技后：

```text
融合人口最高 = 当前总人口上限的35%
```

融合单位同时占用：

```text
普通人口
融合人口
```

这样可以防止融合兵种无限堆。

---

## 5.4 多个占领核心

同一玩家可以占领多个主城。

限制建议：

```text
竞技模式：最多同时拥有2个占领核心
生存模式：最多同时拥有4个占领核心
战役模式：由关卡配置决定
```

# 二十一、验收标准

```text
1. 主城由最后一击方立即占领。
2. 占领后有10秒保护期。
3. 保护期内占领核心不可被攻击、不可生产、不可建造。
4. 保护期结束后解锁正确的定向融合路线。
5. 华夏占领妖族解锁饕餮骑兵、麒麟骑兵等镇妖骑军内容。
6. 妖族占领华夏解锁化形麒麟、化形饕餮等化形妖军内容。
7. A占领B和B占领A获得的建筑、单位、科技不同。
8. 融合建筑上限生效。
9. 融合人口上限生效。
10. 占领核心被摧毁后融合建筑进入断供状态。
11. UI能显示占领方、被占领方、融合路线、保护倒计时。
12. 单位Tips能显示定向来源和弱点。
```

---

# 二十二、最终硬规则

```text
1. 谁最后一下击破主城，谁占领主城。
2. 占领后立即进入10秒保护期。
3. 占领结果是定向融合，不是双向对称融合。
4. 华夏占领妖族是驯兽骑兵路线。
5. 妖族占领华夏是妖兽化形军阵路线。
6. 所有阵营互相占领都必须获得不同内容。
7. 占领后不能获得敌方完整原阵营。
8. 占领核心只解锁有限融合建筑、融合单位和融合科技。
9. 融合单位必须占用融合人口。
10. 融合建筑必须受占领核心供给影响。
11. 占领核心被摧毁后，融合体系断供。
12. UI必须明确显示占领方、原阵营、融合路线、保护期和限制。
```
