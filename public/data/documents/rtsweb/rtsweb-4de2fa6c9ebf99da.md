# 占领主城与定向融合阵营：功能与表现需求文档

## 一、文档目标

本文件用于明确“击破敌方主城后直接占领，并解锁定向融合阵营”的完整功能需求、操作规则、UI表现、战斗表现、程序实现字段与验收标准。

本系统不是简单的胜利结算，而是中后期玩法扩展系统。

核心目标：

```text
1. 主城被最后一击击破后，立即归属最后一击玩家。
2. 占领后进入10秒保护期。
3. 占领结果根据“占领方阵营 + 被占领主城阵营”生成定向融合路线。
4. A占领B和B占领A获得的建筑、单位、科技完全不同。
5. 占领后不是复制敌方完整阵营，而是解锁有限的融合建筑、单位和科技。
6. 所有新增功能必须有明确UI、特效、音效、状态提示和程序判定规则。
```

---

# 二、核心概念定义

## 2.1 主城击破

主城生命归零时触发。

```text
主城被击破 = 主城HP <= 0
```

主城被击破后不会直接消失，而是触发占领流程。

---

## 2.2 最后一击占领

最终造成主城HP归零的单位、技能、建筑或持续伤害来源所属玩家获得占领权。

```text
占领者 = 最后一击伤害来源的归属玩家
```

需要支持以下最后一击来源：

```text
单位普通攻击
单位技能
防御建筑攻击
持续伤害
召唤单位伤害
陷阱伤害
AOE伤害
空袭伤害
舰炮伤害
天气/天象伤害，若有归属玩家
```

如果伤害没有明确归属玩家：

```text
不触发占领，主城进入废墟状态
```

建议所有可造成伤害对象都必须记录 OwnerPlayerId。

---

## 2.3 占领核心

敌方主城被占领后，会转换为：

```text
占领核心
```

占领核心不是原主城，也不是占领方原主城。

它是融合阵营功能节点。

占领核心负责：

```text
显示占领方和原阵营
提供定向融合路线
提供融合建筑建造权限
提供融合人口上限
提供融合科技入口
提供融合建筑供给
```

---

## 2.4 定向融合路线

定向融合路线由两个阵营决定：

```text
占领方阵营
被占领主城阵营
```

例如：

```text
华夏占领妖族 = 镇妖骑军
妖族占领华夏 = 化形妖军
```

二者完全不同。

# 三、整体流程

## 3.1 标准流程

```text
敌方主城HP归零
→ 判断最后一击归属
→ 主城归属最后一击玩家
→ 主城进入占领保护期
→ 播放占领转化表现
→ 10秒保护期倒计时
→ 保护期结束
→ 主城变为占领核心
→ 解锁定向融合建筑菜单
→ 解锁定向融合科技树第一层
→ 玩家可建融合建筑、训练融合单位
```

---

## 3.2 状态机

占领核心状态：

```text
正常敌方主城
被击破中
占领保护期
占领核心启用
断供状态
废墟状态
```

状态流转：

```text
正常敌方主城
  ↓ HP <= 0
被击破中
  ↓ 判断最后一击成功
占领保护期
  ↓ 10秒结束
占领核心启用
  ↓ 核心被摧毁
断供状态
  ↓ 60秒后
废墟状态
```

# 四、主城击破与最后一击规则

## 4.1 最后一击记录需求

每次主城受到伤害时，记录：

```text
LastDamageDealerId
LastDamageOwnerPlayerId
LastDamageFaction
LastDamageSourceType
LastDamageSkillId
LastDamageTime
```

当主城HP <= 0 时，使用最后一次有效伤害归属进行占领。

---

## 4.2 AOE最后一击

如果多个AOE同一帧造成伤害：

优先级：

```text
1. 实际让HP从正数变为0或负数的伤害事件
2. 同帧多个事件时按服务器/逻辑处理顺序
3. 若无法判定，取伤害量最高的该帧事件
```

---

## 4.3 持续伤害最后一击

持续伤害必须保留来源。

示例：

```text
火焰地表由玩家A的火魔树释放。
主城被火焰地表烧到0血。
占领者 = 玩家A。
```

---

## 4.4 召唤物最后一击

召唤物造成最后一击时：

```text
占领者 = 召唤物所属玩家
```

---

## 4.5 中立伤害最后一击

如果中立单位、环境伤害、无归属灾害击破主城：

推荐规则：

```text
不触发占领。
主城变为中立废墟。
```

可选规则：

```text
最近10秒内对主城造成最高玩家伤害的一方获得占领权。
```

建议早期使用第一种，规则更清楚。

---

# 五、占领保护期规则

## 5.1 保护期基础规则

主城被占领后立即进入保护期。

```text
保护期时间：10秒
```

保护期内：

```text
占领核心不可被攻击
占领核心不可被技能选中
占领核心不可被重新占领
占领核心不可生产单位
占领核心不可建造融合建筑
占领核心不可研究科技
占领核心不可释放技能
```

保护期结束后：

```text
占领核心恢复可攻击
融合建筑菜单解锁
融合科技入口解锁
融合人口开始生效
```

---

## 5.2 保护期防止误判

保护期内敌人攻击占领核心时：

```text
攻击无效
弹出提示：占领保护中
攻击单位自动重新寻敌
```

技能选区覆盖占领核心时：

```text
伤害不作用于占领核心
但可以伤害周围单位
```

---

## 5.3 保护期UI

主城头顶显示：

```text
占领保护 10s
```

屏幕提示：

```text
你占领了敌方主城！
正在转化为：镇妖王庭
保护期：10秒
```

小地图：

```text
占领核心图标闪烁10秒
颜色变为占领方颜色
```

---

# 六、占领核心功能规则

## 6.1 占领核心基础面板

面板必须显示：

```text
占领方阵营
原主城阵营
融合路线名称
保护期/启用状态
融合建筑数量
融合人口数量
可建融合建筑
可研究融合科技
断供状态
```

示例：

```text
占领核心：镇妖王庭
占领方：华夏
原阵营：妖族
融合路线：镇妖骑军
状态：已启用
融合建筑：1 / 4
融合人口：5 / 24
```

---

## 6.2 融合建筑上限

每个占领核心默认：

```text
融合建筑上限：4
```

通用科技可提升：

```text
融合扩建 I：+2
融合扩建 II：+2
```

最终最大：

```text
8座
```

如果达到上限：

```text
建筑按钮灰显
提示：融合建筑数量已达上限
```

---

## 6.3 融合人口上限

融合单位除了普通人口，还占用融合人口。

默认：

```text
融合人口上限 = 当前总人口上限 × 20%
```

科技提升：

```text
融合人口 I：提升到28%
融合人口 II：提升到35%
```

UI显示：

```text
融合人口：12 / 24
```

如果融合人口不足：

```text
训练按钮灰显
提示：融合人口不足
```

---

## 6.4 占领核心供给范围

占领核心提供融合建筑供给。

规则：

```text
融合建筑必须建在占领核心供给范围内。
```

默认范围：

```text
18米
```

科技：

```text
占领扩域：供给范围 +20%
```

融合建筑离开供给，或核心被摧毁：

```text
进入断供状态
```

---

# 七、断供系统规则

## 7.1 断供触发

以下情况触发断供：

```text
占领核心被摧毁
融合建筑不在占领核心供给范围
占领核心被特殊技能封锁，科技可选
占领核心被敌人重新夺回，若后续加入夺回玩法
```

---

## 7.2 断供效果

断供中的融合建筑：

```text
停止生产单位
停止研究科技
建筑主动技能禁用
防御建筑攻速 -50%
建筑外观变暗
```

断供中的融合单位：

```text
已存在单位不会死亡
不能继续从该建筑补充
部分依赖核心供能的单位失去光环效果
```

---

## 7.3 断供倒计时

断供持续：

```text
60秒
```

60秒后：

```text
融合建筑变为废墟
```

通用科技：

```text
断供延迟：断供时间 +30秒
```

---

## 7.4 断供UI

融合建筑头顶显示：

```text
断供 42s
```

建筑面板显示：

```text
状态：断供
生产暂停
请恢复占领核心供给
```

小地图：

```text
断供建筑以灰色闪烁
```

# 八、定向融合路线功能需求

## 8.1 华夏占领妖族：镇妖骑军

### 核心表现

```text
妖族建筑被华夏符印和军旗覆盖。
兽骨、锁链、镇妖符、骑兵兽栏明显。
```

### 解锁建筑

```text
镇妖兽栏
符印校场
镇妖兵法阁
镇妖锁塔
```

### 解锁单位

```text
虎妖轻骑
麒麟骑兵
饕餮重骑
镇妖符骑
```

### 新功能需求

| 功能 | 说明 |
|---|---|
| 妖兽骑乘 | 妖兽不作为独立单位，而是作为华夏骑兵坐骑出现 |
| 镇妖符印 | 用于控制大型妖兽，提供减速/压制技能 |
| 冲锋路径 | 麒麟骑兵、虎妖轻骑需要冲锋路径判定 |
| 小型吞阵 | 饕餮重骑击杀小型单位回复生命 |
| 兽骑协同 | 靠近华夏普通士兵获得加成 |

### 表现需求

```text
骑兵身上有华夏甲胄和妖兽身体特征。
麒麟骑兵冲锋时地面有金色震波。
饕餮重骑攻击时出现吞噬血口特效。
镇妖符骑释放技能时出现红金符链。
```

---

## 8.2 妖族占领华夏：化形妖军

### 核心表现

```text
华夏主城被妖纹、血旗、兽骨侵蚀。
原本军营结构被妖化，但仍保留军阵痕迹。
```

### 解锁建筑

```text

血旗妖塔
```

### 解锁单位

```text
化形虎将
化形麒麟
化形饕餮
妖化军师
```

### 新功能需求

| 功能 | 说明 |
|---|---|
| 化形单位 | 妖兽变成人形/半人形精锐单位 |
| 妖化军阵 | 妖族单位获得类似军阵的区域增益 |
| 吞军化血 | 化形饕餮可吞噬小型敌人回复 |
| 阵法破坏 | 化形麒麟可降低敌方光环/阵法效果 |
| 血阵代价 | 妖化军师增益友军但消耗生命 |

### 表现需求

```text
化形单位保留妖兽角、爪、尾、鳞片。
化形麒麟释放技能时出现雷火和妖纹阵。
化形饕餮吞噬时出现黑红吞噬旋涡。
妖化军师释放血阵时地面出现妖血军旗。
```

# 十九、验收标准

## 19.1 占领判定验收

```text
主城由最后一击玩家立即占领。
持续伤害最后一击能正确归属。
召唤物最后一击能正确归属。
中立无归属伤害不会错误占领。
```

## 19.2 保护期验收

```text
占领后出现10秒保护期。
保护期内不可攻击占领核心。
保护期内不可建造融合建筑。
保护期内不可研究融合科技。
保护期倒计时正确显示。
保护期结束后功能解锁。
```

## 19.3 定向路线验收

```text
华夏占领妖族解锁镇妖骑军。
妖族占领华夏解锁化形妖军。
机械占领妖族解锁兽械改造厂。
妖族占领机械解锁血肉机巢。
A占B和B占A获得不同内容。
```

## 19.4 融合建筑验收

```text
融合建筑只能在占领核心供给范围内建造。
融合建筑数量上限生效。
断供后生产、科技和技能停止。
断供倒计时结束后建筑变废墟。
```

## 19.5 融合单位验收

```text
融合单位同时占用普通人口和融合人口。
融合人口不足时无法训练。
高级融合单位数量限制生效。
断供后已存在单位不消失。
单位Tips显示来源、克制和弱点。
```

## 19.6 表现验收

```text
主城被击破有明显破防表现。
占领保护罩清楚可见。
不同定向路线有不同转化表现。
融合单位模型能体现占领方主导和被占领方特征。
断供状态有明显灰暗/熄灭表现。
```

# 二十、最终硬规则

```text
1. 谁最后一下击破主城，谁立即占领。
2. 占领后固定10秒保护期。
3. 保护期内占领核心不可被攻击、不可建造、不可研究、不可生产。
4. 保护期结束后才解锁融合建筑和融合科技。
5. 占领结果必须是定向融合，A占B和B占A完全不同。
6. 占领后不能获得敌方完整阵营。
7. 每条定向融合路线必须有独立建筑、单位、科技和表现。
8. 融合建筑有数量上限。
9. 融合单位占用融合人口。
10. 占领核心提供融合建筑供给。
11. 占领核心被摧毁后融合建筑进入断供。
12. 断供不会删除已存在融合单位，但会阻止继续生产和研究。
13. UI必须明确显示占领方、原阵营、融合路线、保护期、融合建筑上限、融合人口和断供状态。
14. 所有定向融合单位必须有克制和弱点，不能成为无脑最优解。
```

# 二十一、一句话总结

```text
占领系统的核心是：最后一击直接占领主城，10秒保护后按“占领方主导 + 被占领方能力被吸收”解锁定向融合路线；华夏占妖族得到饕餮骑兵、麒麟骑兵，妖族占华夏得到化形饕餮、化形麒麟，并且每一种阵营互占都产生不同的新建筑、新单位、新科技和新表现。
```
