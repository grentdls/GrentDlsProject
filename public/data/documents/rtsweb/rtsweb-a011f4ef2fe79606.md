# 机械阵营完整方案 V1

## 一、阵营核心定位

机械阵营不是普通“科技兵种阵营”，而是：

```text
电力网络 + 模块改造 + 重型机械军团 + 多载具作战
```

机械阵营的核心体验：

```text
我先搭建电力网络，再用电力驱动建筑和单位，最后通过科技解锁各种改造模块，让同一批单位变成不同战术用途。
```

机械阵营关键词：

```text
电力
电路
模块
改造
载具
炮火
无人机
装甲
空军
舰队
能源过载
自动化
```

# 二、与其他阵营差异

| 阵营 | 建筑成长 | 单位成长 | 核心体验 |
|---|---|---|---|
| 华夏 | 建筑3级升级 | 单位升星 | 正规军制、科技解锁、兵种克制 |
| 妖族 | 建筑献祭圣祭 | 单位吞噬变异 | 极端功能、怪物成长、特殊地形 |
| 自然 | 建筑相邻共鸣 | 单位融合 | 五行摆阵、融合新生命 |
| 机械 | 建筑/单位模块改造 | 单位部件改造 | 电力网络、模块化装配、科技压制 |

机械阵营的强项：

```text
远程火力强
防御体系强
改造选择多
空军和重装单位强
后期科技压迫强
```

机械阵营的弱点：

```text
依赖电力网络
前期造价高
单位维修成本高
被断电后战力下降
改造选择错误会被克制
```

# 三、机械阵营基础资源

机械阵营同样使用四资源：

```text
木材
黄金
石料
金属
```

机械阵营资源倾向：

| 资源 | 用途 |
|---|---|
| 木材 | 基础建筑、线路支架、船厂、少量无人机结构 |
| 黄金 | 科技研究、单位制造、改造费用、技能激活 |
| 石料 | 基地建筑、防御工事、发电设施、地基 |
| 金属 | 机械单位、武器模块、装甲、飞机、舰船 |

机械阵营额外核心资源：

```text
电力
```

电力不是采集资源，而是由发电建筑产生、由电路网络传输、由建筑和单位消耗。

# 四、机械阵营核心规则

## 4.1 建筑无普通升级

机械建筑不使用 1/2/3 级升级。

机械建筑成长方式为：

```text
建筑改造槽
```

每个建筑最多拥有：

```text
2个改造槽
```

建筑通过科技树解锁更多改造模块。

## 4.2 单位无等级

机械单位不升星、不吞噬、不融合。

机械单位成长方式：

```text
部件改造
```

每个单位最多装备：

```text
2个改造部件
```

部分大型单位拥有：

```text
3个改造部件
```

但需要高级科技。

## 4.3 电力网络是阵营核心

机械建筑需要电力才能满效率运行。

单位也可以通过电力网络获得强化。

```text
有电：正常运行或强化运行
缺电：效率下降
断电：部分功能停止
过载：短时间增强但有风险
```

# 七、电力系统完整规则

## 7.1 电力基础概念

机械阵营拥有三个电力数值：

```text
电力产出
电力消耗
电力储备
```

UI 显示：

```text
电力：120 / 95
储能：300 / 500
```

含义：

```text
当前发电 120
当前消耗 95
电力充足
储能 300 / 500
```

## 7.2 发电建筑

### 基础发电站

功能：

```text
提供稳定电力
范围较小
容易被集火
```

电力：

```text
+50 电力
```

### 高级反应堆

科技解锁。

功能：

```text
高电力产出
被摧毁时爆炸
```

电力：

```text
+120 电力
```

### 移动发电车

由重装工厂生产。

功能：

```text
可移动供电
支援前线
提供小范围电力
```

电力：

```text
+30 电力
```

---

## 7.3 电力传输规则

电力必须通过电网传输。

电网来源：

```text
机械核心基地
发电站
高压电塔
电容中继站
移动发电车
机械堡垒车
空域母舰，后期科技
```

建筑必须处于电网范围内才能满效率运行。

### 电网连接判定

建筑满足以下条件之一，即接入电网：

```text
在机械核心基地供电范围内
在发电站供电范围内
在高压电塔连接范围内
在电容中继站范围内
在移动供电单位范围内
```

## 7.4 电线建设规则

机械阵营不需要工人一根根铺电线。

采用 RTS 更易用规则：

```text
建筑放置时，如果在电网范围内，自动接电。
如果不在电网范围内，需要先建高压电塔或移动发电车。
```

高压电塔相当于电网节点。

高压电塔连接规则：

```text
两个高压电塔之间距离不超过12米时自动连接。
连接线在地面显示为蓝白色电缆/能量线。
```

## 7.5 电力不足规则

### 电力充足

```text
产出 >= 消耗
所有建筑正常工作
单位可获得电网强化
```

### 电力紧张

```text
产出 < 消耗
但储能可补足
建筑正常运行
储能持续下降
```

### 电力不足

```text
产出 + 储能不足
进入缺电状态
```

缺电效果：

| 类型 | 效果 |
|---|---|
| 生产建筑 | 生产速度 -50% |
| 科研建筑 | 研究速度 -50% |
| 防御建筑 | 攻击速度 -35% |
| 雷达建筑 | 视野 -30%，主动技能禁用 |
| 改造车间 | 无法开始新改造 |
| 终局建筑 | 技能禁用 |

## 7.6 断电规则

某建筑完全离开电网时：

```text
进入断电状态
```

断电影响：

| 建筑 | 断电影响 |
|---|---|
| 机场 | 无法生产飞机，已在队列暂停 |
| 重装工厂 | 生产暂停 |
| 机动机械场 | 生产暂停 |
| 船厂 | 生产暂停 |
| 科研中心 | 研究暂停 |
| 防御炮台 | 无法攻击，少数机枪塔保留低效射击 |
| 雷达站 | 视野大幅降低，反隐失效 |
| 维修平台 | 维修速度 -80% |

## 7.7 电力过载规则

机械阵营可以手动启用：

```text
能源过载
```

能源过载效果：

```text
短时间强化建筑或单位
消耗大量储能
结束后进入过热状态
```

### 建筑过载

| 建筑 | 过载效果 | 过热代价 |
|---|---|---|
| 机场 | 飞机生产速度 +40% | 之后生产速度 -20%，持续20秒 |
| 重装工厂 | 重型单位生产速度 +30% | 电力消耗 +50%，持续30秒 |
| 防御炮台 | 攻速 +50% | 之后停火5秒 |
| 雷达站 | 揭示范围 +50% | 主动技能冷却 +30秒 |
| 改造车间 | 改造时间 -40% | 之后无法改造20秒 |

### 单位过载

单位需要处于电网范围或拥有电池模块。

| 单位类型 | 过载效果 | 过热代价 |
|---|---|---|
| 机械狗 | 移速 +35% | 结束后移速 -20% |
| 动力机甲 | 攻速 +25% | 结束后护甲 -1 |
| 坦克 | 炮击伤害 +20% | 结束后装填速度 -20% |
| 飞机 | 机动 +20% | 结束后无法使用技能5秒 |
| 舰船 | 射程 +0.5 | 结束后转向速度 -20% |

## 7.8 电路玩法和建筑组合

电路不是单纯“有电/没电”，还可以形成组合。

### 电力回路

如果一个区域内建筑通过至少两条路径连接到电源，形成：

```text
稳定回路
```

稳定回路效果：

```text
该区域建筑受到断电影响延迟5秒
防御炮台攻击速度 +5%
维修平台维修速度 +10%
```

### 高压链路

三个高压电塔直线连接，形成：

```text
高压链路
```

效果：

```text
链路范围内防御建筑攻击 +8%
但高压电塔被摧毁时会造成小范围电击爆炸
```

### 工业核心区

重装工厂、改造车间、维修平台、电容中继站相互连接时形成：

```text
工业核心区
```

效果：

```text
重装单位生产速度 +8%
改造时间 -8%
维修速度 +12%
```

### 空军指挥网

机场、雷达站、高压电塔形成连接时：

```text
空军指挥网
```

效果：

```text
飞机出击速度 +10%
侦察机视野 +2
歼击机锁定速度 +15%
```

### 海军电控港

船厂、雷达站、电容中继站连接时：

```text
海军电控港
```

效果：

```text
舰船生产速度 +8%
潜艇潜航时间 +10%
航空母舰无人机补充速度 +10%
```

# 八、改造系统完整规则

## 8.1 改造类型

机械改造分为：

```text
建筑改造
单位改造
武器改造
防御改造
机动改造
能源改造
AI控制改造
特殊形态改造
```

## 8.2 改造槽规则

普通建筑：

```text
最多2个改造槽
```

普通单位：

```text
最多2个改造槽
```

大型单位：

```text
默认2个
科技后最多3个
```

## 8.3 改造互斥规则

同类改造不能重复装。

例如：

```text
坦克不能同时装“重炮模块”和“速射炮模块”
飞机不能同时装“高爆炸弹”和“穿甲导弹”
建筑不能同时装“飞行部件”和“地下锚定部件”
```

## 8.4 改造操作流程

```text
选择单位或建筑
点击【改造】
打开改造列表
选择一个空槽
选择可用模块
确认消耗资源
进入改造时间
完成后模块生效
```

改造期间：

```text
单位无法战斗或移动，除非是战地快速改造科技
建筑可继续低效率工作
```

## 8.5 改造拆卸规则

默认：

```text
改造不可免费拆卸
```

可通过科技解锁：

```text
模块回收
```

效果：

```text
拆卸返还40%资源
```

# 十一、生产建筑与单位设计

# 11.1 机场

## 职责

机场只生产飞机和大型空中机械。

不研究科技。

不生产地面单位。

## 可生产单位

| 单位 | 定位 | 解锁 |
|---|---|---|
| 侦察机 | 高速侦察、标记目标 | 默认 |
| 轰炸机 | 对地范围轰炸、反建筑 | 轰炸协议 |
| 歼击机 | 反空、拦截轰炸机 | 空战AI |
| 电子干扰机 | 干扰雷达、防空、技能 | 电子战科技 |
| 空域母舰 | 后期空中平台、释放无人机 | 空域平台技术 |

## 机场专属功能

# 三十二、最终硬规则

```text
1. 机械阵营建筑不升级，使用改造槽成长。
2. 机械单位不升级，使用部件改造成长。
3. 每个建筑只负责一条清晰生产线。
4. 机场只生产飞机。
5. 重装工厂只生产重型陆地机械。
6. 机动机械场只生产机动机械和机甲。
7. 船厂只生产水上机械。
8. 科研中心只研究科技，不生产普通单位。
9. 改造车间只负责单位/建筑改造。
10. 电力是机械阵营核心玩法。
11. 建筑需要接入电网才能满效率运行。
12. 高压电塔负责拓展电网。
13. 电容中继站负责储能和稳定供电。
14. 电力不足会降低建筑效率。
15. 断电会暂停关键建筑功能。
16. 过载可以短时间强化，但会产生过热代价。
17. 电路组合可以形成稳定回路、高压链路、工业核心区、空军指挥网、海军电控港。
18. 单位改造最多2个槽，大型单位科技后可3个槽。
19. 改造模块必须有收益和代价。
20. 科技树除了解锁单位，还要解锁改造模块、电路玩法、AI控制和过载能力。
```
