# 妖族阵营完整重构设计方案 V3

## 一、版本目标

V3 重点解决 V2 的问题：

```text
1. 建筑线更专一。
2. 单位不再只是名字多，而是每个都有清晰克制和用途。
3. 流派能闭环，不同建筑线可以组成战术体系。
4. 科技树不再只是加数值，而是改变玩法和克制方向。
5. 献祭和吞噬分工明确，不互相抢玩法。
6. 采集体系彻底改为采集妖兽驱动，不再靠资源建筑。
7. 虫类、飞兽、水妖、凶兽都有特殊地形和操作价值。
```

妖族最终体验：

```text
建筑靠献祭变成圣祭形态；
单位靠吞噬成长和变异；
兵种靠特殊功能和极端克制打出差异；
玩家通过选择巢穴和科技流派决定妖族路线。
```

# 二、妖族核心定位

妖族不是正规军，也不是机械模块化军队。

妖族是：

```text
野性生物军团 + 献祭巢穴 + 吞噬成长 + 极端功能兵种
```

## 2.1 阵营关键词

```text
虫海
自爆
巨兽
吞噬
献祭
潜伏
攀爬
水下
空袭
变异
兽潮
```

## 2.2 与其他阵营差异

| 阵营 | 建筑成长 | 单位成长 | 核心体验 |
|---|---|---|---|
| 华夏 | 建筑升级 | 士兵升星 | 正规军制、科技解锁、兵种克制 |
| 妖族 | 建筑献祭圣祭 | 单位吞噬变异 | 野性成长、极端功能、怪物压迫 |
| 机械 | 建筑/单位改造 | 部件改造 | 模块化、科技装配、电力系统 |
| 自然 | 建筑相邻共鸣 | 单位融合 | 五行摆阵、融合新生命 |

# 三、资源与经济规则

妖族使用四资源：

```text
木材
黄金
石料
金属
```

但妖族没有传统资源增益建筑。

```text
没有伐木场
没有采石场
没有金矿营
没有冶铁坊
```

妖族经济完全由采集妖怪承担。

```text
温兽巢生产采集妖怪。
不同采集妖怪专门采集不同资源。
玩家想提高某种资源，就生产对应采集妖怪。
```

## 3.1 资源用途

| 资源 | 妖族用途 |
|---|---|
| 木材 | 巢穴、虫类、飞兽、基础建筑 |
| 黄金 | 科技、特殊妖兽、献祭仪式、英雄/高级单位 |
| 石料 | 防御建筑、主城、祭坛、巨兽建筑 |
| 金属 | 重装妖兽、骨甲单位、高级飞兽、水妖、终局单位 |

## 3.2 妖族经济特点

```text
前期依赖苦役小妖快速铺经济。
中期通过专精采集妖怪拉开资源方向。
后期需要保护高价值采集妖怪。
经济单位本身也能被献祭，但献祭后会损失经济能力。
```

# 四、建筑系统总规则

## 4.1 建筑无等级

妖族建筑没有 1/2/3 级升级。

所有建筑只有两个形态：

```text
蛮荒形态
圣祭形态
```

## 4.2 蛮荒形态

蛮荒形态是建筑初始状态。

特点：

```text
功能基础
可以接受献祭
可生产基础单位/研究基础科技
外观粗糙、兽骨、血肉、藤蔓、巢穴感强
```

## 4.3 圣祭形态

建筑献祭值满后进入圣祭形态。

特点：

```text
不能继续献祭
功能强化
解锁高级单位或高级科技
获得圣祭专精效果
模型明显变化
```

## 4.4 建筑献祭规则

献祭由单位发起。

单位操作：

```text
选择单位 → 点击【献祭】 → 点击可献祭建筑 → 单位走到建筑 → 被吞入建筑 → 建筑获得献祭值
```

不可献祭：

```text
英雄单位
Boss单位
剧情单位
召唤幻象
已经被吞噬锁定的单位
正在运输中的单位
```

## 4.5 圣祭方向选择规则

V3 不再完全依赖“最高献祭倾向自动决定”，而是改成更好控的方式：

```text
献祭值满后，建筑弹出圣祭选择。
可选择的圣祭方向由献祭过的单位类型决定。
献祭越集中，某个方向效果越强。
```

例如虫巢献祭值满后：

```text
如果献祭虫类多：可选【虫海圣祭】
如果献祭自爆虫多：可选【爆浆圣祭】
如果献祭潜伏单位多：可选【潜伏圣祭】
```

这样玩家更可控。

## 4.6 圣祭强度

圣祭方向有三档强度：

| 献祭倾向占比 | 圣祭强度 |
|---|---|
| 低于40% | 普通圣祭 |
| 40%~69% | 强化圣祭 |
| 70%以上 | 纯血圣祭 |

示例：

```text
虫巢献祭值满。
爆浆虫贡献占比 75%。
选择爆浆圣祭时触发“纯血爆浆圣祭”。
爆炸范围和爆炸伤害额外提高。
```


# 二十三、最终硬规则

```text
1. 妖族建筑没有等级，只有蛮荒和圣祭。
2. 妖族建筑功能必须专一，一个建筑只负责一个体系。
3. 温兽巢只生产采集妖怪，不提供资源BUFF。
4. 虫巢只生产虫类，虫类可攀爬悬崖但不能进河。
5. 凶兽巢只生产地面猛兽，分重装、猛攻、迅捷三路线。
6. 飞兽巢只生产飞行妖兽。
7. 水巢只生产潜水、两栖、巨型水妖。
8. 妖血池只负责吞噬科技。
9. 进化祭坑只负责高级进化。
10. 腐肉池只负责后勤、尸体回收、回血。
11. 建筑献祭用于建筑成长。
12. 单位吞噬用于单位成长。
13. 献祭和吞噬必须在 UI 和功能上完全区分。
14. 科技树必须按流派组织，而不是按简单数值强化。
15. 每个单位必须写清克制和被克制。
16. 每个流派必须有优势和弱点。
17. 妖族核心体验是极端功能性和特殊地形能力。
```
