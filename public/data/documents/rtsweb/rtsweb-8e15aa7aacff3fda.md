# 自然阵营：建筑、单位、融合、科技树与数值完整方案

## 一、阵营核心定位

自然阵营不是单纯“召唤元素怪物”，而是：

```text
五行元素建筑 + 地形适应 + 元素克制 + 单位融合 + 共鸣科技
```

自然阵营核心体验：

```text
玩家根据地图环境选择元素建筑，生产对应元素单位；
通过五行克制打针对；
通过单位融合创造新单位；
通过元素科技强化某一条路线或组合路线。
```

自然阵营关键词：

```text
水、火、土、金、木
地形强化
元素克制
元素融合
共鸣
纯属性进化
双属性变异
自然领域
```

---

# 二、自然阵营核心规则

## 2.1 建筑专一化规则

每个元素建筑只负责一个元素体系。

| 建筑 | 单一职责 |
|---|---|
| 自然圣心 | 主城、基础工灵、元素融合入口 |
| 水元素建筑 | 只生产水系单位 |
| 火元素建筑 | 只生产火系单位 |
| 土元素建筑 | 只生产土系单位 |
| 金元素建筑 | 只生产金系单位 |
| 木元素建筑 | 只生产木系单位 |
| 元素融合坛 | 专门进行单位融合 |
| 元素研习所 | 科技树研究 |
| 灵泉之环 | 治疗/回复/净化 |
| 根须守卫 | 基础防御 |
| 天象祭台 | 终局自然天气与大范围元素技能 |

建筑设计原则：

```text
生产建筑只生产单位。
科技建筑只研究科技。
融合建筑只负责融合。
治疗建筑只负责治疗和净化。
防御建筑只负责防守。
```

---

## 2.2 单位成长规则

自然单位没有等级、没有升星、没有吞噬、没有机械改造。

自然单位成长方式：

```text
元素融合
```

单位可以进行：

```text
纯属性融合
双属性融合
高级三段融合，科技解锁
```

---

## 2.3 五行克制规则

自然阵营内部和跨阵营都使用五行克制。

推荐克制关系：

```text
水克火
火克木
木克土
土克水
金克木
火克金
土抗金
水缓金
木缠水
```

为了玩法清楚，采用主克制链：

| 元素 | 强克制 | 被克制 |
|---|---|---|
| 水 | 火 | 土、木缠绕 |
| 火 | 木、金 | 水 |
| 土 | 水、冲锋单位 | 木、穿甲金 |
| 金 | 木、重甲、建筑 | 火 |
| 木 | 土、远程阵地 | 火、金 |

克制加成基础值：

```text
攻击克制目标：伤害 +25%
被克制攻击：受到伤害 +20%
强克制科技后：伤害额外 +10%
```

---

## 2.4 地形强化规则

自然单位受地形影响明显。

| 地形 | 强化元素 |
|---|---|
| 水面/河流/湖泊 | 水系 |
| 火焰地表/熔岩/燃烧区域 | 火系 |
| 山地/岩地/高坡 | 土系 |
| 矿脉/金属地表/遗迹 | 金系 |
| 森林/草地/藤蔓地表 | 木系 |

每个元素单位在自身优势地形上获得强化。

# 三、水系核心特殊规则

## 3.1 水元素建筑建造规则

水元素建筑只能建在水面或水岸特殊点。

建筑名称：

```text
水灵源池
```

建造条件：

```text
必须放置在水面、浅水、湖泊、河流或水岸节点。
不能建在纯陆地。
```

放置表现：

```text
水面出现蓝色圆形建造范围。
可建造区域高亮。
不可建造陆地显示红色。
```

## 3.2 水系单位移动规则

水系单位分为：

```text
水行单位
冰行单位
雨行单位
```

共同规则：

```text
水系单位可以在水面移动。
其他元素单位默认不能在水面移动。
部分融合单位可获得两栖能力。
```

## 3.3 水系单位水面强化

水系单位在水面获得大幅强化。

水面状态：

| 属性 | 加成 |
|---|---:|
| 攻击 | +25% |
| 移速 | +30% |
| 受到伤害 | -20% |
| 每秒回血 | 最大生命 1.5%/s |
| 技能冷却 | -15% |

陆地状态惩罚：

| 属性 | 惩罚 |
|---|---:|
| 攻击 | -25% |
| 移速 | -35% |
| 技能冷却 | +20% |
| 每秒回血 | 无 |

说明：

```text
水系单位是水域霸主，但上岸明显变弱。
```

# 十、元素融合系统

## 10.1 融合入口

融合由元素融合坛执行。

操作流程：

```text
选择单位A
点击【融合】
选择单位B
进入融合坛
消耗资源
等待融合时间
生成融合单位
```

融合后：

```text
原两个单位消失
生成一个新单位
新单位继承两种元素特性
人口一般小于两者总和，但强度更高
```

---

## 10.2 融合类型

| 类型 | 规则 |
|---|---|
| 纯属性融合 | 同元素 + 同元素，强化原路线 |
| 双属性融合 | 两种不同元素，生成新单位 |
| 高级融合 | 融合单位再融合，科技解锁 |
| 反应融合 | 克制元素融合，获得不稳定但强力单位 |

---

## 10.3 融合通用规则

| 项目 | 规则 |
|---|---|
| 融合时间 | 20~60秒，根据单位强度 |
| 融合消耗 | 黄金 + 对应元素主资源 |
| 是否可取消 | 可取消，返还50%资源，原单位不返还 |
| 是否可逆 | 不可逆 |
| 是否继承Buff | 不继承临时Buff |
| 是否继承技能 | 继承核心元素特性，生成新技能 |

# 二十八、最终硬规则

```text
1. 自然阵营建筑必须专一化。
2. 水灵源池只能建在水面或水岸。
3. 水系单位在水面大幅强化，在陆地明显削弱。
4. 其他元素单位默认不能在水面移动。
5. 五元素单位必须有明确克制关系。
6. 水克火，火克木和金，木克土，土克水，金克木和重甲。
7. 单位成长依赖融合，不使用升星、吞噬、机械改造。
8. 融合单位必须产生新技能和新定位，不只是属性相加。
9. 同元素融合产生纯属性高级单位。
10. 双元素融合产生新功能单位。
11. 高级科技解锁三段融合。
12. 每个融合单位必须有克制目标和弱点。
13. 科技树必须强化元素定位、地形优势、克制方向和融合玩法。
14. UI必须显示当前元素、地形状态、克制关系和可融合结果。
15. 美术上每个元素和融合单位必须有清晰辨识度。
```
