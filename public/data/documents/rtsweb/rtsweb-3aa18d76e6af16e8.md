# 建筑选中后的科技树页面 UI 详细规则文档

## 一、设计目标

当玩家点击拥有科技树功能的建筑后，才显示科技树页面。该页面用于快速查看、研究科技，并通过悬停 / 长按查看科技详情。

设计目标：

```text
1. 科技树页面不能全屏，避免遮挡战场视野。
2. 页面大小与造兵页面接近。
3. 科技卡显示科技图片。
4. 科技图片下方显示资源消耗：ICON + 数字。
5. 鼠标悬停 / 手机长按科技卡显示科技详情页。
6. 科技列表横向排布，可横向拖动。
7. 科技需要清楚显示：已研究、可研究、研究中、未解锁、资源不足、互斥。
8. 科技树可以按分类切换，避免所有科技挤在一起。
9. 如果建筑正在研究科技，需要显示研究进度。
10. PC 和手机都要保证可视性、操控性、低误触。
```

最终体验：

```text
玩家点击科研建筑 / 科技建筑 / 改造研究建筑后，
右侧或底部弹出科技树面板，
科技以横向卡片形式展示，
每张卡显示科技图 + 名称 + 消耗，
点击可研究科技开始研究，
悬停 / 长按显示完整科技详情，
面板不遮挡主要战斗视野。
```

# 二、科技树页面出现条件

## 2.1 哪些建筑会显示科技树页面

建筑满足以下条件时，选中后显示科技树页面：

```text
建筑拥有科技树功能
建筑已建造完成
建筑未被摧毁
建筑未被占领为不可控状态
当前玩家拥有控制权
当前阵营允许研究科技
当前游戏模式允许科技研究
```

示例建筑：

| 阵营 | 科技建筑 |
|---|---|
| 华夏 | 玄机观、演武台、神机工坊、兵法阁 |
| 妖族 | 妖魂兵法窟、妖血池、进化祭坑、圣祭巢核 |
| 机械 | 科研中心、改造车间、雷达站、AI控制中心 |
| 自然 | 元素研习所、元素融合坛、天象祭台 |
| 融合阵营 | 镇妖兵法阁、化形兽坛、灵能研究塔、血肉改造槽 |

## 2.2 建筑无科技功能

如果建筑没有科技功能：

```text
不显示科技树页面。
显示普通建筑信息面板和建筑操作按钮。
```

例如：

```text
纯生产建筑
纯防御建筑
纯资源建筑
纯治疗建筑
纯电力建筑
```

## 2.3 建筑有多个功能

如果建筑同时拥有：

```text
造兵
科技
升级
改造
技能
```

推荐使用页签切换：

```text
[造兵] [科技] [改造] [升级]
```

显示优先级：

```text
如果建筑主要功能是造兵 → 默认打开造兵页。
如果建筑主要功能是科研 → 默认打开科技页。
如果玩家上次在该建筑打开过科技页 → 记住上次页签。
```

# 三、科技树页面整体布局

## 3.1 面板大小

科技树页面不允许全屏。推荐与造兵页面保持接近尺寸。

### 手机端

| 项目 | 建议 |
|---|---:|
| 面板宽度 | 屏幕宽度 88% |
| 面板高度 | 245~300 px |
| 分类栏高度 | 36~42 px |
| 科技列表高度 | 145~170 px |
| 研究进度栏高度 | 56~72 px |
| 科技卡宽度 | 92~108 px |
| 科技卡高度 | 130~150 px |
| 科技图片 | 72~82 px |

### PC端

| 项目 | 建议 |
|---|---:|
| 面板宽度 | 760~1040 px |
| 面板高度 | 250~310 px |
| 分类栏高度 | 34~40 px |
| 科技列表高度 | 150~175 px |
| 研究进度栏高度 | 60~78 px |
| 科技卡宽度 | 104~120 px |
| 科技卡高度 | 138~156 px |
| 科技图片 | 78~88 px |
| 一屏显示数量 | 5~8 个 |

## 3.2 手机端布局

推荐显示在屏幕底部偏右或右下信息面板上方。

结构：

```text
┌──────────────────────────────┐
│ 科技分类栏                    │
│ 全部 军事 经济 防御 特殊       │
├──────────────────────────────┤
│ 科技横向列表                  │
│ [科技卡][科技卡][科技卡] →拖动 │
├──────────────────────────────┤
│ 当前研究 / 研究队列            │
│ [研究中科技] 进度条  剩余时间  │
└──────────────────────────────┘
```

## 3.3 PC端布局

推荐显示在屏幕底部中间或建筑信息面板上方。

结构：

```text
┌────────────────────────────────────────┐
│ 分类：全部 军事 经济 防御 建筑 特殊      │
├────────────────────────────────────────┤
│ ← [科技卡][科技卡][科技卡][科技卡] →     │
├────────────────────────────────────────┤
│ 当前研究：[科技图标] 研究中 62%  18s     │
└────────────────────────────────────────┘
```

## 3.4 面板层级

科技树页面层级：

```text
低于战斗警告
低于任务弹窗
高于建筑信息底板
高于战场HUD
不遮挡顶部资源栏
不遮挡右上小地图
```

# 四、页面展开与隐藏

## 4.1 展开规则

点击拥有科技树功能的建筑后：

```text
建筑信息面板打开
科技树页面从底部或右侧滑出
默认显示该建筑可研究科技
如果正在研究科技，底部显示研究进度
```

推荐动效：

```text
0.18秒滑入
透明度 0 → 100%
缩放 96% → 100%
```

## 4.2 隐藏规则

以下情况隐藏科技树页面：

```text
取消选择建筑
选中其他非科技建筑
打开全屏UI
建筑被摧毁
建筑失去控制权
建筑进入断供废墟状态
玩家按返回键
手机系统返回键
```

## 4.3 返回键规则

手机端：

```text
按系统返回键：
如果科技详情页打开 → 关闭详情页
如果科技确认弹窗打开 → 关闭确认弹窗
如果科技树页面打开 → 关闭科技树页面
如果没有打开UI → 不处理或打开暂停菜单
```

PC端：

```text
ESC：
优先关闭详情卡
再关闭确认弹窗
再关闭科技树页面
```

# 五、科技分类栏设计

## 5.1 分类目的

科技数量较多时，必须通过分类减少阅读压力。

分类栏用于：

```text
快速定位科技方向
区分经济、战斗、防御、阵营特色
避免科技卡横向列表过长
```

## 5.2 基础分类

推荐基础分类：

```text
全部科技
军事科技
经济科技
建筑科技
防御科技
阵营科技
特殊科技
```

手机端简写：

```text
全部
军事
经济
建筑
防御
阵营
特殊
```

## 5.3 分类定义

### 全部科技

显示当前建筑可研究的全部科技。

```text
已解锁科技
未解锁但可预览科技
已研究科技
正在研究科技
```

### 军事科技

强化单位、解锁兵种、改变兵种玩法的科技。

包括：

```text
单位攻击强化
单位护甲强化
兵种解锁
技能解锁
克制强化
特殊箭矢
阵型训练
单位被动
```

示例：

```text
火箭矢
毒箭矢
穿甲箭矢
盾墙训练
迅捷步伐
麒麟军阵
```

### 经济科技

提升资源、生产、采集、建造效率的科技。

包括：

```text
采集速度
运输容量
建造速度
资源储量
生产效率
维修效率
自然回复
妖族献祭效率
机械电力效率
```

示例：

```text
伐木效率
矿石精炼
快速建造
维修AI
电力传输优化
温兽采集本能
```

### 建筑科技

强化建筑功能、解锁建筑、升级建筑相关科技。

包括：

```text
建筑解锁
建筑生命强化
建筑功能解锁
建筑升级强化
建造范围扩展
供给范围扩展
```

示例：

```text
高级兵营图纸
城防加固
主城扩建
融合扩建
占领核心加固
```

### 防御科技

防御塔、城墙、反空、反隐、反潜、陷阱相关科技。

包括：

```text
防御塔攻击
防御塔射程
反空强化
反隐强化
陷阱科技
护盾科技
城墙强化
```

示例：

```text
破云弩强化
镇霄灵光
导弹塔锁定
根须守卫元素化
雷达反隐脉冲
```

### 阵营科技

|---|---|
| 华夏 | 星级、军阵、兵法、建筑升级解锁 |

| 自然 | 元素、地形、融合、天象、五行克制 |
| 融合阵营 | 占领核心、融合人口、定向融合单位 |

终局、唯一、互斥、战役专属、融合路线专属科技。

包括：

```text
终局科技
奇观科技
占领科技
融合科技
唯一单位解锁
```

# 六、科技卡片设计

## 6.1 科技卡片基础结构

每张科技卡显示：

```text
科技图片
科技名称
资源消耗
研究时间
状态标记
```

推荐结构：

```text
┌──────────────┐
│   科技图片    │
│              │
├──────────────┤
│ 科技名称      │
│ 🪵120 🪙300   │
│ ⏱45s         │
└──────────────┘
```

## 6.2 科技图片

科技图片要求：

```text
使用科技专属图标
图标必须能看出科技方向
背景透明
主体居中
不要使用过细复杂图案
```

图标方向：

| 科技类型 | 图标建议 |
|---|---|
| 攻击强化 | 武器、箭矢、火焰 |
| 防御强化 | 盾牌、城墙、护甲 |
| 经济强化 | 资源、工具、齿轮 |
| 建筑解锁 | 建筑剪影、图纸 |
| 阵营科技 | 阵营符号 |
| 互斥科技 | 双向箭头或锁 |
| 终局科技 | 发光核心、大型符号 |

尺寸：

| 平台 | 图片尺寸 |
|---|---:|
| 手机 | 72~82 px |
| PC | 78~88 px |

## 6.3 科技名称

显示规则：

```text
最多 5 个汉字
超过则缩略
完整名进入详情页
```

示例：

```text
火箭矢
穿甲箭
电路优化
五行轮转
饕餮重鞍
```

字体：

```text
12~14号
加粗
居中
```

## 6.4 科技消耗

科技卡下方显示研究消耗。

格式：

```text
ICON + 数字
```

最多显示：

```text
3种资源 + 研究时间
```

如果资源超过 4 项：

```text
显示主要3项 + 研究时间
完整消耗进入详情页
```

示例：

```text
🪵120  🪙300
⚙80   ⏱45
```

## 6.5 研究时间

研究时间显示在卡片右下角：

```text
⏱45s
```

如果科技已研究：

```text
显示“已完成”
```

如果正在研究：

```text
显示“研究中”
```

# 七、科技卡片状态表现

## 7.1 状态类型

| 状态 | 表现 |
|---|---|
| 可研究 | 正常亮度，阵营色描边 |
| 资源不足 | 缺少资源数字红色，卡片轻微变暗 |
| 条件不足 | 灰色遮罩，锁图标 |
| 正在研究 | 卡片边框流光，显示进度角标 |
| 已研究 | 卡片显示完成勾，颜色略淡 |
| 互斥锁定 | 红橙互斥锁，显示“互斥” |
| 建筑断电 | 蓝色电力警告 |
| 建筑断供 | 灰色断供标记 |
| 科技队列满 | 显示“队列满” |
| 新解锁 | 右上角“新”角标 |
| 推荐研究 | 柔和脉冲描边 |

## 7.2 可研究状态

可研究科技：

```text
科技图标正常亮度
阵营色细边框
点击可开始研究
```

## 7.3 资源不足状态

资源不足时：

```text
对应资源数字变红
卡片亮度降低到70%
点击不开始研究
弹出缺少资源提示
```

## 7.4 条件不足状态

条件不足时：

```text
卡片灰色遮罩
左上角锁图标
名称可读
底部显示最关键缺失条件
```

点击后：

```text
打开科技详情页
条件区自动高亮
```

## 7.5 正在研究状态

正在研究的科技卡：

```text
边框显示流动光效
右上角显示“研究中”
图片底部显示小进度条
```

如果该建筑同一时间只能研究一个科技：

```text
其他可研究科技按钮保持可见，但点击提示“已有科技研究中”
```

## 7.6 已研究状态

已研究科技：

```text
卡片显示完成勾
底部显示“已完成”
卡片亮度 80%
不可重复点击
可查看详情
```

## 7.7 互斥科技状态

如果科技与已研究科技互斥：

```text
卡片显示红橙互斥锁
底部显示“互斥”
详情页显示与哪个科技互斥
```

示例：

```text
火箭矢已研究
毒箭矢、穿甲箭矢显示互斥锁
```

## 7.8 推荐研究状态

系统可根据局势推荐科技。

推荐条件示例：

```text
敌方空军多 → 推荐防空科技
敌方重甲多 → 推荐穿甲科技
资源采集慢 → 推荐经济科技
机械缺电 → 推荐电力科技
自然阵营对火系敌人 → 推荐水克火科技
```

推荐表现：

```text
柔和呼吸边框
右上角显示“荐”
```

# 八、横向拖动列表规则

## 8.1 横向排布

科技卡横向排列：

```text
[科技卡][科技卡][科技卡][科技卡] →
```

列表可拖动。

## 8.2 手机端拖动

手机端：

```text
手指左右滑动 → 横向滚动
移动超过12px → 判定为拖动
拖动中不触发点击
快速滑动 → 惯性滚动
长按0.35秒 → 显示详情页
长按后移动超过20px → 关闭详情并进入拖动
```

防误触优先级：

```text
拖动 > 长按 > 点击
```

## 8.3 PC端拖动

PC端支持：

```text
鼠标滚轮横向滚动
Shift + 滚轮快速滚动
鼠标拖拽列表滚动
左右箭头按钮翻页
鼠标悬停科技卡显示详情
```

推荐：

```text
鼠标在科技列表上时，滚轮控制科技列表。
鼠标离开科技列表时，滚轮恢复默认镜头缩放。
```

## 8.4 边缘提示

如果还能向右滚：

```text
右侧显示渐隐遮罩
```

如果还能向左滚：

```text
左侧显示渐隐遮罩
```

底部可显示细进度条：

```text
━━━━━━━──
```

# 九、点击科技卡后的研究规则

## 9.1 点击可研究科技

点击可研究科技：

```text
扣除资源
开始研究
科技卡进入研究中状态
底部研究栏显示该科技
播放研究开始音效
```

## 9.2 是否需要确认

普通科技：

```text
点击直接研究
```

高风险 / 高成本 / 互斥科技：

```text
点击后弹出确认详情页
```

必须确认的科技：

```text
互斥科技
终局科技
高成本科技
路线选择科技
不可逆科技
影响全局路线的科技
```

确认弹窗显示：

```text
研究消耗
研究收益
```

## 17.1 互斥科技

互斥科技必须做到：

```text
研究前明确提示。
研究后锁定其他互斥科技。
详情页显示互斥对象。
科技卡显示互斥锁。
```

示例：

```text
火箭矢、毒箭矢、穿甲箭矢互斥。
研究其中一个后，其他两个显示互斥锁。
```

## 17.2 可开关科技

部分科技解锁的是可切换模式。

例如：

```text
火箭矢模式
毒箭矢模式
机械AI控制
元素核心切换
```

科技详情页需要显示：

```text
该科技解锁一个可切换按钮。
同一时间只能启用一种模式。
```

## 17.3 路线科技

部分科技会决定路线。

例如：

```text
妖族圣祭方向
机械AI流派
自然天象方向
融合阵营终局路线
```

这类科技必须确认：

```text
这是路线科技，研究后会影响后续解锁。
```

## 17.4 建筑断电影响科技

机械或融合建筑断电/断供时：

```text
研究暂停
进度保留
科技卡显示暂停原因
```

不能直接清空进度。

```text

11. 正在研究科技必须显示进度和剩余时间。
12. 已研究、研究中、未解锁、资源不足、互斥状态必须清楚区分。
13. 科技分类至少包含：全部、军事、经济、建筑、防御、阵营、特殊。
14. 详情页只放复杂信息，科技卡保持简洁。
15. 不同阵营科技页必须有不同主题边框和进度色。
```

# 二十二、一句话总结

```text
科技树页面不是全屏科技树，而是建筑选中后的轻量研究面板：科技图 + 名称 + 消耗用于快速选择，横向列表用于低遮挡浏览，研究栏显示进度，悬停/长按详情页解释完整效果，让玩家在不离开战场视野的情况下完成科技决策。
```
