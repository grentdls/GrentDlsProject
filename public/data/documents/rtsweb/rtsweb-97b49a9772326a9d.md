# 二、机械阵营新增系统总览

机械阵营新增系统分为 8 大类。

| 系统 | 核心作用 | 关联建筑/单位 |
|---|---|---|
| 电力系统 | 控制建筑运行效率 | 发电站、高压电塔、电容中继站、核心基地 |
| 电路系统 | 管理供电范围、回路、链路 | 高压电塔、电容中继站、生产建筑 |
| 过载系统 | 短时间强化建筑/单位 | 电力建筑、生产建筑、防御塔、单位 |
| 维修系统 | 维修单位、飞机、舰船、建筑 | 维修平台、机器工人、维修无人蜂 |
| 雷达系统 | 侦察、反隐、反潜、目标锁定 | 雷达站、侦察机、防御塔、导弹单位 |
| AI控制系统 | 自动优先级、返航、维修、编队 | 科研中心科技、所有机械单位 |
| 改造系统 | 给单位/建筑安装模块 | 改造车间、生产建筑、机械单位 |
| 载具平台系统 | 飞机、潜艇、母舰等特殊单位规则 | 机场、船厂、空域母舰、航空母舰 |

# 三、电力系统实现规则

## 3.1 电力基础数值

机械阵营拥有 3 个电力数值：

```text
电力产出
电力消耗
储能容量
```

顶部UI显示：

```text
电力：120 / 95
储能：300 / 500
```

含义：

```text
当前总发电量：120
当前总消耗量：95
当前储能：300
最大储能：500
```

---

## 3.2 电力状态

| 状态 | 判定 | 效果 |
|---|---|---|
| 电力充足 | 产出 >= 消耗 | 所有建筑满效率运行 |
| 电力紧张 | 产出 < 消耗，但储能 > 0 | 储能持续下降，建筑暂时正常运行 |
| 电力不足 | 产出 + 储能不足以满足消耗 | 部分建筑降效 |
| 局部断电 | 建筑不在电网范围内 | 建筑功能暂停或低效 |
| 过载状态 | 玩家主动开启 | 短时间强化，之后过热 |

---

## 3.3 电力消耗类型

建筑有 3 种消耗类型。

| 类型 | 说明 | 示例 |
|---|---|---|
| 常驻消耗 | 建筑存在即消耗 | 科研中心、雷达站 |
| 工作消耗 | 工作时才消耗 | 生产建筑、维修平台 |
| 技能消耗 | 释放技能时消耗储能 | 雷达扫描、过载、防御塔集火 |

---

## 3.4 建筑电力消耗建议

| 建筑 | 常驻消耗 | 工作消耗 |
|---|---:|---:|
| 机械核心基地 | 10 | 10 |
| 科研中心 | 20 | 20 |
| 机场 | 25 | 30 |
| 重装工厂 | 30 | 35 |
| 机动机械场 | 20 | 20 |
| 船厂 | 25 | 35 |
| 改造车间 | 20 | 40 |
| 雷达站 | 25 | 30 |
| 维修平台 | 15 | 35 |
| 防御炮台 | 10 | 20 |
| 高级反应堆 | -120 | 0 |
| 发电站 | -50 | 0 |

负数表示发电。

---

## 3.5 电力不足时的建筑优先级

当电力不足时，系统按优先级供电。

默认优先级：

```text
1. 机械核心基地
2. 发电站/电容中继站
3. 防御建筑
4. 雷达站
5. 生产建筑
6. 科研中心
7. 改造车间
8. 维修平台
```

玩家可以在电力面板调整优先级。

### 电力优先级按钮

每个耗电建筑面板增加：

```text
[供电优先级]
```

可选：

```text
高
中
低
关闭
```

规则：

```text
高优先级建筑优先获得电力。
低优先级建筑在缺电时先降效或停机。
关闭表示该建筑主动断电，减少消耗。
```

---

## 3.6 缺电具体影响

| 建筑类型 | 缺电影响 |
|---|---|
| 生产建筑 | 生产速度 -50% |
| 科研中心 | 研究速度 -50% |
| 改造车间 | 改造速度 -50%，不能开始高级改造 |
| 雷达站 | 视野 -30%，主动扫描冷却 +50% |
| 防御炮台 | 攻击速度 -35% |
| 维修平台 | 维修速度 -50% |
| 机场 | 飞机补弹速度 -50% |
| 船厂 | 舰船维修速度 -50% |

---

## 3.7 断电具体影响

断电比缺电更严重。

| 建筑类型 | 断电影响 |
|---|---|
| 生产建筑 | 生产暂停，队列保留 |
| 科研中心 | 研究暂停，进度保留 |
| 改造车间 | 改造暂停，进度保留 |
| 雷达站 | 主动技能禁用，反隐/反潜失效 |
| 防御炮台 | 停火，只有机枪塔保留25%低效射击，需电池模块 |
| 维修平台 | 自动维修停止，手动维修禁用 |
| 机场 | 无法起飞新飞机，返航飞机可降落但维修暂停 |
| 船厂 | 舰船生产暂停，维修暂停 |

# 四、电路连接系统规则

## 4.1 电网节点

以下对象是电网节点：

```text
机械核心基地
发电站
高级反应堆
高压电塔
电容中继站
移动发电车
机械堡垒车，部署状态
空域母舰，科技解锁后
航空母舰，科技解锁后
```

---

## 4.2 电网连接规则

电网节点之间距离小于连接距离时自动连接。

默认连接距离：

```text
12米
```

科技提升：

```text
高压传输科技：连接距离 +20%
```

建筑在任意电网节点供电范围内，即为接电。

---

## 4.3 高压电塔建设规则

高压电塔是机械阵营拓展基地范围的关键。

### 建造规则

```text
机器工人可以建造高压电塔。
高压电塔必须放在可建造地面。
不能建在深水。
不能与敌方建筑过近。
```

### 自动接线

建造完成后：

```text
自动搜索附近电网节点。
若距离满足，自动生成电缆连接线。
若没有连接到任何电网，显示“孤立电塔”。
```

### 孤立电塔状态

孤立电塔：

```text
不传输电力
不提供供电范围
UI显示灰色断电图标
```

---

## 4.4 电容中继站规则

电容中继站作用：

```text
储存电力
稳定电网
延迟断电影响
支持过载
```

### 储能规则

当电力产出大于消耗时：

```text
多余电力逐渐充入储能
```

当电力不足时：

```text
优先消耗储能补足
```

### 中继范围

电容中继站也提供电网节点范围。

---

## 4.5 电路组合规则

机械电路不是单纯连线，而是可以形成组合增益。

---

## 4.5.1 稳定回路

### 判定

一个建筑区域至少拥有两条不同路径连接到电源节点。

例如：

```text
发电站 A → 电塔 B → 工厂
发电站 A → 电塔 C → 工厂
```

形成稳定回路。

### 效果

| 效果 | 数值 |
|---|---:|
| 断电影响延迟 | +5秒 |
| 区域防御塔攻速 | +5% |
| 维修平台维修速度 | +10% |

### 表现

```text
电网视图中稳定回路显示为蓝色闭环。
闭环内建筑底部出现淡蓝色电路纹。
```

---

## 4.5.2 高压链路

### 判定

至少 3 个高压电塔形成连续直线或近似直线连接。

### 效果

| 效果 | 数值 |
|---|---:|
| 链路范围防御建筑攻击 | +8% |
| 链路范围雷达扫描速度 | +10% |
| 电塔被摧毁爆炸伤害 | 小范围电击 |

### 风险

```text
高压链路被敌人摧毁节点时，附近单位受到电击伤害。
```

### 表现

```text
高压链路显示为更粗的蓝白电弧线。
偶尔有电流跳动。
```

---

## 4.5.3 工业核心区

### 判定

以下建筑彼此接入同一稳定电网，且距离较近：

```text
重装工厂
改造车间
维修平台
电容中继站
```

### 效果

| 效果 | 数值 |
|---|---:|
| 重装单位生产速度 | +8% |
| 改造时间 | -8% |
| 维修速度 | +12% |

### 表现

```text
工业核心区地面显示黄色机械线路。
建筑工作时机械臂和电火花更明显。
```

---

## 4.5.4 空军指挥网

### 判定

以下建筑接入同一电网：

```text

雷达站
```

### 表现

```text
机场和雷达站之间出现细蓝色信号线。
飞机起飞时有蓝色导航线。
```


# 五、电力过载系统规则

## 5.1 过载入口

玩家可在以下位置使用过载：

```text
建筑面板
单位面板
电网视图快捷按钮
编队操作栏
```

按钮：

```text
[能源过载]
```

---

## 5.2 过载资源

过载消耗：

```text
储能
```

如果储能不足：

```text
按钮灰显
提示：储能不足
```

---

## 5.3 建筑过载

| 建筑 | 过载效果 | 消耗储能 | 过热惩罚 |
|---|---|---:|---|
| 机场 | 飞机生产/补弹 +40% | 80 | 20秒内效率 -20% |
| 重装工厂 | 生产速度 +35% | 90 | 电力消耗 +50%，30秒 |
| 机动机械场 | 生产速度 +30% | 60 | 停机5秒 |
| 船厂 | 舰船生产 +30% | 100 | 维修暂停10秒 |
| 科研中心 | 研究速度 +40% | 100 | 之后研究速度 -20%，30秒 |
| 改造车间 | 改造时间 -40% | 100 | 之后无法改造20秒 |
| 防御炮台 | 攻速 +60% | 50 | 之后停火5秒 |
| 雷达站 | 扫描范围 +50% | 70 | 主动技能冷却 +30秒 |
| 维修平台 | 维修速度 +60% | 80 | 之后维修速度 -30%，20秒 |

---

## 5.4 单位过载

单位需要满足：

```text
在电网范围内
或装有高效电池模块
或附近有移动发电车/机械堡垒车供电
```

| 单位 | 过载效果 | 过热惩罚 |
|---|---|---|
| 机械狗 | 移速 +35%，攻击 +10% | 移速 -20%，4秒 |
| 装甲车 | 攻速 +25% | 装填速度 -20%，6秒 |
| 坦克 | 炮击伤害 +20% | 装填速度 -25%，8秒 |
| 防空导弹车 | 锁定速度 +40% | 无法锁定3秒 |
| 动力机甲 | 攻速 +25%，移速 +10% | 护甲 -1，6秒 |
| 高达型机甲 | 技能冷却 -30% | 电池耗尽，无法过载30秒 |
| 飞机 | 机动 +20% | 技能禁用5秒 |
| 舰船 | 射程 +0.5，攻速 +10% | 转向速度 -20%，8秒 |

---

## 5.5 过载表现

过载中：

```text
单位/建筑发出蓝紫色电流
核心灯光变亮
动作速度提升
UI边框闪烁
```

过热中：

```text
红橙色过热烟雾
电弧断续
UI显示“过热”状态
```

# 六、维修平台系统规则

## 6.1 维修平台职责

维修平台负责：

```text
维修机械单位
维修建筑
维修飞机
维修舰船
回收机械残骸
补充飞机弹药
修复单位改造损伤
```

---

## 6.2 可维修对象

| 对象 | 是否可维修 |
|---|---|
| 机械狗 | 可 |
| 机器工人 | 可 |
| 装甲车 | 可 |
| 坦克 | 可 |
| 机甲 | 可 |
| 飞机 | 可，需返航到机场/维修平台范围 |
| 舰船 | 可，需在船厂/维修平台水域范围 |
| 建筑 | 可，需机器工人或维修平台模块 |
| 生物单位 | 不可 |
| 妖兽单位 | 不可 |
| 自然单位 | 不可 |

---

## 6.3 维修方式

维修平台有 3 种维修方式。

### 1. 自动维修

默认开启。

规则：

```text
维修平台自动维修范围内血量最低的机械单位。
每次最多维修3个目标。
优先维修战斗单位。
```

优先级：

```text
即将死亡单位
高价值单位
当前被攻击单位
玩家手动指定单位
普通单位
```

---

### 2. 手动维修

操作流程：

```text
选择维修平台
点击【手动维修】
点击目标机械单位/建筑
维修平台集中维修该目标
```

手动维修效果：

```text
维修速度 +50%
资源消耗 +20%
```

适合抢救关键单位。

---

### 3. 队列维修

适合大量单位回基地维修。

操作流程：

```text
选择单位
点击【返回维修】
单位自动前往最近维修平台
进入维修队列
维修完成后返回原集结点
```

---

## 6.4 维修消耗

维修消耗资源：

```text
金属
少量黄金
```

默认比例：

```text
每恢复100生命：消耗金属8，黄金3
```

建筑维修额外消耗石料：

```text
每恢复100建筑生命：石料5，金属5
```

---


# 八、AI控制科技树具体规则

AI控制科技不是“自动帮玩家赢”，而是减少重复操作，提高机械阵营自动化特色。

所有AI功能都必须可以：

```text
开启
关闭
设置优先级
```

---

## 8.1 火控AI

### 解锁效果

单位获得自动目标优先级判断。

默认逻辑：

```text
优先攻击自己克制的目标
其次攻击威胁最高目标
最后攻击最近目标
```

### 示例

防空导弹车：

```text
1. 轰炸机
2. 空域母舰
3. 飞行妖兽
4. 侦察机
5. 其他空中单位
```

坦克：

```text
1. 敌方重装单位
2. 防御建筑
3. 机械堡垒
4. 普通地面单位
```

机械狗：

```text
1. 工程师
2. 工人/采集单位
3. 轻甲远程
4. 隐身单位
```

### UI

单位面板增加：

```text
[火控AI：开/关]
```

高级设置：

```text
优先克制目标
优先低血目标
优先攻击当前目标
优先保护自身
```

---

## 8.2 维修AI

### 解锁效果

维修单位和维修平台自动寻找需要维修的机械目标。

默认优先级：

```text
1. 生命低于25%的高价值单位
2. 当前被攻击单位
3. 飞机/坦克/机甲等高价值单位
4. 普通受损单位
5. 建筑
```

### 维修AI限制

```text
不会自动冲进敌方火力范围
不会维修正在被敌人包围的目标，除非玩家手动命令
资源不足时停止维修
```

### UI

维修平台和维修单位增加：

```text
[维修AI：开/关]
[维修优先级]
```

---

## 8.3 返航AI

### 解锁效果

飞机、无人机、低血机械单位可以自动返回维修点。

默认触发条件：

```text
生命低于30%
弹药耗尽
燃料/电池不足
玩家设置为自动返航
```

### 返航目标选择

```text
最近机场
最近维修平台
最近船厂，舰船使用
最近机械堡垒车，前线部署状态
```

### UI

单位面板：

```text
[自动返航：开/关]
返航阈值：30% / 50% / 手动
```

---

## 8.4 编队AI

### 解锁效果

机械单位自动保持队形。

队形类型：

| 队形 | 效果 |
|---|---|
| 装甲楔形 | 坦克在前，防空车在后 |
| 防空保护 | 防空单位围绕高价值单位 |
| 维修跟随 | 维修单位跟随重型单位后方 |
| 飞机护航 | 歼击机跟随轰炸机 |
| 舰队阵型 | 巡航舰在前，航母在后，潜艇侧翼 |

### UI

编队按钮：

```text
[队形]
```

可选：

```text
自由
装甲楔形
防空保护
维修跟随
护航
舰队阵型
```

---

## 8.5 防空AI

### 解锁效果

防空单位自动分辨高威胁飞行目标。

优先级：

```text
1. 正在投弹的轰炸机
2. 空域母舰/航空母舰无人机
3. 对己方造成伤害的飞行单位
4. 侦察机
5. 普通飞行单位
```

### 特殊规则

```text
防空AI不会把所有火力浪费在低价值侦察机上，除非侦察机正在标记目标。
```

---

## 8.6 反潜AI

### 解锁效果

声呐单位自动标记潜艇或潜水妖。

规则：

```text
发现潜水目标后自动在小地图提示。
反潜单位自动转火。
导弹驱逐舰优先攻击被声呐标记的目标。
```

---

## 8.7 目标共享

### 解锁效果

雷达、侦察机、目标锁定单位共享目标信息。

效果：

```text
被任意机械侦察单位标记的目标，会短时间提供给附近远程单位。
```

数值：

| 效果 | 数值 |
|---|---:|
| 命中率 | +5% |
| 导弹锁定速度 | +10% |
| 轰炸偏差 | -10% |

---

## 8.8 AI控制表现

AI开启时：

```text
单位按钮出现蓝色AI角标
单位执行自动行为时头顶显示小图标
```

示例：

```text
自动返航：绿色回箭头
自动维修：扳手图标
火控AI：准星图标
防空AI：导弹图标
```

# 九、改造系统操作与表现规则

## 9.1 改造入口

改造入口有两个：

```text
改造车间
单位/建筑自身面板
```

但真正改造必须满足：

```text
单位在改造车间范围内
或建筑自身拥有自改造模块
或科技解锁战地改造
```

---

## 9.2 改造流程

```text
选择单位/建筑
点击【改造】
打开改造面板
选择模块槽
选择模块
查看效果和副作用
确认消耗
进入改造进度
完成后生效
```

## 9.3 改造状态

改造中单位：

```text
不能移动
不能攻击
受到伤害会中断改造，返还50%资源
```

战地改造科技后：

```text

改造时间 +50%
受到伤害不会中断，但改造速度暂停
```

同类模块互斥。

示例：

```text
主武器模块只能装一个。
机动模块只能装一个。
核心能源模块只能装一个。
```

如果玩家选择冲突模块：

```text
提示：该模块与当前模块冲突，是否替换？
```

---

## 9.5 改造表现

改造过程中：

```text
单位进入平台
机械臂展开
蓝色焊接火花
模块模型逐渐显示
进度条显示
```

改造完成：

```text
播放机械锁定音效
模块发光
单位模型外观变化
弹字：改造完成：穿甲炮
```

# 十、飞机平台规则

## 10.1 飞机不是普通地面单位

飞机拥有特殊状态：

```text

起飞
执行任务
返航
维修
补弹
坠毁
```

---

## 10.2 飞机弹药规则

轰炸机和部分飞机有弹药。

```text

歼击机导弹可自动缓慢恢复，也可返航快速补充。
```

## 10.3 返航规则

飞机触发返航：

```text

自动返航AI触发
机场被断电但允许紧急降落
```

## 10.4 机场断电影响

机场断电时：

```text
新飞机不能起飞
生产暂停
维修暂停
返航飞机可以紧急降落
补弹暂停
```

如果机场被摧毁：

```text
空中飞机寻找其他机场
没有机场则进入燃料倒计时
倒计时结束后坠毁或撤离地图
```

# 十四、程序实现建议

## 14.1 核心组件

建议拆成以下组件：

```text
PowerProducerComponent
PowerConsumerComponent
PowerGridNodeComponent
PowerStorageComponent
OverloadComponent
RepairableComponent
RepairStationComponent
RadarComponent
StealthDetectComponent
SonarComponent
ModificationSlotComponent
ModuleComponent
AIControlComponent
AircraftStateComponent
NavalUnitComponent
SubmarineComponent
```

---

## 14.2 电力刷新时机

电网刷新不需要每帧完整计算。

刷新时机：

```text
建筑建造完成
建筑被摧毁
高压电塔建造/摧毁
发电站状态变化
电容中继站状态变化
建筑移动，特殊移动建筑
读档
```

---

## 14.3 电网计算逻辑

流程：

```text
1. 找到所有电源节点。
2. 通过连接距离生成电网图。
3. 标记每个建筑是否接入电网。
4. 统计产出、消耗、储能。
5. 根据优先级分配电力。
6. 设置建筑状态：正常/缺电/断电。
```

---

## 14.4 AI控制逻辑

AI控制不应每帧全量扫描。

建议：

```text
每0.5秒刷新一次目标优先级。
受到攻击时立即刷新。
目标死亡时立即刷新。
玩家手动命令时暂停自动AI一段时间。
```

手动命令优先级最高。

```text
玩家命令 > AI自动行为
```

---

# 十五、最终硬规则

```text
1. 电力系统必须影响建筑效率。
2. 建筑必须接入电网才能满效率运行。
3. 电力不足和断电必须有明确UI和表现。
4. 高压电塔负责拓展电网，不需要手动画电线。
5. 电路组合要形成稳定回路、高压链路、工业核心区、空军指挥网、海军电控港。
6. 过载必须有收益和过热代价。
7. 维修平台必须支持自动维修、手动维修、队列维修、残骸回收。
8. 维修必须消耗资源，不能免费回血。
9. 雷达站必须支持区域扫描、目标锁定、反隐、声呐。
10. AI控制科技必须可以开关，并且不能覆盖玩家手动命令。
11. 改造系统必须有槽位、互斥、消耗、改造时间、表现变化。
12. 飞机必须有返航、补弹、维修状态。
13. 潜艇必须有潜航、暴露、声呐发现规则。
14. 所有新增系统都必须有按钮、状态图标、Tips说明。
15. 手机端高风险操作必须二次确认，例如过载和替换模块。
```
