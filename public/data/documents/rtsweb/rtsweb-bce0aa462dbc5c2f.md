# 单位技能喊名冒泡 UI 系统完整设计方案

## 一、系统目标

当前战斗中，单位释放技能、触发被动、进入特殊状态时，玩家很难第一时间知道：

```text
谁放了技能
放了什么技能
这个技能重不重要
是不是触发了强力被动
是不是应该关注这个单位
```

因此新增一套单位头顶“技能喊名冒泡 UI”。

核心体验：

```text
单位释放技能时，头顶弹出类似“喊出技能名”的冒泡。
玩家能像看动画或 RTS 战场叫阵一样，感受到单位在战斗中释放招式。
```

设计目标：

```text
1. 强技能更醒目，弱技能不刷屏。
2. 普通技能、强力技能、终局技能、被动触发有不同表现。
3. 冒泡内容短、清楚、有冲击力。
4. 和伤害跳字区分开，不能混在一起。
5. 支持阵营风格差异。
6. 支持手机端清晰显示，不遮挡过多战场。
7. 支持大量单位释放技能时的合并、降级和优先级。
```

---

# 二、系统适用范围

## 2.1 需要冒泡的事件

以下事件可以触发单位头顶冒泡：

```text
主动技能释放
强力技能释放
终局技能释放
特殊被动触发
单位进入特殊姿态
单位切换模式
关键控制触发
关键防御触发
融合/吞噬/改造类效果触发
占领/召唤/变身类大事件
```

---

## 2.2 不需要冒泡的事件

以下事件不建议冒泡，避免刷屏：

```text
普通攻击
普通移动
普通采集
普通受击
持续伤害每跳
持续治疗每跳
普通Buff刷新
数值很低的小被动
冷却很短的普攻附带效果
```

---

## 2.3 冒泡与伤害跳字的区别

| 类型 | 作用 | 出现位置 | 视觉重点 |
|---|---|---|---|
| 伤害跳字 | 显示数值反馈 | 单位血条附近 | 数字、颜色、伤害类型 |
| 技能冒泡 | 显示行为反馈 | 单位头顶更高处 | 技能名、气势、关注点 |
| 状态图标 | 显示持续状态 | 血条旁 | Buff/Debuff状态 |
| 战场提示 | 显示全局事件 | 屏幕中上方 | 重要事件 |

技能冒泡不显示伤害数字，主要显示：

```text
技能名
被动名
状态名
短标签
```

---

# 三、冒泡触发分类

## 3.1 主动技能冒泡

单位主动释放技能时触发。

示例：

```text
麒麟踏阵！
熔岩重踏！
排枪齐射！
五相能量炮！
```

适合：

```text
技能有明显动作
技能有冷却
技能会改变战局
玩家需要看见
```

---

## 3.2 被动触发冒泡

特殊被动被触发时显示。

示例：

```text
血肉修复
吞军化血
阵列同步
金甲反震
水面强化
```

注意：

```text
被动冒泡不能太频繁。
同一被动短时间内必须有冷却。
```

---

## 3.3 模式切换冒泡

单位切换模式、姿态、箭矢、元素核心时显示。

示例：

```text
切换：火箭矢
五行换势：水
进入部署模式
元素核心：金
```

这类冒泡偏功能提示，动画不需要太夸张。

---

## 3.4 变身 / 进化 / 融合冒泡

单位发生形态变化时显示。

示例：

```text
化形麒麟！
终极妖化！
元素融合完成！
机骸暴走！
```

这类冒泡优先级高，表现要强。

---

## 3.5 战术指令冒泡

群体命令、阵法、AI指令触发时显示。

示例：

```text
军规指令！
兽潮号令！
五行令！
空域压制！
```

这类冒泡可以显示在施法者头顶，也可以同步显示在受影响单位的小型短标签。

# 四、冒泡优先级

## 4.1 优先级等级

冒泡按重要性分为 6 级。

| 等级 | 名称 | 适用 |
|---|---|---|
| 0 | 不显示 | 低价值被动、小数值触发 |
| 1 | 小提示 | 普通被动、模式切换 |
| 2 | 普通技能 | 常规主动技能 |
| 3 | 强力技能 | 控制、AOE、高伤害技能 |
| 4 | 英雄/精英技能 | 高级单位技能、关键被动 |
| 5 | 终局/大招 | 终局技能、变身、占领、超强技能 |

---

## 4.2 优先级示例

| 技能/效果 | 优先级 |
|---|---:|
| 切换毒箭矢 | 1 |
| 机械狗嗅探雷达 | 1 |
| 火球 | 2 |
| 根须缠绕 | 2 |
| 麒麟踏阵 | 3 |
| 熔岩重踏 | 3 |
| 排枪齐射 | 3 |
| 化形饕餮：吞军化血 | 4 |
| 血肉高达：机骸暴走 | 4 |
| 灵能泰坦：五相能量炮 | 5 |
| 万兽狂潮 | 5 |
| 天象：暴雨 | 5 |

---

## 4.3 显示规则

```text
优先级 0：不显示。
优先级 1：小冒泡，短时间。
优先级 2：标准冒泡。
优先级 3：大冒泡，带小震动。
优先级 4：强化冒泡，带边框特效。
优先级 5：大招冒泡，带特殊音效和局部镜头反馈。
```

---

# 五、冒泡强度表现分级

## 5.1 冒泡大小

| 优先级 | 宽度 | 高度 | 字号 | 持续 |
|---|---:|---:|---:|---:|
| 1 小提示 | 110~150 px | 32 px | 14 | 0.8秒 |
| 2 普通技能 | 150~210 px | 40 px | 16 | 1.1秒 |
| 3 强力技能 | 210~280 px | 48 px | 18 | 1.35秒 |
| 4 精英技能 | 260~340 px | 56 px | 20 | 1.6秒 |
| 5 终局大招 | 320~460 px | 66 px | 24 | 2.0秒 |

---

## 5.2 冒泡动画强度

| 优先级 | 动画 |
|---|---|
| 1 | 轻微上弹，快速淡出 |
| 2 | 弹出 + 上飘 |
| 3 | 强弹出 + 小幅抖动 |
| 4 | 爆发弹出 + 边框扫光 |
| 5 | 冲击弹出 + 局部震屏 + 光圈扩散 |

---

## 5.3 冒泡持续时间

持续时间由三个因素决定：

```text
技能优先级
单位强度
技能类型
```

基础公式：

```text
持续时间 = 优先级基础时间 + 单位强度加成 + 技能类型加成
```

单位强度加成：

| 单位强度 | 加成 |
|---|---:|
| 普通单位 | +0秒 |
| 精英单位 | +0.15秒 |
| Boss单位 | +0.25秒 |
| 英雄单位 | +0.25秒 |
| 终局单位 | +0.35秒 |

技能类型加成：

| 技能类型 | 加成 |
|---|---:|
| 普通主动 | +0秒 |
| 控制技能 | +0.1秒 |
| 大范围AOE | +0.15秒 |
| 变身/进化 | +0.25秒 |
| 终局技能 | +0.35秒 |

# 六、冒泡 UI 基础结构

## 6.1 冒泡整体结构

冒泡由 5 个部分组成：

```text
背景底板
阵营边框
技能名称文本
技能类型小图标
尾巴指向单位
```

结构示意：

```text
        ┌──────────────────┐
        │ [图标] 麒麟踏阵！ │
        └───────┬──────────┘
                ▼
              单位
```

---

## 6.2 背景底板

基础形状：

```text
圆角矩形
轻微不规则边缘，可选
半透明底色
```

不同风格：

```text
普通技能：简洁圆角气泡
强力技能：加厚边框
大招技能：双层边框 + 外发光
被动触发：小胶囊标签
```

---

## 6.3 尾巴指向

冒泡底部需要一个小三角或小弧形尾巴指向释放单位。

规则：

```text
尾巴始终指向单位头顶中心。
如果冒泡左右偏移，尾巴也随之偏移。
多单位重叠时，尾巴颜色保持阵营色。
```

---

## 6.4 图标位置

技能图标放在文本左侧。

```text
[技能图标] 技能名称！
```

图标尺寸：

| 冒泡等级 | 图标尺寸 |
|---|---:|
| 小提示 | 16 px |
| 普通技能 | 20 px |
| 强力技能 | 24 px |
| 精英技能 | 28 px |
| 终局大招 | 32 px |

---

## 6.5 文本规则

技能名称尽量短。

推荐：

```text
麒麟踏阵！
吞军化血！
五相能量炮！
排枪齐射！
```

不推荐：

```text
麒麟骑兵正在释放对前方范围造成伤害的麒麟踏阵技能
```

文字长度规则：

```text
技能名最多 8 个汉字。
超过8个字使用简称。
可在详情Tips里显示完整说明。
```

# 七、冒泡文字设计

## 7.1 文案格式

```text

```

示例：

```text
麒麟踏阵！

```

```text

```

示例：

```text

```

```text

```

示例：

```text

姿态：土
```

### 变身进化

```text

```

示例：

```text
化形饕餮！

五灵化形！
```

### 群体号令

```text

```

示例：

```text

五行令！
```

---

## 7.2 标点规则

| 类型 | 标点 |
|---|---|
| 普通被动 | 无标点 |
| 模式切换 | 冒号 |
| 主动技能 | 感叹号 |
| 强力技能 | 感叹号 |
| 终局技能 | 感叹号 + 特效 |
| 失败/免疫 | 不建议冒泡，用状态文字 |


字号层级：

| 类型 | 字号 |
|---|---:|
| 小提示 | 14 |
| 普通技能 | 16 |
| 强力技能 | 18 |
| 精英技能 | 20 |
| 终局大招 | 24 |

## 8.5 融合阵营



# 九、技能类型冒泡样式

## 9.1 普通主动技能

样式：

```text
标准气泡
阵营主题边框
图标 + 技能名
轻微上弹
```

持续：

```text
1.1秒
```

示例：

```text
火球！
水流弹！
根须缠绕！
```

---

## 9.2 强力控制技能

样式：

```text
边框更厚
控制图标
气泡出现时短暂停顿
```

示例：

```text
冻结！
泥沼陷落！
电磁束缚！
```

额外表现：

```text
气泡下方出现小型控制符号
目标单位头顶可以显示状态图标
```

---

## 9.3 AOE大伤害技能

样式：

```text
大号气泡
外发光
气泡弹出时有小冲击圈
```

示例：

```text
熔岩重踏！
爆裂火果！
校准炮击！
```

---

## 9.4 防御/护盾技能

样式：

```text
方正气泡
护盾图标
颜色偏蓝或金
动画更稳重
```

示例：

```text
潮汐护壁！
金岩壁垒！
机关盾阵！
```

---

## 9.5 治疗/净化技能

样式：

```text
柔和气泡
绿色/蓝色
向上轻轻浮起
无强烈抖动
```

示例：

```text
莲华净化
灵鹿奔愈
灵泉涌动
```

---

## 9.6 被动触发

样式：

```text
小胶囊
无尾巴或短尾巴
显示时间短
不抢技能视觉
```

示例：

```text
血肉修复
金甲反震
阵列同步
水面强化
```

触发冷却：

```text
同一单位同一被动 6秒内只显示1次。
```

---

## 9.7 终局技能 / 大招

样式：

```text
最大气泡
双层边框
外发光
专属图标
局部震屏
短暂停留
```

示例：

```text
万兽狂潮！
五相能量炮！
兽灾降临！
天象：暴雨！
```

规则：

```text
同屏最多同时显示3个终局冒泡。
若多个同时触发，按优先级排队显示。
```

# 十、技能威力与冒泡表现关系

## 10.1 技能威力评分

每个技能配置一个 SkillImpactLevel。

```text
1 轻微
2 普通
3 重要
4 强力
5 终局
```

影响：

```text
气泡大小
动画强度
持续时间
音效大小
是否有外发光
是否允许震屏
```

---

## 10.2 技能威力评分参考

| 技能情况 | Impact |
|---|---:|
| 小位移、小Buff | 1 |
| 单体伤害、普通控制 | 2 |
| 中范围AOE、关键控制 | 3 |
| 大范围AOE、变身、高级单位技能 | 4 |
| 终局技能、全局号令、大型召唤 | 5 |

---

## 10.3 单位强度修正

单位等级/强度会修正冒泡表现。

| 单位类型 | 修正 |
|---|---|
| 普通单位 | 不修正 |
| 精英单位 | 冒泡放大 8% |
| Boss单位 | 冒泡放大 15% |
| 英雄单位 | 冒泡放大 15% |
| 终局单位 | 冒泡放大 20% |

例如：

```text
普通火灵释放火球：普通气泡
火凤灵释放烈焰俯冲：强力气泡
灵能泰坦释放五相能量炮：终局气泡
```

# 十一、冒泡动画设计

## 11.1 标准弹出动画

用于普通技能。

```text
0.00s：缩放 70%，透明度 0
0.08s：缩放 115%，透明度 100
0.16s：缩放回 100%
0.16s~0.85s：向上漂浮 18px
0.85s~1.10s：淡出
```

---

## 11.2 强力技能动画

```text
0.00s：缩放 50%，透明度 0
0.06s：缩放 130%
0.12s：缩放 105%
0.12s~0.28s：轻微左右抖动
0.28s：边框扫光
0.28s~1.20s：缓慢上浮
1.20s~1.35s：淡出
```

---

## 11.3 终局大招动画

```text
0.00s：气泡从单位头顶爆开
0.05s：外圈光环扩散
0.10s：缩放到 145%
0.20s：回落到 110%
0.20s~0.45s：局部震动
0.45s~1.60s：保持可读
1.60s~2.00s：淡出并向上漂
```

额外：

```text
播放短音效
可触发轻微镜头震动
单位脚下出现释放光圈
```

---

## 11.4 被动小提示动画

```text
0.00s：从血条上方轻轻弹出
0.10s：停留
0.10s~0.70s：向上漂浮
0.70s~0.80s：淡出
```

# 十二、冒泡位置规则

## 12.1 基础位置

冒泡显示在单位头顶：

```text
血条上方 28~42px
```

如果单位有血条：

```text
冒泡在血条上方
```

如果单位没有血条：

```text
冒泡在模型头顶上方
```

---

## 12.2 大型单位位置

大型单位 / 建筑 / Boss：

```text
冒泡显示在模型中心上方
距离更高
字号更大
```

建筑释放技能时：

```text
冒泡显示在建筑顶部中心
尾巴指向建筑核心
```

---

## 12.3 多冒泡错位

同一时间多个单位冒泡时：

```text
允许左右轻微错位
避免重叠
```

规则：

```text
第1个：正上方
第2个：左上偏移
第3个：右上偏移
第4个：向上堆叠
低优先级超过数量直接隐藏
```

---

## 12.4 冒泡不应遮挡

优先避让：

```text
资源栏
主要操作按钮
关键任务提示
选中单位面板
大型全局提示
```

手机端：

```text
屏幕下方操作区不显示冒泡。
如果单位在屏幕底部，冒泡向上偏移。
```

---

# 十三、冒泡合并与限流

## 13.1 同类技能合并

大量同单位释放同类技能时，合并冒泡。

示例：

5个火铳兵同时释放排枪齐射：

```text
排枪齐射 x5！
```

显示在编队中心上方。

---

## 13.2 群体Buff合并

群体技能影响多个单位时：

```text
只在施法者头顶显示主冒泡。
受影响单位显示小状态图标，不显示冒泡。
```

示例：

```text
五行令！
```

不要每个单位都弹：

```text
攻击提升
攻击提升
攻击提升
```

---

## 13.3 被动触发限流

同一单位同一被动：

```text
6秒内最多冒泡1次
```

同屏同类被动：

```text
1秒内最多显示5个
```

超过：

```text
隐藏低优先级冒泡
```

---

## 13.4 同屏上限

| 冒泡类型 | 同屏上限 |
|---|---:|
| 小提示 | 8 |
| 普通技能 | 10 |
| 强力技能 | 6 |
| 精英技能 | 4 |
| 终局大招 | 3 |

如果超过：

```text
高优先级保留
低优先级隐藏或合并
```

---

# 十四、冒泡与音效联动

## 14.1 是否播放语音

冒泡可以不要求真实语音，先做 UI 和短音效。

推荐分三档：

| 类型 | 音效 |
|---|---|
| 小提示 | 无或轻提示音 |
| 普通技能 | 短技能音 |
| 强力技能 | 技能音 + 低频冲击 |
| 终局技能 | 专属音效 + 号令感 |
| 阵营号令 | 战鼓/兽吼/电流/灵音 |

---

## 14.2 阵营音效风格

| 阵营 | 音效 |
|---|---|
| 华夏 | 战鼓、号角、军令牌 |
| 妖族 | 兽吼、血肉脉动、低吼 |
| 机械 | 电子提示、电流、机械启动 |
| 自然 | 风声、水声、灵晶、叶片 |
| 融合 | 两阵营音效混合 |

---

## 14.3 音效限流

同屏大量技能时：

```text
普通技能音效最多同时播放5个。
终局技能音效优先级最高。
小提示默认不播放音效。
```

---

# 十五、冒泡与镜头反馈

## 15.1 镜头震动条件

不是所有冒泡都震屏。

允许震屏：

```text
Impact 4以上
Boss技能
终局技能
大型爆炸技能
关键占领技能
```

不允许震屏：

```text
普通技能
小被动
治疗
模式切换
```

---

## 15.2 震动强度

| 技能等级 | 震动 |
|---|---|
| Impact 3 | 无或极轻 |
| Impact 4 | 轻微局部震动 |
| Impact 5 | 轻微全屏震动 |

手机端：

```text
默认关闭低等级震动。
只保留终局技能轻震。
```

# 十六、PC 与手机表现差异

## 16.1 PC端

PC可显示完整冒泡：

```text

阵营底板

```

PC悬停冒泡可显示技能详情：

```text

```

这个功能可选，不建议早期必须做。

## 16.2 手机端

```text
同屏上限更低

```

手机端推荐默认：


# 十九、程序实现建议

## 19.1 触发流程

```text
技能系统触发技能释放事件
→ SkillCalloutSystem 接收事件
→ 判断该技能是否允许冒泡
→ 读取 SkillCalloutData
→ 根据单位强度修正大小和持续时间
→ 判断同屏数量和优先级
→ 判断是否合并
→ 从对象池取 CalloutItem
→ 绑定单位头顶位置
→ 播放冒泡动画
→ 动画结束回收
```

---

## 19.2 被动触发流程

```text
被动系统触发效果
→ 检查该被动是否配置冒泡
→ 检查同单位冷却
→ 检查全局限流
→ 显示小冒泡
```

---

## 19.3 对象池

建议对象池：

```text
小提示冒泡：20
普通技能冒泡：30
强力技能冒泡：15
终局冒泡：5
```

池不足时：

```text
回收低优先级已显示超过50%时长的冒泡。
不能回收终局冒泡。
```

---

## 19.4 冒泡跟随单位

冒泡需要跟随单位，但不应完全粘死。

推荐：

```text
冒泡出现前0.25秒跟随单位。
之后缓慢上浮并逐渐脱离。
单位死亡后冒泡继续完成动画。
```

这样不会因为单位高速移动导致文字难看。

# 二十一、验收标准

## 21.1 基础功能验收

```text
单位释放主动技能时，头顶能弹出技能名。
单位触发特殊被动时，能按配置弹出小冒泡。
模式切换能显示短标签。
终局技能冒泡明显大于普通技能。
冒泡能跟随单位头顶位置。
冒泡结束后能自动消失并回收。
```

---

## 21.2 强度区分验收

```text
普通技能和强力技能大小不同。
强力技能动画更明显。
终局技能有外发光和更长停留时间。
普通被动不会抢占主要视觉。
Boss/英雄释放技能的冒泡比普通单位更强。
```

---

## 21.3 阵营风格验收

```text
华夏冒泡有军令/赤金风格。
妖族冒泡有血肉/妖纹风格。
机械冒泡有电路/扫描风格。
自然冒泡有藤蔓/灵晶风格。
融合阵营冒泡能体现占领方主导和被占领方特征。
```

---

## 21.4 限流验收

```text
大量单位同时释放技能时，不会满屏冒泡。
同类技能可以合并显示 x数量。
被动触发有冷却，不会频繁刷屏。
终局技能不会被普通技能挤掉。
手机端冒泡数量明显少于PC端。
```

---

## 21.5 可读性验收

```text
技能名在1秒内能看清。
冒泡不遮挡资源栏和主要操作区。
冒泡不会和伤害跳字混淆。
高强度技能能吸引玩家注意。
普通技能不会过度干扰战斗。
```

---

# 二十二、最终硬规则

```text
1. 技能冒泡只显示行为名称，不显示伤害数字。
2. 冒泡必须根据技能威力和单位强度分级。
3. 普通技能、强力技能、终局技能表现必须明显不同。
4. 被动冒泡必须限流。
5. 同类群体技能必须合并。
6. 冒泡必须有阵营主题。
7. 融合阵营冒泡必须表现占领方主导。
8. 手机端默认减少小冒泡显示。
9. 冒泡不能遮挡主要UI。
10. 终局技能冒泡优先级最高。
11. 冒泡文案必须短，技能名最多8个汉字。
12. 冒泡和伤害跳字必须有明显视觉区别。
```

---

# 二十三、一句话总结

```text
技能喊名冒泡 UI 是战斗气氛系统，不是数值系统。它要让玩家感觉单位在战场上“喊招、叫阵、爆发”，同时通过大小、颜色、动画和阵营风格，让玩家快速判断技能的重要性和战斗节奏。
```
