# Project Overview

## 项目定位

TestRTS2 是 Unity RTS 项目，核心内容包括主界面、关卡选择、图鉴、设置、战斗 HUD、单位/建筑控制、生产、建造、科技树、阵营机制和战斗反馈表现。

## 当前 UI 方向

- 所有可见且需要调整的 UI 优先使用 Prefab。
- 代码只负责实例化、绑定固定节点、刷新动态数据、显隐控制、点击事件和必要动画。
- Canvas、世界坐标跟随点、对象池、动态列表内容可以由代码创建或驱动，但可见条目仍应 Prefab 化。
