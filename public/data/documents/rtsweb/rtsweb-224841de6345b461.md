# Skill Buff Configuration

## Purpose

Buff and debuff skills now support a data-driven advanced configuration instead of only a single timed stat modifier.

The old fields remain available for compatibility:

- `affectedStat`
- `modifierOperation`
- `effectValue`
- `duration`

When `buffConfig.useAdvancedBuff` is disabled, the skill keeps the old timed modifier behavior.

## Advanced Buff Config

Advanced buff data lives on `SkillDefinitionData.buffConfig`.

Core fields:

- `useAdvancedBuff`: opt in to the new runtime.
- `buffId`: stable id for stacking and display.
- `displayNameKey`: optional display key.
- `icon`: optional buff icon.
- `duration`: finite duration.
- `infiniteDuration`: prevents duration countdown.
- `dispellable`: reserved for later dispel rules.
- `stackable`: enables stack growth.
- `maxStacks`: stack cap.
- `refreshMode`: controls reapply behavior.

Refresh modes:

- `RefreshDuration`: reset duration.
- `AddStackAndRefresh`: add one stack and reset duration.
- `AddStackKeepDuration`: add one stack without resetting duration.
- `IgnoreIfActive`: ignore repeated applications.
- `Replace`: remove and recreate the buff.

## Triggers

Each buff can contain multiple trigger rules:

- `OnApply`: fires when the buff is applied.
- `Interval`: fires repeatedly by interval.
- `OnHitTaken`: fires when the buff owner is damaged.
- `OnAttackDealt`: fires when the buff owner deals damage.
- `OnMove`: fires when the buff owner moves.
- `OnJump`: reserved for movement systems that expose jump events later.
- `OnExpire`: fires before the buff is removed.

Trigger fields:

- `interval`: repeat interval for interval triggers.
- `chance`: trigger probability.
- `cooldown`: per-trigger cooldown.
- `triggerImmediatelyOnApply`: interval trigger can fire immediately.
- `requireMoving`: reserved for stricter movement checks.

The current runtime uses `DamageResolvedEvent` for attack and hit triggers, so it avoids modifying the attack pipeline.

## Effects

Each buff can contain multiple effect nodes:

- `ModifyStat`: persistent stat modifier while the buff is active.
- `Heal`: restores health to selected targets.
- `RestoreEnergy`: configuration and VFX placeholder; the project does not currently expose a shared unit energy resource API.
- `AreaDamage`: damages enemies in a radius.
- `DamageOverTime`: same runtime path as interval area/direct damage, usually paired with an interval trigger.
- `InstantDamage`: damages selected targets directly.
- `PlayVfx`: spawns configured VFX without gameplay numbers.

Effect targeting:

- `BuffTarget`: the unit/building carrying the buff.
- `Caster`: the unit that applied the buff.
- `TriggerSource`: source from a trigger event when available.
- `TriggerTarget`: target from a trigger event when available.
- `AlliesInRadius`: allied units/buildings around the resolved center.
- `EnemiesInRadius`: enemy units/buildings around the resolved center.

## Runtime Notes

- Advanced buff states are stored in `UnitSkillController.activeBuffs`.
- Persistent stat modifiers use per-effect source keys so removal is precise.
- Interval effects run from the owning unit controller update loop.
- Damage effects trigger damage popups, hit feedback, and `DamageResolvedEvent`.
- Old buff skills remain compatible when advanced config is disabled.

## Editor Validation

The skill editor warns or errors when:

- advanced buff has no duration and is not infinite
- stackable buff has `maxStacks <= 1`
- no trigger is configured
- no effect node is configured
- radius effects have no radius
- non-VFX effects have zero value
