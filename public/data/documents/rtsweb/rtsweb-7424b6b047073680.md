# 3. 箭矢模式系统

## 3.1 系统定位

箭矢模式是华夏远程单位的重要科技玩法。玩家可以通过研究不同箭矢科技，让弓手、神臂弩手、防空弩兵、弩舟等远程单位获得不同攻击模式。

核心规则：

```text
箭矢科技可以全部研究。
但同一单位同一时间只能启用一种箭矢模式。
```

也就是说：

```text
弓手不能同时开启火箭矢和毒箭矢。
神臂弩手不能同时开启穿甲箭矢和缓速箭矢。
弩舟不能同时拥有火箭燃烧和穿甲破甲模式。
```

---

## 3.2 可用箭矢类型

| 箭矢模式 | 解锁科技 | 核心效果 | 代价 | 适合目标 |
|---|---|---|---|---|
| 普通箭 | 默认 | 无特殊效果 | 无 | 通用战斗 |
| 火箭矢 | 火箭矢科技 | 点燃敌人，持续燃烧 | 攻速降低 | 建筑、密集轻甲 |
| 毒箭矢 | 毒箭矢科技 | 中毒，降低治疗效果 | 对建筑伤害降低 | 高回复单位、治疗体系 |
| 穿甲箭矢 | 穿甲箭矢科技 | 提高伤害，降低目标护甲 | 攻速降低 | 重甲、英雄、重骑、战船 |
| 缓速箭矢 | 缓速箭矢科技 | 降低目标移动速度 | 伤害降低 | 骑兵、飞行、逃跑单位 |

---

## 3.3 箭矢适用单位

| 单位 | 普通箭 | 火箭矢 | 毒箭矢 | 穿甲箭矢 | 缓速箭矢 |
|---|---|---|---|---|---|
| 弓手 | 可用 | 可用 | 可用 | 可用 | 可用 |
| 防空弩兵 | 可用 | 不推荐，可禁用 | 不推荐，可禁用 | 可用 | 可用 |
| 神臂弩手 | 可用 | 可用 | 可用 | 可用 | 不推荐，可禁用 |
| 弩舟 | 可用 | 可用 | 不推荐，可禁用 | 可用 | 可用 |
| 连弩塔 | 可用 | 科技后可用 | 不可用 | 科技后可用 | 科技后可用 |
| 镇关弩台 | 可用 | 可用 | 不可用 | 可用 | 可用 |

第一版建议：

```text
弓手支持全部箭矢模式。
神臂弩手重点支持穿甲、火箭、毒箭。
防空弩兵重点支持穿甲、缓速。
弩舟重点支持火箭、穿甲、缓速。
防御塔只支持火箭、穿甲、缓速，不支持毒箭。
```

---

## 3.4 各箭矢详细规则

### 3.4.1 普通箭

默认攻击模式。

效果：

```text
无额外效果。
无额外代价。
适合普通战斗。
```

UI：

```text
不显示特殊角标。
箭矢模式按钮显示为“普通箭”。
```

---

### 3.4.2 火箭矢

效果：

```text
命中目标后施加燃烧状态。
燃烧持续 3 秒。
每秒造成少量火焰伤害。
对建筑伤害 +10%。
```

代价：

```text
攻击速度 -10%。
```

适合：

```text
建筑
城墙
低护甲单位群
自然阵营回复单位
妖族低级群体单位
```

不适合：

```text
高速单位
高火抗单位
需要快速点杀的目标
```

表现：

```text
箭矢带红橙色火焰尾迹。
命中时出现小火花。
目标身上出现燃烧小特效。
燃烧期间血条旁显示火焰 Debuff 图标。
```

UI Tips：

```text
火箭矢
攻击点燃目标，持续造成火焰伤害。
对建筑伤害提高。
代价：攻速降低。
同一时间只能启用一种箭矢。
```

---

### 3.4.3 毒箭矢

效果：

```text
命中目标后施加中毒状态。
中毒持续 5 秒。
每秒造成少量毒伤。
目标受到的治疗效果 -30%。
```

代价：

```text
对建筑伤害 -20%。
```

适合：

```text
高回复单位
医官治疗体系
自然回复单位
妖族吞噬成长单位
英雄持续回血流
```

不适合：

```text
建筑
机械单位，若设定机械免疫毒素
攻城器械
```

表现：

```text
箭矢带绿色毒雾尾迹。
命中后目标身上出现绿色毒液粒子。
血条旁显示毒滴图标。
治疗被削弱时，治疗数字颜色变暗或出现“治疗降低”提示。
```

UI Tips：

```text
毒箭矢
攻击使目标中毒，并降低其受到的治疗效果。
对建筑效果较差。
同一时间只能启用一种箭矢。
```

---

### 3.4.4 穿甲箭矢

效果：

```text
攻击伤害 +20%。
命中后降低目标护甲 1 点。
破甲持续 4 秒。
```

代价：

```text
攻击速度 -20%。
```

适合：

```text
重骑兵
玄甲重骑
英雄
重甲妖兽
机械重单位
楼船
龙舟旗舰
```

不适合：

```text
大量轻甲单位
军犬
高速骚扰单位
```

表现：

```text
箭矢带金属光泽。
飞行轨迹更直、更亮。
命中时出现破甲碎片。
目标血条旁显示破甲图标。
护甲降低时弹出“-护甲”小字。
```

UI Tips：

```text
穿甲箭矢
提高单发伤害，并降低目标护甲。
代价：攻击速度降低。
适合攻击重甲和高价值目标。
```

---

### 3.4.5 缓速箭矢

效果：

```text
命中目标后降低移动速度 18%。
持续 2 秒。
```

代价：

```text
伤害 -15%。
```

适合：

```text
骑兵
飞行单位
逃跑单位
冲锋单位
正在撤退的工程师
```

不适合：

```text
建筑
不依赖移动的远程阵地单位
静止攻城器械
```

表现：

```text
箭矢带蓝色尾迹。
命中目标后脚下出现蓝色减速圈。
目标移动时有拖尾迟滞感。
血条旁显示减速图标。
```

UI Tips：

```text
缓速箭矢
降低目标移动速度，适合追击或限制骑兵冲锋。
代价：伤害降低。
同一时间只能启用一种箭矢。
```

---

## 3.5 箭矢切换操作规则

### PC 端

```text
选中远程单位或远程单位编队
点击单位面板中的【箭矢模式】按钮
展开箭矢列表
点击目标箭矢模式
单位开始切换
切换完成后生效
```

快捷键建议：

| 快捷键 | 功能 |
|---|---|
| Z | 打开箭矢模式菜单 |
| Z + 1 | 普通箭 |
| Z + 2 | 火箭矢 |
| Z + 3 | 毒箭矢 |
| Z + 4 | 穿甲箭矢 |
| Z + 5 | 缓速箭矢 |

### 手机端

```text
选中远程单位
点击【箭矢模式】按钮
底部弹出横向箭矢模式栏
点击对应箭矢
弹出简短确认或直接切换
```

手机端建议：

```text
普通箭、火箭矢、穿甲箭矢、缓速箭矢直接切换。
毒箭矢第一次使用时显示说明。
```

---

## 3.6 箭矢切换限制

| 限制 | 规则 |
|---|---|
| 切换冷却 | 6 秒 |
| 是否消耗资源 | 不消耗 |
| 是否打断攻击 | 切换期间暂停攻击 0.5 秒 |
| 是否可移动中切换 | 可以 |
| 是否可眩晕中切换 | 不可以 |
| 是否编队统一切换 | 可以 |
| 是否自动切换 | 默认不自动切换 |

---

## 3.7 编队箭矢规则

当玩家选中多个远程单位时：

```text
如果所有单位都支持该箭矢，则统一切换。
如果部分单位不支持该箭矢，则只切换支持单位。
不支持单位保持原模式。
```

UI 提示：

```text
12 个单位切换为火箭矢。
3 个单位不支持该箭矢，保持当前模式。
```

# 4. 盾兵规则

## 4.1 盾兵定位

刀盾兵是华夏的抗远程推进单位。

核心定位：

```text
克制弓手、防空弩兵、普通远程压制。
不克制重骑兵、破甲弩、火焰范围攻击。
```

---

## 4.2 举盾推进技能

解锁科技：盾墙训练  
适用单位：刀盾兵

技能效果：

```text
持续 6 秒。
受到远程伤害 -45%。
移动速度 -20%。
不能使用冲刺类技能。
受到火焰和破甲伤害时减伤效果降低。
```

冷却：

```text
28 秒
```

---

## 4.3 举盾期间的伤害规则

| 伤害来源 | 举盾减免 |
|---|---:|
| 普通箭矢 | -45% |
| 火箭矢初始命中 | -30% |
| 火箭矢燃烧伤害 | 不减免 |
| 毒箭矢命中 | -35% |
| 毒伤 | 不减免 |
| 穿甲箭矢 | -20% |
| 投石车范围攻击 | -10% |
| 骑兵冲锋 | 不减免 |
| 近战攻击 | 不减免 |
| 飞行俯冲 | -15% |

---

## 4.4 举盾操作规则

### PC 端

```text
选中刀盾兵
点击【举盾推进】
单位进入举盾状态
再次点击不能提前取消，或可设置为允许取消
```

建议允许取消：

```text
再次点击【取消举盾】后结束举盾。
取消后技能进入完整冷却。
```

### 手机端

```text
选中刀盾兵
点击右下角【举盾】按钮
按钮进入倒计时状态
状态结束后进入冷却
```

---

## 4.5 举盾 UI 表现

单位 HUD：

```text
血条下方显示盾牌状态条。
举盾期间显示盾牌图标。
```

单位面板：

```text
当前状态：举盾推进
受到远程伤害降低
移动速度降低
```

战斗提示：

```text
远程伤害被格挡时弹出“小盾牌”图标。
```

---

## 4.6 举盾视效表现

```text
刀盾兵举起盾牌。
前方出现半透明盾形弧光。
受到箭矢攻击时盾牌上出现火星。
举盾结束时盾光消散。
```

# 5. 枪兵枪阵规则

## 5.1 枪兵定位

枪兵是反骑兵、反大型单位。

核心定位：

```text
克制轻骑兵、重骑兵、玄甲重骑、大型冲锋单位。
怕弓手、投石车、火焰范围伤害。
```

---

## 5.2 拒马枪阵规则

解锁科技：枪阵训练  
适用单位：枪兵

触发条件：

```text
枪兵停止移动 1 秒。
附近没有被击退或眩晕。
未处于迅捷步伐状态。
```

进入状态：

```text
枪阵状态
```

效果：

```text
对骑兵伤害 +40%。
受到冲锋伤害 -35%。
骑兵冲锋命中枪阵时，自身受到反伤。
```

取消条件：

```text
移动
被击退
被眩晕
使用迅捷步伐
被强制位移
```

---

## 5.3 枪阵与骑兵冲锋交互

| 情况 | 结果 |
|---|---|
| 骑兵冲未列阵枪兵 | 骑兵造成正常冲锋伤害 |
| 骑兵冲枪阵枪兵 | 骑兵伤害降低，骑兵受到反伤 |
| 玄甲重骑冲枪阵 | 仍造成部分伤害，但受到高额反伤 |
| 枪兵移动中被冲 | 不触发枪阵减伤 |

---

## 5.4 枪阵 UI 表现

HUD：

```text
枪兵进入枪阵后，血条旁显示枪阵图标。
```

地面：

```text
枪兵脚下出现小型阵型圆环。
多名枪兵靠近时圆环连接成短线。
```

动作：

```text
枪兵将长枪斜向前方，形成拒马姿态。
```

# 6. 迅捷步伐规则

## 6.1 技能定位

迅捷步伐是步兵科技提供的战术技能。

核心目的：

```text
让步兵短时间调整位置、撤退、追击或抢占阵型点。
但不能无脑永久加速。
```

---

## 6.2 规则

解锁科技：迅捷步伐  
适用单位：枪兵、刀盾兵、弓手、防空弩兵、神臂弩手、羽林卫

效果：

```text
持续 5 秒。
移动速度 +35%。
结束后进入疲惫状态。
疲惫状态持续 4 秒。
疲惫期间移动速度 -20%。
```

冷却：

```text
35 秒
```

限制：

```text
被眩晕时不能使用。
举盾期间使用会取消举盾。
枪阵期间使用会取消枪阵。
```

---

## 6.3 UI与表现

开启时：

```text
单位脚下出现淡金色疾行光。
移动拖尾略微增强。
按钮显示持续倒计时。
```

疲惫时：

```text
脚下出现灰色减速圈。
HUD 显示疲惫图标。
移动速度明显降低。
```

Tips：

```text
迅捷步伐
短时间提升移动速度。
结束后进入疲惫，移动速度降低。
适合撤退、抢位和短距离追击。
```

# 7. 骑兵冲锋规则

## 7.1 骑兵定位

骑兵是华夏的机动和突破单位。

不同骑兵定位：

| 单位 | 定位 |
|---|---|
| 斥候骑 | 侦察、骚扰工兵 |
| 轻骑兵 | 切远程、切后勤 |
| 重骑兵 | 冲阵、突破 |
| 玄甲重骑 | 高价重装冲击单位 |
| 游击骑 | 远程骑射、骚扰 |

---

## 7.2 冲锋通用规则

冲锋触发条件：

```text
骑兵向目标移动一定距离后进入冲锋预备。
距离达到要求后，下一次攻击变为冲锋攻击。
```

推荐距离：

| 单位 | 触发距离 |
|---|---:|
| 轻骑兵 | 4 米 |
| 重骑兵 | 5 米 |
| 玄甲重骑 | 6 米 |

冲锋效果：

```text
首次命中造成额外伤害。
对远程和后勤单位伤害更高。
对枪阵单位伤害降低，并受到反伤。
```

---

## 7.3 轻骑兵突袭

技能：突袭

效果：

```text
快速冲向目标。
下一次攻击造成额外伤害。
如果目标是远程、后勤、攻城器械，额外伤害 +30%。
```

弱点：

```text
撞上枪兵枪阵会受到高额反伤。
被缓速箭矢命中后冲锋距离不足，伤害降低。
```

---

## 7.4 重骑兵冲锋

技能：重骑冲锋

效果：

```text
向目标方向冲锋。
命中第一个敌人造成高额伤害并击退。
冲锋距离越长，伤害越高。
```

限制：

```text
被减速时冲锋伤害降低。
被枪阵阻挡时冲锋被中断。
```

---

## 7.5 玄甲重骑突阵

技能：玄甲突阵

效果：

```text
冲锋后获得临时护盾。
命中敌人越多，护盾越高。
```

弱点：

```text
移动速度较慢。
金属消耗高。
怕枪兵、神臂弩手、穿甲箭矢、破甲鹰弩。
```

---

## 7.6 骑兵 UI与表现

冲锋预备：

```text
骑兵脚下出现速度线。
单位头顶出现小马蹄图标。
```

冲锋命中：

```text
目标被击退或短暂硬直。
弹出“冲锋”文字。
```

被枪阵反制：

```text
骑兵冲锋被打断。
出现长枪格挡特效。
骑兵受到反伤弹字。
```

# 8. 飞行军规则

## 8.1 飞行单位定位

飞行单位负责：

```text
侦察
切后排
反地面高价值目标
反重甲
空军指挥
```

飞行单位弱点：

```text
怕防空弩兵
怕连弩塔
```

```text

水上攻城
```

```text
依赖水域

大型船移动慢
运兵舟战斗能力弱
```


| 水域 | 可通过单位 |

```text
单位不是攻城器械，除非科技允许。
```

# 10. 工程师占领规则

## 10.1 定位

工程师是特殊战略单位，用于占领建筑。

核心：

```text
战斗能力极弱。
战略价值极高。
需要护送。
```

---

## 10.2 可占领目标

| 建筑类型 | 是否可占领 |
|---|---|
| 中立资源建筑 | 可以 |
| 中立科技建筑 | 可以 |
| 敌方资源建筑 | 可以 |
| 敌方防御塔 | 可以，需科技或模式允许 |
| 敌方生产建筑 | 可以 |
| 敌方科技建筑 | 可以 |
| 敌方主城 | 默认不可占领 |
| 奇观/封禅台 | 默认不可占领 |
| 正在建造建筑 | 不可占领 |
| Boss 建筑 | 不可占领 |

---

## 10.3 占领操作

### PC端

```text
选中工程师
点击【占领】
鼠标变为旗帜图标
可占领建筑高亮
点击目标建筑
工程师移动到建筑入口
进入建筑
建筑归属改变
工程师消失
```

### 手机端

```text
选中工程师
点击【占领】
可占领建筑出现黄色外发光
点击目标建筑
弹出确认框
确认后执行占领
```

确认框：

```text
确认占领该建筑？
工程师进入后会消失。
[取消] [确认占领]
```

---

## 10.4 占领时间规则

普通模式：

```text
工程师接触建筑后立即占领。
```

更平衡模式：

```text
工程师进入建筑后需要 3 秒占领时间。
期间建筑闪烁。
若工程师被打断，占领失败。
```

推荐第一版：

```text
中立建筑立即占领。
敌方建筑需要 3 秒占领时间。
```

---

## 10.5 占领表现

```text
工程师进入建筑入口。
建筑上方出现旗帜替换动画。
建筑外发光从敌方颜色转为己方颜色。
占领成功弹出“建筑已占领”。
```

失败表现：

```text
工程师死亡。
占领光效中断。
弹出“占领失败”。
```

# 21. 最终硬规则汇总

```text
1. 箭矢科技可以全部研究，但同一单位同一时间只能启用一种箭矢。
2. 箭矢模式切换有冷却，不消耗资源。
3. 火箭矢点燃敌人，适合打建筑和密集单位。
4. 毒箭矢中毒并降低治疗，适合打回复体系。
5. 穿甲箭矢提高伤害并降低护甲，适合打重甲和英雄。
6. 缓速箭矢降低移动速度，适合限制骑兵和飞行单位。
7. 刀盾兵通过举盾推进克制远程，但不克制近战、火焰和破甲。
8. 枪兵停止移动后进入枪阵，强克制骑兵冲锋。
9. 迅捷步伐提升步兵短时机动，结束后有疲惫减速。
10. 骑兵靠冲锋和机动切后排，但被枪兵和减速克制。
11. 飞行单位可以越过地形，但怕防空单位和防空建筑。
12. 水军只能在水域行动，负责运输、控水和岸边火力。
13. 工程师可以占领建筑，但非常脆弱，怕军犬和远程。
14. 军犬克制工程师和轻甲步兵，但怕重甲、骑兵和防御塔。
15. 攻城器械克制建筑，但移动慢，怕骑兵和飞行单位。
16. 后勤单位提供恢复、修理、鼓舞和调度，但战斗力弱。
17. 所有特殊功能必须有明确按钮、状态图标、Tips 和战场表现。
18. 手机端长按按钮显示详细说明，危险操作必须二次确认。
19. PC端支持快捷键和悬停 Tips，方便 RTS 快速操作。
20. 单位 Tips 必须显示：定位、擅长、害怕、当前模式、已生效科技。
```

# 22. 最终总结

华夏阵营新增功能的核心不是“多几个按钮”，而是让每个兵种都有明确操作空间和克制价值：

```text
远程靠箭矢模式选择战斗目标。
盾兵靠举盾推进抵抗远程。
枪兵靠枪阵反制骑兵。
骑兵靠冲锋和机动切后排。
飞行军靠空中机动打击地面弱点。
水军靠水域控制和登陆改变地图节奏。
工程师靠占领建筑制造战略收益。
军犬靠反工程师和反轻甲保护基地。
攻城器械靠强拆建筑逼迫防守。
后勤单位靠恢复、修理、鼓舞支撑持久战。
```

最终体验目标：

```text
玩家不是只在生产更高级的兵，而是在根据敌人的阵容、地图和科技模式选择正确的克制工具。
```
