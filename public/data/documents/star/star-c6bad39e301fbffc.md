# 《星空掠夺者》基地角色显示、AI行为、动画与气泡系统完整设计文档

> 项目类型：Unity2D 桌面挂机飞船建造游戏  
> 模块定位：基地主界面角色可视化、房间内单位行为、单位工作与生活 AI、状态显示、角色气泡、动画序列帧规范、UI 预制体布局  
> 目标：让飞船基地不再只是静态建筑界面，而是一个“活着的飞船”。玩家能看到每个船员在房间内工作、移动、休息、聊天、吐槽，并能从主界面快速定位任意角色。

---

## 1. 设计目标

### 1.1 当前问题

当前基地主界面存在以下问题：

1. 角色没有真实显示在基地内部，玩家无法感知“船员正在船上生活”。
2. 角色只存在于角色列表、战斗列表或配置界面中，缺少基地内存在感。
3. 玩家不知道某个角色当前在哪个房间、在做什么、是否空闲、是否工作、是否受伤。
4. 角色没有工作循环动画，也没有生活类行为，看起来基地是死的。
5. 角色没有吐槽、气泡、情绪反馈，挂机桌面时缺少趣味性。
6. 角色派遣、岗位、工作、生活、自动行动之间缺少统一 AI 逻辑。

### 1.2 重构目标

本系统需要实现以下体验：

1. **基地主界面常驻显示船员**：部署在基地内的角色会真实出现在飞船房间中。
2. **每个角色有具体房间位置**：角色根据工作岗位、生活需求、随机行为移动到对应房间。
3. **每个角色有当前状态**：例如“维修中”“研究中”“吃饭中”“休息中”“闲逛中”“受伤恢复中”。
4. **角色可快速定位**：基地主界面提供当前部署单位列表，展开后显示所有角色 icon，点击后镜头或视图快速锁定角色。
5. **角色播放对应序列帧动画**：工作时播放工作循环动画，生活时播放生活动画，移动时播放行走动画。
6. **角色会自主行动**：未分配工作时，角色会根据需求执行生活行为，比如吃饭、休息、聊天、锻炼、乱逛。
7. **角色会说话吐槽**：工作、生活、受伤、空闲、饥饿、低士气、发现事件时，会随机弹出气泡文本。
8. **桌面游戏低打扰**：所有 UI 以小弹窗、悬浮按钮、可折叠列表为主，不做全屏遮挡。

## 2. 系统总览

### 2.1 系统组成

基地角色显示系统由以下子系统构成：

| 系统 | 作用 |
|---|---|
| 基地单位部署系统 | 决定哪些角色显示在飞船基地中 |
| 房间位置系统 | 每个房间提供站位点、通行点、工作点、生活点 |
| 角色显示系统 | 在基地房间内生成角色 Sprite/动画对象 |
| AI 行为系统 | 决定角色当前要做什么 |
| 工作系统 | 根据玩家岗位分配执行生产、维修、研究、防御等工作 |
| 生活系统 | 未工作时执行吃饭、休息、闲逛、聊天、锻炼等行为 |
| 状态显示系统 | 在角色头顶显示状态图标、文字、进度条、异常标记 |
| 气泡系统 | 按状态、情绪、种族、职业随机弹出吐槽文本 |
| 快速定位 UI | 角色 icon 列表，点击后定位角色所在位置 |
| 动画系统 | 根据行为播放对应序列帧 |

### 2.2 基础流程

```text
玩家进入基地主界面
        ↓
读取当前部署在基地的角色列表
        ↓
根据每个角色的工作岗位/房间/状态生成角色对象
        ↓
角色 AI 每隔一定时间做一次行为决策
        ↓
如果有工作岗位 → 移动到岗位房间 → 执行工作动画和产出
        ↓
如果没有工作岗位 → 根据生活需求选择生活行为
        ↓
角色在房间中移动、播放动画、显示状态、随机冒气泡
        ↓
玩家点击单位列表 icon → 快速定位角色 → 显示选中光圈和提示箭头
```

## 3. 基地主界面单位显示规则

### 3.1 哪些角色显示在基地里

不是所有角色都必须同时显示，避免桌面窗口太乱。显示规则如下：

| 角色状态 | 是否显示在基地 | 说明 |
|---|---:|---|
| 已部署到基地 | 是 | 常规显示 |
| 已分配工作岗位 | 是 | 显示在对应工作房间 |
| 已设置为休息/疗养 | 是 | 显示在宿舍、医疗舱、休息室 |
| 正在出征/登陆/登舰 | 否 | 显示在战斗界面或任务界面 |
| 远征未归 | 否 | 显示为“外勤中”图标 |
| 仓库未部署单位 | 否 | 只在角色列表中显示 |
| 死亡/冻结/封存单位 | 否 | 特殊状态列表显示 |
| 访客/临时 NPC | 可选 | 事件触发时临时显示 |

### 3.2 基地显示上限

为了避免小窗口拥挤，需要设置显示上限。

| 飞船规模 | 建议显示上限 | 说明 |
|---|---:|---|
| 小型飞船 | 6 人 | 初期飞船，避免拥挤 |
| 中型飞船 | 12 人 | 中期主要规模 |
| 大型飞船 | 20 人 | 高级飞船 |
| 巨型飞船 | 32 人 | 后期基地感更强 |
| 超出上限 | 不显示实体，只显示列表 | 优先显示当前工作角色、收藏角色、高稀有角色 |

### 3.3 显示优先级

当角色数量超过显示上限时，按以下优先级显示：

1. 玩家手动置顶/收藏角色。
2. 当前正在执行重要工作的角色。
3. 当前有异常状态的角色，例如受伤、饥饿、低士气。
4. 当前正在玩家视野附近房间的角色。
5. 高稀有度角色。
6. 最近获得的新角色。
7. 其他普通空闲角色。

### 3.4 角色在房间里的位置规则

角色不应该随便站在房间中心，而是依赖房间配置的行为点。

每个房间需要配置以下点位：

| 点位类型 | 用途 |
|---|---|
| EntrancePoint | 房间入口点 |
| WalkNode | 房间内移动路径点 |
| WorkStationPoint | 工作站位点 |
| IdlePoint | 发呆/等待点 |
| RestPoint | 休息点 |
| SocialPoint | 聊天点 |
| EatPoint | 吃饭点 |
| ExercisePoint | 锻炼点 |
| RepairPoint | 维修点 |
| EmergencyPoint | 警戒/事故处理点 |
| SleepPoint | 睡觉点 |
| DecorationLookPoint | 看装饰/看窗外点 |

## 4. 基地单位列表 UI 设计

### 4.1 入口位置

基地主界面需要新增一个轻量级入口：

```text
基地主窗口右侧 / 底部侧边
┌────────────────────┐
│ 船员  8/12  ▼       │
└────────────────────┘
```

建议位置：

| 桌面布局 | 推荐位置 |
|---|---|
| 横向飞船小窗 | 右侧竖条 |
| 底部常驻窗口 | 左下角展开按钮 |
| 可缩放基地窗口 | 右上角小按钮 |
| 小窗口模式 | 折叠为头像堆叠按钮 |

### 4.2 折叠态

折叠态只显示最关键信息。

```text
┌──────────────┐
│ 👥 船员 8/12 │
└──────────────┘
```

显示内容：

| 内容 | 说明 |
|---|---|
| 船员图标 | 表示基地人员入口 |
| 当前部署数量 | 已部署在基地的角色数量 |
| 最大基地容量 | 当前飞船支持的基地部署上限 |
| 异常红点 | 有角色受伤/空闲/饥饿/低士气时显示 |

### 4.3 展开态

展开后显示角色头像列表。

```text
┌──────────────────────────────┐
│ 当前基地船员  8/12        收起 │
├──────────────────────────────┤
│ [全部][工作][空闲][异常][收藏] │
├──────────────────────────────┤
│ 🟦头像  机械刀兵  维修中  ⚙  │
│ 🟩头像  藤蔓医师  治疗中  ❤  │
│ 🟨头像  星盗枪手  闲逛中  …  │
│ 🟪头像  虚空术士  研究中  ✦  │
└──────────────────────────────┘
```

### 4.4 角色条目内容

每个角色条目显示：

| UI 元素 | 说明 |
|---|---|
| 角色头像 icon | 点击可锁定角色 |
| 稀有度边框 | 白/绿/蓝/紫/橙/红 |
| 名称 | 角色名称或昵称 |
| 种族小图标 | 机械、植物、妖兽、幽灵等 |
| 当前状态文字 | 工作中、休息中、吃饭中、闲逛中 |
| 房间名称 | 可选，鼠标悬停显示 |
| 状态图标 | 工作、饥饿、受伤、低士气等 |
| 小红点 | 有异常时显示 |

### 4.5 点击定位角色逻辑

点击角色 icon 后执行：

```text
点击角色头像
    ↓
判断角色是否在基地内显示
    ↓
如果显示：镜头/基地视图平滑移动到角色所在房间
    ↓
角色脚下显示选中光圈
    ↓
角色头顶显示箭头提示 2 秒
    ↓
弹出小提示：“已定位：机械刀兵，正在维修引擎舱”
```

### 4.6 未显示角色的定位处理

如果角色当前不在基地内显示：

| 状态 | 点击反馈 |
|---|---|
| 外勤中 | 弹提示：“该角色正在星球登陆任务中” |
| 登舰战中 | 弹提示：“该角色正在敌舰内部战斗” |
| 未部署 | 弹提示：“该角色尚未部署到基地” |
| 超出显示上限 | 临时生成角色虚影，并提示所在房间 |
| 受伤休眠 | 定位到医疗舱或休眠舱 |

### 4.7 锁定提示表现

定位角色时需要明显但不吵的提示：

1. 角色脚下出现淡色圆形光圈。
2. 角色头顶出现小箭头。
3. 角色描边闪烁 2 次。
4. 房间边框轻微高亮。
5. 鼠标悬停角色显示小卡片。

### 4.8 角色悬停卡片

```text
┌────────────────────┐
│ 机械刀兵 MK-17      │
│ 稀有度：史诗        │

│ 房间：反应堆舱      │
│ 工作效率：126%      │
```

## 5. 角色状态系统

### 5.1 基础状态分类

| 大类 | 状态 ID | 显示名 | 说明 |
|---|---|---|---|
| 空闲 | Idle | 发呆中 | 没有目标，短暂停留 |
| 移动 | Moving | 移动中 | 正在去目标房间 |
| 工作 | Working | 工作中 | 执行岗位工作 |
| 建设 | Building | 建设中 | 建造/扩建飞船模块 |
| 维修 | Repairing | 维修中 | 修理受损部件 |
| 生产 | Producing | 生产中 | 制造资源/装备/部件 |
| 研究 | Researching | 研究中 | 科研房间执行研究 |
| 防御 | Guarding | 警戒中 | 驻守防御模块 |
| 治疗 | Healing | 治疗中 | 治疗他人或自己 |
| 休息 | Resting | 休息中 | 坐下、躺下、恢复疲劳 |
| 睡觉 | Sleeping | 睡觉中 | 较长时间恢复 |
| 吃饭 | Eating | 吃饭中 | 消耗食物，恢复饥饿 |
| 锻炼 | Training | 锻炼中 | 提升经验/体能 |
| 聊天 | Chatting | 聊天中 | 与其他角色互动 |
| 闲逛 | Wandering | 闲逛中 | 未工作时随机移动 |
| 受伤 | Injured | 受伤中 | 行动效率下降 |
| 低士气 | LowMorale | 情绪低落 | 更容易摸鱼和抱怨 |
| 紧急 | Emergency | 紧急处理中 | 火灾、破损、入侵等 |

### 5.2 头顶状态显示

角色工作中、异常中、被选中时显示头顶 UI。

```text
       [维修中 72%]
          ⚙
        角色
```

### 5.3 状态显示规则

| 情况 | 是否显示头顶状态 | 显示内容 |
|---|---:|---|
| 正在工作 | 是 | 工作图标 + 简短文字 |
| 正在维修/建设/研究 | 是 | 图标 + 进度条 |
| 正在生活行为 | 可选 | 仅图标或短文字 |
| 空闲闲逛 | 默认不显示 | 鼠标悬停才显示 |
| 受伤/饥饿/低士气 | 是 | 异常图标 |
| 被玩家选中 | 是 | 名称 + 状态 |
| 角色太多 | 简化 | 只显示异常状态 |

### 5.4 状态优先级

当角色有多个状态时，按以下优先级显示：

1. 致命异常：重伤、缺氧、中毒。
2. 紧急工作：灭火、修复破洞、抵御入侵。
3. 当前玩家选中。
4. 当前主要工作。
5. 需求异常：饥饿、疲劳、低心情。
6. 生活行为。
7. 普通闲逛。

## 6. AI 行为系统总规则

### 6.1 AI 决策频率

桌面挂机游戏不需要每帧复杂 AI，建议使用低频决策。

| 系统 | 频率 | 说明 |
|---|---:|---|
| 移动插值 | 每帧 | 只负责平滑移动 |
| 动画播放 | 每帧 | 播放序列帧 |
| AI 主决策 | 每 3-8 秒 | 根据状态选择下一个行为 |
| 需求变化 | 每 10 秒 | 饥饿、疲劳、心情变化 |
| 工作产出 | 每 5-30 秒 | 根据工作类型计算 |
| 气泡判定 | 每 15-45 秒 | 随机触发吐槽 |
| 紧急事件判定 | 即时 | 火灾、入侵、损坏等立即打断 |

### 6.2 AI 决策优先级

```text
紧急事件
  > 致命需求
  > 玩家强制指令
  > 已分配工作
  > 高优先级生活需求
  > 社交/训练/闲逛
  > 发呆
```

### 6.3 行为选择伪代码

```csharp
void DecideNextBehavior(Unit unit)
{
    if (unit.HasEmergencyTask())
    {
        StartBehavior(EmergencyBehavior);
        return;
    }

    if (unit.Need.Oxygen < 20 || unit.Health < 25)
    {
        StartBehavior(SeekMedicalOrSafeRoom);
        return;
    }

    if (unit.HasForcedPlayerCommand())
    {
        StartBehavior(PlayerCommandBehavior);
        return;
    }

    if (unit.HasAssignedWork && unit.CanWork())
    {
        StartBehavior(WorkBehavior);
        return;
    }

    if (unit.Need.Hunger > 70)
    {
        StartBehavior(EatBehavior);
        return;
    }

    if (unit.Need.Fatigue > 75)
    {
        StartBehavior(RestBehavior);
        return;
    }

    if (unit.Need.Morale < 35)
    {
        StartBehavior(SocialOrRelaxBehavior);
        return;
    }

    StartBehavior(WeightedRandomLifeBehavior);
}
```

### 6.4 行为打断规则

| 行为 | 可否被打断 | 打断条件 |
|---|---:|---|
| 普通闲逛 | 可 | 玩家指令、工作、紧急事件 |
| 吃饭 | 可 | 紧急事件、战斗警报 |
| 睡觉 | 可 | 入侵、火灾、玩家强制叫醒 |
| 工作 | 可 | 紧急事件、生命危险、岗位取消 |
| 维修 | 可 | 生命危险、玩家取消 |
| 聊天 | 可 | 工作开始、玩家指令 |
| 治疗 | 部分可 | 只被高优先级紧急事件打断 |
| 战斗警戒 | 不可普通打断 | 只能被玩家取消或战斗结束 |

## 7. 工作类 AI 行为

### 7.1 工作行为类型

| 工作类型 | 对应房间 | 角色表现 | 产出/效果 |
|---|---|---|---|
| 采矿控制 | 采矿舱/矿物处理舱 | 操作控制台 | 增加矿物产量 |
| 能源维护 | 反应堆/电池舱 | 拧螺丝、看仪表 | 提升供能稳定 |
| 食物生产 | 温室/厨房/营养舱 | 浇水、切菜、调配 | 产出食物 |
| 装备制造 | 工坊/机械台 | 敲打、焊接、组装 | 制造装备 |
| 部件制造 | 船坞工坊 | 焊接大型部件 | 制造飞船部件 |
| 科学研究 | 实验室/资料舱 | 看屏幕、写记录 | 增加研究点 |
| 医疗治疗 | 医疗舱 | 检查、治疗 | 恢复生命/清异常 |
| 植物培养 | 温室/生态舱 | 浇水、修剪 | 提升生态产出 |
| 防御驻守 | 炮塔舱/护盾舱 | 站岗、瞄准 | 遭遇战时提升防御 |
| 训练执教 | 训练室 | 指导训练 | 提升队员经验 |
| 贸易接待 | 贸易舱 | 对话、整理货物 | 提高交易收益 |
| 清洁维护 | 任意生活房间 | 扫地、擦拭 | 降低故障率 |
| 维修损坏 | 损坏房间 | 焊接、修补 | 恢复部件耐久 |
| 建造扩建 | 新建模块位置 | 搬运、焊接 | 推进建造进度 |
| 数据监察 | 指挥室/雷达室 | 操作屏幕 | 提高事件发现率 |

### 7.2 工作循环流程

```text
检查岗位分配
    ↓
寻找对应房间
    ↓
寻找空闲 WorkStationPoint
    ↓
移动到工作点
    ↓
播放进入工作动画
    ↓
循环播放工作动画
    ↓
周期性结算产出/进度
    ↓
疲劳过高或需求过高 → 暂停工作去生活行为
    ↓
恢复后返回岗位
```

### 7.3 工作效率公式

```text
最终工作效率 = 基础效率
            × 种族工作修正
            × 主职业修正
            × 工作职业修正
            × 装备修正
            × 房间等级修正
            × 心情修正
            × 疲劳修正
            × 异常状态修正
```

建议数值：

| 因素 | 修正范围 |
|---|---:|
| 基础效率 | 100% |
| 种族擅长 | +10% ~ +40% |
| 主职业匹配 | +5% ~ +30% |
| 工作职业匹配 | +10% ~ +60% |
| 装备加成 | +5% ~ +80% |
| 房间等级 | +0% ~ +150% |
| 心情高 | +5% ~ +25% |

## 12. 气泡系统

### 12.1 气泡触发目标

气泡不是纯装饰，需要承担以下作用：

1. 增加基地活人感。
2. 反馈当前角色状态。
3. 提醒玩家问题，例如缺食物、缺床位、工作过载。
4. 表现种族性格差异。
5. 让桌面挂机时更有陪伴感和幽默感。

### 12.2 气泡类型

| 类型 | 触发场景 | 示例 |
|---|---|---|
| 工作吐槽 | 工作循环中 | “这台破机器又冒烟了。” |
| 工作积极 | 高心情工作 | “效率不错，继续！” |
| 疲劳抱怨 | 疲劳高 | “我需要休息一下……” |
| 饥饿提示 | 饥饿高 | “厨房还有吃的吗？” |
| 生活闲聊 | 闲逛/聊天 | “宇宙这么大，为什么我还在加班？” |
| 种族专属 | 特定种族 | 机械：“电压稳定，心情稳定。” |
| 房间专属 | 特定房间 | 温室：“这株菜看起来比舰长精神。” |
| 异常警告 | 受伤/缺氧/火灾 | “这里不太对劲！” |
| 任务反馈 | 战斗/事件后 | “这次收获还不错。” |
| 稀有彩蛋 | 低概率 | “我刚刚是不是看见外面有只猫？” |

### 12.3 气泡触发频率

| 场景 | 触发间隔 | 概率 |
|---|---:|---:|
| 普通工作 | 每 30-60 秒判定 | 20% |
| 高疲劳工作 | 每 20-40 秒判定 | 35% |
| 闲逛生活 | 每 45-90 秒判定 | 15% |
| 聊天行为 | 每 10-20 秒判定 | 50% |
| 异常状态 | 每 15-30 秒判定 | 40% |
| 紧急事件 | 立即触发 | 100% |
| 新角色入驻 | 首次显示 | 100% |

### 12.4 气泡显示规则

| 项目 | 规则 |
|---|---|
| 单个角色冷却 | 30 秒内最多 1 次普通气泡 |
| 全局气泡上限 | 同屏最多 3 个气泡 |
| 气泡持续时间 | 2.5-5 秒，根据文本长度 |
| 优先级 | 警告 > 工作问题 > 角色选中 > 普通吐槽 |
| 文本长度 | 建议 4-18 个字，最多不超过 24 个字 |
| 被遮挡处理 | 气泡自动偏移或隐藏低优先级 |
| 小窗口模式 | 气泡更短，频率降低 |

### 12.5 气泡 UI 样式

```text
       ┌──────────────┐
       │ 好累啊……     │
       └─────┬────────┘
             │

```

## 14. 基地主 UI 弹窗布局

### 14.1 整体桌面 UI 原则

由于本作是桌面游戏，UI 不应全屏化，应遵守：

1. 主基地窗口常驻可缩放。
2. 所有功能界面以弹窗形式出现。
3. 弹窗可拖拽、可缩放、可最小化。
4. 弹窗默认不遮挡整个飞船。
5. 常用信息放在轻量悬浮入口。
6. 详细配置放到二级弹窗。

### 17.1 轻量关系值

| 关系值 | 状态 |
|---:|---|
| -100 ~ -60 | 敌视 |
| -59 ~ -20 | 不合 |
| -19 ~ 19 | 普通 |
| 20 ~ 59 | 熟悉 |
| 60 ~ 100 | 伙伴 |

### 17.2 关系影响

| 行为 | 影响 |
|---|---|
| 聊天成功 | 双方心情上升，关系上升 |
| 聊天失败 | 可能争吵，关系下降 |
| 同房间工作 | 小概率关系上升 |
| 救治/协助 | 关系大幅上升 |
| 种族冲突 | 初始关系偏低 |
| 同族 | 初始关系略高 |

### 17.3 聊天气泡规则

聊天气泡可以两人轮流出现。

```text
角色A：你觉得船长靠谱吗？
角色B：不靠谱，但运气不错。
```

实现方式：

1. 角色 A 进入 Chat 行为。
2. 寻找附近空闲角色 B。
3. 双方移动到 SocialPoint。
4. 播放 Chat 动画。
5. 随机选择对话组。
6. A/B 轮流显示气泡。
7. 结束后增加或降低关系。

## 18. 异常事件与 AI 反应

### 18.1 异常类型

| 异常 | AI 反应 |
|---|---|
| 房间失火 | 维修/工程角色优先灭火，普通角色远离 |
| 船体破损 | 工程角色维修，其他角色避开 |
| 缺氧 | 角色移动到有氧房间或医疗舱 |
| 敌人入侵 | 战斗角色去防御点，非战斗角色躲避 |
| 食物不足 | 角色抱怨，生产岗位优先补食物 |
| 电力不足 | 机械单位充能失败，工作效率降低 |
| 医疗舱满 | 受伤角色在休息室等待 |
| 房间拥挤 | 角色选择其他生活行为 |

### 18.2 紧急状态表现

1. 角色移动速度提升 20%。
2. 头顶显示红色警告图标。
3. 气泡优先播放警告文本。
4. 正在生活的角色立即打断。
5. 工作角色根据岗位决定是否继续。

## 23. MVP 实现范围

第一版不需要一次实现所有复杂行为，建议按以下范围落地：

### 23.1 第一阶段：角色可见 + 定位

必须实现：

1. 基地显示当前部署角色。
2. 每个角色有房间位置。
3. 当前基地船员列表。
4. 点击头像定位角色。
5. 角色头顶显示简单状态。
6. Idle、Walk、Work 三类动画。

### 23.2 第二阶段：工作/生活 AI

增加：

1. 工作岗位行为。
2. 无工作时闲逛。
3. 吃饭、休息、聊天、锻炼。
4. 疲劳、饥饿、士气三个需求。
5. 工作效率受疲劳影响。

### 23.3 第三阶段：气泡与异常

增加：

1. 气泡系统。
2. 工作吐槽和生活吐槽。
3. 种族专属文本。
4. 异常警告气泡。
5. 紧急事件打断 AI。

### 23.4 第四阶段：深度扩展

增加：

1. 角色关系系统。
2. 双人聊天气泡。
3. 种族专属生活行为。
4. 房间脏乱度。
5. 工作岗位自动推荐。
6. 角色显示优先级优化。

```text
机械单位没有工作
```

```text
头顶显示红色警告
气泡：“这里需要马上处理！”
```

## 25. 总结

本系统的核心不是单纯“把角色摆到基地里”，而是让角色成为飞船基地的一部分：

1. 玩家能看到角色在哪里。
2. 玩家能知道角色在做什么。
3. 玩家能快速定位角色。
4. 角色会根据工作和生活需求自主行动。
5. 不工作的角色不会静止不动，而会吃饭、休息、聊天、锻炼、乱逛。
6. 工作中的角色会显示状态和播放对应动画。
7. 角色会用气泡表达状态、性格、种族差异和当前问题。
8. 桌面挂机时，飞船像一个持续运转的小基地，有陪伴感和生命力。

最终效果应该是：玩家即使不打开复杂配置界面，只看桌面上的飞船基地，也能感受到船员正在忙碌、生活、抱怨、休息、成长。这会显著提升《星空掠夺者》的桌面常驻吸引力和长期挂机观赏性。
