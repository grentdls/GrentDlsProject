# 《星空掠夺者》前5分钟新手流程与关键体验文档

版本：V1.0  
目标：设计玩家进入游戏后的前 5 分钟流程，让玩家快速体验资源、建造、单位、战斗、装备、技能、升级、新星球等关键内容。

---

## 1. 前5分钟设计目标

前 5 分钟不是教学全部系统，而是让玩家完成一个清晰的小循环：

```text
飞船破损 → 拾取资源 → 修建核心模块 → 获得2个单位 → 派遣工作 → 小战斗 → 掉装备 → 穿装备 → 升级 → 学技能 → 解锁新建筑 → 出现新星球
```

玩家完成前 5 分钟后，应该理解：

1. 飞船由模块拼出来。
2. 单位会在基地里工作和战斗。
3. 战斗会掉装备和资源。
4. 角色可以升级、穿装备、学技能。
5. 新建筑不是一次性全给，而是随着任务解锁。
6. 地图上会不断出现新的星球和事件。

## 2. 前5分钟功能显示控制

### 2.1 开局显示系统

| 系统 | 是否显示 | 说明 |
|---|---:|---|
| 常驻飞船主界面 | 显示 | 破旧飞船停在桌面边缘 |
| 建造按钮 | 显示 | 只开放核心分页 |
| 背包按钮 | 显示 | 只显示资源、装备、技能书 |
| 角色按钮 | 显示 | 只显示2个初始单位 |
| 地图按钮 | 显示 | 只显示新手星球和漂流残骸点 |
| 战斗信息 | 战斗时显示 | 不常驻占屏 |
| 设置按钮 | 显示 | 基础设置 |
| 职业系统 | 隐藏 | 5分钟内不展示完整职业树 |
| 套装系统 | 隐藏 | 获得第一件套装后再显示 |
| 科研系统 | 隐藏 | 获得残缺蓝图后显示 |
| 贸易系统 | 隐藏 | 发现贸易站后显示 |
| 特殊模块 | 隐藏 | 获得线索后显示 |

### 2.2 初始角色

只给两个单位，保证玩家能理解单位差异。

| 单位 | 定位 | 初始技能 | 初始装备 | 作用 |
|---|---|---|---|---|
| 破损维修机器人 | 工作/修理/远程 | 维护协议 Lv.1 | 无 | 负责建造与维修，教玩家工作单位 |
| 砂爪小兽 | 战斗/近战 | 撕咬 Lv.1 | 无 | 负责登陆战，教玩家战斗单位 |

两个单位差异必须明显：

- 机器人会去维修、搬材料、开控制台。
- 小兽会在生活舱乱逛、吃东西、战斗时冲上去咬。

## 3. 0-5分钟详细流程

### 0:00 - 0:20 进入游戏

#### 画面

- 一个破旧小飞船停在桌面右下角。
- 飞船有 3 个可见房间：破旧舰桥、空仓区、破损推进位。
- 两个角色在飞船内：机器人冒火花，小兽趴在地上。

#### 系统提示

```text
【飞船日志】我们还活着，但飞船只剩下最基础的结构。先收集一点漂流物，把核心设备修起来。
```

#### 自动奖励

| 奖励 | 数量 | 用途 |
|---|---:|---|
| 金属废料 | 80 | 第一建造资源 |
| 食物罐头 | 20 | 船员维持 |
| 燃料 | 15 | 第一次移动 |

#### 玩家操作

点击漂流物小图标，获得资源。

---

### 0:20 - 1:00 建造第一个模块

#### 目标

建造“小型裂变电池”。

#### UI

- 建造按钮出现黄色高亮。
- 打开建造弹窗后只显示“核心分页”。
- 推荐建造卡显示：小型裂变电池。

#### 建造界面只显示

| 模块 | 状态 |
|---|---|
| 破旧舰桥核心 | 已建造 |
| 小型裂变电池 | 可建造，推荐 |
| 老式推进器 | 材料不足或等待引导 |
| 简易货仓 | 可预览，不推荐 |
| 临时生活舱 | 可预览，不推荐 |

#### 建造完成奖励

| 奖励 | 数值 |
|---|---:|
| 飞船电力上限 | +20 |
| 建造经验 | +20 |
| 机器人经验 | +30 |

#### 反馈

机器人移动到电池房间，播放“维修/接线”动画。

气泡：

```text
维修机器人：电力恢复了……虽然只够点亮半个厕所。
```

---

### 1:00 - 1:40 建造推进器

#### 触发资源漂流物

飞船边缘出现“小型金属残骸”。自动拾取或点击拾取。

奖励：

| 奖励 | 数量 |
|---|---:|
| 金属废料 | 120 |
| 燃料 | 20 |

#### 目标

建造“老式推进器”。

#### 建造效果

| 属性 | 增加 |
|---|---:|
| 航行速度 | +10 |
| 可探索星图 | 解锁 |
| 太空遭遇 | 解锁低级漂流物 |

#### 反馈

飞船尾部开始喷出断断续续的火焰。

气泡：

```text
砂爪小兽：这个喷火屁股看起来不太安全。
维修机器人：安全标准已经被我们卖掉了。
```

---

### 1:40 - 2:20 建造简易货仓

#### 目标

建造“简易货仓”。

#### 设计目的

教玩家“库存容量”和“战利品入库”。

#### 建造完成

| 属性 | 增加 |
|---|---:|
| 库存容量 | +100 |
| 可拾取战利品上限 | +10 |

#### 解锁

背包按钮出现轻提示。

背包界面此时只显示 3 个分类：

1. 资源
2. 装备
3. 技能书

---

### 2:20 - 3:00 第一次小型登陆战

#### 触发

地图上出现“近地碎石星”。

系统提示：

```text
扫描到附近有一颗低危险碎石星，上面有少量资源和弱小生物。建议派遣砂爪小兽探索。
```

#### 登陆队

默认派遣：砂爪小兽。

机器人留在船上维修。

#### 敌人

| 敌人 | 数量 | 等级 | 说明 |
|---|---:|---:|---|
| 星尘小虫 | 2 | Lv.1 | 低生命，低攻击 |

#### 战斗时长

20-30 秒。

#### 战斗奖励

| 奖励 | 数量 |
|---|---:|
| 金属废料 | 100 |
| 食物 | 20 |
| 角色经验 | 80 |
| 装备掉落 | 1 件普通武器 |

#### 掉落装备

```text
旧式切割爪 / 普通 / 武器 / 攻击 +8
```

#### 反馈

战后弹出小结算，不打开大背包。

按钮：

- 领取
- 立即装备
- 查看战斗信息

推荐玩家点击“立即装备”。

---

### 3:00 - 3:40 第一次装备更替

#### UI

自动打开角色详情小弹窗，选中砂爪小兽。

只显示：

- 武器槽
- 上衣槽
- 鞋子槽

其他装备槽位隐藏。

#### 装备流程

玩家点击“立即装备”后：

```text
砂爪小兽攻击 18 → 26
战力 86 → 126
```

#### 反馈

砂爪小兽在基地里播放“挥爪试武器”动画。

气泡：

```text
砂爪小兽：这个爪套不错！咬起来更有底气了。
```

---

### 3:40 - 4:20 单位升级与技能书

#### 升级

砂爪小兽从 Lv.1 升到 Lv.2。

提升：

| 属性 | 增加 |
|---|---:|
| 生命 | +18 |
| 攻击 | +3 |
| 防御 | +1 |

#### 技能书掉落

系统奖励一本新手技能书：

```text
技能书：野性冲锋 Lv.1
类型：妖兽基础主动技能
效果：冲向敌人造成 120% 攻击伤害
```

#### 学习流程

- 打开角色技能页。
- 显示技能书可学习。
- 提示技能书一次性消耗。
- 玩家确认学习。

#### 技能学习后

砂爪小兽新增主动技能：野性冲锋。

下一次战斗会自动释放。

---

### 4:20 - 5:00 解锁临时生活舱与第三单位预告

#### 目标

建造“临时生活舱”。

#### 建造效果

| 属性 | 增加 |
|---|---:|
| 船员容量 | +2 |
| 休息恢复 | +10% |
| 生活行为 | 解锁吃饭、休息、聊天 |

#### 建成后触发事件

```text
【求救信号】附近漂来一个破损冷冻舱，里面似乎还有生命迹象。
```

玩家可以选择：

1. 打开冷冻舱：获得第三单位。
2. 拆解冷冻舱：获得材料。
3. 暂时保留：放入事件物品。

推荐默认奖励第三单位：

| 单位 | 种族 | 定位 |
|---|---|---|
| 绿藤维修工 | 植物生命 | 治疗/生产辅助 |

这样玩家在 5 分钟左右获得第三单位，并开始理解“不同种族不同定位”。

## 9. 前5分钟验收标准

如果前 5 分钟完成后，玩家没有做到下面至少 8 项，就说明新手流程还不够顺：

| 验收项 | 是否必须 |
|---|---:|
| 建造 3 个以上飞船模块 | 是 |
| 获得 2 个初始单位 | 是 |
| 看见单位在飞船里行动 | 是 |
| 完成 1 次战斗 | 是 |
| 获得 1 件装备 | 是 |
| 给角色穿上装备 | 是 |
| 角色至少升 1 级 | 是 |
| 学习 1 个技能 | 是 |
| 解锁新建筑或新分页 | 是 |
| 看到新星球/新事件预告 | 是 |

---

## 10. 总结

前 5 分钟必须像一个压缩版完整游戏：

```text
建造 → 工作 → 战斗 → 掉落 → 装备 → 升级 → 技能 → 新单位 → 新建筑
```

不要让玩家在前 5 分钟看复杂系统，而是让玩家不断产生：

```text
我刚刚变强了
我又解锁了新东西
我的飞船更完整了
我的角色真的在基地里活着
```

这才是无限挂机游戏留住玩家的第一步。
