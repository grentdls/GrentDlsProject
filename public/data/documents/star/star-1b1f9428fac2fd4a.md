# 《星空掠夺者》装备与套装系统完整设计文档

> 适用项目：Unity2D 桌面挂机飞船建造 + 自动掠夺战斗游戏  > 文档目标：建立可直接落配置表的装备系统，包含装备槽位、属性定位、稀有度、掉落、强化、套装、词条、以及每个部位 50 件装备内容。

---

## 1. 装备系统定位

装备系统用于解决三件事：

1. **让单位有长期养成目标**：同一种族、同职业的单位，通过装备形成不同战斗流派。
2. **让自动战斗结果更可调**：装备提供攻击、防御、移速、控制、异常、治疗、生产等数值来源。
3. **让掠夺玩法有持续奖励**：飞船战、登舰战、星球登陆战、挂机事件都能产出装备或装备材料。

装备不是单纯加数值，而是和以下系统联动：

- 单位种族：植物更适合治疗、捆绑、毒；机械更适合远程、攻速、火控；妖兽更适合爆发、近战、吸血。
- 主职业：转职和觉醒后解锁更高阶装备适性。
- 副职业：通过通用被动强化装备流派。
- 工作职业：部分装备提升生产、维修、采集、建造效率。
- 飞船部件：穿戴工作装备的单位进入对应房间，会影响产出和建设速度。

### 2.1 槽位穿戴规则

| 规则项 | 设计 |
|---|---|
| 每名单位可穿戴 | 1 武器 + 1 头部 + 1 上衣 + 1 下衣 + 1 手套 + 1 鞋子 + 1 腰带 + 1 项链 + 1 戒指 + 1 耳饰 |
| 武器限制 | 默认所有单位可穿普通武器；大型妖兽、虫巢单位、植物生命可穿戴“殖装/生体/藤蔓类武器”；机械单位可获得机械武器适性加成 |
| 防具限制 | 默认通用；幽灵和虚空单位穿戴实体防具时防御收益降低 20%，穿戴幽影/虚空类装备收益提高 15% |
| 首饰限制 | 默认通用；法术、治疗、召唤、异常流派的核心来源 |
| 工作装备 | 可穿在对应槽位，不影响战斗，但提供生产、建造、采集、维修、科研效率 |
| 套装件识别 | 同一 SetId 的不同部位装备同时穿戴后激活 2/4/6 件套效果 |

### 3.1 装备等级与最终属性公式

装备表中给出的数值为 **装备 1 级基准值**。实际生效数值建议使用以下公式：

```text
最终主属性 = 基准主属性 × 稀有度倍率 × 装备等级系数 × 强化倍率 × 品质浮动
装备等级系数 = 1 + 装备等级 × 0.035
强化倍率 = 1 + 强化等级 × 0.045
品质浮动 = 0.90 ~ 1.12，掉落时随机生成，制造时受工匠等级影响
```

示例：一把基准攻击 60 的史诗武器，装备等级 20，强化 +8，品质 1.05：

```text
60 × 1.75 × (1 + 20×0.035) × (1 + 8×0.045) × 1.05 = 250.05
```

## 5. 套装系统完整逻辑

### 5.1 套装激活规则

| 规则 | 内容 |
|---|---|
| 统计方式 | 统计当前单位身上相同 SetId 的装备数量 |
| 激活门槛 | 2 件、4 件、6 件 |
| 超过 6 件 | 仍只计算 6 件套效果，额外件只提供装备自身属性 |
| 同名重复 | 当前版本每个槽位唯一，所以不存在同槽位重复；后续开放双戒指时，同名戒指只计 1 件 |
| 套装混搭 | 可以同时激活多个 2 件套，例如 2 攻速 + 2 暴击 + 2 范围 |
| 套装品质 | 套装效果不受装备品质浮动影响，避免计算过乱 |
| 套装升级 | 后期可开放“套装共鸣等级”，消耗同套装装备碎片提升套装效果 1%~10% |

## 7. 强化、洗练、拆解、套装补齐

| 系统 | 规则 | 消耗 | 失败惩罚 |
|---|---|---|---|
| 强化 | +1 到 +15，提高主属性和固定属性 | 星铁、装备碎片、金币 | +1~+6 不失败；+7 后失败不降级；+12 后失败消耗保护剂 |
| 洗练 | 重置随机词条，不改变主属性和套装 | 洗练芯片、金币 | 无失败，但可能洗出不想要的词条 |
| 重铸 | 改变装备品质浮动 0.90~1.12 | 重铸核心 | 新品质可保留旧品质二选一 |
| 套装转换 | 同部位、同稀有度装备可转为指定套装 | 套装信标、同稀有装备碎片 | 只能用于史诗及以下，传说/神话不可直接转换 |
| 拆解 | 获得装备碎片、套装碎片、材料 | 无 | 拆解后装备消失 |
| 觉醒 | 传说/神话 +15 后解锁觉醒词条 | 觉醒晶核、同名装备或高阶碎片 | 不失败，消耗巨大 |

| MVP-1 | 掉落、拆解、强化 +10 | 基础养成 |

| MVP-3 | 扩充到每槽位 50 件装备，开放觉醒词条和套装共鸣 | 500 件 |

## 12. 配置落地建议

1. 装备模板和装备实例必须分开，避免玩家每一件装备都复制完整模板数据。
2. 套装效果用 `effectId + value` 实现，不要在 UI 文本里写死逻辑。
3. 装备数值以“基准值 + 倍率公式”管理，后续平衡只改倍率表。
4. 单件装备要比同稀有套装件多 1 个强固定词条，否则玩家只会追套装。
5. 工作装备不要和战斗装备完全分离，允许玩家做“战斗弱一点但产出更高”的取舍。
6. 装备掉落需要保底：连续 20 次没有获得稀有及以上装备时，下次必出稀有；连续 80 次没有获得传说时，下次首领奖励传说权重翻倍。
7. 桌面挂机模式下，不建议频繁弹窗展示装备，应该在右下角用小型浮动提示显示“获得装备”，玩家点击后再展开详情。
