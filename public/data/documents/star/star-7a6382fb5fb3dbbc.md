# 《星空掠夺者》Unity2D 桌面挂机飞船建造游戏完整设计文档

版本：V0.1  
定位：桌面常驻型 2D 飞船建造 + 船员养成 + 自动掠夺战斗游戏  
平台：Windows PC 桌面，后续可扩展 macOS  
推荐引擎：Unity 2D  
核心关键词：桌面挂机、飞船拼装、船员派遣、自动战斗、宇宙掠夺、星球登陆、房间布局、低打扰常驻窗口

---

## 1. 项目一句话概念

玩家在电脑桌面边缘经营一艘不断扩张的宇宙掠夺飞船。飞船由各种房间模块拼接而成，船员可以是生物、机器人、幽灵、外星人、妖兽、植物生命等。游戏在玩家工作或使用电脑时低打扰运行，随机触发宇宙飞船战与星球登陆战，自动战斗后产出资源，再用资源改造飞船、培养船员、解锁更危险的星域。

## 3. 核心体验目标

### 3.1 玩家幻想

玩家不是舰长坐在驾驶舱里手动开炮，而是一个宇宙掠夺集团的幕后船长：

- 设计飞船结构。
- 招募奇怪船员。
- 安排谁开船、谁开炮、谁修船、谁登舰、谁下星球抢东西。
- 看着飞船在桌面边缘自动穿越星空、掠夺敌舰、登陆星球、带回战利品。
- 用战利品把飞船从破烂小船改造成巨型移动星堡。

### 3.2 三大核心乐趣

| 乐趣 | 说明 |
|---|---|
| 飞船拼装乐趣 | 玩家自由摆放房间，像搭积木一样扩船，布局影响效率和战斗。 |
| 船员养成乐趣 | 各种奇怪种族船员拥有职位、技能、天赋、装备和战斗风格。 |
| 掠夺反馈乐趣 | 桌面随机触发战斗，自动产出资源，带来持续惊喜和成长感。 |

### 3.3 体验节奏

平时：桌面边缘低打扰运行。  
偶尔：弹出小事件，玩家选择是否干预。  
空闲：自动探索、自动生产、自动修船、自动战斗。  
管理：点击飞船展开主界面，改造飞船、换装备、分配船员、升级模块。  
高峰：遇到敌舰、星球遗迹、虫群巢穴、幽灵船、黑洞商人等事件。

## 5. 桌面窗口设计

### 5.1 三种窗口形态

#### A. 桌面底栏模式

游戏默认贴在屏幕底部，类似一个横向太空船坞。

- 高度：120px - 260px 可调。
- 宽度：可全屏宽，也可缩成 30% / 50% / 70%。
- 飞船在底部缓慢航行，背景是动态星空。
- 玩家可以看到飞船外观、少量房间、船员活动和事件气泡。
- 适合工作时常驻。

#### B. 桌面侧栏模式

游戏贴在屏幕左侧或右侧。

- 宽度：220px - 360px。
- 适合竖屏副屏或宽屏显示器。
- 飞船可以以纵向停靠舱形式展示。

#### C. 展开管理模式

点击飞船或主按钮后，展开为大窗口。

- 默认 1280×720。
- 可全屏窗口化。
- 显示完整飞船编辑器、船员面板、仓库、星图、战斗报告等。

### 5.2 低打扰原则

1. 普通生产、修理、航行不弹大窗，只显示小图标。
2. 遭遇战斗时先显示小型事件条，玩家不响应则自动处理。
3. 战斗自动进行，玩家可选择“展开观看”或“后台快速结算”。
4. 可开启专注模式：减少动画、降低事件频率、自动领取低级奖励。
5. 可开启点击穿透：不影响桌面操作，只保留快捷键呼出。

## 6. 核心循环

### 6.1 主循环

```text
建造飞船模块
↓
分配船员职位
↓
桌面挂机自动航行
↓
生产资源 / 发现事件 / 遭遇敌舰 / 发现星球
↓
自动战斗或自动登陆
↓
获得资源、装备、蓝图、船员、特殊材料
↓
升级房间、扩建飞船、培养船员
↓
进入更高危险星域
```

### 6.2 短期循环，1 - 5 分钟

- 收取生产模块产出的资源。
- 处理一次小事件。
- 看一次自动战斗结果。
- 给船员换装备或升级技能。
- 修理受损模块。

### 6.3 中期循环，30 - 120 分钟

- 解锁新模块。
- 扩建飞船一层或一段船体。
- 招募新船员。
- 完成一个星域目标。
- 击败一个精英敌舰或星球首领。

### 6.4 长期循环，数天到数周

- 从破烂掠夺艇升级到大型掠夺母舰。
- 收集不同种族船员组合。
- 解锁高级飞船流派。
- 打通多个星域。
- 收集稀有蓝图和传说装备。
- 打造不同风格的飞船布局。

## 7. 飞船系统总览

飞船是游戏的核心载体。它既是基地，也是战斗单位，也是生产系统，也是桌面展示对象。

### 7.1 飞船构成

飞船由以下层级组成：

```text
飞船主体 Ship
 ├─ 船体框架 Hull Frame
 ├─ 房间模块 Room Module
 ├─ 连接通道 Corridor
 ├─ 外挂设备 External Device
 ├─ 能源线路 Power Link
 ├─ 船员 Crew
 └─ 舰载库存 Inventory
```

### 7.2 建造网格

推荐采用 2D 方格布局。

| 项目 | 建议 |
|---|---|
| 基础格子 | 1×1 |
| 小房间 | 2×1 / 2×2 |
| 中房间 | 3×2 / 4×2 |
| 大房间 | 5×2 / 6×3 |
| 最大飞船宽度 | 初期 12 格，中期 24 格，后期 48 格以上 |
| 最大飞船高度 | 初期 3 层，中期 5 层，后期 8 层以上 |

### 7.3 建造规则

1. 房间必须连接船体框架。
2. 房间之间必须有通道或舱门才能让船员移动。
3. 核心舱、动力舱、驾驶舱被摧毁会导致飞船严重瘫痪。
4. 能源类模块需要通过能源线路连接。
5. 生存类模块影响船员状态。
6. 武器类模块需要炮手或 AI 炮控系统才能发挥完整效率。
7. 防御类模块通常要靠近外壳，护盾类模块则需要能源支持。
8. 生产类模块需要仓储或物流通道，否则效率降低。

## 8. 飞船属性体系

### 8.1 舰船基础属性

| 属性 | 作用 |
|---|---|
| 船体耐久 | 飞船整体生命值，归零后进入漂流/战败状态。 |
| 护盾值 | 吸收远程伤害，战斗中可恢复。 |
| 装甲值 | 减少船体和房间受到的物理伤害。 |
| 能源上限 | 决定可运行模块数量。 |
| 能源负载 | 当前所有运行模块消耗。 |
| 氧气/生态 | 决定生物船员生存效率。 |
| 温度稳定 | 影响机械、植物、幽灵等特殊船员效率。 |
| 航速 | 决定探索速度、逃跑成功率、接敌速度。 |
| 探测 | 决定发现事件、稀有星球、隐藏敌舰概率。 |
| 隐匿 | 决定避开强敌、偷袭、潜入成功率。 |
| 货舱容量 | 决定资源携带上限。 |
| 登舰能力 | 决定船员进入敌舰速度和成功率。 |
| 登陆能力 | 决定星球登陆人数、登陆补给和撤离速度。 |

### 8.2 舰船衍生评分

| 评分 | 计算方向 |
|---|---|
| 战斗力 | 武器、炮手、护盾、装甲、攻击模块等级综合。 |
| 生存力 | 船体、氧气、医疗、消防、维修、食物综合。 |
| 生产力 | 生产房间数量、相邻加成、船员职业效率综合。 |
| 掠夺力 | 登舰舱、突击队、仓储、破解、隐匿综合。 |
| 探索力 | 驾驶、雷达、航速、星图数据、侦察船员综合。 |

## 10. 模块详细设计

### 10.1 核心模块

#### 10.1.1 核心舱

飞船最重要的心脏。

- 提供飞船基础控制力。
- 决定最大模块数量上限。
- 决定最大船员数量基础值。
- 被摧毁后飞船进入瘫痪状态。

升级效果：

| 等级 | 效果 |
|---|---|
| Lv1 | 解锁基础飞船功能。 |
| Lv2 | 增加模块上限和能源调度。 |
| Lv3 | 解锁自动战斗策略预设。 |
| Lv4 | 解锁多小队登陆。 |
| Lv5 | 解锁星堡级扩建。 |

#### 10.1.2 驾驶舱

- 提供航速、闪避、逃跑概率。
- 需要驾驶员职位。
- 驾驶员属性影响航行事件概率。

#### 10.1.3 动力炉

- 提供能源上限。
- 越高级越容易产生过热、辐射或能源泄漏事件。
- 相邻工程师舱、冷却室可降低风险。

---

### 10.2 生产模块

| 模块 | 功能 | 适合船员 | 相邻加成 |
|---|---|---|---|
| 废料回收间 | 将战利品残骸转化为废料 | 机器人、拾荒者 | 靠近货舱 +10% |
| 合金熔炉 | 生产合金 | 机器人、火属性生物 | 靠近动力炉 +15%，过热风险 +5% |
| 晶矿精炼室 | 精炼星晶 | 外星人、植物生命 | 靠近冷却室 +10% |
| 黑市复制机 | 复制低级装备或材料 | 幽灵、外星商贩 | 靠近数据室 +10% |
| 生物培养舱 | 产出生物材料、食物 | 植物生命、妖兽 | 靠近生态舱 +20% |
| 数据破解室 | 产出星图、情报、蓝图碎片 | 机器人、外星人 | 靠近雷达室 +15% |

生产模块设计原则：

1. 每个生产模块都需要至少 1 名船员或自动设备。
2. 没有船员时低效率运行。
3. 船员职业、种族、天赋影响产出。
4. 房间受损会降低效率，严重受损会停产。
5. 高级生产可能带来事故，例如过热、污染、虫群失控、幽灵溢出。

---

### 10.3 生存模块

| 模块 | 功能 | 影响船员 |
|---|---|---|
| 氧气室 | 提供氧气 | 人类、妖兽、植物生命需要 |
| 食堂 | 恢复饱食度和士气 | 大多数生物船员需要 |
| 休眠舱 | 船员休息、恢复疲劳 | 所有船员可用，机器人改为充电 |
| 医疗舱 | 治疗伤势、清除异常 | 生物船员效果最佳 |
| 维修舱 | 维修机器人和装备 | 机器人、机械外星人效果最佳 |
| 灵异稳定室 | 稳定幽灵船员 | 幽灵、星灵需要 |
| 生态舱 | 提高植物生命效率 | 植物生命需要 |

生存系统不应太硬核。推荐采用“效率惩罚”而不是频繁死亡。

示例：

- 氧气不足：生物船员工作效率 -30%，战斗恢复 -20%。
- 食物不足：士气下降，自动战斗伤害 -10%。
- 幽灵稳定不足：幽灵船员可能乱飘、附身设备、触发灵异事件。
- 机器人维护不足：机器人可能短路，工作效率下降。

### 10.4 防御模块

| 模块 | 功能 | 特点 |
|---|---|---|
| 护盾室 | 生成护盾值 | 消耗能源高，适合中后期。 |
| 装甲板 | 增加局部防御 | 外挂设备，不占房间。 |
| 拦截炮塔 | 拦截导弹和登陆艇 | 需要炮手或 AI 控制。 |
| 维修无人机舱 | 自动修理受损房间 | 消耗零件。 |
| 灭火喷淋室 | 处理火灾 | 防止动力炉和武器舱连锁爆炸。 |
| 反登舰电网 | 对入侵敌人造成持续伤害 | 适合防守流。 |
| 隔离舱门 | 阻挡敌方登舰单位移动 | 可以拖延时间。 |

---

### 10.5 攻击模块

| 武器 | 伤害类型 | 优点 | 缺点 |
|---|---|---|---|
| 脉冲激光炮 | 能量 | 命中稳定，适合打护盾 | 对厚装甲一般 |
| 导弹仓 | 爆炸 | 高爆发，能打房间 | 会被拦截，消耗弹药 |
| 轨道炮 | 物理 | 穿甲强 | 充能慢，需要高能源 |
| 电磁干扰炮 | 控制 | 瘫痪敌方模块 | 直接伤害低 |
| 生物孢子炮 | 毒素 | 对生物船员强 | 对机器人较弱 |
| 幽能炮 | 灵异 | 无视部分护盾 | 容易反噬幽灵模块 |
| 虫群投射器 | 登舰辅助 | 投放小虫扰乱敌舰 | 需要虫巢资源 |

攻击模块不只打总血量，还能打具体房间。这样飞船布局才有意义。

可攻击目标：

- 敌方武器舱。
- 敌方护盾室。
- 敌方动力炉。
- 敌方驾驶舱。
- 敌方医疗舱。
- 敌方货舱。
- 敌方登舰舱。

### 10.6 登舰模块

登舰是《星空掠夺者》的核心差异化玩法。

| 模块 | 功能 |
|---|---|
| 登舰舱 | 释放突击舱，靠近敌舰后让小队登船。 |
| 传送室 | 直接将小队传送到敌舰指定房间，有失败概率。 |
| 破门钻机 | 撞开敌舰外壳，适合重装登舰流。 |
| 隐形潜入舱 | 让少量单位潜入敌舰，适合刺杀和偷货。 |
| 回收钩爪 | 拉近敌舰，降低双方距离。 |

登舰成功后，战斗从“舰炮战”转入“房间战”。

### 10.7 登陆模块

| 模块 | 功能 |

| 空投舱 | 快速投放突击单位，撤退慢。 |
| 采掘车库 | 提高矿物、遗迹资源收益。 |
| 生物标本舱 | 捕获星球生物。 |
| 星球扫描室 | 提前识别星球危险和奖励。 |
| 便携护盾发生器 | 提高登陆小队生存。 |

## 11. 房间布局玩法

### 11.1 相邻加成

布局不是纯装饰，应提供清晰的策略收益。

| 布局组合 | 效果 |
|---|---|
| 动力炉 + 冷却室 | 过热概率降低。 |
| 武器舱 + 弹药库 | 武器伤害提高，但爆炸风险提高。 |
| 医疗舱 + 休眠舱 | 船员恢复速度提高。 |
| 雷达室 + 数据破解室 | 发现事件和蓝图概率提高。 |
| 登舰舱 + 武器库 | 登舰小队初始伤害提高。 |
| 货舱 + 废料回收间 | 回收效率提高。 |
| 生态舱 + 生物培养舱 | 食物和生物材料产出提高。 |
| 灵异稳定室 + 幽能炮 | 幽能武器伤害提高，反噬降低。 |

### 11.2 危险相邻

不是所有相邻都是好事。

| 危险组合 | 负面效果 |
|---|---|
| 动力炉 + 弹药库 | 被击中时爆炸伤害提高。 |
| 虫巢 + 食堂 | 可能触发虫群偷吃事件。 |
| 幽灵祭坛 + 休眠舱 | 船员可能做噩梦，士气下降。 |
| 生物培养舱 + 数据室 | 植物根须可能破坏数据线路。 |
| 高温模块 + 冷藏仓 | 冷藏资源损耗提高。 |

### 11.3 舱门与通道

舱门和通道决定船员移动与敌方入侵路径。

- 宽通道：移动快，占空间。
- 窄通道：占空间少，但拥堵。
- 防爆门：阻挡火灾和入侵者。
- 气闸门：可将敌人排出太空，但可能误伤己方。
- 秘密通道：适合幽灵、刺客、机器人维修单位快速移动。

## 12. 船员系统

船员是飞船上的核心单位。他们既能工作，也能战斗，也能登陆星球。

### 12.1 船员基础属性

| 属性 | 作用 |
|---|---|
| 生命 | 战斗生存。 |
| 护甲 | 减少物理伤害。 |
| 护盾 | 减少能量伤害。 |
| 攻击 | 基础输出。 |
| 技术 | 影响生产、维修、破解、炮控。 |
| 驾驶 | 影响航速、闪避、逃跑。 |
| 精神 | 影响幽能、士气、异常抵抗。 |
| 体质 | 影响疲劳、毒素、星球环境抗性。 |
| 掠夺 | 影响搜刮、开箱、偷取、捕获。 |
| 忠诚 | 影响叛变、偷懒、特殊事件。 |

### 12.2 船员种族类型

| 类型 | 特点 | 优势职位 | 弱点 |
|---|---|---|---|
| 人类拾荒者 | 均衡，装备适配高 | 驾驶、枪手、登陆兵 | 生存依赖氧气食物 |
| 机器人 | 不吃饭、不缺氧 | 工程、炮控、维修 | 怕电磁干扰 |
| 幽灵 | 可穿墙、精神攻击 | 潜入、灵异模块、侦察 | 需要灵异稳定 |
| 外星人 | 技术和精神强 | 破解、研究、护盾 | 忠诚变化大 |
| 妖兽 | 近战强，体质高 | 登舰、登陆、守卫 | 技术低，食量大 |
| 植物生命 | 可生产食物，恢复强 | 生态、治疗、支援 | 怕火、怕寒冷 |
| 虫族个体 | 数量成长快 | 登舰、污染、消耗战 | 士气和控制难 |
| 星灵 | 精神强，稀有 | 幽能炮、治疗、控制 | 生命较低 |
| 克隆人 | 成长方向可定制 | 任意职位 | 容易出现基因缺陷 |
| 史莱姆 | 可变形，占用小 | 维修、搬运、堵门 | 容易被高温蒸发 |

### 12.3 船员品质

| 品质 | 颜色 | 特点 |
|---|---|---|
| 普通 | 白 | 1 个被动词条。 |
| 优秀 | 绿 | 2 个词条，小概率特殊技能。 |
| 稀有 | 蓝 | 3 个词条，成长更高。 |
| 史诗 | 紫 | 4 个词条，自带专属技能。 |
| 传说 | 橙 | 5 个词条，拥有专属事件线。 |
| 异常 | 红 | 极强但有严重副作用。 |

### 13.2 自动派遣规则

自动派遣策略：

1. 优先满足核心舱、驾驶舱、动力炉。
2. 战斗时优先补齐武器舱和护盾室。
3. 受损时工程师自动前往受损房间。
4. 敌人登舰时守卫自动拦截。
5. 发现星球时登陆小队自动集合。
6. 船员疲劳过高时自动换班。

### 13.3 班次系统

为了适配挂机，不建议做太复杂的排班，但可以有轻量版：

- 主班：常驻关键岗位。
- 备班：主班疲劳后替换。
- 战斗班：战斗触发后自动上岗。
- 登陆班：星球事件触发后集合。
- 登舰班：敌舰接近后集合。

## 15. 掠夺玩法一：飞船间战斗

### 15.1 触发方式

飞船挂机航行时随机遇到：

- 商船。
- 海盗船。
- 赏金猎人。
- 机械巡逻舰。
- 幽灵船。
- 虫族母舰。
- 废弃残骸。
- 星域守卫。
- 黑市押运船。
- BOSS 级巨舰。

### 15.2 战斗阶段

```text
发现目标
↓
目标识别
↓
选择策略：攻击 / 靠近登舰 / 偷袭 / 逃跑 / 谈判
↓
远程舰炮战
↓
接近战 / 登舰战
↓
房间争夺
↓
敌舰投降 / 被摧毁 / 被掠夺 / 我方撤退
↓
结算奖励
```

### 15.3 自动战斗策略

玩家可以预设策略：

| 策略 | 行为 |
|---|---|
| 稳健掠夺 | 先打护盾和武器，保留敌方货舱。 |
| 快速击毁 | 集火核心舱，尽快结束。 |
| 登舰优先 | 拉近距离，优先派突击队。 |
| 偷货撤离 | 潜入货舱，抢到资源就撤退。 |
| 活捉船员 | 降低杀伤，优先瘫痪医疗舱和驾驶舱。 |
| 避战保命 | 低血量时自动逃跑。 |

### 15.4 舰炮战规则

每艘船有多个可被攻击的房间。武器可指定目标，也可由 AI 自动选择。

基础命中公式示例：

```text
命中率 = 武器基础命中 + 炮手技术×0.3 + 雷达加成 - 敌方闪避 - 干扰惩罚
```

基础伤害公式示例：

```text
最终伤害 = 武器基础伤害 × 技能倍率 × 暴击倍率 - 护盾吸收 - 装甲减伤
```

### 15.5 登舰战规则

登舰成功后，我方小队进入敌舰房间。

房间战斗表现：

- 单位在房间内自动攻击。
- 舱门会影响移动路径。
- 敌方守卫会拦截。
- 房间被占领后会产生效果。

占领效果：

| 房间 | 占领效果 |
|---|---|
| 武器舱 | 敌舰对应武器停火。 |
| 护盾室 | 敌舰护盾恢复降低。 |
| 动力炉 | 敌舰能源下降。 |
| 驾驶舱 | 敌舰闪避和逃跑失败率提高。 |
| 医疗舱 | 敌方治疗停止。 |
| 货舱 | 直接获得部分战利品。 |
| 核心舱 | 敌舰投降或战斗结束。 |

### 15.6 战斗失败处理

失败不应过度惩罚，适合桌面挂机体验。

失败结果：

- 飞船进入漂流状态。
- 部分资源损失。
- 部分房间损坏。
- 船员受伤或被俘。
- 触发救援倒计时或自动维修。

避免设计：

- 不建议永久删除飞船。
- 不建议高频船员永久死亡。
- 可以将永久死亡作为高难度模式选项。

```text

↓

↓

```

### 16.3 星球探索节点

每次登陆由若干节点组成。

| 节点 | 内容 |
|---|---|
| 资源点 | 采矿、采集植物、拆残骸。 |

| 遗迹点 | 破解、开箱、触发机关。 |
| 营地点 | 恢复生命和士气。 |

### 16.4 登陆危险值

登陆时间越久，危险值越高。

```text
危险值每经过一个节点 +10
战斗失败 +20
触发陷阱 +15
击败首领 -30
拥有星球扫描室，初始危险 -10
拥有便携护盾发生器，每次战斗危险增加降低 20%
```

危险值达到 100 时触发强制撤离战或追击战。

## 18. 自动战斗系统

### 18.1 自动战斗目标

自动战斗必须满足：

1. 玩家不操作也能正常推进。
2. 玩家设置策略后能明显影响结果。
3. 战斗过程可以缩略展示，也可以展开观看。
4. 结果要有清晰反馈：谁输出高、谁受伤、抢到什么、哪个房间被打坏。

### 18.2 战斗单位 AI

单位行为优先级示例：

#### 登舰突击兵

1. 攻击当前房间敌人。
2. 如果房间敌人清空，占领房间。
3. 如果目标房间未占领，向目标移动。
4. 生命低于 30% 时寻找医疗员或撤退。

#### 工程师

1. 修复正在燃烧或漏气房间。
2. 修复动力炉、护盾室、武器舱。
3. 战斗中优先保持关键模块运行。
4. 无修理任务时回岗位工作。

#### 医疗员

1. 治疗生命最低的己方单位。
2. 清除中毒、燃烧、恐惧等异常。
3. 无治疗目标时跟随突击队。

#### 守卫

1. 拦截入侵敌人。
2. 保护核心舱。
3. 保护医疗舱和动力炉。
4. 清理残余敌人。

### 18.3 战斗报告

每次战斗结束后生成报告。

报告内容：

- 战斗结果：胜利 / 撤退 / 失败 / 投降。
- 用时。
- 我方损失。
- 敌方损失。
- 船员 MVP。
- 获得资源。
- 获得装备。
- 获得蓝图。
- 房间受损列表。
- 船员伤病列表。

## 23. 美术风格

### 23.1 整体风格

建议采用“Q版怪诞科幻 + 桌面微缩玩具感”。

关键词：

- 2D 卡通。
- 可爱但有掠夺感。
- 颜色鲜明。
- 房间模块读形清楚。
- 船员小人动作夸张。
- 飞船像一组可拼接玩具积木。
- 星空背景轻量，不影响桌面使用。

### 23.2 飞船视觉规则

- 每个房间有清楚外轮廓。
- 模块颜色区分功能：生产偏黄橙，生存偏绿蓝，防御偏蓝灰，攻击偏红紫，登舰偏黑黄警示。
- 外壳可破损、冒烟、闪电、漏气。
- 房间内要有明显动态小物件，例如熔炉火光、氧气泡泡、雷达转盘、炮管充能。

### 23.3 船员视觉规则

不同种族需要强识别：

| 种族 | 视觉特征 |
|---|---|
| 人类 | 太空夹克、头盔、工具包。 |
| 机器人 | 方块头、机械关节、屏幕脸。 |
| 幽灵 | 半透明、漂浮、拖尾。 |
| 外星人 | 大眼、触角、奇怪肤色。 |
| 妖兽 | 兽耳、爪子、角、尾巴。 |
| 植物生命 | 叶子、藤蔓、花苞、根须。 |
| 虫族 | 甲壳、复眼、尖足。 |
| 星灵 | 发光轮廓、漂浮符文。 |

### 23.4 特效

- 激光：细长光束，清楚命中房间。
- 导弹：小火尾 + 爆炸云。
- 护盾：半透明圆弧。
- 登舰：突击舱飞出或传送光圈。
- 登陆：小艇从飞船下方飞走。
- 生产：小型图标冒泡。
- 维修：扳手、电焊火花。

### 25.6 自动模拟 Tick

桌面挂机不需要每帧都算复杂逻辑。建议分层 Tick：

| Tick | 内容 |
|---|---|
| 每帧 | UI 动画、角色移动表现。 |
| 每 1 秒 | 船员状态、生产进度、战斗小步进。 |
| 每 10 秒 | 事件概率、资源批量结算。 |
| 每 60 秒 | 星域探索、离线收益记录。 |

### 25.7 离线收益

离线收益不建议完全等同在线收益。

建议公式：

```text
离线收益 = 在线基础收益 × 离线时长 × 离线效率系数
```

离线效率系数：

- 默认 30%。
- 建造自动化模块后提高到 50%。
- 高级 AI 核心提高到 70%。
- 离线最多计算 8 小时，后续可通过升级扩展。

## 28. 数值设计初稿

### 28.1 模块升级消耗

```text
升级消耗 = 基础消耗 × 等级倍率 × 稀有度倍率
```

示例：

| 等级 | 倍率 |
|---|---|
| Lv1 → Lv2 | 1.5 |
| Lv2 → Lv3 | 2.2 |
| Lv3 → Lv4 | 3.2 |
| Lv4 → Lv5 | 4.8 |

### 28.2 生产收益

```text
每分钟产出 = 房间基础产出 × 房间等级倍率 × 船员效率 × 相邻加成 × 状态修正
```

状态修正：

- 房间满耐久：100%。
- 房间轻度受损：80%。
- 房间中度受损：50%。
- 房间严重受损：20%。
- 无能源：0%。

### 28.3 船员工作效率

```text
船员效率 = 100% + 职位匹配加成 + 属性加成 + 装备加成 + 天赋加成 - 疲劳惩罚
```

职位匹配：

- 完全匹配：+30%。
- 部分匹配：+10%。
- 不匹配：-20%。

### 28.4 战斗奖励

```text
奖励 = 敌人基础奖励 × 星域难度倍率 × 保留货舱倍率 × 掠夺效率 × 随机波动
```

保留货舱倍率：

- 敌舰被彻底炸毁：0.6。
- 敌舰投降：1.0。
- 成功占领货舱：1.3。
- 偷货撤离：0.8，但风险低。

## 30. 特殊系统建议

### 30.1 通缉系统

掠夺商船、攻击帝国船、偷黑市货物会提高通缉值。

通缉值影响：

- 遭遇赏金猎人概率提高。
- 黑市价格提高或降低，取决于声望。
- 高通缉可解锁海盗专属任务。
- 太高会触发帝国围剿。

### 30.2 声望系统

阵营：

- 黑市联盟。
- 帝国舰队。
- 虫群意识。
- 幽灵议会。
- 机械自治体。
- 星球自由民。

玩家可以当纯海盗，也可以当雇佣兵、黑商、救援者。

### 30.3 船员关系

轻量关系系统可以增加桌面陪伴感。

- 船员会聊天。
- 船员会吵架。
- 同种族有默契。
- 机器人和植物可能互相不理解。
- 幽灵可能吓到人类。
- 好关系提高协作效率。
- 坏关系触发小事件。

### 30.4 船体外观收藏

不影响战斗或少量影响属性。

- 船壳皮肤。
- 舰旗。
- 船名牌。
- 尾焰颜色。
- 房间装饰。
- 船员皮肤。

## 35. 关键风险与解决方案

| 风险 | 说明 | 解决方案 |
|---|---|---|
| 桌面游戏打扰用户 | 弹窗太多会烦 | 专注模式、自动处理、事件降频。 |
| 飞船布局过复杂 | 新手看不懂 | 初期只开放少量模块，逐步解锁。 |
| 自动战斗无聊 | 玩家没有参与感 | 加策略预设、战斗报告、MVP 船员表现。 |
| 资源线太多 | 管理压力大 | 前期只给废料、星币、合金，后期再加特殊资源。 |
| Unity 桌面透明兼容问题 | 技术实现可能复杂 | MVP 先做普通无边框窗口，再逐步加置顶、透明、点击穿透。 |
| 美术量巨大 | 船员和模块太多 | 先统一模板和骨架，模块化换色换件。 |

## 36. 设计总结

《星空掠夺者》的核心不是做一款普通太空战斗游戏，而是做一艘“住在玩家桌面上的宇宙掠夺飞船”。

它的长期吸引力来自三件事：

1. **飞船越来越大**：玩家能直观看到自己的飞船从破烂小艇成长为巨型星舰。
2. **船员越来越怪**：机器人、幽灵、妖兽、植物生命、外星人组成离谱但有趣的舰队。
3. **事件越来越丰富**：桌面上不断冒出敌舰、星球、黑市、遗迹、事故和战利品。

开发上，建议先把“桌面小窗口 + 飞船拼装 + 自动战斗 + 奖励升级”做成 MVP。只要这条循环好玩，再逐步扩展船员养成、星域、星球登陆和高级模块，就能形成有长期更新潜力的桌面挂机策略游戏。
