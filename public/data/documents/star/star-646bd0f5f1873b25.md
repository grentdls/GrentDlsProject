# 《星空掠夺者》无限挂机成长体验总规划文档

版本：V1.0  
目标：重新规划《星空掠夺者》的整体成长体验，让玩家在前 5 分钟快速理解核心玩法，在 6 小时后进入稳定刷取角色、装备、部件、星球和事件的无尽循环。

---

## 1. 核心问题

当前成长体验差，主要不是内容不足，而是内容释放节奏不对。

常见问题包括：

1. 开局给的信息太多，玩家看不到真正关键的目标。
2. 飞船建筑、单位、装备、技能、星球、敌舰、掉落都很复杂，但没有按时间分层释放。
3. 前 5 分钟没有足够密集的正反馈，玩家无法快速体验“资源→建造→单位→战斗→装备→升级→再建造”的循环。
4. 中期缺少明确目标，玩家不知道刷什么。
5. 6 小时后如果只是重复拿资源，会变得无聊；必须让玩家开始追求高稀有角色、高稀有装备、套装词条、技能书、蓝图、觉醒材料。
6. 桌面挂机游戏需要“短反馈 + 长目标”并存，而不是一直弹复杂界面。

---

## 2. 新成长体验总原则

### 2.1 前 5 分钟要给玩家完整体验闭环

前 5 分钟必须让玩家体验到以下内容：

```text
获得资源 → 建造关键飞船模块 → 获得单位 → 派遣单位 → 自动战斗 → 获得装备 → 穿装备 → 角色升级 → 学技能 → 解锁新建筑
```

注意：这不是让玩家理解全部系统，而是让玩家知道“这个游戏一直在变强”。

### 2.2 前期只显示关键系统

开局不要显示所有内容。前 5 分钟只显示：

| 系统 | 开局状态 |
|---|---|
| 飞船建造 | 只显示核心分页内 4-5 个关键建筑 |
| 单位 | 只给 2 个单位 |
| 背包 | 只显示资源、装备、技能书 3 个分类 |
| 装备 | 只开放武器、上衣、鞋子 3 个槽位 |
| 技能 | 只开放 1 个主动技能槽、1 个被动技能槽 |
| 地图 | 只显示 1 个新手星球和 1 个漂流残骸点 |
| 战斗 | 只出现小型登陆战或小型敌舰战 |
| 职业 | 不显示复杂职业树，只显示“基础职业” |
| 科研 | 暂时隐藏 |
| 套装 | 暂时隐藏，只在获得第 1 件套装后开启说明 |

### 2.3 成长分成 7 个阶段

| 阶段 | 时间 | 体验目标 | 核心产出 |
|---|---:|---|---|
| 阶段 0 | 0-1分钟 | 看到飞船、点第一下建造 | 金属、食物、电力、核心建筑 |
| 阶段 1 | 1-5分钟 | 完成第一轮闭环 | 2个单位、1件装备、1本技能书、3个建筑 |
| 阶段 2 | 5-15分钟 | 解锁基础飞船管理 | 更多建筑、第三个单位、基础战斗队伍 |
| 阶段 3 | 15-60分钟 | 开始选择玩法方向 | 武器/防御/生产/生存分页逐步开放 |
| 阶段 4 | 1-3小时 | 开始刷装备和部件 | 套装、技能书、稀有单位、蓝图残片 |
| 阶段 5 | 3-6小时 | 开始形成流派 | 职业进阶、套装2件/4件、特殊星球 |
| 阶段 6 | 6小时后 | 进入无限挂机刷取 | 角色、装备、词条、觉醒、蓝图、传说掉落 |

## 3. 游戏循环设计

### 3.1 10秒级反馈

玩家每 5-15 秒应该看到小反馈。

| 反馈 | 示例 |
|---|---|
| 资源跳字 | +5 金属、+2 食物、+1 星尘 |
| 船员动作 | 机械工在维修，植物单位在浇水 |
| 气泡吐槽 | “这破船还能飞真是奇迹……” |
| 建筑进度 | 小型电池 72% → 100% |
| 小事件 | 漂流箱靠近飞船，可自动拾取 |

### 3.2 1分钟级反馈

每 45-90 秒给一次明确收益。

| 反馈 | 示例 |
|---|---|
| 建筑完成 | 建成简易货仓，库存 +100 |
| 单位升级 | 机械工 Lv.1 → Lv.2 |
| 装备掉落 | 获得“旧式激光枪” |
| 星球节点完成 | 采集完小矿点 |
| 小战斗胜利 | 击败 2 只荒星小兽 |

### 3.3 5分钟级反馈

每 3-6 分钟给一次系统变化。

| 反馈 | 示例 |
|---|---|
| 新分页开放 | 生产分页解锁 |
| 新单位加入 | 获得第三个单位：砂爪兽 |
| 新星球出现 | 地图上出现“赤锈废铁星” |
| 新蓝图 | 获得“轻型舰炮蓝图” |
| 新玩法 | 解锁飞船战或登陆战 |

### 3.4 30分钟级反馈

每 20-40 分钟给一次长期目标推进。

| 反馈 | 示例 |
|---|---|
| 核心升级 | 舰桥 Lv.2 → Lv.3 |
| 套装进度 | 暴击套 1/2 → 2/2 |
| 职业解锁 | 机械单位可以转职为枪炮机械 |
| 星区推进 | 解锁第二星区 |
| 稀有单位 | 获得 SR 单位或高稀有技能 |

### 3.5 6小时后循环

6小时后玩家不再追求“解锁基础系统”，而是追求“更稀有、更好词条、更适合流派”。

```text
刷星球 → 刷敌舰 → 刷角色 → 刷装备 → 刷技能书 → 洗词条 → 强化套装 → 挑战更高星区 → 无限循环
```

## 4. 成长线总表

| 成长线 | 前5分钟 | 5-60分钟 | 1-6小时 | 6小时后 |
|---|---|---|---|---|
| 飞船建筑 | 只建核心、电力、货仓、生活舱 | 解锁生产、防御、攻击 | 解锁科研、贸易、特殊结构 | 刷蓝图、刷高级模块、重构布局 |
| 单位 | 2个初始单位 | 获得第三、第四个单位 | 组建登舰队/登陆队 | 刷取高稀有单位和高稀有初始技能 |

## 6. 稀有度体验规划


| 稀有度 | 颜色 | 玩家感知 | 主要投放阶段 | 掉落定位 | 成长价值 |
|---|---|---|---|---|---|
| 普通 | 灰白 | 能用、过渡 | 0-30分钟 | 基础装备/材料/单位 | 让玩家快速填满槽位 |
| 优秀 | 绿色 | 比初始强一点 | 5-60分钟 | 早期可替换装备、低阶技能书 | 让玩家体验换装提升 |
| 精良 | 蓝色 | 明显更强 | 30分钟-3小时 | 中期主力装备、部件、单位 | 形成第一个流派雏形 |
| 稀有 | 紫色 | 值得保留 | 1-6小时 | 套装件、职业技能、特殊部件 | 让玩家开始刷词条 |
| 史诗 | 橙色 | 一次大提升 | 3-12小时 | 核心套装、强单位、高阶技能 | 形成核心构筑 |
| 传说 | 红金 | 长期目标 | 6小时后 | 觉醒材料、特殊单位、强套装 | 无尽刷取的主要追求 |
| 神话 | 彩虹/星辉 | 极低概率惊喜 | 12小时后 | 唯一装备、神话技能、特殊蓝图 | 形成长期炫耀与收藏 |


### 6.1 前 5 分钟稀有度策略

前 5 分钟不要给太多稀有度，但必须给一次“比普通更强”的体验。

推荐投放：

| 时间 | 奖励 | 稀有度 | 目的 |
|---|---|---|---|
| 2分钟 | 旧式激光枪 | 普通 | 教玩家装备武器 |
| 3分钟 | 绿色护甲/鞋子 | 优秀 | 让玩家感受到颜色差异 |
| 4分钟 | 基础技能书 | 普通 | 教玩家技能学习 |
| 5分钟 | 蓝色部件残片或装备 | 精良 | 制造第一波惊喜 |

### 6.2 6小时后稀有度策略

6小时后必须让玩家追求：

1. 高稀有单位。
2. 单位出生自带高稀有技能。
3. 装备主词条 + 副词条。
4. 套装件数和套装词条。
5. 飞船特殊部件蓝图。
6. 职业进阶材料。
7. 觉醒材料。
8. 星球稀有度和敌舰稀有度。

## 8. 内容隐藏与显示节奏

### 8.1 前 5 分钟隐藏内容

以下内容前 5 分钟不要显示：

- 全部职业树。
- 觉醒系统。
- 全部装备槽位。
- 全部建筑分页。
- 全部星球类型。
- 高级敌舰。
- 套装图鉴。
- 蓝图库大界面。
- 交易系统。
- 虚空/虫巢/幽灵/古代科技模块。

### 8.2 逐步显示规则

| 内容 | 显示时间/条件 |
|---|---|
| 装备槽位 | 获得对应槽位第一件装备后显示 |
| 技能槽 | 学会第一个技能后显示完整技能页 |
| 建筑分页 | 完成对应任务后显示 |
| 星球类型 | 地图扫描或任务解锁后显示 |
| 职业进阶 | 单位达到 Lv.10 后显示 |
| 副职业 | 完成训练舱建设后显示 |
| 工作职业 | 建造对应工作模块后显示 |
| 套装 | 获得第一件套装装备后显示 |
| 蓝图库 | 获得第一张残缺蓝图后显示 |
| 特殊模块 | 获得对应线索后显示 |

## 9. 无尽挂机的长期目标结构

### 9.1 6小时后的核心玩法

6小时后，玩家不应该只是“等资源”，而应该围绕下面几个目标无限刷：

| 目标 | 刷取内容 | 优化方式 |
|---|---|---|
| 刷角色 | 高稀有单位、高稀有初始技能 | 招募、俘虏、孵化、事件 |
| 刷装备 | 套装、词条、强化材料 | 星球战、敌舰战、Boss |
| 刷技能 | 主职业/副职业/觉醒技能书 | 精英敌人、任务、商人 |
| 刷飞船部件 | 高级模块、特殊结构 | 敌舰掠夺、蓝图解析 |
| 刷星球 | 高稀有星球、高收益事件 | 地图扫描、远航、信标 |
| 刷敌舰 | 高稀有敌舰、完整部件 | 悬赏、星区危险提升 |
| 刷材料 | 觉醒石、重铸石、词条尘 | 高阶事件、分解、Boss |
| 刷布局 | 不同飞船构筑 | 建筑重构、自动策略调整 |

### 9.2 无尽刷取不能只加数值

必须给玩家以下变化：

1. 新词条组合。
2. 新职业路线。
3. 新单位初始技能组合。
4. 新套装搭配。
5. 新星球环境。
6. 新敌舰结构。
7. 新挂机策略。
8. 新自动战斗效率。

## 10. 推荐实现顺序

### 10.1 第一版必须改的内容

1. 前 5 分钟新手流程。
2. 建筑分页隐藏与显示。
3. 初始只给 2 个单位。
4. 第一次装备掉落与穿戴。
5. 第一次技能书学习。
6. 第一次角色升级。
7. 第一次小战斗。
8. 第一个新星球。
9. 资源和战力曲线。
10. 6小时后的刷取循环。

### 10.2 第一版不要做太复杂

暂时不要在前期强推：

- 全职业树。
- 大量套装。
- 神话技能。
- 复杂贸易。
- 多星区政治。
- 超大敌舰。
- 高级 UI 图鉴。

## 11. 总结

新版成长体验的关键词是：

```text
前5分钟密集奖励
前1小时持续解锁
前6小时形成构筑
6小时后无限刷取
```

玩家必须在最早阶段就体验到：

- 我建了一艘飞船。
- 我的单位在飞船里活动。
- 我打赢了战斗。
- 我掉了装备。
- 我给角色穿上了装备。
- 我学了技能。
- 角色升级了。
- 新建筑解锁了。
- 新星球出现了。

只要前 5 分钟这条闭环成立，后续庞大的飞船、单位、装备、职业、星球系统才有承载空间。
