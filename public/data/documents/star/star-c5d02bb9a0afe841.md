# 《星空掠夺者》飞船部件系统完整设计文档

版本：V0.2  
适用项目：Unity2D 桌面挂机飞船建造游戏《星空掠夺者》  
文档目标：补全飞船拼装逻辑、部件获得规则、结构流派差异、数值公式、100 个可配置部件数据。  
设计重点：飞船不是单纯外观拼图，而是一个由房间、管线、电力、船员职位、战斗目标共同组成的可模拟系统。

---

## 1. 飞船系统总目标

飞船系统要同时承担 5 个作用：

1. **桌面展示对象**：玩家挂机时能看到飞船房间、船员活动、炮火、维修、生产动画。
2. **建造拼装玩法**：飞船由格子房间自由拼接，布局影响效率、生存、战斗和掠夺收益。
3. **挂机产出机器**：生产模块、生存模块、仓储模块在桌面模式持续运转。
4. **自动战斗载体**：敌舰战中，武器、护盾、装甲、引擎、登舰模块都会成为目标。
5. **船员职位容器**：每个房间可以安排船员工作，不同种族和职业会放大不同模块效果。

核心体验应当是：

> 玩家像拼积木一样搭飞船，看着这艘怪异飞船在桌面边缘自动航行、生产、开炮、登舰、登陆、抢资源，再用资源继续把飞船改得更离谱。

## 2. 飞船格子与房间基础规则

### 2.1 飞船网格

飞船使用 2D 横向剖面网格。

| 项目 | 规则 |
|---|---|
| 单格大小 | Unity 世界坐标建议 1×1；UI 像素可按 64×64 或 96×96 表现。 |
| 初始飞船 | 8×4 可建造格。 |
| 中期飞船 | 14×6 可建造格。 |
| 后期飞船 | 24×10 可建造格。 |
| 终局旗舰 | 36×14 可建造格，可分多层甲板。 |
| 房间尺寸 | 常见 1×1、2×1、2×2、3×1、3×2、3×3、4×2、4×3、5×2。 |
| 连接方向 | 每个房间拥有上、下、左、右连接口。没有连接口的边不能通行。 |
| 支撑规则 | 普通房间至少需要 1 条边连接已有结构；外挂机翼、推进器可只连接 1 边。 |
| 通行规则 | 船员只能通过走廊、门、房间连接口移动。 |
| 外壳规则 | 位于飞船外边缘的房间更容易被敌舰命中。 |

### 2.2 房间状态

每个部件在运行中会有状态：

| 状态 | 效果 |
|---|---|
| 正常 | 按 100% 数值运行。 |
| 低效 | 耐久低于 50%，效率降至 70%。 |
| 严重破损 | 耐久低于 25%，效率降至 35%，可能触发火灾/漏气/短路。 |
| 停机 | 耐久为 0 或缺少电力，功能关闭。 |
| 着火 | 每秒损失耐久，船员需要灭火或等待灭火模块。 |
| 缺氧 | 生物船员持续掉血，机器人/幽灵不受影响。 |
| 被入侵 | 敌方登舰单位进入房间，房间无法稳定工作。 |
| 异常污染 | 虚空、古神、生化类模块可能产生特殊负面效果。 |

### 2.3 飞船基础属性

| 属性 | 说明 |
|---|---|
| 舰体耐久 | 所有房间 HP 的加权总和，核心房间被毁会导致战斗失败。 |
| 装甲 | 降低实体、导弹、登舰破门伤害。 |
| 护盾 | 先于舰体承受能量/炮击伤害，可由护盾模块恢复。 |
| 电力 | 部件运行需要电力；电力不足时按优先级停机。 |
| 热量 | 武器、引擎、反应堆增加热量；热量过高降低效率并可能起火。 |
| 氧气 | 生物、妖兽、植物、外星人消耗氧气；机器人/幽灵不消耗。 |
| 食物/水 | 影响生物船员长线挂机续航。 |
| 船员容量 | 决定可上船船员数量。 |
| 工作位 | 决定能分配多少船员到指定房间。 |
| 航速 | 影响探索速度、撤退概率、战斗先手。 |
| 闪避 | 降低被敌舰武器命中概率。 |
| 隐匿 | 降低被强敌发现概率，增加伏击收益。 |
| 扫描 | 提高事件品质、战利品识别、敌舰弱点标记。 |
| 掠夺容量 | 决定战斗/登陆后能带回多少资源。 |
| 士气 | 影响船员工作效率、叛逃、恐惧、疯狂等事件。 |

## 3. 部件数据结构

### 3.1 Unity 推荐实现方式

建议使用 **ScriptableObject + JSON 存档实例**。

- `ShipPartDefinition`：静态配置，记录部件基础属性。
- `ShipPartInstance`：玩家实际拥有的部件实例，记录等级、耐久、词条、安装位置。
- `ShipGridSaveData`：飞船布局存档，记录每个实例的位置、旋转、连接状态。

## 4. 部件获得规则

### 4.1 获得来源总表

| 来源 | 说明 | 适合掉落部件 |
|---|---|---|
| 初始蓝图 | 新手阶段直接开放 | 舰桥、走廊、货仓、氧气、轻型炮、基础推进器 |
| 制造 | 消耗资源按蓝图制造 | 机械、废土、基础生存、基础生产 |
| 敌舰掉落 | 击败敌舰后按敌舰类型掉落 | 武器、防御、引擎、登舰部件 |
| 登舰掠夺 | 船员进入敌舰房间后夺取 | 敌舰当前装备的对应房间蓝图或损坏部件 |
| 星球登陆 | 在星球战斗后获取 | 生物、植物、矿物、古代、虫巢类部件 |
| 商店购买 | 空间站、黑市、虚空商人、阵营商人 | 指定结构流派部件 |
| 科研解锁 | 消耗数据、样本、晶体研究 | 高级生产、护盾、外星科技、时间类部件 |
| 合成进化 | 低级部件 + 稀有材料合成 | 高阶同类部件或混合结构部件 |
| 事件奖励 | 黑洞、幽灵船、古神遗迹、星门等 | 虚空、幽灵、传奇、神话部件 |
| 声望奖励 | 完成阵营任务 | 阵营特色部件 |

### 4.2 掉落判定流程

一次战斗或登陆结束后，按以下流程生成奖励：

1. 确定事件等级：普通、危险、精英、首领、终局。
2. 确定场景标签：机械、植物、虚空、幽灵、虫巢、晶体、海盗、军用、生态、古代。
3. 根据玩家扫描值决定可见战利品数量。
4. 根据掠夺容量决定最终可带走数量。
5. 根据登舰/登陆表现增加额外房间掉落概率。
6. 对每个候选部件计算稀有度权重。
7. 生成部件实例，随机质量和词条。

### 4.3 稀有度掉落基础概率

| 事件等级 | 普通 | 精良 | 稀有 | 史诗 | 传奇 | 神话 |
|---|---:|---:|---:|---:|---:|---:|
| 普通事件 | 72% | 22% | 6% | 0% | 0% | 0% |
| 危险事件 | 55% | 30% | 12% | 3% | 0% | 0% |
| 精英事件 | 38% | 34% | 20% | 7% | 1% | 0% |
| 首领事件 | 20% | 30% | 30% | 15% | 5% | 0% |
| 终局事件 | 5% | 18% | 32% | 28% | 14% | 3% |

### 4.4 扫描、掠夺和登舰对掉落的影响

| 条件 | 加成 |
|---|---|
| 扫描值每 10 点 | 稀有及以上候选数量 +1%，最高 +15%。 |
| 战利品扫描仪在线 | 稀有部件掉率 +6%。 |
| 成功登舰并占领敌舰核心 | 额外抽取 1 个敌舰房间蓝图。 |
| 登舰队击毁目标房间 | 有 25% 获得损坏部件实例。 |
| 使用采矿切割炮造成最后一击 | 拆船资源 +15%，武器掉率 -3%。 |
| 掠夺仓库容量不足 | 低价值资源被丢弃，部件优先保留。 |
| 星球登陆全员存活 | 样本、食物、生物部件掉率 +10%。 |

## 5. 部件品质、等级与词条

### 5.1 部件等级

每个部件可升级 1 到 10 级。

```text
升级后核心数值 = 基础数值 × (1 + 0.12 × (等级 - 1))
耐久额外成长 = 基础耐久 × (1 + 0.15 × (等级 - 1))
能耗成长 = 基础能耗 × (1 + 0.04 × floor((等级 - 1) / 2))
```

解释：

- 升级会明显强化产出、攻击、护盾、容量。
- 能耗只轻微增长，避免升级后反而难用。
- 高级武器和反应堆升级后热量也会增加，需要散热布局。

### 5.2 品质修正

| 品质 | 数值修正 | 词条数 | 说明 |
|---|---:|---:|---|
| 破损 | 70% | 0 | 战斗中拆下的旧部件，修复后可变为普通。 |
| 老旧 | 90% | 0-1 | 便宜，适合过渡。 |
| 标准 | 100% | 1 | 制造和普通掉落默认品质。 |
| 精制 | 112% | 2 | 中期主力。 |
| 完美 | 128% | 3 | 高价值部件。 |
| 异常 | 100%-150% | 1-4 | 数值波动大，常伴随副作用。 |

### 5.3 稀有度倍率

| 稀有度 | 核心数值倍率 | 最高词条数 | 典型来源 |
|---|---:|---:|---|
| 普通 | 1.00 | 1 | 初始、制作、普通敌舰 |
| 精良 | 1.15 | 2 | 危险事件、商店 |
| 稀有 | 1.35 | 2 | 精英敌舰、科研 |

| 传奇 | 2.05 | 4 | 终局事件、BOSS |
| 神话 | 2.60 | 5 | 超稀有终局合成 |

## 6. 结构流派差异

### 6.1 机械结构

定位：稳定、可制造、适合大多数基础系统。

| 优点 | 缺点 |
|---|---|
| 数值稳定，容易维修，可量产 | 热量偏高，外观普通，后期缺少特殊能力 |
| 和机器人船员相性好 | 被电磁、黑客、短路克制 |
| 适合生产、武器、推进、防御 | 需要电力和维修资源 |

表现：金属板、铆钉、齿轮、管道、火花、黄黑警示条。

### 6.2 废土结构

定位：便宜、粗暴、掠夺感强。

| 优点 | 缺点 |
|---|---|
| 建造便宜，容易从海盗和废船获得 | 数值波动大，容易起火或爆炸 |
| 登舰、掠夺、仓储效果好 | 士气加成少，美观度低 |
| 可作为前中期过渡 | 后期需要替换或改造 |

表现：锈铁、焊接补丁、沙袋、骷髅旗、外露弹药箱。

### 6.3 植物结构

定位：生态循环、自愈、氧气食物。

| 优点 | 缺点 |
|---|---|
| 提供氧气、食物、士气、自愈 | 怕火，怕真空，爆发伤害低 |
| 和植物生命、妖兽相性好 | 需要水、生物质或光照 |
| 适合长线挂机和星球登陆 | 容易被毒素/枯萎事件影响 |

表现：藤蔓、树根、发光花、绿色液体、半透明叶片。

### 6.4 生体/虫巢结构

定位：高生命值、登舰防守、样本生产。

| 优点 | 缺点 |
|---|---|
| HP 高，可再生，能生成小虫/触手 | 士气负面，可能寄生或暴走 |
| 妖兽、虫族船员效率高 | 需要生物质喂养 |
| 适合登陆、生化攻击、防守 | 被火焰和冷冻克制 |

表现：肉质墙、甲壳、骨刺、黏液、蠕动管道、蜂巢孔洞。

### 6.5 晶体结构

定位：护盾、精密加工、能量增幅。

| 优点 | 缺点 |
|---|---|
| 护盾高，能量武器相性好 | HP 和装甲偏低 |
| 可提升护盾恢复和星灵类收益 | 需要晶体材料维护 |
| 适合高科技、后排核心舱 | 被震荡、音波、破晶武器克制 |

表现：蓝紫晶柱、棱镜、折射光、透明护壁、星尘粒子。

### 6.6 虚空结构

定位：隐匿、异常产出、穿透攻击。

| 优点 | 缺点 |
|---|---|
| 隐匿高，部分攻击无视护盾/装甲 | 士气下降，普通船员不适应 |
| 可产出虚空尘和特殊交易 | 维修困难，副作用强 |
| 适合刺客型、奇袭型飞船 | 容易触发异常污染 |

表现：黑紫裂隙、空间扭曲、吞光边缘、漂浮碎片。

### 6.7 幽灵结构

定位：精神攻击、亡灵船员、异常防御。

| 优点 | 缺点 |
|---|---|
| 不需要氧气，能影响敌方士气 | 对机器人效果较弱 |
| 幽灵船员效率高 | 普通船员士气下降 |
| 可让死亡转化为幽灵玩法 | 光能/圣物类敌人克制 |

表现：半透明墙体、魂火、漂浮符文、残破木铁混合物。

### 6.8 外星科技

定位：高效率、高压缩、高风险。

| 优点 | 缺点 |
|---|---|
| 单格数值高，功能复合 | 耗电高，维修材料稀有 |
| 适合中后期核心模块 | 过热、过载、黑客风险高 |
| 和外星人、机器人相性好 | 初期很难养得起 |

表现：银白外壳、悬浮环、蓝色全息、细密能量纹路。

## 7. 布局与相邻加成规则

### 7.1 基础相邻规则

| 布局 | 效果 |
|---|---|
| 生产模块相邻货仓 | 产出 +10%，搬运时间 -15%。 |
| 武器相邻弹药库 | 实弹武器装填 -10%，但被击中爆炸风险 +5%。 |
| 武器相邻散热/水循环 | 热量 -10%。 |
| 护盾室相邻晶体护壁 | 护盾上限 +12%。 |
| 引擎相邻燃料罐 | 航行消耗 -5%，但爆炸风险上升。 |
| 舰桥相邻战术室 | 命中 +3%，撤退成功率 +5%。 |
| 宿舍相邻娱乐/花园 | 士气 +3。 |
| 虚空模块过多 | 隐匿提升，但普通船员士气下降。 |
| 生体模块相邻防疫隔离间 | 寄生/疾病扩散概率 -30%。 |
| 走廊节点连续连接 | 船员移动速度逐段提升，最高 +25%。 |

### 7.2 模块区域建议

| 区域 | 推荐放置 | 原因 |
|---|---|---|
| 船头 | 装甲、护盾、武器、重力锚 | 更容易接敌，承担火力输出。 |
| 船中 | 舰桥、宿舍、生存、指挥、医疗 | 保护核心，缩短船员移动距离。 |
| 船尾 | 引擎、燃料、推进、散热 | 符合视觉直觉，便于航行表现。 |
| 下层 | 货仓、弹药、燃料、掠夺仓库 | 重型部件放下层更合理。 |
| 外挂 | 太阳帆、推进器、外部炮塔、装甲 | 可以做明显外观变化。 |
| 隔离区 | 虚空、幽灵、古神、生化高危 | 降低异常扩散。 |

### 7.3 电力优先级

电力不足时按优先级保留：

1. 舰桥、氧气、隔离门。
2. 护盾、防御、灭火。
3. 武器、引擎。
4. 医疗、生存生产。
5. 普通生产、训练、研究。
6. 娱乐、装饰、低优先级仓储。

## 8. 战斗中的部件逻辑

### 8.1 敌舰战

飞船间战斗不是简单扣总血，而是按房间目标计算。

| 命中目标 | 结果 |
|---|---|
| 外壳/装甲 | 降低舰体耐久，可能暴露内部房间。 |
| 武器房 | 让对应武器停火或降低攻击频率。 |
| 引擎房 | 降低闪避、撤退和接舷能力。 |
| 护盾房 | 护盾恢复停止，护盾上限降低。 |
| 氧气房 | 生物船员进入缺氧危机。 |
| 舰桥 | 命中/闪避/撤退大幅下降。 |
| 弹药库/燃料罐 | 有概率爆炸，造成范围伤害。 |
| 登舰舱 | 阻止敌我双方继续派遣登舰队。 |

### 8.2 登舰战

当两艘飞船接近后，船员会从登舰舱进入敌舰。

| 系统 | 规则 |
|---|---|
| 登舰人数 | 由登舰舱门、登陆艇、船员职位决定。 |
| 路径 | 从敌舰外部接入点开始，按房间连接口移动。 |
| 目标 | 优先攻击舰桥、武器、护盾、货仓。 |
| 防守 | 自动炮塔、掩体、隔离门可拖慢敌人。 |
| 占领 | 清空房间敌人后可占领，降低敌舰对应功能。 |
| 掠夺 | 占领货仓/蓝图室/核心房间会增加战利品。 |

### 8.3 星球登陆战

登陆战和飞船房间有关，但表现为小队下船战斗。

| 飞船部件 | 对登陆战影响 |
|---|---|
| 突击登陆艇 | 登陆人数 +4，开局护盾 +20。 |
| 星球空投仓 | 快速到达目标区，但撤退变慢。 |
| 登陆医疗站 | 战后伤员恢复，药品消耗下降。 |
| 生物样本采集舱 | 生物样本掉落提高。 |
| 战利品扫描仪 | 显示高价值资源点。 |
| 行星掠夺钻机 | 大幅提高矿物收益，但提高敌意。 |
| 太阳藻/植物花园 | 提升长时间远征补给。 |

## 10. 部件制造资源规则

### 10.1 基础资源

| 资源 | 用途 | 主要来源 |
|---|---|---|
| 废料 | 基础建造、修理 | 废船、普通战斗、拆解 |
| 合金 | 机械结构、防御、武器 | 矿渣熔炉、矿区星球 |
| 晶体粉 | 晶体、护盾、跃迁 | 星尘精炼、晶体星球 |
| 生物质 | 植物、生体、虫巢 | 生物星球、发酵罐 |
| 数据 | 外星科技、科研、技能 | 数据黑匣子、机器人敌舰 |
| 虚空尘 | 虚空部件、异常交易 | 虚空裂隙、虚空凝露井 |
| 魂火 | 幽灵部件、亡灵船员 | 幽灵船、安魂室 |
| 弹药 | 导弹、鱼雷、爆破 | 弹药库、军火商 |
| 燃料 | 航行、引擎、远征 | 燃料罐、矿业公司 |
| 样本 | 生化研究、植物/妖兽 | 登陆战、生物采集舱 |

### 10.2 制造成本公式

```text
制造成本 = 基础成本 × 稀有度倍率 × 尺寸倍率 × 科技等级倍率

尺寸倍率 = 1 + (占格数 - 1) × 0.18
科技等级倍率 = 1 + (Tier - 1) × 0.35
```

稀有度倍率：

| 稀有度 | 成本倍率 |
|---|---:|
| 普通 | 1.0 |
| 精良 | 1.4 |
| 稀有 | 2.1 |
| 史诗 | 3.5 |
| 传奇 | 6.0 |
| 神话 | 10.0 |

### 10.3 示例制造成本

| 部件 | 示例成本 |
|---|---|
| 轻型激光炮 | 废料 80、合金 50、数据 5 |
| 氧气循环舱 | 废料 60、合金 35、数据 3 |
| 能量护盾室 | 合金 100、晶体粉 80、数据 30 |
| 虚空凝露井 | 合金 80、虚空尘 50、魂火 20、数据 40 |
| 终焉主炮 | 合金 3000、晶体粉 800、数据 1200、反物质核心 1 |

## 11. 自动生成部件实例的规则

当玩家获得一个部件时，不直接只给固定模板，而是生成实例。

### 11.1 生成流程

```text
1. 根据事件标签筛选部件池。
2. 按事件等级决定稀有度。
3. 从对应稀有度部件中随机 1 个 definitionId。
4. 随机品质：破损/老旧/标准/精制/完美/异常。
5. 根据品质和稀有度生成词条数量。
6. 根据结构流派生成专属词条。
7. 如果是敌舰拆下来的部件，currentHp = 20%-65%。
8. 如果是商店购买，currentHp = 100%，但价格提高。
9. 如果是异常事件，添加副作用词条。
```

### 11.2 结构专属词条池

| 结构 | 专属词条 |
|---|---|
| 机械 | 节能、自动维护、强化外壳、高效散热、标准接口 |
| 废土 | 掠夺标记、粗暴改装、低价维修、爆炸风险 |
| 植物 | 生体再生、氧气增殖、怕火、共生根系 |
| 生体/虫巢 | 甲壳增厚、寄生反击、孵化虫群、生物质饥饿 |
| 晶体 | 晶格增幅、护盾共振、破晶脆弱、能量折射 |
| 虚空 | 虚空共鸣、空间扭曲、士气污染、相位闪避 |
| 幽灵 | 魂火稳定、恐惧气息、亡魂庇护、圣光脆弱 |
| 外星科技 | 过载核心、紧凑结构、黑客脆弱、智能自检 |

## 12. 部件升级、拆解、改造

### 12.1 升级

升级消耗同结构资源。

| 结构 | 主要升级资源 |
|---|---|
| 机械 | 废料、合金、数据 |
| 废土 | 废料、合金、弹药 |
| 植物 | 生物质、水、样本 |
| 生体/虫巢 | 生物质、样本、魂火 |
| 晶体 | 晶体粉、数据、合金 |
| 虚空 | 虚空尘、魂火、数据 |
| 幽灵 | 魂火、虚空尘、样本 |
| 外星科技 | 数据、晶体粉、稀有合金 |

### 12.2 拆解

| 拆解对象 | 返回资源 |
|---|---|
| 普通部件 | 40% 基础制造资源。 |
| 精良及以上 | 35% 资源 + 10% 概率返还蓝图碎片。 |
| 破损部件 | 25% 资源。 |
| 异常部件 | 30% 资源 + 可能释放异常事件。 |
| 传奇/神话 | 不建议直接拆解，应提示确认。 |

### 12.3 改造

每个部件最多进行 3 次改造。

| 改造类型 | 效果 | 代价 |
|---|---|---|
| 数值强化 | 提升攻击/产出/护盾/容量 | 增加电力或热量 |
| 节能改造 | 降低电力消耗 | 降低少量输出 |
| 结构转化 | 机械转废土、机械转晶体等 | 消耗特殊材料，外观变化 |
| 安全加固 | 降低爆炸/污染/火灾概率 | 占用词条槽 |
| 职位适配 | 指定种族船员效率提升 | 其他种族效率降低 |

## 16. 程序实现建议

### 16.1 核心管理器

| 管理器 | 职责 |
|---|---|
| ShipGridManager | 处理格子、摆放、旋转、连接、占用检测。 |
| ShipPowerSystem | 计算电力生产、消耗、优先级停机。 |
| ShipHeatSystem | 计算热量、散热、过热、火灾。 |
| ShipOxygenSystem | 计算氧气区域、缺氧、泄漏。 |
| ShipCrewSystem | 船员寻路、职位、工作效率。 |
| ShipCombatSystem | 敌舰战、命中房间、伤害结算。 |
| BoardingSystem | 登舰路径、室内战、房间占领。 |
| LandingSystem | 星球登陆队生成、战斗、撤离。 |
| LootGenerator | 战利品、部件实例、词条、品质生成。 |
| SaveSystem | 布局、部件实例、船员、资源存档。 |

### 16.2 数据驱动原则

- 所有部件必须通过配置生成，不要把数值写死在房间脚本里。
- 房间行为由 `PartCategory + Tags + EffectList` 决定。
- 特殊房间可以挂额外 `PartBehavior`，例如黑洞压缩仓、虚空交易终端。
- 战斗目标选择读取房间标签，例如 `Weapon`、`Shield`、`Bridge`、`Ammo`。
- 美术表现读取 `structureStyle` 和 `state` 自动切换材质、特效、音效。

## 17. 后续扩展方向

1. **套装系统**：同结构 4 件套、6 件套，例如虚空套、植物套、机械套。
2. **旗舰蓝图**：玩家可以选择掠夺者、生态母舰、幽灵舰、机械蜂巢等大方向。
3. **船体外观进化**：内部房间影响外部轮廓，例如装很多植物模块后外壳长藤蔓。
4. **部件变异**：虚空、生体、古神部件可能自己成长或产生副作用。
5. **敌舰可俘获**：不是只抢部件，可以直接拖回敌舰当副舰。
6. **桌面互动**：飞船飞到屏幕边缘，船员在窗口边缘维修、钓星尘、搬货。
7. **离线战报**：玩家回来后看到“飞船自动抢了谁、坏了哪里、带回什么”。

## 18. 当前版本落地结论

第一阶段的重点不是堆内容，而是先把飞船模拟框架打通：

```text
格子建造 → 电力/氧气/热量 → 船员职位 → 自动生产 → 敌舰战 → 登舰 → 星球登陆 → 部件掉落 → 改造飞船
```

只要这条链路跑通，后续增加部件、结构流派、船员种族、敌舰类型都会非常顺畅。

本文件中的 100 个部件可以先作为完整设计池，开发时按 MVP 30 个优先实现，后续再按版本逐步开放。
