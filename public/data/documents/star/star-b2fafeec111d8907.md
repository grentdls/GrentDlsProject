# 《星空掠夺者》飞船模块分页建造、解锁与蓝图显示规则完整设计文档

> 适用项目：Unity2D 桌面挂机飞船建造游戏《星空掠夺者》  
> 文档目标：重新设计飞船模块建造界面，解决“内容太多、太乱、早期全部展示导致玩家看不懂”的问题。  
> 核心原则：**分页清晰、前期只显示关键建筑、未解锁内容直接隐藏、通过等级/蓝图/战役/任务逐步开放。**

---

## 1. 当前问题

原本飞船模块系统内容丰富，但在建造界面中一次性展示过多，会造成以下问题：

1. 新玩家进入游戏后不知道先建什么。
2. 战斗、生产、防御、科研、生活类模块混在一起，查找成本高。
3. 大量高阶模块一开始出现，会让玩家误以为都可以建造，实际却因为材料、等级、蓝图不足无法建造。
4. 特殊模块、隐藏模块、事件模块如果过早显示，会削弱探索感。
5. 桌面游戏窗口尺寸较小，不适合使用大型全屏科技树或超长模块列表。

因此飞船模块建造系统需要改为：

- 按功能分页。
- 按阶段逐步显示。
- 只展示当前阶段有意义的信息。
- 不满足显示条件的模块不出现在列表里。
- 被玩家见过但暂时不能建的模块，可以显示为“未满足条件”。
- 未获得蓝图的特殊模块完全隐藏，直到获得相关线索或图纸。

---

## 2. 新版设计目标

### 2.1 玩家体验目标

| 阶段 | 玩家感受 | 系统表现 |
|---|---|---|
| 新手期 | 我知道先修什么 | 只显示核心舱、能源舱、生活舱、简易仓库、简易推进器 |
| 初期扩建 | 我可以开始分工建设 | 开放生产、生存、防御基础分页 |
| 中期掠夺 | 我开始根据玩法选择流派 | 开放攻击、登舰、科研、交易、特殊模块 |
| 后期探索 | 我不断发现新模块 | 通过蓝图、战役、事件、星球遗迹解锁隐藏模块 |
| 长线挂机 | 我能快速管理复杂飞船 | 分页、筛选、收藏、最近建造、推荐建造 |

### 2.2 系统设计目标

- 建造界面不是“显示所有模块”，而是“显示玩家当前应该知道的模块”。
- 模块解锁分为：**基础解锁、等级解锁、前置模块解锁、蓝图解锁、战役解锁、事件解锁、阵营解锁、研究解锁**。
- 对于桌面游戏，建造弹窗必须轻量：默认小窗口，玩家可展开高级信息。
- 建造列表必须有清晰分页，不再混排。
- 每个分页只显示该功能相关模块。
- 重要主线模块会在顶部“推荐建造”区域单独提示。

## 3. 飞船模块分页总览

新版飞船建造弹窗划分为 8 个一级分页。

| 分页编号 | 分页名称 | 主要用途 | 早期是否显示 | 备注 |
|---|---|---|---|---|
| Tab_01 | 核心 | 飞船核心、能源、推进、控制、基础仓储 | 默认显示 | 新手期唯一完整显示的分页 |
| Tab_02 | 生产 | 资源加工、制造、修理、回收、自动生产 | 完成核心链后显示 | 先显示低阶生产，后续逐步展开 |
| Tab_03 | 生存 | 氧气、食物、医疗、休息、士气、人口 | 完成生活舱后显示 | 与船员数量强相关 |
| Tab_04 | 防御 | 船体装甲、护盾、炮台、隔离门、消防 | 遭遇第一次战斗后显示 | 避免新手前期看到过多防御模块 |
| Tab_05 | 攻击 | 主炮、副炮、导弹、无人机、登舰舱 | 获得武器授权后显示 | 通过战役或任务开放 |
| Tab_06 | 科研 | 研究室、蓝图解析、基因仓、改造台 | 获得第一张蓝图后显示 | 未获得蓝图前不显示 |
| Tab_07 | 贸易 | 交易舱、走私仓、拍卖终端、货物压缩 | 发现贸易站后显示 | 偏经济玩法 |
| Tab_08 | 特殊 | 虚空、遗物、虫巢、生体、古代科技模块 | 获得对应线索后显示 | 默认隐藏，不给问号格子 |

### 3.1 分页显示原则

分页本身也有显示条件。

```text
如果分页内没有任何可见模块，则该分页不显示。
如果分页刚刚解锁，则在常驻飞船小窗中弹出轻提示。
如果分页中存在主线推荐模块，则分页右上角出现小红点。
```

### 3.2 分页排序原则

建造弹窗默认排序：

1. 核心
2. 生产
3. 生存
4. 防御
5. 攻击
6. 科研
7. 贸易
8. 特殊

玩家可在设置中开启“按常用排序”，系统会把最近使用的分页排到前面，但核心分页始终在第一位。

## 4. 模块显示状态规则

模块在建造界面中有 5 种状态。

| 状态 | 显示方式 | 玩家是否可见 | 是否可建造 | 用途 |
|---|---|---:|---:|---|
| Hidden | 完全不显示 | 否 | 否 | 未达到认知条件、未获得蓝图、隐藏内容 |
| Silhouette | 灰色剪影/未知模块 | 是 | 否 | 已获得线索但未拿到完整蓝图 |
| Locked | 显示图标但锁定 | 是 | 否 | 等级不足、前置模块不足、材料不足之外的硬门槛 |
| Buildable | 正常显示 | 是 | 是 | 满足所有建造条件 |
| BuiltMax | 显示已达上限 | 是 | 否 | 已达到数量上限或唯一模块已建成 |

### 4.1 什么时候完全隐藏

以下情况模块直接不显示：

- 玩家从未接触过相关系统。
- 未获得设计图。
- 未发现对应阵营或星球。
- 未完成对应战役/任务。
- 属于特殊结构，例如虚空模块、古代遗物模块、虫巢模块、生体模块。
- 当前飞船等级远低于模块要求，并且没有任何提前预告需求。

### 4.2 什么时候显示剪影

玩家已经获得线索，但未获得完整蓝图时显示剪影。

例子：

- 扫描到一艘虚空敌舰，获得“虚空引擎残片”。
- 玩家在建造界面的特殊分页中看到一个剪影：“未知虚空推进模块”。
- 提示：需要收集 3 个虚空引擎残片并完成蓝图解析。

### 4.3 什么时候显示锁定

玩家已经知道该模块存在，但还不能建造。

常见原因：

- 飞船核心等级不足。
- 缺少前置模块。
- 缺少研究项目。
- 缺少岗位船员。
- 缺少阵营声望。
- 已经超过当前飞船结构承载上限。

注意：**材料不足不算锁定**，材料不足仍然显示为可见，但按钮为“材料不足”。

## 5. 初始关键建造链

为了避免新手期模块过多，游戏开局只显示最基础的核心链。

### 5.1 初始只显示 5 个模块

| 模块ID | 模块名称 | 分页 | 是否初始显示 | 作用 |
|---|---|---|---:|---|
| M_CORE_001 | 破旧舰桥核心 | 核心 | 是 | 飞船主体，所有模块依赖它 |
| M_POWER_001 | 小型裂变电池 | 核心 | 是 | 提供基础电力 |
| M_ENGINE_001 | 老式推进器 | 核心 | 是 | 解锁移动、探索、遭遇 |
| M_STORAGE_001 | 简易货仓 | 核心 | 是 | 增加基础库存容量 |
| M_LIFE_001 | 临时生活舱 | 核心 | 是 | 允许搭载船员 |

### 5.2 初始建造顺序引导

推荐顺序：

```text
破旧舰桥核心 → 小型裂变电池 → 老式推进器 → 简易货仓 → 临时生活舱
```

系统不强制玩家完全按顺序建造，但会通过推荐标识引导。

### 5.3 初始建造完成后开放内容

当玩家完成以上 5 个模块后：

| 解锁内容 | 解锁方式 |
|---|---|
| 生产分页 | 建成简易货仓 + 临时生活舱 |
| 生存分页 | 建成临时生活舱 |
| 基础资源采集事件 | 建成老式推进器 |
| 第一次敌舰遭遇 | 飞船战力评分达到 80 或完成新手航行任务 |
| 防御分页 | 完成第一次敌舰遭遇或舰体受损达到 20% |
| 攻击分页 | 获得“武器系统授权”任务奖励 |

## 6. 飞船等级与模块可见规则

飞船等级不等于玩家等级。飞船等级由核心舱决定。

| 飞船等级 | 阶段名称 | 核心舱等级 | 主要开放内容 |
|---:|---|---:|---|
| Lv.1 | 逃生艇阶段 | 1 | 核心基础、临时生活、简易推进 |
| Lv.2 | 小型探索舰 | 2 | 基础生产、基础防御、基础武器 |
| Lv.3 | 掠夺护卫舰 | 3 | 登舰舱、医疗舱、改造台、炮塔扩展 |
| Lv.4 | 中型掠夺舰 | 4 | 高级制造、无人机、专业岗位、交易舱 |
| Lv.5 | 重型战舰 | 5 | 大型主炮、护盾矩阵、蓝图解析站 |
| Lv.6 | 旗舰原型 | 6 | 阵营结构、生体/虫巢/晶体模块 |
| Lv.7 | 星际母舰 | 7 | 多舰队支援、特殊科研、区域控制 |
| Lv.8 | 传说方舟 | 8 | 虚空、遗物、古代科技模块 |

### 6.1 模块显示等级差

为了避免玩家过早看到太远的模块，使用“显示等级差”规则。

```text
如果 模块需求等级 <= 当前飞船等级 + 1，则可显示为 Locked。
如果 模块需求等级 > 当前飞船等级 + 1，则默认 Hidden。
特殊蓝图模块不受该规则影响，未获得蓝图时永远 Hidden。
```

例子：

- 当前飞船 Lv.2，可以看到 Lv.3 的部分锁定模块。
- 当前飞船 Lv.2，看不到 Lv.5 大型主炮。
- 当前飞船 Lv.2，如果提前获得 Lv.5 蓝图残片，可以在科研分页看到剪影，但不能建造。

## 7. 蓝图与设计图规则

### 7.1 蓝图类型

| 蓝图类型 | 作用 | 获得渠道 | 显示规则 |
|---|---|---|---|
| 基础蓝图 | 解锁常规模块 | 主线、新手任务、核心升级 | 获得后直接显示 |
| 生产蓝图 | 解锁生产制造模块 | 任务、商人、拆解部件 | 获得后在生产/科研显示 |
| 武器蓝图 | 解锁炮台、导弹、无人机 | 敌舰掉落、战役、军火商 | 获得前攻击分页可能不显示 |
| 防御蓝图 | 解锁护盾、装甲、隔离门 | 战斗奖励、工程事件 | 获得后防御分页显示 |
| 结构蓝图 | 解锁特殊结构模块 | 星球遗迹、阵营声望 | 特殊分页显示 |
| 残缺蓝图 | 需要解析或收集碎片 | 掉落、奇遇、扫描 | 显示剪影 |
| 传说蓝图 | 唯一或强力模块 | 战役、隐藏事件、Boss | 获得前完全隐藏 |

### 7.2 蓝图完整度

每个蓝图有完整度。

| 完整度 | 状态 | 建造界面显示 |
|---:|---|---|
| 0% | 未发现 | 完全不显示 |
| 1%-49% | 获得线索 | 特殊/科研分页显示剪影 |
| 50%-99% | 可解析 | 显示剪影，可点击查看解析需求 |
| 100% | 完整蓝图 | 进入对应分页，按等级/材料判断是否可建 |

### 7.3 蓝图解析

蓝图解析需要科研模块。

| 解析条件 | 说明 |
|---|---|
| 蓝图残片 | 相同蓝图碎片达到需求数量 |
| 科研点 | 通过科研舱、科学家工作、事件获得 |
| 解析时间 | 桌面挂机倒计时完成 |
| 对应研究台 | 机械、植物、虚空、生体等特殊蓝图需要专门设备 |

### 7.4 设计图获得渠道

| 渠道 | 适合产出 |
|---|---|
| 战役章节 | 关键主线模块、攻击系统授权、舰桥升级图纸 |
| 任务事件 | 特殊生产、贸易、防御、生活类模块 |
| 敌舰掉落 | 武器、防御、推进、登舰类模块 |
| 星球遗迹 | 古代科技、虚空、晶体、植物、生体模块 |
| 商人交易 | 常规中阶蓝图、生产线蓝图、贸易仓蓝图 |
| 拆解部件 | 对应结构模块的蓝图残片 |
| 阵营声望 | 阵营特色模块 |
| Boss 掉落 | 传说模块、唯一模块 |

## 8.1 核心分页

### 8.1.1 定位

核心分页是飞船建造的根节点，主要管理：

- 舰桥核心
- 能源系统
- 推进系统
- 控制系统
- 基础仓储
- 基础生活入口

### 8.1.2 子分类

| 子分类 | 显示条件 | 说明 |
|---|---|---|
| 舰桥 | 默认显示 | 飞船等级来源 |
| 能源 | 默认显示 | 电力供给 |
| 推进 | 默认显示 | 星图移动与遭遇频率 |
| 控制 | 核心 Lv.2 显示 | 自动战斗、无人设备控制 |
| 基础仓储 | 默认显示 | 资源上限 |
| 船体扩展 | 核心 Lv.2 显示 | 扩大飞船格子 |

### 8.1.3 核心分页模块示例

| 模块ID | 名称 | 显示条件 | 建造条件 | 备注 |
|---|---|---|---|---|
| M_CORE_001 | 破旧舰桥核心 | 初始 | 初始赠送 | 唯一模块 |
| M_CORE_002 | 掠夺者舰桥 | 核心 Lv.1 + 完成新手航行 | 基础蓝图 + 金属 300 | 升级到 Lv.2 |
| M_CORE_003 | 战术舰桥 | 核心 Lv.2 + 击败小型敌舰 | 战役 1-3 奖励蓝图 | 解锁攻击分页 |
| M_POWER_001 | 小型裂变电池 | 初始 | 金属 80 | 基础电力 |
| M_POWER_002 | 双联电池组 | 核心 Lv.2 | 基础蓝图 | 提供更多电力 |
| M_ENGINE_001 | 老式推进器 | 初始 | 金属 100 | 解锁星图移动 |
| M_STORAGE_001 | 简易货仓 | 初始 | 金属 60 | 库存上限 +100 |
| M_FRAME_001 | 小型船体扩展框架 | 核心 Lv.2 | 工程蓝图 | 增加建造格子 |

## 8.2 生产分页

### 8.2.1 定位

生产分页用于制造资源、装备、部件、弹药、维修材料。

### 8.2.2 显示条件

```text
建成：简易货仓 + 临时生活舱
或
完成任务：第一次资源回收
```

### 8.2.3 子分类

| 子分类 | 说明 | 初期是否显示 |
|---|---|---:|
| 资源加工 | 矿物、植物、生体材料加工 | 是 |
| 零件制造 | 部件材料、维修件、弹药 | 是 |
| 装备制造 | 武器、防具、饰品制造 | 核心 Lv.3 显示 |
| 自动生产 | 挂机生产线 | 核心 Lv.3 显示 |
| 回收拆解 | 拆装备、拆部件、提取蓝图残片 | 核心 Lv.2 显示 |
| 高级制造 | 稀有材料合成、特殊模块制造 | 需要蓝图显示 |

### 8.2.4 生产模块显示规则

- 基础加工台在新手期完成后显示。
- 装备制造台只有获得第一件装备图纸后显示。
- 高级制造模块只有拥有对应蓝图或残片后显示。
- 阵营制造台默认隐藏，如“虫巢孵化炉”“植物共生温室”。

---

## 8.3 生存分页

### 8.3.1 定位

生存分页影响船员容量、恢复、士气、异常状态、长期挂机稳定性。

### 8.3.2 显示条件

```text
建成：临时生活舱
```

### 8.3.3 子分类

| 子分类 | 说明 |
|---|---|
| 居住 | 船员上限、休息恢复 |
| 氧气 | 船内氧气、火灾/破舱风险控制 |
| 食物 | 船员饱食、特殊种族食物 |
| 医疗 | 治疗、复活、异常净化 |
| 士气 | 提升工作效率、降低叛逃 |
| 特殊生命 | 植物、虫巢、生体、幽灵单位专用设施 |

### 8.3.4 特殊隐藏规则

| 模块类型 | 显示条件 |
|---|---|
| 植物温室 | 拥有植物生命船员或获得植物蓝图 |
| 妖兽巢穴 | 拥有妖兽单位或完成妖兽事件 |
| 幽灵封存室 | 捕获幽灵单位后显示 |
| 机械维修床 | 拥有机械单位后显示 |
| 生体再生池 | 获得生体结构蓝图后显示 |

---

## 8.4 防御分页

### 8.4.1 定位

防御分页用于减少飞船战损、保护船员、阻止登舰。

### 8.4.2 显示条件

满足任意一项：

- 完成第一次飞船战。
- 飞船受到过一次结构损伤。
- 获得防御模块蓝图。
- 核心达到 Lv.2。

### 8.4.3 子分类

| 子分类 | 说明 |
|---|---|
| 船体装甲 | 提升结构生命和抗性 |
| 护盾 | 提供战斗前置护盾值 |
| 隔离 | 防止火灾、毒气、登舰扩散 |
| 炮台防御 | 自动拦截导弹、无人机、登舰舱 |
| 修理 | 战斗中自动修复 |
| 灾害控制 | 灭火、排毒、封舱 |

### 8.4.4 UI简化原则

防御分页默认只展示 3 类基础内容：

1. 装甲
2. 护盾
3. 修理

隔离门、灾害控制、拦截炮台等高级模块，需要对应事件发生后才显示。例如玩家第一次被登舰后，才显示“隔离门”模块。

## 8.8 特殊分页

### 8.8.1 定位

特殊分页只显示玩家已经发现的非常规模块。

包括：

- 虚空结构
- 植物结构
- 虫巢结构
- 生体结构
- 幽灵结构
- 古代遗物结构
- 晶体结构
- 外星科技结构

### 8.8.2 显示条件

```text
特殊分页内至少有 1 个模块达到 Silhouette / Locked / Buildable 状态
```

否则特殊分页完全不显示。

### 8.8.3 特殊分页设计原则

- 不做完整问号图鉴。
- 不提前展示所有隐藏模块。
- 每发现一个线索，才出现一个剪影。
- 每获得完整蓝图，才进入可建造/锁定判断。
- 特殊模块拥有独立视觉标签，例如“虚空”“虫巢”“晶体”。

## 10. 推荐建造系统

为了让玩家不迷路，建造界面顶部新增“推荐建造”。

### 10.1 推荐类型

| 推荐类型 | 触发条件 | 示例文案 |
|---|---|---|
| 主线推荐 | 主线要求 | 建造战术舰桥，解锁武器系统 |
| 生存推荐 | 船员容量不足/缺氧 | 船员数量即将超过生活舱容量 |
| 电力推荐 | 电力不足 | 当前电力不足，建议建造双联电池组 |

| 生产推荐 | 资源加工拥堵 | 建议建造矿物加工台 |

### 10.2 推荐优先级

## 19. 自动隐藏与重新显示规则

### 19.1 默认隐藏

每次打开建造界面，系统根据当前数据重新计算模块状态。

```text
模块可见性 = 分页可见 && 显示条件满足 && 未被永久隐藏
```

### 19.2 玩家手动隐藏

玩家可以在高级设置中“隐藏暂时不想看的模块”。

手动隐藏规则：

- 不影响系统解锁。
- 推荐建造仍可重新提示。
- 蓝图库中仍可找到。

### 19.3 系统重新提示

如果玩家隐藏了某模块，但出现强需求，系统会提示：

```text
你曾隐藏“基础护盾发生器”，但当前飞船战损过高，是否重新显示？
```

## 23. 与其他系统的联动

### 23.1 与背包联动

- 如果对应模块已知，则建造界面更新状态。
- 如果蓝图完整，则在对应分页增加“新”角标。
- 如果只是残片，则蓝图库更新进度。

### 23.2 与地图联动

地图上的事件点可以显示：

```text
可能掉落：轻型导弹舱蓝图残片
```

前提是玩家已经获得过相关线索。

```text

奖励：登舰战自动策略槽 +1
```

## 25. 飞船布局放置模式

点击建造后，不立刻完成，而是进入布局放置。

### 25.1 放置检查

| 检查项 | 说明 |
|---|---|
| 空间 | 目标格子必须为空 |
| 连接 | 必须与核心或已连接模块相邻 |
| 通路 | 生活、生产、攻击模块需要可通行路径 |
| 外壳 | 外部装甲、武器、推进器必须放在外边缘或指定挂点 |
| 电力 | 电力不足可放置，但会提示模块无法运行 |
| 特殊环境 | 植物/虫巢/虚空模块可能需要隔离区 |

### 25.2 放置预览颜色

| 颜色 | 含义 |
|---|---|
| 绿色 | 可放置 |
| 黄色 | 可放置但效率降低 |
| 红色 | 不可放置 |
| 蓝色 | 推荐位置 |
| 紫色 | 特殊结构共鸣位置 |

## 30. 后续扩展方向

1. 每个阵营拥有独立分页皮肤。
2. 高级玩家可开启“专家模式”，显示所有已知锁定模块。

7. 船员职业会影响推荐建造，例如机械船员多时推荐机械维修仓。

# 总结

新版飞船模块系统的核心不是减少内容，而是**控制内容出现时机**。

最终体验应该是：

```text
开局只看到必须建的核心模块。
完成基础飞船后，生产和生存自然展开。
经历战斗后，防御和攻击模块出现。
获得蓝图后，科研和特殊模块逐步浮现。
发现世界越多，建造界面才越丰富。
```

这样既能保留《星空掠夺者》庞大的飞船拼装深度，又不会让桌面弹窗界面变得拥挤混乱。
