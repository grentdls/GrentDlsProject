# 《星空掠夺者》6小时后无尽挂机刷取、重复成长与长期目标文档

版本：V1.0  
目标：设计玩家 6 小时后进入重复刷取阶段的长期成长体验，让玩家愿意持续挂机、刷角色、刷装备、刷技能、刷飞船部件、刷星球和敌舰。

---

## 1. 6小时后玩家状态假设

玩家进入 6 小时后，通常已经拥有：

| 内容 | 目标状态 |
|---|---|
| 飞船等级 | Lv.4-Lv.5 |
| 建筑数量 | 50-70 个已见过，30-50 个已建造 |
| 单位数量 | 15-25 个 |
| 主力队伍 | 1支登陆队、1支登舰队、1支守船队 |
| 装备 | 全员基本穿满，开始追求套装和词条 |
| 技能 | 主力单位有 3-5 个技能 |
| 职业 | 部分单位可转职，少数接近觉醒 |
| 星球 | 解锁 2-3 个星区，多种星球类型 |
| 敌舰 | 能稳定刷普通敌舰和部分精英敌舰 |

此时游戏不能再靠“解锁基础功能”驱动，必须切换到“刷取、优化、构筑、挑战更高层”的长期循环。

---

## 2. 6小时后的核心循环

### 2.1 主循环

```text
选择目标 → 自动挂机刷取 → 获得大量掉落 → 筛选高价值物品 → 强化角色/装备/飞船 → 挑战更高难度 → 解锁更高掉落 → 继续刷
```

### 2.2 分支循环

| 循环 | 目标 | 主要玩法 |
|---|---|---|
| 角色循环 | 获得更强单位 | 招募、俘虏、孵化、事件、洗初始技能 |
| 装备循环 | 获取更好套装词条 | 刷星球、刷敌舰、分解、重铸 |
| 技能循环 | 获取高稀有技能书 | 精英敌人、职业试炼、商人、Boss |
| 飞船循环 | 获取高级部件和蓝图 | 敌舰掠夺、蓝图解析、遗迹 |
| 星球循环 | 找到高价值星球 | 地图扫描、星图信标、事件链 |
| 敌舰循环 | 刷特定阵营敌舰 | 悬赏、通缉、星区危险提升 |
| 资源循环 | 获取终局材料 | Boss、分解、交易、长期挂机 |
| 效率循环 | 提升每小时收益 | 自动策略、工作职业、路线规划 |

## 3. 长期目标层级

### 3.1 6-12小时目标

| 目标 | 说明 |
|---|---|
| 第一套2件套 | 让玩家体验套装激活 |
| 第一名SR/SSR主力单位 | 替换初始队伍 |
| 第一条职业进阶路线 | 例如机械转枪炮机械 |
| 第一艘精英敌舰胜利 | 获得完整飞船部件或蓝图 |
| 第一颗稀有星球刷取 | 掉落明显更好 |
| 第一件史诗装备 | 进入词条与强化循环 |

### 3.2 12-24小时目标

| 目标 | 说明 |
|---|---|
| 4件套效果 | 玩家开始围绕套装构筑 |
| 第一名觉醒候选单位 | 需要觉醒材料 |
| 第二星区稳定刷取 | 开始刷高稀有星球 |
| 第一件传说装备 | 长期目标出现 |
| 第一张传说飞船蓝图残片 | 形成蓝图追踪目标 |
| 第一次挑战传说Boss | 提供强刺激 |

### 3.3 24小时后目标

| 目标 | 说明 |
|---|---|
| 觉醒单位 | 解锁觉醒技能和外观 |
| 传说套装成型 | 长线装备追求 |
| 高级飞船流派成型 | 攻击舰、登舰舰、生产舰、虚空舰等 |
| 高世界等级刷取 | 世界等级/星区危险提升 |
| 神话掉落追求 | 极低概率惊喜 |
| 自动策略优化 | 提升每小时收益 |

## 4. 无尽刷取目标清单

### 4.1 角色刷取

角色价值由以下组成：

```text
角色价值 = 稀有度 + 种族 + 主职业路线 + 初始技能 + 成长资质 + 专属特性 + 可用职位
```

可刷内容：

| 内容 | 说明 |
|---|---|
| 高稀有单位 | SSR、UR 单位 |
| 高稀有初始技能 | 出生自带史诗/传说/神话技能 |
| 好成长资质 | 攻击、法能、速度、工作效率资质 |
| 稀有种族 | 虚空、幽灵、外星、晶体等 |
| 专属职业路线 | 特殊转职或觉醒路线 |
| 稀有外观 | Boss单位、事件单位、异化单位 |

刷取渠道：

| 渠道 | 特点 |
|---|---|
| 星港招募 | 稳定但贵 |
| 黑市契约 | 高稀有概率高，但负面词条风险 |
| 敌舰俘虏 | 可以获得敌方技能组合 |
| 星球捕获 | 妖兽、植物、虫巢单位主要来源 |
| 虫卵/种子/机械核心孵化 | 成长潜力高 |
| Boss投降/事件收编 | 专属单位 |

## 5. 装备无尽刷取

### 5.1 装备价值公式

```text
装备价值 = 装备稀有度 × 主属性适配 × 副词条质量 × 套装价值 × 强化潜力 × 特殊来源词条
```

### 5.2 6小时后装备目标

| 目标 | 说明 |
|---|---|
| 刷套装件 | 先凑2件，再凑4件，再追6件 |
| 刷主属性 | 武器刷攻击/暴击，首饰刷法伤/技能强度 |
| 刷副词条 | 攻速、暴击、技能冷却、异常伤害 |
| 刷强化材料 | 提升装备等级 |
| 刷重铸石 | 洗掉废词条 |
| 刷特殊词条 | 星球/敌人/事件来源独有词条 |

### 5.3 套装长期循环

| 套装方向 | 适合流派 |
|---|---|
| 攻速套 | 机械枪手、近战妖兽 |
| 暴击套 | 刀兵机械、刺客、妖兽爆发 |
| 范围套 | 元素、炮手、虫巢召唤 |
| 异常伤害套 | 植物毒、虚空侵蚀、火焰/冰霜 |
| 防御套 | 盾墙机械、晶体坦克 |
| 治疗套 | 植物治疗、外星护盾医师 |
| 工作套 | 工程师、研究员、贸易职业 |
| 掠夺套 | 登舰、偷窃、战利品获取 |

## 6. 技能书无尽刷取

### 6.1 技能书价值

技能书是一次性消耗，必须保持稀有。

```text
技能书价值 = 技能稀有度 + 职业限制 + 流派适配 + 是否觉醒技能 + 是否可跨种族学习
```

### 6.2 技能书来源

| 来源 | 掉落倾向 |
|---|---|
| 普通敌人 | 普通/优秀技能书 |
| 精英敌人 | 稀有技能书 |
| 队长/Boss | 史诗/传说技能书 |
| 职业试炼 | 指定职业技能书 |
| 黑市商人 | 随机高稀有技能书 |
| 事件奖励 | 特殊技能书 |
| 分解技能书 | 技能残页 |
| 觉醒试炼 | 觉醒技能书 |

### 6.3 技能书消耗循环

```text
获得技能书 → 判断角色是否适配 → 学习或出售/分解 → 获得技能残页 → 升级已有技能 → 挑战更高难 → 获得更高技能书
```

## 7. 飞船部件无尽刷取

### 7.1 部件价值

| 价值点 | 说明 |
|---|---|
| 高稀有度 | 更高基础属性和更多词条 |
| 特殊结构 | 植物、晶体、虫巢、虚空等结构效果 |
| 完整掉落 | 敌舰完整缴获比残片价值高 |
| 蓝图价值 | 解锁永久建造权限 |
| 相邻加成 | 和现有飞船布局匹配 |
| 流派适配 | 攻击舰、登舰舰、生产舰、异常舰 |

### 7.2 刷取方式

| 方式 | 说明 |
|---|---|
| 摧毁敌舰 | 材料多，完整部件少 |
| 登舰占领 | 完整部件概率高 |
| 重点破坏房间 | 对应模块残片概率高 |
| 扫描敌舰 | 可预览敌方稀有模块 |
| 蓝图追踪 | 地图提示可能掉落目标蓝图的节点 |
| 交易购买 | 高价购买关键蓝图 |

## 8. 星球与敌舰刷取

### 8.1 星球稀有度刷取

6小时后地图扫描应变成重要玩法。

玩家可以用“星图信标”锁定目标类型：

| 信标 | 锁定方向 |
|---|---|
| 矿物信标 | 高矿物星球 |
| 植物信标 | 植物/毒素星球 |
| 机械信标 | 敌舰/废船/机械星球 |
| 虚空信标 | 虚空裂隙/异常事件 |
| 贸易信标 | 商队/贸易站 |
| Boss信标 | 高危Boss节点 |

### 8.2 敌舰刷取

| 敌舰目标 | 适合刷什么 |
|---|---|
| 赤锈星盗舰 | 武器、装甲、金币 |
| 商队护卫舰 | 贸易货物、装备、信用币 |
| 机械军团舰 | 芯片、机械单位、火控部件 |
| 虫巢寄生舰 | 虫巢单位、生体模块 |
| 晶体棱镜舰 | 护盾部件、法伤首饰 |
| 虚空裂隙舰 | 虚空残片、特殊技能书 |
| 远古巨舰 | 传说蓝图、终局模块 |

## 9. 6小时后自动挂机策略

### 9.1 自动目标选择

玩家可以设置自动刷取目标：

| 目标 | 自动行为 |
|---|---|
| 刷金属 | 优先矿星和废船 |
| 刷装备 | 优先敌舰和精英星球 |
| 刷技能书 | 优先精英单位和职业试炼 |
| 刷角色 | 优先招募、俘虏、孵化事件 |
| 刷蓝图 | 优先敌舰、遗迹、蓝图任务 |
| 刷套装 | 锁定掉落对应套装的星球/敌人 |
| 刷觉醒 | 优先Boss、传说事件 |

### 9.2 自动筛选

6小时后掉落很多，必须有自动筛选。

| 规则 | 默认 |
|---|---|
| 普通装备 | 自动分解 |
| 优秀装备 | 未锁定自动分解 |
| 精良装备 | 保留套装件，其余可分解 |
| 稀有装备 | 默认保留，玩家可开启分解 |
| 史诗以上 | 永远不自动分解 |
| 技能书 | 稀有以上保留 |
| 蓝图残片 | 全部保留 |
| 觉醒材料 | 全部锁定 |

## 10. 长期保底系统

无限刷取需要保底，否则玩家会觉得无底洞。

### 10.1 装备保底

| 行为 | 保底 |
|---|---|
| 刷同一套装副本 20 次 | 必得 1 件目标套装 |
| 分解 50 件稀有装备 | 获得 1 个套装自选残页 |
| 100 次无史诗掉落 | 下一次精英/Boss 史诗概率大幅提升 |

### 10.2 角色保底

| 行为 | 保底 |
|---|---|
| 高级招募 30 次 | 必出 SSR |
| 捕获失败 10 次 | 下次捕获率 +30% |
| 孵化 20 个同系蛋 | 必出高资质单位 |

### 10.3 技能书保底

| 行为 | 保底 |
|---|---|
| 分解技能书获得残页 | 可兑换指定技能书 |
| 职业试炼失败 | 获得试炼印记 |
| 10 次试炼未出目标技能 | 可用印记兑换 |

### 10.4 蓝图保底

| 行为 | 保底 |
|---|---|
| 同类敌舰击败 20 次 | 获得对应蓝图残片 |
| 蓝图残片重复溢出 | 可转化为通用蓝图粉尘 |
| 追踪蓝图 3 小时无掉落 | 提高相关节点出现率 |

## 11. 世界等级与无尽挑战

### 11.1 世界等级作用

世界等级提升后：

- 敌人更强。
- 掉落更好。
- 高稀有星球概率提高。
- 敌舰完整部件概率提高。
- 传说/神话掉落概率提高。
- 失败损失也提高。

### 11.2 世界等级解锁

| 世界等级 | 解锁条件 | 新内容 |
|---:|---|---|
| W1 | 6小时后默认 | 稀有装备刷取 |
| W2 | 击败第一艘精英敌舰 | 史诗装备、职业试炼 |
| W3 | 完成第一套4件套 | 传说碎片、觉醒石碎片 |
| W4 | 第一个单位觉醒 | 传说敌舰、特殊Boss |
| W5 | 击败传说Boss | 神话材料、唯一事件 |
| W6+ | 无限递增挑战 | 排行榜和极限词条 |

## 13. 防疲劳设计

无限刷取容易疲劳，需要设计“自动化”和“阶段目标”。

| 问题 | 解决方案 |
|---|---|
| 掉落太多 | 自动过滤、批量分解、锁定高价值 |
| 目标不明确 | 目标追踪、推荐刷取地点 |
| 长时间没好东西 | 保底和残页兑换 |
| 重复战斗无聊 | 低难战斗快速结算，高价值战斗展示 |
| 配置太复杂 | 自动推荐装备、队伍、技能 |
| 桌面被打扰 | 低打扰通知和事件挂起 |

## 14. 总结

6小时后，玩家的核心乐趣应该从“解锁基础系统”转为：

```text
刷更好角色
刷更好装备
刷更好技能
刷更好飞船部件
刷更稀有星球和敌舰
提升每小时收益
挑战更高世界等级
```

无限挂机的本质是：

```text
可自动重复 + 有低概率惊喜 + 有明确保底 + 有长期构筑变化
```

只要让玩家一直能回答这个问题：

```text
我接下来要刷什么？为什么值得刷？刷到之后会变强在哪里？
```

这个游戏就有长期挂机的动力。
