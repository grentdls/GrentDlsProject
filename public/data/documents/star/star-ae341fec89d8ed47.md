# 《星空掠夺者》建筑解锁条件、显示规则与阶段开放文档

版本：V1.0  
目标：让飞船建筑按成长节奏逐步出现，前期只显示关键建筑，避免玩家被大量模块淹没。

---

## 1. 设计原则

1. 建筑不是全部显示，而是按阶段和条件显示。
2. 玩家没接触过的系统，相关建筑直接隐藏。
3. 只要建筑会影响当前阶段目标，就进入推荐列表。
4. 所有建筑必须同时配置“显示条件”和“建造条件”。
5. 材料不足不等于隐藏，材料不足只影响建造按钮。
6. 特殊建筑必须通过蓝图、战役、任务、事件、阵营、星球线索解锁。

---

## 2. 建筑显示状态

| 状态 | 含义 | UI表现 |
|---|---|---|
| Hidden | 完全未解锁，玩家不知道存在 | 不显示 |
| Hint | 获得线索，但没有完整蓝图 | 剪影，显示“未知模块” |
| Locked | 已知，但等级/研究/前置不足 | 显示锁定原因 |
| Buildable | 可以建造 | 正常显示，按钮可点 |
| Built | 已建造 | 显示已建造，可定位 |
| Maxed | 达到数量上限 | 显示已达上限 |

## 3. 建筑分页开放规则

| 分页 | 开放条件 | 前期显示策略 |
|---|---|---|
| 核心 | 初始显示 | 只显示基础链建筑 |
| 生产 | 建成简易货仓 | 先显示矿物加工台、回收机 |
| 生存 | 建成临时生活舱 | 先显示氧气、食物、医疗 |

| 攻击 | 完成武器授权任务 | 先显示轻型舰炮 |
| 科研 | 获得第一张残缺蓝图 | 先显示研究台和蓝图解析 |
| 贸易 | 发现贸易站 | 先显示贸易货仓 |
| 特殊 | 获得特殊线索或蓝图残片 | 未发现前不显示分页 |
| 终局 | 6小时后或核心Lv5 | 只显示已获得线索内容 |

## 5. 核心建筑链

### 5.1 开局必建链

```text
破旧舰桥核心 → 小型裂变电池 → 老式推进器 → 简易货仓 → 临时生活舱
```

### 5.2 每个建筑承担的教学功能

| 建筑 | 教学功能 |
|---|---|
| 小型裂变电池 | 教玩家飞船需要电力 |
| 老式推进器 | 教玩家飞船可以航行到地图节点 |
| 简易货仓 | 教玩家背包容量和战利品 |
| 临时生活舱 | 教玩家船员容量和生活行为 |

## 6. 建筑解锁方式分类

### 6.1 等级解锁

| 飞船等级 | 解锁方向 |
|---:|---|
| Lv1 | 核心、电力、推进、货仓、生活 |
| Lv2 | 基础生产、基础防御、基础扫描 |
| Lv3 | 武器、登舰、科研、装备改造 |
| Lv4 | 贸易、自动生产、无人机、高级防御 |
| Lv5 | 旗舰扩展、套装重铸、职业觉醒设施 |
| Lv6+ | 特殊结构、虚空、虫巢、古代科技 |

### 6.2 任务解锁

| 任务 | 解锁建筑 |
|---|---|
| 第一次资源回收 | 矿物加工台 |
| 第一次小战斗 | 简易外部装甲 |
| 武器系统授权 | 轻型舰炮 |
| 第一次船员受伤 | 简易医疗床 |
| 第一次火灾 | 自动灭火罐 |
| 第一次登舰事件 | 手动隔离门 |
| 获得残缺蓝图 | 基础研究台 |
| 第一次贸易事件 | 贸易货仓 |

### 6.3 蓝图解锁

| 蓝图状态 | 建筑显示 |
|---|---|
| 未发现 | 不显示 |

| 残片不足 | 显示蓝图进度 |
| 可解析 | 显示解析按钮 |
| 完整蓝图 | 进入对应分页，可根据条件建造 |

### 6.4 星球/事件解锁

| 星球/事件 | 解锁方向 |
|---|---|
| 植物星球 | 植物温室、共生根系舱 |
| 虫巢星球 | 虫巢孵化腔、酸液舱 |
| 晶体星球 | 晶体共鸣核心、护盾矩阵 |
| 虚空裂隙 | 虚空观测仪、虚空引擎 |
| 废弃研究站 | 基础研究台、蓝图解析仪 |
| 贸易站 | 贸易货仓、交易终端 |

## 7. 推荐建造规则

### 7.1 推荐优先级

```text
主线必需 > 生存危机 > 电力不足 > 库存不足 > 战斗损伤 > 生产瓶颈 > 新蓝图 > 流派增强
```

### 7.2 推荐触发

| 触发条件 | 推荐建筑 |
|---|---|
| 电力剩余 < 10% | 能源建筑 |
| 库存占用 > 85% | 货仓 |
| 船员容量不足 | 生活舱 |
| 战斗损伤超过 30% | 装甲/护盾/维修 |
| 食物不足 10分钟消耗 | 食物合成器 |
| 获得武器蓝图 | 对应武器模块 |
| 获得残缺蓝图 | 研究台/解析仪 |
| 获得新种族单位 | 对应种族生活设施 |

### 7.3 推荐UI

最多显示 3 个推荐。

每个推荐卡包含：

- 建筑名。
- 为什么推荐。
- 缺少什么材料。
- 点击后定位到对应分页。

## 8. 建筑数值成长

### 8.1 建筑升级倍率

```text
建筑核心属性 = 基础值 × (1 + 0.18 × (等级 - 1))
建筑耐久 = 基础耐久 × (1 + 0.22 × (等级 - 1))
建筑耗电 = 基础耗电 × (1 + 0.05 × floor((等级 - 1)/2))
```

### 8.2 建筑等级上限

| 建筑稀有度 | 初始等级上限 | 解锁后上限 |
|---|---:|---:|
| 普通 | 5 | 10 |
| 优秀 | 8 | 15 |
| 精良 | 10 | 20 |
| 稀有 | 15 | 30 |
| 史诗 | 20 | 40 |
| 传说 | 30 | 60 |
| 神话 | 50 | 100 |

## 9. 建筑隐藏检查伪代码

```csharp
ModuleViewState GetViewState(Module module, PlayerState player)
{
    if (!IsTabUnlocked(module.Tab, player)) return Hidden;
    if (!HasDiscoveryFlag(module, player)) return Hidden;
    if (module.RequiresBlueprint && !player.KnowsBlueprint(module.BlueprintId)) return Hidden;
    if (player.KnowsBlueprint(module.BlueprintId) && !player.BlueprintComplete(module.BlueprintId)) return Hint;
    if (!MeetHardConditions(module, player)) return Locked;
    if (module.MaxCount > 0 && player.CountBuilt(module.Id) >= module.MaxCount) return Maxed;
    return Buildable;
}
```

## 10. 验收标准

| 标准 | 目标 |
|---|---|
| 前5分钟建筑数量 | 玩家建成 4-5 个关键建筑 |
| 前5分钟建筑列表 | 不超过 5 个可见建筑 |

| 特殊分页 | 未获得线索前不显示 |
| 推荐建造 | 同时最多 3 条 |
| 蓝图提示 | 获得线索才显示剪影 |

## 11. 总结

建筑系统的成长体验必须从“全部摆出来让玩家筛”改成“系统按阶段逐步开放”。

推荐节奏：

```text
0-5分钟：核心链
5-15分钟：生产与生存
15-60分钟：防御与攻击
1-3小时：科研与贸易
3-6小时：特殊结构出现
6小时后：终局模块和无尽刷取
```

这能显著降低新手期混乱感，同时保留后期深度。
