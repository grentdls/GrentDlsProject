# 《星空掠夺者》数值成长、经济循环与挂机收益文档

版本：V1.0  
目标：为无限挂机游戏设计资源、经验、装备、角色、飞船、敌人和掉落的数值成长框架，让前期爽快、中期有目标、6小时后能无限刷取。

---

## 1. 数值设计总原则

1. 前 5 分钟奖励密度高，数值增长快，让玩家立刻有变化。
2. 5-60 分钟持续解锁，玩家主要追求新功能，而不是刷词条。
3. 1-6 小时开始出现套装、职业、蓝图、稀有单位，让玩家形成构筑。
4. 6 小时后进入重复刷取，重点是稀有度、词条、套装、觉醒、单位初始技能。
5. 资源产出必须高于消耗，但高阶资源要通过特定玩法获得，不能纯挂机白给。
6. 战斗失败不能彻底空手，但必须有损耗，避免无脑挑战高难。

升级所需经验 = 60 × 等级^1.35

## 5. 战力计算

### 5.1 单位战力

```text
单位战力 = 生命×0.18 + 攻击×6 + 防御×4 + 法能×5 + 速度×80 + 暴击评分 + 技能评分 + 装备评分 + 职业评分
```

技能评分建议：

| 技能稀有度 | 评分 |
|---|---:|
| 普通 | 30 |
| 优秀 | 80 |
| 精良 | 150 |
| 稀有 | 300 |
| 史诗 | 700 |
| 传说 | 1600 |
| 神话 | 4000 |

### 5.2 飞船战力

```text
飞船战力 = 舰体耐久×0.08 + 护盾×0.15 + 武器DPS×20 + 能源稳定评分 + 防御模块评分 + 登舰能力评分 + 船员岗位评分
```

### 5.3 队伍战力

```text
队伍战力 = Σ单位战力 × 队伍协同倍率 × 队长光环倍率 × 装备套装倍率
```

协同倍率：

| 情况 | 倍率 |
|---|---:|
| 无明显协同 | 1.00 |
| 有坦克+治疗+输出 | 1.10 |
| 同种族3人 | 1.08 |
| 同流派技能组合 | 1.12 |
| 套装联动明显 | 1.15 |
| 队长光环适配 | 1.05-1.25 |

### 6.1 装备属性曲线

```text
装备主属性 = 基础值 × 稀有度倍率 × (1 + 强化等级 × 0.08)
```

| 稀有度 | 属性倍率 | 词条数量 | 前期出现时间 |
|---|---:|---:|---|
| 普通 | 1.00 | 0-1 | 2分钟 |
| 优秀 | 1.15 | 1 | 3-5分钟 |
| 精良 | 1.35 | 1-2 | 15分钟 |

| 史诗 | 2.10 | 3-4 | 3小时 |
| 传说 | 2.80 | 4-5 | 6小时后 |

### 6.2 6小时后装备刷取重点

6小时后装备不是为了“穿满”，而是为了刷：

1. 正确套装。
2. 正确主属性。
3. 正确副词条。
4. 高强化成长。
5. 稀有词条组合。

## 9. 离线挂机收益

### 9.1 离线收益规则

```text
离线收益 = 在线基础产出 × 离线效率 × 离线时长 × 仓储限制
```

默认离线效率：

| 时长 | 效率 |
|---|---:|
| 0-1小时 | 80% |
| 1-6小时 | 65% |
| 6-24小时 | 45% |
| 24小时以上 | 25% |

### 9.2 离线收益上限

| 阶段 | 最大离线结算时长 |
|---|---:|
| 新手 | 2小时 |
| 初期 | 6小时 |
| 中期 | 12小时 |
| 6小时后 | 24小时 |
| 后期科技 | 可提升到48小时 |

### 9.3 离线战斗

离线期间可以发生自动战斗，但强规则：

- 不挑战高危敌人。
- 船员濒死自动撤退。
- 不自动消耗高稀有道具。
- 传说/神话事件只记录为“待处理”，不自动结算。

## 12. 总结

数值体验要服务成长节奏：

```text
前期：高频奖励，低门槛成长
中期：系统解锁，建立构筑
后期：稀有度、词条、套装、觉醒长期刷取
```

无限挂机游戏最怕“只有资源数字增长”。所以 6 小时后必须把成长重心转到：

- 角色随机技能。
- 装备词条。
- 套装件数。
- 飞船部件蓝图。
- 星球和敌舰稀有度。
- 职业进阶和觉醒。

这样玩家才会愿意无尽肝下去。
