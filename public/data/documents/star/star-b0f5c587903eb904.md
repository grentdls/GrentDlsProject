# 《星空掠夺者》单位职业系统、职业技能与 UI 预制体完整设计文档

> 项目类型：Unity2D 桌面挂机 / 飞船建造 / 自动掠夺 / 船员养成游戏  
> 文档范围：单位主职业、副职业、工作职业、转职、觉醒、职业技能、技能学习规则、职业 UI 预制体布局、数据结构建议  
> 适用模块：船员系统、技能系统、自动战斗、飞船岗位、生产建设、单位生成、掉落、招募、UI 预制体制作

---

## 1. 职业系统总览

单位职业分为三层：

| 职业层级 | 是否必有 | 是否可更换 | 是否绑定种族 | 主要作用 | 技能类型 |
|---|---:|---:|---:|---|---|
| 主职业 | 必有 | 不可随意更换 | 是 | 决定单位战斗成长、进阶路线、觉醒方向 | 主动技能、核心被动、觉醒技能 |
| 副职业 | 初始没有 | 可更换 | 否 | 提供通用成长方向和轻度玩法构筑 | 多数被动，少量主动 |
| 工作职业 | 初始可无 | 可更换，但有冷却/熟练度损耗 | 否 | 提升飞船建设、生产、维护、岗位效率 | 工作被动、岗位技能、生产技能 |

### 1.1 设计目标

1. **种族差异更强**：不同种族不仅技能库不同，主职业树也完全不同。
2. **单位价值更清晰**：同样稀有度的单位，如果随机到高稀有主职业技能、稀有进阶路线适配、优秀工作职业，也会更值钱。
3. **长期养成更深**：单位从基础主职业 → 进阶转职 → 觉醒，是长期目标。
4. **构筑自由但有成本**：副职业可换，但换了会清除原副职业技能，避免无限叠被动。
5. **飞船养成与单位绑定**：工作职业让单位不是只参与战斗，还能负责生产、维修、研究、防御、采集、厨房、医疗等岗位。

## 2. 职业系统核心规则

### 2.1 主职业规则

主职业由单位种族决定，单位出生或获得时自动拥有。

例如：

| 种族 | 初始主职业 |
|---|---|
| 机械族 | 机械生物 |
| 植物生命 | 星植生命 |
| 妖兽族 | 星域妖兽 |
| 幽灵族 | 灵体幽魂 |
| 外星族 | 异星智者 |
| 虚空族 | 虚空造物 |
| 虫巢族 | 群巢子体 |
| 晶体族 | 晶核生命 |
| 元素族 | 星界元素 |
| 星际人形 / 佣兵 | 星海佣兵 |

#### 主职业特点

- 主职业不可删除。
- 主职业不能跨种族学习。
- 主职业拥有基础技能库。
- 达到条件后可选择一个进阶职业。
- 进阶职业选择后不可反悔。
- 进阶职业达到条件后可觉醒。
- 觉醒方向通常与进阶职业绑定，也可以有少量分支。

### 2.2 进阶转职规则

单位达到指定条件后，可以从当前主职业的进阶树中选择一个方向。

#### 基础转职条件

| 条件 | 数值建议 |
|---|---:|
| 单位等级 | ≥ 20 |
| 主职业熟练度 | ≥ 1000 |
| 已学习主职业基础技能 | ≥ 3 个 |
| 消耗资源 | 星尘币 × 2000，职业核心 × 1 |
| 特殊材料 | 对应种族材料 × 5 |

#### 转职结果

- 解锁进阶职业专属技能库。
- 单位基础属性成长发生变化。
- 单位外观发生中等变化。
- 单位 AI 倾向发生变化。
- 单位可装备部分职业专属装备。

#### 不可逆规则

转职后不能回到基础职业，也不能切换到同级其他进阶职业。

例如：

```text
机械生物
├─ 刀兵机械
│  ├─ 觉醒：杀戮机器
│  └─ 觉醒：斩舰执行者
├─ 枪炮机械
│  ├─ 觉醒：轨道炮台
│  └─ 觉醒：歼灭火控体
└─ 盾墙机械
   ├─ 觉醒：钢铁堡垒
   └─ 觉醒：反应装甲核心
```

选择“刀兵机械”后，后续不能转成“枪炮机械”或“盾墙机械”。

### 2.3 觉醒规则

觉醒是主职业成长的最终阶段。

#### 觉醒条件

| 条件 | 数值建议 |
|---|---:|
| 单位等级 | ≥ 50 |
| 进阶职业熟练度 | ≥ 3000 |
| 进阶职业技能等级总和 | ≥ 20 |
| 觉醒试炼 | 完成对应战斗/生产/事件任务 |
| 消耗资源 | 觉醒星核 × 1，星尘币 × 10000 |
| 特殊材料 | 对应觉醒材料 × 10 |

#### 觉醒效果

- 解锁觉醒技能库。
- 获得 1 个觉醒被动。
- 获得 1 个觉醒主动或终结技。
- 基础属性成长大幅改变。
- 外观发生明显变化。
- 单位稀有度评分提升。

### 2.4 副职业规则

副职业是通用职业，不绑定种族。

#### 副职业基本规则

- 单位初始没有副职业。
- 玩家可以让单位申请一个副职业。
- 副职业可以更换。
- 更换副职业时，原副职业技能全部清除。
- 原副职业熟练度保留 30%，方便未来重新学习，但技能不保留。
- 副职业技能多为被动，少量为主动。
- 副职业技能强度低于主职业技能，但适合补短板和构筑。

#### 副职业切换成本

| 单位等级 | 切换消耗 | 冷却 |
|---:|---:|---:|
| 1-19 | 星尘币 × 500 | 无 |
| 20-39 | 星尘币 × 1500 | 10 分钟 |
| 40-59 | 星尘币 × 4000 | 30 分钟 |
| 60+ | 星尘币 × 8000 | 60 分钟 |

### 2.5 工作职业规则

工作职业用于飞船建设、生产、经营、维修和资源产出。

#### 工作职业特点

- 工作职业不直接决定战斗定位。
- 工作职业可通过飞船岗位获得熟练度。
- 工作职业技能大多在飞船房间内生效。
- 工作职业可以和主职业、副职业同时存在。
- 工作职业有“岗位匹配度”。
- 工作职业等级越高，离线挂机收益越高。

#### 工作职业切换规则

- 工作职业可切换。
- 切换后原工作职业熟练度保留 50%。
- 当前装备的工作技能会失效，但不会完全删除，可重新切回后恢复。
- 24 小时内重复切换工作职业，第 2 次起增加额外费用。

## 3. 职业经验、熟练度与技能点

### 3.1 经验类型

| 经验类型 | 获得方式 | 用途 |
|---|---|---|
| 单位经验 | 战斗、登陆、任务、挂机 | 提升单位等级 |
| 主职业熟练度 | 使用主职业技能、参与主职业对应行为 | 转职、觉醒、技能升级 |
| 副职业熟练度 | 使用副职业技能、装备副职业训练书 | 学习副职业技能 |
| 工作职业熟练度 | 在飞船房间工作、生产、维修、研究 | 提升工作效率、解锁工作技能 |

### 3.2 技能点规则

| 来源 | 获得数量 |
|---|---:|
| 单位每升 2 级 | 通用技能点 +1 |
| 主职业每升 5 级 | 主职业技能点 +1 |
| 进阶转职成功 | 进阶技能点 +3 |
| 觉醒成功 | 觉醒技能点 +5 |
| 副职业熟练度每 500 | 副职业技能点 +1 |
| 工作职业熟练度每 500 | 工作技能点 +1 |

### 3.3 技能等级规则

| 技能稀有度 | 最高等级 | 升级消耗 | 说明 |
|---|---:|---|---|
| 普通 | 5 | 技能点 + 星尘币 | 基础技能，容易获取 |
| 优秀 | 5 | 技能点 + 星尘币 + 小材料 | 有明显构筑价值 |
| 稀有 | 4 | 技能点 + 职业材料 | 核心技能 |
| 史诗 | 3 | 技能点 + 稀有职业材料 | 改变玩法 |
| 传说 | 2 | 技能点 + 传说材料 | 强力核心 |
| 神话 | 1 | 不可升级 | 觉醒级或事件唯一技能 |

## 4. 主职业树总览

以下设计按 10 个主要种族建立，每个种族提供：

- 1 个基础主职业

- 每个进阶职业 2 个觉醒方向
- 基础技能库
- 进阶技能库
- 觉醒技能库

# 17. 主职业、进阶、觉醒技能学习规则

## 17.1 技能可学习条件

| 技能来源 | 条件 |
|---|---|
| 主职业基础技能 | 当前种族对应基础主职业，等级达到要求 |
| 进阶职业技能 | 已完成对应进阶转职 |
| 觉醒技能 | 已完成对应觉醒 |
| 副职业技能 | 当前副职业为对应职业 |
| 工作职业技能 | 当前工作职业为对应职业，且工作熟练度达到要求 |
| 技能书技能 | 满足种族、职业、等级、技能槽条件 |

## 17.2 技能槽规划

| 槽位类型 | 初始数量 | 最大数量 | 说明 |
|---|---:|---:|---|
| 主动技能槽 | 2 | 5 | 战斗中可释放 |
| 被动技能槽 | 3 | 8 | 自动生效 |
| 主职业核心槽 | 1 | 3 | 只能装备主职业/进阶/觉醒核心技能 |
| 副职业槽 | 0 | 3 | 装备副职业技能，切副职业后清空 |
| 工作技能槽 | 1 | 4 | 仅在飞船岗位或生产时生效 |
| 觉醒槽 | 0 | 2 | 觉醒后开放 |

## 17.3 技能书规则

技能书是一次性物品，用后消失。

| 技能书稀有度 | 可开出技能 | 使用限制 | 获取难度 |
|---|---|---|---|
| 普通技能书 | 普通技能 | 无特殊要求 | 常见 |
| 优秀技能书 | 普通/优秀技能 | 等级 ≥ 5 | 常见 |
| 稀有技能书 | 优秀/稀有技能 | 等级 ≥ 15 | 较少 |
| 史诗技能书 | 稀有/史诗技能 | 等级 ≥ 25，可能要求转职 | 稀有 |
| 传说技能书 | 史诗/传说技能 | 等级 ≥ 40，常要求进阶或觉醒 | 很稀有 |
| 神话技能书 | 神话技能 | 通常唯一或事件获得 | 极稀有 |

### 17.4 技能书使用流程

1. 玩家选择技能书。
2. 系统筛选单位是否满足：种族、职业、等级、转职、觉醒、副职业、工作职业条件。
3. 如果满足，显示可学习技能列表。
4. 使用后技能书消失。
5. 若是随机技能书，则从对应技能池随机抽取。
6. 如果抽到已拥有技能，转化为技能碎片。

### 17.5 随机技能池权重

| 技能稀有度 | 普通技能书 | 优秀技能书 | 稀有技能书 | 史诗技能书 | 传说技能书 |
|---|---:|---:|---:|---:|---:|

| 职业类型 | AI 行为 |
|---|---|
| 近战爆发 | 优先切入后排、攻击低生命目标 |
| 远程火力 | 保持距离，优先攻击威胁最高目标 |
| 坦克守卫 | 站在门口、通道、脆皮附近，优先嘲讽 |
| 治疗辅助 | 保持后排，优先治疗低生命友军 |
| 控制职业 | 优先控制精英、首领、正在释放技能的敌人 |

| 虚空异常 | 优先给高防御目标施加削弱和真实伤害 |
| 工作型单位 | 舰内防守时优先保护对应房间 |

```text
濒死保命技能 > 打断敌方高威胁技能 > 治疗低血友军 > 控制精英敌人 > 爆发技能 > 普通输出技能 > 位移技能
```

| 外星指挥官 | 站在中后排给队伍加 Buff |
| 虫巢寄生虫 | 在敌舰多房间扩散小虫 |

## 19.4 登陆战 AI 特殊规则

|---|---|

| 近战职业 | 优先保护远程和治疗 |
| 远程职业 | 优先攻击飞行敌人和远程敌人 |

# 22. 职业系统数值平衡建议

## 22.1 主职业强度分层

| 阶段 | 战斗强度 | 技能复杂度 | 养成成本 |
|---|---:|---:|---:|
| 基础主职业 | 1.0 | 低 | 低 |
| 进阶职业 | 1.5 | 中 | 中 |
| 觉醒职业 | 2.2 | 高 | 高 |
| 副职业 | 0.3~0.6 | 低中 | 中 |
| 工作职业 | 战斗 0.1~0.3 / 生产 1.0 | 低 | 中 |

## 22.2 避免数值失控的限制

1. 同类全队光环只取最高值，不叠加。
2. 副职业被动不能无限叠，因为切换副职业会清除旧技能。
3. 觉醒技能强，但技能槽有限。
4. 工作技能大多只在岗位生效，不直接堆战斗。
5. 主职业进阶不可逆，避免玩家频繁切最优解。
6. 高稀有技能书稀有且一次性使用，保证长期价值。

## 22.3 推荐公式

### 职业熟练度获得

```text
主职业熟练度 = 战斗时长 × 1 + 主职业技能释放次数 × 8 + 击杀数 × 5
副职业熟练度 = 副职业技能触发次数 × 6 + 战斗完成奖励 × 20
工作职业熟练度 = 工作时长分钟 × 岗位适配系数 × 房间等级系数
```

### 岗位适配系数

| 适配 | 系数 |
|---|---:|
| S | 1.2 |
| A | 1.05 |
| B | 1.0 |
| C | 0.8 |
| D | 0.5 |

### 技能学习费用

```text
技能学习费用 = 基础费用 × 稀有度系数 × 技能阶段系数
```

| 稀有度 | 系数 |
|---|---:|
| 普通 | 1.0 |
| 优秀 | 1.8 |
| 稀有 | 3.5 |
| 史诗 | 8.0 |
| 传说 | 20.0 |
| 神话 | 50.0 |

| 技能阶段 | 系数 |
|---|---:|
| 基础 | 1.0 |
| 进阶 | 1.6 |
| 觉醒 | 3.0 |
| 副职业 | 1.2 |
| 工作职业 | 1.0 |

# 27. 总结

本职业系统的核心是“三层职业同时存在”：

1. **主职业**负责种族身份和长期成长。  
2. **副职业**负责通用搭配和玩家构筑。  
3. **工作职业**负责飞船经营、生产、建设、维修、研究和挂机收益。  

这样可以让每个单位都拥有多个价值维度：

- 战斗是否强；
- 技能是否稀有；
- 转职路线是否适合队伍；
- 是否有高价值副职业；
- 是否能提高飞船生产效率；
- 是否适合特定房间岗位；
- 是否拥有觉醒潜力。

最终形成《星空掠夺者》的核心养成体验：

```text
获得单位 → 看种族和主职业 → 看初始技能 → 安排岗位 → 选择副职业 → 培养技能 → 进阶转职 → 觉醒 → 成为飞船核心船员
```
