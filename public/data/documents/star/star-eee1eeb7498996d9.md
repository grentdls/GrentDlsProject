# 《星空掠夺者》单位种族、技能库与100个单位数据表完整设计文档

> 项目：Unity2D 桌面挂机 / 飞船拼装 / 自动战斗 / 掠夺养成  
> 文档用途：单位系统专项设计，可直接拆成 `UnitConfig`、`SkillConfig`、`SkillPoolConfig`、`TalentTreeConfig`、`RecruitPoolConfig` 等配置表。  
> 核心原则：单位价值不仅由稀有度决定，也由出生时随机到的技能决定。高稀有技能、强职位适配、稀有获取渠道，会让同名单位产生明显价值差异。

---

## 1. 单位系统设计目标

《星空掠夺者》的单位同时承担四层玩法：

1. **驻船职位**：驾驶、火控、维修、医疗、生产、科研、生态、异常、隐秘、交易等职位会影响飞船属性、产出和桌面挂机事件。
2. **飞船战辅助**：飞船战中，单位在职位上触发舰职技能，例如炮击强化、护盾维护、敌舰扫描、规避预判、登舰支援。
3. **登舰战斗**：飞船接近后，单位进入敌舰房间战斗、破坏模块、击杀敌方船员、偷取资源。
4. **星球登陆**：单位下船探索星球，与本地生物、遗迹守卫、Boss 战斗，掠夺财宝、单位、技能书和飞船部件。

单位总价值建议：

```text
单位总价值 = 单位稀有度价值
         + 初始技能价值
         + 种族/职位适配价值
         + 技能树成长价值
         + 专属特性价值
         + 外观收藏价值
```

其中“初始技能价值”非常关键：同样是 SR 单位，如果出生自带史诗技能，市场价和实战价值都应明显提升。

### 3.3 初始技能池组成

每个单位被获得时，先由单位配置决定可抽技能池，再根据稀有度权重抽取：

```text
最终可抽技能池 = 种族技能池 + 职业技能池 + 系列技能池 + 通用技能池 + 特殊来源技能池
```

| 技能来源 | 权重 | 说明 |
|---|---:|---|
| 种族技能池 | 50% | 保证植物、妖兽、机械等差异明显 |
| 职业技能池 | 25% | 坦克、治疗、炮手、刺客、维修等定位 |
| 通用技能池 | 15% | 急救、射击、手雷、维修工具等通用能力 |
| 系列技能池 | 8% | 毒藤、王兽、奇点、黑帆、星核等系列特色 |
| 特殊来源技能池 | 2% | Boss、事件、虚空污染、古代遗迹等特殊技能 |

### 3.4 高稀有技能价值公式

```text
单位市场估值 = 单位基础价 × 稀有度系数 × 技能价值系数 × 成长词条系数

技能价值系数 = 1 + Σ(初始技能价值权重)
普通 +0.03
优秀 +0.08
稀有 +0.18
史诗 +0.40
传说 +0.95
神话 +2.50
```

示例：SR 毒藤猎手基础价 650，出生自带普通、优秀、史诗技能：

```text
650 × 1.28 × (1 + 0.03 + 0.08 + 0.40) ≈ 1256
```

## 5. 技能书与后天学习规则

技能书是一次性消耗品，主要用来让玩家长期追求高稀有技能，并让低稀有单位也有培养价值。

| 技能书类型 | 可学习技能 | 使用后 | 基础成功率 | 失败补偿 | 设计用途 |
|---|---|---|---:|---|---|
| 普通技能书 | 普通 | 消耗 | 100% | 无 | 补基础技能 |
| 优秀技能书 | 优秀及以下 | 消耗 | 95% | 少量技能经验 | 前期构筑成型 |
| 稀有技能书 | 稀有及以下 | 消耗 | 85% | 稀有残页 | 中期流派补强 |
| 史诗技能书 | 史诗及以下 | 消耗 | 70% | 史诗残页 | 核心构筑资源 |
| 传说技能书 | 传说及以下 | 消耗 | 55% | 传说残页 | 高价值交易品 |
| 神话技能书 | 神话及以下 | 消耗 | 35% | 神话残页 | 长期终局追求 |

亲和修正：

| 情况 | 成功率修正 | 效果修正 |
|---|---:|---|
| 同种族技能 | +15% | 完整效果 |
| 相邻种族技能，例如植物+虫巢、机械+晶体、幽灵+虚空 | +5% | 完整效果 |
| 通用技能 | 0 | 完整效果 |
| 冲突技能，例如机械学植物治疗、幽灵学物理护甲 | -15% | 效果-20%，但获得异化表现 |
| 神话技能跨种族学习 | -25% | 需要星核残页 |

技能槽上限：

## 7. 自动战斗技能逻辑

技能类型分为：主动攻击、控制、治疗、护盾、领域、召唤、舰职、经济探索、被动。自动战斗按优先级选择技能。

```csharp
Skill PickSkill(Unit caster, BattleContext ctx)
{
    var skills = caster.AvailableSkills.Where(s => s.IsReady && s.CanUse(ctx));

    if (caster.HpPercent < 0.30f)
        return skills.BestByTag("SelfShield", "Heal", "Escape");

    if (ctx.Allies.Any(a => a.HpPercent < 0.35f))
        return skills.BestByTag("Heal", "Protect", "Revive");

    if (ctx.Enemies.Any(e => e.IsCastingHighThreat))
        return skills.BestByTag("Stun", "Silence", "Bind", "Interrupt");

    if (ctx.EnemyClusterCount >= 3)
        return skills.BestByTag("Area", "Field", "Summon");

    if (ctx.Target.HpPercent < 0.30f)
        return skills.BestByTag("Execute", "Burst", "Damage");

    return skills.OrderByDescending(s => s.EvaluateScore(ctx)).FirstOrDefault();
}
```

## 10. 技能树通用规则

| 等级 | 解锁内容 | 消耗 |
|---:|---|---|
| Lv1 | 初始技能、专属特性 | 无 |
| Lv5 | 主干节点1 | 单位经验 |
| Lv10 | 分支A/B二选一 | 种族材料 |
| Lv15 | 主干节点2 | 单位经验 + 金币 |
| Lv20 | 分支节点2 | 技能残页 |
| Lv25 | 技能槽扩展机会 | 训练芯片 |
| Lv30 | 分支终点强化 | 稀有种族材料 |
| Lv40 | 专属特性强化 | 史诗材料 |
| Lv50 | 终极节点 | 传说材料/星核残页 |

每个单位有三条线：

1. **主干线**：强化单位基础定位，通常必点。
2. **分支A**：偏战斗方向，例如伤害、控制、坦度、爆发。
3. **分支B**：偏职位/经济/辅助方向，例如产出、修理、探索、招募。

限制建议：N最多8节点，R最多10节点，SR最多12节点，SSR最多15节点，UR最多18节点。这样同一个单位也能养出不同路线。

## 14. 总结

这套单位系统的核心是：

```text
种族差异 + 初始随机技能 + 技能书学习 + 技能树分支 + 飞船职位适配 + 获取渠道差异
```

玩家长期追求的不是单纯“高稀有单位”，而是：

- 植物生命出生自带史诗控制。
- 妖兽单位自带传说爆发。
- 机械单位拥有强力火控舰职。
- 幽灵单位拥有穿墙+复活组合。
- 外星单位拥有神话控制。
- 虚空单位拥有高风险高收益舰职。
- 虫巢单位拥有召唤链。
- 晶体单位同时提供矿物经济和护盾。
- 元素单位拥有高爆发和能源职位收益。
- 普通佣兵如果出生带神话技能，也能成为收藏级单位。
