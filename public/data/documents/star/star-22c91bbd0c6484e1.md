# 《星空掠夺者》星球、敌人、随机事件、掉落与UI完整设计文档

版本：v1.0  
适用项目：Unity2D 桌面挂机飞船建造游戏《星空掠夺者》  
关联系统：飞船部件系统、单位种族技能系统、职业系统、装备套装系统  
核心目标：让桌面挂机时的宇宙探索、敌舰遭遇、星球登陆、奇遇交易、掉落奖励形成一套“随机但可控、数值可平衡、内容可扩展”的配置体系。

---

## 1. 系统定位

本系统负责游戏中所有“外部世界内容”的生成与结算，主要覆盖以下内容：

1. 星区与星球生成。
2. 星球稀有度、环境、资源、敌人、事件配置。
3. 敌人从已有单位角色列表中随机生成。
4. 敌方飞船从已有飞船部件库中随机拼装。
5. 桌面挂机时随机触发奇遇、交易、敌舰战、星球登陆等事件。
6. 掉落物与星球、飞船、敌人、事件稀有度联动。
7. 相关 UI 预制体界面结构。

这个系统不是单纯的随机刷怪，而是整个游戏的“自动内容生成层”。它需要保证玩家挂机时能不断看到新事件、新敌人、新星球、新飞船，同时也能通过星球等级、稀有度、星区危险度控制奖励价值和战斗难度。

## 2. 世界生成总结构

### 2.1 世界层级

```text
宇宙 Universe
 └─ 星区 Sector
     └─ 航线 Route
         └─ 星球 Planet
             ├─ 星球事件 PlanetEvent
             ├─ 登陆敌人 GroundEnemyGroup
             ├─ 资源点 ResourceNode
             └─ 特殊设施 SpecialSite
         └─ 太空遭遇 SpaceEncounter
             ├─ 敌方飞船 EnemyShip
             ├─ 漂流物 Debris
             ├─ 商队 Trader
             ├─ 奇遇事件 Adventure
             └─ 宇宙异常 Anomaly
```

### 2.2 玩家挂机时的基础循环

```text
桌面飞船常驻运行
 → 每隔一段时间推进航行进度
 → 根据当前星区、危险度、玩家飞船噪音值、雷达值生成事件
 → 如果触发普通事件：弹出桌面小提示，可自动处理
 → 如果触发战斗事件：进入自动飞船战或登陆战
 → 战斗结算掉落、经验、材料、俘虏、部件、装备
 → 玩家可手动展开详情界面调整船员、部件、战利品
```

### 2.3 随机内容的控制原则

| 原则 | 说明 |
|---|---|
| 随机但不失控 | 所有随机都受星区等级、星球稀有度、玩家战力影响 |
| 稀有度统一 | 星球、敌人、飞船、掉落、事件共享一套稀有度逻辑 |
| 内容可复用 | 敌人直接从已有单位库抽取，飞船从已有部件库拼装 |
| 低打扰桌面体验 | 小事件可自动结算，大事件才提醒玩家介入 |
| 奖励有记忆点 | 高稀有星球、高稀有敌舰、高稀有事件应明显更有价值 |
| 失败不空手 | 失败也可获得少量残骸、经验、情报、仇敌标记 |

## 3. 统一稀有度体系

### 3.1 稀有度等级

| 稀有度 | 英文ID | 颜色建议 | 基础权重 | 数值倍率 | 掉落品质上限 | 描述 |
|---|---|---:|---:|---:|---|---|
| 普通 | Common | 白/灰 | 55% | 1.00 | 普通~优秀 | 常见星球、普通敌舰、基础掉落 |
| 优秀 | Uncommon | 绿 | 25% | 1.15 | 普通~稀有 | 资源更多，有少量特殊词条 |
| 稀有 | Rare | 蓝 | 12% | 1.35 | 优秀~史诗 | 出现精英敌人、稀有部件、稀有技能书 |
| 史诗 | Epic | 紫 | 5.5% | 1.65 | 稀有~传说 | 特殊星球、精英舰队、套装装备概率上升 |
| 传说 | Legendary | 橙 | 2% | 2.10 | 史诗~神话 | Boss、远古遗迹、核心部件概率提升 |
| 神话 | Mythic | 红/金 | 0.5% | 2.80 | 传说~神话 | 极低概率，唯一事件、特殊单位、觉醒材料 |

### 3.2 稀有度联动规则

星球稀有度、敌人稀有度、敌舰稀有度、掉落稀有度不是完全独立随机，而是相互影响。

```text
最终掉落稀有度评分 =
星球稀有度评分 × 0.30
+ 敌方飞船稀有度评分 × 0.25
+ 敌人角色最高稀有度评分 × 0.20
+ 事件稀有度评分 × 0.15
+ 玩家掠夺加成评分 × 0.10
```

稀有度评分：

```text
普通=1，优秀=2，稀有=3，史诗=4，传说=5，神话=6
```

示例：

```text
星球：史诗 4
敌舰：稀有 3
敌人最高稀有度：传说 5
事件：稀有 3
玩家掠夺加成评分：2
最终评分 = 4×0.30 + 3×0.25 + 5×0.20 + 3×0.15 + 2×0.10
       = 1.2 + 0.75 + 1.0 + 0.45 + 0.2
       = 3.6
```

最终评分 3.6 对应“稀有偏史诗”的掉落池。

| 星球稀有度 | 资源点数量 | 登陆战波数 | 精英概率 | 特殊事件概率 | 高稀有掉落修正 |
|---|---:|---:|---:|---:|---:|
| 普通 | 2-3 | 1-2 | 5% | 5% | +0% |

| 神话 | 8-10 | 4-5 | 55% | 40% | +60% |

### 6.2 星球危险度影响

```text
敌人数量倍率 = 1 + (危险度 - 1) × 0.45
敌人生命倍率 = 1 + (危险度 - 1) × 0.25
敌人攻击倍率 = 1 + (危险度 - 1) × 0.20
掉落数量倍率 = 1 + (危险度 - 1) × 0.18
事件触发倍率 = 1 + (危险度 - 1) × 0.12
```

## 7. 敌人生成系统

### 7.1 敌人来源

敌人不需要重新制作一套单位，而是从已有的“100个不同种族单位列表”中抽取，然后根据星球、事件、阵营、稀有度添加敌人参数修正。

```text
已有单位模板 UnitTemplate
 → 根据星球敌人种族池筛选
 → 根据事件类型筛选定位
 → 按稀有度权重抽取单位
 → 生成 EnemyInstance
 → 添加等级、稀有度、词条、AI、掉落、阵营
```

### 7.5 敌人基础属性公式

每个已有单位都有基础属性。生成敌人时按以下公式计算：

```text
等级倍率 = 1 + (等级 - 1) × 0.075
稀有倍率 = 稀有度数值倍率
阶级倍率 = 敌人阶级倍率
环境适配倍率 = 1.0 ~ 1.25
事件倍率 = 0.85 ~ 1.80

最终生命 = 单位基础生命 × 等级倍率 × 稀有倍率 × 阶级倍率 × 环境适配倍率 × 事件倍率
最终攻击 = 单位基础攻击 × 等级倍率 × 稀有倍率 × 阶级倍率 × 环境适配倍率 × 事件倍率
最终防御 = 单位基础防御 × 等级倍率 × 稀有倍率 × 阶级倍率
最终护盾 = 单位基础护盾 × 等级倍率 × 稀有倍率 × 阶级倍率
```

### 10.6 敌舰随机拼装算法

```text

2. 根据玩家当前战力和星区等级选择舰船等级。
3. 根据事件稀有度选择舰船稀有度。
4. 根据稀有度确定尺寸和部件预算。
5. 先放置舰桥、能源核心、生存模块。
6. 根据阵营偏向放置攻击/防御/生产/特殊模块。
7. 自动生成连接通道。
8. 检查电力是否为正数，若不足则补充能源。
9. 检查氧气覆盖，若不足则补充生存模块。
10. 检查战斗力，若低于目标战力则补充武器或船员。
11. 生成外观主题、部件等级、破损程度。
```

```text
敌舰战力 =
武器战力 × 0.30
+ 防御战力 × 0.20
+ 护盾战力 × 0.15
+ 能源稳定 × 0.10
+ 船员战力 × 0.15

```

## 14. 掉落系统

### 14.1 掉落分类

| 分类 | 内容 |
|---|---|
| 基础资源 | 金属、晶体、燃料、食物、木质纤维、生物胶质 |
| 飞船部件 | 武器模块、防御模块、能源模块、生产模块、生存模块 |
| 装备 | 武器、防具、首饰、套装装备 |
| 技能书 | 种族技能、主职业技能、副职业技能、觉醒技能 |
| 船员 | 俘虏、冷冻舱、雇佣、特殊单位 |
| 蓝图 | 部件蓝图、装备蓝图、套装图纸、飞船布局图 |
| 觉醒材料 | 种族觉醒石、虚空核心、神话晶核 |
| 事件道具 | 藏宝图、商人信物、遗迹钥匙、黑市通行证 |

### 14.2 掉落稀有度计算

```text
掉落基础等级 = 事件等级 或 星球等级 或 敌舰等级
掉落稀有评分 = 星球评分×0.30 + 敌舰评分×0.25 + 敌人评分×0.20 + 事件评分×0.15 + 掠夺加成×0.10
```

掉落品质转换：

| 最终评分 | 掉落池 |
|---:|---|
| 1.0-1.6 | 普通池 |
| 1.7-2.5 | 优秀池 |
| 2.6-3.4 | 稀有池 |
| 3.5-4.3 | 史诗池 |
| 4.4-5.2 | 传说池 |
| 5.3+ | 神话池 |

### 14.3 掉落数量公式

```text
掉落数量 = 基础数量 × 敌人阶级倍率 × 星球危险倍率 × 掠夺效率倍率 × 首次发现倍率
```

| 来源 | 基础数量 |
|---|---:|
| 普通小怪 | 1-2 |
| 精英敌人 | 2-4 |
| 队长 | 3-6 |
| Boss | 5-10 |
| 普通敌舰 | 4-8 |
| 精英敌舰 | 8-15 |
| 传说敌舰 | 15-30 |
| 星球资源点 | 2-8 |
| 传说事件 | 10-30 |

### 14.4 掉落权重修正

| 条件 | 修正 |
|---|---:|
| 星球与材料类型匹配 | 对应材料权重×2 |
| 敌人种族与掉落匹配 | 对应装备/材料权重×1.5 |
| 敌舰部件被完整缴获 | 对应部件掉落+30% |
| 船员有掠夺职业 | 掉落数量+5%~30% |
| 战斗中破坏过度 | 部件完整掉落-20%~60% |
| 登舰成功占领敌舰 | 部件和俘虏概率大幅提升 |
| 使用自动远程摧毁 | 材料多，完整部件少 |
| 星球首次探索 | 稀有掉落+20% |
| 已重复刷同星球 | 稀有掉落逐步衰减 |

## 18. 招募与俘虏规则

### 18.1 来源

| 来源 | 说明 |
|---|---|
| 冷冻舱 | 奇遇获得随机单位 |
| 敌舰俘虏 | 登舰战胜利后概率捕获 |
| 星球救援 | 救出被困单位 |
| 商人雇佣 | 花信用币招募 |
| 黑市购买 | 高稀有但可能有负面词条 |
| 事件孵化 | 植物种子、虫卵、机械核心生成单位 |
| Boss投降 | 特殊首领可转化为船员 |

### 18.2 招募稀有度

```text
招募单位稀有度 = 来源稀有度 × 0.35 + 事件稀有度 × 0.25 + 星球稀有度 × 0.20 + 玩家声望/职业加成 × 0.20
```

### 18.3 俘虏转化流程

```text
击败敌舰
 → 判断是否有存活敌方船员
 → 判断玩家是否有牢房/医疗舱/谈判职业
 → 生成俘虏列表
 → 玩家选择：招降 / 释放 / 卖给黑市 / 处决 / 拆解机械单位
```

PlanetInstance GeneratePlanet(SectorConfig sector, int playerPower)
{
    PlanetConfig config = WeightedPick(sector.planetPool);
    int level = RandomRange(config.minLevel, config.maxLevel);
    Rarity rarity = RollRarity(sector.rarityBonus);
    float danger = config.baseDanger * sector.danger * RarityDangerFactor(rarity);

    PlanetInstance planet = new PlanetInstance();
    planet.planetTypeId = config.planetTypeId;
    planet.generatedName = GeneratePlanetName(config);
    planet.level = level;
    planet.rarity = rarity;
    planet.danger = danger;
    planet.environmentTags = config.environmentTags.ToList();
    planet.exploreNodes = GenerateExploreNodes(planet);
    return planet;
}

                + ctx.enemyRarityScore * 0.20f
                + ctx.eventRarityScore * 0.15f
                + ctx.playerLootBonusScore * 0.10f;

## 23. 数值平衡建议

### 23.1 玩家战力与事件匹配

| 事件难度 | 敌人战力/玩家战力 | 推荐处理 |
|---|---:|---|
| 简单 | 0.5-0.75 | 自动结算，无需提醒 |
| 普通 | 0.75-1.05 | 自动战斗，可弹小提示 |
| 困难 | 1.05-1.35 | 弹出事件详情，建议玩家确认 |
| 危险 | 1.35-1.70 | 强提醒，默认不自动开战 |
| 致命 | 1.70+ | 需要玩家手动确认 |

### 23.2 掉落价值控制

为了避免桌面挂机无限刷爆资源，需要做以下限制：

| 限制 | 说明 |
|---|---|
| 同星球重复衰减 | 同一星球清理多次后稀有掉落降低 |
| 高稀有事件冷却 | 传说/神话事件有全局冷却 |
| 自动挂机保护 | 长时间无人操作时，不自动消耗高价值道具 |
| 背包溢出规则 | 自动拆解低稀有，可设置保留条件 |
| 风险与收益绑定 | 高掉落必须伴随高危险或高消耗 |

## 26. 总结

本系统的核心不是单独增加敌人或事件，而是建立一套统一的随机内容框架：

```text
星区决定大方向
星球决定环境与资源
敌人从单位库抽取
敌舰从部件库拼装
事件决定玩法变化
稀有度贯穿所有奖励
UI负责低打扰展示和快速处理
```

这样设计后，后续只要继续往单位库、部件库、装备库、事件库、星球库里加数据，游戏内容就可以自然膨胀，并且不会破坏基础规则。

玩家在桌面挂机时，会不断遇到：

- 一艘由真实部件拼出来的敌舰。
- 一个稀有度不同、环境不同的星球。
- 一个可能发财也可能翻车的奇遇。
- 一个来自已有单位库、带职业和技能的敌人。
- 一套由星球、敌人、飞船、事件共同决定的掉落奖励。

这就是《星空掠夺者》后续扩展内容的核心框架。
