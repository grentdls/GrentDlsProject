# 《星空掠夺者》桌面弹窗式配置界面、背包、角色、战斗信息、地图与设置完整设计文档

版本：v1.0  
适用项目：Unity2D 桌面挂机飞船建造游戏《星空掠夺者》  
文档定位：用于程序搭建 UI 预制体、策划配置规则、美术拆分界面资源、后续扩展功能页面。

---

## 1. 文档目标

本阶段需要把《星空掠夺者》的主要配置界面完善成一套适合桌面游戏的弹窗系统。游戏不是传统全屏手游，也不是纯菜单管理游戏，而是一个常驻桌面的飞船挂机游戏，所以所有深度配置界面都应该以弹窗形式出现。

本文件重点设计以下界面：

1. 背包界面：管理所有库存，包括装备、飞船部件、资源、技能书、消耗品、事件物品、图纸、材料等。
2. 角色列表界面：查看所有单位，配置装备、技能、职业、职位、天赋、工作岗位、登舰队伍、登陆队伍。
3. 战斗信息界面：查看飞船战、登舰战、登陆战的实时状态、战斗日志、伤害统计、敌我信息、自动策略。
4. 地图界面：查看星区、星球、航线、事件点、敌舰、贸易点、资源点、危险区域。
5. 设置界面：桌面窗口行为、性能、音效、通知、挂机、自动战斗、快捷键、存档等配置。
6. 通用弹窗系统：所有界面的打开、关闭、拖拽、缩放、层级、吸附、最小化、通知联动规则。

## 2. 桌面游戏 UI 总原则

### 2.1 界面不是全屏，而是桌面弹窗

《星空掠夺者》的基础形态是一个常驻桌面的小飞船窗口。玩家平时看到的是飞船在桌面边缘、底部或角落运行。玩家点击飞船、事件提示、功能按钮后，才展开对应弹窗。

所有功能界面必须遵守：

| 规则 | 说明 |
|---|---|
| 弹窗化 | 背包、角色、地图、战斗信息、设置都以弹窗形式出现 |
| 可拖拽 | 弹窗标题栏可以拖动，不固定死在屏幕中央 |
| 可关闭 | 每个弹窗右上角都有关闭按钮，ESC 也能关闭最高层弹窗 |
| 可最小化 | 复杂界面可以缩成小标签，贴在屏幕边缘 |
| 可吸附 | 弹窗靠近屏幕边缘时自动吸附，避免挡住工作区 |
| 可缩放 | 大界面支持 80%、100%、120% 三档 UI 缩放 |
| 低打扰 | 自动战斗或挂机时，不强制弹出大界面，只显示小提示 |
| 信息分层 | 常用信息小窗显示，深度配置通过二级标签进入 |
| 不遮挡桌面 | 默认弹窗宽度不超过屏幕宽度的 65%，高度不超过 75% |
| 适配多显示器 | 记忆上次打开的位置，防止窗口跑到屏幕外 |

### 2.2 桌面模式下的三种界面层级

| 层级 | 名称 | 作用 | 示例 |
|---|---|---|---|
| L0 | 常驻飞船层 | 桌面上一直存在的小飞船、资源浮条、小事件按钮 | 主飞船、事件气泡 |
| L1 | 快捷弹窗层 | 小型配置、提示、快速操作 | 快速背包、快速战斗信息、角色卡片 |
| L2 | 管理弹窗层 | 中大型配置界面 | 背包、角色列表、地图、设置 |
| L3 | 二级详情层 | 从管理界面弹出的详情页 | 装备详情、技能详情、星球详情 |
| L4 | 确认层 | 二次确认、危险操作、购买确认 | 分解确认、转职确认、抛弃物品确认 |
| L5 | 系统提示层 | 不打断玩家的 toast 提示 | 获得装备、战斗胜利、库存满 |

### 2.3 弹窗尺寸建议

以 1920×1080 屏幕为基准：

| 弹窗类型 | 推荐尺寸 | 最小尺寸 | 最大尺寸 | 备注 |
|---|---:|---:|---:|---|
| 小提示弹窗 | 320×180 | 260×140 | 420×240 | 事件选择、快速提示 |
| 角色详情小窗 | 520×620 | 460×560 | 720×760 | 单位详情、装备对比 |
| 背包管理窗口 | 980×720 | 820×620 | 1280×820 | 主背包 |
| 角色列表窗口 | 1120×760 | 920×640 | 1400×860 | 角色配置 |
| 战斗信息窗口 | 960×620 | 760×520 | 1280×780 | 可实时更新 |
| 星图地图窗口 | 1180×760 | 920×620 | 1500×900 | 大地图 |
| 设置窗口 | 860×680 | 720×560 | 1100×780 | 分页设置 |

### 2.4 弹窗通用布局结构

所有大型弹窗使用统一结构：

```text
UI_WindowBase
├── Shadow_Backdrop                      // 可选，柔和阴影，不要黑色遮罩全屏
├── Root_Frame                            // 主窗口框体
│   ├── HeaderBar                         // 标题栏，可拖拽
│   │   ├── Icon_Title
│   │   ├── Text_Title
│   │   ├── Text_Subtitle / Breadcrumb
│   │   ├── Btn_Pin                       // 置顶
│   │   ├── Btn_Minimize                  // 最小化
│   │   ├── Btn_Close                     // 关闭
│   ├── TopStatusBar                      // 可选，资源/筛选/搜索
│   ├── Body                              // 主内容区域
│   ├── BottomActionBar                   // 底部操作区
│   ├── ResizeHandle                      // 右下角缩放点
│   └── EdgeSnapHotArea                   // 边缘吸附检测
```

### 2.5 弹窗视觉风格

本项目的主题是星空、飞船、掠夺、桌面挂机。UI 不能太厚重，也不能像传统科幻硬核面板。建议采用“轻科幻 + 模块卡片 + 桌面浮窗”的风格。

视觉关键词：

- 深蓝灰半透明框体。
- 霓虹青、星紫、暖橙作为功能点缀。
- 卡片边缘有轻微发光线。
- 背景有淡淡星尘、扫描线、网格纹。
- 稀有度颜色明显，但不要刺眼。
- 弹窗阴影柔和，像桌面小工具。
- 所有按钮要适合鼠标点击，不要做得太像手机大按钮。

稀有度颜色建议：

| 稀有度 | 颜色倾向 | UI用途 |
|---|---|---|
| 普通 | 灰白 | 基础装备、普通材料 |
| 优秀 | 绿色 | 常见可用物品 |
| 精良 | 蓝色 | 中期主力 |
| 稀有 | 紫色 | 高价值掉落 |
| 史诗 | 橙色 | 套装、强部件 |
| 传说 | 红金 | 核心战利品 |
| 神话 | 彩虹/星辉 | 极稀有、唯一物品 |

### 3.2 五个主界面的打开方式

| 界面 | 入口 | 快捷键 | 默认行为 |
|---|---|---|---|
| 背包 | 飞船小窗底部背包按钮 | B | 打开上次使用的背包分页 |
| 角色列表 | 船员按钮 | C | 打开角色总览 |
| 战斗信息 | 战斗按钮或战斗提示 | V | 若正在战斗，打开实时战斗页；否则打开最近战报 |
| 地图 | 地图按钮 | M | 打开当前星区地图 |
| 设置 | 齿轮按钮 | Esc 菜单内 | 打开基础设置 |

### 3.3 多窗口同时打开规则

默认允许同时打开 2 个管理弹窗。超过 2 个时，新打开的窗口会自动让最早打开的窗口最小化。

| 情况 | 规则 |
|---|---|
| 背包 + 角色 | 允许，用于给角色穿装备 |
| 背包 + 战斗信息 | 允许，用于战后整理掉落 |
| 地图 + 战斗信息 | 允许，用于查看遭遇点和敌舰 |
| 设置 + 其他窗口 | 设置打开后，其他窗口自动降层但不关闭 |
| 二级详情过多 | 同类详情只保留一个，例如只显示一个装备详情弹窗 |

## 4. 通用交互规则

### 4.1 拖拽

- 点击标题栏任意空白位置拖动窗口。
- 拖动到屏幕边缘 16 px 内触发吸附预览。
- 松开鼠标后吸附到边缘。
- 双击标题栏恢复默认位置。

### 4.2 最小化

窗口最小化后变成桌面边缘小标签。

```text
UI_MinimizedTab
├── Icon_WindowType
├── Text_ShortName
├── Icon_AlertDot
└── Btn_Restore
```

不同窗口最小化标签建议：

| 窗口 | 标签文字 | 有变化时提示 |
|---|---|---|
| 背包 | 库存 | 新物品、小红点 |
| 角色 | 船员 | 可升级、可穿戴 |
| 战斗 | 战斗 | 受伤、胜利、失败 |
| 地图 | 星图 | 新事件、危险接近 |
| 设置 | 设置 | 一般无红点 |

### 4.3 置顶

`Btn_Pin` 可以将弹窗固定在桌面最前。适合战斗信息、地图路线监控。

规则：

- 置顶窗口不会被新窗口自动最小化。
- 最多同时置顶 2 个窗口。
- 置顶窗口透明度可调到 70%。
- 鼠标移出后可自动半透明，鼠标移入恢复。

### 4.4 鼠标穿透模式

桌面挂机游戏很需要“鼠标穿透”。

设置项：

| 模式 | 说明 |
|---|---|
| 关闭 | 所有 UI 正常接收点击 |
| 仅飞船穿透 | 常驻飞船不挡桌面点击，弹窗仍可操作 |
| 战斗小窗穿透 | 战斗信息小窗不挡点击 |
| 全部穿透 | 仅保留热键和托盘唤醒，适合专注工作 |

注意：鼠标穿透模式下，窗口边缘需要保留 4 px 热区，用于恢复操作。

### 4.5 信息红点规则

红点不是所有东西都亮，要按优先级控制。

| 红点等级 | 表现 | 用途 |
|---|---|---|
| 轻提示 | 小蓝点 | 有新物品、新日志 |
| 中提示 | 黄点闪一次 | 可升级、库存快满 |
| 强提示 | 红点持续 | 战斗危险、船员濒死、库存满 |
| 紧急提示 | 红色边框+声音 | 飞船核心受损、战斗失败风险 |

## 5. 背包界面完整设计

### 5.1 背包界面定位

背包是“所有库存”的总管理界面，不只放装备，也要管理飞船部件、技能书、资源、消耗品、图纸、事件物品、贸易货物、战利品、套装、材料。

背包需要支持：

- 查看全部库存。
- 按类型筛选。
- 按稀有度筛选。
- 按来源筛选。
- 搜索名称、ID、标签。
- 批量分解、出售、锁定。
- 快速装备到角色。
- 快速安装到飞船。
- 技能书学习。
- 材料合成。
- 货物交易。
- 战利品结算后的一键入库。

### 5.4 背包容量规则

背包容量不只是格子数量，而是“舰船货舱容量”。

每个物品有 `cargoWeight` 和 `stackLimit`。

```text
当前占用 = Σ(物品数量 × 单件重量 × 堆叠压缩系数)
可用容量 = 飞船货舱容量 + 仓储部件加成 + 工作职业加成 + 临时事件加成
```

| 物品类型 | 默认重量 | 堆叠规则 |
|---|---:|---|
| 普通材料 | 0.01 | 9999 堆叠 |
| 稀有材料 | 0.03 | 999 堆叠 |
| 装备 | 1.0 | 不堆叠 |
| 飞船小部件 | 3.0 | 不堆叠 |
| 飞船大部件 | 8.0 | 不堆叠 |
| 技能书 | 0.2 | 同名可 99 堆叠 |
| 消耗品 | 0.1 | 99 堆叠 |
| 贸易货物 | 0.5 - 5.0 | 按货物类型 |
| 事件物品 | 0 | 不占容量，单独计入事件栏 |

库存满时：

1. 普通掉落会进入“临时战利品舱”。
2. 临时舱最多保留 24 小时游戏时间或 50 个物品。
3. 临时舱满后，低稀有度物品自动转化为资源碎片。
4. 稀有及以上物品不会自动丢弃，会强制弹出低打扰提示。

### 5.5 背包排序规则

排序项：

| 排序 | 说明 |
|---|---|
| 获得时间 | 新获得在前 |
| 稀有度 | 神话 > 传说 > 史诗 > 稀有 > 精良 > 优秀 > 普通 |
| 类型 | 装备、部件、资源、技能书等 |

| 可安装飞船 | 当前飞船可安装的排前 |
| 市场价值 | 高售价在前 |

### 5.7 物品详情面板

详情面板应根据物品类型切换布局。

#### 5.7.1 装备详情

显示内容：

- 装备图标、名称、稀有度、等级。
- 槽位：武器、头部、上衣、下衣、手套、鞋子、腰带、项链、戒指、耳饰。
- 基础属性。
- 随机词条。
- 套装名与已激活件数。
- 可穿戴种族或职业限制。
- 当前选中角色装备对比。
- 操作：装备、卸下、强化、洗练、锁定、分解、出售。

#### 5.7.2 飞船部件详情

显示内容：

- 部件结构：机械、植物、虚空、生体、晶体等。
- 模块类型：生产、生存、防御、攻击、核心、登舰、登陆。
- 尺寸：1×1、2×1、2×2、3×2 等。
- 电力、氧气、热量、耐久、产出、攻击、防御等。
- 相邻加成。
- 安装限制。

## 14. Unity2D 实现建议

### 14.1 UI 管理器

建议实现 `DesktopWindowManager`。

职责：

- 打开窗口。
- 关闭窗口。
- 管理窗口层级。
- 管理拖拽。
- 管理吸附。
- 管理最小化标签。
- 保存窗口位置。
- 控制置顶。
- 控制鼠标穿透状态。
- 管理 Esc 关闭逻辑。

伪代码结构：

```csharp
public class DesktopWindowManager : MonoBehaviour
{
    public void OpenWindow(string windowId, object context = null);
    public void CloseWindow(string windowId);
    public void MinimizeWindow(string windowId);
    public void RestoreWindow(string windowId);
    public void BringToFront(string windowId);
    public void PinWindow(string windowId, bool pinned);
    public void SaveWindowLayout();
    public void LoadWindowLayout();
    public void SetClickThroughMode(ClickThroughMode mode);
}
```

### 14.2 窗口基类

```csharp
public abstract class UIBaseWindow : MonoBehaviour
{
    public string WindowId;
    public RectTransform Root;
    public Button CloseButton;
    public Button MinimizeButton;
    public Button PinButton;
    public bool IsPinned;
    public bool IsMinimized;

    public virtual void Open(object context) {}
    public virtual void Close() {}
    public virtual void Refresh() {}
    public virtual void OnBringToFront() {}
    public virtual void OnMinimize() {}
    public virtual void OnRestore() {}
}
```

### 14.3 背包数据刷新建议

背包物品数量可能很大，应使用对象池和虚拟列表。

建议：

- `ScrollRect + GridLayoutGroup` 初期可用。
- 物品超过 500 个后改为虚拟滚动列表。
- 物品卡片使用对象池复用。
- 筛选和排序只刷新可见部分。
- 详情面板只在选中物品变化时刷新。

### 14.4 角色列表性能建议

角色可能达到 100 - 300 个。

建议：

- 左侧角色卡使用虚拟列表。
- 角色头像使用 Addressables 异步加载。
- 属性变化用事件通知刷新，不要每帧刷新全部角色。
- 战斗中只刷新正在参战角色。

### 14.5 战斗信息刷新建议

战斗信息是实时窗口，但桌面游戏不需要高频刷新。

刷新频率建议：

| 数据 | 刷新频率 |
|---|---|
| 血条 | 5 - 10 次/秒 |
| 战斗日志 | 事件触发时 |
| 掉落预览 | 掉落生成时 |
| 房间状态 | 2 - 5 次/秒 |
| 统计数据 | 1 次/秒 |
| 小地图单位位置 | 5 次/秒 |

### 14.6 地图实现建议

地图用 `RectTransform` 节点即可，不必做复杂 3D 星图。

实现方式：

- 中央星图是一个可拖拽、可缩放的 UI 容器。
- 节点是 `UI_MapNode` 预制体。
- 航线是 `UILineRenderer` 或自定义 Mesh。
- 背景用星云图 + 少量粒子。
- 扫描时在节点周围播放雷达圆环。

## 15. 界面操作流程示例

### 15.1 给角色换装备流程

```text
点击常驻飞船的角色按钮
→ 打开角色列表
→ 选择角色
→ 点击装备页
→ 点击武器槽
→ 背包弹窗打开并自动筛选武器
→ 选择武器
→ 右侧显示属性对比
→ 点击装备
→ 角色装备刷新
→ 套装效果刷新
```

### 15.2 学习技能书流程

```text
打开角色列表
→ 选择角色
→ 技能页
→ 点击可学习技能书列表
→ 背包弹窗筛选可用技能书
→ 选择技能书
→ 显示学习限制与效果
→ 点击学习
→ 弹出一次性消耗确认
→ 学习成功
→ 技能书消耗，技能进入技能槽或技能库
```

### 15.3 自动战斗查看流程

```text
桌面弹出战斗开始小提示
→ 玩家点击提示
→ 打开战斗信息窗口
→ 查看飞船战信息
→ 发现敌舰距离接近
→ 切换登舰优先策略
→ 登舰队进入敌舰
→ 战斗信息自动切换到登舰页
→ 战斗胜利
→ 弹出战后结算
→ 点击打开背包整理战利品
```

### 15.4 地图自动探索流程

```text
打开地图
→ 选择当前星区
→ 点击扫描
→ 发现星球、敌舰、贸易站
→ 选择自动探索策略：稀有优先
→ 设置撤退阈值和库存阈值
→ 开始自动航行
→ 地图最小化成边缘标签
→ 有奇遇时弹出小选择窗
```

### 15.5 库存满处理流程

```text
战斗胜利掉落大量物品
→ 背包容量不足
→ 部分物品进入临时战利品舱
→ 桌面提示“库存已满”
→ 点击打开背包
→ 自动进入临时战利品分页
→ 玩家批量分解普通装备
→ 点击领取全部
```

| 下拉框 | 1 套 | 通用 |
| 快捷键输入框 | 1 套 | 等待输入状态 |

## 18. 细节体验规则

### 18.1 高价值物品保护

以下物品默认自动锁定：

- 传说及以上装备。
- 史诗及以上技能书。
- 套装核心件。
- 唯一事件物品。
- 已装备物品。
- 已安装飞船部件。
- 带有神话词条的任何物品。

### 18.2 推荐按钮不要替玩家乱动

自动装备、自动队伍、自动策略都应该先给预览，再让玩家确认。

规则：

1. 点击自动推荐后，只显示推荐结果。
2. 绿色高亮将被替换的装备或角色。
3. 显示战力变化和关键属性变化。
4. 点击确认后才真正应用。

### 18.3 桌面低打扰模式

当玩家启用专注/低打扰时：

- 普通掉落不弹窗。
- 战斗胜利只显示 3 秒小 toast。
- 只有濒死、库存满、需要选择的奇遇才弹出。
- 弹窗默认半透明。
- 音效降低到 30%。
- 飞船动画降频。

### 18.4 弹窗恢复记忆

每个窗口记录：

- 上次位置。
- 上次尺寸。
- 上次打开分页。
- 是否置顶。
- 是否最小化。
- 透明度。

但以下情况重置：

- 屏幕分辨率变化后窗口超出屏幕。
- 多显示器减少导致窗口不可见。
- 玩家点击“重置窗口位置”。

## 19. 与已有系统的关联

### 19.1 与装备系统关联

- 背包读取装备配置表。
- 角色装备页调用装备穿戴规则。
- 套装效果在角色详情和背包详情中同时显示。
- 高稀有装备默认锁定。

### 19.2 与飞船部件系统关联

- 背包可筛选飞船部件。
- 飞船建造界面点击安装时，打开背包部件筛选。
- 战斗信息显示部件损伤。
- 地图敌舰详情显示敌舰部件预览。

### 19.3 与单位职业系统关联

- 角色职业页显示主职业树、副职业、工作职业。
- 技能书详情显示可学习条件。
- 工作职业影响飞船岗位和生产。
- 队伍配置读取角色职业标签。

### 19.4 与随机事件系统关联

- 奇遇弹窗通过事件系统触发。
- 交易弹窗读取当前星区贸易权重。
- 地图节点显示事件概率。
- 背包显示事件物品和贸易货物。

### 19.5 与掉落系统关联

- 战斗结算先进入战利品弹窗。
- 点击领取后进入背包。
- 稀有掉落触发通知。
- 库存不足进入临时战利品舱。

## 21. 总结

《星空掠夺者》的 UI 核心不是“做一套大而全的全屏菜单”，而是做一套适合桌面挂机的弹窗系统。玩家需要在工作、浏览网页、看视频时也能让飞船自动运行，所以 UI 必须轻量、可收起、可拖动、可置顶、可鼠标穿透。

本阶段最重要的实现顺序是：

```text
桌面飞船小窗
→ 通用弹窗系统
→ 背包
→ 角色列表
→ 战斗信息
→ 地图
→ 设置
→ 战后结算 / 交易 / 奇遇
```

只要通用弹窗系统先搭好，后续装备、飞船部件、职业、技能、星球、随机事件、交易系统都可以复用同一套 UI 框架，避免每个系统单独做一套界面导致后期维护困难。
