# 海盗生涯数值与性能基线

更新时间：2026-07-30

## 权威规则

运行时消耗、战斗缩放和 UI 预览统一读取
`Assets/Scripts/PirateCareer/CareerBalanceRules.cs`。新增数值时不得在
Controller 与 HUD 中分别复制常量。

## 已修正的失衡

| 系统 | 旧表现 | 当前基线 |
|---|---|---|
| 海兽首关 | 推荐战力 270，内容扩充后的默认主舰战力 1994 | 推荐战力 1850，初始态势为“优势”而非碾压 |
| 出航口粮 | 海兽 Lv.1 消耗 22，直接返还约 19 | 消耗 48，直接应急返还约 5，初始 120 口粮只够 2 航 |
| 港口断粮 | 不消耗、无后果 | 按工人和出航主舰持续消耗；断粮时生产降至 35% |
| 舰队派遣 | 只扣少量内部补给，港口恢复免费 | 同时校验并消耗全局口粮与舰载补给；返港补满也消耗口粮 |
| 港防压力 | 首轮评分 120；敌人 86 HP / 8 伤害；最多 32 艘 | 首轮评分 180；敌人 280 HP / 24 伤害；最多 24 艘 |
| 冒险敌人 | 海兽首关生命倍率 0.92、伤害倍率 1.0 | 海兽首关生命倍率 2.5、伤害倍率 1.8 |
| 大世界遭遇 | 普通事件无额外成长倍率 | Lv.1 起生命 1.15、伤害 1.35，并随等级增长 |
| 地基 | 建筑重量、地基承载、局部超载 | 仅使用逐格生命、抗火、抗爆、抗腐蚀和锚固强度 |

教学港防保留原难度：职业港防敌人增强后，教学专用倍率同步缩小，
避免新手教学被正式模式的数值上调波及。

## UI 同步

- 顶部口粮卡显示“足 / 稳 / 紧 / 危 / 断”储备角标。
- 生产建筑详情显示当前口粮状态与实际生产效率。
- 冒险界面显示交战态势、单次口粮消耗和剩余可出航次数。
- 舰队任务显示全局口粮与舰载补给消耗，资源不足时按钮直接禁用并显示原因。
- 地基详情只显示耐久与抗性；原“结构支撑”改为“地基完整度”。

## 性能约束

- 生产模拟由每秒 4 次降为每秒 1 次，仍按累计时间精确结算。
- 生产资源只有跨过 UI 显示整数时才发布刷新事件。
- 冒险战斗 HUD 以 10 Hz 刷新，单次循环统计存活目标，不再每帧执行多次 LINQ 和文本重建。
- 港防敌人上限由 32 降至 24，压力来自单体质量而不是堆实体。

## 自动验证

- `CareerBalanceSmokeTest`：首关压力、口粮航次、断粮效率、舰队任务、
  港防、大世界倍率和 JSON 存档往返。
- `PortInfrastructureSmokeTest`：健康地基忽略任意建筑重量、损毁地基禁止建造、
  逐格耐久状态与旧存档迁移。
