# 《吞吞舰船》敌人、精英与 Boss 攻击方式、挑战逻辑及战斗表现完整设计文档

> 文档类型：战斗内容增量与表现落地文档  
> 适用模式：肉鸽航行、海盗生涯无缝世界、板块核心、固定挑战区、世界巨兽、港口防守  
> 关联系统：36 艘主舰、60 名英雄、英雄普攻/主动技能、方形海域、12 个固定挑战、装备定向产出  
> 核心目标：让不同形象的敌人拥有符合其体型、武器与生态特征的攻击方式，使挑战来自“观察—判断—驾驶—反制”，而不是单纯增加生命和伤害

# 第一部分：版本定位与旧规则处理

## 0.1 本文覆盖的内容

本文补齐以下缺口：

1. 普通敌人、精英敌人、大型敌舰和海怪的真实攻击流程。
2. 敌方撞击、投射物、鱼雷、布雷、导弹、召唤、触手、吞噬等技能表现。
3. 现有 Boss 的阶段、部位、技能循环、狂暴与反制窗口。
4. 新增敌人和 Boss，并投放到现有 12 个主题板块与固定挑战。
5. 敌人编队组合、威胁预算、同屏技能调度与难度成长。
6. 预警、音效、镜头、水面、受击、死亡和模块破坏规则。
7. Unity 数据、AI 状态机、对象池、性能和验收要求。

本文不重做：

- 玩家主舰、英雄、装备的既有名称与来源。
- 船长位不释放普攻和主动技能的规则。
- 装备不进入抽奖池的规则。
- 48 米领海格、12 米生产区格、2 米建筑格的方形网格。
- 固定挑战区不可占领、不可建造、可选择难度的规则。

## 0.2 对旧敌人文档的关系

旧文档中的敌人名称、吞噬层级、两分钟 Boss 航段和基础定位继续有效。

若与本文冲突，以本文为准的内容：

- 攻击前摇和预警时长。
- 敌人攻击卡组。
- Boss 阶段与可破坏部位。
- 同屏攻击许可和危险预算。
- 固定挑战中的敌人组合。
- 难度 I～VI 的机制变化。

## 0.3 本次设计的核心变化

旧体验容易形成：

```text
敌人靠近
→ 自动攻击互相扣血
→ 玩家只需绕圈或堆数值
→ 大型敌人与小型敌人只是血量不同
```

新体验要求：

```text
识别敌人外形和武器
→ 观察攻击准备动作
→ 判断安全方向
→ 用驾驶、撞击、技能或部位破坏反制
→ 获得明确失衡窗口
→ 快速转火或吞噬
```

# 第二部分：敌人挑战设计总原则

## 1. 敌人不是移动血包

每种敌人至少回答四个问题：

| 问题 | 设计要求 |
| --- | --- |
| 它逼玩家做什么 | 转向、加速、减速、绕后、切目标、清场或保留技能 |
| 玩家怎样提前看懂 | 外形、挂点、航迹、预警形状、声音、队形 |
| 玩家怎样反制 | 躲避、打断、击破部位、引导误伤、清除场地、吞噬 |
| 反制后得到什么 | 硬直、弱点、取消技能、敌方误伤、额外掉落或安全区 |

禁止只通过以下方式制造“新敌人”：

- 同模型换颜色。
- 生命提高 300%。
- 攻击提高 300%。
- 所有动作加速到无法反应。
- 同时释放更多完全相同的弹体。

## 2. 单位职责限制

### 2.1 普通单位

- 1 个主威胁。
- 0～1 个辅助威胁。
- 1 个明确弱点或失败状态。
- 从首次发现到理解核心玩法不超过 20 秒。

### 2.2 精英单位

- 保留基础单位主威胁。
- 增加 1 个改变战术的精英机制。
- 最多 1 个通用数值词缀。
- 不同时获得两个全屏级机制。

### 2.3 大型单位

- 2～3 个攻击手段。
- 至少 1 个可破坏模块或方向弱点。
- 有完整攻击循环，不连续无间隔输出。

### 2.4 Boss

- 3～5 个普通技能。
- 1～2 个阶段核心技能。
- 2～4 个可破坏部位或阶段弱点。
- 每阶段只突出一个主要考题。
- 必须有练习后可稳定通过的反制方法。

## 3. 敌人威胁职责

| 职责 | 作用 | 代表单位 |
| --- | --- | --- |
| 压迫 | 持续小伤，迫使玩家不能停留 | 机炮艇、鲨鱼群 |
| 重击 | 长前摇、高伤害，要求明确躲避 | 冲角舰、巨鲸尾拍 |
| 封路 | 用雷区、火海、冰墙改变航线 | 布雷艇、炼油舰 |
| 控制 | 降速、牵引、击退、转向干扰 | 鱼叉舰、章鱼触手 |
| 远程 | 从安全区制造持续压力 | 导弹舰、火箭炮艇 |
| 召唤 | 不处理会不断增加场面复杂度 | 信号舟、航母 |
| 支援 | 保护或恢复核心敌人 | 护盾艇、维修舰 |
| 反吞噬 | 阻止玩家无脑冲入小型单位 | 爆破筏、刺豚群 |
| 猎杀 | 对低血、慢速或受控玩家追加压力 | 虎鲸、追猎艇 |
| 机制 | 改变锁定、视野、弹道或场地 | 烟雾舟、磁暴舰 |

## 4. 挑战必须保留驾驶价值

玩家主舰的核心操作是航行、转向、加速和撞击，因此敌人设计优先考验：

1. 航线选择。
2. 舰首与船侧朝向。
3. 速度差。
4. 转向半径。
5. 对预测落点的判断。
6. 是否愿意进入近身风险区。

不得把高难战斗变成：

- 场地持续全覆盖。
- 无法躲避的锁定伤害。
- 必须依靠指定英雄免疫。
- 玩家操船再好也只能硬吃。

# 第三部分：统一敌方攻击状态机

## 5. 攻击八阶段

所有敌方攻击统一拆为：

| 阶段 | 状态 | 主要内容 |
| --- | --- | --- |
| 选择 | Acquire | 目标、距离、角度、场地和攻击许可 |
| 告知 | Tell | 敌人姿态、武器转向、专属起手声 |
| 预警 | Telegraph | 方向、范围、倒计时和安全区 |
| 前摇 | Windup | 蓄力、装填、下潜、扬起触手、发动机增压 |
| 锁定 | Commit | 技能正式消耗，通常不能无成本取消 |
| 生效 | Active | 冲锋、发射、扫射、刺击、召唤 |
| 收尾 | Recovery | 后坐、过热、撞空、触手拔出、浮出喘息 |
| 冷却 | Cooldown | 返回移动或其他技能 |

标准事件链：

```text
AttackRequested
→ AttackPermitGranted
→ TellStarted
→ TelegraphStarted
→ AttackCommitted
→ PayloadSpawned
→ ImpactResolved
→ RecoveryStarted
→ AttackFinished
```

## 5.1 告知与预警的区别

告知是敌人自身动作：

- 炮口转向。
- 舰首压低。
- 导弹舱盖打开。
- 章鱼触手扬起。
- 鲸鱼吸气、摆尾或下潜。

预警是玩家可读信息：

- 红橙色落点。
- 冲锋走廊。
- 水下鱼雷尾迹。
- 海面隆起。
- 触手刺入点。
- 倒计时刻度。

高难可以减少辅助 UI 强度，但不能删除敌人自身告知动作。

## 5.2 锁定时点

进入 `Commit` 后：

- 攻击冷却开始。
- 目标死亡时按原路径或地面点执行。
- 敌人被普通小控制命中，不再自动退款。
- 只有标记为 `InterruptHeavy` 的打断可取消。
- 成功取消时进入 40%～70% 原冷却，不能立刻重放。

## 5.3 受控与打断

| 攻击阶段 | 普通眩晕 | 重打断 | 击破模块 |
| --- | --- | --- | --- |
| Acquire/Tell | 取消 | 取消 | 取消 |
| Telegraph | 延迟或取消 | 取消并失衡 | 对应技能取消 |
| Windup | 多数延迟 | 取消并失衡 | 对应技能取消并爆舱 |
| Commit 后 | 不取消 | 按技能标签 | 投射物已生成则继续 |
| Active | 不取消已存在弹体 | 可终止持续喷射 | 终止模块持续技能 |
| Recovery | 延长少量硬直 | 延长失衡 | 模块进入永久失效 |

# 第四部分：敌方预警与可读性标准

## 6. 预警形状

| 形状 | 含义 | 典型技能 |
| --- | --- | --- |
| 窄直线 | 精准穿刺或鱼雷 | 剑鱼、重鱼雷 |
| 宽直线/走廊 | 冲撞、巨浪、舰首炮 | 鲸鱼冲撞、冲角舰 |
| 扇形 | 侧舷齐射、喷火、尾拍 | 战列舰、鲸尾 |
| 圆形 | 导弹落点、浮出、爆炸 | 导弹雨、鲸鱼浮出 |
| 环形 | 推开、拉入、声波 | 巨鲸声浪、漩涡 |
| 航迹带 | 雷区、油火、渔网 | 布雷艇、炼油舰 |
| 两点连线 | 鱼叉、触手拉扯、电链 | 捕鲸舰、电鳗 |
| 多边形封区 | 章鱼触手牢笼、无人机墙 | 深渊章皇、蜂巢航母 |
| 棋盘格/分区 | 大范围阶段技能 | 饱和轰炸、风暴核心 |

视觉范围必须与判定误差控制在：

- 普通攻击：±0.15 米。
- 大型范围：±0.3 米。
- Boss 场地机制：±0.5 米。

## 6.1 敌方颜色与纹理

敌方危险区使用红橙主色，但必须通过纹理区分：

| 类型 | 边界 | 内部纹理 |
| --- | --- | --- |
| 即时重击 | 粗实线 | 向中心快速收缩 |
| 延迟爆炸 | 双层圆 | 倒计时扇区 |
| 持续伤害 | 闪烁虚线 | 流动火焰/毒液纹理 |
| 控制区域 | 锯齿或钩形边 | 向内/向外箭头 |
| 可摧毁危险物 | 红边＋白色弱点框 | 物体自身轮廓 |
| Boss 必杀 | 深红＋金属警戒刻度 | 清晰安全区方向 |

不能只靠红绿区分敌我；色弱模式增加：

- 敌方斜线纹。
- 友方点阵纹。
- 危险边缘脉冲。
- 独立图标。

## 6.2 预警时间基准

| 威胁等级 | 示例 | 标准预警 |
| --- | --- | ---: |
| W0 | 轻型机炮 | 0～0.2 秒，以枪口和曳光告知 |
| W1 | 普通炮弹、轻鱼叉 | 0.35～0.65 秒 |
| W2 | 鱼雷、爆破筏、喷火 | 0.7～1.1 秒 |
| W3 | 冲撞、重炮、鲸尾拍 | 1.0～1.6 秒 |
| W4 | 导弹雨、触手阵、浮出重击 | 1.6～2.5 秒 |
| W5 | Boss 阶段必杀 | 2.8～5 秒，分段显示 |

难度提升主要改变组合、数量、追踪方式和安全区，不把 W4/W5 压缩成无法反应。

## 6.3 屏幕外攻击

屏幕外 W2 以上攻击必须提供：

- 屏幕边缘方向标。
- 距离。
- 攻击类型图标。
- 到达前 0.5 秒的声音强调。
- 若镜头安全，轻微外扩以展示威胁方向。

屏幕外攻击不能在玩家完全没有信息时直接命中。

# 第五部分：玩家反制语言

## 7. 八种通用反制

| 反制 | 对应威胁 | 成功结果 |
| --- | --- | --- |
| 横向躲避 | 直线炮、鱼雷、冲撞 | 攻击落空，敌人暴露侧后方 |
| 急转/减速 | 预测导弹、提前量射击 | 落点偏移 |
| 加速穿越 | 闭合包围圈、慢速封区 | 在危险成型前脱离 |
| 撞击打断 | 蓄力炮、支援舰、触手根部 | 取消技能或产生失衡 |
| 击破部位 | 导弹舱、鱼雷管、触手、鲸甲 | 永久削弱对应技能 |
| 引导误伤 | 冲角、导弹、雷区、炸弹 | 伤害敌军或破坏部位 |
| 清理场地 | 水雷、渔网、无人机、寄生物 | 恢复航道 |
| 保留技能 | Boss 必杀、阶段召唤 | 用护盾、位移、爆发处理关键窗口 |

## 7.1 反制公平规则

- 每个 W3 以上攻击至少支持两种反制。
- 每个 Boss 阶段技能至少有一种不依赖特定英雄的驾驶反制。
- 特定英雄和装备可以降低难度，但不能成为唯一解。
- 玩家成功反制后，敌人必须有 0.8～4 秒收益窗口。
- 高难可以缩短收益窗口，但不能删除。

## 7.2 敌方误伤

允许误伤的攻击：

- 冲撞。
- 炮弹爆炸。
- 导弹落点。
- 水雷。
- 油桶和爆破筏。
- 鲸鱼尾拍与浮出。
- 章鱼触手刺击。
- 巨蟹钳击。

不允许误伤或只影响玩家的内容：

- 纯锁定减益。
- 剧情保护单位机制。
- Boss 召唤物的出生保护。

误伤伤害建议为对玩家伤害的 50%～100%，由技能配置决定。

# 第六部分：同屏危险预算

## 8. 攻击许可系统

敌人不能各自冷却结束就同时释放重击。统一由 `EnemyAttackDirector` 发放攻击许可。

攻击消耗危险点：

| 攻击 | 危险点 |
| --- | ---: |
| 轻型压迫攻击 | 1 |
| 普通炮击/轻控制 | 2 |
| 鱼雷/布雷/小范围爆破 | 3 |
| 重型冲撞/大型控制 | 4 |
| 导弹齐射/大型海怪攻击 | 5 |
| Boss 阶段技能 | 8 |
| Boss 必杀 | 12 |

建议上限：

| 场景 | 同时激活危险点 |
| --- | ---: |
| 新手 | 4 |
| 普通自由海域 | 7 |
| 中期固定挑战 | 10 |
| 高难固定挑战 | 14 |
| Boss 普通阶段 | 12 |
| Boss 必杀期间 | 12，暂停其他 W3 以上许可 |
| 多舰终局 | 18，但按各主舰屏幕区域拆分 |

## 8.1 职责槽

同一主控玩家周围同时最多：

- 1 个重击槽。
- 1 个强控制槽。
- 2 个封路槽。
- 4 个压迫槽。
- 1 个 Boss 机制槽。

例如：

```text
导弹审判舰正在饱和轰炸
→ 冻结新的冲撞、尾拍和大型鱼雷许可
→ 小艇仍可机炮压迫
→ 维修舰仍可支援
→ 布雷艇只允许维持旧雷，不新增大片雷区
```

## 8.2 不可组合规则

以下攻击默认不能完全重叠：

- 强制牵引＋不可转向冲撞。
- 全屏导弹雨＋完全封死的水雷环。
- 视野烟雾＋无边缘提示的远程重击。
- 连续击退＋场地边缘即死。
- 两个 Boss 必杀。
- 三个以上高强度屏震事件。

# 第七部分：敌人攻击家族

## 9. 撞击类

标准流程：

```text
拉开距离
→ 舰首/头部对准
→ 冲锋走廊出现
→ 发动机或肌肉蓄力
→ 锁定方向
→ 高速冲锋
→ 命中或撞空
→ 失控/转向恢复
```

参数建议：

- 锁定后转向保留 0%～25%。
- 预警 0.9～1.6 秒。
- 撞空硬直 1.2～3 秒。
- 同一次碰撞只结算一次伤害。
- `OnCollisionStay` 不重复造成冲撞伤害。
- 速度差低于阈值时只造成挤压和小伤害。

表现：

- 舰首发红、喷水向两侧分开。
- 冲锋走廊内出现方向箭头。
- 命中播放 F3；大型 Boss 只局部受力，不整体果冻缩放。
- 撞空撞到礁石或大型敌舰时产生自伤和失衡。

## 10. 普通投射物

类型：

- 轻型机炮：短曳光，持续压迫。
- 普通炮弹：可预测提前量。
- 抛物榴弹：落点圆预警。
- 重炮：长前摇、高弹速、模块破坏。

规则：

- 弹体速度和预警必须匹配。
- 轻武器靠枪口方向和曳光告知，不铺满红线。
- 重炮发射前炮口和目标线必须明显。
- 同类弹体在 0.08 秒内命中时合并低频和伤害数字。

## 11. 鱼雷类

鱼雷主要考验航向，而不是瞬间反应。

标准规则：

- 入水时有明显水花。
- 水下尾迹持续可见。
- 直线鱼雷预警 0.7～1 秒。
- 追踪鱼雷锁定线必须显示转向能力。
- 鱼雷转弯半径不能小于玩家主舰急转半径的 45%。
- 可被爆炸、拦截武器、诱饵或礁石处理。

鱼雷变体：

| 变体 | 玩法 |
| --- | --- |
| 直线重雷 | 伤害高，转向为零 |
| 扇形鱼雷 | 强迫选择缝隙 |
| 追踪鱼雷 | 需要急转、诱饵或拦截 |
| 延迟上浮雷 | 先潜航，再从预测点上浮 |
| 磁吸鱼雷 | 靠近金属舰体后微调 |
| 链式鱼雷 | 首枚命中后在后方产生小爆炸 |

## 12. 水雷与放置炸弹

规则：

- 水雷必须有实体，不用纯地面贴花代替。
- 进入触发半径后闪烁频率提高。
- 可以被攻击、撞击前锥、爆炸或特定清理技能摧毁。
- 被摧毁时可伤害附近敌军。
- 布雷母舰死亡后，普通水雷 3～8 秒内失效。
- Boss 特殊雷按阶段规则处理。

阵型：

- 航迹线。
- 半圆封锁。
- 棋盘错位。
- 中间安全通道。
- 旋转雷环。
- 延迟闭合雷笼。

## 13. 导弹与饱和轰炸

导弹必须表现出“锁定—升空—飞行—落点—爆炸”的完整因果。

标准导弹：

1. 舰上舱盖打开，0.3 秒。
2. 目标附近出现锁定刻度，0.5～1 秒。
3. 导弹垂直升空，保留烟迹。
4. 落点根据导弹类型固定或有限修正。
5. 最后 0.5 秒落点快速收缩。
6. 爆炸产生水柱、冲击环和短暂焦烟。

导弹雨规则：

- 单个圆不能覆盖玩家完整转向空间。
- 多个落点要形成“移动路线”，不是随机铺满。
- 第一轮教学显示清晰安全区。
- 后续轮次可以移动、交错或追踪，但安全区仍可推导。
- Boss 必杀期间暂停其他大型封路技能。

## 14. 持续区域

包括：

- 油火。
- 污染。
- 雷场。
- 冰雾。
- 漩涡。
- 渔网。
- 烟雾。

每个持续区域必须显示：

- 边界。
- 剩余时间或衰减状态。
- 进入后的主要结果。
- 是否可清除。
- 叠加上限。

持续伤害不每 Tick 强闪白；用附着特效、血条脉冲和合并数字表现。

## 15. 鱼叉、绳索与牵引

标准流程：

```text
发射点瞄准
→ 绳索路径预警
→ 鱼叉命中
→ 绳索建立
→ 牵引或限制转向
→ 玩家切断/撞断/离开极限距离
```

公平规则：

- 同一玩家最多被 2 条普通绳索同时生效。
- Boss 强绳索占用 2 个槽。
- 绳索必须有独立生命或张力值。
- 绳索穿过礁石、冰墙或大型舰体时可断裂。
- 玩家仍保留最低 35% 转向与推进能力。

## 16. 触手刺击

章鱼类触手必须由水面和身体动作共同告知：

1. 水下阴影移动到目标点。
2. 水面出现气泡和旋涡。
3. 触手尖端短暂露出或水面隆起。
4. 刺击点圆圈收缩。
5. 触手穿出水面。
6. 命中后抓取、拍击或短暂停留。
7. 拔出时留下可穿越水花，不形成隐形碰撞。

规则：

- 普通刺击预警 0.9～1.3 秒。
- Boss 重刺 1.5～2.2 秒。
- 触手停留期间可受伤。
- 刺空后根部暴露 1～2 秒。
- 触手命中其他敌人可造成误伤。

## 17. 鲸类攻击

鲸类不使用“炮塔转向”语言，依靠身体姿态：

| 动作 | 告知 |
| --- | --- |
| 冲撞 | 头部下压、背鳍对正、尾部加速摆动 |
| 尾拍 | 身体横摆、尾鳍抬出水面 |
| 浮出 | 海面长阴影、气泡带、低频鲸鸣 |
| 喷潮 | 气孔吸气、背部拱起、喷口方向水雾 |
| 声波 | 胸腔发光或水面同心波 |
| 吞噬 | 张口、前方水流向内、漂浮物被吸引 |

鲸鱼冲撞应有巨大惯性：

- 转向慢。
- 撞空后穿行较远。
- 可撞毁小舟、水雷、冰障和部分场景物。
- 玩家从侧面擦过只受轻推，不等同正面命中。

## 18. 召唤类

召唤必须有生产源：

- 信号旗。
- 造船舱。
- 飞行甲板。
- 海怪卵囊。
- 声呐呼唤。
- 残骸复苏。

召唤源可被打断或破坏。

同屏召唤上限：

- 小舟 18。
- 无人机 12。
- 鲨鱼/幼兽 12。
- 寄生蟹 10。
- Boss 特殊触手 8。

超过上限后，召唤技能改为：

- 强化现有单位。
- 补充生命。
- 释放一次性弹幕。
- 延后执行。

# 第十部分：精英敌人

## 25. 精英生成原则

精英不是随机叠满词缀。

组成方式：

```text
基础敌人
+ 1 个机制变体
+ 0～1 个温和数值词缀
+ 专属外观部件
+ 更高奖励
```

普通自由海域：

- 最多 1 个机制变体。
- 最多 1 个数值词缀。

固定挑战 IV～VI：

- 可有 1 个机制变体＋1 个主题强化。
- 不允许两个机制变体互相形成无解组合。

# 第十一部分：Boss 通用框架

## 28. Boss 战斗结构

标准 Boss 战由以下部分组成：

```text
发现/登场
→ 机制教学阶段
→ 第一次部位破坏或生命阈值
→ 机制组合阶段
→ 失衡窗口
→ 最终阶段
→ 狂暴或击败
→ 死亡/净化/撤退结算
```

建议时长：

| 类型 | 目标时长 |
| --- | ---: |
| 肉鸽 2 分钟阶段 Boss | 45～90 秒 |
| 板块控制核心 | 2～4 分钟 |
| 固定挑战 I～III | 3～6 分钟 |
| 固定挑战 IV～V | 5～9 分钟 |
| 世界巨兽 | 6～12 分钟 |
| 终局多舰 Boss | 8～15 分钟 |

时间不是靠单纯增加生命实现。高难延长主要来自：

- 新阶段。
- 部位处理。
- 机制组合。
- 支援舰调度。
- 多舰分工。

## 28.1 Boss 技能槽

每只 Boss 具有：

| 槽位 | 数量 | 说明 |
| --- | ---: | --- |
| 基础压迫 | 1～2 | 轻炮、扑咬、小范围声波 |
| 驾驶重击 | 1～2 | 冲撞、尾拍、鱼雷、刺击 |
| 场地机制 | 1 | 雷区、油海、冰墙、漩涡 |
| 召唤/支援 | 0～1 | 小舟、幼兽、无人机、触手 |
| 阶段核心 | 1 | 导弹雨、吞噬、风暴、触手牢笼 |
| 狂暴变化 | 1 | 加快循环或改变安全区，不直接秒杀 |

## 28.2 阶段切换

阶段切换可由以下条件触发：

- Boss 生命达到 70%/40%。
- 关键部位被破坏。
- 场地目标完成。
- 净化值、节奏值或护航值达到阶段目标。

阶段切换保护：

- 最长无敌 0.3 秒，只用于状态切换。
- 玩家在切换瞬间造成的伤害记入延迟结算，不能吞伤害。
- 已经生成的玩家投射物继续存在。
- Boss 阶段演出期间，场上残留 W3 以上敌方弹体失效或降级。
- 不在玩家危险航线中突然生成碰撞体。

## 28.3 失衡

Boss 进入失衡的主要方式：

- 撞空后撞击场景或友军。
- 阶段技能被正确反制。
- 同一部位在短时间受到足够伤害。
- 多个关键模块被连续破坏。
- 机制目标完成。

失衡表现：

- Boss 血条下方显示“失衡”图标和倒计时。
- 动力、肢体或武器明显停摆。
- 暴露弱点使用白金色破裂轮廓，不与普通敌方红色混淆。
- 音乐降低鼓点或产生短暂抽空。
- 玩家英雄可说一句“就是现在”类提示，但同阶段只说一次。

## 28.4 狂暴

狂暴不是所有数值同时提高。

一级狂暴：

- 超过目标时长 25%。
- 基础攻击间隔缩短 10%～15%。
- 召唤批次略增。
- W4/W5 预警不缩短。

二级狂暴：

- 超过目标时长 60%。
- Boss 伤害提高 15%～20%。
- 场地安全区变少，但仍存在。
- 不无限提高移动速度。

## 28.5 可破坏部位

部位规则：

- 部位有独立生命和受击反馈。
- 主体伤害分摊比例按部位配置，通常 20%～70%。
- 部位破坏会永久关闭或削弱技能。
- 部位破坏产生 F4 反馈，但镜头不超过 0.6 秒。
- 所有部位不要求全部破坏才能击败，除非是明确机制 Boss。

部位图标状态：

```text
正常
→ 受损
→ 过热/可打断
→ 摧毁
→ 对应技能图标划除
```

# 第十二部分：肉鸽与早期 Boss

## 29. B01 冲角海盗王

### 定位

首个大型驾驶教学 Boss。用明显的冲锋走廊教会玩家横向躲避、引导撞击和绕后攻击推进器。

### 部位

- 舰首冲角：破坏后冲撞伤害 -35%，正面装甲降低。
- 左推进器。
- 右推进器。

### 阶段一：单次重撞（100%～70%）

| 技能 | 逻辑 | 表现 | 反制 |
| --- | --- | --- | --- |
| 铁王冲锋 | 1.3 秒预警后直线冲锋 | 舰首压低、双侧白浪、宽走廊 | 横向躲开，引向礁石 |
| 冲角震波 | 近距离扇形水浪 | 舰首砸水，扇形红边 | 贴船侧或拉开 |
| 小舟护卫 | 召唤 4 艘冲撞舟 | 升旗、号角、侧舱放艇 | 吞噬小舟补充收益 |

撞礁或撞到大型友军后：

- 自伤最大生命 4%。
- 推进器暴露 3 秒。
- 进入失衡 2.5 秒。

### 阶段二：三段追撞（70%～35%）

- 连续锁定三条冲锋走廊。
- 第一、二段只小幅修正方向。
- 第三段伤害最高，但预警延长到 1.6 秒。
- 玩家可以让第二段撞毁召唤的小舟，让第三段撞向 Boss 自己留下的残骸。

### 阶段三：破釜冲锋（35%～0%）

- 舰首冲角发红。
- 船尾周期喷出火焰，形成短航迹。
- 两个推进器都被破坏时，不进入高速冲锋，改为短距离震波。
- 不提高转向能力，仍允许稳定躲避。

## 30. B02 白脊老鲸

### 定位

早期海兽 Boss。教会玩家观察身体姿态、水下阴影和侧腹弱点。

### 部位

- 左侧附着鱼叉。
- 右侧附着鱼叉。
- 白脊硬甲。

### 技能

| 技能 | 预警 | 判定 | 反制 |
| --- | --- | --- | --- |
| 巨尾横拍 | 尾鳍抬起 1.2 秒 | 后方 150° 扇形 | 靠近侧腹或驶向头部 |
| 深潜浮出 | 长阴影移动 2 秒 | 大圆浮出击退 | 离开圆心；边缘只受轻推 |
| 鲸鸣呼群 | 低频鲸鸣 1.8 秒 | 召唤 6 条鲨鱼 | 吞噬鲨鱼；打断鲸鸣可减半 |
| 白脊冲浪 | 正前方宽走廊 | 直线冲撞＋浪墙 | 横向绕开；引向鱼叉残骸 |

### 阶段变化

- 70%：第一次深潜，展示浮出机制。
- 45%：鲨鱼群会从玩家两翼出现，但冲锋分批进行。
- 20%：白脊甲裂开，受到伤害提高，冲撞频率增加。

### 净化选择

若该战斗属于鲸歌生态事件：

- 击毁两侧旧鱼叉后出现“安抚”进度。
- 使用声呐、护盾和非致命机制可完成净化。
- 净化不改变基础操作难度，只改变结算与装备来源。

## 31. B03 火药驳船

### 核心考题

利用敌方炸弹制造连锁反伤和安全航道。

### 部位

- 左火药仓。
- 右火药仓。
- 中央引爆台。

### 技能循环

1. 半环布置 8 枚水雷。
2. 侧舷轻炮逼迫玩家移动。
3. 中央引爆台选择其中 3 枚进入红色倒计时。
4. 玩家可以提前击破未点燃水雷制造连锁。
5. 引爆台蓄力时被重击会取消本轮远程引爆。

### 阶段二：移动雷阵

- 50% 生命开始。
- 雷阵由固定半环变为缓慢旋转。
- 安全缺口宽度不低于玩家舰宽的 2.2 倍。
- 火药仓爆炸会清空对应半场水雷并对 Boss 造成 8% 最大生命伤害。

### 核心考题

通过纵向躲避侧撞，并管理幼鲨群。

### 技能

- 大范围侧撞：身体横转 1.4 秒后宽面冲撞。

- 拍水震群：小范围击退，令幼鲨进入冲锋准备。

### 弱点

- 正面宽头减伤 55%。
- 鳃部与尾根为弱点。
- 侧撞失败后头部插入礁石，失衡 3 秒。

# 第十三部分：导弹、雷电与航母 Boss

## 33. B05 导弹审判舰

### 33.1 设计目标

这是“Boss 大量导弹轰炸”的主标杆。

玩家感受到：

- 天空与海面同时形成压力。
- 落点不是随机噪声，而是一道可读的移动题。
- 摧毁导弹舱会真实减少后续弹幕。
- 贴近 Boss 有收益，但仍需处理近防炮和舰体转向。

### 33.2 模型与部位

| 部位 | 数量 | 作用 | 破坏结果 |
| --- | ---: | --- | --- |
| 左垂发舱 | 1 | 左侧导弹批次 | 每轮导弹数量 -25% |
| 右垂发舱 | 1 | 右侧导弹批次 | 每轮导弹数量 -25% |
| 审判雷达 | 1 | 追踪和预测修正 | 追踪落点改为固定落点 |
| 舰首近防炮 | 2 | 防止无脑贴身 | 贴身压力下降 |

### 33.3 导弹通用表现

发射时间线：

| 时间 | 表现 |
| ---: | --- |
| 0.00 秒 | Boss 警报灯亮，技能名“裁决准备”出现 |
| 0.20 秒 | 垂发舱盖逐排打开 |
| 0.45 秒 | 海面出现第一批预测落点 |
| 0.65 秒 | 导弹依次垂直升空，烟柱不超过视野高度 |
| 1.20 秒 | 第二批落点出现，形成可推导安全路线 |
| 1.80 秒 | 第一批导弹落下 |
| 2.30 秒 | 第二批导弹落下 |
| 2.80 秒 | 烟雾衰减，航道重新清晰 |

音频：

- 舱盖：连续金属锁扣。
- 升空：分批低频喷射，不为每枚导弹播放完整峰值。
- 下落：屏幕内最近的 3 枚保留尖啸。
- 命中：0.1 秒内多个爆炸合并低频。

### 33.4 阶段一：列阵审判（100%～70%）

#### 技能 A：纵列轰炸

- 沿玩家当前航向生成 5 个依次爆炸圆。
- 圆间距允许玩家减速或横移。
- 教学目标：不能继续直线航行。

#### 技能 B：横列封锁

- 在玩家前方生成横向 4 个落点。
- 其中一个落点延迟更长，形成安全缺口。
- 缺口用浅色倒计时与水面箭头强调。

#### 技能 C：近防扇扫

- 玩家进入 6 米内时触发。
- 近防炮从船头向两侧扫射。
- 玩家贴近船尾仍是安全区。

阶段循环：

```text
纵列轰炸
→ 4 秒普通移动与近防
→ 横列封锁
→ 5 秒部位输出窗口
```

### 33.5 阶段二：移动裁决（70%～35%）

#### 技能 A：追航导弹

- 3 个落点以每秒 2.5 米速度追随玩家 1.2 秒。
- 随后锁定并停止移动。
- 玩家需要在锁定前引向无人的旧航线，再急转离开。
- 雷达被破坏后不再追踪，直接显示固定落点。

#### 技能 B：十字裁决

- 以玩家预测点为中心生成十字形 5 个落点。
- 四个外圈先爆，中心后爆。
- 玩家可驶入中心短暂等待，再穿过外圈已爆区域离开。

#### 技能 C：导弹舱过载

- 某导弹舱连续发射后进入白热状态 2.5 秒。
- 该部位受到伤害提高 80%。
- 击破时引发爆舱，对 Boss 主体造成 5% 最大生命伤害。

### 33.6 阶段三：饱和轰炸（35%～0%）

#### 必杀：十二枚海上判决

不是 12 个随机圆同时出现，分为三拍：

```text
第一拍：4 个固定外圈落点，逼玩家进入中区
第二拍：4 个追踪落点，逼玩家带离中区
第三拍：4 个交错落点，要求穿过第一拍已爆安全区
```

时间：

- 总预警 4.2 秒。
- 每拍相隔 0.8 秒。
- W5 期间其他大型敌人停止重击。
- 任一导弹舱被破坏，每拍减少 1 枚。
- 两舱全破后改为“六枚残缺判决”。

最终阶段不会：

- 提高落点追踪速度。
- 删除安全区。
- 在爆炸烟雾未散时生成下一轮完整弹幕。

### 33.7 自动难度适配

不是按玩家战力作弊缩放。只按所选难度配置：

| 难度 | 变化 |
| --- | --- |
| I | 只使用纵列、横列；落点顺序编号 |
| II | 加入十字裁决 |
| III | 加入追航导弹；可破坏雷达 |
| IV | 饱和轰炸三拍；小艇轻压迫 |
| V | 一侧导弹舱带护盾，需要先破供能器 |
| VI | 每周在“移动安全区/延迟假弹/双舰分工”中选择一个赛季变体 |

## 38. B09 铁港总督舰

### 场地

- 四座固定岸炮位于软战区边缘。
- Boss 绕中央炮港航行。
- 岸炮不可直接永久占领，但可被瘫痪。

### 核心机制：借炮拆炮

Boss 的总督重炮会锁定玩家并产生长直线。

玩家将直线引向岸炮：

- 重炮命中岸炮可造成 35% 部位伤害。
- 三次命中可瘫痪一座岸炮。
- 直接攻击岸炮也有效，但效率较低。

阶段：

- I：两座岸炮工作。
- II：四座岸炮交错，但同一时刻最多两座开火。
- III：Boss 移动炮港展开侧舷。
- IV 以上：岸炮被瘫痪后会留下可阻挡一轮炮击的残骸。

## 39. B10 活体雷塔舰

### 核心机制

Boss 通过海面导电节点把雷击传到玩家。

节点来源：

- 电鳗。
- 磁雷。
- 雷电小艇。
- 三座接地锚。

技能：

- 三角落雷：三个节点形成三角危险区。
- 雷塔扫链：电弧按距离由近到远跳跃。
- 接地反转：把原安全接地锚变成爆发点。
- 风暴过载：三座雷塔同时蓄能，必须破坏任一供能链。

反制：

- 击毁/吞噬中间节点。
- 把水雷引爆清除电链。
- 切断接地锚后，对应雷塔进入 3 秒过热。

## 40. B11 无声守钟者

### 核心机制：四拍

Boss 的攻击以四拍循环：

1. 外扩声波。
2. 内收声波。
3. 左右交错声波。
4. 守钟者主体重击。

玩家可以：

- 观察水面环形纹。
- 在第四拍前攻击正确钟塔。
- 成功打断第四拍，使 Boss 失衡 4 秒。

难度变化：

| 难度 | 变化 |
| --- | --- |
| I | 钟塔按 1、2、3 明确亮起 |
| II | 移除数字，保留音高和方向 |
| III | 加入一个静默区，但水面纹仍可见 |
| IV | 第二轮开始顺序反转 |
| V | 两艘主舰分别负责不同半场钟塔 |
| VI | 周变体调整节奏，不减少关键反应时间 |

## 41. B12 狂潮鲸卫

### 41.1 设计目标

鲸鱼 Boss 不应只是巨型冲撞怪。狂潮鲸卫同时包含：

- 巨大惯性的横向冲撞。
- 尾拍形成的水墙。
- 呼吸喷潮。
- 身上旧鱼叉导致的狂暴。
- “击杀”与“净化”两种结算路线。

### 41.2 部位

| 部位 | 数量 | 效果 |
| --- | ---: | --- |
| 狂暴鱼叉 | 4 | 每支提高一个技能的攻击性 |
| 左胸鳍伤口 | 1 | 净化进度点 |
| 右胸鳍伤口 | 1 | 净化进度点 |
| 背部旧网 | 1 | 降低鲸鱼转向，拆除后行为改变 |

拆除鱼叉不直接造成大量主体伤害，避免“救援动作反而杀死鲸鱼”。

### 41.3 阶段一：驱离（100%～75%）

技能：

- 胸鳍推浪：左右交替扇形水浪。
- 喷潮扫线：从头部向外横扫，贴近侧腹是安全区。
- 护幼冲撞：当幼鲸受威胁时，从场外进入宽走廊冲撞。

教学：

- 攻击鱼叉而非鲸鱼头部。
- 幼鲸为中立单位，不应被自动锁定。
- 玩家武器自动索敌对幼鲸默认禁用。

### 41.4 阶段二：狂潮（75%～40%）

#### 技能：跨场鲸撞

时间线：

| 时间 | 表现 |
| ---: | --- |
| 0.0 | 鲸卫深吸气并潜下一半 |
| 0.5 | 长走廊从鲸头延伸到场地另一侧 |
| 1.1 | 尾鳍连续摆动，走廊锁定 |
| 1.6 | 鲸卫高速冲撞 |
| 2.4 | 撞到边缘后转为大范围水墙 |
| 3.2 | 鲸卫侧腹露出并喘息 |

反制：

- 在锁定前横向离开。
- 引导其撞断场地旧捕鲸桩。
- 捕鲸桩断裂会自动拉出一支狂暴鱼叉。

#### 技能：双层尾拍

- 第一层近距离实体尾鳍。
- 第二层较慢水墙。
- 玩家可以躲过尾鳍后穿过尾部内侧，或远距离穿越水墙缺口。

### 41.5 阶段三：选择（40%～0%或净化完成）

若鱼叉已拆除 3 支以上：

- 出现安抚声呐窗口。
- 玩家需在两次鲸鸣间保持不攻击头部。
- 完成两轮安抚后战斗以净化结束。

若继续伤害主体：

- 鲸卫进入绝境。
- 冲撞频率提高 15%。
- 不新增无法躲避技能。
- 击败后走普通猎杀结算。

### 41.6 表现

- 鲸鸣使用低频，但提供“低频强度”设置。
- 冲撞镜头先轻拉宽，再在命中时局部震动。
- 不在鲸鱼每次移动时持续震屏。
- 水墙以白色泡沫顶线明确速度和缺口。
- 净化成功后鲸鱼颜色恢复，旧伤口闭合，幼鲸靠近，不播放死亡爆炸。

## 42. B13 炼油督战舰

### 场地机制

- 三座输油塔通过可见管线向 Boss 供油。
- 输油时 Boss 获得火焰强化。
- 管线可被炮击、撞击或冰冷技能切断。

技能：

- 火海切割：沿两条平行航线喷油点燃。
- 过热炮舱：重炮连续发射后暴露。
- 油罐投掷：油罐落地不立即爆炸，可被双方攻击。
- 炼海炉爆燃：三座输油塔均在线时的阶段技能。

反制闭环：

```text
切断输油管
→ 输油塔泄漏形成可引爆油区
→ 引导 Boss 炮弹命中
→ 输油塔爆炸
→ Boss 过热并失衡
```

## 43. B14 冰脊破航兽

### 形象

大型海兽背部长有四根冰脊，可在海面升起冰墙。

技能：

- 双墙夹航：两条冰墙缓慢靠近，保留一个可撞碎薄点。
- 破冰冲锋：沿直线撞碎冰墙，碎片向两侧飞散。
- 寒雾吐息：扇形减速，不造成高爆发。
- 冰脊再生：未被破坏的冰脊缓慢修复一段冰墙。

反制：

- 引导 Boss 自己撞碎强化冰墙。
- 攻击背部冰脊减少墙数量。
- 火焰扩大薄点。
- 碎冰可形成短暂护甲资源或阻挡敌方轻弹。

## 44. B15 百舷墓舰

### 核心机制

由大量沉船拼成的幽灵巨舰，可短暂唤醒周围残骸的原武器。

阶段一：

- 复苏 3 个残骸炮台。
- 幽灵侧舷齐射。
- 墓钟声波。

阶段二：

- 三面灵帆展开。
- 每面灵帆对应一种残骸：炮击、鱼雷、冲撞。
- 破坏灵帆后对应残骸失去复苏能力。

阶段三：

- 百舷合唱：所有仍存在残骸按顺序攻击。
- 玩家可提前清残骸，或在墓钟蓄力时重击打断。
- 不允许已经清除的残骸凭空重生。

## 45. B16 赤潮母体舰

### 核心机制

Boss 不是传统机械舰，而是被赤潮母体寄生的培育舰。

场地：

- 三座净化井。
- 污染区随时间扩张。
- 玩家必须在输出和启动净化井之间切换。

部位：

- 培养囊×4：持续生成寄生物。
- 赤潮核心：阶段弱点。
- 输液触须×2：连接净化井，反向污染。

技能：

- 赤潮喷涌：扇形污染液。
- 寄生跳跃：附着舰体模块。
- 污染脉冲：按当前污染区数量增强。
- 母体转移：核心在剩余培养囊间移动。

胜利：

- 摧毁核心为击杀路线。
- 三座净化井全部完成并切断输液触须为净化路线。

## 46. B17 星落观测者

### 核心机制

Boss 会记录玩家最近 6 秒航迹，并预测下一段。

表现：

- 旧航迹显示为淡紫星线。
- 预测航迹显示为红紫虚线。
- 星磁导弹落在预测航线上。

反制：

- 改变节奏：减速、急转、短时倒车或切换主控舰。
- 离开预测航线会使 Boss 雷达失准。
- 破坏观测镜后，记录窗口从 6 秒降为 2 秒。

必杀“星落校准”：

- 三座观测镜同时对准。
- 场地出现三条预测线。
- 玩家必须在锁定前制造一次明显航向变化。
- 正确反制后，三枚星磁弹会命中观测镜支架，造成反伤。

## 47. B18 风暴王冠核心

### 多舰定位

面向 3～6 艘主舰的终局固定挑战。

场地分为四个王冠区：

- 北塔：导弹。
- 东塔：雷电。
- 南塔：冲击波。
- 西塔：召唤。

规则：

- 同一艘主舰 12 秒内只能有效关闭一座塔。
- 多舰需要分区处理。
- 单舰也可挑战 I～II，但高难要求至少双舰。

阶段核心“王冠闭合”：

1. 四塔依次亮起。
2. 每塔产生一个局部机制。
3. 在 8 秒窗口内至少关闭两塔。
4. 未关闭的塔组合成下一轮攻击。
5. 四塔全关时核心暴露 6 秒。

高难不通过把所有塔同时攻击玩家制造难度，而通过：

- 分舰路线。
- 关闭顺序。
- 不同阵容承担不同塔。

## 48. B19 深渊母猎舰

### 核心机制

半潜敌舰只在攻击前后暴露。声呐、浮标和水面观察是关键。

技能：

- 无声潜航：只留低对比尾迹。
- 三角伏击雷：从三个方向上浮。
- 猎手上浮炮：在玩家船尾预测点上浮重击。
- 压舱下潜：受到重击后紧急下潜。

反制：

- 声呐命中累计“暴露值”。
- 暴露值满时，压载舱失效并强制上浮 5 秒。
- 攻击声呐鳍降低隐蔽时长。
- 在浅水边缘逼迫其转向，可使上浮位置更容易预测。

# 第十五部分：世界巨兽

## 49. B20 铁背鲸王

### 定位

世界巨兽中的重甲与冲撞标杆，比深海装甲鲸体型更大，适合多舰分工。

部位：

- 头部铁背甲。
- 左右侧甲。
- 尾部锚链。
- 腹部软组织。

技能：

- 岛屿级冲撞：超长走廊，锁定后几乎不转向。
- 锚链尾拍：尾拍同时拖动残骸。
- 铁背震落：抖落装甲碎块，形成移动障碍。
- 深潜越舰：从舰队下方穿过并在远端浮出。

多舰玩法：

- 一舰负责诱导冲撞。
- 一舰攻击侧甲。
- 支援舰处理残骸和救援。

不要求固定职业，单舰可通过更长流程完成。

## 50. B21 深渊章皇

### 50.1 设计目标

这是“章鱼海怪刺击”的主标杆。

战斗重点：

- 读懂水下触手位置。
- 在多点刺击中寻找安全航线。
- 攻击刺空后停留的触手。
- 防止被抓取拖入章皇口器。
- 通过断肢改变 Boss 技能组合。

### 50.2 模型与部位

| 部位 | 数量 | 作用 | 破坏结果 |
| --- | ---: | --- | --- |
| 长刺触手 | 2 | 远距离直刺 | 多点刺击数量减少 |
| 拍击触手 | 2 | 扇形横扫 | 近身安全区扩大 |
| 缠绕触手 | 2 | 抓取牵引 | 同时抓取上限减少 |
| 支撑触手 | 2 | 移动、稳定身体 | 转身和场地控制变慢 |
| 墨囊 | 1 | 墨雾与隐蔽 | 墨雾技能关闭 |
| 主眼 | 1 | 阶段弱点 | 只在失衡时开放 |

触手生命独立，但共享断肢保护：

- 10 秒内最多永久断 2 条。
- 超出的触手进入重伤而非立即断裂。
- 防止高爆发瞬间跳过全部机制。

### 50.3 阶段一：试探刺击（100%～75%）

#### 技能 A：单点深刺

时间线：

| 时间 | 表现 |
| ---: | --- |
| 0.0 | 一条长刺触手潜入水下 |
| 0.35 | 水下阴影朝玩家预测点移动 |
| 0.75 | 目标点出现气泡与小圆预警 |
| 1.15 | 圆圈锁定，触手尖端露出 |
| 1.45 | 触手向上刺出 |
| 1.65 | 刺空后停留 |
| 3.0 | 触手拔出并回收 |

反制：

- 最后 0.3 秒横移。
- 诱导触手刺中敌方召唤物或水雷。
- 刺空后攻击触手根部，伤害提高 60%。

#### 技能 B：双触手夹拍

- 左右两条拍击触手扬起。
- 两侧扇形向中央闭合。
- 中央不是安全区；安全区位于其中一条触手根部外侧。
- 其中一条拍击触手被破坏后，技能改为单侧拍击。

#### 技能 C：墨潮遮眼

- 墨囊鼓起 1 秒。
- 向一个扇区喷出半透明墨潮。
- 墨潮降低远程锁定，但水面预警仍保持高对比。
- 声呐可以清除局部墨潮。

### 50.4 阶段二：触手猎场（75%～40%）

#### 技能 A：四点连刺

四个刺击点不是同帧出现：

```text
第 1 点：玩家当前位置
第 2 点：玩家航向前方
第 3 点：玩家左侧预测
第 4 点：根据前三点留下的最大空区边缘
```

目的：

- 形成可读的“S”形安全航线。
- 玩家持续直行会被第二点命中。
- 原地绕小圈会被第三点封住。
- 正确做法是观察顺序后穿过已经刺击过的区域。

#### 技能 B：缠舰拖拽

1. 缠绕触手从水面横向伸出。
2. 命中后连接舰体。
3. 1 秒后开始向口器方向牵引。
4. 玩家可攻击触手、利用礁石拉断或反向加速积累张力。
5. 张力满时触手断开，章皇进入短硬直。

公平限制：

- 普通难度同时最多 1 条缠绕触手。
- 高难最多 2 条，但来自相反方向时不会同时满强度牵引。
- 被抓取期间玩家保留至少 40% 操控。
- 不能与四点连刺最终刺击同时命中。

#### 技能 C：触手牢笼

- 6 条触手在场地周围形成六边形，但这是战斗预警形状，不属于领土网格。
- 触手逐步向内拍击。
- 场内存在 2 个移动缺口。
- 击破任一触手可永久打开一侧出口。

### 50.5 阶段三：深渊怒目（40%～0%）

触发：

- 主眼睁开。
- 剩余触手根据类型重组攻击。
- 已断触手不会无条件再生。

#### 必杀：百腕穿海

实际最多显示 8 条主触手，远处触腕用水面阴影和简化模型表现。

三段：

1. 外圈 4 点刺击，逼玩家向内。
2. 内圈 3 点延迟刺击，逼玩家穿回外圈旧区域。
3. 主眼发出直线深渊凝视，要求用断裂触手残段或大型残骸遮挡。

总预警 4.8 秒。

成功反制：

- 凝视命中触手残段。
- 章皇主眼受反射冲击。
- 进入 5 秒完全失衡。

失败：

- 造成重伤和短减速。
- 不直接秒杀满血合理构筑玩家。

### 50.6 狂暴

- 触手攻击间隔缩短 12%。
- 墨潮范围扩大。
- W4/W5 刺击预警不缩短。
- 已断触手不会复生。

### 50.7 表现与性能

- 近景 8 条主触手使用完整骨骼和 IK。
- 远景触腕只用水面阴影、泡沫和简化网格。
- 触手刺击判定由预计算样条和攻击体完成，不逐骨骼生成碰撞。
- 同时存在的触手水花最多 6 个完整高质量特效。
- 墨潮不使用全屏黑色遮罩，保持玩家能看见危险边缘。
- 断肢使用封口材质、墨液和短暂缩回，不出现过度写实内容。

## 51. B22 裂海巨鳐

### 核心机制

巨鳐通过翼面制造移动漩涡和横跨场地的海沟波。

技能：

- 双翼裂海：左右翼依次拍水，生成两条移动浪墙。
- 漩涡迁徙：三个漩涡沿固定曲线移动。
- 潜底掠影：巨鳐潜到舰队下方，翼缘形成长条危险区。
- 海沟吸附：把水雷、残骸和小单位吸向中央，再一次性抛出。

部位：

- 左翼根。
- 右翼根。
- 尾刺。
- 腹部核心。

破翼根：

- 对应侧浪墙速度下降。
- 双翼裂海出现更大缺口。

玩家可利用漩涡：

- 聚集小敌人进行范围清场。
- 改变敌方鱼雷方向。
- 把爆破筏吸向 Boss。

# 第十六部分：终局 Boss

## 52. B23 吞海旗舰

### 定位

机械阵营最终考核，组合玩家已经学习过的冲撞、侧舷、导弹、鱼雷、布雷和吞噬。

### 模块

- 左右侧舷炮列。
- 左右导弹舱。
- 左右鱼雷舱。
- 舰首吞噬器。
- 舰尾动力核心。

### 阶段一：旗舰炮战（100%～70%）

- 侧舷齐射。
- 小舟护航。
- 舰首震波。
- 目标：破坏至少一侧炮列，创造贴近方向。

### 阶段二：海上封锁（70%～35%）

- 导弹与鱼雷交错，但由危险预算错开发放。
- 布雷只封锁玩家旧航线。
- 破坏一类模块会改变组合，不增加另一类伤害补偿。

示例：

```text
破坏左导弹舱
→ 左半场落点减少
→ Boss 更常尝试转舷
→ 不会把减少的导弹全部加到右舱
```

### 阶段三：吞海（35%～0%）

- 舰首开启巨型吞噬器。
- 前方形成向内水流。
- Boss 吞噬场上小单位恢复生命。
- 玩家可先吞噬小单位、切断供给。
- 将爆破筏或水雷引入吞噬器会造成内部爆炸。
- 吞噬器内部爆炸两次后永久卡死，暴露核心。

## 53. B24 深渊利维坦

### 定位

海兽阵营最终考核，不是站桩巨兽，而是围绕舰队穿行的超大型生物。

阶段一：

- 鲨群。
- 漩涡。
- 巨尾拍。
- 目标：观察身体段落和安全侧。

阶段二：

- 下潜穿行。
- 海啸。
- 吞噬小型单位。
- 身体三个部位轮流暴露。

阶段三：

- 连续追击但保持明显转向惯性。
- 背部、侧鳍、尾根依次成为弱点。
- 击破错误部位不会无效，但效率较低。

最终技能“深渊环游”：

1. 利维坦绕场一周，外圈形成浪墙。
2. 场内出现两条逆向水流。
3. 玩家选择一条水流保持航速。
4. 利维坦从另一条水流穿出。
5. 正确判断可从其侧腹通过并攻击最终弱点。

# 第十八部分：固定挑战难度 I～VI

## 67. 难度变化原则

难度提升顺序：

```text
机制教学
→ 两机制轮换
→ 两机制交错
→ 部位与编队配合
→ 多舰分工
→ 赛季规则变化
```

不使用：

- 预警全部减半。
- 小怪数量无限翻倍。
- Boss 全程免控。
- 玩家没有指定英雄就无法通关。
- 动态读取玩家战力并偷偷提高敌人。

## 68. 通用难度表

| 难度 | 生命倍率 | 伤害倍率 | 机制 | 预警 | 敌人组合 |
| --- | ---: | ---: | --- | --- | --- |
| I 侦察 | 0.75 | 0.7 | 单机制教学 | 完整辅助标识 | 少量单职能 |
| II 标准 | 1.0 | 1.0 | 标准阶段 | 标准 | 基础组合 |
| III 危险 | 1.35 | 1.2 | 增加一种机制交错 | 不缩短 W4/W5 | 加入精英 |
| IV 灾厄 | 1.75 | 1.45 | 部位与编队联动 | 减少部分数字提示 | 主题组合 |
| V 传说 | 2.2 | 1.7 | 多舰/多目标分工 | 保留形状和动作 | 精英机制变体 |
| VI 赛季 | 2.3～2.6 | 1.75～1.9 | 每周一个可预览变体 | 不低于最低公平线 | 受控轮换 |

生命倍率只作为基准，最终仍需按目标时长测试。

## 68.1 W4/W5 最低预警

不论难度：

- 大型冲撞不低于 0.9 秒。
- 导弹雨首批不低于 1.5 秒。
- 章鱼多点刺击单点不低于 0.8 秒。
- 鲸鱼浮出不低于 1.4 秒。
- Boss 必杀整体不低于 2.8 秒。

## 69. 赛季变体池

| 变体 | 内容 | 禁止组合 |
| --- | --- | --- |
| 逆流 | 场地有周期性水流 | 强牵引 Boss |
| 夜航 | 远景变暗，预警保持亮度 | 墨雾、强烟幕 |
| 残骸海 | 增加可利用残骸 | 百舷墓舰的残骸翻倍 |
| 雷暴 | 水面节点可导电 | 活体雷塔舰强化雷链 |
| 追猎 | 精英低血时尝试撤退再攻击 | 超时狂暴高移速 |
| 双核心 | 两个部位需短时间连续破坏 | 单舰强制同时到两处 |
| 生态保护 | 中立生物进入战区 | 大范围不可控自动锁定 |
| 弹药紧缺 | 主动技能资源恢复降低 | 纯数值 DPS 检查 |

玩家在进入前必须看到：

- 本周变体。
- 推荐反制。
- 不受影响的基础规则。
- 奖励变化。

# 第二十部分：AI 行为架构

## 78. 三层 AI

```text
EncounterDirector
├── 决定波次、编队、威胁预算与阶段
SquadCoordinator
├── 决定队形、攻击批次、目标分工与撤退
EnemyBrain
└── 执行移动、瞄准、技能状态机和局部避障
```

职责限制：

- `EncounterDirector` 不直接控制单艘炮塔。
- `EnemyBrain` 不独立决定是否释放 W4/W5。
- `SquadCoordinator` 不修改技能真实判定。

## 79. 目标选择

敌人目标评分：

```text
TargetScore =
威胁贡献 × 0.24
+ 距离适配 × 0.18
+ 当前射界 × 0.14
+ 目标脆弱度 × 0.12
+ 机制适配 × 0.12
+ 最近伤害来源 × 0.08
+ 编队分工 × 0.08
+ 路径可达 × 0.04
- 过度集火惩罚
- 屏幕外不可读惩罚
- 中立保护惩罚
```

规则：

- 普通敌人目标保持至少 1.2 秒。
- 重击在 Tell 后不频繁切换。
- 同一时刻锁定主控舰的 W3 以上敌人不超过 2 个。
- 支援舰优先保护当前编队核心，而非全图最低血。
- Boss 不因玩家刚释放位移就无延迟重新锁定落点。

## 80. 攻击效用评分

```text
AttackUtility =
距离匹配
+ 角度匹配
+ 玩家状态适配
+ 场地协同
+ 队友连携
+ 部位可用
+ 阶段权重
- 危险预算不足
- 重复职责惩罚
- 友军误伤风险
- 连续使用惩罚
```

连续使用惩罚：

- 同一技能连续两次后权重 -40%。
- Boss 核心技能可按固定阶段脚本例外。
- 不允许 AI 因某技能效用最高而无限重复。

## 81. 移动意图

敌人移动意图：

| 意图 | 单位 |
| --- | --- |
| 保持距离 | 火箭、导弹、维修 |
| 平行航行 | 侧舷、机炮 |
| 拉开再冲 | 冲角、鲸类 |
| 切入船尾 | 喷火、登船 |
| 绕到队友后方 | 支援舰 |
| 建立封锁线 | 布雷、冰墙 |
| 潜航伏击 | 鱼雷、深渊单位 |
| 护卫中立目标 | 鲸卫、生态单位 |

## 81.1 汽车式操控适配

敌舰不能像空中单位一样原地旋转：

- 使用最小转弯半径。
- 预测 1～3 秒未来位置。
- 船体朝向和速度方向逐渐一致。
- 冲锋锁定后降低转向。
- 大舰避免在狭窄区域强行原地转向。

海兽允许更灵活，但鲸类和大型鳐仍有明显惯性。

## 82. 编队攻击批次

示例：

```text
网与矛编队
0.0 秒：撒网舟申请控制槽
0.4 秒：渔网投放
1.1 秒：两艘冲撞舟申请重击槽
1.4 秒：第一艘锁定
2.0 秒：第二艘从相反侧锁定
3.2 秒：若玩家已被首次冲撞命中，取消第二艘最终冲锋
```

“取消第二次追击”用于防止控制链把玩家一次失误直接打到无法操作。

## 83. Boss 技能调度

Boss 选择下一个技能时考虑：

- 最近 10 秒已用技能。
- 玩家当前速度和转向状态。
- 可破坏部位。
- 当前安全区。
- 场上召唤物数量。
- 其他敌人的 W3/W4 技能。
- 阶段脚本。

Boss 技能队列最多提前排 2 个。

部位被破坏、玩家切换主控舰或场地变化时重新验证，不强行执行已经不合法的技能。

# 第二十一部分：伤害、控制与数值规则

## 84. 伤害组成

敌方重击伤害建议拆分：

| 部分 | 作用 |
| --- | --- |
| 基础伤害 | 主要生命损失 |
| 装甲伤害 | 对舰体护甲和模块 |
| 冲量 | 位移和转向影响 |
| 异常 | 燃烧、冰冷、污染、导电 |
| 模块压力 | 暂时降低某挂点效率 |

不要每个重击同时包含全部五项。

## 85. 单次伤害上限

普通难度合理构筑下：

- W0：最大生命 0.5%～2%。
- W1：2%～5%。
- W2：5%～10%。
- W3：10%～18%。
- W4：15%～25%。
- W5：20%～35%，通常可通过机制显著降低。

高难允许上浮，但：

- 满血玩家不应被单个普通 W3 秒杀。
- W5 必杀失败可以重伤，但需明确且可防。
- 多段攻击要设置同技能命中保护，避免体型大而吃满全部段数。

## 86. 连续控制保护

玩家受到强控制后获得：

| 状态 | 时间 | 效果 |
| --- | ---: | --- |
| 转向控制保护 | 1.2 秒 | 后续转向降低效果减半 |
| 击退保护 | 0.8 秒 | 后续击退距离 -50% |
| 牵引槽保护 | 绳索断后 1 秒 | 新普通鱼叉不能立即生效 |
| 眩晕保护 | 眩晕结束后 1.5 秒 | 普通眩晕转为减速 |

Boss 明确连段可以覆盖部分保护，但必须在技能说明和预警中体现。

## 87. 部位伤害

建议：

- 精准单体技能：部位伤害系数 1.2。
- 范围爆炸：0.7。
- 高频机炮：0.45。
- 冲撞：按接触点 0.8～1.4。
- DOT：0.25，避免火海自动拆完全部模块。

# 第二十二部分：UI 与战斗信息

## 88. 普通敌人信息

小型单位：

- 不常驻显示名称。
- 受伤后显示细血条。
- 特殊职责用小图标：维修、召唤、控制、爆破。

中型单位：

- 标准血条。
- 1 个职责图标。
- 精英显示 1 个机制图标和最多 1 个数值词缀。

大型单位：

- 名称。
- 主体血条。
- 模块小条。
- 当前准备技能图标。

## 89. Boss HUD

层级：

```text
BossHUD
├── BossNameAndPortrait
├── MainHealthBar
│   ├── PhaseMarkers
│   ├── DamageDelayFill
│   └── BreakGauge
├── ModuleRow
├── CurrentMechanic
├── EnrageTimer
└── CounterHint
```

规则：

- Boss 生命条不因普通小伤害持续抖动。
- 模块破坏时对应图标裂开并划除技能。
- 首次看到某机制时显示一句短提示。
- 同一提示失败两次后才提供更明确反制，不首次就直接解题。
- 高难可关闭文字提示，但保留形状、动作和图标。

## 90. 锁定与预警层级

优先级：

```text
Boss 必杀
> 即将命中的 W4
> 玩家主舰致命危险
> 强控制
> W3 重击
> 普通导弹/鱼雷
> 小型投射物
```

同一位置多个圆重叠时：

- 合并透明填充。
- 保留各自倒计时边界。
- 最先爆炸的边界最亮。
- 不把重叠区域变成完全不透明红块。

## 91. 技能失败解释

玩家死亡或重伤后可在战斗复盘显示：

```text
主要伤害：十二枚海上判决
命中：4 枚
可反制：
1. 第一拍后穿入已爆区域
2. 优先破坏任一导弹舱
3. 追踪落点锁定后再急转
```

不在实时战斗中弹出大段教程。

# 第二十三部分：视觉、音效、镜头与水面表现

## 92. 反馈等级

沿用现有 F0～F5：

| 等级 | 敌方示例 | 表现 |
| --- | --- | --- |
| F0 | DOT、持续机炮 | 小火花、无镜头 |
| F1 | 轻炮、普通扑咬 | 局部闪白、轻碎片 |
| F2 | 鱼叉、榴弹、触手轻刺 | 明显受力、局部水花 |
| F3 | 鱼雷、重撞、鲸尾 | 位移、冲击波、短 Hit Stop |
| F4 | 部位破坏、Boss 失衡 | 模块爆裂、音乐侧链、短镜头 |
| F5 | Boss 终结/净化 | 专属阶段演出 |

## 93. 敌人准备动作

每个 W2 以上攻击至少包含三项：

- 模型动作。
- 水面变化。
- 音效。
- UI 预警。
- 挂点灯光。

至少三项，不允许只画红圈。

示例：

| 攻击 | 模型 | 水面 | 音频 |
| --- | --- | --- | --- |
| 冲角 | 舰首压低、推进器升温 | 两侧白浪 | 发动机升调 |
| 鱼雷 | 舱盖打开 | 入水花、尾迹 | 闷响＋水下推进 |
| 导弹 | 垂发盖依次打开 | 落点收缩 | 警报＋升空喷射 |
| 触手 | 肢体潜下 | 气泡、阴影 | 水下低鸣 |
| 鲸尾 | 身体横摆 | 扇形浪纹 | 鲸鸣＋破水 |

## 94. 命中表现

### 94.1 撞击

- 方向性压缩只作用 `VisualRoot`。
- 玩家舰体向受力方向倾斜。
- 金属、木船、生物使用不同材质碎片和音色。
- 低速顶住只产生摩擦水花，不重复结算完整撞击。

### 94.2 导弹

- 入水爆炸产生竖向水柱。
- 近船爆炸增加水滴和船体遮挡，但不长时间盖屏。
- 多枚同帧爆炸合并低频，保留最近 3 个主体爆炸。

### 94.3 触手

- 刺中水面产生窄高水柱。
- 刺中舰体产生湿润撞击、局部墨液和船体倾斜。
- 触手不让整艘主舰出现夸张果冻变形。

### 94.4 鲸鱼

- 正面重撞用宽水幕和低频冲击。
- 擦碰只用船侧浪和轻推。
- 浮出时先分开水面，再出现身体，不能突然穿模。

## 95. 镜头规则

- 普通敌人攻击不夺镜头。
- W3 命中使用方向性冲击，不自动旋转镜头。
- W4 预警时允许轻微拉宽 2°～4°。
- Boss 必杀开始可拉高，持续不超过 0.8 秒。
- 玩家仍然控制主舰。
- 0.6 秒内只允许一个 F4 以上事件拥有主镜头权。
- 关闭镜头震动时仍保留构图、模型和 UI 反馈。

## 96. 音频优先级

```text
Boss 必杀提示
> 屏幕外 W4
> 玩家濒死
> 强控制建立
> 玩家手动主动技能
> 敌方 W3
> 普通炮火
> 环境和生产
```

同屏规则：

- 完整警报最多 1 个。
- 次级重击只保留方向音和短提示。
- 导弹、爆炸和雷声使用音频并发组。
- 章鱼、鲸鱼等大型生物拥有独立低频组，避免与爆炸叠加失真。

## 97. Boss 死亡与净化

舰船 Boss：

1. 最终命中。
2. 武器模块依次失效。
3. 船体多点爆炸。
4. 倾斜沉没。
5. 核心或装备箱浮出。

海兽 Boss：

- 击杀：身体失去力量、缓慢下沉或离开，不使用机械爆炸。
- 净化：污染/鱼叉脱落、颜色恢复、动作平缓、离开战区。
- 撤退：世界巨兽未被击杀时带伤潜走，保留下次追踪状态。

演出期间：

- 停止新敌人生成。
- 残余 W3 以上投射物失效。
- 玩家不会在结算镜头中被水雷击杀。

## 108. 攻击许可伪代码

```csharp
bool TryGrantAttack(AttackRequest request)
{
    if (!HasDangerBudget(request.DangerCost))
        return false;

    if (!RoleSlotAvailable(request.RoleSlot))
        return false;

    if (ConflictsWithActiveMechanic(request))
        return false;

    if (!IsReadableForTarget(request))
        return false;

    ReserveBudget(request);
    ReserveRoleSlot(request);
    return true;
}
```

## 109. 多舰危险预算

多舰时不使用一个全图预算简单相加。

```text
GlobalBossBudget
+ 每艘主舰 LocalBudget
+ SharedMechanicSlot
```

- Boss 必杀占用 `SharedMechanicSlot`。
- 针对单舰的普通攻击消耗该舰 `LocalBudget`。
- 同一技能不能同时完整复制到 6 艘舰上。
- 多目标技能要明确每舰的局部版本。

# 结论

新版敌人体系的核心不是“更多血量更高的怪”，而是：

```text
小型单位提供吞噬、资源与方向压力
中型单位提供单一战术职责
大型单位提供模块与航线考题
精英改变一条熟悉规则
Boss 通过阶段、部位和场地组合考核
```

导弹、鲸鱼和章鱼分别承担三种最重要的驾驶挑战：

- 导弹：阅读连续落点，规划未来航线。
- 鲸鱼：理解巨大惯性，利用场景引导冲撞。
- 章鱼：观察水下预警，在多点刺击间穿行并切断控制。

所有高强度技能都必须让玩家经历：

```text
看见原因
→ 理解范围
→ 做出选择
→ 承担结果
→ 获得反击窗口
```

只要这条链条始终成立，敌人的数量增加才会真正转化为新的玩法体验，而不是更混乱的画面和更高的数值压力。
