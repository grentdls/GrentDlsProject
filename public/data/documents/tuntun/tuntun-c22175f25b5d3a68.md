# 《吞吞舰船》英雄船舰搭配、角色与装备界面视觉布局及交互动效改造文档

> 文档定位：在既有“1个船长位＋4个作战位、最多6艘主舰、英雄升级/技能/天赋/装备”规则上，重做英雄与舰船养成界面的视觉层级、布局、图标系统、交互流程和点击动效。  
> 适用版本：海盗生涯·英雄船舰系统 UI 改造版。  
> 参考基准：1920×1080 横屏；同时兼容16:10与21:9。  
> 核心目标：界面首先像一个有角色、有舰船、有收藏价值的正式游戏界面，其次才是数据管理后台。

---

## 1. 当前问题

当前英雄相关界面“不美观”的根本原因，不只是缺少美术图，而是信息组织方式存在以下问题：

1. 英雄、技能、装备、货币大多以文字或普通按钮表达，缺少可快速识别的图形锚点。
2. 英雄没有成为页面视觉中心，看起来更像一张属性表。
3. 舰船、英雄、装备、技能同时争抢画面，没有明确主次。
4. 船长位和作战位视觉差别不够强，容易误解技能生效规则。
5. 资源数字散落在不同位置，玩家不知道升级到底缺什么。
6. 装备更换只显示战力变化，无法看懂英雄、技能、舰船分别发生了什么变化。
7. 点击、拖拽、升级、装备成功后的反馈太弱，操作没有“装上去了”的满足感。
8. 页面边框、列表、按钮数量过多，产生明显的后台管理界面感。
9. 即使后续替换正式立绘或模型，如果布局不变，仍然会显得拥挤。

本次改造不只替换资源图标，而是重新划分整个英雄舰队养成系统的页面职责和视觉重心。

## 2. 必须保留的系统规则

### 2.1 主舰岗位

每艘主舰固定拥有：

- 1个船长位。
- 4个作战位。

禁止重新使用“4个技能槽”“4个攻击槽”“船员槽”等旧称。

### 2.2 船长位

船长位英雄：

- 提供英雄属性换算。
- 最多3个被动技能生效。
- 普攻不生效。
- 主动技能不生效。
- 不显示Q/E/R/F技能按键。

### 2.3 作战位

每个作战位英雄：

- 提供英雄属性换算。
- 提供自身普攻。
- 装配1个主动技能。
- 最多装配3个被动技能。
- 分别对应Q、E、R、F。

### 2.4 多主舰

- 初始拥有1艘主舰。
- 每占领1块新海域，解锁1个主舰席位。
- 占领5块新海域后达到6艘主舰上限。
- 玩家同时只直接控制1艘主舰。
- 其他主舰继续在无缝海域中巡逻、驻防、护航或执行任务。

### 2.5 页面职责

| 页面 | 主要回答的问题 | 不应承担的内容 |
| --- | --- | --- |
| 舰队总览 | 6艘主舰在哪里、在做什么、状态如何 | 不编辑完整技能树 |
| 单舰搭配 | 这艘主舰使用什么舰体、船长和作战英雄 | 不进行完整装备强化 |
| 英雄界面 | 这个英雄是谁、如何养成、当前属于哪艘船 | 不承担六舰调度 |
| 技能界面 | 学习、升级、装配主动与被动 | 不编辑舰体模块 |
| 天赋界面 | 分支选择、预览、确认、重置 | 不替代技能详情 |
| 装备界面 | 穿戴、对比、强化、重铸、精炼 | 不承担舰组编成 |

## 3. 改造后的总体视觉方向

### 3.1 视觉关键词

- 卡通海盗船舰。
- 柔和手绘材质。
- 木材、铜件、帆布与海水色。
- 有收藏感的英雄卡片。
- 少量立体层次，不做沉重写实金属UI。
- 信息清楚，但不做满屏细线和密集小字。
- 角色与舰船优先，装饰框体退居第二层。

### 3.2 建议主色

| 功能 | 建议色 | 用途 |
| --- | --- | --- |
| 页面背景 | 深海蓝灰 | 承托立绘和卡片 |
| 主交互 | 暖金/黄铜 | 主按钮、已选择、船长徽记 |
| 作战位 | 海水青蓝 | 作战英雄、技能激活 |
| 升级成长 | 青绿色 | 正向增长、经验、可提升 |
| 警告 | 珊瑚红 | 冲突、负伤、资源不足 |
| 稀有信息 | 紫蓝 | 高阶技能、随机词条 |
| 普通文本 | 暖白 | 主信息 |
| 次级文本 | 蓝灰白 | 说明、来源、条件 |

颜色不能单独承担信息。品质、状态和岗位必须同时使用图标、边框结构、文字或角标。

### 3.3 材质层级

页面中最多保留三层明显材质：

1. 背景层：模糊港口、海图、船舱或海面环境。
2. 内容层：半透明深色面板、木质标签、黄铜节点。
3. 强调层：英雄立绘、舰船模型、装备和技能图标。

不要让每张卡片都使用高亮金边。只有当前选中、稀有奖励和关键操作才使用高亮边缘。

## 4. 全局页面结构

### 4.1 统一框架

所有舰队与英雄养成页面共享以下结构：

| 区域 | 高度/宽度建议 | 内容 |
| --- | ---: | --- |
| 顶部导航栏 | 72～80 px | 返回、页面标题、主导航、资源条 |
| 左侧导航/列表 | 280～340 px | 主舰或英雄列表 |
| 中央展示区 | 620～820 px | 英雄大图、角色模型或主舰模型 |
| 右侧功能区 | 430～560 px | 详情、对比、升级、候选列表 |
| 底部操作栏 | 88～112 px | 主要操作、保存、撤销、确认 |

### 4.2 安全区

1920×1080基准下：

- 左右安全边距：48 px。
- 顶部安全边距：32 px。
- 底部安全边距：32 px。
- 主要面板间距：16～24 px。
- 卡片内边距：16～20 px。
- 按钮最小高度：52 px。
- 图标按钮点击区域最小：48×48 px。

### 4.3 顶部主导航

推荐一级入口：

- 舰队。
- 英雄。
- 舰体。
- 仓库。
- 海域地图。

进入“英雄”后，二级页签为：

- 总览。
- 升级。
- 技能。
- 天赋。
- 装备。
- 故事/羁绊。

进入“舰队”后，二级页签为：

- 六舰总览。
- 单舰搭配。
- 舰体模块。
- 自动策略。
- 编队预设。

不要把所有二级页签长期放在港口主界面上。

## 5. 全局图标系统

### 5.1 图标覆盖范围

以下内容必须使用“图标＋文字”，不能只显示文字：

- 英雄。
- 英雄职业。
- 船长位。
- 作战位。
- 普攻。
- 主动技能。
- 被动技能。
- 天赋分支。
- 装备部位。
- 装备物品。
- 舰体。
- 舰体模块。
- 船规。
- 货币和养成材料。
- 主舰任务状态。
- 属性类别。
- 筛选标签。

### 5.2 图标尺寸规范

| 使用场景 | 图标建议尺寸 |
| --- | ---: |
| 顶部资源 | 28～32 px |
| 角色列表头像 | 64～72 px |
| 舰队主卡头像 | 72～88 px |
| 英雄大头像 | 144～200 px |
| 装备槽 | 72～88 px |
| 装备背包格 | 64～76 px |
| 主动技能 | 72～88 px |
| 被动技能 | 48～60 px |
| 属性图标 | 24～28 px |
| 状态角标 | 18～24 px |
| 页面功能按钮 | 28～36 px |

### 5.3 图标边框

每个物品图标至少有四层可组合结构：

1. 内容图。
2. 品质底色。
3. 品质边框。
4. 状态角标。

状态角标包括：

- 已装备。
- 已装配。
- 新获得。
- 可升级。
- 已锁定。
- 已占用。
- 负伤。
- 推荐。
- 无法生效。
- 套装激活。

### 5.4 临时占位图

正式美术完成前，必须使用统一占位资源，不允许每个页面出现风格不同的默认方块。

占位规则：

- 英雄：使用不同轮廓和职业色的半身剪影。
- 装备：使用部位轮廓，如帽子、上衣、手套、靴子、武器、饰品。
- 技能：使用单色符号，如炮击、雷电、护盾、维修、鱼雷。
- 舰体：使用正侧45度船舰剪影。
- 材料：使用箱子、卷轴、齿轮、矿石、徽章等轮廓。
- 所有占位图的安全边界和后续正式资源保持一致。

正式资源替换时只替换Sprite、Addressable或RenderTexture引用，不改变Prefab尺寸和布局。

## 6. 货币与养成资源显示改造

### 6.1 统一格式

所有货币和养成资源统一显示为：

`[图标] 名称  数字`

示例：

- 技能点 12。
- 天赋点 3。
- 英雄经验 18,420。
- 英雄信物 24。
- 职业手册 6。
- 强化材料 1,280。
- 重铸零件 86。
- 舰体研究点 42。

### 6.2 顶部资源条

顶部只显示当前页面最相关的2～4种资源。

| 页面 | 默认显示资源 |
| --- | --- |
| 英雄总览 | 英雄经验、英雄信物 |
| 英雄升级 | 英雄经验、英雄信物、通用金币 |
| 技能 | 技能点、职业手册、通用金币 |
| 天赋 | 天赋点、重置凭证 |
| 装备 | 强化材料、重铸零件、通用金币 |
| 舰体模块 | 舰体研究点、模块材料、通用金币 |

其余资源通过“全部资源”按钮打开资源抽屉，不在顶部堆满。

### 6.3 资源胶囊

资源胶囊组成：

- 左侧资源图标。
- 中部资源名称。
- 右侧资源数字。
- 最右侧可选的“＋”或来源按钮。

交互：

- 悬停显示用途和主要来源。
- 点击打开来源面板。
- 资源不足时胶囊边框短暂变红，不持续闪烁。
- 数字变化时只滚动变化位，不整条资源栏跳动。

### 6.4 数字格式

- 0～999：显示完整数字。
- 1,000～999,999：常规页面使用千分位完整数字。
- 空间极小的卡片允许使用1.2K、18.4K。
- 详情和消耗确认必须显示完整数字。
- 大数字变化需要同时显示`-120`或`+450`的短暂浮字。

### 6.5 消耗预览

所有升级按钮上方或按钮内部显示：

`[材料图标] 120 / 300`

前者是消耗，后者是拥有量时，应明确排列为：

`需要120｜拥有300`

不能只显示一个红色数字，让玩家猜测是需要量还是缺少量。

## 7. 英雄界面总体改造

### 7.1 页面视觉重心

英雄界面第一眼必须先看到：

1. 英雄大图或模型。
2. 英雄姓名与定位。
3. 当前装配的技能和装备。
4. 可执行的养成操作。

详细属性公式、随机范围和获取日志全部进入次级面板。

### 7.2 推荐布局比例

| 区域 | 占宽 | 主要内容 |
| --- | ---: | --- |
| 左侧英雄名单 | 17% | 英雄切换、筛选、状态 |
| 中央英雄展示 | 38% | 大图/模型、身份、当前岗位 |
| 右侧详情区域 | 45% | 当前分页内容、资源、操作 |

在“装备”分页可将中央展示缩至32%，为背包和对比面板让出空间。

### 7.3 页面顶部

左侧：

- 返回。
- 英雄标题。
- 英雄拥有数量。

中部：

- 总览。
- 升级。
- 技能。
- 天赋。
- 装备。
- 故事。

右侧：

- 当前页面相关资源。
- 帮助。
- 关闭。

### 7.4 英雄切换

- 鼠标点击左侧英雄卡切换。
- A/D或左右箭头切换上一/下一英雄。
- 切换英雄时保持当前分页。
- 若当前有未保存的天赋预览，先提示确认。
- 切换模型只做短淡入和位移，不播放长加载动画。

## 8. 左侧英雄名单

### 8.1 英雄卡片结构

每张卡片显示：

- 头像图标。
- 名称。
- 等级。
- 品质框。
- 职业图标＋职业名称。
- 当前主舰编号。
- 当前岗位图标。
- 战力简值。
- 最多2个状态角标。

### 8.2 状态优先级

从高到低：

1. 负伤。
2. 当前不可调动。
3. 当前主控舰。
4. 船长。
5. 作战位。
6. 可升级。
7. 有新装备。
8. 新获得。

同一张卡不要同时显示五六个角标。低优先级状态放入悬停详情。

### 8.3 筛选

筛选栏使用图标＋文字：

- 全部。
- 船长推荐。
- 作战推荐。
- 炮击。
- 速射。
- 鱼雷。
- 工程。
- 航海。
- 空闲。
- 已占用。
- 可升级。

支持二级筛选抽屉，但首屏最多展示6个常用筛选。

### 8.4 选中状态

选中英雄卡：

- 卡片向右平移4～6 px。
- 边框由暗色过渡为岗位色。
- 头像底部出现短亮线。
- 不使用持续大幅呼吸。

## 9. 英雄大图/模型展示区

### 9.1 容器规则

中央区域必须是独立展示容器，支持三种内容：

1. 正式英雄立绘。
2. RenderTexture实时模型。
3. 临时剪影或概念占位图。

三种模式使用同一套锚点和裁切安全区。

### 9.2 构图

- 英雄头部位于画面高度的18%～30%。
- 角色主体占展示区高度的75%～92%。
- 不把脚部和武器重要结构裁掉。
- 角色朝向略微面向详情区。
- 右侧有长武器时允许部分越出展示框，但不能遮挡关键按钮。

### 9.3 模型模式

支持：

- 鼠标左键拖动旋转。
- 滚轮缩放。
- 双击恢复默认角度。
- 待机动作。
- 装备更换时局部外观更新。
- 技能页播放短技能演示。

模型预览不与场景主相机共用后处理。

### 9.4 立绘模式

- 使用轻微呼吸位移，幅度不超过4 px。
- 切换英雄时前一张向左淡出，新英雄由右侧轻移进入。
- 禁止让整张立绘持续缩放。
- 立绘底部可增加轻量海雾、木板、船舱光影，遮挡裁切边缘。

### 9.5 身份铭牌

英雄脚下或左下角显示：

- 英雄名称。
- 称号。
- 品质。
- 职业图标＋职业名称。
- 等级。
- 当前所属主舰。
- 当前岗位。

当前岗位必须直接写为“2号主舰·船长”或“1号主舰·作战位E”，不要只放一个含义不明的图标。

## 10. 英雄总览页

### 10.1 页面目标

玩家在5秒内看懂：

- 这个英雄是谁。
- 适合做什么。
- 当前在什么岗位。
- 目前装配什么技能和装备。
- 下一步最值得提升什么。

### 10.2 右侧结构

从上到下：

1. 定位摘要。
2. 核心属性。
3. 当前战斗能力。
4. 当前装备摘要。
5. 当前天赋摘要。
6. 成长建议。

### 10.3 定位摘要

示例：

`雷电速射｜群体清杂｜作战位优先`

下面使用3个短标签：

- 高频攻击。
- 弹射。
- 能源压力较高。

标签不超过6个字，详细说明放在悬停提示中。

### 10.4 核心属性

总览只显示6项：

- 火力。
- 防护。
- 操舰。
- 技术。
- 感知。
- 支援。

每项包含：

- 属性图标。
- 名称。
- 数字。
- 与同等级英雄平均值的短刻度。

点击“详细属性”打开抽屉，显示公式来源和舰船换算。

### 10.5 当前能力

使用图标卡表达：

- 普攻1个。
- 主动技能1个。
- 被动技能3个。

船长位状态下：

- 普攻和主动技能加半透明遮罩。
- 显示锁形角标。
- 悬停说明“当前任命为船长，普攻和主动技能不参与战斗”。
- 三个被动保持正常高亮。

### 10.6 成长建议

最多显示2项：

- `建议：主动技能可升级至Lv.4`
- `建议：更换手套可使全舰冷却降低2.3%`

点击建议直接跳到对应分页并定位目标。

## 11. 英雄升级与突破界面

### 11.1 布局

中央保留英雄大图。

右侧从上到下：

- 当前等级和经验条。
- 升级后核心属性预览。
- 升级资源。
- 单级升级。
- 一键升级。
- 突破节点。

### 11.2 经验条

显示：

- 当前等级。
- 当前经验/下级所需经验。
- 本次计划提升到的等级。
- 经验溢出处理。

一键升级时允许通过滑块或加减按钮选择目标等级。

### 11.3 前后对比

只显示实际变化：

| 属性 | 当前 | 升级后 | 变化 |
| --- | ---: | ---: | ---: |
| 火力 | 182 | 194 | +12 |
| 技术 | 140 | 146 | +6 |
| 舰船持续火力贡献 | 328 | 349 | +21 |

不要重复展示完全没有变化的所有属性。

### 11.4 突破节点

突破阶段使用横向5节点或纵向阶梯：

- 当前节点为实体徽章。
- 未达到节点为轮廓。
- 下一节点显示所需等级和信物。
- 已完成节点有轻微常亮，不持续放射光。

### 11.5 升级动效

点击升级：

1. 按钮压下，持续0.08秒。
2. 资源数字扣除，持续0.18秒。
3. 经验条快速填充，持续0.25～0.45秒。
4. 等级数字向上滚动。
5. 变化属性逐项上浮，间隔0.04秒。
6. 英雄播放轻微确认动作或立绘抬升2～4 px。

普通升级不播放全屏闪光。

突破动效：

- 徽章闭合。
- 角色背后短暂出现岗位色光环。
- 解锁内容以卡片形式从徽章旁弹出。
- 总时长控制在1.2～1.8秒，可点击跳过。

按以下顺序：

2. 技能演示或动态图标。

4. 关键数值。
5. 下一级变化。

### 12.7 技能装配动效

1. 技能图标从列表生成一个拖拽副本。
2. 放入槽位后图标缩至0.92倍。
3. 0.10秒回弹到1.00倍。
4. 槽位边缘沿顺时针亮一圈。
5. 对应作战位和HUD预览同步闪亮一次。

总时长0.25～0.4秒。

显示：

- 方案1/方案2/方案3。

- 当前等级。
- 最大等级。
- 前置连线。
- 岗位生效图标。

### 13.4 节点状态

| 状态 | 表现 |
| --- | --- |
| 已点亮 | 图标完整、边框常亮 |

| 预览 | 虚线金边、数字暂存 |

### 13.6 加点动效

- 预览：节点内部出现短波纹，不播放强光。
- 确认：能量沿前置连线流向节点，0.25～0.45秒。
- 多节点确认：按路径快速依次点亮，总时长不超过1.2秒。
- 解锁技能行为变化时，右侧技能卡弹出“行为改变”标记。

## 15. 装备详情与对比

### 15.1 双卡对比

右侧上部：

1. 英雄属性。

- 增加：绿色数字＋上箭头。
- 减少：珊瑚红数字＋下箭头。
- 行为改变：金色“变化”标签。

悬停示例：

### 15.5 全舰实际影响

装备详情必须显示：

- 英雄自身变化。
- 英雄在当前岗位下的实际生效比例。
- 最终主舰变化。

如果英雄当前未编入主舰：

- 显示英雄自身变化。
- 下方提示“当前未编入主舰，暂无全舰实时换算”。
- 可选择一艘主舰进行模拟。

## 16. 装备操作流程

### 16.1 穿戴流程

1. 点击装备部位。
2. 背包自动筛选同部位。
3. 点击候选装备。
4. 右侧显示完整对比。
5. 点击“装备”或双击候选装备。
6. 检查占用、等级和锁定条件。
7. 播放穿戴反馈。
8. 更新英雄、技能和主舰属性。
9. 保存装备状态。

### 16.2 快速换装

允许双击，但必须满足：

- 装备可以穿戴。
- 不涉及高价值装备从其他英雄拆下。
- 不会打破已锁定的编队预设。

否则先弹出确认卡，显示来源英雄或主舰。

### 16.3 穿戴动效

1. 候选图标缩小并沿短曲线飞向装备槽，0.18～0.28秒。
2. 旧装备图标向背包方向淡出。
3. 槽位压缩到0.92倍后回弹。
4. 套装计数若变化，对应套装徽记点亮或熄灭。
5. 英雄模型外观可见时局部淡入新装备。
6. 右侧属性数字平滑滚动到新值。

不要让整个角色界面白闪。

### 16.4 强化界面

点击强化后，右侧详情切为强化子页：

- 当前强化等级。
- 下一等级。
- 固定属性提升。
- 可选的概率机制。
- 材料图标＋名称＋数量。
- 强化按钮。
- 连续强化目标。

如果强化在港口建筑中完成：

- 野外只允许查看。
- 按钮显示“前往锻造工坊”。
- 点击后在无缝港口中聚焦对应建筑或打开其功能页。

### 16.5 重铸界面

- 明确标记锁定词条。
- 显示锁定成本。
- 显示可出现词条池。
- 重铸前后两列。
- 玩家点击“保留原属性”或“采用新属性”。
- 离开前必须处理未选择结果。

### 16.6 分解保护

以下装备需要二次确认：

- 高品质。
- 已强化。
- 已锁定。
- 已装备。
- 会导致套装失效。
- 带高品质随机词条。

确认框必须显示具体损失，不只显示“是否确认”。

## 19. 船长位卡片

### 19.1 视觉结构

船长卡必须比单个作战位宽30%～50%，但不需要更高。

包含：

- 船长徽记。
- 英雄头像。
- 名称和等级。
- 职业。
- 3个被动图标。
- 属性贡献摘要。
- 船规/指挥加成摘要。
- 当前主舰影响。

### 19.2 无效能力表达

普攻和主动技能不应完全消失，否则玩家可能误以为英雄没有这些技能。

建议：

- 在卡片右侧小尺寸显示普攻和主动技能。
- 统一加暗色遮罩。
- 叠加“船长位不生效”标签。
- 悬停可查看完整技能。

### 19.3 任命反馈

任命船长：

1. 英雄头像飞入船长框。
2. 船长徽记由轮廓变为实体。
3. 舰桥区域短暂亮起。
4. 全舰被动摘要按顺序更新。
5. 若新船长导致流派变化，流派标签轻量替换。

总时长0.45～0.7秒。

- 一般。
- 不推荐。

悬停说明原因，例如：

`该英雄拥有3个作战被动，但船长加成较弱。`

### 20.4 作战位激活反馈

英雄落位后：

- 对应卡片缩放回弹。
- 普攻和主动技能逐个点亮。
- 舰船对应武器挂点短暂高亮。
- HUD预览槽同步出现英雄头像和技能图标。

## 21. 候选英雄区

### 21.1 默认状态

未选择岗位时：

- 显示全部英雄。
- 按当前舰组提升排序。
- 标出空闲、已占用、负伤。

选择船长位后：

- 自动切换为船长推荐排序。
- 重点显示被动和全舰属性贡献。

选择作战位后：

- 自动切换为作战推荐排序。
- 重点显示普攻、主动和能源压力。

### 21.2 候选卡

显示：

- 头像。
- 名称。
- 等级。
- 当前岗位。
- 2个核心能力图标。
- 对当前槽位的提升箭头。
- 来源主舰角标。

### 21.3 悬停预览

悬停候选英雄时，中央岗位区显示半透明替换预览：

- 原英雄头像降低透明度。
- 候选英雄头像叠加进入。
- 底部显示获得和失去的能力。
- 舰船核心属性显示变化数字。

不实际修改阵容，移开鼠标立即恢复。

## 22. 舰船搭配拖拽与交换

### 22.1 拖拽规则

- 英雄可从候选列表拖入岗位。
- 岗位之间可以直接交换。
- 从其他主舰拖来英雄时显示来源。
- 负伤或任务锁定英雄禁止直接拖动。
- 船长位与作战位交换时必须重新校验技能生效。

### 22.2 合法反馈

- 合法槽位亮边。
- 当前最佳推荐槽位出现小型锚点图标。
- 被拖卡片倾斜不超过2度。
- 鼠标下方显示人物头像拖拽副本。

### 22.3 非法反馈

- 非法槽位不接受落下。
- 卡片轻微左右摇动2次。
- 提示具体原因。

示例：

- `英雄正在3号主舰执行战斗任务。`
- `英雄负伤，需先返回医务室。`
- `该预设已锁定，先解除锁定。`

### 22.4 交换确认

普通空闲英雄直接交换。

以下情况需要确认：

- 从其他正在执行任务的主舰调动。
- 导致另一艘主舰出现空岗位。
- 使当前任务条件不满足。
- 破坏锁定的预设。

确认卡必须显示两艘主舰和两个岗位的变化。

## 23. 全舰属性与阵容诊断

### 23.1 底部核心属性

常驻显示8项：

- 生命。
- 持续火力。
- 爆发。
- 防护。
- 航速。
- 转向。
- 能源。
- 维修。

更多属性进入展开抽屉。

### 23.2 流派标签

最多显示4个主要标签：

- 雷暴速射。
- 鱼雷攻坚。
- 堡垒防守。
- 高速追猎。
- 自动维修。
- 护航支援。

每个标签必须有图标和短解释。

### 23.3 阵容诊断

诊断只显示最关键的2～3条：

- `缺少稳定破甲，攻坚大型核心时效率较低。`
- `能源压力91%，连续释放可能使主舰停火。`
- `拥有双工程被动，维修能力优秀。`

不要显示十几条低价值提示。

### 23.4 属性来源

点击任意属性打开来源抽屉：

- 舰体基础。
- 舰体模块。
- 船长。
- 作战英雄。
- 装备。
- 被动。
- 天赋。
- 海域加成。

用于回答“这个数字为什么这么高/低”。

- 装备冲突。

## 26. 页面之间的跳转关系

### 26.1 舰队到英雄

- 双击岗位英雄：进入英雄总览。
- 点击英雄技能图标：进入该英雄技能页。
- 点击装备提醒：进入该英雄装备页并筛选推荐装备。
- 返回时回到原主舰和原岗位，不重置上下文。

### 26.2 英雄到舰队

- 点击所属主舰：进入对应单舰搭配页。
- 点击“任命船长”：打开主舰选择轻量弹窗。
- 点击“配置到作战位”：打开主舰与空位选择。
- 完成后返回英雄页，并更新所属信息。

### 26.3 深层返回

系统记录：

- 来源页面。
- 当前主舰。
- 当前英雄。
- 当前分页。
- 当前筛选。
- 当前滚动位置。

点击返回应回到发起操作的位置，而不是永远回到港口首页。

## 27. 鼠标交互状态规范

每个可点击控件必须至少有：

1. 默认。
2. 悬停。
3. 按下。
4. 选中。
5. 禁用。
6. 锁定。

### 27.1 默认

- 正常亮度。
- 不持续漂浮。
- 非主按钮不使用强发光。

### 27.2 悬停

- 亮度提高5%～10%。
- 边框轻微提亮。
- 卡片上浮2～4 px。
- 0.08～0.14秒过渡。
- 延迟0.35～0.5秒显示Tooltip。

### 27.3 按下

- 缩放至0.96～0.98。
- 阴影减弱。
- 0.05～0.08秒。

### 27.4 选中

- 使用稳定边框、底部亮线或左侧定位条。
- 不使用高频闪烁。
- 必须能与悬停区分。

### 27.5 禁用

- 降低饱和度。
- 保留可读名称。
- 悬停时解释禁用原因。
- 不仅依赖降低透明度。

### 27.6 锁定

- 显示锁图标。
- 显示具体解锁条件。
- 点击可打开来源或条件说明。

## 28. 按钮等级与点击反馈

### 28.1 主按钮

用于：

- 出航。
- 保存阵容。
- 确认加点。
- 装备。
- 升级。
- 突破。

规则：

- 每个主要面板最多1个强主按钮。
- 使用暖金或当前功能强调色。
- 图标＋动词。

### 28.2 次按钮

用于：

- 查看来源。
- 自动策略。
- 筛选。
- 另存预设。
- 预览。

使用深色底和浅色边框。

### 28.3 危险按钮

用于：

- 分解。
- 重置。
- 覆盖预设。
- 解除锁定。

默认不使用整块红色，只在悬停或确认阶段加强红色。

### 28.4 点击音效建议

- 普通按钮：短木扣或柔和金属扣。
- 装备：布料＋轻金属装配声。
- 技能装配：能量嵌入声。
- 船长任命：短号角或舰钟。
- 主舰切换：帆布滑动＋水浪。
- 错误：低沉短音，不使用刺耳蜂鸣。

## 29. 页面切换动效

### 29.1 一级页面

舰队与英雄之间：

- 背景环境交叉淡化。
- 主内容沿导航方向移动24～40 px。
- 总时长0.22～0.35秒。

### 29.2 二级分页

总览、升级、技能、天赋、装备之间：

- 英雄大图保持。
- 右侧内容淡出并轻移12～20 px。
- 0.16～0.24秒。
- 不重复播放英雄入场。

### 29.3 弹窗

- 遮罩在0.12秒内淡入。
- 弹窗从0.96缩放至1.00。
- 使用轻微回弹，峰值不超过1.015。
- 关闭反向播放，总时长0.12～0.18秒。

### 29.4 抽屉

属性详情、资源来源、筛选使用侧边抽屉：

- 沿屏幕边缘滑入。
- 主页面不缩小，只轻微变暗。
- 抽屉宽度不超过屏幕35%。

## 30. 数值与资源变化动效

### 30.1 数值上升

- 数字滚动到目标值。
- 右侧出现绿色`+X`。
- `+X`上浮8～14 px并淡出。
- 0.35～0.65秒。

### 30.2 数值下降

- 数字滚动。
- 显示珊瑚红`-X`。
- 不进行屏幕震动。

### 30.3 资源不足

- 对应资源胶囊左右轻摆一次。
- 边框短暂变红。
- 消耗位置显示缺少数量。
- 打开来源按钮。

### 30.4 战力变化

战力只能作为摘要：

- 显示总战力变化。
- 同时显示最重要的2～3个具体变化。
- 如果存在关键能力损失，不能只播放绿色战力上升。

## 31. 红点、角标与通知

### 31.1 红点使用范围

允许红点：

- 新英雄。
- 新技能可学习。
- 天赋点未使用。
- 装备栏有明显升级。
- 主舰存在空岗位。
- 预设不完整。

不使用红点：

- 可重复强化。
- 无限循环资源消耗。
- 普通背包新物品。
- 每次资源足够。

### 31.2 角标

角标优先使用有含义的图标：

- 上箭头：可升级。
- 感叹号：冲突。
- 锁：锁定。
- 舰号：已占用。
- 十字绷带：负伤。
- 星形：新获得。

### 31.3 通知位置

- 页面内成功：按钮上方或对应卡片附近。
- 全局奖励：右上角资源区。
- 阵容冲突：底部诊断条。
- 高风险操作：中央确认卡。

## 32. 空状态、锁定与错误状态

### 32.1 英雄未获得

显示：

- 英雄剪影。
- 职业和定位预览。
- 主要获取方式。
- 来源跳转。

不显示空白格。

### 32.2 装备部位为空

显示：

- 部位图标。
- 部位名称。
- `点击选择装备`。
- 当前背包存在可用装备时显示小箭头。

### 32.3 技能未解锁

显示：

- 灰色技能图标。
- 技能名称。
- 解锁条件。
- 获取来源。

不把技能完全隐藏，否则玩家无法形成成长目标。

### 32.4 主舰岗位为空

显示推荐岗位类型和一键筛选入口。

### 32.5 加载

- 英雄图和舰船模型使用骨架占位或剪影。
- 列表先显示结构，再加载图片。
- 不让整个页面只显示转圈。

### 32.6 数据错误

- 保留当前页面。
- 显示失败的具体区域。
- 提供重试。
- 不因单个头像加载失败而关闭整个界面。

## 34. Tooltip规范

### 34.1 出现规则

- 鼠标稳定悬停0.35～0.5秒后出现。
- 移动到相邻图标时快速替换。
- 不遮挡当前鼠标和主要按钮。
- 屏幕边缘自动翻转方向。

### 34.2 内容层级

第一层：

- 图标。
- 名称。
- 类型。
- 一句话说明。

第二层：

- 关键数值。
- 生效岗位。
- 获取方式。

第三层：

- 按Alt展开详细公式、范围和来源。

### 34.3 对比Tooltip

悬停装备时按住Alt：

- 固定当前装备卡。
- 候选装备显示在旁边。
- 高亮不同字段。

## 36. 关键交互时序

### 36.1 英雄装入作战位

1. 玩家选中作战位E。
2. 候选区自动按作战适性排序。
3. 悬停英雄时显示替换预览。
4. 玩家点击或拖拽英雄。
5. 系统检查占用和任务状态。
6. 英雄头像进入E位。
7. 普攻、主动、被动依次点亮。
8. 舰船对应挂点高亮。
9. 底部全舰属性滚动更新。
10. 阵容诊断重新计算。
11. 保存按钮出现未保存标记。

### 36.2 任命船长

1. 选中船长位。
2. 候选区显示船长适性。
3. 悬停时只计算属性和被动，不计算普攻与主动。
4. 选择英雄。
5. 系统显示被禁用的普攻与主动。
6. 船长徽记点亮。
7. 舰桥短亮。
8. 全舰属性和船规重新计算。

### 36.3 更换装备

1. 选择装备部位。
2. 背包筛选。
3. 选择候选装备。
4. 显示英雄/技能/舰船/套装四层对比。
5. 玩家确认装备。
6. 图标飞入槽位。
7. 角色外观更新。
8. 数值滚动。
9. 套装效果更新。
10. 保存。

### 36.4 技能升级并装配

1. 选择技能。
2. 查看当前与下一级。
3. 点击升级。
4. 扣除技能点和手册。
5. 技能等级数字更新。
6. 点击或拖入主动/被动槽。
7. 检查岗位和互斥。
8. 槽位回弹。
9. HUD预览更新。

## 41. 性能规则

### 41.1 列表

- 英雄列表使用虚拟化。
- 装备背包使用虚拟化网格。
- 技能长列表使用虚拟化。
- 卡片对象池复用。
- 状态改变只刷新可见卡片。

### 41.2 图标

- 常用小图标使用图集。
- 大型英雄立绘单独加载。
- 非当前英雄立绘及时释放或降级缓存。
- 品质框与角标尽量复用。

### 41.3 模型

- 同时只渲染1个英雄实时模型和1个主舰实时模型。
- 离开页面暂停预览动画。
- 使用独立Preview Scene或受控RenderTexture。
- 模型旋转时才提高刷新率，静止时允许降低刷新频率。

### 41.4 动效

- 动效优先修改Transform、CanvasGroup和材质参数。
- 避免整页Layout持续重建。
- 数值滚动使用缓存组件。
- 大量红点更新合并到一帧或短队列中。

## 46. 验收清单

### 46.1 视觉

- [ ] 英雄大图或模型是英雄页面第一视觉中心。
- [ ] 主舰模型是舰船搭配页第一视觉中心之一。
- [ ] 资源统一使用图标＋名称＋数字。
- [ ] 英雄、装备、技能、舰体均有对应图标。
- [ ] 临时占位图风格统一，后续可直接替换正式美术。
- [ ] 页面没有过量金边、发光和高频呼吸。
- [ ] 不依赖颜色单独表达品质、岗位和状态。

### 46.2 英雄界面

- [ ] 能在5秒内看懂英雄定位、岗位、技能和装备。
- [ ] 英雄列表清楚显示当前主舰和岗位。
- [ ] 总览只展示核心属性，详细公式进入抽屉。
- [ ] 船长状态下普攻和主动明确显示为不生效。
- [ ] 成长建议最多展示2项并可直接跳转。

### 46.3 舰船搭配

- [ ] 船长位比作战位更突出。
- [ ] 四个作战位明确对应Q/E/R/F。
- [ ] 作战位显示普攻、主动和3个被动。
- [ ] 拖拽前能预览全舰属性和流派变化。
- [ ] 从其他主舰调人时明确显示来源和影响。
- [ ] 阵容诊断只显示最关键问题。

### 46.4 装备

- [ ] 6个装备部位均有图标和空槽状态。
- [ ] 背包装备有品质、强化、锁定、新获得和推荐角标。
- [ ] 对比同时展示英雄、技能、舰船和套装变化。
- [ ] 随机词条显示当前值、范围和生效状态。
- [ ] 高价值装备分解和跨英雄拆卸有明确确认。

### 46.5 技能和天赋

- [ ] 技能列表使用图标、名称、类型、等级和装配状态。
- [ ] 主动槽与3个被动槽清楚区分。
- [ ] 非法拖拽会解释具体原因。
- [ ] 天赋节点拥有图标、前置、岗位和技能关联信息。
- [ ] 天赋允许预览、撤销和统一确认。

### 46.6 动效

- [ ] 所有按钮具备默认、悬停、按下、选中、禁用和锁定状态。
- [ ] 装备、技能、英雄落位都有局部反馈。
- [ ] 普通升级不播放全屏闪光。
- [ ] 数值变化只更新相关字段，不刷新整页。
- [ ] 页面切换时英雄大图尽量保持，减少视觉跳动。
- [ ] 动效时长与强度符合L1～L4分级。

### 46.7 性能

- [ ] 英雄、技能、装备列表使用虚拟化。
- [ ] 卡片对象池复用。
- [ ] 同时只渲染必要的英雄和主舰模型。
- [ ] 离开页面后停止预览动画。
- [ ] 图标和立绘按需加载。
- [ ] 单个状态变化不触发整页Layout重建。

## 47. 最终核心规则摘要

1. 英雄界面不再以属性表为中心，而以独立英雄大图或模型为中心。
2. 技能点、天赋点、经验、强化材料等统一显示为“图标＋名称＋数字”。
3. 英雄、技能、装备、舰体和材料全部使用统一图标体系。
4. 正式美术未完成时使用统一剪影和符号占位，后续不改布局即可替换。
5. 舰队页负责六舰状态和编成，英雄页负责单个角色养成。
6. 单舰搭配页使用大型主舰模型、船长大卡和2×2作战位卡。
7. 船长位明确禁用普攻和主动技能，只显示属性与最多3个被动。
8. 四个作战位明确对应Q/E/R/F，并显示普攻、主动和3个被动。
9. 装备对比必须拆分英雄、技能、舰船和套装四层影响。
10. 所有操作都采用局部动效，不通过整页闪烁制造反馈。
11. 普通操作保持轻快，突破、新英雄和新主舰才使用较强演出。
12. 所有页面保留来源上下文，深层跳转后能返回原主舰、原英雄和原位置。
