# 《吞吞舰船》商业化：充值货币、付费商城、双卡池抽奖、重复进阶与 UI 完整设计文档

> 文档性质：独立增量设计文档  
> 适用模块：海盗生涯、英雄船舰、多主舰、角色养成、装备、商城、抽奖  
> 原则：不修改旧文档文件；当本文件与旧的“英雄突破卡等级上限”“占领海域直接获得主舰”等规则冲突时，以本文件的商业化改造规则为准。

---

## 0. 本次改造结论

本次新增一套完整但克制的商业化系统：

1. 新增充值货币“航海晶石”。
2. 开发阶段新增作弊按钮，可快速增加航海晶石和测试抽奖券。
3. 新增付费商城，所有商品只使用航海晶石购买。
4. 商城出售部分主舰、英雄、固定装备和基础建造材料。
5. 商城直售内容可以好用、易成型，但不能是对应类别的最强内容。
6. 新增英雄招募池和主舰建造池。
7. 两个池子使用不同抽奖券、不同保底计数和不同抽奖记录。
8. 两个池子都支持单抽和十连抽。
9. 抽奖券可以从玩法中获得，也可以用航海晶石购买。
10. 英雄主要来自抽奖，部分来自任务、特殊玩法和商城。
11. 主舰主要来自抽奖，部分来自任务、特殊玩法和商城。
12. 装备仍然主要来自游戏掉落，商城只提供过渡型固定装备。
13. 强力装备来自海域核心、高危航线、世界海怪、遗迹等特殊玩法。
14. 重复英雄和重复主舰用于同名对象进阶。
15. 英雄进阶与等级上限彻底解耦。
16. 主舰进阶与编制席位彻底解耦。
17. 进阶只稳定提升基础全属性，不设置失败、降级和随机结果。
18. 满阶后继续获得重复对象，会转化为溢出兑换资源，不会变成无价值废品。

一句话概括：

> 抽奖负责扩展英雄与舰体收藏，掉落装备负责长期刷取，海域玩法负责产出最强内容，商城负责确定性补充与缩短等待，但不能直接买到毕业答案。

## 1. 商业化定位

### 1.1 商业化服务的核心需求

商业化不能成为与核心玩法割裂的单独按钮，它应服务以下长期目标：

- 玩家愿意收集更多英雄，组建不同舰组。
- 玩家愿意收集更多舰体，让六艘主舰产生不同分工。
- 玩家愿意尝试不同角色、技能、天赋和装备构筑。
- 玩家可以通过付费更快得到确定目标，但不能跳过全部玩法。
- 玩家即使不付费，也能获得完整的新手舰组并持续获得抽奖机会。
- 装备掉落始终是长期游戏动力，不能被商城和抽奖替代。

### 1.2 不采用的方向

首版不建议加入：

- 装备抽奖池。
- 技能抽奖池。
- 天赋点直接售卖。
- 传奇毕业装备直售。
- 付费专属的基础功能。
- 付费才能解锁的第2～6主舰席位。
- 购买后随机词条的商城装备箱。
- 进阶失败、掉阶、装备强化失败。
- 多层充值货币反复兑换。
- 十连概率高于单抽但不明确说明。
- 隐藏保底、动态调整个人概率。
- “差一点抽中”的虚假擦边演出。

### 1.3 付费强度边界

付费可以带来：

- 更快获得目标英雄或目标舰体。
- 更快扩展可用阵容。
- 更快完成低阶进阶。
- 更快补充基础建造材料。
- 更快得到一套可用但非毕业的装备。

付费不能直接带来：

- 只在付费商城出现的最强英雄。
- 只在付费商城出现的最强主舰。
- 只在付费商城出现的最高装备词条。
- 无法通过玩法获得的核心战斗机制。
- 无限制购买高阶特殊材料。
- 直接占领海域、自动击败核心或跳过关键玩法。

## 2. 与成熟手游的参考关系

本方案参考成熟商业化手游中已经验证过的几类结构，但不照搬其数值：

| 参考结构 | 可借鉴点 | 本项目调整 |
| --- | --- | --- |
| 角色活动抽取 | 独立保底、限定目标、保底跨轮换继承 | 英雄与主舰彻底分池，并各用专属券 |
| 重复角色成长 | 重复对象具有长期价值 | 只做稳定全属性提升，不解锁决定性核心机制 |
| 抽奖溢出兑换 | 满重复对象后仍有价值 | 进入溢出凭证商店，可兑换自选进阶凭证 |
| 直售商店 | 确定性获得，降低纯随机挫败 | 只卖非顶级英雄、舰体、固定装备和基础材料 |
| 十连保底 | 控制连续低品质结果 | 十连与连续10次单抽使用同一序列、同一概率 |
| 历史记录 | 玩家可核对结果和保底 | 两个池分别记录，显示时间、结果、计数变化 |

参考的核心不是“让玩家抽得更多”，而是：

- 玩家在购买前知道花什么。
- 玩家知道最多多少抽可以获得高品质结果。
- 玩家知道当前还差多少抽触发保底。
- 玩家知道重复内容会变成什么。
- 玩家知道商店商品和游戏内最强内容之间的边界。

## 4. 货币与资源体系

### 4.1 商业化相关资源

| 资源 | 主要来源 | 主要用途 | 是否可直接充值 |
| --- | --- | --- | --- |
| 航海晶石 | 充值、维护补偿、极少量重大成就 | 商城、购买两类抽奖券 | 是 |
| 英雄招募券 | 任务、活动、战令、玩法首通、晶石购买 | 英雄池单抽/十连 | 否 |
| 主舰建造券 | 海域占领、章节、活动、战令、晶石购买 | 主舰池单抽/十连 | 否 |
| 英雄溢出凭证 | 满阶英雄重复获取 | 兑换英雄自选进阶凭证等 | 否 |
| 舰体溢出凭证 | 满阶主舰重复获取 | 兑换舰体自选进阶凭证等 | 否 |

### 4.2 航海晶石规则

- 航海晶石是唯一充值货币。
- 不再设计“付费钻石→免费钻石→抽奖石→抽奖券”的多层兑换。
- 航海晶石可以直接购买商品，也可以购买两种专属抽奖券。
- 任何使用航海晶石的按钮都必须显示晶石图标、名称和完整数字。
- 余额不足时打开充值页，不自动跳转支付。
- 正式支付前必须显示本地货币价格、晶石数量和到账内容。
- 首版开发阶段不接真实支付，仅使用作弊按钮模拟到账。

### 4.3 抽奖券规则

- 英雄招募券不能用于主舰池。
- 主舰建造券不能用于英雄池。
- 抽奖券没有随机类型，不再兑换成第三层资源。
- 单张券对应一次抽奖。
- 十连需要10张同类券。
- 券不足时，可以使用航海晶石补齐。
- 混合支付时必须明确显示：

```text
本次十连消耗
英雄招募券  6张
航海晶石    640
```

- 不允许在确认后悄悄把所有票券保留下来、只扣晶石。

### 4.4 通用货币与商业货币的边界

通用金币、木材、金属、鱼产等旧资源：

- 不能兑换航海晶石。
- 不能无限兑换抽奖券。
- 可以在周期任务或重大成就中间接奖励少量抽奖券。
- 仍然负责建筑、英雄升级、装备强化和港口生产。

## 5. 充值商品与开发阶段作弊按钮

### 5.1 正式充值档位建议

以下仅定义晶石数量，真实价格由发行地区和平台配置：

| 商品ID | 晶石 | 定位 |
| --- | ---: | --- |
| Crystal_60 | 60 | 最小档 |
| Crystal_300 | 300 | 轻量档 |
| Crystal_980 | 980 | 小额常用档 |
| Crystal_1980 | 1,980 | 中档 |
| Crystal_3280 | 3,280 | 中高档 |
| Crystal_6480 | 6,480 | 高档 |

正式页面必须同时显示：

- 本地货币价格。
- 基础晶石数量。
- 额外赠送数量。
- 首充奖励是否已经使用。
- 每单位晶石的实际价值可在详情中查看。

不建议首版使用容易混淆的“不规则兑换链”。

### 5.2 作弊按钮

开发阶段在顶部航海晶石资源胶囊旁增加：

`[＋测试]`

点击后打开开发面板：

```text
商业化测试
├── 航海晶石 +10,000
├── 英雄招募券 +100
├── 主舰建造券 +100
├── 清空英雄池保底
├── 设置英雄池保底为79/80
├── 设置主舰池保底为59/60
├── 模拟下一抽传奇
├── 模拟下一抽非精选
├── 模拟下一抽精选
└── 清空商城限购记录
```

### 5.3 作弊按钮安全规则

- 仅在`Development Build`或编辑器环境出现。
- 正式包编译时从入口层彻底移除，不只是隐藏。
- 每次操作写入本地测试日志。
- 测试资源标记`IsTestGrant=true`。
- 测试存档不能上传正式排行榜和正式账号服务器。
- 如果以后连接服务器，作弊请求只允许测试环境和测试账号。

## 6. 商业化总入口

### 6.1 首页入口

首页增加两个一级入口：

- 商城。
- 招募/建造。

不建议把商城、英雄池、主舰池、充值全部拆成四个同权重首页按钮。

推荐层级：

```text
首页
├── 开始/继续
├── 舰队
├── 英雄
├── 商城
│   └── 充值
└── 招募与建造
    ├── 英雄招募
    └── 主舰建造
```

### 6.2 顶部常驻资源

商业化页面顶部统一显示：

```text
[航海晶石图标] 航海晶石  3,280  [+]
[英雄券图标]   英雄招募券 12
[主舰券图标]   主舰建造券 7
```

规则：

- 商城页默认突出航海晶石。
- 英雄池页默认突出航海晶石和英雄招募券。
- 主舰池页默认突出航海晶石和主舰建造券。
- 其他页面只显示航海晶石，不堆满全部商业资源。
- 点击“＋”打开充值页。
- 点击券胶囊打开来源面板。

## 7. 付费商城总体结构

### 7.1 商城页签

商城包含六个页签：

1. 精选。
2. 主舰。
3. 英雄。
4. 装备。
5. 建造材料。
6. 抽奖券。

所有商品均使用航海晶石购买。

### 7.2 商城商品类型

| 页签 | 商品 | 商业定位 |
| --- | --- | --- |
| 精选 | 推荐组合、轮换商品 | 提高发现效率 |
| 主舰 | 非顶级舰体、重复舰体副本 | 确定性获得 |
| 英雄 | 非顶级英雄、重复英雄副本 | 确定性补阵容 |
| 装备 | 固定属性过渡装备 | 快速形成可用套装 |
| 建造材料 | 木材、金属、基础零件等 | 缩短基础等待 |
| 抽奖券 | 英雄券、主舰券 | 进入双卡池 |

### 7.3 商城刷新

- 精选页：每30天轮换。
- 英雄与主舰直售：每30天轮换。
- 装备页：每14天轮换。
- 基础材料：每日限购，每日刷新。
- 抽奖券：常驻单张和十张购买。
- 所有刷新时间使用服务器时间。
- 倒计时同时显示日期与剩余时间。
- 商品下架前72小时必须明确提示。
- 已经进入支付确认的订单，商品刷新不能改变成交内容。

### 7.4 商城不制造虚假稀缺

- 常驻商品明确标记“常驻”。
- 轮换商品显示“预计再次上架”，不写“永不返场”。
- 不在最后一分钟突然提高折扣。
- 不使用虚假库存数字。
- 不通过频繁弹窗强迫玩家查看商城。
- 同一商品的“原价”必须存在真实销售依据。

## 8. 商城主舰设计

### 8.1 可售主舰范围

商城主舰应是：

- 定位明确。
- 容易搭配。
- 中等强度。
- 适合补齐舰队分工。
- 不拥有全游戏唯一且最强的核心机制。

适合直售的例子：

| 舰体 | 定位 | 优势 | 明确短板 |
| --- | --- | --- | --- |
| 铁鲸运输舰 | 远洋、运输 | 货舱和续航优秀 | 战斗机动差 |
| 海盾巡逻舰 | 防守、护航 | 护盾稳定 | 输出上限一般 |
| 风帆侦察舰 | 侦察、追击 | 航速和视野优秀 | 耐久低 |
| 工坊维修舰 | 工程、支援 | 维修和建筑支援 | 单舰攻击弱 |

### 8.2 不可直售主舰

以下舰体不进入付费商城：

- 赛季最高难度核心掉落舰体。
- 世界海怪唯一舰体。
- 特殊剧情终章舰体。
- 当前版本综合强度明显最高的舰体。
- 能跳过海域玩法或无视地图规则的舰体。

### 8.3 主舰商品卡

主舰卡至少显示：

- 舰体大图或模型预览。
- 名称、品质、定位标签。
- 已拥有/未拥有。
- 当前进阶等级。
- 主要优势3项。
- 明确短板1～2项。
- 技能或船规摘要。
- 航海晶石价格。
- 限购次数。
- “查看完整属性”按钮。

如果玩家已经拥有：

```text
购买后获得：该舰体同名副本 ×1
当前进阶：2/6
购买后可进阶至：3/6
```

### 8.4 建议价格

| 品质 | 建议价格 |
| --- | ---: |
| 稀有舰体 | 980航海晶石 |
| 史诗舰体 | 1,980航海晶石 |

首版商城不直售传奇舰体。

## 9. 商城英雄设计

### 9.1 可售英雄范围

商城英雄主要解决：

- 缺少治疗/维修英雄。
- 缺少某类武器英雄。
- 第二、第三艘主舰缺人。
- 新玩家想快速组成基础流派。

适合直售：

- 功能完整的稀有英雄。
- 机制清楚的史诗英雄。
- 新手友好的船长候选。
- 中后期仍可使用但不垄断阵容的角色。

### 9.2 不可直售英雄

- 当前版本最高输出角色。
- 只有付费才能获得的关键治疗角色。
- 世界事件唯一剧情英雄。
- 赛季最高难度奖励英雄。
- 对某类敌人形成无条件绝对克制的英雄。

### 9.3 英雄商品卡

显示：

- 英雄头像和半身大图。
- 名称、品质、职业、岗位推荐。
- 普攻图标。
- 主动技能图标。
- 最多3个被动摘要。
- 船长位价值和作战位价值。
- 当前拥有状态与进阶等级。
- 晶石价格和限购。
- 试玩/预览按钮。

### 9.4 建议价格

| 品质 | 建议价格 |
| --- | ---: |

- 玩家想抽角色却抽到大量无关材料。

## 15. 单抽与十连的统一逻辑

### 15.1 核心原则

十连不是一次独立概率事件，而是顺序执行10次单抽。

每一次都按以下顺序：

1. 读取对应池的传奇计数。
2. 计算当前抽传奇概率。
3. 判断是否触发传奇。
4. 未触发传奇时检查10抽史诗保底。
5. 确定具体品质。
6. 在该品质内容表内选择目标。
7. 传奇结果处理精选保证。
8. 更新保底状态。
9. 处理首次获得或重复获得。
10. 写入抽奖记录。

### 15.2 十连中途触发保底

例如玩家在英雄池传奇计数为75时进行十连：

- 第1抽按第76抽概率计算。
- 如果第3抽获得传奇，则传奇计数归零。
- 后续第4～10抽从新的第1～7抽重新计数。
- 结果界面必须按真实顺序排列。

### 15.3 资源消耗

资源扣除在抽奖事务开始时执行：

- 优先使用对应抽奖券。
- 不足部分使用航海晶石补齐。
- 资源不足则不发送抽奖请求。
- 抽奖服务失败时原路返还。
- 已经获得结果但客户端断线时，不重复扣款或重复抽奖。

## 18. 英雄重复获取与进阶

### 18.1 首次与重复获取

首次获得英雄：

- 解锁可用英雄。
- 播放完整首次获得演出。
- 加入英雄列表。
- 不自动进阶。

重复获得英雄：

- 不生成第二个可独立上阵的同名英雄。
- 记录为“该英雄同名副本 ×1”。
- 结果页继续显示该英雄头像和名称。
- 明确提示可用于进阶。

### 18.2 英雄进阶等级

每名英雄拥有0～6阶：

| 阶位 | 同名副本消耗 | 效果 |
| ---: | ---: | --- |
| 0→1 | 1 | 基础全属性+3% |
| 1→2 | 1 | 基础全属性+3% |
| 2→3 | 1 | 基础全属性+3% |
| 3→4 | 1 | 基础全属性+3% |
| 4→5 | 1 | 基础全属性+3% |
| 5→6 | 1 | 基础全属性+3% |

满阶累计：

`英雄基础全属性 +18%`

### 18.3 “全属性”的精确定义

英雄进阶提升六项英雄基础属性：

- 体魄。
- 火力。
- 防护。
- 操舰。
- 技术。
- 感知。

计算公式：

```text
英雄进阶后基础属性
= 英雄等级基础属性 ×（1 + 进阶阶数 × 3%）
```

进阶不直接乘算：

- 装备属性。
- 天赋百分比。
- 被动技能固定数值。
- 舰体基础属性。
- 其他英雄贡献。

这样可以实现“整体提升全部属性”，同时避免多层乘法失控。

### 18.4 进阶不解锁内容

进阶不再：

- 解锁等级上限。
- 解锁技能槽。
- 解锁被动槽。
- 解锁天赋点。
- 解锁装备部位。
- 改变英雄能否使用。

技能、天赋、被动槽继续由等级、任务和角色成长解锁。

## 19. 主舰重复获取与进阶

### 19.1 重复舰体

首次获得舰体：

- 解锁该舰体所有权。
- 可以放入任意已解锁主舰编制席位。

重复获得：

- 记录为该舰体同名副本。
- 不自动生成可同时部署的第二艘同型主舰。
- 用于该舰体进阶。

### 19.2 舰体进阶

同样采用0～6阶：

| 阶位 | 同名副本 | 效果 |
| ---: | ---: | --- |
| 每一阶 | 1 | 舰体基础全属性+3% |
| 满6阶 | 共6个 | 舰体基础全属性+18% |

提升的舰体基础属性包括：

- 基础耐久。
- 基础护盾。
- 基础防护。
- 基础航速。
- 基础转向。
- 基础能源。
- 基础载重。
- 基础维修效率。

### 19.3 舰体进阶不乘算英雄

```text
最终舰组属性
= 进阶后的舰体基础属性
+ 英雄换算贡献
+ 模块
+ 船规
+ 其他加成
```

舰体进阶只提升舰体自身基础部分，不额外乘算五名英雄的贡献。

## 20. 等级上限与阶位彻底解耦

### 20.1 新等级规则

- 英雄首版版本等级上限仍为60。
- 所有已拥有英雄都可以直接升到版本等级上限。
- 不要求阶位。
- 不要求同名英雄。
- 不再每10级执行突破。
- 升级只消耗英雄经验和通用金币。
- 特定技能或天赋可以要求等级和角色任务，但不能要求抽到重复英雄。

### 20.2 旧突破规则废止

旧规则：

> 每10级消耗英雄信物、职业材料和海域资源，解锁下一等级上限。

新规则：

> 等级不再分段封锁；同名副本只用于独立进阶，进阶只提升基础全属性。

### 20.3 旧资源迁移

如果项目中已经实现旧资源：

| 旧资源 | 新处理 |
| --- | --- |
| 专属英雄信物 | 按英雄归属转为同名副本进度 |
| 通用英雄信物 | 转为英雄溢出凭证 |
| 职业突破材料 | 转为技能学习/天赋材料 |
| 已完成突破阶数 | 映射为对应进阶阶数，最高不超过6 |
| 突破解锁等级上限 | 直接解除 |

迁移后不得降低英雄当前等级。

## 21. 满阶后的重复内容

### 21.1 溢出规则

英雄满6阶后再次抽到：

- 转为英雄溢出凭证。

舰体满6阶后再次抽到：

- 转为舰体溢出凭证。

不同品质获得：

| 品质 | 溢出凭证 |
| --- | ---: |
| 稀有 | 10 |
| 史诗 | 40 |
| 传奇 | 120 |

### 21.2 溢出商店

英雄溢出商店：

- 稀有英雄自选同名副本。
- 史诗英雄轮换同名副本。
- 传奇英雄自选进阶凭证碎片。
- 英雄培养材料。

舰体溢出商店：

- 稀有舰体自选同名副本。
- 史诗舰体轮换同名副本。
- 传奇舰体自选进阶凭证碎片。
- 舰体研究材料。

### 21.3 通用进阶凭证限制

- 通用凭证不能直接替代首次获得。
- 只有已经拥有对象时才能使用。
- 传奇自选凭证需要较高兑换成本。
- 不允许付费商城无限直售通用传奇凭证。
- 溢出商店按月刷新，但未消耗凭证永久保留。

## 22. 主舰编制席位与舰体所有权

### 22.1 重新定义海域奖励

旧规则“每占领1块海域解锁1艘主舰”改为：

> 每占领1块新海域，解锁1个主舰编制席位，最多6个。

海域解锁的是：

- 舰队调度容量。
- 同时部署的主舰数量。
- 对应主舰任务队列。

不是：

- 某个特定付费舰体。
- 随机传奇舰体。
- 重复舰体进阶。

### 22.2 席位解锁保底舰体

为了避免有席位但没有船：

- 初始赠送1艘基础主舰。
- 第2～6席位解锁时，各赠送1个基础舰体选择箱。
- 选择箱包含2～3种非抽奖限定基础舰体。
- 已拥有时可以选择另一艘，或转为对应同名副本。

### 22.3 同型舰体限制

首版建议：

- 同一舰体所有权只记录一次。
- 同一舰体不能同时占用两个主舰席位。
- 重复获得用于进阶，不生成第二个部署实例。
- 以后如需要同型量产舰，单独设计“量产型号”，不与抽奖副本混用。

## 36. 商城购买流程

### 36.1 状态机

```text
Idle
→ OfferSelected
→ Confirming
→ Submitting
→ ServerValidated
→ Granted
→ Completed
```

异常：

```text
Submitting
├── FailedAndRefunded
├── TimeoutPendingQuery
└── AlreadyCompleted
```

### 36.2 事务原则

- 每次购买生成唯一事务ID。
- 扣款和发货必须处于同一个服务端事务。
- 重复请求只能返回原结果。
- 客户端超时后先查询，不能直接再次购买。
- 商品刷新不能改变已经创建的事务。
- 背包满时英雄和舰体不受影响；装备进入临时收件箱。

## 37. 抽奖服务逻辑

### 37.1 服务端权威

正式版本：

- 概率配置由服务端下发。
- 随机结果由服务端生成。
- 保底状态保存在服务端。
- 客户端只负责请求和演出。
- 抽奖结果先落库，再返回客户端。

### 37.2 本地原型

原型阶段允许本地模拟，但必须：

- 使用固定配置版本。
- 每次抽取写入日志。
- 可设置随机种子。
- 可批量模拟100万抽验证概率。
- 不把本地测试逻辑直接带入正式支付版本。

### 37.3 抽奖幂等

请求包含：

- AccountId。
- PoolId。
- PoolVersion。
- DrawCount。
- TransactionId。
- ClientKnownPityVersion。

相同TransactionId重复提交只返回首次结果。

- 已售罄：降低饱和度，保留内容可查看。
- 时间不足：只在剩余24小时内使用轻微倒计时强调。

### 41.2 货币变化

- 数字滚动到新值。
- 消耗时出现短暂`-160`浮字。
- 图标不持续闪烁。
- 余额不足时资源胶囊短暂变红一次。

### 41.3 购买成功

- 商品图标飞入对应背包入口。
- 英雄或舰体首次获得播放首次演出。
- 重复对象显示“同名副本+1”。
- 不使用连续多层“恭喜获得”弹窗。

### 41.4 防误触

- 提交后立即禁用按钮。
- 弹窗确认按钮需要100ms以上稳定展示后才响应。
- 触摸设备按钮热区不小于44×44逻辑像素。
- 返回键不能在支付处理中直接关闭页面。

## 42. 新手商业化流程

### 42.1 前30分钟

- 不主动弹出充值。
- 通过任务获得基础5人舰组。
- 解锁英雄池。
- 赠送10张英雄招募券。
- 教学一次单抽和一次十连入口。
- 教学概率、保底、重复进阶。

### 42.2 占领第一块海域

- 解锁第2主舰编制席位。
- 赠送基础舰体选择箱。
- 解锁主舰池。
- 赠送2张主舰建造券。
- 教学“席位”和“舰体所有权”不是同一件事。

### 42.3 首次重复英雄

显示简短教学：

```text
重复英雄已转化为同名副本。
同名副本用于进阶，进阶不会限制英雄等级。
```

### 42.4 首次进入商城

强调：

- 商城装备是固定过渡装备。
- 最强装备来自海域特殊玩法。
- 英雄和主舰也存在任务与特殊玩法来源。

## 43. 数值平衡边界

### 43.1 进阶战力占比

英雄满阶为基础属性+18%，但作用于完整舰组后的实际总提升应控制：

- 单名英雄0阶到6阶，对完整舰组总战力提升约3%～6%。
- 五名英雄全部满阶，对完整舰组总战力提升约15%～25%。
- 单艘舰体0阶到6阶，对完整舰组总战力提升约6%～10%。

实际数值通过属性换算率调整。

### 43.2 商城装备边界

- 商城史诗套达到同期普通高难玩法约70%～80%的装备强度。
- 可以完成主线和常规海域。
- 不能替代高危航线和世界Boss装备。
- 不能出现同时覆盖多流派的万能毕业套。

### 43.3 角色与舰体边界

传奇不等于所有数值最高：

- 传奇提供更独特机制或复杂组合。
- 史诗可以在专门场景中优于传奇。
- 直售史诗必须能长期使用。
- 免费任务英雄必须存在清晰后期用途。

## 44. 免费玩家完整性

不付费玩家必须能够：

- 获得完整5人初始舰组。
- 解锁6个主舰编制席位。
- 获得6艘可用基础舰体。
- 持续获得两种抽奖券。
- 参与所有海域玩法。
- 获得传奇装备和独特效果。
- 获得部分传奇英雄和主舰。
- 完成主线、占领海域和挑战高危内容。

付费主要提高：

- 收藏速度。
- 目标获得确定性。
- 进阶速度。
- 基础材料和过渡装备成型速度。

## 45. 运营与内容轮换

### 45.1 英雄池周期

- 推荐每期21～28天。
- 每期1名精选传奇。
- 同期可加入2～3名史诗概率提升。
- 史诗提升必须显示各自概率。

### 45.2 主舰池周期

- 推荐每期28～42天。
- 舰体内容制作成本更高，轮换可以更慢。
- 每期1艘精选传奇。

### 45.3 商城轮换

- 与抽奖池不完全同步。
- 当期精选传奇不同时在商城直售。
- 商城可以上架适合搭配当期精选的非顶级英雄或舰体。
- 不出售“抽到A后必须再买B才能使用”的强制组合。

## 47. 风险与防止系统失控

### 47.1 装备动力被商城破坏

风险：

- 商城史诗套过强，玩家不再刷装备。

控制：

- 固定词条。
- 无传奇独特效果。
- 无特殊玩法词条。
- 强度低于同期高难掉落。

### 47.2 抽奖内容过少

风险：

- 主舰数量少，重复率过高。

控制：

- 主舰保底较短。
- 首次席位赠送基础选择箱。
- 满阶溢出可兑换目标。
- 首版舰体池至少准备足够的稀有和史诗舰体。

### 47.3 六舰养成压力过大

控制：

- 免费基础英雄和舰体足够填满前期席位。
- 训练追赶机制保留。
- 商城只补缺口。
- 不要求六舰全部满阶才能参与玩法。

### 47.4 进阶成为硬门槛

控制：

- 关卡推荐以0～2阶阵容为基准。
- 高阶只提供容错和效率。
- 不设置“必须达到4阶才能进入”。
- 技能核心机制不锁在重复进阶中。

## 48. 概率与消费透明规则

正式上线前必须满足：

- 抽取按钮附近能打开概率详情。
- 明确显示每个品质概率。
- 明确显示当期精选实际概率。
- 明确显示硬保底次数。
- 明确显示软保底逐抽变化。
- 明确显示精选保证。
- 明确显示保底是否跨轮换继承。
- 明确显示两个池子互不共享。
- 明确显示单抽和十连概率一致。
- 使用航海晶石时显示晶石和本地货币关系。
- 显示抽奖历史。
- 显示重复对象转化。
- 提供未成年人、家长控制、退款和客服入口。

Apple要求提供付费随机物品的应用在购买前披露各类物品概率；Google Play也要求在购买前、且在购买行为附近清楚披露随机虚拟物品的获得概率。美国FTC在2025年的相关执法说明中也特别强调了真实成本、多层虚拟货币换算、稀有奖励概率和未成年人购买控制的风险。因此本项目不应只把概率放在官网，也不应隐藏航海晶石与真实支付价格的关系。

## 51. 完整验收清单

### 51.1 货币

- [ ] 航海晶石是唯一充值货币。
- [ ] 两类券不能互相使用。
- [ ] 券不足时明确显示晶石补差。
- [ ] 正式包不存在作弊按钮。
- [ ] 每次货币变化有事务记录。

### 51.2 商城

- [ ] 所有商城商品只使用航海晶石。
- [ ] 商城不出售传奇毕业装备。
- [ ] 商城装备属性购买前完全可见。
- [ ] 商城英雄和舰体不是当前最强内容。
- [ ] 基础材料有每日或每周限购。
- [ ] 商品刷新和下架时间清楚。

### 51.3 英雄池

- [ ] 只产出英雄。
- [ ] 单抽和十连共享保底。
- [ ] 10抽至少史诗。
- [ ] 80抽传奇硬保底。
- [ ] 软保底曲线按配置执行。
- [ ] 精选保证跨英雄池轮换继承。

### 51.4 主舰池

- [ ] 只产出主舰舰体。
- [ ] 与英雄池使用不同券。
- [ ] 与英雄池保底独立。
- [ ] 10抽至少史诗。
- [ ] 60抽传奇硬保底。
- [ ] 精选保证跨主舰池轮换继承。

### 51.5 重复进阶

- [ ] 首次获得解锁对象。
- [ ] 重复获得生成同名副本。
- [ ] 每阶只消耗1个同名副本。
- [ ] 英雄满阶基础全属性累计+18%。
- [ ] 舰体满阶基础全属性累计+18%。
- [ ] 进阶不限制等级上限。
- [ ] 满阶重复会转为溢出凭证。

### 51.6 等级解耦

- [ ] 所有英雄可升到版本等级上限。
- [ ] 不再每10级突破。
- [ ] 技能槽和被动槽不要求重复抽取。
- [ ] 旧突破资源有迁移规则。

### 51.7 主舰席位

- [ ] 占领海域解锁的是编制席位。
- [ ] 舰体所有权来自抽奖、任务、特殊玩法或商城。
- [ ] 第2～6席位各有基础舰体选择箱。
- [ ] 同型舰体不能同时占两个席位。

### 51.8 UI

- [ ] 顶部资源使用图标+名称+数字。
- [ ] 抽奖页常驻显示保底进度。
- [ ] 抽取按钮显示准确消耗。
- [ ] 结果页显示新获得、重复和溢出。
- [ ] 概率详情在购买附近可打开。
- [ ] 抽奖历史按两个池子分开。
- [ ] 商城商品有完整属性和来源说明。

### 51.9 安全与事务

- [ ] 支付由服务端验证。
- [ ] 抽奖结果由服务端生成。
- [ ] 保底由服务端保存。
- [ ] 重复请求不会重复扣款。
- [ ] 断线后可以查询原结果。
- [ ] 概率配置版本不一致时禁止抽取。

## 52. 推荐首轮实现范围

如果当前目标是尽快把商业化逻辑跑通，首轮只做：

1. 航海晶石和开发作弊按钮。
2. 英雄招募券、主舰建造券。
3. 商城的英雄、主舰、装备、材料、券五类静态商品。
4. 英雄池1个精选英雄。
5. 主舰池1个精选舰体。
6. 单抽、十连、10抽史诗保底。
7. 英雄80抽、主舰60抽传奇保底。
8. 两池独立历史记录。
9. 重复对象0～6阶进阶。
10. 英雄等级上限与进阶解耦。
11. 满阶重复转化。
12. 完整概率页和消耗确认。

先不要做：

- 多个并行限定池。
- 装备池。
- 复杂月卡。
- 订阅制。
- 多层礼包嵌套。
- 付费排行榜。

这一首轮完成后，商业化核心闭环已经成立：

```text
玩法获得抽奖券
→ 英雄/主舰抽取
→ 首次获得扩展舰组
→ 重复获得用于进阶
→ 满阶溢出进入兑换
→ 新阵容继续参与海域玩法
→ 装备仍从战斗和特殊玩法长期刷取
```
