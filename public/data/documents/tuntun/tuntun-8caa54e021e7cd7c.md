## 1. 本次深化目标

旧版港口已经拥有地基、生产、防御、自动战斗和主舰养成的骨架，本次重点解决四个问题：

### 1.1 防御建筑只看数值，没有真正差异

新的防御体系要求：

- 每种建筑都有明确目标类型。
- 存在不能覆盖的盲区和弱点。
- 射程、射界、弹道、转向、穿透、控制和攻击频率共同决定用途。
- 高级建筑不是低级建筑的纯数值替代。
- 玩家需要根据下一轮敌人组成调整布局。

### 1.2 造船厂只有“自动放出小船”，缺少长期养成

新的造船厂需要同时承担：

- 解锁舰船蓝图。
- 制造守卫舰。
- 扩充生产队列。
- 增加同时制造数量。
- 提升港口可部署舰数。
- 修理、改装和编队守卫舰。
- 为玩家提供可观察的制造过程。

### 1.3 建造玩法只有摆放，没有长期决策

新的建筑玩法增加：

- 军事区、生产区、生活区和船坞区。
- 攻击射界、交叉火力和水道设计。
- 邻接、区域加成和供给覆盖。
- 建筑模块与升级分支。
- 建筑蓝图、研究和港口工程项目。
- 防守方案预设与布局测试。

### 1.4 成长存在突然卡住或等待过久的问题

新的成长节奏要求：

- 玩家每5～10分钟至少完成一次可见成长。
- 新建筑先试用，再通过蓝图长期解锁。
- 卡关时明确告诉玩家缺少的是火力、承伤、控制还是后勤。
- 自动刷取能够积累升级资源。
- 主动出击可以定向获取当前缺少的材料。
- 建造、船厂和主舰三条成长线交替推进，不要求同时全部升级。

## 2. 港口战斗的基础克制框架

## 2.1 敌人尺寸

| 尺寸 | 示例 | 特点 | 主要应对 |
| --- | --- | --- | --- |
| 微型 | 爆破筏、鱼群、无人机 | 数量极多、生命极低 | 机枪、火焰、电弧 |
| 小型 | 小舟、冲撞舟、鲨鱼 | 速度快、容易穿过火力网 | 速射、霰弹、渔网 |
| 中型 | 炮艇、布雷艇、补给船 | 数值均衡、数量适中 | 火炮、鱼叉、导弹 |
| 大型 | 重甲舰、巨鲸、攻城舰 | 生命和护甲高、速度慢 | 重炮、鱼雷、穿甲 |
| 巨型 | Boss旗舰、海怪 | 模块多、机制复杂 | 多类建筑协同 |

## 2.2 防护类型

首版使用四类防护，避免伤害类型过多：

| 防护 | 特征 | 弱点 |
| --- | --- | --- |
| 轻型船体 | 生命低、速度快 | 速射、火焰、范围攻击 |
| 厚木船体 | 生命高、怕燃烧 | 火焰、爆炸 |
| 金属装甲 | 减免普通小口径伤害 | 穿甲炮、鱼雷、雷电 |
| 生物躯体 | 无装甲、生命恢复较强 | 火焰、流血、持续伤害 |

## 2.3 五种伤害标签

伤害标签主要用于克制与表现，不要求玩家计算复杂公式：

| 标签 | 玩法特点 |
| --- | --- |
| 轻弹 | 高频、追踪快、容易被重甲减免 |
| 炮击 | 中低频、冲击强、适合中型目标 |
| 穿甲 | 对重甲和大型目标有效，容易过度击杀小怪 |
| 爆炸 | 范围伤害，适合集群，可能有最小射程 |
| 元素 | 燃烧、雷电、减速等机制效果 |

## 2.4 防御建筑的六种职责

每个防御建筑必须至少属于一种职责，但不能同时把所有职责做满：

1. 拦截：快速消灭微型、小型敌人。
2. 反重甲：处理大型舰、重甲舰和Boss模块。
3. 范围压制：打击密集编队。
4. 近岸封锁：阻止敌人贴近港口。
5. 控制：减速、拉扯、击退、暴露弱点。
6. 支援：维修、供弹、护盾、侦察和强化。

## 3. 防御建筑通用规则

## 3.1 射界

防御塔不再全部360°无条件攻击。

| 射界类型 | 规则 | 适合建筑 |
| --- | --- | --- |
| 全向 | 可攻击四周，转向时间较长 | 机枪塔、雷暴塔 |
| 前方扇形 | 只能攻击朝向前方的区域 | 喷火塔、霰弹塔、重炮 |
| 沿岸直线 | 只能攻击面向外海的狭长区域 | 鱼雷台、轨道炮 |
| 抛物线全向 | 可越过低矮建筑，但有最小射程 | 迫击炮、导弹塔 |
| 区域连接 | 多个节点形成伤害区域 | 电网、渔网、声呐浮标 |

放置时必须显示：

- 最大射程圈。
- 最小射程圈。
- 当前朝向。
- 可攻击扇区。
- 被大型建筑遮挡的区域。
- 对空、对水面或对水下标签。

## 3.2 索敌优先级

每座塔可以选择一个优先策略：

- 距离最近。
- 生命最低。
- 速度最快。
- 体型最大。
- 护甲最高。
- 正在冲撞。
- 正在攻击核心。
- 玩家手动标记目标。

建筑默认策略由类型决定，例如：

- 机枪塔默认攻击速度最快的小型单位。
- 重炮默认攻击护甲最高的大型单位。
- 鱼叉塔默认攻击正在冲撞或接近内圈的目标。
- 防空塔默认攻击导弹，其次攻击无人机。

## 3.3 转向与锁定

塔的实际输出不能只由射速决定：

```text
实际开火周期 =
索敌时间
+ 转向时间
+ 瞄准时间
+ 发射间隔
+ 装填或冷却
```

- 机枪塔转向快，适合频繁切换目标。
- 重炮转向慢，目标死亡后会损失一段重新瞄准时间。
- 导弹塔转向需求低，但弹体飞行时间长，可能打空。
- 鱼雷台无法快速改变发射方向。

## 3.4 过量伤害控制

多个重炮不能全部把炮弹浪费在一只残血小舟上。

系统需要记录“飞行中的预计伤害”：

```text
目标预计剩余生命 =
当前生命
- 已发射且预计命中的伤害
```

当预计剩余生命小于0时：

- 其他防御塔优先切换目标。
- 持续锁定型武器立即寻找新目标。
- 范围武器仍可攻击该区域，只要区域内还有其他目标。

## 3.5 建筑耐久与失效

- 防御建筑生命归零后，本轮失效。
- 建筑不会永久消失。
- 失效建筑停止攻击，模型进入损坏状态。
- 战后消耗维修材料与时间恢复。
- 同一建筑连续多轮损坏会积累“疲劳”，使维修时间略微增加。
- 使用一次完整保养可清除疲劳。
- 已通关的稳定刷取轮次可降低维修消耗，避免挂机收益被维修完全吃掉。

## 4. 基础实弹防御建筑

## 4.1 速射机枪塔

定位：清理微型、小型单位，最基础的反集群防御。

| 属性 | 规则 |
| --- | --- |
| 射程 | 中近 |
| 射界 | 360° |
| 攻速 | 极快 |
| 单发伤害 | 低 |
| 转向 | 快 |
| 弱点 | 对金属重甲几乎无效 |

特殊规则：

- 连续攻击同一目标1秒后，命中率逐步提高。
- 切换目标会重置稳定射击加成。
- 适合放在水道转角或港口内圈补漏。

升级分支：

- “双联枪座”：弹丸数量增加，更擅长清群。
- “穿甲枪芯”：攻速略降，可对中型金属目标造成一定伤害。

## 4.2 近防拦截塔

定位：专门拦截敌方导弹、无人机、飞行炸弹和抛射物。

规则：

- 不优先攻击普通船体。
- 对进入拦截半径的敌方投射物高速开火。
- 每次拦截消耗拦截弹储备。
- 没有威胁投射物时才会攻击微型敌人。

升级分支：

- “密集阵”：拦截频率提高，拦截半径缩小。
- “广域预警”：拦截范围提高，同时为附近建筑提高导弹预警时间。

## 4.3 霰弹防浪塔

定位：近距离一次打击多个小型目标，防止小舟和鲨鱼突破。

规则：

- 前方80°扇形。
- 距离越近，命中的弹丸越多。
- 对贴脸的小型敌人有短暂击退。
- 射程短、装填中等，无法处理远程炮艇。

升级分支：

- “扩散弹巢”：扇形更宽、击退更强。
- “重型独头弹”：扇形变窄，可重创中型目标。

## 4.4 单管火炮塔

定位：通用中距离炮塔，是中前期稳定主力。

规则：

- 中等伤害、中等射程、中等装填。
- 对小舟容易产生过量伤害。
- 能够切换普通弹和轻型爆炸弹。
- 适合成组布置形成交叉火力。

升级分支：

- “双联炮”：单轮两发，持续输出更稳定。
- “长身炮”：射程和精度提高，转向速度下降。

## 4.5 重型穿甲炮塔

定位：远距离拆除重甲舰、攻城舰和Boss装甲模块。

规则：

- 射程远，最小射程明显。
- 炮塔转向慢，无法追踪快速贴近的小舟。
- 穿透目标后可以继续伤害后方一个目标。
- 对轻型目标伤害溢出严重。

升级分支：

- “破城炮”：对建筑、Boss模块和护盾发生器增伤。
- “贯穿炮”：穿透数量提高，适合直线舰队。

## 4.6 旋转链炮塔

定位：介于机枪与火炮之间，持续压制中小型敌人。

规则：

- 开火前需要预热。
- 持续射击时攻速越来越快。
- 停火后转速逐步下降。
- 长时间射击会过热并强制冷却。

升级分支：

- “水冷枪管”：过热上限和持续射击时间提高。
- “高爆弹链”：降低攻速，使命中产生小范围爆炸。

## 5. 近距离封锁建筑

## 5.1 焚海喷火塔

定位：近距离封锁狭窄水道，克制木船、生物和密集小舟。

| 属性 | 规则 |
| --- | --- |
| 射程 | 极近 |
| 射界 | 前方扇形 |
| 伤害 | 持续范围伤害 |
| 状态 | 叠加燃烧 |
| 弱点 | 无法攻击远程敌人，怕重甲 |

防止无限强控规则：

- 火焰每0.25秒结算一次伤害。
- 燃烧持续3秒，重复命中刷新持续时间，但每个来源只叠加有限层数。
- 燃烧中的爆破筏可能提前爆炸，玩家需要注意摆放位置。

升级分支：

- “黏性燃油”：燃烧持续更久，水面留下短时火区。
- “高压喷焰”：射程变长、扇形变窄，可烧穿部分护甲。

## 5.2 沸水蒸汽塔

定位：近距离减速和持续伤害，不引爆易燃单位。

规则：

- 对生物敌人额外有效。
- 使目标转向和攻击频率降低。
- 不产生燃烧，可与火焰塔形成不同选择。
- 对金属重甲直接伤害较低，但能使其“过热”，降低攻击速度。

升级分支：

- “高压冲洗”：附带推力，阻挡冲撞舟。
- “灼热雾幕”：范围扩大，为区域内敌人附加命中率降低。

## 5.3 旋刃防撞桩

定位：无主动射击的贴身反冲撞建筑。

规则：

- 敌人接触时造成一次碰撞伤害和流血。
- 同一敌人离开接触范围并经过冷却后才能再次触发。
- 自身承受部分冲击伤害。
- 不需要弹药，但需要较高维修。

升级分支：

- “倒钩桩”：使撞上的敌人短暂卡住。
- “弹性撞角”：反弹敌人并降低自身受到的冲击。

## 5.4 爆燃油沟

定位：玩家预先布置的近岸范围陷阱。

规则：

- 由点火塔或玩家手动触发。
- 点燃一条水道，持续数秒。
- 战斗中触发后需要重新装填。
- 不能与生活区和木质生产区过近。

升级分支：

- “连锁油槽”：可串联多个油沟一起点燃。
- “缓释燃油”：范围较小，但持续时间更长。

## 6. 范围与间接火力建筑

## 6.1 爆炸迫击炮

定位：跨越前排建筑打击远处集群。

规则：

- 抛物线弹道。
- 有较大最小射程。
- 发射时锁定落点，不持续追踪目标。
- 敌人移动过快可能离开爆炸区。
- 对被渔网、鱼叉或减速区控制的目标非常有效。

升级分支：

- “重型炮弹”：范围和伤害提高，飞行时间更长。
- “快速校射”：落点预判更准确，装填加快。

## 6.2 垂直导弹塔

定位：超远程支援，可跨区攻击高威胁目标。

规则：

- 需要雷达提供完整索敌时，才可攻击超视距目标。
- 导弹升空后再转向目标区域。
- 飞行时间长，可能被敌方近防拦截。
- 对密集的中型舰队和Boss模块有效。

升级分支：

- “蜂群导弹”：一次发射多枚小导弹，适合多目标。
- “攻城导弹”：单枚巨大导弹，对建筑和Boss模块增伤。

## 6.3 火箭弹幕架

定位：在一条宽阔区域进行不精确火力覆盖。

规则：

- 短时间连续发射多枚火箭。
- 精度低、范围大。
- 适合敌人刚出现或集中通过外圈水道时使用。
- 完成一轮齐射后需要长时间装填。

升级分支：

- “密集覆盖”：火箭数量增加。
- “校准弹幕”：数量降低，落点更集中。

## 6.4 深水炸弹投放塔

定位：对潜水艇、水下鱼雷和水下海兽。

规则：

- 只在临水地基或外圈平台建造。
- 自动向侦测到的水下目标投放炸弹。
- 对水面舰船伤害较低。
- 需要声呐浮标才能提前发现隐蔽水下目标。

升级分支：

- “连环深弹”：多段爆炸，持续封锁水域。
- “追踪深弹”：范围缩小，但会缓慢追向水下目标。

## 7. 反大型与专用防御建筑

## 7.1 鱼雷发射台

定位：沿直线攻击大型舰和巨型海兽。

规则：

- 必须建在港口外缘，前方需要连续水面。
- 有保险距离，太近的敌人不会触发鱼雷爆炸。
- 鱼雷直线移动，不能穿过友方挡板。
- 对大型目标高伤害，对小舟容易打空。
- 被敌方拦截网命中时可能提前引爆。

升级分支：

- “重型鱼雷”：速度降低、爆炸和穿甲提高。
- “制导鱼雷”：伤害降低，可小幅修正方向。

## 7.2 捕鲸鱼叉塔

定位：控制大型海兽、冲撞舰和逃跑单位。

规则：

- 命中后连接绳索。
- 绳索持续期间降低目标速度和转向。
- 目标离开最大距离或障碍切断绳索时效果结束。
- 同一目标受到多条绳索时，减速收益递减。

升级分支：

- “重锚鱼叉”：拉扯更强，对冲撞舰额外有效。
- “放血倒钩”：控制降低，附加持续流血。

## 7.3 磁轨穿舰炮

定位：后期直线贯穿型终极防御。

规则：

- 只能攻击前方狭窄直线。
- 充能时间长，发射前有明显红色瞄准线。
- 贯穿多个敌人和部分护盾。
- 发射后进入长冷却并消耗大量战备供给。

升级分支：

- “超载线圈”：伤害和贯穿提高，冷却更长。
- “快速电容”：伤害降低，充能和冷却缩短。

## 7.4 海兽猎杀弩

定位：专门猎杀大型生物，较弱于金属舰船。

规则：

- 命中生物后附加流血标记。
- 同一目标身上的猎杀标记达到层数时触发一次弱点伤害。
- 对金属目标只能造成基础冲击。
- 可与鱼叉控制形成组合。

升级分支：

- “毒性弩矛”：抑制海兽生命恢复。
- “猎鲸巨矛”：对生命值高于70%的巨型生物额外伤害。

## 8. 元素与控制防御建筑

## 8.1 雷暴桅杆

定位：对密集敌人弹射雷电，克制金属编队。

规则：

- 雷电可在附近目标间弹射。
- 同一个目标单次攻击最多被命中一次。
- 敌人越密集，利用率越高。
- 对单个Boss的基础伤害一般，但能干扰其模块。

升级分支：

- “链式雷暴”：弹射次数增加。
- “蓄能雷击”：弹射减少，首个目标受到高额伤害和短暂麻痹。

## 8.2 冰雾冷却塔

定位：制造减速区域，为迫击炮和重炮争取命中时间。

规则：

- 周期性喷出低温雾气。
- 区域内敌人移动和转向降低。
- 不持续造成高伤害。
- 同类冰雾只刷新持续时间，不无限叠加减速。

升级分支：

- “广域冰雾”：范围扩大。
- “冻结脉冲”：范围缩小，周期性使小型目标短暂停止。

## 8.3 声波驱离塔

定位：击退冲撞舟、鲨鱼群和已经接近港口的敌人。

规则：

- 周期性释放扇形声波。
- 伤害低，击退和打断强。
- 大型目标只会被减速，不会大幅位移。
- 对正在蓄力冲撞的敌人可打断蓄力。

升级分支：

- “高频震荡”：伤害和打断能力提高。
- “低频巨浪”：范围和击退提高，攻击间隔变长。

## 8.4 渔网投射塔

定位：限制小型高速单位。

规则：

- 向目标区域发射渔网。
- 小型敌人被强减速，中型敌人轻度减速，大型敌人不受束缚。
- 渔网有生命值，可被敌人攻击或燃烧摧毁。
- 对火焰攻击覆盖区域使用时，渔网会更快损坏。

升级分支：

- “加重铁网”：对中型目标控制提高。
- “多重撒网”：一次覆盖多个小区域。

## 8.5 诱饵灯塔

定位：改变部分敌人的攻击路线，为核心区争取时间。

规则：

- 周期性对可被诱导的敌人产生高仇恨。
- Boss、指挥舰和部分精英免疫。
- 诱饵塔自身防御低，需要挡板或维修塔保护。
- 敌人摧毁诱饵后会重新选择路线。

升级分支：

- “海兽气味”：优先吸引海洋生物。
- “伪造信号”：优先吸引导弹、无人机和智能舰船。

## 9. 防御支援建筑

## 9.1 弹药补给站

定位：提高周围实弹类炮塔的持续作战能力。

功能：

- 提高装填速度。
- 降低战后战备供给消耗。
- 允许附近炮塔使用高级弹药模块。
- 补给范围内的炮塔过多时，效果按负载衰减。

升级分支：

- “快速装填线”：强化射速。
- “特种弹药库”：解锁穿甲、燃烧或爆破弹种。

## 9.2 瞄准指挥塔

定位：强化远程炮塔的命中、索敌和目标分配。

功能：

- 增加射程，但不超过各塔上限。
- 减少导弹和迫击炮对移动目标的预判误差。
- 减少多座重炮对同一残血目标的过量攻击。
- 可设置一个全区优先目标。

升级分支：

- “炮术计算室”：提升火炮、迫击炮精度。
- “舰队雷达室”：提升导弹、近防和守卫舰索敌。

## 9.3 战地维修塔

定位：战斗中缓慢修复附近建筑。

规则：

- 同一建筑受到多个维修塔时，额外效率递减。
- 建筑刚受到伤害后的1秒内，维修效率降低，防止完全抵消爆发。
- 自身不能维修自己。
- 优先维修挡板、失血最多的防御塔或玩家指定目标。

升级分支：

- “快速抢修”：低生命目标维修更快。
- “预防维护”：为满生命建筑提供少量减伤层。

## 9.4 消防与损管站

定位：处理燃烧、腐蚀、漏水和建筑失效。

功能：

- 缩短附近建筑的负面状态。
- 阻止燃烧在相邻木质建筑间扩散。
- 战后降低维修时间。
- 对纯直接伤害没有明显帮助。

## 9.5 区域护盾发生器

定位：抵挡远程炮火和导弹齐射。

规则：

- 为范围内建筑共享一层护盾。
- 护盾破裂后需要长时间充能。
- 对进入护盾内部的近战、冲撞和喷火伤害无效或效果较弱。
- 多个护盾范围重叠时只使用最强的一层。

升级分支：

- “广域穹顶”：范围提高、护盾总量降低。
- “坚固壁垒”：范围缩小、护盾和恢复提高。

## 9.6 声呐侦测站

定位：发现潜水艇、水下海兽、隐形快艇和远程威胁。

功能：

- 提前显示来袭方向。
- 解除一定范围内的隐蔽。
- 提高鱼雷台、深水炸弹和守卫舰的索敌距离。
- 提供下一轮敌人更完整的侦察报告。

## 9.7 战斗指挥所

定位：军事区的高级核心建筑。

功能：

- 解锁区域集火指令。
- 允许保存防守编队和炮塔优先级预设。
- 提高守卫舰复活或重新出航效率。
- 每个港口同时只允许一个主指挥所生效。

## 10. 挡板、城墙与水道设施

## 10.1 防御挡板不再只是高生命墙

| 建筑 | 主要作用 | 弱点 |
| --- | --- | --- |
| 浮木挡板 | 低成本拖延小舟 | 怕火、怕爆炸 |
| 加固木墙 | 中期通用承伤 | 仍然怕持续燃烧 |
| 铁甲挡板 | 抗轻弹、抗冲撞 | 维修消耗较高 |
| 斜面防撞墙 | 把冲撞敌人偏转到两侧 | 对炮击防护一般 |
| 尖刺墙 | 反伤贴身单位 | 容易被远程拆除 |
| 吸能挡板 | 减少爆炸和声波伤害 | 抗穿甲较弱 |
| 防鱼网墙 | 阻挡海兽和微型单位 | 可被火焰烧毁 |
| 活动闸门 | 允许友军与主舰出入 | 结构复杂、生命较低 |
| 模块化堡垒墙 | 可安装近防或修理模块 | 占地和承重较高 |

## 10.2 路线设计规则

- 港口不能完全封死全部水路。
- 敌人至少拥有一条可计算的水上路径。
- 玩家可以用挡板、诱饵和狭窄水道延长敌人路径。
- 过窄水道会降低友方守卫舰通行效率。
- 大型Boss可以撞毁部分普通挡板，不能靠迷宫永久困住。
- 路线变化需要在建造预览中显示敌人可能路径。

## 10.3 城墙模块

高级挡板拥有一个模块槽：

- 自动修复模块。
- 反冲撞尖刺。
- 拦截网。
- 小型机枪座。
- 火焰隔离层。
- 护盾增幅器。

模块可以更换，不需要拆除整面挡板。

## 11. 防御建筑升级与专精

## 11.1 基础升级

每个防御建筑拥有1～10级：

- 1～3级：强化基础属性。
- 4级：解锁第一个模块槽。
- 5级：选择A/B专精分支。
- 6～8级：强化分支机制。
- 9级：解锁第二个模块槽或外观变化。
- 10级：获得终极特性和明显模型变化。

选择分支后可以重置：

- 重置不损失建筑等级。
- 返还已投入的分支材料。
- 收取少量金币并有短暂改装时间。
- 鼓励玩家根据关卡更换策略。

## 11.2 建筑模块

通用模块示例：

| 模块 | 效果 | 代价 |
| --- | --- | --- |
| 快速转台 | 转向提高 | 单次伤害略降 |
| 加长炮管 | 射程提高 | 最小射程增加 |
| 自动装填 | 装填提高 | 过热或供给消耗提高 |
| 重型底座 | 抗冲撞和生命提高 | 承重需求提高 |
| 目标计算机 | 精度和预判提高 | 需要供能 |
| 节能机构 | 战备消耗降低 | 输出略降 |
| 应急护板 | 低生命时减伤 | 维修时间增加 |
| 溅射弹头 | 增加小范围伤害 | 对主目标伤害下降 |

## 11.3 蓝图品质

防御建筑蓝图分为：

- 基础：随港口等级直接解锁。
- 改良：通过防守Boss和海上舰船冒险获得。
- 稀有：通过敌方堡垒首通和特殊事件获得。
- 传奇：通过赛季目标、无尽防守或高阶Boss获得。

品质主要影响可选模块和特殊机制，不应让基础建筑完全失去价值。

## 13. 敌人波次与防守解题

每个关卡不只提高生命和伤害，还要出现新的“战术题”。

| 阶段 | 敌人组合 | 主要教学 |
| --- | --- | --- |
| 1～5轮 | 小舟、冲撞舟 | 机枪与挡板 |
| 6～10轮 | 小舟群、炮艇 | 近远搭配 |
| 11～20轮 | 爆破筏、鲨鱼、布雷艇 | 射界和优先级 |
| 21～30轮 | 重甲舰、维修船 | 穿甲与后排集火 |
| 31～40轮 | 导弹舰、无人机 | 近防与护盾 |
| 41～50轮 | 潜水艇、巨型海兽 | 声呐和专用反潜 |
| 51轮后 | 多阵营混编、Boss模块 | 区域与舰队协同 |

挑战下一轮前显示侦察报告：

- 主要敌人类型。
- 轻型/重甲/生物占比。
- 是否拥有空中、水下或远程单位。
- 预计从哪些方向进攻。
- 推荐的防御标签。
- 玩家当前覆盖是否不足。

系统只做提示，不自动替玩家建造。

## 14. 造船厂系统总览

## 14.1 造船厂的四种容量

必须清楚区分以下概念：

| 容量 | 含义 | 提升方式 |
| --- | --- | --- |
| 生产队列 | 可以提前排多少艘船 | 船厂等级、计划室模块 |
| 同时制造位 | 同一时间有多少艘船在建造 | 船台扩建、船厂等级 |
| 港口舰队上限 | 可以拥有多少艘守卫舰 | 舰队指挥所、港口等级 |
| 当前部署上限 | 一场防守能出动多少艘 | 船厂等级、指挥容量、战场水道 |

示例：

```text
船厂Lv.3
生产队列：5
同时制造位：2
港口拥有舰船：8/12
本轮可部署舰船：4
```

这样升级船厂不只是“制造快10%”，而是逐步打开完整舰队玩法。

## 14.2 船厂类型

| 船厂 | 定位 | 可制造 |
| --- | --- | --- |
| 简易小舟厂 | 前期、低成本 | 拦截舟、冲撞舟、运输筏 |
| 轻型战船厂 | 中期主力 | 炮艇、鱼雷艇、布雷艇 |
| 支援船坞 | 辅助舰专用 | 维修艇、补给艇、护盾艇 |
| 重型造船厂 | 大型战舰 | 重炮舰、导弹舰、装甲护卫舰 |
| 特种舰船研究坞 | 稀有蓝图 | 雷暴舰、无人机母艇、猎鲸舰 |
| 旗舰船坞 | 后期唯一建筑 | 港口旗舰、舰队指挥舰 |

首版可以只制作“简易小舟厂”和“轻型战船厂”，其余逐步扩展。

## 15. 造船厂等级与解锁

以“轻型战船厂”为例：

| 等级 | 队列 | 同时制造 | 部署贡献 | 解锁内容 |
| ---: | ---: | ---: | ---: | --- |
| 1 | 2 | 1 | +1 | 拦截小舟 |
| 2 | 3 | 1 | +1 | 小型冲撞舟、加速制造 |
| 3 | 5 | 2 | +2 | 轻型炮艇 |
| 4 | 6 | 2 | +2 | 舰船模块槽、批量制造 |
| 5 | 8 | 2 | +3 | 鱼雷艇、船厂专精 |
| 6 | 10 | 3 | +3 | 布雷艇、自动补充损失 |
| 7 | 12 | 3 | +4 | 火焰艇、舰船改装 |
| 8 | 14 | 4 | +4 | 装甲护卫艇 |
| 9 | 16 | 4 | +5 | 精英舰体、第二模块槽 |
| 10 | 20 | 5 | +6 | 船厂终极特性、传奇涂装 |

重要限制：

- 当前部署上限不是简单叠加所有船厂贡献，需要受到舰队指挥容量的总上限约束。

## 16. 守卫舰类型

## 16.1 前排与拦截

| 舰船 | 定位 | 战斗行为 |
| --- | --- | --- |
| 拦截小舟 | 追击微型敌人 | 快速接近并用轻机枪攻击 |
| 小型冲撞舟 | 一次性高冲击 | 锁定敌方炮艇或爆破筏进行冲撞 |
| 装甲巡逻艇 | 承受火力 | 在港口外圈巡逻并吸引近程敌人 |
| 防鱼快艇 | 对海兽 | 撒网并驱赶鲨鱼群 |

## 16.2 远程输出

| 舰船 | 定位 | 战斗行为 |
| --- | --- | --- |
| 轻型炮艇 | 通用输出 | 与敌人保持中距离侧向开火 |
| 火箭炮艇 | 范围打击 | 对密集敌人发射不精确火箭 |
| 鱼雷艇 | 反大型 | 从侧翼寻找大型目标发射鱼雷 |
| 导弹艇 | 超远打击 | 优先攻击敌方后排和支援舰 |
| 猎鲸舰 | 对巨型生物 | 使用鱼叉和猎杀弩持续追踪 |

## 16.3 控制与支援

| 舰船 | 定位 | 战斗行为 |
| --- | --- | --- |
| 布雷艇 | 水道封锁 | 在预设区域布置水雷后撤离 |
| 烟雾艇 | 防护 | 在被集火区域释放烟幕 |
| 维修艇 | 抢修 | 修理受损挡板、炮塔和友舰 |
| 补给艇 | 强化 | 为弹药不足或过热的友方提供补给 |
| 护盾艇 | 保护 | 跟随高价值重炮或主舰 |
| 声呐艇 | 侦察 | 搜索潜艇并标记远程目标 |

## 16.4 高级守卫舰

| 舰船 | 定位 | 解锁来源 |
| --- | --- | --- |
| 重炮护卫舰 | 移动远程重炮 | 高阶船厂与重甲舰蓝图 |
| 无人机母艇 | 派出拦截无人机 | 特殊堡垒首通 |
| 雷暴战舰 | 对密集金属舰弹射 | 雷暴核心 |
| 港口指挥舰 | 强化附近守卫舰 | 旗舰船坞 |
| 复合维修舰 | 维修、消防、拖船 | 后期支援科技 |

## 17. 守卫舰制造规则

## 17.1 制造消耗

每艘舰船需要：

- 金币：通用制造成本。
- 建材：船体结构。
- 金属：武器和装甲。
- 食物：船员出航储备。
- 舰船零件：中高级舰种。
- 蓝图：只负责解锁，不在每次制造时消耗。

## 17.2 制造时间

```text
实际制造时间 =
基础制造时间
× 船体规模系数
× 批量惩罚
÷ 船厂效率
÷ 工人效率
```

推荐基础时间：

| 舰船 | 初始制造时间 |
| --- | ---: |
| 拦截小舟 | 30秒 |
| 冲撞舟 | 45秒 |
| 炮艇 | 2分钟 |
| 布雷艇 | 3分钟 |
| 鱼雷艇 | 5分钟 |
| 维修艇 | 5分钟 |
| 重炮护卫舰 | 15分钟 |
| 港口指挥舰 | 30分钟以上 |

移动端或纯挂机版本可以整体延长，但首小时必须避免长时间无事可做。

## 17.3 批量制造

- 玩家可输入制造数量。
- 批量制造先占用队列，不一次扣完所有资源。
- 每艘开工时扣除对应资源。
- 资源不足时队列暂停，并显示缺少材料。
- 可以启用“保持库存”规则，例如始终补足4艘拦截艇。

## 17.4 取消与加速

- 未开工项目取消：返还100%资源。
- 正在制造项目取消：返还80%材料。
- 不使用强制付费加速作为基础机制。
- 可通过临时工人、船厂订单、港口庆典或广告奖励缩短少量时间。

## 19. 舰队管理与编队

## 19.1 舰队界面

舰队界面分为：

1. 已拥有舰船。
2. 当前防守编队。
3. 维修中舰船。
4. 船厂制造队列。
5. 舰船蓝图。
6. 编队预设。

## 19.2 部署消耗

不同舰船占用不同指挥点：

| 舰船规模 | 指挥点 |
| --- | ---: |
| 小舟、拦截艇 | 1 |
| 炮艇、布雷艇、维修艇 | 2 |
| 鱼雷艇、导弹艇 | 3 |
| 重型护卫舰 | 5 |
| 指挥舰、旗舰 | 8～10 |

当前可部署舰队不能超过：

```text
最大部署指挥点 =
舰队指挥所
+ 船厂部署贡献
+ 港口等级奖励
+ 特殊科技
```

## 19.3 编队站位

玩家可以给守卫舰设置起始区域：

- 外圈拦截区。
- 左翼水道。
- 右翼水道。
- 核心护卫区。
- 后排火力区。
- 自由巡逻区。

不是精确逐格摆船，而是指定区域，降低操作负担。

## 19.4 AI策略

每种守卫舰提供2～3个简单策略：

- 激进追击。
- 保守守区。
- 优先保护核心。
- 优先保护重炮。
- 优先攻击后排。
- 生命低于30%时撤回维修区。

## 19.5 舰船损伤

- 舰船被击沉不会永久消失。
- 战后进入修理队列。
- 修理消耗少量建材、金属和时间。
- 舰船耐久低时可以主动召回，减少修理消耗。
- 自动刷取已通关轮次时，舰船修理成本降低。

## 20. 船厂专精

造船厂5级时选择一个专精，可以付费重置。

## 20.1 快速建造厂

- 同时制造位更早增加。
- 小型舰制造速度提高。
- 批量制造成本略降。
- 适合损耗大、数量多的拦截舰队。

## 20.2 精工改装厂

- 制造速度略慢。
- 新造舰船获得额外模块槽或更高初始星级概率。
- 中大型舰修理更快。
- 适合少量精英舰。

## 20.3 支援船坞

- 维修艇、补给艇和护盾艇成本降低。
- 友方舰船战后维修时间降低。
- 当前部署上限略低，但续航更强。

## 20.4 战时船厂

- 港口被攻击时可快速完成一艘小型应急艇。
- 自动补充损失舰船。
- 生产资源消耗略高。

## 21. 建筑玩法深化：区域系统

## 21.1 区域不是强制画格子

系统根据相邻建筑自动识别功能区域：

- 居住区。
- 食物区。
- 工业区。
- 商业区。
- 军事区。
- 船坞区。
- 景观区。

玩家也可手动给区域命名和设置主题外观。

## 21.2 区域等级

区域通过以下内容获得经验：

- 区域内建筑升级。
- 建筑组合完整。
- 工人满足。
- 供给正常。
- 装饰和道路完善。
- 完成对应区域订单。

区域等级提供轻度加成：

| 区域 | 加成示例 |
| --- | --- |
| 居住区 | 人口容量、满意度 |
| 食物区 | 食物产出、仓储保鲜 |
| 工业区 | 建材和金属加工 |
| 商业区 | 金币和订单奖励 |
| 军事区 | 防御塔装填、维修 |
| 船坞区 | 制造、修理、舰队容量 |
| 景观区 | 繁荣度、居民满意 |

## 21.3 区域加成上限

- 区域加成只占总效率的10%～25%。
- 布局不完美仍然可以正常游玩。
- 不要求所有建筑挤在固定最优模板。
- 大型港口允许建立多个同类型区域。

---

## 22. 建筑玩法深化：供给系统

## 22.1 简化供给

不模拟每一颗炮弹和每一名搬运工的完整路径，而使用“区域供给覆盖”：

- 仓库向附近生产建筑提供原料。
- 弹药站向附近实弹塔提供战备。
- 发电设施向高级建筑提供能量。
- 食堂向附近工人设施提供生活供给。
- 码头道路和栈桥使供给网络连接。

## 22.2 三类供给

| 供给 | 用途 | 中断后果 |
| --- | --- | --- |
| 生活供给 | 房屋、工人、医疗 | 效率缓慢下降，不会立即停摆 |
| 工业供给 | 工坊、造船厂、维修 | 制造和加工速度降低 |
| 战备供给 | 炮塔、护盾、守卫舰 | 高级功能关闭，基础攻击保留 |

设计原则：

- 供给不足是效率问题，不是让建筑完全无法使用。
- 基础机枪、普通火炮即使断供仍能以较低效率战斗。
- 高级导弹、护盾和磁轨炮需要完整战备供给。

## 22.3 供给覆盖界面

建造模式可切换覆盖层：

- 绿色：供给充足。
- 黄色：超出推荐负载，效率降低。
- 红色：未连接。
- 蓝线：供给路径。
- 图标：缺少的是食物、工业还是战备。

---

## 23. 建筑玩法深化：升级、改造与地标

## 23.1 建筑等级

普通建筑1～10级，每次升级必须至少产生一种可见变化：

- 模型增加部件。
- 占地或高度变化。
- 生产动画更繁忙。
- 新增工人位置。
- 范围、队列或槽位变化。
- 解锁模块。

避免只有面板数字上涨。

## 23.2 建筑突破

建筑达到3、5、8级时需要突破材料：

- 3级：基础建材。
- 5级：对应专业零件。
- 8级：稀有蓝图部件或Boss核心。

突破后提供机制变化，而不仅是数值：

- 工坊增加第二配方。
- 仓库增加专用分类。
- 船厂增加第二制造位。
- 炮塔选择专精。
- 房屋可选择工人宿舍或高级住宅。

## 23.3 地标建筑

每个大阶段解锁一个港口地标：

| 地标 | 主要效果 |
| --- | --- |
| 海盗议事厅 | 解锁港口政策和订单 |
| 巨鲸纪念馆 | 提高海兽冒险和景观繁荣 |
| 舰队胜利广场 | 提高守卫舰经验和士气 |
| 海上大市场 | 增加资源交换与订单 |
| 巨型灯塔 | 扩大侦察、预警和冒险刷新 |
| 海神护港像 | 提供后期防守领域效果 |

地标占地大、模型明显，每类只能建造一个。

## 24. 科技与蓝图

## 24.1 五条科技线

| 科技线 | 内容 |
| --- | --- |
| 海上工程 | 地基、承重、扩建、城墙 |
| 民生生产 | 房屋、食物、仓储、工人 |
| 火力防御 | 炮塔、弹药、护盾、陷阱 |
| 舰船制造 | 船厂、舰种、模块、编队 |
| 远洋探索 | 冒险、侦察、稀有资源 |

## 24.2 研究规则

- 同时只研究一个主要科技。
- 研究需要时间和资源。
- 完成每日任务、Boss首通和冒险可以获得研究加速。
- 研究不会占用普通工人。
- 前期关键科技研究时间短，保证连续体验。
- 后期研究提供长期目标。

## 24.3 试用蓝图

为避免玩家解锁建筑前完全不了解它：

- 首次遇到新敌人时，可获得1～3场对应防御塔的试用权。
- 试用建筑只能建造一个。
- 试用结束后保留建筑模型展示，但不能继续升级。
- 获得正式蓝图后自动转为永久建筑。

## 25. 港口工程项目

工程项目是跨多个建筑的中长期建设目标。

示例：

### 25.1 外环防波堤

需求：

- 建造指定长度的加固外围平台。
- 放置三座挡板和一座维修塔。
- 消耗大量建材。

效果：

- 港口外圈建筑抗冲撞提高。
- 解锁新的外围防守位。

### 25.2 舰队干船坞

需求：

- 轻型船厂达到5级。
- 建造维修区和工业仓库。
- 通过指定海上舰船关卡。

效果：

- 增加舰队拥有上限。
- 舰船维修可以并行进行。

### 25.3 海上能源网络

需求：

- 建造发电机组和供能节点。
- 完成一次雷暴Boss防守。

效果：

- 解锁护盾、磁轨炮和高级船厂模块。

工程项目有明显的港口模型变化，用来制造长期建设成就感。

## 26.2 工人岗位

| --- | --- |

## 27. 建造订单与任务

## 27.1 短订单

持续5～20分钟：

- 制造3艘拦截舟。
- 生产一批建材。
- 升级一座机枪塔。
- 完成一轮自动防守。
- 修复三座受损建筑。

奖励：

- 金币。
- 基础材料。
- 少量研究点。
- 建造加速。

## 27.2 中期工程订单

持续1～6小时：

- 建立完整军事区。
- 将船厂升级到指定等级。
- 制造一支包含三种职责的舰队。
- 通关新的Boss轮次。

奖励：

- 建筑模块。
- 舰船零件。
- 改良蓝图。

## 27.3 长期里程碑

- 港口面积达到指定规模。
- 解锁全部基础塔种。
- 拥有十艘守卫舰。
- 建成第一个地标。
- 三条冒险线达到指定等级。

长期目标主要奖励外观、地标、传奇蓝图和功能解锁。

## 28. 成长节奏总览

## 28.1 前5分钟

玩家获得：

- 初始6×6平台。
- 海心指挥台。
- 简易房屋、捕鱼点和建材工坊。
- 一座速射机枪塔。
- 一小段挡板。
- 第一艘免费拦截小舟。

体验顺序：

```text
放置地基
→ 建造捕鱼点
→ 建造机枪塔
→ 防守第一轮小舟
→ 获得金币与材料
→ 建造简易小舟厂
→ 制造第一艘拦截舟
```

## 28.2 5～15分钟

- 解锁普通火炮。
- 解锁第二种敌人：冲撞舟。
- 获得声波塔试用权。
- 船厂升级到2级，队列从2增加到3。
- 学会设置拦截舟的守区。
- 完成第一个军事区小目标。

## 28.3 15～30分钟

- 敌人出现炮艇和小型Boss。
- 解锁喷火塔或霰弹塔。
- 船厂升级到3级，开放第二制造位。
- 制造第一艘炮艇。
- 解锁建筑模块。
- 主动出海获取第一张改良蓝图。

## 28.4 30～60分钟

- 解锁迫击炮和鱼雷台的其中之一。
- 学习最小射程和沿岸部署。
- 建立工业区和船坞区。
- 挑战第一次需要调整布局的Boss。
- 船厂拥有2条生产线、5个队列位、4～6艘舰船。
- 主舰、守卫舰和防御塔共同参与战斗。

## 28.5 1～3小时

- 港口形成至少三个功能区域。
- 解锁维修塔、弹药站和声呐。
- 防守开始出现混合舰队。
- 选择第一座主力防御塔的专精。
- 建立第一支有前排、输出和支援的守卫舰队。
- 完成第一个港口工程项目。

## 28.6 第一天结束目标

- 港口等级3～4。
- 防守轮次20～30。
- 拥有5～8种防御建筑。
- 拥有6～10艘守卫舰。
- 轻型战船厂3～5级。
- 三类主动冒险均有基础进度。
- 港口拥有明显的居住区、生产区和军事区。

## 28.7 第二天至第七天

- 解锁水下、导弹和重甲敌人。
- 建立近防与反潜体系。
- 解锁高级船厂和支援舰。
- 完成2～3个大型港口工程。
- 开始收集稀有建筑与舰船蓝图。
- 形成至少两套防守预设。

## 28.8 长期循环

```text
挂机获得基础资源
→ 升级建筑和船厂
→ 手动挑战下一轮
→ 发现新的敌人机制
→ 主动出海获取对应蓝图
→ 调整防守布局和舰队
→ 击败Boss
→ 扩建新的港口区域
```

## 29. 让成长更顺滑的规则

## 29.1 双解锁规则

重要内容不同时要求多个高门槛：

- 港口等级提供“可见和可试用”。
- 蓝图提供“永久建造资格”。
- 试用期间让玩家先感受玩法。
- 正式蓝图在接下来1～3个目标内可定向获得。

## 29.2 缺少资源时给出路径

任何升级按钮资源不足时，点击资源图标显示：

- 当前拥有。
- 本次需要。
- 每分钟自动产出。
- 对应主动冒险入口。
- 可完成的订单。
- 预计获取时间。

## 29.3 卡关诊断

挑战失败后不只显示“战斗力不足”，而是分析：

| 失败表现 | 提示 |
| --- | --- |
| 小舟大量穿过 | 拦截和范围火力不足 |
| 重甲舰长期不死 | 穿甲与鱼雷不足 |
| 炮塔先被远程拆除 | 远程反击或护盾不足 |
| 核心被冲撞 | 控制、挡板和水道不足 |
| 导弹伤害过高 | 近防和护盾不足 |
| 守卫舰很快沉没 | 维修、前排或撤退策略不足 |
| 防守后维修成本过高 | 防御层次和损管不足 |

提供“查看对应建筑”按钮，但不自动替玩家购买。

## 29.4 保底进度

- 重复刷取已通关轮次始终获得基础材料。
- 连续挑战Boss失败后获得少量“战术研究点”。
- 战术研究点可临时提高该Boss战的侦察、维修或试用建筑次数。
- 不直接永久降低Boss强度，避免失去成长目标。

## 29.5 建造无死路

- 普通建筑可自由移动。
- 装饰拆除100%返还。
- 防御建筑重置分支不损失等级。
- 关键建筑迁移只需要短暂施工时间。
- 供给不足只降低效率，不让整个港口停摆。

## 35. 数值框架

## 35.1 防御建筑有效输出

```text
有效输出 =
基础伤害
× 攻击频率
× 命中率
× 射界覆盖率
× 对应护甲倍率
× 实际开火时间
```

平衡时不能只比较面板DPS。

例如：

- 机枪塔面板DPS高，但对重甲倍率低。
- 重炮面板单发高，但转向和过量伤害明显。
- 迫击炮对静止集群强，对快艇命中率低。
- 喷火塔需要敌人进入近距离才产生价值。

## 35.2 建筑升级

建议：

```text
升级消耗 = 基础消耗 × 1.5^(等级-1)
基础伤害 = 初始伤害 × 1.28^(等级-1)
基础生命 = 初始生命 × 1.32^(等级-1)
```

机制解锁的价值应高于纯数字增长。

## 35.3 舰船制造成本

```text
舰船成本 =
舰体基础成本
× 舰船规模
× 品质系数
× 模块系数
```

舰船升级不建议无限提高制造成本；已拥有舰船通过改装和升星成长。

## 35.4 自动刷取维修占比

稳定刷取已通关轮次时：

- 平均维修消耗不超过该轮基础收益的15%～25%。
- 如果连续三次超过30%，系统提示降低轮次或调整防御。
- 离线模拟使用较保守但不会亏损的维修估算。

## 39. 性能规则

## 39.1 防御塔

- 不允许每座塔在每帧执行全场敌人搜索。
- 敌人由空间网格或统一索敌管理器分区。
- 低攻速塔按0.1～0.25秒间隔刷新候选目标。
- 高频机枪只保持当前目标，不重复全场检索。
- 射程预览只在建造、选中或战术模式显示。

## 39.2 守卫舰

- 使用统一舰队管理器调度。
- 远距离舰船降低AI更新频率。
- 小舟使用简化转向和避障。
- 不进行复杂的全局动态NavMesh烘焙。
- 水道可使用航行节点、局部避障和软分离。

## 39.3 制造与生产

- 制造进度按时间戳计算。
- 离线时不实例化在建舰船动画。
- 回到港口后根据完成度显示对应外观阶段。
- 所有生产队列由统一Tick更新。

## 42. 验收清单

### 防御差异

- [ ] 机枪塔能快速消灭小舟，但明显打不动重甲。
- [ ] 重炮能有效攻击重甲，但容易漏掉快速小舟。
- [ ] 喷火塔必须依赖近距离水道布局。
- [ ] 迫击炮存在最小射程并可能打空。
- [ ] 鱼雷台必须建在外缘并拥有清晰发射水道。
- [ ] 声波塔能够打断冲撞，而不是成为高伤害万能塔。
- [ ] 维修塔不能完全抵消持续集火。
- [ ] 玩家可以看见射界、盲区和覆盖关系。

### 防御成长

- [ ] 防御建筑升级有模型或机制变化。
- [ ] 5级可以选择专精。
- [ ] 分支可以重置且不损失建筑等级。
- [ ] 模块能够改变用途而不是只有数值加成。
- [ ] 下一轮侦察能提示敌人构成和防御缺口。

### 造船厂

- [ ] 制造队列和同时制造位是两个独立数值。
- [ ] 港口拥有上限和当前部署上限是两个独立数值。
- [ ] 船厂升级会解锁队列、生产线、舰种或功能。
- [ ] 舰船卡可以显示锁定原因。
- [ ] 玩家可批量制造并调整等待顺序。
- [ ] 资源不足时队列暂停且明确显示来源。
- [ ] 舰队容量满时，已完成舰船不会丢失。
- [ ] 在建舰船能在港口模型上看到制造过程。

### 守卫舰

- [ ] 拦截艇、炮艇、鱼雷艇和维修艇行为明显不同。
- [ ] 玩家可以指定守区而不需要逐格控制。
- [ ] 舰船被击沉后进入维修而非永久消失。
- [ ] 自动补充能维持设定库存。
- [ ] 舰船能够在低生命时撤退。

### 港口建造

- [ ] 军事、生产和船坞区域能自然形成。
- [ ] 区域加成不会强迫唯一最优布局。
- [ ] 供给不足只降低效率，不会使全部建筑停摆。
- [ ] 建造模式可查看路线、射界、维修和供给覆盖。
- [ ] 普通建筑可移动，装饰可无损调整。

### 成长体验

- [ ] 前5分钟完成建造、防守和第一艘船制造。
- [ ] 前30分钟解锁第二制造位。
- [ ] 每5～10分钟至少出现一次明显成长。
- [ ] 卡关后能明确知道缺少哪类能力。
- [ ] 每种关键资源都有挂机和主动两种来源。
- [ ] 重复刷取已通关轮次不会因维修长期亏损。

## 43. 最终体验目标

玩家看到自己的港口时，应该能够一眼理解它的成长：

- 最初只有几块浮木、一座机枪塔和一艘小舟。
- 中期形成外墙、水道、火炮阵地、工业区和两条造船线。
- 后期拥有分层火力、护盾、雷达、支援舰队和巨型船坞。
- 每一种防御建筑都在处理不同问题，而不是全部堆最高DPS。
- 船厂里可以看到舰船从龙骨、船体到武器逐步完成。
- 新舰船下水后真实加入港口巡逻和自动防守。
- 防守失败不会摧毁长期成果，而会给出清晰的调整方向。
- 主动出海能够针对当前缺少的蓝图、零件和资源进行获取。

最终形成的长期循环不是单纯等待数值上涨，而是：

```text
观察敌人
→ 调整水道和射界
→ 建造对应防御
→ 制造合适守卫舰
→ 挑战新轮次
→ 获得蓝图与资源
→ 扩建港口区域
→ 解锁更复杂的敌人与建筑
```

港口的规模、模型、舰队数量和战斗方式都会随着成长持续发生可见变化，使“海上城市”既是玩家的长期养成主体，也是每场自动战斗真实发生的战场。
