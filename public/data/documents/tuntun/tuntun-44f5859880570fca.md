# 《吞吞舰船》主舰、英雄、装备大规模内容扩充与全产出规划文档

> 文档版本：V1.0  
> 文档性质：现有结构完成后的内容扩充增量文档，不修改旧文档  
> 对应模式：海盗生涯、无缝六边形海域、英雄多主舰、商业化双卡池  
> 核心内容：36艘主舰、60名英雄、30套共180件装备、24种核心材料及完整产出投放  
> 推荐实现环境：Unity 3D

---

## 0. 本文与旧文档的关系

本文继承并严格遵守以下既有规则：

1. 玩家最多拥有6个可同时编入舰队的主舰席位。
2. 每艘主舰由1个船长位和4个作战英雄位组成。
3. 船长位不释放普攻和主动技能，只提供属性与最多3个被动。
4. 作战位英雄才提供普攻、主动技能和对应的战斗表现。
5. 英雄池只出英雄，主舰池只出主舰舰体，两个池子的保底与抽奖券完全独立。
6. 主舰席位通过占领海域解锁；舰体所有权通过抽奖、任务、特殊玩法或商城获得。
7. 英雄和主舰的等级上限不与进阶挂钩；重复对象用于0～6阶进阶，每阶只提升自身基础全属性。
8. 装备不进入抽奖池，装备是长期战斗、掉落和定向刷取的核心动力。
9. 商城最多直售非毕业史诗装备、非顶级英雄和非顶级主舰，不出售全游戏最强内容。
10. 所有玩法在当前连续海面地图内发生，不为获取内容额外切换到独立二级战斗场景。
11. 已拥有的主舰不会永久损失，英雄不会永久死亡。
12. 旧文档中的英雄示例与舰体原型，在本文中转化为正式内容并给予正式产出。

若本文与更早版本的“英雄信物突破等级上限”规则冲突，以最新商业化文档和本文为准：

- 英雄等级上限只受版本等级上限控制。
- 同名英雄只用于英雄进阶。
- 同名舰体只用于舰体进阶。
- 装备强化、精炼、重铸与英雄/舰体进阶互不占用材料。

| 内容类别 | 完整规划量 | 首发建议量 | 后续投放量 |

| 主舰舰体 | 36艘 | 12艘 | 24艘 |

| 装备套装 | 30套 | 12套 | 18套 |
| 装备单件 | 180件 | 72件 | 108件 |

这里的“完整规划量”不是要求首发一次制作完，而是先把内容位置和产出关系固定，避免后续版本临时塞内容导致：

- 同一玩法奖励越来越拥挤。
- 新英雄没有合适舰体或装备。
- 新舰体只比旧舰体数值更高。
- 商城商品破坏装备刷取。
- 玩家不知道某件物品到底在哪里获得。

## 2. 内容设计的四条硬规则

### 2.1 每项内容必须有唯一主产出

每艘主舰、每名英雄、每套装备都必须拥有一个“唯一主产出”。其他渠道只能作为：

- 保底兑换。
- 周期复刻。
- 首次获得。
- 碎片/进度补充。
- 满阶后的溢出处理。

不能出现一件内容同时在五六个地方低概率掉落，导致玩家不知道该刷哪里。

### 2.2 卡池解决收藏，玩法解决荣誉，装备解决长期刷取

| 内容 | 主要动力 | 不允许替代 |
| --- | --- | --- |
| 英雄 | 英雄池、阵容搭配、角色故事 | 不能把基础职责全部锁在付费中 |
| 主舰 | 主舰池、舰队分工、流派载体 | 不能让付费舰全面碾压玩法舰 |
| 装备 | 敌舰、Boss、海域、遗迹、特殊事件 | 不能进入抽奖池 |
| 特殊英雄/舰体 | 世界事件、赛季挑战、海域荣誉 | 不直接进入付费商城 |
| 商城内容 | 确定性补阵容、补舰队分工、追赶 | 不提供毕业上限 |

### 2.3 新内容必须扩大玩法，不只扩大数值

每个英雄、舰体或套装至少改变以下一项：

- 攻击位置。
- 攻击节奏。
- 目标选择。
- 航行方式。
- 资源管理。
- 召唤单位。
- 状态组合。
- 编队关系。
- 世界地图行为。
- 掉落与掠夺方式。

禁止仅用“伤害提高20%”当作新内容的唯一价值。

### 2.4 强力内容必须来自可识别的挑战

最强装备和特殊机制舰体必须能被玩家明确指认来源，例如：

- “风暴眼核心三阶段挑战。”
- “赤潮净化世界事件。”
- “沉钟遗迹无伤敲钟路线。”
- “鲸王共生声望终阶。”

不能把最强内容放进没有主题的随机箱子。

## 3. 品质与获取渠道统一规则

### 3.1 主舰与英雄品质

| 品质 | 内容定位 | 是否可长期使用 | 主要来源 |
| --- | --- | --- | --- |
| 普通 | 新手教学、简单明确 | 可用，机制较少 | 初始、任务 |
| 优良 | 单一职责完整 | 可用，培养便宜 | 任务、基础活动 |
| 稀有 | 完整流派组件 | 是 | 卡池、任务、商城 |
| 史诗 | 具有组合机制 | 是 | 卡池、特殊玩法、商城 |
| 传奇 | 独特机制和高构筑要求 | 是 | 卡池、最高难度玩法 |

传奇不等于所有场景数值最高。传奇的优势应是玩法独特、构筑上限高，代价是：

- 更依赖阵容。
- 操作难度更高。
- 某些敌人具有明确克制。
- 培养与装备需求更高。

### 3.2 装备品质

| 品质 | 常见产出 | 最高定位 |
| --- | --- | --- |
| 普通/优良 | 普通敌舰、航线货箱 | 分解、过渡 |
| 稀有 | 精英敌舰、航线、锻造 | 前中期成型 |
| 史诗 | 海域核心、Boss、声望、商城 | 长期可用 |
| 传奇 | 高危航线、世界海怪、遗迹、终局核心 | 毕业构筑与独特效果 |

### 3.3 产出标记

所有内容详情页统一显示以下来源标记：

| 标记 | 含义 |
| --- | --- |
| `稳定` | 完成明确条件必得 |
| `卡池` | 英雄池或主舰池 |
| `玩法` | 指定玩法与挑战 |
| `世界` | 无缝地图中的世界事件 |
| `声望` | 指定阵营/海域声望兑换 |
| `锻造` | 收集材料后定向制造 |
| `商城` | 航海晶石固定购买 |
| `复刻` | 周期重新开放 |
| `保底` | 达到次数或进度必得 |

# 第一部分：36艘主舰完整内容

## 5. 主舰内容分配

| 主来源 | 数量 | 占比 | 作用 |
| --- | ---: | ---: | --- |
| 初始/席位箱/章节任务 | 5 | 13.9% | 确保多舰系统可用 |
| 主舰池 | 21 | 58.3% | 主要收藏与版本轮换 |
| 特殊玩法 | 6 | 16.7% | 荣誉、世界主题和终局追求 |
| 航海晶石商城 | 4 | 11.1% | 确定性补舰队分工 |
| 合计 | 36 | 100% |  |

### 5.1 主舰共同结构

每艘主舰包含：

- 舰体基础属性。
- 1个舰体核心被动。
- 1个船规倾向。
- 3～5个兼容模块类别。
- 1个明确优势。
- 1～2个明确短板。
- 推荐英雄标签，但不锁职业。
- 主产出、辅助保底和重复获得规则。

主舰本身不额外占用Q/E/R/F主动技能键。所有主动技能仍由4名作战英雄提供。

### 6.1 席位箱防卡死规则

第1～5个新增主舰席位仍然各赠送一个基础舰体选择箱。若玩家已经拥有S02～S05：

- 可选择未拥有的基础舰体。
- 全部拥有时可选任一同名副本。
- 不得只给随机舰体。
- 新主舰最低以“船长＋1名作战英雄”出航。

## 7. 主舰池舰体（S06～S26）

### 7.1 常驻与精选规则

- S06～S14为基础常驻舰体。
- S15～S22为版本主题舰体，首次上线进入精选池，精选结束后延迟一个版本进入常驻。
- S23～S26为传奇主题舰体，只在同类型精选池复刻，保底跨同类主舰池继承。
- 主舰池只产出舰体，不混入英雄或装备。
- 首次抽到获得舰体所有权；重复获得转为同名舰体副本。

但首次所有权仍要求至少一次完整完成对应核心目标，不能只挂机攒满。

## 20. 定向刷取与坏运气保护

### 20.1 套装追踪

玩家在图鉴、英雄推荐或掉落预览中选择一套装备后，可以启用“航海寻装”：

- 大地图标出对应海域、Boss或航线。
- 结算页优先展示追踪套装进度。
- 不增加实际掉率，只减少信息成本。
- 同时最多追踪1套装备和1个具体部位。

### 20.2 普通航线装备

普通航线套装采用“敌人类型＋部位”固定映射：

| 部位 | 主要掉落单位 |
| --- | --- |
| 主武器 | 炮艇、鱼雷艇、精英攻击舰 |
| 防具 | 重甲艇、护卫舰、建筑守军 |
| 手套 | 速射艇、装填手、武装商船 |
| 靴具 | 追击艇、冲撞艇、逃跑宝箱船 |
| 航海工具 | 侦察艇、通讯船、瞭望站 |
| 饰品 | 航线首领、海域宝箱、周首胜箱 |

连续4次获得同一套装但未获得追踪部位时，第5次必定获得追踪部位。

### 20.3 Boss与核心装备

- 挑战前可选择1个目标部位。
- Boss结算至少掉落1件对应套装装备。
- 目标部位基础命中率为60%。
- 连续3次未命中，第4次必定为目标部位。
- 每周首次击破提供1个“该Boss套装自选箱”。
- 最高难度提高传奇概率，不增加独占的基础功能。

特殊玩法采用“掉落＋进度兑换”双轨：

```text
实际战斗掉落
+ 每次有效完成获得专属凭证
→ 凭证可直接兑换指定部位
```

即使随机掉落不好，玩家也能看到明确完成次数。

### 20.5 装备实例

每件掉落装备都是独立实例，保留：

- 品质。
- 强化等级。
- 3～4条随机词条。
- 独特效果。
- 套装ID。
- 来源海域。
- 首次获得时间。
- 是否锁定。
- 当前穿戴英雄。

## 43. 数值与强度验收

### 43.1 主舰

- 同品质主舰综合强度差距控制在可接受范围。
- 专精舰在目标场景领先，但在非目标场景有明显短板。
- 商城舰不能在综合战斗评分中超过同阶段玩法传奇舰。
- 特殊玩法舰的优势来自机制，不是无条件基础属性更高。
- 多舰指挥类内容在单舰状态下不能保持全部收益。

### 43.2 英雄

- 稳定英雄能组成完整基础舰组。
- 商城英雄不提供全游戏唯一基础功能。
- 传奇英雄不应同时拥有最高输出、最高防护和最高地图收益。
- 船长位与作战位都有价值，但不能让船长错误释放普攻/主动。
- 推荐算法不按品质简单排序。

### 43.3 装备

- 普通套装可以完成基础构筑。
- Boss套装提供玩法强化。
- 世界套装提供终局机制。
- 商城装备不具备传奇独特效果。
- 所有装备都能定向追踪。
- 最差运气下仍能通过保底或兑换获得指定部位。

## 44. 产出体验验收

玩家询问“在哪里获得”时，游戏内必须在两次点击内回答：

- 什么海域。
- 什么敌人/Boss/事件/池子。
- 当前是否开放。
- 需要什么前置。
- 当前保底或兑换进度。
- 预计还需多少次。

以下情况判定为失败：

- 只写“参与活动获得”。
- 只写“商店获取”但不说明是哪种商店。
- 只显示随机箱，不显示具体概率或保底。
- Boss掉落池超过6套装备且不能定向。
- 同一套装散落在完全无关的五个海域。
- 特殊玩法关闭后永久无法追赶。
- 商城装备成为推荐系统中的唯一答案。

## 47. 结论

这套内容扩充把《吞吞舰船》的长期目标拆成三条互相支持、但不会彼此替代的主线：

```text
收集英雄与主舰
→ 形成更多舰组与海域分工

挑战海域、Boss和世界事件
→ 获得流派装备与特殊内容

重复刷取装备、词条和材料
→ 持续优化六艘主舰
```

36艘主舰负责改变舰队载体与世界任务分工，60名英雄负责改变攻击方式、技能组合和角色表现，30套共180件装备负责建立长期刷取目标。所有内容均有明确主产出、稳定保底和可追踪路径。

最终玩家不应只看到“战力更高的新东西”，而应不断获得新的问题与新解法：

- 这块海域该派哪艘主舰？
- 谁更适合当船长？
- 四个作战位如何连携？
- 这套装备要去哪个Boss刷？
- 是继续追求传奇掉落，还是用凭证直接换指定部位？
- 六艘主舰如何在同一张无缝海图上分工？

当这些选择持续成立时，大量内容才会转化为真正可玩的长期游戏，而不只是不断变长的收集列表。
