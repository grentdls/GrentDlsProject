# 《吞吞舰船》海盗生涯：场景生动性、气泡反馈与关键事件视效完整设计文档

> 文档类型：独立增量设计文档  
> 适用模式：海盗生涯  
> 目标版本：无缝六边形海域、动态港口、英雄多主舰版本  
> 核心目标：让舰船、英雄、建筑、敌人、功能船、海怪和海洋生态都像“正在生活”，而不是一组静态模型与数值面板。

---

## 0. 与现有文档的关系

本文件不覆盖旧文档，而是在以下既有规则上新增统一的表现层：

- 世界由六边形海域划分。
- 建筑仍在海域内部的小网格与浮动地基上搭建。
- 战斗、追逐、拦截、采集、核心攻坚均发生在当前无缝海面，不切换二级战斗场景。
- 玩家初始拥有一艘主舰，占领新海域后逐步解锁，最多六艘。
- 每艘主舰拥有一名船长和四名作战英雄。
- 船长位不能普攻或释放主动技能，只提供属性、被动、判断和指挥反馈。
- 作战位英雄提供普攻、主动技能、被动与对应战斗表现。
- 港口具有动态鱼群、漂浮物、航线船只、捕鱼船、打捞船和生产建筑。
- 地图缩放仍沿用 L0～L4 层级。
- 普通命中不频繁触发屏震，重炮、撞击、Boss技能等重反馈才允许轻微屏震。
- 所有气泡、头像、图标和长文本都必须具有遮挡、合并、折叠与性能控制。

本次新增的系统只负责：

1. 读取已经发生的玩法事件。
2. 判断哪些单位需要做出反应。
3. 选择文字、表情、动作、音效、镜头和屏幕视效。
4. 控制表现优先级、冷却、数量、遮挡和重复度。
5. 不改变原有战斗结算、生产数值和事件结果。

## 1. 当前趣味性不足的根本问题

当前场景“平”的原因不是特效数量少，而是缺乏以下五种反馈：

### 1.1 缺少角色态度

玩家能看到船和建筑工作，却看不到角色对事情的判断：

- 找到宝箱，没人兴奋。
- 船快沉了，没人紧张。
- 捕鱼船满载返港，没人邀功。
- 建筑缺资源停工，场景没有抱怨。
- 敌人看到玩家压境，没有挑衅、慌乱或求援。

### 1.2 缺少事件节奏

不同事件都用近似强度表现：

- 小额金币与占领海域同样只是一个数字。
- 建造小仓库与完成大型奇观没有明显差别。
- 普通巡逻艇出现与Boss舰队来袭缺少层级区分。

### 1.3 缺少对象之间的关系

单位只与系统交互，不与其他单位互相反应：

- 船员不会对队友技能做出回应。
- 建筑不会提示相邻建筑的问题。
- 敌人不会呼叫增援。
- 功能船遇险时，护卫舰不会表达“正在支援”。

### 1.4 缺少动作的起因与结果

建筑直接出现、升级直接换模型、船直接进入工作状态，会让玩家感觉系统在切数据，而不是世界在变化。

### 1.5 缺少安静与爆发的对比

如果所有对象都说话、跳动、闪光，场景反而更乱。生动性必须来自：

```text
平静生活
→ 小变化
→ 局部冲突
→ 关键事件爆发
→ 余波与恢复
```

## 2. 改造目标

### 2.1 体验目标

玩家将镜头停在港口十秒，应自然看到：

- 船员头像偶尔产生符合性格的短气泡。
- 建筑有工作循环、装卸、灯光、烟雾、机械活动。
- 捕鱼船、打捞船、运输船真实进出泊位。
- 鱼群避让船只，海鸟跟随渔船，漂浮物受洋流移动。
- 两到三个对象发生一次小互动。
- 没有事件时仍有生活气息，但不持续刷屏。

玩家经历关键事件时，应在 0.5～3 秒内清楚知道：

- 发生了什么。
- 发生在哪里。
- 严重程度如何。
- 哪名英雄或哪艘主舰正在处理。
- 玩家现在可以做什么。

### 2.2 系统目标

- 所有表现均由统一事件驱动。
- 文案可配置，不写死在角色脚本中。
- 人格、岗位、阵营、心情和事件可组合。
- 同一事件在近景、战术视图和大地图采用不同表现。
- 支持最多六艘主舰同时运行。
- 支持低性能设备关闭部分装饰和屏幕特效。
- 支持玩家分别调节气泡、表情、镜头和屏幕特效强度。

## 3. 生动性表现的八个通道

每个事件不需要使用全部通道，由表现导演按强度选择。

| 通道 | 用途 | 示例 |
| --- | --- | --- |
| 头像反应 | 强化英雄存在感 | 头像眨眼、震动、变色、切换表情 |
| 世界文字气泡 | 角色化叙事 | “这片鱼群够我们吃几天了！” |
| 表情气泡 | 无文字快速反应 | 惊叹号、鱼、金币眼、冷汗 |
| 模型动作 | 让对象像在行动 | 炮塔转向、船体后坐、建筑弹跳 |
| 环境联动 | 让事件影响周围 | 海鸟飞散、水波扩散、灯光闪烁 |
| 音效语音 | 补充触感 | 木板咯吱、汽笛、短促角色拟声 |
| 镜头反馈 | 引导注意力 | FOV拉近、短跟焦、轻屏震 |
| 屏幕视效 | 表达最高强度 | 色散、变色、遮罩、暗角、冲击波 |

### 3.1 最小组合

普通事件建议只使用一至两个通道：

```text
建筑完成一轮生产
→ 建筑动作 + 小资源图标
```

重要事件使用三至五个通道：

```text
稀有鱼群出现
→ 船长头像 + 文字气泡 + 海面标记 + 短促音效
```

关键事件使用五至八个通道：

```text
海域Boss现身
→ 远景轮廓 + 天色变化 + 船长警告 + 镜头跟焦
→ FOV变化 + 边缘色散 + Boss标题 + 环境生物逃散
```

## 4. 统一事件表现流程

```text
玩法系统产生事件
→ EventVisualRouter 接收
→ 找出相关实体与观察距离
→ 读取角色性格、岗位、状态、关系
→ 计算事件表现等级
→ ExpressionDirector 选择表现通道
→ DialogueSelector 选择文字或表情
→ PresentationBudget 裁剪同时表现数量
→ 播放表现
→ 写入近期表现记录与冷却
```

### 4.1 玩法与表现必须解耦

错误做法：

```text
捕鱼船脚本里直接播放“抓到鱼了”气泡。
```

正确做法：

```text
捕鱼船发出 FishingCargoFull 事件。
表现系统判断镜头距离、船员性格、近期气泡数量后决定是否表现。
```

### 4.2 事件基础字段

每个可表现事件至少包含：

| 字段 | 说明 |
| --- | --- |
| EventId | 事件实例唯一编号 |
| EventType | 事件类型 |
| Importance | 事件基础重要度 |
| SourceEntity | 发起者 |
| TargetEntity | 目标，可为空 |
| WorldPosition | 世界位置 |
| HexRegionId | 所属六边形海域 |
| ShipId | 所属主舰，可为空 |
| HeroId | 直接相关英雄，可为空 |
| Value | 伤害、资源量、进度等 |
| Tags | 战斗、生产、危险、稀有、喜剧等 |
| StartTime | 发生时间 |
| CanMerge | 是否允许合并 |
| ForceNotify | 是否必须提示 |

## 5. 表现强度分级

## 5.1 E0：环境呼吸

无明确玩法事件，只负责让场景不死板。

- 建筑轻微浮动。
- 旗帜与绳索摆动。
- 工人走动。
- 炊烟与灯光变化。
- 船员头像偶尔眨眼。
- 海鸟落下又飞起。
- 小鱼群从码头下穿过。

限制：

- 不使用屏震。
- 不使用屏幕色散。
- 不抢占玩家视线中心。
- 每个对象的环境动作相位必须随机，不能同时摆动。

## 5.2 E1：轻量反馈

适用：

- 一轮普通生产完成。
- 小额资源入库。
- 普通船只离港。
- 船员轻微疲劳。
- 建筑开始工作。

允许：

- 小表情气泡。
- 0.15～0.25 秒局部缩放。
- 小资源图标。
- 短促局部音效。

## 5.3 E2：明确事件

适用：

- 货舱满载。
- 稀有漂浮物出现。
- 建筑升级完成。
- 敌人进入警戒范围。
- 英雄技能准备完毕。

允许：

- 一条短文字气泡。
- 头像表情变化。
- 目标描边或光圈。
- 0.3～0.6 秒镜头轻微偏移，但默认不夺取控制。

## 5.4 E3：重要事件

适用：

- 主舰重伤。
- 大型船队遭遇。
- 多座建筑停工。
- 海域核心进入阶段转换。
- Boss轮次开始。

允许：

- 多通道组合。
- 轻度 FOV 变化。
- 轻度暗角、色调变化。
- 0.1～0.25 秒时间缩放。
- 一次明确镜头引导。

## 5.5 E4：里程碑事件

适用：

- 占领新海域。
- 解锁新主舰席位。
- 击败海域核心。
- 大型港口地标建成。
- 英雄首次觉醒或关键剧情发生。

允许：

- 完整镜头段落。
- 环境与全局 UI 联动。
- FOV、遮罩、标题、色散、粒子和音乐段落。
- 1.5～4 秒表现。
- 必须支持跳过或缩短。

## 6. 表现预算与防吵闹规则

### 6.1 同屏上限

L0～L1 近景建议：

| 表现 | 同屏上限 |
| --- | ---: |
| 完整文字气泡 | 3 |
| 表情气泡 | 5 |
| 头像侧边提示 | 2 |
| 高亮目标 | 4 |
| 同时弹跳建筑 | 3 |
| E3及以上事件 | 1 |

L2 海域视图：

- 完整文字气泡最多 2 个。
- 其他单位合并为状态图标。
- 同类事件合并为一个区域气泡。

L3～L4 大地图：

- 不显示世界文字气泡。
- 英雄反馈进入主舰状态卡。
- 建筑反馈聚合为六边形状态标记。
- 只保留 E3、E4 和玩家主动展开的日志。

### 6.2 抑制条件

以下情况降低气泡概率：

- 玩家正在拖动建筑。
- 玩家正在打开角色、装备或天赋界面。
- E3/E4事件正在播放。
- 同一角色十秒内已说过两次。
- 同一事件类型三十秒内重复出现三次。
- 当前气泡会遮挡玩家点击目标。

### 6.3 绝对禁止

- 普通炮弹每次命中都说话。
- 每次获得一条鱼都弹气泡。
- 多个建筑同一帧完成时同时弹跳。
- 每次技能冷却完成都使用全屏提示。
- 同一句台词在短时间连续重复。
- 角色在重伤状态说过度轻松的普通闲聊。

## 7. 船员头像系统

## 7.1 主舰头像布局

每艘主舰配置：

- 船长头像一枚。
- 四名作战英雄头像四枚。
- 头像下方保留血量、能量、技能冷却或异常状态。
- 非主控舰在地图状态卡中显示船长头像加四个小岗位点。

### 7.2 头像动态层

头像不是一张完全静态图片，至少支持：

| 层 | 内容 |
| --- | --- |
| 基础肖像 | 角色默认头像 |
| 表情替换 | 高兴、愤怒、害怕、受伤、得意、疲惫 |
| 眼睛层 | 眨眼、眯眼、震惊 |
| 嘴型层 | 短促说话动画或两帧拟声 |
| 受击层 | 红闪、抖动、裂纹遮罩 |
| 状态层 | 中毒、燃烧、冰冻、眩晕 |
| 品质框层 | 稀有度和职位颜色 |
| 通讯层 | 通讯波纹、信号干扰 |

首版可以不做复杂 Live2D，采用：

- 6 张表情头像。
- 2 帧眨眼。
- 2 帧说话。
- 统一缩放、抖动、染色和遮罩。

### 7.3 头像反应动作

| 事件 | 头像动作 |
| --- | --- |
| 普通说话 | 上浮 4～8px，轻微放大 |
| 兴奋 | 先压缩 0.9，再弹至 1.08 |
| 紧张 | 高频小幅左右抖动 |
| 受伤 | 向受击方向偏移，短红闪 |
| 得意 | 轻微上扬，出现星光 |
| 疲惫 | 下沉，降低饱和度 |
| 通讯受阻 | 水平噪声切片和断续闪烁 |
| 技能释放 | 头像框脉冲一次，颜色取技能属性 |

### 7.4 非主控主舰的头像反馈

其他主舰发生事件时：

- E1：仅状态点闪烁。
- E2：船长头像上出现小表情。
- E3：屏幕边缘出现带方向的通讯卡。
- E4：进入统一里程碑提示。

点击通讯卡：

- 镜头移动至对应主舰。
- 不传送舰船。
- 不打断该舰当前真实航行和战斗。

## 8. 文字气泡系统

## 8.1 气泡类型

| 类型 | 主要使用者 | 视觉 |
| --- | --- | --- |
| 对话泡 | 英雄、友军、敌人 | 白/阵营色底，带尾巴 |
| 思考泡 | 英雄、工人 | 圆点尾巴，文字偏轻 |
| 命令泡 | 船长、敌方指挥官 | 硬边框、短促入场 |
| 警报泡 | 建筑、无人设施 | 红黄警示框 |
| 工作泡 | 建筑、功能船 | 图标加短文字 |
| 无线电泡 | 远处主舰、航线船队 | 噪声纹理、通讯波形 |
| 拟声泡 | 武器、碰撞、机器 | “轰！”“咔哒！”“噗通！” |
| 系统泡 | 教学与首次触发 | 统一中性样式 |

## 8.2 文字长度

- 世界气泡：推荐 4～12 个汉字。
- 无线电气泡：推荐 6～18 个汉字。
- 最大两行。
- 单行不超过 10～12 个全角字符。
- 超过长度的说明进入日志，不强塞在世界气泡中。

### 8.3 生命周期

推荐时序：

```text
0.00s  缩放 0.65，透明度 0
0.10s  缩放 1.08，透明度 1
0.18s  回弹至 1.00
1.80s  保持
2.10s  上浮并淡出
```

警报气泡可保持 3～5 秒，但必须在问题解除后主动收起。

### 8.4 气泡尾巴与锚点

- 舰艇气泡锚定对应英雄头像或船体通讯点。
- 建筑气泡锚定最高可读位置，避开烟囱和炮口。
- 敌人气泡锚定船体中心上方。
- 海怪气泡优先使用表情或拟声，不强制人类语言。
- 气泡始终朝向摄像机。
- 镜头旋转时尾巴重新定位，但气泡主体不快速跳动。

### 8.5 遮挡处理

优先级：

1. 玩家正在点击或拖拽的对象。
2. E3/E4事件。
3. 主控舰英雄。
4. 当前目标敌人。
5. 重要建筑。
6. 普通生态对象。

冲突时：

- 同类气泡合并。
- 低优先气泡缩为表情图标。
- 再冲突则延迟 0.4～1.2 秒。
- 仍无法显示则写入航海日志。

## 9. 表情气泡系统

## 9.1 基础表情图标

首版建议至少制作：

- 开心笑脸。
- 愤怒。
- 疑问。
- 惊叹。
- 冷汗。
- 害怕。
- 困倦。
- 受伤。
- 爱心。
- 金币眼。
- 食物。
- 鱼。
- 木材。
- 金属。
- 宝箱。
- 修理扳手。
- 弹药不足。
- 燃料不足。
- 仓库已满。
- 路线受阻。
- 锚。
- 雷达。
- 敌舰。
- 海怪。
- 风暴。
- 火焰。
- 漏水。
- 骷髅。
- 胜利旗。
- SOS。

### 9.2 组合表情

允许两个图标形成更具体语义：

| 组合 | 语义 |
| --- | --- |
| 鱼 + 开心 | 发现鱼群 |
| 鱼 + 问号 | 鱼群异常或消失 |
| 宝箱 + 金币眼 | 发现高价值漂浮物 |
| 扳手 + 冷汗 | 设备即将损坏 |
| 敌舰 + 惊叹 | 发现敌人 |
| 风暴 + 害怕 | 风暴逼近 |
| 弹药 + 骷髅 | 弹药耗尽 |
| 锚 + 红叉 | 无法停靠 |
| 爱心 + 船 | 成功救援 |

### 9.3 表情动画

- 惊叹号：快速上冲后轻摆。
- 问号：左右摆动两次。
- 冷汗：水滴向下滑。
- 愤怒：图标颤动并短红闪。
- 金币眼：金币旋转。
- 修理：扳手转动半圈。
- 鱼：小幅游动。
- SOS：红白交替脉冲。

## 10. 角色性格驱动系统

每名英雄配置多个性格标签，不只配置一套固定台词。

## 10.1 性格字段

| 维度 | 示例 |
| --- | --- |
| 基础气质 | 热血、冷静、胆小、乐观、阴沉、毒舌 |
| 价值取向 | 贪财、重情、荣誉、求知、生存、秩序 |
| 说话方式 | 简短、啰嗦、古怪比喻、专业术语、口头禅 |
| 风险偏好 | 冒险、谨慎、保守 |
| 社交倾向 | 领导、协作、独行、挑衅 |
| 职业经验 | 船长、炮手、工程师、医生、渔夫、学者 |

### 10.2 情绪状态

英雄当前情绪影响台词池：

- 平静。
- 兴奋。
- 紧张。
- 愤怒。
- 恐惧。
- 疲惫。
- 受伤。
- 得意。
- 沮丧。
- 专注。

情绪变化由事件产生，具有 15～90 秒衰减时间。

### 10.3 说话人格示例

| 人格 | 发现宝箱 | 敌舰出现 | 主舰重伤 |
| --- | --- | --- | --- |
| 热血炮手 | “里面最好是炮弹！” | “炮口给我转过去！” | “还能打，别停！” |
| 冷静航海士 | “先确认是否有陷阱。” | “敌舰，右舷七码。” | “建议立即脱离火线。” |
| 贪财打捞者 | “这箱子归谁？先说好。” | “击沉以后残骸归我。” | “修理费可不便宜啊！” |
| 胆小厨师 | “不会突然炸吧？” | “要、要不先绕过去？” | “锅都漏了，船也漏了！” |
| 毒舌机械师 | “终于捞到点能用的。” | “这破船也敢来？” | “谁又把船开墙上了？” |
| 乐观渔夫 | “今天海神心情不错。” | “赶走他们再撒网！” | “补上洞，还能回家。” |
| 神秘学者 | “箱子上有旧海域纹章。” | “他们的航迹不自然。” | “结构正在失去平衡。” |
| 老练船长 | “先封存，回港再开。” | “全舰进入战斗位置。” | “稳住船头，准备撤离。” |

### 10.4 岗位对台词的修正

同一英雄在不同岗位的说话重点不同：

- 船长位：局势判断、航线、撤退、集火、资源决策。
- 作战位：自己武器、技能、击破、受击、连携。
- 未上舰：港口生活、训练、装备、任务申请。
- 负伤休养：恢复、担忧、无法出击。

## 11. 船长位专属反馈规则

船长不能普攻和释放主动技能，因此不能播放：

- “我来开火”类台词。
- 主动技能施放头像特写。
- 对应武器攻击动作。

船长主要负责：

- 发现事件。
- 下达航行命令。
- 提醒资源和风险。
- 宣布进入与脱离战斗。
- 对其他英雄连携做总结。
- 在E3/E4事件担任主要叙述者。

### 11.1 船长典型触发

| 事件 | 船长反馈 |
| --- | --- |
| 进入未占领海域 | 判断威胁与地形 |
| 发现敌方核心 | 指定侦察或强攻建议 |
| 船员重伤 | 下令保护与撤退 |
| 补给不足 | 提醒返航 |
| 占领完成 | 宣布海域归属 |
| 边境来袭 | 给出方向、规模和预计抵达时间 |
| 其他主舰求援 | 决定是否响应 |

## 12. 四名作战英雄专属反馈规则

作战英雄只对与自己职责有关的事件高频响应。

### 12.1 普攻反馈

- 普通射击默认不说话。
- 连续命中阈值后可触发得意表情。
- 击破关键模块时允许短台词。
- 弹药耗尽、过热、目标丢失时允许状态气泡。

### 12.2 主动技能反馈

技能释放建议组合：

```text
头像脉冲
→ 0.2秒角色短台词
→ 武器或技能表现
→ 命中结果触发目标反馈
```

同一英雄连续自动释放技能时：

- 第一次可说完整台词。
- 十五秒内再次释放只用头像表情或拟声。
- E3技能可覆盖普通冷却。

### 12.3 英雄连携

连携触发条件：

- A英雄施加燃烧，B英雄引爆。
- A英雄拉拽目标，B英雄重炮命中。
- A英雄提供护盾，B英雄残血反击。
- A英雄标记弱点，其他三名英雄集火。

表现：

- 第一名英雄发起短句。
- 第二名英雄用表情或半句回应。
- 连携名称在战斗区短暂出现。
- 不允许四人同时说完整句子。

示例：

```text
工程师：“标记好了！”
炮手：“看我的。”
→【弱点爆破】
```

## 13. 角色关系与相互吐槽

为英雄配置关系值：

- 陌生。
- 熟悉。
- 信任。
- 挚友。
- 竞争。
- 矛盾。

关系值不直接增加大量战斗数值，主要影响：

- 相互回应概率。
- 称呼。
- 胜利庆祝动作。
- 重伤时的关心程度。
- 连携台词。
- 港口闲聊。

### 13.1 互动场景

| 事件 | 可能互动 |
| --- | --- |
| 炮手连续打空 | 机械师吐槽校准 |
| 工程师快速修复 | 船长表示认可 |
| 厨师提供补给 | 疲劳英雄恢复表情 |
| 胆小英雄击败Boss | 队友惊讶或鼓励 |
| 贪财英雄发现残骸 | 其他英雄提醒先救人 |

### 13.2 防止角色喧宾夺主

- 一次互动最多两人完整说话。
- 第三人只能用表情回应。
- 同一组合六十秒内不重复互动。
- 战斗危急时禁用纯闲聊。

## 14. 敌人文字与表情反馈

敌人不只是血条和攻击源，也需要表现组织、性格和当前状态。

## 14.1 敌方类型差异

| 敌人 | 说话风格 |
| --- | --- |
| 普通海盗 | 粗鲁、贪财、虚张声势 |
| 精英舰长 | 简短命令、判断玩家阵容 |
| 商队护卫 | 警告、请求停止靠近 |
| 走私船 | 狡猾、拖延、试图逃跑 |
| 狂热教团 | 仪式化、重复口号 |
| 机械无人舰 | 状态码、目标优先级 |
| 海怪 | 拟声、怒气、疑惑、受惊表情 |
| 敌方建筑 | 警报、增援请求、系统状态 |

### 14.2 敌方触发事件

- 首次发现玩家。
- 玩家进入禁区。
- 关键模块被击毁。
- 友军沉没。
- 试图逃跑。
- 呼叫增援。
- 弹药不足。
- 被控制或撞击。
- Boss阶段切换。
- 投降、欺骗或自毁。

### 14.3 敌人示例台词

普通海盗：

- “把货留下，船可以走！”
- “他们的炮怎么这么多？”
- “顶不住了，往雾里撤！”
- “别打仓库！那里面是钱！”

精英舰长：

- “先击沉他们的功能船。”
- “左翼拉开，不要挤在炮线里。”
- “核心受损，启动第二防线。”
- “对方主舰已露出侧舷。”

机械舰：

- “威胁等级：上调。”
- “动力模块损毁。”
- “重新计算撤离路径。”
- “终止回收，执行自毁。”

### 14.4 敌人表情优先于长台词

大量普通敌人只显示：

- 惊叹。
- 愤怒。
- 逃跑方向。
- 求援。
- 弹药不足。
- 目标锁定。

只有精英、舰长和Boss使用较完整文字。

## 15. 建筑的文字气泡与人格化

建筑“说话”分为三种来源：

1. 建筑内的工作人员。
2. 建筑自身的系统或机械提示。
3. 建筑状态的拟人化趣味表达。

### 15.1 建筑语气规则

| 建筑 | 语气 |
| --- | --- |
| 捕鱼码头 | 热闹、叫卖、催船返港 |
| 打捞站 | 工业、粗犷、关注重量和价值 |
| 仓库 | 抱怨空间、提醒分类 |
| 酒馆 | 喧闹、八卦、招募消息 |
| 造船厂 | 工程术语、进度和材料 |
| 医疗站 | 冷静、关怀、紧急呼叫 |
| 雷达站 | 简短、方向与距离 |
| 炮塔 | 机械、目标、过热和弹药 |
| 灯塔 | 航线、天气、远方目标 |
| 市场 | 价格、订单、人流和缺货 |
| 发电设施 | 负载、电压和过热 |
| 住宅 | 日常闲聊、抱怨、庆祝 |

### 15.2 建筑气泡示例

捕鱼码头：

- “三号渔船满载回来了！”
- “今天的鱼比昨天肥。”
- “冷库再不来人就塞满了。”

打捞站：

- “这块残骸至少值三袋金属。”
- “吊钩卡住了，来个人！”
- “先拆核心，别把好东西砸了。”

仓库：

- “真装不下了！”
- “木材区又被鱼箱占了。”
- “空出一个货位，快！”

造船厂：

- “龙骨对齐，准备下水。”
- “还缺两批钢板。”
- “别催，歪了你来开？”

雷达站：

- “东北边缘发现高速目标。”
- “信号进入风暴区。”
- “六个回波，不像商船。”

炮塔：

- “目标锁定。”
- “炮管过热！”
- “弹药只剩一轮。”

### 15.3 建筑情绪不是生命

建筑人格化只用于趣味反馈，不代表建筑真的有意识。除机械文明或特殊剧情外，气泡应能解释为工作人员、广播或系统提示。

## 17. 功能船、守卫舰与中立船队反馈

### 17.1 捕鱼船

- 发现鱼群：鱼图标和短鸣笛。
- 开始撒网：船员拟声“下网！”
- 渔网破损：冷汗和扳手。
- 满载：鱼箱堆高、船体吃水变深。
- 返港：显示目的泊位。
- 卸货：货箱逐批进入码头，不瞬间消失。

### 17.2 打捞船

- 锁定残骸：吊钩图标。
- 拖曳过重：船体后仰、速度降低、黑烟增加。
- 发现稀有核心：金色惊叹。
- 遇到危险物：骷髅或辐射图标。
- 返港时残骸应真实挂在拖索后方。

### 17.3 守卫舰

- 接到护航：盾牌气泡。
- 发现伏击：红色惊叹。
- 与功能船距离过远：断链图标。
- 成功驱离敌人：胜利旗。
- 需要维修：扳手和返航箭头。

### 17.4 中立与商贸船

- 即将进入港口：无线电请求靠泊。
- 港口拥堵：抱怨等待时间。
- 遭到袭击：SOS。
- 玩家护航成功：感谢和交易折扣提示。
- 玩家主动拦截：警告、逃跑或讨价还价。

## 18. 海怪与海洋生物表现

海怪不应像会说人话的普通敌人，优先使用：

- 拟声。
- 动作。
- 水面痕迹。
- 眼神或表情符号。
- 环境生物的逃散反应。

### 18.1 海怪预告

```text
鱼群突然散开
→ 海鸟升空
→ 水面出现不规则涌浪
→ 雷达短暂出现巨大回波
→ 船员产生疑问或紧张表情
→ 海怪才正式现身
```

### 18.2 海洋生物小互动

- 海豚短暂跟随高速主舰。
- 鲨鱼围绕受损船只。
- 鲸鱼呼吸产生远距离水柱。
- 海鸟跟随满载渔船。
- 小鱼躲进人工鱼礁。
- 夜间发光鱼群照亮船底。

这些互动主要提供生动性，不需要每次都转化为奖励。

## 19. 世界对象的“呼吸动作”

## 19.1 建筑

- 浮台随海浪轻微升降。
- 木结构产生不同步的细小摆动。
- 起重机偶尔调整方向。
- 炮塔进行缓慢空闲扫描。
- 窗口灯光分区域开启。
- 烟囱烟量随生产负载变化。
- 旗帜朝风向摆动。
- 绳索、渔网和浮标有滞后运动。

## 19.2 船只

- 怠速时随浪摆动。
- 加速时船尾下沉、船头抬起。
- 转弯形成不同方向尾流。
- 急停时产生前涌水花。
- 货物越多，吃水越深。
- 严重受损时偏航、冒烟或间歇失速。

## 19.3 港口生活

- 工人搬运箱子。
- 船员靠在栏杆观察海面。
- 酒馆门口短暂聚集。
- 医疗站担架移动。
- 市场摊位开合。
- 夜间巡逻灯沿道路移动。
- 建造区工人敲击、拉绳、测量。

## 20. 建筑放置表现

用户点击确认建筑后，不应直接出现完成模型。

## 20.1 推荐标准动画

总时长：0.65～1.00 秒。

```text
0.00s  地基位置出现轮廓与落点波纹
0.08s  建筑从落点上方1.5～3米出现，缩放0.82
0.20s  建筑快速下降
0.34s  接触地基，纵向压缩0.90、横向扩张1.06
0.42s  地基下沉，水花与木屑/铆钉粒子向外
0.52s  建筑回弹至1.08
0.68s  回到1.00，结构件轻微余震
0.80s  工人、灯光或机械开始运行
```

### 20.2 海上场景修正

建筑不是落到陆地，而是：

- 落到木筏地基。
- 落到石质浮台。
- 落到钢制甲板。
- 或由起重船放置到指定泊位。

地基反馈必须跟随材质：

| 地基 | 反馈 |
| --- | --- |
| 木筏 | 下沉明显、木板弯曲、绳结拉紧 |
| 石质浮台 | 下沉较小、沉重水花 |
| 钢制甲板 | 金属震动、铆钉火花 |
| 巨舰甲板 | 机械锁扣、液压支撑 |

### 20.3 建造来源变化

为避免所有建筑都“从天而降”，配置多种建造演出：

- 快速投放：小型装饰、路灯、箱子。
- 吊机放置：普通生产建筑。
- 浮台拖入：大型仓库、船厂部件。
- 分段拼装：炮塔、雷达站。
- 水下升起：特殊遗迹建筑。
- 船体展开：机械阵营模块。

同类建筑随机使用轻微不同的落点角度、回弹幅度和工人动作。

## 21. 建筑施工过程

建造时间超过十秒的建筑，不应只显示进度条。

### 21.1 三阶段模型

| 阶段 | 视觉 |
| --- | --- |
| 0%～30% | 地基、支架、材料堆 |
| 30%～70% | 主体骨架、吊机与脚手架 |
| 70%～99% | 外壳、设备、灯光调试 |
| 100% | 完成动画、工人撤离、正式运行 |

### 21.2 施工现场反馈

- 材料船抵达。
- 材料箱数量逐渐减少。
- 工人分散到不同施工点。
- 锤击、焊接、拉绳动作循环。
- 夜间点亮施工灯。
- 缺材料时工人停下并产生资源问号。
- 暂停施工时覆盖防水布或停用标牌。

### 21.3 玩家加速施工

加速后：

- 工人移动速度小幅提升。
- 敲击与火花频率增加。
- 进度环出现短加速波纹。
- 不直接使用刺眼全屏闪光。

---

## 22. 建筑升级表现

## 22.1 升级开始

- 玩家点击升级后，建筑先轻微缩小至 0.96。
- 外围出现升级范围圈。
- 新增结构以半透明轮廓展示。
- 工人与工程船进入。
- 头像或建筑气泡说明“准备改造”。

### 22.2 升级进行

- 新部件逐段出现。
- 旧部件局部拆除，不让整栋建筑消失。
- 不同阶段开放不同施工动画。
- 建筑保持“有限工作”或明确停工状态。

### 22.3 升级完成标准演出

总时长：0.9～1.5 秒。

```text
建筑灯光依次点亮
→ 新结构从内向外展开
→ 模型压缩至0.94
→ 回弹到1.10
→ 稳定到1.00
→ 升级光环沿地基扩散
→ 新功能图标与关键数值短暂出现
```

重要升级允许：

- 镜头轻微拉近。
- 围绕建筑旋转 8°～15°。
- 世界时间缩放到 0.7，持续不超过 0.4 秒。

不建议完全暂停世界，除非是首次解锁核心功能或大型地标完成。

## 23. 建筑受击、损坏、停工与修复

### 23.1 受击

- 小伤害：局部火花、轻微摆动。
- 中伤害：结构件震动、掉落少量碎片。
- 重伤害：明显倾斜、黑烟、警报气泡。
- 普通攻击不触发全屏屏震。
- 重炮命中可触发一次轻屏震。

### 23.2 损坏状态

建筑生命值不是唯一表现：

- 75%以下：局部焦痕。
- 50%以下：间歇火花、工作速度下降表现。
- 25%以下：明显冒烟、灯光闪烁、工作人员撤离。
- 0%：进入瘫痪，不永久消失，战后等待维修。

### 23.3 修复

```text
维修船或工人抵达
→ 扳手气泡
→ 火花变少
→ 破损部件逐段恢复
→ 烟雾降低
→ 灯光重新点亮
→ 建筑轻弹一次表示恢复运行
```

## 26. 关键事件视效总则

## 26.1 FOV与焦距变化

用户提到的“foc缩放”统一定义为 FOV/焦距与镜头距离变化。

| 事件 | 推荐变化 |
| --- | --- |
| 发现稀有物 | FOV缩小 3°～5°，短跟焦 |
| 重炮命中 | FOV快速放大 2°后恢复 |
| Boss现身 | FOV缩小 6°～10°，镜头后拉保留体量 |
| 技能爆发 | 视技能方向短推近 |
| 占领海域 | 先推近核心，再缓慢拉远展示新边界 |
| 主舰濒危 | FOV略缩，边缘暗角加强 |

原则：

- 变化时长 0.15～1.2 秒。
- 玩家正在手动精确操船时降低幅度。
- 连续事件不叠加 FOV，采用队列与覆盖规则。

### 26.2 色散

色散只用于：

- 巨大冲击。
- 海怪精神干扰。
- 通讯异常。
- 主舰濒临沉没。
- 特殊空间或遗迹事件。

限制：

- 普通战斗禁用持续色散。
- 单次冲击 0.08～0.25 秒。
- 持续异常采用低强度脉冲。
- 设置中允许完全关闭。

### 26.3 变色

| 状态 | 色调 |
| --- | --- |
| 危险逼近 | 饱和度略降，红橙警报增强 |
| 深海异常 | 蓝绿偏色，黑位加深 |
| 火灾 | 暖色脉冲、局部烟雾 |
| 中毒污染 | 黄绿色边缘 |
| 暴风雨 | 冷灰色、对比提高 |
| 胜利占领 | 暖色恢复、饱和度短提升 |
| 英雄濒危 | 头像和边缘局部去色 |

### 26.4 遮罩

可用遮罩：

- 圆形聚焦遮罩：首次教学和重要目标。
- 方向遮罩：来袭方向。
- 波浪遮罩：海怪、水下异常。
- 舷窗遮罩：主舰内部通讯或角色特写。
- 六边形边界遮罩：占领新海域。
- 破损遮罩：主舰严重受损，但不遮挡中心操作区。

## 27. 关键事件演出模板

## 27.1 发现稀有鱼群

```text
鱼群发光或跃出水面
→ 附近海鸟聚集
→ 雷达站转向
→ 船长或渔夫头像弹出
→ “这不是普通鱼群。”
→ 海面出现柔和定位圈
→ 捕鱼船表情气泡变为鱼+惊叹
```

不暂停世界，不强制移动镜头。

### 27.2 发现敌方舰队

```text
远处雷达回波
→ 屏幕边缘方向警示
→ 船长短句报告数量和方位
→ 战斗音乐层进入
→ 当前主舰作战英雄头像进入战备表情
→ 炮塔与守卫舰转向威胁方向
```

### 27.3 Boss舰队来袭

```text
天气或环境音先变化
→ 边境海域出现巨大航迹
→ FOV缓慢变化
→ 轻度暗角和低频震动
→ Boss通讯/拟声
→ 标题和阶段目标出现
→ 镜头返回玩家主控舰
```

总时长控制在 2.5～4 秒，允许跳过。

### 27.4 主舰濒危

```text
船体局部爆炸
→ 船长头像切换受伤/紧张
→ 作战英雄中一人报告具体故障
→ 屏幕边缘破损遮罩
→ 低频警报
→ 撤退、修理、护盾三个可执行入口高亮
```

不要连续弹出多名英雄完整台词。

### 27.5 击败海域核心

```text
最后命中短时间缩放
→ 核心停止攻击
→ 敌方小单位产生惊恐/撤退表情
→ 友方船员欢呼
→ 环境色调从压迫状态恢复
→ 镜头拉高展示整个六边形海域
→ 六边形边界由敌对色转为玩家色
→ 新建造范围沿边界点亮
```

### 27.6 解锁新主舰席位

```text
占领结算后
→ 港口造船厂或主舰席位亮起
→ 新主舰轮廓从暗到亮
→ 船长头像候选与英雄编成入口出现
→ 文案强调“新的舰队任务能力”，而不只是获得一艘数值更高的船
```

### 27.7 大型建筑完成

```text
施工机械停下
→ 新结构展开
→ 地基承重反馈
→ 建筑弹性回弹
→ 灯光由下至上点亮
→ 港口汽笛与周围船员表情
→ 新功能按钮出现
```

## 28. 战斗生动性改造

### 28.1 攻击前

- 炮塔先转向。
- 炮管或武器蓄力。
- 船员头像进入专注。
- 目标出现锁定反馈。
- 重武器开火前留出可识别的预备动作。

### 28.2 攻击中

- 船体后坐。
- 水面产生反向波纹。
- 弹道、炮口火焰和音效同步。
- 近距离喷火影响海面烟雾与反光。
- 鱼雷入水后形成真实航迹。

### 28.3 命中后

根据命中类型区分：

| 命中 | 反馈 |
| --- | --- |
| 轻型子弹 | 火花、小摆动 |
| 重炮 | 结构后仰、碎片、轻屏震 |
| 喷火 | 持续燃烧、烟雾、敌人慌乱 |
| 鱼雷 | 水下爆炸、水柱、船体抬升 |
| 撞击 | 双方位移、水花、短暂停顿 |
| 控制 | 对应符号、动作受限 |
| 弱点击破 | 模块爆裂、英雄短反馈 |

### 28.4 战斗中的气泡节奏

- 开战：船长一次。
- 关键模块击破：相关作战英雄一次。
- 生命降至50%：船长或工程师一次。
- 生命降至25%：一次强提醒。
- 胜利：最多两名英雄互动。
- 普通击杀不逐个说话。

## 29. 海域边境来袭表现

边境来袭从玩家当前领土暴露边动态产生，表现必须指向真实边缘。

### 29.1 预警阶段

- 对应六边形暴露边出现远方航灯或黑点。
- 灯塔光束转向。
- 雷达站显示目标数量。
- 边境建筑出现紧张或战备表情。
- 主舰状态栏给出最近支援舰ETA。

### 29.2 接敌阶段

- 敌舰从真实边缘进入。
- 沿途鱼群和民船让路或逃散。
- 防区炮塔按顺序进入锁定。
- 不清空场景中的捕鱼船和商船。
- 中立船只可以发出SOS或改变航线。

### 29.3 战后余波

- 海面残骸漂浮。
- 打捞船申请出港。
- 受损建筑等待维修。
- 船员从紧张恢复到疲惫或庆祝。
- 战斗烟雾逐渐消散。
- 航线恢复，不瞬间回到“什么都没发生”。

## 30. 昼夜、天气与气泡表现

### 30.1 夜间

- 气泡降低整体亮度，提高文字对比。
- 船只通讯灯闪烁。
- 建筑窗灯成为生活感主要来源。
- 夜间闲聊频率降低。
- 警报色更醒目，但避免大面积纯红。

### 30.2 雨天

- 气泡具有轻微防水罩视觉，不被雨粒穿透。
- 船员台词更多关注视野、甲板和航行。
- 建筑施工速度变化要有相应动作反馈。
- 小型船更明显摇摆。

### 30.3 风暴

- 普通闲聊停止。
- 只保留航行、危险、救援和故障反馈。
- 通讯气泡可有轻微干扰。
- FOV与镜头摆动必须受晕动设置限制。

### 30.4 晴朗与节庆

- 表情更活跃。
- 酒馆和市场增加生活事件。
- 船员可能对景色、鱼群、战果进行闲聊。
- 不应影响关键战斗信息优先级。

## 32. 气泡文案写作规则

### 32.1 文案必须提供信息或性格

无效文案：

- “太好了！”
- “小心！”
- “出发！”

更有效：

- “鱼舱满了，回港！”
- “右舷有鱼雷航迹！”
- “打捞船跟上，别让残骸漂走！”

### 32.2 一句话只表达一个意思

不在世界气泡中同时说明：

- 原因。
- 数值。
- 解决方案。
- 背景故事。

详细信息放在点击后的状态面板。

### 32.3 口头禅控制

- 每名英雄可有 1～2 个口头禅。
- 口头禅概率不超过对应台词池的 15%。
- 危急事件不强行使用搞笑口头禅。

### 32.4 数值文案

世界气泡尽量不用长数字：

- “仓库快满了”优于“仓库容量达到92%”。
- 具体92%显示在点击面板中。
- 战斗关键数值仍使用跳字和HUD。

## 35. 事件台词选择算法

### 35.1 候选过滤

候选台词必须同时满足：

- 事件类型匹配。
- 阵营匹配。
- 岗位匹配。
- 当前情绪允许。
- 角色状态允许。
- 当前LOD允许。
- 不在单句冷却。
- 不在语义冷却。
- 不与高优先事件冲突。

### 35.2 触发概率

建议公式：

```text
最终概率 =
基础触发率
× 事件重要度系数
× 角色相关度
× 镜头关注系数
× 新鲜度系数
× 当前表现预算
```

示例：

- 普通生产完成基础率：5%。
- 捕鱼船首次满载：100%。
- 同类满载第二次：30%。
- 三十秒内第三次：5%或只显示表情。

### 35.3 新鲜度

```text
新鲜度 = 1 / (1 + 近期同语义触发次数 × 0.8)
```

同一句台词建议至少：

- 普通台词：90秒冷却。
- 特色台词：5分钟冷却。
- 里程碑台词：每次事件实例仅一次。

### 35.4 兜底

没有合适文字时：

1. 使用匹配表情。
2. 使用中性系统短句。
3. 只做模型动作。
4. 不强行说话。

## 36. 事件合并规则

### 36.1 建筑合并

五座生产建筑同时缺木材：

错误：

- 五个“缺木材”气泡。

正确：

- 最近一座建筑产生木材问号。
- 海域资源栏显示“5座建筑缺少木材”。
- 点击后逐个高亮。

### 36.2 战斗合并

大量普通敌人进入范围：

- 不逐舰播报。
- 船长说“东北方向出现敌舰群”。
- 雷达显示数量。
- 精英舰单独标记。

### 36.3 多主舰合并

三艘非主控舰同时完成巡逻：

- 右侧舰队状态栏出现“3项任务完成”。
- 最高价值结果由对应船长说话。
- 其他结果进入日志。

## 38. 气泡视觉规范

### 38.1 阵营颜色

- 玩家：主UI色加暖白底。
- 友军：青绿或浅蓝。
- 中立：米黄。
- 敌对：暗红或橙红。
- 机械：冷灰与扫描线。
- 海怪：深蓝绿与不规则边缘。

颜色只用于边框、尾巴和小标，不使用大面积高饱和底色影响阅读。

### 38.2 字体

- 正文使用高可读中文字体。
- 拟声可使用更夸张的手绘字体。
- 关键数字使用等宽或清晰粗体。
- 最小字号需在目标移动设备实机验证。

### 38.3 背景

- 半透明但必须保持对比度。
- 海面亮度变化时自动增加描边或阴影。
- 不使用虚假棋盘透明背景素材。
- 气泡框体、尾巴、表情、文字和头像框必须能作为独立UI素材拆分。

### 38.4 动画曲线

- 普通出现：Back Out。
- 警报出现：快速 Ease Out。
- 建筑落地：Bounce或自定义压缩回弹。
- 消失：Ease In加轻微上浮。
- 危险抖动：短促，不使用长时间正弦摇摆。

## 40. 镜头与控制权保护

### 40.1 默认不抢镜头

E0～E2事件：

- 只提示方向。
- 不强制移动镜头。
- 玩家点击提示后才跟随。

### 40.2 E3镜头

- 可以短暂偏移或拉近。
- 玩家持续按住操控输入时立即减弱或取消。
- 不改变主舰航向。
- 不影响鼠标选中与拖拽。

### 40.3 E4镜头

- 可进入短演出。
- 提供“跳过”。
- 跳过后保留结果摘要。
- 不传送主舰或改变世界对象位置。

### 40.4 摄像机基线

- 保留俯视约50°～60°的既有基线。
- 建筑升级可轻微拉近并旋转展示新增结构。
- 普通命中不屏震。
- 重炮、鱼雷、大型撞击使用轻微屏震。

## 45. 性能规则

### 45.1 气泡

- 全部使用对象池。
- 世界气泡只在摄像机可见区域更新跟随。
- 屏幕后方事件使用边缘提示，不创建世界气泡。
- 远距离文字直接聚合。
- 文字排版结果缓存。

### 45.2 头像

- 首版使用图集和简单帧动画。
- 同一时刻只有可见头像播放动态。
- 非主控舰远景状态卡不持续播放嘴型。

### 45.3 建筑动作

- 空闲摆动用低频动画或顶点方案。
- 远景停用骨骼与工人细节。
- 建筑弹性只驱动VisualRoot，不移动玩法碰撞和网格占位。
- 施工动画按阶段切换，不需要持续复杂物理。

### 45.4 屏幕视效

- 使用统一混合器，禁止多个系统分别改后处理参数。
- 同类型效果取最大值或按配方混合，不直接相加。
- 低性能档关闭装饰性色散、景深和大量粒子。

### 45.5 生态联动

- 鱼群和海鸟使用群体事件，不逐个订阅所有战斗事件。
- 一次爆炸只广播一个半径事件。
- 远景生态只改变聚合状态。

## 49. 验收清单

### 49.1 角色与气泡

- [ ] 舰艇上能清楚看到船长和四名作战英雄头像。
- [ ] 船长不会播放普攻或主动技能台词。
- [ ] 作战英雄只对自己相关的攻击与技能高频反馈。
- [ ] 每名英雄的文字符合性格、岗位、情绪和状态。
- [ ] 气泡最多两行，不遮挡主要操作。
- [ ] 同一句话不会短时间连续重复。
- [ ] 危急状态会压制普通闲聊。
- [ ] 其他主舰能通过简化通讯卡表达状态。

### 49.2 表情

- [ ] 船员支持文字气泡和表情气泡。
- [ ] 敌人支持阵营化表情。
- [ ] 建筑支持状态表情。
- [ ] 海怪优先使用拟声和动作，而不是普通人类对白。
- [ ] 表情图标点击后能查看具体问题。

### 49.3 建筑

- [ ] 建筑确认后不是瞬间出现。
- [ ] 建筑能从半空落到海上地基并产生压缩回弹。
- [ ] 不同地基有不同承重反馈。
- [ ] 大建筑能用吊运、拖入或分段拼装替代统一空投。
- [ ] 长时间施工有三阶段模型。
- [ ] 升级能看见新结构逐步出现。
- [ ] 受损、停工和修复均有明确表现。
- [ ] 生产动画与真实资源流转一致。

### 49.4 战斗与事件

- [ ] 敌人会发现、挑衅、求援、慌乱和撤退。
- [ ] 敌方精英与普通单位的表达密度不同。
- [ ] 普通命中不会每次屏震。
- [ ] 重炮、鱼雷和撞击有差异化反馈。
- [ ] 边境来袭从真实暴露边出现。
- [ ] 战后保留残骸、损坏和恢复过程。
- [ ] 占领海域在当前地图完成，不切换二级场景。

### 49.5 关键视效

- [ ] FOV变化不影响玩家操船。
- [ ] 色散只用于高强度或特殊事件。
- [ ] 变色与遮罩不会遮挡核心HUD。
- [ ] E4事件可跳过。
- [ ] 关闭屏震、色散和FOV后仍保留完整信息。
- [ ] 多个事件同时发生时只有一个主导演出。

### 49.6 地图与性能

- [ ] L0～L4使用不同表现密度。
- [ ] 缩放时气泡平滑聚合，不反复闪烁。
- [ ] 六艘主舰同时运行不会产生通讯轰炸。
- [ ] 二十座建筑同类异常会合并。
- [ ] 气泡、表情、水花、火花全部对象池化。
- [ ] 低性能档仍保留重要信息。

## 50. 推荐第一轮制作重点

第一轮不要同时制作全部角色和事件，先完成一条最能体现变化的完整体验链：

```text
玩家在港口选择捕鱼码头
→ 半透明预览
→ 建筑由吊机放到木筏地基
→ 地基下沉、建筑压缩回弹
→ 三阶段施工
→ 工人和渔船进入
→ 渔船发现鱼群，英雄头像说话
→ 渔船真实出港捕鱼
→ 满载后产生鱼+开心表情
→ 返港卸货
→ 仓库接收，若已满则建筑产生状态气泡
→ 此时边境敌舰出现
→ 雷达、船长、炮塔、功能船和鱼群同时作出不同反应
→ 战斗在当前海面发生
→ 战后打捞船清理残骸，建筑修复，场景恢复生活状态
```

这条链完成后，玩家能够直接感受到：

- 英雄有性格。
- 建筑有过程。
- 船具有任务。
- 敌人有反应。
- 海洋有生态。
- 关键事件有节奏。
- 战斗结果会留在场景里。

## 51. 最终体验目标

改造后的海盗生涯不应只是“等待数字增长、点击图标、进入战斗”，而应像一座持续运转的海上家园与舰队：

- 船长在判断局势。
- 作战英雄在操控各自武器与技能。
- 港口工人忙着装卸和施工。
- 建筑会工作、抱怨、受损和恢复。
- 捕鱼船和打捞船在真实海面上往返。
- 敌人会观察、组织、慌乱和撤退。
- 海怪出现前，整个海洋先做出反应。
- 玩家占领一块海域后，边界、航线、建筑和角色都会共同庆祝与变化。

生动性系统的最终标准不是“屏幕上一直有东西跳”，而是让玩家相信：

> 即使自己暂时不操作，这片海域里的每艘船、每座建筑和每名英雄，也都在经历属于自己的事情。
