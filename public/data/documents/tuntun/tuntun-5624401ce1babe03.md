# 《吞吞舰船》港口泊位、舰队保障、建筑职能、地基防守与陷阱完整重构文档

> 文档类型：海盗生涯港口系统增量重构  
> 适用范围：方形小领海、港口建造、英雄主舰、守卫舰、功能船、商船、防守模式  
> 核心目标：让每一座建筑都能在世界中改变舰船行为、港口吞吐、战斗能力或防守结果  
> 文档原则：新建独立文档，不修改旧文档；发生冲突时，以本文件明确标注的替换规则为准

---

## 0. 本文与旧文档的关系

### 0.1 继续保留的规则

以下既有规则继续有效：

- 世界采用48米领海方格、12米生产区格、2米建筑基础格。
- 水面生产区占用建造规划空间，但生产区本身不阻挡航行。
- 只有码头、平台、吊机、挡板、炮塔、水雷等实体产生碰撞。
- 功能船必须真实出航、作业、装载、返港并卸货，资源才进入仓库。
- 商业产品必须真实装上商船并完成离港结算，才产生完整贸易收入。
- 主舰必须真实航行到交战边，不能瞬移参加防守。
- 英雄主舰失去动力后可以拖回，不会永久丢失。
- 守卫舰被击沉后进入维修或重建流程，不永久从账号删除。
- 防守中被击毁的已购买建筑不会从玩家布局中永久删除。
- 固定挑战区域不可占领、不可建造，不作为普通入侵出生边。
- 船长位仍然不释放普攻和主动技能。

### 0.2 本文正式替换的规则

以下旧规则被本文件替换：

1. “只要建成船厂就能无限停船”被替换为实体泊位、锚地与服务吞吐规则。
2. “港口等级统一提高所有舰船属性”被替换为建筑职能、舰种专精和装配解锁。
3. “商船按概率凭空产生贸易收益”被替换为商港、航道、靠泊、装卸、离港完整链路。
4. “生产船完成工作后立即结算资源”统一替换为指定码头卸货结算。
5. “守卫舰战后直接恢复”被替换为返港、排队、维修、重下水或重建流程。
6. “主舰失去动力后按固定时间复活”被替换为救援、拖航、英雄舰坞维修与再出航。
7. “地基只是建造前置，没有战斗意义”被替换为可受击、有生命、有承重关系的结构系统。
8. “建筑生命归零只让自身失效”被替换为地基失效可连带建筑坍塌。
9. “防守失败只扣固定资源”被替换为按本轮实际毁坏、实际建造与升级投入计算损失。
10. “防守建筑战后无条件免费恢复”被替换为布局恢复，但消耗对应维修、补充和战备资源。

### 0.3 本文不改变的内容

本文不重新设计：

- 36艘主舰的名称、品质和获取来源。
- 60名英雄的技能、进阶与抽取规则。
- 180件装备与30套装备的产出。
- 74种敌人、12种精英机制和24只Boss的主体技能。
- 方形领土扩建、生产区禀赋、固定挑战难度。

本文只补齐它们与港口建筑、实体泊位、补给、维修、防守破坏之间的关系。

# 第一部分：问题、目标与核心体验

## 1. 当前系统的主要问题

### 1.1 建筑没有改变真实行为

当前多数建筑只提供：

- 产量增加10%。
- 攻击增加5%。
- 制造速度增加15%。
- 港口繁荣增加固定值。

这些数值不会改变：

- 哪些船能靠港。
- 哪些武器能装配。
- 舰船从哪里出航。
- 舰船受伤后去哪里维修。
- 商船为什么会来。
- 生产船如何把货物送回来。
- 敌人摧毁什么才会削弱港口。

结果是玩家建造后看不到世界发生明显变化。

### 1.2 英雄、舰船与港口彼此割裂

当前英雄成长主要发生在菜单内，主舰和港口的关系只剩：

- 换装需要回港。
- 维修需要等待。
- 建筑提供少量属性。

缺少：

- 专属英雄舰泊位。
- 英雄登舰与离舰。
- 舰体模块装配设施。
- 武器弹药与英雄技能装置的整备。
- 船员疲劳、英雄负伤和舰体损伤的空间表现。
- 主舰失去动力后的拖回、抢修与重新下水。

### 1.3 守卫舰与船厂关联不足

玩家可以拥有大量防守船，却不需要考虑：

- 它们停在哪里。
- 哪些船已经补满弹药。
- 哪些船正在维修。
- 哪些船只是在锚地等待。
- 舰队多、军港少时为什么会降低防守效率。

### 1.4 港口没有“港”的感觉

港口周围若全部铺满建筑，就会出现：

- 船只穿模。
- 舰船凭空生成。
- 商船没有靠泊位置。
- 功能船在建筑中卸货。
- 大型主舰无法转向。
- 港口看起来像漂浮城市，而不是有岸线、泊位、航道和锚地的海上港区。

### 1.5 防守没有拆城压力

敌人只攻击炮塔或核心，不攻击地基，导致：

- 玩家不在意建筑结构。
- 外围地基没有防守价值。
- 敌人无法逐段撕开防线。
- 防守失败缺少可见的战损过程。
- 建筑损坏没有经济压力。

## 2. 新版一句话体验

玩家建造的不只是“提供加成的房子”，而是一座真实运转的海上港口：

> 商船因为商港而来，渔船带着远洋鱼货返港，守卫舰在军港补弹，英雄主舰在专用船坞换装；敌人从边境一步步打碎地基、撕开防墙和码头，玩家用炮塔、舰队、铁皮墙与海上陷阱守住昂贵的港口布局。

## 3. 六条核心设计原则

### 3.1 建筑必须改变至少一种真实能力

每座功能建筑至少改变以下一项：

- 解锁一种船或模块。
- 提供实体泊位。
- 提供一种服务。
- 增加一种服务的并行数。
- 改变舰队部署规则。
- 改变功能船作业链。
- 形成一条贸易或生产链。
- 提供防守空间。
- 提供侦察、控制、救援或恢复能力。

只提供“全局属性+5%”的建筑不得作为独立建筑存在。

### 3.2 百分比加成必须依附实体功能

可以保留数值加成，但必须建立在功能之上。

例如：

- 弹药库首先允许军舰补弹，升级后才提高补弹速度。
- 英雄舰坞首先允许主舰靠泊，升级后才降低大修时间。
- 商港首先允许商船到访，升级后才提高贸易议价。
- 鱼货码头首先允许渔船卸货，升级后才降低卸货损耗。

### 3.3 船多不等于立即能全部出战

舰船数量由制造和拥有上限决定。

舰船可用性由以下内容共同决定：

- 泊位。
- 补给。
- 维修。
- 航道。
- 指挥容量。
- 出航闸口。
- 舰船当前状态。

### 3.4 被毁有代价，但不永久毁号

- 战斗中建筑、地基、陷阱和舰船可以真实损坏或被摧毁。
- 战后恢复原有布局与拥有关系。
- 玩家支付一部分实际重建价值作为损失。
- 独特建筑、付费内容、传奇舰体和英雄不会永久丢失。
- 失败会疼，但不会让玩家因一次防守失去数天进度。

### 3.5 防守必须能读懂破口形成过程

玩家应能看见：

1. 敌人接近外圈。
2. 触发水雷和减速网。
3. 冲撞艇攻击铁皮墙。
4. 炮舰轰击地基。
5. 地基开裂、进水、下沉。
6. 上方建筑倾斜并失效。
7. 敌人通过缺口攻击更深层设施。

### 3.6 港口效率来自布局，而不是固定模板

布局要产生取舍：

- 岸线用来建商港，还是军港。
- 英雄舰坞放内港更安全，但出航更慢。
- 功能船码头靠近生产区效率高，但更容易遇袭。
- 弹药库靠近军港补给快，但被引爆时风险高。
- 防墙建得厚会更安全，但压缩航道和泊位空间。

# 第二部分：港口空间与水域预留

## 4. 港口空间的五层判定

| 层级 | 内容 | 是否占用建筑格 | 是否阻挡航行 |
| --- | --- | ---: | ---: |
| 领土层 | 已占领方格、禁建区、固定挑战 | 否 | 否 |
| 固体地基层 | 浮木、钢制、装甲地基 | 是 | 是 |
| 建筑功能层 | 工坊、仓库、炮塔、船坞主体 | 是 | 是 |
| 港务水域层 | 泊位、回转区、排队区、航道 | 禁止普通建筑 | 允许指定船型 |
| 动态航行层 | 舰船、敌人、鱼群、投射物 | 否 | 动态避障 |

港务水域不是实体建筑，但会锁定水面用途。

## 5. 建造码头时自动生成的禁建水域

每个码头由两部分组成：

1. 岸上或地基上的码头主体。
2. 临水侧的港务水域占用。

港务水域至少包含：

- 靠泊矩形。
- 进出通道。
- 船头回转区。
- 装卸安全带。

普通建筑、生产区实体平台和其他泊位不能与其重叠。

允许重叠的内容：

- 水面生产区的非实体范围。
- 装饰鱼群。
- 航道标线。
- 低矮导航浮标。
- 临时友军通行。

## 5.1 推荐港务水域尺寸

以2米建筑格为基础：

| 泊位级别 | 服务船型 | 主体参考占地 | 临水禁建区 | 回转区 |
| --- | --- | --- | --- | --- |
| S级小泊位 | 小舟、快艇 | 3×4格 | 4×8格 | 直径8格 |
| M级标准泊位 | 炮艇、捕鱼船、商船 | 4×6格 | 6×12格 | 直径12格 |
| L级重型泊位 | 护卫舰、大型功能船 | 6×9格 | 8×18格 | 直径18格 |
| XL英雄舰坞 | 英雄主舰、旗舰 | 10×14格 | 14×28格 | 直径28格 |

实际舰体较大时可以按模型缩放，但四级尺寸关系不变。

## 5.2 岸线连接要求

泊位必须满足：

- 主体至少一边连接可承重地基。
- 临水面无遮挡。
- 进出通道能连到公共航道。
- 服务管线能连接对应仓库或设施。
- 不与固定挑战禁建水域重叠。

## 5.3 公共航道

港口至少保留一条从外海到内港的公共航道。

推荐最小宽度：

| 航道 | 最小宽度 |
| --- | ---: |
| 小艇支路 | 8米 |
| 功能船/商船航道 | 14米 |
| 军舰主航道 | 20米 |
| 英雄主舰航道 | 28米 |

航道过窄不会让船直接穿模，而会：

- 限制可通行船级。
- 增加排队和避让时间。
- 降低紧急出航效率。
- 显示红色“瓶颈航道”提示。

## 6. 泊位、锚地与船厂不是同一个概念

| 设施 | 作用 |
| --- | --- |
| 船厂 | 制造新船、重建沉没船 |
| 泊位 | 停靠、装卸、补给、维修或编成 |
| 锚地 | 让暂时无泊位的船在水面等待 |
| 干船坞 | 对重度损坏舰船进行大修 |
| 出航闸口 | 控制舰队批次离港 |
| 调度塔 | 管理靠泊顺序和航道冲突 |

一艘船可以被制造出来，但如果没有空闲泊位：

- 先下水进入锚地。
- 无锚地容量时留在船厂占用交付位。
- 交付位被占用会暂停后续制造。

## 7. 锚地规则

锚地是划定的非建筑水域。

功能：

- 暂停泊位不足的舰船。
- 等待编队集结。
- 等待商港空位。
- 让受损舰排队进入维修泊位。

限制：

- 锚地不提供补给、维修或卸货。
- 锚地内舰船在防守中可以被攻击。
- 锚地过于靠近航道会增加拥堵。
- 过多舰船停在锚地会降低港口安全度与繁荣。

# 第三部分：港口容量体系

## 8. 五种必须分开的容量

| 容量 | 说明 | 主要来源 |
| --- | --- | --- |
| 拥有容量 | 玩家能持有多少艘该类船 | 船厂、舰队指挥中心 |
| 泊位容量 | 同时有多少艘船能停靠 | 实体码头与船坞 |
| 服务容量 | 同时能补给、维修、卸货多少艘 | 服务设施和管线 |
| 部署容量 | 一次防守可出动多少战船 | 指挥中心、出航口、水道 |
| 航道吞吐 | 单位时间进出港数量 | 航道宽度、信号塔、调度规则 |

## 8.1 港口拥堵指数

```text
Congestion =
0.30 × WaitingForBerthRatio
+ 0.25 × ChannelLoadRatio
+ 0.20 × ServiceQueueRatio
+ 0.15 × AnchorageLoadRatio
+ 0.10 × RecentCollisionRatio
```

建议显示五档：

| 数值 | 状态 |
| ---: | --- |
| 0～0.24 | 畅通 |
| 0.25～0.44 | 繁忙 |
| 0.45～0.64 | 拥堵 |
| 0.65～0.84 | 严重拥堵 |
| 0.85以上 | 港务停滞 |

拥堵影响：

- 船只等待时间。
- 商船到访意愿。
- 紧急出航速度。
- 功能船单位时间有效作业次数。

拥堵不直接降低舰船战斗属性。

## 9. 服务作业槽

一个泊位不等于同时拥有全部服务。

泊位可安装或连接：

- 弹药服务。
- 燃料服务。
- 食物与船员补给。
- 轻维修。
- 重维修。
- 货物装卸。
- 冷藏卸货。
- 危险品卸货。
- 英雄登舰。
- 舰体模块换装。

同一艘船可按顺序通过多个服务状态。

# 第五部分：英雄主舰与港口的强关联

## 11. 英雄主舰完整港口状态机

```text
外海任务
→ 返航
→ 请求英雄舰泊位
→ 进入公共主航道
→ 靠泊
→ 英雄下舰
→ 卸下战利品
→ 补充弹药/燃料/食物
→ 舰体检查
→ 轻修或转入干船坞
→ 英雄治疗/休息/训练
→ 舰体模块与英雄编成确认
→ 英雄登舰
→ 解缆
→ 离港
```

任何环节缺失时，UI必须说明真实原因。

## 12. 英雄舰泊位需求

- 每艘可驻泊英雄主舰需要1个XL英雄舰泊位。
- 同一泊位只能停1艘主舰。
- 没有泊位的主舰可以临时锚泊，但不能完成换装和完整整备。
- 锚泊主舰可以参加紧急防守，但以未完成补给的实际状态出战。
- 第2～6主舰席位解锁时，只授予“建造对应泊位”的权限，不免费生成泊位。
- 新席位任务必须同步提供建造第一个对应泊位所需的基础材料，避免卡死。

## 13. 主舰船坞功能拆分

英雄主舰船坞提供：

1. 主舰实体泊位。
2. 英雄登舰与离舰点。
3. 舰体模块更换。
4. 船规和编成保存。
5. 弹药、燃料、食物整备入口。
6. 轻度舰体维修。
7. 战利品卸载。

不提供：

- 重度舰体大修。
- 失去动力主舰重建。
- 英雄重伤治疗。
- 高级装备锻造。

这些需要其他建筑。

## 14. 英雄主舰干船坞

功能：

- 接收失去动力的主舰。
- 分阶段修复船体、武器挂点、动力、航行与生活模块。
- 在场景中显示维修进度。
- 允许玩家选择“优先恢复可出航”或“完整修复”。

### 14.1 快速抢修

恢复条件：

- 舰体生命恢复至40%。
- 主推进器可用。
- 至少一个作战挂点可用。
- 最低补给完成。

优点：

- 更快重新出航。

代价：

- 部分模块仍损坏。
- 舰体最大生命临时降低。
- 英雄技能对应挂点可能暂时禁用。

### 14.2 完整大修

- 恢复100%舰体。
- 清除结构疲劳。
- 恢复全部挂点。
- 消耗更多材料与时间。

## 15. 英雄建筑与舰队功能关联

| 建筑 | 不建造时的缺失 | 建造后的实体能力 |
| --- | --- | --- |
| 英雄招募所 | 只能通过固定剧情获得英雄 | 处理招募、线索和重复凭证 |
| 舰队训练馆 | 只能实战获得熟练度 | 派驻英雄训练、试用技能 |
| 战斗学院 | 无法学习通用战斗教材 | 解锁技能教材与战术预设 |
| 舰长议事厅 | 只能使用基础船规 | 解锁船长被动、舰队指令 |
| 英雄宿舍 | 英雄只能缓慢恢复疲劳 | 空闲英雄实体休息与快速轮换 |
| 海盗诊所 | 重伤英雄只能自然恢复 | 治疗槽、医疗资源和出院时间 |
| 装备锻造坊 | 只能穿戴掉落装备 | 强化、重铸、分解和套装管理 |
| 天赋研究室 | 只能使用默认天赋方案 | 重置、预览和保存天赋预设 |
| 主舰船坞 | 主舰只能锚泊 | 编成、换装、整备和停泊 |
| 英雄舰干船坞 | 失去动力后恢复极慢 | 拖入、大修和快速抢修 |
| 舰队指挥中心 | 多舰只能逐艘手动下令 | 多舰队列、集结、支援和驻防 |

## 16. 舰体模块解锁建筑

装配内容必须对应港口设施：

| 模块类别 | 必要建筑 | 未满足时 |
| --- | --- | --- |
| 轻型火炮 | 军械工坊 | 不能制造/更换该模块 |
| 重炮与穿甲炮 | 重炮铸造所 | 已装模块可用，但不能换装与升级 |
| 鱼雷 | 鱼雷装配库 | 无法补充高级鱼雷 |
| 水雷 | 水雷工坊 | 无法装配布雷模块 |
| 导弹 | 导弹总装塔 | 不能补充导弹弹药 |
| 无人机 | 无人机机库 | 无法补充损失的无人机 |
| 护盾 | 能量研究站 | 只能使用基础护盾 |
| 维修装置 | 舰体工程所 | 不能安装高级维修臂 |
| 声呐 | 声呐测绘站 | 无法使用高级锁定模块 |
| 冲撞头 | 重型锻压厂 | 只能安装基础撞角 |
| 捕鲸设备 | 猎鲸装备所 | 无法安装大型鱼叉 |
| 召唤/特殊核心 | 特种舰研究坞 | 只能在该坞维护 |

规则：

- 建筑被防守战打至失效时，不会立刻拆掉已装模块。
- 但战斗结束前无法在港口重新换装或补充对应特殊消耗品。
- 战后建筑恢复后功能恢复。

## 17. 英雄主舰基础属性建筑

基础属性建筑不提供无限叠加的全局百分比，而提供“舰体认证”和有限专精。

| 建筑 | 适用舰型 | 核心能力 | 数值上限 |
| --- | --- | --- | ---: |
| 装甲船体研究所 | 堡垒、重甲主舰 | 解锁装甲板槽、降低结构伤 | 同类最多+12%舰体基础生命 |
| 动力试验塔 | 高速、冲撞主舰 | 解锁推进器等级与过载 | 同类最多+10%基础航速 |
| 炮术校准台 | 炮击主舰 | 解锁重炮校准与射表 | 同类最多+10%基础命中 |
| 航空调度塔 | 无人机母舰 | 增加机库调度槽 | 主要提升召唤上限，不加全伤 |
| 深水武器所 | 鱼雷、布雷主舰 | 解锁水下弹药槽 | 提升携带量，不直接乘算英雄伤害 |
| 生态航海站 | 捕鱼护航、资源舰 | 解锁护航与侦察指令 | 提升任务效率与安全 |
| 损管训练中心 | 全舰型 | 解锁应急损管队 | 同类最多+10%基础维修 |

所有“基础属性”只作用于舰体原始面板：

```text
建筑属性收益 =
舰体原始基础属性
× 建筑认证加成
```

不乘算：

- 英雄进阶属性。
- 装备属性。
- 临时Buff。
- 其他英雄贡献。

# 第六部分：普通守卫舰与港口的强关联

## 18. 守卫舰从制造到出战的完整流程

```text
船厂制造
→ 下水交付
→ 分配军港或锚地
→ 安装标准模块
→ 补充弹药与船员
→ 编入守备编队
→ 港外巡逻或泊位待命
→ 收到警报
→ 从出航口分批离港
→ 交战
→ 生还返港/失去动力被拖回
→ 维修与补充
→ 再次待命
```

## 19. 军港类型与舰种专精

| 军港 | 重点舰种 | 提供能力 |
| --- | --- | --- |
| 快艇军港 | 拦截舟、冲撞舟、防鱼快艇 | 快速出航、低成本维修 |
| 炮艇军港 | 轻炮艇、火箭艇 | 通用弹药和炮管维护 |
| 水下武器港 | 鱼雷艇、布雷艇 | 鱼雷、水雷装填和安全存放 |
| 支援舰港 | 维修艇、补给艇、护盾艇 | 工程材料和能量充填 |
| 重型军港 | 重炮护卫舰、导弹舰 | 重弹药、重装维修 |
| 特种军港 | 雷暴舰、无人机母艇 | 特殊能源与耗材 |

舰船可以停在不匹配的军港，但只获得：

- 基础燃料。
- 基础食物。
- 最慢轻修。

不能获得：

- 专属弹药。
- 专精模块维护。
- 快速重生。

## 20. 军港数量不足的后果

当舰船数量超过有效军用泊位：

1. 多余舰船进入军用锚地。
2. 锚地舰船不能自动完成补弹和维修。
3. 防守前系统按优先级抢占泊位整备。
4. 未整备舰船可以作为后备，但可能缺弹或低血。
5. 被击沉舰船返港后会延长重生队列。

不会发生：

- 舰船永久删除。
- 舰船基础属性凭空下降。
- 因少一个泊位就整支舰队完全不可用。

## 21. 守卫舰战备状态

每艘守卫舰具有四项战备：

| 项目 | 0状态 | 100状态 |
| --- | --- | --- |
| 舰体 | 失去动力 | 完整 |
| 弹药 | 只能撞击/撤退 | 满弹 |
| 燃料 | 不能出航 | 满航程 |
| 船员战备 | 不能执行复杂策略 | 完整响应 |

综合战备：

```text
Readiness =
Min(HullReady, FuelReady, CrewReady)
× AmmoRoleFactor
```

弹药不足时，不同船型受影响不同：

- 冲撞舟仍能出战，但只能冲撞一次。
- 炮艇射击频率下降。
- 鱼雷艇无鱼雷时几乎失去作用。
- 维修艇缺工程物资时只能拖航。

## 22. 守卫舰重生逻辑

### 22.1 轻度损伤

- 返港后进入普通泊位。
- 使用轻维修。
- 不占用船厂制造位。

### 22.2 失去动力但未完全沉没

- 由拖船救回。
- 进入维修泊位。
- 保留舰船实例、经验、模块和涂装。

### 22.3 战场判定沉没

- 账号拥有关系保留。
- 战后生成“重建订单”。
- 重建占用对应船厂制造位。
- 重建成本为该舰当前标准制造成本的20%～45%。
- 重建后保留改装和经验，不重新抽取随机属性。

### 22.4 军港不足导致的重生拥堵

```text
实际恢复时间 =
基础修理或重建时间
× 损伤系数
× 舰体规模
× 港口拥堵系数
÷ 匹配维修效率
```

港少舰多时，问题表现为排队，而非莫名其妙的“复活冷却+100%”。

# 第七部分：生产船、远洋捕捞与真实入账

## 23. 生产船必须绑定装卸港

每艘功能船必须指定：

- 母港。
- 默认卸货港。
- 备用卸货港。
- 对应仓库。
- 对应生产区或任务类型。

若没有有效卸货港：

- 船只不会自动开始常规生产任务。
- UI显示“缺少可用卸货泊位”。
- 玩家可以执行一次性手动任务，但货舱满后必须等待。

## 24. 远洋捕鱼完整流程

```text
渔业码头装冰、渔网、食物
→ 捕鱼船离港
→ 穿过港口航道
→ 前往高鱼群禀赋区
→ 侦察并追踪鱼群
→ 展网/拖网/鱼叉作业
→ 鱼货进入船舱
→ 货舱满或保鲜时间临界
→ 返航
→ 在港外排队
→ 靠泊渔业码头
→ 吊机和传送带卸鱼
→ 鱼货进入冷库
→ 资源栏增加
→ 船只补网、补冰、维修
→ 再次出航
```

## 25. 鱼货入账公式

```text
实际入库鱼货 =
船上毛鱼货
× 保鲜率
× 安全返航率
× 卸货完整率
```

其中：

```text
保鲜率 =
Clamp(1 - 超出保鲜时间 × 腐损速度, 0.50, 1.00)
```

冷藏渔港和冷藏船：

- 延长保鲜时间。
- 不凭空增加捕捞量。

## 26. 远洋感的表现规则

生产船离港时：

- 船员搬运冰块、渔网和空箱。
- 船体吃水较浅。
- 甲板相对整洁。

作业时：

- 船只围绕鱼影移动。
- 拖网形成水面弧线。
- 海鸟跟随。
- 鱼群受惊逃逸。
- 船员拉网、吊鱼、分类。

满载返港时：

- 船体吃水更深。
- 甲板出现鱼箱、网具和水迹。
- 海鸟尾随。
- 远处港口信号灯引导返航。
- 船员气泡显示“满舱”“冰快不够”“今天有大货”。

卸货时：

- 货箱数量真实减少。
- 冷库门开启并出现冷雾。
- 资源数字在最后一批货完成交接时结算。
- 不能在船刚进入港口范围时立即跳资源。

## 27. 其他生产船的入账点

| 生产船 | 结算港 | 真正入账时点 |
| --- | --- | --- |
| 捕鱼船 | 渔业/冷藏渔港 | 鱼货卸入冷库 |
| 漂木船 | 木材浮运港 | 原木完成拖入和分类 |
| 采矿船 | 矿物重载港 | 矿箱吊入矿仓 |
| 打捞船 | 打捞码头 | 残骸完成称重与分拣 |
| 勘探船 | 宝物鉴定港 | 宝箱封存并完成登记 |
| 储油船 | 油品港 | 管线抽取并完成安全检查 |
| 盐业驳船 | 通用货运港 | 盐袋入库 |
| 药藻船 | 生物材料港 | 活体材料进入保育箱 |

## 28. 功能船港口不足

影响顺序：

1. 等待卸货。
2. 货舱无法清空。
3. 无法再次出航。
4. 生产区出现“船只不足”。
5. 单位时间产量下降。

这条链必须能在场景中看见：

- 港外排队。
- 码头吊机忙碌。
- 船上货箱堆积。
- 生产区空闲。

# 第八部分：商港、商船与商业往来

## 29. 没有商港就没有常规商船停靠

基础规则：

- 中立商船可以从玩家领海外经过。
- 未建商港时，只会形成装饰航线或少量海上遭遇。
- 商船不会进入港口核心区域。
- 不产生稳定贸易订单、港口税和访客消费。

建造商船码头后才解锁：

- 商船靠泊请求。
- 贸易订单。
- 货物装卸。
- 港口税。
- 商人和访客上岸。
- 商路声望。

## 30. 商船到访条件

```text
VisitScore =
TradeRouteActivity
× PortReputation
× GoodsDemandMatch
× BerthAvailability
× ChannelSafety
× CustomsEfficiency
× MarketAttraction
- CongestionPenalty
- RecentRaidPenalty
```

若没有空闲泊位：

- 商船在外港等待。
- 等待超过耐心值后离开。
- 玩家只获得少量路过繁荣，不产生完整交易。

## 31. 商船完整状态机

```text
世界航线生成
→ 发送靠港请求
→ 海关预审
→ 分配泊位
→ 进入导航航道
→ 靠泊
→ 船员系缆
→ 卸下进口货
→ 装上玩家出口货
→ 商人和访客登陆
→ 完成付款与税务
→ 离泊
→ 驶离港区
→ 最终贸易结算
```

## 32. 贸易收入分段结算

为避免商船刚靠港就刷钱：

| 阶段 | 结算内容 |
| --- | --- |
| 靠泊完成 | 不结算，只锁定订单 |
| 进口卸货 | 玩家获得已购买货物 |
| 出口装货 | 锁定玩家货物 |
| 交易确认 | 结算70%货款 |
| 商船安全离港 | 结算剩余30%、税收、声望 |

若防守中商船被击沉：

- 未装船货物不损失。
- 已装船但未离港货物按保险规则返还一部分。
- 不允许玩家故意击沉商船重复获得货物和赔偿。

## 33. 商业建筑职能

| 建筑 | 实体功能 |
| --- | --- |
| 商船码头 | 提供中型商船泊位 |
| 深水通商港 | 接纳大型远洋商船 |
| 海关税务所 | 查验、征税、违禁品事件 |
| 海鲜市场 | 消化鱼货和本地消费 |
| 拍卖浮台 | 将古物、珍稀鱼和装备残件竞价 |
| 仓储交易所 | 创建大宗长期订单 |
| 海上酒馆 | 商人、佣兵、英雄线索和任务 |
| 船员旅店 | 延长商队停留，提高访客消费 |
| 航运公会 | 解锁定期商路和护航委托 |
| 保险行 | 降低贸易与防守货物损失 |

## 34. 通商港的可见表现

港口繁忙程度必须反映真实数据：

- 空闲：栈桥空、吊机停、仓库门关闭。
- 有船请求：远处旗帜和入港灯。
- 靠泊：拖船协助、船员抛缆。
- 装卸：吊机、货箱、驳车、人流。
- 高繁荣：多旗帜、摊位、访客、夜间灯火。
- 拥堵：港外多船排队、喇叭声、警告气泡。
- 受袭后：商船减少、保险与护航需求提高。

# 第九部分：建筑职能全面分类

## 35. 建筑一级分类

建造菜单统一分为：

1. 地基与结构。
2. 港务与泊位。
3. 生产与加工。
4. 仓储与物流。
5. 商业与生活。
6. 船厂与制造。
7. 英雄与主舰。
8. 军事训练与研究。
9. 固定防御。
10. 防线与障碍。
11. 陷阱与消耗品。
12. 能源、维修与公共服务。
13. 装饰与繁荣。

## 36. 建筑卡片必须显示的职能

每张建筑卡片显示：

- 提供什么实体能力。
- 服务对象。
- 需要多少地基承重。
- 需要多少临水禁建区。
- 需要何种航道。
- 提供几个泊位或作业槽。
- 关联哪些船型、英雄或模块。
- 被摧毁后会让哪些系统失效。
- 防守损失上限。

## 41. 地基核心属性

每个地基单元拥有：

- 最大生命。
- 当前生命。
- 装甲类型。
- 浮力。
- 承重上限。
- 当前承重。
- 火灾抗性。
- 爆炸抗性。
- 腐蚀抗性。
- 锚固强度。
- 相邻结构连接。
- 战斗损伤等级。

## 42. 建筑与地基依赖

建筑部署时记录其覆盖的全部地基格。

```text
SupportRatio =
仍有效的支撑地基格
/ 建筑要求的支撑地基格
```

推荐状态：

| 支撑率 | 建筑状态 |
| ---: | --- |
| 75%以上 | 正常工作 |
| 50%～74% | 倾斜受损，效率-35%，停止升级 |
| 25%～49% | 严重失稳，停止主要功能 |
| 低于25% | 坍塌/沉没，本轮摧毁 |

重型建筑可要求更高阈值。

## 43. 防止“一格地基带走整栋建筑”

- 建筑不能只依赖中心点地基。
- 伤害按实际覆盖与爆炸范围分配。
- 单个2米地基格被毁不会直接让10×10建筑消失。
- 地基失效根据支撑率和关键支撑点共同判断。
- 关键支撑点至少有2～4个，不能只有一个。

## 44. 地基连锁坍塌规则

当建筑因地基失效坍塌：

- 建筑停止功能。
- 对邻近小范围地基造成坠落伤害。
- 不无限递归引发全港口连环爆炸。
- 单次坍塌传播最多1层。
- 相邻装甲分舱地基可以隔断传播。

## 45. 地基被攻击的表现阶段

| 生命 | 表现 |
| ---: | --- |
| 100%～76% | 正常，轻微弹痕 |
| 75%～51% | 木板裂缝/铁皮凹陷、少量进水 |
| 50%～26% | 明显倾斜、浪花涌入、警示灯 |
| 25%～1% | 剧烈晃动、断梁、船员撤离 |
| 0% | 断裂、下沉、上方建筑坍塌 |

## 46. 建筑危险品连锁

以下建筑被毁时有特殊后果：

| 建筑 | 战斗后果 |
| --- | --- |
| 弹药库 | 局部爆炸，附近建筑受伤 |
| 油品港/燃料罐 | 形成短时火海 |
| 冷库 | 冷雾泄漏，附近减速但不高伤 |
| 导弹总装塔 | 未锁定导弹殉爆，可被拦截 |
| 水雷工坊 | 安全系统失效后延迟爆炸 |
| 能量站 | EMP脉冲，短时关闭友军设备 |

规则：

- 必须有明显危险标识。
- 建造预览显示殉爆半径。
- 消防站、隔爆墙和分舱地基可以降低连锁。
- 不允许一次爆炸无预警摧毁半个港口。

## 49. 港口目标评分

```text
StructureTargetScore =
路径接近度 × 0.20
+ 职责匹配度 × 0.20
+ 破坏后通路收益 × 0.18
+ 功能价值 × 0.14
+ 当前脆弱度 × 0.10
+ 编队指令 × 0.08
+ 最近仇恨 × 0.05
+ 可读性修正 × 0.05
- 过度集火惩罚
- 无法到达惩罚
- 已注定摧毁惩罚
```

## 50. “优先打附近地基”的准确规则

敌人不是无脑攻击任意地基。

满足以下条件时提高地基优先级：

- 地基挡住前往战术目标的最短可行路线。
- 地基支撑高价值建筑。
- 地基已低于50%生命。
- 爆破单位可以形成有价值缺口。
- 当前没有更高优先级的直接威胁。

普通远程敌人不会所有人同时转火同一块2米地基。

## 51. 敌人逐步推进

标准进攻流程：

```text
侦察边境
→ 选择外圈薄弱防区
→ 扫雷/诱爆陷阱
→ 冲撞或炮击防墙
→ 打开第一处航道缺口
→ 压制附近炮塔
→ 爆破支撑地基
→ 摧毁军港或补给设施
→ 阻断守卫舰再出航
→ 向内港与核心推进
```

每一步都应改变战况。

## 52. 防止敌人拆家无解

- 爆破地基前必须有放置、钻孔或蓄力动作。
- 重炮轰击地基显示落点与弹道。
- 章鱼刺击显示水下阴影和水面鼓包。
- 鲸鱼冲撞显示方向、浪墙和吼声。
- 玩家可以摧毁爆破单位、击退、控制或维修目标。
- 同一时刻攻击关键地基的W3以上威胁不超过2个。
- 镜头外地基被攻击时提供边缘方向提示。

# 第十四部分：陷阱系统

## 56. 陷阱与防御建筑的区别

陷阱具有：

- 建造成本较低。
- 需要预先布置。
- 一次或有限次数触发。
- 可以被发现、扫除、诱爆。
- 战后需要补充消耗品。
- 不占用大型建筑承重，但占用陷阱槽或水域。

## 58. 陷阱布置层

陷阱占用12米生产区格内的子槽，不与普通建筑格完全相同。

规则：

- 同一2米位置不能重叠两种实体陷阱。
- 生产区可允许低密度陷阱，但会降低功能船安全。
- 公共主航道默认禁止自动布雷。
- 玩家强制布置时必须设置友军识别或绕行路线。
- 商港航道不能布置未识别水雷。

## 59. 陷阱友军规则

默认：

- 玩家舰船不会直接触发己方感应雷。
- 但会受到己方陷阱被敌人引爆后的范围伤害20%。
- 减速网会对大型友舰产生轻微航行影响。
- 火油和爆破木筏具有真实友伤风险。

玩家必须为高风险陷阱选择：

- 安全模式：伤害低、无友伤。
- 战斗模式：伤害高、存在有限友伤。

## 60. 陷阱补充

战后：

- 已触发陷阱保留在布局中。
- 自动生成补充订单。
- 补充消耗对应弹药、金属、纤维或能源。
- 未补充前显示空壳、断网或熄灭状态。
- 玩家可以设置“仅在高威胁防守自动补充”。

# 第十五部分：防守战损与资源损失

## 61. 战斗中的摧毁与战后的恢复

战斗内：

- 地基可以断裂下沉。
- 建筑可以爆炸、坍塌和停止工作。
- 泊位可以失效。
- 舰船可以沉没。
- 陷阱可以耗尽。

战斗结束后：

- 原布局蓝图完整保留。
- 建筑和地基生成维修/重建状态。
- 玩家不需要重新手动摆放。
- 支付资源并等待修复后恢复。
- 可使用“一键战后恢复”按优先级处理。

## 62. 建造价值记录

每个建筑实例记录实际投入：

```text
InvestedCost =
初建实际消耗
+ 历次升级实际消耗
+ 已安装模块实际消耗
+ 当前库存中的专用消耗品
- 已返还或拆除部分
```

记录资源种类，不只换算成金币。

促销、任务减免或建筑折扣：

- 按玩家实际支付记录。
- 不按原价收取战损。

## 63. 战损等级

| 战斗结束状态 | 损失系数 |
| --- | ---: |
| 轻伤：生命50%以上 | 0%～1% |
| 重伤：生命1%～49% | 2%～5% |
| 本轮摧毁 | 6%～12% |
| 地基连带坍塌 | 5%～10% |
| 危险品殉爆 | 8%～14% |

推荐初始版本使用：

- 重伤：实际投入的3%。
- 主动被摧毁：实际投入的8%。
- 连带坍塌：实际投入的6%。
- 陷阱按真实补充成本结算，不再额外乘建筑损失。

## 64. 最终战损公式

```text
ResourceLossByType =
InvestedCostByType
× DamageStateRate
× DifficultyRate
× RepeatProtection
× InsuranceRate
× AutoDefenseRate
```

建议系数：

| 项目 | 推荐范围 |
| --- | ---: |
| 难度I～II | 0.60～0.80 |
| 难度III～IV | 0.90～1.10 |
| 难度V～VI | 1.15～1.35 |
| 同日首次失败保护 | 0.70 |
| 连续失败第2次 | 0.55 |
| 连续失败第3次及以后 | 0.40 |
| 基础保险 | 0.85 |
| 高级保险 | 0.65 |
| 离线自动防守 | 0.65～0.80 |

## 65. 单场损失上限

为防止一次失败摧毁长期积累：

```text
单场可扣损失上限 =
Min(
本轮毁坏建筑计算损失,
港口可动基础资源库存 × 15%,
该难度标准防守收益 × 2.5
)
```

不计入可扣库存：

- 充值货币。
- 抽奖券。
- 英雄和主舰。
- 唯一蓝图。
- 传奇装备。
- 任务关键物品。

## 66. 资源不足时

如果修复资源不足：

- 不产生负数资源。
- 建筑保留“待修复”状态。
- 可分批修复。
- 港口核心、一个基础泊位和基础资源链拥有最低恢复保障。
- 系统给出对应资源的可追踪产出。
- 不允许玩家因防守失败进入永久无法生产、无法出航的死锁。

## 67. 修复优先级

一键修复默认：

1. 港口核心与供能。
2. 主航道和必要闸门。
3. 英雄主舰泊位。
4. 军港与守卫舰出航口。
5. 基础生产卸货港。
6. 仓库与物流。
7. 防御塔和防墙。
8. 商业建筑。
9. 装饰。

玩家可以保存修复预设。

## 68. 失败与胜利的战损差异

| 结果 | 规则 |
| --- | --- |
| 完胜 | 重伤建筑少量维护，摧毁建筑按低系数修复 |
| 险胜 | 正常计算战损 |
| 核心受损但守住 | 损失提高，获得防守奖励 |
| 防守失败 | 正常战损+部分未入库货物损失 |
| 主动撤离 | 保留更多舰船，港口外围承受更高结构损失 |
| 离线防守 | 使用保护系数，不出现不可控巨额损失 |

# 第十六部分：防守中的港口服务失效

## 69. 建筑被毁必须真实影响战斗

| 被毁设施 | 即时后果 |
| --- | --- |
| 快艇军港 | 后备小艇无法继续出航 |
| 重型军港 | 重舰补给和增援暂停 |
| 英雄舰泊位 | 尚未出航主舰无法从该泊位离港 |
| 弹药库 | 周围炮塔弹药恢复停止 |
| 维修站 | 战中抢修停止 |
| 舰队指挥中心 | 高级编队指令关闭 |
| 声呐站 | 潜水敌人重新隐蔽 |
| 能量站 | 护盾、雷暴和部分设施进入低功率 |
| 调度塔 | 港内船只排队效率下降 |
| 商港 | 商船紧急离港或停止装卸 |
| 渔港 | 返港渔船转向备用港或在外等待 |

已出航舰船不会因母港失效而立刻爆炸或消失。

## 70. 港口紧急战时调度

进入防守警报后：

- 商船停止新靠泊。
- 正在装卸的商船决定紧急离港或留港避难。
- 功能船停止离港并优先返航。
- 军港泊位转为战斗优先。
- 拖船清理主航道。
- 英雄主舰进入快速整备。
- 弹药库开放战时储备。
- 港务信号灯切换为红色。

## 71. 紧急征用

玩家可以临时征用民用泊位：

- 功能船码头可为小型守卫舰提供基础补给。
- 商港可临时停靠护卫舰。
- 会中断生产和贸易。
- 服务效率只有专业军港的40%～60%。
- 战后产生额外维护成本。

此功能防止军港被毁后完全无解，同时保留专业设施价值。

# 第十七部分：战斗流程与典型防守局

## 72. 防守准备阶段

玩家可以查看：

- 来袭方向。
- 敌人拆港职责。
- 预计重击类型。
- 推荐防墙。
- 推荐陷阱。
- 军舰战备。
- 主舰抵达时间。
- 商船和功能船撤离进度。
- 高价值建筑风险。

可执行：

- 调整舰队预设。
- 临时关闭商港。
- 召回功能船。
- 补充陷阱。
- 调整闸门。
- 标记重点维修地基。
- 使用一次有限的港务重新调度。

## 73. 标准防守时间线

### 73.1 侦察期

- 远方出现船影、烟柱、背鳍。
- 声呐站识别敌人类型。
- 功能船开始返航。

### 73.2 外围接触

- 敌人接触雷区与诱饵。
- 扫雷单位和先遣小舟出场。
- 远程敌人测距。

### 73.3 破墙期

- 冲撞艇、鲸类或爆破单位攻击外墙。
- 防御塔获得清晰集火窗口。
- 玩家决定是否提前引爆油囊。

### 73.4 拆基期

- 敌人攻击关键地基。
- 维修艇和战地维修塔抢修。
- 地基低血预警扩大。

### 73.5 港区混战

- 缺口形成。
- 友军舰队从内港出航。
- 敌人攻击军港、弹药与调度设施。

### 73.6 核心压力

- Boss或攻城舰进入。
- 剩余防线和主舰共同作战。
- 已毁军港无法继续放出后备舰。

### 73.7 战后

- 敌人撤退或被消灭。
- 舰船拖回。
- 消防、救援和维修船进入。
- 统计实际战损。
- 布局以损坏状态恢复。

## 74. 典型敌人组合

| 编队 | 构成 | 对港口的考题 |
| --- | --- | --- |
| 冲撞破口队 | 冲撞舟+烟雾艇+炮艇 | 偏转墙、近防和后排识别 |
| 爆破拆基队 | 爆破筏+护盾艇+机炮舟 | 抢杀爆破单位 |
| 火焰纵火队 | 焚海船+爆破筏 | 木基隔离与消防 |
| 水下封港队 | 鱼雷艇+布雷艇+潜艇 | 声呐、扫雷与出口保护 |
| 重炮攻城队 | 重炮舰+维修护卫舰 | 远程反炮和切支援 |
| 巨兽撞港队 | 鲸类Boss+鲨群 | 深锚桩、诱导撞击 |
| 章鱼拆坞队 | 章鱼Boss+寄生蟹 | 触手弱点与地基抢修 |
| 劫掠商港队 | 高速盗艇+信号舟 | 保护货物和商船撤离 |

# 第十八部分：表现规则

## 75. 港口常态表现

港口需要持续展示：

- 船只靠泊和离泊。
- 锚地等待。
- 拖船协助大型舰转向。
- 英雄上下舰。
- 弹药箱、燃料管、鱼箱和矿箱移动。
- 船厂逐步制造舰体。
- 军舰甲板装弹。
- 功能船满载返港。
- 商人、船员和访客在栈桥移动。

## 76. 泊位识别

不同泊位使用不同视觉语言：

| 泊位 | 视觉 |
| --- | --- |
| 渔港 | 蓝白浮标、鱼箱、渔网 |
| 矿港 | 黄黑吊机、重载轨道 |
| 商港 | 彩旗、海关牌、货箱 |
| 轻军港 | 红色编号、弹药车、快速闸门 |
| 重军港 | 装甲防波堤、重吊机 |
| 英雄舰坞 | 舰队徽记、英雄登舰桥、专属灯光 |
| 维修坞 | 脚手架、焊花、损管船员 |

## 77. 建筑损坏表现

必须区分：

- 受到攻击。
- 功能受限。
- 地基失稳。
- 本轮摧毁。
- 战后待修。
- 正在修复。
- 恢复完成。

不能全部只用冒黑烟。

## 78. 地基下沉表现

流程建议：

1. 命中产生材质破损。
2. 浮筒破裂或钢梁变形。
3. 海水涌上平台。
4. 平台向受损侧倾斜。
5. 上方货箱和小物体滑动。
6. 船员撤离。
7. 结构断开并局部下沉。
8. 建筑坍塌生成大水花。
9. 留下低矮残骸，不长时间阻塞全航道。

## 79. 陷阱表现

陷阱要同时满足可识别与不杂乱：

- 己方陷阱有淡色范围与状态灯。
- 敌人发现陷阱后出现扫雷光束或警告动作。
- 海雷爆炸先有水下闪光，再有水柱。
- 减速网展开时显示网绳张力和船体拖拽。
- EMP使用蓝白脉冲，不与雷电伤害完全相同。
- 陷阱耗尽后保留破损浮标或空挂架。

## 80. 战损结算表现

战后镜头不要逐个强制播放。

默认：

- 拉高镜头显示受损区域热图。
- 高亮3个最大损失来源。
- 显示“哪个地基坍塌带走了哪些建筑”。
- 显示军舰与主舰恢复队列。
- 显示陷阱补充和资源损失。

玩家点击任意损失项可定位现场。

## 91. 服务时间公式

```text
ServiceTime =
BaseTime
× ShipSize
× RequiredAmountRatio
× DamageFactor
× CongestionFactor
÷ FacilityEfficiency
÷ WorkerEfficiency
```

## 95. 防守经济目标

稳定刷取已通关防守：

- 平均战损不超过基础收益的15%～25%。

- 连续失败保护会快速降低损失。
- 陷阱补充属于玩家主动选择的战备投入，应在战后单独显示。

# 第二十二部分：成长展开

## 96. 前5分钟

解锁：

- 1个简易通用栈桥。
- 1艘基础捕鱼舟。
- 1个小型渔业卸货点。
- 第一段临时浮木地基。
- 1艘基础拦截小舟。

教学：

1. 捕鱼舟离港。
2. 捕鱼舟满载返港。
3. 靠泊并卸货。
4. 肉类资源在卸货后入账。
5. 玩家看到“港口不是自动跳资源”。

不开放：

- 地基连锁坍塌。
- 复杂战损。
- 商港拥堵。

## 97. 5～15分钟

解锁：

- 轻型军港。
- 基础弹药补给。
- 2个防御塔。
- 浮木挡板。
- 第一种触发海雷。

教学：

- 军舰需要补弹。
- 海雷是消耗品。
- 敌人会攻击外墙，但暂不攻击复杂关键地基。

## 98. 15～30分钟

解锁：

- 英雄主舰船坞。
- 英雄登舰、离舰和完整整备。
- 渔港升级。
- 港务水域覆盖层。
- 锚地。

教学：

- 主舰没有泊位只能锚泊。
- 泊位需要预留回转水域。
- 船多港少会排队。

## 99. 30～60分钟

# 第二十三部分：港区专精

## 104. 港区不是行政标签，而是功能集合

连续建筑与水域可形成港区：

- 渔业港区。
- 工业港区。
- 通商港区。
- 轻军港区。
- 重军港区。
- 英雄舰港区。
- 维修与救援港区。
- 外围防御区。

## 105. 港区形成条件

例如英雄舰港区：

- 至少1个英雄主舰船坞。
- 至少1个主舰服务建筑。
- 连接舰队指挥中心。
- 连接主航道。
- 拥有最低安全与维修覆盖。

形成后解锁：

- 专属港区标识。
- 更完整的调度规则。
- 小幅效率加成。
- 更丰富的船员和英雄表现。

## 106. 港区专精取舍

每个港区只可选择一个专精：

### 渔业港区

- 快速周转：卸货快。
- 远洋冷链：保鲜强。
- 珍稀拍卖：稀有鱼价值高。

### 军港区

- 快速反应：出航快。
- 持续战备：补弹快。
- 低损维修：战后成本低。

### 英雄舰港区

- 远征整备：补给强。
- 舰体改装：换装快。
- 损管救援：大修快。

### 通商港区

- 大宗货运：容量高。
- 稀有贸易：特殊订单多。
- 安全保险：战时损失低。

# 第二十四部分：离线与自动防守

## 107. 离线模拟原则

离线不能逐帧模拟所有靠泊，但必须保留因果：

1. 计算可用泊位和服务吞吐。
2. 计算功能船作业周期。
3. 只有完成卸货的货物入库。
4. 计算商船到访和实际装卸批次。
5. 计算守卫舰战备恢复。
6. 结算防守损伤和保护系数。
7. 生成可读报告。

## 108. 离线生产上限

```text
有效离线产出 =
Min(
理论作业产出,
泊位卸货吞吐,
仓储剩余容量,
功能船周转能力
)
```

## 109. 离线防守保护

- 不在离线时永久删除内容。
- 使用0.65～0.80战损系数。
- 连续离线失败触发最低港口保障。
- 核心泊位与基础生产链优先恢复。
- 离线不会消耗玩家锁定为“手动使用”的稀有陷阱。

## 110. 离线报告

显示：

- 船只完成多少次作业。
- 因泊位不足损失多少潜在时间。
- 商船完成多少次交易。
- 哪些舰船仍在维修。
- 哪些防区受到攻击。
- 地基、建筑、陷阱和舰船损失。
- 推荐扩建哪个泊位或修复哪段防线。

| `PortPresentationDirector` | 船流、吊机、船员、损坏和拥堵表现 |

## 122. 泊位分配优先级

默认：

1. 失去动力并被拖回的英雄主舰。
2. 低血紧急返航舰船。
3. 防守警报中的军舰。
4. 货物即将腐损的功能船。
5. 已接受限时订单的商船。
6. 普通功能船。
7. 非紧急访客船。

玩家可以对港区修改，但不能让低血救援船永远饿死。

## 123. 港口路径规则

- 码头路径使用水面导航图。
- 建造/摧毁实体后局部重烘焙。
- 港务水域用于预约，不直接作为碰撞。
- 大型舰使用回转轨迹，不做原地旋转。
- 船只等待时优先进入锚地，不堵住主航道。
- 战斗中允许紧急航行简化，但不穿越固体建筑。

## 124. 地基支撑更新

只在以下事件重新计算：

- 地基被建造或拆除。
- 地基跨过损伤阈值。
- 建筑建造、升级或坍塌。
- 爆炸造成批量损坏。

不每帧遍历全港地基。

## 125. 战损结算顺序

```text
记录战斗结束状态
→ 计算地基与建筑损伤
→ 识别连带坍塌
→ 计算舰船修理/重建
→ 计算陷阱补充
→ 计算未入库货物损失
→ 应用难度、保险与连续失败保护
→ 应用单场上限
→ 生成资源分类账
→ 恢复布局为待修状态
```

## 127. 地基表现优化

- 地基逻辑保持2米格。
- 视觉模型按连续区域合批。
- 损坏材质使用分级参数，不为每格生成独立高模。
- 坍塌只拆分可见附近区域。
- 远处坍塌使用代理水花和残骸。

## 128. 陷阱预算

推荐同屏：

- 实体可交互陷阱不超过40个。
- 远处陷阱合并为区域代理。
- 连锁雷阵使用同一调度器分批爆炸。
- 网具使用简化骨骼或曲线，不为每根绳独立模拟。

## 129. 港口船员预算

- 近景30～50名可见船员代理。
- 港区视图使用10～20组人流代理。
- 英雄始终高于普通船员LOD。
- 装卸繁忙程度可以通过货箱、吊机和音效补足，不必堆满NPC。

# 第二十八部分：旧内容迁移

## 130. 旧码头迁移

旧存档中的码头：

- 保留等级、位置和投入。
- 自动转换为最接近的新码头类型。
- 根据临水方向生成港务水域。
- 若水域与现有建筑冲突，进入“历史布局宽限”。

宽限状态：

- 码头仍可使用。
- 不允许继续升级。
- 玩家移动冲突建筑后恢复正常。
- 提供一次免费移动码头或冲突建筑的机会。

## 131. 旧舰船迁移

- 所有已拥有舰船保留。
- 自动分配现有可用泊位。
- 多余舰船进入免费临时锚地。
- 临时锚地持续到玩家完成港务教学和一次扩建。
- 不因新规则直接让旧舰船失去战备。

## 132. 旧主舰迁移

- 已解锁主舰席位保留。
- 已拥有主舰保留。
- 根据主舰数量赠送有限的“英雄舰泊位改造券”。
- 改造券只用于完成旧系统迁移，不进入长期商业化。

## 133. 旧建筑百分比迁移

旧建筑若只提供全局百分比：

1. 保留原建筑外观和投入。
2. 转换为对应职能建筑。
3. 原加成转换为有限认证或服务效率。
4. 超过新上限的部分转换为升级材料。

## 134. 旧防守损伤迁移

- 迁移当天不追溯旧战损。
- 第一次新版防守提供战损保护。
- 首次地基坍塌只做教学，不收取完整损失。
- 玩家完成防线改造任务后再启用标准战损。

# 第三十一部分：验收清单

## 148. 港口空间

- [ ] 码头主体和临水禁建区分开判定。
- [ ] 玩家能看见泊位、航道、回转区和锚地。
- [ ] 普通建筑不能占用泊位水域。
- [ ] 水面生产区仍允许舰船穿过。
- [ ] 大型舰不能通过过窄航道。
- [ ] 港口至少保留一条有效公共航道。

## 149. 英雄主舰

- [ ] 每艘驻泊主舰需要实体英雄舰泊位。
- [ ] 主舰无泊位时进入锚地而非消失。
- [ ] 主舰真实完成返航、补给、维修和再出航。
- [ ] 英雄能在港口上下舰。
- [ ] 主舰失去动力后进入拖航和大修。
- [ ] 快速抢修与完整大修结果不同。

## 150. 守卫舰

- [ ] 守卫舰由船厂制造并由军港保障。
- [ ] 舰船多、军港少时形成可见排队。
- [ ] 弹药不足会改变舰船实际战斗行为。
- [ ] 军港被毁后后备舰无法继续出航。
- [ ] 已出航舰船不会因军港失效直接消失。
- [ ] 沉没舰船保留实例并进入重建。

## 151. 功能船

- [ ] 功能船必须绑定卸货港。
- [ ] 生产资源在卸货完成后入账。
- [ ] 远洋船有出航、作业、满载、返航和卸货表现。
- [ ] 泊位不足会真实减少生产周转。
- [ ] 冷藏只降低腐损，不凭空增加捕捞量。
- [ ] 仓库满时功能船停止无限出航。

## 152. 商业

- [ ] 没有商港时商船不会进入港口交易。
- [ ] 商船必须申请、靠泊、装卸和离港。
- [ ] 商船等待过久会放弃靠港。
- [ ] 贸易收益不会在商船生成时直接结算。
- [ ] 商港拥堵与安全影响来访。
- [ ] 商船被击沉没有重复赔偿漏洞。

## 153. 建筑职能

- [ ] 每座功能建筑至少解锁一种真实能力。
- [ ] 纯全局百分比建筑已删除或转换。
- [ ] 舰体模块对应明确维护建筑。
- [ ] 建筑被毁会关闭对应港口功能。
- [ ] 同名建筑不能无限叠加战斗倍率。
- [ ] 建筑卡片显示服务对象与失效后果。

## 154. 地基

- [ ] 地基有生命、护甲、浮力和承重。
- [ ] 敌人可以攻击地基。
- [ ] 单格地基不会无条件带走整栋大建筑。
- [ ] 支撑率决定建筑状态。
- [ ] 地基坍塌表现清晰。
- [ ] 连锁坍塌最多传播一层。
- [ ] 危险品连锁有预警和隔断手段。

## 155. 敌人拆港

- [ ] 不同敌人有明确拆港职责。
- [ ] 敌人优先攻击有战术价值的附近地基。
- [ ] 爆破、触手和冲撞都有可读前摇。
- [ ] 敌人逐步形成缺口而非直接瞬移核心。
- [ ] 同时攻击关键地基的重威胁受预算限制。
- [ ] 玩家能通过控制、击杀、修理和诱导反制。

## 156. 防线与陷阱

- [ ] 重型铁皮墙与普通木墙功能不同。
- [ ] 斜面墙可以真实偏转冲撞路线。
- [ ] 闸门影响友军出航。
- [ ] 海雷和减速网可以被扫除或破坏。
- [ ] 陷阱战后保留布局但需要补充。
- [ ] 友军识别和有限友伤规则明确。

## 157. 战损

- [ ] 战损按建筑实际建造与升级消耗计算。
- [ ] 折扣建造不会按原价收取损失。
- [ ] 重伤、主动摧毁和连带坍塌系数不同。
- [ ] 有连续失败保护。
- [ ] 有单场损失上限。
- [ ] 不扣充值货币、英雄、主舰、传奇装备和唯一物品。
- [ ] 资源不足不会导致永久死锁。
- [ ] 战后恢复原布局，不要求重新摆放。

## 158. 表现与UI

- [ ] 玩家能从场景看出船为什么等待。
- [ ] 不同泊位视觉可区分。
- [ ] 满载功能船与空船外观不同。
- [ ] 港口受袭时商船、功能船和军舰行为改变。
- [ ] 战后可定位最大损失和坍塌链。
- [ ] UI明确显示缺少的泊位、服务或建筑。
- [ ] 多处损坏时信息不会淹没主舰战斗。

## 159. 离线

- [ ] 离线资源受真实卸货吞吐限制。
- [ ] 离线商贸受商港容量限制。
- [ ] 离线防守使用保护系数。
- [ ] 离线不会消耗锁定的稀有陷阱。
- [ ] 离线报告能说明拥堵与战损原因。

# 第三十二部分：最终核心规则摘要

1. 港口建造必须预留实体泊位、进出通道和回转水域，预留区禁止普通建筑占用。
2. 没有对应码头，商船、军舰、英雄主舰和生产船就不能完成对应的靠泊服务。
3. 船厂负责制造，泊位负责停靠，服务设施负责补给和维修，锚地只负责等待。
4. 英雄主舰必须在英雄舰坞完成编成、换装和整备；失去动力后进入拖航与干船坞大修。
5. 守卫舰必须依赖军港补弹、维修和重新出航；舰多港少会形成真实重生与战备拥堵。
6. 功能船必须真实远洋作业、返港并卸货，货币与资源才进入仓库。
7. 没有通商港就不会有稳定商船停靠，也不会产生完整商业往来。
8. 建筑必须解锁实体能力或服务，不再以纯全局百分比作为主要价值。
9. 地基拥有生命、承重与支撑关系；地基被毁后，上方建筑会失效或坍塌。
10. 敌人会根据职责逐步扫雷、破墙、拆地基、摧毁军港和补给，再向核心推进。
11. 防线扩充为木墙、重型铁皮墙、斜面防撞墙、分舱墙、隔爆墙、巨兽桩等多种职责。
12. 新增海上炸弹、水雷、减速网、鱼叉绊索、油囊、EMP雷、诱饵等陷阱。
13. 陷阱保留布局，但每次触发后需要真实补充。
14. 防守中建筑可以彻底爆掉，但战后恢复原布局为待修状态，不永久删除。
15. 战损按该建筑实际建造、升级和模块投入的一定百分比计算。
16. 推荐重伤损失3%、主动摧毁8%、连带坍塌6%，再乘难度、保险和失败保护。
17. 单场损失有库存与难度收益双重上限，不允许一次失败摧毁长期账号进度。
18. 港口效率最终由岸线、泊位、服务、航道、舰队、建筑职能与防线共同决定。

## 结语

新版港口的价值不再是“建造越多，面板数字越高”，而是形成一个可以观察、可以理解、可以优化，也可以被敌人逐层破坏的真实系统。

玩家会因为新的渔港，看见远洋渔船满载归来；因为新的商港，看见商船排队、装货和离港；因为新的军港，看见守卫舰补弹、维修和重新投入防线；因为英雄舰坞，看见英雄登舰、主舰换装和重伤舰体被拖入干船坞。

当敌人进攻时，玩家守护的也不再只是一个抽象核心，而是自己亲手规划的岸线、航道、泊位、舰队、生产链和商业网络。
