# 《吞吞舰船》舰船行为、战术 AI、编队操舵与自然寻路完整重构文档

> 文档类型：海盗生涯舰船行为与航行底层增量重构  
> 适用范围：英雄主舰、随行舰、港口守卫舰、敌舰、商船、生产船、维修与拖航船  
> 核心目标：让不同舰种真正按照自己的战斗职责行动，并让所有舰船在建造、港口、航道、生产区和战场中自然航行，不再穿过建筑、原地抖动或机械追点  
> 文档原则：新建独立文档，不修改旧文档；本文只替换舰船行为、编队、操舵和寻路规则  

---

# 第一部分：与旧文档的关系

## 0.1 继续保留的既有规则

以下规则继续有效：

- 世界使用48米领海方格、12米生产区格和2米建筑基础格。
- 世界、港口、生产、航行与战斗处于同一张无缝地图。
- 水面生产区占用建造规划空间，但生产区整体不阻挡航行。
- 地基、建筑、码头、吊机、平台、炮塔、防墙、水雷、残骸等实体按自身碰撞规则参与航行阻挡。
- 固定挑战区不可占领、不可建造，并具有独立的入口和战斗边界。
- 玩家同一时间直接控制一艘主舰，其他随行舰由AI执行编队命令。
- 主舰、守卫舰和功能船不能通过传送替代真实航行。
- 功能船必须真实出航、作业、装载、返港、靠泊和卸货，资源才进入仓库。
- 商船必须完成申请、靠泊、装卸和安全离港，贸易才完成结算。
- 守卫舰被击沉后进入维修或重建流程，不会永久从账号删除。
- 英雄主舰失去动力后可被拖回英雄舰坞，不会永久丢失。
- 港口最小推荐航道宽度继续采用：

| 船级 | 最小推荐航道宽度 |
| --- | ---: |
| 小艇 | 8米 |
| 功能船、普通商船 | 14米 |
| 普通军舰 | 20米 |
| 英雄主舰、旗舰 | 28米 |

## 0.2 本文正式替换的旧规则

以下旧做法统一废除：

1. 舰船只用一个目标点做直线移动。
2. 所有舰种共用“发现敌人后追到攻击距离”的行为。
3. 炮船、鱼雷艇、布雷艇与冲撞船仅有属性差异，没有空间行为差异。
4. 只把目标位置送给NavMeshAgent或简单A*，不考虑舰体长度、转弯半径和制动距离。
5. 局部避障失败后临时关闭碰撞或直接穿过建筑。
6. 多船拥堵时每艘船各自抢路，导致对顶、抖动、绕圈和港口堵死。
7. 舰船到达泊位时瞬间吸附、瞬间转向或穿过码头完成靠泊。
8. 目标死亡、道路变化或建筑被摧毁后，每帧重新计算完整路径。
9. 编队位置是刚性跟随点，船只为了回槽位强行横穿队友。
10. 战斗AI只按距离选目标，不考虑职责、威胁、射界、友军、建筑和撤退路线。

## 0.3 本文解决的核心问题

本文必须同时解决五类问题：

- **舰种不聪明**：冲撞船不撞、炮船贴脸、鱼雷艇正面对射、布雷艇随地丢雷。
- **船体不自然**：原地旋转、急停、倒车过多、左右抖动、像悬浮单位而不是船。
- **寻路会穿建筑**：只计算中心点，没有把整条船体和转弯轨迹纳入路径判定。
- **多船会互相卡住**：每艘船独立寻路，没有车道、优先级、队列和编队共享路径。
- **港口不真实**：船不会排队、让行、转向、靠泊、离泊和绕开装卸区域。

# 第二部分：新版体验目标

## 1. 一句话体验

> 玩家放出的每艘船都像真正理解自己职责：冲撞船寻找加速走廊撞向高价值目标，炮船以侧舷对敌并边打边拉开，鱼雷艇绕向目标侧面，布雷艇在敌人将要经过的航线上设伏，维修艇躲在前排后方抢修；它们会沿真实航道航行、互相让行、绕过港口建筑并自然靠泊。

## 2. 玩家能够直接观察到的变化

### 2.1 同样一个敌人，不同舰种的行动不同

- 冲撞船先绕到适合的冲锋方向，再拉开、对准和加速。
- 轻型炮艇保持中距离，用侧舷持续射击并逐渐后撤。
- 火箭炮艇藏在前排后方，优先攻击敌方密集区。
- 鱼雷艇从侧翼切入，确保发射走廊没有友军。
- 布雷艇不追着目标屁股乱丢雷，而是在航道、缺口或预计撤退路线上布雷。
- 维修艇不会冲进最前排，会选择安全维修位并在被突进时撤离。
- 重型护卫舰主动占据前线，遮挡通往主舰、维修艇和炮艇的路径。

### 2.2 船只不再机械地追逐一个点

舰船移动由以下内容共同决定：

- 当前战术职责。
- 目标未来位置。
- 自身武器射界。
- 船体朝向与转弯半径。
- 制动距离与当前速度。
- 静态障碍和动态障碍。
- 编队槽位与队友行动。
- 安全撤退方向。
- 港口航道和泊位预约。

### 2.3 建造会真实改变航行

- 建筑会切割水域并改变船只路径。
- 防墙会形成可利用的防守航道。
- 炮塔会让敌舰选择掩体、突破点或拆基地基。
- 港口建筑会生成靠泊区、回转区和禁建水域。
- 生产区本身允许穿行，但作业船、实体平台和吊机会形成动态或局部障碍。
- 建造若完全封死关键航道，系统应在放置阶段阻止，而不是等船卡住后补救。

# 第三部分：AI总体架构

## 3. 五层舰船智能

每艘船不再使用一个巨大的AI脚本，而拆成五层：

| 层级 | 名称 | 负责内容 | 更新频率建议 |
| --- | --- | --- | ---: |
| L1 | 世界任务层 | 出航、巡逻、护航、返港、生产、贸易 | 0.2～1 Hz |
| L2 | 舰队指挥层 | 编队目标、职责分配、集火、撤退、航线 | 1～2 Hz |
| L3 | 单舰战术层 | 选目标、选站位、选技能、保持距离 | 3～5 Hz |
| L4 | 局部航行层 | 避障、让行、走廊、速度协调、脱困 | 5～10 Hz |
| L5 | 船体操舵层 | 油门、舵角、制动、侧倾、尾迹 | 20～50 Hz |

低层不能擅自推翻高层意图。

例如：

- 舰队层命令炮艇守住左侧航道。
- 单舰层可在左侧区域内选择更安全的炮击点。
- 局部航行层可暂时绕开队友。
- 船体操舵层负责用可实现的转弯完成路径。
- 炮艇不能因为局部避障，永久跑到右侧追敌。

## 4. 核心组件职责

| 组件 | 主要职责 |
| --- | --- |
| `ShipWorldTaskController` | 世界任务、港口、生产与战斗状态切换 |
| `FleetCommander` | 舰队目标、编队、职责槽、共享航线 |
| `ShipTacticalBrain` | 单舰效用评分、目标选择、战术动作 |
| `ShipWeaponCoordinator` | 射界、发射许可、友军阻挡、齐射错峰 |
| `ShipNavigationAgent` | 战略路径、局部走廊、重寻路 |
| `ShipAvoidanceAgent` | 动态避碰、会船、优先权和紧急制动 |
| `ShipSteeringController` | 舵角、油门、倒车限制、速度曲线 |
| `ShipFormationMember` | 弹性槽位、编队重排、脱队与归队 |
| `ShipDockingController` | 预约、排队、进港、靠泊和离泊 |
| `ShipStuckResolver` | 卡死识别、局部倒车、让行和重寻路 |
| `ShipPerceptionSensor` | 敌我、建筑、投射物、危险区与可见性 |
| `ShipPresentationDriver` | 船体倾斜、炮塔、尾迹、灯光与动画 |

# 第四部分：统一舰船状态机

## 6. 世界级状态

```text
未部署
→ 下水
→ 待命/锚泊
→ 接受任务
→ 集结
→ 航行
→ 执行任务
→ 返航
→ 候泊
→ 靠泊
→ 补给/卸货/维修
→ 再次待命
```

特殊分支：

```text
执行任务
├── 进入战斗
├── 失去动力 → 等待拖航
├── 低战备 → 主动撤退
├── 航道中断 → 改道/等待
└── 任务取消 → 安全返航
```

## 7. 战斗级状态

| 状态 | 行为 |
| --- | --- |
| `Acquire` | 感知威胁、确认目标与职责 |
| `Approach` | 接近适合自己武器的战术区域 |
| `Align` | 调整舰首、侧舷、鱼雷管或冲锋方向 |
| `Execute` | 射击、冲撞、布雷、维修或控制 |
| `Reposition` | 改变射击面、拉开距离、绕侧或找掩体 |
| `Disengage` | 暂时脱离火力或危险区 |
| `Retreat` | 返回安全点、军港或边境 |
| `Disabled` | 失去动力，等待拖航或战斗结算 |

## 8. 状态切换必须有迟滞

为避免AI反复横跳：

- 非紧急情况下，目标切换最短间隔1.5秒。
- 战术动作最短承诺时间0.8～2.5秒，按舰种调整。
- 进入理想距离后，不因0.5～1米误差立即切换前进/后退。
- 距离带使用进入阈值和退出阈值。
- 低生命撤退一旦确认，除非航路完全封死或受到强制命令，不恢复追击。
- 冲撞进入最终加速后，不再因为目标小幅偏移反复修正。
- 布雷开始后至少完成一个安全投放序列，除非即将相撞。

# 第五部分：目标选择与战术评估

## 9. 目标不是“最近的敌人”

统一目标评分：

```text
目标效用 =
威胁值 × 职责适配
+ 可击杀价值
+ 对保护对象的威胁
+ 当前编队集火奖励
+ 侧后方暴露奖励
+ 部位弱点奖励
+ 路径可达奖励
+ 武器射界奖励
- 距离代价
- 转向代价
- 友军遮挡代价
- 建筑遮挡代价
- 危险区代价
- 过度追击代价
- 重复分配惩罚
```

## 10. 目标职责适配

| 己方舰种 | 优先目标 | 降低优先级目标 |
| --- | --- | --- |
| 冲撞舟 | 炮艇、维修艇、爆破筏、侧面暴露的大舰 | 正面装甲舰、灵活小艇、墙后目标 |
| 拦截艇 | 高速突进、鱼雷、爆破单位 | 重甲大舰 |
| 轻型炮艇 | 中小型持续威胁、无掩体目标 | 超远后排、强装甲正面 |
| 火箭/导弹艇 | 密集编队、后排支援、固定模块 | 贴身小艇 |
| 鱼雷艇 | 大型舰、重甲舰、Boss部位 | 小而灵活的快艇 |
| 布雷艇 | 必经航道、冲锋路线、撤退路线 | 已停止或不会经过的区域 |
| 维修艇 | 高价值友舰、即将失效的防线 | 满血单位、即将沉没且不可救目标 |
| 护盾艇 | 正在承受集火的编队 | 单个远离编队的小艇 |
| 重型护卫舰 | 冲撞单位、重炮威胁、进入核心的敌舰 | 远处低威胁目标 |
| 指挥舰 | 不直接按目标追击，以维持指挥覆盖为主 | 任何会让其脱离编队的诱饵 |

## 11. 目标分配上限

为避免全队追一艘小船：

- 小型目标默认最多被2艘普通舰锁定。
- 中型目标默认最多被4艘锁定。
- 大型目标和Boss由编队指挥器分配攻击扇区。
- 冲撞许可独立计算，同一小目标同一时刻最多1艘进入最终冲锋。
- 同一目标已有足够预计伤害时，后续舰船转向次优目标。
- 维修艇的同一友军默认最多被2条维修链同时服务。

## 12. 目标切换原因必须可调试

开发模式显示：

```text
当前目标：EN015 深水鱼雷艇
主因：威胁保护对象 +42
职责适配：+30
可达：+18
友军已分配：-12
总分：78
次选目标：EN014 强袭冲角艇，71
目标锁定剩余：0.8s
```

# 第六部分：战术点与距离控制

## 13. 不追目标位置，追“战术点”

舰船的移动目标通常不是敌人中心，而是围绕敌人生成的候选战术点。

候选点类型：

- 舰首冲锋起点。
- 左舷炮击点。
- 右舷炮击点。
- 鱼雷侧射点。
- 远程轰炸点。
- 保护对象前方拦截点。
- 维修安全点。
- 布雷预测点。
- 撤退出口。
- 掩体后方等待点。

## 14. 战术点评分

```text
战术点评分 =
武器命中质量
+ 射界完整度
+ 目标未来可见时间
+ 与职责距离匹配
+ 友军协同
+ 撤退路线完整
+ 掩体收益
- 航行成本
- 转向成本
- 建筑碰撞风险
- 友军拥堵
- 敌方危险覆盖
- 死胡同风险
```

## 15. 距离带

每个舰种使用四段距离：

| 距离带 | 含义 |
| --- | --- |
| 禁止距离 | 进入后立即脱离或紧急避碰 |
| 近身距离 | 可自卫，但不适合主要战术 |
| 理想距离 | 主要武器命中、射界和生存最平衡 |
| 脱战距离 | 再远则需要重新接近或换目标 |

距离不是一个固定圆环，还要考虑：

- 武器安装方向。
- 目标朝向。
- 建筑遮挡。
- 自身转弯能力。
- 队友站位。
- 当前弹药与冷却。

# 第七部分：不同舰种完整行为

## 16. 小型拦截舟

### 16.1 定位

- 外圈接敌。
- 截断高速敌人。
- 保护炮艇、维修艇和功能船。
- 逼迫敌人转向，不以自身伤害为核心。

### 16.2 行为流程

```text
发现高速威胁
→ 预测威胁与保护对象的交汇点
→ 抢占交汇点外侧
→ 与目标同向切入
→ 机炮压制/轻微碰撞干扰
→ 目标改变方向后回到屏障位置
```

### 16.3 自然表现

- 不贴着目标尾部追逐。
- 优先切弯和抄近路。
- 两艘拦截舟从左右分开包夹。
- 完成拦截后不追出守区。
- 与冲撞舟区别明显：拦截舟重在阻断，冲撞舟重在一次重击。

## 17. 冲撞舟

### 17.1 核心体验

冲撞舟必须真的寻找机会撞击敌人，而不是靠近后用普通近战攻击。

### 17.2 完整状态

```text
寻找目标
→ 评估目标是否适合冲撞
→ 选择撞击面
→ 寻找冲锋起点
→ 拉开距离
→ 舰首对准
→ 申请冲撞许可
→ 加速预备
→ 最终冲锋
→ 碰撞结算或撞空
→ 滑行/失衡
→ 脱离目标周围
→ 冷却并重新选位
```

### 17.3 冲锋起点

冲锋起点必须满足：

- 与目标预计位置形成近似直线。
- 直线走廊宽度大于冲撞舟包围体宽度加安全边距。
- 走廊内没有地基、墙体、码头、友军和己方水雷。
- 目标在冲锋结束前不会被建筑完全遮挡。
- 冲锋后方或侧方存在至少一个脱离方向。
- 起点不在港口泊位回转区和公共航道核心段。

### 17.4 目标选择

优先：

- 远程炮船。
- 维修、护盾、指挥单位。
- 爆破筏与鱼雷艇。
- 侧面暴露的大型舰。
- 正在蓄力且难以转向的敌人。

不优先：

- 舰首装甲朝向自己的重型舰。
- 正靠近己方建筑的目标。
- 正处于狭窄友军通道的目标。
- 转向能力极强的小艇。

### 17.5 最终冲锋

- 最终冲锋通常持续0.8～2.2秒。
- 冲锋锁定后只允许小角度修正。
- 目标大幅变向时可提前中止，但必须保留减速和重新对准过程。
- 不能瞬间旋转舰首追踪。
- 冲撞伤害只在有效碰撞瞬间结算一次。
- `OnCollisionStay`不能持续触发冲撞伤害。
- 撞到墙体、礁石或重甲正面时自身进入失衡。
- 撞空后保留明显滑行与减速，不立即180度回头。

### 17.6 友军协同

- 同一目标同时最多一艘普通冲撞舟最终冲锋。
- 第二艘可提前占据另一方向，但等待第一艘结果。
- 鱼叉或减速生效后，冲撞舟获得短期高优先级。
- 炮艇不能站在冲撞走廊上。
- 冲锋线生成时，附近友军获得“让出走廊”短指令。

## 18. 轻型炮艇

### 18.1 核心体验

炮艇应一边用侧舷或旋转炮持续射击，一边把敌人保持在理想距离之外。

### 18.2 完整流程

```text
发现目标
→ 选择左舷或右舷炮击面
→ 接近理想距离外沿
→ 舰体侧面对敌
→ 以切线方向航行并开火
→ 敌人靠近时逐渐拉远
→ 即将进入死角时换舷或转移
→ 保持射击节奏
```

### 18.3 距离控制

- 不用“倒车直退”作为常规拉距方式。
- 优先选择弧形后撤、斜向切出或绕掩体。
- 目标逼近时，选择远离目标且不会进入死胡同的切线点。
- 到达理想距离外沿后降低油门，而不是反复前进后退。
- 目标被前排拦住时，可短时间维持稳定炮位。

### 18.4 侧舷选择

侧舷评分考虑：

- 哪一侧炮管完好。
- 哪一侧弹药更多。
- 哪一侧空间更开阔。
- 哪一侧不会压住队友。
- 换舷需要的转向时间。
- 敌人是否即将穿过舰首或舰尾死角。

### 18.5 拉开距离逻辑

```text
若目标距离 < 理想距离下限
→ 生成3～6个后撤候选点
→ 排除建筑后方死路
→ 排除友军密集区
→ 排除敌方雷区和冲撞走廊
→ 选择“能继续保持射界”的候选点
→ 边转向边开火
```

### 18.6 禁止行为

- 不得贴着敌舰绕小圈。
- 不得为了保持精确距离而每秒切换前进与后退。
- 不得把舰首长期正对目标，浪费侧舷武器。
- 不得追一艘高速小艇离开后排阵地。

## 19. 火箭炮艇与导弹艇

### 19.1 定位

- 后排远程火力。
- 攻击密集敌群和敌方支援。
- 通过长射程减少走位频率。

### 19.2 行为

- 优先进入前排舰后的远程射击区。
- 导弹可越过低矮友军时，不要求完全直线视野。
- 火箭需要抛射走廊，不可从大型建筑内部发射。
- 目标接近自卫距离后，立刻向己方前排另一侧转移。
- 每轮齐射后有小幅位置变化，避免长期站桩。
- 多艘导弹艇错开0.2～0.8秒发射，避免视觉和伤害重叠。

### 19.3 阵地选择

优先：

- 友方重甲舰后方。
- 防墙内侧但仍能射出的区域。
- 有两个以上出口的开阔水面。
- 声呐或侦察覆盖内。

回避：

- 单出口内港。
- 冲撞走廊。
- 友军泊位进出线。
- 敌方可能快速贴身的狭窄水道。

## 20. 鱼雷艇

### 20.1 核心体验

鱼雷艇不应正面对着目标发射，而应主动寻找侧面、舰尾或狭窄航道的发射机会。

### 20.2 行为流程

```text
选择大型目标
→ 判断目标预计航线
→ 选择左/右侧翼
→ 沿外圈接近
→ 与目标航向形成30°～90°夹角
→ 检查鱼雷发射走廊
→ 发射
→ 立即脱离正面火力
→ 等待装填并重新绕侧
```

### 20.3 发射许可

以下情况禁止发射：

- 鱼雷前方短距离有友军。
- 目标即将被地基或防墙遮挡。
- 目标太小且转向能力过强。
- 自身船头尚未稳定。
- 预计鱼雷会进入己方泊位、生产船作业点或盟友密集区。

### 20.4 被贴身

- 进入禁止距离后不继续原地装填。
- 释放烟幕或自卫武器后横向脱离。
- 优先向重型护卫舰或防御塔方向撤退。
- 无安全方向时宁可中止鱼雷发射，也不与敌人贴身绕圈。

## 21. 布雷艇

### 21.1 核心体验

布雷艇负责改变敌人的未来路线，不负责把水雷直接丢在敌人脚下。

### 21.2 布雷点类型

- 港口外圈敌军必经航道。
- 防墙缺口外侧。
- 敌方冲撞舟拉距区域。
- 大型敌舰预计转弯外侧。
- 敌方撤退或增援路线。
- 友军诱饵后方。
- 已有炮塔覆盖的交叉区。

### 21.3 布雷流程

```text
预测敌方10～20秒航线
→ 选择布雷线或布雷弧
→ 规划自身进入与退出路线
→ 检查友军航道
→ 低速稳定投放
→ 标记雷区
→ 沿预定出口撤离
→ 移动到观察位
```

### 21.4 安全规则

- 不能完全封死己方唯一航道。
- 雷间距必须留下小艇可穿过的维护通道。
- 港口公共主航道仅允许战时临时布雷，并需调度塔批准。
- 友军路径代价图实时提高雷区权重。
- 己方舰船可识别水雷，但不能假设绝对不会误触。
- 布雷艇被追击时可以尾部投雷，但只投短线，不无限铺满地图。

## 22. 喷火艇、霰弹艇与近距控制艇

### 22.1 共同逻辑

- 进入近距但不与目标发生持续贴碰。
- 使用短弧线掠过目标侧面。
- 一次攻击后穿出，不在目标旁边原地绕圈。
- 优先攻击小艇群、轻甲单位和被减速目标。
- 面对重型冲撞舰时不从正面接近。

### 22.2 喷火艇

- 选择顺风或目标撤退方向喷火。
- 不在己方地基和生产区实体设施旁制造火海。
- 火海已覆盖时改变角度，不重复叠放。

### 22.3 霰弹艇

- 寻找短距离正面窗口。
- 射击后立刻横切，避免被反冲撞。
- 对小艇群可在队形前方短暂停留。

## 23. 重型护卫舰

### 23.1 定位

- 吸收火力。
- 守住航道和港口缺口。
- 保护主舰、炮艇和支援舰。
- 用舰体迫使敌人改变路线。

### 23.2 行为

- 优先占据保护对象与主要威胁之间的拦截扇区。
- 不追逐低威胁小艇。
- 缓慢调整舰首，使重装甲面朝向主要伤害。
- 允许小幅前后移动维持防线，但避免频繁转身。
- 敌方重撞时可正面接撞或斜向偏转。
- 生命较低时以倒退和侧移方式撤出，不突然转身暴露舰尾。

### 23.3 航道封锁

- 可以临时占据指定防守航道。
- 其他友军自动把该位置视为软障碍。
- 必须保留至少一条己方撤退缝隙。
- 舰体失去动力时立即通知编队改道，拖船优先处理。

## 24. 重炮护卫舰

### 24.1 定位

- 移动远程炮台。
- 攻击大型目标、建筑和Boss部位。
- 转向慢，依赖前排保护。

### 24.2 行为

- 提前选择炮击阵地，不频繁换位。
- 以目标未来20～30秒仍可见为重要条件。
- 每次转向前检查炮塔是否可继续跟踪。
- 目标贴身后优先撤向前排后方，不尝试急转绕圈。
- 建筑遮挡时只移动到最近可射击点，不绕完整大圈追目标。

## 25. 维修艇

### 25.1 核心体验

维修艇必须让玩家看到“正在抢修谁、为什么靠近、何时撤离”，而不是隐藏在数值层自动加血。

### 25.2 维修目标评分

```text
维修价值 =
单位战略价值
× 可挽救程度
× 当前受压强度
+ 关键建筑/舰船失效风险
+ 编队核心奖励
- 到达风险
- 预计过量维修
- 即将沉没不可救惩罚
```

### 25.3 位置行为

- 选择友军背向敌人的一侧。
- 与目标保持维修臂或维修束的有效距离。
- 维修目标前进时使用平滑跟随，不紧贴船尾。
- 敌人突进时先切断维修，再向重甲舰后方撤退。
- 两艘维修艇自动分摊目标。
- 不穿过敌我交火线去修一艘低价值小艇。

### 25.4 拖航

- 失去动力舰船需要生成拖航接入点。
- 拖船先对准接入点，再低速连接。
- 拖航后的组合体使用更大包围体、更低航速和更大转弯半径。
- 拖航路径只选择L级以上可通行航道。
- 紧急情况下可在安全锚地临时释放目标。

## 26. 护盾艇与补给艇

### 26.1 护盾艇

- 围绕2～4艘友军形成保护区域。
- 优先站在敌方火力方向和友军中心之间。
- 不为了保护单个脱队小艇而离开主编队。
- 护盾即将破裂时向编队内侧退一步，避免自身被秒杀。

### 26.2 补给艇

- 根据弹药短缺和舰种重要性规划补给顺序。
- 在安全水域与目标并行完成转运。
- 不在冲撞走廊和重炮预警区停船。
- 战斗中只进行应急补给，完整补给仍需返港。

## 27. 港口指挥舰

- 维持在多数守卫舰可接收指挥的中心区域。
- 不主动追击普通目标。
- 根据编队压力移动到左翼、右翼或核心后方。
- 指挥覆盖与安全之间取平衡。
- 遭到突进时呼叫最近拦截艇和护卫舰，而不是独自逃出编队。
- 指挥舰失效后，各舰继续当前命令，但协同刷新频率降低。

## 28. 英雄主舰自动驾驶

### 28.1 玩家控制优先

- 玩家直接操控时，AI不能抢夺方向和油门。
- AI只提供危险提示、推荐航线、自动瞄准和可选辅助操舵。
- 玩家5秒未输入且开启自动驾驶时，主舰继续当前命令。
- 玩家任何方向输入立即平滑接管，不瞬间清空船速。

### 28.2 自动驾驶策略

英雄主舰的默认策略由舰体与四名作战英雄共同生成：

| 构筑特征 | 自动驾驶倾向 |
| --- | --- |
| 冲撞、近战英雄较多 | 主动寻找冲锋走廊 |
| 炮击、导弹英雄较多 | 中远距离侧舷与拉距 |
| 鱼雷、布雷较多 | 侧翼和航线控制 |
| 护盾、治疗较多 | 编队中心与保护位置 |
| 召唤、无人机较多 | 开阔区域和持续机动 |

自动驾驶不能修改玩家装备和技能释放规则。

## 29. 捕鱼船与远洋生产船

### 29.1 世界任务链

```text
码头装载工具
→ 请求离港
→ 沿公共航道出港
→ 沿世界航线前往生产区
→ 选择作业点
→ 执行捕捞/采矿/打捞
→ 货舱装满或风险过高
→ 真实返航
→ 候泊
→ 靠泊
→ 卸货
→ 资源入账
```

### 29.2 作业点选择

评分内容：

- 当前资源密度。
- 与其他作业船的间距。
- 风浪和天气。
- 敌对威胁。
- 距离码头的航程。
- 货舱剩余。
- 对生态恢复的影响。
- 是否有护航和灯塔覆盖。

### 29.3 自然作业表现

- 捕鱼船围绕鱼群缓慢调整，不在一个点静止读条。
- 围网船从鱼群侧前方切入，形成弧形作业轨迹。
- 采矿船在平台附近低速定位，吊装期间保持稳定。
- 打捞船需要与残骸对准并考虑拖缆方向。
- 多艘功能船自动分散，不叠在同一资源点。

### 29.4 遇袭

- 优先判断是否能在装满前完成作业。
- 危险超过策略阈值时停止作业并返航。
- 向最近护航舰、前哨或己方边境发出求援。
- 货物越重，转向和加速越慢。
- 不会为了绕开一个小敌人穿过建筑或固定挑战区。

## 30. 商船

- 按贸易航线进入世界，不在港口附近凭空生成。
- 到达港外等待点后申请泊位。
- 没有商港、航道中断或安全度过低时改道或离开。
- 进港时遵守船级、单向航道和优先权。
- 靠泊后才生成装卸表现与贸易结算。
- 离港后保持一段安全航行时间，再切换为远景代理。
- 遭袭时优先逃向外海或友方巡逻，不参与无意义战斗。

## 31. 敌舰对本文系统的复用

敌舰使用同一套：

- 船体包围体。
- 转弯半径。
- 路径走廊。
- 动态避碰。
- 战术点。
- 冲撞和炮击行为。

敌舰不能为了攻击地基而穿过地基。

敌人可根据职责选择：

- 沿航道推进。
- 拆除阻挡路径的防墙或地基。
- 绕侧寻找薄弱区域。
- 炮击远处地基。
- 清雷后为后续舰队开路。

敌人若没有可达路径，应切换为“破障目标选择”，不能直接忽略碰撞。

# 第八部分：编队系统

## 32. 弹性编队

编队槽位是期望区域，不是强制坐标。

每个槽位包含：

- 相对舰队锚点的位置。
- 可接受半径。
- 推荐朝向。
- 船级限制。
- 职责标签。
- 最大离队距离。

舰船只需进入槽位可接受区域，不必精确重合。

## 33. 编队类型

| 编队 | 适用场景 | 站位 |
| --- | --- | --- |
| 航行纵队 | 狭窄航道、港口出航 | 小船在前，大舰间隔通过 |
| 宽线战列 | 开阔正面交战 | 重甲在前，炮艇在后 |
| 楔形突击 | 主动进攻 | 冲撞与护卫居前 |
| 环形护航 | 保护功能船或主舰 | 拦截外圈，支援内圈 |
| 双翼包夹 | 攻击大型目标 | 鱼雷、冲撞分居两翼 |
| 港口分区防守 | 多入口防守 | 左翼、右翼、核心、后排 |
| 撤退纵队 | 受损返航 | 健康护卫断后，伤舰居中 |

## 34. 编队锚点

锚点可由以下对象提供：

- 玩家主舰。
- 指挥舰。
- 护航目标。
- 防守区域中心。
- 航线虚拟领航点。

锚点移动时：

- 槽位提前预测1～3秒位置。
- 大船使用更长预测。
- 槽位不会瞬间跳到锚点另一侧。
- 编队大转向时先外侧加速、内侧减速。

## 35. 编队重排

以下情况触发重排：

- 航道变窄。
- 大型舰进入或退出。
- 前排舰失去动力。
- 敌人从侧翼出现。
- 玩家下达新战术命令。
- 港口出航需要按船级排队。

重排流程：

```text
冻结旧槽位归位冲动
→ 舰队指挥器分配新槽位
→ 生成过渡走廊
→ 先让关键舰移动
→ 其他舰按优先级让行
→ 到达宽阔区域后恢复战斗编队
```

## 36. 脱队与归队

- 冲撞、绕侧、维修和拦截允许短时脱队。
- 脱队舰保留职责，不立刻被编队拉回。
- 战术动作结束后寻找不会横穿编队的归队路线。
- 归队优先进入最近合适空槽，不强求原槽。
- 低血舰归队后优先进入内侧保护区。

## 37. 舰队共享路径

舰队长距离航行只计算一条主走廊。

- 小船在走廊内部局部偏移。
- 大船决定走廊最低宽度。
- 编队共享前方阻挡信息。
- 发现窄口后提前切换纵队。
- 每艘船不单独绕向不同方向。
- 只有脱队、绕侧或战术需求时才申请独立路径。

# 第九部分：四层寻路方案

## 38. 寻路总览

```text
世界战略航线
→ 区域路径走廊
→ 局部动态避碰
→ 船体操舵轨迹
```

四层缺一不可：

- 战略层避免跨越不可航行的大区域。
- 区域层绕过建筑、地基和礁石。
- 局部层处理其他舰船、鱼群、临时残骸和投射危险。
- 操舵层保证轨迹符合船体转弯与制动能力。

## 39. 第一层：世界战略航线

### 39.1 节点

世界航线图节点包括：

- 领海方格中心航行节点。
- 方格四边通行门户。
- 港口入口。
- 公共主航道交叉点。
- 固定挑战入口。
- 生产区入口。
- 锚地等待点。
- 世界边境出口。

### 39.2 边代价

```text
航线代价 =
距离
× 船级可通行系数
× 天气系数
× 敌对风险系数
× 拥堵系数
× 补给风险
+ 禁区惩罚
+ 逆流代价
- 灯塔与友军巡逻奖励
```

### 39.3 用途

- 远征。
- 返港。
- 商船航线。
- 生产船调度。
- 敌方增援。
- 跨板块巡逻。

战略层不负责绕开一座具体炮塔。

## 40. 第二层：区域路径走廊

### 40.1 基础数据

近景水域使用导航网格或水面多边形。

推荐：

- 2米建筑格作为静态占用来源。
- 1～2米导航采样精度。
- 按船级生成不同膨胀后的可航行层。
- 小艇、功能船、军舰、英雄主舰至少四套船级通行数据。

### 40.2 不能只用船中心点

每艘船使用二维航行包围体：

- 舰长。
- 舰宽。
- 艏艉突出。
- 当前速度安全边距。
- 转向外摆安全边距。

静态障碍对不同船级进行膨胀：

```text
有效障碍边界 =
实体障碍边界
+ 舰体半宽
+ 转向外摆
+ 当前速度安全距离
```

因此中心点能通过但船尾会扫到墙体的路线会提前判定不可用。

### 40.3 路径算法

建议分船级：

| 船级 | 区域路径 |
| --- | --- |
| S小艇 | 网格A*或导航多边形A*＋曲线平滑 |
| M功能船/炮艇 | 带朝向代价A*＋曲率约束平滑 |
| L军舰 | 状态格/Hybrid A*，包含朝向与转弯半径 |
| XL英雄主舰 | 预计算宽航道图＋Hybrid A*＋专用回转点 |

不建议直接把普通Unity `NavMeshAgent`当作最终移动器。

可使用NavMesh或导航网格提供可通行区域与路径查询，但最终速度和旋转必须交给自定义船体操舵。

### 40.4 路径平滑

原始路径完成后：

1. 删除可直达的冗余点。
2. 按船体最小转弯半径生成圆弧或Bezier过渡。
3. 重新做扫掠体碰撞测试。
4. 给弯道添加推荐速度。
5. 给窄口添加会船限制。
6. 给终点添加到达朝向。

若平滑后发生碰撞，则回退到更保守的路径。

## 41. 第三层：局部动态避碰

局部避碰对象：

- 友军舰船。
- 敌舰。
- 商船和功能船。
- 临时漂浮残骸。
- 拖航组合体。
- 鲸鱼等大型生物。
- 移动鱼群只作为低权重软障碍。
- 导弹预警、火海和敌方雷区作为危险代价，不是实体墙。

### 41.1 预测窗口

| 船型 | 预测时间 |
| --- | ---: |
| 小艇 | 1.0～2.0秒 |
| 炮艇/功能船 | 2.0～3.5秒 |
| 大型军舰 | 3.0～5.0秒 |
| 英雄主舰/拖航体 | 4.0～7.0秒 |

### 41.2 避碰不是瞬间横移

局部避碰输出：

- 推荐速度。
- 推荐舵角。
- 推荐让行侧。
- 是否减速。
- 是否紧急制动。

不能直接修改Transform把船推开。

### 41.3 海上让行规则

简化为玩家可理解的规则：

- 普通会船默认各自向右小幅让行。
- 窄航道内，已进入者优先。
- 离港舰优先于普通候泊舰。
- 失去动力和拖航组合体优先。
- 紧急返港低血舰优先于普通巡逻。
- 商船与生产船在战斗警报时让军舰。
- 英雄主舰不拥有无限优先权；狭窄港口也需遵守调度。
- 执行最终冲撞的舰船获得短时战斗走廊，但不能穿过友军。

## 42. 第四层：船体操舵

### 42.1 非完整汽车式模型

舰船仍保留当前“类似汽车操作”的易用方式，但AI操舵应表现出水上惯性：

- 航向变化依赖舵角和速度。
- 低速转向变差或由辅助推进器补偿。
- 高速无法瞬间大角度转弯。
- 倒车速度和转向能力受限。
- 停船需要制动距离。
- 大船侧滑和尾部外摆更明显。

### 42.2 操舵输入

```text
期望航向
+ 期望速度
+ 路径曲率
+ 前方碰撞时间
+ 战术朝向要求
→ 油门
→ 舵角
→ 制动/倒车
```

### 42.3 速度曲线

- 直线路段逐渐加速。
- 接近弯道前提前减速。
- 弯道中维持稳定速度。
- 出弯后恢复油门。
- 接近泊位时分阶段降速。
- 战斗拉距时保留射击稳定性，避免频繁满油门急停。

# 第十部分：建筑、建造与导航联动

## 43. 障碍分类

| 障碍类型 | 是否阻挡 | 导航处理 |
| --- | --- | --- |
| 水面生产区范围 | 否 | 可加轻微拥挤代价 |
| 装饰鱼群、海鸟 | 否 | 视觉驱散 |
| 低矮浮标 | 小艇可穿或轻避让 | 软障碍 |
| 地基 | 是 | 静态硬障碍 |
| 普通建筑主体 | 是 | 静态硬障碍 |
| 码头主体/吊机 | 是 | 静态硬障碍 |
| 泊位水域 | 指定船可进入 | 权限区域 |
| 公共航道 | 可航行 | 低代价走廊 |
| 防墙/重型铁皮墙 | 是 | 静态硬障碍 |
| 己方水雷 | 可绕开 | 危险软障碍 |
| 敌方水雷 | 未发现时未知 | 发现后高代价 |
| 临时残骸 | 是或高代价 | 动态障碍 |
| 摧毁后下沉残骸 | 视深度 | 定时移除或转软障碍 |

## 44. 建造预检查

放置任何会阻挡航行的实体前，必须检查：

1. 是否占用泊位、回转区或装卸安全带。
2. 是否切断外海到港口核心的公共航道。
3. 是否使已建泊位失去对应船级的可达性。
4. 是否封死守卫舰出航点。
5. 是否封死功能船到生产区的唯一通道。
6. 是否使英雄主舰无法从舰坞离开。
7. 是否造成小于最小宽度的瓶颈。
8. 是否形成大型船无法掉头的死水袋。

### 44.1 放置反馈

| 颜色 | 含义 |
| --- | --- |
| 绿色 | 所有关键路径保持连通 |
| 黄色 | 可建，但形成拥堵或限制某船级 |
| 橙色 | 会让某个泊位或任务点不可用 |
| 红色 | 切断关键航道，禁止建造 |

### 44.2 黄色情况

允许玩家有意识地建造狭窄防线，但必须明确显示：

- 最大可通过船级。
- 预计拥堵等级。
- 受影响泊位。
- 受影响舰队。
- 可使用的替代航道。

## 45. 增量导航更新

建筑建造、升级、摧毁或恢复时：

```text
改变局部占用格
→ 标记受影响导航块
→ 更新船级通行数据
→ 路径版本号+1
→ 通知经过该块的舰船
→ 舰船在安全时机重算走廊
```

不能每次建造都重烘焙整张世界。

建议以24米或48米为一个导航块。

## 46. 地基摧毁

防守中地基被摧毁后：

- 地基及其建筑立即失效并播放坍塌表现。
- 原实体碰撞根据坍塌阶段更新。
- 大型残骸短时间保留，形成新的临时障碍。
- 部分残骸下沉后转为可通行水面。
- 正在经过的舰船先紧急减速，再申请局部改道。
- 不允许在坍塌瞬间把舰船弹飞到建筑另一侧。
- 战后恢复布局时再次执行增量导航更新。

## 47. 敌人破障

若敌人到目标没有可航行路径：

```text
识别阻挡链
→ 找出防墙/地基/闸门/失去动力舰
→ 计算破坏成本
→ 选择最近薄弱点或战术价值最高点
→ 炮舰远程拆基
→ 冲撞舰攻击防墙
→ 扫雷艇清除雷区
→ 路径打开后继续推进
```

禁止：

- 把目标点投影到建筑另一侧后直接穿过。
- 因寻路失败而临时关闭碰撞。
- 全体敌人挤向同一个像素级缺口。

# 第十一部分：港口航行与靠泊

## 48. 港口不是普通寻路区域

港口内使用：

- 公共主航道。
- 船级支路。
- 单向进港线。
- 单向离港线。
- 候泊点。
- 回转区。
- 最终靠泊曲线。

## 49. 泊位预约

```text
舰船提出服务需求
→ 港务系统匹配泊位
→ 分配预计可用时间
→ 分配港外等待点
→ 分配进港时间窗
→ 锁定最终靠泊曲线
→ 完成靠泊
```

没有预约的船不能直接冲向泊位。

## 50. 进港流程

### 50.1 外海阶段

- 舰船驶向港口入口，不直接瞄准泊位中心。
- 根据船级选择入口。
- 提前降低编队规模，切换纵队。
- 随行护卫在港外解散或进入军用锚地。

### 50.2 候泊阶段

- 到达分配的等待点。
- 以低速绕行或抛锚等待。
- 显示预计等待时间。
- 紧急舰可申请提高优先级。

### 50.3 进港阶段

- 获得进港许可后进入专用航道。
- 航道中的其他船收到让行指令。
- 大船进入窄口后暂时禁止对向大船进入。
- 速度按航道限速自动降低。

### 50.4 靠泊阶段

靠泊使用预制或动态生成的三段曲线：

1. 对准点。
2. 减速点。
3. 接触点。

最后5～15米：

- 关闭普通局部避碰。
- 使用泊位专用轨迹。
- 只处理紧急碰撞。
- 低速调整角度。
- 船体与码头平行后完成系泊。
- 不允许最后一刻瞬间旋转。

## 51. 离泊

```text
完成服务
→ 申请离泊
→ 检查后方和主航道
→ 解缆
→ 低速离开接触点
→ 在回转区调整船头
→ 进入离港线
→ 离开港区后恢复普通航行AI
```

## 52. 港口优先权

推荐优先顺序：

1. 失去动力拖航组合体。
2. 生命极低的紧急维修舰。
3. 防守警报下的出航军舰。
4. 满载且有腐损风险的渔船。
5. 已预约时间窗的商船。
6. 普通返航军舰。
7. 空载功能船。
8. 普通巡逻与装饰船。

优先权只影响队列，不允许相互穿越。

## 53. 港口死锁处理

典型死锁：

- 两艘大船对向进入窄航道。
- 一艘失去动力舰堵在回转区。
- 候泊船挡住离港线。
- 玩家新建建筑后封死泊位。

处理顺序：

1. 冻结新进入请求。
2. 判断谁更接近退出点。
3. 低优先级船退回最近让行湾。
4. 必要时调用拖船。
5. 标记港口瓶颈并提示玩家。
6. 若由建造造成，提供一键定位阻挡建筑。

# 第十二部分：战斗中的自然移动

## 54. 预判目标而不是尾随

追击点：

```text
预测位置 =
目标当前位置
+ 目标速度 × 预测时间
+ 目标转向趋势修正
```

预测时间按舰种：

- 拦截艇：1～2秒。
- 炮艇：0.8～1.5秒。
- 鱼雷艇：2～5秒。
- 冲撞舟：最终冲锋0.6～1.2秒。
- 导弹艇：按导弹飞行时间。

## 55. 掩体和建筑

舰船可把建筑用于战术，但不得像陆地角色贴墙：

- 炮艇可利用防墙遮挡敌方直射炮。
- 导弹艇可在低矮建筑后发射垂直导弹。
- 小艇可绕过大型地基侧翼。
- 大舰不能进入小艇专用狭道。
- 维修艇选择有两个出口的掩体后方。
- AI评估掩体时必须考虑未来5秒是否会变成死路。

## 56. 危险区代价

危险区包括：

- 导弹落点。
- 冲撞走廊。
- 鱼雷航迹。
- 水雷。
- 火海、油面、冰区。
- 触手刺击点。
- 鲸鱼冲撞带。

危险不会都变成不可通行：

| 危险 | 处理 |
| --- | --- |
| 即将生效的致命区 | 临时不可通行或极高代价 |
| 普通持续伤害区 | 高代价，可在必要时穿过 |
| 低伤减速区 | 中代价 |
| 己方增益区 | 低代价或奖励 |
| 已经刺过的旧区域 | 快速降低代价，形成可学习路线 |

## 57. 过度追击限制

- 守区舰有最大追击半径。
- 后排舰追击半径小于前排。
- 敌人离开软战区后，普通守卫舰停止追击。
- 冲撞舟完成一次冲锋后先返回职责区域。
- 保护功能船的护卫不能被一艘诱饵艇引走。
- 玩家可切换“激进、标准、保守”追击策略。

## 58. 撤退

撤退点不是固定港口中心，而按当前情况选择：

- 最近己方防墙内侧。
- 最近维修覆盖。
- 最近可用军港入口。
- 最近安全边境。
- 编队指定撤退浮标。

撤退路径必须：

- 避开敌方主火力。
- 避免横穿己方冲锋线。
- 避免穿过泊位接触区。
- 对低血舰提高安全权重。

# 第十三部分：卡死、抖动与异常处理

## 59. 卡死识别

满足任一条件进入卡死检测：

- 有有效路径但2秒内前进小于舰长的10%。
- 油门持续大于50%，速度接近0。
- 舵角在左右之间高频切换超过1.5秒。
- 与同一艘船对顶超过1秒。
- 距离同一路径点长期不下降。
- 局部避碰连续否决所有速度。

## 60. 脱困等级

### L1：等待与让行

- 降低油门。
- 保持当前方向。
- 让高优先级对象通过。

### L2：局部偏移

- 在路径走廊内选择左或右偏移线。
- 保留总体航向。

### L3：短距离倒车

- 仅在低速和无后方障碍时执行。
- 小艇倒车1～3米。
- 大舰倒车2～6米。
- 不把倒车作为常规寻路方式。

### L4：局部重寻路

- 暂时把阻挡单位视为膨胀障碍。
- 寻找最近可重新进入主走廊的位置。

### L5：舰队调度

- 编队指挥器重新安排通过顺序。
- 大船先退至让行湾。
- 其他舰暂停抢路。

### L6：失败保护

仅用于严重异常：

- 把船移动到最近经过验证的安全水面。
- 必须播放拖航或救援解释。
- 不得移动到建筑另一侧获得战术优势。
- 记录完整日志供开发定位。

## 61. 防抖动规则

- 路径点有到达半径，不追求像素级重合。
- 局部避碰方向有最短保持时间。
- 左右让行选择一旦确定，短时间不切换。
- 舰船朝向误差小于容差时不持续微调。
- 目标点移动使用低通滤波。
- 编队槽位移动进行插值。
- 战术点切换设置最小收益差，例如新点至少高15%才切换。

## 62. 目标不可达

```text
目标不可达
├── 有可破坏障碍 → 选择破障
├── 可远程攻击 → 移动到最近射击点
├── 可等待开门/航道 → 进入等待
├── 可换目标 → 重新选目标
└── 无解 → 返回守区/编队
```

不能：

- 在障碍两侧来回切换路径。
- 每帧重复请求同一失败路径。
- 把不可达目标当作永久最高优先级。

# 第十四部分：自然表现规则

## 63. 船体视觉与物理分离

推荐层级：

```text
ShipRoot              逻辑位置、碰撞、航行
├── PhysicsHull       物理与导航包围体
├── VisualRoot        视觉侧倾、俯仰、受击摇晃
├── WeaponMounts      武器挂点
├── WakePoints        尾迹点
└── FXAnchors         烟、火、泡沫、维修等
```

冲撞缩放、受击摇晃和浪涌只作用于`VisualRoot`，不能改变导航根节点。

## 64. 转向表现

- 船头先产生小幅偏转，再出现明显弧线。
- 船体向转弯外侧轻微侧倾。
- 船尾产生外摆尾迹。
- 高速急转出现更宽泡沫。
- 大舰转向前炮塔继续跟踪目标，船体缓慢跟上。
- 小艇反应快，但也不能原地自转。

## 65. 加速与减速

- 推进器启动、螺旋桨或桨轮表现与油门同步。
- 高油门尾迹更长更亮。
- 减速时尾迹逐渐收短。
- 紧急倒车产生船首前方或船尾紊流。
- 货舱满载的功能船加速更慢、吃水更深。

## 66. 舰种辨识

| 舰种 | 远距离行为轮廓 |
| --- | --- |
| 冲撞舟 | 拉开、对准、直线爆发 |
| 炮艇 | 侧面对敌、弧形后撤 |
| 鱼雷艇 | 外圈绕侧、发射后脱离 |
| 布雷艇 | 沿预测线低速投放 |
| 护卫舰 | 稳定占据前线 |
| 维修艇 | 躲后方、短距离接近受损目标 |
| 导弹艇 | 后排停留、齐射后转移 |
| 捕鱼船 | 围绕鱼群缓慢作业、满载返港 |

玩家不看头顶文字也应能大致判断舰种。

## 67. 音效

- 冲撞预备：发动机升转和舰首金属锁定。
- 炮艇拉距：持续炮声与转舵水声。
- 鱼雷发射：舱门、入水、低频推进。
- 布雷：机械释放和落水闷响。
- 维修：焊接、吊臂、泵机。
- 靠泊：减速、缆绳、木材或金属接触。
- 拥堵：短促汽笛，不应持续刺耳。

## 80. 单舰决策

```text
TickTacticalBrain(ship):
    if ship.worldState requires docking or production:
        execute world task behavior
        return

    if ship.mustRetreat():
        select safe retreat point
        set Retreat
        return

    candidates = perception.getValidTargets()
    target = scoreTargetsByRole(candidates)

    if target is null:
        returnToFormationOrPatrol()
        return

    actions = getAvailableActions(target)
    action = scoreActions(actions)

    tacticalPoints = generatePoints(action, target)
    point = scoreReachablePoints(tacticalPoints)

    commit(action, target, point)
```

## 81. 炮艇拉距

```text
UpdateGunboat(ship, target):
    distance = getDistance(ship, target)

    if distance < forbiddenRange:
        point = findEscapeArc(
            awayFrom = target,
            keepBroadside = true,
            avoidDeadEnd = true
        )
        moveTo(point)
        fireSelfDefenseOnly()
        return

    if distance < idealRangeMin:
        point = findKitePoint(
            targetFuturePosition,
            preferredBroadside,
            formationBounds
        )
        moveTo(point)
        fireWhenArcValid()
        return

    if distance <= idealRangeMax:
        followTangentialArc(target)
        maintainModerateSpeed()
        fireMainWeapons()
        return

    approachBroadsidePoint(target)
```

## 82. 冲撞行为

```text
UpdateRamShip(ship, target):
    if not isGoodRamTarget(target):
        chooseOtherTarget()
        return

    impact = predictImpactPoint(target)
    start = findChargeStart(impact, ship.minChargeDistance)

    if not hasClearSweptCorridor(start, impact, ship.hull):
        repositionOrChooseOtherTarget()
        return

    if not requestRamPermission(target, corridor):
        holdAtStagingPoint()
        return

    alignBowTo(impact)

    if alignmentError <= allowedAngle:
        beginCharge()

    duringFinalCharge:
        allowLimitedCorrection()
        if criticalObstacleAppears:
            emergencyAbort()
```

```text
PlanMinefield(enemyFleet):

    candidates = generateMineLines(chokePoints)
```

Boss和英雄主舰可提高战术频率，但不能无限提高全体舰船刷新频率。

## 87. 路径缓存

- 同一编队共享主路径。
- 同船级、同起终区域可复用路径走廊。
- 建筑只使相交导航块的缓存失效。
- 战术点使用短期缓存。
- 失败路径设置0.5～2秒冷却，避免重复查询。
- 固定港口靠泊曲线预计算。

## 88. 空间查询

- 感知使用分区、四叉树或空间哈希。
- 不对全场所有船两两计算避碰。
- 只处理预测时间内可能相撞的邻居。
- 同编队共享远方威胁和大障碍信息。
- 生产区鱼群不参与高精度船舶避碰。

## 89. 远景模拟

远景舰队：

- 沿战略航线图移动。
- 按编队代理计算速度。
- 遭遇时进行聚合战斗模拟。
- 接近玩家后在验证过的航线上展开成真实舰船。
- 展开时按编队槽位生成，不随机堆叠。

## 95. 安全边距

建议：

```text
静态安全边距 =
max(0.5米, 舰宽 × 0.15)

动态安全边距 =
静态边距
+ 当前速度 × 反应时间 × 0.25

窄航道附加边距 =
船级基础值 × 拥堵系数
```

战斗小艇可降低安全边距以显得灵活；商船和满载功能船提高安全边距。

## 96. 重寻路节流

- 普通战斗舰最短0.3秒。
- 大型舰最短0.6秒。
- 世界航线最短2秒。
- 港口最终靠泊阶段禁止普通重寻路。
- 建筑突然坍塌可越过节流触发紧急重算。

# 第二十二部分：测试场景

## 104. 冲撞船测试

场景：

- 开阔水域单目标。
- 目标横向移动。
- 目标背靠建筑。
- 冲锋线中有友军。
- 两艘冲撞舟抢同一目标。
- 目标在冲锋中死亡。
- 冲撞撞空。
- 冲撞撞墙。

通过标准：

- 会先拉开和对准。
- 不会穿过友军或建筑。
- 一次碰撞只结算一次。
- 撞空后有失衡与脱离。
- 多船不会同时堆叠冲锋。

## 105. 炮艇测试

场景：

- 敌人缓慢接近。
- 高速敌人追击。
- 左侧有墙，右侧开阔。
- 后方是死胡同。
- 多艘炮艇并排。
- 目标切换。

通过标准：

- 保持侧舷。
- 边拉距边射击。
- 不长期倒车。
- 不进入死胡同。
- 不贴脸绕圈。
- 多艘炮艇会分散炮位。

## 106. 鱼雷艇测试

- 大型直航目标。
- 小型灵活目标。
- 友军横穿发射线。
- 目标靠近地基。
- 左右两艘鱼雷艇包夹。

通过标准：

- 优先绕侧。
- 友军挡线时不发射。
- 发射后脱离。
- 不对明显不适合的目标浪费鱼雷。

## 107. 布雷艇测试

- 单入口航道。
- 双入口防区。
- 己方公共航道。
- 敌军撤退路线。
- 布雷艇被追击。

通过标准：

- 雷区放在未来路径上。
- 不完全封死己方。
- 投放前规划出口。
- 被追击时只短线尾投。

## 108. 港口测试

- 一艘船正常靠泊。
- 三艘船争同一泊位。
- 军舰紧急出航。
- 满载渔船返港。
- 大型主舰与商船对向。
- 拖航组合体进港。
- 建筑封窄航道。
- 泊位在建造后不可达。

通过标准：

- 有真实排队和优先级。
- 不重叠、不穿模。
- 最终靠泊自然。
- 死锁可解除。
- 建造前能提示航道问题。

## 109. 建筑动态测试

- 战斗中建造允许的临时设施。
- 地基被摧毁。
- 防墙坍塌。
- 残骸下沉。
- 战后恢复布局。

通过标准：

- 只更新受影响导航块。
- 船提前减速或改道。
- 不因障碍变化瞬移。
- 恢复后路径重新可用。

- 重寻路频率。

- 港口平均候泊时间。
- 舰种行为识别率。

# 第二十三部分：量化验收指标

## 111. 行为识别率

让未参与开发的测试者只看录像判断舰种：

- 冲撞舟识别率不低于85%。
- 炮艇识别率不低于80%。
- 鱼雷艇识别率不低于75%。
- 布雷艇识别率不低于75%。
- 维修艇识别率不低于85%。

## 112. 寻路质量

- 100次港口到外海往返，不出现穿建筑。
- 100次随机建造合法布局，不出现关键泊位假可达。
- 大舰通过最小合规航道成功率不低于99%。
- 近景战斗中非战术碰撞率低于每船每分钟0.2次。
- 原地抖动持续超过1秒的发生率低于1%。
- 卡死超过5秒的发生率低于0.1%。

## 113. 战术质量

- 冲撞舟有效冲撞中，正面撞己方建筑比例为0。

- 布雷艇己方唯一出口封死率为0。

## 114. 自然度

- 常规航行无瞬间180度转向。
- 靠泊最后阶段无瞬移和模型吸附。
- 大舰转弯可提前从尾迹和速度看出。
- 编队转向不会全体同时原地旋转。
- 两船会船能保持稳定让行侧。

# 第二十四部分：完整验收清单

## 115. 共同行为

- [ ] 所有舰种拥有明确的主要职责。
- [ ] 目标选择不只依赖最近距离。
- [ ] 目标切换存在冷却和迟滞。
- [ ] 战术点替代直接追逐目标中心。
- [ ] 低生命舰能主动撤退。
- [ ] 不可达目标能换目标或破障。
- [ ] 舰船不会被低价值敌人无限引走。

## 116. 冲撞舟

- [ ] 会寻找冲锋起点。
- [ ] 会检查完整冲锋走廊。
- [ ] 会拉开、对准和加速。
- [ ] 最终冲锋只有有限修正。
- [ ] 碰撞伤害只结算一次。
- [ ] 撞空后有失衡。
- [ ] 多艘冲撞舟会错开冲锋。
- [ ] 不会穿友军和建筑。

## 117. 炮艇

- [ ] 会用侧舷或有效炮弧对敌。
- [ ] 敌人靠近时会边打边拉距。
- [ ] 拉距优先走弧线，不长期倒车。
- [ ] 会避开后方死路。
- [ ] 不贴着目标绕小圈。
- [ ] 多炮艇不会挤在同一点。

## 118. 鱼雷与布雷

- [ ] 鱼雷艇会绕侧。
- [ ] 发射前检查友军。
- [ ] 发射后会脱离。
- [ ] 布雷艇预测敌人未来路线。
- [ ] 雷区不会封死己方唯一出口。
- [ ] 布雷后有明确撤离路线。

## 119. 支援舰

- [ ] 维修艇选择目标有战略价值。
- [ ] 维修艇站在安全侧。
- [ ] 两艘维修艇会分摊目标。
- [ ] 护盾艇不追随脱队小艇。
- [ ] 补给艇只在安全区域转运。
- [ ] 拖航组合体使用更大包围体。

## 120. 编队

- [ ] 槽位是区域而不是像素点。
- [ ] 狭窄航道自动转纵队。
- [ ] 开阔战场恢复战斗编队。
- [ ] 脱队舰不会立即被拉回。
- [ ] 归队不会横穿整个编队。
- [ ] 舰队共享主路径。
- [ ] 失去动力舰会触发重排。

## 121. 静态寻路

- [ ] 船体宽度和长度参与路径判定。
- [ ] 障碍按船级膨胀。
- [ ] 路径符合最小转弯半径。
- [ ] 平滑后重新扫掠碰撞。
- [ ] 弯道有推荐速度。
- [ ] 大舰不会进入小艇通道。
- [ ] 生产区范围本身不阻挡航行。
- [ ] 实体平台和码头正常阻挡。

## 122. 动态避碰

- [ ] 会船默认稳定向右让行。
- [ ] 高优先级舰船得到通行权。
- [ ] 局部避碰不直接移动Transform。
- [ ] 船只不会左右高频抖动。
- [ ] 冲撞走廊会通知友军让行。
- [ ] 拖航体不会被普通小艇卡死。

## 123. 建造

- [ ] 放置前检查关键航道连通。
- [ ] 放置前检查全部已建泊位可达。
- [ ] 黄色提示能说明限制的船级。
- [ ] 红色情况禁止封死唯一航道。
- [ ] 建造只更新局部导航块。
- [ ] 摧毁和恢复都会更新路径版本。
- [ ] 可一键定位造成瓶颈的建筑。

## 124. 港口

- [ ] 船先请求泊位。
- [ ] 船在港外候泊。
- [ ] 进港和离港有独立路径。
- [ ] 大船进入窄口时限制对向船。
- [ ] 靠泊最后阶段使用专用曲线。
- [ ] 不瞬间吸附和转向。

- [ ] 港口死锁可自动解除。

## 125. 生产与贸易

- [ ] 多艘生产船会分散作业。

# 第二十五部分：最终设计结论

本次重构的重点不是给旧AI再增加几个条件判断，而是把舰船真正拆成：

```text
理解任务
→ 理解职责
→ 选择目标
→ 选择战术位置
→ 规划可通行走廊
→ 与其他船协调
→ 用符合船体惯性的方式操舵
→ 完成攻击、生产、靠泊或撤退
```

完成后，玩家应能看到：

- 冲撞舟在远处拉开角度，舰首对准敌方炮艇后高速撞入。
- 炮艇始终保持侧舷，一边炮击一边沿弧线拉开。
- 鱼雷艇绕向大型敌舰侧面，确认友军离开航线后发射。
- 布雷艇在敌人即将冲入的缺口外铺设弧形雷阵并及时撤走。
- 护卫舰停在防线前方，维修艇在它身后不断寻找安全抢修位。
- 大型主舰进港前在外海等待，获得许可后沿宽航道缓慢回转靠泊。
- 捕鱼船穿过不会阻挡航行的渔场范围，在鱼群间真实作业，满载后返港卸货。
- 新建地基、防墙和码头会真实改变航路，系统在建造时就告诉玩家哪些船还能通过。
- 敌人无法穿过建筑时，会拆墙、炮击地基、寻找缺口或换路，而不是作弊穿模。

最终目标是让玩家相信：

> 每艘船都有自己的任务、判断、驾驶习惯和空间需求；港口是一套真实运行的航运系统，战场是一片会被建筑、舰队、雷区、火力和船体惯性不断改变的水域。
