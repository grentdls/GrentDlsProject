# 《吞吞舰船》60名英雄普攻、主动技能战斗表现与逻辑落地完整设计文档

> 文档性质：在既有英雄、主舰、装备、海域与战斗反馈框架上的独立增量文档  
> 核心目标：将H01～H60已有的“普攻名称＋标志主动描述”转化为可制作、可配置、可测试、可识别的真实战斗表现  
> 适用模式：海盗生涯无缝世界战斗、固定挑战、港口防守、肉鸽战斗  
> 首版范围：每名英雄1种独特普攻＋1个标志主动的完整表现与逻辑；后续另外2个主动技能必须复用本文模板  

---

## 0. 与既有文档的关系

本文不重做英雄名字、来源、品质与核心定位，继续沿用：

- H01～H60共60名英雄。
- 每艘主舰固定“1名船长＋4名作战英雄”。
- 船长位只贡献属性、船长规则和最多3个被动。
- 船长位不释放普攻，不释放主动技能，不显示Q/E/R/F技能按钮。
- 四个作战位分别对应Q/E/R/F。
- 每名作战英雄提供1种独特普攻、战前装配的1个主动技能和最多3个被动。
- 当前内容表中已经确定的“标志主动”作为首个正式制作的主动技能。
- 英雄最终可拥有3个主动，但同时只装配1个；未确定的另外2个主动不在本文中凭空扩写。
- 普攻通常自动执行，主动技能支持手动释放与自动策略。
- 普通命中不频繁屏震、不逐次说话。
- 重炮、冲撞、模块摧毁、Boss失衡等重要结果才提高反馈强度。

本文新增并覆盖旧文档中的模糊部分：

1. 每种普攻从哪里产生。
2. 炮塔、桅杆、甲板、船侧、舰首、水下或无人机等挂点如何响应英雄。
3. 技能前摇、预警、发射、飞行、命中、持续、结束各阶段如何表现。
4. 自动索敌、手动指向、目标丢失、受控、死亡与切换主舰时如何处理。
5. 四名英雄同时作战时怎样限制视觉、音频、镜头与台词预算。
6. H01～H60逐个英雄的普攻与标志主动落地方案。

旧文档中出现的“六边形海域”表现词，在本项目现版本统一替换为方形小领海与方形板块语义，不影响技能战斗逻辑。

# 第一部分：总体表现目标

## 1. 当前问题

当前英雄已经拥有技能描述，但进入战斗后容易出现以下问题：

- 玩家只看到舰船自动射击，看不出是哪名英雄在发挥作用。
- 不同英雄可能复用同一个炮口和弹道，角色差异只存在于图标和文字。
- 技能开始、命中和结束没有连续过程，像突然生成伤害。
- 维修、护盾、净化、增益等技能只改变数字，没有空间表现。
- 拉拽、击退、减速、固定、失衡等控制没有统一符号。
- 四名作战英雄一起释放时粒子互相覆盖，危险区和目标弱点看不清。
- 自动释放没有解释，玩家不知道技能为什么放、放给谁。
- 角色大图、头像、气泡与实际舰体武器没有建立联系。
- 高品质英雄只是特效更亮，没有新的动作语言和节奏结构。
- 技能逻辑、表现、美术资源与音频资源没有统一配置字段。

---

## 2. 核心体验目标

玩家应在不阅读战斗日志的情况下理解：

1. 哪名英雄正在普攻或释放主动技能。
2. 技能从主舰哪个位置产生。
3. 它会攻击、保护、维修或控制谁。
4. 何时进入有效判定。
5. 能否通过移动、转向、打断或摧毁模块应对。
6. 命中后具体造成了伤害、异常、控制、修复还是增益。
7. 技能何时结束，场上残留区域还会持续多久。

英雄辨识不依赖满屏角色立绘，而依赖六个共同证据：

```text
英雄槽位脉冲
→ 英雄专属起手声
→ 对应舰体装置接管
→ 独特弹道/区域形状
→ 专属命中结果
→ 冷却与状态回写
```

---

## 3. “英雄接管舰船装置”原则

英雄不是站在海面上直接施法，而是通过主舰的舰载装置发挥能力。

### 3.1 接管表现

主动技能开始时：

- 对应作战位头像边框亮起。
- 从头像或英雄槽位产生一条0.12～0.2秒的能量/指令流，指向舰体装置。
- 对应炮塔、机械臂、桅杆、甲板装置或水下舱门亮起英雄识别色。
- 装置播放专属准备动作。
- 技能图标从“按下”进入“施放中”，再进入冷却。

能量流只用于建立因果，不应长期跨越屏幕。

### 3.2 无专属模型时的首版做法

首版允许多个英雄共用基础装置骨架，但必须至少替换：

- 炮口/发射口形状。
- 发射特效。
- 弹体或作用体。
- 尾迹。
- 命中特效。
- 技能识别色。
- 起手与命中音效。
- 装置上的英雄徽记投影。

不得只改颜色后称为独立英雄技能。

### 3.3 正式美术替换

正式版本可将临时装置替换为：

- 专属甲板武器。
- 专属机械臂。
- 专属无人机舱。
- 专属桅杆附件。
- 专属船首撞具。
- 专属水下发射舱。
- 英雄本人短暂出现在甲板操作位的低模动作。

替换不能改变判定原点、碰撞尺寸和技能时间线。

# 第二部分：统一战斗表现语言

## 4. 表现阶段

所有普攻和主动统一拆为以下阶段：

| 阶段 | 英文状态 | 主要职责 |
| --- | --- | --- |
| 选择 | Acquire | 找目标、验证角度、距离、状态与资源 |
| 预备 | Telegraph | 告诉玩家技能将从哪里、朝哪里发生 |
| 前摇 | Windup | 炮塔转向、蓄力、开舱、英雄头像响应 |
| 生效 | Commit | 扣除冷却/资源，创建投射物或区域 |
| 过程 | Travel/Active | 飞行、持续喷射、召唤、牵引或维修 |
| 命中 | Impact | 伤害、控制、修复、异常与主要反馈 |
| 残留 | Residual | 火海、索网、护盾、标记、召唤物等 |
| 收尾 | Recovery | 后坐、散热、收索、关舱、解除接管 |
| 冷却 | Cooldown | UI计时，可响应缩减、重置或交换 |

### 4.1 扣冷却时点

- 瞬发技能：进入Commit时扣冷却。
- 蓄力技能：蓄力达到最低可释放阈值后扣冷却。
- 选区技能：玩家确认区域且验证成功后扣冷却。
- 召唤技能：第一只召唤物成功创建后扣冷却。
- 若技能在Commit前被取消，不扣完整冷却。
- 若Commit后目标死亡或离开，仍视为已释放。

### 4.2 取消与打断

| 情况 | 处理 |
| --- | --- |
| 玩家主动取消瞄准 | 不扣冷却 |
| 前摇中主舰沉没 | 取消，不产生效果 |
| 前摇中对应作战模块失效 | 取消，进入20%基础冷却 |
| Commit后模块失效 | 已产生的投射物/区域继续 |
| 目标在Commit前死亡 | 自动重选；无合法目标则取消 |
| 目标在Commit后死亡 | 技能按原路径执行或转为地面点 |
| 主舰被眩晕 | 普攻暂停；主动是否打断由技能标签决定 |
| 玩家切换主控舰 | 技能继续，镜头与台词降级 |

---

## 5. 友军与敌军视觉语言

### 5.1 阵营边界

- 友方范围：青蓝或青绿色细边，内部低透明度。
- 敌方危险：红橙色外圈，内部有方向或倒计时纹理。
- 中立生态：淡金或自然绿色，不使用敌方红圈。
- 可交互残骸/货物：金色虚线与拾取方向线。
- 同一技能被敌方使用时必须切换阵营外轮廓，不能只依赖内部颜色。

### 5.2 作用形状

| 形状 | 含义 |
| --- | --- |
| 细直线 | 精准射击、鱼雷、鱼叉、雷矛 |
| 扇形 | 机枪扫射、喷火、声波 |
| 圆形 | 爆炸、护盾、修复、灯标 |
| 环形 | 推开、拉回、节奏波、净化 |
| 航迹带 | 油火、索网、增益航线、水雷 |
| 两点连线 | 锁链、并联、缝合、冰墙 |
| 十字/四向 | 全舰四面护盾、四槽协同 |
| 多角包围线 | 鱼雷阵、同步炮击 |

形状必须与真实判定一致，不允许视觉比判定明显大或小。

颜色仅用于辅助，必须同时配合形状、图标和动作。

| 类型 | 主色 | 形状/材质 | 命中关键词 |
| --- | --- | --- | --- |
| 动能/炮击 | 米白、黄橙 | 火花、金属碎片、烟环 | 重、脆、后坐 |

| 爆破 | 橙红 | 膨胀球、碎片、水柱 | 先收缩后爆开 |
| 燃烧 | 橙红＋黑烟 | 液态油膜、持续火苗 | 持续、蔓延 |
| 雷电 | 蓝白＋紫 | 分叉电弧、节点跳跃 | 瞬亮、链式 |
| 冰冷 | 青白 | 晶体边、霜雾、裂纹 | 凝结、碎裂 |
| 声呐 | 青蓝 | 同心水纹、半透明波 | 节奏、穿透 |
| 维修 | 绿色＋黄铜 | 铆钉、焊花、补片 | 从破损处闭合 |
| 护盾 | 青蓝/紫 | 六边晶片、折射面 | 吸收、碎裂 |

| 召唤 | 英雄专色 | 清晰单位轮廓 | 出舱、编队 |
| 污染/异常 | 黄绿/暗红 | 黏液、颗粒、脉冲 | 叠层、净化 |

## 7. 命中反馈等级

| 等级 | 示例 | 模型反馈 | 镜头 | 音频 |
| --- | --- | --- | --- | --- |
| F0 | DOT跳字、持续修复 | 不闪或极弱局部闪 | 无 | 低音量循环 |
| F1 | 机枪、轻炮 | 小火花、弱闪白 | 无 | 短促 |
| F2 | 榴弹、鱼叉、普通主动 | 明显局部受力 | 极轻可选 | 中等瞬态 |
| F3 | 重炮、鱼雷、冲撞 | 碎片、水柱、船体位移 | 0.08～0.15秒冲击 | 低频＋主体声 |
| F4 | Boss失衡、多舰齐射 | 阶段性结构反馈 | 短FOV与时间缩放 | 音乐侧链 |

限制：

- 高频攻击不重复强闪白。
- 同一目标闪白间隔不低于0.07秒。
- DOT每0.3～0.5秒最多一次弱闪。
- 普通普攻不触发全屏色散。
- 主动技能的F3反馈也必须经过表现预算裁剪。

## 8. 音频识别

每名英雄至少需要：

- 1个主动技能起手拟声或短台词。
- 1个装置准备声。
- 1个主要发射声。
- 1个飞行/持续循环声。
- 1个命中声。
- 1个技能结束声。
- 1个失败/无目标提示音。

音频优先级：

```text
Boss机制提示
> 玩家主动技能关键预警
> 主舰受到致命攻击
> 玩家主动技能命中
> 普攻
> 环境与生产
```

四个主动同时释放时：

- 最先释放或玩家手动释放的技能保留完整主体声。
- 其他技能降低3～6dB。
- 同类爆炸在0.08秒内合并低频，不叠加四次峰值。
- 台词最多一名英雄说完整句，第二名只用半句或拟声。

---

## 9. 镜头规则

### 9.1 普攻

- 默认无镜头运动。
- 击破关键模块可有0.05～0.1秒局部冲击。
- 普攻暴击只强化命中和数字，不推拉镜头。

### 9.2 手动主动

- 选区时镜头轻微抬高，保证预警区域完整可见。
- 锁定远处目标时镜头最多偏移屏幕宽度8%。
- Commit瞬间可向技能方向短推近。
- F3命中允许FOV快速放大2°后恢复。
- 不夺取操船控制。

### 9.3 自动主动

- 不强制转镜头。
- 只在屏幕边缘显示方向箭头。
- 玩家当前镜头可见时才播放轻冲击。
- 非主控舰技能仅在舰队状态卡与世界位置显示简化反馈。

### 9.4 演出保护

- 0.6秒内只允许一个技能获得主镜头权。
- 后续技能进入“局部表现模式”。
- 玩家正在穿越礁石、冰墙、雷区或Boss必躲技能时，关闭英雄技能镜头推拉。
- 设置中提供：完整、简化、关闭技能镜头。

# 第三部分：普攻统一逻辑

## 10. 普攻索敌

每个普攻定义：

- 最小与最大射程。
- 前向、侧舷、后方或全向射界。
- 优先目标标签。
- 是否预测移动。
- 是否可攻击水下。
- 是否可攻击空中/无人机。
- 是否可攻击中立对象。
- 是否需要视线。
- 是否受转向、航速、天气与过热影响。

推荐评分：

```text
TargetScore =
威胁值 × 0.28
+ 目标类型适配 × 0.24
+ 距离适配 × 0.16
+ 射界稳定 × 0.12
+ 已标记弱点 × 0.12
+ 连携价值 × 0.08
- 过量伤害惩罚
- 友军遮挡惩罚
```

### 10.1 目标保持

- 普攻不应每帧切换目标。
- 轻武器最短目标保持0.4秒。
- 重炮最短目标保持到本轮发射结束。
- 目标离开射界、隐身或死亡才强制重选。
- 速射英雄允许在小艇间快速切换，但每次切换要有短锁定线。

---

## 11. 普攻节奏

普攻不应只有“冷却到点→生成子弹”：

```text
索敌
→ 装置转向
→ 0.08～0.4秒准备
→ 发射
→ 后坐/散热
→ 装填
```

不同类型推荐节奏：

| 类型 | 准备 | 发射 | 收尾 |
| --- | ---: | ---: | ---: |
| 速射 | 0.08～0.15秒 | 3～12发一组 | 0.15～0.4秒 |
| 轻炮 | 0.15～0.3秒 | 单发/短连发 | 0.25～0.6秒 |
| 重炮 | 0.4～0.8秒 | 单发/齐射 | 0.6～1.2秒 |
| 鱼雷 | 0.35～0.65秒 | 开舱入水 | 0.5～1秒 |
| 维修 | 0.2秒接管 | 0.8～2秒作用 | 0.2秒收臂 |
| 召唤 | 0.3秒开舱 | 放出单位 | 视整备时间 |
| 声呐 | 0.15秒蓄能 | 波纹扩散 | 0.25秒衰减 |

---

## 12. 普攻表现降级

当同屏单位和弹体过多时：

- L0：显示完整炮口、弹体、尾迹、命中与水面响应。
- L1：减少尾迹粒子，保留弹体和命中。
- L2：弹体可改为短线或轨迹插值，命中合并。
- L3：只显示高价值技能、伤害汇总和状态图标。
- 屏幕外：不创建纯视觉尾迹，只保留逻辑投射物或服务器结果。

普攻表现降级不得改变命中时点。

# 第四部分：主动技能统一逻辑

## 13. 主动释放方式

| 类型 | 操作 | 示例 |
| --- | --- | --- |
| 即时自身 | 按键立即释放 | 全舰护盾、压力释放 |
| 智能目标 | 按键选择当前最优目标 | 破甲齐射 |
| 点选目标 | 按键后点选单位 | 紧急大修、掠夺钩锁 |
| 地面区域 | 按键后选择海面位置 | 燃烧油海、灯塔锁定 |
| 方向技能 | 按住显示方向，松开释放 | 弹幕扫射、雷矛 |
| 两点技能 | 选择起点与终点 | 冻结航道、王家航线 |
| 节奏技能 | 在窗口内再次按键 | 第四声、回声护盾 |
| 条件技能 | 满足状态后高亮释放 | 无声上浮、残骸合唱 |

### 13.1 快速施放

- 玩家短按：使用智能推荐目标/方向。
- 玩家按住0.18秒：进入精确瞄准。
- 移动端短点：智能释放。
- 移动端拖拽：方向/区域选择。
- 自动模式：只走智能选择，不生成瞄准停顿。

---

## 14. 自动释放策略

每个主动至少支持：

- 关闭自动。
- 冷却即用。
- 精英/Boss优先。
- 达到目标数量。
- 低血/异常/模块失效时使用。
- 等待连携标签。
- 保留到玩家手动使用。

自动释放判定示例：

```text
CanAutoCast =
技能可用
&& 当前策略允许
&& 有合法目标
&& 预计收益超过阈值
&& 不会打断更高优先级操作
&& 不与同类区域严重重叠
&& 不处于演出锁定
```

UI必须能解释自动释放原因：

```text
自动释放：检测到3个以上小型敌舰
自动释放：主舰生命低于35%
暂缓释放：等待燃烧标记
暂缓释放：目标即将离开有效区域
```

## 15. 区域与重叠

- 同类火海不重复创建四层独立粒子；逻辑层可叠加，表现层合并亮度和边缘。
- 多个护盾重叠时按来源显示主护盾与小来源图标。
- 多个拉拽同时作用时合成最终力，不让目标高频抖动。
- 两个冰墙相交时生成稳定连接点，不产生物理爆炸。
- 多个声呐波同时扩散时降低次要波透明度。
- 召唤单位必须有全舰共享上限。

## 16. 技能失败与边界情况

技能不能静默失败。

| 原因 | UI与场景反馈 |
| --- | --- |
| 无合法目标 | 技能图标轻摇，显示“无目标” |
| 射界不符 | 舰体上显示需要转向的方向弧 |
| 距离过远 | 预警线在最大射程处断开 |
| 区域受限 | 区域变灰并显示原因 |
| 模块失效 | 对应挂点冒烟，技能图标显示模块图标 |
| 浅水无法召唤海兽 | 海面轮廓变为虚线并提示水深不足 |
| 没有残骸 | 残骸合唱/引魂技能显示0个可用目标 |
| 没有异常 | 净化技能可释放但不建议，高亮关闭 |
| 多舰不在同海域 | 六舰齐令显示实际响应舰数 |

- 挂点：医疗吊臂。
- 目标：最低当前耐久或负伤状态英雄所在模块。
- 过程：短时间绿色脉冲束，显示稳定恢复。
- 视觉：目标区域出现心电/医疗小图标，不使用神圣光柱。

### 标志主动：远航护理

- 操作：点选友军主舰或自身。
- 预警：显示持续恢复总量与负伤时间缩短。
- 前摇：苏茜头像打开医疗箱；医疗无人机起飞。
- 生效：一段时间内持续恢复英雄状态和模块小额耐久。
- 逻辑：高级异常只抑制、不立即清除；与H38/H49保持差异。
- 自动条件：多名英雄受伤或主舰持续受到小额伤害。
- 音频：医疗设备、平稳脉冲与无人机轻鸣。
- 表现：低强度持续，不遮挡战斗中心。

## 76. H60 甲板长奥托

### 普攻：甲板撞钩

- 挂点：舰首短撞钩。
- 触发：近身接触后钩住目标边缘，造成一次稳定撞击伤害。
- 作用：提高碰撞稳定，减少自身弹开。
- 战利品：普通掉落被短钩拖近。

### 标志主动：清舷夺货

- 操作：即时近身/智能目标。
- 预警：主舰两侧显示清舷范围与可回收普通战利品。
- 前摇：奥托头像吹甲板哨；船员影子在舷侧集合。
- 生效：两侧短撞钩和扫舷杆同时推出，推开小艇并拉回普通货物。
- 逻辑：不作用于Boss核心和高价值特殊任务物品。
- 自动条件：近身小艇包围或大量普通战利品即将消失。
- 音频：甲板哨、木杆/金属钩碰撞、货箱落甲板。
- 短板：对大型核心只造成轻微碰撞，不做夸张F3。

# 第十八部分：最终执行规则

## 104. 必须遵守的十条规则

1. 技能表现必须从玩法事件读取，不能由特效决定伤害。
2. 每次主动都必须建立“英雄—舰体装置—目标—结果”的因果链。
3. 船长位绝不播放普攻或主动技能表现。
4. 预警形状必须匹配真实判定。
5. 自动释放与手动释放玩法一致，只降低镜头和台词强度。
6. 高频普攻不频繁屏震、不逐发说话、不持续强闪白。
7. 四技能同时释放时，敌方危险预警优先于友方装饰特效。
8. 维修、护盾、净化、掠夺等非伤害结果也必须有空间过程。
9. 复杂技能必须进入统一状态机，不为单英雄写无法维护的旁路。
10. 正式美术可以替换临时装置，但不能改变判定、时间线和操作逻辑。

## 105. 推荐的首个完整战斗样板

推荐先制作以下阵容：

```text
船长：H01 罗盘艾伦
Q：H02 快枪米娅
E：H05 铁钩雷蒙
R：H03 老锤格鲁
F：H04 风帆凯
```

完整样板流程：

```text
发现逃跑宝箱船
→ H01船长头像给出追击判断，但不释放技能
→ H04超速追猎建立追击航线
→ H02双联机枪自动清理护航小艇
→ H05重炮普攻击破宝箱船外甲
→ 玩家手动释放破甲齐射
→ 敌方护航炮命中主舰并打坏模块
→ H03维修臂先进行普攻修复
→ 玩家释放紧急大修恢复失效模块
→ 宝箱船被击败，实体货箱落海
→ 主舰靠近吸附并入舱
→ 战斗结束，英雄最多两人进行短互动
```

这个样板同时验证：

- 船长与作战位边界。
- 追击航线。
- 高频与重型普攻差异。
- 主动技能预警和命中。
- 非伤害维修技能。
- 实体掉落与战后反馈。
- 四英雄表现预算。

完成样板后，再按第95～98节逐批扩展到H01～H60。

## 106. 结论

60名英雄的差异不能只存在于数值、技能名称和角色图鉴中。进入战斗后，每名英雄都必须通过舰体装置、动作节奏、作用形状、声音、目标选择与命中结果体现自己的职业和性格。

本文已经为H01～H60逐个明确：

- 普攻从何处产生。
- 如何索敌与作用。
- 前摇、发射、命中和收尾如何表现。
- 标志主动如何操作。
- 主动的完整时间线和空间反馈。
- 自动释放条件。
- 主要音效与镜头规则。
- 失败、克制和特殊边界。

后续新增的每个主动技能必须使用同一模板：

```text
玩法目的
→ 操作类型
→ 合法目标
→ 准确预警
→ 英雄与舰体接管
→ Commit时点
→ 生效过程
→ 命中/状态结果
→ 残留与结束
→ 自动策略
→ 音频/镜头
→ 失败与边界
→ LOD与性能
→ 验收用例
```

只有这样，英雄体系才能从“文字描述的技能库”升级为真正可读、可操作、可连携、可长期扩展的舰队战斗系统。
