# Unity《亲密城堡》角色美术与动作序列帧规则文档  
## 对标《杀戮尖塔》角色站位的成人向卡牌爬塔素材生成规范

> 目标：为 Unity 成人向卡牌爬塔项目《亲密城堡》建立一套可直接指导 AI 绘图、人工绘制、序列帧拆分、Unity 导入和 Prefab 装配的角色美术规则。  
> 范围：主角、普通对手、精英对手、Boss、NPC、卡牌头像、意图图标、Buff / Debuff 图标、动作序列帧、失败 / 胜利 / 受击表现。  
> 重要限制：本文档只做 **18+成人主题的抽象化亲密互动表现**，不制作露骨器官特写、真实性行为过程、未成年人、非自愿、羞辱性或歧视性内容。肤色、性取向、性别认同只作为外观和身份表达，不绑定数值强弱。能力差异由职业、性格、体型风格、派系和卡组机制决定。

---

# 1. 总体美术方向

## 1.1 项目视觉关键词

《亲密城堡》的角色美术应保持：

1. **成人向但非露骨**：性感、暧昧、戏剧化、舞台感，不直接表现露骨行为。
2. **卡牌爬塔可读性优先**：角色剪影清晰，动作幅度夸张，战斗意图一眼可懂。
3. **对标《杀戮尖塔》舞台布局**：玩家站左侧，对手站右侧，中间留出卡牌和效果飞行路径。
4. **角色不是写实人体素材**：使用 2D 手绘 / 半厚涂 / 轻暗黑童话风，避免摄影感、真人感。
5. **图标替代文字**：职业、攻击方式、Buff、Debuff、意图、奖励尽量使用图标和颜色区分。
6. **统一资源规格**：所有角色都能落到同一 Prefab 结构，方便程序替换素材。

## 1.2 成人主题的安全表达边界

| 内容 | 可以做 | 不建议 / 禁止 |
|---|---|---|
| 角色服装 | 晚礼服、舞台装、皮革装、丝绸装、面具、披风、贴身但不露骨的剪裁 | 裸体器官特写、透明露骨服装、过度暴露重点部位 |
| 动作表现 | 靠近、邀舞、抚肩、耳语、回旋、压迫感、心跳特效、香气特效、节奏波纹 | 明确性行为过程、性器官动作、强迫/束缚/非自愿情节 |
| 数值名称 | 张力、忍耐、共鸣、冷静、魅力、节奏、专注 | 过度露骨的器官或行为命名直接出现在 UI |
| 失败表现 | 主角退场、跪地喘息、镜头淡出、被弹出房间、卡牌散落 | 羞辱、侵犯、非自愿、伤害化成人内容 |
| 胜利表现 | 对手脸红、心形粒子、握手、优雅退场、契约印记 | 露骨高潮画面或细节描写 |
| 多样性 | 不同性别表达、肤色、体型、风格、服装文化感 | 将肤色、性取向、性别认同绑定强弱属性或负面刻板印象 |

## 1.3 肤色与 LGBT+ 表达规则

用户希望存在不同肤色和不同性别表达的对手。实现时必须遵守以下规则：

1. **肤色只作为外观色板，不改变数值。**  
   不允许出现“某肤色攻击更高 / 更低”“某肤色更容易被控制”等绑定。

2. **性取向和性别认同只作为角色身份表达，不决定战斗强弱。**  
   角色可以是男性、女性、非二元、跨性别表达、酷儿风格，但战斗机制来自职业、派系和性格。

3. **体型可以影响动作剪影，但不做羞辱性描述。**  
   例如：高大型角色适合大范围压迫动作；柔韧型角色适合闪避和连击；运动型角色适合冲刺动作。

4. **所有角色都必须为成年人。**  
   美术提示词必须写明：`adult character, mature appearance, no minor traits`。

# 2. 统一资源规格

## 2.1 角色基础画布

| 资源类型 | 推荐尺寸 | 单帧尺寸 | 用途 |
|---|---:|---:|---|
| 普通角色序列帧 | 4096×4096 | 512×512，8×8 网格 | 普通敌人、主角基础动作 |
| 大型精英序列帧 | 6144×6144 | 768×768，8×8 网格 | 精英、双人角色、中型 Boss |
| Boss 序列帧 | 8192×8192 | 1024×1024，8×8 网格 | 大 Boss、终章角色 |
| 角色立绘 | 2048×2048 | 单图 | 图鉴、事件、奖励界面 |
| 卡牌头像 / 半身像 | 1024×1024 | 单图 | 卡牌插画、角色详情 |
| 头像小图标 | 512×512 | 单图 | 对话、事件、Map 节点 |
| Buff / Debuff 图标 | 256×256 | 单图 | 战斗 HUD |
| 意图图标 | 256×256 | 单图 | 敌人头顶意图 |

## 2.2 透明背景规则

所有角色与动作序列帧默认导出：

- 文件格式：PNG。
- 背景：透明通道。
- 角色外轮廓：保留 2–4 px 柔和描边。
- 阴影：单独导出一张椭圆阴影，不要烘焙进角色帧。
- 特效：若复杂，拆成独立 VFX 序列，不要和角色主体混死。
- 角色不能使用接近透明背景的纯白高光，避免抠图丢边。

## 2.3 角色朝向与站位

战斗界面对标《杀戮尖塔》：

- 玩家在左侧，面向右。
- 对手在右侧，面向左。
- 角色采用 **3/4 侧向**，不是纯正面。
- 主角站位稳定，对手可以有轻微浮动或舞台位移。
- 所有动作的脚底基准线必须统一。

### Unity Pivot 规则

| 资源 | Pivot X | Pivot Y | 说明 |
|---|---:|---:|---|
| 普通站立角色 | 0.5 | 0.08 | 脚底中心 |
| 大型角色 | 0.5 | 0.05 | 脚底中心偏下 |
| 浮空角色 | 0.5 | 0.35 | 身体中心偏下 |
| 卡牌头像 | 0.5 | 0.5 | 中心点 |
| 图标 | 0.5 | 0.5 | 中心点 |

## 2.4 角色高度比例

以主角在战斗画面中的显示高度为 1.0：

| 类型 | 显示比例 | 说明 |
|---|---:|---|
| 主角 | 1.00 | 基准 |
| 小型普通对手 | 0.85–0.95 | 灵巧、侍从、调香师 |
| 标准普通对手 | 1.00–1.10 | 舞者、歌手、图书管理员 |
| 高大型普通对手 | 1.15–1.30 | 教练、保镖、骑士 |
| 精英 | 1.30–1.55 | 双人、舞台主角、机械装置 |
| Boss | 1.60–2.20 | 女公爵、镜厅主宰、城堡核心 |

| 动作类型 | 推荐 FPS | 循环 | 说明 |
|---|---:|---|---|

| Intent 预备 | 10–12 | 可循环 | 敌人出招前状态 |
| Attack 攻击 | 12–15 | 否 | 需要有明显前摇、命中、收招 |
| Skill 技能 | 12–15 | 否 | 特效更明显 |

| Fail 失败 | 10–12 | 否 / 可停最后帧 | 退场或跪地，不做露骨表现 |
| Entrance 入场 | 10–12 | 否 | 从阴影、门、雾气中进入 |
| Exit 退场 | 10–12 | 否 | 胜利或事件后离场 |

# 6. 序列帧制作规则

## 6.1 通用帧表结构

每个动作至少包含：

1. **前摇帧**：告诉玩家动作即将发生。
2. **发力帧**：角色身体重心变化。
3. **命中帧**：特效最亮、伤害或状态结算。
4. **收招帧**：动作回归待机。

### 标准 8 帧攻击动作

| 帧 | 内容 | 要点 |
|---:|---|---|
| 1 | 待机过渡 | 身体压低，眼神转向目标 |
| 2 | 前摇 | 手臂 / 道具 / 光效蓄力 |
| 3 | 起步 | 角色向目标方向移动 10–20 px |
| 4 | 发力 | 剪影最大，衣摆和特效拉长 |
| 5 | 命中 | 冲击光、心形波纹、卡牌闪光 |
| 6 | 余波 | 对手受击或状态图标弹出 |
| 7 | 收招 | 身体回正，特效淡化 |
| 8 | 回待机 | 回到 Idle 首帧附近 |

### 标准 6 帧受击动作

| 帧 | 内容 | 要点 |
|---:|---|---|
| 1 | 命中瞬间 | 白闪 / 红心碎片 / 星星 |
| 2 | 后仰 | 身体重心后移 |
| 3 | 最大后仰 | 表情变化最明显 |
| 4 | 稳住 | 一只脚后撤或手扶道具 |
| 5 | 恢复 | 服装和头发回弹 |
| 6 | 回待机 | 接 Idle |

### 标准 12 帧失败动作

| 帧 | 内容 | 要点 |
|---:|---|---|
| 1–2 | 反应 | 角色意识到失败 |
| 3–5 | 失衡 | 卡牌、图标或光效散落 |
| 6–8 | 退场准备 | 身体下沉或被门影覆盖 |
| 9–11 | 退场 | 向后淡出、被城堡雾气包裹 |
| 12 | 停帧 | 留一个安全、非露骨的失败 Pose |

## 6.2 动作位移规则

| 动作 | 最大位移 | 说明 |
|---|---:|---|
| 待机 | 0–3 px | 只做呼吸 |
| 轻攻击 | 10–25 px | 角色主体不离开站位过远 |
| 重攻击 | 30–60 px | 可前踏但必须回位 |
| 技能 | 0–30 px | 主要靠特效表达 |
| 受击 | 10–35 px | 受击后回到原位 |
| 失败退场 | 60–120 px | 可淡出或下沉 |
| 胜利 | 0–20 px | 更像舞台 Pose |

## 6.3 特效拆分规则

角色主体和特效尽量拆开：

```text
角色主体：CH_Common_Dancer_Sheet_Attack_RhythmWave.png
命中特效：VFX_RhythmWave_12f.png
状态图标：ICON_Debuff_RhythmMark.png
```

这样可以在 Unity 中复用特效，并减少角色序列帧重绘成本。

## 6.4 表情层规则

若需要表情变化，建议拆成 Overlay：

| 表情 | 用途 |
|---|---|
| Neutral | 待机 |
| Smile | 增益 / 胜利 |
| Focus | 攻击 / 技能 |
| Surprised | 受击 |
| Blush | 共鸣接近满值 |
| Exhausted | 失败 |

# 7. 主角美术设计

## 7.1 CH_Player_MaleTraveler：男主 / 城堡挑战者

### 角色定位

- 玩家唯一可用角色。
- 视觉上是“误入亲密城堡的成年男性挑战者”。
- 不是硬核战士，而是卡牌策略游戏里的舞台主角。
- 需要适合大量皮肤、遗物、增幅叠加表现。

### 外观描述

| 项目 | 描述 |
|---|---|
| 性别表达 | 成年男性，成熟外观 |
| 体型 | 标准运动型，肩背清晰但不过度肌肉化 |
| 服装 | 深色长外套、内搭衬衫、腰带、手套、轻微舞台装元素 |
| 色彩 | 主色深酒红 / 黑 / 暖金，辅色蓝紫 |
| 头发 | 中短发，动作时有轻微摆动 |
| 道具 | 卡牌、契约徽章、腰间小挂件、可换装饰物 |
| 剪影 | 上身挺拔，手部动作清楚，适合出牌动画 |

### 视觉关键词

```text
adult male card battler, dark romantic castle, confident but not aggressive, theatrical fantasy outfit, no nudity, mature appearance, 2D hand-painted, transparent background, three-quarter side view, readable silhouette
```

### 皮肤变体

| 变体名 | 外观 | 作用 |
|---|---|---|
| BaseTraveler | 默认长外套 | 默认皮肤 |
| VelvetNoble | 天鹅绒贵族装 | 商店皮肤 |

> 皮肤只改变外观，不改变数值。

# 12. 卡牌插画规则

## 12.1 卡牌画面结构

卡牌对标《杀戮尖塔》的可读性：上方标题区、中央插画、下方描述。但本项目尽量图标化。

卡牌插画建议采用：

```text
图标化动作剪影 + 背景光效 + 数值图标
```

不要在卡牌中画复杂的人体互动细节。

## 12.2 卡牌插画尺寸

| 类型 | 尺寸 | 说明 |
|---|---:|---|
| 原始插画 | 1024×768 | 横向构图，方便裁切 |

# 22. 最终落地原则

1. **先保证战斗识别，再追求成人氛围。**  
   玩家必须一眼看懂谁要攻击、谁有 Buff、谁快满共鸣。

2. **成人向主要由主题、服装、光效、表情、舞台氛围表达。**  
   不依赖露骨身体细节。

3. **所有角色都按同一 Prefab 结构生产。**  
   程序只替换 Sprite、Animator、SO 数据，不为单个角色写特殊 UI。

4. **不同肤色和 LGBT+ 表达是外观多样性，不是属性模板。**  
   数值差异来自职业和机制。

5. **每个动作都要服务玩法。**  
   攻击看前摇，防御看护盾，Debuff 看紫色图标，增益看金色图标，失败看退场，胜利看谢幕。
