# Unity《亲密城堡》楼层主题与流派扩展设计文档

> 版本：V1.0  
> 用途：扩展每层玩法差异、主题卡池、敌人套路、事件、Boss、伙伴与 Build 组合。  
> 定位：成人向卡牌爬塔，核心结构参考《杀戮尖塔》的爬塔逻辑，但美术、卡牌、楼层和机制全部原创。  
> 合规说明：所有角色默认为 **18+ 成年角色**；“教室、监狱、电车”等主题均为幻想舞台、合意角色扮演或成人场景，不表现未成年、不表现真实强迫，不把肤色、性取向、身份作为属性强弱来源。  
> 字段说明：文档保留部分成人向系统字段，例如【连续抽插】、【喷射命数】、【阳具弹珠】等；实际上架时可做“内部字段 / 外显名称”分离，例如【连续推进】、【临界命数】、【珠核插件】。

---

# 1. 总体目标

## 1.1 当前问题

现在不同楼层的玩法差异还不够明显，容易变成“换背景 + 换敌人”。需要让每一层都有独立主题、独立敌人压力、独立卡池奖励和独立 Build 机会。

## 1.2 优化目标

每个楼层都要形成完整闭环：

```text
楼层主题
→ 敌人机制
→ 掉落卡池
→ 专属遗物
→ 专属事件
→ 可招募伙伴
→ Boss 机制
→ 推荐 Build
→ 被克制 Build
```

玩家进入新楼层后，应当能立刻感知：

- 这一层敌人擅长什么。
- 这一层能拿到什么套路卡。
- 当前卡组适不适合打这一层。
- 哪些事件值得冒险。
- 是否值得招募伙伴。
- Boss 会考验哪种机制理解。

# 2. 楼层主题总规则

## 2.1 楼层数据结构

```text
FloorThemeData
├─ FloorId                  楼层 ID
├─ FloorName                楼层名称
├─ VisualTheme              视觉主题
├─ FloorRuleModifier        本层规则修正
├─ EnemyTraitPool           敌人特性池
├─ ThemeCardPool            主题卡池
├─ ThemeRelicPool           主题遗物池
├─ EventPool                奇遇事件池
├─ PartnerPool              可招募伙伴池
├─ BossPool                 Boss 池
├─ RecommendedBuilds        推荐流派
└─ CounteredBuilds          被克制流派
```

## 2.2 楼层长度建议

| 类型 | 节点数 | 用途 |
|---|---:|---|
| 小主题层 | 6~8 | 支线、短路线、特殊事件层 |
| 标准主题层 | 10~14 | 常规爬塔楼层 |
| 大型主题层 | 16~20 | Act 级主线区域 |
| 混合主题层 | 12~18 | 后期双主题高难区域 |

## 2.3 标准楼层节点比例

| 节点类型 | 数量 |
|---|---:|
| 普通战斗 | 5~7 |
| 精英战斗 | 1~2 |
| 事件 | 2~4 |
| 商店 | 1 |
| 休息 | 1~2 |
| 宝箱 | 1 |
| Boss | 1 |

## 2.4 主题卡池掉落规则

卡牌奖励建议按权重生成：

```text
基础职业卡池：50%
当前楼层主题卡池：35%
当前已有 Build 相关卡池：10%
稀有跨主题卡：5%
```

已有核心遗物后，提高相关卡牌出现率：

```text
已有【连续抽插次数】属性：连击卡权重 +20%
已有【阳具弹珠】：追击卡权重 +20%
已有【粘液】核心卡：粘液卡权重 +20%
已有伙伴：群战协同卡权重 +15%
已有反伤遗物：反伤卡权重 +15%
已有命数遗物：喷射命数卡权重 +15%
```

# 4. 酒吧楼层：酒意与失控爆发

## 4.1 主题定位

酒吧层强调随机性、爆发和风险收益。敌人擅长喝酒相关卡牌，会给自己或玩家叠加【酒意】，酒意越高越强，但也越容易失控。

### 视觉关键词

暗红酒吧、霓虹灯、吧台、酒杯、金色泡沫、摇晃灯光、舞池边缘。

### 玩法关键词

【酒意】、【醉步】、【酒水牌】、【随机强化】、【失控】。

## 4.2 楼层规则

```text
所有敌人开局获得 1~3 层【酒意】。
敌人每获得【酒意】，有概率获得随机增益。
玩家使用酒水卡时，效果较强，但会增加自身忍耐。
酒吧层卡牌奖励中，酒水相关卡出现率提高。
```

## 4.3 新状态：酒意

```text
酒意：每层使该单位造成的共鸣 / 忍耐影响 +3%，但行动有 5% 概率偏移。
最多 10 层。
达到 6 层后，进入【微醺】。
达到 10 层后，进入【失控】。
```

### 微醺

```text
每回合第一次攻击额外触发一次 30% 伤害的随机追击。
```

### 失控

```text
攻击力 +40%，但每回合结束自身共鸣 +8%。
```

## 4.4 酒吧敌人

| 敌人 | 机制 | 反制 |
|---|---|---|
| 调酒师 | 给全体叠酒意，随机强化 | 先控场，避免拖回合 |
| 醉舞客 | 闪避高，攻击随机 | 多段攻击破闪避 |
| 吧台女王 | 每次受击获得酒意 | 用状态伤害或爆发收尾 |
| 酒杯魔术师 | 把玩家手牌变成临时酒水牌 | 利用随机收益，保留低费牌 |
| 失控保镖 | 高攻击，酒意越高越危险 | 快速破防或削酒意 |

## 4.5 酒水流卡牌

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---:|---:|---|---|
| 微醺推进 | 攻击 | 1 | 造成伤害；若自身有酒意，抽 1 | 红金酒气缠绕突进 |
| 烈酒入喉 | 技能 | 0 | 获得 2 酒意，抽 1，忍耐 +2 | 酒杯图标飞入玩家 |
| 酒后连击 | 攻击 | 1 | 【连续抽插】2 次；每有 2 层酒意，次数 +1 | 摇晃残影多段冲刺 |
| 烈焰酒雾 | 技能 | 1 | 全体施加 2 酒意和 1 挑逗 | 酒雾扩散全场 |
| 醉步闪避 | 技能 | 1 | 获得冷静，下一次受击减半 | 身影左右晃动 |
| 燃杯一击 | 攻击 | 2 | 消耗所有酒意，每层提高 8% 伤害 | 酒杯爆成火焰弧光 |
| 失控拥抱 | 强化 | 2 | 每回合开始获得 1 酒意；酒意≥6 时攻击 +20% | 红色酒气环绕 |
| 清醒一瞬 | 技能 | 1 | 移除所有酒意，每层回复冷静 | 蓝光驱散酒雾 |

## 4.6 酒吧遗物

| 遗物 | 效果 |
|---|---|
| 银质酒杯 | 每场战斗第一次获得酒意时，额外抽 1 |
| 破裂调酒壶 | 酒意达到 6 时，自动对随机敌人造成一次 50% 追击 |
| 微醺玫瑰 | 每 3 层酒意使魅力牌效果 +10% |
| 空瓶护符 | 移除酒意时，获得等量冷静 |
| 烈酒契约 | 失控时不会随机偏移，但忍耐额外 +2 |

## 4.7 酒吧 Boss：红酒伯爵

### Boss 特点

- 每回合给双方叠酒意。
- 酒意越高，Boss 攻击越强。
- Boss 达到 10 酒意会释放【满杯终曲】。

### 反制方式

- 用清醒类卡清酒意。
- 快速爆发抢在满杯前结束。
- 利用酒意反噬让 Boss 自己共鸣上涨。

# 5. 舞会楼层：魅力、假意与姿态切换

## 5.1 主题定位

舞会层强调魅力值、假动作、姿态切换、闪避与控制。敌人会使用假意魅惑，让玩家第一次攻击收益降低。

### 视觉关键词

华丽舞厅、水晶灯、面具、礼服、镜面地板、旋转聚光、金色音符。

### 玩法关键词

【魅力】、【假意】、【舞步】、【闪避】、【姿态切换】。

## 5.2 楼层规则

```text
敌人拥有更高闪避和更多诱导类行动。
每 3 回合触发一次舞会节拍。
舞会节拍时，所有舞步牌费用 -1。
魅力牌奖励出现率提高。
```

## 5.3 新资源：魅力值

```text
魅力值：玩家临时资源。
每点魅力使下一张状态牌效果 +5%。
魅力达到 10 时，下一张魅力牌触发额外效果，并清空魅力。
```

## 5.4 新状态：假意魅惑

```text
假意魅惑：敌人的伪装状态。
拥有假意时，第一次受到攻击只承受 50% 效果，并移除假意。
若玩家使用控制牌，可直接破除假意。
```

## 5.5 舞会敌人

| 敌人 | 机制 | 反制 |
|---|---|---|
| 面具舞者 | 拥有假意，闪避高 | 先用控制牌破假意 |
| 领舞者 | 每回合切换姿态 | 观察意图，保留反制卡 |
| 水晶歌姬 | 通过歌声叠魅惑 | 净化或快速打断 |
| 双人舞搭档 | 两个敌人互相保护 | AOE 或破防 |
| 镜厅幻影 | 复制玩家上一张牌的弱化版 | 避免连续打核心牌 |

## 5.6 魅力流卡牌

|---|---:|---:|---|---|
| 开场邀舞 | 技能 | 0 | 获得 3 魅力 | 玩家伸手，聚光落下 |
| 旋步试探 | 攻击 | 1 | 造成伤害，获得 2 魅力 | 弧形舞步突进 |
| 假意靠近 | 技能 | 1 | 施加 2 挑逗；若魅力≥5，额外施加虚弱 | 面具碎光飞向敌人 |
| 领舞压制 | 攻击 | 2 | 魅力越高伤害越高 | 金色舞步线包围目标 |
| 反身错步 | 技能 | 1 | 获得冷静并闪避下一次轻攻击 | 身影旋转错开 |
| 魅力爆点 | 攻击 | 1 | 消耗全部魅力，每点造成追加共鸣 | 心形聚光爆开 |

| 谢幕一击 | 攻击 | 3 | 若魅力达到 10，造成巨额伤害 | 谢幕式大弧光 |

## 5.7 舞会遗物

| 遗物 | 效果 |
|---|---|
| 银色面具 | 每场战斗第一次获得魅力时，额外 +3 |

| 破碎假面 | 破除敌人假意时，抽 1 |
| 聚光胸针 | 魅力达到 10 时，获得 1 能量 |
| 黑天鹅羽 | 闪避成功后，对攻击者施加 2 挑逗 |

## 5.8 舞会 Boss：假面公爵

### Boss 特点

- 拥有多层假意。
- 每次假意被破除，切换舞步姿态。
- 不同姿态反制不同类型卡牌。

### 反制方式

- 准备控制牌破假意。
- 避免单一攻击类型。
- 用魅力爆点作为终结。

# 6. 大学教室楼层：低上限、多命数、快节奏复活

## 6.1 主题定位

大学教室层是成人校园幻想主题。所有角色必须明确为成年大学生、研究生、讲师或社团成员。本层强调“共鸣上限低、命数多、快速复活、低费速攻”。

### 视觉关键词

夜间成人学院、教室、黑板、课桌、社团海报、讲台、台灯、笔记本。

### 玩法关键词

【低共鸣上限】、【多命数】、【喷射命数】、【复活】、【低费连击】。

## 6.2 楼层规则

```text
本层多数敌人共鸣上限低，但拥有 2~4 条命数。
敌人每次被结算后，会以较低状态重新站起。
本层掉落更多与喷射次数、命数、复活、重置相关的卡牌。
```

## 6.3 命数规则

```text
命数：单位可承受结算的次数。
敌人共鸣满时，消耗 1 命数并进入短暂失衡。
若命数归零，敌人真正退场。
玩家默认喷射命数为 1，可通过卡牌和遗物增加。
```

## 6.4 教室敌人

| 敌人 | 机制 | 反制 |
|---|---|---|
| 社团新人 | 共鸣低，命数多 | 多段追击快速清命 |
| 课堂助教 | 给其他敌人补命数 | 优先击破 |
| 学术偶像 | 被击破后获得魅力 | 控制复活节奏 |
| 夜读组长 | 每回合给全体护持 | 破防或粘液增伤 |
| 实验课代表 | 退场时给玩家状态牌 | 控制手牌污染 |

## 6.5 命数流卡牌

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---:|---:|---|---|
| 快速点名 | 攻击 | 0 | 小伤害；若击破一条命，抽 1 | 粉笔光点命中 |
| 课间突袭 | 攻击 | 1 | 【连续抽插】2 次；若击破命数，追加 1 次 | 多段短冲刺 |
| 临界续命 | 技能 | 1 | 本场战斗喷射命数 +1，但忍耐上限 -10% | 额外心格出现 |
| 重置呼吸 | 技能 | 1 | 喷发后回复部分冷静 | 蓝光重填忍耐条 |
| 二次上课 | 技能 | 0 | 从弃牌堆取回 1 张 0 费牌 | 卡牌从课桌飞回 |
| 命数转化 | 强化 | 2 | 每消耗敌人 1 命数，获得 1 能量 | 命数图标转能量 |
| 毕业考核 | 攻击 | 2 | 对命数大于 1 的敌人造成额外伤害 | 黑板判定印章 |
| 期末爆发 | 攻击 | 3 | 消耗自身 1 喷射命数，造成全体大量共鸣 | 全教室灯光爆闪 |

## 6.6 教室遗物

| 遗物 | 效果 |
|---|---|
| 课代表徽章 | 每场战斗第一次击破命数时，抽 2 |
| 厚笔记本 | 喷射命数 +1，但初始手牌 -1 |
| 社团申请表 | 每个伙伴使最大忍耐 +5 |
| 粉笔盒 | 0 费攻击造成伤害后追加 5% 追击 |
| 毕业证书 | Boss 战中第一次喷发不消耗命数 |

## 6.7 教室 Boss：夜校讲师

### Boss 特点

- 共鸣上限低，但命数很多。
- 每次消耗命数都会改变教学模式。
- 后期会把玩家手牌改成考试状态牌。

### 反制方式

- 多段伤害和追击流非常有效。
- 需要过牌清理状态牌。
- 命数流可用 Boss 当作资源发动机。

# 7. 健身房楼层：高上限、高防御、单命强敌

## 7.1 主题定位

健身房层强调高耐久敌人、强防守、蓄力、破防和长线战斗。

### 视觉关键词

健身器材、镜墙、沙袋、训练垫、红蓝灯光、金属哑铃、汗水高光。

### 玩法关键词

【高共鸣上限】、【单命】、【防守】、【破防】、【蓄力】、【粘液增伤】。

## 7.2 楼层规则

```text

奖励卡池也混合两个主题。
精英数量提高。
```

# 16. 核心套路与楼层适配

## 16.1 连击流：【连续抽插】

### 核心规则

```text
带有【连续抽插】字段的卡，会根据角色的“连续抽插次数加成”增加段数。
每一段视为一次独立伤害，可触发弹珠、粘液、追击、命中状态。
```

### 公式

```text
最终段数 = 卡牌基础段数 + 连续抽插次数加成
每段伤害 = 基础伤害 × 段伤倍率
总伤害 = 每段伤害 × 最终段数
```

### 楼层适配

| 楼层 | 适配度 | 原因 |
|---|---:|---|
| 大学教室 | S | 多命数敌人适合多段清命 |
| 酒吧 | A | 酒意可强化连击 |
| 舞会 | A | 可破假意和闪避 |
| 健身房 | B | 容易被硬化克制，需要破防 |
| 监狱 | A | 连续鞭影可叠束缚 |
| 电车 | C | 多段直接攻击容易吃反伤 |

### 核心卡

| 卡牌 | 效果 |
|---|---|
| 快速推进 | 【连续抽插】2 次 |
| 酒后连击 | 【连续抽插】2 次，酒意加段 |
| 课间突袭 | 击破命数追加段数 |
| 连续鞭影 | 【连续抽插】3 次，每段施加束缚 |
| 节奏支配 | 每回合第一张连击牌触发两次 |
| 连段记忆 | 每打出 3 张攻击牌，连续抽插次数 +1 |

### 核心遗物

| 遗物 | 效果 |
|---|---|
| 节拍腰链 | 每场战斗开始连续抽插次数 +1 |
| 计数珠串 | 每造成 10 次命中，本场连续次数 +1 |
| 舞步计时器 | 连击牌每多一段，获得 1 魅力 |
| 破频铃铛 | 连击最后一段额外造成 50% 伤害 |

## 16.2 追击流：【阳具弹珠】

### 核心规则

```text
玩家每拥有 1 个阳具弹珠，每次施加伤害后额外造成 1 次追击。
每次追击伤害 = 原伤害的 10%。
多个弹珠可以叠加。
追击也算命中，但默认不再次触发弹珠，除非有特殊遗物。
```

### 公式

```text
追击次数 = 阳具弹珠数量
单次追击伤害 = 原始伤害 × 10%
追击总伤害 = 原始伤害 × 10% × 弹珠数量
最终伤害 = 原始伤害 + 追击总伤害
```

### 特殊规则

```text
默认：追击不触发追击。
拥有【多核共振】：追击有 20% 概率再次追击。
拥有【稳定改造】：每个弹珠追击倍率 +2%。
```

### 楼层适配

| 楼层 | 适配度 | 原因 |
|---|---:|---|
| 大学教室 | S | 多命数敌人怕追击 |
| 诊疗室 | S | 弹珠改造资源多 |
| 夜市 | A | 可买临时弹珠 |
| 酒吧 | A | 随机强化触发追击收益 |
| 健身房 | B | 需要粘液或破防提升小伤害 |
| 电车 | C | 追击可能触发反伤，需特殊卡规避 |

### 核心卡

| 卡牌 | 效果 |
|---|---|
| 珠核植入 | 本场获得 1 弹珠 |
| 珠核摊位 | 夜市临时获得 1 弹珠 |
| 精密校准 | 下 3 次追击伤害翻倍 |
| 多核共振 | 追击有概率追加追击 |
| 弹珠齐鸣 | 根据弹珠数量造成多段伤害 |
| 珠核回收 | 移除 1 弹珠，获得大量能量和冷静 |

### 核心遗物

| 遗物 | 效果 |
|---|---|
| 第一颗弹珠 | 战斗开始获得 1 弹珠 |
| 旋转珠核 | 每 5 次追击，随机敌人获得 1 粘液 |
| 稳定珠槽 | 弹珠追击不触发反伤 |
| 珠核放大镜 | 追击可以暴击 |
| 共振珠串 | 每个伙伴使弹珠追击倍率 +1% |

## 16.3 粘液流：Buff 增伤与持续压迫

### 核心规则

```text
粘液：附着在敌人身上的增伤状态。
每层粘液使目标受到的每次伤害 +1 固定值或 +1%。
多段攻击和追击可以多次吃到粘液收益。
```

### 推荐公式

```text
最终伤害 = (基础伤害 + 粘液层数) × (1 + 粘液层数 × 1%)
```

### 层数限制

```text
普通敌人：最高 20 层
精英：最高 30 层
Boss：最高 50 层
```

### 楼层适配

| 大学教室 | B | 敌人命数多但单条低，可能来不及叠 |
| 舞会 | B | 被闪避影响，需要控制配合 |

# 17. 群战伙伴流：招募、协战与合击

## 17.1 核心规则

玩家在部分奇遇中可以招募伙伴。伙伴不是完整第二角色，而是“协战单位”。

```text
伙伴拥有：
- 协战技能
- 被动效果
- 冷却回合
- 亲密等级
- 退场风险
```

## 17.2 伙伴上限

```text
默认最多 1 名伙伴。
遗物或事件可提升至 2 名。
剧院层允许临时第 3 名舞台伙伴。
```

## 17.3 伙伴行动规则

```text
每回合开始，伙伴冷却 -1。
冷却为 0 时，玩家可点击伙伴技能发动。
部分卡牌可立即触发伙伴协击。
伙伴不会占用玩家手牌，但会占用伙伴 UI 槽。
```


```text
图书馆 → 舞会 → 剧院 → Boss
```

特点：依靠抽牌、复制、魅力、终曲形成爆发。

# 22. 平衡规则

## 22.1 单层不要只支持一种套路

每层建议：

```text
1 个主推套路
2 个可用套路
1 个被克制套路
1 个隐藏高收益套路
```

例如电车层：

```text
主推：反伤流
可用：防守流、粘液流
被克制：连击流
隐藏高收益：稳定珠槽追击流
```

## 22.2 克制不等于不能玩

弱势流派应该可以通过遗物或关键卡解决：

```text
连击流怕电车反伤
→ 遗物【稳定珠槽】：追击不触发反伤
→ 卡牌【低调推进】：直接伤害不触发反伤
```

## 22.3 Boss 要检验本层机制

Boss 不只是数值强，而是要考察玩家是否理解楼层规则：

- 酒吧 Boss 考察酒意管理。
- 舞会 Boss 考察破假意。
- 教室 Boss 考察多命数处理。
- 健身房 Boss 考察破防和长线输出。
- 监狱 Boss 考察束缚牌处理。
- 电车 Boss 考察直接攻击风险控制。

# 23. 制作优先级

## 第一批：6 个强主题层

1. 酒吧
2. 舞会

4. 健身房

# 24. 最终体验目标

完成这套楼层主题后，玩家每次爬塔都会形成不同体验：

```text
酒吧：随机、爆发、酒意失控
舞会：魅力、假动作、姿态博弈
教室：低上限、多命数、快速清场
健身房：高血高防、破防、长线战
监狱：束缚、规则限制、惩戒反制
电车：反伤、拥挤、间接输出
温泉：回复、净化、忍耐管理
图书馆：过牌、复制、卡组污染
剧院：聚光、热度、终曲、伙伴合击
夜市：道具、金币、风险交易
诊疗室：改造、弹珠、命数成长
地下俱乐部：双主题混合高难挑战
```

最终目标：

```text
不是只有“敌人换皮”，
而是每一层都能改变玩家的出牌节奏、构筑目标、风险判断和奖励选择。
```
