# 1. 项目整体美术目标

## 1.1 核心方向

游戏核心玩法完全参考《杀戮尖塔》的爬塔卡牌结构，但视觉主题替换为：

- 舞台：**性爱城堡 / 亲密城堡**
- 战斗本质：**张力对抗 / 共鸣累积 / 忍耐博弈**
- 战斗结果：
  - 玩家“忍耐值”满则进入喷发结算
  - 对手“高潮值”满则进入失衡结算
- 整体气质：
  - **暧昧、诱惑、轻幻想、哥特、丝绒、烛光、舞台化**
  - **非写实、非猎奇、非重口**
  - **插画化 2D 风格，适合卡牌、UI、角色序列帧统一**

## 1.2 风格关键词

- 哥特城堡
- 烛台、纱幔、花窗、红丝绒
- 紫红 / 暗金 / 月白 / 黑玫瑰色
- 戏剧舞台感
- 轻度成人氛围，但画面尽量不直白
- 图标化表达强，少文字，多视觉信息

## 1.3 画风建议

推荐统一为：

- **2D 手绘插画风**
- 明暗对比明确
- 角色轮廓清晰
- 特效偏半透明丝带 / 心形粒子 / 光雾 / 音波 / 烟纱
- UI 偏“古堡纸牌 + 金属雕框 + 宝石嵌件”

# 2. 技术规格总则

## 2.1 项目分辨率基准

- 目标平台：PC / 平板优先，后续可适配移动端
- 逻辑基准分辨率：**1920 × 1080**
- 设计稿基准：**1920 × 1080**
- 高清母版建议：**3840 × 2160**

## 2.2 导出规范

### 场景类
- 背景大图：PNG，3840 × 2160
- 前景装饰：PNG，透明底，单独导出
- 地面平台：PNG，透明底，2048 × 768 或 3072 × 1024
- 房间 UI 配图：PNG，2048 高度内

### UI 类
- 所有 UI 元素透明底 PNG
- 按钮 / 面板尽量按**最小可复用单元**拆分
- 需要 9-slice 的框体单独导出
- 统一保留 20~40 像素安全边距

### 卡牌类
- 完整卡牌展示图：1024 × 1536
- 卡牌插画区原图：1024 × 1024
- 卡框拆件：512 / 1024 两档
- 图标母版：256 × 256

## 2.3 图层层级建议

场景统一按以下图层输出：

1. Sky / 背景远景
2. 建筑主体中景
3. 室内装饰中前景
4. 地面平台
5. 前景遮挡物
6. 可选动态粒子层（单独）

## 2.4 透视与构图统一

- 战斗房间以**横向舞台构图**为主
- 玩家位于**左下偏中**
- 敌人位于**右上偏中**
- 地面为一条可读性清晰的平台
- 背景层次清楚，不要抢角色

# 3. 关卡章节美术设定

为了对标《杀戮尖塔》的三幕结构，建议将城堡分为三大章节，每章有统一主色与建筑语言。

## 3.1 第一章：绯雾前厅（Act 1）

### 视觉定位
- 玩家刚进入城堡的区域
- 氛围偏“诱惑、试探、轻危险”
- 场景较开阔，敌人以普通守卫、侍者、初阶魅影为主

### 主色
- 酒红
- 暗紫
- 烛金
- 雾灰

### 常见元素
- 高窗
- 烛台
- 地毯
- 柱廊
- 玫瑰花瓣
- 铁艺门

### 适用房间
- 普通战斗
- 篝火 / 休息室
- 商店
- 小事件
- 小宝箱

## 3.2 第二章：月纱回廊（Act 2）

### 视觉定位
- 城堡中部，氛围更华丽更暧昧
- 纱幔、镜面、浴池、乐厅、私密会客室增多
- 敌人机制更复杂，更多 Debuff、控制、节奏扰乱

### 主色
- 紫蓝
- 玫红
- 月白
- 银灰

### 常见元素
- 镜厅
- 垂纱
- 月光窗
- 香薰炉
- 室内水景
- 羽毛装饰

### 适用房间
- 精英战斗
- 事件房
- 大宝箱
- 强化商人房
- 剧情节点

## 3.3 第三章：禁欲王座区（Act 3）

### 视觉定位
- 最深处区域，威压、冷艳、仪式感更强
- 敌人强度高，Boss 房更肃穆
- 视觉上减少杂物，强调权力与终局

### 主色
- 黑红
- 暗金
- 冷白
- 深蓝黑

### 常见元素
- 王座
- 巨型花窗
- 锁链装饰
- 仪式圆阵
- 金属高台
- 圣坛

### 适用房间
- Boss 房
- 高阶事件
- 最终休息房
- 最终宝箱

# 4. 不同房间场景美术说明

本章按“房间类型”编写，方便你批量生成资源。每种房间都可以分别做 3 套章内变体。

---

## 4.1 普通战斗房（Battle Room）

### 功能定位
最常见战斗场景，对应普通怪。

### 构图规则
- 玩家站位区域：左侧 30% 宽度范围
- 敌人站位区域：右侧 30% 宽度范围
- 中间留出卡牌视觉焦点
- 地面必须是一条**稳定、平直、可读**的横向平台

### 画面结构
- 背景：柱廊 / 窗户 / 墙饰 / 烛光
- 中景：挂画、纱幔、立柱、屏风
- 前景：花瓣、灯架、轻薄帘角
- 地面：红地毯 / 石砖 / 木地板

### 重点要求
- 不可过于花哨，避免遮挡敌人意图图标
- 中央区域不放高对比装饰
- 地面和背景对比需明确，角色轮廓清楚

### 推荐尺寸拆分
- BG_Far_Battle_A1：3840 × 2160
- BG_Mid_Battle_A1：3840 × 2160
- Ground_Battle_A1：3072 × 1024
- FG_Deco_Battle_A1：透明 PNG

---

## 4.2 精英战斗房（Elite Room）

### 功能定位
更危险、更有压迫感，对应精英怪。

### 构图规则
- 玩家与敌人站位保持与普通战斗一致
- 背景需要比普通房更“完整”和“庄重”
- 加入视觉焦点：巨大雕像 / 镜子 / 祭台

### 画面语言
- 光线更集中
- 地面纹样更复杂
- 场景中可以加入“警戒符文 / 华丽地毯 / 高背座椅”

### 视觉关键词
- 华丽
- 危险
- 精致
- 戏剧张力强

---

## 4.3 Boss 房（Boss Chamber）

### 功能定位
最终战斗空间，必须体现仪式感和压迫感。

### 构图规则
- 敌方位置可略高于普通敌人，形成居高临下感
- 玩家左侧仍保持标准站位，方便统一动画
- 背景中央建议有“王座 / 巨型花窗 / 巨门 / 圆阵”之一作为核心焦点

### 氛围要求
- 杂物少
- 主体强
- 对比更集中
- 环境更大气

### 建议变体
1. 王座大厅
2. 花窗圣堂
3. 锁链圆坛
4. 黑玫瑰王室寝宫

---

## 4.4 休息房（Campfire / Rest Room）

### 功能定位
对应《杀戮尖塔》的篝火房。

### 主题替换建议
可改为：
- **静息室**
- **沐香室**
- **纱灯休憩间**

### 构图规则
- 中景必须有一个“交互焦点”
  - 如香炉、软榻、池边坐席、烛光屏风
- 玩家立绘可居中偏左，环境更放松

### 氛围关键词
- 温暖
- 放松
- 隐私感
- 柔光

### 视觉元素
- 软垫
- 帷幕
- 茶具 / 香炉
- 温泉或洗浴元素（抽象化）
- 柔和烛火

---

## 4.5 商店房（Merchant Room）

### 功能定位
用于购买卡牌、消耗品、遗物。

### 构图规则
- 商人位于右侧或中央偏右
- 左侧留出玩家视角停靠区
- 货架、柜台、悬挂物组成视觉包围

### 视觉元素
- 小型陈列柜
- 宝石、香瓶、卡盒、古书
- 羽毛笔、卷轴、烛台
- 柔和暖光

### 商人房气质
- 神秘
- 安全
- 古怪
- 收纳丰富但不混乱

---

## 4.6 宝箱房（Treasure Room）

### 功能定位
用于展示稀有奖励与大宝箱。

### 构图规则
- 中央必须有一个绝对焦点：宝箱 / 奖励台
- 背景可简化
- 地面高光更明显

### 视觉元素
- 宝箱
- 金属锁扣
- 花纹底座
- 聚光
- 漂浮粒子

### 章节变体建议
- 第一章：金属镶边木宝箱
- 第二章：月纱珍藏箱
- 第三章：王室印记秘箱

---

## 4.7 事件房（Event Room）

### 功能定位
用于文本事件、选择分支、特殊遭遇。

### 构图规则
- 中央要有事件主体
- 左右空间留给事件 UI
- 事件主体不能太碎，必须一眼能读懂

### 常见事件主体
- 魔镜
- 诡异契约桌
- 迷香喷泉
- 密室书柜
- 神秘门扉
- 失衡雕像

### 视觉关键词
- 神秘
- 戏剧化
- 选择感
- 轻叙事

---

## 4.8 地图节点房（Map Node Visual）

### 功能定位
对应地图总览中的节点图标与路径视觉。

### 需求说明
- 地图本身不需要完整写实场景
- 更像一张“城堡内部路线图 / 挂画式航线图”

### 地图背景建议
- 羊皮纸 / 烫金纹理
- 城堡章节轮廓剪影
- 路径节点用图标表示
- 路径线可用细金线 / 紫色丝带线 / 发光路径

# 5. 场景拆件清单与导出规则

## 5.1 每章最低资源包

每一章至少准备：

1. 普通战斗房 × 3
2. 精英战斗房 × 2
3. Boss 房 × 1
4. 休息房 × 1
5. 商店房 × 1
6. 宝箱房 × 1
7. 事件房 × 2
8. 地图背景 × 1

## 5.2 每个房间最少拆件

- 远景背景 1 张
- 中景主体 1 张
- 地面 1 张
- 前景遮挡 1~3 张
- 特殊焦点物件 1~2 张
- 粒子 / 氛围可选层 1 张

## 5.3 地面资源规则

地面单独拆出，方便不同场景复用。

### 地面要求
- 长条横向
- 中心平稳
- 两端渐弱
- 不要极端透视
- 角色脚底接地清晰

### 推荐类型
- 红毯石砖
- 木地板 + 金纹
- 大理石圆环
- 丝绒地毯平台

# 6. UI 美术说明与拆分规则

本项目 UI 布局对标《杀戮尖塔》，但所有素材重新原创。

## 6.1 UI 总体风格

### 风格关键词
- 古堡纸牌感
- 金属雕框
- 哥特纹样
- 宝石装饰
- 羊皮纸 / 天鹅绒 / 鎏金

### 设计原则
- **多图标，少文字**
- 大功能块位置与《杀戮尖塔》一致
- 框体细节丰富，但不影响信息读取
- Buff、意图、费用、数值要一眼辨认

## 6.2 战斗主界面 UI 资源说明

### 1）玩家状态区
位置：左下偏左，角色脚边附近  
内容：
- 玩家头像小框
- 忍耐值条（替代 HP）
- 冷静 / 护持值显示
- Buff 图标列

### 美术要求
- 忍耐值条：建议竖向或半弧形，色彩为蓝紫到红的渐变
- 玩家信息底框：古铜 / 暗金雕边
- Buff 图标小而醒目

### 2）敌人状态区
位置：敌人脚边或模型下方  
内容：
- 共鸣值条（替代敌方 HP）
- 防御值 / 护持
- Buff / Debuff 图标

### 3）敌人意图图标
位置：敌人头顶正上方  
内容：
- 下一回合动作图标
- 数值显示
- 多段攻击 / 施加状态 / 强化等标识

### 美术要求
- 图标外框统一圆形或盾形徽章
- 数值显示区域独立，不被图标遮挡
- 不同意图颜色区分明显

### 4）手牌区
位置：底部中央  
布局：扇形排开，对标《杀戮尖塔》

### 美术要求
- 卡牌在未选中时略向外张开
- Hover 时上移并放大
- 可打出卡牌高亮边框
- 不足能量时整体压暗

### 5）能量区
位置：左下角 / 手牌左侧  
建议表现：
- 使用“欲能水晶 / 心焰宝石 / 月辉水晶”作为能量球
- 数值显示清晰

### 6）抽牌堆 / 弃牌堆 / 消耗区
位置：右下角区域  
建议排列：
- DrawPile
- DiscardPile
- ExhaustPile

### 美术说明
- 图标化牌堆
- 点击弹出详细列表
- 每个牌堆有数量数字徽章

### 7）回合结束按钮
位置：右下角边缘  
美术要求：
- 大号按钮
- 明确高亮
- 采用宝石嵌边 / 鎏金按键
- 状态区分：可点击 / 不可点击 / Hover / 按下

# 7. 卡牌美术总规则

## 7.1 卡牌结构

每张卡牌建议拆为：

1. 外框 Frame
2. 顶部标题条
3. 费用宝石位
4. 立绘区域
5. 类型横条
6. 说明文字区
7. 稀有度角标
8. 升级标识

## 7.2 类型分类

- 攻击牌（Action）
- 技能牌（Skill）
- 强化牌（Power）
- 状态牌（Status）
- 诅咒牌（Curse）
- 无色牌（Colorless）

## 7.3 稀有度颜色建议

- 普通：灰铜 / 暗银
- 非凡：蓝紫
- 稀有：金红
- 特殊：黑金 / 彩虹珠光

## 7.4 卡牌插画统一要求

### 构图
- 单一焦点
- 中近景优先
- 动作明确
- 背景简化
- 方便缩略图识别

### 表现内容
- 以“情绪压迫、节奏控制、诱导、冷静、爆发、契约、护持”等抽象玩法为核心
- 尽量避免直白器官展示
- 用姿态、手势、丝带、阴影、心形粒子、锁链、光带、雾气来表达动作意图

### 特效语言
- 攻击：冲击线、红色弧光、裂纹、压力波
- 防御：护罩、玻璃光、缎带包裹、盾面
- 强化：符文、光环、浮动纹样
- 控制：锁链、禁锢环、紫雾、黑丝带
