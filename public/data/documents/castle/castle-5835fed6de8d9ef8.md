# 2. 新增核心资源：敏感度

## 2.1 敏感度定位

【敏感度】是敌方身上的一类全局易伤状态，主要用于放大后续卡牌收益。

它不是直接伤害，而是让敌人更容易累积【高潮值 / 共鸣值】。

```text
敏感度越高：
→ 插入牌增加的共鸣值越多
→ 连击牌每段收益越高
→ 追击伤害更有效
→ 粘液、挑逗、束缚等状态更容易转化成爆发
```

## 2.2 敏感度规则

```text
敏感度：敌方 Debuff。
每 1 层敏感度，使该敌人受到的共鸣累积 +2%。
最高默认 50 层。
Boss 最高 100 层。
```

## 2.3 推荐公式

```text
最终共鸣增加 = 基础共鸣 × (1 + 敏感度层数 × 2%)
```

示例：

```text
基础共鸣 = 10
敌方敏感度 = 8 层
最终共鸣 = 10 × (1 + 8 × 2%) = 11.6
向下取整或保留小数均可
```

## 2.4 敏感度衰减

建议做成可控资源，避免无限滚雪球。

```text
普通敌人：每回合结束敏感度 -1
精英敌人：每回合结束敏感度 -2
Boss：每回合结束敏感度 -3
```

可通过遗物或强化牌减少衰减。

# 3. 新增流派一：【束缚】控制辅助流

## 3.1 流派定位

【束缚】是强控制辅助流派，核心作用不是直接输出，而是：

- 限制敌方攻击
- 增加敌方敏感度
- 给连击、长度、粗度、SM、粘液等流派创造输出窗口
- 对抗高攻击敌人和 Boss 蓄力技

## 3.2 束缚基础规则

```text
束缚：敌方 Debuff。
被束缚的回合，敌人不能发动【攻击类行动】。
敌人仍可发动其他行动：防御、强化、Debuff、召唤、清除状态。
每回合结束，束缚层数 -1。
```

## 3.3 敌方行动类型限制

| 敌人行动 | 是否被束缚禁止 | 说明 |
|---|---:|---|
| 单体攻击 | 是 | 不可发动，改为防御或待机 |
| 多段攻击 | 是 | 完全禁止 |
| 全体攻击 | 是 | 完全禁止 |
| 蓄力终结技 | 部分 | 若是攻击终结技则延迟 1 回合 |
| 防御 | 否 | 仍可加护盾 |
| 强化 | 否 | 仍可叠 Buff |
| Debuff | 否 | 仍可施加状态 |
| 召唤 | 否 | 仍可召唤单位 |
| 清除负面 | 否 | 仍可解除束缚或减少层数 |

## 3.4 束缚与敏感度联动

```text
当敌人处于束缚状态时：
插入牌施加的敏感度 +50%。
SM 牌施加的敏感度 +100%。
粘液牌施加的粘液 +1。
```

## 3.5 束缚抗性

为了避免控死 Boss，需要加入抗性。

```text
普通敌人：束缚全额生效。
精英敌人：束缚持续时间 -1，最低 1。
Boss：每次被束缚后获得 1 层【束缚抗性】。
每层束缚抗性使下次束缚持续 -1。
```

## 3.6 束缚流核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 流派定位 |
|---|---:|---:|---|---|
| 锁腕牵制 | 技能 | 1 | 施加 1 束缚，2 敏感度 | 基础控制 |
| 交叉锁链 | 技能 | 2 | 施加 2 束缚；若目标已有束缚，抽 1 | 强控制 |
| 低位固定 | 技能 | 1 | 施加 1 束缚，并使下张插入牌敏感度 +50% | 长度/粗度辅助 |
| 丝带缠身 | 技能 | 1 | 对全体施加 1 束缚，但自身忍耐 +2 | 群控 |
| 束缚破绽 | 攻击 | 1 | 对束缚目标造成伤害并施加 3 敏感度 | 控制转输出 |
| 越挣越紧 | 强化 | 1 | 敌人尝试攻击但被束缚阻止时，获得 2 敏感度 | 控制收益 |
| 禁止反抗 | 技能 | 2 | 目标下回合不能攻击，且不能清除负面 | Boss 对策 |
| 锁链收束 | 攻击 | 2 | 消耗目标全部束缚，每层造成一次小伤害 | 终结 |
| 合意束缚 | 强化 | 2 | 每场战斗第一次束缚敌人时，额外 +1 层 | 核心 Power |
| 全场封锁 | 技能 | 3 | 对全体施加 1 束缚和 3 敏感度 | 稀有群控 |

## 3.7 束缚流遗物

| 遗物 | 效果 |
|---|---|
| 黑丝缎带 | 每场战斗第一次施加束缚时，额外 +1 层 |
| 银锁扣 | 束缚目标受到的敏感度增加 +25% |
| 合意契约环 | 束缚不会被普通敌人清除 |
| 缠绕玫瑰 | 敌人束缚结束时，获得 2 挑逗 |
| 禁锢钟摆 | 每 3 回合，对随机敌人施加 1 束缚 |
| 软锁链 | 施加束缚时，自身获得 3 冷静 |

## 3.8 束缚流弱点

- 对清状态敌人效果变差。
- 对高抗性 Boss 不能无限控制。
- 输出较慢，需要和其他流派组合。
- 遇到以 Buff、防御、召唤为主的敌人时，束缚收益降低。

# 4. 新增流派二：【阴茎长度】敏感度放大流

## 4.1 流派定位

【阴茎长度】是偏稳定成长的输出辅助属性。

设计目的：

```text
越长 → 插入牌施加的敏感度越多
越长 → 更适合打持续叠层和爆发前铺垫
越长 → 不明显增加玩家喷射风险
```

与【粗度】相比，长度更偏“稳定增益”，粗度更偏“高风险爆发”。

## 4.2 长度属性规则

```text
默认长度等级 = 0
每 1 点长度等级：
插入牌施加的敏感度 +1
插入牌对束缚目标额外 +1 敏感度
最高建议：10 级
```

## 4.3 长度公式

```text
插入牌最终敏感度 = 基础敏感度 + 长度等级 + 束缚加成 + 卡牌加成
```

示例：

```text
卡牌基础敏感度 = 2
长度等级 = 4
目标被束缚 = +1
最终敏感度 = 2 + 4 + 1 = 7
```

## 4.4 长度流特点

| 维度 | 表现 |
|---|---|
| 输出节奏 | 中速成长 |
| 主要收益 | 敏感度叠加 |
| 风险 | 较低 |
| 适合卡牌 | 插入牌、控制牌、敏感度引爆牌 |
| 适合楼层 | 舞会、健身房、监狱、诊疗室 |
| 克制 | 高净化敌人、敏感度免疫敌人 |

## 4.5 长度流核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 定位 |
|---|---:|---:|---|---|
| 长度改造 | 技能 | 2 | 本场战斗长度等级 +2 | 核心成长 |
| 逐寸推进 | 攻击 | 1 | 造成伤害，施加 1 敏感度；长度每 2 级额外 +1 | 基础输出 |
| 深层触达 | 攻击 | 2 | 施加大量敏感度，不额外增加喷射值 | 稳定铺垫 |
| 拉长节奏 | 技能 | 1 | 本回合所有插入牌施加敏感度 +长度等级的一半 | 爆发准备 |
| 长距压迫 | 攻击 | 1 | 若目标被束缚，额外施加长度等级的敏感度 | 束缚联动 |
| 尺度掌控 | 强化 | 2 | 每回合第一张插入牌额外施加 2 敏感度 | 核心 Power |
| 延伸优势 | 技能 | 0 | 若长度≥5，抽 1；若长度≥8，获得 1 能量 | 过牌收益 |
| 极限深入 | 攻击 | 3 | 根据长度等级造成伤害并施加等量敏感度 | 稀有终结 |

## 4.6 长度流遗物

| 遗物 | 效果 |
|---|---|
| 测量丝带 | 战斗开始长度 +1 |
| 延展符文 | 长度提供的敏感度加成 +25% |
| 深层指南针 | 对 Boss 施加敏感度时，长度加成不衰减 |
| 稳定轴心 | 长度改造不增加任何负面状态 |
| 长距节拍器 | 每打出 3 张插入牌，长度 +1，本场有效 |

## 4.7 长度流弱点

- 前期伤害不高，需要先叠敏感度。
- 怕敏感度清除。
- 卡组需要一定过牌能力，否则容易成长慢。

# 5. 新增流派三：【阴茎粗度】高风险爆发流

## 5.1 流派定位

【阴茎粗度】是高风险高收益流派。

设计目的：

```text
越粗 → 插入牌施加的敏感度越多
越粗 → 插入牌造成的共鸣越高
但越粗 → 自身喷射值增加越多
```

该流派适合玩家在临界边缘打爆发，也能和【喷射命数】、【冷静防守】形成组合。

## 5.2 粗度属性规则

```text
默认粗度等级 = 0
每 1 点粗度等级：
插入牌施加敏感度 +1
插入牌造成共鸣 +3%
插入牌额外增加自身喷射值 +1
最高建议：8 级
```

## 5.3 粗度公式

```text
最终共鸣 = 基础共鸣 × (1 + 粗度等级 × 3%)
最终敏感度 = 基础敏感度 + 粗度等级
自身喷射值增加 = 卡牌基础喷射增加 + 粗度等级
```

示例：

```text
基础共鸣 = 20
基础敏感度 = 2
基础喷射增加 = 3
粗度等级 = 5
最终共鸣 = 20 × 1.15 = 23
最终敏感度 = 2 + 5 = 7
自身喷射增加 = 3 + 5 = 8
```

## 5.4 粗度流特点

| 维度 | 表现 |
|---|---|
| 输出节奏 | 中后期爆发 |
| 主要收益 | 共鸣 + 敏感度双加成 |
| 风险 | 高，喷射值上涨快 |
| 适合卡牌 | 插入牌、喷射命数牌、冷静牌 |
| 适合楼层 | 健身房、诊疗室、温泉、教室 |
| 克制 | 高压敌人、反伤敌人、降冷静敌人 |

## 5.5 粗度流核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 定位 |
|---|---:|---:|---|---|
| 粗度改造 | 技能 | 2 | 本场战斗粗度 +2，喷射值 +3 | 核心成长 |
| 厚重推进 | 攻击 | 1 | 造成伤害，粗度越高敏感度越高，自身喷射值增加 | 基础输出 |
| 压迫扩张 | 攻击 | 2 | 造成高共鸣，施加粗度等级敏感度 | 爆发输出 |
| 危险膨胀 | 强化 | 1 | 粗度 +1；每回合开始喷射值 +1 | 风险成长 |
| 临界压制 | 攻击 | 2 | 若自身喷射值超过 70%，伤害 +50% | 临界收益 |
| 冷却间隙 | 技能 | 1 | 降低喷射值；若粗度≥4，抽 1 | 风险管理 |
| 厚度掌控 | 强化 | 2 | 粗度带来的喷射值增加 -50% | 核心稳定 |
| 超限扩张 | 攻击 | 3 | 粗度越高伤害越高；使用后立即检查喷射 | 稀有终结 |

## 5.6 粗度流遗物

| 遗物 | 效果 |
|---|---|
| 扩张环 | 战斗开始粗度 +1 |
| 稳定润滑剂 | 粗度导致的喷射值增加 -1，最低 0 |
| 厚重核心 | 粗度上限 +2 |
| 临界保险 | 每场战斗第一次因粗度导致喷射时，不消耗命数 |
| 压迫宝石 | 粗度每 2 级，插入牌额外造成 5% 共鸣 |

## 5.7 粗度流弱点

- 容易自爆，需要冷静和喷射命数支持。
- 电车反伤层非常危险。
- 遇到减少玩家冷静的敌人时，风险更高。

# 6. 新增流派四：【SM 鞭打】多段惩戒流

## 6.1 流派定位

【鞭打】是 SM 系列中的多段攻击流，和【连续抽插】类似，但它更偏：

- 多段小伤害
- 叠加惩戒
- 叠加敏感度
- 与束缚强联动

## 6.2 鞭打关键词

```text
鞭打：攻击标签。
鞭打牌通常为多段伤害。
每段鞭打有概率施加 1 敏感度或 1 惩戒印记。
目标被束缚时，鞭打效果翻倍。
```

## 6.3 惩戒印记

```text
惩戒印记：敌方 Debuff。
敌人下次发动攻击时，先受到印记层数 × 固定值的共鸣。
触发后清除一半层数。
```

公式：

```text
惩戒伤害 = 惩戒层数 × 3 + 玩家力量修正
```

## 6.4 鞭打流核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 定位 |
|---|---:|---:|---|---|
| 皮鞭轻击 | 攻击 | 1 | 造成伤害，施加 1 惩戒 | 基础卡 |
| 连续鞭影 | 攻击 | 2 | 连续 3 段鞭打，每段 30% 伤害 | 多段核心 |
| 鞭痕标记 | 技能 | 1 | 施加 3 惩戒和 2 敏感度 | 状态铺垫 |
| 交叉鞭击 | 攻击 | 1 | 若目标被束缚，额外攻击一次 | 束缚联动 |
| 训诫节奏 | 强化 | 1 | 每回合第一张鞭打牌多 1 段 | 核心 Power |
| 回响鞭声 | 技能 | 1 | 本回合鞭打造成伤害时，给随机敌人 1 惩戒 | 群体扩散 |
| 惩戒爆裂 | 攻击 | 2 | 消耗所有惩戒，造成总层数相关伤害 | 爆发 |
| 终局鞭笞 | 攻击 | 3 | 对束缚目标造成大量多段伤害 | 稀有终结 |

## 6.5 鞭打流遗物

| 遗物 | 效果 |
|---|---|
| 红纹皮鞭 | 鞭打牌额外施加 1 惩戒 |
| 银铃鞭柄 | 每打出 2 张鞭打牌，抽 1 |
| 惩戒刻印 | 惩戒触发时额外施加 1 敏感度 |
| 柔韧鞭梢 | 鞭打牌对束缚目标伤害 +25% |
| 回声刑架 | 鞭打最后一段对全体敌人造成 20% 溅射 |

# 7. 新增流派五：【SM 蹂躏】破防压制流

## 7.1 流派定位

【蹂躏】不是多段，而是重压、破防、削弱和压制。

适合打：

- 高护甲敌人
- 健身房高上限敌人
- Boss 单体
- 会反复防御的敌人

## 7.2 蹂躏关键词

```text
蹂躏：重压攻击标签。
通常伤害较高，费用较高。
若目标有束缚、敏感度、粘液，则获得额外破防效果。
```

## 7.3 破防规则

```text
破防：移除目标部分护持 / 硬化 / 防御增益。
破防后，目标本回合受到的敏感度增加 +25%。
```

## 7.4 蹂躏流核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 定位 |
|---|---:|---:|---|---|
| 重压按制 | 攻击 | 2 | 造成伤害并破防 | 基础破防 |
| 践踏压迫 | 攻击 | 2 | 对有粘液目标造成额外伤害 | 粘液联动 |
| 墙边压制 | 技能 | 1 | 施加 1 束缚和 1 易伤 | 控制准备 |
| 粗暴推进 | 攻击 | 2 | 粗度越高，破防越强 | 粗度联动 |

## 18.5 伤害 / 共鸣计算伪代码

```csharp
public int CalculateResonance(CardData card, Unit target, PlayerBuildStats stats)
{
    float value = card.baseResonance;

    if (card.isInsertionCard)
    {
        value *= 1f + stats.girthLevel * stats.girthResonanceBonus;
    }

    int sensitivity = target.GetStatus(StatusType.Sensitivity);
    value *= 1f + sensitivity * stats.sensitivityMultiplier;

    int slime = target.GetStatus(StatusType.Slime);
    value += slime;
    value *= 1f + slime * 0.01f;

    if (target.poseState == PoseState.Lying && card.isInsertionCard)
        value *= 1.5f;

    if (target.HasStatus(StatusType.Bind) && card.isSMCard)
        value *= 1.25f;

    return Mathf.RoundToInt(value);
}
```

## 18.6 敏感度计算伪代码

```csharp
public int CalculateSensitivityAdd(CardData card, Unit target, PlayerBuildStats stats)
{
    int value = card.baseSensitivity;

    if (card.isInsertionCard)
    {
        value += stats.lengthLevel;
        value += stats.girthLevel;
    }

    if (target.HasStatus(StatusType.Bind))
        value = Mathf.RoundToInt(value * 1.5f);

    if (target.poseState == PoseState.Lying && card.isInsertionCard)
        value = Mathf.RoundToInt(value * 1.5f);

    return value;
}
```

## 18.7 喷射值增加伪代码

public int CalculateEruptionAdd(CardData card, PlayerBuildStats stats)
{
    int value = card.baseEruptionAdd;

    if (card.isInsertionCard)
        value += stats.girthLevel;

    if (HasRelic("稳定润滑剂"))
        value = Mathf.Max(0, value - 1);

    if (HasPower("厚度掌控"))
        value = Mathf.RoundToInt(value * 0.5f);

    return value;
}

# 21. 总结

本次扩展后，卡牌流派会从原来的几个大方向，扩展成更完整的成人向卡牌构筑体系：

```text
控制辅助：束缚、支配、姿势锁定
成长属性：长度、粗度、弹珠、喷射命数
状态叠层：敏感度、粘液、蜡滴、羞耻
SM 体系：鞭打、蹂躏、滴蜡、惩戒、疼痛转化
爆发体系：粗度临界、姿态失衡、敏感度引爆
防守体系：冷静、反伤、疼痛转化
群战体系：伙伴协击、姿势配合、主题楼层招募
```

核心目标是：

```text
每个流派都有独立玩法目标；
每个流派都能和至少 2~3 个其他流派组合；
每个楼层都能推动不同流派成型；
敌人也有反制，避免单一卡组无脑通关。
```
