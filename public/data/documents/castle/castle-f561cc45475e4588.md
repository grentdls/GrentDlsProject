# 1. Build 设计总原则

## 1.1 一个流派必须具备的内容

每个成熟 Build 至少需要包含：

```text
1. 核心关键词
2. 触发条件
3. 成长属性
4. 主要输出方式
5. 防守或续航方式
6. 关键卡牌
7. 关键遗物
8. 关键事件
9. 反制敌人
10. UI 表现
```

## 1.2 Build 的三层结构

所有套路都按三层设计：

```text
基础层：不依赖遗物也能打出基本效果
成长层：获得核心卡 / 属性卡后开始变强
成型层：遗物、伙伴、强化牌联动后形成质变
```

## 1.3 Build 避免的问题

不能所有流派都只是“伤害变高”。每个流派需要有不同操作体验：

| 流派 | 操作体验 |
|---|---|
| 连击流 | 多段触发、攻击次数堆叠、最后一击爆发 |
| 追击流 | 每次伤害后追加小额伤害，越多段越强 |
| 粘液流 | 先上状态，再靠多次攻击吃增伤 |
| 喷发流 | 主动控制危险值，把喷发变成收益 |
| 冷静流 | 高防御、高净化、稳定推进 |
| 契约流 | 标记目标，后续卡牌吃标记加成 |
| 挑逗流 | 叠状态，达到层数后引爆 |
| 姿态流 | 在不同姿态间切换，吃姿态奖励 |
| 过牌流 | 抽牌、弃牌、回收、低费循环 |
| 伙伴流 | 多单位协作，主角与伙伴共同行动 |

# 2. 核心战斗字段扩展

## 2.1 新增关键词字段

| 中文关键词 | 内部字段 | 类型 | 说明 |
|---|---|---|---|
| 连续抽插 | ContinuousThrust | 卡牌标签 | 表示该卡属于连击推进类，会受到连续次数加成 |
| 连续次数 | ThrustCountBonus | 玩家属性 | 增加带【连续抽插】卡的攻击段数 |
| 弹珠 | BeadCore | 玩家插件 | 每个弹珠使每次伤害额外触发 10% 追击伤害 |
| 粘液 | SlimeMark | 敌方 Debuff | 每层使目标受到的每次伤害增加固定值或百分比 |
| 临界 | EnduranceCritical | 状态 | 玩家忍耐值超过阈值后的危险收益状态 |
| 喷发次数 | EruptionCharge | 额外生命 | 玩家可承受喷发的次数 |
| 伙伴 | Companion | 协战单位 | 可在奇遇中招募，加入战斗队列 |
| 协战 | Assist | 伙伴动作 | 满足条件后伙伴自动行动 |
| 合击 | DuoAction | 联动技 | 主角与伙伴共同释放 |
| 烙印 | Brand | 敌方 Debuff | 标记目标，后续卡牌获得额外效果 |
| 挑逗 | Tease | 敌方 Debuff | 层数叠加，到阈值后可引爆 |
| 冷静 | Calm | 防御资源 | 抵消忍耐增长或伤害压力 |
| 共鸣 | Resonance | 敌方生命 | 目标满后进入结算 |

## 2.2 伤害结算顺序

所有伤害建议按以下顺序结算：

```text
1. 基础伤害 BaseDamage
2. 卡牌倍率 CardMultiplier
3. 玩家攻击力加成 PlayerDamageBonus
4. 敌方易伤 / 粘液 / 烙印等受伤加成
5. 暴击 / 终结 / 条件增伤
6. 造成主伤害
7. 触发弹珠追击
8. 触发伙伴协战
9. 触发 Buff / Debuff 层数变化
10. 检查共鸣结算
```

## 2.3 统一公式

### 主伤害公式

```text
FinalDamage = BaseDamage × CardMultiplier × (1 + PlayerDamageBonus) × (1 + EnemyDamageTakenBonus) + FlatBonus
```

### 弹珠追击公式

```text
BeadExtraHitDamage = FinalDamage × 10% × BeadCount
```

说明：

- 每个弹珠追加一次独立伤害。
- 每次追加伤害都可以触发“命中时”效果，但默认不再触发新的弹珠，避免无限递归。
- 可通过高级遗物解除限制，让弹珠追击也触发部分状态。

### 粘液增伤公式

推荐两种方案二选一：

#### 方案 A：固定增伤

```text
ExtraDamage = SlimeStack × 1
```

适合前期，数值稳定。

#### 方案 B：百分比增伤

```text
DamageTakenBonus = SlimeStack × 3%
```

适合中后期，成长更强。

建议最终使用混合方案：

```text
SlimeBonus = SlimeStack × 1 + FinalDamage × SlimeStack × 1%
```

# 3. 流派一：【连续抽插】连击流

> UI 建议可显示为【连续推进】或【连段推进】，内部字段保留 ContinuousThrust。

## 3.1 流派定位

这是最直接、最爽快的攻击流派。核心是：

```text
一张攻击卡造成多段伤害。
通过属性卡、遗物、伙伴增加攻击段数。
段数越多，越容易触发弹珠、粘液、命中 Buff、伙伴协战。
```

## 3.2 核心规则

### 卡牌标签

带有【连续抽插】字段的卡会获得额外段数。

```text
实际攻击段数 = 卡牌基础段数 + 玩家连续次数加成 + 临时段数加成
```

### 每段伤害

```text
每段伤害 = 卡牌基础伤害
总伤害 = 每段伤害 × 实际段数
```

### 段数上限

为了避免失控：

```text
普通战斗段数上限：12
精英 / Boss 战段数上限：16
特殊遗物可突破到 20
```

## 3.3 核心属性

| 属性 | 说明 |
|---|---|
| 连续次数 +1 | 所有【连续抽插】卡额外攻击 1 段 |
| 连击增幅 | 每段攻击伤害提高 |
| 终段爆发 | 最后一段造成额外伤害 |
| 连击冷静 | 每攻击若干段获得冷静 |
| 连击升温 | 每段攻击也会增加自身少量忍耐 |

## 3.4 核心卡牌

### 1）基础连段

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---|---:|---|---|
| 连续推进 | 攻击 | 1 | 造成 3 段 4 点共鸣 | 玩家快速突进，连续三段紫红弧光 |
| 深入连段 | 攻击 | 2 | 造成 5 段 3 点共鸣 | 残影加速，多段命中火花 |
| 贴身节奏 | 技能 | 1 | 本回合【连续抽插】卡段数 +1 | 玩家脚下出现节奏光环 |
| 再来一轮 | 技能 | 0 | 下一张【连续抽插】卡额外 +2 段，但自身忍耐 +3 | 红色警戒光与加速线 |
| 稳定连击 | 技能 | 1 | 本回合每 3 段攻击获得 2 冷静 | 蓝色护光随着段数跳动 |

### 2）成长连段

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---|---:|---|---|
| 节拍叠加 | 强化 | 1 | 每回合第一次【连续抽插】卡段数 +1 | 节拍器图标悬浮 |
| 连击上瘾 | 强化 | 2 | 每打出 3 张攻击牌，获得连续次数 +1，持续本场战斗 | 红紫连击计数器增长 |
| 终段重压 | 强化 | 1 | 【连续抽插】卡最后一段伤害 +100% | 最后一击金色爆点 |
| 节奏回收 | 技能 | 1 | 若本回合攻击段数 ≥6，抽 2 张 | 卡牌从攻击轨迹中飞回手牌 |
| 连段喘息 | 技能 | 1 | 若本回合攻击段数 ≥8，降低 4 忍耐 | 蓝光压制红色临界条 |

### 3）稀有连段

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---|---:|---|---|
| 无尽推进 | 攻击 | 3 | 造成 4 段 5 点共鸣；每有 1 点额外连续次数，额外 +1 段 | 全屏多残影突进 |
| 暴雨连击 | 攻击 | 2 | 对随机敌人造成 8 段 2 点共鸣 | 多目标随机闪击 |
| 临界连段 | 攻击 | 2 | 忍耐超过 70% 时，段数翻倍 | 红色临界爆发，镜头轻震 |
| 节奏支配 | 强化 | 3 | 所有【连续抽插】卡额外 +2 段 | 主角身后出现巨大节拍阵 |

## 3.5 连击流遗物

| 遗物 | 效果 |
|---|---|
| 节奏手套 | 每场战斗第一次【连续抽插】卡段数 +2 |
| 红丝计数器 | 每造成 10 段攻击，获得 1 点力量 |
| 余韵鞋跟 | 使用【连续抽插】卡后，下一张技能牌费用 -1 |
| 失控节拍器 | 连续次数 +2，但每回合开始忍耐 +2 |
| 终段戒指 | 每张多段攻击的最后一段必定暴击 |

## 3.6 连击流弱点

- 害怕反伤敌人。
- 害怕“每次被命中获得防御”的敌人。
- 段数多会快速增加自身忍耐，容易喷发失败。
- 打高护甲低增伤时效率低。

## 3.7 推荐联动

| 联动 | 说明 |
|---|---|
| 连击 + 弹珠 | 每段攻击都触发弹珠追击，成长极强 |
| 连击 + 粘液 | 粘液层数越高，多段收益越高 |
| 连击 + 伙伴 | 达到攻击段数阈值后伙伴协战 |
| 连击 + 冷静 | 用冷静抵消连击带来的忍耐风险 |

# 4. 流派二：【阳具弹珠】追击流

> 建议 UI 名称：**珠核插件 / 弹珠插件 / 珠核追击**。  
> 内部可保留“阳具弹珠”作为成人主题设定，但表现上用“珠核”“插件”“嵌件”更容易统一美术与审核。

## 4.1 流派定位

核心是：

```text
每次主伤害后，根据弹珠数量追加若干次 10% 伤害。
攻击次数越多，收益越高。
低伤多段卡可以变成高频追击。
```

## 4.2 核心规则

### 基础规则

```text
每拥有 1 个弹珠：
玩家每次造成主伤害后，额外造成 1 次 10% 的追击伤害。
```

### 多弹珠规则

```text
弹珠数量 = 3
主伤害 = 20
追击 = 2 + 2 + 2
总伤害 = 26
```

### 多段攻击规则

```text
若一张卡造成 5 段伤害，每段都会触发弹珠追击。
```

### 防止无限递归

默认规则：

```text
弹珠追击不会再次触发弹珠追击。
```

高级遗物可以允许：

```text
弹珠追击可以触发粘液、挑逗、烙印，但不能触发新的弹珠。
```

## 4.3 弹珠属性

| 属性 | 说明 |
|---|---|
| 弹珠数量 | 决定追击次数 |
| 弹珠倍率 | 默认 10%，可提升到 12% / 15% |
| 弹珠触发范围 | 单体 / 全体 / 随机 |
| 弹珠状态附着 | 追击可附加粘液、挑逗、烙印 |
| 弹珠暴击 | 追击有几率暴击 |

## 4.4 核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---|---:|---|---|
| 珠核嵌入 | 技能 | 1 | 本场战斗弹珠 +1 | 一枚红金珠核嵌入光环 |
| 珠核校准 | 技能 | 0 | 本回合弹珠伤害倍率 +5% | 珠核旋转并发光 |
| 追击试探 | 攻击 | 1 | 造成 8 点共鸣，弹珠伤害翻倍触发 | 主击后小光珠追击 |
| 珠核连射 | 攻击 | 2 | 造成 3 段 4 点共鸣，每段额外触发弹珠 | 三段命中后多珠飞击 |
| 嵌件扩容 | 强化 | 2 | 每场战斗开始时弹珠 +1 | 主角身后出现插件槽 |
| 滚珠热流 | 攻击 | 1 | 造成 6 点共鸣，每有 1 个弹珠额外施加 1 粘液 | 粉红小珠沿轨迹滚动 |
| 余震弹珠 | 强化 | 1 | 弹珠追击会对随机敌人造成 1 点溅射 | 小珠命中后反弹 |
| 珠核风暴 | 攻击 | 3 | 每个弹珠对随机敌人造成 3 次 3 点共鸣 | 多颗珠核环绕全屏打击 |

## 4.5 弹珠流遗物

| 遗物 | 效果 |
|---|---|
| 第一枚珠核 | 开局获得 1 个弹珠 |
| 珠核扩展器 | 弹珠上限 +2 |
| 高敏珠核 | 弹珠追击倍率从 10% 提升到 15% |
| 反弹珠 | 弹珠追击有 25% 几率攻击另一名敌人 |
| 双槽插件 | 每次获得弹珠时，额外获得 1 层冷静 |
| 过热珠核 | 弹珠追击伤害 +50%，但每触发 5 次忍耐 +1 |
| 粘液珠 | 弹珠追击时有 30% 几率施加 1 层粘液 |
| 烙印珠 | 对有烙印的敌人，弹珠追击倍率翻倍 |

## 4.6 弹珠流弱点

- 初期没弹珠时较弱。
- 害怕减伤和护盾厚的敌人。
- 害怕“受到多次小伤害后反击”的敌人。
- 需要多段卡或低费攻击卡配合。

# 5. 流派三：【粘液】Buff 增伤流

## 5.1 流派定位

核心是：

```text
先给敌人叠加粘液。
粘液会增加每次伤害的伤害值。
粘液层数越高，多段攻击、弹珠追击、伙伴攻击收益越高。
```

## 5.2 粘液规则

### 基础规则

```text
敌人每有 1 层粘液：
每次受到伤害时，额外受到 1 点固定伤害。
```

### 进阶规则

当获得某些强化后：

```text
每层粘液额外使目标受到的伤害 +1%
```

### 层数衰减

默认：

```text
每回合结束，粘液层数减少 1。
```

也可以通过遗物改变：

```text
粘液不再自然衰减。
粘液每回合会扩散到相邻敌人。
```

## 5.3 粘液状态视觉

| 层数 | 表现 |
|---|---|
| 1~3 层 | 敌人脚下出现少量粉紫粘液光泽 |
| 4~7 层 | 身体周围有粘液丝线和滴落粒子 |
| 8~12 层 | 粘液覆盖明显，受到伤害时爆出粉紫波纹 |
| 13+ 层 | 粘液进入临界，攻击时出现额外爆点 |

## 5.4 核心卡牌

| 卡牌 | 类型 | 费用 | 效果 | 表现 |
|---|---|---:|---|---|
| 粘液涂抹 | 技能 | 1 | 对目标施加 3 层粘液 | 粉紫液态光覆盖目标脚下 |
| 粘液推进 | 攻击 | 1 | 造成 7 点共鸣，施加 1 层粘液 | 命中后粘液印记扩散 |
| 粘稠连段 | 攻击 | 2 | 造成 3 段 4 点共鸣，每段施加 1 粘液 | 多段命中带液态光点 |
| 扩散粘液 | 技能 | 1 | 将目标一半粘液扩散到其他敌人 | 液态波纹横向蔓延 |
| 粘液催化 | 技能 | 1 | 本回合粘液增伤翻倍 | 粘液发光并起泡 |
| 粘液护膜 | 技能 | 1 | 每有 3 层粘液，获得 2 冷静 | 粘液转化成蓝紫护膜 |
| 黏着烙印 | 技能 | 1 | 对有粘液的目标施加烙印 | 粘液中浮出黑红印章 |
| 粘液爆裂 | 攻击 | 2 | 消耗目标全部粘液，每层造成 3 点共鸣 | 粘液爆成粉紫冲击波 |
| 粘液雨 | 技能 | 2 | 对所有敌人施加 4 层粘液 | 天空落下液态粒子 |
| 深层浸润 | 强化 | 2 | 粘液不再自然衰减 | 敌人脚下形成持续液池 |

## 5.5 粘液流遗物

| 遗物 | 效果 |
|---|---|
| 粘液瓶 | 战斗开始对所有敌人施加 2 粘液 |
| 浓稠核心 | 粘液固定增伤 +1 |

# 6. 流派四：【忍耐临界】喷发反打流

## 6.1 流派定位

核心是：

```text

忍耐越高，攻击越强。
喷发不再只是失败风险，而是可控资源。
```

## 6.2 临界区间

| 忍耐比例 | 状态 | 效果 |
|---|---|---|
| 0%~39% | 平稳 | 无特殊效果 |
| 40%~69% | 升温 | 部分卡获得额外效果 |
| 70%~99% | 临界 | 临界卡大幅增强 |
| 100% | 喷发 | 触发喷发结算 |

## 6.3 核心规则

### 临界增伤

```text
若忍耐 >= 70%，临界卡伤害 +50%。
```

### 喷发次数

```text
默认喷发次数 = 1
每增加 1 次喷发次数，相当于额外生命。
喷发后忍耐清空，喷发次数 -1。
```

### 喷发收益

```text
玩家喷发时，固定对敌人增加 10% 共鸣值。
部分卡 / 遗物可提升到 15% / 20%。
```

| 二次耐受 | 强化 | 2 | 喷发次数 +1 |

# 12. 流派十：【群战伙伴】协战流

## 12.1 流派定位

核心是：

```text
通过奇遇招募伙伴。
伙伴作为独立单位进入战斗。
玩家卡牌可以触发伙伴协战。
不同伙伴提供不同 Build 支持。
```

## 12.2 群战基础规则

### 伙伴位置

```text
玩家站位：左侧主位
伙伴 1：玩家后上方
伙伴 2：玩家后下方
最多同时上场伙伴：2 名
```

### 伙伴行动方式

伙伴不使用完整手牌，而是有自己的行动条。

```text
伙伴行动点 AssistGauge = 0~100
玩家满足条件时，伙伴行动点增加。
行动点满后，伙伴自动释放协战技。
```

### 行动点获取

| 触发 | 行动点增加 |
|---|---:|
| 玩家打出攻击牌 | +10 |
| 玩家打出技能牌 | +6 |
| 玩家造成 5 次伤害 | +15 |
| 玩家施加 Debuff | +8 |
| 玩家进入临界 | +20 |
| 玩家喷发 | +30 |
| 敌人进入高潮结算 | +50 |

## 12.3 伙伴类型

| 伙伴类型 | 定位 | 适合流派 |
|---|---|---|
| 攻击伙伴 | 追加伤害 | 连击、弹珠 |
| 状态伙伴 | 施加粘液 / 挑逗 / 烙印 | 粘液、契约、挑逗 |
| 防御伙伴 | 给冷静、净化、保护 | 冷静、临界 |
| 过牌伙伴 | 抽牌、回收、降费 | 过牌流 |
| 群攻伙伴 | 对多敌人打击 | 群战、粘液扩散 |
| Boss 对策伙伴 | 打断、破防、削弱 | 精英 / Boss 战 |

## 12.4 伙伴协战规则

### 自动协战

```text
AssistGauge >= 100 时自动释放协战技。
释放后 AssistGauge = 0。
```

### 合击技

当玩家打出特定标签卡，且伙伴行动点 ≥50：

```text
可触发合击技。
合击技消耗 50 行动点。
```

### 伙伴受击

建议伙伴默认不直接承受伤害，避免系统复杂。可设计部分敌人拥有“压制伙伴”的行动：

```text
敌人特殊行动：伙伴沉默 1 回合 / 行动点减少 30。
```

## 12.5 伙伴招募限制

| 项目 | 规则 |
|---|---|
| 最多携带 | 3 名伙伴 |
| 最多上场 | 2 名伙伴 |
| 伙伴替换 | 休息房 / 事件房可调整 |
| 伙伴升级 | 通过事件、Boss 奖励、特殊遗物 |
| 伙伴死亡 | 不死亡，但可被封锁 / 沉默 |

## 18.5 弹珠追击伪代码

```csharp
void ResolveDamage(DamageContext ctx)
{
    int finalDamage = CalculateMainDamage(ctx);
    ApplyDamage(ctx.Target, finalDamage);

    if (ctx.CanTriggerBead && !ctx.IsBeadExtraHit)
    {
        for (int i = 0; i < playerStats.BeadCount; i++)
        {
            int beadDamage = Mathf.CeilToInt(finalDamage * playerStats.BeadDamageRate);
            DamageContext beadCtx = ctx.Clone();
            beadCtx.IsBeadExtraHit = true;
            beadCtx.CanTriggerBead = false;
            ApplyDamage(beadCtx.Target, beadDamage);
        }
    }
}
```

## 18.6 粘液增伤伪代码

```csharp
int ApplySlimeBonus(Unit target, int damage)
{
    int slimeStack = target.GetStatusStack(StatusType.SlimeMark);
    int flatBonus = slimeStack;
    int percentBonus = Mathf.CeilToInt(damage * slimeStack * 0.01f);
    return damage + flatBonus + percentBonus;
}
```

## 18.7 伙伴行动点伪代码

```csharp
void OnPlayerAction(CardData card)
{
    foreach (var companion in activeCompanions)
    {
        int gain = 0;
        if (card.Type == CardType.Attack) gain += 10;
        if (card.Type == CardType.Skill) gain += 6;
        if (card.Tags.Contains(CardTag.Slime)) gain += companion.SlimeBonusGauge;
        if (card.Tags.Contains(CardTag.ContinuousThrust)) gain += companion.ComboBonusGauge;

        companion.AssistGauge += gain;

        if (companion.AssistGauge >= 100)
        {
            companion.AssistGauge = 0;
            TriggerCompanionAssist(companion);
        }
    }
}
```

## 19.1 各流派强度曲线

| 流派 | 前期 | 中期 | 后期 | 风险 |
|---|---|---|---|---|
| 连击流 | 强 | 强 | 中高 | 忍耐增长快 |
| 弹珠流 | 弱 | 强 | 极强 | 依赖遗物 |
| 粘液流 | 中 | 强 | 强 | 启动慢 |
| 临界流 | 中 | 强 | 极强 | 失败风险高 |
| 冷静流 | 稳 | 稳 | 中 | 输出较慢 |
| 烙印流 | 中 | 强 | 强 | 依赖单体目标 |
| 挑逗流 | 中 | 中强 | 强 | 怕净化 |
| 姿态流 | 中 | 强 | 强 | 操作复杂 |
| 过牌流 | 弱 | 强 | 极强 | 怕卡手和状态牌 |
| 伙伴流 | 中 | 强 | 极强 | 依赖事件和伙伴 |

## 19.2 数值上限建议

| 属性 | 建议软上限 | 说明 |
|---|---:|---|
| 连续次数加成 | +6 | 超过后收益递减 |
| 弹珠数量 | 6 | Boss 遗物可到 8 |
| 粘液层数 | 30 | 超过后显示为临界层 |
| 挑逗层数 | 30 | 每 15 层触发一次阈值 |
| 烙印层数 | 20 | 防止单体秒杀失控 |
| 伙伴数量 | 3 携带 / 2 上场 | 避免画面混乱 |
| 喷发次数 | 3 | Boss 遗物可到 4 |

## 19.3 防止无限循环

需要限制以下触发：

```text
弹珠不能触发弹珠。
伙伴协战不能触发伙伴协战。
每回合抽牌触发类效果需要次数上限。
每回合能量返还类效果需要次数上限。
粘液扩散不能无限扩散。
喷发后收益不能再次立刻触发喷发收益。
```

# 22. 结语

这套 Build 扩展后，游戏会从单一“打伤害”变成多套路构筑：

```text
连击流：靠段数压制。
弹珠流：靠每次伤害后的追击扩大收益。
粘液流：靠状态增伤滚雪球。
临界流：靠忍耐风险换高收益。
冷静流：靠防御和净化稳定推进。
烙印流：靠标记和消耗爆发。
挑逗流：靠层数阈值与引爆。
姿态流：靠不同姿态切换获得奖励。
过牌流：靠循环和低费操作打出高频触发。
伙伴流：靠招募、协战、合击扩展战斗维度。
```

最终目标是让玩家每一局都能形成不同构筑，而不是只堆攻击力。每个流派都能单独成型，也能互相混搭，形成更多随机性和重玩价值。
