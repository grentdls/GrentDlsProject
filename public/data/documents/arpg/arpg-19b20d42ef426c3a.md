# 86 小地图、任务目标、边缘提示、威胁预警 HUD 规则

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. 设计目标

虽然本次重点是名称、血条、跳字、Buff，但完整 HUD 还必须包含导航类信息：

- 小地图。
- 区域名称。
- 任务目标。
- 传送门/出口。
- 离屏 Boss/精英威胁。
- 高价值掉落提示。
- 场景事件进度。

导航 HUD 的目标是减少玩家迷路，但不能破坏探索感。

## 3. 小地图模式

| 模式 | 说明 |
|---|---|
| 右上角小地图 | 默认显示 |
| 半透明大地图 | 按 Tab 打开，覆盖屏幕但不暂停 |
| 全屏地图 | 打开地图面板，暂停或半暂停 |
| 主城功能地图 | 显示 NPC 功能区 |
| 终局地图册 | 独立 UI，不属于战斗 HUD |

---

## 4. 小地图标记规则

| 标记 | 显示条件 | 优先级 |
|---|---|---:|
| 玩家 | 永远显示 | 100 |
| 主线任务目标 | 当前地图内显示 | 95 |
| 出口/传送门 | 发现后显示 | 90 |
| Boss | Boss 区域/战斗中显示 | 90 |
| 精英怪 | 近距离/任务相关/高威胁显示 | 70 |
| NPC 功能 | 主城显示 | 65 |
| 宝箱/祭坛 | 发现后显示 | 55 |
| 高价值掉落 | 掉落后短时间显示 | 80 |
| 普通怪 | 默认不显示 | 10 |

## 5. 任务追踪 UI

```text
Prefab_QuestTrackerHUD
├── Root
│   ├── Text_AreaObjectiveTitle

│   │   ├── QuestObjectiveItem_01
│   │   └── QuestObjectiveItem_N
│   ├── EventProgressBar

```

### 5.1 任务文字规则

| 状态 | 显示 |
|---|---|
| 主线目标 | 右侧常驻，战斗中透明度降低 |
| 支线目标 | 可折叠 |
| 地图目标 | 进入地图后显示 5 秒，再缩小 |
| 事件目标 | 事件开始后强显示 |
| Boss 目标 | Boss 战中显示在 Boss 条下方或右侧 |

示例：

```text
当前目标
- 穿过断桥荒原
- 找到裂石矿洞入口
```

事件示例：

```text
净化祭坛：12 / 20
剩余敌人：8
```

## 6. 边缘提示规则

当目标在屏幕外时，显示边缘箭头。

```text
Prefab_EdgeIndicator
├── Root
│   ├── Arrow
│   ├── Icon_TargetType
│   ├── Text_Distance
│   └── PulseAnim
```

### 6.1 显示对象

| 对象 | 是否显示边缘提示 |
|---|---|
| 主线目标 | 是 |
| 地图出口 | 是，发现后 |
| Boss | 是，Boss 战中或追击时 |
| 高威胁精英 | 可选 |
| 高价值掉落 | 短时显示 |
| 普通 NPC | 否 |
| 普通怪 | 否 |
| 普通掉落 | 否 |

### 6.2 箭头规则

- 箭头贴屏幕安全区边缘。
- 箭头指向目标屏幕外方向。
- 显示距离数字，可配置。
- 多个箭头重叠时按优先级合并。
- Boss 致命技能来源可短暂使用红色威胁箭头。

## 7. 威胁预警

### 7.1 威胁类型

| 类型 | HUD 表现 |
|---|---|
| Boss 致命技能 | 屏幕边缘红光 + 地面范围 |
| 离屏投射物 | 边缘方向闪光 |
| 精英冲锋 | 敌人方向箭头 + 音效 |
| 玩家被点名 | 角色脚下标记 + Buff 栏图标 |
| 地面危险 | 地面 Decal + 倒计时边框 |
| 大范围爆炸 | 屏幕中心短提示 + 地面范围 |

### 7.2 预警等级

| 等级 | 说明 | 表现 |
|---|---|---|
| 低 | 可忽略小威胁 | 轻微地面提示 |
| 中 | 需要移动或防御 | 地面范围 + 音效 |
| 高 | 可能造成重伤 | 红色边缘提示 + 强音效 |
| 致命 | 可能秒杀/机制失败 | 屏幕警告 + 倒计时 + 特效 |

## 8. 地面预警 UI

地面预警不属于普通 UI Canvas，但由 HUD 规则管理。

```text
SkillWarningDecal
├── Decal_Circle
├── Decal_Cone
├── Decal_Line
├── Decal_Donut
├── CountdownRing
├── EdgePulse
└── DangerColorByLevel
```

### 8.1 预警形状

| 形状 | 用途 |
|---|---|
| 圆形 | 落雷、陨石、爆炸 |
| 扇形 | Boss 正面扫击、吐息 |
| 直线 | 激光、冲锋、箭雨线 |
| 环形 | 近身安全/远离安全机制 |
| 多段矩形 | 地刺、滚石、火墙 |
| 追踪圈 | 玩家被点名 |

## 9. 地图完成提示

地图目标完成时显示：

```text
区域目标完成
Boss 已击败
传送门已开启
```

显示位置：

- 屏幕上方中部 Toast。
- 小地图出口闪烁。
- 任务追踪更新。

## 10. 配置字段

```json
{
  "MinimapMarkerRuleId": "Quest_Main_Target",
  "TargetType": "QuestMain",
  "IconPath": "UI/Icons/Minimap/QuestMain",
  "ShowOnMinimap": true,
  "ShowOnOverlayMap": true,
  "ShowEdgeIndicator": true,
  "ShowDistance": true,
  "Priority": 95,
  "PulseWhenNear": true,
  "VisibleWhenUndiscovered": true,
  "ColorRule": "QuestGold"
}
```

威胁预警配置：

```json
{
  "WarningRuleId": "Boss_Lethal_AOE",
  "WarningLevel": "Lethal",
  "Shape": "Circle",

  "UseEdgeFlash": true,
  "UseCountdown": true,
  "CountdownSeconds": 2.5,
  "AudioCue": "SFX_Warning_Lethal",
  "Priority": 100
}
```

## 11. 验收标准

- 主城小地图能显示功能 NPC、仓库、传送点。
- 战斗地图能显示任务目标、出口、Boss 区域。
- 屏幕外主线目标能显示边缘箭头。
- Boss 致命技能预警明显强于普通技能。
- 地面预警形状与技能范围一致。
- 小地图标记不会被普通怪和低价值掉落污染。
- 手柄/移动端可以打开大地图和查看任务目标。
