# 97. 输入系统：键鼠、手柄、移动端与 InputAction 配置


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 输入系统目标

同一套 3C 必须支持键鼠、手柄和未来移动端虚拟摇杆。输入层不能直接写进角色控制器，需要通过 InputAction 抽象成统一命令。

## 2. 输入架构

```text
InputSystem
├── InputActionAsset_ARPG3C
├── PlayerInputRouter
├── InputBuffer
├── InputDeviceDetector
├── RebindManager
├── CursorModeManager
└── UIInputBridge
```

## 5. 输入缓冲规则

`InputBuffer` 记录短时间输入，防止动作后摇阶段吞输入。

| 输入 | 缓冲时间 | 消费条件 |
|---|---:|---|
| 普攻 | 0.25s | 连段窗口打开 |
| 重击 | 0.22s | 当前动作可接重击 |
| 跳跃 | 0.12s | grounded 或 coyote time |
| 闪避 | 0.15s | 体力足且可取消 |
| 交互 | 0.10s | 焦点交互物存在 |
| 技能 | 0.20s | 技能可释放 |

## 6. 输入优先级

当同一帧多个输入触发：

```text
系统菜单 > UI确认 > 受击受身 > 闪避 > 防御/格挡 > 技能 > 攻击 > 跳跃 > 交互 > 普通移动
```

注意：交互和攻击冲突时，如果玩家处于战斗中，攻击优先；非战斗且面对 NPC/宝箱，交互优先。

## 7. 键鼠模式

### 7.1 光标状态

| 状态 | 光标 |
|---|---|
| 主界面 | 显示 |
| 游戏自由镜头 | 锁定隐藏 |
| 背包/商店 | 显示 |
| 鼠标瞄准技能 | 可显示准星，不显示系统光标 |
| 对话 | 显示或半锁定，按设置 |

### 7.2 鼠标灵敏度

分开设置：

- 普通镜头 X/Y 灵敏度。
- 瞄准状态灵敏度。
- 锁定状态镜头修正强度。
- 鼠标 Y 反转。

## 8. 手柄模式

### 8.1 死区

| 摇杆 | 死区 |
|---|---:|
| 左摇杆 | 0.12 |
| 右摇杆 | 0.15 |
| 触发器 | 0.10 |

### 8.2 曲线

右摇杆不要线性，使用指数曲线：

```text
Output = Sign(Input) * Pow(Abs(Input), 1.35)
```

低幅度精细瞄准，高幅度快速转向。

## 9. 移动端输入预留

虽然当前是 PC/主机优先，但移动端可预留：

```text
MobileHUD
├── LeftVirtualJoystick
├── RightCameraDragArea
├── AttackButton
├── DodgeButton
├── JumpButton
├── SkillButtons
├── LockButton
├── PotionButton
└── InteractButton
```

规则：

- 按钮布局可编辑。
- 技能按钮支持冷却显示。
- 右半屏拖动控制镜头。
- 锁定按钮用于解决触屏精准瞄准问题。

## 10. UI 与 Gameplay 输入隔离

打开 UI 时：

| UI | Gameplay 输入 |
|---|---|
| 背包 | 暂停大部分战斗输入，若多人在线则角色站定 |
| 商店 | 禁用移动/攻击 |
| 地图 | 可选择是否保留慢走 |
| 设置 | 全禁用 |
| 死亡界面 | 全禁用，只保留 UI |
| 快捷轮盘 | 慢动作或不暂停，按项目模式 |

## 13. 验收标准

- 键鼠和手柄都能完整游玩。
- UI 打开时不会误触攻击。
- 关闭 UI 后角色控制恢复正常。
- 手柄右摇杆低速可精确、高速可快速转身。
- 键位重绑能保存到本地设置。
- 输入缓冲让连段和闪避手感稳定。
