# 191 地图词缀与怪物词缀扩展：反制构筑、奖励倾斜

## 1. 地图词缀目标

地图词缀用于改变副本玩法，制造刷图变化。

类型：
```text
怪物增强
玩家限制
掉落倾斜
机制事件
反制构筑
高风险高收益
```

## 2. 怪物增强词缀

```text
怪物火焰抗性 +40%，火焰装备掉落提高。
怪物护盾提高 80%，破盾奖励提高。
怪物死亡后留下毒池。
怪物投射物会分裂一次。
怪物被击杀时有概率召唤小怪。
```

## 3. 玩家限制词缀

```text
玩家吸血效果降低 50%。
玩家护盾回复延迟 +1 秒。
玩家投射物数量 -1。
玩家控制持续时间降低 30%。
玩家药剂回复降低，但药剂掉落提高。
```

## 4. 掉落倾斜

```text
火焰词条装备掉落率提高。
召唤物相关装备掉落率提高。
破盾词条出现概率提高。
投射物词条出现概率提高。
Boss 专属材料掉落提高。
```

## 5. 反制构筑词缀

```text
怪物获得反投射物护盾。
怪物受到 AOE 伤害降低。
怪物对召唤物造成更多伤害。
怪物受到控制时间降低。
怪物受到真伤有上限。
```

## 6. 地图奖励计算

```text
rewardMultiplier = baseReward
                 * difficultyMultiplier
                 * affixRiskMultiplier
                 * clearBonus
```

高风险词缀必须提高奖励，否则玩家不会选择。
