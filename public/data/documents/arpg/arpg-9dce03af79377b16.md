# 99. 3C 参数表：配置字段、策划调参与数据结构


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 目标

3C 手感必须可调。不要把速度、转向、镜头距离、闪避无敌帧、跳跃高度写死在脚本里。策划需要能通过 ScriptableObject / JSON / 编辑器面板调整不同职业、不同状态、不同地图模式的参数。


## 3. CameraProfile 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| profileId | string | 配置 ID |
| mode | enum | Free/Combat/Lock/Boss |
| followDistance | float | 跟随距离 |
| heightOffset | float | 镜头目标高度 |
| sideOffset | float | 角色屏幕偏移 |
| fov | float | 默认 FOV |
| fovSprint | float | 疾跑 FOV |
| pitchMin | float | 最小俯仰 |
| pitchMax | float | 最大俯仰 |
| dampingMove | float | 跟随阻尼 |
| dampingRotate | float | 旋转阻尼 |
| occlusionRadius | float | 遮挡检测半径 |
| lockTargetMix | float | 锁定目标混合权重 |

## 11. 策划调参面板

编辑器窗口：`Tools/ARPG/3C Tuning Panel`

```text
3C Tuning Panel
├── Profile Selector
│   ├── 职业
│   ├── 镜头模式
│   └── 地图模式
├── Movement Tab
├── Camera Tab
├── Jump Tab
├── Dodge Tab
├── Lock Tab
├── Collision Tab
├── Traversal Tab
├── Combat Motion Tab
├── Live Preview
└── Validation Log
```

功能：

- 运行时热更新参数。
- 参数曲线可视化。
- 一键恢复默认值。
- 一键复制某职业参数。
- 对比两个职业的移动差异。
- 自动生成测试报告。

## 12. 校验规则

| 规则 | 报错 |
|---|---|
| dodgeIFrameEnd > dodgeDuration | 错误 |
| jumpHeight <= 0 | 错误 |
| maxSlopeAngle > 75 | 警告 |
| sprintSpeed < runSpeed | 警告 |
| lockDistance <= softLockDistance | 警告，除非特殊配置 |
| capsuleRadius <= 0 | 错误 |
| autoStepHeight > vaultMinHeight | 警告 |

## 13. 验收标准

- 策划能不改代码调整移动速度、镜头、跳跃、闪避。
- 参数保存后重新打开项目不丢失。
- 参数错误能在编辑器中提示。
- 运行时修改参数能立即看到手感变化。
- 每个职业可以有独立移动手感。
