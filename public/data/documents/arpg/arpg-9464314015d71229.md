# 267 HUD 性能 Profiler 排查流程：测试场景、指标与验收

## 1. 压力测试场景

```text
1 个玩家
30 个普通敌人
5 个精英
1 个 Boss
持续多段伤害
持续 DOT
20 个血条同时显示
8 个技能按钮冷却
12 个 Buff
小地图开启
```

## 2. 分项测试

### 常驻 HUD

无敌人、无跳字，只测试角色血条、技能冷却、Buff。

### 敌人血条

分别测试：

```text
5 / 15 / 30 / 50 个敌人
```

### 伤害跳字

分别测试：

```text
每秒 20 / 50 / 100 / 200 次伤害
```

### 小地图

对比：

```text
256 / 512 / 1024 RenderTexture
60 / 20 / 10 Hz 刷新
```

## 3. Profiler 重点

```text
CPU Usage
Rendering
UI
Memory
GC Alloc
Timeline
```

```text
Canvas.BuildBatch

Camera.Render

Object.Destroy
GC.Collect
```

## 4. 常见症状

### 每隔几秒卡一下

```text
GC
Destroy
字符串分配
对象池容量不足
```

### 敌人越多越卡

```text
World Space Canvas
逐帧位置更新
遮挡 Raycast
血条 Animator
```

### 技能多时卡

```text
每个按钮独立 Update
冷却文本逐帧更新
材质不统一
```

### 小地图打开掉帧

```text
RenderTexture 太大
Layer 过多
阴影/后处理未关闭
刷新频率过高
```

## 5. 定位顺序

```text
关闭伤害跳字
→ 关闭敌人血条
→ 关闭小地图
→ 关闭技能冷却动画
→ 关闭 Buff
```

逐项对比锁定主要来源。

## 6. 推荐指标

60 FPS 目标：

```text
总帧时间：16.6 ms
HUD CPU：< 1.5 ms
World HUD：< 0.5 ms
伤害跳字：< 0.5 ms
小地图：< 1.0 ms
稳定战斗 GC.Alloc：接近 0
```

## 7. 最终验收

```text
30 个敌人
每秒 100 次伤害
20 个敌人血条
8 个技能冷却
12 个 Buff
小地图开启
Boss 血条开启
```

验收要求：

```text
无周期性 GC 卡顿
敌人死亡后 UI 正常回池
技能冷却不触发整块 HUD 重建
伤害数字对象池稳定
小地图关闭后性能变化符合预期
```
