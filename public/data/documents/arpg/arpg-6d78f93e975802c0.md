# 68. 技能执行流配置：输入、目标、阶段、判定、伤害


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第五批 —— 技能编辑器 / 怪物技能编辑器 / 策划配置工具  
> 目标：让策划不改代码，也能配置玩家技能、怪物技能、Boss 阶段技能、辅助模块、Buff、VFX/SFX、数值成长、AI 使用条件与测试验收。


---

## 1. 技能运行总流程

运行时释放技能必须经过统一流程：

```text
输入/AI请求
→ 检查可释放条件
→ 创建 SkillExecutionContext
→ 锁定目标/方向/位置
→ 扣除资源
→ 进入 CastStart 阶段
→ 触发动画/VFX/SFX/判定/投射物事件
→ 结算命中
→ 应用伤害/Buff/异常/召唤
→ 进入 Recovery 阶段
→ 开启取消窗口
→ 技能结束
→ 进入冷却
```

任何玩家技能、怪物技能、Boss 技能都走这条管线。区别只在于输入来源和 AI 使用规则。

---

## 2. SkillExecutionContext

每次释放技能都创建上下文，不能直接修改 SkillDefinition。

```text
SkillExecutionContext
├── Caster
├── SkillDefinition
├── SkillLevel
├── FinalSkillStats
├── InputTargetUnit
├── InputTargetPoint
├── AimDirection
├── StartPosition
├── StartRotation
├── RuntimeSupportModules[]
├── RuntimeDamageModifiers[]
├── RuntimeTags[]
├── HitRecord
└── RandomSeed
```

作用：

- 记录这次释放的最终数值。
- 保证同一个技能被不同装备/天赋/辅助影响时互不污染。
- 方便战斗回放。
- 方便 Debug。

## 5. 技能阶段模型

所有技能至少包含三个阶段：

```text
CastStart：前摇
Active：生效
Recovery：后摇
```

可以额外包含：

```text
Charge：蓄力
Channel：引导
CancelWindow：取消窗口
ComboWindow：连段窗口
InvulnerableWindow：无敌窗口
SuperArmorWindow：霸体窗口
```

## 8. Hitbox 判定执行

### 8.1 判定生命周期

```text
SpawnHitbox Event
→ 从对象池取 HitboxRuntime
→ 设置形状/位置/目标过滤
→ 每帧检测目标
→ 判断是否已命中过
→ 写入 HitRecord
→ 调用 DamageResolver
→ 播放命中特效与受击反馈
→ 持续时间结束后回收
```

### 8.2 HitRecord

```text
HitRecord
├── hitId
├── skillExecutionId
├── casterId
├── targetId
├── hitTime
├── hitPosition
├── hitNormal
├── damageBlockId
├── isCrit
├── isBlocked
├── isDodged
├── finalDamage
└── appliedBuffs[]
```

## 10. 伤害结算顺序

```text
读取 DamageBlock
→ 计算基础伤害
→ 应用技能等级倍率
→ 应用武器/法强倍率
→ 应用辅助模块倍率
→ 应用角色属性加成
→ 应用目标抗性/护甲
→ 判定暴击
→ 判定格挡/闪避
→ 计算最终伤害
→ 触发 OnHit / OnCrit / OnKill
→ 应用 Buff / 异常
```

## 11. 多段技能配置

多段技能不要做多个技能，而是一个技能多个事件。

示例：三连斩

```text
Phase 1：第一刀
0.12s SpawnHitbox hitbox_01 damage_01
0.14s PlayVFX slash_01

Phase 2：第二刀
0.36s SpawnHitbox hitbox_02 damage_02
0.38s PlayVFX slash_02

Phase 3：第三刀
0.62s SpawnHitbox hitbox_03 damage_03
0.64s PlayVFX slash_heavy
```

配置重点：

```text
每一刀可以不同伤害倍率
每一刀可以不同范围
第三刀可以造成击退或眩晕
中途有 ComboWindow，可接下一技能
```

## 14. 投射物技能执行

```text
SpawnProjectile Event
→ 读取 ProjectileBlock
→ 从对象池生成投射物
→ 设置初始位置、速度、目标、随机种子
→ 每帧移动
→ 碰撞检测
→ 命中后触发 OnHitAction
→ 穿透/连锁/弹跳判断
→ 生命周期结束触发 OnExpireAction
```

## 15. 投射物高级行为

### 15.1 穿透

```text
pierceCount = 2
每命中一个敌人消耗 1 次
穿透次数归零后销毁
```

### 15.2 连锁

```text
chainCount = 3
命中后搜索半径内新目标
不能连锁回已命中过的目标
连锁目标优先最近敌人
```

### 15.3 弹跳

```text
bounceCount = 2
碰到墙体时按法线反射
适合地牢狭窄空间技能
```

### 15.4 追踪

```text
homing = true
homingStrength = 4.5
maxTurnAnglePerSecond = 180
loseTargetAfterDistance = 12
```

## 16. 地面区域技能执行

```text
SpawnArea Event
→ 生成 AreaRuntime
→ 设置区域半径、持续时间、Tick 间隔
→ 创建地面预警圈
→ 延迟后激活伤害
→ 每 Tick 搜索目标

```

Area 字段：

```text
areaShape：Circle / Box / Donut / Line / Cone
radius
innerRadius
duration
tickInterval
warningTime
followTarget
canOverlap
maxStackOnTarget
```

## 17. 技能取消规则

ACT 操作必须有取消窗口。

```text
CancelRule
├── cancelType：Dodge / Movement / Skill / HitReaction
├── startTime
├── endTime
├── allowedSkillTags
├── forbiddenSkillTags
├── staminaCost
└── keepCooldown
```

示例：

```text
重击 0.55s 后可以翻滚取消
普通攻击 0.20s 后可以接下一段连击
法术前摇不可取消，后摇可移动取消
Boss 技能不可被普通硬直打断
```

## 18. 怪物技能执行差异

怪物技能与玩家技能共用执行流，但有额外处理：

```text
可以忽略资源消耗
可以有 AI 预警时间
可以根据难度缩放前摇
可以读取地图词缀修改伤害
可以绑定怪物体型缩放 Hitbox
可以释放时朝向玩家预测位置
```

怪物预测瞄准：

```text
PredictedTargetPoint = Target.Position + Target.Velocity * PredictTime
```
