# 247 增益、恢复、祭坛、压力板、隐藏机关与关卡互动玩法库

## 1. 增益祭坛

### 攻击祭坛
```text
攻击提高
暴击提高
穿甲提高
元素伤害提高
持续一定时间
```

### 防御祭坛
```text
恢复护盾
提高护甲
提高抗性
获得一次致死保护
```

### 速度祭坛
```text
移动速度提高
攻击速度提高
冷却恢复加快
```

### 召唤祭坛
```text
召唤临时盟友
召唤物数量临时 +1
召唤物伤害提高
```

## 2. 恢复交互物

```text
生命井
法力泉
护盾充能台
药剂补给架
复活祭坛
检查点
```

配置：

```text
固定恢复值
百分比恢复
刷新药剂
使用次数
冷却
是否保存使用状态
```

## 3. 风险收益祭坛

```text
失去当前生命，获得伤害
降低最大护盾，获得投射物 +1
随机获得 Buff 或 Debuff
献祭材料，换取高稀有装备
```

## 4. 临时技能祭坛

交互后：

```text
获得临时技能
替换一个技能槽
获得临时辅助模块
强化当前技能
```

持续范围：

```text
本房间
本关卡
固定时间
直到死亡
```

## 5. 压力板

触发方式：

```text

敌人站上

```

可控制：

```text
门
平台
陷阱
桥梁
隐藏房间
宝箱
```
