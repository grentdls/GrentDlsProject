# 226 抛射弹轨迹规则：重力、固定时间、最高点、弹跳、落点

## 1. 适用类型

```text
手雷、毒瓶、炮弹、迫击炮、陨石、投石、抛射火球、Boss 范围技能
```

完整参数：

```text
目标位置、飞行时间、最高点、重力、起始速度、落点误差
地形碰撞、弹跳、滚动、落点预警、落地爆炸、持续区域
```

## 2. 目标点来源

```text
鼠标地面点、目标当前位置、预测未来位置、目标脚下
随机区域点、场景预设点、技能 Timeline 给定点
```

## 3. 固定重力模式 Gravity

```json
{
  "ballisticMode": "Gravity",
  "gravity": 18.0,
  "launchSpeed": 14.0,
  "arcPreference": "High"
}
```

物理感强，适合手雷、石块和炮弹。

## 4. 固定飞行时间 FixedTime

策划指定 1.2 秒到达：

```text
horizontalVelocity = horizontalDelta / flightTime
verticalVelocity = (verticalDelta + 0.5 * gravity * flightTime²) / flightTime
```

```json
{
  "ballisticMode": "FixedTime",
  "flightTime": 1.2,
  "gravity": 16.0
}
```

优点：节奏稳定，预警圈可精确倒计时。

## 5. 指定最高点 ApexHeight

```json
{
  "ballisticMode": "ApexHeight",
  "apexHeight": 4.0,
  "gravity": 18.0
}
```

适合视觉可控的魔法抛射。

## 6. 高抛与低抛

同一目标存在高弧和低弧解：

```text
Low：飞得快、轨迹平、较容易撞障碍
High：飞得慢、轨迹高、预警时间长
```

## 7. 移动目标预测

```text
predictedTarget = targetPosition + targetVelocity * estimatedFlightTime
```

配置预测权重和最大预测距离，避免对急转目标过度预测。

## 8. 落点散布

```text
圆形、环形、扇形、高斯分布、固定编队
```

用于迫击炮群、陨石雨和 Boss 炮击。

## 9. 弹跳

```json
{
  "bounce": {
    "enable": true,
    "maxCount": 3,
    "restitution": 0.55,
    "friction": 0.2,
    "explodeOnFinalBounce": true
  }
}
```

可配置每次弹跳的伤害、速度和爆炸变化。

## 10. 落地后行为

```text
直接爆炸、生成持续区域、附着、滚动、滑行
分裂小弹、召唤单位、生成陷阱、延时引爆
```

## 11. 落点预警

敌方抛射弹必须显示：

```text
范围形状、剩余时间、伤害类型、中心点、是否跟随
```

表现：

```text
外圈向内收缩
中心脉冲加速
落地前 0.3 秒音效变急
```

## 12. 地形处理

检测：

```text
天花板、墙壁、高台、水面、不可落地区域、动态障碍
```

处理：

```text
提前爆炸、改低弧、修正到最近可落地点、取消施法、转直线
```

## 13. 示例

毒瓶：

```json
{
  "trajectoryType": "Ballistic",
  "ballisticMode": "FixedTime",
  "flightTime": 1.0,
  "gravity": 14,
  "onLand": [{"effect": "SpawnArea", "areaId": "AREA_PoisonCloud"}]
}
```

迫击炮：

```json
{
  "trajectoryType": "Ballistic",
  "ballisticMode": "ApexHeight",
  "apexHeight": 8.0,
  "warningTime": 1.4,
  "onLand": [{"effect": "Explosion", "radius": 4.5}]
}
```
