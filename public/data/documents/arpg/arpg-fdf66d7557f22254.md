# 189 技能与辅助模块高级词条库：投射物、AOE、召唤、控制、引导

## 1. 投射物辅助

```text
分裂辅助：投射物命中时分裂 2 个，伤害降低 20%。
连锁辅助：投射物连锁 +2，单次伤害降低 15%。
穿透辅助：投射物穿透 +3。
返回辅助：投射物到达终点后返回，返回伤害 60%。
远射辅助：投射物飞行越远伤害越高。
```

## 2. AOE 辅助

```text
范围扩大：范围 +35%，伤害 -10%。
集中范围：范围 -25%，伤害 +30%。
持续区域：技能留下持续区域。
爆炸扩散：击杀敌人时产生小爆炸。
重叠限制解除：允许最多 2 个区域重叠命中。
```

## 3. 召唤辅助

```text
额外召唤：召唤数量 +1，但召唤物伤害 -20%。
精英召唤：召唤数量 -1，但召唤物生命和伤害提高。
死亡爆炸：召唤物死亡时爆炸。
继承暴击：召唤物继承玩家 30% 暴击率。
集火标记：召唤物优先攻击被标记目标。
```

## 4. 控制辅助

```text
延长控制：控制时间 +25%。
控制增伤：对被控制敌人伤害 +20%。
控制爆破：控制结束时造成一次伤害。
Boss 转化：对 Boss 控制效果转为韧性伤害。
束缚强化：被束缚敌人受到投射物伤害提高。
```

## 5. 引导辅助

```text
稳定引导：引导期间受到伤害降低。
聚能引导：每层引导使伤害提高。
爆发释放：停止引导时释放一次爆炸。
护盾引导：引导期间护盾回复不中断。
移动引导：引导时可慢速移动。
```

## 6. 辅助模块 UI

辅助模块必须显示：
- 适用技能标签
- 增益
- 代价
- 是否改变技能行为
- 是否新增触发
- 是否影响性能
