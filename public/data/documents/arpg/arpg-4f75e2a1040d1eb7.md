# 技能核心、辅助模块、天赋树、BD 系统

---

## 1. 技能系统目标

本项目技能系统不采用传统“职业固定技能栏”，而采用：

```text
技能核心 + 辅助模块 + 装备标签 + 天赋树 + 触发条件
```

这样玩家可以围绕一个技能做大量变化：

- 火球变成多重投射。
- 火球变成地面燃烧区域。
- 火球击中后分裂。
- 火球不再直接造成伤害，而是召唤火灵。
- 近战技能附带冲击波。
- 召唤物继承玩家装备属性。

## 4. 技能分类

### 4.1 近战攻击

特点：

- 绑定武器动作。
- 受攻击速度影响。
- 命中盒来自武器或技能范围。
- 手感依赖动画前后摇。

示例原创技能：

| 技能 | 机制 |
|---|---|
| 裂地斩 | 向前方扇形斩击，命中地面产生短裂纹 |
| 回环刃舞 | 原地旋转两段，第二段范围更大 |
| 碎甲重击 | 高眩晕，高破甲，前摇长 |
| 影步刺 | 短距离突进到目标身后，背击增伤 |

### 4.2 远程攻击

| 技能 | 机制 |
|---|---|
| 穿云箭 | 高速直线投射物，穿透一个目标 |
| 裂弹弩击 | 命中后爆裂成小弹片 |
| 回旋飞刃 | 飞出后返回，可二次命中 |
| 标记射击 | 对目标施加标记，后续投射物追踪 |

### 4.3 法术

| 技能 | 机制 |
|---|---|
| 余烬弹 | 火焰投射物，命中点燃 |
| 冰棘环 | 自身周围生成冰刺环，冰缓敌人 |
| 雷链 | 在敌人之间弹跳 |
| 虚空脉冲 | 延迟爆炸，造成混沌伤害 |

### 4.4 召唤

| 技能 | 机制 |
|---|---|
| 召唤灰狼 | 近战召唤物 |
| 召唤灯灵 | 远程法术召唤物 |
| 召唤守卫石像 | 坦克召唤物，可嘲讽 |
| 亡骸引爆 | 消耗尸体造成范围伤害 |

### 4.5 光环/姿态

| 技能 | 机制 |
|---|---|
| 铁壁姿态 | 增加护甲，降低移速 |
| 疾风姿态 | 增加移速和闪避，降低格挡 |
| 灼热光环 | 周围敌人持续受火焰伤害 |
| 灵能光环 | 召唤物获得伤害和生命 |

### 5.2 辅助类型

| 辅助 | 效果 |
|---|---|
| 多重投射 | 投射物数量增加，单发伤害降低 |
| 穿透 | 投射物穿透敌人 |
| 连锁 | 投射物命中后跳向附近敌人 |
| 范围扩大 | 范围技能半径增加，消耗增加 |
| 集中爆发 | 范围变小，伤害更多 |
| 持续延长 | Buff/Dot 持续时间增加 |
| 快速施放 | 施法速度增加，消耗增加 |
| 低耗能 | 魔力消耗降低，伤害降低 |
| 暴击强化 | 暴击率与暴击伤害增加 |
| 异常扩散 | 击杀异常敌人时扩散异常 |
| 回血击中 | 击中时回复生命，伤害降低 |
| 护盾转化 | 消耗能量护盾替代魔力 |
| 触发投射 | 近战命中时发射短程波 |
| 自动追踪 | 技能轻微追踪目标，伤害降低 |

## 6. 辅助兼容规则

技能与辅助连接时：

```text
SkillTags 必须包含 AllowedSkillTags 中至少一个
SkillTags 不能包含 BlockedSkillTags
同组辅助不能重复
最终消耗 = 基础消耗 * 所有 CostMultiplier
最终冷却 = 基础冷却 * 所有 CooldownMultiplier
```

示例：

```text
多重投射：Allowed = Projectile，Blocked = Melee, Aura
范围扩大：Allowed = Area，Blocked = ProjectileOnly
持续延长：Allowed = Duration, Buff, Ailment
```

## 7. 技能释放状态机

```text
Ready
  ↓ 输入
CheckCondition
  ↓
PayCost
  ↓
PreCast
  ↓
CastFrame
  ↓
Recovery
  ↓
Cooldown
  ↓
Ready
```

每个阶段都可被标签影响：

- Instant 技能跳过 PreCast。
- Channel 技能循环 CastFrame。
- Movement 技能会接管移动控制器。
- Trigger 技能不由玩家手动释放。

## 8. 天赋树系统

### 8.1 设计目标

天赋树要提供：

- 大量小数值加成。
- 少量核心机制改变。
- 明确路线选择。
- 可重置但有成本。
- 支持不同职业从不同起点进入同一张大树。

### 8.2 PassiveNodeData

```text
NodeId
Name
Description
Position
NodeType: Small / Notable / Keystone / Mastery / JewelSocket
RequiredNodeIds[]
ModifierList[]
Tags[]
Icon
```

### 8.3 节点类型

| 类型 | 说明 |
|---|---|
| Small | 小属性，如 +10 力量、+8% 火焰伤害 |
| Notable | 中型核心，如火焰技能点燃概率提高 |
| Keystone | 改变规则的大节点，有强代价 |
| Mastery | 某类专精的可选节点 |
| JewelSocket | 插入特殊宝珠/符文 |

### 8.4 Keystone 示例

```text
名称：孤注一掷
效果：你的暴击率翻倍，但非暴击伤害降低 40%。
```

```text
名称：空盾契约
效果：受到伤害优先消耗魔力，然后才消耗生命。你的魔力回复降低 30%。
```

```text
名称：寒焰同源
效果：你的火焰伤害可以冰缓，冰霜伤害可以点燃。点燃和冰缓效果降低 25%。
```

## 10. BD 方向样例

### 10.1 火焰点燃流

核心：

- 技能：余烬弹 / 灼热光环。
- 辅助：持续延长、异常扩散、集中爆发。
- 装备：火焰持续伤害、点燃加速、火焰抗性穿透。
- 天赋：点燃伤害、异常效果、元素暴露。

### 10.2 双手重击眩晕流

核心：

- 技能：碎甲重击。
- 辅助：集中爆发、眩晕强化、范围扩大。
- 装备：双手锤、物理伤害、攻击速度、眩晕门槛降低。
- 天赋：护甲压制、重击、Boss 打断。

### 10.3 闪电连锁清图流

核心：

- 技能：雷链。
- 辅助：连锁、快速施放、暴击强化。
- 装备：闪电伤害、暴击、施法速度。
- 天赋：感电效果、连锁次数、能量护盾。

### 10.4 召唤自爆流

核心：

- 技能：召唤灰狼 + 亡骸引爆。
- 辅助：召唤生命、召唤数量、爆炸范围。
- 装备：召唤物死亡触发、召唤物生命、尸体生成。
- 天赋：召唤物继承属性、召唤死亡回复资源。

## 11. 技能 UI 要求

技能面板必须显示：

- 技能核心图标。
- 辅助模块插槽。
- 可连接/不可连接状态。
- 连接后变化说明。
- 最终消耗、冷却、伤害、标签。
- DPS 估算。
- 受哪些装备词条影响。

---

## 12. 验收标准

- 同一个技能至少能做出 5 种不同玩法。
- 辅助模块不是纯加伤，必须改变行为。
- 天赋树能让玩家产生路线选择，而不是无脑点最近伤害。
- 装备、技能、天赋三者必须互相影响。
