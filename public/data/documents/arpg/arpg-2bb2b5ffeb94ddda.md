# 135 伤害受击表现优化总览：HitFeedback 管线

## 1. 文档目的

本批文档用于统一项目中“打击感、受击表现、伤害跳字、材质闪烁、顿帧、击退、击飞、击倒、镜头震动、音效、特效”的完整规则。

目标不是单纯“多加特效”，而是建立一套可配置的 **HitFeedback 表现管线**：

```text
技能命中
→ 伤害计算
→ 生成 HitContext
→ 判定表现强度
→ 触发 UI 跳字
→ 触发受击动作
→ 触发位移/击退/击飞/击倒
→ 触发材质闪烁
→ 触发粒子/VFX
→ 触发音效/SFX
→ 触发顿帧/HitStop
→ 触发镜头震动
→ 记录战斗日志
```

这套系统必须支持：玩家打怪、怪物打玩家、怪物打召唤物、Boss 被打、Boss 打玩家、多段技能、DOT 持续伤害、暴击、破盾、破韧、击退、击飞、击倒、霸体、格挡、闪避、免疫、元素伤害、混合伤害、战士类重击顿帧。

---

## 2. 设计原则

### 2.1 伤害数值和表现分离
伤害计算负责“打多少血”，表现系统负责“看起来有多重”。

同样是 1000 点伤害：
- 普通攻击命中：小跳字 + 轻受击。
- 暴击命中：大跳字 + 强震动 + 短顿帧。
- 重锤技能命中：大跳字 + 强受击 + 后退 + 地面碎屑。
- DOT：小跳字合并 + 无明显受击动作。
- 破盾：护盾破裂特效 + 特殊跳字。
- 破韧：踉跄/跪地/硬直大窗口。

### 2.2 表现由 HitFeedbackProfile 驱动

```text
HitFeedbackProfile
├── FloatingTextProfile
├── HitReactionProfile
├── KnockbackProfile
├── MaterialFlashProfile
├── VFXProfile
├── SFXProfile
├── HitStopProfile
└── CameraShakeProfile
```

### 2.3 表现强度分级

| 强度 | 名称 | 用途 |
|---|---|---|
| 0 | None | DOT、无感伤害、免疫 |
| 1 | Light | 小怪轻攻击、普通小伤害 |
| 2 | Medium | 普通技能命中、常规受击 |
| 3 | Heavy | 重击、暴击、破盾、精英技能 |
| 4 | Massive | Boss 重击、处决、破韧、爆发技能 |

## 3. HitContext 命中上下文

每次命中都生成一个上下文对象，用于驱动所有表现。

```json
{
  "attackerId": "Player_001",
  "targetId": "Monster_SeaBrute_001",
  "skillId": "SK_Warrior_HeavyCleave",
  "damageTotal": 1280,
  "damageTypes": ["Physical", "Fire"],
  "isCritical": true,
  "isBlocked": false,
  "isDodged": false,
  "isImmune": false,
  "isShieldBreak": false,
  "isPoiseBreak": true,
  "hitPoint": [12.4, 1.1, 8.7],
  "hitDirection": [0.6, 0.0, 0.8],
  "targetFacing": [0.0, 0.0, 1.0],
  "hitBodyPart": "Torso",
  "hitStrength": "Heavy",
  "reactionType": "StaggerBack",
  "knockbackDistance": 2.5,
  "hitStopTime": 0.08,
  "cameraShakeId": "Shake_Hit_Heavy"
}
```

必要字段：
- 攻击者、受击者、技能 ID、伤害总量、伤害类型列表。
- 是否暴击、格挡、闪避、免疫、破盾、破韧。
- 命中点、命中方向、目标朝向、命中部位。
- 表现强度、受击动作类型、位移参数、顿帧参数、镜头震动参数。

## 4. 表现系统模块

### 4.1 UI 伤害跳字模块
负责显示伤害数字、区分暴击/普通/DOT/治疗/护盾/免疫、区分元素颜色、在数字前添加元素图标、合并多段小伤害、控制跳字大小/速度/弹性/震动。

### 4.2 受击动作模块
负责判断前后左右受击、轻/中/重受击、霸体、无硬直、硬直、击倒、击飞，并与 Animator 和状态机联动。

### 4.3 位移反应模块
负责击退、击飞、击倒、拉扯、浮空、地面滑行、墙体碰撞中断。

### 4.4 材质反馈模块
负责闪白、元素染色、护盾裂纹、破甲闪烁、受击溶解边缘、Boss 部位闪光。

### 4.5 VFX/SFX/Camera 模块
负责命中特效、元素命中特效、破盾/破韧特效、命中音效、受击音效、镜头震动、屏幕冲击波、HitStop。

---

## 5. 表现优先级

当多个反馈同时触发时，按以下优先级处理：

```text
死亡 > 处决 > 破韧 > 击飞 > 击倒 > 重击退 > 暴击 > 破盾 > 普通受击 > DOT
```

示例：
- 暴击 + 破韧：播放破韧跳字和破韧动作，暴击只影响数字表现。
- 击飞 + 死亡：死亡表现覆盖击飞，除非配置允许“死亡飞出”。
- DOT + 暴击：DOT 默认不暴击；若特殊技能允许，只放大跳字，不触发强受击。

---

## 6. 怪物体型差异

### 6.1 小型怪
可击退、可击飞、可击倒、可被连段控制，受击动作明显。

### 6.2 中型怪
轻击只小硬直，重击可击退，破韧后可击倒，击飞需要特殊技能。

### 6.3 大型怪
不被普通击退，只显示局部受击，破韧后进入短暂大硬直，Boss 血条下显示韧性条。

### 6.4 Boss
普通命中只触发材质/VFX/局部动作，不播放完整小怪式受击打断；破阶段、破韧、弱点击破时触发大表现；Boss 重击玩家时必须有更强镜头与音效反馈。
