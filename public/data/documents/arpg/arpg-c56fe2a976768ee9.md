# 221 装备详情描述排版 UI 优化方案：固定加成、随机加成、套装词条

## 1. 文档目标

当前装备详情面板的问题是：装备拥有固定加成、随机加成、套装效果、传奇机制、打造词条、激活/未激活效果、属性对比等大量信息，如果全部用普通文字堆在一起，玩家很难快速判断装备价值。

本方案目标是让玩家在 1-3 秒内看懂：

```text
这是什么装备
它是什么稀有度
它适合什么流派
它比当前装备强在哪里
哪些属性是固定的
哪些属性是随机 Roll 出来的
哪些是套装效果
哪些套装效果已经激活
哪些还没激活
哪些是传奇机制
哪些是打造词条
哪些词条影响当前技能
哪些词条对当前职业没用
```

### 2.2 推荐显示顺序

装备信息应该按“玩家判断价值”的顺序显示：

```text
名称 / 稀有度
→ 装备类型 / 等级 / 流派标签
→ 快速对比
→ 基础属性
→ 固定隐性属性
→ 随机词条
→ 打造词条
→ 套装效果
→ 传奇机制
→ 当前技能影响
→ 可洗练/打造状态
```

原因：

```text
玩家先判断能不能穿
再判断基础强不强
再判断随机词条好不好
再判断套装/传奇是否有构筑价值
最后判断要不要洗练、打造、替换
```

## 4. 字体大小与层级

### 4.1 字号建议

以 1920×1080 UI 为基准：

| 内容 | 字号 | 字重 | 说明 |
|---|---:|---|---|
| 装备名称 | 28-32 | Bold | 最醒目 |
| 装备类型/等级 | 18-20 | Medium | 次级信息 |
| 区块标题 | 20-22 | Bold | 分区识别 |
| 主要属性数值 | 19-21 | Medium | 重点读取 |
| 普通词条 | 17-18 | Regular | 正文 |
| 词条标签 | 14-15 | Bold | 小胶囊标签 |
| 未激活套装 | 16-17 | Regular | 灰色弱化 |
| 说明/限制 | 15-16 | Regular | 次要说明 |
| 快捷键提示 | 14 | Regular | 底部提示 |

### 4.2 字体层级原则

```text
装备名最大
区块标题次之
核心机制词条比普通词条稍大
负面代价用颜色区分，不必特别大
未激活效果降低透明度
```


## 6.2 快速对比区

### 目的

让玩家不用读完所有词条，也能先判断大概强弱。

### 内容

```text
生命：+80
护甲：-35
火抗：+18%
移动速度：无变化
新增机制：击杀燃烧敌人爆炸
失去机制：投射物分裂
```

### UI 结构

```text
CompareSummary
├── ScoreChange
├── MainStatDeltaGrid
├── MechanicChangeList
└── WarningText
```

### 注意

评分不能只看 DPS，要按职业和当前技能标签加权。

---

## 6.3 基础属性区

显示装备基底属性。

示例：

```text
【基底属性】
护甲 +120
生命 +60
```

规则：
- 使用浅灰色。
- 不用太强的背景。
- 不占随机词条数量。
- 如果基底属性高于同等级平均值，可显示小箭头。

---

## 6.4 固定隐性加成区

显示装备基底自带固定方向。

示例：

```text
【固定加成】
近战受到伤害 -3%
```

规则：
- 使用暗金色。
- 标签写“固定”或“隐性”。
- 帮助玩家理解该基底的定位。
- 不要和随机词条混在一起。

---

## 6.5 随机加成区

随机词条是装备价值核心，必须重点排版。

### 推荐结构

```text
【随机加成】
[前缀] 最大生命 +80
[前缀] 护甲提高 24%
[后缀] 火焰抗性 +18%
[后缀] 受击时反射 60 点物理伤害
```

### 前缀/后缀分组

更高级方案：

```text
【随机前缀 2/3】
最大生命 +80
护甲提高 24%

【随机后缀 2/3】
火焰抗性 +18%
受击时反射 60 点物理伤害
```

### 数值 Roll 品质

可以在词条右侧显示 Roll 质量：

```text
最大生命 +80    T3 / 87%
火焰抗性 +18%   T4 / 62%
```

颜色：

```text
90%-100%：金色
70%-89%：绿色
40%-69%：白色
0%-39%：灰色
```

---

## 6.6 打造词条区

示例：

```text
【打造加成】
[打造] 移动速度 +8%
```

规则：
- 使用青绿色。
- 加锤子图标。
- 显示“可替换”或“已锁定”。
- 如果没有打造词条，显示一个弱提示：

```text
可添加 1 条打造词条
```

---

## 6.7 套装效果区

套装区必须把已激活和未激活分开。

### 示例

```text
【套装：亡骨契约 3/5】

已装备：
✓ 头盔
✓ 胸甲
✓ 手套
× 鞋子
× 腰带

【3件套 已激活】
召唤物数量 +1
召唤物生命 +20%

【5件套 未激活】
召唤物死亡时爆炸，造成其最大生命 18% 的火焰伤害
```

### 颜色

```text
已激活：绿色高亮
未激活：灰色，透明度 55%
已装备部位：绿色勾
未装备部位：灰色叉
```

### 交互

鼠标悬停未装备部位时：

```text
显示该部位可能掉落来源
```

例如：

```text
亡骨契约·鞋子
掉落：亡骨圣所、终局裂隙、套装兑换
```

---

## 6.8 传奇机制区

传奇机制必须视觉上最特殊，但不能压过装备名。

示例：

```text
【传奇机制】
击杀燃烧敌人时，爆炸会继续点燃附近敌人。
冷却：0.25 秒

【代价】
冰冷抗性 -15%
```

规则：
- 传奇机制使用橙色背景。
- 代价使用红色背景。
- 机制词条要用完整句子。
- 如果有冷却、概率、限制，必须显示。

---

## 6.9 当前技能影响区

这个区块能极大提升可读性，特别适合复杂 ARPG。

示例：

```text
【影响当前技能】
✓ 火焰斩：击杀爆炸可触发
✓ 火球：火焰伤害提高
× 毒云：不是火焰技能，不受该词条影响
```

显示规则：
- 适用技能绿色。
- 不适用技能灰色。
- 只显示当前装备栏中绑定的技能。
- 默认折叠，按 Alt 展开详细。

---

## 6.10 可操作状态区

显示装备后续培养空间。

```text
前缀：2/3
后缀：2/3
可添加打造词条
可重 Roll 数值
可锁前缀
未腐化
```

如果不可操作：

```text
已腐化：不可普通洗练
传奇机制：不可替换
套装ID：不可改变
```



## 10. 装备对比排版

当鼠标悬停背包装备时，旁边显示当前已装备装备对比。

```text
左：当前装备
右：悬停装备
```

或：

```text
主面板显示悬停装备
右侧小浮窗显示与当前装备差异
```

### 对比内容

```text
主要属性变化
生存属性变化
输出属性变化
抗性变化
机制变化
套装变化
```

### 套装变化特殊显示

```text
装备后：
亡骨契约 2/5 → 3/5
将激活 3件套：召唤物数量 +1
```

这个提示非常重要，能让玩家知道“单件装备本身不强，但能激活套装”。

## 11. 鼠标交互与反馈

### 11.1 鼠标悬停

### 11.3 右键装备

```text
右键：装备 / 卸下

```

## 12. 装备锁定与洗练状态显示

装备锁定：

```text
装备名旁显示锁图标
被锁定装备不能分解、出售、洗练
```

词条锁定：

```text
被锁词条行右侧显示小锁
锁定词条背景更深
洗练预览时不会被替换
```

洗练预览：

```text
旧词条：灰色删除线
新词条：绿色高亮
风险提示：红色警告
```

## 19. 验收标准

```text
固定加成和随机加成必须分区显示。
套装已激活和未激活必须视觉区分。
传奇机制必须独立高亮。
负面代价必须红色提示。
打造词条必须有锤子图标和特殊颜色。
随机词条必须显示前缀/后缀来源。
套装进度必须显示缺失部位。
装备对比必须能显示机制变化，不只显示数值变化。
当前技能影响必须能显示适用/不适用。
Tooltip 高度必须自适应，超长时可滚动。
```
