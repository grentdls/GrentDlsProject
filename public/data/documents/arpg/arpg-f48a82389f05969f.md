- 武器
- 盾牌
- 法杖
- 弓
- 弩
- 腰包
- 药瓶
- 背包
- 翅膀
- 尾巴
- 头饰
- 项链
- 护符
- 宠物挂件
- 武器挂饰
- 光环特效

## 4. 偏移配置

挂件必须支持：

```text
localPosition
localEuler
localScale
```

### 4.1 为什么需要偏移
不同模型的原点不一定一致，比如：
- 剑柄原点在中心
- 法杖原点在底部
- 弓原点在握把
- 背包原点在底部
- 头饰原点在中心

所以必须给每个挂件独立偏移。

## 5. 显隐规则

字段：

```json
{
  "showInTown": true,
  "showInCombat": true,
  "showInCutscene": false,
  "hideWhenSheathed": false,
  "hideInLowLOD": true,
  "hideWhenHelmetClosed": true
}
```

常见规则：
- 武器在城镇可背在背上，战斗时在手上。
- 弓箭可在非战斗挂背部。
- 盾牌可在非战斗挂背部，战斗挂左手。
- 头饰在戴全封闭头盔时隐藏。
- 翅膀在 UI 预览中显示，战斗中可关闭低配显示。

## 6. 拔出/收起武器

武器需要支持多挂点切换。

```json
{
  "weaponSheathConfig": {
    "combatSocket": "Weapon_R",
    "sheathedSocket": "Back",
    "drawAnimationEventFrame": 12,
    "sheathAnimationEventFrame": 18,
    "combatOffset": {
      "position": [0.02, -0.01, 0.04],
      "euler": [0, 90, 0]
    },
    "sheathedOffset": {
      "position": [0.1, 0.2, -0.12],
      "euler": [20, 0, 45]
    }
  }
}
```

流程：
```text
进入战斗
→ 播拔武器动画
→ 第 N 帧从 Back Socket 移到 Weapon_R
→ 开启武器 Trail / Hitbox
```

## 8. 挂件带特效

挂件可以带：
- 常驻 VFX
- Trail
- 点光源
- 声音循环
- 物理摆动

```json
{
  "attachmentVfx": [
    {
      "vfxId": "VFX_Sword_FireAura",
      "socket": "Blade",
      "attach": true,
      "showOnlyInCombat": true
    }
  ]
}
```

---

## 9. 验收标准

- 武器能挂在手上。
- 武器能在收起时挂背上。
- 挂件可配置偏移、旋转、缩放。
- 双持武器能正确挂左右手。
- 头饰/背饰/腰饰能挂在对应 Socket。
- 低 LOD 可以隐藏高成本挂件。
