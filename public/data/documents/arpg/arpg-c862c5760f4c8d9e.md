# 272 敌人刷新判定规则：全部清除、间隔、波次与状态保存

## 1. 刷新模式

```text
Never
AfterAllDead
AfterAliveBelowThreshold
FixedInterval
AfterPlayerLeavesAndReturns
AfterCooldownAndAreaClear
WaveSequence
ManualTrigger
```

## 2. 全部清除后刷新

用户需求的默认区域模式：

```text
生成器创建的所有怪物死亡或回收
→ AliveCount == 0
→ 进入 RespawnCooldown
→ 等待 RespawnDelay
→ 检查玩家位置和生成条件
→ 开始下一轮生成
```

注意：只统计该生成器拥有的敌人，不统计区域里其他生成器的怪。

## 3. 存活阈值刷新

```text
AliveCount <= Threshold
```

例如：

```text
初始 10 只
低于 3 只时补怪
最多补到 10 只
```

适合持续战斗区域，不适合普通房间。

## 4. 固定时间刷新

```text
每 30 秒尝试刷新
```

必须同时检查：

```text
MaxAliveCount
玩家安全距离
区域是否激活
是否正在生成
```

## 5. 离开后返回刷新

流程：

```text
玩家清理或离开区域
→ 离开时间达到 ResetDelay
→ 标记区域可刷新
→ 玩家再次进入
→ 重新生成
```

适合开放世界和资源区域。

## 6. 波次模式

```text
Wave 1 清除
→ 等待 3 秒
→ Wave 2
→ 清除
→ Wave 3 Boss
→ 完成遭遇
```

每波可配置：

```text
独立 EnemySpawnList
生成数量
等级
延迟
入场方式
完成动作
```

## 7. 最大刷新次数

```text
MaxRespawnCount = -1：无限
MaxRespawnCount = 0：不刷新
MaxRespawnCount = N：最多 N 次
```

## 8. 玩家距离条件

默认推荐：

```text
RespawnOnlyWhenPlayerAway = true
MinPlayerDistance = 8-15 米
```

避免敌人在玩家视野中心凭空出现。

可选入场方式：

```text
地下钻出
传送门出现
高空落下
雾中生成
房间门后生成
```

## 9. 敌人逃离和失踪

如果敌人未死亡但离开有效区域：

```text
超过最大距离
卡死
跌出地图
长时间不可到达
```

处理方式：

```text
传回区域
判定为失效并回收
继续计入存活数
```

默认建议：超过范围并持续 10 秒后回收，通知生成器减少存活数。

## 10. 死亡通知

敌人生成后绑定：

```text
OnDeath
OnDespawn
OnPoolReturn
OnInvalidated
```

无论死亡还是异常回收，都必须只结算一次。

## 11. 状态保存

模式：

```text
None
SessionOnly
SceneSave
PermanentClear
```

Boss、任务怪：

```text
PermanentClear
```

普通刷怪区：

```text
SessionOnly 或 None
```

## 12. 场景卸载

场景卸载时：

```text
停止计时器
取消待生成任务
解绑敌人事件
回收对象
保存必要状态
```

## 13. 刷新竞态保护

需要：

```text
IsSpawning
RespawnToken
SpawnGenerationId
```

防止多个死亡事件同时触发两次刷新。

## 14. JSON 示例

```json
{
  "respawnMode": "AfterAllDead",
  "respawnDelay": 15,
  "maxRespawnCount": -1,
  "respawnOnlyWhenPlayerAway": true,
  "minPlayerDistance": 10,
  "saveMode": "SessionOnly"
}
```
