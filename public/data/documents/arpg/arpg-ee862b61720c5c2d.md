# 141 命中特效、音效、镜头震动规则：VFX / SFX / CameraShake

## 1. 设计目标

命中特效、音效和镜头震动负责把“命中事件”转化为感官冲击。

它们必须与伤害强度一致：
- 小伤害：轻提示。
- 普通伤害：明确命中。
- 暴击/重击：强冲击。
- Boss 大招：压迫感。
- DOT：低频持续反馈。

---

## 2. VFX 命中特效分类

### 2.1 按伤害类型
- VFX_Hit_Physical_Slash
- VFX_Hit_Physical_Blunt
- VFX_Hit_Fire
- VFX_Hit_Cold
- VFX_Hit_Lightning
- VFX_Hit_Poison
- VFX_Hit_Shadow
- VFX_Hit_Holy

### 2.2 按强度
- Tiny
- Light
- Medium
- Heavy
- Massive

### 2.3 按命中材质
可选：
- Flesh
- Armor
- Bone
- Stone
- Metal
- Wood
- Shield

不同材质改变粒子：
- 金属：火花。
- 木头：碎屑。
- 石头：尘土。
- 血肉：冲击雾/红色粒子。
- 护盾：能量波纹。

---

## 3. VFX 放置规则

### 3.1 位置
默认放在命中点 `hitPoint`。

### 3.2 方向

```text
rotation = LookRotation(-hitDirection)
```

### 3.3 贴合表面

```text
rotation = LookRotation(surfaceNormal)
```

### 3.4 大型 Boss
Boss 使用部位挂点：
- HeadHitPoint
- ChestHitPoint
- LeftArmHitPoint
- RightArmHitPoint
- WeakPointHitPoint

---

## 4. SFX 音效规则

### 4.1 音效组成
一次命中可由多层音效组成：

```text
WeaponImpactLayer
+ BodyImpactLayer
+ ElementLayer
+ CriticalLayer
+ EnvironmentLayer(optional)
```

示例：战锤火焰暴击命中铁甲敌人：

```text
Blunt_Heavy
+ Armor_Impact
+ Fire_Burst
+ Critical_Clang
```

### 4.2 音效强度
- 普通命中：短促。
- 暴击：增加高频冲击。
- 重击：增加低频。
- 破盾：玻璃/能量碎裂。
- 破韧：沉重断裂感。

---

## 5. 镜头震动规则

### 5.1 震动等级

| 等级 | 用途 |
|---|---|
| Shake_None | DOT / 远处小伤害 |
| Shake_Light | 普通命中 |
| Shake_Medium | 暴击 / 中型技能 |
| Shake_Heavy | 重击 / 破盾 |
| Shake_Massive | Boss 大招 / 破韧 / 爆炸 |

### 5.2 玩家视角规则
玩家造成伤害：
- 普通命中可不震。
- 暴击轻震。
- 战士重击中震。
- 处决/破韧强震。

玩家受到伤害：
- 普通伤害轻震。
- 精英技能中震。
- Boss 大招强震 + 屏幕边缘提示。

### 5.3 防晕规则
镜头震动必须可在设置中降低或关闭。

```text
Camera Shake: 0% / 25% / 50% / 75% / 100%
```

---

## 6. 屏幕反馈

### 6.1 玩家受伤
- 屏幕边缘红色闪烁。
- 来袭方向箭头。
- 低血量时红色呼吸边框。
- 重击时短暂暗角。

### 6.2 Boss 大招
- 预警圈。
- 屏幕轻微拉近。
- 地面冲击波。
- 命中后强震和低频音效。

---

## 7. 配置字段

```json
{
  "vfxProfile": {
    "hitVfxId": "VFX_Hit_Fire_Heavy",
    "spawnAtHitPoint": true,
    "attachToTarget": false,
    "scaleByDamage": true,
    "lifeTime": 1.2
  },
  "sfxProfile": {
    "impactSfxId": "SFX_Impact_Blunt_Heavy",
    "elementSfxId": "SFX_Fire_Burst",
    "criticalSfxId": "SFX_Crit_Metal",
    "volume": 0.9,
    "pitchRandom": 0.08
  },
  "cameraShakeProfile": {
    "shakeId": "Shake_Heavy",
    "amplitude": 0.7,
    "frequency": 18,
    "duration": 0.18
  }
}
```

---

## 8. 对象池
VFX 必须对象池：
- HitVFXPool_Physical
- HitVFXPool_Element
- HitVFXPool_Crit
- HitVFXPool_Shield
- HitVFXPool_Boss

---

## 9. 验收标准
- 火冰雷毒等命中特效差异明显。
- 暴击音效和普通命中不同。
- Boss 重击命中玩家有明显镜头反馈。
- 频繁命中不会造成 VFX 大量 Instantiate。
- 镜头震动支持设置关闭或降低。
