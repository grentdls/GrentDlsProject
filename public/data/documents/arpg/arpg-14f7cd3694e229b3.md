## 3. 框体样式库

### 3.1 Main Panel
用途：大面板、主要详情页。
- 深色半透明底
- 强边框
- 标题条
- 内边距大

### 3.2 Section Panel
用途：详情页内部模块。
- 中深底色
- 细边框
- 标题条较短
- 内边距中等

### 3.3 Compare Panel
用途：对比信息。
- 左右分栏
- 中央可显示箭头或差值
- 提升/下降色彩明确

### 3.4 Warning Panel
用途：不可用条件、危险确认。
- 深红底或红边框
- 图标警示

### 3.5 Hint Panel
用途：风味描述、操作提示、说明。
- 低权重背景
- 弱边框
- 小字号

## 4. 标签样式库 Chip System
标签用于替代纯文字分类。

### 4.1 标签种类
- TypeChip：主动 / 辅助 / 保留 / 触发
- DamageChip：火 / 冰 / 雷 / 物理 / 毒 / 暗影
- BuildChip：近战 / 远程 / 法术 / 召唤 / 暴击 / DoT
- StateChip：已学习 / 已装备 / 可升级 / 不可用
- RequirementChip：等级需求 / 属性需求 / 前置需求

### 4.2 视觉规则
- 胶囊形或小矩形
- 左图标 + 文本
- 不同芯片大小统一规范

## 10. 验收标准
- 同类信息必须使用同类样式。
- 色彩语义不能冲突。
- 所有 Tooltip 都基于同一个 Base 样式扩展。
- 所有详情页必须由 Section Panel 拼装，不可硬写整页。
