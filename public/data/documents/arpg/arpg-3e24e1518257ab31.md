# 230 投射物轨迹配置编辑器、JSON、Prefab 与制作清单

## 1. 编辑器入口

```text
Tools / Game / Projectile Trajectory Editor
```

支持：

```text
轨迹类型选择、速度曲线、转向曲线、贝塞尔控制点
螺旋参数、抛射参数、阶段列表、碰撞预览、落点预览
多枚编队、目标移动模拟、JSON/SO 导出
```

## 2. 编辑器布局

```text
TopToolbar：选择、保存、校验、导出、播放
LeftPanel：基础、轨迹、目标、碰撞、阶段
CenterPreview：起点、目标木桩、轨迹 Gizmo、落点、碰撞
RightInspector：速度、转向、曲线、抛射、返回、视觉
```

## 3. ProjectileDefinition

```json
{
  "projectileId": "PROJ_HomingSpiral_Fire",
  "prefabPath": "Assets/Projectiles/PF_HomingSpiral_Fire.prefab",
  "trajectoryProfileId": "TRAJ_HomingSpiral_01",
  "collisionProfileId": "COL_Projectile_Small",
  "hitProfileId": "HIT_FireProjectile",
  "visualProfileId": "VIS_FireSpiral"
}
```

## 4. 多阶段轨迹示例

```json
{
  "trajectoryProfileId": "TRAJ_HomingSpiral_01",
  "trajectoryType": "Composite",
  "arrivalMode": "TimeBased",
  "flightTime": 1.6,
  "stages": [
    {"stageId": "Launch", "type": "Linear", "duration": 0.25, "speed": 8},
    {"stageId": "Track", "type": "SpiralHoming", "duration": 1.0,

    {"stageId": "Terminal", "type": "DirectDash",
     "trigger": "DistanceToTarget<2.5", "speed": 24}
  ]

```

## 7. 校验规则

```text
飞行时间 > 0
最大速度 >= 最小速度
贝塞尔控制点存在
抛射落点可达
分裂代数有限
返回目标存在
阶段持续时间不冲突
目标丢失有 fallback
高威胁敌方投射物配置预警
```

## 8. 开发顺序

### 阶段 A

```text
直线、平滑跟踪、预测跟踪、固定时间到达
固定重力抛射、固定时间抛射
```

### 阶段 B

```text
螺旋、二次/三次贝塞尔、波浪、蛇形
```

### 阶段 C

```text
返回、环绕、地面爬行、天降、多阶段、蜂群
```

### 阶段 D

```text
穿透、弹射、连锁、分裂、附着、爆炸
```

### 阶段 E

```text
编辑器轨迹预览、控制点、速度曲线、目标模拟、导出
```

## 9. 第一版最小闭环

```text
直线
平滑跟踪
预测跟踪
固定时间到达
螺旋跟踪
贝塞尔飞弹
固定时间抛射
指定最高点抛射
落点预警
返回投射物
穿透、分裂、爆炸
轨迹编辑器预览
```

## 10. 验收标准

```text
跟踪弹不再机械直线拐弯
可固定时间到达目标
螺旋可配置半径、转速和收束
贝塞尔可配置控制点和目标更新方式
抛射弹准确落到目标位置
目标丢失后不原地绕圈
多枚飞弹不完全重叠
高伤敌方投射物有清晰预警
装备、天赋、辅助模块可按轨迹标签修改
```
