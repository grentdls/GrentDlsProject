# 220 装备物品库数据结构与配置导入规则

## 1. 装备库数据结构

本批所有装备可以进入统一的 `ItemDefinition` 和 `EquipmentInstance` 配置体系。

```json
{
  "itemId": "UNI_002",
  "displayName": "焚城指环",
  "slot": "Ring",
  "rarity": "Legendary",
  "requiredLevel": 75,
  "buildTags": ["Fire", "Burning", "OnKill", "Explosion"],
  "baseStats": [
    {"stat": "FireResistance", "value": 25}
  ],
  "fixedAffixes": [
    {"stat": "BurningDamage", "valueRange": [20, 35]}
  ],
  "uniquePower": {
    "trigger": "OnKill",
    "condition": "TargetHasBurning",
    "effect": "ExplosionApplyBurning",
    "cooldown": 0.25
  },
  "drawbacks": [
    {"stat": "ColdResistance", "value": -15}
  ]
}
```

## 2. 随机装备实例

```json
{
  "instanceId": "EQ_DROP_000001",
  "itemId": "ARM_023",
  "rolledAffixes": [
    {"affixId": "AFF_Life_T3", "value": 78},
    {"affixId": "AFF_FireRes_T4", "value": 18},
    {"affixId": "AFF_OnTakeHit_Reflect_T3", "value": 60}
  ],
  "quality": 12,
  "lockedAffixes": [],
  "craftedAffix": null
}
```

## 3. 导入规则

```text
ItemDefinition：配置装备模板
EquipmentInstance：运行时掉落实例
SetDefinition：套装效果
UniqueDefinition：传奇机制
AffixDefinition：随机词条
DropBiasTable：副本掉落倾斜
```

## 4. 校验规则

导入时必须检查：

```text
ID 是否重复
部位是否合法
稀有度是否合法
套装部件是否完整
传奇机制是否有触发限制
低阶装备是否没有过强机制
随机词条数量是否符合稀有度
词条池是否符合部位限制
互斥词条是否冲突
```

## 5. 第一版推荐导入顺序

```text
1. 低阶过渡装备
2. 武器和防具基础稀有装备
3. 戒指项链触发装备
4. 3件/5件套
5. 传奇装备
6. 副本掉落倾斜
```
