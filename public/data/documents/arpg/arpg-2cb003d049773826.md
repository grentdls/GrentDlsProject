# 职业设计：长弓游侠

> 参考边界：本项目参考暗黑刷宝 ARPG 的系统结构：职业起点、主动技能、辅助模块、保留技能、触发技能、巨型被动树、职业专精树、装备词条联动、Boss 机制与终局构筑。
> 不直接复制任何商业游戏的职业名、技能名、图标、数值、UI截图、专有词条与怪物设定。下面所有职业、技能、天赋节点、数值区间、特效表现均为项目原创，用于 Unity 原型和后续美术/程序落地。

## 1. 职业基础

```text
职业名：长弓游侠
职业ID：CLASS_RANGER_BOW
参考方向：敏捷远程、弓箭、元素箭、机动、陷阱
主属性：敏捷主属性，智慧支持元素与陷阱，力量只满足装备
推荐武器：长弓、短弓、轻弩、箭袋
核心定位：远距离风筝、箭雨清图、弱点标记、陷阱控场。
职业资源：专注：保持移动、闪避和远程命中获得；站桩会下降。用于强化射击。
职业手感：轻快、拉扯、翻滚射击，强调 3D 空间中的走位。
```

## 2. 战斗定位

长弓游侠 的设计目标不是简单复制某个原版职业，而是把同类 ARPG 的职业定位转成 3D ACT 可操作角色。

### 2.1 适合玩家

- 喜欢明确战斗节奏的玩家。
- 喜欢通过装备、技能和天赋组合出不同 BD 的玩家。
- 可以接受技能不是固定职业技能，而是“职业推荐 + 全局可学习”的玩家。

### 2.2 职业优势

```text
清图能力：中
Boss能力：中高，取决于 BD
生存能力：与装备和天赋强相关
操作难度：由技能组合决定
装备依赖：中高
```

### 2.3 职业短板

- 跨属性构筑成本较高。
- 如果只堆伤害，防御会明显不足。
- 技能需要和武器标签匹配，否则不能释放或表现不完整。

## 8. 职业天赋节点方向

- 投射物速度、远距离伤害、暴击率、闪避、移动时伤害、陷阱触发半径
- 标记效果、穿透数量、箭雨范围、元素异常几率
- 翻滚后增伤、未被命中叠专注、弓技能耗蓝降低

### 8.1 小节点

```text
+5 主属性
+4% 对应武器伤害
+3% 对应防御属性
+2% 技能释放速度/攻击速度
+5% 职业资源获得
```

### 8.2 中节点

```text
对应技能标签伤害提高 12%
对应异常状态积累提高 15%
对应防御机制提高 10%
职业资源上限 +1 段
核心技能冷却恢复 +8%
```

### 8.3 大节点

大节点必须改变玩法，不只是加数值。例如：

```text
某类技能变成可移动释放
某类技能消耗职业资源获得新效果
某类防御成功后触发反击
某类异常状态达到满层后爆炸
某类召唤物继承玩家某个词条
```

## 12. 第一阶段开发技能

第一阶段只做 4 个技能，避免动画和 VFX 失控：

```text
主输出技能：穿云箭
范围清图技能：散星射击
位移/防御技能：寒霜箭雨
职业资源技能：爆裂箭
```

验收标准：

- 能装到技能栏。
- 能被辅助模块改变至少 2 个参数。
- 有 Hitbox、伤害、状态、VFX、SFX。
- 能在职业 UI 上显示资源变化。
- 至少有 1 个天赋节点能改变该技能逻辑。
