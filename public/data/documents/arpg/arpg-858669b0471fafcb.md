# 196 高级数值与词条扩展制作清单与验收标准

## 1. 阶段目标

继续扩展数值玩法和词条玩法，让游戏形成更多可刷、可搭配、可平衡的构筑路线。

## 2. 优先制作内容

第一批优先：

```text
近距离增伤
远距离增伤
连击层数
蓄力层数
低血增伤
满盾增伤
破盾狂热
溢出治疗转护盾
物理转火焰
燃烧击杀爆炸
冻结碎裂
感电连锁
中毒层数爆发
流血血爆
诅咒扩散
冷却刷新
技能充能
药剂爆发
```

## 3. 装备接入

任务：
- 新增武器高级词条池。
- 新增防具高级词条池。
- 新增首饰高级词条池。
- 新增传奇词条。
- 新增套装词条。

验收：
- 武器可刷出距离、连击、蓄力词条。
- 防具可刷出低血、满盾、反伤词条。
- 首饰可刷出转化、异常联动词条。
- 传奇能改变构筑规则。

## 4. 技能接入

任务：
- 技能增加距离/蓄力/引导支持。
- 投射物支持飞行距离计算。
- AOE 支持重叠限制。
- 控制支持 Boss 换算。
- 召唤物支持继承与触发限制。

验收：
- 远距离投射物增伤生效。
- 蓄力技能按档位增强。
- 引导技能按层数增强。
- Boss 控制不会无限控。

## 5. 天赋接入

任务：
- 新增关键节点。
- 新增职业专精高级节点。
- 新增代价型节点。
- 天赋详情显示影响预览。

验收：
- 关键节点能改变规则。
- 天赋和装备词条能联动。
- 天赋能显示当前适配技能。

## 6. 地图和怪物接入

任务：
- 新增地图词缀。
- 新增怪物反制词缀。
- 新增 Boss 数值限制。
- 奖励倾斜接入掉落池。

验收：
- 地图词缀能改变刷图体验。
- 高风险词缀有更高奖励。
- Boss 不会被无限控制或秒杀。

## 7. 最终验收

- 至少支持 20 个明确 BD 方向。
- 不出现无限递归触发。
- 不出现无限召唤。
- 不出现 Boss 被永久控制。
- UI 能看懂词条条件和效果。
- 性能在大量触发时可控。
