# 253 符石系统核心规则：品质、等级、插槽、兼容与绑定

## 1. 品质

| 品质 | 颜色 | 定位 | 效果复杂度 |
|---|---|---|---|
| 普通 | 灰白 | 前期补属性 | 单一基础数值 |
| 精良 | 蓝色 | 中期过渡 | 百分比或双属性 |
| 稀有 | 金色 | 流派成型 | 条件增益 |
| 史诗 | 紫色 | 深度构筑 | 触发和复合机制 |
| 传奇 | 橙色 | 玩法改变 | 独特规则与限制 |
| 神器 | 红金 | 终局核心 | 强规则改变和代价 |

---

## 2. 等级

品质与等级分开：

```text
品质决定机制复杂度
等级决定数值强度和使用需求
```

等级段：

```text
I：需求等级 1
II：需求等级 15
III：需求等级 30
IV：需求等级 50
V：需求等级 70
VI：需求等级 85
```

---

## 3. 数值 Roll

每枚符石可配置：

```text
最小值
最大值
当前值
Roll 百分比
```

示例：

```text
最大生命 +30 至 +40
当前值 +38
Roll 质量 95%
```

---

## 4. 插槽类型

### 通用孔

可镶嵌所有非专属符石。

### 攻击孔

```text
伤害、穿甲、暴击、攻速、投射物、元素附伤
```

### 防御孔

```text
生命、护甲、护盾、抗性、格挡、闪避、减伤
```

### 技巧孔

```text
移动、资源、冷却、药剂、控制、掉落球
```

### 召唤孔

```text
召唤物、御剑、环绕法球、伙伴
```

### 共鸣孔

```text
传奇符石、神器符石、套装共鸣、组合符石
```

## 5. 装备孔位上限

| 部位 | 基础上限 | 推荐孔型 |
|---|---:|---|
| 单手武器 | 2 | 攻击、通用 |
| 双手武器 | 3 | 攻击、攻击、通用 |
| 盾牌 | 2 | 防御、通用 |
| 法器/箭袋 | 2 | 技巧、攻击 |
| 头盔 | 2 | 技巧、召唤 |
| 胸甲 | 3 | 防御、防御、通用 |
| 手套 | 2 | 攻击、技巧 |
| 鞋子 | 2 | 技巧、防御 |
| 腰带 | 1 | 技巧 |
| 戒指 | 1 | 通用 |
| 项链 | 1 | 共鸣或通用 |

特殊装备可突破，但必须由传奇机制或终局铁匠服务明确提供。

---

## 6. 部位兼容

```text
移动速度：鞋子、腰带
格挡：盾牌、胸甲
投射物数量：弓、弩、箭袋、项链
召唤物数量：头盔、法杖、项链、召唤孔
环绕法球数量：法器、项链、共鸣孔
御剑数量：武器、头盔、项链、召唤孔
```

---

## 7. 唯一规则

```text
Unlimited：不限数量
OnePerItem：单件最多一枚
OnePerCharacter：全身最多一枚
OnePerCategory：同系列最多一枚
UniqueEquipped：同名传奇唯一
```

---

## 8. 叠加规则

```text
Add：加算
Increase：同类增幅加算
More：独立乘算，只用于高阶
HighestOnly：只取最高值
SharedCooldown：共用触发冷却
IndependentCooldown：独立冷却
```

---

## 9. 状态

第一版不做传统耐久消耗，使用状态：

```text
正常
裂纹
绑定
锁定
已镶嵌
未鉴定
```

---

## 10. 强化

可选：稀有以上符石支持 +1 至 +5。

```text
强化只提高数值
不改变品质
不改变机制
```

## 12. 属性结算顺序

```text
装备基底
→ 品质
→ 强化
→ 固定词条
→ 随机词条
→ 打造词条
→ 套装效果
→ 符石基础数值
→ 符石机制
→ 天赋
→ Buff
→ 最终属性
```

## 13. 作用范围

```text
Local：只影响该装备基底
Global：影响角色全局
SkillTag：只影响匹配技能
Trigger：提供触发事件
SetLink：套装激活时生效
```

---

## 14. 冲突

```text
无法暴击 与 暴击率符石冲突
投射物不能穿透 与 穿透符石冲突
生命回复转护盾 时，生命回复符石先转换再结算
```

UI 必须明确显示冲突，不能让符石静默失效。
