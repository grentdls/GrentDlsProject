# 199 装备稀有度与词条数量规则：普通、魔法、稀有、套装、传奇

## 1. 稀有度目标

稀有度不只是颜色变化，而是决定：

```text
词条数量
词条等级
是否有套装ID
是否有传奇机制
是否可洗练
是否可打造
掉落稀有度
UI 展示层级
```

---

## 2. 稀有度表

| 稀有度 | 随机词条 | 固定机制 | 可洗练 | 可打造 | 定位 |
|---|---:|---|---|---|---|
| 普通 | 0 | 基底 | 可升级 | 可 | 材料胚子 |
| 魔法 | 1-2 | 基底 + 隐性 | 可 | 可 | 过渡装 |
| 稀有 | 3-5 | 基底 + 隐性 | 可 | 可 | 主力刷装 |
| 套装 | 2-4 | 套装ID + 件数效果 | 部分可 | 可 | 流派组件 |
| 传奇 | 0-3浮动 | 独特机制 | 核心不可洗 | 通常不可 | 玩法改变 |
| 神器 | 4-6 | 终局机制 | 高级重铸 | 可 | 终局追求 |

---

## 3. 普通装备

普通装备只有：
```text
基底属性
部位定位
物品等级
品质
```

用途：
- 作为打造胚子
- 早期过渡
- 商店出售
- 分解材料

---

## 4. 魔法装备

魔法装备有 1-2 个随机词条：

```text
1 个前缀
或 1 个后缀
或 1 前缀 + 1 后缀
```

适合：
- 新手阶段
- 定向刷某个单词条
- 作为打造起点

---

## 5. 稀有装备

稀有装备是刷装主体。

随机词条数量：
```text
最低 3
最高 5
```

推荐分布：
```text
3词条：常见
4词条：较好
5词条：稀有
```

前后缀限制：
```text
最多 3 前缀
最多 3 后缀
总数第一版最多 5
```

示例：
```text
前缀1：生命 +80
前缀2：护甲 +25%
后缀1：火抗 +18%
后缀2：受击反伤 +60
后缀3：低血时减伤 +8%
```

---

## 6. 套装装备

套装装备包含：
```text
基底属性
套装ID
2-4 个随机词条
套装件数效果
套装专属词条池
```

套装装备随机性比稀有装备略低，但提供套装目标。

推荐：
```text
3件套：流派启动
5件套：流派质变
```

---

## 7. 传奇装备

传奇装备不是词条数量多，而是机制特殊。

结构：
```text
固定基础属性
固定传奇机制
1-3 个浮动数值
可能带代价
```

示例：

```text
龙焰戒指
固定：火焰抗性 +25%
传奇：击杀燃烧敌人时，爆炸会继续点燃附近敌人
浮动：燃烧伤害 +20%-35%
代价：冰冷抗性 -15%
```

---

## 8. 词条数量生成规则

掉落时：

```text
roll rarity
→ roll base type
→ roll item level
→ roll implicit
→ roll random affix count by rarity
→ roll prefix/suffix
→ roll affix tier
→ roll affix value
→ apply special rules
```

稀有词条数量权重示例：

```json
{
  "Rare": {
    "affixCountWeights": [
      {"count": 3, "weight": 60},
      {"count": 4, "weight": 30},
      {"count": 5, "weight": 10}
    ]
  }
}
```

---

## 9. UI 显示规则

装备详情中必须分组：

```text
基底属性
隐性属性
随机前缀
随机后缀
打造词条
套装效果
传奇机制
```

不同来源用不同底色和标签区分，避免一大坨文字。
