# 105_药剂商杂货商内容_药剂_消耗品_基础材料_补给经济

> NPC：药剂师·诺姆 / 杂货商·帕奇  
> 目标：提供基础补给、药剂升级、传送耗材、低阶材料和新手容错。

---

## 1. 药剂商定位

药剂商负责：

1. 生命药剂
2. 资源药剂
3. 状态解除药剂
4. 抗性临时药剂
5. 药剂瓶升级
6. 药剂词条洗练，后期开
7. 药草和药剂材料出售

药剂商不是单纯卖红蓝瓶，而是要让玩家围绕不同副本准备补给。

## 4. 药剂瓶升级

### 4.1 药剂瓶属性

| 属性 | 说明 |
|---|---|
| 恢复量 | 总恢复数值 |
| 恢复时间 | 几秒内恢复 |
| 充能上限 | 可使用次数 |
| 每次消耗充能 | 使用成本 |
| 击杀回充 | 击杀怪物恢复充能 |
| 特殊词条 | 如低血时恢复更快 |

### 4.2 升级规则

| 升级阶段 | 条件 | 效果 |
|---|---|---|
| 破旧瓶 | 默认 | 基础恢复 |
| 稳固瓶 | 等级 8 + 药草 | 恢复量提升 |
| 精制瓶 | 第 2 章 + 药剂核心 | 充能上限提升 |
| 炼金瓶 | 第 3 章 + 稀有药剂材料 | 可出现药剂词条 |
| 星纹瓶 | 终局后 | 可洗特殊词条 |

| 材料 | 来源 | 用途 |

## 6. 药剂与杂货的经济限制

### 6.1 避免问题

| 问题 | 处理 |
|---|---|
| 玩家无限买材料强化 | 高阶材料不直接卖，只卖低阶 |
| 玩家跳过掉落成长 | 商店装备只保底，不出毕业词条 |
| 玩家靠药硬吃 Boss | 药剂冷却/充能限制 |
| 材料副本券滥用 | 每日购买限量 |
| 回城石没意义 | 第一版可免费回城，但保留商品位 |

### 6.2 商店限购规则

| 商品 | 限购 |
|---|---|
| 材料副本券 | 每日 2 |
| 低阶重铸卷 | 每日 5 |
| 魔尘小包 | 每日 10 |
| 高级药剂材料 | 每周 3，后期开 |
| 新手装备包 | 角色等级 10 后隐藏 |

## 12. 当前 Unity 实现映射

### 12.1 已接入数据

- 商店表：`Assets/_Game/Resources/GameData/shops.json`
- 商品表：`Assets/_Game/Resources/GameData/shop_items.json`
- 药剂商：`SHOP_A01_POTION`
- 杂货商：`SHOP_A01_MIRA_GENERAL`

### 12.2 已实现功能

- 药剂购买：已配置小/中生命药剂、小/中能量药剂、解毒、清燃、融冰、抗火、抗冰、抗雷、疾行药剂。
- 药剂升级：新增 `PotionUpgradeService` 和 `PotionUpgradeState`，支持生命、能量、解除三类药剂瓶升级。
- 药剂升级材料：苦叶草、血藤根、蓝晶露、净化盐、药剂核心已加入药剂商。
- 杂货补给：回城卷轴、临时传送卷、低阶重铸卷、粗铁碎片包、魔尘小包、材料副本券、新手武器包、防具补给包已加入杂货商。
- 限购：`ShopItemData.DailyLimit` 已接入 `ShopService`，购买会扣减当日次数。
- 隐藏：`ShopItemData.HideAfterLevel` 已接入商品生成，新手包等级 10 后隐藏。
- 发放数量：`ShopItemData.GrantCount` 已接入可堆叠商品发放，材料包可一次给多份材料。
- UI：`ArpgShopWindow` 的药剂页已显示补给商品、药剂瓶阶级、升级预览和升级结果。

### 12.3 第一版保留项

- 药剂实际“使用”效果仍需后续接入快捷栏消耗品使用逻辑。
- 药剂词条洗练、每周高级材料限制、异常解除免疫 Buff 表现待 Buff/药剂使用系统完善后接入。
