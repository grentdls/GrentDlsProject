# 233 御剑系统完整逻辑：无规则环绕、目标选择、发射与返回

## 1. 核心定义

御剑系统与环绕法球不同：

```text
飞剑在玩家周围无规则、但受约束地漂浮。
环绕阶段不以碰撞造成伤害。
系统按攻击间隔选择可用飞剑发射。
飞剑命中目标后返回玩家周围，重新加入御剑群。
```

核心体验：

```text
身边剑群越多，视觉威势越强。
发射节奏清晰，飞剑不是一团同时乱冲。
锁定目标时优先集火。
无锁定目标时智能分配附近目标。
```

## 2. 飞剑状态机

```text
Spawn
→ JoinOrbit
→ OrbitIdle
→ ReservedForAttack
→ Launch
→ Travel
→ Hit / Miss
→ Return
→ Rejoin
→ OrbitIdle
```

特殊状态：

```text
Disabled
Destroyed
Stuck
Empowered
TemporaryExpire
```

每把剑有独立状态，不允许同一把剑被重复调度。

---

## 3. 无规则环绕表现

“无规则”不等于真正随机乱飞，否则会抖动和穿模。

推荐使用：

```text
基础环绕中心
+ 每把剑独立轨道半径
+ 独立高度
+ 独立相位
+ 低频噪声偏移
+ 相互避让
+ 与角色身体保持最小距离
```

每把飞剑的 IdleTarget：

```text
baseOrbitPosition
+ PerlinNoiseOffset
+ breathingOffset
+ separationOffset
```

推荐范围：

```text
半径：1.2~2.8 米
高度：0.6~2.4 米
最小剑间距：0.25~0.45 米
噪声更新频率：0.2~0.8 Hz
```

剑尖朝向可选择：

```text
沿轨迹切线
朝外
朝上
朝锁定目标
随机慢速摆动
```

---

## 4. 剑群分层

御剑数量多时，建议分为多个视觉层：

```text
内层：1~6 把，半径 1.4 米
中层：7~14 把，半径 2.0 米
外层：15~24 把，半径 2.7 米
```

分层规则：

```text
按索引自动分层
每层相位错开
高度略有差异
不采用严格等角排布，保留剑群自然感
```

## 5. 御剑数量结构

```text
BaseSwordCount        技能基础数量
PermanentSwordCount   装备/天赋永久数量
TemporarySwordCount   临时生成数量
EchoSwordCount        仅本次发射的复制剑
MaxSwordCount         常驻上限
MaxTemporaryCount     临时上限
```

推荐：

```text
早期：3~5 把
中期：6~12 把
成型：12~20 把
终局：20~30 把
同屏实体极限需由性能预算决定
```

## 6. 攻击调度器

```text
SwordAttackScheduler
├── AttackInterval
├── VolleySize
├── LaunchPattern
├── SwordSelection
├── TargetSelection
├── ReservationQueue
└── GlobalCooldown
```

核心参数：

```text
attackInterval       每次调度间隔
volleySize           每次发射几把
swordLaunchGap       同一齐射中剑与剑的间隔
maxConcurrentFlying  同时在外飞行的剑数
```

示例：

```text
每 0.6 秒发射 1 把
或每 1.5 秒齐射 4 把，每把间隔 0.08 秒
```

## 7. 飞剑选择

优先选择：

```text
OrbitIdle 状态
离目标方向最近
最长时间未发射
当前未被强化/保留
```

可配置模式：

```text
RoundRobin       轮流发射
NearestToTarget  离目标最近
RandomAvailable  随机可用剑
OldestIdle       空闲最久
ElementPriority  优先某元素剑
```

---

## 8. 目标选择

### 8.1 有锁定目标

```text
锁定目标有效且在最大射程内
→ 优先攻击锁定目标
```

### 8.2 无锁定目标

在搜索半径内选择：

```text
视野前方目标
最近目标
生命最低目标
被标记目标
未被其他飞剑分配的目标
精英/Boss 优先
```

目标评分示例：

```text
score = 距离分 + 正前方分 + 标记分 + 威胁分 - 已分配飞剑惩罚
```

### 8.3 目标分配模式

```text
Focus      全部集火一个目标
Spread     尽量均匀分配
Smart      小怪分散、精英集火
Random     随机目标
```

## 9. 发射轨迹

御剑可复用投射物轨迹系统：

```text
直线冲刺
贝塞尔侧绕
螺旋飞剑
延迟锁定
闪现斩击
从目标上方俯冲
```

发射阶段：

```text
从当前漂浮位置出发
0.05~0.15 秒预备朝向
拖尾开启
加速飞向目标
```

## 10. 命中与返回

命中后可：

```text
立即返回
穿透后返回
在目标身边盘旋一次再返回
插入目标短暂停留
弹射另一个目标后返回
```

返回目标：

```text
角色当前 OrbitAnchor
系统分配的新空闲槽位
```

返回过程：

```text
使用贝塞尔曲线
避免所有剑沿同一线返回
接近玩家时减速
平滑加入 IdleOrbit
```

## 11. 发射增加御剑数量的词条

用户要求的核心词条：发射飞剑时增加自身御剑数量。

必须拆成安全版本：

### 11.1 概率生成临时剑

```text
发射飞剑时，有 20% 概率生成 1 把临时飞剑，持续 8 秒。
最多同时存在 5 把临时飞剑。
```

### 11.2 累计发射生成

```text
每累计发射 6 把飞剑，生成 1 把临时飞剑。
```

### 11.3 齐射复制

```text
每次齐射额外生成 1 把 EchoSword，仅参与本次攻击，命中后消失。
```

### 11.4 永久成长（局内）

```text
每击杀一个精英，御剑数量 +1，持续到本次关卡结束，最多 +5。
```

### 防递归字段

```json
{
  "spawnedSwordTag": "GeneratedSword",
  "canTriggerSameAffix": false,
  "maxTemporarySwordCount": 5,
  "duration": 8.0,
  "triggerDepthLimit": 1
}
```

## 14. 典型技能

### 万剑归流

```text
基础 8 把飞剑
每 0.45 秒发射 1 把
锁定目标时集火
飞剑命中后返回
每累计发射 8 把，生成 1 把临时剑，持续 10 秒，最多 4 把
```

### 剑阵风暴

```text
所有空闲飞剑在 0.8 秒内连续射出
每把剑优先选择不同目标
若只有一个目标则全部集火
技能结束后飞剑依次返回
```
