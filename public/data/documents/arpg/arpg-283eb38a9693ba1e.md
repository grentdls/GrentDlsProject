# 110_主城NPC数据表_商品表_服务表_副本表_示例JSON

> 目标：给程序和策划一套可以直接落地的数据表结构。主城 NPC 的服务、商品、传送、副本、任务、商店刷新都必须数据化。

---

## 1. 表结构总览

| 表名 | 用途 |
|---|---|
| TownNpcTable | 主城 NPC 基础信息 |
| NpcServiceTable | NPC 提供的服务按钮 |
| ShopTable | 商店基础配置 |
| ShopItemTable | 商品配置 |
| ShopRefreshTable | 商店刷新规则 |
| SkillShopTable | 技能商店商品 |
| BlacksmithServiceTable | 铁匠服务 |
| DungeonTable | 副本配置 |
| DungeonDifficultyTable | 副本难度 |
| PotionUpgradeTable | 药剂升级 |
| StashConfigTable | 仓库配置 |
| RuneTable | 符石配置 |
| ExchangeTable | 兑换配置 |
| QuestTable | 任务配置 |
| BountyTable | 悬赏配置 |

## 2. TownNpcTable

### 2.1 字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| npcId | string | 是 | NPC 唯一 ID |
| displayName | string | 是 | 显示名称 |
| npcType | enum | 是 | 类型 |
| prefabPath | string | 是 | Prefab 地址 |
| spawnMarker | string | 是 | 场景出生点 |
| icon | string | 是 | 头顶图标 |
| subtitle | string | 是 | 功能副标题 |
| unlockCondition | string | 是 | 解锁条件 |
| defaultServiceId | string | 否 | 默认服务 |
| showOnMinimap | bool | 是 | 是否小地图显示 |
| priority | int | 是 | HUD 优先级 |

### 2.2 示例 JSON

```json
{
  "npcId": "NPC_BLACKSMITH_001",
  "displayName": "老炉匠·斐洛",
  "npcType": "Blacksmith",
  "prefabPath": "Prefabs/NPC/PF_NPC_Blacksmith",
  "spawnMarker": "Town_Blacksmith_01",
  "icon": "Icon_NPC_Blacksmith",
  "subtitle": "装备强化 / 分解 / 出售",
  "unlockCondition": "Always",
  "defaultServiceId": "SERVICE_BLACKSMITH_SHOP",
  "showOnMinimap": true,
  "priority": 90
}
```

## 11. 表之间的引用关系

```text
TownNpcTable.npcId
    ↓
NpcServiceTable.npcId
    ↓
ShopTable.npcId / uiPrefab
    ↓
ShopItemTable.shopId
    ↓
ItemTable.itemId / SkillTable.skillId / DungeonTable.dungeonId
```

副本传送：

```text
TownNpcTable[NPC_TRANSFER_001]
    ↓
NpcServiceTable[SERVICE_DUNGEON_TELEPORT]
    ↓
UI_DungeonTeleportPanel
    ↓
DungeonTable
    ↓
SceneLoader.Load(sceneName)
```

技能购买：

```text
TownNpcTable[NPC_SKILL_001]
    ↓
ShopTable[SHOP_SKILL_MAIN]
    ↓
SkillShopTable
    ↓
SkillDefinitionTable
    ↓
SkillInventory.Add(skillId)
```

## 12. 配置校验规则

| 校验 | 报错条件 |
|---|---|
| NPC 服务 | npcId 不存在 |
| UI Prefab | uiPrefab 路径为空或文件不存在 |
| 商品 | itemId/skillId 不存在 |
| 解锁条件 | 条件表达式无法解析 |
| 副本 | sceneName 不存在 |
| 日限购 | dailyLimit < -1 |
| 价格 | priceGold < 0 |
| 技能需求 | requiredWeaponTag 与技能标签冲突 |
| 符石 | compatibleSocket 为空 |

---

## 13. 策划填表顺序

1. 先填 `TownNpcTable`
2. 再填 `NpcServiceTable`
3. 商店类 NPC 填 `ShopTable`
4. 商品填 `ShopItemTable` 或 `SkillShopTable`
5. 传送类填 `DungeonTable`
6. 打造类填 `BlacksmithServiceTable`
7. 仓库/符石/兑换分别填对应表
8. 进 Unity 编辑器校验
9. 进主城测试交互
10. 打包前跑全表扫描

|---|---:|
| 主城 NPC | 8 个 |
| NPC 服务按钮 | 30 个以上 |

| 技能商品 | 120 个主动技能 + 15 个辅助模块 + 20 个保留技能 |
| 药剂/杂货商品 | 30 个以上 |
| 副本 | 25 个章节 + 7 个材料 + 5 个挑战 + 5 个 Boss 回战 |
| 符石 | 30 个以上 |
| 悬赏 | 每日 20 条池，周常 10 条池 |

## 15. 验收标准

| 项目 | 标准 |
|---|---|
| 表读取 | 所有 NPC 和服务可从表生成 |
| 商品 | 商品不存在时编辑器报错 |
| 副本 | 场景不存在时不能发布 |
| 技能 | 未配置 SkillDefinition 的技能不能上架 |
| 条件 | 解锁条件可预览结果 |
| UI | 每个服务能跳到正确 UI |
| 存档 | 已购技能、限购次数、解锁状态能存档 |
