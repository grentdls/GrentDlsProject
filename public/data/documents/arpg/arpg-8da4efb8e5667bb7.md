# 202 套装系统设计规则：3件套、5件套、流派套装、混搭

## 1. 套装目标

套装的作用是给玩家明确的流派目标。

套装不能只是：
```text
2件：攻击 +10%
3件：防御 +10%
5件：伤害 +20%
```

而应该强化某个玩法：

```text
穿甲套
召唤套
护盾套
投射物套
火焰爆炸套
控制套
药剂套
反伤套
```

---

## 2. 套装件数结构

本项目推荐 3/5 件套为主。

```text
3件套：流派启动
5件套：流派质变
```

套装常用部位：
```text
头盔
胸甲
手套
鞋子
腰带
```

也可以扩展：
```text
戒指
项链
武器
盾牌
```

但第一版建议套装主件优先使用防具 5 件，避免武器被锁死。

## 4. 穿甲套示例

### 碎甲战铠

部位：
```text
头盔、胸甲、手套、鞋子、腰带
```

3件套：
```text
穿甲 +18%
重击破韧伤害 +20%
```

5件套：
```text
破韧敌人时，下一次重击必定暴击，并造成额外真实伤害。
```

适合：
```text
战士
重击
双手武器
破韧 Boss
```

---

## 5. 召唤套示例

### 亡骨契约

3件套：
```text
召唤物数量 +1
召唤物生命 +20%
```

5件套：
```text
召唤物死亡时爆炸，造成其最大生命 18% 的火焰或暗影伤害。
```

随机套装词条池：
```text
召唤物伤害
召唤物攻击速度
召唤物抗性
召唤物击杀召唤骷髅
```

## 9. 套装混搭规则

允许玩家 3+2、3+3、5+散件。

规则：
```text
3件套给启动
5件套给质变
散件给补词条
传奇装备可以破坏套装完整性但提供更强机制
```

不要让 5件套永远压过散件，否则刷稀有装备没意义。

---

## 10. 套装掉落规则

套装来源：
```text
特定副本
特定 Boss
赛季玩法
地图词缀倾斜
套装兑换
```

掉落建议：
```text
低级副本掉 3件套启动件
高级副本掉 5件完整件
Boss 掉核心套装件
```

## 11. 套装 UI

装备详情显示：
```text
套装名称
已装备件数
未装备件
3件套效果
5件套效果
当前激活效果高亮
```

示例：

```text
碎甲战铠 3/5
✓ 头盔
✓ 胸甲
✓ 手套
× 鞋子
× 腰带

3件套：已激活
穿甲 +18%，重击破韧伤害 +20%

5件套：未激活
破韧敌人时，下一次重击必定暴击
```
