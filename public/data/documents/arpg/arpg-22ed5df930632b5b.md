# 258 NPC 功能 UI 交互方案：商店、镶嵌、合成、强化与预览

## 1. 设计目标

NPC 界面需要让玩家快速理解：

```text
当前在做什么
可以放入什么物品
操作后会得到什么
需要消耗什么
是否有失败风险
失败会损失什么
```

不允许只放一个“确认”按钮，让玩家自己猜结果。

---

## 3. 符石商店

布局：

```text
左侧：商品分类
中间：符石图标网格
右侧：符石详情和当前装备适配
底部：购买数量、价格、购买按钮
```

筛选：

```text
品质
孔型
流派标签
适用部位
已拥有/未拥有
图鉴未收录
可镶嵌当前装备
```

商品卡显示：

```text
符石图标
名称
品质边框
需求等级
价格
限购次数
推荐标记
```

## 4. 镶嵌界面

```text
RuneSocketPage
├── EquipmentInventory
├── SelectedEquipmentPreview
│   ├── 装备图标
│   ├── 当前属性
│   └── 插槽排列
├── RuneInventory
├── SelectedRuneDetail
├── AttributeDeltaPreview
└── ConfirmBar
```

操作：

```text
点击装备 → 显示插槽
拖拽符石 → 兼容孔高亮
悬停孔位 → 显示可用符石
放入后 → 显示属性前后变化
确认后 → 播放镶嵌动画
```

颜色：

```text
兼容孔：绿色
可替换孔：黄色
不兼容孔：红色
空孔：灰色虚线
共鸣孔：紫金色
```

属性预览：

```text
最大生命 1220 → 1260  +40
火焰抗性 63% → 75%  +12%
技能变化：环绕法球数量 3 → 4
冲突：该符石与“无法暴击”机制不兼容
```

## 5. 拆卸界面

显示三种方案：

```text
无损拆卸
低成本拆卸
强行摧毁
```

每个方案显示：

```text
费用
符石结果
装备结果
裂纹概率
是否绑定
```

强行拆卸使用红色按钮，并要求二次确认。

## 7. 批量分解

左侧物品网格，右侧规则：

```text
分解普通以下
分解精良以下
保留高 Roll
保留图鉴未收录
保留锁定
保留当前构筑推荐
```

底部实时显示预计获得：

```text
符石粉尘 ×135
稀有碎片 ×12
传奇碎片 ×1
```

## 8. 铁匠强化界面

```text
EnhancePage
├── EquipmentSlot
├── CurrentEnhanceLevel
├── AttributeBeforeAfter
├── SuccessRate
├── FailureResult
├── PityProgress
├── ProtectionMaterialSlot
└── EnhanceButton
```

核心显示：

```text
铁铸胸甲 +7 → +8
护甲 420 → 445
生命基底 80 → 84
成功率 50%
失败：强化降至 +6
使用稳固粉后：失败不降级
```

强化动画不应阻止快速连续操作。支持：

```text
普通动画
跳过动画
连续强化至指定等级
```

连续强化必须设置：

```text
目标等级
最大花费
是否自动使用保护材料
失败是否停止
```

## 9. 品质界面

显示：

```text
当前品质

每次材料增加值
```

```text
品质 14% → 16%

随机词条不变化
传奇机制不变化
```

```text
├── SocketTypeOptions
├── SuccessRate
```

```text
失败：保留原有孔位，材料消耗
```

## 11. 强化转移界面

左右双装备槽：

```text
源装备 → 目标装备
```

显示：

```text
源装备强化等级
目标装备当前强化
转移后等级
源装备结果
费用
是否消耗源装备
```

套装和传奇必须显示特殊限制。

---

## 12. 操作反馈

成功：

```text
属性数字向上跳动
装备边框闪光
NPC 动画
对应音效
```

失败：

```text
不过度羞辱玩家
显示明确失败结果
更新保底进度
材料变化立即刷新
```

## 13. 键鼠与手柄

键鼠：

```text
左键选择

拖拽装备和符石
Shift 批量

```

手柄：

```text

方向键移动格子
A 确认

```

```text
唯一规则、冲突
```

```text
当前孔位

可开孔上限
强化等级
品质
```

---

## 15. 验收标准

```text
所有操作都有结果预览。
失败后果在确认前可见。
拖拽与右键均可完成镶嵌。
不兼容原因明确显示。
强化、品质、开孔不会混在同一个信息区。
批量分解有保留过滤条件。
连续强化有最大花费和停止条件。
```
