# 90. 角色基础操控：移动、转向、加减速、惯性


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 基础移动目标

角色移动要兼顾刷宝 ARPG 的效率和动作游戏的身体感。玩家按下方向键后需要快速响应，但不能像无质量滑块一样瞬间满速、瞬间转向、瞬间停止。

## 2. 移动模式

| 模式 | 描述 | 主要场景 |
|---|---|---|
| FreeMove | 自由移动，方向基于镜头 | 探索/普通刷怪 |
| CombatMove | 战斗移动，转向更快 | 小怪战斗 |
| LockedStrafe | 锁定目标侧移 | Boss/精英战 |
| SprintMove | 疾跑 | 跑图/脱战 |
| AimMove | 瞄准/施法慢移 | 弓弩/法术蓄力 |
| RootMotionMove | 动画根运动驱动 | 重攻击/处决/冲锋 |
| ForcedMove | 外力位移 | 击退/拉扯/弹飞 |

## 3. 输入到移动方向

### 3.1 自由移动

```text
输入：WASD / 左摇杆
参考：摄像机水平朝向
输出：WorldMoveDirection
```

规则：

- W = 朝镜头前方移动。
- S = 朝镜头后方移动。
- A/D = 以镜头右方向为基准侧移。
- W+A / W+D 归一化，不允许斜向速度超标。
- 没有锁定目标时，角色身体朝向逐渐转向移动方向。

### 3.2 锁定移动

锁定目标时，移动方向仍由输入决定，但角色身体朝向优先面向目标：

| 输入 | 行为 |
|---|---|
| W | 靠近目标 |
| S | 后撤 |
| A | 向左环绕 |
| D | 向右环绕 |
| W+A | 左前斜步 |
| S+D | 右后斜步 |

锁定时不建议强制角色完全“螃蟹步”。本项目采用混合规则：

- 近战距离 < 5m：角色胸口朝目标，脚步为侧移/后撤。
- 中距离 5m - 12m：身体可向移动方向偏转 30°。
- 远距离 > 12m：接近自由移动，镜头仍保持目标同屏。

## 4. 速度层级

| 状态 | 速度建议 | 说明 |
|---|---:|---|
| 慢走 | 2.2m/s | 城镇、对话附近、精确移动 |
| 普通跑 | 5.2m/s | 默认移动 |
| 战斗跑 | 4.6m/s | 进入战斗后略慢，更利于判定 |
| 疾跑 | 7.4m/s | 消耗体力或脱战免费 |
| 负重移动 | -5%~-20% | 可选，用装备重量影响 |
| 蓄力移动 | 1.5m/s~3.0m/s | 部分技能蓄力时 |

## 5. 加减速曲线

角色不能瞬间满速。使用加速度曲线：

| 阶段 | 参数 |
|---|---|
| 起步加速 | 0 → 70% 速度，0.12s 内完成 |
| 满速补足 | 70% → 100%，0.18s 内完成 |
| 停止刹车 | 100% → 0，0.16s - 0.28s |
| 战斗刹车 | 0.10s - 0.18s，更利落 |
| 冰面/泥地 | 刹车时间增加，转向迟滞增加 |

推荐实现：

```csharp
currentSpeed = Mathf.MoveTowards(currentSpeed, targetSpeed, acceleration * deltaTime);
velocity = desiredDirection * currentSpeed;
```

## 6. 转向规则

### 6.1 非战斗转向

角色朝向移动方向。

| 角度差 | 转向速度 |
|---|---:|
| < 30° | 720°/s |
| 30° - 90° | 900°/s |
| > 90° | 1080°/s，可播放急转动画 |

### 6.2 战斗转向

| 动作 | 转向规则 |
|---|---|
| 普通移动 | 快速朝移动方向 |
| 普攻前摇 | 可修正 30° - 60° |
| 重攻击前摇 | 可修正 15° - 35° |
| 技能释放瞬间 | 朝目标/输入方向锁定 |
| 技能后摇 | 通常不可自由转向，部分技能允许慢转 |
| 受击硬直 | 不允许玩家转向 |
| 闪避 | 朝闪避方向立即对齐或保留战斗面向 |

## 7. 移动状态机

```text
Idle
 ├── 输入移动 → StartMove
 ├── 输入跳跃 → Jump
 ├── 输入闪避 → Dodge
 └── 输入攻击 → Attack

StartMove
 ├── 持续输入 → Run
 ├── 输入疾跑 → Sprint
 └── 松开输入 → Stop

Run
 ├── 松开输入 → Stop
 ├── 输入闪避 → Dodge
 ├── 输入跳跃 → Jump
 ├── 进入战斗 → CombatMove
 └── 地面丢失 → Fall

CombatMove
 ├── 锁定目标 → LockedStrafe
 ├── 脱战 → Run
 ├── 攻击 → AttackMove
 └── 闪避 → Dodge
```

## 8. 根运动与代码位移

### 8.1 推荐规则

| 类型 | 位移来源 |
|---|---|
| 普通移动 | 代码 CharacterMotor 控制 |
| 闪避 | 动画曲线 + 代码校正混合 |
| 冲锋技能 | 技能位移模块控制 |
| 重攻击小前踏 | Root Motion 控制 |
| 被击退 | 物理/脚本外力控制 |
| 处决/抓取 | 动画匹配点控制 |

### 8.2 混合规则

Root Motion 不直接支配全部移动。由 `MotionAuthority` 决定当前位移权重：

```text
CodeMoveWeight = 1.0 - RootMotionWeight - ForcedMoveWeight
```

示例：

| 状态 | Code | Root | Forced |
|---|---:|---:|---:|
| 普通跑 | 1.0 | 0 | 0 |
| 普攻 | 0.4 | 0.6 | 0 |
| 重击 | 0.1 | 0.9 | 0 |
| 被击飞 | 0 | 0 | 1.0 |
| 闪避 | 0.3 | 0.7 | 0 |

## 9. 体力对移动的影响

如果本项目保留体力系统：

- 疾跑消耗体力。
- 闪避消耗体力。
- 体力不足时不能闪避，只能普通跑。
- 战斗中体力恢复降低。
- 脱战后体力恢复提高。

```text
体力满值：100
疾跑消耗：12/s
闪避消耗：25
重闪避消耗：35
战斗恢复：12/s
脱战恢复：25/s
被击中恢复延迟：0.8s
```

## 10. 输入缓冲

为了手感流畅，关键输入需要缓冲：

| 输入 | 缓冲时间 |
|---|---:|
| 跳跃 | 0.12s |
| 闪避 | 0.15s |
| 普攻连段 | 0.25s |
| 技能 | 0.20s |
| 交互 | 0.10s |

规则：如果当前状态不能执行输入，记录输入；当状态进入可执行窗口，自动消费。

## 12. 验收标准

- WASD 移动与镜头方向一致。
- 角色转向不会脚底滑得太明显。
- 锁定时能绕 Boss 走，不会背对 Boss 乱砍。
- 斜向移动速度与正向一致。
- 从跑动接攻击时，角色能自然朝攻击方向修正。
- 从攻击后摇恢复移动时，不出现瞬移或卡帧。
