# 地图玩法、终局 Atlas、赛季机制

---

## 1. 地图系统目标

章节剧情只是前期教学，真正长期内容是终局地图。

终局地图要提供：

- 无限刷图目标。
- 地图等级递进。
- 地图词缀风险收益。
- 可选择的地图机制。
- Boss 与碎片追求。
- Atlas 天赋树改变刷图策略。
- 赛季机制长期扩展。

## 4. 地图词缀

地图词缀必须遵守风险收益原则：

```text
越危险 → 掉落数量越高 / 稀有度越高 / 机制奖励越多
```

### 4.1 地图危险词缀

| 词缀 | 效果 | 奖励修正 |
|---|---|---:|
| 怪物生命提高 | 怪物生命 +30%~80% | +8% 数量 |
| 怪物伤害提高 | 怪物伤害 +20%~60% | +10% 数量 |
| 怪物投射物增加 | 投射物 +2 | +12% 数量 |
| 玩家回复降低 | 生命/魔力回复 -40% | +10% 稀有度 |
| 玩家抗性降低 | 全抗 -8%~-15% | +14% 数量 |
| 怪物暴击提高 | 暴击率/倍率提高 | +12% 稀有度 |
| 地面持续伤害 | 随机生成危险地面 | +15% 数量 |
| Boss 狂暴 | Boss 低血时增强 | +25% Boss 掉落 |

### 4.2 地图奖励词缀

| 词缀 | 效果 |
|---|---|
| 额外精英怪 | 增加精英怪数量 |
| 额外宝箱 | 增加奖励房间 |
| 机制强化 | 地图机制奖励翻倍，但难度提高 |
| Boss 额外掉落 | Boss 掉落额外地图材料 |
| 装备基底加权 | 某类装备基底掉落提高 |

## 6. 地图目标

每张地图必须有完成目标。

常见目标：

- 击杀地图 Boss。
- 击杀足够数量怪物后开启出口。
- 净化 3 个污染节点。
- 保护地图核心直到计时结束。
- 找到并击败隐藏精英。
- 完成地图机制主事件。

第一版建议统一为：

```text
击杀地图 Boss = 地图完成
```

## 8. Atlas 天赋树

Atlas 天赋树不是强化角色，而是强化地图收益和机制。

### 8.1 节点类型

| 类型 | 说明 |
|---|---|
| 地图维持 | 地图钥石掉落率、地图升阶概率 |
| Boss 奖励 | Boss 掉落、Boss 碎片、Boss 强化 |
| 机制专精 | 强化某个地图机制 |
| 怪物密度 | 增加怪物群和精英 |
| 风险收益 | 地图更危险但奖励更多 |
| 商业收益 | 材料、金币、稀有基底掉落 |

### 8.2 Atlas 点数获取

- 完成新地图基底。
- 击败特定地图 Boss。
- 完成机制挑战。
- 击败 Pinnacle Boss。
- 完成赛季任务线。

## 9. 地图机制设计

第一版建议 6 个地图机制。

### 9.1 裂隙潮

玩法：

- 玩家触碰裂隙核心。
- 地面打开裂隙，怪物不断涌出。
- 玩家击杀越快，裂隙扩展越远。
- 时间结束后掉落奖励。

奖励：

- 裂隙碎片。
- 高密度装备。
- 裂隙 Boss 门票。

### 9.2 古墓爆破

玩法：

- 地图中出现古墓埋藏物。
- 玩家放置爆破点。
- 爆破会释放怪物和奖励箱。
- 爆破范围互相连锁。

策略：

- 选择奖励箱还是强怪。
- 放得越贪，怪越强。

### 9.3 迷雾追猎

玩法：

- 开启迷雾后，地图被雾覆盖。
- 离起点越远，怪物越强，奖励越高。
- 玩家需要决定继续深入还是提前结算。

奖励：

- 迷雾碎片。
- 特殊持续伤害装备。

### 9.4 祭坛回响

玩法：

- 玩家激活祭坛。
- 场地锁定，之前击杀过的怪物被复制回来。
- 击杀后获得祭品点数。
- 地图结束前在祭坛商店兑换奖励。

### 9.5 星核矿脉

玩法：

- 地图中随机出现星核矿。
- 玩家采集时吸引怪潮。
- 守住采集器可获得打造材料。

### 9.6 猎首印记

玩法：

- 地图中出现被标记的强大精英。
- 精英会吞噬附近怪物变强。
- 玩家越晚击杀，奖励越高但风险越高。

## 10. Pinnacle Boss 线

每条机制都有 Boss 碎片。

```text
裂隙潮 → 裂隙碎片 x100 → 裂隙领主
古墓爆破 → 古墓铭牌 x4 → 爆破王
迷雾追猎 → 迷雾镜片 x300 → 雾中双子
祭坛回响 → 祭品徽记 x4 → 回响之王
星核矿脉 → 星核钥匙 x5 → 地心龙
猎首印记 → 猎首契约 x4 → 万兽猎主
```

## 11. 地图失败规则

- 每张地图开启 6 个传送门。
- 玩家死亡消耗 1 个传送门。
- 传送门耗尽地图失败。
- 地图失败不会返还钥石。
- Boss 已死亡则地图算完成。

可选硬核模式：

- 死亡直接结束地图。
- 掉落背包部分材料。

## 12. 地图生成结构

地图由 Tile 拼接。

```text
MapRuntimeRoot
  EntryRoom
  MainPathTiles
  BranchTiles
  EventRooms
  BossRoom
  RewardRoom
  ExitPortal
```

生成流程：

```text
选择 MapBase
  ↓
根据 LayoutType 生成主路径
  ↓
插入分支房间
  ↓
插入机制事件点
  ↓
插入精英怪群
  ↓
插入 Boss 房
  ↓
烘焙/加载 NavMesh
  ↓
生成掉落容器
```

## 13. 地图验收标准

- 玩家每开一张地图都能看懂危险和奖励。
- 地图词缀能明显影响打法，而不只是数值膨胀。
- 至少 3 种地图机制能支撑不同刷图策略。
- Atlas 天赋能让玩家选择“刷 Boss / 刷材料 / 刷装备 / 刷地图维持”。
- 高阶地图失败有压力，但不是纯数值秒杀。
