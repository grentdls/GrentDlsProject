# 技能逻辑与表现：元素法术：火、冰、雷

> 参考边界：本项目参考暗黑刷宝 ARPG 的系统结构：职业起点、主动技能、辅助模块、保留技能、触发技能、巨型被动树、职业专精树、装备词条联动、Boss 机制与终局构筑。
> 不直接复制任何商业游戏的职业名、技能名、图标、数值、UI截图、专有词条与怪物设定。下面所有职业、技能、天赋节点、数值区间、特效表现均为项目原创，用于 Unity 原型和后续美术/程序落地。

## 1. 技能标签

```text
Spell, Fire, Cold, Lightning, Ailment
```

## 2. 设计目标

该类技能必须同时满足：

```text
手感清晰
判定可信
表现和伤害一致
可被辅助模块改造
可被天赋节点改变机制
可以在 3D ACT 镜头下读懂
```

## 3. 判定类型

- 投射法术
- 延迟范围
- 连锁目标
- 持续区域

## 4. 释放阶段

```text
PreCast：前摇，可被攻速/施法速度影响
Active：真正产生 Hitbox / Projectile / Area
Recovery：后摇，可被取消或不可取消
ComboWindow：连段输入窗口
CancelWindow：翻滚/防御取消窗口
```

## 5. Unity 结构

```text
SkillRuntime_元素法术_火_冰_雷
├── SkillCastController

├── VFXBinder
├── SFXBinder
└── CameraFeedback
```

## 6. 表现规则

### 6.1 动画

- 前摇必须清楚展示发力方向。
- Active 帧必须和命中帧一致。
- 后摇要给玩家判断风险。
- 可取消技能必须有明确取消窗口。

### 6.2 特效

- 特效范围不能大于实际判定 20% 以上。
- 高伤技能必须有更明显的蓄力、音效和镜头反馈。
- 低伤高频技能不能使用过亮特效，否则会污染画面。

### 6.3 音效

```text
StartSound：起手
ReleaseSound：释放
HitSound：命中
CritSound：暴击
EndSound：收招或爆炸
```

## 8. 辅助模块兼容

| 辅助方向 | 是否兼容 | 说明 |
|---|---|---|
| 增加范围 | 是 | 修改 AreaRadius 或 HitboxScale |
| 增加投射物 | 条件兼容 | 只有 Projectile 标签有效 |
| 冷却缩短 | 是 | 不能低于技能最小冷却 |
| 改变伤害类型 | 是 | 需要同步 VFX 颜色和异常状态 |
| 自动触发 | 条件兼容 | 大招和位移技能默认禁止 |
| 召唤物继承 | 条件兼容 | 只对 Minion/Turret/Totem 有效 |

## 9. 验收标准

- 编辑器里可以独立播放技能预览。
- 可以显示 Hitbox Gizmo。
- 可以通过数据表修改范围、冷却、伤害、VFX。
- 至少支持 3 个辅助模块改变技能。
- 支持键鼠和手柄输入。
