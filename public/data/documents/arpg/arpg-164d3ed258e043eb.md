# 第三批 UI 功能实现审计

更新时间：2026-07-02

## 已完成

1. 运行时 UI 根：
   - 新增 `ArpgThirdBatchUIRoot`，运行时创建 Canvas_HUD、Canvas_WorldSpace、Canvas_Window、Canvas_Popup、Canvas_Tooltip、Canvas_DragLayer、Canvas_Loading。
   - 接入快捷键：I/C/K/P/M/J/L/F10/Esc。
   - `RuntimeArpgUIBootstrap` 已切到第三批 UI 根，原型地图玩家生成后会打开新 HUD/UI。

2. 战斗 HUD：
   - 新增 `ArpgCombatHudView`。
   - 包含生命、法力、闪避资源、技能栏冷却、药剂栏、小地图占位、目标信息、Boss 信息、掉落物标签。

3. 整备/角色/装备/背包/技能/天赋/地图/任务/图鉴：
   - 新增 `ArpgLoadoutWindow`。
   - 已绑定 `InventoryComponent`、`EquipmentComponent`、`AttributeAggregator`、`SkillLoadoutComponent`、`PassiveTreeController`、`ConfigManager`。
   - 支持装备、卸下、右键物品菜单、Ctrl 快速装备、技能/辅助模块查看与绑定、天赋节点分配入口、地图/任务/图鉴数据浏览。

4. 商店与城镇服务：
   - 新增 `ArpgShopWindow`。
   - 支持 Buy、Sell、Blacksmith、Skills、Flasks、Maps、Rare 七类页签。
   - 已接入 `ShopService`、`BlacksmithService`、`ItemGenerator`、`ShopCurrencyWallet`、`SkillLoadoutComponent`、`ResourceComponent`。

5. NPC、传送、地图装置、Atlas、任务、设置、死亡、结算：
   - 新增 `ArpgNpcDialogWindow`、`ArpgWaypointWindow`、`ArpgMapDeviceWindow`、`ArpgAtlasWindow`、`ArpgQuestLogWindow`、`ArpgSettingsWindow`、`ArpgDeathWindow`、`ArpgMapResultWindow`。
   - 地图装置会调用 `MapKeyService.Generate` 和 `BuildRunContext`，不再只是静态面板。
   - 设置面板会保存 `Application.persistentDataPath/arpg_ui_settings.json`。

6. 通用 UI 组件：
   - 新增 `UIGridView`、`UISlotBase`、`UIDragHandler`、`UICompareController`、`UIDataBinder`、`UIStateAnimator`、`UIHotkeyHint`、`UICurrencyBar`、`UISearchFilter`、`UISortButton`。
   - 保持一个 MonoBehaviour 一个脚本文件，避免 prefab 脚本引用丢失。

7. 第三批 Prefab：
   - 新增 `ThirdBatchUIPrefabFactory` 菜单：`Game/ARPG/Create Third Batch UI Prefabs`。
   - `Game/ARPG/Repair Generated Assets` 已调用第三批 prefab 工厂。
   - 已创建文档命名的 `Assets/_Game/Prefabs/UI/UI_*.prefab` 占位资产和 `UIRoot_ThirdBatch.prefab`。

## 未完全完成 / 需要下次继续

1. Unity BatchMode 生成完整脚本化 prefab 被阻止：
   - 日志：`Logs/third_batch_ui_prefabs.log`
   - 原因：当前工程已有 Unity 实例打开，Unity 报错 `another Unity instance is running with this project open`。
   - 当前已生成的是文档命名 prefab 占位资产；完整层级和脚本组件需要在 Unity 可执行菜单时由 `ThirdBatchUIPrefabFactory.CreateAll()` 覆盖生成。

2. 全工程仍有历史缺失脚本引用：
   - 当前扫描总数：128。
   - 第三批新 `UI_*.prefab` 没有新增缺失脚本。
   - 这些主要来自旧 `PF_*` prefab/scene，需要 Unity 关闭当前占用后执行 `Game/ARPG/Repair Generated Assets` 重新生成。

3. 美术资源仍是灰盒：
   - 第三批功能窗口已可运行，但图标、九宫格切图、真实美术材质未制作。
   - 文档允许原型阶段使用灰盒 UI；后续应从 `ThirdBatchUIPrefabFactory` 生成的 prefab 上替换正式 Sprite/Material。

## 下次继续的准确起点

1. 先关闭当前打开的 Unity 工程，或直接在已打开的 Unity 菜单执行：
   - `Game/ARPG/Create Third Batch UI Prefabs`
   - 然后执行 `Game/ARPG/Audit Asset Health`

2. 如果继续由 Codex 自动处理，下一次从这里开始：
   - 运行 Unity BatchMode：`Game.EditorTools.ThirdBatchUIPrefabFactory.CreateAll`
   - 再运行：`Game.EditorTools.ArpgGeneratedAssetRepair.RepairGeneratedAssets`
   - 最后重新扫描 `m_Script: {fileID: 0}`，把旧 128 个缺失引用降到 0。
