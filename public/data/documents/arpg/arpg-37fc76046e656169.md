# 92. 闪避、冲刺、滑步、疾跑与体力消耗


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 定位

闪避是 3D ACT 的核心生存操作。它负责让玩家主动躲避 Boss 技能、精英怪突进、投射物和地面危险区。疾跑负责跑图效率。冲刺/滑步负责战斗位移与技能衔接。

## 2. 位移类型

| 类型 | 触发 | 用途 |
|---|---|---|
| Dodge 闪避 | Shift / B / 右键组合 | 战斗躲避，有短暂无敌 |
| Sprint 疾跑 | 按住 Shift / L3 | 跑图，持续消耗体力或脱战免费 |
| Dash 冲刺 | 部分技能 | 快速接近/穿越小怪 |
| Backstep 后撤步 | 锁定状态 S + Dodge | 拉开距离 |
| SideStep 侧步 | 锁定状态 A/D + Dodge | 绕 Boss 技能 |
| Slide 滑步 | 疾跑 + 蹲伏/下坡 | 探索和战斗短滑移 |

## 3. 闪避输入规则

### 3.1 自由状态

| 输入 | 闪避方向 |
|---|---|
| 移动输入存在 | 沿移动方向闪避 |
| 无移动输入 | 沿角色当前后方或镜头后方，取决于配置 |
| 镜头方向变化 | 闪避开始后方向锁定，不随镜头改变 |

### 3.2 锁定状态

| 输入 | 结果 |
|---|---|
| W + Dodge | 前闪/贴近 |
| S + Dodge | 后撤步 |
| A/D + Dodge | 侧闪，保持面向目标 |
| 无输入 + Dodge | 默认后撤步 |

## 4. 闪避阶段

```text
DodgeStart 0.05s
 ├── 消耗体力
 ├── 确定方向
 ├── 播放起手动画
DodgeActive 0.20s - 0.32s
 ├── 位移最大
 ├── 无敌帧/减伤帧
 ├── 禁止普通移动
DodgeRecover 0.15s - 0.28s
 ├── 可以提前接轻攻击/移动
 ├── 重武器恢复更慢
```

## 5. 无敌帧规则

| 类型 | 无敌/减伤 |
|---|---|
| 普通闪避 | 0.08s - 0.22s 完全无敌 |
| 重甲职业 | 无敌较短，但霸体/减伤更高 |
| 轻甲职业 | 无敌更长，恢复更快 |
| 后撤步 | 无敌短，距离长 |
| 侧闪 | 无敌标准，距离中等 |
| 技能冲刺 | 按技能配置决定，不默认无敌 |

注意：不要让所有位移都有无敌，否则 Boss 机制会失效。

## 6. 体力消耗规则

| 行为 | 消耗 |
|---|---:|
| 普通闪避 | 25 |
| 锁定侧闪 | 22 |
| 后撤步 | 20 |
| 重闪避 | 35 |
| 疾跑 | 12/s |
| 滑步 | 18 |
| 空中闪避 | 35，可由天赋解锁 |

体力不足时：

- 不能闪避。
- 输入闪避会播放轻微失败反馈，不打断当前动作。
- 可以保留“疲劳小滑步”，但无无敌帧，避免完全失控。

## 7. 闪避距离和速度

| 类型 | 距离 | 时长 | 速度曲线 |
|---|---:|---:|---|
| 普通闪避 | 4.0m | 0.42s | 前快后慢 |
| 侧闪 | 3.4m | 0.36s | 快速横移 |
| 后撤步 | 4.4m | 0.45s | 起步快，后段慢 |
| 重甲翻滚 | 3.2m | 0.50s | 慢但有减伤 |
| 轻甲滑步 | 4.8m | 0.34s | 快速短冷却 |

## 8. 闪避取消规则

| 当前动作 | 是否可闪避取消 |
|---|---|
| 普通移动 | 可 |
| 普攻前摇 | 通常不可，部分轻武器可 |
| 普攻后摇 | 可在取消窗口内 |
| 重攻击蓄力 | 可，但消耗额外体力或损失蓄力 |
| 技能释放中 | 按技能配置 |
| 喝药 | 不可或很晚可取消 |
| 受击轻硬直 | 不可，除非有受身技能 |
| 击飞 | 不可，空中受身另算 |

## 9. 疾跑规则

### 9.1 开始疾跑

条件：

- 有移动输入。
- 体力 > 10，或处于脱战免费疾跑模式。
- 当前不是攻击、受击、交互、施法硬直。

### 9.2 疾跑镜头

疾跑开始后：

- FOV 从 62 过渡到 70。
- 镜头后拉 0.3m - 0.6m。
- 角色身体前倾。
- 脚步声频率提高。

### 9.3 疾跑停止

停止条件：

- 松开疾跑键。
- 体力耗尽。
- 输入攻击/技能/交互。
- 受到攻击。
- 进入锁定战斗。

## 10. 滑步规则

滑步作为探索和动作表现，不作为核心无敌操作。

触发方式：疾跑状态 + 蹲伏/滑步键，或下坡达到速度阈值。

规则：

- 可从低矮障碍下穿过。
- 无完全无敌，可有 30% 减伤。
- 不能连续无限滑。
- 滑步结束可接跳跃或翻越。

## 12. 验收标准

- 闪避按下后响应明确，不吞输入。
- 闪避方向与玩家输入一致。
- 锁定 Boss 时侧闪不会突然背对 Boss。
- 闪避不能穿过厚墙。
- 体力不足时有明确失败反馈。
- 疾跑镜头变化不晕，不影响转向。
- 闪避和攻击取消窗口稳定可测。
