# 81 伤害跳字规则：类型、颜色、大小、动画、合并

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. 设计目标

伤害跳字的作用不是只显示数字，而是让玩家立即读出：

- 这次打中了没有。
- 是什么类型的伤害。
- 是否暴击。
- 是否被格挡、闪避、免疫、吸收。
- 是否触发异常、持续伤害、击杀、破防。
- 当前 BD 是否正在生效。

本项目所有跳字使用统一事件：

```text
CombatTextEvent
├── SourceUnit
├── TargetUnit
├── Value
├── TextType
├── DamageType
├── HitResult
├── IsCritical
├── IsDot
├── IsMerged
├── WorldPosition
└── Importance
```

## 3. 伤害颜色规则

为了可读性，颜色应服务于类型，不要过度花哨。

| 伤害/事件 | 颜色倾向 | 字体风格 | 备注 |
|---|---|---|---|
| 物理 | 白/米白/浅灰 | 常规 | 默认伤害 |
| 火焰 | 橙红 | 轻微火星 | 燃烧相关 |
| 冰冷 | 冰蓝 | 碎冰粒子 | 冰冻/减速 |
| 闪电 | 紫蓝/亮蓝 | 快速抖动 | 感电/连锁 |
| 毒/腐蚀 | 绿 | 溶解感 | 中毒/腐蚀 |
| 暗影/混沌 | 紫黑 | 扭曲 | 特殊伤害 |
| 神圣/光辉 | 金白 | 光晕 | 神圣技能 |
| 治疗 | 绿色 | 上升 | 玩家友好收益 |
| 护盾回复 | 蓝白 | 护罩粒子 | 护盾收益 |
| 暴击 | 伤害类型色 + 金边 | 放大 + 震动 | 不能只靠颜色区分 |
| 免疫/格挡/闪避 | 灰/白 | 粗体文字 | 必须读清 |

## 4. 跳字大小规则

基础字号按重要度和数值分级。

| 级别 | 条件 | 字号倍率 | 动画强度 |
|---|---|---:|---|
| 小 | Dot、小额伤害、召唤物小伤害 | 0.75 | 弱 |
| 普通 | 普通命中 | 1.0 | 标准 |
| 大 | 高于目标最大生命 5% | 1.2 | 中 |
| 重击 | 高于目标最大生命 12% | 1.4 | 强 |
| 暴击 | 暴击 | 1.35-1.7 | 强 |
| 破防/处决 | 关键机制 | 1.6-2.0 | 极强 |
| Boss 伤害 | 玩家对 Boss | 0.95-1.2 | 控制刷屏 |

避免使用无限放大规则，最高不超过 2.0 倍。

## 5. 跳字动画规则

### 5.1 普通伤害

```text
出生：目标命中点上方
0.00s：透明 0，缩放 0.85
0.06s：透明 1，缩放 1.05
0.18s：缩放回 1.0
0.60s：向上漂移 + 轻微左右偏移
0.75s：透明 0，回收对象池
```

### 5.2 暴击

```text
出生：目标中心上方，略靠屏幕前
0.00s：缩放 0.65
0.08s：缩放 1.45，冲击闪光
0.16s：缩放 1.18
0.65s：向上 + 斜向飞出
0.95s：淡出
```

### 5.3 持续伤害

持续伤害不应刷屏：

- 高频 Dot 合并为每 0.5 秒一次显示。
- 字号较小。
- 动画更轻，向上速度更慢。

### 5.4 格挡/闪避/免疫

这类不是数字，必须在目标旁边清楚显示：

```text
格挡：目标正面弹开方向，短促出现
闪避：目标侧面飘移，透明较高
免疫：目标中心上方，短暂强显示
抵抗：数字旁边附带小字或图标
```

## 6. 跳字位置规则

### 6.1 世界位置到屏幕投射

跳字从 `HitPoint` 或目标 `HUDAnchor_Center` 投射到屏幕空间。

优先使用：

```text
命中点 HitPoint
→ 目标胸口 HUDAnchor_Center
→ 目标头顶 HUDAnchor_Head
→ 目标根节点 + 高度偏移
```

### 6.2 偏移规则

为避免重叠：

- 同目标同时生成多个跳字，按圆形/扇形散开。
- 多元素伤害可合并显示，不建议同时弹 5 个数字。
- 玩家受到伤害的跳字靠近玩家血条或角色附近，不能混入敌人跳字。

### 6.3 对玩家受到伤害

玩家受伤跳字必须更醒目：

| 类型 | 位置 | 备注 |
|---|---|---|
| 玩家受到普通伤害 | 角色上方 + 屏幕轻闪 | 不遮挡技能栏 |
| 玩家受到大额伤害 | 角色上方大字 + 血条震动 | 需要危险感 |
| 玩家被 Dot | 小字周期显示，可合并 | Buff 栏也要显示 Debuff |
| 玩家格挡/闪避 | 角色附近文字 | 正反馈 |

## 7. 合并规则

高频 ARPG 技能必须合并跳字，否则屏幕会变成数字雨。

### 7.1 同目标同类型合并

在合并窗口内，同一目标、同一伤害类型、同一来源技能合并。

```text
合并窗口：0.25s - 0.5s，可配置
显示格式：总伤害 或 单次×次数
```

示例：

```text
12
14
13
15
```

合并为：

```text
54×4
```

或：

```text
54
```

### 7.2 持续伤害合并

```text
Dot 每 0.5 秒汇总一次
显示总 Dot 数值
若 Dot 来源超过 3 个，显示主类型颜色 + 小图标
```

### 7.3 召唤物伤害合并

召唤流会产生大量跳字：

- 普通召唤物伤害可合并到召唤物群组。
- 重要召唤物可单独显示暴击。
- Boss 战默认降低召唤物小伤害跳字密度。

---

## 8. 玩家与敌人跳字区分

| 来源/目标 | 显示方式 |
|---|---|
| 玩家打敌人 | 敌人附近，使用伤害类型颜色 |
| 敌人打玩家 | 玩家附近或屏幕中心偏下，颜色偏红/警告 |
| 友方治疗玩家 | 玩家附近绿色上升 |
| 玩家治疗召唤物 | 召唤物附近小号绿色 |
| 环境伤害 | 目标附近，附带环境图标 |
| 反伤 | 玩家附近，标记“反伤” |

## 9. 特殊跳字规则

### 9.1 暴击

暴击文字规则：

```text
数字 + 感叹号
类型色 + 高亮边
轻微屏幕冲击，不每次震屏
```

暴击示例：

```text
1,284!
```

### 9.2 破防

破防优先级高于普通伤害：

```text
破防
```

出现时：

- 目标血条韧性条闪白。
- 目标模型播放硬直表现。
- 玩家技能栏可提示处决/重击窗口。

### 9.3 击杀与连杀

普通小怪击杀不必每只都显示“击杀”。

显示条件：

- 精英/稀有怪死亡。
- Boss 死亡。
- 触发击杀流派效果。
- 连续击杀达到阈值。

示例：

```text
击杀
连杀 x12
处决
```

### 9.4 免疫 / 无效

当伤害完全无效：

```text
免疫
无效
未命中
闪避
格挡
```

这些文字不应和普通伤害一样飘得太快，需停留 0.55 秒以上。

## 10. 跳字对象池

```text
DamageNumberPool
├── Pool_NormalPhysical
├── Pool_ElementFire
├── Pool_ElementCold
├── Pool_ElementLightning
├── Pool_Dot
├── Pool_Critical
├── Pool_Heal
├── Pool_Shield
├── Pool_BlockDodgeImmune
├── Pool_BreakGuard
└── Pool_Debug
```

对象池容量建议：

| 场景 | 普通跳字 | 暴击 | Dot | 治疗 | 特殊文字 |
|---|---:|---:|---:|---:|---:|
| 主城 | 0 | 0 | 0 | 0 | 10 |
| 普通战斗 | 120 | 40 | 60 | 30 | 40 |
| Boss 战 | 180 | 60 | 100 | 40 | 60 |
| 压力测试 | 300 | 100 | 150 | 80 | 100 |

超过容量时：

1. 优先合并。
2. 降低 Dot 显示频率。
3. 隐藏低价值召唤物伤害。
4. 保留暴击、破防、免疫、玩家受伤。

## 12. 调试功能

技能测试沙盒中必须支持：

- 开关所有跳字。
- 只显示某种伤害类型。
- 显示合并前原始伤害事件。
- 显示合并后跳字事件。
- 显示对象池占用。
- 显示跳字丢弃数量。
- 固定目标位置测试跳字重叠。
- 模拟 Boss 战高频伤害。

## 13. 验收标准

- 物理、火、冰、雷、毒/腐蚀、神圣等伤害有明显区分。
- 暴击比普通伤害更醒目，但不会遮挡屏幕。
- Dot 高频伤害会自动合并。
- 召唤物大量攻击不会造成数字雨。
- 格挡、闪避、免疫、破防、护盾破裂有独立文字。
- 玩家受到大伤害时反馈明显。
- 同屏 200 个伤害事件时 HUD 不明显掉帧。
