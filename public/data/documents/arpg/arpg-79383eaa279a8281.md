# 27_角色属性、天赋树、专精树 UI 预制体


> 设计边界说明：本项目可以参考《流放之路2》这类暗黑刷宝 ARPG 的信息架构、交互复杂度和系统深度，但不能一比一复制其 UI 视觉、图标、文字、专有数值、专有命名、具体排版截图。本批文档采用“同类结构 + 原创表现”的方式：界面功能、层级、预制体和数据绑定可直接用于 Unity 原型开发。


## 1. 界面定位

角色属性页用于“看结果”，天赋树用于“做构筑决策”。二者要强关联：玩家点天赋时必须立刻预览生命、伤害、抗性、资源、技能需求变化。

节点类型：

| 类型 | 用途 |
|---|---|
| SmallStat | 小属性点 |
| MediumStat | 中型属性点 |
| Notable | 显著天赋，构筑方向明显 |
| Keystone | 关键天赋，大幅改变机制 |
| Mastery | 专精节点，提供选择项 |
| Start | 职业起点 |
| JewelSocket | 插入特殊天赋物 |

## 6. 天赋树交互

| 操作 | 结果 |
|---|---|
| 鼠标滚轮 | 缩放树 |
| 鼠标拖拽空白 | 平移视图 |
| 点击节点 | 选中节点，右侧显示详情 |
| 双击可点节点 | 分配节点 |
| Shift 点击远端节点 | 预览最短路径 |
| 搜索关键词 | 高亮相关节点 |
| 右键已分配节点 | 进入退点确认 |
| 手柄右摇杆 | 平移视图 |
| 手柄扳机 | 缩放视图 |

## 10. 原型验收标准

1. 天赋树支持缩放和平移。
2. 节点支持可点、已点、锁定、预览四态。
3. 点击节点能显示详情。
4. Shift 点击远端节点能预览路径。
5. 分配天赋后角色属性栏实时刷新。
6. 支持搜索关键词并高亮节点。
