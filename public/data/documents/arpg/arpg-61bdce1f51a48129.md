## 2. 四方向判定

```text
Front
Back
Left
Right
```

选择逻辑：

```text
hitStrength = Light / Medium / Heavy
hitDirection = Front / Back / Left / Right
clip = reactionSet[hitStrength][hitDirection]
```

## 8. 打断规则

```text
死亡可以打断所有受击
击飞可以打断普通受击
破韧可以打断普通技能
轻受击不能打断霸体技能
Boss 普通受击不打断技能
```

## 9. 验收标准

- 普通人形敌人有四方向轻中重受击。
- 空中受击有独立动画。
- 击退不会只滑动不动身体。
- 击飞有起飞、空中循环、落地。
- 击倒有倒地循环和起身。
- 破韧动画有输出窗口。
