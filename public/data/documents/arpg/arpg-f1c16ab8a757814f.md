# 102_铁匠铺内容_商品_分解_强化_镶孔_服务规则

> NPC：老炉匠·斐洛  
> 位置：星陨营地西北角铁匠铺  
> 主要目标：让玩家回城后能快速处理装备垃圾，并为装备成长提供第一层可控改造。

---

## 1. 铁匠铺功能总览

铁匠铺不是一个单纯商店，包含 6 个服务页签：

```text
铁匠铺 UI
├── 购买装备
├── 出售装备
├── 分解装备
├── 强化装备
├── 品质锻造
├── 镶孔 / 改孔
└── 修理耐久，可选系统
```

| 服务 | 开放时机 | 高频程度 | 目的 |
|---|---|---:|---|
| 购买装备 | 初次进城 | 低 | 给缺装备玩家保底 |
| 出售装备 | 初次进城 | 高 | 快速换金币 |
| 分解装备 | 教学 Boss 后 | 高 | 获得打造材料 |
| 强化装备 | 等级 6 | 中 | 让好装备继续使用 |
| 品质锻造 | 等级 8 | 中 | 装备基础数值提升 |
| 镶孔 / 改孔 | 第 2 章 | 中后期 | 接入符石和技能构筑 |
| 修理耐久 | 可选 | 低 | 只有启用耐久系统才显示 |

## 3. 出售装备页

### 3.1 出售规则

玩家把物品拖入出售栏，或右键快速出售。

```text
出售价格 = 基础价格 × 品质倍率 × 物品等级倍率 × 耐久倍率 × 词条数量倍率
```

### 3.2 出售价格倍率

| 品质 | 出售倍率 |
|---|---:|
| 普通 | 1.0 |
| 魔法 | 1.8 |
| 稀有 | 4.5 |
| 传奇 | 20.0，第一版可禁止出售并弹窗确认 |

### 3.3 快捷出售规则

| 操作 | 功能 |
|---|---|
| 右键物品 | 出售单件 |
| Shift + 右键 | 批量出售同品质 |
| Ctrl + 点击 | 标记为出售 |
| 一键出售普通 | 出售所有普通装备，不含材料和锁定物品 |
| 一键出售低价值 | 出售普通 + 低等级魔法装备 |

### 3.4 保护规则

以下物品不能被一键出售：

1. 已装备物品
2. 已锁定物品
3. 传奇装备
4. 带有“保留”标记的物品
5. 任务物品
6. 装有符石的装备，需二次确认

## 5. 强化装备页

### 5.1 强化目标

强化只提升装备主属性，不直接改变词条。

| 装备类型 | 强化提升 |
|---|---|
| 武器 | 基础攻击、法术强度、异常附加强度 |
| 防具 | 护甲、闪避、能量护盾、抗性小幅加成 |
| 饰品 | 主属性、生命、资源、特殊评分 |

### 5.2 强化等级

第一版建议强化上限：+10。

| 强化等级 | 成功率 | 失败结果 | 材料 |
|---:|---:|---|---|
| +1 ~ +3 | 100% | 无 | 基础材料 |
| +4 ~ +6 | 85% | 不掉级 | 魔尘 |
| +7 ~ +8 | 65% | 失败掉 1 级 | 稀有精华 |
| +9 ~ +10 | 45% | 失败掉 1 级，可用保护石 | 高阶精华 |

### 5.3 强化成本示例

| 等级 | 金币 | 材料 |
|---:|---:|---|
| +1 | 100 | 粗铁碎片 × 3 |
| +2 | 160 | 粗铁碎片 × 5 |
| +3 | 240 | 粗铁碎片 × 8 |
| +4 | 400 | 魔尘 × 3 |
| +5 | 650 | 魔尘 × 5 |
| +6 | 950 | 魔尘 × 8 |
| +7 | 1400 | 稀有精华 × 1 + 魔尘 × 10 |
| +8 | 2000 | 稀有精华 × 2 + 魔尘 × 15 |
| +9 | 3000 | 高阶精华 × 1 |
| +10 | 4500 | 高阶精华 × 2 |

### 5.4 强化保护规则

| 道具 | 作用 |
|---|---|
| 稳定铁砧券 | 强化失败不掉级 |
| 精准锻造券 | 本次强化成功率 +10% |
| 破损保护石 | 装备不会降到 +6 以下 |

第一版可以先不做付费道具，只保留材料消耗。

## 6. 品质锻造页

品质是装备的基础性能修正。

| 装备类型 | 品质影响 |
|---|---|
| 武器 | 基础伤害 +0% ~ +20% |
| 防具 | 防御基底 +0% ~ +20% |
| 饰品 | 第一版不开放品质，避免复杂 |

品质材料：

| 材料 | 作用 |
|---|---|
| 打磨石 | 武器品质 +1% |
| 护甲片 | 防具品质 +1% |
| 精工锉刀 | 品质 +2%，稀有 |

## 7. 镶孔 / 改孔页

### 7.1 孔位规则

| 装备部位 | 孔位上限 | 说明 |
|---|---:|---|
| 武器 | 1-3 | 放攻击符石 / 元素符石 |
| 胸甲 | 1-4 | 防御 / 生命 / 抗性符石 |
| 头盔 | 1-2 | 技能强化符石 |
| 手套 | 1-2 | 攻速 / 施法 / 命中符石 |
| 靴子 | 1-2 | 移速 / 闪避 / 体力符石 |
| 饰品 | 1 | 特殊符石，后期开放 |

### 7.2 服务类型

| 服务 | 作用 |
|---|---|
| 开孔 | 给无孔装备增加 1 个孔 |
| 洗孔数 | 随机改变孔位数量 |
| 改孔色/类型 | 改变孔类型，用于符石兼容 |
| 拆卸符石 | 取下符石，保留装备 |

### 7.3 孔类型

| 孔类型 | 颜色 | 支持符石 |
|---|---|---|
| 力量孔 | 红 | 物理、重击、防御 |
| 敏捷孔 | 绿 | 攻速、投射、闪避 |
| 智慧孔 | 蓝 | 法术、元素、护盾 |
| 混合孔 | 白 | 任意，稀有 |

## 10. 第一版验收标准

| 验收项 | 标准 |
|---|---|
| 购买装备 | 能按等级刷新 12 件装备 |
| 出售装备 | 能批量出售普通和魔法装备 |
| 分解装备 | 能预览材料并产出材料 |
| 强化装备 | 能强化到 +10，成功率正常 |
| 保护规则 | 锁定、传奇、任务物品不能误操作 |
| UI | 买卖、分解、强化页签可切换 |
| 数据 | 所有商品、服务、材料来自表格 |
| 反馈 | 强化成功/失败有音效、震动、粒子 |
