# 240 UI、HUD、技能预览、掉落物提示与状态可视化

## 1. 战斗 HUD 新增信息

### 环绕法球

```text
当前法球数量 / 上限
临时法球数量与剩余时间
当前转速强化状态
多环状态
法球类型小图标
```

推荐 HUD：

```text
法球图标 × 8
内环 5 / 外环 3
临时球使用倒计时边框
```

不需要为场上每个球都放一个巨大 UI，可以用点阵或计数。

---

## 2. 御剑 HUD

必须区分：

```text
空闲环绕剑
正在飞行剑
返回中剑
护剑
临时剑
```

推荐表现：

```text
御剑 12/16
空闲 7
飞行 3
护剑 2
临时 +4（6.2秒）
```

技能槽角标：

```text
齐射技能显示当前可用剑数
没有空闲剑时技能置灰或显示“回剑中”
```

---

## 3. 掉落球 HUD

基础掉落球不需要逐个 HUD，但需要：

```text
吸附技能状态
连续拾取层数
三色顺序进度
掉落进度条（可选高级显示）
特殊高品质球屏幕边缘提示
```

示例：

```text
三色巡礼：生命 ✓ → 法力 ✓ → 护盾 ○
拾取狂热：4/5
```

---

## 4. 场景可读性

### 法球

```text
玩家法球亮度高于敌人环境特效
碰撞体对应明确外轮廓
不同元素颜色统一
临时法球有倒计时闪烁
```

### 飞剑

```text
环绕阶段拖尾弱
发射阶段拖尾强
返回阶段颜色略淡或反向流光
护剑使用不同边框/符文
```

### 掉落球

```text
生命球：红/粉
法力球：蓝
护盾球：青白
剑意球：银金
元素核：对应元素色
```

不要只靠颜色，还要使用不同图标、形状和粒子。

---

## 5. 技能页面预览

环绕法球预览：

```text
显示玩家中心水平环
可调整数量滑杆
实时查看等角度排布
点击+1时展示平滑重排
可切换内外环
显示碰撞范围
```

御剑预览：

```text
显示无规则剑群环绕
显示锁定木桩与随机目标模式
循环发射、命中、返回
显示当前空闲/飞行/返回数量
```

掉落球预览：

```text
击杀木桩生成球
球体落地、弹跳、吸附、拾取
切换满血/缺血状态观察转化
显示拾取爆炸范围
```

## 6. 装备详情字段

新增标签和字段：

```text
法球数量
环绕半径
环绕速度
命中冷却
御剑数量
发射间隔
齐射数量
返回速度
掉落球进度
恢复值
吸附范围
拾取触发
```

机制词条必须清楚显示：

```text
临时实体上限
持续时间
触发概率
是否可由生成实体再次触发
冷却时间
```

---

## 7. 屏幕边缘提示

特殊球体距离玩家较远时：

```text
显示小箭头
仅提示稀有球、Boss球、剑意球
普通生命球不显示边缘箭头
```

---

## 8. 无障碍与性能显示

```text
可关闭法球呼吸摆动
可降低飞剑环绕密度，保留实际数量但合并显示
可降低掉落球粒子
颜色弱视模式增加形状差异
```
