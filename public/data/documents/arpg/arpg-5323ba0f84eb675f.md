# 25_装备、背包、仓库、物品格、详情比较 UI 预制体


> 设计边界说明：本项目可以参考《流放之路2》这类暗黑刷宝 ARPG 的信息架构、交互复杂度和系统深度，但不能一比一复制其 UI 视觉、图标、文字、专有数值、专有命名、具体排版截图。本批文档采用“同类结构 + 原创表现”的方式：界面功能、层级、预制体和数据绑定可直接用于 Unity 原型开发。


## 1. 界面定位

装备与背包是刷宝 ARPG 最核心的 UI。玩家需要在极短时间内完成：

1. 看出物品类型。
2. 看出稀有度。
3. 看出装备部位。
4. 看出词条价值。
5. 看出是否比当前装备更好。
6. 能快速卖出、拆解、存仓库、打造、锁定、标记收藏。

### 2.1 ItemSlot 组件

| 组件 | 用途 |
|---|---|
| `UIItemSlot` | 绑定物品数据、刷新显示 |
| `UIDragHandler` | 拖拽逻辑 |
| `UITooltipTrigger` | 悬浮详情 |
| `UIContextMenuTrigger` | 右键菜单 |
| `UIFocusElement` | 手柄焦点 |
| `UIRarityFrameBinder` | 稀有度边框刷新 |

### 2.2 ItemSlot 状态

| 状态 | 表现 |
|---|---|
| Empty | 暗色空格，无图标 |
| Normal | 普通边框 |
| Magic | 蓝色系边框，占位阶段可用蓝灰 |
| Rare | 黄色系边框 |
| Unique | 棕金系边框 |
| Currency | 圆角功能物品边框 |
| Quest | 特殊任务边框，不可出售 |
| Invalid | 红色半透明遮罩 |
| Selected | 明亮外框 + 轻微缩放 |
| Hover | 边框亮起 |

1. 名字。
2. 稀有度。
3. 物品类型。
4. 需求等级/需求属性。

7. 前缀/后缀。

9. 特殊状态：已腐化、已绑定、不可交易、任务物品。

差异显示规则：

| 类型 | 表现 |
|---|---|

| 条件不满足 | 红色需求提示 |
| 技能被禁用 | 黄字提示“属性不足导致技能失效” |

## 11. 原型验收标准

1. 背包格子可以显示不同稀有度。
2. 物品 Tooltip 自动根据词条数量拉高。
3. 两件装备可以比较。
4. Ctrl 点击可以在背包和仓库之间快速转移。
5. 右键物品弹出操作菜单。
6. 仓库支持页签和搜索。
7. 手柄可以在所有格子中焦点移动。
