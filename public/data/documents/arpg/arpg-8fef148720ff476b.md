# 225 曲线飞弹轨迹规则：螺旋、贝塞尔、波浪、蛇形、样条

## 1. 逻辑中心路径与视觉偏移

复杂曲线建议拆成两层：

```text
CenterPath：直线、跟踪、抛射或样条中心路径
OffsetMotion：螺旋、波浪、噪声、左右摆动
```

最终位置：

```text
finalPosition = centerPathPosition + curveOffset
```

这样可组合：

```text
直线 + 波浪
跟踪 + 螺旋
贝塞尔 + 小幅噪声
抛射 + 旋转
```

## 2. 螺旋飞弹 Spiral

```text
finalPosition = center
              + right * cos(angle) * radius
              + up * sin(angle) * radius
```

配置：

```json
{
  "curveType": "Spiral",
  "radius": 0.8,
  "rotationSpeed": 720,
  "clockwise": true,
  "radiusCurve": "ExpandThenShrink",
  "centerPathType": "Homing"
}
```

变化：

```text
固定半径、逐渐扩张、逐渐收缩、先扩后收
双螺旋、多枚相位错开、接近目标时收束
```

碰撞模式：

```text
VisualOnly：真实碰撞走中心路径，适合大量弹幕
PhysicalCurve：真实位置沿螺旋，适合玩家技能和少量精英技能
```

## 3. 二次贝塞尔

```text
P0 起点
P1 控制点
P2 终点
```

适合一次侧绕、简单弧线和绕盾攻击。

## 4. 三次贝塞尔

```text
P0 起点
P1 起点控制点
P2 终点控制点
P3 终点
```

适合 S 型、先升空后俯冲、左右绕侧和 Boss 演出弹。

控制点来源：

```text
世界坐标、施法者本地坐标、目标本地坐标
起终点中点、目标侧面、目标上方、随机偏移
```

```json
{
  "curveType": "CubicBezier",
  "controlPoint1": {"base": "Start", "offset": [1.5, 2.0, 0.0]},
  "controlPoint2": {"base": "Target", "offset": [-1.0, 1.0, 0.0]}
}
```

## 5. 动态目标更新

```text
FixedEnd：生成时锁定终点
DynamicEnd：每帧更新终点
Segmented：每 0.1 秒更新，进度 70% 后锁死
```

推荐使用分段更新，避免动态贝塞尔抖动。

## 6. 波浪 Wave

```text
offset = sin(time * frequency + phase) * amplitude
```

```json
{
  "curveType": "Wave",
  "axis": "Horizontal",
  "amplitude": 0.8,
  "frequency": 3.0,
  "phase": 0.0
}
```

## 7. 蛇形 Snake

由横向主波浪、纵向小波浪、频率噪声组成，比单一正弦更自然。

```json
{
  "curveType": "Snake",
  "horizontalAmplitude": 0.9,
  "verticalAmplitude": 0.3,
  "frequency": 2.5,
  "frequencyNoise": 0.2
}
```

## 8. 锯齿与折线 Zigzag

配置：

```text
转折次数、每段持续时间、转折角、是否逐步朝目标收敛
```

适合闪电弹、不稳定机械弹和虚空飞刀。

## 9. 样条路径 Spline

场景中手绘路径：

```text
SplinePath → Point0 → Point1 → PointN
```

适合固定机关弹道、绕场飞剑、Boss 场景弹幕。

## 10. 曲线速度

贝塞尔按参数 t 运行容易忽快忽慢，应支持：

```text
Parameter：按 t
ArcLength：弧长近似匀速
CustomCurve：自定义速度曲线
```

## 11. 示例

螺旋跟踪弹：

```json
{
  "trajectoryType": "Composite",
  "centerPath": "Homing",
  "curveType": "Spiral",
  "radius": 0.65,
  "rotationSpeed": 600,
  "radiusCurve": "ShrinkNearTarget",
  "flightTime": 1.4
}
```

贝塞尔侧绕弹：

```json
{
  "trajectoryType": "Bezier",
  "bezierType": "Cubic",
  "controlPoint1": {"base": "Start", "offset": [2,1,0]},
  "controlPoint2": {"base": "Target", "offset": [-2,1,0]},
  "targetUpdateMode": "Segmented"
}
```
