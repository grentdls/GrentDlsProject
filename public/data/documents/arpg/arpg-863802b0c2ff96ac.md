# UI 预制体结构：背包、装备、地图、技能、战斗 HUD

---

## 1. UI 总体原则

本项目 UI 信息密度很高，必须模块化。

目标：

- 玩家能看懂装备好坏。
- 玩家能快速整理背包。
- 玩家能理解技能辅助连接关系。
- 玩家能在地图装置中判断风险收益。
- 战斗 HUD 不遮挡 3D 场景。

---

## 2. UI 根结构

```text
UIRoot
  Canvas_ScreenSpaceOverlay
    HUDLayer
    PanelLayer
    PopupLayer
    TooltipLayer
    DragLayer
    LoadingLayer
  EventSystem
  UIManager
  TooltipManager
  DragDropManager
  UIAudioBinder
```

分层规则：

| 层 | 内容 |
|---|---|
| HUDLayer | 血球、魔力球、技能栏、小地图、Buff |
| PanelLayer | 背包、角色、技能、地图、仓库 |
| PopupLayer | 确认框、拾取提示、死亡提示 |
| TooltipLayer | 装备 Tooltip、技能 Tooltip |
| DragLayer | 拖拽物品、拖拽技能 |
| LoadingLayer | 加载界面 |

## 13. UI 验收标准

- 装备 Tooltip 能让玩家 3 秒判断是否值得看。
- 地图装置能让玩家清楚知道风险收益。
- 技能连接不需要看教程也能拖拽理解。
- 战斗 HUD 不遮挡 Boss 技能提示。
- 背包、仓库、地图、技能都支持手柄导航。
