# 31_HUD 战斗界面：血条、药剂、技能、小地图、目标、掉落标签


> 设计边界说明：本项目可以参考《流放之路2》这类暗黑刷宝 ARPG 的信息架构、交互复杂度和系统深度，但不能一比一复制其 UI 视觉、图标、文字、专有数值、专有命名、具体排版截图。本批文档采用“同类结构 + 原创表现”的方式：界面功能、层级、预制体和数据绑定可直接用于 Unity 原型开发。


## 1. HUD 目标

3D ACT 操作模式下，玩家更多关注角色动作、闪避、锁定目标和技能冷却。因此 HUD 要比传统 2D 锁视角刷宝游戏更强调：

1. 锁定目标信息。
2. 技能冷却和资源消耗。
3. 闪避/体力/架势资源。
4. 地面掉落可读性。
5. Boss 阶段和范围预警。

掉落标签显示规则：

| 物品 | 显示规则 |
|---|---|
| 普通白装 | 默认隐藏，可按 Alt 显示 |
| 魔法装备 | 近距离显示 |
| 稀有装备 | 常显，带边框 |
| 独特装备 | 常显，带强提示音和光柱 |
| 货币 | 常显 |
| 地图钥石 | 常显 |
| 任务物品 | 常显，不受过滤影响 |

## 10. HUD 输入

| 输入 | 功能 |
|---|---|
| Alt | 显示全部掉落标签 |
| Z | 切换掉落标签显示模式 |
| Tab | 展开/收起大地图 |
| 鼠标中键/手柄 R3 | 锁定目标 |
| 数字键 1-5 | 使用药剂 |
| Q/E/R/F/鼠标键 | 释放技能 |
| Space | 闪避 |

## 11. 原型验收标准

1. HUD 可以显示血量、能量、药剂、技能栏、小地图。
2. 技能使用后显示冷却遮罩。
3. 资源不足时技能槽变暗并提示。
4. 锁定敌人后显示目标信息条。
5. Boss 出现时显示大型 Boss 血条。
6. 掉落物根据稀有度显示不同标签。
