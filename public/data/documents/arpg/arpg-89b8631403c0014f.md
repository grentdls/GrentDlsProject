# 197 装备体系接入总览：部位定位、词条、套装、打造

## 1. 文档目标

本批文档用于把前面已经扩展的数值玩法、词条玩法、技能标签、天赋方向，正式接入装备系统。

核心目标：

```text
装备不只是加攻击和防御
而是让每个部位都有明确定位
让每个稀有度有明确词条结构
让固定属性、随机属性、套装属性、传奇机制各司其职
让装备、技能、天赋形成完整构筑闭环
```

---

## 2. 装备体系总结构

```text
EquipmentSystem
├── EquipmentSlotDefinition      装备部位定义
├── EquipmentBaseType            装备基底
├── EquipmentRarityRule          稀有度规则
├── EquipmentImplicitRule        隐性固定属性
├── EquipmentFixedAffixRule      固定词条属性
├── EquipmentRandomAffixRule     随机词条属性
├── EquipmentSetRule             套装规则
├── EquipmentUniqueRule          独特/传奇规则
├── EquipmentCraftingRule        洗练/打造/重铸
├── EquipmentDropGeneration      掉落生成
├── EquipmentTalentLinkRule      天赋接入
└── EquipmentSkillTagLinkRule    技能标签接入
```

---

## 3. 装备属性来源分层

一件装备最终属性由 7 层组成：

```text
1. 部位基础定位
2. 装备基底属性
3. 隐性固定属性
4. 稀有度随机词条
5. 打造词条
6. 套装词条
7. 独特/传奇机制
```

示例：一件胸甲

```text
部位定位：生存防御
基底属性：护甲 + 120，生命 + 80
隐性属性：受到近战伤害 -3%
随机词条：生命 +10%，火抗 +18%，受击反伤 +60
打造词条：护盾回复速度 +12%
套装词条：3件套时召唤物生命 +20%
传奇机制：受到致命伤时消耗全部护盾保命，冷却 60 秒
```

## 4. 装备部位基础定位

### 4.1 武器
主定位：输出来源。

提供：
```text
基础伤害
攻击速度 / 施法速度
暴击率
武器类型标签
技能适配方向
穿甲 / 元素附伤 / 投射物 / 召唤物 / 控制词条入口
```

### 4.2 副手
主定位：战斗风格分支。

类型：
```text
盾牌：格挡、防御、反击、破韧
法器：法术、护盾、元素、保留
副武器：双持、攻速、暴击、连击
箭袋：投射物、远程、弱点
```

### 4.3 头盔
主定位：技能、感知、召唤、控制抗性。

提供：
```text
技能等级
召唤物数量
控制抗性
冷却缩减
异常效果
```

### 4.4 上衣 / 胸甲
主定位：生命、防御、护盾、承伤规则。

提供：
```text
生命
护甲
护盾
伤害减免
受击触发
破盾保护
```

### 4.5 手套
主定位：击中、攻速、施法速度、异常施加。

提供：
```text
攻击速度
施法速度
击中附伤
击中施加异常
暴击触发
召唤物击中
```

### 4.6 鞋子
主定位：移动、闪避、减速抗性、位移技能。

提供：
```text
移动速度
闪避
减速抗性
冰缓抗性
位移技能冷却
闪避后触发
```

### 4.7 腰带
主定位：药剂、资源、生存补强、承伤缓冲。

提供：
```text
药剂效果
药剂持续时间
生命
护盾
资源回复
受击后触发
```

### 4.8 戒指
主定位：抗性、元素、触发词条、资源。

提供：
```text
元素抗性
元素附伤
击杀触发
击中触发
资源回复
异常联动
```

### 4.9 项链
主定位：构筑核心、关键属性、技能等级、机制增强。

提供：
```text
全部属性
技能等级
关键机制词条
异常效果
召唤物增强
投射物/AOE/控制大方向
```

## 5. 稀有度规则

装备稀有度决定随机词条数量、可出现词条等级、是否允许特殊机制。

| 稀有度 | 固定属性 | 随机词条数 | 是否可打造 | 是否可套装 | 是否可传奇机制 |
|---|---:|---:|---|---|---|
| 普通 | 基底 | 0 | 可升级 | 否 | 否 |
| 魔法 | 基底 + 隐性 | 1-2 | 可洗 | 否 | 否 |
| 稀有 | 基底 + 隐性 | 3-5 | 可洗/可打造 | 可 | 否 |
| 套装 | 基底 + 隐性 + 套装ID | 2-4 | 可洗部分 | 是 | 否 |
| 独特/传奇 | 固定机制 | 固定或少量随机 | 通常不可洗核心 | 可特殊 | 是 |
| 神器/终局 | 固定机制 + 高级随机 | 4-6 | 终局打造 | 可 | 是 |

本项目第一版建议：

```text
普通：0 随机
魔法：1-2 随机
稀有：3-5 随机
套装：2-4 随机 + 套装加成
传奇：固定机制 + 1-3 浮动数值
```

## 6. 固定属性与随机属性

### 6.1 固定属性
固定属性来自：
```text
装备部位
装备基底
套装件
传奇设计
```

固定属性用于保证装备定位稳定。

例如：
```text
胸甲必定有生命/护甲/护盾之一
鞋子必定有移动速度或闪避倾向
武器必定有基础伤害
戒指必定偏抗性或元素
```

### 6.2 随机属性
随机属性来自：
```text
前缀池
后缀池
部位专属词条池
流派词条池
稀有度限制
物品等级限制
副本掉落倾斜
```

随机属性用于制造刷装深度。

## 7. 套装玩法

套装不是简单加属性，应该强化某个流派。

套装结构：

```text
套装ID
套装件列表
2件套效果
3件套效果
5件套效果
可选部位
套装词条池
套装掉落来源
```

示例：

```text
破甲战铠套装
部位：头盔、胸甲、手套、鞋子、腰带

3件套：穿甲 +18%，重击破韧伤害 +20%
5件套：破韧敌人时，下一次重击必定暴击，并造成额外真实伤害
```

## 8. 装备与天赋接入

装备负责“给材料”，天赋负责“把材料变成流派”。

示例：

```text
装备提供：
+投射物数量
+投射物分裂
+远距离增伤

天赋强化：
远距离命中时，投射物必定穿透第一个敌人
投射物分裂后仍可造成 70% 伤害
```

如果只靠装备，会变成堆数值；  
如果只靠天赋，会缺少刷装乐趣。  
两者必须互相咬合。

---

## 9. 装备与技能接入

技能必须通过标签接受装备加成。

示例：

```text
鞋子：位移技能冷却 -15%
只影响 SkillTag = Movement 的技能

戒指：火焰技能击杀时爆炸
只影响 SkillTag = Fire + Hit 的技能

手套：击中有概率流血
只影响可以 Hit 的技能，不影响 DOT
```

## 10. 第一版落地建议

优先做以下部位定位：

```text
武器：输出、暴击、穿甲、元素、投射物
胸甲：生命、护甲、护盾、受击
鞋子：移动速度、闪避、减速抗性
手套：击中、攻速、异常
头盔：技能等级、召唤、控制抗性
腰带：药剂、生命、资源
戒指：抗性、元素、击杀/击中
项链：构筑核心、技能等级、关键机制
```

优先做以下装备系统：

```text
稀有度随机 1-5 词条
部位词条池
前缀/后缀
套装 3/5 件
随机洗练
固定传奇机制
UI 分组显示
```
