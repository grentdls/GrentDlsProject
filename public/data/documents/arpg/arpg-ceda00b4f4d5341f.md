# 210 装备流派套装示例库：穿甲、召唤、护盾、投射物、控制

## 1. 碎甲战铠：穿甲重击套

部位：
```text
头盔、胸甲、手套、鞋子、腰带
```

3件套：
```text
穿甲 +18%
重击破韧伤害 +20%
```

5件套：
```text
破韧敌人时，下一次重击必定暴击，并造成额外真实伤害。
```

推荐技能：
```text
蓄力重斩
跳劈
盾裂冲击
```

推荐天赋：
```text
重击穿甲
破韧处决
蓄力霸体
```

## 2. 亡骨契约：召唤爆炸套

3件套：
```text
召唤物数量 +1
召唤物生命 +20%
```

5件套：
```text
召唤物死亡时爆炸，造成其最大生命 18% 的火焰或暗影伤害。
```

随机套装词条：
```text
召唤物伤害
召唤物攻速
召唤物抗性
召唤物击杀召唤骷髅
```

## 3. 星辉护幕：满盾法术套

3件套：
```text
最大护盾 +25%
护盾回复速度 +20%
```

5件套：
```text
满护盾时，法术伤害提高 30%；护盾破裂后获得 2 秒护盾回复不中断。
```

推荐天赋：
```text
护盾转闪电附伤
满盾施法
护盾回复不中断
```

## 4. 疾风猎装：远距投射物套

3件套：
```text
投射物速度 +25%
远距离命中伤害 +18%
```

5件套：
```text
远距离暴击时，投射物分裂一次，分裂投射物造成 60% 伤害。
```

```text
分裂箭
```

## 5. 霜缚仪式：控制爆破套

3件套：
```text
控制持续时间 +20%
对被控制敌人伤害 +15%
```

5件套：
```text
冻结或束缚结束时，对目标周围造成一次冰冷爆裂。
```

Boss 换算：
```text
对 Boss 的冻结和束缚转化为额外韧性伤害。
```

## 8. 血誓狂怒：低血吸血套

3件套：
```text
低血时伤害 +25%
吸血上限 +30%
```

5件套：
```text
低血时，你的过量吸血会转化为临时护盾。
```

代价：
```text
最大护盾降低 30%
```

---

## 9. 套装设计注意事项

```text
3件套必须能启动流派
5件套必须有玩法质变
套装不能全是纯数值
套装要和技能标签联动
套装要和天赋形成组合
套装必须允许散件和传奇竞争
```
