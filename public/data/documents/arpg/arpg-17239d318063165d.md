# 28_商店 UI：普通商人、铁匠铺、技能商人、药剂商人


> 设计边界说明：本项目可以参考《流放之路2》这类暗黑刷宝 ARPG 的信息架构、交互复杂度和系统深度，但不能一比一复制其 UI 视觉、图标、文字、专有数值、专有命名、具体排版截图。本批文档采用“同类结构 + 原创表现”的方式：界面功能、层级、预制体和数据绑定可直接用于 Unity 原型开发。

## 4. 买入流程

```text
玩家与商人交互
→ 打开商店
→ 选择买入页
→ 点击商品
→ 右侧显示玩家背包，中央显示商品详情
→ 检查货币是否足够
→ 点击购买
→ 如果可堆叠，弹数量选择
→ 扣除货币
→ 加入背包
→ 刷新商品库存
```

## 5. 卖出流程

```text
打开商店卖出页
→ 玩家点击背包物品
→ 中央显示售价
→ 点击出售
→ 物品移入回购列表
→ 玩家获得货币
→ 回购页显示最近出售物品
```

### 6.1 铁匠功能说明

| 功能 | 输入 | 输出 | UI 重点 |
|---|---|---|---|
| 强化 | 装备 + 强化材料 + 货币 | 提高品质或基础值 | 成功率、失败保护 |
| 打孔 | 装备 + 打孔材料 | 增加/调整孔位 | 预览孔位 |
| 重铸 | 装备 + 重铸货币 | 随机改变词条 | 高风险警告 |
| 拆解 | 装备 | 材料/碎片 | 批量拆解 |
| 修理 | 受损装备 + 货币 | 耐久恢复 | 费用预览 |
| 打造 | 装备 + 配方 + 材料 | 添加一条打造词条 | 词条池选择 |

## 10. 商店刷新规则

| 类型 | 刷新时机 |
|---|---|
| 普通商人 | 玩家升级、章节推进、每日刷新、手动刷新 |
| 铁匠配方 | 任务解锁、地图掉落图纸解锁 |
| 技能商人 | 角色等级、主线进度、职业专精解锁 |
| 药剂商人 | 地区等级、药剂升级任务 |
| 地图商人 | 进入终局后解锁，按地图等级刷新 |

## 11. 原型验收标准

1. 普通商店可以买入、卖出、回购。
2. 铁匠铺能放入装备和材料并显示结果预览。
3. 技能商人能购买技能核心和辅助模块。
4. 药剂商人能升级药剂槽。
5. 商店和背包之间支持 Ctrl 点击快速交易。
6. 手柄焦点可以从商品列表移动到背包和确认按钮。
