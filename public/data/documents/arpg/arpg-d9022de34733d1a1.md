# 266 Unity HUD 工程实现规范：Canvas、TMP、Layout、Raycast 与材质

## 1. Canvas 分区

```text
Canvas_Static
Canvas_PlayerStatus
Canvas_SkillBar
Canvas_WorldHud
Canvas_DamageText
Canvas_Minimap
Canvas_Popup
```

不要按每个控件建立 Canvas，也不要把所有系统塞进一个 Canvas。

## 2. Layout 系统

高风险组件：

```text
HorizontalLayoutGroup
VerticalLayoutGroup
GridLayoutGroup
ContentSizeFitter
AspectRatioFitter
```

可以用于低频菜单，但不建议用于：

```text
伤害跳字
敌人血条
技能槽
高频 Buff 增删区
```

这些区域使用固定锚点和固定槽位。

## 3. SetActive

频繁 SetActive 会触发 OnEnable/OnDisable、布局和 Canvas 重建。

高频 Overlay 可使用：

```text
Image.enabled
CanvasGroup.alpha
材质参数
```

长期隐藏对象仍可 SetActive(false)。

## 4. Raycast

关闭不需要交互的：

```text
Image.raycastTarget
TMP.raycastTarget
```

World HUD 和伤害跳字 Canvas 不需要 GraphicRaycaster。

## 5. TMP 字体

```text
HUD 数字独立字体 Atlas
中文说明独立 Atlas
预热常用字符
避免运行时扩图
```

## 6. 材质与图集

```text
共享 Sprite Atlas
共享 TMP 材质
元素颜色优先顶点色
避免每个技能按钮独立材质实例
```

建议 Atlas：

```text
HUD_Common
HUD_Skills
HUD_Status
HUD_Minimap
HUD_Enemy
```

## 7. Mask

优先：

```text
RectMask2D > Mask > 复杂 SoftMask
```

## 8. Animator

适合少量明确状态，不适合每个伤害数字、血条和 Buff 计时。高频动画用轻量代码插值。

## 9. 统一 Tick 管理

```text
HudTickManager
├── CooldownTickList
├── WorldHudPositionTickList
├── FloatingTextTickList
└── MinimapTickList
```

统一控制刷新频率、分帧、暂停和优先级。

## 10. GC 规范

禁止高频：

```text
new List
LINQ
字符串拼接
闭包
频繁协程
GetComponent
Camera.main
Find
```

缓存组件和引用。

## 11. 资源预加载

进入战斗前预加载：

```text
技能图标
Buff 图标
字体
材质
血条 Prefab
伤害数字 Prefab
```

## 12. 暂停与隐藏

暂停或过场时：

```text
停止敌人血条位置刷新
停止伤害跳字 Tick
停止小地图 Camera
保留必要菜单动画
```
