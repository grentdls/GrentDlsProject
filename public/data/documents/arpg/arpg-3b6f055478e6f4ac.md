# 276 敌人生成 Prefab、脚本组件、Scene Gizmo 与编辑器预览

## 1. 固定生成 Prefab

```text
PF_EnemySpawnPoint
├── SpawnAnchor
├── FacingArrow
├── ActivationVolume
├── SpawnVFXPoint
├── EnemyFixedSpawner
├── EnemyLevelConfig
├── EnemyRespawnConfig
├── EnemyAggroOverride 可选
├── SpawnConditionList
├── DeathActionList
└── DebugRoot
```

## 3. 核心组件职责

### EnemyFixedSpawner

```text
解析敌人定义
计算等级
生成单个敌人
绑定死亡事件
处理固定刷新
```

### EnemyAreaSpawner

```text
解析敌人列表
抽取敌人
采样位置
批量生成
维护运行时分组
```

### EnemySpawnRuntimeGroup

```text
追踪所属敌人
维护 AliveCount
防止重复死亡结算
报告区域完成
```

### EnemyRespawnController

```text
刷新条件
刷新倒计时
最大刷新次数
玩家距离检查
波次推进
```

## 4. Scene Gizmo

固定生成点显示：

```text
敌人图标或简化模型
出生朝向箭头
激活范围
警戒范围预览
等级文本
刷新文本
```

区域生成器显示：

```text
生成盒子
激活盒子
排除区域
采样点
最大生成数量
敌人列表名称
刷新方式
```

颜色建议：

```text
蓝色：生成区域
绿色：激活区域
红色：排除区域
黄色：警戒范围
紫色：巡逻路线
```

## 7. 关卡校验工具

菜单：

```text
Tools / Game / Enemy Spawn Validator
```

检查：

```text
重复 SpawnerId
EnemyDefinition 为空
等级区间反向
区域体积为 0
没有 SpawnList
全部权重为 0
MaxAliveCount 小于生成数量
NavMesh 必须但不存在
刷新间隔小于安全值
Boss 开启无限刷新
木桩仍开启攻击
SpawnPoint 位于墙内
```
