# 128 UI信息可视性改版总览：设计目标、视觉层级与改版范围

## 1. 文档目的
本批文档用于解决当前 **技能界面 / 装备界面 / 天赋界面** 过度文字化、信息堆叠、缺乏视觉分层、难以快速阅读的问题。

本次改版目标是：
- 参考高信息密度 ARPG（如《流放之路2》一类）在 **信息层级、卡片结构、词条高亮、模块分区、悬浮详情、对比展示、按钮反馈** 等方面的优点。
- 不直接复制原版美术资源、图标、专有文案和具体布局比例，而是沉淀为我们项目自己的 **可实现 UI 规范**。
- 将“看文字”改为“看结构 + 看颜色 + 看图标 + 看标签”。

---

## 2. 本次改版覆盖范围
本次改版覆盖 4 大块：

1. **技能界面与技能详情**
2. **装备界面与装备详情**
3. **天赋界面与单节点详情**
4. **全局按钮与交互反馈状态**

涉及 UI 页面：
- 整备页 / 技能页 / 装备页 / 天赋页
- 商店物品详情浮窗
- 背包物品详情浮窗
- 角色装备对比浮窗
- 技能学习/替换/升级浮窗
- 天赋确认、重置、预览浮窗
- 所有通用按钮、分页、页签、筛选、下拉、切换、确认弹窗

---

## 3. 核心问题总结
当前问题：
- 所有信息几乎都以纯文本列表展示。
- 标题、关键词、词条、限制条件、提示文本没有清晰层级。
- 属性区、效果区、描述区、消耗区、成长区混在一起。
- 不同稀有度、不同伤害类型、不同标签没有明显视觉区分。
- 按钮没有 Hover / Press / Disabled 的即时反馈，缺乏手感。
- 装备、技能、天赋都缺少“重点信息一眼看懂”的设计。

用户感知问题：
- 看不出这个技能到底强在哪里。
- 看不出这件装备和身上装备谁更好。
- 看不出某个天赋是“增伤、保命、机制、触发、资源、召唤、移动”哪一类。
- 看界面只能逐行读字，阅读成本高。

---

## 4. 改版后的整体视觉原则

### 4.1 信息层级原则
UI 所有信息统一分为五层：

#### L1：核心识别层（第一眼要看到）
- 名称
- 图标
- 稀有度/品质
- 关键数值
- 类型标签
- 当前状态（已装备 / 已学习 / 可升级 / 不可用）

#### L2：主要效果层（第二眼）
- 主属性 / 主效果 / 主要词条
- 技能核心机制
- 装备主词缀
- 天赋主收益

#### L3：附加效果层（第三眼）
- 次级词条
- 条件效果
- 额外触发
- 进阶说明

#### L4：成长与限制层
- 等级需求
- 属性需求
- 消耗
- 冷却
- 装备限制
- 前置节点

#### L5：说明与叙述层
- Flavor 文案
- 说明性文本
- 操作提示
- 设计性注释

> 规则：L1 > L2 > L3 > L4 > L5 的字号、亮度、权重逐级下降。

---

### 4.2 色彩分层原则
颜色只用于“传达信息”，不可滥用。统一色彩语义：

- **白色/浅灰**：普通信息
- **蓝色**：魔法/法术/冷静型信息
- **金色**：稀有/史诗/传奇/关键强化
- **绿色**：生命/恢复/增益/可用/提升
- **红色**：伤害/危险/警告/不可用
- **紫色**：诅咒/暗影/异常/神秘机制
- **橙色**：火焰/爆发/重击/传奇强调
- **青色**：冰冷/控制/防御型法力护盾
- **黄色**：闪电/敏捷/暴击/速度

禁止：
- 同一块文字出现过多彩色。
- 颜色代替结构。
- 所有文字都高亮。

---

### 4.3 框体分区原则
每个详情面板必须使用明确的模块框体，而不是一整块文字堆叠。

详情类浮窗统一划分为：
1. 头部识别区
2. 主信息区
3. 效果区
4. 条件/限制区
5. 成长/对比区
6. 底部操作区

每个区块需具备：
- 标题条或标签头
- 背景明暗差异
- 内边距
- 区块间距
- 分隔线/细边框

---

## 5. 三个重点页面的改版方向

### 5.1 技能界面
重点提升：
- 技能标签图标化
- 伤害类型可视化
- 冷却/消耗/施法方式单独模块化
- 等级成长与辅助模块效果分块展示
- 当前快捷栏绑定状态一眼可见

### 5.2 装备界面
重点提升：
- 装备类型与部位单独强调
- 主词条、前缀、后缀、特殊词条分组
- 对比装备的提升/下降颜色明确
- 孔位、品质、耐久、需求、套装、传奇效果模块化
- 可镶嵌、可强化、不可装备状态明显

### 5.3 天赋界面
重点提升：
- 节点类型（小点 / 中点 / 大点 / 关键点 / 专精点）明确区分
- 节点收益摘要前置
- 前后路径、点数消耗、预览变化清晰
- 单个天赋详情支持“当前属性变化预览”
- 节点归类标签化（进攻 / 防御 / 资源 / 召唤 / 位移 / 异常 / 暴击 等）

## 6. 统一视觉令牌（Design Tokens）

### 6.1 字号层级建议
- 页面标题：30-36
- 二级标题：24-28
- 详情标题：22-26
- 模块标题：18-20
- 重点数值：20-24
- 常规正文：16-18
- 次级正文：14-16
- 说明备注：12-14

### 6.2 透明度层级
- 主框背景：90% 不透明
- 子块背景：82%-88%
- 分割条背景：70%-78%
- 次级信息：文字 70%-80%
- 禁用态：整体 35%-45%

### 6.3 边框规则
- 主框：1-2 px 强调边
- 次框：1 px 弱边
- 高亮框：外发光 + 边框颜色变化
- 稀有物品：边角装饰允许更华丽

## 7. 通用交互规则

### 7.1 鼠标悬停（Hover）
所有可交互按钮、标签页、物品格子、技能格子、天赋节点，必须有 Hover 反馈：
- 轻微放大（1.02 ~ 1.06）
- 边框亮起
- 背景亮度提升
- 播放轻提示音
- Tooltip 延迟弹出（0.1 ~ 0.2 秒）

### 7.2 按下（Pressed）
- 按钮轻微下压
- 阴影缩短
- 内部高光减弱
- 按下音效

### 7.3 选中（Selected）
- 外框常驻高亮
- 标签页高亮条
- 图标或标题染色
- 如果是当前装备/当前技能，增加“当前使用中”角标

### 7.4 不可用（Disabled）
- 降低亮度
- 文本灰化
- 不满足条件处显示红字原因
- Hover 仍可显示原因 Tooltip

## 8. UI 预制体改版原则
- 不做整页写死。
- 全部页面必须通过可复用模块搭建。
- 模块优先于页面，页面优先于业务逻辑。

基础预制体必须包括：
- Panel_Header
- Panel_Section
- Label_Tag
- Stat_Row
- Compare_Row
- Icon_TextChip
- Requirement_Row
- Button_Primary / Secondary / Ghost / Danger
- Tooltip_Skill
- Tooltip_Item
- Tooltip_PassiveNode
- Tabs_Top
- Tabs_Sub
- List_FilterBar
- Grid_Slot
