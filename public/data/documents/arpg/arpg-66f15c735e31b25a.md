# 职业与技能预制体结构：Animator、VFX、SFX、Hitbox

> 参考边界：本项目参考暗黑刷宝 ARPG 的系统结构：职业起点、主动技能、辅助模块、保留技能、触发技能、巨型被动树、职业专精树、装备词条联动、Boss 机制与终局构筑。
> 不直接复制任何商业游戏的职业名、技能名、图标、数值、UI截图、专有词条与怪物设定。下面所有职业、技能、天赋节点、数值区间、特效表现均为项目原创，用于 Unity 原型和后续美术/程序落地。

## 4. Animator 分层

```text
Base Layer：移动、待机、死亡
UpperBody Layer：上半身施法、射击
FullBody Skill Layer：重击、跳斩、翻滚、变形
HitReact Layer：受击、硬直、击飞
Override Layer：武器动作覆盖
```

## 5. Animation Event 标准

| Event | 作用 |
|---|---|
| EVT_SkillStart | 技能开始，锁输入 |
| EVT_CostPay | 扣资源 |
| EVT_HitboxOn | 开启命中判定 |
| EVT_HitboxOff | 关闭命中判定 |
| EVT_ProjectileSpawn | 生成投射物 |
| EVT_AreaSpawn | 生成区域 |
| EVT_VFXSpawn | 播放特效 |
| EVT_SFXPlay | 播放音效 |
| EVT_CancelOpen | 开放取消窗口 |
| EVT_SkillEnd | 技能结束 |

## 7. VFX 规范

- 特效必须分 Cast、Travel、Hit、End。
- 元素变体必须支持颜色和材质切换。
- VFX 不能承担伤害逻辑。
- 大招必须有屏幕层级控制，避免 UI 被完全遮挡。

## 8. SFX 规范

```text
轻技能：0.2-0.8 秒
普通技能：0.5-1.5 秒
重击技能：1.0-2.5 秒
大招：2.0-5.0 秒
```

## 10. 验收标准

- 所有职业都能复用 Base Controller。
- 技能不依赖单个角色 Prefab，可以跨职业测试。
- Hitbox Gizmo 在编辑器内可视化。
- VFX/SFX 可通过 Addressables 加载。
- Animator Event 和 SkillRuntime 不互相硬编码。
