# 282 上跃技能系统：普攻中跳跃派生、武器限制与可替换

## 1. 定义

上跃技能是特殊槽位：

```text
RisingAttackSlot
```

默认由地面普攻中按下跳跃键触发。

## 2. 触发条件

```text
角色处于地面
正在释放地面普攻
当前段开启 RisingBranchWindow
上跃槽中有有效技能
武器条件满足
角色未被控制
```

## 3. 执行流程

```text
取消当前普攻部分后摇
→ 播放上跃技能
→ 攻击前方/上方敌人
→ 角色离地
→ 对普通敌人尝试浮空
→ 结束后进入空中状态
→ 下一次左键执行空中普攻第一段
```

## 4. 可替换方向

```text
快速挑空
高破韧上挑
范围旋升
后撤升空
踏箭腾空
法术托举
踏剑升空
```

## 5. 可配置参数

```text
LaunchVerticalSpeed
LaunchForwardSpeed
GravityDelay
AirControlLockTime
LaunchOnMiss
LiftForce
PoiseDamage
RisingInputBuffer
```

## 6. 武器限制

```text
AllowedWeaponTags
ForbiddenWeaponTags
RequiredHandMode
```

例如：

```text
挑空斩：单手剑
震升锤：单手锤/双手锤
踏箭腾空：弓/弩
御风升腾：法杖/法器
```

## 7. 槽位限制

上跃技能只能放入：

```text
RisingAttackSlot
```

不能放入普通主动技能槽、地面普攻槽或空中普攻槽。

## 8. 未命中处理

默认：

```text
LaunchOnMiss = true
```

部分高风险重武器技能可以设置为未命中不升空。

## 9. Boss 换算

对 Boss：

```text
不强制浮空
转为额外韧性伤害
保留命中停顿和升空动作
```
