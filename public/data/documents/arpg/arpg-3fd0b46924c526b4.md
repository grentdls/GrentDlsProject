# 224 跟踪飞弹轨迹规则：时间到达、转向、预测、丢失目标

## 1. 跟踪飞弹完整参数

跟踪弹不能只是每帧 `LookAt(Target)`。完整配置至少包括：

```text
飞行总时间、初始速度、最大速度、加速度、减速度
转向速度、转向加速度、锁定延迟、锁定融合时间
目标预测、近距离辅助、终点冲刺、丢失目标、重新搜索
多弹编队、路径分离、同步到达
```

## 2. 到达模式

### 2.1 按速度到达 SpeedBased

```text
到达时间由距离和速度决定。
```

```json
{
  "arrivalMode": "SpeedBased",
  "initialSpeed": 8.0,
  "maxSpeed": 18.0,
  "acceleration": 12.0
}
```

适合普通导弹、箭矢、常规追踪魔法弹。

### 2.2 固定时间到达 TimeBased

```text
飞弹无论初始距离如何，都在指定时间附近到达目标。
desiredSpeed = remainingDistance / remainingTime
```

```json
{
  "arrivalMode": "TimeBased",
  "flightTime": 1.5,
  "minSpeed": 4.0,
  "maxSpeed": 30.0,
  "maxAcceleration": 20.0,
  "maxDeceleration": 15.0
}
```

适合多枚飞弹同步命中、Boss 演出、技能 Timeline 精确配合。

## 3. 跟踪算法

### 普通追逐 PurePursuit

每帧朝目标当前位置转向。简单稳定，但高速时容易追尾绕圈。

### 平滑追踪 SmoothHoming

```text
currentDirection = RotateTowards(currentDirection, desiredDirection, turnRate * dt)
```

```json
{
  "turnMode": "Smooth",
  "turnRate": 240.0,
  "turnAcceleration": 360.0,
  "maxTurnRate": 720.0
}
```

### 预测拦截 PredictiveIntercept

```text
predictedPosition = targetPosition + targetVelocity * predictionTime
```

适合高速玩家、冲刺目标和远距离导弹。

### 比例导航 ProportionalNavigation

按目标视线角速度修正横向加速度，适合高速导弹，较少出现目标附近绕圈。

```json
{
  "turnMode": "ProportionalNavigation",
  "navigationConstant": 3.5,
  "maxLateralAcceleration": 25.0
}
```

## 4. 锁定阶段

推荐轨迹：

```text
0.00-0.20 秒：朝施法者前方起飞
0.20-0.50 秒：逐渐融合到跟踪方向
0.50 秒后：完全跟踪
```

```json
{
  "lockDelay": 0.2,
  "lockBlendTime": 0.3,
  "initialLaunchDirection": "CasterForward"
}
```

## 5. 终点冲刺

距离目标小于阈值时：

```text
提高速度、提高转向、降低曲线幅度、增强拖尾、关闭过度预测
```

```json
{
  "terminalPhase": {
    "triggerDistance": 3.0,
    "speedMultiplier": 1.5,
    "turnRateMultiplier": 1.8,
    "vfxIntensityMultiplier": 1.4
  }
}
```

## 6. 近距离防绕圈

```text
距离 < 1.2 米：停止预测
距离 < 0.8 米：切换直线冲刺
距离 < 命中辅助半径：直接执行碰撞检查
```

## 7. 目标丢失

目标死亡、隐身、传送、进入无敌或离开范围后，可配置：

```text
飞向最后位置
搜索新目标
转直线
落地爆炸
原地爆炸
返回施法者
立即消失
```

```json
{
  "lostTargetMode": "SearchNewTarget",
  "searchRadius": 8.0,
  "searchDuration": 0.8,
  "fallbackMode": "FlyToLastPosition"
}
```

重新锁定优先级：

```text
被标记目标 > 飞行方向前方 > 最近目标 > 最低生命 > 未被其他飞弹锁定
```

## 8. 多枚飞弹编队

```text
扇形、环形、纵队、左右交错、螺旋编队、先散开后汇聚
```

多弹需要：

```text
相位差、路径分离力、最小间距、目标均摊、是否同步到达
```

```json
{
  "trajectoryType": "Homing",
  "arrivalMode": "TimeBased",
  "flightTime": 1.8,
  "turnMode": "Predictive",
  "predictionTime": 0.3,
  "formation": "Radial",
  "terminalPhase": {
    "triggerDistance": 2.5,
    "speedMultiplier": 1.7
  }
}
```
