# 70. 表现配置：动画、VFX、SFX、镜头、UI反馈


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第五批 —— 技能编辑器 / 怪物技能编辑器 / 策划配置工具  
> 目标：让策划不改代码，也能配置玩家技能、怪物技能、Boss 阶段技能、辅助模块、Buff、VFX/SFX、数值成长、AI 使用条件与测试验收。


---

## 1. 设计目标

技能编辑器必须让策划和特效美术能把技能表现完整配置进去：

- 动画状态机参数。
- 动画事件时间点。
- 武器挂点和角色骨骼挂点。
- VFX 生成位置、缩放、跟随规则、生命周期。
- SFX 播放、随机音色、距离衰减。
- 命中反馈、受击硬直、击退、定帧。
- 镜头震动、镜头聚焦、手柄震动。
- UI 技能图标、冷却、资源不足提示、掉落/战斗提示。

## 4. 动画事件同步

不要完全依赖 Animation Event，因为策划调时间不方便。推荐使用技能时间轴驱动。

同步模式：

```text
TimelineDriven：技能时间轴触发 Hitbox/VFX/SFX
AnimationEventDriven：动画事件触发
Hybrid：动画事件通知，但时间轴做兜底
```

第一版建议：TimelineDriven。

WarningShape：

```text

Line
Grid
```

规则：


## 13. 定帧 HitStop

ACT 打击感需要定帧，但要可控。

字段：

```text
hitStopForCaster
hitStopForTarget
hitStopDuration
hitStopScale
maxHitStopPerSecond
ignoreForDOT
ignoreForMinions
```

建议：

| 技能类型 | 定帧 |
|---|---:|
| 普通攻击 | 0.03 - 0.06s |
| 重击 | 0.08 - 0.12s |
| 爆炸 | 0.05 - 0.10s |
| DOT | 0 |
| 召唤物攻击 | 0 - 0.03s |

## 17. 性能预算

每个技能必须有性能预算字段。

```text
PerformanceBudget
├── maxParticles
├── maxLights
├── maxDecals
├── maxTrailCount
├── maxAudioVoices
├── allowScreenSpaceEffect
├── mobileQualityFallback
└── lowEndFallbackVFX
```

预算建议：

| 技能类型 | 粒子数 | 动态光 | Decal |
|---|---:|---:|---:|
| 普通攻击 | < 80 | 0 | 0 |
| 主力技能 | < 200 | 0-1 | 0-1 |
| 爆发技能 | < 500 | 1 | 1-2 |
| Boss 技能 | < 1000 | 1-3 | 1-4 |
| 地图全屏机制 | 必须有低配替代 | 0-2 | 控制数量 |

## 18. 表现预览功能

编辑器右侧必须支持：

```text
Preview Animation：只播动画
Preview Cast VFX：只播起手特效
Preview Hit VFX：只播命中特效
Preview Full Skill：完整释放
Preview With Target：带假人目标
Preview Boss Warning：只看 Boss 预警
Preview Low Quality：低配表现预览
```

---

## 19. 表现校验规则

| 规则 | 级别 |
|---|---|
| 技能没有动画 | Warning，怪物瞬发技能可忽略 |
| Hitbox 事件没有命中特效 | Warning |
| Boss 高伤技能没有 WarningVFX | Error |
| VFX prefab 丢失 | Error |
| AudioClip 丢失 | Warning |
| 粒子数超过预算 | Warning |
| 动态光超过 3 个 | Warning |
| stopOnSkillEnd=false 且 lifetime=-1 | Error |
| 使用不存在的 Socket | Error |
