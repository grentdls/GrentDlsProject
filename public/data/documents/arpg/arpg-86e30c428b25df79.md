# 243 传送门系统完整规则：场景传送、目标点、预制体引用、位置配置

## 1. 系统目标

传送门支持：

```text
传送到不同场景
传送到同场景不同位置
传送到指定 SpawnPoint
传送到某个目标 Prefab
直接配置世界坐标
配置玩家朝向
配置镜头朝向
配置加载方式
配置传送条件
配置单向/双向
配置是否保存返回点
```

## 2. 传送目标类型

### SceneSpawnPoint（推荐）

```text
目标场景 + SpawnPointId
```

优点：
- 目标点在场景里可视化。
- 场景改动后不易失效。
- 可统一配置朝向、镜头和安全区。

### PrefabReference

目标场景中放置 `PF_LevelSpawnPoint`：

```text
PF_LevelSpawnPoint
├── SpawnPointController
├── PlayerAnchor
├── CameraAnchor
├── CompanionAnchorGroup
└── DebugArrow
```

跨场景不能直接保存 GameObject 引用，配置中保存 `SpawnPointId`，加载场景后由 `SpawnPointRegistry` 查找。

### DirectPosition

```json
{
  "position": [12.5, 1.2, -8.0],
  "rotationEuler": [0, 90, 0]
}
```

适合临时测试和程序生成场景，正式关卡优先使用 SpawnPoint。

### SameSceneTransform

同场景内可以直接引用 Transform，适用于楼层、电梯、隐藏宝库、短距瞬移。

## 7. 场景加载流程

```text
玩家确认传送
→ 禁止输入
→ 播放进入特效
→ 淡出画面
→ 保存当前关卡状态
→ 异步加载目标场景
→ 等待 SpawnPointRegistry 初始化
→ 解析目标点
→ 修正到可行走地面
→ 设置玩家位置和朝向
→ 清空速度/击退/击飞
→ 设置相机
→ 播放出口特效
→ 淡入画面
→ 恢复输入
```

## 8. 目标点解析优先级

```text
1. Scene + SpawnPointId
2. SameScene Transform
3. DirectPosition
4. Scene Default SpawnPoint
5. 安全回退点
```

目标找不到时必须输出错误并使用默认出生点，不能把玩家放在世界原点。
