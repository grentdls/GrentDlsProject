## 2. 武器前缀

```text
+物理伤害
+元素附加伤害
+技能伤害
+穿甲
+暴击伤害
+投射物数量
+召唤物伤害
```

示例：

```text
攻击击中附加 12-24 点火焰伤害
物理伤害提高 35%
重击技能穿透 18% 护甲
投射物技能额外发射 1 个投射物
召唤物伤害提高 28%
```

## 3. 武器后缀

```text
+暴击率
+攻击速度
+施法速度
+击杀触发
+击中触发
+异常几率
+资源回复
```

示例：

```text
击杀敌人时有 20% 概率召唤骷髅
暴击时释放一次连锁闪电，冷却 0.5 秒
击中冰缓敌人时恢复 3 点法力
```

## 6. 隐性词条

```text
剑：+近战物理伤害
匕首：+暴击率
弓：+投射物速度
法杖：+法术伤害
盾牌：+格挡率
胸甲：+护甲或护盾
鞋子：+移动速度
戒指：+元素抗性
项链：+全部属性
```

## 7. 传奇词条

传奇词条必须改变玩法。

示例：

```text
击杀燃烧敌人时，其爆炸会继续点燃附近敌人。
你的投射物不能穿透，但每次命中都会分裂。
你的召唤物死亡时会爆炸，但召唤物持续时间减少 40%。
你造成的真实伤害不能暴击，但真实伤害提高 50%。
满护盾时技能消耗生命而非法力。
```

## 8. 套装词条

```text
2件：召唤物伤害 +20%
3件：召唤物击杀时有概率召唤骷髅
4件：召唤物死亡爆炸
```


## 10. 装备 UI

装备详情必须分组显示：

```text
隐性词条
前缀
后缀
传奇词条
套装词条
打造词条
```

触发词条必须显示触发条件、概率、冷却、是否影响召唤物、是否影响 Boss。
