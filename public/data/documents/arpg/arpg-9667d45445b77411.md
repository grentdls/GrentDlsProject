# 98. 角色控制器预制体：Animator、Cinemachine、碰撞与组件结构


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 目标

本文件定义玩家角色 3C 预制体结构。所有职业角色都共用基础 Player3CController，职业差异通过外观、Animator Override、技能配置和移动参数覆盖实现。

## 3. 核心组件职责

| 组件 | 职责 |
|---|---|
| PlayerInputRouter | 把 InputAction 转成游戏命令 |
| CharacterMotor3C | 基础位移、重力、地面检测、碰撞处理 |
| PlayerCameraController | 镜头模式、锁定镜头、遮挡修正 |
| RotationController | 控制角色身体朝向 |
| JumpController | 跳跃、落地、空中控制 |
| DodgeSprintController | 闪避、疾跑、滑步、体力消耗 |
| TargetLockController | 目标搜索、锁定、切换 |
| CombatFacingController | 战斗朝向、攻击朝向辅助 |
| TraversalController | 翻越、抓边、攀爬、牵引 |
| AbilityMovementAdapter | 技能位移、Root Motion 权重 |
| AnimatorBridge | 参数同步、动画事件接收 |
| PlayerDebug3C | 调试 Gizmo、当前状态显示 |

## 5. Animator Layer

| Layer | 内容 |
|---|---|
| Base Locomotion | 待机、走、跑、疾跑、跳跃、落地 |
| Combat UpperBody | 上半身攻击、弓弩、施法 |
| FullBody Attack | 重攻击、闪避、受击、处决 |
| Additive Aim | 上半身瞄准/看向 |
| Traversal | 翻越、攀爬、抓边 |
| HitReact | 受击叠加或全身 |

## 9. 职业移动 Profile

每个职业可以覆盖移动参数：

```text
ProfessionMoveProfile_HeavyWarrior
ProfessionMoveProfile_Ranger
ProfessionMoveProfile_Monk
ProfessionMoveProfile_Mage
```

字段：

- RunSpeed。
- SprintSpeed。
- DodgeDistance。
- DodgeIFrame。
- JumpHeight。
- AirControl。
- TurnSpeed。
- LockStrafeSpeed。
- StaminaCostMultiplier。
- RootMotionScale。

## 11. 验收标准

- 替换职业模型不会破坏基础移动。
- Animator 参数能正确反映移动状态。
- 动画事件能打开/关闭 Hitbox 和取消窗口。
- CameraTarget 位置正确，不因模型身高变化导致镜头偏移严重。
- Prefab 可以直接拖进 3C 测试场景运行。
