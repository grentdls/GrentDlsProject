# 187 高级武器词条库：近战、弓弩、法杖、盾牌、双持

## 1. 近战武器词条

```text
近距离命中时，物理伤害提高 20%。
重击额外穿透 25% 护甲。
对破甲敌人造成更多伤害。
连续命中同一目标时获得连击层数。
满连击时下一次重击必定暴击。
击中流血敌人时恢复生命。
重击击杀敌人时产生冲击波。
```

## 2. 双手武器词条

```text
攻击速度降低 10%，但重击伤害提高 40%。
重击命中时造成额外破韧伤害。
蓄力满档时造成真实伤害。
对大型敌人伤害提高。
击杀敌人时震退附近敌人。
```

## 3. 匕首/双持词条

```text
背后命中暴击率 +25%。
暴击时获得 1 层连击。
双持时攻击速度 +15%。
连续暴击 3 次后释放影刃。
对中毒敌人暴击伤害提高。
```

## 4. 弓弩词条

```text
远距离命中时伤害提高。
投射物飞行越远，暴击率越高。
投射物数量 +1。
投射物命中时分裂。
投射物穿透第一个敌人。
暴击时释放连锁箭。
击杀敌人时下一发箭必定暴击。
```

## 5. 法杖/法器词条

```text
元素穿透 +12%。
满护盾时法术伤害 +25%。
暴击时施加元素暴露。
引导技能每层聚能提高伤害。
法术击中感电敌人时恢复法力。
破盾时刷新一个法术技能。
```

## 6. 盾牌词条

```text
格挡率 +8%。
格挡时反射物理伤害。
格挡后下次攻击必定暴击。
格挡时恢复护盾。
护盾破裂时释放冲击波。
盾击造成额外破韧。
```

## 7. 武器传奇词条示例

```text
你的投射物不能穿透，但每次命中都会分裂一次。
你的重击无法暴击，但会造成额外真实伤害。
暴击不会造成额外伤害，改为召唤一把幻影武器。
满护盾时，法术消耗护盾并附加闪电伤害。
近战击杀敌人时，召唤一个短暂的血影复制你的下一次攻击。
