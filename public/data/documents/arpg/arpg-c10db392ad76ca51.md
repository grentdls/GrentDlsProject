## 2. 技能购买基础规则

### 2.1 购买条件

每个技能至少有 4 类限制：

| 条件 | 说明 |
|---|---|
| 角色等级 | 控制技能解锁节奏 |
| 职业推荐 | 非硬限制，第一版建议非本职业也可买但价格更高 |
| 武器需求 | 如弓类技能需要弓，盾技需要盾 |
| 前置任务 | 特殊技能需要完成试炼或主线 |

### 2.2 价格结构

```text
技能价格 = 基础价格 × 技能等级阶段倍率 × 稀有度倍率 × 非推荐职业倍率
```

| 技能阶段 | 等级 | 基础价格 |
|---|---:|---:|
| 入门 | 1-5 | 100-300 金币 |
| 初级 | 6-12 | 400-900 金币 |
| 中级 | 13-24 | 1000-2500 金币 |
| 高级 | 25-40 | 3000-8000 金币 |
| 终局 | 41+ | 10000+ 金币 + 特殊材料 |

非推荐职业购买倍率：1.5。  
不兼容武器的技能不可购买，只显示“需要装备对应武器”。

### 2.3 购买后处理

玩家购买技能后，不是直接装备到快捷栏，而是进入：

```text
技能库存 SkillInventory
```

玩家需要在整备界面把技能装入技能槽，并绑定按键。

### 3.2 辅助模块页

辅助模块用于修改主动技能行为。

| 辅助类型 | 作用 |
|---|---|
| 连射 | 增加投射物数量，降低单发伤害 |
| 扩散 | 投射物散射 |
| 穿透 | 投射物穿过敌人 |
| 重击 | 增加近战伤害和硬直 |
| 快速施放 | 减少前摇 |
| 元素附加 | 附加火/冰/雷伤害 |
| 范围扩大 | 扩大 AoE |
| 持续延长 | 增加持续区域和 Dot 时间 |
| 召唤强化 | 提升仆从生命和伤害 |
| 资源节流 | 降低消耗，降低伤害 |
| 暴击专注 | 提升暴击，降低稳定伤害 |
| 击中回复 | 命中时恢复生命/资源，带冷却 |

### 3.3 保留技能页

保留技能是持续占用资源上限的技能。

| 类型 | 示例方向 | 作用 |
|---|---|---|
| 攻击光环 | 战意光环 | 增加攻击速度/命中 |
| 元素光环 | 炽焰环绕 / 寒霜环绕 / 雷鸣环绕 | 附加元素或异常概率 |
| 防御光环 | 石肤守护 | 增加护甲/格挡 |
| 资源光环 | 星辉流转 | 提升回蓝 / 降低消耗 |
| 姿态 | 猎手姿态 / 守御姿态 | 改变角色手感和属性倾向 |
| 召唤保留 | 魂烛侍从 | 召唤永久仆从，占用资源 |

## 6. 技能试用系统

技能商人旁边放训练场，玩家可以在购买前试用技能。

### 6.1 试用流程

```text
选中商店技能
→ 点击试用
→ 玩家进入训练状态
→ 临时装备技能到试用槽
→ 训练木桩生成
→ 30 秒后结束 / 手动退出
→ 恢复原技能配置
```

### 6.2 试用限制

1. 试用技能不消耗材料
2. 试用技能不能带出训练场
3. 试用期间不可进入副本
4. 试用期间不可保存技能配置
5. 技能数据使用当前角色属性模拟
