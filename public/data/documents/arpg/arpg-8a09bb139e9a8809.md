# 80 敌人血条规则：小怪、精英、稀有、Boss、护盾、阶段

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. 血条系统目标

血条必须让玩家快速判断：

- 目标是否快死。
- 目标是否有护盾、韧性、护甲或特殊保护。
- 目标是否正在进入危险阶段。
- 当前攻击是否有效。
- Boss 战机制是否推进。

本项目血条分为：

```text
EnemyHealthbar
├── CommonSmallBar        # 普通怪小血条
├── MagicBar              # 强化怪血条
├── EliteRareBar          # 精英/稀有怪血条
├── MiniBossBar           # 小 Boss / 地图首领血条
├── BossTopBar            # 屏幕顶部 Boss 大血条
├── BossMechanicBar       # Boss 机制条
├── ShieldOverlay         # 护盾层
├── GuardBreakBar         # 韧性/破防条
└── SegmentPhaseBar       # 分段阶段血条
```

## 2. 普通怪血条

### 2.1 显示条件

普通怪血条默认不常驻，只有在以下条件出现：

- 被玩家攻击或受到玩家伤害，显示 2 秒。
- 正在攻击玩家，显示 2 秒。
- 被玩家锁定，常驻显示。
- 玩家鼠标悬浮或手柄焦点选中，显示。
- 普通怪血量低于 20%，可短暂显示提醒击杀机会。

### 2.2 结构

```text
Prefab_Healthbar_Enemy_Common
├── Root
│   ├── CanvasGroup
│   ├── Bg_Frame
│   ├── Fill_HP
│   ├── Fill_DamageDelay       # 延迟扣血条
│   ├── Shield_Strip           # 可选，薄护盾条
│   └── StatusMiniIcons        # 最多 3 个小状态图标
```

### 2.3 视觉规则

| 项 | 规则 |
|---|---|
| 宽度 | 48-72px，按怪物体型配置 |
| 高度 | 4-6px |
| 扣血延迟 | 0.25 秒后追赶，0.35 秒完成 |
| 血量低于 20% | 血条轻微闪烁，不能过度刺眼 |
| 死亡 | 血条归零后 0.15 秒淡出 |
| 过远 | 血条缩小并淡出 |

---

## 3. 强化怪血条

强化怪用于“比普通怪重要，但不是精英”。

### 3.1 显示条件

- 战斗中距离 25m 内显示。
- 受击后显示 4 秒。
- 被锁定常驻。

### 3.2 额外内容

```text
名称/等级
HP 血条
护盾薄条，可选
1-2 个强化标签图标
```

强化标签示例：

| 标签 | HUD 图标含义 |
|---|---|
| 迅捷 | 移动/攻速较快 |
| 硬壳 | 护甲较高 |
| 寒气 | 冰冷异常 |
| 燃火 | 火焰地面/燃烧 |
| 召唤 | 会召小怪 |

---

## 4. 精英/稀有怪血条

精英怪是战斗信息重点，必须比普通怪更显眼。

### 4.1 显示条件

- 战斗状态中常驻。
- 进入玩家警戒范围后显示。
- 离屏后显示边缘方向标，可选。
- 被 Boss 召唤的精英优先级下降，但不能完全隐藏。

### 4.2 结构

```text
Prefab_Healthbar_Enemy_EliteRare
├── Root
│   ├── Elite_Frame
│   ├── Text_Name
│   ├── Text_AffixLine              # 词缀摘要
│   ├── Fill_HP
│   ├── Fill_DamageDelay
│   ├── Fill_Shield
│   ├── Fill_GuardBreak             # 韧性/破防
│   ├── StateIcons_Row              # Buff/Debuff 简略
│   └── ThreatMarker                # 锁定/仇恨/危险技能
```

### 4.3 精英血条规则

| 元素 | 规则 |
|---|---|
| 名称 | 常驻，最多 10 字，超出用短名或缩略 |
| 词缀摘要 | 最多显示 3 个核心词缀 |
| HP 条 | 比普通怪宽 1.5-2 倍 |
| 护盾条 | 位于 HP 上方或覆盖外框 |
| 韧性条 | 位于 HP 下方，破防后闪白并清空 |
| 状态图标 | 最多 5 个，超出合并为 “+N” |
| 危险技能 | 施法时血条外框发光/脉冲 |

## 5. 小 Boss / 地图首领血条

小 Boss 介于精英与正式 Boss 之间。

### 5.1 显示方式

- 地图事件首领：顶部中型血条。
- 副本小 Boss：顶部中型血条 + 头顶血条。
- 正式章节 Boss：顶部大血条。

### 5.2 结构

```text
Prefab_Healthbar_MiniBoss_Top
├── Root_TopCenter
│   ├── Text_BossName
│   ├── Text_Subtitle
│   ├── Fill_HP
│   ├── Fill_Shield
│   ├── SegmentMarkers
│   ├── MechanicMiniSlot
│   └── StatusResistIcons
```

### 5.3 显示规则

- 战斗开始后 0.5 秒滑入。
- 脱战 5 秒后淡出。
- 首领死亡后保留 1 秒，随后显示掉落/完成提示。

## 6. Boss 大血条

Boss 血条是 Boss 战的主 UI。

### 6.1 位置

- 屏幕顶部中心。
- 宽度约为屏幕宽度的 55%-70%。
- 移动端可压缩为 80% 宽度但高度更小。

### 6.2 结构

```text
Prefab_BossBar_Top
├── Root_BossBar
│   ├── Panel_Backplate
│   ├── Header_Row
│   │   ├── Icon_BossPortrait
│   │   ├── Text_BossName
│   │   ├── Text_BossLevel
│   │   └── Icon_BossRank
│   ├── Bar_HP
│   │   ├── Fill_HP_Current
│   │   ├── Fill_HP_DamageDelay
│   │   ├── Fill_HP_LostFlash
│   │   └── SegmentMarkers
│   ├── Bar_Shield
│   ├── Bar_GuardBreak
│   ├── Mechanic_Row
│   │   ├── MechanicSlot_01
│   │   ├── MechanicSlot_02
│   │   └── MechanicTimer
│   ├── Status_Row
│   │   ├── Icon_Burning
│   │   ├── Icon_Frozen
│   │   ├── Icon_Shocked
│   │   └── MoreStatus
│   └── Anim_BossBar
```

### 6.3 Boss 大血条内容

| 内容 | 是否必须 | 说明 |
|---|---|---|
| Boss 名称 | 必须 | 顶部左/中显示 |
| Boss 头像 | 可选 | 重要 Boss 建议显示 |
| Boss 等级 | 可选 | 便于数值验证 |
| HP 当前百分比 | 可选 | 默认不显示具体数值，调试可开 |
| 分段标记 | 必须 | Boss 阶段转换点 |
| 护盾条 | 有护盾 Boss 必须 | 与生命区分 |
| 韧性条 | 有破防机制 Boss 必须 | 玩家打断/处决依据 |
| 机制条 | 机制 Boss 必须 | 例如充能、怒气、仪式、护盾核心 |
| 状态图标 | 可选 | 只显示关键异常 |

## 7. Boss 分段血条规则

Boss 血量段用于触发阶段：

```text
Phase 1：100% - 70%
Phase 2：70% - 35%
Phase 3：35% - 0%
```

配置字段：

```json
{
  "BossId": "BOSS_BlackForgeGatekeeper",
  "PhaseSegments": [
    {"PhaseId":"P1", "HpFrom":1.0, "HpTo":0.7, "Marker":"70%"},
    {"PhaseId":"P2", "HpFrom":0.7, "HpTo":0.35, "Marker":"35%"},
    {"PhaseId":"P3", "HpFrom":0.35, "HpTo":0.0, "Marker":"0%"}
  ],
  "ShowSegmentMarker": true,
  "LockHpDuringTransition": true,
  "TransitionInvulnerable": true
}
```

### 7.1 锁血规则

当 Boss 到达阶段阈值时：

1. 血量锁定在阈值。
2. Boss 进入转阶段动画。
3. Boss 大血条显示阶段提示。
4. 机制完成后解除锁血。
5. 如果阶段动画可跳过，血条仍要完整显示阶段变化。

## 8. 护盾条规则

护盾不同于生命，应显著区分。

| 护盾类型 | 显示方式 | 扣减反馈 |
|---|---|---|
| 普通能量护盾 | HP 上方薄条 | 蓝白碎裂 |
| 物理护盾 | HP 外框甲壳 | 金属裂纹 |
| 元素护盾 | HP 上方彩色薄条 | 元素粒子 |
| Boss 护盾核心 | 独立机制条 | 需要机制破除 |
| 临时免伤护盾 | 血条外框罩 | 显示倒计时 |

护盾被击破时：

- 血条外框闪白。
- 播放碎裂 SFX。
- 跳字显示“护盾破裂”。
- 若触发 Boss 机制，显示机制提示。

---

## 9. 韧性/破防条规则

韧性条用于 ACT 操作反馈，尤其近战重击、Boss 打断。

### 9.1 显示对象

- 精英怪：可显示小韧性条。
- Boss：必须显示韧性条或机制条。
- 普通怪：默认不显示，除非怪物有硬直玩法。

### 9.2 破防流程

```text
受到破防伤害
→ 韧性条减少
→ 归零
→ 进入破防状态
→ Boss 大血条显示“破防”
→ 玩家输出窗口
→ 韧性条锁定恢复倒计时
→ 韧性恢复
```

### 9.3 UI 表现

| 状态 | 表现 |
|---|---|
| 正常 | 韧性条稳定显示 |
| 快破防 | 条体震动/闪烁 |
| 破防瞬间 | 闪白、碎裂、音效 |
| 破防中 | 条体清空，显示倒计时 |
| 恢复中 | 从 0 缓慢填充 |

## 10. 血条颜色状态

| 状态 | HP Fill | 外框 | 备注 |
|---|---|---|---|
| 普通敌人 | 暗红系 | 灰黑 | 低干扰 |
| 强化怪 | 红 + 蓝/紫边 | 蓝/紫 | 强化识别 |
| 精英怪 | 深红 + 金/紫边 | 金/紫 | 重点目标 |
| Boss | 深红 + 暗金/黑 | 厚重 | 压迫感 |
| 中毒 | HP 条边缘出现绿色流动 | 不改变基础血量颜色 | 避免误读 |
| 燃烧 | 外框火焰闪动 | 不改变 HP | 状态图标配合 |
| 冰冻 | 血条覆盖冰霜罩 | 不改变 HP | |
| 免疫 | 外框银白罩 | 伤害跳字显示免疫 | |

## 11. 血量变化动画

| 事件 | 动画 |
|---|---|
| 普通扣血 | 当前血条立即减少，延迟条慢慢追赶 |
| 暴击扣血 | 血条轻震，扣血区域闪亮 |
| 大额伤害 | 血条产生冲击波，延迟条明显 |
| 治疗 | 血条向右增长，绿色短闪 |
| 护盾回复 | 护盾条从左到右填充，蓝白闪 |
| 免疫 | 血条不变，外框弹一下 |
| Boss 阶段变化 | 血条锁定，阶段标记亮起，条体重新分段 |

## 12. 血条性能规则

- 普通怪血条使用对象池，禁止频繁 Instantiate/Destroy。
- 普通怪血条最多同屏显示 20 个，可配置。
- 精英怪血条最多同屏显示 8 个。
- Boss 大血条只有 1 个主实例，多 Boss 时使用多段 BossRow。
- 血条刷新频率：血量变化即时刷新；距离/遮挡 10Hz 刷新；位置每帧刷新。
- 延迟扣血动画用本地插值，不依赖每帧广播事件。

## 14. 验收标准

- 普通怪受击后显示小血条，脱战后自动隐藏。
- 精英怪血条包含名称、词缀摘要、护盾/韧性信息。
- Boss 战开始后顶部大血条出现，分段点可见。
- Boss 转阶段时血条能锁血、显示阶段提示、再解除。
- 护盾破裂、破防、免疫、治疗都有独立反馈。
- 同屏大量怪物时，血条数量不会失控。
