# 109_主城NPC交互UI与预制体结构_对话_商店_服务入口

> 目标：统一所有主城 NPC 的交互 UI、对话、商店、服务入口和 Prefab 结构，避免每个 NPC 单独写一套逻辑。

---

## 1. 主城 NPC 交互流程

```text
玩家进入交互范围
→ 显示头顶交互提示
→ 玩家按 E
→ 打开 NPC 对话服务面板
→ 选择服务
→ 打开对应功能 UI
→ 关闭后返回 NPC 面板或直接退出
```

### 1.1 快捷打开规则

高频 NPC 支持直接打开默认服务：

| NPC | 默认服务 | 快捷逻辑 |
|---|---|---|
| 铁匠 | 出售/分解 | 短按 E 打开服务菜单，长按 E 打开出售页 |
| 仓库 | 仓库 | E 直接打开仓库 |
| 技能商人 | 技能商店 | E 打开技能商店 |
| 副本传送师 | 副本传送 | E 打开副本传送 |
| 药剂商 | 药剂商店 | E 打开药剂页 |
| 任务 NPC | 对话任务 | E 打开任务对话 |

## 7. 服务路由配置

每个 NPC 不直接写死按钮，而是读取 `NPCServiceList`。

```json
{
  "npcId": "NPC_BLACKSMITH_001",
  "services": [
    {
      "serviceId": "BLACKSMITH_SHOP",
      "displayName": "购买装备",
      "uiPrefab": "UI_Shop_Blacksmith",
      "unlockCondition": "Always",
      "hotkey": "1"
    },
    {
      "serviceId": "BLACKSMITH_SALVAGE",
      "displayName": "分解装备",
      "uiPrefab": "UI_SalvagePanel",
      "unlockCondition": "QuestComplete:TUTORIAL_BOSS",
      "hotkey": "2"
    }
  ]
}
```

## 8. 输入操作

| 输入 | NPC 面板 | 商店面板 | 传送面板 |
|---|---|---|---|
| E / A键 | 确认 | 购买/执行 | 进入 |
| Esc / B键 | 关闭/返回 | 返回 NPC 面板 | 返回 NPC 面板 |
| Tab / LB-RB | 切换页签 | 切换分类 | 切换分类 |
| 鼠标右键 | 快捷购买/出售 | 快捷操作 | 无 |
| Shift | 批量选择 | 批量购买/出售 | 无 |
| F | 默认快捷服务 | 快速出售/存入 | 快速进入推荐副本 |

## 9. NPC 对话文本规则

### 9.1 文本长度

| 类型 | 长度 |
|---|---:|
| 初次见面 | 2-3 句 |
| 日常问候 | 1 句 |
| 功能提示 | 1-2 句 |
| 解锁提示 | 1 句 + 条件 |
| 主线剧情 | 3 句以内，长文本放剧情回顾 |

### 9.2 示例

铁匠初次见面：

```text
“你身上的铁味还不够重。把捡来的破烂放这儿，我能把它们变成还能救命的东西。”
```

技能商人新功能解锁：

```text
“你已经能承受更复杂的星纹了。辅助模块现在开放，它们会改变技能的形状。”
```

副本传送未解锁：

```text
“那条路还没有稳定。完成【黑炉深处】后，我可以为你打开下一道门。”
```

## 10. 性能与加载规则

1. 主城 NPC 模型常驻
2. NPC UI 面板按需加载
3. 商店商品图标使用 Addressables
4. 关闭 UI 后延迟 30 秒卸载大型预览图
5. 商品列表最多一次显示 60 个，超过分页或虚拟列表
6. 头顶 HUD 使用对象池
7. NPC 语音只播放短句，避免频繁打断

## 12. 当前 Unity 实现映射

| 模块 | 实现位置 | 当前能力 |
|---|---|---|
| NPC 服务路由 | `Assets/_Game/Scripts/UI/ArpgNpcDialogWindow.cs` | NPC 面板优先读取 `npc_services.json`，按 `SortOrder` 生成按钮，显示中文名称、描述、快捷键、推荐和未解锁状态 |
| 服务打开 | `Assets/_Game/Scripts/UI/ArpgNpcDialogWindow.cs` | 支持 `UiWindowId` / `UiArgument` / `ShopId` 路由到商店、副本、任务、地图、资产服务 |
| 资产服务窗口 | `Assets/_Game/Scripts/UI/ArpgAssetServicesWindow.cs` | 仓库、材料、地图、符石、兑换共用一个 UI 基类入口 |
| UI 注册 | `Assets/_Game/Scripts/UI/ArpgThirdBatchUIRoot.cs` | 注册 `AssetServices` 窗口，主城 NPC 可直接打开 |
| Prefab 解析 | `Assets/_Game/Scripts/UI/ArpgUIPrefabResolver.cs` | 支持 `UI_AssetServicesRoot`，无 prefab 时仍动态构建 |
| NPC HUD 标签 | `Assets/_Game/Scripts/UI/ArpgCombatHudView.cs` | 新增符石匠、兑换回收服务识别，仓库服务支持 `StashPersonal/Shared/Material/Map` |
| Prefab 脚手架 | `Assets/_Game/Scripts/Editor/ArpgPrefabScaffolder.cs` | `PF_NPC_Base` 已按统一结构扩展，并新增 `PF_NPC_StashKeeper`、`PF_NPC_RuneSmith`、`PF_NPC_Recycler` |

第一版路由规则：

- 服务表配置 `UiWindowId=AssetServices` 时，会根据 `UiArgument` 打开 `Personal`、`Shared`、`Materials`、`Maps`、`Runes` 或 `Exchange`。
- 服务表配置 `UiWindowId=Shop` 且带 `ShopId` 时，会直接进入对应商店表。
- `Level:X` 与 `PlayerLevel>=X` 条件已在 NPC 面板上做按钮解锁判断；任务/旗标条件保留给后续存档旗标系统统一接入。
