# 85 HUD 数据配置、事件驱动、性能优化、验收清单

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. 设计目标

HUD 规则必须可配置、可测试、可扩展。

禁止把以下内容写死在 UI 脚本里：

- 血条颜色。
- 跳字颜色与动画。
- NPC 功能图标。
- Buff 图标优先级。
- 交互距离。
- 拾取标签过滤规则。
- Boss 机制条显示条件。
- 小地图标记类型。

## 10. 事件流

### 10.1 单位生成

```text
CombatUnit Spawn
→ UnitHUDRegisterEvent
→ HUDVisibilitySystem 判断是否需要 HUD
→ 从对象池取 Nameplate/Healthbar
→ 绑定 UnitHUDAnchor
→ 按配置初始化
```

### 10.2 受伤

```text
DamageResolvedEvent
→ Healthbar 更新当前值
→ DamageTextSystem 生成/合并跳字
→ StatusSystem 判断异常变化
→ BossBar 判断阶段阈值
```

### 10.3 交互焦点

```text
InteractableEnterRange
→ 加入候选列表
→ InteractionFocusSystem 计算评分
→ 最高分对象成为 Focus
→ InteractionPrompt 显示
→ 玩家按键
→ 执行交互/打开 UI/提示失败原因
```

### 10.4 掉落物

```text
LootDropped
→ LootFilter 过滤
→ LootLabelSystem 创建标签
→ 标签避让/合并
→ 玩家拾取
→ LootPickedEvent
→ 回收标签
```

## 11. 性能预算

### 11.1 显示数量上限

| HUD 元素 | 普通场景 | Boss 场景 | 极限场景 |
|---|---:|---:|---:|
| 普通怪血条 | 20 | 12 | 30 |
| 精英血条 | 8 | 5 | 12 |
| NPC 名称 | 25 | 0 | 40 |
| 交互提示 | 1 主 + 5 弱 | 1 主 | 10 |
| 拾取标签 | 60 | 40 | 100 |
| 伤害跳字活跃 | 120 | 180 | 300 |
| Buff 图标 | 40 | 60 | 80 |
| 小地图标记 | 80 | 80 | 150 |

### 11.2 刷新频率

| 系统 | 刷新频率 |
|---|---|
| 玩家血量/资源 | 事件即时 + 动画每帧 |
| 敌人血条位置 | 每帧，仅显示对象 |
| 距离显隐判断 | 10Hz |
| 遮挡检测 | 5-10Hz，分帧 |
| Buff 倒计时文本 | 10Hz |
| 小地图标记 | 5-10Hz |
| 拾取标签避让 | 掉落变化时 + 低频刷新 |
| 伤害跳字 | 事件触发 + 本地动画 |

## 12. 降级策略

当性能压力过高：

1. 降低普通怪血条数量。
2. 降低 Dot 跳字频率。
3. 合并召唤物伤害。
4. 隐藏普通掉落标签。
5. 降低小地图标记刷新频率。
6. 暂停普通状态图标动画。
7. 保留 Boss、玩家受伤、交互、任务、高价值掉落。

降级状态不能影响玩法判断。

## 15. 验收清单

### 15.1 美术/UI 验收

- 字体清晰，描边和阴影统一。
- 不同信息层级有明确强弱。
- Boss 信息压迫感足够，但不挡视野。
- 普通怪信息不抢屏。
- 伤害类型颜色清晰。
- Buff 图标边框和类别一致。

### 15.2 策划验收

- 可通过配置表改 HUD 规则。
- 可配置新伤害类型跳字。
- 可配置新 Boss 机制条。
- 可配置新交互物类型。
- 可配置拾取过滤规则。
- 可配置 Buff 显示优先级。

### 15.3 程序验收

- HUD 与战斗系统通过事件连接，低耦合。
- 所有高频 UI 使用对象池。
- 无明显 GC Alloc 峰值。
- 大量对象显示时帧率稳定。
- HUD 错误不会阻塞战斗逻辑。
- 支持本地化和多输入模式。

### 15.4 体验验收

- 玩家 3 秒内能识别 Boss 血量和阶段。
- 玩家 1 秒内能识别当前可交互物。
- 玩家能区分暴击、Dot、免疫、格挡、破防。
- 玩家能判断哪些掉落值得捡。
- 玩家受到危险 Debuff 时不会漏看。
