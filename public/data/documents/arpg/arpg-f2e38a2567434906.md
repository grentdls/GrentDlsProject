# 78 HUD 规则总览：显示对象、层级、优先级

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. HUD 系统目标

HUD 不是单纯把信息堆在屏幕上，而是解决三个问题：

1. 玩家当前最应该看什么。
2. 玩家当前能交互什么。
3. 玩家当前承受了什么风险、造成了什么收益。

本项目是 3D ACT 操作模式，镜头可转动、单位会遮挡、敌人会冲脸，因此 HUD 需要同时满足：

- **战斗可读性**：玩家能立刻分辨小怪、精英、Boss、危险技能、可交互物。
- **操作反馈**：攻击、暴击、异常、格挡、闪避、吸血、护盾破裂都有明确反馈。
- **空间关系**：头顶信息跟随 3D 目标，但不能抖动、穿模、遮挡太严重。
- **信息降噪**：非关键内容在战斗中自动隐藏或降低透明度。
- **可配置**：策划能改颜色、字号、距离、显隐、动画、优先级。
- **移动端/手柄适配**：所有提示不依赖鼠标悬浮，也支持锁定目标和焦点选择。

## 2. HUD 信息分类

### 2.1 世界空间 HUD

世界空间 HUD 绑定在 3D 场景对象附近，跟随摄像机朝向。

| 类型 | 示例 | 绑定对象 | 显示空间 | 说明 |
|---|---|---|---|---|
| 单位名称 | NPC 名称、怪物名、召唤物名 | UnitRoot | World Space | 通常在头顶或目标根节点上方 |
| 敌人血条 | 小怪、精英、稀有怪、召唤物 | CombatUnit | World Space | 小血条跟随敌人 |
| 交互提示 | 按 E 对话、开启宝箱、进入传送门 | Interactable | World Space + Screen Space | 近距离显示 |
| 拾取标签 | 金币、装备、地图钥石、材料 | LootDrop | World Space | 可筛选、可合并、可高亮 |
| 危险技能提示 | 地面红圈、Boss 蓄力线、落点范围 | SkillWarning | World Space | 战斗表现优先级高 |
| 任务目标标记 | 目标 NPC、任务物、地图出口 | QuestTarget | World Space | 可叠加边缘箭头 |

### 2.2 屏幕空间 HUD

屏幕空间 HUD 固定在 Canvas 上，不跟随 3D 物体。

| 类型 | 示例 | 显示位置 | 说明 |
|---|---|---|---|
| 玩家状态 | 生命、护盾、资源、药剂 | 屏幕底部 | 常驻最高可读性 |
| 技能栏 | 普攻、技能、保留、位移、药剂 | 底部中心/右侧 | 显示冷却、按键、可用状态 |
| Boss 大血条 | Boss 名称、阶段、护盾、异常抗性 | 顶部中心 | Boss 战常驻 |
| 伤害跳字 | 伤害、治疗、吸收、格挡、闪避 | 目标附近投射到屏幕 | 使用对象池 |
| Buff 条 | 玩家 Buff、Debuff、光环、保留 | 血条上方/技能栏上方 | 可折叠、可排序 |
| 小地图 | 地图轮廓、任务点、传送门、怪群 | 右上角 | 可切换透明/全图 |
| 任务追踪 | 当前任务、地图目标、事件进度 | 右侧 | 战斗中弱化 |
| 通知提示 | 获得物品、等级提升、挑战完成 | 屏幕上方/左下 | 排队显示 |

## 3. HUD 层级规则

Unity Canvas 层级建议：

```text
CanvasRoot_HUD
├── Layer_00_BackgroundOverlay         # 暗角、全屏提示底层
├── Layer_10_Minimap_Quest             # 小地图、任务追踪
├── Layer_20_PlayerHUD                 # 血球、资源、药剂、技能栏
├── Layer_30_TargetInfo                # 当前锁定目标信息
├── Layer_40_WorldLabelProjection      # 世界 UI 投射后的屏幕标签容器
├── Layer_50_DamageNumbers             # 伤害跳字
├── Layer_60_BossBar                   # Boss 大血条
├── Layer_70_InteractionPrompt         # 交互提示、拾取提示
├── Layer_80_Toast                     # 获得提示、系统通知
├── Layer_90_MenuOverlay               # ESC 菜单、暂停遮罩
└── Layer_99_Debug                     # 调试信息，仅编辑器/开发包
```

World Space Canvas 建议：

```text
WorldHUDRoot
├── EnemyNameplatesPool
├── FriendlyNameplatesPool
├── InteractableLabelsPool
├── LootLabelsPool
├── WarningDecalPool
└── QuestMarkerPool
```

## 4. 显示优先级总表

当屏幕信息过多时，按优先级决定显示、压缩、隐藏。

| 优先级 | 信息 | 规则 |
|---:|---|---|
| 100 | 玩家生命危险提示、Boss 致命技能预警 | 永远显示，不受普通隐藏规则影响 |
| 95 | Boss 大血条、Boss 阶段提示 | Boss 战内常驻 |
| 90 | 当前锁定目标名称/血条 | 常驻，距离较远也显示 |
| 85 | 可立即交互对象提示 | 玩家靠近且视线可达时显示 |
| 80 | 高稀有掉落标签 | 永远显示或强高亮 |
| 75 | 精英/稀有怪头顶血条 | 进入战斗距离后显示 |
| 70 | 任务目标标记 | 可显示边缘箭头 |
| 60 | 玩家 Buff / Debuff | 常驻但可折叠 |
| 50 | 普通伤害跳字 | 战斗中显示，过量时合并 |
| 40 | 普通怪名称/血条 | 近距离或受击时显示 |
| 30 | 普通掉落物 | 受拾取过滤器控制 |
| 20 | 环境说明标签 | 非战斗显示，战斗隐藏 |
| 10 | 装饰性提示 | 屏幕拥挤时立即隐藏 |

## 5. HUD 状态机

HUD 根据游戏状态切换显隐：

```text
Boot
└── MainMenu
    └── Loading
        └── InTown
            ├── InventoryOpen
            ├── ShopOpen
            ├── DialogOpen
            └── TeleportOpen
        └── InCombatArea
            ├── Exploration
            ├── Combat
            ├── BossFight
            ├── Looting
            └── Death
```

### 5.1 主城状态

- 显示 NPC 名称、功能图标、传送门、仓库、商人入口。
- 默认不显示玩家技能冷却详细数字，只显示底部技能栏。
- 伤害跳字关闭。
- 小地图显示功能区图标。
- NPC 名称可以常驻，但距离远时半透明。

### 5.2 探索状态

- 显示任务目标、出口、宝箱、可交互物。
- 敌人未警觉时只显示少量名称，不显示全部血条。
- 拾取标签按照过滤器显示。

### 5.3 战斗状态

- 玩家 HUD、技能栏、目标血条、伤害跳字开启。
- 普通 NPC / 环境标签隐藏。
- 任务文字透明度降低。
- 普通怪名称只在受击、被锁定、靠近时显示。

### 5.4 Boss 战状态

- Boss 大血条开启。
- Boss 头像/名称/阶段/机制条开启。
- 小怪血条降级显示，避免遮挡 Boss 机制。
- 危险技能提示优先级提高。
- 屏幕边缘警告开启。

### 5.5 死亡状态

- 伤害跳字停止新生成。
- Boss 血条保留 1 秒后淡出。
- 死亡原因、击杀来源、复活按钮显示。
- 可选择回城、复活点、消耗道具复活。

## 6. 距离与透明度规则

### 6.1 世界标签距离

| 对象 | 完全显示距离 | 淡出开始 | 完全隐藏 | 例外 |
|---|---:|---:|---:|---|
| NPC 名称 | 0-12m | 12m | 20m | 当前任务 NPC 可到 35m |
| 普通怪血条 | 0-18m | 18m | 28m | 被锁定不隐藏 |
| 精英怪血条 | 0-28m | 28m | 45m | 战斗中不隐藏 |
| Boss 大血条 | 不受距离影响 | - | - | Boss 战内常驻 |
| 宝箱标签 | 0-15m | 15m | 25m | 稀有宝箱可到 35m |
| 掉落标签 | 按过滤器 | 按过滤器 | 按过滤器 | 高价值物永远显示 |
| 任务标记 | 0-60m | 60m | 不隐藏 | 超出屏幕用边缘箭头 |

### 6.2 遮挡规则

若单位被墙体完全遮挡：

- 普通怪：隐藏名称和血条。
- 精英怪：血条透明度 35%，显示轮廓方向箭头。
- Boss：Boss 大血条不受遮挡影响，头顶血条可隐藏。
- NPC：被建筑遮挡隐藏，任务 NPC 可显示边缘方向标。
- 交互物：视线不可达时隐藏交互按键，保留任务标记。

## 7. 缩放规则

HUD 需要适配不同分辨率、镜头距离、UI 缩放。

| 元素 | 最小缩放 | 最大缩放 | 缩放依据 |
|---|---:|---:|---|
| 普通怪血条 | 0.75 | 1.0 | 镜头距离 |
| 精英怪血条 | 0.9 | 1.15 | 怪物等级/稀有度 |
| Boss 大血条 | 1.0 | 1.0 | 固定屏幕空间 |
| 伤害跳字 | 0.8 | 1.8 | 伤害类型、暴击、重要度 |
| NPC 名称 | 0.8 | 1.0 | 距离 |
| 拾取标签 | 0.9 | 1.2 | 稀有度 |
| 交互提示 | 1.0 | 1.1 | 当前焦点对象 |

## 8. 输入与 HUD 关联

### 8.1 键鼠

| 操作 | HUD 反馈 |
|---|---|
| 鼠标悬浮敌人 | 显示目标名称、等级、血条、抗性摘要 |
| 鼠标悬浮掉落物 | 高亮标签，显示拾取提示 |
| 鼠标悬浮 NPC | 显示对话/商店/传送图标 |
| 按 Alt | 临时展开全部允许显示的拾取标签 |
| 按 Tab | 切换小地图透明覆盖 |
| 按 E | 交互当前焦点对象 |
| 按 Shift | 原地攻击，HUD 显示站定标识 |

### 8.2 手柄

| 操作 | HUD 反馈 |
|---|---|
| 右摇杆锁定目标 | 当前目标血条强化，目标脚下出现锁定环 |
| LB/RB 切换目标 | 切换目标 HUD 焦点 |
| A 键交互 | 最近可交互物提示放大 |
| 十字键切换掉落选择 | 拾取标签获得焦点框 |
| Start | 打开暂停/设置 |
| Select | 打开地图/任务 |

### 8.3 移动端

| 操作 | HUD 反馈 |
|---|---|
| 点击敌人 | 设置软锁定，显示目标血条 |
| 长按掉落 | 显示物品简略详情 |
| 点击交互按钮 | 执行当前交互 |
| 双指缩放小地图 | 小地图切全屏地图 |

## 10. 验收标准

### 10.1 基础验收

- 玩家进入主城，NPC 名称、功能图标、传送点、仓库可以正确显示。
- 玩家进入战斗地图，普通怪、精英怪、Boss 的名称和血条规则不同。
- Boss 战开始后顶部大血条出现，Boss 死亡后淡出。
- 不同伤害类型产生不同跳字样式。
- Buff、Debuff、异常状态按优先级排序。
- 宝箱、可破坏物、任务物、传送门都有明确交互提示。

### 10.2 压力验收

- 同屏 80 个普通怪，最多显示 20 个普通怪血条。
- 同屏 200 个伤害跳字，系统自动合并或降级，不掉帧。
- 同屏 100 个掉落物，拾取过滤器正确隐藏低价值物。
- Boss 战中 20 个小怪、30 个地面预警、50 个跳字时，Boss 信息仍清晰。

### 10.3 可配置验收

- 策划无需改代码，可以修改血条颜色、尺寸、距离、显隐条件。
- 策划无需改代码，可以新增一种伤害跳字类型。
- 策划无需改代码，可以配置某个 Boss 的专属机制条。
- 策划无需改代码，可以配置 NPC 的功能图标和交互按钮文本。
