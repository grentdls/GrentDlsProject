# 数值成长、掉落权重、经济循环

---

## 1. 数值设计原则

本文件提供原创数值框架，用于替代任何商业游戏的专有数值表。

核心原则：

```text
早期成长快 → 中期开始筛选 → 后期追求极小提升 → 终局靠组合和打造延长寿命
```

---

## 2. 角色等级

建议等级上限：100。

### 2.1 经验曲线

```text
Level 1~30：快速升级，每 5~15 分钟 1 级
Level 31~60：中速升级，每 20~40 分钟 1 级
Level 61~85：刷图升级，每 1~3 小时 1 级
Level 86~100：长期追求，每级需要大量终局地图
```

### 2.2 每级奖励

- +1 天赋点。
- 少量生命/魔力基础成长。
- 解锁装备等级需求。
- 特定等级解锁技能槽/辅助槽。

## 3. 基础属性成长

### 3.1 生命

```text
BaseLife = 80 + Level * 12
```

不同职业修正：

| 职业 | 生命修正 |
|---|---:|
| 战士 | +15% |
| 游侠 | 0% |
| 法师 | -10% |

### 3.2 魔力

```text
BaseMana = 50 + Level * 6
```

### 3.3 怪物生命

```text
MonsterLife = BaseByMonsterType * LevelCurve * MapTierMultiplier * RarityMultiplier
```

建议曲线：

```text
LevelCurve = 1.12 ^ MonsterLevel
```

## 4. 玩家伤害成长

玩家伤害来自：

```text
武器/技能基础 → 技能等级 → 装备词条 → 天赋 → 辅助模块 → Buff → 暴击/异常
```

第一版目标：

| 阶段 | 单体 DPS 目标 |
|---|---:|
| Level 10 | 80~150 |
| Level 30 | 800~1500 |
| Level 60 | 8000~18000 |
| T1 地图 | 20000~50000 |
| T10 地图 | 150000~500000 |
| T15 地图 | 800000~2500000 |
| Pinnacle | 3000000+ |

这是项目内部原创调试目标，可根据手感调整。

目标：

- 小怪不能单下秒杀。
- 精英组合能造成压力。
- Boss 大招能秒低防角色，但必须可读。

建议：

| 阶段 | 玩家生命目标 | 小怪单击 | 精英重击 | Boss 大招 |
|---|---:|---:|---:|---:|

| Level 30 | 700 | 50~90 | 150~230 | 350 |
| Level 60 | 1800 | 180~300 | 500~800 | 1300 |
| T10 | 3500 | 400~800 | 1200~2200 | 3500 |
| T15 | 5000 | 700~1400 | 2500~4000 | 6000+ |

## 8. 物品过滤器

掉落多后必须提供过滤器。

过滤条件：

- 稀有度。
- 部位。
- 物品等级。
- 基底类型。
- 是否有指定词条。
- 是否有高阶词条。
- 是否为地图钥石。
- 是否为材料。
- 是否有价值。

过滤器表现：

```text
隐藏 / 缩小 / 普通显示 / 高亮 / 光柱 / 特殊音效
```

## 9. Crafting 经济循环

打造材料来源：

| 来源 | 材料特点 |
|---|---|
| 普通刷图 | 基础材料 |
| 分解装备 | 对应部位/词条碎片 |
| 地图机制 | 机制专属材料 |
| Boss | 高级材料 |
| Pinnacle | 稀有核心材料 |

材料消耗：

- 早期：提升装备稀有度、补抗性。
- 中期：定向添加词条、洗数值。
- 后期：锁词条、星痕、污染、特殊合成。

---

## 10. 地图维持

终局刷图必须让玩家既能继续刷，又不能无限无脑升阶。

地图钥石掉落策略：

```text
同阶掉落：基础 18%
低一阶掉落：基础 28%
高一阶掉落：基础 5%
Boss 额外地图：基础 35%
Atlas 天赋可提高这些概率
```

目标：

- 普通玩家能维持当前阶。
- 会打造地图的玩家能稳定升阶。
- 高阶地图需要投入材料。

---

## 11. 装备价值分层

| 层级 | 描述 |
|---|---|
| 过渡装 | 等级过程使用，词条只要对就行 |
| 合格装 | 抗性/生命/主伤害达标 |
| 优质装 | 多个高阶词条，数值较好 |
| 打造底材 | 好基底 + 高物品等级 + 特殊状态 |
| 终局装 | 高阶词条组合 + 特殊机制 |
| 镜像级 | 极小概率，完美词条，长期目标 |

## 13. 验收标准

- 章节期间每 5~10 分钟有一次明显装备替换。
- 初入地图时玩家能通过补抗性解决生存问题。
- T10 后不能只靠等级碾压，需要装备和 BD。
- Relic 掉落足够稀有，但不能让普通玩家完全刷不到。
- Crafting 材料有消耗出口，不会无限通胀。
