# 192 Boss 专属数值机制：破盾、破韧、阶段、弱点、抗性变化

## 1. Boss 为什么需要专属数值

普通词条如果完全作用于 Boss，容易出现：
- 无限控制
- 秒杀
- 召唤物卡死
- 爆炸连锁秒阶段
- 真伤绕过机制

所以 Boss 需要专属换算。

## 2. Boss 护盾阶段

```text
Boss 进入护盾阶段
→ 护盾值出现
→ 普通伤害先打护盾
→ 破盾触发输出窗口
→ Boss 进入短硬直
```

破盾奖励：
```text
输出窗口 5 秒
Boss 抗性降低 20%
召唤物集火 Boss
掉落破盾奖励计数 +1
```

## 3. Boss 韧性

控制转化为韧性伤害：

```text
冻结 → 韧性伤害
眩晕 → 韧性伤害
束缚 → 减速或韧性伤害
击退 → 无效或小硬直
```

破韧：
```text
Boss 跪地
弱点暴露
受到伤害提高
部分技能冷却暂停
```

## 4. Boss 弱点

弱点配置：

```json
{
  "weakPointId": "Boss_Core",
  "damageMultiplier": 1.35,
  "poiseDamageMultiplier": 1.5,
  "breakThreshold": 5000,
  "onBreakWindow": 6.0
}
```

## 5. 阶段抗性变化

```text
第一阶段：普通抗性
第二阶段：火抗提高，冰抗降低
第三阶段：护盾提高，破盾奖励提高
狂暴阶段：控制抗性提高，破韧窗口缩短
```

## 6. Boss 词条限制

```text
击杀爆炸对 Boss 不触发。
真伤对 Boss 有每秒上限。
控制时间转为韧性伤害。
投射物霰弹命中有上限。
召唤物数量对 Boss 战有软上限。
```
