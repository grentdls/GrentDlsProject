# 161 装备 SkinnedMesh 换装规则：盔甲、头盔、手套、鞋子、披风

## 1. 适用装备

SkinnedMesh 换装适用于需要随骨骼变形的装备：

- 头盔
- 胸甲
- 护肩
- 手套
- 裤子
- 鞋子
- 披风
- 全身套装
- 变身皮肤

---

## 2. 核心原则

装备模型不使用自己独立的运行时骨架，而是绑定到角色当前骨架。

```text
装备 SkinnedMeshRenderer
→ 读取装备 bones 名称
→ 在角色 SkeletonRoot 中查找同名骨骼
→ 替换 bones 数组
→ 设置 rootBone
→ 应用材质
→ 挂到 EquipmentRoot
```

## 4. 装备导入规范

### 4.1 骨骼命名
装备导出时必须使用标准骨骼名：

```text
hips
spine_01
spine_02
spine_03
neck
head
upperarm_l
lowerarm_l
hand_l
upperleg_l
lowerleg_l
foot_l
...
```

### 4.2 坐标规范
- Unity 单位：米
- 模型面向：Z+
- Up：Y+
- 缩放：1,1,1
- 旋转：0,0,0
- 不允许导入后整体歪斜

### 4.3 权重规范
- 单顶点最大骨骼影响建议 4
- 避免无效骨骼权重
- 胸甲不要错误绑定到腿骨
- 披风可使用额外骨骼或布料组件

---

## 5. 运行时绑定流程

```text
Equip Item
→ Get SkinnedEquipmentConfig
→ Instantiate equipment prefab
→ Find SkinnedMeshRenderer
→ Resolve bones by name
→ Set renderer.bones
→ Set renderer.rootBone
→ Parent to EquipmentRoot
→ Apply materials
→ Hide body parts
→ Refresh LOD
```

伪代码：

```csharp
foreach (var sourceBone in equipmentRenderer.bones)
{
    string boneName = sourceBone.name;
    Transform targetBone = characterSkeleton.FindBone(boneName);
    resolvedBones.Add(targetBone);
}
equipmentRenderer.bones = resolvedBones.ToArray();
equipmentRenderer.rootBone = characterSkeleton.FindBone(config.rootBone);
```

## 6. 部位隐藏规则

穿装备后隐藏原身体 Mesh，避免穿模。

### 6.1 胸甲
```json
"hideBodyParts": ["Torso", "UpperArm_L", "UpperArm_R"]
```

### 6.2 手套
```json
"hideBodyParts": ["Hand_L", "Hand_R", "LowerArm_L", "LowerArm_R"]
```

### 6.3 靴子
```json
"hideBodyParts": ["Foot_L", "Foot_R", "LowerLeg_L", "LowerLeg_R"]
```

### 6.4 头盔
```json
"hideBodyParts": ["Hair"],
"optionalHide": ["Head"]
```

## 7. 披风特殊规则

披风可以有三种实现：

### 7.1 SkinnedMesh 披风
- 绑定 spine / shoulder / cloak bones
- 成本低
- 表现稳定

### 7.2 Cloth 披风
- 使用 Unity Cloth 或自定义布料
- 表现好
- 性能更高

### 7.3 挂点披风
- 挂在 Back Socket
- 不完全随身体变形
- 适合硬质背饰

配置：

```json
{
  "slot": "Cloak",
  "visualType": "SkinnedMesh",
  "clothSimulation": true,
  "clothQuality": "Medium",
  "hideInLowLOD": true
}
```

## 8. 性别/体型适配

装备可以配置不同体型版本：

```json
{
  "bodyTypeVariants": [
    {"bodyType": "Male_Strong", "meshPrefab": "PF_IronChest_MaleStrong"},
    {"bodyType": "Female_Slim", "meshPrefab": "PF_IronChest_FemaleSlim"}
  ],
  "fallbackBodyType": "Male_Normal"
}
```

如果没有对应体型：
- 使用 fallback
- 允许轻微缩放
- 输出警告
- 不允许直接报错导致装备消失

---

## 9. 验收标准

- 盔甲换装后跟随角色动画。
- 骨骼自动绑定成功。
- 未找到骨骼时有明确错误日志。
- 装备穿戴后能隐藏原身体部位。
- 不同性别/体型可配置不同 Mesh。
- 披风支持 SkinnedMesh / Cloth / Attachment 三种方案。
