# 228 投射物碰撞命中规则：穿透、弹射、分裂、附着、爆炸

## 1. 碰撞层

```text
World、Enemy、Player、Shield、Projectile、Ground、TriggerVolume
```

高速投射物推荐每帧从上一位置到当前位置做 Sweep，避免穿模。

## 2. 穿透 Pierce

```json
{
  "pierce": {
    "count": 2,
    "damageDecayPerTarget": 0.15,
    "ignoreSameTarget": true
  }
}
```

可分别配置是否穿透敌人、护盾、可破坏物和墙壁。

## 3. 物理弹射 Ricochet

可对墙、地面、盾牌和场景机关反弹。

```json
{
  "ricochet": {
    "maxCount": 3,
    "angleLimit": 75,
    "speedRetention": 0.85,
    "damageRetention": 0.8
  }
}
```

## 4. 连锁 Chain

命中后重新选择目标，不依赖反射角。

```text
搜索半径、目标优先级、最大次数、伤害衰减、能否回跳原目标
```

## 5. 分裂 Split

触发：

```text
命中、飞行结束、穿透完成、死亡、到达目标点
```

```json
{
  "split": {
    "count": 3,
    "angle": 45,
    "inheritSpeed": 0.8,
    "inheritDamage": 0.5,
    "maxGeneration": 1
  }
}
```

## 6. 附着 Stick

附着到敌人骨骼、地面、墙壁或盾牌，之后可：

```text
延迟爆炸、持续伤害、标记、生成区域、被其他技能引爆
```

## 7. 爆炸 Explosion

触发：

```text
命中、延迟、穿透结束、返回结束、破盾、高度条件
```

字段：

```text
半径、伤害衰减、最大目标数、视线检测、击退、状态施加
```

## 8. 同目标命中限制

```text
同一投射物对同一目标最大命中次数
单目标命中冷却
回程是否可再次命中
环绕是否周期命中
```

## 9. 护盾交互

```text
阻挡、反射、吸收、削弱、偏转、转化所有权
```

## 10. 地形碰撞行为

```text
消失、爆炸、弹射、附着、生成区域、切换贴地轨迹
```

## 11. 触发深度

```text
Depth 0：原始投射物
Depth 1：分裂/连锁投射物
Depth 2：二次爆炸
Depth 2 默认不能继续分裂或产生同类爆炸
```
