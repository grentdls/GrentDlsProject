# 183 距离、连击、蓄力与节奏数值玩法

## 1. 距离玩法

距离玩法让同一个技能在不同站位下有不同收益。

### 1.1 近距离增伤

```text
距离目标 3 米内时，近战伤害提高 20%。
距离目标 4 米内时，破甲效果提高 30%。
贴身命中时，重击额外造成破韧伤害。
```

字段：

```json
{
  "condition": "DistanceToTarget",
  "compare": "<=",
  "value": 3.0,
  "effect": {
    "stat": "MeleeDamage",
    "op": "More",
    "value": 0.2
  }
}
```

### 1.2 远距离增伤

```text
投射物每飞行 1 米，伤害提高 2%，最多提高 40%。
距离目标超过 8 米时，暴击率 +10%。
远距离命中时，投射物有 20% 概率分裂。
```

字段：

```json
{
  "condition": "ProjectileTravelDistance",
  "effect": {
    "stat": "Damage",
    "op": "MorePerUnit",
    "valuePerMeter": 0.02,
    "maxValue": 0.4
  }
}
```

### 1.3 背后/侧面攻击

```text
从背后命中敌人时，暴击率 +15%。
从侧面命中时，穿甲 +20%。
背刺暴击时，造成额外真实伤害。
```

## 2. 连击层数 Combo Stack

连击层数鼓励连续命中。

### 2.1 连击获得

```text
连续命中同一目标时获得 1 层连击，最多 10 层。
每层连击使攻击速度提高 2%。
3 秒未命中则失去所有连击。
```

字段：

```json
{
  "stackId": "ComboStack",
  "gainTrigger": "OnHit",
  "maxStack": 10,
  "expireTime": 3.0,
  "refreshOnGain": true,
  "effectsPerStack": [
    {"stat": "AttackSpeed", "op": "Add", "value": 0.02}
  ]
}
```

### 2.2 连击消耗

```text
消耗所有连击层数，使下一次重击每层提高 8% 伤害。
消耗 5 层连击，立即刷新闪避冷却。
连击达到 10 层时，下次技能必定暴击。
```

## 3. 蓄力玩法 Charge

### 3.1 蓄力等级

```text
蓄力 0.5 秒：1 档
蓄力 1.2 秒：2 档
蓄力 2.0 秒：3 档
```

效果：
```text
1档：基础释放
2档：伤害 +50%，范围 +20%
3档：伤害 +120%，附加击退和破韧
```

配置：

```json
{
  "chargeProfileId": "Charge_HeavySlash",
  "levels": [
    {"time": 0.5, "damageMore": 0.0, "areaMore": 0.0},
    {"time": 1.2, "damageMore": 0.5, "areaMore": 0.2},
    {"time": 2.0, "damageMore": 1.2, "areaMore": 0.35, "extraPoiseDamage": 50}
  ],
  "maxChargeTime": 2.0
}
```

### 3.2 蓄力词条

```text
蓄力速度 +25%
满蓄力时必定暴击
满蓄力时额外穿透 30% 护甲
蓄力期间获得 20% 减伤
蓄力被打断时释放小范围冲击
```

## 4. 引导玩法 Channel

引导技能强调持续输出和站桩风险。

### 4.1 引导层数

```text
每引导 0.5 秒获得 1 层聚能，最多 6 层。
每层聚能使伤害提高 8%。
移动或被打断时失去所有层数。
```

### 4.2 引导词条

```text
引导达到 3 层时，范围扩大 25%。
引导达到满层时，投射物数量 +2。
引导期间护盾回复不中断。
引导期间受到伤害降低 15%，但移动速度降低 50%。
```

## 5. 节奏型 UI 显示

需要显示：
- 连击层数
- 蓄力阶段
- 引导层数
- 距离增伤是否生效
- 满层强化提示

HUD 示例：

```text
Combo x7
Charge Lv.3
Channel 5/6
Far Shot Active
```
