# 160 敌人预制体模型配置：怪物、Boss、精英变体

## 1. 敌人模型目标

敌人模型需要支持：

- 普通怪固定外观
- 精英怪外观变体
- 稀有怪词缀特效
- Boss 部位模型
- 弱点模型
- 武器挂点
- 破甲/断肢/部位破坏
- 材质变体
- LOD
- Hitbox 与受击点

---

## 4. 精英怪外观变体

精英怪可通过配置添加：

- 光环
- 体型放大
- 材质染色
- 武器替换
- 头部/肩部装饰
- 词缀特效
- 名称板边框增强

示例：

```json
{
  "eliteVisualProfileId": "Elite_FireBerserker",
  "scaleMultiplier": 1.12,
  "materialOverride": "MatSet_FireElite",
  "auraVfx": "VFX_Aura_Fire_Elite",
  "attachmentOverrides": [
    {
      "socket": "Back",
      "prefab": "PF_FireBanner_Back",
      "localPosition": [0, 0.12, -0.05],
      "localEuler": [0, 0, 0],
      "localScale": [1, 1, 1]
    }
  ]
}
```

## 5. Boss 模型结构

Boss 通常比普通怪复杂，需要部位配置。

```text
PF_Boss_BlackForgeWarden
├── BossRoot
├── SkeletonRoot
├── BodyPartRoot
│   ├── HeadPart
│   ├── TorsoPart
│   ├── Arm_L
│   ├── Arm_R
│   ├── Leg_L
│   ├── Leg_R
│   └── CoreWeakPoint
├── BossSocketRoot
├── BossHitboxRoot
├── BossWeakPointRoot
├── BossBreakablePartRoot
└── BossPhaseVFXRoot
```

Boss 部位配置：

```json
{
  "bossPartId": "CoreWeakPoint",
  "bone": "spine_03",
  "renderer": "SMR_Boss_Core",
  "hitbox": "HB_Boss_Core",
  "isWeakPoint": true,
  "damageMultiplier": 1.35,
  "breakable": true,
  "breakVfx": "VFX_Boss_CoreBreak",
  "breakHideRenderer": false
}
```

## 6. 怪物装备化外观

有些敌人可以像玩家一样装备武器或护甲，但不需要完整装备系统。

```json
{
  "monsterVisualLoadout": {
    "weapon_R": "AT_Skeleton_Axe_01",
    "helmet": "SKELMESH_Skeleton_Helmet_01",
    "back": "AT_BoneFlag_Back"
  }
}
```

用途：
- 同一种怪多个外观变体
- 不同难度怪更强外观
- 精英怪更醒目

---

## 7. 敌人模型初始化流程

```text
Spawn Monster
→ Load Enemy Prefab
→ Apply MonsterModelConfig
→ Apply Variant / Elite Visual
→ Apply Affix VFX
→ Build Hitbox
→ Build Socket Cache
→ Bind AnimationSet
→ Enable AI
```

---

## 8. 验收标准

- 普通怪能加载基础模型。
- 精英怪能叠加材质和光环变体。
- Boss 能配置部位和弱点。
- 敌人武器挂点能正确显示武器。
- 词缀特效不会影响动画和碰撞。
