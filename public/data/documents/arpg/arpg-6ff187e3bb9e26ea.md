# 101_主城NPC内容总览_功能定位_解锁节奏

> 目标：把主城从“几个可点击按钮”变成完整的 ARPG 服务中枢。玩家回城后，能完成卖货、整理、打造、买技能、传送副本、领取任务、进入终局、试炼、训练和仓库管理。
>
> 设计原则：参考暗黑类刷宝游戏的主城职能密度，但所有 NPC 名称、服务项、商品、技能、数值、文案均为本项目原创。

---

## 1. 主城定位

主城名称：**星陨营地**

主城不是单纯菜单，而是玩家的长期循环中枢：

```text
战斗地图 / 副本 / Boss / 终局地图
        ↓ 回城
卖垃圾 → 分解 → 强化装备 → 更换技能 → 存仓库 → 接新任务 → 传送下一张地图
        ↓
继续刷图
```

主城必须承载以下功能：

| 模块 | 目的 | 对应 NPC / 物件 |
|---|---|---|
| 装备处理 | 出售、分解、强化、品质、镶孔、修理 | 铁匠铺 NPC |
| 技能成长 | 购买主动技能、辅助模块、保留技能、技能升级书 | 技能商人 |
| 药剂循环 | 购买药剂、药剂基底、恢复类消耗品 | 药剂商 |
| 副本入口 | 章节副本、材料副本、挑战副本、Boss 回战 | 副本传送师 |
| 终局入口 | 地图钥石、地图装置、地图词缀、地图仓库 | 地图商人与秘境装置 |
| 任务推进 | 主线、支线、悬赏、日常、教程 | 任务 NPC / 悬赏板 |
| 资产管理 | 仓库、共享仓库、角色切换、材料仓库 | 仓库管理员 |
| 训练测试 | 木桩、伤害统计、技能试用 | 训练教官 / 训练场 |
| 商业补给 | 基础装备、卷轴、传送耗材、低阶材料 | 杂货商 |
| 赛季玩法 | 限时机制、赛季货币、特殊商店 | 赛季使者，后期开放 |

## 2. 主城空间分区

### 2.1 白盒区域划分

```text
[北侧高台]    秘境装置 / 终局地图商人 / 地图仓库

[西北角]      铁匠铺：熔炉、铁砧、武器架、分解箱
[西侧街道]    杂货商、药剂商、材料摊

[中央广场]    回城出生点、传送石碑、副本传送师、公告板

[东侧廊道]    技能商人、训练教官、技能试炼木桩
[东南角]      仓库管理员、个人仓库、共享仓库、换装衣柜

[南侧出口]    章节地图出口、教学地图入口、战斗区域门
```

### 2.2 主城最小尺寸建议

| 区域 | 原型尺寸 | 说明 |
|---|---:|---|
| 中央广场 | 30m × 30m | 出生点、传送、玩家集散 |
| 铁匠铺 | 18m × 14m | 需容纳装备展示架和熔炉 |
| 技能摊位 | 18m × 12m | 靠近训练场 |
| 训练场 | 24m × 18m | 3 个木桩 + 1 个移动假人 |
| 终局高台 | 24m × 20m | 地图装置、地图仓库、终局商人 |
| 仓库区 | 16m × 14m | 仓库 NPC 和箱子模型 |
| 南侧出口门 | 14m × 8m | 章节地图入口 |

### 2.3 主城动线

玩家回城点必须面向中央广场，视野内直接能看到：

1. 传送石碑
2. 铁匠铺招牌
3. 技能商人的发光书架
4. 仓库箱子
5. 副本传送门

玩家从回城点到核心 NPC 的距离控制：

| NPC | 最大距离 | 目的 |
|---|---:|---|
| 铁匠 | 18m | 高频出售、分解 |
| 仓库 | 22m | 高频整理物品 |
| 技能商人 | 24m | 中频换技能 |
| 副本传送师 | 12m | 高频进图 |
| 地图装置 | 30m | 后期终局核心 |
| 药剂商 | 20m | 低中频补给 |

## 4. NPC 功能解锁节奏

### 4.1 新手 0-20 分钟

| 时间点 | 开放内容 | 说明 |
|---|---|---|
| 初次进城 | 铁匠出售、仓库、技能商人基础技能 | 立刻让玩家处理掉落和换技能 |
| 完成教学 Boss | 药剂商、杂货商、传送石碑 | 让玩家知道回城补给循环 |
| 完成第一张野外地图 | 副本传送师开放章节地图 | 开始地图选择 |
| 第一次拾取稀有装备 | 铁匠分解、材料仓库提示 | 引导分解而不是全卖 |
| 第一次技能升级 | 技能商人开放辅助模块 | 引导技能搭配 |

### 4.2 第 1-2 小时

| 条件 | 新开放 |
|---|---|
| 角色等级 8 | 铁匠品质强化、技能商人卖第一批保留技能 |
| 角色等级 12 | 副本传送开放材料副本 |
| 角色等级 15 | 悬赏板开放日常讨伐 |
| 击败第 1 章 Boss | 职业试炼入口开放 |
| 角色等级 20 | 符石匠开放基础符石镶嵌 |

### 4.3 中后期

| 条件 | 新开放 |
|---|---|
| 主线第 3 章 | Boss 回战系统 |
| 主线第 4 章 | 高阶材料副本 |
| 主线通关 | 秘境装置、地图钥石、终局商店 |
| 第一次完成终局地图 | 地图词缀重铸、地图仓库 |
| 完成职业试炼 2 | 专精技能商店页签 |

## 5. NPC 交互标准结构

所有 NPC 统一使用 `NPCInteractionController`，但不同 NPC 挂不同服务组件。

```text
NPC_Root
├── ModelRoot
├── Animator
├── Collider_InteractTrigger
├── NPCInteractionController
├── NPCDialogueComponent
├── NPCServiceRouter
├── WorldSpaceHUDAnchor
├── IconMarker
└── Services
    ├── ShopServiceComponent         可选
    ├── CraftServiceComponent        可选
    ├── TeleportServiceComponent     可选
    ├── StashServiceComponent        可选
    ├── QuestServiceComponent        可选
    ├── TrainingServiceComponent     可选
    └── TrialServiceComponent        可选
```

### 5.1 交互入口规则

玩家靠近 NPC 后，头顶显示：

```text
[图标] NPC 名称
功能副标题
[E] 交互
```

示例：

```text
⚒ 老炉匠·斐洛
装备强化 / 分解 / 出售
[E] 交互
```

### 5.2 交互菜单结构

点击 NPC 后，不要直接进入单一面板，先显示右侧服务菜单：

```text
NPC 对话框
├── NPC 名称与立绘
├── 当前主线提示语
├── 服务按钮列表
│   ├── 购买 / 出售
│   ├── 分解装备
│   ├── 强化装备
│   ├── 镶孔 / 符石
│   └── 离开
└── 当前货币显示
```

高频 NPC 可支持快捷键：

| 快捷键 | 功能 |
|---|---|
| E | 打开默认服务 |
| F | 打开出售页 |
| R | 打开分解页 |
| Tab | 切换服务页签 |
| Esc | 返回 / 关闭 |

## 6. 主城 NPC 状态表现

### 6.1 可用状态

| 状态 | HUD | 说明 |
|---|---|---|
| 可交互 | 白色名称 + 功能图标 | 已解锁 |
| 有新货 | 名称旁小黄点 | 商店刷新 |
| 有任务 | 头顶金色感叹号 | 可接任务 |
| 可交任务 | 头顶绿色问号 | 任务完成 |
| 功能未解锁 | 名称灰色 + 锁图标 | 可见但不可用 |
| 限时活动 | 紫色星标 | 赛季/活动 |

### 6.2 解锁引导

未解锁功能不可隐藏太深。玩家点击时要给清晰提示：

```text
“符石镶嵌将在第 2 章击败【裂骨看守】后开放。”
```

## 8. 第一版必须完成的 NPC

第一阶段主城必须先做 6 个：

1. 铁匠：卖装备、出售、分解、基础强化
2. 技能商人：卖职业技能、辅助模块、保留技能
3. 副本传送师：传章节图、材料图、Boss 回战
4. 仓库管理员：个人仓库、共享仓库、材料仓库
5. 药剂商：药剂、恢复品、药剂升级
6. 训练教官：木桩测试、技能试用

第二阶段再加：

1. 地图商人
2. 符石匠
3. 悬赏板
4. 职业试炼 NPC
5. 赛季 NPC
