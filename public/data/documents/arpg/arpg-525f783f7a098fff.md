# 143 HitFeedback 预制体结构：组件、事件、对象池

## 1. 设计目标

将伤害表现从技能脚本中剥离出来，形成可复用组件。  
技能只负责发出命中事件，表现系统根据配置自动播放反馈。

---

## 2. 核心预制体结构

### 2.1 角色单位预制体

## 3. HitFeedbackReceiver

### 3.1 职责
接收 HitContext，并分发到各表现模块。

```text
HitFeedbackReceiver
├── DamageNumberEmitter
├── HitReactionController
├── MaterialFlashController
├── HitVFXEmitter
├── HitSFXEmitter
├── HitStopController
├── CameraShakeRequester
└── CombatDisplacementController
```

### 3.2 接口示例

```csharp
public void ReceiveHit(HitContext context)
{
    ResolveProfile(context);
    EmitDamageNumber(context);
    PlayHitReaction(context);
    ApplyMaterialFlash(context);
    SpawnHitVFX(context);
    PlayHitSFX(context);
    ApplyHitStop(context);
    RequestCameraShake(context);
    ApplyDisplacement(context);
}
```

## 4. DamageNumberEmitter

### 4.1 职责
- 生成伤害跳字请求。
- 判断世界空间位置。
- 处理合并。
- 发送给对象池。

### 4.2 字段
```text
anchorTransform
defaultOffset
mergeWindow
allowDOTMerge
maxNumbersPerSecond
```

---

## 5. HitReactionController

### 5.1 职责
- 选择受击动画。
- 设置 Animator 参数。
- 判断霸体。
- 判断破韧。
- 中断当前动作。

### 5.2 字段
```text
bodySize
armorType
canBeKnockedBack
canBeLaunched
canBeKnockedDown
reactionSetId
```

---

## 6. MaterialFlashController

### 6.1 职责
- 控制闪白。
- 控制元素染色。
- 控制护盾效果。
- 使用 MaterialPropertyBlock。

### 6.2 字段
```text
targetRenderers
flashShaderProperty
elementShaderProperty
shieldShaderProperty
useWeakPointFlash
```

---

## 7. HitVFXEmitter

### 7.1 职责
- 从对象池取特效。
- 根据命中点和法线摆放。
- 根据伤害强度缩放。
- 支持挂点特效。

### 7.2 字段
```text
hitSocketRoot
defaultHitPoint
vfxPoolGroup
attachVfxToTarget
```

---

## 8. HitSFXEmitter

### 8.1 职责
- 播放命中音效。
- 叠加元素音效。
- 叠加暴击音效。
- 距离衰减。

### 8.2 字段
```text
audioSource
sfxGroup
volumeMultiplier
pitchRandomRange
maxSfxPerSecond
```

---

## 9. CombatDisplacementController

### 9.1 职责

```

### 11.1 伤害数字池

```

### 11.2 VFX 池
```text
Pool_VFX_Hit_Physical
Pool_VFX_Hit_Element

Pool_VFX_PoiseBreak
Pool_VFX_BossHit
```

### 11.3 池回收规则
- 动画播完自动回收。
- 超时强制回收。
- 对象池不足时降级表现。
- 禁止战斗中 Instantiate 关键对象。

---

## 12. 调试面板

调试面板必须支持：
- 手动触发普通命中。
- 手动触发暴击。
- 手动触发火/冰/雷/毒伤害。
- 手动触发击退/击飞/击倒。
- 手动触发破盾/破韧。
- 查看当前 HitContext。
- 查看对象池数量。
- 查看跳字合并状态。

---

## 13. 验收标准
- 技能脚本不直接控制跳字和受击动作。
- 所有表现通过 HitContext + Profile 触发。
- 大量敌人受击时无频繁 Instantiate。
- 可以在调试面板快速测试每种反馈。
