# 天赋系统总设计：大天赋树、职业起点、专精树

> 参考边界：本项目参考暗黑刷宝 ARPG 的系统结构：职业起点、主动技能、辅助模块、保留技能、触发技能、巨型被动树、职业专精树、装备词条联动、Boss 机制与终局构筑。
> 不直接复制任何商业游戏的职业名、技能名、图标、数值、UI截图、专有词条与怪物设定。下面所有职业、技能、天赋节点、数值区间、特效表现均为项目原创，用于 Unity 原型和后续美术/程序落地。

## 1. 设计目标

天赋系统用于把职业、装备、技能和地图玩法连成一个长期成长网络。

核心结构：

```text
大天赋树 GlobalPassiveTree
├── 12 个职业起点
├── 属性主干
├── 武器分支
├── 技能标签分支
├── 防御分支
├── 异常状态分支
├── 召唤/触发/保留分支
└── 珠宝/特殊节点插槽

专精树 ClassSpecializationTree
├── 每个职业 3 个专精
├── 每个专精 8 个小节点
├── 每个专精 4 个中节点
├── 每个专精 4 个大节点
└── 每个专精 1 个终极节点
```

## 2. 大天赋树布局

```text
                  智慧/法术/护盾
                         ↑
        召唤/诅咒 ← 女巫区   术士区 → 元素/触发
              ↖                         ↗
       刺客区 ← 敏智区       力智区 → 祭司/裁决者
             ↙                           ↘
        游侠区 ← 敏捷/投射  力量/重击 → 战士区
                         ↓
                  生命/护甲/近战
```

### 2.1 职业起点

每个职业起点附近 20 个节点必须支持新手自然成长：

```text
主属性
生命/魔力/护盾之一
主武器伤害
一个防御方向
一个职业资源方向
一个推荐技能标签方向
```

### 2.2 跨区成本

跨区不禁止，但需要路径成本。

| 跨区类型 | 路径成本 | 设计意义 |
|---|---:|---|
| 同属性相邻职业 | 8-14 点 | 鼓励流派融合 |
| 双属性到单属性 | 12-18 点 | 可以做但不轻松 |
| 对角跨越 | 20-32 点 | 后期 BD 才考虑 |

## 3. 节点类型

| 类型 | 作用 | 示例 |
|---|---|---|
| 小节点 | 提供基础数值 | +5 力量、+4% 火焰伤害 |
| 中节点 | 提供构筑方向 | 投射物穿透 +1、召唤物生命 +12% |
| 大节点 | 改变机制 | 近战重击可生成震波，但攻击速度降低 |
| 核心节点 | 强代价强收益 | 生命不再自然回复，但吸血上限提高 |
| 插槽节点 | 装入符文/珠宝 | 改变周围节点或提供特殊词条 |
| 专精入口 | 连接职业专精树 | 需要完成试炼 |

## 4. 天赋点来源

```text
角色升级：1 点/级，最高 99 点
主线任务：每章 2-4 点
Boss 首杀：关键 Boss 给 1 点
专精试炼：给专精点，不给普通点
终局地图：不给角色天赋点，只给地图/Atlas 点
```

## 5. 专精树规则

```text
每个职业 3 个专精
角色只能选择 1 个主专精
后期可通过高成本道具重置专精
专精点最高 8 点
每个专精拥有 4 条路径
```

专精节点示例：

```text
小节点：职业资源获得 +8%
中节点：核心技能标签伤害 +15%
大节点：职业资源满时，下一个核心技能改变表现
终极节点：职业专精核心循环成立
```

## 8. 验收标准

- 可以缩放、拖拽、搜索节点。
- 节点可以显示未解锁、可点、已点、预览状态。
- 点节点后角色属性实时刷新。
- 点大节点后技能逻辑能真实变化，而不是只改 Tooltip。
- 专精点和普通点严格分开。
