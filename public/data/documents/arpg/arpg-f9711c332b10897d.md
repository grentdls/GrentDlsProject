# 222 技能页面与战斗 HUD 技能槽 UI 优化方案：技能列表、详情、预览、装配

## 1. 文档目标

当前技能页面需要从“文字列表 + 简单描述”升级成更接近正式暗黑刷宝 ARPG 的技能管理界面。

玩家在技能页面里应该能快速完成：

```text
查看已有技能
理解技能类型和流派标签
查看技能伤害规则
查看技能字段：消耗、冷却、范围、投射物、召唤物、控制等
查看技能受到哪些装备、套装、天赋影响
预览当前角色释放技能的实际效果
升级技能
装配技能
修改快捷键
拖拽替换技能
右键快速更替技能
```

同时战斗 HUD 的技能槽也必须清楚显示：

```text
可以释放
释放中
冷却中
资源不足
被控制禁用
引导中
蓄力中
充能中
强化可用
连段窗口
```

# 第一部分：技能页面整体布局

## 2. 技能页面主结构

技能页面使用“三栏式布局”：

```text
PF_SkillPage
├── Left_SkillInventoryPanel      左侧：技能列表，图标网格
├── Center_EquippedSkillPanel     中间：已装备技能槽，类似角色装备槽
└── Right_SkillInfoPanel          右侧：技能预览 + 技能详情 + 操作按钮
```

推荐宽度比例：

```text
左侧技能列表：34%
中间装配槽：24%
右侧详情/预览：42%
```

16:9 横屏示意：

```text
┌──────────────────────┬───────────────────┬────────────────────────────┐
│ 技能列表              │ 已装备技能槽        │ 技能预览                    │
│ 图标网格              │ 主动/保留/触发槽    │ 当前角色 + 木桩循环演示      │
│ 名称显示在图标下方    │ 快捷键显示          ├────────────────────────────┤
│ 筛选/搜索/排序        │ 拖拽装配            │ 技能详情                    │
│                      │ 右键更替            │ 描述/伤害规则/字段/成长      │
│                      │ 快捷键修改          ├────────────────────────────┤
│                      │                    │ 升级/装配/卸下/测试按钮      │
└──────────────────────┴───────────────────┴────────────────────────────┘
```

## 3. 左侧：技能列表区域

## 3.1 技能列表定位

技能列表参考装备背包格子的排布方式，不使用纯文字列表。

```text
Left_SkillInventoryPanel
├── Header
│   ├── Title_技能列表
│   ├── SearchInput_搜索
│   ├── SortDropdown_排序
│   └── FilterButton_筛选
├── CategoryTabs
│   ├── 全部
│   ├── 主动
│   ├── 辅助
│   ├── 保留
│   ├── 位移
│   ├── 召唤
│   └── 触发
├── SkillGridScroll
│   └── PF_SkillIconCell × N
└── Footer
    ├── Text_OwnedCount
    ├── Text_CanLearnCount
    └── NewSkillHint
```

## 3.2 技能图标 Cell 结构

每个技能 Cell 显示：

```text
PF_SkillIconCell
├── Background_TypeOrRarity
├── Icon_Skill
├── Frame_SkillType
├── Text_SkillName
├── Text_SkillLevel
├── Icon_DamageType
├── Marker_Equipped
├── Marker_CanUpgrade
├── Marker_New
├── LockOverlay
├── SelectionFrame
└── HoverHighlight
```

显示规则：

```text
技能图标：主体最大
技能名称：显示在图标下方
技能等级：右下角小标签 Lv.12 / Max
伤害类型：左上角小图标，火/冰/雷/毒/物理等
已装备：右上角小勾或槽位编号
可升级：向上箭头
未解锁：灰色遮罩 + 锁图标
新获得：小红点或新字标
```

## 3.3 技能格尺寸

推荐尺寸：

```text
普通密度 SkillCell：88 × 108
技能图标：72 × 72
名称高度：24
等级角标：22 × 18
元素图标：18 × 18
```

如果技能数量很多，支持紧凑模式：

```text
紧凑 SkillCell：72 × 92
技能图标：60 × 60
```

## 3.4 技能列表筛选

筛选维度：

```text
技能类型：主动 / 辅助 / 保留 / 触发 / 位移 / 召唤
伤害类型：物理 / 火焰 / 冰冷 / 闪电 / 毒素 / 暗影 / 神圣
技能标签：近战 / 投射物 / AOE / DOT / 控制 / 引导 / 蓄力
职业推荐：当前职业 / 全职业 / 其他职业
装配状态：已装备 / 未装备
升级状态：可升级 / 已满级 / 缺材料
资源类型：法力 / 怒气 / 能量 / 魂火 / 护盾
```

搜索支持：

```text
技能名
技能标签
伤害类型
流派关键词
例如：投射物、召唤、火焰、破盾、控制
```

# 第二部分：中间已装备技能槽

## 4. 技能装配槽整体结构

已装备技能槽类似角色装备槽位，需要清楚显示当前战斗配置。

```text
Center_EquippedSkillPanel
├── Header_当前技能配置
├── ActiveSkillSlots_主动技能槽
├── UtilitySkillSlots_位移/防御/特殊槽
├── ReserveSkillSlots_保留技能槽
├── TriggerSkillSlots_触发技能槽
├── ShortcutEditPanel_快捷键编辑
└── BuildSummary_当前流派标签
```

## 4.1 推荐槽位数量

第一版建议：

```text
主动技能槽：6 个
位移技能槽：1 个
保留技能槽：3 个
触发技能槽：2 个
```

键鼠默认：

```text
LMB：普通攻击 / 主攻击
RMB：主技能
Q：技能 1
W：技能 2
E：技能 3
R：技能 4
Space：闪避 / 位移
1-5：药剂，属于 HUD 药剂槽
```

## 4.2 装配槽 Prefab

```text
PF_EquippedSkillSlot
├── SlotBackground
├── SlotFrame
├── Icon_Skill
├── Text_KeyBinding
├── Text_SkillLevel
├── Icon_SkillType
├── CooldownPreviewMask
├── EquippedStateGlow
├── EmptySlotHint
├── DragDropReceiver
├── RightClickMenuArea
└── ConflictWarningIcon
```

空槽显示：

```text
空技能槽
拖入技能或点击选择
```

已装备显示：

```text
技能图标
快捷键
技能等级
技能类型图标
技能状态小标记
```

## 4.3 右键更替技能

右键技能列表中的技能：

```text
如果技能未装备：
    弹出可装备槽位列表
    玩家选择槽位
    装配技能

如果技能已装备：
    弹出菜单：
        卸下技能
        替换槽位
        修改快捷键
        查看详情
        加入收藏
```

右键空槽：

```text
弹出技能选择小面板
只显示可放入该槽位的技能
```

右键已装备槽：

```text
卸下
替换
修改快捷键
锁定槽位
查看技能详情
```

## 4.4 拖拽装配规则

```text
从技能列表拖到技能槽：装配技能
从技能槽拖到另一个技能槽：交换技能槽位
从技能槽拖到空白处：卸下技能，可弹确认
从技能槽拖回技能列表：卸下技能
```

拖拽反馈：

```text
可放入槽位：绿色边框
不可放入槽位：红色边框
替换槽位：黄色边框
同类型推荐槽位：蓝色呼吸光
```

失败原因提示：

```text
该槽位只能放入保留技能
该技能需要弓或弩
该技能未解锁
该技能需要双手武器
该技能需要召唤槽位
当前职业无法使用
```

## 4.5 快捷键修改

点击快捷键标签或右键菜单选择“修改快捷键”。

流程：

```text
点击快捷键
→ 槽位进入等待输入状态
→ 文本显示“按下新按键”
→ 玩家按下新按键
→ 检查冲突
→ 如果冲突，提示覆盖/交换/取消
→ 保存快捷键
```

冲突处理：

```text
覆盖：新槽位占用按键，原槽位清空
交换：两个槽位交换快捷键
取消：不保存修改
```

视觉反馈：

```text
等待输入：快捷键框体变亮
冲突：红色提示
修改成功：绿色闪光 + 音效
```

# 第三部分：右侧技能预览与详情

## 5. 右侧面板结构

右侧面板上方是技能效果预览，中间是技能详情，下方是操作按钮。

```text
Right_SkillInfoPanel
├── SkillPreviewPanel      上方：技能效果预览
├── SkillDetailPanel       中部：技能详情
└── SkillActionPanel       下方：升级/装配/快捷键/测试按钮
```

推荐高度比例：

```text
技能预览：35%
技能详情：45%
操作按钮：20%
```

## 6. 技能效果预览界面

## 6.1 预览目标

技能预览是一个小型演示场景：

```text
当前角色单独站在预览场景中
旁边生成几个木桩
角色自动重复释放当前技能
玩家能看到动作、弹道、范围、命中特效、伤害跳字、控制表现
```

## 6.2 预览区域结构

```text
SkillPreviewPanel
├── PreviewViewport
│   ├── PreviewCamera
│   ├── CharacterPreview
│   ├── TrainingDummyGroup
│   ├── GroundGrid
│   ├── SkillVFXPreview
│   └── DamageNumberPreview
├── PreviewControls
│   ├── Button_PlayPause
│   ├── Button_Replay
│   ├── Toggle_Speed 0.5x/1x/2x
│   ├── Toggle_DummyCount
│   ├── Toggle_DummyType
│   └── Toggle_ViewMode
└── PreviewInfoOverlay
    ├── Text_CurrentSkillName
    ├── Text_HitCount
    ├── Text_EstimatedDamage
    ├── Text_DPS
    └── Text_RangeOrRadius
```

## 6.3 预览木桩配置

默认木桩：

```text
近距离木桩：1 个，距离 2 米
中距离木桩：1 个，距离 6 米
远距离木桩：1 个，距离 10 米
群体木桩：3-5 个，用于 AOE 和连锁
```

木桩类型：

```text
普通木桩
护盾木桩
高护甲木桩
元素抗性木桩
Boss 木桩
召唤物目标木桩
```

## 6.4 技能预览循环逻辑

```text
选择技能
→ 加载当前角色模型和装备外观
→ 生成木桩
→ 播放技能起手
→ 释放技能
→ 显示命中、伤害、状态、特效
→ 等待 1 秒
→ 重置木桩状态
→ 再次循环
```

特殊技能预览：

```text
引导技能：起手 → 引导 2 秒 → 收招
蓄力技能：短蓄力演示一次 + 满蓄力演示一次
召唤技能：召唤 → 召唤物攻击木桩 → 重置
保留技能：展示开启光环效果 + 属性变化
位移技能：展示移动路径和落点范围
控制技能：展示控制状态图标和持续时间
```

## 6.5 预览信息显示

预览浮层显示：

```text
命中次数
预计总伤害
每秒伤害
伤害类型
异常状态
控制时间
投射物数量
AOE 半径
召唤物数量
冷却时间
资源消耗
```

显示规则：

```text
小型浮层，不挡住角色动作
元素伤害用对应元素图标
控制和异常用状态图标
```

## 7.2 技能头部 Header

示例：

```text
雷裂箭
Lv.12 主动技能
标签：攻击  投射物  闪电  命中  连锁
```

技能类型颜色：

```text

保留技能：金色
召唤技能：绿色
位移技能：青色

```

## 7.3 核心描述

核心描述要短，说明玩法，不堆公式。

推荐写法：

```text
发射一支闪电箭，命中敌人后会向附近目标连锁。
适合远距离暴击和感电流派。
```

详细公式放到伤害规则区。

## 7.4 伤害规则区

伤害规则要结构化显示：

```text
【伤害规则】
基础伤害：120% 武器伤害
伤害类型：70% 物理 + 30% 闪电
命中次数：1 次主命中
连锁：最多 2 次
连锁伤害：主命中的 45%
暴击：可以暴击
异常：可造成感电
```

UI 规则：

```text
字段名左对齐
数值右对齐
伤害类型用图标 + 颜色
重要机制用小标签
不生效规则灰色显示
```

## 7.6 成长与缩放区

显示技能如何随等级、装备、天赋成长。

```text
【成长来源】
技能等级：每级基础伤害 +8%
武器伤害：继承 120%
法术强度：继承 85%
投射物加成：可生效
闪电伤害加成：可生效
暴击加成：可生效
```

不生效内容：

```text
不受攻击速度影响
不受投射物数量影响
DOT 部分不能暴击
触发伤害不能再次触发击杀爆炸
```

## 7.7 装备、套装、天赋影响区

显示当前构筑实际对技能产生的改变。

```text
【当前加成】
来自装备：
投射物数量 +1
闪电伤害 +24%
暴击率 +8%

来自天赋：
感电效果 +20%
暴击时连锁 +1

来自套装：
远距离暴击时投射物分裂一次
```

不适用词条灰色显示：

```text
灰色：AOE 范围 +20% —— 该技能不是 AOE
```

## 7.8 升级预览区

升级技能时显示升级前后变化。

```text
【升级预览 Lv.12 → Lv.13】
基础伤害：120% → 128%
法力消耗：18 → 19
感电几率：22% → 24%
连锁伤害：45% → 47%
```

颜色：

```text
提升：绿色
增加消耗：黄色
负面变化：红色
无变化：灰色
```

## 7.9 需求区

```text
需求等级：12

职业推荐：游侠
资源类型：法力
```

# 第五部分：技能页面交互流程

## 9. 鼠标悬停技能

悬停技能图标时：

```text
图标高亮
右侧显示技能详情
技能预览切换到该技能
已装备槽位高亮
显示简短 Tooltip
```

简短 Tooltip：

```text
雷裂箭 Lv.12
投射物 / 闪电 / 连锁
左键查看，右键装配
```

## 10. 点击技能

```text
选中该技能
右侧详情固定显示
预览开始循环播放
中间可装备槽位高亮
```

## 11. 双击技能

```text
如果有空槽：自动装配到推荐槽位
如果没有空槽：弹出替换槽位面板
```

## 12. 右键技能

右键菜单：

```text
装配到槽位
替换已有技能
卸下
修改快捷键
查看升级材料
加入收藏
```

## 16. 技能槽状态表

| 状态 | 显示方式 | 说明 |
|---|---|---|
| 可释放 Ready | 图标正常，边框轻微亮光 | 当前可用 |
| 释放中 Casting | 边框流光，底部进度条 | 前摇/释放中 |

| 蓄力中 Charging | 蓄力条增长，阶段刻度亮起 | 长按蓄力 |

| 资源不足 NoResource | 图标偏暗，资源图标红闪 | 法力/怒气不足 |

| 强化可用 Empowered | 金色或元素色角标 | Buff/套装强化 |
| 连段窗口 ComboWindow | 槽位边框短闪 | 可接下一段 |

## 17. 冷却显示

使用双层显示：

```text
环形冷却遮罩
+ 中间秒数
```

规则：

```text
冷却 > 10 秒：显示整数
冷却 1-10 秒：显示 1 位小数
冷却 < 1 秒：只显示环形，不显示数字
```

## 18. 释放中状态

释放中显示：

```text
边框变成技能类型颜色
底部显示 CastingProgressBar
技能图标轻微放大
不可重复点击的技能显示锁定
可排队技能显示 Queue 标记
```

释放阶段：

```text
前摇 Startup：黄色进度
生效 Active：亮色闪光
后摇 Recovery：灰黄进度
```

```text
环形引导进度
```

```text
聚能 4/6
```


## 22. 资源不足状态


## 24. 强化状态

```text
破韧后下一次重击必暴
药剂期间投射物 +1

满盾时法术伤害提高
套装 5 件效果触发
```

HUD 表现：

```text
技能槽右上角显示强化角标

悬停显示强化来源
```

示例：

```text

下一次重击必定暴击
```

## 36. 验收标准

```text
技能列表必须是图标网格，不是纯文字列表。
技能名称必须显示在图标下方。
已装备技能必须使用类似装备槽位的结构。
技能可以右键装配/替换/卸下。
技能可以拖拽到槽位快速更替。
技能槽快捷键可以修改。
鼠标悬停技能时右侧显示详情。
点击技能时右侧详情固定。
右侧上方必须有技能效果预览。
技能预览必须能看到当前角色对木桩循环释放技能。
技能详情必须拆分技能描述、伤害规则、字段、成长、装备天赋影响。
技能升级按钮必须显示材料消耗和升级前后变化。
战斗 HUD 技能槽必须显示可释放、释放中、冷却中、资源不足、禁用等状态。
冷却必须有环形遮罩和数字。
引导/蓄力/充能技能必须有专用状态显示。
强化技能必须有明显角标。
```
