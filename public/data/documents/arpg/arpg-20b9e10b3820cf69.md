# 14_地形搭建规范：白盒模块、尺寸、碰撞、NavMesh

> 目标：定义 Unity 里搭建 3D ACT ARPG 地形原型的标准。先用统一尺寸的白盒模块搭建主城、野外、地牢、Boss 房，再替换成正式美术。

---

## 1. Unity 单位规范

| 项目 | 标准 |
|---|---|
| 1 Unity Unit | 1 米 |
| 玩家角色高度 | 1.8m - 2.0m |
| 玩家胶囊半径 | 0.35m - 0.45m |
| 普通怪高度 | 1.4m - 2.2m |
| 大型怪高度 | 2.5m - 4.0m |
| Boss 高度 | 4.0m - 12.0m |
| 单人通道最小宽度 | 3.0m |
| 双向战斗通道宽度 | 6.0m - 8.0m |
| 普通战斗场地直径 | 18m - 30m |
| 精英战斗场地直径 | 30m - 45m |
| Boss 房直径 | 60m - 110m |
| 主城主路宽度 | 8m - 12m |
| 主城功能广场 | 25m - 45m |

## 3. 地形类型规范

### 3.1 主城地形

主城必须是功能优先，不追求迷宫感。

结构：

```text
主城入口/复活点
    ↓
中央传送广场
    ├── 商店区
    ├── 铁匠区
    ├── 技能商人区
    ├── 仓库区
    ├── 地图装置区
    ├── 任务 NPC 区
    └── 出城门/传送门区
```

主城设计规则：

- 所有核心 NPC 距离出生点不超过 25m。
- 仓库、铁匠、商店互相距离不超过 15m。
- 传送点必须明显，放在中央或入口旁。
- 不允许做复杂楼梯和绕路。
- 主城内禁止战斗，怪物层关闭。
- 主城内可放少量装饰互动物，但不能影响寻路。

### 3.2 野外地形

野外地形适合 3D ACT 战斗和探索。

推荐结构：

```text
入口安全区 -> 小战斗区 -> 分叉路 -> 大战斗区 -> 支线事件 -> 精英区 -> 出口/Boss入口
```

设计规则：

- 主路线清晰，但允许 1 到 3 个支线。
- 每 30m 到 50m 设置一个战斗点。
- 每个战斗点至少有一个绕行空间。
- 远程怪区域必须有柱子、石头、断墙等遮挡。
- 支线尽头放宝箱、精英或事件。
- 出口前必须有一个相对安静的缓冲区。

### 3.3 地牢地形

地牢用于高密度战斗，适合房间图结构。

推荐结构：

```text
入口房
    ↓
普通房 x 2-4
    ↓
分叉房 / 机关房
    ├── 宝箱房
    └── 精英房
    ↓
Boss 前缓冲房
    ↓
Boss 房
```

设计规则：

- 房间之间走廊不宜太长，10m 到 25m 为宜。
- 房间最小 16m x 16m，标准 24m x 24m。
- 精英房建议 32m x 32m。
- Boss 前必须有补给、传送或检查点。
- 迷宫感来自分叉，不来自低可读性。

### 3.4 Boss 房地形

Boss 房必须服务 Boss 技能和玩家闪避。

常用结构：

| Boss 类型 | 推荐地形 |
|---|---|
| 近战压迫型 | 圆形大场地，少量柱子 |
| 远程法术型 | 大场地 + 柱子遮挡 |
| 召唤型 | 中央 Boss + 四周召唤门 |
| 冲锋型 | 长方形/椭圆场地，边缘安全 |
| 多阶段型 | 圆形场地 + 阶段地形变化 |
| 巨型 Boss | 半圆平台或宽阔平台，Boss 在边缘/中心 |

## 4. 场景高度与相机规则

### 4.1 可行走高度

| 高度差 | 处理方式 |
|---:|---|
| 0m - 0.3m | 可直接通过 |
| 0.3m - 1.0m | 需要坡道或台阶 |
| 1.0m - 3.0m | 需要楼梯/坡道/跳台机制 |
| 3.0m 以上 | 视为平台层级，需要单独 NavMesh Link |

### 4.2 相机安全规则

3D ACT 镜头容易被墙体和柱子遮挡，地形搭建必须遵守：

- 普通墙不应贴近战斗中心。
- 关键战斗场地周围 5m 内不要放高于 5m 的实墙。
- 地牢墙体进入相机视线时可以半透明。
- Boss 房中心到墙体距离至少 30m。
- 柱子可用于遮挡远程技能，但数量不要超过 4 到 6 根。
- 大型 Boss 不要放在低顶棚地牢中。

## 5. 碰撞层规范

### 5.1 Layer 规划

| Layer | 用途 |
|---|---|
| Default | 默认物体 |
| Player | 玩家 |
| Enemy | 敌人 |
| PlayerSkill | 玩家技能判定 |
| EnemySkill | 敌人技能判定 |
| Ground | 可行走地面 |
| Wall | 墙体/障碍 |
| Interactable | 可交互物 |
| Loot | 掉落物 |
| Breakable | 可破坏物 |
| Trigger | 触发器 |
| CameraBlocker | 相机阻挡 |
| CameraTransparent | 可透明遮挡 |
| NavObstacle | 动态寻路阻挡 |

### 5.2 地形碰撞规则

| 对象 | Collider | Rigidbody | 说明 |
|---|---|---|---|
| 地面 | MeshCollider/BoxCollider | 无 | 静态 |
| 墙体 | BoxCollider | 无 | 静态 |
| 隐形墙 | BoxCollider | 无 | 阻挡玩家和怪物 |
| 可破坏物 | Box/Sphere/Capsule | 可选 Kinematic | 被攻击后破坏 |
| 宝箱 | BoxCollider | 无 | 可交互 |
| NPC | CapsuleCollider | 无 | 可交互，不挡主路 |
| 机关区域 | BoxCollider Trigger | 无 | 进入触发 |
| 传送点 | SphereCollider Trigger | 无 | 交互或自动触发 |

## 6. NavMesh 规则

### 6.1 Agent 类型

| Agent | 半径 | 高度 | 用途 |
|---|---:|---:|---|
| PlayerAgent | 0.4 | 2.0 | 玩家移动检测 |
| SmallEnemy | 0.35 | 1.5 | 小怪 |
| MediumEnemy | 0.55 | 2.2 | 普通怪/精英 |
| LargeEnemy | 1.2 | 4.0 | 大型怪 |
| BossAgent | 2.0 | 8.0 | 可移动 Boss |

### 6.2 NavMesh 区域

| Area | Cost | 用途 |
|---|---:|---|
| Walkable | 1 | 正常地面 |
| Mud | 1.5 | 泥地，减速 |
| Poison | 2.5 | 毒池，AI 尽量避免 |
| Fire | 3.0 | 火焰区域 |
| JumpLink | 1 | 跳跃/跨越点 |
| Blocked | 不可走 | 阻挡 |

### 6.3 地牢 NavMesh 注意事项

- 门打开前 NavMesh 使用 `NavMeshObstacle` 阻挡。
- 机关桥放下后重新启用可行走区域。
- 可破坏路障破坏后需要更新局部 NavMesh。
- 小怪可以穿过窄道，大型怪不能进入窄道。
- Boss 房不要做过多 NavMesh 断裂，否则冲锋技能会不稳定。

## 7. 地图灰盒搭建流程

### 第 1 步：创建 Scene

```text
新建 Scene
设置 LightingProfile
创建 MapRoot
添加 SceneInfo
设置地图边界
```

### 第 2 步：铺主路线

使用 `WB_Floor_20x20` 搭出主路径，保证玩家可以从入口走到出口。

### 第 3 步：添加战斗区域

每个战斗区用不同颜色标记：

| 颜色 | 含义 |
|---|---|
| 绿色 | 安全区 |
| 黄色 | 普通战斗区 |
| 橙色 | 精英战斗区 |
| 红色 | Boss 区 |
| 蓝色 | NPC/交互区 |
| 紫色 | 事件区 |

### 第 4 步：添加阻挡和遮挡

- 用墙体明确地图边界。
- 用石头/柱子做战斗遮挡。
- 用隐形墙阻止玩家越界。
- 用相机透明墙测试镜头遮挡。

### 第 5 步：放置交互物

- 宝箱点。
- 可破坏物点。
- 传送点。
- 出口门。
- 任务物件。
- NPC。

### 第 6 步：放置刷怪点

- 普通怪群。
- 远程怪位置。
- 精英怪位置。
- 伏击点。
- Boss 点。

### 第 7 步：烘焙 NavMesh

- 检查所有主路线是否可走。
- 检查怪物能否追到玩家。
- 检查大型怪不会刷在窄路。
- 检查 Boss 不会卡在场景边缘。

### 第 8 步：跑完整流程

必须测试：

```text
进入地图 -> 杀怪 -> 拾取 -> 开箱 -> 破坏物体 -> 触发事件 -> 进入 Boss -> 击杀 Boss -> 拿奖励 -> 传送回城
```

## 8. 白盒到正式地形替换规则

灰盒通过后，再进行美术替换。

替换规则：

- 不改变主路宽度。
- 不改变 Boss 房尺寸。
- 不随意添加会挡镜头的高墙。
- 不删除调试标记，只隐藏到 Debug 层级。
- 不直接删除碰撞体，而是替换为正式碰撞体。
- 美术地形和逻辑碰撞分离。

推荐结构：

```text
Terrain
├── Whitebox_Hidden
├── Art_Ground
├── Art_Walls
├── Art_Props
├── Colliders
└── NavMeshSurface
```

## 9. 地形验收清单

每张地图完成时检查：

- [ ] 玩家不会卡在角落。
- [ ] 怪物可以正常寻路。
- [ ] Boss 技能不会被地形异常打断。
- [ ] 相机不会被墙完全挡住。
- [ ] 所有交互物有可达路径。
- [ ] 所有宝箱点不会刷到墙里。
- [ ] 所有怪物点不会刷到不可走区域。
- [ ] 出口门和传送点可正常使用。
- [ ] 地图边界完整，没有漏出世界外。
- [ ] 小地图边界与真实地图一致。
