# 255 符石合成配方与升阶系统：定向合成、失败与保底

## 1. 系统目标

符石合成用于处理重复符石，并给玩家稳定追求高品质符石的路线。

合成不能完全取代掉落：

```text
掉落负责惊喜和高 Roll
合成负责回收和稳定进度
Boss 配方负责终局目标
```

---

## 2. 合成类型

```text
同名升阶
同系随机升阶
定向升阶
跨系融合
传奇碎片合成
神器配方
数值重铸
机制升华
```

---

## 3. 同名升阶

基础配方：

```text
3 枚同名、同品质、未镶嵌符石
→ 1 枚高一品质同系列符石
```

结果规则：

```text
普通 → 精良：100% 成功
精良 → 稀有：100% 成功
稀有 → 史诗：基础 80%
史诗 → 传奇：基础 45%
传奇 → 神器：不能使用普通同名配方
```

失败时不建议直接全部摧毁。

推荐损失：

```text
稀有升史诗失败：保留主符石，材料符石消耗
史诗升传奇失败：保留主符石，获得失败精华和保底进度
```

---

## 4. 同系随机升阶

```text
3 枚同品质、同标签系列符石
→ 随机 1 枚高一品质同系列符石
```

示例：

```text
火焰伤害 + 燃烧 + 火焰抗性
→ 随机稀有火焰符石
```

随机池权重：

```text
普通数值符石：高权重
触发符石：中权重
数量符石：低权重
传奇候选：极低权重
```

---

## 5. 定向合成

配方：

```text
主符石
+ 两枚指定标签材料
+ 定向核心
+ 金币
→ 指定子系列结果
```

例：

```text
主符石：鎏金多矢符石
材料：投射物速度符石、分裂符石
核心：裂空核心
→ 紫曜裂空符石
```

定向合成只固定“系列”，不一定固定具体数值 Roll。

---

## 6. 词条继承

高阶合成可选择一项继承：

```text
保留主标签
保留孔型
保留适用部位
保留当前数值倾向
保留强化等级的一部分
```

继承概率：

```text
基础 50%
使用继承印记后 80%
符石匠最高声望 90%
```

不能 100% 保证所有内容，避免无限复制极品。

---

## 7. 跨系融合

用于生成复合符石。

示例：

```text
生命 + 护盾 → 丰生符石
火焰 + 击杀 → 焚爆符石
闪电 + 暴击 → 雷链符石
召唤 + 爆炸 → 殉爆符石
掉落球 + AOE → 血潮符石
环绕法球 + 元素 → 万象轮候选
御剑 + 临时召唤 → 剑生符石
```

跨系配方必须通过任务、Boss 或图鉴解锁，不能一开始全部公开。

---

## 8. 传奇碎片合成

传奇符石分解获得对应系列碎片。

```text
10 枚传奇通用碎片
+ 3 枚系列碎片
+ 1 枚传奇符石胚胎
→ 随机传奇符石
```

定向传奇：

```text
15 枚通用碎片
+ 8 枚指定系列碎片
+ 指定配方卷轴
→ 指定传奇系列随机一枚
```

---

## 9. 神器配方

神器不能通过普通概率随机升阶。

需要：

```text
指定传奇符石
指定 Boss 核心
神器余烬
终局货币
完整配方
```

示例：

```text
橙曜星轨核心符石
+ 天轮核心
+ 神器余烬 ×20
+ 星界锻印
→ 神铸·天轮符石
```

神器合成默认 100% 成功，但材料极其稀有，避免“高材料 + 失败全没”的双重挫败。

---

## 10. 数值重铸

不改变符石名称和机制，只重新 Roll 数值。

```text
低品质：消耗粉尘
高品质：粉尘 + 品质核心
传奇/神器：专属重铸材料
```

支持：

```text
完全重 Roll
只提高最低 Roll
锁定一项数值
```

---

## 11. 符石升华

史诗或传奇符石可升华一次，获得小型附加效果。

示例：

```text
鎏金雷链符石
→ 升华后：电弧搜索半径 +10%

紫曜剑生符石
→ 升华后：临时剑持续时间 +1 秒
```

升华效果不得改变核心机制，避免一枚符石过度复杂。

---

## 12. 失败与保底

### 保底进度

史诗升传奇失败时获得：

```text
10~20 点传奇保底进度
```

达到 100 点时：

```text
下一次同系列合成必定成功
```

### 保护材料

```text
护符粉：失败保留一枚材料
定魂印：失败保留主符石强化等级
无损刻刀：失败不产生裂纹
```

## 15. 验收标准

```text
重复符石有明确回收价值。
普通与精良合成不会失败。
高阶失败不会把全部核心材料清空。
史诗升传奇有保底进度。
神器采用配方制而不是纯随机。
合成前能看到所有风险和可能结果。
```
