# 280 地面普攻连段系统：段数、连接窗口、派生与重置

## 1. 连段结构

```text
GroundBasicAttackDefinition
├── ComboStep_01
├── ComboStep_02
├── ComboStep_03
└── ComboStep_04
```

每段包含：

```text
动画
伤害倍率
攻击范围
根运动位移
命中停顿
破韧
资源恢复
连接窗口
取消窗口
上跃派生窗口
```

## 2. 段数建议

```text
匕首/拳套：4-6 段
单手剑：4 段
单手斧/锤：3-4 段
双手武器：3 段
弓：3-4 段
弩：3 段
法杖/权杖：3 段
```

## 3. 四段伤害示例

```text
第一段：70%
第二段：80%
第三段：95%
第四段：145%
```

最后段主要承担高破韧、击退和构筑触发。

## 4. 命中形态

```text
单次斩击
多段连击
扇形扫击
直线突刺
范围震荡
投射物射击
```

多次命中必须配置同段同目标命中上限。

## 5. 上跃派生

每段配置：

```text
CanBranchToRising
RisingWindowStart
RisingWindowEnd
```

推荐普通四段连击第 1-3 段支持上跃，终结段视武器而定。

## 6. 根运动和磁吸

```text
RootMotionMode
ForwardDistance
TargetAssistDistance
TargetAssistAngle
```

磁吸不能穿墙、不能吸到身后目标、不能跨越不可行走区域。

## 7. 连段重置条件

```text
超时
离地
被击倒
切换武器
进入交互
死亡
攀爬/翻越
过场
```

## 8. 资源与词条

地面普攻可以：

```text
恢复法力或怒气
增加连击层
触发击中词条
触发暴击、吸血、异常
生成掉落球或临时飞剑
```

## 9. 最后一段模式

```text
LoopToFirst
EndAndReset
HoldFinalPose
BranchToSpecial
```

第一版默认 `LoopToFirst`。
