# 178 技能系统词条接入规则：技能标签、辅助模块、技能成长

## 1. 技能标签

每个技能必须配置标签：

```text
Melee
Projectile
AOE
Spell
Attack
Minion
Fire
Cold
Lightning
Poison
Shadow
Holy
DOT
Hit
Channel
Charge
Control
Shield
Movement
```

## 2. 技能标签示例

```json
{
  "skillId": "SK_Ranger_SplitArrow",
  "tags": ["Attack", "Projectile", "Physical", "Hit"],
  "canCrit": true,
  "canTriggerOnHit": true,
  "canTriggerOnKill": true,
  "projectileConfig": {
    "baseProjectileCount": 3,
    "canSplit": true,
    "canChain": true,
    "canPierce": true
  }
}
```

## 3. 词条匹配规则

投射物词条只影响 Projectile：

```text
投射物数量 +1
投射物分裂
投射物穿透
投射物连锁
```

AOE 词条只影响 AOE：

```text
范围扩大
范围伤害
持续区域时间
范围重叠
```

召唤词条只影响 Minion/Summon：

```text
召唤物数量
召唤物伤害
召唤物击杀触发
召唤物死亡爆炸
```

控制词条要求技能能施加控制：

```text
冻结持续时间
束缚增强
眩晕时增伤
控制结束爆炸
```

## 4. 辅助模块

```text
分裂辅助：给投射物技能增加 Split 标签
连锁辅助：给投射物技能增加 Chain 行为
燃烧辅助：让火焰命中可点燃
召唤增强辅助：召唤物伤害提高，但数量减少
范围扩大辅助：AOE 半径提高，但伤害降低
```

配置：

```json
{
  "supportId": "SUP_Projectile_Split",
  "requiredTags": ["Projectile"],
  "addTags": ["Split"],
  "modifiers": [
    {"stat": "ProjectileSplitCount", "op": "Add", "value": 2},
    {"stat": "Damage", "op": "Less", "value": 0.15}
  ]
}
```

## 5. 技能成长

技能升级可以成长：

```text
基础伤害
伤害效率
异常几率
投射物数量
AOE 范围
召唤物生命
召唤物伤害
控制时间
冷却
消耗
```

## 6. 技能详情 UI

技能详情需要显示：
- 标签
- 可被哪些词条影响
- 当前来自装备/天赋/辅助模块的改变
- 投射物数量变化
- AOE 范围变化
- 召唤物数量变化
- 控制时间变化
