# 297 战斗打击感测试场景、调参流程、性能与验收标准

## 1. 测试场景

建立：

```text
Scene_CombatImpact_Test
```

区域：

```text
普通人形木桩
可移动普通敌人
高韧性精英
Boss 木桩
空中浮空测试
击退墙面测试
倒地测试
不同材质目标
大量敌人性能区
不同武器架
```

---

## 2. 测试单位

### 普通木桩

```text
受击动画开启
不攻击
自动回血
可浮空
可击倒
```

### 超级护甲木桩

```text
不播放完整硬直
只测试闪白、特效和韧性
```

### Boss 木桩

```text
普通攻击不硬直
韧性归零后破韧
```

## 4. 调参顺序

```text
先调整攻击动画节奏
→ 再调整伤害生效帧
→ 调整受击动画
→ 调整命中停顿
→ 调整击退
→ 调整特效
→ 调整音效
→ 最后调整镜头震动
```

不要先用超强震屏掩盖动画和判定问题。

## 7. 连续攻击测试

测试：

```text
每秒 2 次
每秒 5 次
每秒 10 次
每秒 30 次多段伤害
```

检查：

```text

顿帧是否叠加过度
```

## 9. 性能预算

同屏 20 个敌人持续受击时：

```text
命中特效使用对象池
闪白不实例化材质
伤害跳字不产生 GC
镜头震动由统一系统合并
音效并发受限
```

## 11. 第一版实现顺序

```text
HitRequest 与统一管线
→ 轻/中/重受击
→ 移动中断
→ 四方向受击动画
→ 闪白
→ 命中停顿
→ 击退
→ 韧性与破韧
→ 空中浮空
→ 击倒与起身
→ Boss 霸体和破韧
→ 武器/元素反馈矩阵
→ 调试场景
```

---

## 12. 核心验收标准

```text
敌人在正常移动中受到有效硬直攻击时停止移动。
敌人根据命中方向播放对应受击动画。
轻攻击不会无限硬直精英和 Boss。
单位受击时有短促闪白。
重击比轻击有更明显顿帧、音效和镜头反馈。
击退不会穿墙或掉入非法位置。
浮空敌人可以被空中普攻追击。
落地后正确进入倒地或恢复状态。
Boss 普通受击不频繁中断技能。
Boss 韧性归零后进入完整破韧状态。
多段伤害不会让闪白常亮或无限叠加顿帧。
受击结束后 AI 能重新追击目标。
死亡能够覆盖所有受击状态。
```

---

## 13. 体验验收标准

玩家应能仅凭画面和声音分辨：

```text
有没有命中
是不是暴击
攻击轻还是重
目标是否被破盾
目标是否被破韧
攻击是否造成击退
目标是否可以继续空中追击
Boss 当前是否处于可爆发窗口
```
