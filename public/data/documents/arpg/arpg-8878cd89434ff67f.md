# 152 状态动画配置：束缚、冰冻、眩晕、持续控制、覆盖规则

## 1. 状态动画范围

包括：
- Bound 束缚
- Frozen 冰冻
- Stunned 眩晕
- Petrified 石化
- Sleep 睡眠
- Fear 恐惧
- PoisonWeak 中毒虚弱
- BurningStruggle 燃烧挣扎
- Guarding 防御姿态
- Channeling 引导姿态
- Transformed 变形态

## 2. StatusAnimationConfig

```json
{
  "statusId": "Bound",
  "animationConfig": {
    "enterClip": "ANI_Bound_Enter",
    "loopClip": "ANI_Bound_Loop",
    "exitClip": "ANI_Bound_Exit",
    "loop": true,
    "fadeIn": 0.10,
    "fadeOut": 0.12,
    "layer": "FullBody",
    "priority": 80,
    "canBeInterruptedByHit": true,
    "canBeInterruptedByDeath": true
  }
}
```

## 3. 束缚动画 Bound

播放流程：

```text
Bound_Enter → Bound_Loop → Bound_Exit
```

规则：
- 禁止移动
- 禁止跳跃
- 禁止闪避
- 可允许部分技能
- 可被受击动作短暂覆盖，也可保持束缚姿态

```json
{
  "statusId": "Bound",
  "lockMovement": true,
  "lockDodge": true,
  "lockJump": true,
  "allowCastSkills": ["BreakFree", "SelfCleanse"],
  "hitReactionMode": "OverlaySmallHit"
}
```

## 4. 冰冻动画 Frozen

```json
{
  "statusId": "Frozen",
  "enterClip": "ANI_Frozen_Enter",
  "loopClip": "ANI_Frozen_Loop",
  "freezeAnimatorSpeed": 0.0,
  "useCurrentPoseFreeze": true,
  "exitClip": "ANI_Frozen_Exit"
}
```

## 5. 状态覆盖优先级

```text
死亡 > 击飞/击倒 > 冰冻/石化 > 束缚 > 眩晕 > 恐惧 > 燃烧/中毒 > 普通移动
```

## 6. Layer 建议

| 状态 | Layer |
|---|---|
| 束缚 | FullBody |
| 冰冻 | FullBody / FreezePose |
| 眩晕 | FullBody |
| 中毒虚弱 | UpperBody Overlay |
| 燃烧 | UpperBody Overlay |
| 防御姿态 | UpperBody 或 FullBody |
| 引导施法 | UpperBody / FullBody |

## 7. 验收标准

- 束缚有进入、循环、结束动画。
- 下落/击飞能覆盖束缚。
- 冰冻能定格或播冻结循环。
- 眩晕能循环且可恢复。
- 状态动画不会和基础移动互相抢状态。
