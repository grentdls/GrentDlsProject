# 279 基础攻击输入与状态切换规则：同键切换、缓存与取消

## 1. 输入路由

```text
BasicAttack = Mouse Left
Jump = Space
```

```text
收到 BasicAttack
→ 检查角色是否可操作
→ 判断地面状态
→ 读取对应基础攻击槽
→ 检查武器兼容
→ 立即释放或写入输入缓存
```

## 2. 输入缓存

推荐：

```text
InputBufferDuration = 0.20-0.35 秒
最多缓存一次下一段输入
```

不缓存多段，避免玩家连点后无法改变决策。

## 3. 连接窗口

每段配置：

```text
InputAcceptStart
InputAcceptEnd
TransitionStart
TransitionEnd
```

输入在接受窗口内时排队，进入转换窗口后切换下一段。

## 4. 超时重置

```text
ComboResetDelay = 0.6-1.0 秒
```

超过时间未继续：

```text
ComboIndex = 0
```

下一次从第一段开始。

## 5. 最后一段循环

```text
LoopAfterLast = true
```

四段连击：

```text
1 → 2 → 3 → 4 → 1
```

也可对重武器设置 `EndAndReset`，使最后段后强制停顿。

## 6. 地面/空中切换

```text
离地：清空地面缓存，激活空中槽
落地：清空空中缓存和 AirComboIndex，激活地面槽
```

建议加入 `LandingGraceTime = 0.05-0.10 秒`，避免落地瞬间吞掉输入。

## 7. 上跃输入优先级

地面普攻中按跳跃：

```text
如果当前段处于 RisingBranchWindow
→ 释放上跃技能
否则
→ 缓存普通跳跃或在动作结束后跳跃
```

默认：

```text
RisingAttack > NormalJump
```

## 8. 动作取消

每段独立配置：

```text
DodgeCancelWindow
BlockCancelWindow
RisingCancelWindow
SkillCancelWindow
JumpCancelWindow
```

轻武器取消更早，重武器取消更晚。

## 9. 按住与连点

支持：

```text
TapOnly
HoldRepeat
HoldToCharge
```

建议：

```text
剑/拳套/弓：允许按住连续普攻
重锤/巨斧：默认要求逐次输入，或只在设置中开启按住连段
```

## 10. 锁定与朝向

```text
有锁定目标：面向锁定目标
无锁定目标：面向移动输入或镜头方向
```

每段可配置最大转向角和转向窗口。
