# 234 掉落球系统完整逻辑：生命球、法力球、吸附与拾取触发

## 1. 核心定义

掉落球是由击杀、破盾、破韧、暴击、技能或装备触发后生成的场景拾取实体。

基础类型：

```text
生命球 HealthOrb
法力球 ManaOrb
护盾球 ShieldOrb
怒气球 RageOrb
能量球 EnergyOrb
剑意球 SwordIntentOrb
元素球 ElementOrb
```

基础用途：

```text
恢复资源
提供临时 Buff
生成伤害
生成法球/飞剑
刷新技能
叠加构筑层数
```

---

## 2. 掉落流程

```text
触发事件
→ 计算是否掉落
→ 选择球类型
→ 确定数量与价值
→ 生成抛出轨迹
→ 落地
→ 等待吸附/拾取
→ 触发恢复与附加效果
→ 销毁或转化
```

---

## 3. 掉落来源

```text
OnKill
OnEliteKill
OnBossPhaseBreak
OnShieldBreak
OnPoiseBreak
OnCritKill
OnMinionKill
OnOrbitOrbKill
OnSwordKill
OnPotionUse
OnSkillCast
```

默认规则：

```text
普通怪低概率
精英怪高概率或必掉
Boss 阶段固定掉落
由掉落球造成的击杀默认不再掉同类球
```

---

## 4. 掉落概率与保底

简单概率：

```text
dropChance = baseChance × sourceMultiplier × buildMultiplier
```

推荐增加“掉落进度”避免脸黑：

```text
每次符合条件但未掉落，累积 DropMeter
DropMeter 达到 1 时必定掉落，并扣除 1
```

示例：

```text
普通怪每次增加 0.12 生命球进度
理论平均约 8~9 个怪掉 1 个
```

这比纯 12% 随机更稳定。

---

## 5. 球体价值

每个掉落球携带 Value：

```text
FlatValue
PercentMaxValue
SourceScaledValue
Tier
Quality
```

生命球恢复：

```text
heal = flatHeal + maxLife × percentHeal
```

可配置恢复上限和不同难度衰减。

---

## 6. 掉落抛出表现

生成时不要原地出现，推荐：

```text
从敌人身体中心向上弹出
使用短抛物线
落点在敌人附近 0.5~1.5 米
不同球体相互分散
落地时轻微弹跳
```

抛出参数：

```text
launchHeight
scatterRadius
flightTime
bounceCount
```

---

## 7. 拾取归属

单机项目也应保留归属字段，方便召唤物和未来扩展：

```text
OwnerOnly
PartyShared
Public
SummonerOnly
KillerOnly
```

玩家召唤物击杀：

```text
默认归属于召唤者
```

---

## 8. 吸附 Vacuum

球体进入吸附范围后飞向玩家。

核心参数：

```text
pickupRadius
vacuumRadius
vacuumDelay
vacuumSpeed
vacuumAcceleration
lineOfSightCheck
```

状态：

```text
IdleOnGround
→ VacuumPending
→ VacuumFlying
→ Picked
```

吸附轨迹：

```text
平滑贝塞尔
速度逐渐增加
接近玩家时缩小
```

推荐：

```text
普通吸附范围：2.5 米
构筑强化：最高 8~12 米
全屏吸附只给特殊技能或传奇效果
```

---

## 9. 合并与同屏上限

大量小球会污染画面和性能。

合并规则：

```text
同类型
同归属
距离小于 MergeRadius
生成时间接近
```

合并后：

```text
Value 相加
模型尺寸小幅增加
显示数字层数
最多合并到一个上限
```

示例：

```text
5 个小生命球合并为 1 个大生命球
恢复总值不丢失
```

同屏建议：

```text
每类型 12~20 个
全部球体 40~60 个
超限时优先合并最旧、最近球体
```

## 10. 生命周期

```text
默认存在 12~20 秒
到期前 3 秒闪烁
到期后消失或触发到期效果
```

到期模式：

```text
Despawn
AutoPickup
ExpireExplosion
ConvertToDamageOrb
ReturnToSource
```

## 11. 生命球玩法

基础：

```text
拾取恢复生命
```

扩展：

```text
恢复量提高
过量治疗转护盾
拾取后获得吸血
拾取后生成血色环绕法球
拾取时对周围敌人造成血爆
生命全满时改为伤害球
```

---

## 12. 法力球玩法

基础：

```text
拾取恢复法力
```

扩展：

```text
恢复量提高
拾取后技能冷却恢复
拾取后法球转速提高
拾取后立即刷新一把飞剑
法力全满时转为护盾或元素伤害
```

---

## 13. 护盾球玩法

```text
恢复护盾
护盾满时增加临时最大护盾
拾取后获得一次投射物格挡
拾取时对附近敌人施加破盾标记
```

---

## 14. 剑意球玩法

御剑专属掉落：

```text
拾取后生成 1 把临时飞剑
或恢复一把正在冷却/被破坏的飞剑
或使下一次齐射数量 +1
```

必须配置临时上限。

---

## 15. 拾取产生伤害

### 15.1 拾取爆炸

```text
拾取生命球时，对周围敌人造成物理或血伤害。
```

### 15.2 球体冲击

吸附飞向玩家过程中，穿过敌人可造成一次伤害。

### 15.3 拾取发射

```text
拾取法力球时，向最近敌人发射一枚法力飞弹。
```

### 15.4 过量恢复爆炸

```text
超过当前缺失量的恢复值转化为伤害。
```

限制：

```text
拾取造成的伤害默认不能掉落同类球。
每次拾取触发伤害有全局冷却或同帧合并。
```

---

## 16. 球体磁化路线玩法

可做一类“收集路线”构筑：

```text
球体不会立即吸附
玩家移动路径经过球体才拾取
连续拾取不同球体形成连锁奖励
```

示例：

```text
3 秒内连续拾取 5 个球，获得“收集狂热”
生命球 → 法力球 → 护盾球按顺序拾取，触发三色爆炸
```
