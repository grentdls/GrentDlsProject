# 95. 战斗 3C 联动：攻击朝向、根运动、硬直、取消窗口


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 目标

本项目的技能系统已经有大量主动技能、辅助模块和怪物技能。3C 层必须定义“玩家按技能后角色怎么动、镜头怎么跟、判定怎么出、能否取消、被打断如何处理”。否则技能表再多也会变成按钮特效，而不是动作游戏。

## 2. 动作执行阶段

每个攻击/技能动作拆为：

```text
InputBuffer
→ PreCast 前摇
→ Active 生效判定
→ Recovery 后摇
→ CancelWindow 取消窗口
→ ReturnToMove 回到移动
```

| 阶段 | 控制权 |
|---|---|
| InputBuffer | 玩家输入记录 |
| PreCast | 可少量转向/蓄力/瞄准 |
| Active | 判定锁定，通常不可大幅转向 |
| Recovery | 恢复动作，可在窗口内取消 |
| CancelWindow | 可接移动/闪避/下一段攻击 |
| ReturnToMove | 归还 CharacterMotor 控制 |

## 3. 攻击朝向规则

### 3.1 非锁定状态

攻击方向来源优先级：

```text
鼠标准星/屏幕中心目标 > 当前移动方向 > 角色当前朝向
```

近战普通攻击：

- 若移动输入存在，朝移动方向。
- 若屏幕中心近处有敌人，朝敌人微修正。
- 若无输入无目标，朝角色当前前方。

### 3.2 锁定状态

攻击方向优先朝锁定目标，但保留技能配置：

| 技能 | 规则 |
|---|---|
| 近战单体 | 朝锁定目标 |
| 扇形攻击 | 朝锁定目标方向或输入方向，取决于技能 |
| 冲锋 | 朝锁定目标路径点 |
| 地面范围 | 目标脚下或玩家指定点 |
| 蓄力攻击 | 按住期间可慢速修正方向 |

## 4. 攻击转向窗口

| 动作类型 | 前摇可转角 | 生效帧可转角 | 后摇可转角 |
|---|---:|---:|---:|
| 轻攻击 | 60° | 15° | 90° |
| 重攻击 | 35° | 5° | 45° |
| 突进攻击 | 20° | 0° | 30° |
| 法术 | 45° | 10° | 60° |
| 弓弩射击 | 75° | 25° | 90° |
| Boss 大招 | 按技能配置 | 通常锁定 | 通常不可转 |

## 5. 根运动规则

### 5.1 Root Motion 分类

| 类型 | 描述 |
|---|---|
| None | 完全代码控制位移 |
| Additive | 动画提供小位移，代码可修正 |
| Dominant | 动画主导位移，代码仅防穿墙 |
| FullRoot | 处决/抓取/特殊演出完全动画驱动 |

### 5.2 攻击前踏

近战攻击需要轻微前踏，增强命中稳定：

- 轻攻击前踏：0.25m - 0.6m。
- 重攻击前踏：0.4m - 1.2m。
- 冲锋技能：由技能移动模块控制，不算普通前踏。
- 前方有墙/悬崖时自动截断。

## 6. 命中吸附与攻击辅助

为了避免 3D 近战总是空刀，可配置轻微命中辅助。

| 辅助 | 说明 |
|---|---|
| FacingAssist | 出手前朝目标修正 |
| StepAssist | 出手时向目标小步靠近 |
| HitboxInflate | 锁定时判定体略加宽 |
| TargetMagnet | 极短距离内贴近目标，但不能穿越 |

限制：

- 辅助不能超过玩家可感知的合理范围。
- PvE 可强一些，PVP/竞技可关闭。
- Boss 大体型目标不需要太强吸附。

## 7. 硬直规则

### 7.1 玩家硬直

| 状态 | 能否移动 | 能否闪避 | 能否攻击 |
|---|---|---|---|
| 轻受击 | 否，短时 | 否 | 否 |
| 重受击 | 否 | 否 | 否 |
| 击退 | 否 | 否 | 否 |
| 倒地 | 否 | 可受身，按配置 | 否 |
| 霸体受击 | 可减速移动 | 可选 | 可继续攻击 |

### 7.2 怪物硬直

| 怪物类型 | 硬直规则 |
|---|---|
| 普通怪 | 频繁受击可硬直 |
| 精英怪 | 有硬直抗性条 |
| 稀有怪 | 需要破韧后硬直 |
| Boss | 大多数攻击不硬直，仅破阶段/破韧触发 |

## 8. 取消窗口

取消窗口是动作手感核心。每个技能都要配置：

```text
CancelWindow
├── MoveCancelStart
├── DodgeCancelStart
├── AttackComboCancelStart
├── SkillCancelStart
├── PotionCancelAllowed
└── LockRotateAllowed
```

示例：

| 动作 | 移动取消 | 闪避取消 | 连段取消 |
|---|---:|---:|---:|
| 轻攻击 1 | 0.32s | 0.28s | 0.22s |
| 轻攻击 2 | 0.36s | 0.30s | 0.25s |
| 重攻击 | 0.80s | 0.65s | 不可 |
| 法术小火球 | 0.45s | 0.40s | 可接技能 |
| 喝药 | 不可 | 不可 | 不可 |

## 9. HitStop 与反馈

命中反馈不能影响操作太久。

| 命中 | HitStop |
|---|---:|
| 普通命中 | 0.03s - 0.05s |
| 暴击 | 0.06s - 0.08s |
| 重击命中 | 0.08s - 0.12s |
| Boss 破韧 | 0.12s - 0.18s |
| 小怪群体 AoE | 不对每个小怪单独 HitStop，避免卡顿 |

## 10. 技能与移动权限

| 技能类型 | 释放时移动 |
|---|---|
| 瞬发增益 | 可移动 |
| 小法术 | 减速移动 |
| 大法术 | 原地施法 |
| 弓弩射击 | 可慢移 |
| 近战连段 | 动画前踏 |
| 位移技能 | 技能控制移动 |
| 召唤技能 | 原地或慢移，按技能配置 |

## 12. 验收标准

- 近战攻击不需要完全贴脸也能合理命中。
- 重攻击有重量感，不能随便 180° 转向。
- 闪避取消窗口稳定，玩家能练习掌握。
- Boss 被击中不会频繁抽搐硬直。
- 技能位移不会穿墙、不会卡入 Boss 身体。
- 非锁定状态攻击方向和镜头/输入一致。

## 13. 当前 Unity 实现映射

本节对应当前工程运行时代码，目标是让策划文档中的攻击朝向、根运动、硬直与取消窗口不只停留在规则描述，而是可以在 Unity 中直接验证。

### 13.1 技能执行阶段

- `PlayerSkillController.CastRoutine` 已按 `CheckCondition -> PayCost -> PreCast -> CastFrame -> Recovery -> Cooldown` 执行。
- `PreCast` 开始时调用 `PlayerMovementController.BeginCombatAction`，进入 `AttackRootMotion` 战斗动作态。
- `CastFrame / Active` 开始时调用 `SetCombatActionPhase`，切换主动帧移动与转向权限。
- `Recovery` 开始时再次切换阶段，并由恢复段循环打开移动、闪避、技能取消窗口。

### 13.2 攻击朝向

当前攻击方向优先级：

```text
锁定目标 > 瞄准点/鼠标点 > 最近移动方向 > 角色当前前方
```

实现位置：

- `PlayerSkillController.ResolveAttackDirection`
- `PlayerSkillController.FaceAttackDirection`
- `PlayerMovementController.FaceCombatDirection`

技能阶段会读取 `SkillRuntimeStats.CastRotationControl / ActiveRotationControl / RecoveryRotationControl`。支持值包括：

- `Free`
- `FaceAimAtStart`
- `FaceAimDuringCast`
- `LockStartRotation`
- `FaceTargetBone`

轻攻击、重攻击、位移、法术、弓弩/投射物使用不同默认转向角度；恢复段允许更大的纠正角度，保证收招后能自然回到移动朝向。

### 13.3 根运动与攻击补步

`SkillRuntimeBuilder` 已从技能表现块读取：

- `use_root_motion`
- `root_motion_scale`

`PlayerSkillController.ApplyRootMotionStep` 会在命中/主动帧前后触发短距离补步：

| 类型 | 默认补步 |
|---|---:|
| 近战轻攻击 | 0.45m |
| 重击 / Slam / Hammer | 0.85m |
| 配置 RootMotion 的技能 | 按 `root_motion_scale` 修正 |

实际位移由 `PlayerMovementController.BeginRootMotionStep` 执行，并经过 `ClipDisplacementForCollision` 防穿墙处理。位移技能、闪现、传送不会再叠加普通攻击补步。

### 13.4 取消窗口

恢复段中当前默认打开规则：

| 窗口 | 打开时间 |
|---|---:|
| 闪避取消 | `min(0.30s, RecoveryTime * 0.35)` |
| 移动取消 | `min(0.36s, RecoveryTime * 0.45)` |
| 技能/连段取消 | `RecoveryTime - CancelWindow` 起，持续 `CancelWindow` |

实现位置：

- `PlayerSkillController.RunRecoveryAndCancelWindows`
- `PlayerSkillController.CanSkillCancelNow`
- `PlayerMovementController.OpenCombatCancelWindow`
- `PlayerMovementController.HandleCombatActionUpdate`

取消窗口打开后：

- 移动输入可以打断后摇并回到移动控制。
- 闪避输入可以打断后摇并走闪避逻辑。
- 技能输入可以在 `CancelWindow` 内取消当前动作并接下一技能。

### 13.5 技能移动权限

技能执行流中的 `movement_control` 已映射到运行时：

| 配置值 | 行为 |
|---|---|
| `None` | 使用技能基础移动权限 |
| `SlowByPercent` | 允许慢速移动，倍率 0.35 |
| `FullLock` | 锁定移动 |
| `RootMotion` | 锁定普通移动，交给根运动/补步 |
| `DashCurve` | 锁定普通移动，交给技能位移 |
| `Teleport` | 锁定普通移动，交给瞬移 |
| `KnockbackSelf` | 锁定普通移动，交给自击退 |

### 13.6 HitStop 命中停顿

`SkillRuntimeBuilder` 已从 `SkillHitReactionBlockData` 读取：

- `hit_stop_duration`
- `hit_stop_scale`
- `knockback_distance`
- `knockback_duration`
- `poise_damage`
- `apply_to_boss`
- `boss_scale`

`PlayerSkillController.ApplySkillHitFeedback` 会在即时命中成功后触发命中反馈：

- 配置了 `hit_stop_duration` 的技能使用配置值。
- 未配置时，暴击约 0.06s，重击约 0.075s，近战普通命中约 0.035s。
- `RuntimeHitStop` 使用 `Time.unscaledTime` 计时，并在命中停顿后恢复原 `timeScale / fixedDeltaTime`。
- 多目标命中有节流，避免 AoE 对每个目标重复 HitStop 导致卡顿。
- 配置了 `knockback_distance` 时，可对带 `PlayerMovementController` 的目标触发击退。

实现位置：

- `SkillRuntimeBuilder.ApplyCorePresentationBlocks`
- `PlayerSkillController.ApplySkillHitFeedback`
- `RuntimeHitStop`

### 13.7 受击硬直

`HealthComponent.ApplyDamage` 结算后会对挂有 `PlayerMovementController` 的目标触发轻量硬直：

- 普通命中：约 0.08s
- 格挡命中：约 0.04s
- 暴击：额外增加约 0.04s
- 破盾：额外增加约 0.04s
- 持续伤害：不触发硬直

实现位置：

- `HealthComponent.ApplyMovementHitReaction`
- `PlayerMovementController.ApplyHitStun`
- `PlayerMovementController.ApplyKnockback`

当前只对玩家移动控制器生效，不直接改怪物 AI 的硬直模型；怪物硬直/韧性仍走后续怪物战斗模块扩展。

### 13.8 验收清单

- 近战攻击按锁定目标或瞄准点决定朝向。
- 重击不会随意大角度甩身，恢复段才允许更大修正。
- 近战命中帧会有短促补步，并受碰撞裁剪。
- 后摇中移动、闪避、下一技能取消均有独立窗口。
- 命中会按技能配置或默认规则触发短 HitStop，多目标不会连续卡顿。
- 玩家受击会短暂停顿，持续伤害不会打断操作。
- `dotnet build RPG.sln --no-restore` 通过，无编译错误。
