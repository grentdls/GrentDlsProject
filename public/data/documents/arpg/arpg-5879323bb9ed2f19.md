## 5. 编辑器工具

```text
Tools / Game / Orbit & Sword & Pickup Editor
```

功能：

```text
实时调整法球数量、半径、转速
预览动态重排
预览多环
预览飞剑群噪声和避让
预览发射/返回/目标分配
模拟锁定目标和随机目标
模拟掉落、弹跳、吸附、合并
模拟满血/满法力转化
验证生成上限和防递归
```

---

## 6. 法球编辑器校验

```text
数量上限必须 > 0
单环数量超过12时提示分环
命中冷却不能为0
高速转速必须使用Sweep检测
重排时间不能为负
碰撞伤害必须有目标重复命中限制
```

---

## 7. 御剑编辑器校验

```text
临时剑必须配置上限或持续时间
生成剑默认禁止触发同源生成
同时飞行数不能超过总剑数
返回轨迹必须存在
无目标时必须有Fallback
护剑数量不能超过总剑数
```

---

## 8. 掉落球编辑器校验

```text
掉落球必须有生命周期
必须有同屏上限或合并规则
吸附速度不能为0
拾取伤害必须有触发频率限制
过量转化必须有上限
掉落球伤害默认不能触发同类掉落
```

## 9. 性能预算

### 环绕法球

```text
实体数量：常规12，极限16
超过8个可共享碰撞调度器
远距离角色可合并视觉
VFX使用对象池
```

### 御剑

```text
常规20，极限30
只有飞行中的剑启用完整Sweep碰撞
Idle剑关闭伤害碰撞
剑群噪声低频更新，不必每帧重算
```

### 掉落球

```text
同屏全部球体建议不超过50
超限自动合并
远处球体降低粒子和更新频率
吸附中的多个球可批量更新
```

## 10. 开发阶段

### 阶段 A：环绕法球闭环

```text
水平环绕
等角度排布
动态增减与平滑重排
碰撞伤害
每目标命中冷却
数量/转速词条
```

### 阶段 B：御剑闭环

```text
无规则环绕
攻击调度
锁定/随机目标
发射与返回
临时飞剑
防递归
```

### 阶段 C：掉落球闭环

```text
击杀掉落
生命/法力恢复
吸附
合并
生命周期
拾取触发伤害
```

```text
45个技能
15套套装
30件传奇装备
随机词条池

```

## 11. 最终验收标准

```text
法球始终以角色身体中心水平面规则环绕。
法球数量变化时角度自动均分并平滑重排。
法球高速旋转不会漏判，也不会每帧重复伤害。
御剑环绕阶段不造成碰撞伤害。
御剑能按周期发射、命中、返回并重新加入。
无锁定目标时能智能选择附近目标。
发射飞剑生成额外飞剑时不会无限递归。
掉落球能按击杀/破盾等事件生成。
掉落球能弹出、落地、吸附、合并、拾取。
满资源、过量恢复和拾取伤害逻辑可配置。
套装、装备、技能和天赋能完整接入三类玩法。
同屏高数量下性能仍受预算控制。
```
