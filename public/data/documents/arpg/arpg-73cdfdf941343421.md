# 242 关卡交互与可破坏场景系统总览：Prefab 化、配置化、可视化

## 1. 文档目标

本批文档用于规范 Unity 关卡中所有可交互、可传送、可移动、可触发、可破坏对象的制作方式。

目标是做到：

```text
所有关卡玩法对象都做成 Prefab
Prefab 挂统一脚本
策划直接拖入场景
Scene 视图中能看到范围、方向、路径、落点和触发关系
Inspector 中直接配置
运行时自动注册
无需每次单独写逻辑
```

本系统覆盖：

```text
传送门
大门
移动平台
机关开关
地刺陷阱
喷火陷阱
宝箱
增益祭坛
恢复井
祝福柱
传送装置
资源矿
可破坏石墙
可倒塌石柱
爆炸桶
脆弱地板
可破坏桥梁
机关核心
隐藏墙
```

## 3. Prefab 设计原则

每个关卡玩法对象都必须有：

```text
唯一配置 ID
统一根节点
视觉节点
碰撞节点
交互区域
逻辑脚本
特效挂点
音效挂点
调试显示
可选的动画控制器
```

通用结构：

```text
PF_LevelObject_Base
├── Root
│   ├── VisualRoot
│   ├── ColliderRoot
│   ├── InteractionRoot
│   ├── VFXRoot
│   ├── AudioRoot
│   ├── RuntimeRoot
│   └── DebugRoot
```

## 4. 通用交互流程

```text
玩家进入交互区域
→ 检查交互条件
→ 显示交互提示
→ 玩家按下交互键
→ 锁定交互对象
→ 播放交互表现
→ 执行交互动作
→ 更新对象状态
→ 保存状态（如需要）
→ 刷新提示
```

## 6. Scene 视图必须可视化

```text
交互范围

移动路径
传送目标
门的旋转方向
门的移动终点

宝箱掉落点
破坏物倒塌方向
倒塌伤害区域
开关连接对象
```

颜色建议：

```text
绿色：可交互范围
黄色：触发范围
红色：伤害范围
蓝色：移动路径
紫色：传送链接
橙色：掉落范围
白色：物体移动/旋转预览
```

## 7. 关卡玩法对象分类

### 7.1 交互型
```text
大门、宝箱、祭坛、恢复井、传送门、拉杆、按钮、机关终端
```

### 7.2 自动触发型
```text
地刺、喷火、落石、移动平台、自动门、压力板、触发式爆炸物
```

### 7.3 可破坏型
```text
矿石、石墙、木箱、爆炸桶、机关核心、倒塌石柱、脆弱地板、桥梁
```

### 7.4 组合机关型
```text
开关 + 大门
压力板 + 地刺
机关核心 + 喷火陷阱
破坏石柱 + 区域高伤
多个按钮 + 隐藏宝箱
```

## 8. 开发原则

```text
Prefab 中不写死场景名称
Prefab 中不写死目标坐标
Prefab 中不直接查找 GameObject 名称
全部通过 ID、引用或注册表关联
所有交互都要支持禁用
所有机关都要支持 Scene 预览
所有破坏物都要有性能降级方案
```
