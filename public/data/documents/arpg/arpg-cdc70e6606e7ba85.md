# 211 装备物品库总览：数百件装备分类与命名规则

## 1. 本批目标

本批开始正式生成可落地的装备物品库，基于之前的装备规则、词条规则、套装规则和数值玩法，产出一批可直接进入配置表的装备设计。

本批总计设计装备数量：

```text
低阶过渡装备：100 件
近战武器/盾牌：50 件
远程/法术武器：50 件
防具：60 件
戒指/项链/首饰：48 件
套装部件：60 件
传奇/独特装备：60 件

合计：428 件
```

## 2. 稀有度设计原则

```text
普通：主要是基底和低阶过渡，不带复杂玩法
魔法：1-2 个简单随机词条，用于新手期补属性
稀有：3-5 个随机词条，是中后期刷装主体
套装：2-4 个随机词条 + 套装 3/5 件效果
传奇：固定机制 + 少量浮动数值，改变玩法但带限制或代价
```

## 3. 物品命名规则

```text
低阶装备：地区/材料 + 基础物品名
稀有装备：基础物品名 + 阶段后缀
套装装备：套装名 + 部位
传奇装备：独特名称 + 固定机制
```

示例：

```text
灰烬短剑
黑铁巨剑·深炉
亡骨契约·头盔
焚城指环
```
