# 23_UI功能总览：界面清单、层级规范、Prefab 总规则


> 设计边界说明：本项目可以参考《流放之路2》这类暗黑刷宝 ARPG 的信息架构、交互复杂度和系统深度，但不能一比一复制其 UI 视觉、图标、文字、专有数值、专有命名、具体排版截图。本批文档采用“同类结构 + 原创表现”的方式：界面功能、层级、预制体和数据绑定可直接用于 Unity 原型开发。


## 1. UI 总目标

本项目是 3D ACT 版本的暗黑刷宝 ARPG。UI 需要同时满足：

1. 高信息密度：装备、词条、技能、地图、任务、交易都要能在同一套 UI 框架中快速切换。
2. 强刷宝可读性：物品价值、装备部位、稀有度、需求等级、词条强弱、可打造状态必须一眼能看懂。
3. 主机/手柄兼容：鼠标键盘可以拖拽、悬浮、右键；手柄必须支持焦点导航、快捷操作、长按展开详情。
4. 移动端预留：虽然当前是 Unity 3D 桌面/主机原型，但 UI Prefab 必须保留缩放锚点和触控热区。
5. 预制体化：所有界面拆成可复用 Prefab，不允许把逻辑写死在单个 Canvas 内。

## 3. Canvas 总层级

```text
UIRoot
├── Canvas_Background          // 纯界面背景、大型面板遮罩
├── Canvas_HUD                 // 战斗常驻 HUD
├── Canvas_WorldSpace          // 世界空间血条、交互点、掉落名牌
├── Canvas_Window              // 背包、角色、商店、地图、设置
├── Canvas_Popup               // 确认框、错误提示、快捷弹窗
├── Canvas_Tooltip             // 物品详情、比较、节点详情
├── Canvas_DragLayer           // 拖动物品、拖动技能图标
├── Canvas_Loading             // 加载遮罩、场景切换
└── EventSystem
```

## 4. UI Layer 规则

| Sorting Layer | Order | 用途 |
|---|---:|---|
| UI_Background | 0 | 半透明暗底、页面背景 |
| UI_HUD | 100 | 血条、技能栏、小地图 |
| UI_Window | 300 | 整备、商店、传送、仓库 |
| UI_Popup | 500 | 二级确认、数量输入、错误提示 |
| UI_Tooltip | 700 | 物品详情、对比详情 |
| UI_Drag | 900 | 鼠标拖拽物品/技能 |
| UI_Loading | 1000 | 加载界面 |

## 6. 统一窗口打开规则

| 操作 | 结果 |
|---|---|
| `I` | 打开整备界面，默认背包页 |
| `C` | 打开整备界面，默认个人信息页 |
| `K` | 打开整备界面，默认技能页 |
| `P` | 打开天赋树页 |
| `M` | 打开地图册或当前地图 UI |
| `Esc` | 关闭最上层窗口；无窗口时打开暂停菜单 |
| 鼠标悬浮物品 | 打开物品详情 Tooltip |
| Shift + 悬浮装备 | 打开装备比较 Tooltip |
| Ctrl + 点击物品 | 快速移动到相对容器 |
| 右键物品 | 使用/装备/打开快捷菜单 |

## 8. UI 美术占位规范

原型阶段只使用灰盒 UI：

```text
Panel：深色半透明矩形
Header：更亮的深色条
Slot：方形边框 + 稀有度外框
Button：三态按钮
Icon：纯色占位图 + 类型字母
Tooltip：深色背景 + 彩色字段
```

美术正式化时要保持：

1. 稀有度颜色统一。
2. 装备部位图标统一。
3. 正负收益颜色统一。
4. 可交互控件有悬浮、选中、按下、禁用四态。
5. 物品、技能、天赋、地图的详情页共用字段组件。
