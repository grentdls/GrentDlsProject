# 仙侠 UI v2 设计稿与运行界面对照

## 验收口径

- 设计稿用于锁定信息架构、视觉层级、主要操作位置和页面气质。
- 运行界面使用真实配置数据，不要求与设计稿中的演示数值逐字一致。
- 动态列表、装备数量、技能数量和地图数量允许变化，但不得破坏分栏、操作区和详情区。
- 所有玩家可见页面标题、地图类型、状态和操作均使用中文。

## 验证结论

- C# 项目编译通过，0 个错误。
- 三个重点页面已完成两轮 1920x1080 Unity 批处理截图检查。
- UI 预制体未发现 `m_Script: {fileID: 0}` 缺失脚本标记。
- HUD 新增内容均为静态层级，生命、资源、冷却和状态继续沿用事件驱动与 Slider 更新逻辑。
