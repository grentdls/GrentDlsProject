# 244 通用场景交互系统：交互区域、提示、条件、动作、状态机

## 1. 统一交互接口

所有可交互对象实现：

```csharp
IInteractable
```

核心接口：

```text
CanInteract(player)
GetPromptData(player)
BeginInteract(player)
CancelInteract(player)
CompleteInteract(player)
GetInteractionPriority()
```

## 2. InteractableBase 字段

```text
InteractableId

InteractionShape
PromptText
PromptIcon

Cooldown

```

## 3. 交互区域类型

```text
Sphere
Box
Capsule
CustomCollider
ViewCone
DistanceOnly
```

建议：
```text
门：Box
宝箱：Sphere
拉杆：Sphere
大型机关：Box
终端：Capsule
```

## 4. 多对象候选选择

玩家同时靠近多个对象时：

```text
先检查距离
再检查视角
再检查优先级
再检查是否可交互
```

默认只显示评分最高的提示。

## 5. 交互提示

```text
交互键
动作文字
对象名称
条件提示
长按进度
```

示例：

```text
[E] 打开 石门
[E] 关闭 石门
[按住 E] 开启 稀有宝箱
需要：黑炉钥匙 ×1
```

## 12. 状态保存

需要保存：

```text
宝箱是否已开
大门是否开启
机关是否激活
隐藏墙是否破坏
祭坛是否使用
传送门是否解锁
```

状态键：

```text
SceneId + InteractableId
```
