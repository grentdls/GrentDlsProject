# 87 HUD 制作任务清单：第七阶段里程碑

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. 阶段目标

第七阶段目标是完成一套可用于实机战斗的 HUD 原型：

```text
玩家 HUD
+ NPC/交互物头顶提示
+ 敌人名称与血条
+ Boss 大血条
+ 伤害跳字
+ Buff/Debuff 栏
+ 拾取标签
+ 小地图/任务/边缘提示
+ HUD 配置表
+ HUD 压力测试场景
```

## 9. 风险点

| 风险 | 解决方案 |
|---|---|
| 伤害跳字过多 | 合并、对象池、优先级丢弃 |
| 世界 UI 抖动 | 使用屏幕空间投射 + 平滑插值 |
| 名称遮挡战斗 | 距离/数量/优先级控制 |
| Boss 机制被忽略 | Boss 条机制区 + 地面预警双重提示 |
| 手柄交互不稳定 | 统一焦点评分系统 |
| 配置表变复杂 | 提供编辑器预览和校验 |
| 色彩依赖过重 | 颜色 + 图标 + 字形三重区分 |

---

## 10. 最终验收演示流程

```text
进入主城
→ NPC 名称和功能提示显示
→ 与商人交互
→ 进入战斗地图
→ 普通怪受击显示血条和跳字
→ 精英怪出现，显示精英血条和词缀
→ 玩家受到 Debuff，Buff 栏警告
→ 宝箱出现，显示交互提示
→ 掉落装备，拾取标签按稀有度显示
→ 进入 Boss 房
→ Boss 大血条出现
→ Boss 转阶段，血条锁定并提示
→ Boss 致命技能出现地面预警
→ Boss 死亡，血条淡出，奖励标签出现
→ 出口和任务目标提示更新
```
