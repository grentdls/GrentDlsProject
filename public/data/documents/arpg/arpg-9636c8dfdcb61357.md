# 角色属性、战斗公式、状态系统

---

## 1. 属性系统总览

属性分为 8 层：

```text
基础属性 → 装备属性 → 天赋属性 → 技能属性 → Buff 属性 → 地图词缀 → 怪物词缀 → 临时战斗修正
```

最终属性必须由 AttributeAggregator 统一计算，不允许各系统直接乱改最终值。

---

## 2. 角色基础属性

### 2.1 三大主属性

| 属性 | 作用 |
|---|---|
| 力量 Strength | 增加生命、重武器需求、护甲收益、近战伤害条件 |
| 敏捷 Dexterity | 增加命中、闪避、投射物需求、攻速条件 |
| 智慧 Intelligence | 增加能量护盾、法术需求、魔力和召唤条件 |

| 属性 | 说明 |
|---|---|
| Life | 生命值，归零死亡 |

| Armour | 主要减免物理击中伤害 |
| Evasion | 让攻击未命中 |
| BlockChance | 格挡概率，格挡后减伤或完全抵消 |
| Suppression | 法术压制，降低法术击中伤害 |

### 2.3 伤害属性

| 属性 | 说明 |

## 3. 属性叠加规则

### 3.1 Flat / Increased / More

所有属性分三种修正：

```text
Final = (Base + FlatSum) * (1 + IncreasedSum) * MoreMultiplierA * MoreMultiplierB * ...
```

示例：

```text
基础火焰伤害 100
装备 +20 火焰伤害
天赋 +50% 火焰伤害
技能辅助 30% 更多火焰伤害
最终 = (100 + 20) * 1.5 * 1.3 = 234
```

### 3.2 为什么必须分层

如果不分 Flat/Increased/More，后期数值会崩。复杂刷宝游戏里，每个词条都能堆叠，必须让“普通加成”和“乘区加成”区分清楚。

## 5. 伤害类型

### 5.1 物理

特点：

- 受护甲影响。
- 易转化为元素。
- 适合近战和弓弩。

护甲减免建议公式：

```text
PhysicalReduction = Armour / (Armour + Damage * 10)
```

### 5.2 火焰

特点：

- 可点燃。
- 高爆发，持续燃烧。
- 擅长范围清怪。

### 5.3 冰霜

特点：

- 可冰缓、冻结。
- 控制强，爆发中等。

### 5.4 闪电

特点：

- 伤害上下限波动大。
- 可感电，提高后续承伤。
- 擅长连锁和弹射。

### 5.5 毒素

特点：

- 叠层持续伤害。
- 适合高频击中。

### 5.6 混沌

特点：

- 绕过部分常规防御。
- 掉落和词条更稀有。
- 作为高阶 BD 核心。

## 6. 命中、闪避、格挡

### 6.1 命中判定

```text
HitChance = Accuracy / (Accuracy + Evasion * 0.8)
```

限制：

```text
MinHitChance = 5%
MaxHitChance = 95%
```

### 6.2 格挡判定

流程：

```text
被击中 → 判断是否可格挡 → Roll 格挡 → 减伤/完全格挡 → 触发格挡特效
```

建议第一版：

- 普通格挡：减免 70% 击中伤害。
- 完美格挡：在攻击前 0.25 秒内按格挡，完全抵消并触发反击窗口。

## 7. 暴击系统

```text
CritChanceFinal = BaseCritChance * (1 + IncreasedCritChance) + FlatCritChance
CritDamage = Damage * CritMultiplier
```

限制：

```text
CritChanceMax = 100%
CritMultiplierBase = 150%
```

暴击可触发：

- 元素异常。
- 暴击回血。
- 暴击刷新技能。
- 暴击召唤投射物。
- 暴击施加脆弱。

## 8. 异常状态系统

### 8.1 异常总表

| 异常 | 类型 | 效果 | 主要来源 |
|---|---|---|---|
| Ignite | 火焰持续 | 按击中火伤造成持续燃烧 | 火焰暴击/点燃率 |
| Chill | 冰缓 | 降低移动/攻击/施法速度 | 冰霜击中 |
| Freeze | 冻结 | 禁止行动 | 高冰霜爆发 |
| Shock | 感电 | 增加承受伤害 | 闪电击中 |
| Poison | 毒 | 可叠层持续混沌伤害 | 毒素/物理击中 |
| Bleed | 流血 | 移动时受到更多持续伤害 | 物理切割 |
| Stun | 眩晕 | 短时间硬直 | 大额击中 |
| Expose | 暴露 | 降低对应抗性 | 技能/辅助模块 |
| Marked | 标记 | 被特定技能追踪/增伤 | 诅咒/印记 |

### 8.2 异常抵抗

怪物和玩家都有：

```text
AilmentChanceReduction
AilmentDurationReduction
AilmentEffectReduction
```

## 11. 怪物抗性与地图压制

地图等级越高，玩家需要补抗性。

建议：

```text
普通难度抗性目标：30%
中期抗性目标：60%
高阶地图抗性目标：75%
特殊构筑可突破上限到 80~90%
```

地图可以增加：

- 怪物元素抗性。
- 怪物异常免疫。
- 玩家回复降低。
- 玩家护盾回复延迟。
- 怪物暴击率。
- 怪物投射物数量。

## 13. 验收标准

- 同一个技能换武器后伤害变化明显。
- 同一件装备对不同技能的影响不同。
- 抗性不足进入高阶地图会明显变脆。
- 暴击、异常、召唤、持续伤害都能做成独立 BD。
- 所有最终属性可以在 Debug 面板看到来源拆分。
