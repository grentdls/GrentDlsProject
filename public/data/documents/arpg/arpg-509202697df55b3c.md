# 181 数值扩展与词条玩法制作任务清单与验收标准

## 1. 阶段目标

完成完整的数值扩展和词条玩法体系，让装备、技能、天赋都能围绕构筑玩法产生联动。

---

## 2. 阶段 A：属性与伤害体系

任务：
- 新增属性定义表。
- 新增伤害类型表。
- 新增护甲、穿甲、抗性、护盾、破盾、真伤。
- 新增暴击、吸血、反伤、资源回复。

验收：
- 物理伤害受护甲影响。
- 穿甲能降低有效护甲。
- 元素伤害受对应抗性影响。
- 护盾先于生命承伤。
- 破盾能触发事件。
- 真伤绕过普通防御但受限制。

---

## 3. 阶段 B：触发词条系统

任务：
- 实现 OnHit。
- 实现 OnKill。
- 实现 OnCrit。
- 实现 OnTakeHit。
- 实现 OnShieldBreak。
- 实现 OnProjectileHit。
- 实现 OnMinionKill。
- 实现 OnControlApplied。
- 实现防无限递归规则。

验收：
- 击杀能触发爆炸。
- 击中能触发连锁。
- 暴击能触发额外效果。
- 受击能触发反伤。
- 破盾能触发破盾词条。
- 不会出现无限触发。

---

## 4. 阶段 C：装备词条池

任务：
- 武器前缀池。
- 武器后缀池。
- 防具前缀池。
- 防具后缀池。
- 首饰词条池。
- 传奇词条池。
- 套装词条池。
- 打造词条池。

验收：
- 装备能随机出穿甲、暴击、护盾、吸血等词条。
- 装备能随机出击杀、击中、受击词条。
- 传奇词条能改变玩法。
- 词条 UI 分组清晰。

---

## 5. 阶段 D：技能接入

任务：
- 给技能补齐标签。
- 技能配置能声明可受哪些词条影响。
- 投射物技能支持数量、分裂、穿透、连锁。
- AOE 技能支持范围、持续、重叠。
- 召唤技能支持召唤物增强。
- 控制技能支持控制增强。

验收：
- 投射物数量词条能影响对应技能。
- AOE 范围词条能影响范围技能。
- 召唤物词条能影响召唤技能。
- 控制词条能影响束缚、冻结、眩晕。

---

## 6. 阶段 E：天赋接入

任务：
- 通用小节点。
- 中型机制节点。
- 大型流派节点。
- 关键节点。
- 职业专精节点。
- 天赋详情预览。

验收：
- 天赋能强化装备词条。
- 天赋能改变技能机制。
- 关键节点有收益和代价。
- 职业专精方向明确。

---

## 7. 阶段 F：平衡与 UI

任务：
- 触发冷却。
- 触发深度限制。
- 召唤数量上限。
- 投射物上限。
- AOE 重叠上限。
- UI 词条模板。
- 伤害详情面板。
- 构筑标签统计。

验收：
- 不刷屏。
- 不无限连锁。
- 不无限召唤。
- 玩家能看懂词条触发条件。
- 装备、技能、天赋的词条颜色和标签清晰。

---

## 8. 推荐最小闭环

第一版先做：

```text
穿甲
暴击
护盾
破盾
吸血
真实伤害
击杀爆炸
击杀召唤骷髅
击中连锁闪电
受击反伤
投射物 +1
投射物分裂
召唤物伤害增强
控制敌人增伤
```

这批做完，装备、技能、天赋就会真正进入“刷词条、做构筑”的阶段。
