# 268 敌人生成与 AI 警戒系统总览：固定摆放、区域随机、刷新与木桩

## 1. 目标

建立一套可直接在 Unity 场景内摆放、预览和配置的敌人生成系统，支持两种主流程：

```text
固定敌人生成器：指定某一种敌人，适合 Boss、精英、特殊怪和木桩
区域随机生成器：在一个区域内按敌人列表随机生成，适合普通怪群和刷怪房
```

统一支持：

```text
固定等级或随机等级区间
是否开局生成
是否重复刷新
刷新间隔与最大刷新次数
全部清除后刷新
低于存活阈值刷新
玩家进入后激活
玩家离开后休眠
对象池
状态保存
Scene Gizmo
测试场景
```

AI 统一支持：

```text
主动警戒玩家
受击后激怒
警戒半径
受击后越过警戒范围追击
角色与召唤物目标选择
持续追杀直到死亡
木桩模式
```

## 8. AI 默认值

默认：

```text
AggroOnProximity = true
AggroOnDamage = true
CombatPersistence = UntilDeath
```

玩家进入警戒范围后：

```text
进入战斗
选择玩家阵营目标
持续追击直到敌人死亡
```

受到超远距离攻击时：

```text
无视原警戒触发距离
进入战斗
选择附近有效玩家阵营单位
开始追击
```

两个开关都关闭时：

```text
不会主动进入战斗
受击不会反击
适合作为木桩或中立目标
```

## 9. 设计边界

```text
生成器只负责生成、追踪和刷新
敌人本体负责 AI、伤害和死亡
刷新逻辑不写进敌人 Prefab
场景不直接写死 Prefab 路径
Boss 与普通怪使用同一生成接口
对象池回收时必须解绑事件
```
