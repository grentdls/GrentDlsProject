# 172 暴击、吸血、反伤与资源回复体系：命中、击杀、受击

## 1. 暴击体系

字段：

```text
critChance
critDamageMultiplier
critChanceAgainstMarked
critChanceAgainstControlled
critChanceWithElement
critChanceWithWeaponType
```

计算：

```text
finalCritChance = baseCritChance + flatCritChanceBonus
finalCritChance *= critChanceMultiplier
finalCritChance = clamp(finalCritChance, 0, critChanceCap)
```

建议：

```text
critChanceCap = 95%
critDamageMultiplier = 1.5
```

暴击触发词条：

```text
暴击时感电目标
暴击时释放连锁闪电
暴击时恢复能量
暴击时召唤一个幻影
暴击时刷新位移技能冷却
暴击击杀时产生爆炸
```

## 2. 生命吸血

```text
lifeLeechAmount = damageDealt * lifeLeechPercent
```

吸血限制：

```text
maxLeechPerSecond = maxLife * maxLeechRate
maxLeechRate = 0.12
```

击中吸血适合：
- 近战
- 多段攻击
- 高攻速
- 召唤物继承型构筑

击杀回血：

```text
OnKill:
    Heal(maxLife * killHealPercent)
```

溢出治疗转护盾：

```text
overflowHealToShieldPercent = 50%
```

## 3. 护盾吸取

```text
shieldLeech = damageDealt * shieldLeechPercent
```

词条：

```text
法术伤害的 2% 转化为护盾吸取
暴击时立即回复部分护盾
满护盾时获得更多伤害
破盾后 3 秒内护盾吸取翻倍
```

## 4. 反伤

受击反伤：

```text
reflectDamage = damageTaken * reflectPercent
```

固定反伤：

```text
受到近战命中时，反射 120 点物理伤害
```

限制：
- 反伤不能触发反伤。
- 反伤默认不能吸血。
- 反伤默认不能暴击。
- 反伤默认不能触发击杀爆炸，除非特殊传奇允许。

## 5. 资源回复

命中回资源：

```text
击中敌人获得 2 点怒气
闪电技能击中感电敌人时恢复 5 点法力
```

击杀回资源：

```text
击杀敌人恢复 8 点能量
击杀被诅咒敌人恢复 3% 最大法力
```

受击回资源：

```text
受到伤害的 5% 转化为怒气
格挡时获得 10 点专注
```

## 6. 处决

条件：

```text
targetLifePercent <= executeThreshold
```

效果：
- 普通怪可直接击杀。
- 精英造成额外真实伤害。
- Boss 造成固定比例伤害但有上限。

词条示例：

```text
对 20% 生命以下敌人造成真实伤害
暴击时若目标低于 15% 生命，造成处决伤害
召唤物攻击低生命敌人时必定暴击
```
