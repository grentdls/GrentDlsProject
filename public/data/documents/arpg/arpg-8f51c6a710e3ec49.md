# 157 动画配置制作任务清单与验收标准

## 1. 阶段目标

建立一套完整的动画配置体系，让项目支持：
- 基础动作
- 技能 Timeline
- 受击动画
- 状态动画
- 动画融合
- 动画事件
- 编辑器可视化配置

## 2. 阶段 A：基础动画配置

任务：
- 建立 AnimationClipTable。
- 建立 UnitAnimationSetTable。
- 配置待机、移动、跳跃、下落、落地、出生、死亡。
- 接入 Animator Controller / BlendTree。
- 支持循环和融入融出。

验收：
- 待机循环自然。
- 移动循环自然。
- 跳跃阶段完整。
- 高处掉落直接播 FallLoop。
- 死亡掉落事件可触发。

## 3. 阶段 B：技能 Timeline

任务：
- 实现 SkillTimeline 数据结构。
- 实现 Segment 播放。
- 实现 FullClip 模式。
- 实现 StartupLoopEnd 模式。
- 实现 ChargeRelease 模式。
- 实现 ComboChain 模式。

验收：
- 完整技能可播放。
- 前摇 + 循环 + 结束技能可播放。
- 蓄力技能可按住循环、松手释放。
- 连段能在输入窗口进入下一段。

## 4. 阶段 C：Timeline 事件轨道

任务：
- AnimationTrack
- HitboxTrack
- DamageTrack
- ProjectileTrack
- VFXTrack
- SFXTrack
- MovementTrack
- CameraTrack
- StateTrack
- CancelWindowTrack

验收：
- 可指定第几帧出伤害。
- 可指定第几帧开关 Hitbox。
- 可指定第几帧播特效音效。
- 可指定技能位移。
- 可配置取消窗口。

## 5. 阶段 D：受击动画

任务：
- 四方向受击。
- 轻中重受击。
- 空中受击。
- 击退。
- 击飞。
- 击倒。
- 破韧。
- 起身。

验收：
- 不同方向受击正确。
- 击退有动画和位移。
- 击飞有起飞、空中、落地。
- 击倒有倒地循环和起身。
- 破韧有输出窗口。

## 6. 阶段 E：状态动画

任务：
- 束缚。
- 冰冻。
- 眩晕。
- 睡眠。
- 恐惧。
- 中毒虚弱。
- 燃烧挣扎。
- 状态覆盖优先级。

验收：
- 束缚动画可持续循环。
- 束缚能锁移动。
- 冰冻能定格或循环。
- 眩晕能进入循环再恢复。
- 状态和死亡/受击优先级正确。

## 7. 阶段 F：Timeline 编辑器

任务：
- 编辑器窗口。
- 轨道绘制。
- 事件拖拽。
- Inspector 编辑。
- 预览角色。
- 预览 Hitbox。
- 校验错误。
- 导出配置。

验收：
- 策划能配置一个完整技能。
- 策划能拖动伤害帧。
- 策划能看到 Hitbox。
- 策划能校验资源缺失。
- 配置可导入运行时。

## 8. 推荐排期

```text
第1周：基础动画配置
第2周：完整技能 Timeline
第3周：前摇循环结束 / 蓄力 / 连段
第4周：受击四方向 / 击退击飞击倒 / 状态动画
第5周：Timeline 编辑器与校验
```
