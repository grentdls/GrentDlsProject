# 34_UI 数据绑定、事件刷新、MVVM、文本本地化、音效动画


> 设计边界说明：本项目可以参考《流放之路2》这类暗黑刷宝 ARPG 的信息架构、交互复杂度和系统深度，但不能一比一复制其 UI 视觉、图标、文字、专有数值、专有命名、具体排版截图。本批文档采用“同类结构 + 原创表现”的方式：界面功能、层级、预制体和数据绑定可直接用于 Unity 原型开发。


## 1. UI 架构原则

UI 不直接读取角色组件，不直接操作背包数组，不直接生成掉落。所有 UI 通过 ViewModel 和事件总线刷新。

```text
Gameplay System → Model → ViewModel → UI View
UI 操作 → UI Command → Gameplay Service → Model 变化 → 事件 → UI 刷新
```

## 4. UI 事件

| 事件 | 触发时机 | 影响 UI |
|---|---|---|
| `OnInventoryChanged` | 物品增加/删除/移动 | 背包、仓库、商店 |
| `OnEquipmentChanged` | 装备变化 | 装备栏、属性、技能需求 |
| `OnSkillChanged` | 技能组变化 | 技能页、HUD 技能栏 |
| `OnCurrencyChanged` | 货币变化 | 商店、货币栏 |
| `OnQuestUpdated` | 任务进度变化 | 任务日志、HUD 目标 |
| `OnMapOpened` | 地图装置开启 | 传送门 UI、地图状态 |
| `OnPlayerStatsChanged` | 属性变化 | 角色页、Tooltip 比较 |
| `OnTargetChanged` | 锁定目标变化 | 目标信息条 |

## 6. 刷新策略

| UI 类型 | 刷新方式 |
|---|---|
| HUD 血条 | 高频刷新，使用插值，不走完整 Rebuild |
| 背包格子 | 事件刷新，只刷新变动槽位 |
| Tooltip | 打开时生成，数据变化时重建 |
| 商店列表 | 打开时构建，交易后局部刷新 |
| 天赋树 | 初始化生成节点，点数变化只刷新状态 |
| 地图册 | 初始化生成节点，完成状态局部刷新 |

## 7. 本地化字段

所有 UI 文本不得写死中文，使用 Key。

```text
ui.loadout.title = 整备
ui.tab.character = 角色
ui.tab.equipment = 装备
ui.tab.skills = 技能
ui.shop.buy = 购买
ui.shop.sell = 出售
ui.blacksmith.enhance = 强化
ui.mapdevice.open = 开启地图
```

## 10. UI 动画

| 组件 | 动画 |
|---|---|
| 大窗口 | 0.12s 淡入 + 轻微缩放 |
| Tooltip | 0.06s 淡入，不缩放 |
| 物品格悬浮 | 边框亮起 + 1.03 缩放 |
| 错误提示 | 红色闪烁 + 轻微横向抖动 |
| 购买成功 | 商品格短暂闪光 |
| 装备变化 | 装备槽发光 0.2s |
| 天赋分配 | 节点光圈扩散 |
| 地图开启 | 传送门槽旋转发光 |

## 11. 原型验收标准

1. UI 通过 ViewModel 刷新，不直接读写 Gameplay 数据。
2. 背包变化只刷新变动格子。
3. 所有文字可通过 Key 替换。
4. 关键操作有音效。
5. 主要窗口有打开/关闭动画。
