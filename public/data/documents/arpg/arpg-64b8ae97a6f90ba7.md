# 装备系统：基底、词条、稀有度、打造、掉落

---

## 1. 装备系统目标

装备系统是长期刷宝体验的核心。玩家每次刷图都要期待：

- 掉一个更高物品等级的基底。
- 掉一个稀有词条组合。
- 掉一个能改变技能机制的传奇装备。
- 掉一个能继续打造的半成品。
- 掉一个能卖给其他玩家/分解为材料的物品。

本项目采用原创装备系统，但复杂度目标对齐顶级刷宝 ARPG。

---

## 2. 装备部位

第一版建议 12 个装备位：

| 部位 | 主要功能 |
|---|---|
| 主手武器 | 决定基础攻击、技能可用性、攻击距离 |
| 副手 | 盾、法器、副武器、箭袋、焦点 |
| 头盔 | 防御、技能等级、抗性 |
| 胸甲 | 最大防御、生命、护甲、护盾 |
| 手套 | 攻速、施法速度、命中、异常 |
| 靴子 | 移速、闪避、抗性、冷却 |
| 腰带 | 药剂、生命、防御、掉落 |
| 项链 | 全局伤害、属性、技能等级 |
| 戒指 1 | 抗性、资源、伤害补充 |
| 戒指 2 | 抗性、资源、伤害补充 |
| 护符/圣物 | 特殊机制、Build 转换 |
| 技能核心槽 | 技能核心和辅助模块承载 |

## 5. 稀有度

| 稀有度 | 颜色 | 词条规则 | 用途 |
|---|---|---|---|
| Common | 白 | 只有基底 | 打造底材、早期过渡 |
| Magic | 蓝 | 1 前缀 + 1 后缀上限 | 早期过渡、低成本打造 |
| Rare | 黄 | 3 前缀 + 3 后缀上限 | 主力装备 |
| Relic | 橙 | 固定特殊机制 + 可变数值 | 改变玩法 |
| Corrupted | 红边 | 被污染，不能常规修改 | 高风险高收益 |
| Fractured | 裂纹 | 部分词条锁定 | 高级打造底材 |
| Synthesized | 星痕 | 特殊隐性词缀 | 终局追求 |

注意：名称可继续美术化，颜色仅用于 UI 识别。

## 7. 原创词条分类

### 7.1 攻击类

- 增加物理伤害。
- 增加元素伤害。
- 增加攻击速度。
- 增加暴击率。
- 增加暴击倍率。
- 击中回复生命。
- 击中获得怒气。
- 对流血敌人更多伤害。
- 近距离更多伤害。
- 连续命中同一目标叠加伤害。

### 7.2 法术类

- 增加法术伤害。
- 增加施法速度。
- 增加法术暴击。
- 增加元素穿透。
- 技能范围扩大。
- 持续伤害加成。
- 每消耗魔力获得护盾。
- 站立施法满 1 秒后下一次法术增强。

### 7.3 防御类

- 最大生命。
- 最大魔力。
- 最大能量护盾。
- 护甲。
- 闪避。
- 格挡率。
- 抗性。
- 受到暴击伤害降低。
- 生命低于 35% 时获得屏障。

### 7.4 速度类

- 移动速度。
- 闪避冷却回复。
- 技能冷却回复。
- 攻击后短时移动速度。
- 击杀后移动速度。
- 药剂持续时间。

### 7.5 掉落与地图类

- 增加金币掉落。
- 增加稀有装备掉落。
- 地图钥石掉落率。
- Boss 掉落额外材料概率。
- 地图机制奖励量。

### 7.6 构筑改变类

- 火焰伤害可以施加中毒。
- 闪避值的一部分转化为护甲。
- 最大生命不能超过 1，但能量护盾翻倍。
- 召唤物继承玩家暴击倍率的一部分。
- 近战技能发射一次短距离冲击波。
- 药剂效果期间技能不消耗魔力。

这类词条建议只出现在 Relic、Boss 专属掉落或终局打造中。

## 9. 装备生成流程

```text
1. 确定掉落源：怪物/箱子/Boss/地图奖励/任务
2. 计算物品等级：地图等级 + 掉落源修正
3. 选择装备部位
4. 选择基底
5. Roll 稀有度
6. Roll 隐性词条
7. Roll 前缀数量
8. Roll 后缀数量
9. 根据物品等级和标签抽词条
10. Roll 每条数值
11. Roll 特殊状态：裂纹/污染/星痕
12. 生成 ItemInstance
```

## 10. Crafting 打造材料

使用原创材料，不复制商业游戏道具名称。

| 材料 | 作用 |
|---|---|
| 粗炼石 | 白装变蓝装 |
| 重铸粉 | 重新随机蓝装词条 |
| 贵族印 | 蓝装变黄装，添加新词条 |
| 裂隙锤 | 随机重置黄装全部词条 |
| 定向火漆 | 给装备添加一个指定大类词条 |
| 镜纹针 | 重新 Roll 某条词条数值，不改变词条类型 |
| 锁纹石 | 锁定一个词条后重铸其他词条 |
| 污染烙印 | 污染装备，可能增强、破坏、变异或无变化 |
| 星痕核心 | 生成特殊隐性词条 |
| 传承卷轴 | 提取传奇装备的一部分机制碎片 |

---

## 11. 打造限制

- 普通装备可常规打造。
- 污染装备不能常规打造。
- 裂纹词条不能被移除。
- 星痕隐性词条会替换原有隐性词条。
- Relic 装备不能变更核心机制，只能 Roll 可变范围。
- 同一个装备最多 3 前缀 + 3 后缀。

## 12. 传奇/Relic 装备设计规则

传奇装备不要只是“数值更高”，必须改变玩法。

### 12.1 好传奇装备标准

```text
牺牲一个维度 → 强化另一个维度 → 打开一个新 BD
```

示例：

```text
名称：余烬誓环
部位：戒指
机制：你的冰霜技能不能冻结，但可以点燃。点燃伤害按照冰霜伤害的一部分计算。
代价：火焰抗性上限 -5%。
```

```text
名称：空壳王冠
部位：头盔
机制：召唤物死亡时，给主人恢复能量护盾。
代价：你无法通过药剂恢复生命。
```

## 15. 装备验收标准

- 黄色装备能刷很久，但不会每件都值得捡。
- Relic 装备能让玩家产生“我想围绕它做一套 BD”的想法。
- 打造材料既能用于早期升级，也能用于终局追求。
- 词条筛选器是必须功能，不然后期掉落会变成噪音。
- 任意装备必须能在 Debug 里还原生成流程。
