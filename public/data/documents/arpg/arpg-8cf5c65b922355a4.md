# 252 符石匠 NPC 完整功能：购买、镶嵌、拆卸、合成、分解

## 1. 符石匠定位

符石匠负责装备插槽和符石成长。符石提供可控补强，不替代装备随机词条。

---

## 2. 符石购买

### 固定商品

```text
普通生命符石
普通护甲符石
普通护盾符石
基础元素抗性符石
基础攻击符石
基础资源符石
符石粉尘
无损取石器
```

### 随机商品

```text
精良符石
稀有符石
职业推荐符石
当前构筑推荐符石
高 Roll 符石
折扣商品
```

### 限购商品

```text
史诗符石
传奇符石碎片
定向合成核心
神器符石胚胎
```

价格：

```text
基础价格 × 品质倍率 × 等级倍率 × 世界难度倍率 × NPC 折扣
```

## 3. 符石镶嵌

流程：

```text
选择装备
→ 显示插槽
→ 选择符石
→ 拖入插槽
→ 检查兼容
→ 预览属性变化
→ 确认
→ 扣除费用
→ 写入符石实例
→ 刷新属性
```

检查：

```text
是否有空孔
孔型是否兼容
装备部位是否兼容
符石等级是否超过装备承载等级
是否超过唯一数量
是否存在冲突词条
装备是否锁定
```

镶嵌费用：

```text
普通/精良：金币
稀有/史诗：金币 + 符石粉尘
传奇/神器：金币 + 粉尘 + 品质核心
```

---

## 4. 符石拆卸

### 无损拆卸

```text
消耗金币 + 无损取石器
符石返回背包
插槽恢复为空
```

### 低成本拆卸

```text
只消耗金币
可能使符石变为裂纹状态
```

裂纹符石：

```text
不能镶嵌
不能交易
可以修复
可以分解
```

### 强行拆卸

```text
不需要稀有材料
符石被摧毁
插槽保留
```

必须二次确认。

### 传奇拆卸

需要：

```text
传奇取石器
或符石匠高声望
```

---

## 5. 快速替换

把新符石拖到已有符石的插槽时，弹出：

```text
无损取出旧符石
摧毁旧符石
取消
```

系统不得默认摧毁旧符石。

---

## 6. 符石合成

### 同名升阶

```text
3 枚同名同品质符石
→ 1 枚高一品质同系符石
```

### 同系随机

```text
3 枚同品质同类别符石
→ 1 枚同类别随机高一品质符石
```

### 定向合成

```text
主符石 + 两枚材料符石 + 定向核心
→ 指定系列高阶符石
```

### 词条继承

```text
选择主符石的一条效果
→ 合成时提高该效果的继承概率
```

---

## 7. 分解

分解获得：

```text
符石粉尘
品质碎片
元素精华
传奇碎片
神器余烬
```

产出受品质、等级、强化等级和裂纹状态影响。

---

## 8. 修复

```text
裂纹符石 + 粉尘 + 金币
→ 恢复正常
```

史诗以上需要对应品质核心。

---

## 9. 鉴定

普通和精良符石直接显示效果；史诗以上可存在未鉴定版本。

```text
未鉴定符石只显示品质、类别、适用孔型
鉴定后显示具体机制和数值 Roll
```

降低前期操作负担，不给低品质符石增加鉴定步骤。

---

## 10. 图鉴

显示：

```text
名称、图标、品质、系列、孔型、适用部位
效果、最高数值、掉落来源、配方、发现状态
```

图鉴奖励示例：

```text
发现 20 枚：商店折扣
发现 60 枚：合成费用降低
发现 120 枚：每日免费拆卸
全图鉴：神器配方
```

---

## 11. 批量功能

```text
批量购买
自动选择合成材料
按品质自动合成
批量分解
自动锁定史诗以上符石
保留未收录图鉴符石
保留高 Roll 符石
```

---

## 12. 声望解锁

| 声望 | 功能 |
|---|---|
| 1 | 普通购买、镶嵌 |
| 2 | 无损拆卸、精良商店 |
| 3 | 同名合成、稀有商店 |
| 4 | 定向合成、史诗鉴定 |
| 5 | 传奇拆卸、碎片兑换 |
| 6 | 神器配方、词条继承 |

---

## 13. 验收标准

```text
可购买符石
可拖拽镶嵌
不兼容时明确提示
镶嵌前显示属性变化
支持无损和摧毁拆卸
支持同名与同系合成
支持分解和修复
批量操作不会处理锁定物品
```
