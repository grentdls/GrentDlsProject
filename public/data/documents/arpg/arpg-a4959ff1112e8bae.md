# 205 套装与天赋联动规则：套装强化、天赋解锁、流派成型

## 1. 设计目标

套装给玩家提供流派骨架，天赋负责把套装玩法继续放大或改变规则。

设计原则：

```text
套装 = 装备侧流派启动
天赋 = 成长侧流派深化
技能 = 操作侧流派表现
```

---

## 2. 套装与天赋的关系

### 2.1 套装提供关键词
例如穿甲套提供：

```text
穿甲
重击
破韧
真实伤害
```

### 2.2 天赋识别关键词
天赋节点可以强化：

```text
你从装备获得的穿甲提高 20%
破韧敌人后，穿甲加成翻倍 3 秒
重击技能继承 30% 破韧伤害为真实伤害
```

---

## 3. 天赋强化套装

### 3.1 直接强化
```text
套装效果提高 20%
3件套效果额外获得 50% 数值
5件套触发效果冷却降低
```

### 3.2 条件强化
```text
当你装备至少 3 件同套装时，获得额外效果。
当你装备 5 件套装时，关键天赋效果翻倍。
```

### 3.3 混搭强化
```text
同时装备两个 3件套时，获得混搭奖励。
每激活一个 3件套，所有抗性 +5%。
```

---

## 4. 流派套装 + 天赋示例

### 4.1 穿甲套

套装：
```text
3件：穿甲 +18%，破韧伤害 +20%
5件：破韧后下一次重击必暴
```

天赋：
```text
装备提供的穿甲额外提高 15%
重击暴击时造成额外真实伤害
破韧窗口延长 1 秒
```

### 4.2 召唤套

套装：
```text
3件：召唤物数量 +1，召唤物生命 +20%
5件：召唤物死亡时爆炸
```

天赋：
```text
召唤物死亡爆炸可以施加燃烧
召唤物击杀有概率召唤骷髅
召唤物继承你 30% 暴击率
```

### 4.3 护盾套

套装：
```text
3件：护盾 +25%，护盾回复 +20%
5件：满盾时法术伤害 +30%
```

天赋：
```text
满盾时技能消耗降低
护盾回复不中断时间延长
护盾转化为闪电附加伤害
```

---

## 5. 天赋解锁套装隐藏效果

可设计高级节点：

```text
当你激活任意 5 件套时，解锁套装超载效果。
```

示例：
```text
碎甲战铠超载：破韧敌人时，重置所有重击技能冷却。
亡骨契约超载：召唤物死亡爆炸会召唤一个短暂幽魂。
星辉护幕超载：护盾破裂不会中断法术引导。
```

---

## 6. 套装 UI 与天赋提示

天赋界面需要显示：
```text
该节点可强化哪些套装
当前已装备几件
当前能激活哪些额外效果
缺少哪些部位
```

装备界面需要显示：
```text
该套装推荐天赋
当前天赋已强化的套装效果
```

---

## 7. 平衡规则

- 套装不应该强制绑定唯一职业。
- 天赋不应只服务一套装备。
- 5件套要强，但不能让散件和传奇完全失效。
- 套装强化天赋要有路径成本。
