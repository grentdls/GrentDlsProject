# 184 生命、护盾、资源转化玩法：低血、满盾、溢出、保留、代价

## 1. 低血玩法

低血阈值：

```text
LowLife = 当前生命 <= 最大生命 35%
```

低血词条：

```text
低血时伤害提高 30%
低血时吸血上限提高 50%
低血时受到的治疗提高 25%
低血时获得 20% 伤害减免
低血时暴击率 +15%
```

风险：
- 容错低。
- 需要防止永久无敌。
- 对 Boss 斩杀技能更危险。

---

## 2. 满血玩法

```text
满血时暴击率 +10%
满血时移动速度 +15%
满血时投射物数量 +1
受到伤害后该效果失效 3 秒
```

适合：
- 远程
- 闪避
- 护盾隔离生命流派

---

## 3. 满盾玩法

```text
满护盾时法术伤害 +25%
满护盾时技能消耗降低 20%
满护盾时暴击造成感电
满护盾时受到第一次伤害减少 30%
```

满盾判断：

```text
currentShield >= maxShield * 0.98
```

---

## 4. 破盾后玩法

```text
护盾破裂后，4 秒内伤害 +30%
护盾破裂后，释放一次冲击波
护盾破裂后，立即恢复 20 点怒气
护盾破裂后，进入 1 秒无敌，但 8 秒内不能再次触发
```

字段：

```json
{
  "trigger": "OnSelfShieldBreak",
  "cooldown": 8.0,
  "effects": [
    {"stat": "Damage", "op": "More", "value": 0.3, "duration": 4.0}
  ]
}
```

---

## 5. 溢出治疗转护盾

```text
当治疗超过最大生命时，50% 的溢出值转化为护盾。
```

```text
overflow = max(0, healAmount - missingLife)
shieldGain = overflow * convertPercent
```

词条：

```text
溢出治疗的 50% 转为护盾
溢出治疗转护盾时，获得 3 秒伤害提高
溢出治疗转护盾上限为最大生命 20%
```

---

## 6. 生命转护盾

```text
最大生命降低 20%，最大护盾提高 40%。
生命回复改为护盾回复。
生命吸血改为护盾吸取。
```

适合护盾法师和高风险构筑。

---

## 7. 护盾转伤害

```text
每 100 点最大护盾，使法术伤害提高 1%。
满护盾时，护盾值的 5% 转化为额外闪电伤害。
释放技能消耗 3% 当前护盾，附加等量法术伤害。
```

限制：
- 消耗护盾不能直接触发护盾破裂词条，除非配置允许。
- 护盾转伤害必须有上限。

---

## 8. 资源保留玩法

```text
保留 30% 法力，获得火焰伤害光环。
保留 20% 生命，召唤物数量 +2。
保留 40% 护盾，获得持续雷电护体。
```

字段：

```json
{
  "reserveType": "Mana",
  "reservePercent": 0.3,
  "grantedEffect": "Aura_FireDamage"
}
```

---

## 9. 代价型词条

```text
技能消耗生命而非法力。
技能消耗护盾而非法力。
你的护盾无法自然回复，但击中会恢复护盾。
你不能吸血，但击杀会恢复大量生命。
你无法暴击，但真实伤害提高。
```

代价型词条适合：
- 关键天赋
- 传奇装备
- 高级辅助模块
