# 132 按钮与交互反馈规范：悬停、按下、禁用、手柄焦点

## 1. 文档目标
定义所有按钮、页签、切换控件、物品格、技能格、天赋节点、列表项的交互反馈标准。

目标：
- 玩家一眼知道“这里能点”。
- 玩家一碰就能感受到“有反馈”。
- 键鼠、手柄两套交互都成立。

---

## 2. 交互状态总表
每个可交互 UI 元素最少包含以下状态：
- Default
- Hover
- Pressed
- Selected
- Focused（手柄/键盘）
- Disabled
- Warning
- Success（可选）

---

## 3. 按钮分类

### 3.1 主按钮 Primary
用途：确定、学习、装备、确认、进入、开始
表现：
- 高亮主色背景
- 明确边框
- Hover 更亮
- Press 有压下感

### 3.2 次按钮 Secondary
用途：替换、预览、筛选、切换、查看更多
表现：
- 深底描边
- Hover 边框变亮

### 3.3 幽灵按钮 Ghost
用途：低优先级、更多说明、可选项
表现：
- 无实底
- Hover 才出现底色

### 3.4 危险按钮 Danger
用途：删除、重置、销毁、放弃
表现：
- 红色边框/红色底
- Hover 红光增强

### 3.5 Tab / Segment / Toggle
用途：页面切换、分类切换、过滤开关
表现：
- 未选中较弱
- 选中高亮条明显

---

## 4. 状态表现规则

### 4.1 Default
- 按钮边框正常
- 阴影正常
- 文本高对比
- 图标不做高亮

### 4.2 Hover
触发时机：鼠标进入可交互区域。

反馈项：
- 缩放：1.00 -> 1.03（普通按钮） / 1.05（重要按钮）
- 背景亮度：+8% ~ +15%
- 边框亮度：+20%
- 阴影：轻微加深
- 光泽扫光：可选
- 音效：轻量“tick”
- Tooltip：延迟 0.1~0.2s 弹出

### 4.3 Pressed
触发时机：鼠标按下 / 手柄确认按下。

反馈项：
- 缩放：1.03 -> 0.98
- 位置：Y 向下偏移 1~3 px
- 阴影缩短
- 内部高光减弱
- 确认音效播放

### 4.4 Selected
- 常驻高亮边框
- 背景亮于 Default
- 页签底部选中条显示
- 允许图标染色或角标出现

### 4.5 Focused（手柄/键盘导航）
- 和 Hover 类似，但强调“焦点框”
- 焦点框需要显式脉冲动画
- 焦点移动时要有音效

### 4.6 Disabled
- 透明度降至 40~55%
- 文本灰化
- 图标去饱和
- Hover 不能高亮，但允许显示原因 Tooltip

---

## 5. 物品格 / 技能格 / 天赋节点反馈规范

### 5.1 Slot Hover
- 边框亮起
- 图标轻微放大
- 稀有度边框发光增强
- Tooltip 显示

### 5.2 Slot Pressed / Drag Start
- 半透明拖拽镜像出现
- 原位置显示占位边框
- 无效放置目标显示红框
- 有效放置目标显示绿框

### 5.3 Node Hover
- 节点外环发光
- 路径轻微高亮
- 右侧详情同步更新

### 5.4 Node Select
- 节点选中环常驻
- 路径高亮保持
- 行为按钮可用性刷新

---

## 6. 动画参数建议
- Hover 入场：0.08~0.12s
- Hover 离场：0.06~0.10s
- Press 下压：0.04~0.06s
- Press 回弹：0.08~0.12s
- Focus 脉冲周期：0.8~1.2s
- Tooltip 淡入：0.12s

Easing 建议：
- Hover：OutQuad
- Press：OutCubic / InQuad
- 回弹：OutBack（轻度）

---

## 7. 音效规则
- Hover：轻提示，不刺耳，不叠太多
- Press：明确、短促
- Disabled Click：闷音 / 失败音
- 成功操作：清晰确认音
- 危险操作：需二次确认，音效更谨慎

---

## 8. 手柄导航专项
- 焦点必须 100% 可见。
- 同屏必须存在默认焦点。
- 焦点顺序遵循视觉阅读顺序。
- 弹窗打开时焦点自动落在主按钮。
- 若按钮 Disabled，焦点自动跳过。

---

## 9. 通用按钮预制体层级
```
Button_Base
├── Bg_Default
├── Bg_Highlight
├── Border
├── Shadow
├── Icon(optional)
├── Label
├── Badge(optional)
└── StateAnimator
```

### Animator States
- Idle
- Hover
- Pressed
- Selected
- Disabled
- Focused

---

## 10. 验收标准
- 所有按钮必须有 Hover 与 Press 反馈。
- 所有页签必须有 Selected 状态。
- 所有 Disabled 控件必须能说明“为什么不可点”。
- 手柄焦点在任何页面都不能丢失。
- 拖拽交互必须清楚表达“可放 / 不可放”。
