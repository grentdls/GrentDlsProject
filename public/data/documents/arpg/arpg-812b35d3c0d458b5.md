# 13_地图结构总览：全部原型地图清单

> 目标：先用 Unity 灰盒/白盒把所有核心地图玩法跑通，再逐步替换美术资源。本文档定义主城、战斗区域、Boss 区、终局地图的整体结构、命名、尺寸、流程和原型搭建优先级。

---

## 1. 制作原则

### 1.1 不是直接复刻商业地图，而是复刻暗黑类 ARPG 的系统骨架

本项目的地图结构参考暗黑刷宝 ARPG 的常见系统：

- 主城作为功能节点。
- 野外地图作为任务推进和刷怪空间。
- 地牢/据点作为高密度战斗空间。
- Boss 房作为阶段性考核。
- 终局地图作为无限刷取和构筑验证空间。

地图名称、结构、剧情、Boss、事件、数值均使用原创设计，避免直接照搬其他商业游戏的专有内容。

### 1.2 先搭建原型地图

第一阶段只做可玩的灰盒地图，不做完整美术：

- 地面：灰色 Plane / ProBuilder 地块。
- 墙体：Cube / 模块墙。
- 遮挡：透明高度墙或调试色墙。
- 入口出口：发光方框。
- NPC：胶囊体 + 名称牌。
- 怪物：占位模型。
- 宝箱：方块箱体。
- 可破坏物：木桶/石堆占位。
- Boss：大型胶囊体 + 技能范围提示。

### 1.3 地图必须服务 3D ACT 操作

因为本项目从 2D 锁定视角改为 3D ACT 操作，地图不能照搬俯视刷宝游戏的狭窄走廊结构，必须满足：

- 玩家能前后左右翻滚。
- 相机有旋转和跟随空间。
- Boss 攻击有侧闪和绕背空间。
- 近战怪能包围但不能完全卡死玩家。
- 远程怪需要视线遮挡物。
- 场景边缘需要防跌落阻挡。
- 悬崖、墙体、巨物不能频繁挡住镜头。

## 2. 场景类型总表

| 类型 | 场景用途 | 是否可反复刷 | 是否有 Boss | 是否有主线任务 | 原型优先级 |
|---|---|---:|---:|---:|---:|
| 主城 Hub | NPC、商店、仓库、传送、打造、任务 | 是 | 否 | 是 | S |
| 教学地图 | 输入、攻击、闪避、拾取、装备教学 | 否 | 小 Boss | 是 | S |
| 野外战斗区 | 普通推进、支线、事件、刷怪 | 是 | 可选 | 是 | S |
| 地牢战斗区 | 高密度战斗、宝箱、精英、机关 | 是 | 是 | 是 | S |
| 据点战斗区 | 破坏/解救/占领类目标 | 是 | 小 Boss | 是 | A |
| Boss 房 | 单体 Boss / 双 Boss / 阶段 Boss | 是 | 是 | 是 | S |
| 赛季事件区 | 特殊机制、限时挑战、词缀奖励 | 是 | 可选 | 否 | B |
| 终局地图 | 无限刷图、地图词缀、Atlas 推进 | 是 | 是 | 否 | A |
| 试炼地图 | 角色成长/转职/升阶试炼 | 是 | 是 | 是 | B |
| 藏身处 | 玩家自定义功能主城 | 是 | 否 | 否 | C |

## 3. 原型阶段地图命名规则

### 3.1 Scene 文件命名

```text
Scene_[类型]_[章节]_[地图序号]_[地图名]
```

示例：

```text
Scene_Hub_A01_001_星陨营地
Scene_Field_A01_002_断桥荒原
Scene_Dungeon_A01_003_裂石矿洞
Scene_Boss_A01_004_黑炉看守者
Scene_Endgame_T01_001_灰烬边境
```

### 3.2 MapId 命名

```text
MAP_A01_HUB_001
MAP_A01_FIELD_002
MAP_A01_DUNGEON_003
MAP_A01_BOSS_004
MAP_END_T01_001
```


## 11. 地图基本结构规范

每张地图都必须包含下列核心节点：

```text
MapRoot
├── SceneInfo
├── PlayerSpawnPoints
├── Navigation
├── Terrain
├── StaticBlockers
├── DynamicObjects
├── Interactables
├── MonsterSpawnGroups
├── EliteSpawnPoints
├── BossAreaTrigger
├── LootPoints
├── DestructibleGroups
├── EventVolumes
├── TeleportPoints
├── ExitPortals
├── MinimapBounds
└── DebugMarkers
```

### 11.1 MapRoot

用于挂载地图控制脚本。

推荐组件：

- `MapController`
- `MapRuntimeState`
- `MapObjectiveManager`
- `MapSpawnDirector`
- `MapInteractableRegistry`
- `MapDropManager`
- `MapFogOfWarController`

### 11.2 SceneInfo

记录地图静态配置。

字段：

```text
MapId
MapName
MapType
ActIndex
Tier
RecommendedLevel
MapTheme
MapSize
MainObjectiveId
BossId
MusicId
AmbientSoundId
LightingProfileId
```

### 11.3 PlayerSpawnPoints

至少包含：

- `Spawn_Entry`：第一次进入地图的位置。
- `Spawn_Checkpoint_01`：复活点。
- `Spawn_FromPortal`：从传送门返回的位置。
- `Spawn_BossRetry`：Boss 死亡重试点。

### 11.4 TeleportPoints

每个重要区域必须有传送点：

- 主城中央传送。
- 每章中段传送。
- Boss 前传送。
- 终局地图入口传送。

### 11.5 ExitPortals

出口规则：

- 主线地图出口：通往下一张地图。
- 地牢出口：通往 Boss 或返回野外。
- Boss 出口：通往下一章主城或返回当前主城。
- 终局地图出口：返回主城/藏身处。

## 12. 原型搭建优先级

2. 赛季事件地图。
3. 多 Boss 地图。

5. 玩家藏身处。

## 13. 第一批灰盒验收标准

完成第一批灰盒地图时，必须满足：

- 玩家可以从主城传送到战斗地图。
- 战斗地图可以刷怪、掉落、开箱、破坏场景物。
- 小地图可以显示入口、出口、NPC、传送点、Boss 门。
- 玩家可以进入 Boss 房并完成击杀。
- Boss 死亡后生成奖励宝箱和出口门。
- 回城传送门可用。
- NPC 可以交互，商店可以买卖。
- 铁匠可以打开打造界面。
- 技能商人可以打开技能购买界面。
- 仓库可以打开存储界面。
- 所有地图切换不丢失玩家状态。
