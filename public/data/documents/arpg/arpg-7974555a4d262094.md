# 265 小地图性能优化：相机、RenderTexture、图标与刷新频率

## 1. 两种方案

### 实时相机

适合程序生成或场景变化多，但有额外 Camera 与 RenderTexture 成本。

### 静态贴图

适合固定主城和固定地牢，成本低、表现稳定。

推荐：

```text
固定地图：静态贴图
程序生成/破坏变化多：低频实时相机
```

## 2. 小地图相机

只渲染：

```text
简化地面层
墙体轮廓层
关键机关层
```

不渲染：

```text
高模角色
粒子
阴影
后处理
植被
动态灯光
天空盒
```

关闭：

```text
HDR
MSAA
后处理
阴影
深度纹理（非必要）
```

## 3. RenderTexture

建议：

```text
256×256
512×512
```

一般不需要 1024×1024。

## 4. 刷新频率

```text
玩家移动：10-20 Hz
玩家静止：2-5 Hz
大地图界面：20-30 Hz
```

可关闭 Camera，按需调用 `Camera.Render()`。

## 5. 图标层

敌人、任务、传送门、宝箱等图标使用独立 UI 层，不让小地图相机渲染模型。

```text
MinimapIconRegistry
├── PlayerIcon
├── EnemyIcons
├── QuestIcons
├── PortalIcons
└── ChestIcons
```

## 6. 图标刷新

```text
玩家：10-30 Hz
普通敌人：5-10 Hz
Boss/精英：15-30 Hz
固定图标：注册或状态变化时更新
```

临时图标对象池化。

## 7. 战争迷雾

避免逐像素每帧绘制。ARPG 地牢推荐：

```text
房间级揭示
低分辨率 Mask
低频更新
```

## 8. Overdraw

结构尽量保持：

```text
一层地图
一层 Mask
一层图标
一层边框
```

避免多层半透明和复杂 SoftMask。

## 9. 验收

```text
小地图只渲染必要 Layer
关闭小地图后性能差异可控
静止时显著降频
图标对象池化
RenderTexture 分辨率合理
```
