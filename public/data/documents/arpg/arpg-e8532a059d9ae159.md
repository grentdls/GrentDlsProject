```text
拖入 Prefab
修改 Inspector
直接看到路径/范围/朝向
点击测试按钮预览
不需要写代码
```

## 11. 校验窗口

菜单：

```text
Tools / Game / Level Gameplay Validator
```

检查：

```text
重复 ID
空目标引用
传送目标不存在
SpawnPointId 重复
交互范围为空
门终点与起点相同
移动平台路径点不足
宝箱无 LootTable
可破坏物无 Collider
陷阱无伤害范围
石柱无倒塌方向
开关目标不存在
```

## 12. Prefab Variant

```text
PF_Door_Base
├── PF_Door_Wood_Small
├── PF_Door_Stone_Large
└── PF_Door_Mechanical

PF_Chest_Base
├── PF_Chest_Common
├── PF_Chest_Rare
├── PF_Chest_Legendary
└── PF_Chest_Cursed
```

共享逻辑，只替换视觉和配置。

## 13. 关卡制作流程

```text
选择玩法 Prefab
→ 拖入场景
→ 设置唯一 ID
→ 调整视觉
→ 调整交互/触发范围
→ 配置动作
→ 查看 Gizmo
→ 点击 Validate
→ 运行测试
```
