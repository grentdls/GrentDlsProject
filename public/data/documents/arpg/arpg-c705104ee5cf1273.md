# 153 动画融合与打断规则：融入融出、取消窗口、优先级

## 1. 通用融合字段

```json
{
  "fadeIn": 0.08,
  "fadeOut": 0.12,
  "minPlayTime": 0.0,
  "canBeInterrupted": true,
  "interruptPriority": 30,
  "exitPriority": 20
}
```

## 2. 推荐融合时间

| 动画类型 | fadeIn | fadeOut |
|---|---:|---:|
| Idle | 0.15 | 0.15 |
| Move | 0.10 | 0.12 |
| JumpStart | 0.04 | 0.06 |
| FallLoop | 0.08 | 0.08 |
| LandLight | 0.03 | 0.10 |
| LandHeavy | 0.04 | 0.14 |
| LightAttack | 0.04 | 0.10 |
| HeavyAttack | 0.05 | 0.16 |
| SkillCast | 0.06 | 0.12 |
| HitLight | 0.03 | 0.08 |
| HitHeavy | 0.02 | 0.12 |
| Knockdown | 0.04 | 0.15 |
| Death | 0.02 | 0.00 |
| BoundLoop | 0.10 | 0.12 |

## 4. 技能取消窗口

```json
{
  "cancelWindows": [
    {
      "startFrame": 22,
      "endFrame": 36,
      "allowCancelTo": ["Dodge", "Move"],
      "consumeResource": false
    },
    {
      "startFrame": 18,
      "endFrame": 28,
      "allowCancelTo": ["ComboNext"],
      "nextTimeline": "TL_Warrior_Slash_02"
    }
  ]
}
```

## 5. 技能阶段锁定

```json
{
  "segmentName": "Startup",
  "lockInput": true,
  "lockMovement": true,
  "lockRotation": false,
  "superArmor": false
}
```

## 6. 验收标准

- 所有动画都有 fadeIn/fadeOut。
- 技能取消只能在配置窗口内发生。
- 受击不会随便打断霸体技能。
- 死亡能打断所有动画。
- 束缚状态不会被移动动画覆盖。
