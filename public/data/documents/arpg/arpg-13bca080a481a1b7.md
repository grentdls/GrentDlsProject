# 288 战斗打击感与受击反馈系统总览：命中反馈链与表现层级

## 1. 文档目标

本批文档用于完善 Unity 3D ACT ARPG 的整体打击感和战斗反馈，使一次攻击命中不再只是“扣血 + 跳字”，而是形成完整反馈链：

```text
攻击命中
→ 伤害与韧性结算
→ 判断受击等级
→ 中断或保留当前动作
→ 停止移动或限制移动
→ 选择受击动画
→ 处理面向
→ 闪白/材质反馈
→ 命中停顿
→ 击退/浮空/击倒
→ 特效、音效、镜头
→ HUD 与伤害跳字
→ AI 仇恨与战斗状态
→ 恢复行为或进入死亡
```

系统需要与之前已有内容接入：

```text
地面普攻与空中普攻
上跃技能
投射物轨迹
敌人 AI 警戒
敌人血条
伤害跳字
破甲、破盾、破韧
控制与异常状态
Boss/精英/普通敌人
可破坏场景物
```

---

## 2. 打击感的组成

打击感不是单一“震屏”或“闪白”，而是以下维度共同作用：

```text
时间反馈：命中停顿、慢动作、动画节奏
空间反馈：击退、浮空、倒地、位移
视觉反馈：闪白、火花、受击特效、残影
声音反馈：武器命中音、材质音、重击低频
镜头反馈：震动、冲击、轻微拉近
动画反馈：受击姿势、身体部位、方向
数值反馈：跳字、暴击、破盾、破韧提示
操作反馈：取消窗口、连段确认、资源增长
敌人反馈：停止移动、AI 中断、目标切换
```

## 3. 命中事件管线

推荐统一使用：

```text
HitRequest
→ HitResolver
→ DamageResolver
→ PoiseResolver
→ ReactionResolver
→ MotionResolver
→ FeedbackResolver
→ CombatEventDispatcher
```

### 3.1 HitRequest

包含：

```text
攻击者
受击者
技能 ID
攻击段 ID
命中点
命中方向
命中骨骼
伤害类型
攻击强度
破韧值
击退值
浮空值
命中标签
```

### 3.2 ReactionResolver

根据数据决定：

```text
无明显硬直
轻受击
中受击
重受击
破韧
击退
浮空
击飞
击倒
倒地追加
死亡
```

### 3.3 FeedbackResolver

负责：

```text
闪白
顿帧
镜头震动
命中特效
音效
伤害跳字
控制器震动
```

## 4. 受击等级

统一受击级别：

| 级别 | 名称 | 常见来源 | 主要表现 |
|---|---|---|---|
| 0 | 无硬直 | DOT、弱小持续伤害 | 只闪光或跳字 |
| 1 | 轻受击 | 普攻前段、小投射物 | 小幅停步、轻受击 |
| 2 | 中受击 | 普攻后段、普通技能 | 明显硬直、小击退 |
| 3 | 重受击 | 重击、蓄力、爆炸 | 强硬直、明显击退 |
| 4 | 破韧 | 韧性归零 | 专属破韧动画 |
| 5 | 浮空/击飞 | 上跃、爆发技能 | 进入空中受击 |
| 6 | 击倒 | 重锤、冲撞、处决 | 倒地与起身 |
| 7 | 死亡 | 生命归零 | 死亡类型选择 |

## 5. 普通敌人与 Boss 的差异

### 普通敌人

允许完整反馈：

```text
轻受击
重受击
击退
浮空
击飞
击倒
连续空中追击
```

### 精英敌人

```text
轻攻击可能只播放叠加层
中重攻击才中断动作
浮空效果降低
击退距离降低
破韧后完整硬直
```

### Boss

```text
普通命中只反馈闪白、特效和轻微动画
不因每次攻击中断技能
破韧后才播放完整受击和倒地
部分攻击阶段拥有霸体
浮空转化为韧性伤害
击退转化为位移抗性结算
```

## 6. 动作中断原则

不是所有受击都强制打断敌人。

判断依据：

```text
受击等级
敌人当前动作抗打断等级
当前韧性
是否霸体
是否处于不可中断阶段
攻击是否带强制中断标签
```

公式概念：

```text
攻击中断强度 >= 当前动作抗打断等级
→ 中断动作
```

---

## 7. 移动停止原则

敌人在正常移动、巡逻、追击中受到有效硬直攻击：

```text
停止 NavMeshAgent / 移动输入
清空当前移动速度或快速衰减
进入受击状态
播放受击动画
受击结束后重新请求路径
```

如果为无硬直伤害：

```text
不停止移动
只播放轻微叠加反馈
```

---

## 8. 反馈优先级

同一帧收到多个命中时：

```text
死亡
> 击倒
> 破韧
> 浮空/击飞
> 重受击
> 中受击
> 轻受击
> 无硬直
```

低级反应不能覆盖高级反应。

---

## 9. 同一目标高频命中

多段攻击需要避免受击动画疯狂重播。

支持：

```text
受击动画最短保护时间
同技能同段命中合并
轻受击冷却
重受击可打断轻受击
破韧强制覆盖
```
