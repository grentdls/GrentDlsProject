# 179 天赋系统词条接入规则：通用节点、关键节点、职业专精

## 1. 天赋分层

```text
小节点：基础数值
中节点：组合数值
大型节点：明确方向
关键节点：改变规则
职业专精：强化职业玩法
```

## 2. 通用小节点

```text
物理伤害 +8%
火焰伤害 +8%
护盾上限 +6%
生命上限 +5%
暴击率 +3%
召唤物伤害 +10%
投射物速度 +8%
控制持续时间 +6%
```

## 3. 中型节点

```text
击中被控制敌人时，恢复 2 点能量。
投射物穿透 1 个敌人。
击杀敌人时恢复 2% 最大生命。
召唤物击中时有 10% 概率施加中毒。
护盾开始回复速度 +25%。
```

## 4. 大型节点

```text
破甲打击：你的重击技能额外穿透 20% 护甲。
寒霜掌控：冻结敌人时，获得 3 秒护盾回复加速。
雷暴连锁：闪电技能暴击时，释放一次额外连锁电弧。
亡者军势：召唤物上限 +2，但召唤物持续时间 -20%。
爆裂收割：击杀敌人时有 20% 概率产生爆炸。
```

## 5. 关键节点

真伤节点：

```text
你的暴击不再造成额外伤害。
你的暴击会造成等同于原暴击额外伤害 35% 的真实伤害。
```

护盾节点：

```text
生命回复不再生效。
你的所有生命回复改为护盾回复，护盾上限提高 25%。
```

投射物节点：

```text
你的投射物不能连锁。
你的投射物命中时必定分裂一次。
```

召唤节点：

```text
你不能直接造成伤害。
召唤物造成的伤害提高 60%，并继承你 30% 的暴击率。
```

## 6. 职业专精方向

战士：

```text
重击穿甲
破韧增伤
受击获得怒气
低血吸血增强
```

游侠：

```text
投射物数量
投射物分裂
远距离增伤
暴击触发连锁
```

法师：

```text
元素穿透
异常效果
护盾回复
引导技能强化
```

亡魂女巫：

```text
击杀召唤
召唤物死亡爆炸
召唤物继承属性
诅咒扩散
```
