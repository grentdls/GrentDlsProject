# 227 特殊投射物轨迹：返回、环绕、地面爬行、天降、多阶段

## 1. 返回投射物

触发返回：

```text
达到最大距离、命中目标、时间结束、玩家再次按键、击杀目标
```

返回目标：

```text
施法者当前位置、手部挂点、原始出生点、指定召回点
```

```json
{
  "return": {
    "enable": true,
    "trigger": "MaxDistance",
    "returnTarget": "CasterCurrentPosition",
    "returnSpeedMultiplier": 1.3,
    "canHitOnReturn": true,
    "sameTargetHitLimit": 2
  }
}
```

## 2. 回旋镖

圆弧出射和圆弧返回，配置：

```text
最大距离、侧向偏移、回旋半径、返回速度、穿透、回程命中
```

## 3. 环绕投射物

可围绕：

```text
施法者、目标、召唤物、场景中心、移动路径中心
```

结束行为：

```text
射出、爆炸、分裂、消失、继续环绕
```

## 4. 环绕后逐个射出

```text
生成 6 把飞剑
→ 围绕玩家旋转 2 秒
→ 每 0.3 秒射出 1 把
```

## 5. 地面爬行弹

```text
贴地移动、沿坡度旋转、跨小台阶、遇墙爆炸或转向
```

```json
{
  "groundFollow": {
    "enable": true,
    "groundRayLength": 2.0,
    "heightOffset": 0.15,
    "maxSlope": 45,
    "stepHeight": 0.4,
    "wallMode": "Explode"
  }
}
```

适合地刺波、火焰裂隙、雷蛇和毒液爬行。

## 6. 天降投射物

```text
目标点预警 → 高空生成 → 垂直/斜向落下 → 爆炸
```

适合陨石、雷击、箭雨、冰锥雨和炮击。

## 7. 闪现投射物

```text
飞行 → 消失 → 前方出现 → 再飞行
```

适合暗影飞刀、虚空弹和特殊 Boss 技能。

## 8. 多阶段轨迹

示例：

```text
阶段1：直线起飞 0.3 秒
阶段2：螺旋跟踪 0.8 秒
阶段3：接近目标后直线冲刺 0.2 秒
阶段4：命中爆炸
```

阶段切换条件：

```text
时间、距离、命中、目标丢失、玩家输入、达到最高点
碰撞地面、技能 Timeline 事件、充能层数
```

## 9. 蜂群飞弹

群体参数：

```text
群体中心、个体偏移、分离力、聚合力、随机摆动
目标均摊、统一目标、同步到达、编队变换
```

## 10. 词条接入

```text
返回投射物伤害 +30%
环绕飞剑数量 +2
地面投射物宽度 +20%
天降投射物落点数量 +1
多阶段飞弹终点冲刺伤害提高
```
