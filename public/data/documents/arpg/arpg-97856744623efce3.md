# 120_挑战副本敌人与玩法：波次、限时、防守、追猎

> 目标：让挑战副本承担“检验BD强度”和“提供额外刷取目标”的功能。挑战副本奖励不应完全替代主线/终局刷图，而是提供挑战币、称号进度、定向装备箱和战斗训练价值。

## 3. CHALL_002 灰烬试炼场

### 玩法

限时 6 分钟清掉 4 个火焰祭坛。每个祭坛都有不同怪物组合。时间越短奖励越高。

| 祭坛 | 怪物 | 机制 |
|---|---|---|
| 东祭坛 | 火裔兵 + 油桶投手 | 地面燃烧 |
| 西祭坛 | 灰烬兽 + 灰雾祭司 | 火盾回血 |
| 南祭坛 | 熔岩巨壳 | 重型怪挡路 |
| 北祭坛 | 炎爆巫师 x3 | 可打断炎爆 |

### 掉落

- 火系材料
- 火抗符石
- 称号进度：灰烬挑战者
- SS 概率掉落：赤焰试炼徽章

## 4. CHALL_003 断桥守卫战

### 玩法

保护断桥工程师 5 分钟，工程师修桥期间怪物从 3 条路进攻。玩家需要优先击杀远程和爆炸怪。

| 路线 | 怪物特点 | 防守建议 |
|---|---|---|
| 左路 | 小怪多 | AOE清理 |
| 中路 | 重型怪 | 控制/破甲 |
| 右路 | 远程/爆炸 | 优先打断 |

### 失败条件

- 工程师死亡。
- 玩家死亡次数超过限制，困难难度。

### 掉落

- 防御装备箱
- 金币
- 盾牌/重甲基底概率提升
- 守卫战奖章

## 5. CHALL_004 暗影追猎

### 玩法

移动 Boss “暗影逃犯”会沿地图路线逃跑，玩家需要追击并在 8 分钟内击杀。Boss 每损失 25% 生命就会逃到下一区域并召唤伏击怪。

| 阶段 | Boss行为 | 召唤怪 |
|---|---|---|
| 100%-75% | 短距瞬移，飞刀 | 毒刃刺客 |
| 75%-50% | 烟雾致盲，陷阱 | 赝品术士 |
| 50%-25% | 分身干扰 | 裂隙幽影 |
| 25%-0% | 连续逃跑，低血狂暴 | 混合追猎怪 |

### 掉落

- 移动技能强化材料
- 暗影追猎币
- 暴击/移动词条装备
- SS 概率：暗影步伐符片

## 6. CHALL_005 星门裂隙

### 玩法

高压精英连战。玩家选择 3 个裂隙词缀，然后进入 5 房间连战。每个房间至少 1 个精英。

| 房间 | 怪物组合 | 压力 |
|---|---|---|
| 1 | 星界兽 + 残域游魂 + 精英 | 入门压力 |
| 2 | 重力异常体 + 漂浮魔像 | 控制场地 |
| 3 | 禁卷召唤师 + 书灵群 | 召唤滚雪球 |
| 4 | 双精英 + 随机词缀 | 高压爆发 |
| 5 | 钥石守卫 | 小Boss |

### 掉落

- 终局地图钥石
- 星尘
- 地图词缀材料
- 高阶稀有装备

实现文件：

- `Assets/_Game/Resources/GameData/dungeon_teleports.json`：挑战入口指向独立挑战 MapId，避免覆盖主线地图。
- `Assets/_Game/Resources/GameData/scene_maps.json`：新增 5 张 Challenge 地图配置。
- `Assets/_Game/Resources/GameData/map_events.json`：落地波次、限时、防守、追猎、精英连战事件。
- `Assets/_Game/Resources/GameData/spawn_groups.json`、`encounter_areas.json`、`map_objectives.json`：落地刷怪组、遭遇区、完成目标。
- `Assets/_Game/Resources/GameData/drop_tables.json`、`dungeon_loot_pools.json`、`equipment_drop_pools.json`：落地评分宝箱、挑战币、定向装备箱和终局钥石奖励。
- `Assets/_Game/Resources/GameData/monsters.json`、`monster_pools.json`：新增断桥守卫战敌人和暗影逃犯，并补全挑战专用怪物池。

运行时注意：

- 传送窗口会通过 `DungeonRunRequest` 记录玩家选择的副本 MapId，复用同一 Scene 时仍会加载正确的挑战地图配置。
- 挑战事件使用 `MapEventRuntimeController` 触发，遭遇区清理通过 `MapObjectiveTracker` 结算。
