# 203 装备随机生成流程：掉落、词条抽取、数值浮动、权重

## 1. 装备掉落生成总流程

```text
击杀怪物 / 开宝箱 / 完成副本
→ 计算掉落数量
→ 选择装备大类
→ 选择装备部位
→ 选择基底
→ 选择物品等级
→ 选择稀有度
→ 生成固定属性
→ 生成随机词条数量
→ 抽取前缀/后缀
→ 抽取词条 Tier
→ Roll 数值
→ 应用地图/副本掉落倾斜
→ 生成最终装备实例
```

---

## 3. 稀有度抽取

```json
{
  "rarityWeights": [
    {"rarity": "Normal", "weight": 500},
    {"rarity": "Magic", "weight": 300},
    {"rarity": "Rare", "weight": 170},
    {"rarity": "Set", "weight": 25},
    {"rarity": "Unique", "weight": 5}
  ]
}
```

可被影响：
```text
副本难度
怪物稀有度
地图词缀
掉落倍率
Boss 首杀
玩家幸运值
```

---

## 4. 词条数量抽取

魔法：
```text
1词条：60%
2词条：40%
```

稀有：
```text
3词条：60%
4词条：30%
5词条：10%
```

套装：
```text
2词条：50%
3词条：35%
4词条：15%
```

---

## 5. 前缀/后缀分配

稀有装备最多：
```text
3 前缀
3 后缀
第一版总数最多 5
```

分配示例：
```text
3词条：2前1后 / 1前2后
4词条：2前2后 / 3前1后 / 1前3后
5词条：3前2后 / 2前3后
```

---

## 6. 词条抽取权重

词条权重由以下因素影响：

```text
装备部位
装备类型
物品等级
副本标签
怪物标签
地图词缀
套装ID
玩家掉落倾斜
```

示例：
```text
火焰副本中，火焰词条权重 +50%
召唤副本中，召唤物词条权重 +40%
破盾 Boss 掉落破盾词条权重 +60%
```

---

## 7. 数值浮动

每条词条有范围。

```json
{
  "affixId": "AFF_Life_T3",
  "min": 65,
  "max": 85
}
```

掉落时 Roll：
```text
value = random(min, max)
```

极品装备追求：
```text
词条对
词条 Tier
数值 Roll
套装件
基底品质
```

---

## 8. 词条互斥检查

抽词条后必须检查：
```text
不能重复同组词条
不能出现互斥机制
不能超过部位限制
不能超过前后缀限制
```

例：
```text
无法暴击
不能和
暴击率 +20%
同时出现
```

---

## 9. 掉落倾斜

副本可以倾斜掉落：
```text
火焰副本：火焰词条权重提高
亡灵副本：召唤/诅咒装备权重提高
护盾 Boss：破盾词条和护盾装备权重提高
弓手营地：投射物词条权重提高
```

---

## 10. 验收标准

- 同一件装备掉落时属性随机。
- 稀有度影响词条数量。
- 物品等级影响词条 Tier。
- 副本能倾斜特定词条。
- 互斥词条不会同时出现。
