# 怪物、AI、Boss、精英词缀系统

---

## 1. 怪物系统目标

刷宝 ARPG 的怪物不是越多越好，而是要形成节奏：

```text
小怪提供割草快感
精英提供短期压力
地图机制提供爆发密度
Boss 提供动作挑战和记忆点
```

---

## 2. 怪物分类

| 类型 | 作用 |
|---|---|
| 小怪 | 大量出现，提供清图爽感和掉落基础 |
| 中型怪 | 有明显技能，打断玩家节奏 |
| 精英怪 | 带词缀，有更高掉落 |
| 稀有怪 | 多词缀，接近小 Boss |
| 地图 Boss | 地图完成目标 |
| 机制 Boss | 地图机制专属 Boss |
| Pinnacle Boss | 终局挑战 |

## 6. 小怪行为模板

### 6.1 近战追击怪

```text
发现玩家 → 追击 → 到攻击距离 → 普攻 → 后摇 → 重新追击
```

参数：

```text
AttackRange = 1.8
AttackCooldown = 1.2
TurnSpeed = 360
HitStunResistance = Low
```

### 6.2 远程怪

```text
发现玩家 → 保持距离 → 射击 → 玩家靠近则后撤 → 继续射击
```

参数：

```text
PreferredRange = 10
RetreatRange = 5
ProjectileSpeed = 18
```

### 6.3 自爆怪

```text
发现玩家 → 高速靠近 → 进入范围 → 读条爆炸 → 死亡
```

要点：

- 必须有明显音效。
- 必须有爆炸范围提示。
- 不能无提示秒杀。

## 7. 精英词缀

### 7.1 精英词缀规则

| 怪物类型 | 词缀数量 |
|---|---:|
| Magic | 1 |
| Rare | 2~4 |
| Map Boss | 0~3，来自地图词缀 |
| Pinnacle Boss | 固定机制，不随机词缀 |

### 7.2 精英词缀示例

| 词缀 | 效果 |
|---|---|
| 燃烧之血 | 受到攻击时在脚下生成火焰地面 |
| 冰壳 | 每 8 秒获得冰盾，破盾时爆发冰环 |
| 雷脉 | 周期性向周围发射闪电链 |
| 召唤者 | 周期性召唤小怪 |
| 迅捷 | 移动和攻击速度提高 |
| 厚皮 | 生命和护甲提高 |
| 反伤壳 | 短时间反弹部分击中伤害，有明显护罩提示 |
| 吸血 | 命中玩家回复生命 |
| 腐蚀光环 | 周围玩家持续受到混沌伤害 |
| 分裂 | 死亡后分裂成多个小怪 |

## 8. Boss 设计原则

Boss 不应该只是高血量怪，而要有动作阶段。

### 8.1 Boss 结构

```text
BossRoot
  BossController
  BossStateMachine
  BossPhaseController
  BossSkillController
  BossWeakPointController
  BossArenaController
  BossHealthBarBinder
  ModelRoot
  Hitboxes
  Hurtboxes
  Telegraphs
  VFX
  Audio
```

### 8.2 Boss 技能结构

每个技能必须有：

```text
SkillId
WarningTime
CastTime
ActiveTime
RecoveryTime
HitboxData
DodgeWindow
Blockable
Interruptible
PhaseCondition
```

## 9. Boss 阶段设计模板

### 阶段 1：教学阶段

- 技能少。
- 出招慢。
- 让玩家理解 Boss 核心攻击方式。

### 阶段 2：组合阶段

- 技能组合。
- 场地开始变化。
- 出现小怪/机关。

### 阶段 3：压迫阶段

- Boss 攻速变快。
- 场地安全区减少。
- 需要玩家掌握闪避和输出窗口。

## 10. 示例 Boss：星核巨像

### 基础设定

- 地图：星核矿脉机制 Boss。
- 体型：大型机械巨人。
- 核心玩法：攻击手臂弱点，暴露胸口核心。

### 技能列表

| 技能 | 表现 | 应对 |
|---|---|---|
| 地裂拳 | 砸地生成前方裂纹 | 横向闪避 |
| 核心激光 | 胸口蓄力直线激光 | 躲到柱子后 |
| 矿刺喷发 | 地面多个圆圈延迟爆炸 | 观察安全区 |
| 召唤无人机 | 召唤小机器人修复 Boss | 优先击杀 |
| 过载震荡 | 全场冲击波，需要跳/翻滚时机 | 精准闪避 |

### 阶段

```text
100%~70%：只用拳击和矿刺
70%~35%：加入激光和无人机
35%~0%：场地柱子减少，技能连发，核心弱点暴露时间缩短
```

## 11. 怪物掉落规则

| 来源 | 掉落特点 |
|---|---|
| 小怪 | 基础装备、金币、小材料 |
| 精英 | 稀有装备、地图钥石、打造材料 |
| 地图 Boss | 高物品等级装备、地图进度、Boss 材料 |
| 机制 Boss | 机制专属装备和材料 |
| Pinnacle Boss | 专属 Relic、特殊打造核心、天赋点 |

---

## 12. 验收标准

- 小怪群能被玩家快速清理，有爽感。
- 精英怪能逼玩家走位，但不能靠无提示秒杀。
- Boss 每个技能都能通过动画/音效/地面提示读出来。
- Boss 必须有输出窗口和惩罚窗口。
- 怪物词缀与地图词缀叠加后仍然可读。
