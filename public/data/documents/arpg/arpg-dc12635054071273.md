# 19_商店系统设计：NPC商人、铁匠、技能商人、功能商人

> 目标：定义所有商店和功能 NPC 的系统，包括普通商店、铁匠铺、技能商人、药剂商、地图商人、赛季商人、仓库、鉴定、分解、打造、购买和出售。

---

## 1. 商店系统总览

商店系统不是单一买卖窗口，而是一组 NPC 服务系统。

| 服务类型 | NPC 示例 | 功能 |
|---|---|---|
| GeneralShop | 普通商人 | 买卖基础装备、药剂、回城卷轴 |
| Blacksmith | 铁匠 | 分解、强化、打造、修理、重铸 |
| SkillMerchant | 技能商人 | 购买技能核心、辅助模块、技能重置 |
| PotionVendor | 药剂师 | 药剂购买、升级、洗药剂词条 |
| RuneVendor | 符文商 | 购买符文、宝石、镶嵌材料 |
| MapVendor | 地图商人 | 购买地图石、地图改造材料 |
| GamblingVendor | 珍品商人 | 随机装备赌博 |
| StashService | 仓库管理员 | 存储、搜索、整理 |
| IdentifyService | 鉴定师 | 鉴定未知装备 |
| RespecService | 重置导师 | 重置技能点、天赋点 |

## 3. 普通商店

### 3.1 功能

普通商店提供：

- 购买基础武器。
- 购买基础防具。
- 购买药剂。
- 购买回城卷轴。
- 出售玩家物品。
- 回购最近卖出的物品。

### 3.2 商品分类

| 分类 | 内容 | 刷新规则 |
|---|---|---|
| 武器 | 当前等级附近的普通/魔法武器 | 每次玩家升级刷新 |
| 防具 | 当前等级附近的普通/魔法防具 | 每次玩家升级刷新 |
| 药剂 | 生命/能量/功能药剂 | 固定库存 |
| 消耗品 | 回城卷轴、鉴定卷轴 | 固定库存 |
| 材料 | 低级打造材料 | 主线进度解锁 |

## 4. 铁匠铺系统

铁匠是装备循环的核心。

### 4.1 铁匠功能列表

| 功能 | 说明 | 解锁时机 |
|---|---|---|
| 分解 | 装备转化为材料 | 第一章 |
| 强化 | 提升装备基础数值 | 第一章 |
| 修理 | 修复耐久，若项目有耐久系统 | 可选 |
| 重铸 | 随机重置装备词条 | 第二章 |
| 定向改造 | 锁定某一类词条进行改造 | 第四章 |
| 镶嵌孔 | 添加/调整宝石孔 | 第三章 |
| 品质提升 | 提升装备品质等级 | 第二章 |
| 词条封存 | 保存一个词条用于后续打造 | 终局 |
| 批量分解 | 一键分解低稀有装备 | 第四章 |

### 4.3 分解规则

输入：装备。

输出：材料。

| 装备稀有度 | 分解产物 |
|---|---|
| 普通 | 基础碎片 |
| 魔法 | 基础碎片 + 魔法粉尘 |
| 稀有 | 稀有碎片 + 词缀粉尘 |
| 传奇 | 传奇残片 + 特殊材料 |

分解流程：

```text
玩家放入装备
  ↓
显示分解预览
  ↓
确认
  ↓
移除装备
  ↓
生成材料
  ↓
播放分解特效
```

### 4.4 强化规则

强化目标：

- 武器基础攻击。
- 防具基础护甲。
- 饰品基础效果。

强化等级：+1 到 +10。

| 强化等级 | 消耗 | 失败处理 |
|---:|---|---|
| +1 到 +3 | 基础材料 | 必定成功 |
| +4 到 +6 | 中级材料 | 失败不降级 |
| +7 到 +9 | 高级材料 | 失败可能降 1 级 |
| +10 | 稀有材料 | 失败保持但消耗材料 |

### 4.5 重铸规则

重铸分类：

| 类型 | 效果 |
|---|---|
| 全词条重铸 | 所有随机词条重新生成 |
| 前缀重铸 | 只重置前缀 |
| 后缀重铸 | 只重置后缀 |
| 数值重掷 | 词条不变，数值重掷 |
| 定向元素 | 更高概率出现某元素词条 |
| 定向防御 | 更高概率出现防御词条 |

## 5. 技能商人系统

技能商人提供技能核心、辅助模块和技能调整。

### 5.1 技能商品分类

| 分类 | 内容 |
|---|---|
| 主动技能核心 | 火球、旋斩、箭雨等原创技能核心 |
| 辅助模块 | 多重、穿透、连锁、延迟、增幅等 |
| 光环技能 | 持续开关型技能 |
| 位移技能 | 闪现、冲刺、跃击等 |
| 召唤技能 | 召唤物核心 |
| 技能升级材料 | 技能经验、突破材料 |
| 重置服务 | 重置技能点或技能连接 |

### 5.2 技能购买规则

- 初始只出售基础技能。
- 每章通关解锁一批新技能。
- 技能根据职业、属性、等级显示推荐。
- 不强制职业限定，但有属性需求。
- 高级辅助模块需要完成试炼或终局掉落解锁。

## 6. 功能商人

### 6.1 药剂师

功能：

- 购买药剂。
- 升级药剂容量。
- 改造药剂词条。
- 给药剂添加条件触发效果。

药剂词条示例：

- 低血量时回复量增加。
- 使用后短时间加速。
- 移除流血。
- 移除中毒。
- 使用后获得短暂护盾。

### 6.2 符文商

功能：

- 购买低阶符文。
- 合成高阶符文。
- 镶嵌符文。
- 拆除符文。

### 6.3 地图商人

终局解锁后出现。

功能：

- 出售低阶地图石。
- 出售地图改造材料。
- 回收低阶地图。
- 提供每日地图任务。

### 6.4 珍品商人

赌博商店。

规则：

- 商品只显示基底和部位，不显示具体词条。
- 购买后随机生成稀有度和词条。
- 消耗特殊金币或赌博券。
- 可以作为金币回收系统。

## 7. 商店库存生成

### 7.1 库存生成流程

```text
打开商店
  ↓
读取 ShopData
  ↓
根据玩家等级和章节进度计算 ItemLevel
  ↓
按分类生成商品
  ↓
应用 NPC 特殊权重
  ↓
保存本轮库存
  ↓
显示 UI
```

### 7.2 商品字段

```text
ShopItemData
├── ShopItemId
├── ItemId
├── ItemLevel
├── Rarity
├── Price
├── CurrencyType
├── StockCount
├── IsLimited
├── UnlockCondition
├── RefreshGroup
└── Weight
```

### 7.3 价格公式

```text
价格 = 基础价格 × 物品等级系数 × 稀有度系数 × 商人倍率 × 折扣倍率
```

示例系数：

| 稀有度 | 价格系数 |
|---|---:|
| 普通 | 1.0 |
| 魔法 | 2.5 |
| 稀有 | 8.0 |
| 传奇 | 不在普通商店出售 |

## 8. 出售与回购

玩家出售物品流程：

```text
右键背包物品
  ↓
进入出售预览
  ↓
显示金币/材料回收价
  ↓
确认出售
  ↓
物品进入 BuyBack 列表
```

回购规则：

- 最近 20 件出售物品进入回购列表。
- 离开游戏后回购列表清空，或保存当前主城会话。
- 回购价格可等于出售价格，也可略高。

## 10. 商店系统验收标准

- [ ] NPC 能打开正确商店。
- [ ] 商品显示图标、价格、库存、需求。
- [ ] 玩家金币不足时不能购买。
- [ ] 背包满时不能购买装备。
- [ ] 出售后金币增加。
- [ ] 回购功能可用。
- [ ] 铁匠分解消耗装备并生成材料。
- [ ] 强化能正确修改装备数据。
- [ ] 技能商人购买后技能进入玩家技能库。
- [ ] 商店库存能按等级和章节刷新。
- [ ] 所有商店 UI 可以关闭并恢复操作。
