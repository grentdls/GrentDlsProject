# 198 装备部位基础数值定位：武器、防具、首饰、副手

## 1. 部位定位总表

| 部位 | 主定位 | 副定位 | 主要属性 |
|---|---|---|---|
| 主武器 | 输出核心 | 流派入口 | 伤害、攻速、暴击、穿甲、元素 |
| 副手 | 防御/辅助/双持 | 战斗风格 | 格挡、法术、投射物、双持 |
| 头盔 | 技能/召唤/控制 | 视野、异常 | 技能等级、召唤、控制抗性 |
| 胸甲 | 主防御 | 承伤规则 | 生命、护甲、护盾、减伤 |
| 手套 | 击中/攻速 | 异常施加 | 攻速、击中、暴击、异常 |
| 鞋子 | 机动 | 抗减速 | 移速、闪避、冰缓/减速抗性 |
| 腰带 | 药剂/资源 | 生存补强 | 药剂、生命、资源回复 |
| 戒指 | 抗性/元素 | 触发词条 | 抗性、元素、击杀、击中 |
| 项链 | 构筑核心 | 技能等级 | 属性、技能等级、关键机制 |

## 2. 主武器定位

主武器决定主要输出方式。

### 2.1 近战武器
基础属性：
```text
基础物理伤害
攻击速度
基础暴击率
攻击距离
破韧倍率
```

可出现词条：
```text
物理伤害
穿甲
重击伤害
流血
击中吸血
暴击伤害
连击层数
近距离增伤
```

### 2.2 弓弩武器
基础属性：
```text
基础物理伤害
攻击速度
基础暴击率
投射物速度
射程
```

可出现词条：
```text
投射物数量
投射物速度
投射物穿透
远距离增伤
暴击连锁
弱点标记
投射物分裂
```

### 2.3 法杖/法器
基础属性：
```text
法术强度
施法速度
基础暴击率
元素伤害
法力/护盾
```

可出现词条：
```text

异常效果
护盾转伤害
满盾增伤
法术暴击
引导层数
技能冷却
```

## 4. 防具定位

### 4.1 胸甲
胸甲是主防御件。

基础属性权重：
```text
生命：高
护甲：高
护盾：高
抗性：中
伤害词条：低
```

常见词条：
```text
最大生命
最大护盾
护甲提高
受到近战伤害降低
受击反伤
低血减伤
护盾破裂保护
```

### 4.2 头盔
头盔偏功能和技能。

基础属性权重：
```text
技能等级：中
控制抗性：中
召唤：中
生命/护盾：中
```

常见词条：
```text
某类技能等级 +1
召唤物数量
控制抗性
异常效果
冷却缩减
```

### 4.3 手套
手套是击中触发部位。

基础属性权重：
```text
攻速：高
施法速度：中
击中附伤：高
异常几率：高
```

常见词条：
```text
击中附加火焰伤害
击中有概率流血
暴击时恢复能量
召唤物击中施毒
攻击速度提高
```

### 4.4 鞋子
鞋子是机动部位。

基础属性权重：
```text
移动速度：高
闪避：中
减速抗性：高
冰缓抗性：中
位移技能：中
```

常见词条：
```text
移动速度 +20%
减速抗性 +30%
闪避后下次技能伤害提高
位移技能冷却缩短
远距离命中后获得加速
```

### 4.5 腰带
腰带是药剂和资源部位。

常见词条：
```text
药剂效果提高
药剂持续时间提高
药剂期间投射物 +1
生命提高
资源回复
受击获得怒气
```


### 5.2 项链
项链负责构筑核心。

常见词条：
```text
全部属性

异常效果

```

项链可以出现更强的机制词条，但数量应少。

## 6. 部位词条边界

为了避免所有装备都能刷一切，必须限制：

```text
投射物数量：主要出现在弓、箭袋、项链、特定套装
穿甲：主要出现在武器、手套、项链
生命：主要出现在胸甲、腰带、戒指
移动速度：主要出现在鞋子
药剂：主要出现在腰带
技能等级：主要出现在头盔、项链、法杖
格挡：主要出现在盾牌
召唤物数量：主要出现在头盔、项链、召唤套装
```

这样装备选择才有重量。
