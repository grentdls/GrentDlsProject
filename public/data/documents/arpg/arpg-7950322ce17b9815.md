# 17_Boss区域设计：房间结构、阶段触发、奖励出口

> 目标：定义 Boss 区域的搭建标准。Boss 房不是只放一个怪物，而是一套完整流程：进入、封门、开场、阶段变化、死亡、掉落、奖励、出口、复活重试。

---

## 1. Boss 区域基本流程

```text
Boss 前缓冲区
  ↓
Boss 门交互
  ↓
进入 Boss 房
  ↓
封门 + 开场演出
  ↓
Boss 激活
  ↓
阶段战斗
  ↓
Boss 死亡
  ↓
生成掉落 + 奖励宝箱
  ↓
打开出口门/传送门
  ↓
返回主城或进入下一章
```

### 3.2 Boss 门状态

| 状态 | 表现 | 说明 |
|---|---|---|
| Locked | 锁链/红光 | 前置任务未完成 |
| Ready | 高亮提示 | 可进入 |
| Opening | 播放开门动画 | 防止重复交互 |
| Sealed | 战斗中封闭 | 玩家不能逃离 |
| Cleared | 门打开/出口出现 | Boss 已击杀 |

## 4. Boss 房尺寸规范

| Boss 类型 | 建议尺寸 | 场地要求 |
|---|---:|---|
| 小型教学 Boss | 35m - 50m | 简单圆形场地 |
| 第一章 Boss | 60m - 75m | 少量柱子，可绕背 |
| 中型 Boss | 75m - 90m | 支持冲锋和范围技能 |
| 大型 Boss | 90m - 120m | 支持多阶段和召唤 |
| 巨型固定 Boss | 半圆 80m+ | Boss 在边缘，玩家在平台 |
| 多 Boss | 100m+ | 足够分散空间 |

## 5. Boss 战阶段系统

### 5.1 阶段触发条件

| 条件 | 说明 |
|---|---|
| HPPercent | 血量低于 75/50/25% |
| TimeElapsed | 战斗经过一定时间 |
| AddKilled | 召唤物被清掉 |
| ArenaObjectDestroyed | 场景目标被破坏 |
| PlayerEnterZone | 玩家进入指定区域 |
| BossSkillCompleted | Boss 放完大招后切阶段 |

## 6. 第一批 Boss 设计

### 6.1 滩涂爬行者首领

地图：坠星海岸。

用途：教学 Boss。

场地：45m 直径圆形浅滩。

技能：

| 技能 | 说明 | 目的 |
|---|---|---|
| 前爪挥击 | 近战扇形 | 教玩家后撤 |
| 泥浆喷吐 | 直线范围 | 教玩家横向闪避 |
| 召唤小虫 | 召唤 3 只小怪 | 教玩家清小怪 |
| 潜地突袭 | 延迟圆形提示 | 教玩家看地面预警 |

阶段：

- P1：普通攻击 + 泥浆喷吐。
- P2：50% 血量后加入召唤小虫。
- P3：25% 血量后加入潜地突袭。

奖励：第一件稀有装备、技能核心、回城功能解锁。

---

### 6.2 黑炉看守者

地图：黑炉深井。

场地：70m 直径，中央炉心，四周 4 个冷却柱。

技能：

| 技能 | 说明 | 场地关系 |
|---|---|---|
| 熔锤砸地 | 大范围圆形冲击 | 玩家需要离开中心 |
| 火线横扫 | 180 度横扫 | 玩家绕背或翻滚穿过 |
| 炉心过载 | 场地随机火圈 | 冷却柱附近安全 |
| 召唤炉工 | 召唤小怪修炉心 | 玩家需要清小怪 |
| 终焉锻击 | 三连延迟砸地 | Boss 低血量大招 |

阶段：

| 阶段 | 触发 | 变化 |
|---|---|---|
| P1 | 开战 | 近战 + 火线横扫 |
| P2 | 70% 血量 | 炉心过载，出现火圈 |
| P3 | 40% 血量 | 召唤炉工，攻击频率提高 |
| P4 | 15% 血量 | 终焉锻击，场地火圈增加 |

奖励：章节通关宝箱、第二章入口、打造材料。

---

### 6.3 腐根女巫

地图：腐根圣坛。

场地：80m 直径，周围毒池，4 个净化花。

机制：

- Boss 会给玩家叠毒。
- 玩家靠近净化花可清除毒层，但花有冷却。
- Boss 会召唤藤蔓束缚区域。

阶段：

- P1：毒箭、藤蔓刺。
- P2：召唤毒花，小范围毒雾。
- P3：净化花减少，Boss 进入狂暴。

---

### 6.4 日轮守墓人

地图：日轮墓室。

场地：90m 直径，周围有 8 根光束柱。

机制：

- 光束柱按顺序点亮。
- 玩家需要躲避旋转光束。
- Boss 在光束中获得减伤。

阶段：

- P1：近战连击。
- P2：光束柱启动。
- P3：Boss 碎裂成 3 个分身，需要找真身。

---

### 6.5 熔炉巨像

地图：黑雨熔炉。

场地：95m 直径，地上有熔岩沟和冷却阀。

机制：

- Boss 体型巨大，攻击慢但范围大。
- 冷却阀可短暂降低 Boss 护甲。
- 熔岩沟会周期喷发。

阶段：

- P1：慢速重击。
- P2：熔岩喷发。
- P3：Boss 破甲窗口出现，玩家集火。
- P4：全场高压，需要连续闪避。

---

### 6.6 无光裁决者

地图：无光核心。

场地：110m 直径，多平台裂隙场。

机制：

- 战斗分三块平台。
- Boss 会摧毁平台边缘。
- 玩家需要通过裂隙传送到安全平台。

阶段：

| 阶段 | 玩法 |
|---|---|
| P1 | 正常战斗，学习 Boss 技能 |
| P2 | 平台开始破碎，出现传送裂隙 |
| P3 | Boss 分身，玩家需要击破核心 |
| P4 | 最终阶段，场地缩小，技能密度提高 |

奖励：主线通关、终局 Atlas 解锁、第一枚地图石。

## 8. Boss 奖励系统

Boss 死亡后执行：

```text
BossDeath
  ↓
停止 Boss AI
  ↓
播放死亡动画
  ↓
清理场地危险区
  ↓
生成普通掉落
  ↓
生成 Boss 奖励宝箱
  ↓
掉落任务物品
  ↓
打开出口门
  ↓
保存 Boss 已击杀状态
```

奖励类型：

| Boss 类型 | 奖励 |
|---|---|
| 教学 Boss | 技能核心、基础稀有装备 |
| 章节 Boss | 稀有装备、打造材料、章节通关道具 |
| 支线 Boss | 特殊材料、随机装备 |
| 终局地图 Boss | 地图石、Atlas 材料、稀有装备 |
| 赛季 Boss | 赛季材料、特殊词条装备 |

## 9. Boss 复活与重试

玩家死亡后：

- 可选择在 Boss 房外复活。
- Boss 血量是否重置由地图类型决定。
- 主线 Boss 默认重置。
- 终局 Boss 默认不重置地图，但玩家死亡次数有限。
- 如果地图生命次数耗尽，地图关闭。

复活点：

```text
Spawn_BossRetry
```

必须放在 Boss 门外 10m 到 20m 的安全区。

## 10. Boss 房验收标准

- [ ] 进入 Boss 房后门会关闭。
- [ ] Boss 开场不会在玩家未准备时直接秒杀。
- [ ] 所有大招有清楚地面提示。
- [ ] 场地有足够闪避空间。
- [ ] 相机不会被 Boss 或墙体完全遮挡。
- [ ] Boss 不会卡墙或掉出场地。
- [ ] Boss 死亡后危险区清除。
- [ ] 奖励能正常生成。
- [ ] 出口门能打开。
- [ ] 死亡重试流程可用。
