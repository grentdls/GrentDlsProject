# 164 材质、皮肤、染色与装备外观覆盖规则：MaterialVariant

## 1. 目标

装备和模型不仅要能换 Mesh，还要能换材质、染色、显示稀有度效果、元素附魔效果和皮肤外观。

本系统支持：

- 默认材质
- 材质变体
- 染色通道
- 稀有度外观
- 附魔发光
- 皮肤覆盖
- 破损状态
- 受击闪白兼容
- LOD 材质切换

---

## 2. MaterialSetConfig

```json
{
  "materialSetId": "MatSet_IronChest_01",
  "materials": [
    {
      "slot": "Main",
      "material": "MAT_IronChest_Main",
      "supportsDye": true,
      "dyeChannels": ["Primary", "Secondary", "Metal"]
    },
    {
      "slot": "Leather",
      "material": "MAT_IronChest_Leather",
      "supportsDye": true,
      "dyeChannels": ["Leather"]
    }
  ]
}
```

---

## 3. 染色通道

推荐通道：

```text
Primary      主色
Secondary    副色
Metal        金属色
Leather      皮革色
Cloth        布料色
Glow         发光色
Trim         边饰色
```

染色配置：

```json
{
  "dyeConfig": {
    "Primary": "#3A4B5F",
    "Secondary": "#A88A4A",
    "Metal": "#C0C0C0",
    "Glow": "#4AA8FF"
  }
}
```

---

## 4. 稀有度外观

装备稀有度可以影响：
- 边缘高光
- 微弱粒子
- 材质发光
- UI 预览底光
- 不是所有装备都要在 3D 模型上强发光

```json
{
  "rarityVisual": {
    "Rare": {
      "rimLightColor": "#F5D15C",
      "rimLightIntensity": 0.15
    },
    "Legendary": {
      "rimLightColor": "#FF9B3D",
      "rimLightIntensity": 0.35,
      "ambientVfx": "VFX_Legendary_Glow_Subtle"
    }
  }
}
```

---

## 5. 附魔外观

武器或装备可有附魔效果：

```json
{
  "enchantVisual": {
    "element": "Fire",
    "weaponTrail": "VFX_Trail_Fire_01",
    "idleVfx": "VFX_Weapon_Fire_Idle",
    "hitVfxOverride": "VFX_Hit_Fire_Weapon"
  }
}
```

---

## 6. 皮肤覆盖规则

皮肤外观优先级：

```text
临时剧情外观 > 商城皮肤 > 装备外观 > 默认身体
```

示例：

```json
{
  "cosmeticOverride": {
    "slot": "Chest",
    "overrideVisualId": "COS_Chest_DragonArmor",
    "hideOriginalEquipment": true,
    "keepStatsFromItem": true
  }
}
```

说明：
- 皮肤只改外观，不改装备数值。
- 可设置是否显示原装备特效。
- UI 上需要提示“外观覆盖中”。

---

## 7. 受击闪白兼容

所有角色和装备材质必须支持受击参数：

```text
_HitFlashAmount
_HitFlashColor
_ElementTint
_ElementTintAmount
_DissolveAmount
_RimLightColor
_RimLightIntensity
```

如果某材质不支持：
- 编辑器校验警告
- 运行时使用 fallback 材质或跳过闪白

---

## 8. 验收标准

- 装备能应用不同材质。
- 装备能染色。
- 稀有度可以给装备增加弱外观效果。
- 附魔可以改变武器 Trail 和命中特效。
- 皮肤能覆盖装备外观但保留数值。
- 材质支持受击闪白。
