## 掉落倾斜规则

```text
副本标签会提高对应词条权重，但不保证必出。
Boss 首杀可提高套装部件掉落率。
终局地图可通过地图词缀改变掉落倾斜。
```

示例：

```json
{
  "dungeonId": "BlackForgePit",
  "dropBias": [
    {"tag": "Fire", "weightMore": 0.5},
    {"tag": "Explosion", "weightMore": 0.35},
    {"tag": "Armor", "weightMore": 0.25}
  ]
}
```
