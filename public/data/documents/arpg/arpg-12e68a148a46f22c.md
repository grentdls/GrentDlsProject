# Unity 工程架构与核心模块

---

## 1. 推荐 Unity 版本与基础包

推荐使用：

- Unity 2022 LTS / Unity 6 LTS。
- URP 或 HDRP。若目标是 PC 端优先，HDRP 画面上限更高；若要兼容移动端，URP 更稳。
- Input System。
- Addressables。
- Cinemachine。
- NavMeshComponents / A* Pathfinding Project。
- DOTween 或自研 Tween。
- Odin Inspector 可选。
- FMOD / Wwise 可选。

## 3. 程序模块划分

建议拆成 Assembly Definition：

```text
Game.Core
Game.Data
Game.Combat
Game.Character
Game.Items
Game.Skills
Game.MapSystem
Game.AI
Game.UI
Game.Save
Game.EditorTools
```

模块依赖方向：

```text
UI → Character / Items / Skills / MapSystem
Combat → Character / Skills / Items
Skills → Data / Combat
Items → Data
AI → Combat / Character
MapSystem → Data / Items / AI
Save → Character / Items / MapSystem
```

原则：

- Data 不依赖 Gameplay。
- UI 不直接改数据，通过 Controller / ViewModel。
- Combat 不直接访问 UI。
- 掉落物、怪物、技能、装备都由 ID 驱动。

## 5. 核心管理器

### 5.1 GameBootstrap

职责：

- 全局初始化。
- 防止重复实例。
- 控制场景加载顺序。
- 管理全局状态。

字段：

```text
bool IsInitialized
GameState CurrentState
PlayerProfile CurrentProfile
```

### 5.2 ConfigManager

职责：

- 加载所有 JSON / ScriptableObject。
- 建立 ID → 配置索引。
- 校验配置合法性。

必须支持：

- 技能配置。
- 装备基底配置。
- 词条配置。
- 怪物配置。
- 地图配置。
- 掉落表。
- UI 文本。

### 5.3 EventBus

所有跨系统事件必须走 EventBus。

常见事件：

```text
OnPlayerLevelUp
OnItemDropped
OnItemPicked
OnEquipmentChanged
OnSkillChanged
OnMapStarted
OnMapCompleted
OnMonsterKilled
OnBossPhaseChanged
OnInventoryChanged
OnCurrencyChanged
OnDamageDealt
OnDamageTaken
```

### 5.4 PoolManager

池化对象：

- 子弹。
- 技能特效。
- 飘字。
- 掉落物。
- 怪物。
- 音效实例。
- 地面范围提示。

## 9. 开发原则

1. **所有玩法数据表化**：不要把技能系数、词条范围、掉落权重写死在代码里。
2. **所有实例有唯一 GUID**：装备、地图钥石、角色存档都需要唯一 ID。
3. **所有数值可回放**：装备生成必须能通过 Seed 复现，方便调试掉落。
4. **先做手感，再做复杂度**：ACT 项目若移动、攻击、镜头不好，装备系统再复杂也撑不起来。
5. **UI 预制体模块化**：背包格子、词条行、技能槽、地图节点都要做成可复用小 Prefab。
