# 190 天赋关键节点与职业专精高级词条库：规则改写与代价

## 1. 关键节点设计原则

关键节点必须改变规则，不只是加数值。

必须包含：
- 明确收益
- 明确代价
- 明确流派方向
- UI 明确提示

## 2. 关键节点示例

### 血盾转换

```text
你的生命回复改为护盾回复。
最大生命降低 20%，最大护盾提高 40%。
```

### 分裂箭律

```text
你的投射物不能连锁。
你的投射物第一次命中时必定分裂。
分裂投射物伤害降低 35%。
```

### 真实暴击

```text
你的暴击不再造成额外伤害。
暴击时造成等同于原暴击额外伤害 35% 的真实伤害。
```

### 亡者契约

```text
你不能直接造成伤害。
召唤物伤害提高 80%，并继承你 30% 的暴击率。
```

### 破盾狂热

```text
你对护盾造成的伤害提高 50%。
你对无护盾敌人的伤害降低 15%。
破盾时获得 4 秒狂热。
```

## 3. 职业高级专精

### 战士
```text
重击穿甲
蓄力霸体
破韧处决
受击转怒气
低血吸血
```

### 游侠
```text
远距离暴击
投射物分裂
连锁箭
移动射击
弱点标记
```

### 法师
```text
满盾施法
元素暴露
引导聚能
护盾转伤害
异常扩散
```

### 女巫
```text
击杀召唤
召唤物死亡爆炸
诅咒扩散
召唤物继承
献祭召唤物
```

## 4. 天赋 UI 要求

必须显示：
- 规则改变
- 代价
- 当前构筑受影响技能
- 当前装备可触发词条
- 预计收益标签
