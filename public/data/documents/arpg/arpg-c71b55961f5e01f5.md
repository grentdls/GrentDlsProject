# 163 骨骼自动绑定与校正规则：BoneMapping / SkeletonResolver

## 1. 目标

运行时换装的关键是：装备 Mesh 的 bones 必须绑定到当前角色骨架。

本系统负责：
- 建立角色骨骼缓存
- 根据骨骼名匹配装备 bones
- 自动设置 SkinnedMeshRenderer.bones
- 自动设置 rootBone
- 处理缺失骨骼
- 处理缩放/姿态差异
- 输出校验日志

---

## 2. SkeletonResolver

### 2.1 职责

```text
SkeletonResolver
├── BuildBoneCache()
├── FindBone(name)
├── ResolveBones(sourceBones)
├── ResolveRootBone(rootBoneName)
├── ValidateRequiredBones()
└── ReportMissingBones()
```

### 2.2 骨骼缓存

```csharp
Dictionary<string, Transform> boneMap;
```

初始化：

```text
遍历 SkeletonRoot 所有 Transform
→ 用 bone.name 建立字典
→ 忽略大小写或使用标准化名称
→ 缓存结果
```

## 3. 骨骼匹配规则

### 3.1 完全匹配
优先按完全名称匹配：

```text
source: spine_03
target: spine_03
```

### 3.2 别名匹配
如果美术导出名不同，可配置别名：

```json
{
  "boneAliases": [
    {"source": "Bip001 Spine2", "target": "spine_03"},
    {"source": "Bip001 Head", "target": "head"},
    {"source": "mixamorig:RightHand", "target": "hand_r"}
  ]
}
```

### 3.3 失败处理
找不到骨骼时：
- 如果是必需骨骼：装备加载失败并提示。
- 如果是可选骨骼：使用最近父骨骼或 rootBone。
- 记录警告日志。
- 编辑器校验中标红。

## 5. 自动绑定流程

```text
BindSkinnedMesh(equipmentRenderer):
    sourceBones = equipmentRenderer.bones
    resolvedBones = []
    for sourceBone in sourceBones:
        normalizedName = Normalize(sourceBone.name)
        targetBone = characterSkeleton.FindBone(normalizedName)
        if not found:
            targetBone = ResolveFallback(sourceBone)
        resolvedBones.add(targetBone)
    equipmentRenderer.bones = resolvedBones
    equipmentRenderer.rootBone = ResolveRootBone(config.rootBone)
```

## 6. 姿态校正

不同装备导出时可能有轻微姿态差异。

### 6.1 严格方案
所有装备必须使用统一 T Pose / A Pose 导出。

优点：
- 稳定
- 性能好
- 不需要运行时复杂校正

### 6.2 偏移校正方案
允许装备配置整体修正：

```json
{
  "bindPoseCorrection": {
    "positionOffset": [0, 0, 0],
    "rotationOffset": [0, 0, 0],
    "scaleOffset": [1, 1, 1]
  }
}
```

### 6.3 不推荐
不推荐运行时复杂重算 bindpose，容易出错且性能不稳定。

## 7. RootBone 规则

常见 rootBone：

| 装备 | rootBone |
|---|---|
| 头盔 | head |
| 胸甲 | hips 或 spine_01 |
| 手套 | lowerarm / hand |
| 鞋子 | foot / lowerleg |
| 披风 | spine_03 |
| 全身套装 | hips |

---

## 8. 校验工具

编辑器必须提供：
- 检查装备骨骼是否都能匹配
- 检查 rootBone 是否存在
- 检查是否存在多余骨骼
- 检查是否有空 bones
- 检查材质槽数量
- 检查默认缩放

---

## 9. 验收标准

- 同一件盔甲可穿到所有使用标准骨架的职业身上。
- 换装后动画跟随角色骨骼。
- 缺失骨骼能明确报错。
- 支持骨骼别名。
- 运行时不需要给每件装备保留独立骨架。
