## 2. 投射物数量

```text
投射物数量 +1
弓技能额外发射 2 个投射物
低生命时投射物数量 +3
```

配置：

```json
{
  "stat": "ProjectileCount",
  "operation": "Add",
  "value": 1,
  "conditions": {
    "skillTag": ["Projectile"]
  }
}
```

限制：
- 额外投射物通常降低单发伤害。
- 是否允许多个投射物命中同一目标由技能配置。
- Boss 霰弹命中必须设置上限。

## 3. 投射物穿透

```text
投射物穿透 2 个敌人。
闪电投射物穿透感电敌人。
```

```json
{
  "stat": "ProjectilePierce",
  "operation": "Add",
  "value": 2
}
```

## 4. 投射物连锁

```text
投射物命中后连锁到附近 2 个敌人。
```

```json
{
  "stat": "ProjectileChain",
  "operation": "Add",
  "value": 2,
  "chainRadius": 7.0
}
```

规则：
- 优先未命中的目标。
- 不重复命中同一目标，除非技能允许。
- 超出范围停止。
- 连锁次数耗尽停止。

## 5. 投射物分裂

```text
投射物命中时分裂成 3 个小投射物。
```

```json
{
  "trigger": "OnProjectileHit",
  "effect": "SplitProjectile",
  "splitCount": 3,
  "splitAngle": 45,
  "damageMultiplier": 0.45,
  "maxSplitTimes": 1
}
```

限制：
- 分裂投射物默认不能再次分裂。
- 分裂伤害需要降低。
- 分裂次数必须有上限。

## 6. 投射物返回

```text
投射物到达终点后返回施法者。
返回时造成 60% 伤害。
```

```json
{
  "stat": "ProjectileReturn",
  "enabled": true,
  "returnDamageMultiplier": 0.6
}
```

## 9. AOE 重叠

```json
{
  "areaOverlapAllowed": true,
  "maxOverlapHitsPerTarget": 3,
  "overlapDamagePenalty": 0.65
}
```

限制：
- 必须有每目标命中上限。
- 必须有重叠伤害衰减。
- Boss 目标可额外限制。
