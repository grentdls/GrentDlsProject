# 辅助模块设计：支持宝石替代系统与连携规则

> 参考边界：本项目参考暗黑刷宝 ARPG 的系统结构：职业起点、主动技能、辅助模块、保留技能、触发技能、巨型被动树、职业专精树、装备词条联动、Boss 机制与终局构筑。
> 不直接复制任何商业游戏的职业名、技能名、图标、数值、UI截图、专有词条与怪物设定。下面所有职业、技能、天赋节点、数值区间、特效表现均为项目原创，用于 Unity 原型和后续美术/程序落地。

## 1. 系统定位

辅助模块是本项目替代“支持宝石”的原创系统。它不提供新主动技能，而是改变主动技能的行为、数值、范围、触发条件和表现。

```text
主动技能 = 技能核心
辅助模块 = 技能改造器
```

## 2. 辅助模块类型

| 类型 | 作用 | 示例原创模块 |
|---|---|---|
| 数量类 | 增加投射物/重复次数 | 分裂弹道、连发回声 |
| 范围类 | 扩大或改变范围 | 扩散冲击、收束爆发 |
| 元素类 | 改变伤害类型 | 炽化、霜化、雷化 |
| 异常类 | 增加状态积累 | 毒蚀、撕裂、震慑 |
| 触发类 | 满足条件自动释放 | 格挡释放、暴击释放 |
| 防御类 | 技能释放时获得护盾 | 护体释放、稳固释放 |
| 代价类 | 增强技能但增加消耗 | 超载、血祭、慢速强击 |
| 召唤类 | 改变召唤物行为 | 自爆仆从、冰霜炮塔 |
| 位移类 | 让技能附带移动 | 推进、后撤、追击 |

## 3. 连接规则

```text
辅助模块必须匹配 SkillTags
同名辅助模块全角色只能使用 1 次
一个技能最多 5 个辅助模块
第一版开放 2 个槽
辅助模块可以增加属性需求
辅助模块可以改变技能消耗
辅助模块不能让技能完全失去可读性
```

## 4. 互斥规则

| 模块 A | 模块 B | 互斥原因 |
|---|---|---|
| 多重投射 | 收束单发 | 一个要求多发，一个要求单发 |
| 自动触发 | 手动蓄力 | 触发技能不能等待玩家蓄力 |
| 快速释放 | 超慢强击 | 同时存在会难以理解 |
| 持续引导 | 一次爆发 | CastType 冲突 |
| 召唤继承 | 投射分裂 | 目标技能类型不同 |

## 7. Tooltip 拼接

辅助模块必须让 Tooltip 自动变化：

```text
基础技能描述
+ 辅助模块改变项
+ 代价变化
+ 标签变化
+ 当前装备/天赋最终数值
```

## 8. 验收标准

- 每个辅助模块至少支持 3 个技能。
- 每个主动技能至少有 6 个可用辅助模块。
- Tooltip 能显示最终变化。
- VFX 能根据元素类辅助替换颜色和命中特效。
- 辅助模块不会破坏技能输入手感。
