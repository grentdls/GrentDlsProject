# 174 击杀与击中词条玩法库：爆炸、召唤、连锁、附伤

## 1. 击杀爆炸

```text
击杀敌人时，引发一次火焰爆炸，造成目标最大生命 8% 的火焰伤害。
```

配置：

```json
{
  "trigger": "OnKill",
  "effect": "Explosion",
  "damageType": "Fire",
  "damageByTargetMaxLifePercent": 0.08,
  "radius": 3.5,
  "cooldown": 0.2,
  "canTriggerOtherOnKill": false
}
```

变体：

```text
击杀中毒敌人产生毒云
击杀冰冻敌人产生碎冰爆裂
击杀感电敌人释放电弧
击杀被诅咒敌人扩散诅咒
击杀流血敌人产生血爆
```

## 2. 击杀概率召唤

```text
击杀敌人时，有 20% 概率召唤 1 个骷髅战士，持续 12 秒。
```

配置：

```json
{
  "trigger": "OnKill",
  "chance": 0.2,
  "effect": "Summon",
  "summonId": "SUM_Skeleton_Warrior",
  "count": 1,
  "duration": 12,
  "maxActive": 8
}
```

变体：

```text
击杀精英时必定召唤 2 个骷髅
击杀被诅咒敌人召唤幽魂
召唤物击杀也有 30% 概率召唤额外仆从
```

## 3. 击杀回复

```text
击杀敌人恢复 3% 最大生命。
击杀敌人恢复 5 点怒气。
击杀被燃烧敌人时，恢复护盾。
击杀被诅咒敌人时，刷新一个召唤物持续时间。
```

## 4. 击中附加伤害

```text
击中敌人时，附加 12-24 点闪电伤害。
```

配置：

```json
{
  "trigger": "OnHit",
  "effect": "AddDamage",
  "damageType": "Lightning",
  "min": 12,
  "max": 24
}
```

## 5. 击中连锁伤害

```text
击中敌人时，有 30% 概率向附近 2 个敌人释放连锁闪电。
```

配置：

```json
{
  "trigger": "OnHit",
  "chance": 0.3,
  "effect": "ChainDamage",
  "damageType": "Lightning",
  "damageRatio": 0.35,
  "chainCount": 2,
  "chainRadius": 6.0,
  "cooldown": 0.25
}
```

## 6. 击中施加状态

```text
击中有 20% 概率施加流血。
火焰技能击中有 25% 概率点燃。
冰冷技能击中冰缓敌人时，有 10% 概率冻结。
```

配置：

```json
{
  "trigger": "OnHit",
  "chance": 0.25,
  "effect": "ApplyStatus",
  "statusId": "Burning",
  "duration": 4.0
}
```

## 7. 平衡限制

- 击杀爆炸默认不能再次触发击杀爆炸。
- 召唤数量必须有上限。
- 击中触发连锁必须有冷却。
- DOT 默认不触发 OnHit。
- 召唤物击杀是否算玩家击杀必须配置。
