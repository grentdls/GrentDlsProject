# 166 模型配置编辑器：预览、挂点调整、换装测试、校验

## 1. 编辑器目标

制作 Unity Editor 工具，让策划/美术能可视化配置模型外观。

菜单入口：

```text
Tools / Game / Model Config Editor
```

---

## 3. 预览功能

### 3.1 玩家预览
支持：
- 切换职业
- 切换性别/体型
- 播放 Idle / Run / Attack / Jump
- 穿戴装备
- 卸下装备
- 显示/隐藏身体部位
- 切换染色

### 3.2 敌人预览
支持：
- 切换怪物模型
- 切换精英变体
- 切换词缀 VFX
- 播放受击/死亡动画
- 显示 Hitbox / Hurtbox

### 3.3 挂点预览
支持：
- 选择 Socket
- 拖动 Position
- 旋转 Rotation
- 缩放 Scale
- 保存偏移
- 一键镜像到左/右手

---

## 4. Socket 调整工具

界面字段：

```text
Socket Name
Prefab
Local Position X/Y/Z
Local Rotation X/Y/Z
Local Scale X/Y/Z
Attach Mode
Show In Town
Show In Combat
Hide In LowLOD
```

支持 Gizmo：
- 位置箭头
- 旋转圆环
- 缩放手柄
- 本地/世界坐标切换

---

## 5. 骨骼绑定校验

编辑器必须显示：

```text
Total Bones
Matched Bones
Missing Bones
Unused Bones
RootBone
SkeletonId
```

错误示例：
- 找不到 spine_03
- rootBone 不存在
- 装备骨架和角色 skeletonId 不匹配
- SkinnedMeshRenderer bones 为空
- 材质槽数量不匹配

---

## 6. 换装测试

测试流程：

```text
选择玩家模型
→ 添加头盔
→ 添加胸甲
→ 添加手套
→ 添加鞋子
→ 添加武器
→ 播放 Run 动画
→ 播放 Attack 动画
→ 检查穿模和挂点
→ 保存配置
```

支持测试：
- 多职业穿同装备
- 不同体型穿同装备
- 动画播放时观察装备变形
- LOD 切换
- 染色切换
- 武器拔出/收起

---

## 7. 导出内容

支持导出：
- JSON
- ScriptableObject
- 依赖资源列表
- 校验报告
- 预览截图

---

## 8. 验收标准

- 能预览玩家穿装备。
- 能预览武器挂点偏移。
- 能保存 Socket 偏移。
- 能校验骨骼匹配。
- 能显示身体部位隐藏结果。
- 能测试动画中装备是否跟随骨骼。
