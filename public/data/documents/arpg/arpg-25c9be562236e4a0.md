# 156 技能动画 Timeline 编辑器界面：轨道绘制、预览、校验

## 1. 编辑器目标

Unity Editor 内制作技能动画 Timeline 编辑器。

菜单入口：

```text
Tools / Game / Skill Timeline Editor
```

## 2. 界面布局

```text
SkillTimelineEditor
├── TopToolbar
│   ├── Skill Select
│   ├── Timeline Select

│   └── Preview Play Controls
```

## 3. 轨道绘制规则

帧尺：

```text
0  5  10  15  20  25  30  35  40
```

事件显示：
- 点事件：小菱形或小图标。
- 区间事件：条形块。
- 可拖动改变帧。
- 可拖动区间边缘改变开始/结束。
- 双击打开 Inspector。

## 4. Event Inspector

```text
Frame
DamageBlockId
TargetSource
HitFeedbackProfile

```

Hitbox Event：
```text
StartFrame

```

VFX Event：
```text

VfxId
Socket

```

Cancel Window：
```text

EndFrame
AllowCancelTo

```

## 5. 预览系统

角色预览：
- 加载角色模型
- 播放动画段
- 显示当前帧
- 显示 Root Motion 轨迹

Hitbox 预览：
- 在角色武器/骨骼处显示 Hitbox
- 区间内高亮
- 支持暂停查看
- 支持显示命中范围

假人测试：
- 显示命中时刻
- 显示伤害触发
- 显示 HitFeedback
- 显示跳字

## 6. 校验规则

检查：
- Timeline 是否有动画段。
- totalFrame 是否大于 0。
- 事件帧是否超出范围。
- 区间事件 start < end。
- DamageEvent 是否有目标来源。
- HitboxEvent 是否有关闭帧。
- ProjectileEvent 是否有发射方向。
- CancelWindow 是否越界。
- Loop 技能是否有退出条件。
- Clip/VFX/SFX/Hitbox/DamageBlock 是否存在。

## 7. 快捷键

```text
Space        播放/暂停
Left/Right   前后 1 帧
Shift+Left/Right 前后 5 帧
Ctrl+S       保存
Ctrl+D       复制事件
Delete       删除事件
Alt+Drag     复制拖动事件
F            聚焦选中事件
```

## 8. 验收标准

- 能新建技能 Timeline。
- 能添加动画段。
- 能添加伤害、Hitbox、VFX、SFX 事件。
- 能拖动事件帧。
- 能预览动画和 Hitbox。
- 能校验错误。
- 能导出配置。
- 策划不写代码也能完成一个技能动画配置。
