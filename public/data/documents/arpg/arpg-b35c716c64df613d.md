# 112_怪物数值框架：等级、属性、抗性、难度缩放

> 目标：统一所有副本怪物的生命、伤害、护甲、抗性、经验、掉落预算、精英倍率和难度缩放。策划只需要填怪物角色类型和地图等级，就能获得合理初始值。

---

## 1. 怪物数值核心公式

```text
MonsterLevel = DungeonRecommendedLevel + LevelOffset + DifficultyOffset
FinalHP      = BaseHP[MonsterLevel] * RoleHPMult * RarityHPMult * DifficultyHPMult * PartyHPMult
FinalDamage  = BaseDamage[MonsterLevel] * RoleDamageMult * RarityDamageMult * DifficultyDamageMult
FinalArmor   = BaseArmor[MonsterLevel] * RoleArmorMult * RarityArmorMult
FinalXP      = BaseXP[MonsterLevel] * RoleXPMult * RarityXPMult
LootBudget   = BaseLootBudget[MonsterLevel] * RoleLootMult * RarityLootMult * MapQuantityMult
```

### 1.1 使用原则

1. 白盒阶段所有怪物都从公式生成，不手填每只怪的最终值。
2. Boss 可以单独覆盖 HP 和阶段血量，但仍保留等级、抗性、掉落预算公式。
3. 精英词缀只加倍率，不直接改基础表。
4. 地图词缀只影响全图，不写进怪物静态数据。
5. 后期平衡只改曲线和倍率，不逐个副本修数值。

## 8. 怪物数值验收

1. 同等级普通小怪，玩家 3-5 次轻击可以击杀。
2. 同等级标准怪，玩家 1 个基础技能循环可以击杀。
3. 同等级重型怪，需要玩家躲避至少 1 次重击。
4. 同等级精英，战斗时长 20-45 秒。
5. 章节 Boss，首通战斗时长 2.5-5 分钟。
6. 单图普通怪总伤害压力不能让玩家被屏外远程秒杀。
7. 精英词缀组合不得出现“硬控 + 秒杀 + 高机动”三件套。

当前默认难度规则：

- 普通章节图使用 `Normal`。
- Boss 图默认 `Hard`。
- 终局地图按 Tier 进入 `Hard` / `Nightmare` / `Abyss`。
- 后续若增加难度 UI 或地图词缀，可只改 `ResolveDifficultyId` 或传入显式难度 id。
