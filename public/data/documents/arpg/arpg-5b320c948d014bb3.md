# 260 符石与铁匠玩法接入装备、技能、天赋：构筑示例

## 1. 接入原则

```text
装备提供部位与插槽
符石提供可控属性和小型机制
技能通过标签接受符石效果
天赋深化符石方向
套装提供流派骨架
铁匠提升装备基底，不直接增加机制
```

符石不能绕过技能标签。

例如：

```text
投射物分裂符石只影响 Projectile 技能
召唤物符石只影响 Minion/Summon
环绕法球符石只影响 OrbitOrb
御剑符石只影响 FlyingSword
```

## 2. 穿甲重击构筑

装备：

```text
双手锤：攻击孔 ×2、通用孔 ×1
碎甲战铠 3件套
```

符石：

```text
鎏金碎甲符石
紫曜裂骨符石
湛蓝重击符石
```

技能：

```text
蓄力重斩
震地击
跳劈
```

天赋：

```text
重击穿甲
破韧处决
满蓄力霸体
```

铁匠优先：

```text
提高双手武器强化
品质提升基础伤害
开第三攻击孔
```

## 13. 强化与符石的关系

错误设计：

```text
强化 +10 让所有符石效果提高 50%
```

这会导致系统指数膨胀。

正确设计：

```text
强化提高装备基底
符石提供独立加成
个别神器符石可以改变强化/品质效率，但必须有代价
```

---

## 14. 套装共鸣孔

部分完整 5 件套可以通过终局铁匠开启一个共鸣孔。

共鸣孔可镶嵌：

```text
套装专属符石
传奇符石
神器符石
```

限制：

```text
每个角色最多激活 1 个套装共鸣孔
更换套装后共鸣效果失效
符石不会消失
```

## 15. 构筑推荐 UI

在符石详情中显示：

```text
适合技能
适合套装
推荐装备部位
当前角色是否受益
当前冲突机制
```

示例：

```text
鎏金星轮符石
推荐：环绕法球、赤曜星轮套装
当前角色：可使法球数量 4 → 5
冲突：已达到普通数量符石上限
```

---

## 16. 验收标准

```text
符石通过技能标签生效。
铁匠强化不会放大随机词条和符石机制。
套装、天赋和符石可以联动。
同类数量机制有上限。
触发类符石不会无限递归。
构筑推荐能显示当前实际收益。
```
