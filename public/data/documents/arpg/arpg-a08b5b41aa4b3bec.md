# 22_原型地图搭建任务清单：第一阶段里程碑

> 目标：把前面所有地图、交互、商店、放置物系统落到第一阶段可执行任务中。第一阶段不追求最终美术，只追求“能完整玩一圈”。

---

## 1. 第一阶段目标

完成 6 张核心原型地图：

1. 星陨营地：主城。
2. 坠星海岸：教学。
3. 断桥荒原：野外。
4. 裂石矿洞：地牢。
5. 黑炉深井：Boss 房。
6. 灰烬边境：终局地图雏形。

完成 5 套核心交互：

1. NPC 对话。
2. 普通商店。
3. 铁匠铺。
4. 技能商人。
5. 传送点/回城门。

完成 4 套场景物件：

1. 宝箱。
2. 可破坏物。
3. 门。
4. 事件祭坛。

## 9. 第一阶段最终体验闭环

最终必须能实现：

```text
玩家进游戏
  ↓
在主城接任务
  ↓
传送到教学地图
  ↓
战斗、拾取、开箱
  ↓
回城卖装备、分解、强化、买技能
  ↓
进入野外地图
  ↓
进入地牢
  ↓
击杀 Boss
  ↓
解锁终局地图装置
  ↓
刷第一张终局地图
  ↓
获得更强装备和下一张地图
```

## 10. 第一阶段不做的内容

为了避免范围失控，第一阶段暂不做：

- 完整美术场景。
- 全部职业。
- 全部章节正式剧情。
- 大规模程序化地图。
- 在线交易。
- 多人联机。
- 完整赛季机制。
- 大型天赋树全量节点。
- 百件传奇装备。
- 完整语音演出。

这些内容必须等核心闭环跑通后再扩展。

## 12. 第一阶段风险

| 风险 | 处理 |
|---|---|
| 地图太大，跑图无聊 | 原型期控制尺寸，增加传送点 |
| 3D 相机遮挡严重 | 墙体透明、减少高墙、Boss 房加大 |
| 交互物太多难选中 | 交互优先级 + 目标切换 |
| 商店 UI 太复杂 | 第一版只做买卖和基础分类 |
| 打造系统范围失控 | 第一版只做分解和强化 |
| Boss 技能太难调 | 先用几何范围技能验证 |
| 终局系统太大 | 第一版只做一张地图 + 简单词缀 |
