# 88. 3C 系统总览：参考边界、手感目标与模块拆分


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 3C 定义

3C = Character + Camera + Control。

本项目原本是暗黑类刷宝 ARPG，但操作方式改为 3D ACT，因此不能继续使用纯点击移动、俯视固定镜头、鼠标点怪自动转向的传统规则。玩家需要直接控制角色移动方向、镜头方向、闪避方向、跳跃落点、锁定目标和技能释放朝向。

### 1.1 本项目 3C 核心体验

| 模块 | 目标 |
|---|---|
| Character | 角色有明确身体朝向、移动惯性、起步/刹车/转向动作、跳跃与空中控制 |
| Camera | 镜头始终服务于操作和战斗，不让角色挡住目标，不让 Boss 技能出屏 |
| Control | 输入响应要快，允许移动、转向、攻击、闪避、跳跃、锁定、技能之间形成可控衔接 |
| Combat | 技能不是自动索敌按钮，而是带有释放方向、判定体、前摇/后摇/取消窗口的动作 |
| Exploration | 场景中存在台阶、坡道、矮墙、桥、平台、悬崖、可跳跃路径、可攀爬点 |

## 2. 参考方向与原创边界

### 2.1 可以参考的高层方向

- 第三人称自由镜头。
- 键鼠/手柄双摇杆式移动与视角控制。
- 近战战斗中的目标锁定与近距离镜头修正。
- 高机动移动：冲刺、闪避、跳跃、落地、空中转向。
- 垂直地形互动：爬墙、翻越、抓边、短距离攀附。
- 动作游戏的根运动、硬直、取消窗口、攻击转向。

### 2.2 不直接照搬的内容

| 原版类内容 | 本项目处理方式 |
|---|---|
| 原版角色动作参数 | 重新调参，按 ARPG 刷图节奏设计 |
| 原版技能动作名 | 全部原创命名 |
| 原版锁定手感 | 参考思路，重新设计目标优先级和相机距离 |
| 原版飞索/攀爬功能 | 改为本项目的“战术牵引/短距跃迁/攀附点”系统 |
| 原版 PVP 平衡 | 本项目优先 PVE、Boss、刷怪、刷装备体验 |

## 5. 第一版原型目标

第一版不要追求全部炫酷动作。先做可验证的最小闭环：

1. 自由镜头 + 角色移动。
2. 镜头方向决定前进方向。
3. 左键/技能释放时角色朝向技能方向。
4. 普通跳跃、落地、空中轻微控制。
5. 闪避有无敌帧、方向、距离、冷却/体力消耗。
6. 锁定目标后角色默认面向目标，移动变为环绕/侧移。
7. Boss 战时启用顶部大血条和 Boss 镜头限制。
8. 地形中能处理坡道、台阶、墙体、边缘、窄桥。

## 6. 3C 体验基准

| 项目 | 目标体验 |
|---|---|
| 移动响应 | 按下移动键 0.05s 内产生明显位移反馈 |
| 转向 | 非战斗可快速跟随输入；战斗中受动作约束 |
| 镜头 | 鼠标移动低延迟；手柄摇杆平滑但不拖沓 |
| 闪避 | 立刻打断普通移动，但不能随意取消所有重攻击 |
| 跳跃 | 更偏探索和躲技能，不做平台跳跃游戏那么苛刻 |
| 锁定 | 让近战更稳，不让玩家失去自由视角感 |
| 碰撞 | 不被小台阶卡死，不穿墙，不在斜坡抖动 |
