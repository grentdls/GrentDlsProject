# 126_副本敌人数据表与JSON示例：MonsterPool、Spawn、Loot

> 目标：把副本敌人、刷怪组、掉落点、事件奖励和副本内容表整理成当前 Unity 工程可以直接读取、校验和扩展的数据规范。

---

## 1. 当前数据链路

```text
dungeon_contents.json
  -> scene_maps.json
    -> encounter_areas.json
    -> spawn_groups.json
      -> monster_pools.json 或 monsters.json
        -> monster_skill_sets.json
        -> elite_affixes.json
        -> drop_tables.json
    -> loot_points.json
      -> drop_tables.json
    -> map_events.json
      -> spawn_groups.json

dungeon_loot_pools.json
  -> equipment_drop_pools.json
  -> drop_tables.json
```

刷怪组的 `MonsterPoolId` 支持两种写法：

- 指向 `monster_pools.json` 的 `PoolId`，用于普通随机怪物池。
- 直接指向 `monsters.json` 的 `id`，用于 Boss、固定精英、事件首领。

## 2. MonsterData 字段

数据表：`Assets/_Game/Resources/GameData/monsters.json`

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 怪物唯一 ID |
| `name_key` | string | 本地化名称 key |
| `family` | string | 怪物家族，用于技能池回退和词缀限制 |
| `rank` | string | Normal、Magic、Rare、Boss 等 |
| `base_level` | int | 基础等级 |
| `base_life` | float | 基础生命 |
| `base_damage` | float | 基础伤害 |
| `move_speed` | float | 移动速度 |
| `aggro_range` | float | 索敌距离 |
| `leash_range` | float | 脱战距离 |
| `skills` | string[] | 旧版技能列表，作为保底技能 |
| `ai_pattern_id` | string | MeleeChaser、RangedKiter、Exploder 等 |
| `drop_table_id` | string | 怪物死亡掉落表 |
| `exp_value` | int | 击杀经验 |
| `tags` | string[] | Beast、Undead、Ranged、Elite 等标签 |
| `skill_set_id` | string | 新版 AI 技能池，优先级高于家族回退 |
| `model_address` | string | 模型 Addressable 地址 |
| `animator_address` | string | Animator 地址 |
| `vfx_profile` | string | 表现配置 |
| `sfx_profile` | string | 音效配置 |
| `elite_affix_pool` | string[] | 可抽取精英词缀 |

## 3. MonsterPoolData 字段

数据表：`Assets/_Game/Resources/GameData/monster_pools.json`

| 字段 | 类型 | 说明 |
|---|---|---|
| `PoolId` | string | 怪物池唯一 ID |
| `BiomeId` | string | 生物群系/地图主题 |
| `MonsterEntries` | array | 可抽取怪物列表 |
| `MonsterEntries.MonsterId` | string | 指向 `monsters.json:id` |
| `MonsterEntries.Weight` | int | 抽取权重 |
| `MonsterEntries.MinLevel` | int | 最低出现等级 |
| `MonsterEntries.MaxLevel` | int | 最高出现等级 |
| `MonsterEntries.Role` | string | MeleeSmall、Ranged、Caster、Brute 等 |
| `MonsterEntries.MaxCountInGroup` | int | 单组最大同类数量 |
| `EliteModifierPoolId` | string | 精英修正池占位 |
| `BossModifierPoolId` | string | Boss修正池占位 |

### 示例：海岸腐化兽池

```json
{
  "PoolId": "POOL_A01_COAST_BEASTS",
  "BiomeId": "BIOME_COAST",
  "MonsterEntries": [
    {
      "MonsterId": "MON_A01_BEACH_ROTBEAST",
      "Weight": 45,
      "MinLevel": 1,
      "MaxLevel": 3,
      "Role": "MeleeSmall",
      "MaxCountInGroup": 5
    },
    {
      "MonsterId": "MON_A01_SCAVENGER_STONETHROWER",
      "Weight": 18,
      "MinLevel": 2,
      "MaxLevel": 3,
      "Role": "Ranged",
      "MaxCountInGroup": 2
    }
  ],
  "EliteModifierPoolId": "ELITE_POOL_A01_BASIC",
  "BossModifierPoolId": "BOSS_POOL_A01_TUTORIAL"
}
```

## 4. SpawnGroupData 字段

数据表：`Assets/_Game/Resources/GameData/spawn_groups.json`

| 字段 | 类型 | 说明 |
|---|---|---|
| `SpawnGroupId` | string | 刷怪组唯一 ID |
| `MapId` | string | 指向 `scene_maps.json:MapId` |
| `EncounterAreaId` | string | 指向 `encounter_areas.json:EncounterAreaId` |
| `SpawnPointIds` | string[] | 关卡内出生点标记 |
| `MonsterPoolId` | string | 指向怪物池或直接指向怪物 ID |
| `MinCount` | int | 最少生成数量 |
| `MaxCount` | int | 最多生成数量 |
| `SpawnMode` | string | Fixed、RandomFromPool、Ambush 等 |
| `TriggerType` | string | OnMapStart、OnPlayerEnterArea、OnEventStart 等 |
| `Delay` | float | 延迟刷怪秒数 |
| `RespawnRule` | string | None、Timed、EventOnly 等 |
| `DifficultyScale` | float | 数值倍率 |
| `EliteChance` | float | 精英概率 |
| `IsRequiredForCompletion` | bool | 是否计入清图目标 |
| `DebugColor` | string | 编辑器/调试颜色 |

### 示例：开局海岸刷怪组

```json
{
  "SpawnGroupId": "SG_A01_COAST_BEACH_01",
  "MapId": "MAP_A01_TUTORIAL_001",
  "EncounterAreaId": "EA_A01_COAST_TUTORIAL",
  "SpawnPointIds": [
    "SP_A01_COAST_01",
    "SP_A01_COAST_02"
  ],
  "MonsterPoolId": "POOL_A01_COAST_BEASTS",
  "MinCount": 2,
  "MaxCount": 4,
  "SpawnMode": "Fixed",
  "TriggerType": "OnMapStart",
  "DifficultyScale": 0.8,
  "EliteChance": 0,

  "DebugColor": "#7EC8E3"
}
```

## 9. 配置校验规则

| 校验项 | 等级 | 当前实现 |
|---|---|---|
| JSON 无法解析 | Error | Node 引用校验 + Unity 资源加载 |
| 重复 ID | Error | `GameDataValidator.CheckDuplicateIds` |
| MonsterPool 指向不存在怪物 | Error | `CheckMonsterPoolRefs` |
| SpawnGroup 指向不存在地图/区域/怪物池/怪物 | Error | `CheckSpawnGroupRefs` |
| SceneMap 挂接不存在的区域/刷怪组/交互物/掉落点/事件 | Error | `CheckSceneMapRefs` |
| MapEvent 指向不存在刷怪组 | Error | `CheckMapEventRefs` |
| LootPoint 指向不存在掉落表/地图/事件 | Error | `CheckLootPointRefs` |
| DungeonContent 指向不存在地图/怪物池/刷怪组/掉落表/掉落计划 | Error | `CheckDungeonContentRefs` |
| DungeonLootPool 指向不存在装备池/材料池/货币池 | Error | `CheckDungeonLootPoolRefs` |
| DungeonContent 没有 DungeonTeleport 入口 | Warning | 允许终局/测试内容先落数据，后补入口 |

## 11. 制作顺序建议

1. 先在 `monsters.json` 增加怪物，并确认 `skill_set_id`、`drop_table_id` 有效。
2. 再在 `monster_pools.json` 增加怪物池。
3. 在 `encounter_areas.json` 定义区域。
4. 在 `spawn_groups.json` 定义刷怪组。
5. 在 `scene_maps.json` 把区域、刷怪组、掉落点和事件挂到地图。
6. 在 `drop_tables.json`、`loot_points.json` 配置奖励。
7. 在 `dungeon_contents.json`、`dungeon_loot_pools.json` 汇总副本内容和掉落计划。
8. 运行 `游戏/ARPG/验证游戏数据`，再运行工程构建。
