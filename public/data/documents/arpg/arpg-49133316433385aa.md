# 15_主城场景设计：功能分区、NPC、传送门

> 目标：定义所有主城 Hub 的结构。主城不是纯装饰场景，而是玩家刷图、整理装备、打造、学习技能、交易、传送、接任务的核心循环节点。

---

## 1. 主城整体功能

主城提供：

- 玩家出生/复活。
- NPC 对话和任务。
- 商店购买/出售。
- 铁匠打造、分解、强化。
- 技能商人购买技能核心/辅助模块。
- 仓库存取。
- 传送到已解锁地图。
- 打开终局地图装置。
- 鉴定、洗词条、改造装备。
- 组队/社交预留。
- 训练木桩测试伤害。

## 3. 第一主城：星陨营地

### 3.1 主城定位

第一主城是新手玩家的核心基地，必须最清晰、最短路径、最少干扰。

主题：坠星后的临时营地。

美术关键词：

- 帐篷。
- 木架。
- 篝火。
- 石头传送阵。
- 临时铁砧。
- 货箱。
- 破旗。
- 灰烬和蓝色坠星光。

### 3.2 主城平面结构

```text
                 [出城门/野外入口]
                         |
              [任务NPC]  |  [训练木桩]
                         |
[铁匠铺] ---- [中央传送广场] ---- [技能商人]
                         |
              [仓库箱]  |  [普通商人]
                         |
                   [玩家出生点]
```

### 3.3 尺寸

| 区域 | 尺寸 | 说明 |
|---|---:|---|
| 整体主城边界 | 120m x 120m | 原型足够，不做大城 |
| 中央广场 | 35m x 35m | 容纳传送点和任务板 |
| 出生点到传送点 | 12m | 玩家进城马上看见 |
| 传送点到仓库 | 8m | 高频功能最近 |
| 传送点到铁匠 | 12m | 高频功能 |
| 传送点到技能商人 | 14m | 成长功能 |
| 传送点到出城门 | 25m | 保持清晰方向 |

### 3.4 NPC 配置

| NPC | 功能 | 解锁时机 | 位置 |
|---|---|---|---|
| 诺恩，营地指挥官 | 主线任务、章节推进 | 初始 | 中央广场北侧 |
| 米拉，普通商人 | 买卖药剂、基础装备、回城卷轴 | 初始 | 出生点右侧 |
| 铁锤格兰，铁匠 | 分解、强化、打造、修理 | 完成教学后 | 中央广场左侧 |
| 维娅，技能商人 | 技能核心、辅助模块、技能重置 | 完成第一个技能教学后 | 中央广场右侧 |
| 旧箱管理员 | 仓库、共享仓库 | 初始 | 出生点左侧 |
| 星石传送者 | 传送到已解锁地图 | 完成坠星海岸后 | 中央广场中心 |
| 训练假人 | 伤害测试 | 初始 | 北侧空地 |

## 4. 第二主城：雾林驿站

主题：森林驿站、树屋、湿地补给点。

新增功能：

- 符文商人：出售低级符文和抗性补强材料。
- 药剂改良师：药剂升级和附加效果。
- 支线猎人：提供狩猎任务。

结构：

```text
[树门入口]
    |
[传送树] -- [仓库树洞] -- [铁匠棚]
    |
[药剂师] -- [篝火广场] -- [符文商]
    |
[出城木桥]
```

重点：

- 引导玩家关注抗性、毒、药剂和异常状态。
- 视觉上比第一城更立体，但功能路径不能复杂。

## 5. 第三主城：沙海集市

主题：沙漠商队、遗迹市场。

新增功能：

- 珍品商人：出售随机稀有装备。
- 试炼引导者：打开试炼地图入口。
- 镶嵌工匠：宝石孔、插槽、符石镶嵌。

结构：

```text
[玩家出生点]
    |
[传送方尖碑]
    |------ [普通商队]
    |------ [铁匠帐篷]
    |------ [技能卷轴摊]
    |------ [镶嵌工匠]
    |------ [试炼入口]
```

重点：

- 引导玩家理解插槽、符石、试炼、随机装备。
- 商店区可以更密集，有集市感，但 UI 图标必须清楚。

## 6. 第四主城：铁脊避难所

主题：山脉机械避难所、熔炉大厅。

新增功能：

- 高阶铁匠：高级打造、定向洗词条。
- 词缀研究员：词条解锁、图鉴查看。
- 装备回收炉：批量分解。

结构：

```text
[升降平台入口]
    |
[传送炉] -- [仓库升降箱]
    |
[大熔炉大厅]
    |------ [高阶铁匠]
    |------ [回收炉]
    |------ [词缀研究员]
    |------ [技能改造台]
    |
[山门出口]
```

重点：

- 强调装备深度。
- 让玩家在终局前学会打造循环。

## 7. 第五主城：裂隙前哨

主题：虚空裂隙前线据点。

新增功能：

- 地图装置：进入终局地图。
- Atlas 管理者：查看终局推进。
- 赛季机制 NPC：进入赛季事件。
- 高级商人：出售地图石、改造材料。

结构：

```text
                 [终局地图装置]
                       |
[Atlas NPC] -- [裂隙传送广场] -- [赛季NPC]
                       |
[仓库] ---- [铁匠/打造] ---- [技能商人]
                       |
                 [玩家出生点]
```

重点：

- 这是终局刷图循环核心。
- 地图装置、仓库、铁匠必须非常近。
- 不再让玩家走远路。

## 8. 主城交互对象

### 8.1 传送点 Prefab

```text
PF_Hub_Waypoint
├── Model
├── VFX_Activated
├── VFX_Locked
├── Light
├── Collider_InteractTrigger
├── UIAnchor
├── Audio
└── Components
    ├── Interactable_Waypoint
    ├── WaypointStateView
    └── MapUnlockRequirement
```

状态：

| 状态 | 表现 | 功能 |
|---|---|---|
| Locked | 暗淡，无光 | 不可用 |
| Unlockable | 微光，显示提示 | 交互后解锁 |
| Activated | 常亮，有粒子 | 可打开传送界面 |
| QuestLocked | 有锁图标 | 需要任务进度 |

### 8.2 仓库 Prefab

```text
PF_Hub_Stash
├── Model_Chest
├── Collider_InteractTrigger
├── UIAnchor
├── VFX_Idle
├── Audio_Open
└── Components
    ├── Interactable_Stash
    ├── StashAccessController
    └── InteractionPromptProvider
```

仓库功能：

- 存入物品。
- 取出物品。
- 自动整理。
- 标签页分类。
- 搜索物品。
- 共享仓库预留。

### 8.3 训练木桩 Prefab

```text
PF_Hub_TrainingDummy
├── Model
├── Collider_HitBox
├── UIAnchor_DamageText
├── Components
│   ├── DamageReceiver
│   ├── TrainingDummyStats
│   ├── DPSMeterProvider
│   └── ResetDummyButton
└── VFX_Hit
```

功能：

- 显示单次伤害。
- 显示 DPS。
- 显示暴击率、命中率。
- 可切换抗性模板：无抗、低抗、高抗、Boss 模板。

## 10. 主城验收标准

每个主城完成时检查：

- [ ] 玩家出生点朝向中央功能区。
- [ ] 传送点可见且可交互。
- [ ] 所有 NPC 有名称牌和功能图标。
- [ ] 高频 NPC 距离出生点不超过 25m。
- [ ] 仓库、铁匠、商店、技能商人功能可打开。
- [ ] 主城内不能释放攻击技能，或释放后不造成伤害。
- [ ] 主城内不会刷怪。
- [ ] 玩家无法跳出场景边界。
- [ ] 小地图显示所有功能点。
- [ ] 主城切换后 NPC 状态保持正确。
