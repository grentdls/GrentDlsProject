# 201 装备词条池分配规则：按部位、按流派、按物品等级

## 1. 为什么要分词条池

如果所有部位都能刷所有词条，会导致：
- 装备选择没有定位
- 玩家只找最高数值
- 构筑没有取舍
- 掉落价值难以判断

因此词条必须按部位、流派、等级、稀有度分配。

---

## 2. 词条池分类

```text
GlobalAffixPool       全局词条池
SlotAffixPool         部位词条池
WeaponTypeAffixPool   武器类型词条池
BuildAffixPool        流派词条池
SetAffixPool          套装词条池
UniqueAffixPool       传奇词条池
MapDropAffixPool      地图掉落倾斜池
```

---

## 3. 全局词条池

全局词条可以出现在多个部位，但要控制权重。

示例：
```text
生命
抗性
护盾
少量属性
少量资源回复
```

不应该全局出现：
```text
投射物数量
召唤物数量
技能等级
移动速度
格挡率
```

## 6. 物品等级限制

高级词条必须要求更高 itemLevel。

示例：

```text
T5 词条：itemLevel 1+
T4 词条：itemLevel 20+
T3 词条：itemLevel 40+
T2 词条：itemLevel 60+
T1 词条：itemLevel 75+
T0 词条：终局 Boss / 特殊打造
```

---

## 7. 词条权重

词条出现概率由权重决定。

```json
{
  "affixId": "AFF_ProjectileCount",
  "weight": 50,
  "allowedSlots": ["Bow", "Quiver", "Amulet"],
  "requiredItemLevel": 55
}
```

稀有机制词条权重要低于普通数值词条。

---

## 8. 词条互斥

某些词条不能同时出现。

示例：
```text
投射物不能穿透
和
投射物穿透 +3
互斥

无法暴击
和
暴击率 +20%
互斥

生命回复转护盾
和
生命回复提高
需要特殊处理
```

字段：

```json
{
  "affixId": "AFF_NoPierceButSplit",
  "exclusiveTags": ["ProjectilePierce"]
}
```
