# 69. 伤害数值与成长配置：等级曲线、标签、武器系数


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第五批 —— 技能编辑器 / 怪物技能编辑器 / 策划配置工具  
> 目标：让策划不改代码，也能配置玩家技能、怪物技能、Boss 阶段技能、辅助模块、Buff、VFX/SFX、数值成长、AI 使用条件与测试验收。


---

## 1. 设计目标

技能编辑器里的数值配置要满足三件事：

1. **策划能直接调**：不需要改代码。
2. **数值能统一平衡**：同类技能用模板生成基础曲线。
3. **装备/天赋/辅助能联动**：技能标签和伤害块能被外部系统修改。

本项目不直接复制任何商业游戏的具体数值。这里提供原创数值框架和可调模板。

---

## 2. 技能数值组成

最终技能强度由以下部分组成：

```text
技能基础值
+ 技能等级成长
+ 武器伤害/法术强度倍率
+ 职业属性加成
+ 装备词条加成
+ 天赋节点加成
+ 辅助模块加成
+ Buff/Debuff 加成
+ 怪物/地图难度修正
```

## 4. 技能数值模板

### 4.1 普通近战模板

适合低冷却、高频率技能。

```text
baseFlatDamage = 0
weaponDamagePercent = 90% - 140%
attackPowerScale = 0.4 - 0.8
baseCooldown = 0
manaCost = 3 - 10
hitboxRange = 1.5 - 3.0
```

### 4.2 重击模板

适合慢速、高冲击、破防技能。

```text
weaponDamagePercent = 180% - 360%
attackPowerScale = 1.0 - 1.8
baseCooldown = 2 - 8s
manaCost = 12 - 35
stunPower = 高
canBeInterrupted = 前摇可被打断
```

### 4.3 投射物模板

适合远程主力输出。

```text
weaponDamagePercent = 70% - 130%
spawnCount = 1
projectileSpeed = 12 - 28
maxDistance = 12 - 30
pierce/chain/bounce 默认 0
```

### 4.4 法术模板

适合不依赖武器，主要看法术强度。

```text
baseMinDamage = 8 + 等级成长
baseMaxDamage = 12 + 等级成长
spellPowerScale = 0.8 - 1.6
manaCost = 8 - 45
cooldown = 0 - 10s
```

### 4.5 召唤模板

```text
summonBaseDamage = 区域等级 × 模板倍率
inheritOwnerStats = true
inheritPercent = 20% - 80%
maxAlive = 1 - 12
summonDuration = -1 或 8-30s
```

### 4.6 Boss 技能模板

```text
baseDamage = 区域等级预算 × 1.0 - 3.0
warningTime = 0.8 - 2.5s
cooldown = 6 - 20s
oneShotAllowed = false 默认禁止
safeZoneRequired = 大范围高伤技能必须有
```

## 5. 技能等级成长

### 5.1 LevelScaleTemplate


## 6. 怪物技能等级缩放

怪物技能不建议逐个配等级，应该按区域等级自动缩放。

```text
MonsterSkillPower = MonsterBasePowerByAreaLevel × SkillBudgetMultiplier × DifficultyMultiplier
```

字段：

```text
monsterAreaScaleMode
skillBudgetMultiplier
normalMonsterScale
eliteMonsterScale
bossMonsterScale
mapModifierScale
partyScale
```

推荐：

| 怪物类型 | 技能预算倍率 |
|---|---:|
| 普通怪普通攻击 | 0.6 - 1.0 |
| 普通怪强技能 | 1.0 - 1.4 |
| 精英怪技能 | 1.2 - 2.0 |
| 小 Boss 技能 | 1.8 - 3.0 |
| 章节 Boss 机制 | 2.0 - 4.0，但必须有预警 |

## 7. 伤害类型配置

```text
Physical：物理，受护甲影响
Fire：火焰，可点燃
Cold：冰霜，可冰缓/冻结
Lightning：闪电，可感电
Poison：毒素，可持续伤害
Bleed：流血，移动时加重
Chaos：混沌，无视部分护盾
Holy：神圣，对亡魂额外有效
Shadow：暗影，适合诅咒与吸取
Arcane：奥术，适合纯法术缩放
```

技能可以有多个 DamageBlock，支持混伤。

示例：火焰斩：

```text
DamageBlock_01：Physical，weaponDamagePercent 100%
DamageBlock_02：Fire，weaponDamagePercent 40%，ailmentAllowed true
```

## 8. 标签驱动加成

装备、天赋、Buff 不应该写死影响某个技能，而是通过标签匹配。

示例词条：

```text
+15% Melee 技能伤害
+20% Fire 技能范围
Projectile 技能额外发射 1 个投射物
Area 技能半径 +10%
Summon 仆从生命 +25%
```

运行时流程：

```text
技能释放
→ 读取技能 Tags
→ 查找角色所有 Modifier
→ 判断 Modifier.RequiredTags 是否匹配
→ 修改 FinalSkillStats
```

## 9. 武器伤害系数

武器技能使用 `weaponDamagePercent`。

```text
FinalWeaponDamage = WeaponAverageDamage × weaponDamagePercent × AttackPowerScale × 其他倍率
```

配置建议：

| 技能类型 | 武器系数 |
|---|---:|
| 快速普攻 | 60% - 100% |
| 普通主力攻击 | 100% - 160% |
| 慢速重击 | 180% - 360% |
| 多投射物技能 | 单个 40% - 90% |
| 大范围 AoE | 80% - 180% |

---

## 10. 法术基础伤害

法术不要依赖武器基础伤害，使用 `baseMinDamage/baseMaxDamage + spellPowerScale`。

```text
FinalSpellDamage = SkillBaseDamageByLevel × (1 + SpellPower × spellPowerScale) × Modifiers
```

配置建议：

| 法术类型 | 法强系数 | 冷却 |
|---|---:|---:|
| 小法术 | 0.5 - 0.9 | 0 |
| 主力法术 | 0.8 - 1.4 | 0 - 2s |
| 爆发法术 | 1.5 - 3.0 | 4 - 12s |
| 持续法术 | 0.2 - 0.6 每 Tick | 持续消耗 |

## 11. DOT 持续伤害

DOT 不暴击，通常不触发 OnHit。

字段：

```text
dotDamagePerSecond
dotDuration
dotTickInterval
dotStackMode
dotMaxStack
dotRefreshMode
dotDamageType
```

StackMode：

```text
Independent：每层独立计时
Refresh：刷新持续时间
ReplaceStronger：只保留更强一层
Additive：叠加伤害
```

---

## 12. 异常状态强度

异常状态建议拆为“施加概率”和“异常强度”。

```text
AilmentApplyChance = 技能基础概率 + 角色加成 + 装备加成
AilmentPower = 伤害贡献 × 技能异常倍率 × 角色异常加成
```

字段：

```text
ailmentType
baseApplyChance
powerFromHitDamagePercent
minDuration
maxDuration
bossEffectiveness
```

Boss 规则：

```text
Boss 不免疫异常，但降低效果
冻结类控制对 Boss 变成 Break 累积
硬控转换为削韧/破防条
```

## 13. 伤害衰减配置

大范围技能必须支持范围衰减。

```text
FalloffRule
├── falloffType：None / Distance / TargetCount / ChainIndex
├── startPercent
├── endPercent
├── minMultiplier
└── curve
```

示例：爆炸中心到边缘衰减：

```text
中心 100%
半径 50% 处 80%
边缘 55%
```

---

## 14. 目标数量惩罚

用于防止多目标技能刷图过强。

```text
TargetCountFalloff
├── enable
├── startAtTargetCount = 5
├── reducePerExtraTarget = 5%
├── minMultiplier = 60%
```

## 15. 辅助模块数值修改

辅助模块统一输出 Modifier。

```text
SupportModifier
├── targetField
├── operation：Add / Multiply / Override / Append
├── value
├── conditionTags
└── conflictGroup
```

示例：多重投射辅助

```text
ProjectileCount +2
ProjectileDamage ×0.65
ManaCost ×1.25
SpreadAngle +18°
```

## 16. 数值预览面板

编辑器中每个技能要有数值预览：

```text
当前等级伤害
满级伤害
每秒伤害估算
每蓝耗伤害
范围
冷却
命中目标数
对普通怪 TTK
对精英怪 TTK
对 Boss TTK 估计
```

预览不要求 100% 精准，但要能发现明显异常。

---

## 17. 数值警戒线

校验器需要检查：

| 规则 | 类型 |
|---|---|
| 0 冷却技能伤害倍率超过模板上限 | Warning |
| Boss 大范围技能 warningTime < 0.8s | Error |
| 玩家技能 ManaCost = 0 且高伤害 | Warning |
| 投射物数量 > 8 且无伤害惩罚 | Warning |
| DOT TickInterval < 0.1s | Error |
| 技能半径 > 12 且无冷却 | Warning |
| 怪物技能前摇 < 0.2s 且高伤害 | Error |

---

## 18. 推荐数值开发流程

```text
1. 先按模板生成技能基础数值
2. 在测试沙盒打木桩
3. 记录 10 秒输出
4. 装 0/2/4 个辅助模块再测
5. 测 1 个普通怪、5 个普通怪、1 个精英、1 个 Boss
6. 观察清怪速度和 Boss 压制力
7. 调整技能预算倍率
8. 写入版本备注
```
