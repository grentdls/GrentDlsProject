# 91. 跳跃与空中控制：起跳、空中移动、落地、边缘保护


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 跳跃定位

本项目跳跃不是平台动作游戏的核心，而是 3D ACT 战斗和探索的辅助能力：

- 躲避地面横扫、冲击波、毒池。
- 越过低矮障碍、断桥、矮墙。
- 衔接空中攻击、空中技能、下劈。
- 触发场景互动：翻越、抓边、爬墙、下落攻击。

## 2. 跳跃状态机

```text
Grounded
 ├── JumpPressed → JumpStart
JumpStart
 ├── 动画起跳帧 → JumpRise
JumpRise
 ├── 垂直速度 <= 0 → Fall
 ├── 输入攻击 → AirAttack
 ├── 靠近可抓边 → LedgeGrab
Fall
 ├── 接触地面且速度低 → LandLight
 ├── 接触地面且速度高 → LandHeavy
 ├── 输入攻击 → AirAttack
LandLight
 ├── 0.08s 后 → Grounded
LandHeavy
 ├── 0.35s 后 → Grounded
```

## 3. 基础跳跃参数

| 参数 | 建议值 | 说明 |
|---|---:|---|
| 跳跃高度 | 1.6m - 2.2m | 普通角色 |
| 起跳垂直速度 | 5.6 - 6.4 | 按重力调整 |
| 上升重力倍率 | 1.0 | 标准上升 |
| 下落重力倍率 | 1.8 - 2.4 | 下落更快，手感利落 |
| 空中横向控制 | 35% - 55% | 不允许空中急转过猛 |
| 土狼时间 | 0.12s | 离开地面后仍可跳 |
| 跳跃缓冲 | 0.12s | 落地前按跳可自动跳 |
| 重落地阈值 | -12m/s | 触发硬直/落地震动 |

## 4. 起跳规则

### 4.1 普通跳跃

- 角色必须处于 Grounded、Run、CombatMove、LockedStrafe 中。
- 攻击重后摇、硬直、击飞、眩晕不可跳。
- 部分轻攻击后摇可通过天赋/技能解锁跳跃取消。
- 起跳方向继承当前移动方向。

### 4.2 锁定状态跳跃

| 输入 | 跳跃表现 |
|---|---|
| W + Jump | 朝目标方向小跳靠近 |
| S + Jump | 后跳拉开 |
| A/D + Jump | 侧跳，保持面向目标 |
| 无输入 + Jump | 原地小跳，保持面向目标 |

## 5. 空中控制

空中移动分为两部分：继承起跳速度 + 玩家输入修正。

```text
AirVelocityXZ = InitialJumpXZ * InheritWeight + InputDirection * AirControlSpeed
```

规则：

- 起跳后前 0.12s 不允许完全反向，避免空中抽搐。
- 空中输入可修正方向，但最大转向角每秒有限制。
- 空中攻击会降低横向控制。
- 空中被击中进入 `AirHitReact`，暂时失去控制。

## 6. 可变跳高

是否支持长按跳跃更高？建议支持轻量版：

| 操作 | 效果 |
|---|---|
| 轻点跳跃 | 标准高度 80% |
| 按住跳跃 0.15s 以上 | 标准高度 100% |
| 松开跳跃 | 提前增加重力，下落更快 |

用于增强操作感，但不要做得太平台化。

## 7. 落地规则

### 7.1 轻落地

条件：下落速度低于重落地阈值。

- 可快速恢复移动。
- 可接普攻/闪避。
- 落地特效轻微。

### 7.2 重落地

条件：下落速度大、从高处落下、被击飞落地。

- 触发 0.25s - 0.5s 落地硬直。
- 播放落地震动。
- 可造成小范围冲击波，作为某些天赋/技能效果。
- 可被特定天赋减少硬直。

## 8. 边缘保护规则

为了避免玩家走到悬崖边被小碰撞弹下，加入边缘保护。

### 8.1 边缘检测

角色前方/下方做多点 Raycast：

```text
FootCenterRay
FootForwardRay
FootLeftRay
FootRightRay
```

若前方无地面但角色速度低，启动边缘阻挡：

- 非战斗状态：轻微阻止角色直接掉落。
- 疾跑状态：允许冲出边缘。
- 闪避状态：允许冲出边缘。
- 被击退状态：允许掉落。

### 8.2 断崖确认

如果高度差超过 `DangerDropHeight`：

- 普通移动不会自动迈出。
- 玩家按住前进 + 跳跃才会跳出。
- 镜头可轻微下压显示落差。

## 9. 台阶与翻越联动

当玩家按跳跃且前方有低障碍：

| 障碍高度 | 行为 |
|---|---|
| < 0.25m | 自动台阶处理，不触发跳跃 |
| 0.25m - 0.75m | 翻越 Vault |
| 0.75m - 1.8m | 抓边/攀爬 |
| > 1.8m | 普通跳跃撞墙或触发攀爬点检测 |

## 10. 空中攻击与下劈

| 技能类型 | 空中规则 |
|---|---|
| 空中普攻 | 保持少量横向速度 |
| 空中重击 | 降低横向速度，向目标/输入方向修正 |
| 下劈 | 强制向下落，落地触发 AoE |
| 空中射击 | 可缓慢移动，但不可无限滞空 |
| 空中法术 | 释放时短暂停滞 0.1s - 0.25s |

## 12. 验收标准

- 玩家从平台边缘刚离开时仍能跳起。
- 落地前提前按跳可顺畅连续跳。
- 跳跃不会因为地形微小凸起被吞输入。
- 从斜坡跳起时方向正确。
- 空中攻击不会导致角色穿墙或悬停太久。
- 高处落地有明确轻/重落地区分。
