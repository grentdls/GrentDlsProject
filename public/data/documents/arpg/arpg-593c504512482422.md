# 113_掉落池总设计：装备、材料、货币、副本专属奖励

> 目标：统一所有副本、怪物、Boss、宝箱、可破坏物和事件的掉落池，让刷图奖励可控、可调、可追踪。

---

## 1. 掉落来源分类

| 来源 | 掉落特点 | 是否受地图数量影响 | 是否受稀有度影响 |
|---|---|---|---|
| 普通怪 | 少量金币、低概率装备、材料碎片 | 是 | 是 |
| 魔法怪 | 较高装备概率，少量材料 | 是 | 是 |
| 稀有怪 | 必掉装备或材料包 | 是 | 是 |
| 地图小头目 | 高概率稀有装备，地图专属材料 | 是 | 是 |
| 章节 Boss | Boss 宝箱、首通奖励、专属材料 | 部分 | 部分 |
| 宝箱 | 装备/材料/金币，和宝箱等级相关 | 是 | 是 |
| 可破坏物 | 金币、药剂、低阶材料 | 否 | 否 |
| 事件奖励 | 事件币、宝箱、材料包 | 是 | 是 |
| 终局地图 Boss | 高阶装备、地图钥石、专属碎片 | 是 | 是 |

## 7. 掉落验收标准

1. 普通刷图 10 分钟内，玩家至少获得 5-10 件可检查装备。
2. 单个章节 Boss 必须给 1 个稳定成长奖励。
3. 材料副本的奖励必须比普通图更定向，但总价值不能超过主线刷图太多。
4. 稀有怪必须让玩家有“值得打”的反馈，至少掉落材料包或高品质装备。
5. 终局地图必须让玩家持续获得地图钥石，不允许钥石经济断裂。

当前第一版掉落接入原则：

- 装备、遗物继续生成可拾取世界物品，保留检查装备和地面反馈。
- 金币、打造材料、Boss材料、挑战币、钥石等非装备奖励直接写入玩家钱包或地图钥石背包，避免掉落后没有物品 prefab 而丢失。
- 稀有度、难度和队伍规模会通过 `MonsterTuningResult.LootBudget` 影响掉落次数，精英、Boss、终局难度能自然提高掉落量。
- 掉落表仍保持轻量独立概率模型，方便策划先快速调权重；后续需要严格总权重抽取时，可只替换 `DropTableResolver` 的抽取规则。
