# 200 固定属性、随机属性、隐性属性、打造属性结构规则

## 1. 属性来源分类

装备上的属性必须标明来源。

```text
BaseStat       基底属性
Implicit       隐性属性
FixedAffix     固定词条
RandomAffix    随机词条
CraftAffix     打造词条
SetBonus       套装效果
UniquePower    传奇机制
CorruptAffix   腐化词条
```

---

## 2. 基底属性 BaseStat

基底属性由装备类型决定。

例如胸甲：

```text
布甲：护盾高，护甲低
皮甲：闪避高，生命中
重甲：护甲高，生命高
混合甲：护甲 + 护盾
```

示例：

```json
{
  "baseTypeId": "Chest_Heavy_Iron",
  "slot": "Chest",
  "baseStats": [
    {"stat": "Armor", "value": 120},
    {"stat": "Life", "value": 60}
  ]
}
```

---

## 3. 隐性属性 Implicit

隐性属性是基底自带的固定方向。

示例：

```text
剑：近战物理伤害 +8%
匕首：暴击率 +5%
法杖：法术伤害 +10%
盾牌：格挡率 +6%
鞋子：移动速度 +5%
戒指：随机元素抗性 +12%
项链：全部属性 +8
```

隐性属性通常不占随机词条数。

---

## 4. 固定属性 FixedAffix

固定属性来自：
- 套装件设计
- 传奇装备设计
- 副本专属装备
- 任务奖励装备

示例：

```text
这件套装手套固定拥有：召唤物伤害 +15%
这件传奇鞋固定拥有：移动速度 +25%
```

---

## 5. 随机属性 RandomAffix

随机属性来自词条池。

随机属性必须有：
```text
affixId
affixType 前缀/后缀
tier
valueRange
tags
weight
itemLevelRequirement
slotRequirement
```

示例：

```json
{
  "affixId": "AFF_Life_T3",
  "type": "Prefix",
  "stat": "Life",
  "min": 65,
  "max": 85,
  "tier": 3,
  "requiredItemLevel": 45,
  "allowedSlots": ["Chest", "Belt", "Ring"]
}
```

---

## 6. 打造属性 CraftAffix

打造属性是玩家后期补短板的方式。

规则：
- 默认最多 1 条打造词条。
- 打造词条强度低于天然随机词条。
- 打造词条可被替换。
- 某些高级工艺可锁前缀/锁后缀。

示例：

```text
打造：火抗 +12%
打造：移动速度 +8%
打造：召唤物生命 +10%
打造：穿甲 +60
```

---

## 7. 传奇机制 UniquePower

传奇机制必须独立显示，不与普通词条混在一起。

示例：

```text
你的投射物不能穿透，但每次第一次命中都会分裂。
低血时你的吸血翻倍，但最大护盾变为 0。
你的召唤物死亡时爆炸，造成其最大生命 20% 的火焰伤害。
```

传奇机制字段：

```json
{
  "uniquePowerId": "UP_MinionsExplodeOnDeath",
  "description": "召唤物死亡时爆炸",
  "rules": [
    {"trigger": "OnMinionDeath", "effect": "Explosion"}
  ],
  "hasDrawback": true
}
```

---

## 8. 属性来源 UI

UI 必须显示来源标签：

```text
[基底] 护甲 +120
[隐性] 格挡率 +6%
[前缀] 最大生命 +80
[后缀] 火焰抗性 +18%
[打造] 移动速度 +8%
[套装3件] 召唤物数量 +1
[传奇] 召唤物死亡时爆炸
```

---

## 9. 设计原则

```text
基底决定装备大方向
隐性决定基底特色
随机词条决定刷装深度
打造词条补短板
套装词条形成流派
传奇机制改变规则
```
