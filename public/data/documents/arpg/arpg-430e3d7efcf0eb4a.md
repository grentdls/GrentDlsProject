# 139 HitStop 顿帧与攻击命中节奏：战士重击、多段技能、Boss

## 1. 设计目标

HitStop 是动作游戏打击感的关键。  
但顿帧不是越长越好，必须根据技能类型、目标类型、命中强度控制。

本项目要实现：
- 战士重击命中顿帧明显。
- 暴击顿帧更强。
- 小伤害不卡。
- 多段技能不疯狂卡顿。
- Boss 技能命中玩家有压迫感。
- 网络/性能不受影响。

---

## 2. HitStop 基础规则

HitStop 分为：
- 攻击者顿帧。
- 受击者顿帧。
- 世界顿帧。
- 镜头轻停顿。
- 动画速度缩放。

推荐不要真正冻结整个游戏，而是使用局部 timeScale / AnimatorSpeed / PlayableSpeed 控制。

---

## 3. 顿帧强度表

| 命中类型 | 攻击者 | 受击者 | 镜头 | 时长 |
|---|---:|---:|---:|---:|
| 小伤害 | 0 | 0.02 | 无 | 0.00~0.02s |
| 普通命中 | 0.02 | 0.04 | 无 | 0.03~0.05s |
| 暴击 | 0.04 | 0.07 | 轻 | 0.06~0.09s |
| 战士重击 | 0.06 | 0.10 | 中 | 0.08~0.13s |
| 破盾 | 0.05 | 0.09 | 中 | 0.07~0.12s |
| 破韧 | 0.08 | 0.16 | 强 | 0.12~0.20s |
| Boss 重击命中玩家 | 0 | 0.14 | 强 | 0.10~0.18s |

---

## 4. 战士类技能顿帧规则

战士类技能强调重量，命中时要有“砍进去”的阻力。

### 4.1 适用技能
- 重斩。
- 盾击。
- 跳劈。
- 战锤砸地。
- 大剑蓄力。
- 破甲打击。
- 处决技。

### 4.2 表现组合

```text
Heavy HitStop
+ 大跳字
+ 受击后仰
+ 火花/碎屑
+ 低频命中音
+ 镜头轻震
+ 武器命中拖尾停顿
```

### 4.3 顿帧曲线

```text
命中瞬间 0.00s：攻击者和受击者动画速度降到 0
0.06s：受击者恢复到 40%
0.10s：攻击者恢复到 60%
0.14s：完全恢复
```

---

## 5. 多段技能顿帧限制

多段技能如果每段都顿帧，会导致卡成 PPT。

### 5.1 合并规则

```text
hitStopMergeWindow = 0.18s
maxHitStopPerSkillCast = 2
```

### 5.2 首段/终段强化
多段技能推荐：
- 第一段：轻顿帧。
- 中间段：无或极轻顿帧。
- 最后一段：中/重顿帧。

### 5.3 DOT 不触发顿帧
持续伤害默认不触发 HitStop，除非是特殊脉冲类技能。

---

## 6. Boss 战 HitStop

### 6.1 玩家攻击 Boss
普通命中 Boss：
- 不频繁顿帧。
- 只在弱点、破盾、破韧、阶段事件触发明显顿帧。

### 6.2 Boss 攻击玩家
Boss 命中玩家：
- 可触发受击者顿帧。
- 可触发镜头震动。
- 可触发屏幕暗角/冲击。
- 不应频繁打断玩家输入，除非是大招。

---

## 7. 技能配置字段

```json
{
  "hitStopProfile": {
    "enable": true,
    "attackerStopTime": 0.06,
    "targetStopTime": 0.10,
    "worldStopTime": 0.00,
    "cameraPauseTime": 0.02,
    "mergeWindow": 0.18,
    "maxPerCast": 2,
    "applyOnlyOnFinalHit": false,
    "ignoreForDOT": true
  }
}
```

## 8. 与动画系统联动

### 8.1 Animator Speed
命中时临时修改：

```text
attackerAnimator.speed = 0
targetAnimator.speed = 0
```

恢复时使用曲线插值，不能瞬间恢复，否则抖。

### 8.2 Root Motion
HitStop 时：
- 攻击者 Root Motion 暂停。
- 受击者位移延迟启动。
- 击退在顿帧结束后开始更有力量。

---

## 9. 与输入系统联动
HitStop 期间：
- 玩家输入可缓存。
- 不立即执行取消。
- 顿帧结束后根据取消窗口处理。
- 避免玩家感觉按键丢失。

---

## 10. 验收标准
- 战士重击命中普通怪有明显顿帧。
- 弓箭和小法术不会过度卡顿。
- 多段技能不会每段都强顿。
- Boss 普通受击不频繁停顿。
- 破韧、破盾、暴击能明显比普通命中更有冲击。
