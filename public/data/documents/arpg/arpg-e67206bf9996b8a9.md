# 263 敌人血条与世界空间 UI 优化：可见性、距离、分帧与对象池

## 1. 推荐方案

不建议每个敌人一个 World Space Canvas。推荐：

```text
一个 Screen Space Canvas
+ EnemyHudRegistry
+ EnemyHealthBarPool
+ WorldToScreenPoint
```

结构：

```text
Canvas_WorldHud
└── EnemyHealthBarPool
    ├── HealthBar_01
    ├── HealthBar_02
    └── HealthBar_N
```

## 2. 显示条件

显示：

```text
被玩家命中
进入战斗
被锁定
当前目标
精英/Boss
鼠标悬停
距离足够近
```

隐藏：

```text
超出距离
离开屏幕
死亡
满血且未战斗
长期被遮挡
```

## 3. 统一注册与分配

敌人只向 `EnemyHudRegistry` 注册数据，统一管理器决定：

```text
是否显示
分配哪个血条实例
多久刷新
何时回收
```

敌人脚本不直接 Instantiate UI。

## 4. 更新频率 LOD

```text
当前目标/Boss：30-60 Hz
近距离精英：30 Hz
中距离普通怪：15 Hz
远距离：5-10 Hz
屏幕外：0 Hz
```

## 5. 分帧更新

例如 30 个敌人：

```text
第1帧更新 0-9
第2帧更新 10-19
第3帧更新 20-29
```

当前目标、Boss、刚受伤敌人不分帧，始终优先。

## 6. 坐标转换

```text
缓存主摄像机
缓存血条挂点 Transform
只对可见对象调用 WorldToScreenPoint
禁止 Update 中反复 Camera.main
```

## 7. 遮挡检测

不要每个敌人每帧 Raycast。

推荐：

```text
只检测当前目标/精英
每 0.2 秒一次
遮挡后延迟隐藏
```

## 8. 数值更新

生命变化事件只更新目标 fill。位置更新与数值更新分离。

延迟掉血条只在受伤时运行。

## 9. 血条 LOD

```text
LOD0 Boss：生命、护盾、韧性、名称、异常、阶段
LOD1 精英：生命、护盾、名称、少量异常
LOD2 普通：只有生命条
LOD3 远处：不显示
```

## 10. 异常图标

```text
最多显示 4 个
控制类优先
当前构筑关键异常优先
同类状态合并层数
```

## 11. 对象池回收清理

```text
解绑目标
取消事件订阅
清空名称
清空 Buff 图标
重置精英边框
重置锁定标记
```

## 12. 验收

```text
普通敌人不再各自创建 Canvas
屏幕外敌人停止位置刷新
死亡后血条立即回池
大量敌人时分帧更新
当前目标始终流畅
```
