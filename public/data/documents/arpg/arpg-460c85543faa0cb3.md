# 96. 攀爬、跑墙、战术牵引：垂直地形与高机动移动


> 项目：Unity 3D ACT 刷宝 ARPG  
> 批次：第八批 - 3C 视角与操控专项  
> 目标：用第三人称自由视角 ACT 操控替代传统 2D/等距锁定视角，让玩家在刷宝、Boss 战、地牢探索中获得更强的动作控制感。  
> 参考边界：参考《永劫无间》这类第三人称动作游戏的高层 3C 思路：自由镜头、动作转向、跳跃/闪避/攀爬、锁定辅助、垂直移动与战斗镜头调度。具体参数、手感曲线、动作名称、镜头表现、输入节奏均采用本项目原创实现。


## 1. 定位

《永劫无间》类动作游戏的一个核心感受是空间立体、移动自由。本项目是 PVE 刷宝 ARPG，不需要完全变成跑酷游戏，但需要让 3D ACT 视角有价值：场景可以上下分层，玩家可以越过障碍、攀上平台、用战术牵引进入高处或快速接近怪物。

## 2. 垂直移动模块

| 模块 | 本项目名称 | 用途 |
|---|---|---|
| Vault | 翻越 | 低墙、栏杆、窗台 |
| LedgeGrab | 抓边 | 平台边缘补救 |
| Climb | 攀爬 | 指定可攀爬墙/梯/藤蔓 |
| WallRun | 墙面疾行 | 短距离沿墙移动，可选 |
| GrapplePull | 战术牵引 | 拉向锚点/敌人/地形点 |
| AirDash | 空中冲刺 | 部分职业/技能解锁 |
| DropAttack | 下落攻击 | 从高处攻击敌人 |

## 3. 交互式跳跃

当玩家按住前进并按跳跃，如果前方有 Traversal Marker，则优先触发地形互动，而不是普通跳跃。

优先级：

```text
Vault > LedgeGrab > Climb > WallRun > NormalJump
```

条件：

- 角色朝向与交互点角度小于配置值。
- 距离满足进入范围。
- 当前状态允许地形互动。
- 没有被攻击硬直、击飞、眩晕。

## 4. 翻越 Vault

### 4.1 使用场景

- 低墙。
- 栏杆。
- 窗户。
- 破碎石块。
- 地牢矮障碍。

### 4.2 参数

| 参数 | 建议值 |
|---|---:|
| 最小高度 | 0.25m |
| 最大高度 | 0.75m |
| 进入距离 | 0.8m |
| 动作时间 | 0.35s - 0.65s |
| 可取消 | 通常不可 |

### 4.3 位置匹配

翻越必须有 EntryPoint 和 ExitPoint：

```text
VaultMarker
├── EntryPoint
├── ExitPoint
├── ObstacleHeight
├── AnimationType
└── CameraHint
```

## 5. 抓边 LedgeGrab

抓边用于防止玩家因为小失误掉下平台，也能作为探索动作。

触发条件：

- 角色正在下落。
- 前方有可抓边层。
- 手部高度附近检测到边缘。
- 边缘上方有可站立出口。

状态：

```text
Fall → LedgeGrabHold → ClimbUp / Drop / BackJump
```

输入：

| 输入 | 行为 |
|---|---|
| W / Jump | 爬上去 |
| S / Dodge | 松手下落 |
| 无输入 | 保持悬挂，消耗体力可选 |
| A/D | 沿边缘小幅移动，可选 |

## 6. 攀爬 Climb

本项目攀爬只在指定区域生效，不做所有墙都可爬，避免关卡失控。

可攀爬物：

- 梯子。
- 藤蔓。
- 破墙裂缝。
- 木架。
- 城墙缺口。

规则：

- 进入攀爬后移动变为上下左右。
- 镜头可自由旋转，但角色贴墙。
- 被攻击会掉落或进入挂墙受击。
- 体力耗尽会滑落，可选。

## 7. 墙面疾行 WallRun / WallSlide

作为可选高级移动，只在特殊地图区域使用。

触发：

- 疾跑或跳跃后接近可跑墙面。
- 输入方向沿墙切线。
- 角色速度大于阈值。

规则：

- 最长持续 1.2s - 1.8s。
- 不允许无限绕墙。
- 墙面结束后进入跳跃/下落。
- 墙面期间不能释放大部分技能，只能轻攻击/跳离。

## 8. 战术牵引 GrapplePull

本项目不直接复制飞索系统，改为“战术牵引”：可以拉向锚点、敌人弱点、场景高台，作为 ARPG 技能/装备/地图机制的一部分。

### 8.1 牵引目标

| 目标 | 处理 |
|---|---|
| 地形锚点 | 玩家拉向锚点 |
| 小怪 | 玩家拉向小怪或把小怪拉来，按技能配置 |
| 精英怪 | 只能拉自己过去 |
| Boss 弱点 | 拉向 Boss 弱点附近平台/安全点 |
| 机关 | 拉动机关或拉向机关 |

### 8.2 牵引阶段

```text
Aim → Fire → Attach → Pull → Land/Impact → Recovery
```

### 8.3 安全检测

- 牵引路径做 CapsuleCast。
- 目标点必须有落脚检测。
- 不允许穿越封闭墙体。
- 若路径被阻挡，提前落地或撞击中断。

## 9. 下落攻击 DropAttack

当玩家从高处下落并按攻击：

- 锁定最近敌人或朝输入方向下劈。
- 降低空中横向控制。
- 落地造成范围伤害。
- 下落高度越高，伤害或范围可略增，但要有上限。

## 10. 地图设计要求

每张原型地图至少放置：

| 地图类型 | 垂直移动点 |
|---|---|
| 主城 | 少量翻越/楼梯，不影响功能区 |
| 教学海岸 | 1 个低墙翻越，1 个抓边教学 |
| 野外 | 高低台、断桥、可跳下攻击区域 |
| 地牢 | 窄桥、矮墙、机关门、可攀爬梯 |
| Boss 房 | 通常减少复杂跑酷，只保留躲避平台/牵引点 |
| 终局地图 | 随机组合垂直模块，提高重复刷图变化 |

## 12. 验收标准

- 翻越必须落到正确位置，不穿墙。
- 抓边能稳定从平台边缘触发。
- 攀爬区域必须由 Marker 控制，不能误爬所有墙。
- 战术牵引目标点必须安全，不能把玩家拉进墙里。
- Boss 房的高机动点不破坏 Boss 机制。
- 垂直移动不能让玩家跳过关键任务门或地图边界。

## 13. 当前 Unity 实现映射

本节对应当前工程运行时代码，目标是先把可验证的垂直移动闭环接入玩家控制器，再给关卡侧保留 Marker 扩展入口。

### 13.1 核心脚本

新增运行时脚本：

- `PlayerTraversalController`
- `TraversalMarker`

已接入位置：

- `PlayerMovementController.Update`：玩家按跳跃时，先尝试 `TryStartTraversalFromJump`，失败后才走普通跳跃。
- `PrototypePlayerBootstrap.EnsureRuntimePlayerComponents`：运行时玩家自动补齐 `PlayerTraversalController`。
- `ArpgPrefabScaffolder.CreatePlayer`：生成玩家预制体时自动挂载 `PlayerTraversalController`。

### 13.2 Marker 优先规则

场景中可以放置 `TraversalMarker`，支持类型：

| Marker 类型 | 运行时状态 |
|---|---|
| `Vault` | `Traversal` |
| `LedgeGrab` | `LedgeGrab` |
| `Climb` | `Climb` |
| `WallRun` | `WallRun` |
| `GrapplePoint` | `GrapplePull` |

Marker 字段：

- `type`
- `inputMode`
- `entryPoint`
- `exitPoint`
- `duration`
- `maxApproachAngle`
- `pullSpeed`

当玩家按跳跃时，系统会在角色附近搜索 Marker，并检查进入角度与输入模式。命中 Marker 后优先使用 `exitPoint`，没有配置点时使用 Marker 自身位置。

### 13.3 无 Marker 兜底探测

没有 Marker 时，`PlayerTraversalController` 会按以下顺序尝试：

```text
疾跑贴墙跑墙 > 地面低障碍翻越 > 空中抓边停挂/攀上平台 > 普通跳跃
```

当前物理探测：

- `Vault`：前方低位射线命中障碍，再从上方向下找可落脚点。
- `LedgeGrab / Climb`：空中前方探墙，再从上方向下找平台出口；抓边会先进入短暂停挂，按跳跃/前进攀上，按闪避/后退松手。
- `WallRun`：疾跑且速度足够时，左右探墙，沿墙面切线移动。
- `GrapplePull`：对外提供 `TryGrappleTo(Vector3 target)`，供后续技能、场景锚点或交互物调用；路径被阻挡时会尝试提前安全落地，不能安全落地则不触发。

所有最终位移都走 `PlayerMovementController.BeginTraversalMove` 或 `BeginGrapplePull`，由移动控制器统一进入 `Traversal / Climb / WallRun / GrapplePull` 状态。

### 13.4 碰撞与落点安全

当前安全检查：

- 落点使用向下 Raycast 寻找地面。
- 落点使用 `CheckCapsule` 检查角色胶囊空间。
- 牵引路径使用 `CapsuleCast` 检查封闭墙体，按 `grappleStopBeforeObstacle` 提前截停。
- 位移过程使用 `PlayerMovementController.ClipDisplacementForCollision` 裁剪，防止直接穿墙。
- 自身 Collider 会被忽略，避免玩家胶囊误判为障碍。

### 13.6 已完成验收点

- 跳跃输入会优先触发地形交互，再回退普通跳跃。
- 关卡可以通过 `TraversalMarker` 明确控制翻越、抓边、攀爬、跑墙、牵引目标。
- 没有 Marker 的低障碍、平台边缘、墙面也有基础兜底识别。
- 抓边支持停挂、继续攀上、松手下落，避免误触发后只能强制攀上。
- 战术牵引会检查路径和落点，避免把玩家拉入墙体。
- 玩家生成链路和玩家预制体脚手架都会自动挂载新组件。
- `dotnet build RPG.sln --no-restore` 通过，无编译错误。

### 13.7 后续扩展

- 反身跳、沿边横移和体力消耗还未完整接入，当前版本先完成停挂、攀上、松手三种核心输入。
- 攀爬区域仍建议使用 Marker 控制，避免误爬所有墙体。
- 战术牵引的敌人拉拽、Boss 弱点、机关拉动需要在技能和交互物模块继续接入 `TryGrappleTo`。
- 跑墙当前是短距离位移原型，后续可补体力消耗、墙面冷却和动画事件。
