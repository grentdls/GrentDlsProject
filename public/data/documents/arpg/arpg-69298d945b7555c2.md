# 194 高级数值平衡规则：上限、递减、触发深度、性能预算

## 1. 为什么需要限制

高级词条如果不限制，会导致：
- 无限爆炸
- 无限召唤
- 无限冷却刷新
- Boss 秒杀
- 性能爆炸
- 构筑单一化

## 2. 推荐上限

```text
暴击率上限：95%
抗性基础上限：75%
吸血每秒上限：最大生命 12%
投射物分裂次数：默认 1
连锁次数：默认最多 5
AOE 重叠命中：默认最多 3
召唤物上限：按技能配置
真伤对 Boss：每秒上限
控制 Boss：转韧性
```

## 3. 递减收益

适合递减的属性：
```text
冷却缩减
控制持续时间
抗性上限
闪避
格挡
吸血上限
召唤物数量
```

## 4. 触发深度

```text
TriggerDepth 0：原始技能
TriggerDepth 1：词条触发效果
TriggerDepth 2：二次触发，默认禁止
```

规则：
```text
爆炸不能触发爆炸
反伤不能触发反伤
召唤物复制不能触发复制
触发技能默认不能再次触发同类技能
```

## 5. 性能预算

```text
同屏伤害跳字上限
同屏投射物上限
同屏召唤物上限
同屏持续区域上限
同屏触发 VFX 上限
```

超限处理：
- 合并 DOT
- 降低召唤物表现
- 隐藏低优先级 VFX
- 降低投射物拖尾
- 禁止低伤害触发连锁表现

## 6. 平衡验收

- 单个词条不能单独构成完整流派。
- 传奇机制必须有代价。
- Boss 不能被无限控制。
- 不允许无限递归触发。
- 高风险地图必须有高奖励。
