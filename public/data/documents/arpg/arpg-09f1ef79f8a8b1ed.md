# 186 冷却、充能、药剂与临时增益词条：刷新、充能、爆发窗口

## 1. 冷却缩减

```text
技能冷却缩短 10%
位移技能冷却缩短 20%
破韧时刷新重击技能
击杀精英时重置药剂冷却
```

字段：

```json
{
  "stat": "CooldownRecovery",
  "op": "Add",
  "value": 0.15,
  "conditions": {
    "skillTag": ["Movement"]
  }
}
```

---

## 2. 冷却刷新

```text
暴击时有 10% 概率刷新闪避冷却。
击杀敌人时有 5% 概率刷新当前技能。
破盾时刷新一个随机法术技能。
破韧时重置所有战士重击技能。
```

限制：
- 必须有内置冷却。
- 不能刷新自身触发源，除非明确允许。
- Boss 战可降低触发概率。

---

## 3. 技能充能

技能可拥有充能：

```text
最大充能 3
每 8 秒恢复 1 层
击杀敌人恢复 1 层
满充能时技能强化
```

配置：

```json
{
  "chargeId": "Charge_Dash",
  "maxCharge": 3,
  "recoverTime": 8.0,
  "gainOnKill": 1,
  "consumePerCast": 1
}
```

---

## 4. 充能消耗强化

```text
消耗全部充能，每层使伤害 +25%。
满充能释放时，投射物数量 +2。
满充能释放时，必定暴击。
```

---

## 5. 药剂词条

药剂不仅是回血，也可以是临时构筑按钮。

```text
药剂期间火焰伤害 +30%
药剂期间投射物 +1
药剂期间护盾回复不中断
药剂期间击杀敌人延长药剂 0.5 秒
药剂期间召唤物攻速 +25%
```

---

## 6. 爆发窗口

爆发窗口是短时间高收益状态。

触发来源：
```text
破盾
破韧
击杀精英
药剂开启
满连击
满蓄力
Boss 弱点击破
```

效果：
```text
伤害提高
暴击提高
资源不消耗
冷却加快
召唤物集火
投射物数量增加
```

---
