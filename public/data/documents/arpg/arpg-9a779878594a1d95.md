# 264 伤害跳字性能优化：对象池、TMP、合并、动画与上限

## 1. 必须对象池化

```text
DamageNumberManager
├── NormalPool
├── CriticalPool
├── HealingPool
├── StatusPool
└── BossDamagePool
```

生命周期：

```text
Get → 设置内容 → 播放动画 → Reset → Return
```

禁止每次 `Instantiate / Destroy`。

## 2. 预热数量

```text
普通伤害：50
暴击：20
治疗：10
状态提示：10
```

根据实际压测调整。

## 3. 数字合并

### DOT 合并

```text
0.5 秒内同目标、同伤害类型、同来源技能合并
```

### 多段技能合并

显示：

```text
1,840 ×6
```

而不是 6 个独立数字。

### 小伤害抑制

低于阈值的伤害可：

```text
不显示
降低刷新频率
并入累计数字
```

## 4. 同屏上限

建议：

```text
普通数字 30-40
暴击 10-15
状态提示 10
总量约 50
```

超限策略：

```text
优先合并
丢弃低优先级 DOT
缩短生命周期
复用最旧对象
```

## 5. TMP 优化

```text
预热 0-9、+、-、%、x 等字符
使用 TMP.SetText
元素颜色使用顶点色/TMP Color
尽量共享 TMP 材质
避免运行时扩充字体 Atlas
```

## 6. 动画

推荐手写轻量状态机：

```text
Spawn
Pop
Float
Fade
Return
```

只做位置、缩放、透明度插值。不要每个数字一个复杂 Animator 或新 Tween。

## 7. 统一 Screen Space Canvas

伤害数字由世界坐标转屏幕坐标，放在同一 Canvas 中，避免大量 World Space Canvas。

## 8. 跳字优先级

```text
Boss 暴击
玩家受到伤害
治疗
普通暴击
普通伤害
DOT
状态提示
```

高负载时先牺牲低优先级。

## 9. GC 风险

禁止高频：

```text
LINQ
new List
Lambda 捕获
字符串拼接
频繁协程
每次创建 Tween
```

## 10. 合并键

```text
TargetId + DamageType + SourceSkillId
```

## 11. 验收

```text
跳字无 Instantiate/Destroy
多段 DOT 能合并
同屏数字有上限
TMP 不动态扩图集
高频战斗 GC.Alloc 接近 0
```
