# 269 固定敌人生成器规则：等级、重复刷新、Boss、精英与特殊敌人

## 1. Prefab

```text
PF_EnemySpawnPoint
├── SpawnAnchor
├── FacingArrow
├── ActivationVolume
├── SpawnVFXPoint
├── EnemyFixedSpawner
├── EnemyLevelConfig
├── EnemyRespawnConfig
├── SpawnConditionList
├── DeathActionList
└── DebugRoot
```

```text
SpawnerId

ActivationMode
SpawnDelay
SpawnPositionMode
SpawnRotationMode
SpawnVFXId
SpawnSFXId
UseObjectPool

```

## 3. 等级规则

### 固定等级

```text
LevelMode = Fixed
FixedLevel = 35
```

### 随机等级区间

```text
LevelMode = RandomRange
MinLevel = 30
MaxLevel = 38
```

### 关卡等级偏移

```text
LevelMode = AreaLevelOffset
MinOffset = -2
MaxOffset = +3
```

### 玩家等级限制

仅用于动态副本：

```text
LevelMode = PlayerLevelClamp
MinLevel = 20
MaxLevel = 80
```

## 4. 敌人品质

可使用敌人默认品质，或覆盖为：

```text
Normal
Elite
Rare
Boss
Unique
TrainingDummy
```

扩展字段：

```text
ForcedAffixList
RandomAffixCount
LevelBonus
LootMultiplier
```

## 5. 出生位置

```text
SpawnerTransform
ChildSpawnAnchor
RandomSmallRadius
GroundSnap
NavMeshSnap
```

Boss 和剧情敌人建议使用固定 SpawnAnchor。

## 6. 出生朝向

```text
SpawnerForward
LookAtPlayerOnSpawn
LookAtTargetTransform
RandomYaw
UseEnemyDefault
```

Boss 建议使用固定朝向，避免演出开始时突然扭头。

## 7. 重复刷新

```text
RepeatSpawn
RespawnMode
RespawnDelay
MaxRespawnCount
RespawnOnlyWhenPlayerAway
MinPlayerDistance
RerollLevelOnRespawn
RerollAffixesOnRespawn
```

示例：

```text
死亡 10 秒后刷新
玩家必须离开 15 米
最多刷新 5 次
每次重新随机等级
```

## 8. Boss 规则

默认：

```text
RepeatSpawn = false
SaveState = true
ActivationMode = PlayerEnterArea / EncounterStart
```

生成前可执行：

```text
锁门
播放镜头
关闭传送门
显示 Boss 名称
启用 Boss HUD
```

死亡后可执行：

```text
标记遭遇完成
解锁门
生成宝箱
激活传送门
保存状态
```

## 9. 精英怪规则

```text
固定或随机精英词缀
额外等级
掉落倍率
携带护卫
特殊出生特效
```

## 10. 特殊敌人规则

通过条件与动作配置：

```text
无敌直到机关关闭
死亡后开门
死亡掉钥匙
受击后逃跑
任务激活后生成
夜间生成
```
