# 251 NPC 城镇服务系统总览：符石匠、铁匠、商店与功能解锁

## 1. 文档目标

本批文档用于补全城镇 NPC 的核心功能，使 NPC 不再只是打开商店窗口，而是承担稳定成长、装备加工、资源回收和流派构筑职责。

本批重点 NPC：

```text
符石匠
铁匠商人
```

符石匠负责：

```text
购买和出售符石
符石镶嵌、替换、拆卸
符石合成、升阶、分解
符石鉴定、修复、图鉴
符石批量整理与自动合成
```

铁匠商人负责：

```text
购买基础武器和防具
装备强化
装备品质提升
装备开孔
插槽改型
强化转移
装备修理与分解
```

---

## 2. 系统分工

```text
装备基底：决定基础攻击、防御和部位定位
随机词条：决定刷装深度
套装/传奇：决定流派机制
符石：提供可控、可替换的补强与小型机制
强化：提高装备基础数值
品质：提高基底属性效率
开孔：提高装备可塑性
```

符石匠不能修改装备随机前后缀；铁匠不能修改符石效果。这样可以避免两个 NPC 功能重叠。

---

## 3. 服务解锁阶段

### 初始开放

```text
购买普通符石
普通符石镶嵌
强化 +1 至 +3
品质提升至 10%
装备修理和普通分解
```

### 第二章开放

```text
无损拆卸普通/精良符石
同名符石合成
稀有符石商店
强化 +4 至 +7
品质提升至 15%
开启第一个插槽
强化转移
```

### 高级开放

```text
史诗符石合成
定向合成
传奇符石鉴定和拆卸
强化 +8 至 +10
品质提升至 20%
第二、第三插槽
插槽类型重铸
高阶强化保护
```

### 终局开放

```text
神器符石配方
传奇符石重构
符石升华
品质突破
特殊共鸣孔
套装共鸣加工
腐化装备有限加工
```

## 4. NPC 服务架构

```text
TownNpcServiceSystem
├── NpcServiceDefinition
├── NpcServiceUnlockCondition
├── NpcShopModule
├── NpcCraftModule
├── NpcDialogueModule
├── NpcReputationModule
├── NpcQuestModule
├── NpcPreviewModule
└── NpcTransactionLog
```

NPC 脚本只负责打开功能入口；具体商品、配方、费用和解锁条件全部由配置表决定。

---

## 5. 交互流程

```text
玩家靠近 NPC
→ 显示交互提示
→ 打开 NPC 主菜单
→ 显示已解锁功能
→ 选择具体服务
→ 放入装备/符石或选择商品
→ 显示结果预览
→ 显示材料和风险
→ 玩家确认
→ 扣除资源
→ 执行结果
→ 播放动画音效
→ 写入交易日志
```

## 9. 安全规则

不可逆操作必须二次确认：

```text
摧毁符石拆卸
传奇/神器合成
高阶开孔
品质突破
强化降级
腐化装备加工
分解套装或传奇装备
```

确认窗口必须显示：

```text
消耗资源
预期结果
成功率
失败损失
是否绑定
是否可撤销
```
