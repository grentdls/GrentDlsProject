## 2. 职业设计总原则

### 2.1 职业不是技能限制，而是起点和倾向

职业只决定：

```text
初始属性权重
默认武器熟练
天赋树起点
初始推荐技能
专精树入口
剧情身份包装
初始模型/动作风格
```

职业不决定：

```text
不能使用其他职业技能
不能装备其他武器
不能走其他天赋路线
不能改变 BD 方向
```

玩家后期可以跨职业构筑，但是跨得越远，需要付出更多属性、装备和天赋路径成本。

## 3. 属性三角

```text
力量：生命、护甲、重武器、眩晕、近战硬直抗性
敏捷：闪避、命中、攻速、位移、投射物、暴击
智慧：法术、护盾、精神资源、召唤、异常、触发
```

双属性职业：

```text
力量+敏捷：近战机动、弩枪、长矛、双持
敏捷+智慧：连段、毒、陷阱、闪避法术
力量+智慧：神圣、自然、护盾、图腾、变形
```

## 4. 职业资源系统

每个职业有一个“职业资源”，不替代生命/魔力/精神，而是形成职业手感。

| 职业 | 职业资源 | 获得方式 | 消耗方式 |
|---|---|---|---|
| 重甲战士 | 怒势 | 格挡、受击、重击命中 | 强化重击/防御 |
| 荒怒蛮王 | 血怒 | 攻击、受击、自伤 | 暴走、吸血、处决 |
| 长弓游侠 | 专注 | 移动射击、闪避、远距命中 | 强化射击 |
| 猎矛行者 | 狩印 | 投矛、穿刺、翻越 | 召回、追击、处决 |
| 弩炮佣兵 | 弹仓 | 装填、切换弹药 | 射击、榴弹、炮塔 |
| 圣锤裁决者 | 信念 | 圣域战斗、格挡、治疗 | 审判、庇护 |
| 风雷武僧 | 气脉 | 连段、闪避、异常触发 | 瞬步、强化招式 |
| 暗影刺客 | 影能 | 背击、暴击、陷阱触发 | 隐身、分身、毒爆 |
| 元素术士 | 秘能 | 施法、异常、护盾充能 | 元素超载 |
| 亡魂女巫 | 魂火 | 尸体、召唤物死亡、诅咒死亡 | 献祭、召唤爆发 |
| 变形德鲁伊 | 野性 | 人形/兽形交替 | 变形强化 |

## 6. 第一阶段优先开放建议

第一版不要直接做 12 职业全部可玩，否则动画、VFX、技能和装备工作量会爆炸。
