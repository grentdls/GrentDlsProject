# 122_终局秘境敌人与掉落：地图词缀、高阶怪物池

> 目标：定义通关后的终局刷图内容。终局秘境使用地图钥石进入，地图词缀改变怪物强度、掉落数量、掉落稀有度和事件出现概率。

---

## 1. 终局地图层级

```text
EndgameAtlas
├── T1-T5 低阶秘境，Lv50-60
├── T6-T10 中阶秘境，Lv61-72
├── T11-T15 高阶秘境，Lv73-85
├── 特殊秘境，Boss/材料/事件专精
└── 顶层秘境，赛季Boss和终局Boss
```

## 6. 终局秘境完成条件

终局地图可使用两套完成标准：

| 模式 | 完成条件 | 适合地图 |
|---|---|---|
| BossKill | 击败地图 Boss | 标准地图 |
| ClearProgress | 清理进度达到 80% | 开放地图 |
| EventComplete | 完成地图主事件 | 特殊秘境 |
| Survival | 存活到计时结束 | 防守秘境 |

## 9. 当前 Unity 实现映射

### 9.1 配置表落地

| 设计项 | 已实现配置 |

| 地图词缀 | `Assets/_Game/Resources/GameData/map_affixes.json`：新增 `MAP_MOD_MORE_ELITE`、`MAP_MOD_FIRE_GROUND`、`MAP_MOD_RIFT_BLIND`、`MAP_MOD_FAST_MONSTER`、`MAP_MOD_RESIST_FIRE`、`MAP_MOD_PROJECTILE`、`MAP_MOD_BOSS_RAGE`、`MAP_MOD_LOW_FLASK` |
| 高阶怪物池 | `monster_pools.json`：新增 `POOL_END_STAR`、`POOL_END_ASH`、`POOL_END_RIFT`、`POOL_END_UNDEAD`、`POOL_END_BEAST`、`POOL_END_MIXED` |
| 秘境场景内容 | `scene_maps.json`：`MAP_END_T01_001` 到 `MAP_END_T08_001` 已补齐怪物等级、主目标、刷怪组、事件、掉落点、地图边界与层级需求 |
| 遭遇与刷怪 | `encounter_areas.json`、`spawn_groups.json`：每张终局图包含普通战斗区、事件区、Boss 区三段结构 |
| 掉落 | `drop_tables.json`、`dungeon_loot_pools.json`、`equipment_drop_pools.json`：已拆分低阶/中阶/高阶、星界、灰烬、裂隙、亡军、荒兽主题掉落 |
| Atlas 节点 | `atlas_nodes.json`：新增 `ATLAS_END_T01_001` 到 `ATLAS_END_T08_001`，形成 T1-T8 推进链 |

### 9.2 运行时落地

| 运行时 | 实现点 |
|---|---|
| 地图钥石生成 | `MapKeyService` 支持 `blocked_affix_groups`，避免互斥词缀重复出现 |
| 词缀效果 | `MapKeyService.ApplyAffixes` 会把 MaxLife、伤害、投射物、精英数量、宝箱、祭坛、裂隙事件等 modifier 汇总到 `MapRunContext` |
| 地图生成 | `MapRuntimeGenerator` 已消费 `MonsterDensityBonus`、`ChestBonus`、`ShrineChanceBonus`、`DungeonEventChanceBonus` |
| UI 显示 | `ShopRuntime.DisplayCurrency` 已补充终局新材料中文显示名 |

### 9.3 验收口径

1. 终局钥石随机词缀不会出现同组冲突。
2. T1-T8 终局场景均能从场景表找到主目标、刷怪组、事件和奖励点。
3. 刷怪组引用的怪物池存在，怪物池引用的怪物存在。
4. 地图奖励点和事件奖励引用的掉落表存在。
5. 地图词缀在预览上下文中能改变数量、稀有度、密度、事件/宝箱倾向和怪物强度。
