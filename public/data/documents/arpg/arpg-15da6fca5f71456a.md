# 229 投射物视觉表现规则：拖尾、预警、镜头、轨迹可读性

## 1. 可读性目标

玩家必须看懂：

```text
从哪里来、飞向哪里、能否躲、何时命中
伤害类型、是否跟踪、是否爆炸、是否返回
```

## 2. 拖尾

参数：

```text
长度、宽度、颜色、透明度、噪声、发光、消散、速度映射
```

速度越快：拖尾更长、更亮、更细。终点冲刺时增强粒子密度和音效音高。

## 3. 轨迹预览

支持：

```text
直线、贝塞尔、抛物线、落点圆、反弹线、返回路径、环绕半径
```

玩家技能瞄准时可显示部分轨迹；技能页面预览可显示完整轨迹。

## 4. 跟踪提示

被锁定时：

```text
角色锁定图标、屏幕边缘方向箭头、接近音效、最终冲刺红色闪烁
```

## 5. 落点预警

```text
范围图形、剩余时间环、中心冲击点、伤害类型颜色
```

危险级别：

```text
Low、Medium、High、Fatal
```

影响预警亮度、音效和屏幕提示。

## 6. 螺旋和贝塞尔限制

```text
螺旋半径不能遮住目标
多枚飞弹需要相位错开
接近目标必须收束
贝塞尔不能明显穿墙
高伤曲线弹必须提示最终目标点
```

## 7. 元素视觉

```text
物理：白灰、金属火花
火焰：橙红、火星
冰冷：浅蓝、霜雾
闪电：蓝紫、折线电弧
毒素：黄绿、腐蚀液滴
暗影：紫黑、烟雾
神圣：金白、光尘
```

## 8. 命中反馈

根据伤害类型、强度、暴击、破盾和破韧触发：

```text
命中爆点、受击闪白、伤害跳字、短顿帧、局部震动、元素残留
```

## 9. 同屏性能预算

大量投射物时：

```text
降低次要投射物亮度
合并拖尾
隐藏远处粒子
减少动态灯光
限制低优先级命中闪光
优先显示高威胁弹
```

## 10. 技能预览

技能页面预览支持：

```text
显示中心路径、真实轨迹、控制点、速度、命中范围、目标、落点和阶段切换
```
