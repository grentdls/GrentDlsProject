# 232 环绕法球系统完整逻辑：规则环绕、碰撞伤害、动态重排

## 1. 核心定义

环绕法球是附着于单位的持续实体，围绕玩家身体中心的**水平面**旋转。

核心原则：

```text
以玩家 OrbitAnchor 为圆心。
默认使用世界 Up 轴，避免玩家站在斜坡时整个法球环倾斜。
法球排布必须规则等距。
数量变化时平滑重排，不瞬移。
主要伤害来自法球扫过或碰撞敌人。
```

推荐锚点：

```text
OrbitAnchor = 玩家根节点位置 + Y 轴 0.9~1.1 米
```

允许职业或模型单独校正：

```text
anchorLocalOffset
bodyRadiusCompensation
characterHeightScale
```

---

## 2. 法球环数据结构

```text
OrbitOrbController
├── OrbitAnchor
├── OrbitRingGroup[]
│   ├── RingId
│   ├── Radius
│   ├── HeightOffset
│   ├── Axis
│   ├── AngularSpeed
│   ├── Direction
│   ├── OrbList
│   └── ReflowState
├── CollisionScheduler
└── VisualController
```

一名角色可以存在多个环：

```text
内环：半径 1.3 米，近战碰撞
中环：半径 2.1 米，元素法球
外环：半径 3.0 米，防御/辅助法球
```

第一版建议最多 3 个 RingGroup。

---

## 3. 等角度排布

当同一环中有 N 个法球：

```text
angleStep = 360° / N
目标角度 = baseAngle + index × angleStep
```

示例：

```text
1 个：0°
2 个：0° / 180°
3 个：0° / 120° / 240°
4 个：0° / 90° / 180° / 270°
6 个：每 60° 一个
```

不同法球类型混排时仍以统一序列排布：

```text
火 / 冰 / 火 / 冰
而不是火球挤在一起、冰球挤在一起
```

也可配置排序模式：

```text
Alternating      类型交错
BySpawnOrder     按生成顺序
ByElement        按元素分组
CustomPriority   自定义优先级
```

## 4. 动态增减数量与平滑重排

数量从 3 增加到 4 时，旧法球目标角度会改变。

错误做法：

```text
直接把所有法球瞬移到 0/90/180/270°
```

正确流程：

```text
记录当前真实角度
重新计算每个法球目标角度
为旧法球分配“总旋转距离最短”的目标槽位
在 ReflowDuration 内平滑插值到新间隔
新法球从施法者手部/身体中心飞入空槽
重排期间仍保持环绕运动
```

推荐参数：

```text
reflowDuration = 0.25~0.45 秒
reflowEase = EaseOutCubic
spawnJoinDuration = 0.2~0.35 秒
```

分配算法：

```text
对旧法球当前角度排序
对新目标角度排序
尝试不同循环偏移
选择总角距离最小的映射
```

这样不会发生法球互相穿过半圈抢位置。

## 5. 环绕位置计算

默认水平环：

```text
x = cos(angle) × radius
z = sin(angle) × radius
y = heightOffset
```

最终世界位置：

```text
worldPosition = OrbitAnchor + right*x + forward*z + up*y
```

可选轻微呼吸：

```text
visualHeightOffset = sin(time × bobFrequency + phase) × bobAmplitude
```

注意：呼吸仅影响视觉，碰撞体是否同步由配置决定。

## 6. 旋转速度

核心参数：

```text
angularSpeedBase
angularSpeedAdd
angularSpeedMore
angularSpeedCap
rotationDirection
```

最终角速度：

```text
finalAngularSpeed = (base + flatAdd) × (1 + percentAdd) × moreMultiplier
```

建议范围：

```text
低速防御球：60~100°/s
普通伤害球：120~220°/s
高速切割球：240~420°/s
极限临时加速：不超过 720°/s
```

转速越高，扫过同一敌人的频率越高，因此不能只靠提高转速无限提高 DPS，必须配合命中冷却。

## 7. 碰撞伤害模式

### 7.1 每次进入碰撞 ContactEnter

```text
法球进入 Hurtbox 时造成一次伤害
离开后再次进入才能再伤害
```

适合：
- 大半径法球
- 低速法球
- 清晰的“扫过一次”手感

### 7.2 每目标冷却 PerTargetCooldown

```text
同一法球对同一目标每 X 秒最多命中一次
```

推荐：

```text
0.25~0.8 秒
```

### 7.3 每圈一次 OncePerRevolution

每个法球对同一目标每完成一圈最多命中一次。

适合高转速技能，防止转速带来指数收益。

### 7.4 全环共享冷却 SharedRingCooldown

同一环中的所有法球对同一目标共享冷却。

适合数量成长非常高的玩法。

## 8. 高速扫掠检测

高速法球不能只用普通 Trigger，否则会穿过小型敌人。

推荐每个 FixedUpdate：

```text
记录上帧位置
计算本帧位置
用 SphereCast / CapsuleCast 扫过这段弧线的近似线段
必要时把弧线分成 2~4 段检测
```

碰撞半径：

```text
collisionRadius = visualRadius × 0.65~0.9
```

视觉可以略大于实际判定，减少“不碰也中”的感觉。

## 10. 数量来源与数量层级

法球数量分为：

```text
BaseCount        技能基础数量
PermanentCount   装备/天赋永久加成
TemporaryCount   Buff 临时数量
EchoCount        仅本次触发生成，不进入常驻环
ReserveCount     等待加入的法球
```

最终常驻数量：

```text
finalCount = clamp(Base + Permanent + Temporary, 0, MaxCount)
```

建议：

```text
普通构筑：3~8 个
强化构筑：8~12 个
终局极限：12~16 个
单环建议不超过 12，更多数量分配到第二环
```

---

## 11. 法球持续时间

```text
Permanent       持续存在，死亡/卸下技能时移除
Duration        持续 X 秒
ChargeBased     消耗次数后消失
HitBased        命中 N 次后消失
ShieldBased     吸收伤害后消失
```

临时法球到期时：

```text
淡出
飞回玩家
爆炸
转化为掉落球
```

---

## 12. 法球被阻挡与地形

默认法球属于角色附属实体：

```text
不被普通墙壁卡住
视觉可穿过窄墙，但敌人隔墙不可受伤
```

推荐伤害时增加视线检测：

```text
LineOfSightCheck = true
```

Boss 场景可配置允许穿墙，普通地图默认不允许隔墙伤害。

## 13. 典型技能流程

### 炎环法球

```text
生成 3 个火球
半径 1.8 米
转速 180°/s
每个火球对每个敌人 0.45 秒命中一次
命中施加燃烧
拾取生命球后 4 秒内临时增加 1 个火球
```

### 雷切星环

```text
生成 6 个雷刃球
半径 2.3 米
共享命中冷却 0.25 秒
暴击时临时提高转速 30%
每转满 3 圈释放一次向外电弧
```
