# 188 高级防具与首饰词条库：生命、护盾、抗性、反伤、功能

## 1. 头盔词条

```text
技能冷却缩短。
召唤物数量 +1。
击杀被诅咒敌人时扩散诅咒。
低血时获得控制抗性。
满盾时法术暴击率提高。
```

## 2. 胸甲词条

```text
最大生命提高。
最大护盾提高。
受到近战命中时反伤。
护盾破裂后获得短暂无敌。
低血时受到伤害降低。
受到暴击时获得护盾。
```

## 3. 手套词条

```text
击中附加元素伤害。
攻击速度提高。
击中时有概率施加流血。
暴击时恢复能量。
召唤物击中时有概率施加中毒。
```

## 4. 鞋子词条

```text
移动速度提高。
闪避后下次技能伤害提高。
移动时流血伤害降低。
远距离命中后获得加速。
踩过燃烧区域时获得火焰增伤。
```

## 5. 戒指词条

```text
元素抗性。
击杀回血。
击杀回能。
击中感电敌人时释放电弧。
燃烧敌人死亡时扩散燃烧。
```

## 6. 项链词条

```text
全部属性。
关键技能等级 +1。
异常效果提高。
控制持续时间提高。
真实伤害提高但不能暴击。
```

## 7. 腰带词条

```text
药剂持续时间提高。
药剂期间投射物数量 +1。
药剂期间护盾回复不中断。
药剂使用时解除一个异常。
击杀敌人延长药剂持续时间。
```

## 8. 防具传奇词条示例

```text
你的护盾无法自然回复，但击中敌人会回复护盾。
生命回复改为护盾回复，护盾上限提高。
受到伤害时，有概率召唤一个护卫骷髅。
低血时吸血翻倍，但最大护盾变为 0。
格挡时释放一次扇形冲击波。
```
