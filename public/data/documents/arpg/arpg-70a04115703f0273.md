# 79 单位名称与头顶信息规则：NPC、交互物、敌人、友方

> 项目：Unity 3D ACT 暗黑刷宝 ARPG  
> 文档批次：第七批 HUD 全规则  
> 原则：参考同类暗黑刷宝 ARPG 的信息层级与战斗可读性，不复制任何商业游戏的 UI 视觉、图标、专有名称或具体数值。  
> 目标：所有头顶信息、血条、跳字、Buff、交互提示、拾取标签、Boss 条、目标提示都可以由策划配置，程序只实现通用规则。

## 1. 设计目标

名称与头顶信息负责告诉玩家“这个对象是谁、能不能打、能不能交互、是否重要”。

本项目单位头顶信息分为 6 类：

```text
UnitNameplate
├── PlayerSelf          # 玩家自己，默认不显示名称
├── FriendlyNPC         # 城镇 NPC / 任务 NPC / 功能 NPC
├── FriendlySummon      # 玩家召唤物 / 队友
├── EnemyCommon         # 普通敌人
├── EnemyEliteRare      # 精英 / 稀有 / 词缀怪
├── EnemyBoss           # Boss / 小 Boss / 事件首领
└── InteractableObject  # 宝箱 / 机关 / 传送门 / 任务物
```

## 2. 头顶信息组成

### 2.1 通用结构

```text
Prefab_Nameplate_Base
├── Root_RectTransform
│   ├── CanvasGroup
│   ├── OffsetFollower                 # 绑定 3D Anchor
│   ├── VisibilityController            # 距离/遮挡/状态控制
│   ├── LayoutGroup
│   │   ├── Icon_FunctionOrRank          # 功能/稀有度/阵营图标
│   │   ├── Text_Name                    # 名称
│   │   ├── Text_Subtitle                # 副标题：商人/任务/词缀/等级
│   │   ├── StateIcons_Row               # 任务、可交互、锁定等状态
│   │   └── Healthbar_Slot               # 可选，小型血条挂点
│   └── Anim_Nameplate
```

### 2.2 3D Anchor 规则

每个可显示头顶信息的对象必须提供锚点：

```text
UnitRoot
├── ModelRoot
├── ColliderRoot
├── HUDAnchor_Head          # 人形单位头顶
├── HUDAnchor_Center        # 大体型单位中心上方
├── HUDAnchor_Interact      # 交互物提示位置
├── HUDAnchor_Target        # 锁定框/目标框位置
└── HUDAnchor_Boss          # Boss 特殊机制提示位置
```

锚点高度规则：

| 对象 | 锚点高度 |
|---|---|
| 人形普通怪 | 模型最高点 + 0.35m |
| 大型怪 | 模型包围盒顶部 + 0.5m |
| 超大型 Boss | 屏幕空间 Boss 条为主，头顶信息放中心可见处 |
| NPC | 头顶 + 0.25m |
| 宝箱 | 箱体顶部 + 0.35m |
| 地面机关 | 机关中心 + 0.5m |
| 传送门 | 门中心上方 + 1.0m |

## 3. NPC 名称规则

### 3.1 NPC 类型

| NPC 类型 | 显示内容 | 显示规则 | 图标 |
|---|---|---|---|
| 普通居民 | 名称 | 靠近显示 | 无或小点 |
| 主线任务 NPC | 名称 + 主线标记 | 远距离可见 | 主线图标 |
| 支线任务 NPC | 名称 + 支线标记 | 中距离可见 | 支线图标 |
| 商店 NPC | 名称 + 功能名 | 主城常驻/近距高亮 | 钱袋图标 |
| 铁匠 | 名称 + 打造/分解 | 主城常驻 | 铁砧图标 |
| 技能商人 | 名称 + 技能训练 | 主城常驻 | 技能书图标 |
| 传送 NPC | 名称 + 传送 | 主城常驻 | 门/罗盘图标 |
| 仓库管理员 | 名称 + 仓库 | 主城常驻 | 箱子图标 |
| 赛季机制 NPC | 名称 + 机制名称 | 解锁后显示 | 特殊机制图标 |

### 3.2 NPC 显示状态

```text
Far       ：只显示任务/功能图标，透明 45%
Near      ：显示名称 + 功能副标题，透明 100%
Focused   ：名称放大 1.08，出现交互按键
Talking   ：隐藏头顶交互按键，打开对话 UI
Disabled  ：名称灰色，副标题显示“暂未解锁”
```

### 3.3 NPC 文本格式

```text
[功能图标] NPC名称
副标题：铁匠 / 技能商人 / 仓库 / 传送 / 任务委托
```

示例：

```text
[铁砧] 赫伦
铁匠 · 打造 / 分解 / 修理
```

### 3.4 NPC 任务标记

| 状态 | 头顶图标 | 颜色建议 | 动画 |
|---|---|---|---|
| 可接主线 | 主线叹号 | 金色系 | 慢速上下浮动 |
| 可交主线 | 主线问号 | 金色系 | 闪光 |
| 可接支线 | 支线叹号 | 蓝色系 | 慢速呼吸 |
| 可交支线 | 支线问号 | 蓝色系 | 闪光 |
| 任务进行中 | 小圆点 | 白/灰 | 无 |
| 暂未解锁 | 锁 | 灰色 | 无 |

## 4. 敌人名称规则

### 4.1 普通敌人

默认策略：**不常驻显示名称，避免屏幕污染。**

显示条件：

- 被玩家鼠标悬浮。
- 被玩家锁定。
- 正在攻击玩家。
- 受到玩家伤害后的 2 秒内。
- 精英怪召唤的关键小怪。

显示内容：

```text
敌人名称
等级 / 类型标签，可选
```

普通怪不显示复杂词缀，不显示抗性，不显示完整状态图标，只在目标面板显示摘要。

### 4.2 魔法/强化怪

显示条件比普通怪更宽松：

- 距离 25m 内进入战斗显示。
- 受击后显示 4 秒。
- 被锁定后常驻。

显示内容：

```text
[强化图标] 敌人名称
强化词缀摘要：冰霜 / 迅捷 / 护盾
```

### 4.3 精英/稀有怪

精英怪必须一眼可见。

显示内容：

```text
[精英图标] 精英名称
词缀 1 · 词缀 2 · 词缀 3
小型血条 / 护盾条 / 韧性条
```

显示规则：

- 战斗中常驻。
- 离屏时可显示边缘威胁箭头。
- 玩家被精英技能锁定时，精英名称高亮。
- 精英死亡后名称快速淡出，奖励标签出现。

### 4.4 Boss 名称

Boss 使用双层显示：

1. 顶部屏幕空间 Boss 大血条。
2. 头顶世界空间小标签，可选。

Boss 头顶名称只用于定位，Boss 信息以大血条为主。

显示内容：

```text
Boss 名称
阶段名 / 机制状态，可选
```

例如：

```text
黑炉守门者
阶段二：熔铁狂怒
```

## 5. 友方与召唤物名称规则

### 5.1 玩家自身

玩家默认不显示自己的头顶名称。以下情况才显示：

- 多人模式。
- 观战模式。
- 截图/录像模式开启名称。
- 编辑器调试。

### 5.2 召唤物

召唤物 HUD 需要低干扰：

| 召唤物类型 | 默认名称 | 血条 | 备注 |
|---|---|---|---|
| 普通短时召唤物 | 不显示 | 受伤时显示 | 避免挡住敌人 |
| 重要召唤物 | 显示小图标 | 可显示 | 如永久仆从 |
| 图腾/炮塔 | 显示功能图标 | 显示耐久条 | 可交互/可被攻击 |
| 队友单位 | 显示名称 | 显示血条 | 多人/AI 队友 |

召唤物名称示例：

```text
[仆从图标] 骨卫 3
[炮塔图标] 重弩炮塔
```

## 6. 交互物名称规则

### 6.1 交互物分类

| 类型 | 示例 | 名称显示 | 交互提示 |
|---|---|---|---|
| 宝箱 | 普通箱、稀有箱、诅咒箱 | 近距显示 | 开启 |
| 可破坏物 | 木桶、罐子、石柱 | 默认不显示 | 可选 |
| 机关 | 拉杆、按钮、压力板 | 近距显示 | 激活 |
| 任务物 | 祭坛、钥匙、遗物 | 常驻/任务范围显示 | 拾取/调查 |
| 传送门 | 城镇门、区域门、地图门 | 中远距显示 | 进入 |
| 商店货架 | 商人附近陈列物 | 不显示 | 不交互或装饰 |
| 地图装置 | 终局地图装置 | 主城常驻 | 打开地图装置 |

### 6.2 交互物标签结构

```text
[对象图标] 对象名称
[E] 开启 / 调查 / 进入 / 对话 / 使用
```

### 6.3 不同状态

| 状态 | 显示效果 |
|---|---|
| 可交互 | 正常亮度，按键提示显示 |
| 距离不足 | 名称显示，按键提示隐藏或变灰 |
| 条件不足 | 名称显示，副标题显示缺少钥匙/任务未完成 |
| 已使用 | 名称灰色，按键隐藏 |
| 冷却中 | 显示倒计时 |
| 危险交互 | 红/橙提示，二次确认或长按 |

## 7. 名称颜色与字体规则

### 7.1 对象颜色

| 对象 | 颜色倾向 | 说明 |
|---|---|---|
| 普通 NPC | 暖白 | 主城舒适、低压力 |
| 功能 NPC | 浅金/浅蓝 | 功能区分 |
| 任务 NPC | 金/蓝 | 主线与支线区分 |
| 普通敌人 | 灰白/淡红 | 不抢屏 |
| 强化敌人 | 蓝/紫 | 与普通怪区分 |
| 精英/稀有怪 | 金/橙/紫 | 强威胁 |
| Boss | 深红/金 | 严肃、压迫 |
| 友方召唤 | 青绿/白 | 与敌人区分 |
| 任务物 | 金色/青色 | 可识别 |
| 危险机关 | 红/橙 | 警告 |

### 7.2 字号规则

| 类型 | 字号 | 描边 | 阴影 | 备注 |
|---|---:|---|---|---|
| NPC 名称 | 18-22 | 1px | 有 | 主城可读 |
| 普通怪名称 | 16-18 | 1px | 有 | 不抢屏 |
| 精英怪名称 | 20-24 | 1.5px | 有 | 强化可读性 |
| Boss 名称 | 28-36 | 2px | 有 | 顶部大血条使用 |
| 交互物名称 | 18-22 | 1px | 有 | 与按键提示一起显示 |
| 拾取标签 | 16-24 | 1px | 有 | 按稀有度变化 |

## 8. 名称重叠避让

当多个名称重叠时：

1. 当前锁定目标永远最上层。
2. 任务目标高于普通 NPC。
3. 精英怪高于普通怪。
4. 高价值掉落高于低价值掉落。
5. 同类对象按屏幕 Y 轴排序，上方对象先显示。
6. 普通怪超过显示上限时，只显示最近、正在攻击、刚受击的单位。

避让算法建议：

```text
每帧收集候选 HUD
→ 按优先级排序
→ 投射到屏幕坐标
→ 检测矩形重叠
→ 高优先级保留
→ 低优先级向上/左右偏移
→ 偏移失败则淡出或隐藏
```

## 11. 验收标准

- 主城 20 个 NPC 同屏时，功能 NPC 与任务 NPC 一眼可识别。
- 战斗中 50 个普通怪不会铺满屏幕名称。
- 精英怪进入战斗后名称和词缀摘要能持续显示。
- Boss 战顶部大血条为主，头顶名称不遮挡战斗。
- 可交互物靠近时显示按键提示，远离后自动淡出。
- 手柄模式下可交互焦点对象名称有明显高亮。
