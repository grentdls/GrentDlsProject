# 274 敌人目标选择与仇恨系统：角色、召唤物、最近目标与伤害仇恨

## 1. 目标系统目的

敌人不应只写死追玩家角色，需要支持玩家阵营中的多种单位：

```text
玩家
队友
召唤物
临时盟友
护卫单位
诱饵
嘲讽单位
```

## 2. 有效目标条件

```text
属于敌对阵营
未死亡
未被销毁
可被目标选择
不处于完全隐身
处于可寻路或可攻击状态
```

## 3. 默认目标选择

### 警戒触发

```text
选择警戒范围内最近的玩家阵营单位
```

### 受击触发

```text
攻击来源有效：优先攻击来源
攻击来源无效：选择最近玩家阵营单位
```

这满足“超远距离受击也会反击”的需求。

## 4. 目标评分

推荐评分：

```text
Score =
距离分
+ 伤害仇恨
+ 嘲讽值
+ 目标类型权重
+ 当前目标保持加成
+ 可达性加成
```

## 5. 目标类型权重

示例：

```text
玩家：1.0
队友：0.9
召唤物：0.7
诱饵：由嘲讽值决定
```

不同敌人可覆盖：

```text
猎人优先玩家
食尸鬼优先低生命目标
反召唤敌人优先召唤物
Boss 根据技能切换目标
```

## 6. 仇恨来源

```text
造成伤害
治疗队友
施加控制
破盾
嘲讽
靠近
剧情强制
```

第一版可以只实现：

```text
距离 + 伤害 + 嘲讽
```

## 7. 伤害仇恨

```text
Threat += Damage × ThreatMultiplier
```

DOT 可按一定时间聚合，避免每跳创建记录。

## 8. 最近目标模式

用户要求的简单模式：

```text
TargetSelectionMode = NearestPlayerFactionUnit
```

用于大部分普通敌人。

受击后：

```text
先检查攻击来源
再扫描最近玩家阵营单位
```

## 9. 目标切换

切换条件：

```text
当前目标死亡
当前目标不可达
新目标仇恨超过阈值
受到强制嘲讽
Boss 阶段技能要求
```

为了避免来回抖动：

```text
TargetSwitchCooldown
KeepCurrentTargetBonus
ThreatSwitchThreshold
```

## 10. 目标丢失

当前目标失效后：

```text
立即从玩家阵营单位中重新选择
```

在 UntilDeath 模式下：

```text
只要还有有效玩家阵营目标，就继续战斗
```

全部目标消失时：

```text
保持 SearchTarget
等待玩家复活或重新出现
或按关卡规则暂停 AI
```

## 11. 可达性

不能只按直线距离选择，否则可能选择墙后不可达目标。

可选检查：

```text
NavMesh 可达
攻击射线可达
目标高度差
路径长度
```

普通敌人可先选近目标，再异步检查路径。

## 12. 召唤物规则

召唤物被选为目标后：

```text
召唤物死亡 → 重新选目标
召唤物消失 → 立即清除引用
召唤物离开战斗 → 降低仇恨
```

## 13. 嘲讽

```text
强制目标持续时间
嘲讽结束后保留部分仇恨
Boss 可缩短嘲讽持续时间
```

## 14. 目标注册表

推荐：

```text
FactionTargetRegistry
```

统一管理当前可被敌人选择的玩家阵营单位，避免每个敌人频繁全场搜索。

## 15. JSON 示例

```json
{
  "selectionMode": "ThreatScore",
  "prioritizeDamageSource": true,
  "fallbackMode": "NearestPlayerFactionUnit",
  "targetWeights": {
    "Player": 1.0,
    "Companion": 0.9,
    "Minion": 0.7
  },
  "switchCooldown": 1.0,
  "keepCurrentTargetBonus": 15
}
```
