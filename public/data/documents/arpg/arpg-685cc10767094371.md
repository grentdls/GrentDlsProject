# 271 敌人列表配置器：权重、等级、精英概率、词缀与测试场景

## 1. EnemySpawnListDefinition

敌人列表应使用 ScriptableObject 或配置表，不在区域生成器中逐个拖 Prefab。

```text
EnemySpawnListDefinition
├── ListId
├── DisplayName
├── Tags
├── EntryList
├── GlobalLevelRule
├── EliteRule
├── AffixRule
└── BudgetRule
```

## 2. 条目字段

```text
EnemyDefinitionId
Weight
MinCount
MaxCount
GuaranteedCount
LevelOverride
RankOverride
CanRepeat
MaxPerSpawn
RequiredCondition
ForbiddenCondition
AffixPoolId
ThreatCost
```

## 3. 权重抽取

示例：

| 敌人 | 权重 |
|---|---:|
| 骷髅战士 | 50 |
| 骷髅弓手 | 30 |
| 骷髅法师 | 15 |
| 骷髅队长 | 5 |

抽取时先过滤不满足条件的条目，再按权重抽取。

## 4. 保证数量

可配置：

```text
至少 1 个近战
至少 1 个远程
最多 2 个法师
队长最多 1 个
```

生成顺序：

```text
先生成 GuaranteedCount
→ 再按权重补足剩余数量
```

## 5. 威胁预算

每个敌人有 ThreatCost：

```text
普通近战：10
远程：15
法师：20
精英：50
Boss：200
```

区域预算 100 时，系统可随机组合但不能超过预算容差。

## 6. 精英概率

```text
EliteChance
MaxEliteCount
EliteLevelBonus
EliteAffixPoolId
EliteAffixCountRange
```

例如：

```text
每轮 12% 概率将一只普通怪升级为精英
一轮最多 1 只精英
```

## 7. 特殊词缀

列表可统一附加：

```text
火焰区域敌人更容易获得火焰词缀
毒沼区域敌人获得毒素抗性
终局区域允许双词缀精英
```

## 8. 条件条目

条件示例：

```text
世界难度达到 3
任务完成
夜间
玩家等级达到
地图词缀存在
上轮未生成该敌人
```

## 9. 列表组合

支持嵌套列表：

```text
森林普通列表
森林精英列表
森林稀有事件列表
```

主列表可引用子列表，但要限制递归深度。

## 10. 配置器编辑器

建议窗口：

```text
Tools / Game / Enemy Spawn List Editor
```

功能：

```text
搜索敌人
拖入列表
调整权重
批量设置等级
设置数量上下限
预览抽取结果
模拟 1000 次生成分布
检查权重和条件
保存 ScriptableObject
```

## 11. 测试场景

建立：

```text
Scene_EnemySpawner_Test
```

场景包含：

```text
固定生成器测试区
区域生成器测试区
NavMesh 地形
障碍物区
坡地区
玩家安全区
木桩区
Boss 生成区
测试控制面板
```

测试面板按钮：

```text
生成一次
清除当前敌人
模拟全部死亡
立即刷新
暂停生成器
重载配置
显示采样点
显示敌人归属
打印统计
```
