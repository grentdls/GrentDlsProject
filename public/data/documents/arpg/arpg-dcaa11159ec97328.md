# 134 UI可视性改版实施清单：任务拆分与验收标准

## 1. 改版目标
把现有过度文字化的 UI，升级为“可读、可扫、可比较、可反馈”的高信息密度 ARPG UI。

---

## 2. 实施顺序

### 阶段 A：样式库与按钮反馈（优先级 S）
1. 建立 Color Token
2. 建立 Text Style
3. 建立 Panel 预制体
4. 建立 Button 预制体状态机
5. 建立 Tooltip Base
6. 建立 Chip 系统

### 阶段 B：技能页重构（优先级 S）
1. 技能卡片重做
2. 技能详情区块重构
3. 辅助模块区块重构
4. 技能成长对比模块
5. 绑定与推荐搭配模块

### 阶段 C：装备页重构（优先级 S）
1. 装备 Tooltip 重做
2. 词条分组
3. 对比模块
4. 镶孔与强化模块
5. 装备位提示与替换提示

### 阶段 D：天赋页重构（优先级 A）
1. 节点视觉分级
2. 节点详情卡重做
3. 路径与点数预览
4. 属性变化预览
5. 天赋搜索与标签过滤

### 阶段 E：全局收口（优先级 A）
1. 商店物品详情同步新样式
2. 仓库、掉落 Tooltip 同步
3. 手柄焦点适配
4. 音效与动效补齐

---

## 3. 策划与程序配合点

### 3.1 策划需要补的数据
- 技能标签
- 技能核心机制摘要
- 装备词条分组标记
- 天赋节点分类标签
- 推荐搭配数据
- 可比较字段名单

### 3.2 程序需要支持
- Tooltip 比较系统
- 节点预览模拟计算
- Button 状态机
- Hover/Press 动画事件
- 动态 Chip 生成
- 条件未满足原因返回

### 3.3 UI 需要产出
- 样式库预制体
- 页面的新版布局
- Icon/Chip/Panel 图集
- 动效与状态动画

---

## 4. 关键验收清单

### 4.1 技能页验收
- 是否有明显头部识别区
- 是否拆出核心参数区
- 是否拆出主效果区
- 是否拆出成长区
- 是否拆出辅助模块区
- 是否可快速识别技能标签

### 4.2 装备页验收
- 是否能一眼看出稀有度与部位
- 是否主词条上提
- 是否前缀/后缀/特殊词条分组
- 是否支持与当前装备比较
- 是否镶孔与强化独立显示

### 4.3 天赋页验收
- 是否节点类型可视化
- 是否标签化分类清晰
- 是否点亮预览明确
- 是否路径与点数需求清楚

### 4.4 按钮与反馈验收
- 所有按钮是否有 Hover
- 所有按钮是否有 Press
- 所有页签是否有 Selected
- 是否有 Disabled 理由提示
- 手柄焦点是否完整

---

## 5. 量化标准
- 识别技能核心类型时间：<= 2 秒
- 识别装备主价值时间：<= 2 秒
- 识别天赋主收益时间：<= 2 秒
- 看懂装备对比结论时间：<= 3 秒
- Hover 延迟：<= 0.12 秒
- Tooltip 出现：<= 0.2 秒

---

## 6. 最终交付要求
最终 UI 改版完成后，至少以下界面全部上线新版样式：
- 技能页
- 技能 Tooltip
- 装备页
- 装备 Tooltip
- 天赋页
- 天赋节点详情
- 商店物品详情
- 背包物品详情
- 所有主按钮 / 次按钮 / 页签 / Toggle

---

## 7. 推荐先做的最小闭环
第一周建议先完成：
- Button 样式库
- Tooltip Base
- Skill Detail 新版
- Item Tooltip 新版
- Passive Node Detail 新版

先让三个“最常看”的详情窗明显变强，再逐步替换整页。
