# 108_仓库符石匠分解兑换NPC_资产管理与装备扩展服务

> 目标：补齐主城中长期资产管理与装备扩展功能，包括仓库、材料仓库、符石、珠宝、兑换、回收和角色共享。

---

## 1. 仓库管理员内容

NPC：仓库管理员·摩尔  
位置：东南仓库区

### 1.1 仓库功能

```text
仓库 UI
├── 个人仓库
├── 账号共享仓库
├── 材料仓库
├── 地图仓库，终局后跳转
├── 快速整理
├── 搜索 / 筛选
└── 扩容
```

| 仓库类型 | 说明 | 开放 |
|---|---|---|
| 个人仓库 | 当前角色独享 | 默认 |
| 共享仓库 | 同存档角色共享 | 默认 |
| 材料仓库 | 自动存放材料 | 教学 Boss 后 |
| 地图仓库 | 存地图钥石 | 通关后 |
| 赛季仓库 | 存赛季道具 | 赛季开放 |

### 1.2 仓库格子规则

| 仓库 | 初始页数 | 每页大小 | 扩容 |
|---|---:|---:|---|
| 个人仓库 | 2 | 12 × 8 | 金币/任务奖励 |
| 共享仓库 | 1 | 12 × 8 | 稀有材料 |
| 材料仓库 | 分类无限堆叠 | 列表式 | 不扩容 |
| 地图仓库 | 10 × 12 | 地图专用 | 终局任务扩容 |

### 1.3 快速整理规则

| 按钮 | 功能 |
|---|---|
| 存入材料 | 背包材料全部进入材料仓库 |
| 存入地图 | 地图钥石进入地图仓库 |
| 自动堆叠 | 相同物品合并 |
| 按品质排序 | 普通→魔法→稀有→传奇 |
| 按部位排序 | 武器、防具、饰品、材料 |
| 搜索 | 根据名称、标签、等级筛选 |

开放：第 2 章荆棘墓园后  
位置：铁匠铺旁

### 2.1 功能总览

```text
符石匠 UI
├── 符石镶嵌
├── 符石拆卸

├── 符石升级
├── 珠宝镶嵌，后期
```

| 星火符石 | 智慧孔 | 火焰 / 法术 |

## 8. 当前 Unity 实现映射

本批已落地为可运行逻辑，而不是仅文档占位：

| 模块 | 实现位置 | 当前能力 |
|---|---|---|
| 资产服务运行时 | `Assets/_Game/Scripts/AssetServices/AssetServicesRuntime.cs` | 个人/共享仓库存取、扩容、排序、快速存入、符石购买/镶嵌/拆卸/合成、材料兑换 |
| 资产服务 UI | `Assets/_Game/Scripts/UI/ArpgAssetServicesWindow.cs` | 页签：个人仓库、共享仓库、材料仓库、地图仓库、符石匠、材料兑换 |
| 装备符石槽 | `Assets/_Game/Scripts/Items/ItemInstance.cs` | `SocketedRuneIds` 与装备 `Sockets` 对齐，支持孔位内符石状态 |
| 背包移动接口 | `Assets/_Game/Scripts/Items/InventoryEquipment.cs` | 支持按实例移除、排序和容量读取 |
| 配置表 | `Assets/_Game/Resources/GameData/stash_configs.json`、`runes.json`、`exchanges.json` | 仓库容量/扩容、符石商品/兼容孔、兑换成本/奖励全部数据化 |
| NPC 接入 | `Assets/_Game/Resources/GameData/npcs.json`、`npc_spawns.json`、`npc_services.json` | 仓库管理员·摩尔、符石匠·希尔、回收师·塔姆已接入主城服务 |

补充说明：

- 材料仓库第一版与 `ShopCurrencyWallet` 共用无限堆叠数据，铁匠分解、商店购买和兑换奖励都会显示在材料页。
- 地图仓库第一版与 `MapKeyInventoryComponent` 共用钥石库，能从仓库页跳转秘境商人、秘境装置和 Atlas。
- 兑换 `EX_005` 会把 `map_mat_boss` 转成随机 T1 地图钥石并写入地图钥石库。
