# 中文化与 3D 表现层实现说明

## 实现范围

本轮将玩家可见文本统一为简体中文，并将城市建造和幸存者战斗的核心场景表现改为运行时生成的透视 3D 世界。现有纯 C# 规则、存档和数值模拟仍是唯一权威数据源；3D 表现层只读取状态并负责模型、相机、特效和交互映射，避免视觉改造破坏既有玩法结果。

屏幕固定 HUD、按钮、弹窗和伤害数字继续使用竖版 uGUI。这些内容属于屏幕空间信息层，不是 2D 游戏场景；角色、敌人、地块、建筑、子弹、拾取物、地面预警和攻击反馈均由真实的 Unity 3D 对象表现。

## 中文化

- 建筑、英雄、资源、卡牌、关卡、技能、战斗消息、建造订单和全部主要 UI 页面均使用中文显示。
- 枚举不再直接通过 `ToString()` 暴露给玩家，由 `ChineseText` 统一转换为中文语义。
- 数字缩写改为 `万`、`百万`，时间和等级格式改为中文。
- 项目内嵌 `NotoSansSC-UI.otf` 中文字体子集，运行时优先从 `Resources/Fonts` 加载，不依赖手机或抖音容器提供系统字体。
- 字体基于 Noto Sans CJK SC，随项目保留 SIL Open Font License；子集只包含当前运行时代码所需字符和基础拉丁/符号字符，以控制 WebGL 包体。

## 城市建造 3D 世界

- 使用独立透视相机、方向光、城市地面、道路和街灯组成竖版城市世界。
- 城市页的场景区域保持透明，由 3D 相机直接显示模型；顶部资源、任务、队列与底部导航仅占据边缘，不再使用全屏 UI 背景覆盖城市。
- 所有固定地块都有 3D 基座、碰撞体、选择光环和世界空间中文状态文字。
- 点击通过屏幕射线命中 `CityPlot3DHandle`，拖动旋转观察角度，滚轮或平台映射可调整远近。
- 已建建筑按建筑类别、占地和等级生成不同组合的临时 3D 模型；建造确认后立即由存档状态刷新为对应模型。
- 空地、锁定、预留、可放置、不可放置、施工、可收取、缺少工人和仓储已满等状态均同步到 3D 地块。

## 幸存者战斗 3D 世界

- 将原有模拟平面坐标映射到 XZ 地面，角色移动和敌人追踪仍完全使用确定性的战斗模拟结果。
- 玩家和不同敌人类型使用由多个 Primitive/MeshRenderer 组成的临时 3D 模型。
- 子弹为真实 3D 模型并带 `TrailRenderer`；敌方和玩家弹道使用不同颜色和材质。
- 拾取物、圆形/矩形地面预警、命中特效、光束和震屏都在 3D 世界中呈现。
- 命中特效使用固定池复用；敌人、弹道、拾取物和预警对象按模拟 ID 增删，避免每帧无条件重建。
- 透视相机跟随玩家，并将原有震屏强度应用到 3D 相机位置。

## 生命周期与 WebGL 约束

- 3D 世界根对象不挂在 `RectTransform` 下，避免 UI 缩放影响世界坐标；`RuntimeWorldLifetime` 将其生命周期显式绑定到对应页面所有者。
- 所有临时材质集中缓存并复用；移动模型只更新 Transform，不在普通帧中创建材质。
- 方向光关闭实时阴影，透视相机关闭 HDR，适合竖版移动 WebGL 的基础性能预算。
- 保留 `HeroCityEmscriptenAccessCompat.jslib`，为抖音 jscore 补齐 `SYSCALLS.doAccess` 并处理成功隐式退出，避免 `___syscall_faccessat` 加载回归。
- 本轮制作与验证没有执行任何截图操作。

## 自动化验证

- EditMode：26 项规则、存档、建造和战斗测试全部通过。
- PlayMode：5 项启动、中文字体、城市建造、幸存者 3D 战斗和 UI 页面测试全部通过。
- PlayMode 明确断言两套世界使用非正交相机，并验证城市页面背景透明、足量 `MeshRenderer`、3D 建筑、3D 敌人和弹道 `TrailRenderer` 已实际创建。

设备端仍需通过抖音开发者工具或真机确认性能、字体锐度、触摸手感和平台安全区；这属于平台运行环境验证，不改变当前 Unity 逻辑实现状态。
