# 文字与数字对齐复核

基准：竖版 1080×1920，测试截图使用 720×1280 等比例画布。

## 已修正的共性问题

- 文本组件改为几何对齐、允许完整换行，并降低行距，避免 CanvasScaler 四舍五入后第二行被裁切。
- 正式按钮的文字增加左右安全内边距，长文案不再压到两侧金色卷角。
- 货币芯片的数值改为居中落在内框清晰区域，避免 `2,000`、`900` 贴到右侧装饰。
- 英雄名册卡片拆分为“身份 / 职业 / 状态”三段，绿色底轨只承载“查看详情/未解锁”。
- 战斗 HUD 的威胁、敌技、弹体数量集中到右上状态框，绝技状态使用独立信息条，不再漂浮在战场背景上。
