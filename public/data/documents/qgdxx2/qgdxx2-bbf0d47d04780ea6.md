# 竖版城市幸存者战斗实现说明

本实现以《竖版城市幸存者_战斗逻辑与表现完整方案》为当前最高优先级，替换旧版“即时发射、贴身即扣血、按固定序号刷怪”的战斗路径。城市、英雄永久卡、存档事务和关卡奖励保持独立兼容。

## 本次完成

### 战斗权威

- 普通攻击使用 `Ready → Windup → Active → Recovery → Cooldown` 时间轴，伤害不依赖动画事件。
- 玩家移动采用死区、最低有效速度、加减速和边界修正；攻击不夺取移动方向。
- 玩家有效受击后获得 0.35 秒全局受击保护，敌人接触攻击有独立前摇和冷却。
- 投射物使用上一帧到当前帧的 Sweep 线段判定，支持穿透、回旋和弹射的命中去重。
- 物理/元素/真实伤害统一经过防御、章节和暴击计算；Boss 破防期间承伤提高。
- 暂停只冻结统一战斗时间；AI、投射物、预警、技能、刷怪、经验吸附和关卡时间不会偷跑。
- 永久卡应用后按已过去比例换算攻击冷却；最大生命增加会恢复新增上限的 75%，不再按新上限重算旧生命比例。

### 敌人、波次和 Boss

- 追逐、快速、坦克、远程、冲锋、精英和 Boss 均走显式状态机。
- 远程射击、冲锋、精英范围技和 Boss 高伤技能先生成逻辑预警，到时准点生效。
- 冲锋在前摇开始时锁定方向，冲锋途中不追踪玩家，结束后进入硬直。
- 波次导演按威胁费用、阶段进度、同屏上限、远程/特殊敌人上限和玩家低血状态安排刷新。
- 敌人出生在当前视野外；战场扩大为可跟随移动的世界，镜头带平滑、前视和玩家偏下构图。
- “腐化树王”包含入场、阶段一、60% 转阶段、阶段二、20% 狂暴、韧性破防和死亡收束。
- Boss 招式包含根须扇扫、木刺直线和腐化种子弹幕，并限制连续招式轮换。

### 掉落和永久成长

- 经验、治疗掉落使用对象池；同区域及超预算经验自动合并且总量不变。
- 吸附有 0.05 秒启动延迟并随距离加速。
- 多级升级继续使用原有唯一事务和候选存档；暂停恢复后提供 0.5 秒保护、推开贴脸敌人，并保证旧高伤预警至少留出 0.25 秒。
- Boss 胜利时回收场上经验；若触发永久升级，会先完成所有待选卡，再进入胜利结算。

### 竖屏表现与交互

- 屏幕下方 65% 为浮动摇杆唤起区，摇杆按下出现、抬起在 0.1 秒内淡出。
- HUD 显示生命、护盾、永久经验、关卡时间、Boss 倒计时、对象预算和终极技能充能。
- Boss HUD 显示生命、阶段和韧性；普通怪受击后短时显示血条，精英常驻血条。
- 预警单独位于角色下层，按危险等级和倒计时加强，不会被玩家投射物覆盖。
- 伤害、暴击、玩家承伤、护盾和治疗跳字使用 28 个固定槽，0.22 秒内同源伤害聚合。
- 命中、暴击、破盾、死亡、Boss 阶段和终极技能通过池化反馈、局部震屏、横幅和抖音震动分级表现。
- 升级界面改为半透明压暗，仍能看到暂停战场和危险轮廓。
- 失败结算记录最终伤害类型，并给出针对冲锋、远程、Boss 扇扫、木刺或种子弹幕的具体建议。

### 性能边界

- 敌人空间查询统一使用 120 单位网格，索敌、弹体和分离不再逐技能全场扫描。
- 默认同屏敌人上限 50～72，活跃投射物硬上限 160，掉落硬上限 60。
- 敌人、投射物、掉落、预警、命中特效和跳字全部复用；池对象重置命中记录、状态、计时和表现字段。
- 普通索敌按 0.15 秒刷新并保持分数接近的旧目标，避免高频左右切换。
- 高频跳字、命中和震动均有聚合或上限，战斗逻辑随机与纯表现随机互不影响。

## 关卡节奏调整

主线时长已从旧版 75～240 秒调整为 240～480 秒：前期关卡 4～5 分钟，标准关约 6 分钟，后期与章节 Boss 关逐步延长到 8 分钟。Boss 在末段 30～60 秒进入，入场前停止普通刷新并清理敌方危险物。

## 当前制作边界

当前项目没有正式角色模型、Animator Controller、动画片段、粒子、音效和中文字体，因此本次通过运行时 uGUI 图形完成逻辑时序、层级、颜色、预警、跳字、镜头和反馈验收。逻辑事件已经与表现解耦，后续可将色块视图替换成 3D/2.5D 资源而不改伤害权威。

尚未纳入本轮的生产内容包括：复活/激励广告、两个局内道具槽、城市援助主动按钮、可破坏场景物、完整 Buff 图标与驱散、真实音频混音、设置页的左右手镜像/色弱/震屏档位，以及正式模型动画和粒子资产。这些属于方案 P1 后段和 P2，不应使用占位广告 ID 或伪平台调用提前接入。

## 验证约束

- 已通过 Unity EditMode 22/22、PlayMode 3/3，以及最终源码 WebGL/IL2CPP 构建验证；抖音竖屏、TTSDK 与启动场景前置校验通过。
- 全部制作和验证禁止执行截图操作。
