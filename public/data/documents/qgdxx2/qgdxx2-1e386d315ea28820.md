## Coding Conventions

- Namespace style: `HeroCity.<Area>`.
- Runtime authority: plain C# simulations and systems; MonoBehaviour/uGUI classes bridge lifecycle, input and presentation.
- Configuration: code-defined catalogs; runtime UI does not require scene wiring. Shared colors, rounded cards, resource chips, stat/effect components and unscaled-time transitions live in `UiFactory`/`UiMotion`. City building and UI prefab contracts are generated under `Assets/HeroCity/Prefabs` and validated by EditMode tests.
- Presentation: `ProceduralModelFactory3D` supplies temporary real 3D models; city, survivor and cultivation views mirror authoritative simulation state into separate perspective worlds. Screen-space HUD and touch surfaces remain uGUI.
- Localization: player-facing runtime strings are simplified Chinese, enum labels are routed through `ChineseText`, and the embedded Noto Sans SC subset is loaded from `Resources/Fonts`.
