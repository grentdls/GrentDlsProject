# 竖版城市幸存者 UI 视觉重制清单

## 视觉基线

- 画布基准：1080 × 1920，竖屏 9:16。
- 风格：Q 版福瑞修仙，深青夜色为底，暖木、鎏金、玉石绿为主要材质。
- 正文和交互文字由 Unity 动态绘制，正式图片不烘焙文字，避免多语言、分辨率和裁切问题。
- 可缩放面板和按钮使用九宫格；头像、节点、物品框使用等比显示，不允许非等比拉伸。
- 3D 英雄预览使用 512:640 RenderTexture，并在目标区域内等比适配。

## 页面实现状态

- 城市主页：资源条、侧边入口、底部导航已统一正式框体；底部导航使用固定安全区单元，避免被布局系统推到屏幕外。
- 远征：节点式路线图、折线路径、关卡简报、英雄选择和挑战按钮已重排。
- 招募：双行卡池、3D 英雄主展示、保底与货币状态、快捷功能和底部招募操作区已重排。
- 商店：钱包、累计补给、快捷入口、分类与双列商品卡已重排。
- 英雄名册：3D 当前英雄展示、双列正式卡片和锁定状态已重排。
- 英雄详情：3D 主角、六装备位、页签、属性和功法列表已统一。
- 建造：双列建筑目录、紧凑快捷面板和建筑详情底板已统一。
- 战斗：顶部低遮挡 HUD、Boss 条、暂停入口和底部绝技按钮已统一。

## 加载图规则

- 首次进入游戏：使用启动加载图。
- 进入战斗关卡：使用战斗加载图。
- 城市内页面切换、挑战入口和普通弹窗：不加载整屏背景图，只使用轻量页面过渡。

## 验收要求

- 720 × 1280 与 1080 × 1920 下不得出现主导航、确认按钮或关闭按钮越过安全区。
- 九宫格组件只能等边拉伸中心区域，边角花纹不得变形。
- 3D 预览不得横向压扁；商品、英雄和建筑卡片不得互相覆盖。
- 弹窗背景点击区、关闭按钮和主要操作按钮必须保留独立射线区域。
- WebGL / 抖音小游戏验证由正式构建流程执行，本轮仅做 Unity 编辑器编译与 Play Mode 视觉复查。
