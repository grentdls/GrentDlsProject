# UI 清晰版视觉重制说明

## 目标

本轮重制针对竖版手机与抖音小游戏 WebGL 的实际阅读距离，统一解决“文字太小、信息层级过多、框体抢视觉”的问题。保留现有正式美术资源引用与节点命名，避免影响场景、测试和后续换图。

## 统一规则

- 运行时 `UiFactory.Text` 的字号下限为 15；正文最佳适配不低于 14。
- 富文本中的 `<size=11>`、`<size=13>` 等内嵌说明会自动提升到可读下限，保留标题与正文的相对层级。
- 中文正文行距由 0.92 调整为 0.98，减少紧贴和笔画糊成一团的情况。
- 一级操作按钮标签统一使用 19–20 号字；底部导航和城市功能按钮使用 18 号字。
- 卡片描边、按钮描边和阴影只承担分组与点击反馈，不再重复叠加厚边、强阴影和高亮。
- 已有正式九宫格底板不再额外叠加 Outline/Shadow，避免边角重复发亮；纯程序卡片才保留一层轻描边。
- 正式底板、标题缎带、英雄卡和物品框继续沿用 `FurryXianxiaUiArt` 的资源契约，改由更克制的透明度与描边表达层级。

## 适用范围

公共规则会覆盖主城、英雄名册、招募、装备、修行、建筑详情、关卡选择、战斗 HUD、弹窗和底部导航等所有运行时 uGUI 页面。新页面只要通过 `UiFactory.Text`、`UiFactory.Button` 或 `GameIconFactory.CreateFloatingButton` 创建，就会自动继承这套清晰版规范。

## 验证方式

本轮只做代码与静态编译检查，不执行截图和 WebGL 构建。正式构建后需要重点检查：

1. 低分辨率竖屏下长标题是否换行完整。
2. 二级分页按钮文字是否仍保持单行可读。
3. 招募、商店和战斗 HUD 的数值是否没有被框体装饰遮挡。
