# 竖版城市幸存者：装备系统 2.0 与大型装备内容库完整方案

> 适用项目：竖版单手移动、自动普攻与自动技能、手动终极技能、战斗升级永久选卡、36 名妖族英雄、12 种攻击原型、16 个修行派系、城市铁匠铺与招募商业化循环。
>
> 本文是旧《英雄装备、随机词条、强化进阶与套装完整方案》的 2.0 扩展版。旧版中可继承升级、部位强化、进阶、升品、重铸、套装和智能掉落等成熟规则继续保留；本版重点解决装备数量不足、武器差异不明显、随机词条偏纯数值、装备与修炼及攻击方式联动不足的问题。

## 1. 装备系统扩展目标

### 1.1 当前问题

1. 六个旧槽位虽然属性不同，但战斗中主要仍体现为攻击、生命、暴击等数值变化。
2. 同类武器只有攻击力和词条不同，换一把剑后飞行路线、归返方式和命中逻辑基本不变。
3. 词条多为“伤害 +X%”，缺少御剑、回旋、环绕、阵地、召唤等原型专属行为。
4. 套装数量少，且容易退化为指定元素或指定职业的固定答案。
5. 高品质装备缺乏“这件物品独有”的记忆点，传说装备只是数值更高。
6. 装备与 16 修行派系没有稳定接口，容易出现每新增一个派系就手工补一批硬编码。
7. 装备来源虽然包括掉落、制造和招募，但缺少明确分工与目标追踪。

### 1.2 新版一句话定义

**装备决定英雄以什么器物、什么节奏和什么路径完成自己的攻击；修炼决定这些攻击如何被进一步改写。**

一件好装备至少提供以下三层价值：

- 看得见：模型、轮廓、攻击轨迹和特效发生变化。
- 玩得出：攻击范围、节奏、返回路径、落点、阵地或指令发生变化。
- 养得久：可以升级、继承、进阶、重铸、升品或觉醒，但不会因换装损失全部投入。

### 1.3 验收标准

- 隐藏装备面板数值，只看十秒战斗，应能辨认至少大部分武器底材差异。
- 每种攻击原型至少拥有 6 条行为词条，而不是只有伤害词条。
- 每个修行派系至少有 3 条装备联动词条，但不能依赖专属装备才能正常运行。
- 每个普通装备槽位有独立职责，不出现“六个槽都想要暴击率”的情况。
- 传说装备拥有固定名器特效；神话成长主要改变机制，不只提高基础倍率。
- 玩家可以通过掉落、铁匠铺、挑战和招募四条路线获得目标装备。

## 2. 装备在完整构筑中的位置

### 2.1 最终构筑公式

```text
英雄基础攻击原型
× 英雄固定普攻与技能
× 武器底材参数与固有式
× 先天命格
× 修行派系规则改写
× 永久卡牌路线
× 装备随机词条、套装与法宝
= 最终战斗套路
```

### 2.2 各系统职责

| 系统 | 决定内容 | 示例 |
|---|---|---|
| 英雄模板 | 基础动作和攻击原型 | 月芽投出回旋轮刃 |
| 武器底材 | 实体武器的基础形态 | 月轮远点更宽，飞镰回程更快 |
| 先天命格 | 同名英雄个体差异 | 回程伤害翻倍但去程变慢 |
| 修行派系 | 长期规则改写 | 梦道重演完整去回轨迹 |
| 永久卡牌 | 逐级强化路线 | 轮刃 +1、去程穿透、接住爆炸 |
| 装备词条 | 调整触发、参数和条件 | 急转后回程切线伤害提高 |
| 套装 | 连接多个标签形成完整循环 | 去程种印、回程收印并返冷却 |
| 法宝 | 提供一个额外但受控的战场器官 | 照影镜周期记录下一次攻击 |

### 2.3 装备贡献目标

装备负责英雄长期总战力约 25%～32%，内部构成为：

| 内容 | 装备系统内部贡献 |
|---|---:|
| 基础属性、等级与部位强化 | 42%～48% |
| 随机词条 | 20%～25% |
| 固有式与名器特效 | 12%～16% |
| 套装 | 10%～14% |
| 铭纹、法宝与本命器 | 8%～12% |

装备系统不能压过英雄技能、修行派系和永久卡牌。装备负责把已有玩法做深，而不是取代英雄本身。

## 3. 装备 2.0 的八个槽位

### 3.1 槽位总表

| 槽位 | 固定主属性 | 独立职责 | 典型行为词条 | 套装计数 |
|---|---|---|---|:---:|
| 主武器 | 攻击、武器威力 | 决定攻击实体、范围、节奏和轨迹 | 御剑归返、回旋远点、斩击外缘 | 是 |
| 头冠 | 生命、感知 | 索敌、预警、经验、控制防护 | 精英优先、屏外预警、抗控反击 | 是 |
| 护甲 | 生命、防御 | 承伤、护盾、重量姿态、受击反应 | 护盾破裂、霸体、过量治疗 | 是 |
| 护手 | 攻击、攻速 | 命中节奏、暴击、连段和触发 | 第几击、弱点、收招、精准命中 | 是 |
| 足具 | 移速、少量生命 | 走位路径、急转、冲锋和地面适应 | 急转、擦身、路径残留、落点保护 | 是 |
| 腰佩 | 生命、携带量 | 充能、击杀库存、回复与拾取循环 | 药囊、魂火、材料吸附、保命次数 | 是 |
| 灵饰 | 技能威力、派系资源 | 修行、冷却、终极、元素与标记 | 灵息、血气、符序、星辉、因果 | 是 |
| 法宝 | 无统一主属性 | 提供唯一自动法宝技或护主机制 | 镜、印、灯、盘、葫芦、幡 | 否 |

### 3.2 为什么从六槽扩展到八槽

- 旧饰品同时承担冷却、元素、终极、召唤、拾取和回复，词条池过于拥挤。
- 腰佩接管战斗库存、击杀资源、恢复和拾取。
- 灵饰专门处理技能与修行派系资源。
- 法宝作为唯一机制槽，承担独立战场表现，不与普通数值装备混在一起。
- 八槽在竖屏英雄页可以左右各四个围绕角色，不需要横向滚动。

### 3.3 固定槽位特性

| 槽位 | 不可被随机删除的固定特性 |
|---|---|
| 主武器 | 提高英雄主攻击与核心技能的武器继承率 |
| 头冠 | 强控制持续时间降低，并提前显示高威胁提示 |
| 护甲 | 来自装备的生命、护盾和韧性效果提高 |
| 护手 | 普攻与核心技能的攻击后摇小幅缩短 |
| 足具 | 基础移动加速度和转向响应提高 |
| 腰佩 | 战斗恢复物与击杀库存上限提高 |
| 灵饰 | 派系资源获取和终极技能充能小幅提高 |
| 法宝 | 获得该法宝唯一技能，不参与普通词条随机 |

### 3.4 套装组合空间

法宝不计套装，其他七槽可以构成：

- `4 + 2 + 1`：一个主套装、一个副套装、一个强力散件。
- `2 + 2 + 2 + 1`：多标签混搭。
- `4 + 1 + 1 + 1`：主套装配三件名器。
- 不制作必须 7 件才能生效的强制套装。

## 4. 旧装备存档迁移

### 4.1 六槽到八槽

| 旧槽位 | 新槽位 | 处理 |
|---|---|---|
| 武器 | 主武器 | 完整保留 |
| 头盔 | 头冠 | 完整保留，名称分类扩展 |
| 护甲 | 护甲 | 完整保留 |
| 手套 | 护手 | 完整保留 |
| 鞋子 | 足具 | 完整保留 |
| 饰品 | 灵饰或腰佩 | 根据原主标签自动分类，玩家可免费改选一次 |
| 无 | 法宝 | 通过新主线和万法道院任务解锁首件 |

### 4.2 旧饰品分类

- 冷却、元素、终极、召唤、技能资源类自动成为灵饰。
- 恢复、拾取、击杀库存、材料、经济类自动成为腰佩。
- 同时拥有两类词条的史诗/传说旧饰品会复制为两个“迁移候选”，玩家选择保留一个版本；未选版本只用于预览，不造成资产复制。
- 旧饰品等级、品质、星级、套装和投入材料完整继承。

### 4.3 旧词条迁移

- 纯数值词条按原值映射。
- 已不符合新槽位的词条免费重铸一次，并保证同档位。
- 旧套装的 2件/4件计数保持不变。
- 原饰品部位强化拆分为腰佩与灵饰时，两者继承旧等级；后续分别强化。
- 迁移后首周允许不限次数免费在腰佩/灵饰版本间重新选择，防止误操作。

## 5. 装备实例的完整结构

```text
装备实例
├─ 装备模板：名称、槽位、模型、图标、标签
├─ 底材参数：范围、重量、速度、实体数量等
├─ 稀有度：普通→良品→稀有→史诗→传说→神话
├─ 物品强度：决定基础值和可出现词条档位
├─ 装备等级：提升基础主属性
├─ 进阶星级：当前品质内0～4星
├─ 固有式：模板固定的小型行为
├─ 随机词条：属性、原型、派系和触发词条
├─ 铭纹槽：可拆卸的确定性模块
├─ 名器特效：传说模板固定效果
├─ 套装归属：2件/4件效果
├─ 本命器进度：仅被英雄选为本命的武器
└─ 外观：模型、染色、幻化与器魂轮廓
```

### 5.1 名称结构

```text
[品质前缀，可隐藏] + [底材/名器名称] + [构筑后缀，可选]
```

示例：

- 稀有·流云背匣。
- 北斗列宿匣·归锋。
- 守望者玄甲·壁垒。
- 梦蝶灯·叠梦。

列表只显示主名称和关键后缀；完整来源、词条档位和制作信息放在详情页，避免物品名过长。

### 5.2 标签结构

| 标签层 | 示例 | 用途 |
|---|---|---|
| 槽位 | `Weapon`、`Armor`、`Artifact` | 过滤和装备位置 |
| 武器家族 | `SwordCase`、`Bow`、`Hammer` | 英雄兼容与动画 |
| 攻击原型 | `HomingWeapon`、`Boomerang` | 行为词条过滤 |
| 伤害家族 | `Sharp`、`Blunt`、`Ranged`、`Spell` | 伤害加成与抗性 |
| 修行 | `Cultivation_Immortal`等 | 派系词条过滤 |
| 战斗事件 | `Return`、`OuterEdge`、`OnBeat` | 触发器 |
| 来源 | `Boss`、`Crafted`、`Recruit` | 掉落与保底 |
| 套装 | `Set_MirrorSky` | 套装计数 |

## 6. 武器底材与适配

### 6.1 武器不是英雄技能换皮

英雄固定普攻决定基础攻击原型，武器底材只能在安全范围内修改实体参数和一个关键行为，不能把斩击英雄直接变成召唤英雄。

例如同为回旋英雄：

- 月轮：远点绕行半径更大，覆盖强。
- 飞镰：回程加速，单体强。
- 齿轮锯：远点停留短时旋转，区域强。
- 双翼刃：去回之间可分裂成两条线，但单体倍率降低。

### 6.2 武器底材参数

| 参数 | 影响 | 安全变化范围 |
|---|---|---:|
| `Reach` | 斩击、突刺、震波范围 | 基准的85%～130% |
| `Cadence` | 普攻节奏 | 基准的80%～125% |
| `EntityCount` | 实体剑、轮刃、弹体基础量 | 通常只允许0或+1 |
| `TravelSpeed` | 飞剑、弹体、回旋速度 | 基准的75%～140% |
| `ReturnSpeed` | 御剑/回旋归返 | 基准的70%～160% |
| `TurnRate` | 追踪、回旋转向 | 基准的70%～140% |
| `OrbitRadius` | 环绕轨道 | 基准的80%～135% |
| `Impact` | 击退、破势、命中停顿 | 基准的80%～150% |
| `Weight` | 装备负荷、动作厚重感 | 1～20点 |

### 6.3 英雄武器适配

沿用既有规则：

| 适配 | 系数 | 说明 |
|---|---:|---|
| 核心武器 | 1.20 | 使用完整固有式与模型动作 |
| 兼容武器 | 1.00 | 使用完整基础属性与合法行为词条 |
| 临时武器 | 0.85 | 只使用通用固有式，部分专属词条失效 |
| 不兼容 | 不可装备 | 动画或攻击逻辑无法成立 |

核心适配系数计入武器继承，不与同名伤害词条重复乘算。

### 6.4 装备负荷姿态

主武器、头冠、护甲、护手和足具提供负荷。负荷不是单纯惩罚，而是三种姿态选择：

| 总负荷 | 姿态 | 收益 | 代价 |
|---:|---|---|---|
| 0～29 | 轻灵 | 转向 +10%、移动加速度 +8%、擦身判定更宽 | 韧性 -12% |
| 30～59 | 均衡 | 无额外修正 | 无 |
| 60～89 | 重装 | 韧性 +20%、轻击减伤 +5%、震波/冲锋破势 +8% | 加速度 -6% |
| 90以上 | 超载 | 不禁止进入战斗，但显示强提醒 | 加速度 -12%、派系资源获取 -5% |

玩家可以通过足具、腰佩和词条调整负荷。超载不是终局最优，只作为特殊重甲构筑。

## 7. 稀有度与名器层级

### 7.1 六档稀有度

| 稀有度 | 颜色 | 基础倍率 | 随机词条 | 固有式/特效 | 铭纹槽 |
|---|---|---:|---:|---|---:|
| 普通 | 灰蓝 | 1.00 | 0 | 基础固有式 | 0 |
| 良品 | 绿色 | 1.14 | 1 | 基础固有式 | 0 |
| 稀有 | 蓝色 | 1.32 | 2 | 强化固有式 | 0 |
| 史诗 | 紫色 | 1.55 | 3 | 史诗固有式 | 1 |
| 传说 | 金橙 | 1.82 | 4 | 固定名器特效 | 1，4星后2 |
| 神话 | 赤金/虹彩 | 1.95 | 4 | 名器特效 + 器魂二选一 | 2 |

### 7.2 神话不能直接抽取

- 神话装备由传说名器完成终局挑战后觉醒。
- 装备招募最多直接获得传说。
- 神话只小幅提高基础倍率，主要价值是器魂分支和外观变化。
- 神话觉醒不增加第五条随机词条，避免追求完美词条成本再次膨胀。
- 赛季或活动可以提供神话材料，但不能出售付费独占器魂。

### 7.3 物品强度与词条档位

稀有度决定槽位数量，物品强度决定基础值与可出现档位。低章节掉落的传说可以成长，但需要通过铁匠铺“重铸器胚”提高物品强度，不要求整件报废。

## 9. 等级、强化、进阶与升品

### 9.1 装备等级

- Lv.1～Lv.80，只提高基础主属性和固定槽位特性。
- 消耗金币与装备经验，不提高随机词条。
- 换装时默认按钮为“装备并继承等级”。
- 重置返还100%装备经验和90%～100%金币，按经济测试调整。

### 9.2 部位强化

- 八槽分别 +0～+30，账号共享。
- 主武器与护手偏输出，头冠与护甲偏生存，足具偏机动，腰佩偏库存，灵饰偏派系资源，法宝偏冷却与效果稳定性。
- 强化100%成功，不爆装、不掉级。
- +10、+20、+30解锁槽位纹章节点，纹章为二选一机制而非固定数值。

示例：

| 槽位 | +10纹章 | +20纹章 | +30纹章 |
|---|---|---|---|
| 武器 | 固有式效率提高 | 原型词条上限提高半档 | 本命器经验获取提高 |
| 护甲 | 护盾或治疗二选一 | 轻/重姿态收益强化 | 一次护主减伤 |
| 足具 | 急转或直行二选一 | 地面危险或减速抗性 | 路径技能形变 |
| 灵饰 | 资源获取或上限二选一 | 派系触发内置CD缩短 | 终极后保留少量资源 |
| 法宝 | 冷却或持续二选一 | 护主或进攻二选一 | 法宝终局外观 |

### 9.3 进阶星级

每个品质0～4星：

| 星级 | 收益 |
|---:|---|
| 1星 | 基础属性与固有式数值小幅提高 |
| 2星 | 随机词条整体提高5%，铭纹效率提高 |
| 3星 | 固有式解锁第二段行为或降低代价 |
| 4星 | 达成升品条件，传说额外解锁第二铭纹槽 |

消耗优先级：同名装备 > 同家族同品质 > 通用装备精华。无失败、无降星。

### 9.4 升品

- 品质提高一级，星级回到0。
- 等级、词条、套装、锁定和外观完整保留。
- 新品质增加词条槽时，从三个合法方向中先选方向，再随机具体词条与档位。
- 史诗升传说需要名器图纸或 Boss 核心。
- 传说升神话需要完成装备专属觉醒挑战，不能只交材料。

### 9.5 器胚重铸

用于让早期获得的好词条装备追上后期物品强度：

- 消耗同章节材料和金币提高 `ItemPower`。
- 不改变词条类型，只按原档位百分位映射数值。
- 每次跨大章节需要新器胚材料。
- 目标是保留幸运掉落，不让第一章装备直接免费变成终局装备。

## 10. 铭纹系统

### 10.1 定位

铭纹用于提供确定性构筑补足，解决随机词条永远差一条的问题。它不参与装备招募随机，不会镶嵌失败，也不会拆卸损毁。

### 10.2 槽位规则

- 史诗：1槽。
- 传说：1槽，4星后2槽。
- 神话：2槽。
- 同名铭纹全身只能生效一个。
- 攻击铭纹不能镶入头冠和护甲，防御铭纹不能镶入主武器；混合铭纹按模板限制。
- 法宝拥有专属“法印槽”，不能安装普通铭纹。

### 10.3 铭纹成长

- 同名铭纹碎片提升等级，最高5级。
- 升级只提高数值或降低内置CD，不增加新的递归触发。
- 拆卸免费；战斗中不可更换。
- 铭纹页支持按攻击原型、修行派系和槽位筛选。

### 10.4 铭纹与随机词条的边界

| 随机词条 | 铭纹 |
|---|---|
| 决定装备是否惊喜和独特 | 提供可计划的最后一块拼图 |
| 数量多、档位随机 | 数量少、效果固定 |
| 可以重铸 | 可以收集和升级 |
| 允许通用数值 | 优先提供条件或行为 |

## 11. 名器、本命器与器魂

### 11.1 三层区别

| 层级 | 对象 | 获取 | 作用 |
|---|---|---|---|
| 固有式 | 所有武器模板 | 装备即有 | 提供一个小型底材行为 |
| 名器特效 | 传说模板 | 掉落、制造、招募 | 该名称独有的完整机制 |
| 器魂 | 神话本命武器 | 觉醒挑战 | 从两个终局方向中选择一个 |

### 11.2 本命器规则

- 英雄修为60级、主城铁匠铺达到对应等级后开放。
- 每名英雄同一时间只能将一把传说或神话武器设为本命器。
- 本命关系可以转移；旧武器的本命经验转化为可继承的“器魂火”，不永久绑定。
- 本命器亲自参与战斗获得默契，派遣和扫荡按较低效率获得。
- 本命器不会增加第五条随机词条，主要解锁外观、器灵动作和攻击形变。
- 器道修行获得更快炉温与法器协同，但本命器不属于器道专属。

### 11.3 三段本命成长

| 阶段 | 名称 | 解锁 |
|---|---|---|
| 一阶 | 认主 | 武器出现英雄种族纹样，固有式稳定性提高 |
| 二阶 | 灵识 | 出现小型器灵轮廓，学会回鞘、接刃、护主等反应动作 |
| 三阶 | 化形 | 完成觉醒挑战，选择“同形器魂”或“异形器魂” |

### 11.4 两类器魂方向

- **同形器魂**：强化原攻击最具代表性的行为。例如御剑增加归返调度，回旋强化去回路径，震波强化波前。
- **异形器魂**：补足原型弱点，但不改变英雄职业。例如斩击产生一次远程风刃，飞弹在近身时形成护体弹幕。

### 11.5 十二原型器魂样例

| 原型 | 同形器魂 | 异形器魂 |
|---|---|---|
| 御剑 | 归鞘后立刻重排目标，下一把剑从侧翼离匣 | 所有剑未归时生成一把不占槽的护主幻剑 |
| 斩击 | 外缘命中后下一斩半径提高、角度收窄 | 每第四斩发出低倍率远程风刃 |
| 回旋 | 接住后保留上次远点方向，下一投形成交叉线 | 远点短暂停留并形成小范围旋切 |
| 飞弹 | 连续命中同一目标逐步校准弹道 | 近身敌人达到阈值时释放一次环形击退弹 |
| 落点 | 连续命中同一区域让下一落点更快 | 空放区域转为脚下护阵，不完全浪费 |
| 环绕 | 内外轨道周期换位并重置一次接触冷却 | 可短暂脱轨攻击精英后返回 |
| 突刺 | 对齐多个目标后延长下一次枪线 | 突刺末端产生小范围横扫 |
| 震波 | 波前经过中心标记后折返一次弱波 | 受到近战攻击时从脚下生成短震环 |
| 冲锋 | 命中目标越多，终点冲击越宽 | 冲锋结束生成护盾并取消部分走位风险 |
| 陷阱 | 同类陷阱相邻时连接触发 | 超限回收的最早陷阱产生一次弱效果 |
| 召唤 | 指令后首个响应单位获得强化 | 召唤物全灭时器灵临时充当护卫 |
| 连锁 | 链尾沿原路径逆向回弹一次 | 单目标时把剩余弹射次数转为递减多段 |

### 11.6 器魂觉醒挑战

觉醒挑战读取武器原型，而不是统一打一个高血Boss：

- 御剑要管理离匣和归鞘槽位。
- 回旋要用去回路线同时击中两组器灵。
- 斩击要用内外缘分别破解护甲。
- 落点要预测器魂移动位置。
- 召唤要通过指令让武器器灵与召唤物协同。

挑战成功前不消耗觉醒核心，失败可立即重试。

## 12. 随机词条 2.0 架构

### 12.1 六类词条

| 类别 | 作用 | 示例 |
|---|---|---|
| 基础词条 | 提供稳定属性 | 攻击、生命、防御、暴击 |
| 槽位词条 | 强化槽位职责 | 头冠预警、足具急转、腰佩库存 |
| 原型词条 | 改变12种攻击方式 | 回程切线、震波折射、环绕换轨 |
| 派系词条 | 与16修行资源和对象联动 | 灵息、血债、阵眼、符序、星位 |
| 触发词条 | 命中、击杀、受击等条件效果 | 第四击、护盾破裂、精英死亡 |
| 双相词条 | 同时提供收益和代价 | 范围扩大但攻速降低 |

### 12.2 词条档位

继续使用T1～T6。高档位必须提高行为稳定性或降低代价，不能只把百分比无限放大。

| 档位 | 来源 | 行为词条变化 |
|---|---|---|
| T1 | 初期良品 | 小数值或低概率触发 |
| T2 | 稀有 | 稳定数值，机制开始可用 |
| T3 | 中期史诗 | 提高触发稳定性 |
| T4 | 高级史诗 | 降低内置CD或代价 |
| T5 | 传说/Boss | 完整高阶效果 |
| T6 | 神话/终局定向 | 不增加新递归，只优化条件或上限 |

### 12.3 高品质方向保护

| 品质 | 保证 |
|---|---|
| 稀有 | 至少1条符合槽位职责 |
| 史诗 | 至少1条槽位词条 + 1条模板/原型匹配词条 |
| 传说 | 至少2条有效方向，其中1条必须匹配原型或当前愿望标签 |
| 神话 | 完整保留传说词条，由器魂提供机制选择，不重新随机 |

### 12.4 窄词条控制

- 单件装备最多出现1条指定修行派系词条。
- 单件装备最多出现2条同一攻击原型词条。
- 只有英雄已解锁的修行派系会进入普通智能掉落池；图鉴和定向制造可查看全部。
- 派系词条不计入装备基础战力的大部分评分，避免系统错误推荐。
- 重铸派系词条时可以选择“保留派系类别”，但具体效果和档位仍随机。

### 12.5 双相词条

双相词条只来自危险秘境、诅咒Boss或邪铸制造，物品卡使用黑金裂纹框：

| 词条 | 收益 | 代价 |
|---|---|---|
| 巨刃 | 攻击范围提高 | 攻击准备时间增加 |
| 疾返 | 回程速度和伤害提高 | 去程最大距离降低 |
| 群星过载 | 星线伤害提高 | 星位熄灭时间延长 |
| 血铸 | 借血攻击威力提高 | 普通治疗效率降低 |
| 万灵喧嚣 | 召唤上限提高 | 单体召唤继承降低 |
| 逆因 | 果报倍率提高 | 结算时间缩短且更难调整 |

双相词条不会在新手装备或普通装备招募中随机出现。

## 13. 装备生成算法

### 13.1 标准流程

```text
确定来源和目标愿望标签
→ 选择槽位与模板
→ 计算ItemPower与稀有度
→ 生成底材参数和固定固有式
→ 计算随机词条数量
→ 先抽词条组，再抽具体词条
→ 应用槽位/原型/派系过滤
→ 检查互斥、窄词条和属性上限
→ 应用高品质方向保护
→ 生成套装、名器特效与铭纹槽
→ 计算推荐解释与战力
→ 保存随机种子和配置版本
```

### 13.2 愿望标签

玩家可以在掉落追踪、铁匠铺和装备招募分别选择：

- 1个攻击原型标签，例如回旋或召唤。
- 1个修行派系标签，例如梦道或修体。
- 1个套装或槽位目标。

愿望只提高匹配权重，不提高稀有度概率。史诗以上至少命中一个已选择愿望方向。

### 13.3 防垃圾组合

- 武器不会生成四条纯防御词条。
- 护甲不会生成四条都需要主动击杀才能生效的词条。
- 不同时生成“站立强化”和“持续移动强化”两个互斥核心词条。
- 不同时生成两条会改变同一关键事件结算方式的词条，例如两个不同回程改道。
- 经济词条不占用史诗以上的原型方向保护槽。
- 若随机结果有效词条少于一半，重新生成词条组而不是直接发给玩家。

### 13.4 推荐解释

推荐系统必须给出原因：

```text
更适合月芽·梦道回旋路线
+ 回程速度与梦轨记录匹配
+ 激活回月套装4件
+ 补足当前缺少的接刃恢复
- 失去现有暴击率6%
```

不能只显示“战力 +381”。

## 14. 触发、递归与结算顺序

### 14.1 统一结算顺序

```text
英雄基础攻击请求
→ 武器底材与固有式
→ 修行派系规则改写
→ 永久卡牌形变
→ 装备属性、原型词条和套装修正
→ 最终命中
→ 装备触发词条与法宝技
→ 二次伤害结算
```

### 14.2 来源深度

- `SourceDepth 0`：本体攻击，可触发全部合法装备效果。
- `SourceDepth 1`：仙影、法器、梦轨、星线、套装追加攻击，只按 `ProcCoefficient` 触发状态，不能再次生成同类攻击。
- `SourceDepth 2`：爆炸、蛊爆、果报、反伤等，默认不触发攻击型装备词条。

### 14.3 每秒预算

| 效果 | 默认限制 |
|---|---|
| 额外投射实体 | 每秒不超过基础攻击实体的50%预算 |
| 击杀爆炸 | 0.25秒同目标组内置CD，合并密集敌人 |
| 回复触发 | 每秒恢复上限，不因多段攻击无限触发 |
| 免伤/无敌 | 独立长CD，同类效果共享锁定组 |
| 资源返还 | 每个攻击事件只结算一次 |
| 星线/阵线/业线 | 使用统一线对象池和可见上限 |

### 14.4 冲突处理

若多个效果修改同一行为，按以下优先级：

```text
英雄不可替代规则
> 武器固有式
> 修行派系核心规则
> 永久卡牌核心进化
> 名器/器魂特效
> 套装
> 普通随机词条
> 铭纹便利效果
```

低优先级效果冲突时不静默失效：装备详情显示“当前构筑中被××替代”，并降低推荐分。

### 17.1 派系词条掉落规则

- 英雄试炼可选择一个派系，提高对应词条权重。
- 派系突破挑战主要掉落灵饰、腰佩和派系铭纹。
- 普通世界掉落只出现已解锁派系词条，避免背包堆满当前无法理解的内容。
- 铁匠铺图鉴始终可查看全部派系词条和未来解锁条件。
- 装备招募可以选择一个派系愿望，但不保证精确词条。

- 不设置强制6件或7件套，保留 `4+2+1` 与 `2+2+2+1` 混搭。
- 4件套平均贡献不超过装备系统总战力的8%～10%，高收益必须带条件。
- 套装追加攻击均为 `SourceDepth 1`。

## 39. 装备获取与目标掉落

### 39.1 四条来源的明确分工

| 来源 | 主要产出 | 玩家体验 |
|---|---|---|
| 装备招募 | 大部分英雄通用名器模板、史诗/传说整件、首次图纸解锁 | 快速扩充收藏和获得新套路 |
| 战斗掉落 | 普通到史诗装备、随机高档词条、Boss专属名器 | 高频检查战利品和刷取惊喜 |
| 铁匠铺 | 已解锁模板的定向制造、套装补件、器胚提升 | 长期确定性完成目标 |
| 活动/任务 | 部分主题装备、法宝、纪念外观和保底自选 | 明确阶段目标与免费获取 |

### 39.2 模板解锁比例

为了符合“大部分英雄和装备通过招募获得”，但保留战斗和建造价值：

| 首次模板来源 | 建议占比 |
|---|---:|
| 常驻装备招募 | 50%～55% |
| 主线、Boss和玩法挑战 | 20%～25% |
| 铁匠铺研究与城市任务 | 15%～20% |
| 活动、战令、登录和邀请 | 10%左右 |

首次获得任一装备模板后，自动解锁该模板的基础锻造图鉴。招募负责“发现名器”，铁匠铺负责“持续打造和修正”，两者不是互相替代。

### 39.3 掉落来源分工

| 战斗内容 | 掉落倾向 |
|---|---|
| 普通冒险 | 通用底材、装备经验、低中档词条 |
| 精英关 | 当前英雄攻击原型匹配装备 |
| Boss | 固定名器图纸、Boss核心、双相词条装备 |
| 修行突破 | 对应派系灵饰、腰佩和铭纹 |
| 守城 | 护甲、陷阱、召唤、守望者套装 |
| 资源战 | 腰佩、远征者套装、铁矿和器胚 |
| 无尽模式 | 高ItemPower、词条精华、排行榜外观材料 |
| 器魂挑战 | 觉醒核心和本命器外观，不掉普通随机装备 |

### 39.4 智能掉落

智能掉落只改变模板和词条方向，不改变总品质概率：

- 当前英雄核心和兼容武器权重提高。
- 当前保存的构筑方案标签权重提高。
- 当前追踪原型、派系或套装权重提高。
- 已解锁但长期没有可用武器的英雄获得追赶权重。
- 最近连续获得相同槽位时，其他槽位权重逐步提高。

### 39.5 目标追踪

图鉴中可追踪：

- 1件具体名器。
- 1个套装。
- 1种铭纹。
- 1条攻击原型或派系词条方向。

追踪后在关卡、Boss、招募愿望和铁匠铺入口显示图标，不直接提高所有掉率；系统明确告诉玩家去哪刷。

### 39.6 掉落保底

- 连续若干次精英/Boss未获得史诗时提高史诗概率，并显示进度。
- 套装关卡连续掉落重复槽位后，提高未拥有槽位权重。
- 世界Boss名器图纸达到明确次数后必出。
- 保底不会因版本更新、退出或切换愿望被静默清零；切换愿望只暂停对应进度。
- 神话不能直接掉落，只掉觉醒材料和挑战资格。

## 41. 重铸、传承与分解

### 41.1 单词条重铸

- 选择1条随机词条，其他词条不变。
- 生成新旧两个结果，玩家选择保留。
- 材料在生成候选时扣除，强退后重新进入仍显示同一候选。
- 同一装备连续重铸费用逐步提高，每日只回落部分，防止无限点击。

### 41.2 定向重铸

可以选择：

- 基础属性。
- 槽位行为。
- 攻击原型。
- 当前已解锁修行派系。
- 防御/恢复。

定向只保证大类，不保证具体词条或T6档位。

### 41.3 词条传承

后期允许把一条优秀词条转移给同槽位装备：

- 来源装备被消耗。
- 目标必须同槽位；武器原型词条还要求目标武器支持该原型。
- 传承词条替换目标的一条词条，不增加槽位。
- 最多传承到T5，T6只能通过终局内容或词条升阶获得。
- 名器特效、套装效果、双相词条和器魂不能传承。
- 每件装备只能接受一次传承，之后可以正常重铸该条。

### 41.4 词条升阶

- 使用词条精华将T2→T3等逐档提高。
- 上限受装备稀有度和ItemPower限制。
- 数值按原档位百分位映射，不会从高值变成新档最低值。
- T6需要终局Boss材料和对应原型/派系挑战证明。

### 41.5 分解返还

| 投入 | 返还 |
|---|---|
| 装备经验 | 100% |
| 部位强化 | 不在装备上，无需返还 |
| 进阶材料 | 70%～85%通用精华 |
| 铭纹 | 自动拆下，100%保留 |
| 传说名器 | 名器精华、图纸残页、部分核心 |
| 本命器 | 先执行解除/转移，禁止直接分解 |

### 41.6 自动保护

以下默认禁止批量分解：

- 已装备、锁定或方案引用。
- 史诗以上。
- 当前唯一套装部件。
- 拥有T5/T6、双相词条或已传承词条。
- 传说名器、法宝、本命器。
- 已投入大量进阶或觉醒材料。

## 42. 装备招募与商业化衔接

### 42.1 装备招募池结构

- 常驻武器池：16个武器家族与通用防具饰品。
- 原型精选池：周期提高一种攻击原型的模板权重。
- 法宝池：只包含法宝与法印材料，保底独立。
- 主题活动池：新套装或名器提前登场，结束后进入常驻、Boss或铁匠铺研究。

### 42.2 招募获得什么

| 结果 | 内容 |
|---|---|
| 首次获得模板 | 实际装备 + 基础锻造图鉴解锁 |
| 重复普通装备 | 实际装备，可穿戴、进阶、传承或分解 |
| 重复名器 | 名器本体 + 额外名器精华 |
| 已满觉醒名器 | 转为通用名器精华和自选图纸进度 |
| 法宝重复 | 法宝升阶材料，不要求无限同名 |

### 42.3 单抽与十连基本规则

- 单抽与十连使用装备招募券或付费货币。
- 十连至少1件稀有以上，并提高出现完整套装方向的可读性，但不暗改传说概率。
- 达到明确次数保底史诗，较长周期保底传说。
- 传说保底触发时优先当前愿望家族，但不保证精确同名；达到更高愿望保底后可自选一个已公开范围模板。
- 抽取概率、保底继承、愿望切换影响必须在池详情公开。

### 42.4 公平边界

- 神话装备不能直接抽取。
- 最强词条T6不能只靠招募，需要玩法材料升阶。
- 活动限定名器在商业独占期结束后进入可获取轮换或图纸研究。
- Boss和任务专属装备不放入付费池冒充“全部内容”。
- 付费可以缩短收藏时间，不能跳过器魂挑战与修行适配学习。

### 42.5 免费获得

- 新手奖励提供一把与初始英雄核心原型匹配的史诗武器。
- 七日登录提供一件自选史诗防具和10张装备招募券。
- 三十日登录提供常驻传说愿望箱或法宝自选残页。
- 战令免费线提供铭纹、铁矿、重铸石和招募券；付费线可提供更多数量和外观，不提供独占机制。
- 活动、任务、邀请和Boss均能产出部分完整名器。

| 法宝砂 | 法宝玩法、重复法宝 | 法宝升级和法印 |

### 43.2 防堵塞原则

- 金币是通用消耗，但不能同时成为所有系统唯一瓶颈。
- 铁矿和木材通过城市建造产出，强化建造—战斗循环。
- 重铸石每日稳定获得，不完全依赖付费商店。
- 进阶允许同家族装备或通用精华，不强制同名。
- 铭纹拆卸无损，避免每次换装重复投入。
- 器魂火可继承，防止本命器更换造成巨大沉没成本。

### 43.3 长期消耗

- 高ItemPower器胚重铸。
- 多套方案的词条精修。
- 铭纹升级。
- 名器图鉴和外观幻化。
- 神话觉醒与器魂分支切换。
- 城市铁匠铺研究和制造队列。

长期消耗优先提供横向构筑和收藏，不把基础装备等级做成无限指数。

## 44. 背包、筛选与装备方案

### 44.1 背包规则

- 装备、铭纹、法宝和材料分四个页签，材料不占装备格。
- 初始容量满足正常1～2天掉落，不用容量焦虑逼付费。
- 普通/良品可按规则自动分解，结算页可撤回最近一批。
- 史诗以上使用虚拟化列表和分组显示，避免大量卡片造成性能问题。

### 44.2 筛选维度

- 槽位。
- 武器家族。
- 攻击原型。
- 修行派系。
- 品质、等级、星级、ItemPower。
- 套装。
- 词条档位和是否存在双相词条。
- 已装备、锁定、本命、方案引用。

### 44.3 装备方案

- 每名英雄默认3套，可由城市成就扩至5套。
- 方案保存八件装备、铭纹、法印、负荷姿态和名称。
- 一件装备可被多个非同时出战方案引用。
- 多英雄同时出战的玩法中，装备不能被两人同时占用；进入前显示冲突并推荐替代。
- 方案可绑定英雄永久卡牌和修行天赋方案，实现完整构筑一键切换。

### 44.4 一键推荐

提供四种推荐：

- 最高即时战力。
- 当前攻击原型。
- 当前修行派系。
- 生存/守城优先。

推荐结果必须显示原因、套装变化、负荷姿态变化和失效词条，不自动覆盖锁定或本命装备。

## 45. 装备界面 UI 布局

### 45.1 英雄装备总览

竖版1080×1920参考布局：

| 区域 | 高度占比 | 内容 | 视觉规则 |
|---|---:|---|---|
| 顶部栏 | 6% | 金币、铁矿、装备精华、重铸石，均为图标+数字 | 最多显示4种，点击查看全部 |
| 英雄展示 | 36% | 英雄模型、当前武器、法宝、器魂轮廓 | 角色居中，武器动作循环预览 |
| 左侧四槽 | 26% | 头冠、护甲、护手、足具 | 品质底框+装备图标+等级 |
| 右侧四槽 | 26% | 主武器、腰佩、灵饰、法宝 | 法宝槽使用圆形独立框 |
| 构筑状态条 | 10% | 套装徽章、负荷姿态、攻击原型、修行派系 | 使用图标与短标签 |
| 下部背包 | 可展开 | 当前槽位装备卡或全部背包 | 上拉展开、下滑收起 |
| 底部导航 | 8% | 英雄、装备、修炼、技能、城市 | 当前页图标抬起 |

左右槽位垂直排列，不能让八个图标围成过小圆圈导致误触。槽位之间至少保留12～16像素安全间距。

### 45.2 装备槽卡片

卡片常显：

- 装备图标。
- 稀有度底框。
- `Lv.42`。
- 0～4星。
- 套装小徽章。
- 铭纹槽点。
- 锁定、本命、其他英雄装备等角标。

部位强化属于槽位，显示在槽位框外沿，例如 `+18`；不重复写进背包每张物品卡。

### 45.3 装备详情头部

采用“图像先于文字”的结构：

| 区域 | 内容 |
|---|---|
| 左/上大图 | 武器或装备高清图、品质背景、套装纹样 |
| 名称区 | 名称、品质、槽位、等级、星级 |
| 标签区 | 攻击原型、伤害家族、推荐派系图标 |
| 预览按钮 | 4秒攻击形变预览，不进入战斗也能看效果 |
| 装备状态 | 当前英雄头像、方案引用和锁定 |

### 45.4 详情内容分区

1. **基础属性卡**：大号主属性、底材范围/速度/负荷。
2. **固有式卡**：使用独立武器图标和动态路径小图。
3. **随机词条卡**：每条显示图标、名称、T档菱形、数值与当前是否生效。
4. **名器/器魂卡**：传说以上使用金色大框；器魂二选一可切换预览。
5. **铭纹卡**：显示已镶嵌图标和空槽。
6. **套装卡**：已激活实色、未激活灰色，显示当前 `2/4`。
7. **来源卡**：Boss、招募、铁匠铺、活动图标，可点击追踪。

长内容采用分段卡片和折叠，不让文字超出背景框。背景高度根据内容自适应，底部按钮固定在安全区。

### 45.5 装备对比

竖屏不适合两个长详情横向并列，采用字段对齐的上下对比：

- 上半张：新装备。
- 下半张：当前装备缩略卡。
- 相同字段合并为一行 `当前值 → 新值`。
- 新增机制使用金色 `NEW` 图标；失去机制使用紫红警示。
- 套装从 `4→2`、负荷从 `轻灵→均衡`、铭纹槽变化单独置顶提醒。
- 提供“纯属性”“构筑效果”“完整详情”三种对比页签。

### 45.6 推荐解释卡

推荐卡不只显示战力箭头：

```text
更适合当前「梦道回旋」方案
✓ 回程速度匹配梦轨
✓ 回月套装由2件变4件
✓ 新增接刃资源恢复
! 负荷由轻灵变均衡
－ 暴击率降低4.2%
```

每项配图标，优势绿色/金色，代价紫红；色盲模式增加形状。

### 45.7 背包筛选

- 顶部使用槽位图标行。
- 第二行使用攻击原型、派系和套装筛选胶囊。
- 筛选项超过一行时横向滑动，主装备列表仍竖向滚动。
- “适合当前英雄”是排序，不是隐藏不适配装备，避免玩家找不到物品。
- 保存最近三组筛选。

### 45.8 法宝页

- 中央显示法宝3D/2D悬浮模型和当前冷却环。
- 下方播放自动触发条件与一次完整演示。
- 左侧显示固定法宝技，右侧显示法印槽。
- 不显示普通四条随机词条，突出“获得即理解”。
- 护主法宝明确写每场次数和冷却，不能只写概率。

### 45.9 本命器页

- 英雄头像与武器大图通过器魂线相连。
- 三段成长为认主、灵识、化形三个大节点。
- 化形节点展示同形/异形两段视频和优缺点。
- 转移前显示可继承器魂火、旧武器变化和材料消耗。
- 本命器不能从普通背包长按菜单直接分解。

### 46.1 窗口与页面转场

| 操作 | 动效 | 时长 |
|---|---|---:|
| 打开装备页 | 八槽从英雄周围错峰落位，英雄武器先显现 | 0.28秒 |
| 点击槽位 | 槽位框抬起，背包从下方上滑 | 0.18秒 |

| 进入铁匠铺 | 炉门或锤击火星作为遮罩转场 | 0.35秒 |

### 46.2 装备成功表现

- 普通换装：槽位亮一次，武器或外观部件平滑替换。
- 激活2件套：套装徽章点亮并出现短提示。
- 激活4件套：角色脚下出现一次套装纹样，4件效果卡从徽章展开。
- 负荷姿态改变：角色站姿和脚底姿态图标变化，不弹大窗口打断。
- 新攻击固有式：右上角出现可点击4秒预览提示。

### 46.3 强化、进阶、升品

| 系统 | 核心表现 |
|---|---|
| 等级 | 经验流入装备，等级数字滚动 |
| 部位强化 | 槽位纹章被铁锤敲亮，强调属于槽位 |
| 进阶 | 0～4星沿装备外框依次点亮 |
| 升品 | 旧品质框碎成新框，新词条独立翻开 |
| 铭纹 | 铭纹压印进入槽位，纹路沿装备扩散 |
| 名器制造 | 图纸、器胚、核心进入炉中，名器轮廓从火中拔出 |
| 器魂觉醒 | 武器器灵从武器纹路中化形，与英雄完成一次联合攻击 |

重复操作可选择简化演出；首次史诗、传说、神话和器魂觉醒不可完全跳过，但可缩短。

### 46.4 重铸 UX

- 玩家先点选一条词条，其他条目压暗但不消失。
- 可能大类使用图标网格展示。
- 生成后旧词条在左、新词条在右，底部明确“保留旧词条”“使用新词条”。
- 未选择退出时默认保留旧词条，但服务器保存候选；再次进入继续比较。
- T档降低时使用紫红提示；数值虽高但构筑不匹配时显示原因。

### 46.5 十连装备揭示

沿用商业化抽卡演出：

- 十张装备卡先以锻造图纸/卡背形式排列。
- 玩家可逐张点击锻造翻开，也可一键全部锻造。
- 史诗卡背有紫色炉纹，传说在未翻开前只表现为金色裂纹，不提前显示具体装备。
- 翻开后先展示大图与固有式，再展开随机词条。
- 十连总览用图标、品质框、套装徽章和“新模板”角标，不堆长文本。

## 47. 装备模型、战斗表现与幻化

### 47.1 哪些装备必须显示在角色上

| 槽位 | 战斗模型显示 |
|---|---|
| 主武器 | 必须完整显示，并参与攻击路径 |
| 头冠 | 默认显示，可单独隐藏外观但保留属性 |
| 护甲 | 显示肩、胸、背三个主要模块，不完全覆盖角色种族特征 |
| 护手 | 显示手腕、爪套或机关部件 |
| 足具 | 俯视下只显示轮廓明显的靴筒、蹄甲或足部光效 |
| 腰佩 | 显示一到两个挂件，其他库存不实体化 |
| 灵饰 | 以颈部、胸前或背后小型悬浮符号表现 |
| 法宝 | 悬浮在角色后侧安全位置，冷却时压暗 |

### 47.2 妖族角色防遮挡规则

- 猫耳、犬吻、鹿角、鸟翼、龟甲、尾巴等种族轮廓优先级高于装备。
- 头冠根据耳、角类型使用6组自动适配挂点，不允许直接穿模。
- 护甲不覆盖整张兽脸和尾根。
- 大型法宝自动选择角色背后左右空位，避开剑匣、翅膀和神像。
- 返祖或法相期间，普通防具模型淡出到40%～70%，保留套装纹样和武器。

### 47.3 武器攻击预览

每把武器图鉴包含三段4秒短预览：

1. 基础攻击路径。
2. 固有式触发。
3. 传说名器或器魂效果。

预览使用真实判定半径和当前英雄模型，不能用概念特效误导范围。

### 47.4 掉落表现

| 品质 | 表现 |
|---|---|
| 普通/良品 | 进入战利品流，不打断战斗 |
| 稀有 | 蓝色短光柱和清脆掉落音 |
| 史诗 | 紫色纹章、卡片放大、套装徽章 |
| 传说 | 金橙光柱、名器剪影、短慢镜；可简化 |
| 神话材料 | 赤金器魂火，不直接伪装成神话装备掉落 |

### 47.5 词条触发可读性

- 原型词条使用武器路径上的小型纹路，不新增大面积全屏特效。
- 派系词条沿用对应派系色彩和形状。
- 套装4件效果使用套装徽章作为短提示。
- 同一秒内多个装备效果触发，只显示最高优先级的机制图标。
- 装备追加伤害跳字使用小号银边数字，0.15秒内同目标聚合。

### 47.6 幻化与染色

- 获得装备模板即可解锁基础外观图鉴。
- 分解不会失去已解锁外观。
- 幻化只改变模型和材质，不改变攻击判定；不同长度武器需使用同家族安全缩放。
- 套装染色解锁于图鉴、成就和活动，不占装备词条。
- 传说与神话器魂外观可独立开关，照顾低特效和视觉简洁玩家。

### 48.8 装备更换事务


高价值操作必须可幂等：升品、传承、重铸、名器制造、法宝升阶、本命转移、神话觉醒和传说分解。

### 48.9 冲突解析器

冲突解析器输出三种状态：

- `Active`：完整生效。
- `Modified`：被高优先级机制调整，详情显示实际效果。
- `Suppressed`：冲突失效，推荐分降低并显示原因。

示例：永久卡牌已经让回旋武器远点立即返回，而名器要求远点停留，则名器词条显示“被快速回返卡牌抑制”，玩家可以直接定位冲突。

### 48.10 性能规则

- 装备词条不得各自进行物理范围查询；复用攻击命中列表或空间查询服务。
- 额外攻击、线条、状态图标、跳字和音效都走对象池。
- 同屏装备追加实体受全局预算控制，超出时用合并伤害和视觉代理。
- 背包列表使用虚拟化；物品图标异步加载并缓存。
- 英雄换装只重绑变化的模型节点，不重建完整角色Prefab。
- 低画质减少器魂、套装纹样和粒子，不减少命中判定。

### 48.11 存档与版本迁移

- 每件装备保存唯一实例ID、生成种子和配置版本。
- 服务器保存词条结果，不在客户端重新随机。
- 旧六槽迁移使用一次性迁移事务和可回滚备份。
- 词条被版本删除时转换为同档自选重铸券，不静默变成低档词条。
- 套装重做时保留旧版一段时间，玩家可选择旧效果或免费转新。

## 49. 数值与平衡框架

### 49.1 基础属性公式

```text
装备基础属性 = 模板基础值
             × ItemPower曲线
             × 稀有度倍率
             × [1 + 等级成长系数 × (等级 - 1)]
             × [1 + 进阶星级系数 × 星级]

最终槽位属性 = 装备基础属性
             × 部位强化倍率
             + 固定值词条
             → 再结算百分比词条与条件效果
```

等级后期使用分段成长，避免Lv80对Lv60形成无法通过机制弥补的巨大差距。

### 49.2 同家族底材DPS归一

同一英雄、同ItemPower、无词条条件下，同家族武器30秒平均基础输出差应控制在±5%：

- 范围更大则攻速、单体或破势之一降低。
- 实体更多则单体倍率或触发系数降低。
- 回程更快则最大距离或去程威力降低。
- 自动校准更强则理论暴击或极限射程降低。
- 重武器可用控制、范围和守城价值补足，不要求木桩DPS完全相同。

### 49.3 词条预算

| 词条类型 | 单条预算定位 | 说明 |
|---|---:|---|
| 基础属性 | 1.0标准预算 | 稳定、容易计算 |
| 槽位行为 | 0.8～1.1 | 包含条件和便利价值 |
| 原型形变 | 1.0～1.3 | 高上限必须带触发条件 |
| 派系词条 | 0.9～1.2 | 不得成为派系必需品 |
| 触发追加伤害 | 0.8～1.2 | 受内置CD和Proc限制 |
| 双相词条 | 1.3～1.6收益 | 同时配置0.3～0.6等价代价 |

史诗三词条和传说四词条的平均有效预算差由多一条词条及名器特效组成，不额外暗加隐藏乘区。

### 49.4 行为词条的价值换算

行为词条不能只用木桩DPS衡量：

| 行为 | 等价评价 |
|---|---|
| 扩大攻击范围 | 实际额外命中目标数，不直接按面积平方计算 |
| 弹道校准 | 命中率和转火损失改善 |
| 安全落点 | 减少冲锋进入危险区的死亡率 |
| 指令响应 | 召唤物有效输出时间提高 |
| 阵线/星线 | 清群、控制和站位价值 |
| 资源返还 | 实际循环缩短，受每秒上限 |
| 护盾与韧性 | 生存时间、攻击不被打断的有效收益 |

### 49.5 名器、套装与法宝预算

| 内容 | 平均等价贡献 |
|---|---:|
| 史诗固有式增强 | 该件装备强度的3%～5% |
| 传说名器特效 | 该件装备强度的6%～9% |
| 套装2件 | 英雄总战力2%～4% |
| 套装4件新增部分 | 英雄总战力4%～6% |
| 法宝 | 英雄总战力5%～8%，含生存/控制等价价值 |
| 神话器魂 | 相对传说再提高3%～6%，主要是玩法形变 |

不能把名器、4件套、法宝和器魂全部做成独立乘法。它们大多进入追加伤害、条件增益或等价价值模块。

### 49.6 属性软硬上限

| 属性 | 建议规则 |
|---|---|
| 暴击率 | 常规硬上限75%，特殊短时效果可到100% |
| 冷却恢复 | 50%软上限，之后收益递减 |
| 攻速 | 每个原型独立安全上限，不能破坏动画和归返状态 |
| 移速 | 超额部分转为加速度或减速抗性 |
| 闪避 | 常规上限35%～45%，不形成常驻无敌 |
| 通用减伤 | 与防御综合后上限70% |
| 吸血/回复 | 每秒恢复上限，召唤和多段按Proc结算 |
| 额外实体 | 全局攻击实体预算，不按每系统分别放开 |

### 49.7 负荷平衡

- 轻灵、均衡、重装各自至少有一套S级构筑。
- 超载只适合特殊法相或守城，不得成为通用最高DPS。
- 负荷姿态不计入简单战力数字的大部分分值，推荐系统单独解释。
- 装备外观重量与逻辑负荷近似一致，避免薄布甲却算最重。

### 49.8 十二原型测试矩阵

每个攻击原型至少测试：

1. 基准稀有武器。
2. 史诗固有式武器。
3. 传说名器。
4. 一套2+2混搭。
5. 一套4件主套装。
6. 一个高适配法宝。
7. 一个非推荐修行派系。

测试房：静止Boss、移动Boss、密集潮、稀疏精英、三路守城和高危险地形。

### 49.9 十六派系装备依赖检查

| 指标 | 健康目标 |
|---|---:|
| 无派系专属词条时的完成度 | 达到派系理论强度85%以上 |
| 3条高适配装备效果后的提升 | 约10%～18%等价收益 |
| 单一必备名器使用率 | 不超过该派系玩家的45% |
| 非推荐武器使用率 | 至少15%具有可玩构筑 |
| 4件套集中度 | 任一套不超过全部终局方案30% |

### 49.10 装备评分

```text
装备评分 = 基础属性预算
         + 有效词条预算
         + 固有式当前可用价值
         + 套装即时激活价值
         + 当前原型与派系匹配
         + 负荷姿态适配
         - 属性溢出
         - 冲突或失效词条
```

评分同时输出“即时战力分”和“构筑匹配分”，不合成一个无法解释的数字。

### 49.11 招募与免费强度边界

- 抽到传说可以更快获得名器机制，但同模板可通过长期图纸制造。
- 神话觉醒、T6词条和器魂挑战必须参与玩法。
- 付费与免费同ItemPower同模板的基础数值完全一致。
- 限定期结束后的获取路径和时间必须在活动开始前公示。
- 排行玩法可按赛季对装备提供归一或分段匹配，避免纯收藏深度决定全部结果。

## 51. 主要风险与解决方案

### 风险1：八槽和五条成长线过于复杂

解决：按时间分批开放；首场只开放换装和继承，首日开放强化，之后再开放进阶、重铸、铭纹、法宝和本命器。装备页始终只推荐当前最值得进行的一步。

### 风险2：装备数量增加后背包全是垃圾

解决：高品质方向保护、愿望标签、智能掉落、自动分解、词条传承和器胚重铸共同减少垃圾；史诗以上至少一半词条必须有效。

### 风险3：原型和派系词条太窄

解决：单件最多1条派系词条、2条同原型词条；无专属词条时派系仍达到85%以上完成度；重铸可定向大类。

### 风险4：某件传说名器成为唯一答案

解决：同家族至少提供“范围、节奏、单体、控制”等多个方向；监控单一名器使用率，超过45%时优先增加替代机制而不是直接砍废。

### 风险5：套装压制所有散件

解决：只设2件/4件；4件新增贡献受控；传说散件、2+2+2和4+2都能竞争；法宝独立于套装。

### 风险6：招募让战斗掉落和铁匠铺失去意义

解决：招募负责首次发现大部分模板；战斗提供高ItemPower、Boss专属、T5/T6材料；铁匠铺负责复制、补件、修正和升品；神话不能直接抽。

### 风险7：铁匠铺能做装备后招募没有价值

解决：首次模板与图鉴解锁仍有价值，招募快速获得完整史诗/传说和重复名器精华；制造需要已解锁图纸和时间资源，二者服务不同节奏。

### 风险8：行为词条无限触发

解决：统一 `SourceDepth`、`ProcCoefficient`、独占组、内置CD和每秒预算；Depth2默认不再触发攻击型装备效果。

### 风险9：武器模型影响角色攻击判定不一致

解决：每个家族有安全长度区间，视觉边缘与判定误差小于8%；幻化限制同家族缩放；预览显示真实判定。

### 风险10：妖族角色装备严重穿模

解决：制作耳角、翼背、龟甲、尾巴等种族挂点包；装备模块化显示；提供隐藏头冠与简化法宝选项。

### 风险11：本命器造成换武器沉没成本

解决：器魂火可继承、本命关系可转移、旧器魂外观保留；本命成长不提高随机词条数量。

### 风险12：神话装备导致付费强度断层

解决：神话不能直接抽，基础倍率只小幅提高；主要解锁器魂机制；觉醒需要玩法挑战，免费可获得核心。

### 风险13：装备对比无法理解

解决：同时显示即时属性分、构筑匹配分、套装变化、负荷变化和失效机制；提供真实4秒新旧攻击预览。

### 风险14：资源种类太多

解决：前期只显示金币、铁矿、装备经验、精华；重铸石、铭纹墨、名器核心、器魂火随系统开放才进入资源页，不同时堆给新手。

### 风险15：旧六槽迁移引发损失争议

解决：迁移事务可回滚；旧饰品免费选择腰佩或灵饰；等级、品质、星级和投入保留；不合法词条提供同档免费重铸。

## 53. 最终装备结构与内容量

```text
8个装备槽位
├─ 7个普通装备槽：可随机词条、套装、铭纹
└─ 1个法宝槽：固定唯一法宝技

16个武器家族
└─ 每家族6把武器 = 96把

6个非武器普通槽
└─ 每槽8件 = 48件防具、腰佩与灵饰

24件法宝
24套2/4件套装
24枚铭纹
72条攻击原型词条
48条修行派系词条
16条邪铸双相词条
```

首轮明确命名并配置的基础装备模板共168件：96把武器、48件防具饰品、24件法宝。24套套装可以基于这些底材派生七槽部件，使实际可收集装备数量进一步扩大，而不要求等量增加独立模型。

装备2.0的核心不是让玩家多穿两件装备，也不是把词条数量翻倍，而是建立三层清晰差异：

1. **武器底材决定攻击实体和手感。**
2. **随机词条、套装和铭纹决定具体套路。**
3. **法宝与本命器提供少量、强识别的终局机制。**

推荐最先制作并实机验证四套完整构筑：凌锋的仙影归宗御剑、震岳的巨灵断岳重斩、月芽的梦轨日月回刃、绯月的阵道坠星法术。只要玩家在不查看面板的情况下也能从攻击轨迹和走位判断四套装备的差异，装备扩展方向才真正成立。
