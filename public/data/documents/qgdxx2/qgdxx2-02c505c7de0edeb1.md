# 竖版城市幸存者——战斗逻辑、操作、动画与表现完整制作方案

> 所属项目：《英雄城：永夜守望》（暂定名）  
> 文档版本：V1.0  
> 对应总案：《竖版城市建造 × 永久成长幸存者小游戏完整制作方案》  
> 默认实现环境：Unity、3D/2.5D 俯视角、竖屏、单英雄、自动攻击、单手移动  
> 目标：让策划、程序、动画、特效、UI、音频和测试能够依据同一套标准直接制作与验收

---

## 1. 战斗定位

### 1.1 战斗核心体验

战斗不是纯挂机数值对撞，也不是高操作动作游戏，而是由四种持续决策组成：

1. **位置决策**：在敌群、弹幕和环境危险之间寻找安全路线。
2. **威胁决策**：优先靠近补给、经验、精英或安全区域。
3. **终极技能决策**：在被包围、精英出现或 Boss 破绽阶段主动释放。
4. **长期构筑决策**：升级时从英雄专属卡池三选一，卡牌与等级永久保留。

玩家在一场 4～8 分钟的战斗中，应反复经历以下情绪变化：

```text
安全清怪 → 敌群增压 → 走位脱险 → 升级变强 → 技能形态变化
→ 精英压力 → 构筑开始联动 → 高密度清场 → Boss 决战 → 带资源回城
```

### 1.2 战斗设计原则

- 自动攻击降低操作门槛，但走位始终有价值。
- 玩家死亡必须能指出具体原因，禁止无预警秒杀。
- 技能升级必须有视觉变化，不能只有后台数字增长。
- 普通怪提供爽感，特殊怪制造问题，精英检验构筑，Boss 检验理解与操作。
- 永久成长不因失败回滚，失败只影响本局部分资源结算。
- 逻辑判定与动画表现解耦，伤害时间不能只依赖 Animation Event。
- 屏幕越混乱，预警、玩家、Boss 和拾取物的辨识优先级越高。

### 1.3 战斗基本参数

| 项目 | 推荐值 |
| --- | --- |
| 主线时长 | 4～8 分钟，标准关 6 分钟 |
| 资源关时长 | 3～5 分钟 |
| Boss 单独战 | 2～4 分钟 |
| 同屏普通敌人 | 中高端 80～120，低端 50～80 |
| 同屏有效投射物 | 建议 150～250，上限受设备档位控制 |
| 玩家受击无敌 | 0.30～0.45 秒，默认 0.35 秒 |
| 接触伤害间隔 | 同一敌人对同一目标 0.6～1.0 秒 |
| 单次高伤预警 | 普通怪至少 0.45 秒，Boss 至少 0.7 秒 |
| 目标帧率 | 默认 60 FPS，低端保底 30 FPS |

## 2. 一场战斗的完整生命周期

### 2.1 战前阶段

1. 玩家在关卡页选择英雄。
2. 系统装载英雄基础等级、星级、装备、账号天赋和城市援助。
3. 装载该英雄所有已获得的永久卡牌及当前路线。
4. 显示本关环境、主要敌人、Boss、推荐战力和主要掉落。
5. 玩家点击出征，扣除粮食；首次主线和失败重试按总案规则处理。
6. 异步加载场景、特效池、音效池、敌人池和英雄资源。
7. 镜头展示场景 1～1.5 秒，英雄入场，出现“战斗开始”。
8. 玩家获得 1.5 秒出生保护；移动或主动攻击不会取消保护，终极技能不可在保护期充能。

### 2.2 战中阶段

```text
生成波次
  ↓
敌人进入 → 寻路/攻击 → 玩家走位与自动攻击
  ↓                         ↓
掉落经验 ← 敌人死亡 ← 命中/伤害/状态结算
  ↓
拾取经验 → 永久经验条满 → 暂停 → 三选一 → 保存 → 应用卡牌
  ↓
精英/事件/补给 → Boss 入场 → Boss 战
```

### 2.3 结算阶段

胜利流程：

1. Boss 或终局目标死亡后进入 0.3 秒慢动作。
2. 停止新敌人生成，清除敌方危险投射物和范围伤害。
3. 剩余普通敌人被震飞或转化为结算表现，不再伤害玩家。
4. 自动吸收场上未拾取的重要掉落；普通经验按既定比例结算。
5. 播放英雄收势和胜利动作，镜头轻微拉近。
6. 依次展示关卡结果、英雄永久升级、装备/材料、城市资源和首通解锁。
7. 玩家点击返回城市或下一关。

失败流程：

1. 玩家生命归零，立刻停止玩家输入和新伤害结算。
2. 播放死亡/倒地，时间缩放至 0.35，持续约 0.6 秒后恢复。
3. 若有复活次数，弹出复活选择；复活弹窗期间战场完全暂停。
4. 无复活或放弃复活后进入失败结算。
5. 已确认的永久等级、永久卡牌和保底资源保留；未达成的关卡奖励不发放。
6. 根据死亡数据给出一条具体建议，不使用泛化的“提升战力”。

### 2.4 暂停状态

以下情况进入逻辑暂停：

- 永久卡牌三选一。
- 战场宝箱选择。
- 系统暂停菜单。
- 复活选择。
- 新机制首次教学。

暂停时必须冻结：AI、移动、投射物、伤害区域、Buff 计时、刷怪计时、技能冷却和关卡计时。粒子可使用 Unscaled Time 播放少量界面背景效果，但不得继续造成判定。

## 3. 玩家操作方案

### 3.1 移动输入

- 屏幕下方约 65%区域均可唤起浮动摇杆。
- 按下点作为摇杆中心，拖动方向为移动方向。
- 摇杆视觉半径建议 110～140 px，具体按参考分辨率缩放。
- 输入死区建议为半径的 10%～14%，防止轻触抖动。
- 输入强度低于 0.25 时不移动；0.25～1.0 映射为 45%～100%移速。
- 手指离开后摇杆淡出，角色在 0.08～0.12 秒内减速至停止。
- 手指滑出屏幕后应继续按最后有效方向移动，直到抬手或系统收到取消事件。

### 3.2 自动攻击

- 普通攻击和主要自动技能由系统按冷却自动释放。
- 玩家移动不会默认打断普通攻击。
- 攻击时上半身或武器朝向目标，下半身继续按移动方向运动。
- 不适合分层动画的英雄使用短时朝向目标，但不能强制拉回或改变玩家移动方向。
- 没有合法目标时不播放空攻击；周期范围技能、环绕技能和地雷类技能除外。

### 3.3 手动终极技能

- 终极技能位于右下角，距离系统边缘和安全区至少 24 px。
- 充能方式按英雄配置：随时间、造成伤害、击杀、承受伤害或组合充能。
- 充满后按钮放大一次并出现柔和脉冲，不持续剧烈闪烁。
- 点击后立即记录输入，技能在 0.1 秒内开始响应。
- 若角色处于不可释放状态，进入 0.3 秒输入缓存；状态解除后仍合法则自动释放。
- 需要方向的终极技能默认朝当前锁定目标或最高威胁方向，不增加第二摇杆。
- 需要位置的终极技能默认选择敌人最密集区域，并在释放前显示 0.15～0.25 秒目标预览。

### 3.4 局内道具

首版最多同时携带 2 个：

- 治疗药剂：点击立即使用，满血时禁止误用并显示“生命已满”。
- 炼金炸弹：投向敌人最密集区域，有清晰落点。
- 全屏磁铁：吸取所有经验和普通掉落。
- 城市信号弹：触发当前装配的城市援助。

道具点击不打断移动，使用后必须显示剩余数量与冷却遮罩。

### 3.5 操作设置

- 摇杆灵敏度：低/中/高。
- 固定摇杆/浮动摇杆。
- 左手/右手布局镜像。
- 自动释放终极技能开关，仅用于已通关资源关。
- 震动强度、镜头震动、伤害数字详细度。
- 色弱预警模式和高对比危险区。

## 4. 玩家移动、碰撞与朝向

### 4.1 移动逻辑

推荐使用自定义 Kinematic Motor 或 CharacterController，不依赖刚体受力作为主要移动方式。

```text
期望速度 = 输入方向 × 基础移速 × Buff倍率 × 地形倍率
实际速度 = MoveTowards(当前速度, 期望速度, 加速度 × DeltaTime)
最终位移 = 实际速度 × DeltaTime + 技能位移 + 击退位移
```

移动优先级：

1. 强制位移，如 Boss 抓取、击飞。
2. 技能位移，如冲锋、闪现。
3. 控制状态修正，如定身、减速。
4. 玩家输入移动。
5. 轻微碰撞分离和边界修正。

### 4.2 碰撞层级

- 玩家与地图硬障碍：阻挡。
- 玩家与普通敌人：软碰撞或轻微分离，不允许敌群把玩家完全卡死。
- 玩家与 Boss/大型敌人：硬碰撞，避免穿模。
- 普通敌人之间：使用低成本分离力，不做完整刚体堆叠。
- 投射物：按阵营、技能标签和穿透次数判断，不与无关物理层碰撞。
- 拾取物：触发器，不阻挡任何单位。

### 4.3 防卡死规则

- 玩家周围半径内若敌人重叠量超过阈值，敌人之间分离强度提高。
- 玩家连续 0.5 秒收到多个单位夹击且没有可行出口时，可获得极短“穿过小体型敌人”能力，但仍会受到接触伤害。
- 角色被地形挤压到非法位置时，回退到最近 0.5 秒内记录的安全点。
- 冲锋和击退结束后进行一次 NavMesh/可行走区域投影。

### 4.4 朝向规则

| 状态 | 朝向来源 |
| --- | --- |
| 无目标移动 | 移动方向 |
| 普通攻击准备/生效 | 当前攻击目标 |
| 自由施法 | 技能目标方向 |
| 冲锋 | 冲锋方向 |
| 受击 | 保持原朝向或轻微朝伤害来源偏转 |
| 死亡 | 最后有效朝向 |

朝向平滑时间建议 0.05～0.12 秒；Boss 高伤攻击可以更慢地转向，以给玩家可读的躲避窗口。

## 5. 战斗单位状态机

### 5.1 通用状态

```text
Spawn
  ↓
Alive ───────────────────────────────┐
  ├─ Locomotion                     │
  ├─ Attack/Cast                    │
  ├─ Controlled                     │
  ├─ SkillMove                      │
  └─ Invulnerable                   │
  ↓ HP ≤ 0                          │
Dying → Dead → Despawn              │
```

### 5.2 状态字段

每个单位至少维护：

- UnitId、阵营、单位类型、当前状态。
- 当前/最大生命、护盾、防御、抗性、韧性。
- 移速、朝向、目标、攻击冷却。
- 无敌、无法选中、霸体、控制免疫标记。
- Buff 列表、伤害来源记录、最近安全位置。
- 当前技能实例和技能阶段。
- 死亡归属、经验与掉落归属。

### 5.3 玩家状态优先级

```text
死亡 > 强制控制 > 强制位移 > 终极技能 > 普通技能 > 普通攻击 > 移动 > 待机
```

高优先状态可以中断低优先状态；低优先状态不能覆盖高优先状态。每个技能配置以下字段：

- CanMove：释放期间能否移动。
- MoveSpeedRate：释放期间移速倍率。
- CanRotate：能否更新朝向。
- InterruptLevel：可打断等级。
- SuperArmor：是否霸体。
- InputBufferTime：输入缓存时长。

### 5.4 技能移动锁定等级

| 类型 | 规则 | 使用场景 |
| --- | --- | --- |
| Free Cast | 完全不限制移动 | 飞剑、雷击、环绕物 |
| Soft Lock | 0.1～0.25 秒内移速降至 40%～70% | 火枪射击、短挥砍 |
| Hard Lock | 0.2～0.5 秒不可移动 | 强力蓄力、终极技能 |
| Skill Move | 由技能驱动位移 | 冲锋、闪现、跳斩 |

竖屏幸存者战斗中，普通攻击原则上使用 Free Cast 或 Soft Lock。Hard Lock 必须带来明显收益、保护或可预期时机，不能频繁夺走操作权。

## 6. 索敌与威胁评估

### 6.1 合法目标条件

目标必须满足：

- 存活且未进入死亡状态。
- 阵营敌对。
- 未处于不可选中状态。
- 位于技能搜索范围内。
- 技能要求的高度、地面/空中、障碍条件合法。
- 尚未超过同一投射物的命中次数限制。

### 6.2 默认威胁分

```text
威胁分 = 距离分
       + 即将命中分
       + 精英/Boss权重
       + 正在施法权重
       + 低生命可击杀权重
       + 技能偏好权重
       - 障碍惩罚
       - 无效目标惩罚
```

推荐权重：

| 因素 | 建议 |
| --- | ---: |
| 最近距离 | 0～100 |
| 1 秒内可能命中玩家 | +80 |
| 精英 | +35 |
| Boss | +50 |
| 正在释放高威胁技能 | +30 |
| 一击可击杀 | +15 |
| 被障碍阻挡 | -1000 |

### 6.3 索敌刷新

- 不在每帧为所有技能全场搜索。
- 普通攻击每 0.10～0.20 秒刷新目标。
- 低频自动技能在冷却即将结束前 0.15 秒搜索。
- 环绕、范围和持续技能使用空间分区查询。
- 当前目标仍合法且分数接近新目标时保持目标，避免角色频繁左右抖头。

### 6.4 技能目标模式

- Nearest：最近敌人。
- HighestThreat：最高威胁。
- EliteFirst：精英/Boss 优先。
- LowestHP：最低生命。
- HighestDensity：敌人最密集位置。
- RandomValid：随机合法目标。
- Self/Owner：自身或召唤者。
- PredictedPosition：根据目标速度预测位置。

## 7. 攻击与技能执行逻辑

### 7.1 技能执行阶段

所有技能统一拆分为：

```text
Ready → Request → Validate → Windup → Active → Recovery → Cooldown → Ready
```

- Ready：冷却完成，可以请求。
- Request：自动逻辑或玩家输入提出释放。
- Validate：检查目标、资源、状态和场地。
- Windup：前摇，可包含转向和预警。
- Active：生成判定、投射物、范围或位移。
- Recovery：后摇，判定已经完成。
- Cooldown：进入冷却。

### 7.2 判定权威

- 技能配置时间轴决定命中判定时间。
- Animator 只根据技能时间轴同步播放动画。
- Animation Event 可触发武器拖尾、音效、脚步尘等表现，但不能独立决定伤害。
- 即使动画资源替换、播放速度变化或低端机跳帧，技能判定仍保持一致。

### 7.3 攻击快照

技能释放时记录：

- 施法者攻击、暴击、增伤、元素、卡牌等级。
- 技能等级、目标、起点、方向、随机种子。
- 是否允许技能飞行期间继承新的属性变化。

默认使用“释放时快照”；持续范围和召唤物可按配置每次命中动态读取。避免同一技能在中途因 Buff 消失而产生难以理解的伤害跳变。

### 7.4 冷却与攻速

```text
最终攻击间隔 = 基础间隔 / (1 + 攻击速度加成)
最终技能冷却 = 基础冷却 × 冷却倍率
```

- 普通攻击间隔建议下限 0.12 秒。
- 冷却缩减建议软上限 50%，特殊构筑可突破但需单独控制。
- 动画播放速度建议最高 1.8～2.0 倍；逻辑攻速继续提高时，使用多发、额外判定或简化动画，不无限加速骨骼动画。
- 冷却从 Active 开始还是 Recovery 结束开始，必须按技能配置统一说明。

### 7.5 技能模板

#### 近战扇形

- 在 Active 时刻查询扇形内目标。
- 每次挥击对同一目标最多命中一次。
- 判定半径应略大于视觉武器长度 5%～10%，减少“看起来打到却没伤害”。
- 可配置击退方向为施法者到目标方向。

#### 直线投射物

- 生成位置、方向、速度、寿命、半径、穿透数、碰撞层可配置。
- 高速弹体使用 Sweep/Raycast 防止穿透。
- 命中后先结算伤害，再减少穿透次数；穿透耗尽后回收。

#### 抛物/落点技能

- 先确定目标点，再显示落点预览。
- 飞行时间与距离可以固定或按速度计算。
- 命中地面时生成一次范围伤害和残留区。

#### 持续范围

- 创建 Area 实例，按固定 Tick 间隔查询目标。
- 同一目标的 Tick 间隔不得依赖帧率。
- 高频 Tick 默认 0.2～0.5 秒；表现可连续，伤害不需要每帧结算。

#### 环绕物

- 位置由逻辑角度计算，不使用刚体追随。
- 每个环绕物维护独立或共享命中冷却。
- 数量过多时合并轨迹特效和命中检测批次。

#### 召唤物

- 继承召唤瞬间或实时属性由配置决定。
- 有独立目标、生命、持续时间、攻击间隔和最大数量。
- 超过上限时刷新最早召唤物，避免无限增长。

#### 冲锋/位移

- Windup 锁定方向，Active 由技能位移控制器移动。
- 每个目标维护已命中集合。
- 遇到不可穿越地形提前停止，并触发结束效果。
- 位移结束必须投影到合法区域。

## 8. 命中与伤害结算

### 8.1 完整伤害流程

```text
生成命中候选
→ 检查阵营/存活/无敌/重复命中
→ 读取攻击快照
→ 判定闪避或格挡
→ 计算基础伤害
→ 计算暴击
→ 计算增伤、易伤、防御、抗性
→ 护盾吸收
→ 生命扣除
→ 韧性/击退/控制
→ 吸血、反伤、击中触发
→ 受击表现与跳字
→ 死亡判定
→ 击杀触发与掉落
```

### 8.2 基础公式

```text
技能原始伤害 = 技能基础值 + 施法者攻击 × 技能系数

增伤后伤害 = 技能原始伤害
            × (1 + 通用增伤 + 同类技能增伤)
            × (1 + 条件独立增伤)

减伤率 = 防御 / (防御 + 100 + 20 × 章节序号)

最终生命伤害 = 增伤后伤害
              × 暴击倍率
              × (1 - 减伤率)
              × (1 - 元素抗性)
              × 难度修正
```

### 8.3 伤害类型

| 类型 | 主要特点 | 表现颜色 |
| --- | --- | --- |
| 物理 | 受防御影响，可暴击 | 白/浅黄 |
| 火焰 | 燃烧、爆炸、持续伤害 | 橙红 |
| 雷电 | 弹射、感电、短控制 | 蓝紫 |
| 冰霜 | 减速、冻结、破碎 | 冰蓝 |
| 毒素 | 叠层、持续、削弱 | 绿色 |
| 神圣 | 护盾、治疗、对亡灵加成 | 金白 |
| 真实 | 忽略防御，严格控制来源 | 亮白/紫边 |

首版不需要所有英雄都覆盖全部元素，但底层应支持标签化扩展。

### 8.4 暴击

- 默认暴击伤害 150%。
- 常规暴击率建议上限 75%。
- 持续伤害默认不能暴击，除非卡牌明确允许。
- 同一高频技能暴击数字可以聚合，防止每 Tick 产生大字。
- Boss 的特殊部位弱点可使用“弱点伤害”而不是简单提高暴击率。

### 8.5 闪避、格挡与护盾

- 闪避：本次伤害和附带控制均无效，显示“闪避”。
- 格挡：按比例降低伤害，可保留部分控制或韧性伤害。
- 护盾：先扣护盾，再扣生命；护盾受击跳字使用蓝色。
- 无敌：不产生伤害和控制，不触发吸血；可按技能配置是否触发“命中时”效果。
- 无法选中：技能不能选择目标，已飞行的锁定弹可丢失目标或按配置继续追踪。

### 8.6 玩家受击保护

- 玩家受到有效伤害后获得默认 0.35 秒受击无敌。
- 同一时间多枚弹体命中只结算第一批合法伤害，特殊 Boss 连击另行配置。
- 受击无敌期间仍允许移动和拾取。
- 受击无敌不免疫地图持续区域，地图区域按独立较慢 Tick 结算。
- 高难模式可以缩短保护时间，但不能完全取消。

### 8.7 接触伤害

- 敌人碰到玩家不会每物理帧造成伤害。
- 每个敌人维护对玩家的接触伤害冷却，默认 0.8 秒。
- 大量小怪同时重叠时，玩家全局接触伤害最短间隔与受击无敌共同限制爆发。
- 接触攻击表现必须有身体前倾、咬击或撞击动作，禁止“仅靠模型重叠扣血”。

### 8.8 击杀归属

- 最后一次有效伤害为默认击杀来源。
- 持续伤害保留原施法者和技能来源。
- 环境击杀可追溯到最近 3 秒内推动/标记该敌人的玩家技能。
- 击杀触发卡、吸血、经验和任务都读取统一 KillContext，避免系统各自判断。

## 9. Buff、Debuff 与控制

### 9.1 Buff 数据字段

- BuffId、来源单位、目标单位。
- Buff 标签、正面/负面、元素类型。
- 持续时间、Tick 间隔、最大层数。
- 叠层规则、刷新规则、同源/异源规则。
- 属性修改、触发器、视觉、音效、UI 图标。
- 驱散类型、死亡是否保留、阶段切换是否清除。

### 9.2 叠层规则

| 规则 | 说明 | 示例 |
| --- | --- | --- |
| Refresh | 叠加只刷新时间 | 减速 |
| StackAndRefresh | 增加层数并刷新总时间 | 感电 |
| Independent | 每层独立计时 | 中毒 |
| ReplaceStronger | 只保留更强效果 | 攻击提升 |
| UniqueBySource | 每个来源独立存在 | 多个召唤物标记 |

### 9.3 控制类型

- 减速：降低移速，不影响攻击动画速度，除非明确说明。
- 定身：无法移动，可以攻击和施法。
- 沉默：无法使用主动/自动技能，普通攻击是否保留按角色配置。
- 眩晕：无法移动、攻击和施法。
- 击退：强制位移，结束后恢复原状态。
- 击飞：短时离地并失去行动，Boss 通常免疫。
- 冻结：强控制，解除时可触发破碎伤害。
- 嘲讽：只用于有多目标或城市守卫的玩法。

### 9.4 韧性和 Boss 控制衰减

- 普通怪：正常接受控制。
- 精英：控制持续时间 × 50%～70%。
- Boss：强控制转化为韧性伤害或短暂停顿。
- Boss 韧性条被打空后进入 2～4 秒破防状态，受到额外伤害。
- 同种控制短时间重复作用时产生衰减，防止无限控制。

## 10. 敌人 AI 与行为逻辑

### 10.1 AI 基础结构

```text
出生 → 选择行为 → 移动/保持距离 → 攻击预备 → 攻击 → 后摇 → 再评估
                       ↘ 受控/击退 ↗
```

AI 不需要所有敌人每帧执行完整决策。建议将感知与决策分帧更新，移动在更高频率更新。

### 10.2 追逐怪

- 选择玩家为目标。
- 朝玩家移动，并加入轻微横向偏移，避免所有敌人排成直线。
- 进入攻击距离后播放攻击前摇，再进行接触/近战判定。
- 后摇结束后重新评估，不持续贴身每帧攻击。

### 10.3 远程怪

- 尝试保持在理想距离区间。
- 距离过近时后撤或横移，过远时接近。
- 射击前显示方向和短预警。
- 屏幕内远程怪数量受 WaveDirector 限制。
- 玩家被大量近战包围时，远程怪刷新权重降低。

### 10.4 冲锋怪

1. 接近到触发距离。
2. 停顿并锁定方向，地面显示直线预警。
3. 蓄力 0.5～0.9 秒。
4. 直线冲锋，不在途中追踪玩家。
5. 命中或撞墙后进入 0.6～1.0 秒硬直。

玩家应能通过横向移动躲避，并利用其硬直反击。

### 10.5 召唤怪

- 保持中远距离。
- 召唤动作清晰，召唤点出现可攻击或可打断的提示。
- 召唤物计入同屏预算，达到上限时召唤怪改用普通攻击。
- 召唤怪本体生命不应同时过高，否则会拖长战斗。

### 10.6 护盾怪

- 可给周围敌人提供减伤区域，或自身正面高减伤。
- 保护效果必须有连线、罩体或地面圈。
- 护盾被破时有明显破碎和短硬直，形成爽点。

### 10.7 自爆怪

- 进入近距离后发光、膨胀并发出独立提示音。
- 自爆预警 0.7～1.0 秒，期间可被击退或击杀。
- 被提前击杀可以缩小爆炸、取消爆炸或反伤敌人，提供策略差异。

### 10.8 敌群分离与队形

- 使用空间哈希/网格获取邻居，仅与少量邻居分离。
- 分离力小于追逐力，避免敌人在玩家周围形成不可接近的圆环。
- 大体型敌人具有更高避让权重，小怪优先为其让路。
- 特殊怪保留一定屏幕间距，避免多个预警完全重叠。

## 11. 刷怪与波次导演

### 11.1 WaveDirector 职责

- 按关卡时间和玩家状态生成敌群。
- 控制同屏数量、远程怪数量、特殊怪数量和总威胁预算。
- 选择出生位置，避免视野内无提示生成。
- 在玩家过强时提高组合压力，在玩家濒死时减少瞬间刷新但不直接削弱存量敌人。
- 负责精英、事件、Boss 的时间节点。

### 11.2 威胁预算

每种敌人有 Cost：

| 敌人 | 示例 Cost |
| --- | ---: |
| 普通追逐怪 | 1 |
| 快速小怪 | 1.5 |
| 远程怪 | 2.5 |
| 冲锋怪 | 3 |
| 护盾/召唤怪 | 4 |
| 精英 | 10～18 |

每一波按预算选择敌人组合。提高难度优先增加组合和精英频率，其次增加数量，最后才增加生命。

### 11.3 出生规则

- 普通敌人默认出生在镜头外 1～3 米的环形区域。
- 不得出生在玩家前进方向过近位置、封闭地形、危险区或玩家刚刚经过的位置。
- 特殊敌人在镜头内出生时必须有传送阵、地裂或落地预警。
- Boss 出生前停止普通生成，处理残留危险物并锁定出生区。

### 11.4 标准 6 分钟节奏

| 时间 | 波次内容 | 表现 |
| --- | --- | --- |
| 0:00～0:30 | 少量追逐怪 | 建立攻击反馈 |
| 0:30～1:15 | 快速怪加入 | 提高走位频率 |
| 1:15～1:40 | 第一精英 | 精英标记、宝箱预告 |
| 1:40～2:40 | 近战 + 远程组合 | 强调目标优先级 |
| 2:40～3:10 | 资源事件/小休息 | 治疗、磁铁或宝箱 |
| 3:10～4:20 | 冲锋/护盾怪加入 | 构筑压力测试 |
| 4:20～5:15 | 高密度高潮波 | 清场爽感与终极技能时机 |
| 5:15～5:30 | 波次收束 | Boss 提示、回收危险区 |
| 5:30～6:00+ | Boss | 终局战，根据血量可延长 |

## 12. Boss 战斗逻辑

### 12.1 Boss 结构

Boss 至少包含：

- 1 个基础攻击。
- 2 个需要移动躲避的技能。
- 1 个召唤、场地变化或阶段机制。
- 1 个可被利用的破绽窗口。
- 1 次阶段转换和专属死亡演出。

### 12.2 Boss 状态

```text
Intro → CombatPhase1 → Transition → CombatPhase2 → Enrage/Final → Dying
```

阶段转换期间：

- Boss 可无敌，但时间控制在 1～2.5 秒。
- 清理或冻结已有的冲突技能。
- 镜头、音乐和特效明确提示变化。
- 不在玩家无法操作时突然结算伤害。

### 12.3 技能选择

Boss 不完全随机连续放招。使用技能权重与约束：

- 技能冷却完成。
- 与玩家距离合适。
- 不连续释放同一个高压技能。
- 不连续使用两个完全封路技能。
- 玩家刚复活后的 1.5 秒不释放不可躲高伤技能。
- 阶段必用技能按时间或生命阈值触发。

### 12.4 Boss 预警规范

| 危险等级 | 预警时间 | 视觉 | 音效 |
| --- | ---: | --- | --- |
| 普通攻击 | 0.35～0.55 秒 | 动作前摇/小范围 | 武器蓄力声 |
| 中伤范围 | 0.6～0.9 秒 | 黄色/橙色边界 | 短提示 |
| 高伤技能 | 0.9～1.4 秒 | 红色填充、方向清晰 | 独立警报 |
| 必杀/阶段技 | 1.5～2.5 秒 | 屏幕提示、镜头反应 | 语音或强提示 |

预警时长不是越长越好。必须配合动作节奏，在预警结束时准时生效，不能出现地面圈消失后才受伤。

### 12.5 破防与韧性

- Boss 受到控制类攻击时累积韧性伤害。
- 韧性条归零后进入破防，取消当前非强制技能。
- 破防持续 2～4 秒，Boss 承伤提高 15%～30%。
- 破防结束后韧性恢复，并获得短时间抗性，防止连续破防。

### 12.6 首章 Boss“腐化树王”完整节奏

#### 阶段一：100%～60%

- 根须横扫：0.8 秒扇形预警，横扫后地面残留 0.6 秒木刺，不重复伤害。
- 木刺直线：锁定玩家当前位置，0.7 秒后沿直线连续刺出。
- 腐化种子：投出 3 枚种子，5 秒后孵化小怪；种子可被击破。

#### 转阶段

- Boss 扎根并怒吼，震开周围敌人但不造成伤害。
- 镜头拉远 5%，场地边缘生长毒藤。
- 音乐增加鼓点和低频层。

#### 阶段二：60%～0%

- 根须横扫连续两次，第二次方向相反。
- 木刺变为三条，中心线先出现、两侧后出现，保留安全缝隙。
- 腐化种子被击破后掉落治疗能量，鼓励主动处理。
- 20%生命进入狂暴：攻击间隔缩短 15%，不增加不可读的新技能。

#### 死亡

- 树王身体开裂，核心亮起。
- 0.2 秒命中停顿，镜头轻震，核心爆裂。
- 枝干向后倒下，腐化雾消散，地面恢复色彩。
- Boss 核心与建筑图纸从核心位置飞出，禁止与普通金币混在一起。

## 13. 永久经验与卡牌升级流程

### 13.1 经验获得

- 敌人死亡生成经验晶体，归属当前英雄。
- 经验拾取后立即增加英雄永久战斗经验。
- 达到升级阈值时创建唯一升级事务。
- 一次拾取跨越多个等级时，升级选择按顺序排队，不合并跳过。

### 13.2 升级触发流程

```text
经验条满
→ 0.15秒时间减速
→ 战场逻辑暂停
→ 生成并保存三张候选卡
→ 卡牌从下方弹入
→ 玩家查看/刷新/选择
→ 二次确认互斥路线
→ 保存永久卡牌和新等级
→ 应用技能参数与表现变化
→ 卡牌飞入英雄头像
→ 0.35秒渐进恢复战斗
```

### 13.3 升级保护

- 恢复战斗后玩家获得 0.5 秒升级保护。
- 暂停前已贴脸的敌人被轻微推开 0.3～0.5 米，仅做空间整理，不造成伤害。
- 暂停前的高伤预警保持原进度，恢复后给予至少 0.25 秒反应时间。
- 不清除玩家主动制造的持续技能。

### 13.4 卡牌即时应用

- 纯属性卡：选择确认后立即重算属性。
- 投射物数量：下一次攻击生效，不修改已经飞出的投射物。
- 攻速/冷却：按“已过去比例”重算剩余时间，避免重新获得完整冷却。
- 环绕物数量：用 0.3 秒生成动画补充新环绕物。
- 技能进化：先淡出旧特效，再以短暂爆发生成新形态。
- 最大生命提升：同时按增加量的一定比例恢复生命，建议 50%～100%，避免升级后只增加空血条。

### 13.5 卡牌获得表现

- 普通卡：短促亮光、图标飞入。
- 新技能：英雄周围出现技能象征物，播放专属音效。
- 路线核心：卡面扩大、背景变化、确认锁定关系。
- 进化卡：战场背景短暂压暗，旧技能图标与组合卡汇聚成新图标。
- 永久保存必须显示“已永久记录”，但首几次后可缩短提示。

## 14. 掉落、拾取与战场物件

### 14.1 掉落类型

| 类型 | 是否落地 | 拾取方式 |
| --- | --- | --- |
| 经验晶体 | 是 | 进入吸附范围 |
| 金币/普通材料 | 是 | 吸附或结算回收 |
| 治疗能量 | 是 | 接触立即使用，满血可保留短时间 |
| 磁铁 | 是 | 接触吸取全场普通掉落 |
| 宝箱 | 是 | 靠近自动打开或击败精英后弹窗 |
| Boss 核心/图纸 | 特殊展示 | 胜利阶段自动获取 |

### 14.2 吸附逻辑

```text
距离 > 感应半径：静止或轻微漂浮
距离 ≤ 感应半径：延迟0.05秒后加速飞向玩家
距离 ≤ 拾取半径：结算并回收
```

- 吸附速度随距离缩短提高，保证末段快速进入。
- 多个经验晶体同时吸附时形成弧线和轻微时间差。
- 不为每个普通金币播放独立强音效，使用连续拾取音阶和频率限制。

### 14.3 掉落合并

- 同区域经验晶体超过阈值时自动合并为高一级晶体。
- 合并保持经验总量不变。
- 屏幕外掉落也参与合并。
- 掉落物总数超过硬上限时，优先合并经验，其次将普通金币转入结算缓存。

### 14.4 可破坏物

- 木箱、矿石、腐化植物等可被玩家攻击破坏。
- 不参与自动索敌最高优先级，除非附近无敌人或配置为目标。
- 破坏物掉落资源、治疗或短期场景增益。
- 破坏动画使用碎片池，低端机只播放缩放破碎和少量粒子。

## 15. 生命、死亡、复活与结算

### 15.1 玩家濒死表现

- 生命低于 30%：生命条红色脉冲，屏幕边缘出现低强度红晕。
- 生命低于 15%：加入心跳音，但每 2 秒最多一次。
- 低血表现不得遮挡 Boss 预警，可在设置中降低或关闭。
- 医疗、护盾或无敌生效后立即减弱濒死效果。

### 15.2 死亡判定

- 伤害结算后生命 ≤ 0，检查免死、复活和任务保护。
- 若触发免死，生命锁定为 1，播放独立护佑特效，并进入技能冷却。
- 否则进入 Dying，取消所有可取消技能、停止碰撞伤害、禁用输入。
- 死亡动画期间不继续受到伤害，也不触发新的掉落。

### 15.3 复活规则

- 每场默认最多 1 次，来源可以是英雄天赋、道具或激励广告。
- 复活位置优先为当前安全位置；若无安全位置则回到最近记录点。
- 复活恢复 50%～100%生命，获得 2 秒无敌。
- 清除玩家周围 2～3 米内普通敌人或将其击退；Boss 不被清除。
- 清除正在覆盖复活点的敌方持续伤害区域。
- Boss 技能状态继续，但复活保护结束前不立即释放高伤锁定技。

### 15.4 失败保留

- 永久战斗经验：100%保留。
- 已确认永久卡牌：100%保留。
- 普通战斗资源：按关卡规则保留 40%～70%。
- 首通奖励、Boss 核心：失败不发放。
- 已消耗局内道具：不返还，教学关可例外。

### 15.5 死亡原因记录

保存：

- 最终伤害来源、技能和伤害类型。
- 最后 5 秒承伤列表。
- 死亡时周围敌人数量。
- 玩家生命、护盾、关键 Buff。
- 关卡时间、英雄构筑和装备。

提示示例：

- “你被冲锋兽命中。它冲锋前会出现红色直线，横向移动可以躲开。”
- “远程敌人存活过多，尝试优先靠近并击杀紫色弓手。”
- “Boss 的种子孵化了大量小怪，先击破种子可以获得治疗。”

## 16. 动画系统总规范

### 16.1 Animator 分层

推荐层级：

| Layer | 内容 | 方式 |
| --- | --- | --- |
| Base | 待机、移动、冲锋、死亡 | 全身 |
| UpperBody | 普通攻击、轻技能 | 上半身 Avatar Mask |
| AdditiveHit | 轻受击、后坐力、呼吸 | Additive |
| Status | 冻结、眩晕、强化姿态 | 按状态覆盖 |
| Face/Accessory | 表情、飘带、武器附属 | 可选独立控制 |

### 16.2 玩家基础动画清单

- Idle：1 个主待机 + 1～2 个低频变体。
- Move：前、后、左、右或 8 方向 Blend Tree。
- Attack01/02：基础攻击；远程英雄包含后坐力。
- Skill01/02：自动技能动作。
- Ultimate：终极技能起手、维持、结束。
- HitLight：轻受击 Additive。
- HitHeavy/Knockback：重受击或击退。
- Stun、Frozen、Knockdown。
- Spawn/Entrance。
- Victory。
- Dying/Death。
- Revive/GetUp。

MVP 可减少方向动画，但不能缺少攻击、受击、死亡、胜利和终极技能。

### 16.3 动画状态切换

- Idle ↔ Move 混合时间 0.08～0.15 秒。
- 普通攻击进入时间 0.03～0.08 秒，保证响应。
- 轻受击使用 Additive，不频繁打断移动和攻击。
- 重受击可以中断普通攻击，但不打断霸体技能。
- 死亡为最高优先级，强制退出所有其他状态。
- 同一攻击连续触发时允许 Combo 或从 Recovery 缩短切回 Windup。

### 16.4 动画与移动

- 常规移动关闭 Root Motion，由战斗移动系统驱动。
- 冲锋、跳斩等位移技能也建议由逻辑曲线驱动，动画只匹配节奏。
- 动画脚步速度通过 Animator Speed 或 Blend 参数匹配实际移速。
- 移速变化过大时不要无限加速跑步动画，可切换冲刺动画或使用拖尾表现。

### 16.5 攻击动画三段

| 阶段 | 动画含义 | 允许中断 |
| --- | --- | --- |
| Windup | 抬手、蓄力、锁定 | 可被高等级控制打断 |
| Active | 武器命中或弹体生成 | 默认不被普通移动取消 |
| Recovery | 收势、后坐力恢复 | 可被移动或下一次攻击部分取消 |

例：剑客普通飞剑

| 时间 | 逻辑/动画 |
| ---: | --- |
| 0.00 | 抬手、朝目标转向 |
| 0.10 | 飞剑发光、蓄力音 |
| 0.18 | 生成投射物，手臂挥出 |
| 0.18～0.42 | 收势，可继续移动 |
| 0.32 起 | 允许下一技能请求进入缓存 |

### 16.6 攻速适配

- 动画时长按攻速缩短，但 Windup 保留最低可读时间。
- 攻速 ≤ 1.8 倍：直接加速动画。
- 攻速 1.8～3.0 倍：动画维持上限速度，逻辑使用额外弹体或一次动作多次发射。
- 更高频攻击：合并枪口火焰、命中音和跳字，避免视觉噪声与性能浪费。

### 16.7 敌人动画档位

- 普通小怪：Idle、Move、Attack、Hit/程序化受击、Death。
- 特殊怪：增加技能前摇、技能动作、硬直。
- 精英：增加出生、破防、狂暴。
- Boss：完整阶段动作、转阶段、破防、专属死亡。

远处或屏幕边缘敌人可以降低 Animator 更新频率，但攻击 Active 帧必须与逻辑同步。

### 16.8 受击动画规则

- 高频小伤不强制播放完整受击，使用 Additive 摇摆、材质闪白和轻微缩放。
- 重击、暴击、破盾、击退才播放完整重受击。
- 同一单位受击动画有 0.15～0.25 秒表现冷却。
- Boss 常规受击不打断动作，仅使用材质、局部粒子和轻微姿态反馈。
- 击杀一击可以加强死亡初速度、后仰或碎裂方向。

## 17. 特效系统规范

### 17.1 特效分层

从下到上：

1. 地形底层与非危险装饰。
2. 敌方预警底图。
3. 持续区域与地面技能。
4. 角色、敌人和召唤物。
5. 投射物、武器拖尾。
6. 命中特效、爆炸、护盾破碎。
7. 关键状态标记、Boss 指示。
8. 世界空间 HUD 与屏幕 UI。

危险预警边界必须始终可见，不能被友方火焰、经验晶体或地表装饰覆盖。

### 17.2 阵营与颜色

| 用途 | 主色建议 |
| --- | --- |
| 玩家普通攻击 | 英雄专属主色 |
| 玩家暴击/强化 | 金色高亮 |
| 敌方普通危险 | 红/橙 |
| 敌方强控制/诅咒 | 紫红 |
| 治疗 | 绿色/青绿 |
| 护盾 | 青蓝 |
| 冰冻 | 冰蓝 |
| 雷电 | 蓝紫 |
| 可拾取资源 | 资源固定色，外围白边 |

颜色不能是唯一信息。危险区同时使用边界形状、填充动画和方向指示，兼容色弱玩家。

### 17.3 技能表现组成

一个完整技能至少考虑：

- 起手：角色动作、武器亮起、蓄力粒子。
- 发射：枪口、剑气、法阵或冲击。
- 飞行/持续：轨迹、拖尾、范围边界。
- 命中：接触火花、方向、元素反馈。
- 目标反馈：闪白、染色、受击、状态标记。
- 结束：爆炸、消散、碎片或能量回收。

普通技能不一定全部做满六项，但英雄核心技能、进化技能和 Boss 技能必须完整。

### 17.4 地面预警三阶段

1. **准备阶段**：低透明填充出现，显示形状和范围。
2. **倒计时阶段**：边缘向内收缩、纹理流动或颜色加深。
3. **生效阶段**：填充快速闪亮，伤害与爆发同步发生。

预警结束与逻辑伤害误差目标小于 1 帧；30 FPS 下也不得超过 33 ms。

### 17.5 命中特效分级

| 等级 | 使用场景 | 表现 |
| --- | --- | --- |
| L1 | 高频普通命中 | 小火花、短闪白，无镜头震动 |
| L2 | 暴击/重击 | 更大火花、拖尾断裂、轻震 |
| L3 | 精英破盾/技能进化 | 爆发、音频重音、局部慢顿 |
| L4 | Boss 破防/死亡 | 镜头、慢动作、全套演出 |

### 17.6 材质反馈

- 普通受击闪白 0.04～0.08 秒。
- 火焰附着使用局部橙色脉冲，不整只怪长期纯红。
- 冰冻使用冰层、冰晶和低饱和，不仅改颜色。
- 中毒使用绿色气泡/滴落标记，避免与治疗混淆。
- 无敌使用柔和轮廓或护罩，不能与可受击护盾完全相同。

### 17.7 低端降级

优先保留：预警、玩家核心技能、Boss 技能、命中反馈、拾取物。  
优先降低：地面装饰粒子、普通敌人死亡碎片、远处拖尾、重复烟雾、次要光源。

## 18. 打击感与镜头表现

### 18.1 打击感组成

```text
打击感 = 判定准确
       + 动作节奏
       + 命中特效
       + 受击反应
       + 音效重音
       + 轻微停顿/震动
       + 清晰伤害反馈
```

不能只依赖屏幕震动。普通攻击每次都大幅震屏会快速疲劳，并遮挡走位。

### 18.2 Hit Stop

- 玩家普通重击：0.02～0.04 秒。
- 暴击/精英破盾：0.04～0.07 秒。
- Boss 破防：0.08～0.12 秒。
- Boss 死亡关键帧：0.12～0.20 秒。
- 高频远程攻击不逐发停顿，可按 0.2 秒窗口合并。
- Hit Stop 优先影响施法者、受击者和局部特效，不强制冻结全部战场。

### 18.3 镜头基础

- 俯视角建议 45°～55°，根据场景遮挡调整。
- 玩家位于屏幕中心略偏下，使上方保留更多前进视野。
- 相机跟随平滑时间 0.08～0.15 秒。
- 根据移动方向提供 0.4～0.8 米 Look Ahead。
- 快速位移时相机不立即完全追随，使用阻尼防止眩晕。
- 场景边界处调整相机而不是强行把玩家锁在正中心。

### 18.4 镜头震动

| 事件 | 强度 | 时长 |
| --- | ---: | ---: |
| 普通暴击 | 0.08 | 0.08 秒 |
| 玩家重技能 | 0.15～0.25 | 0.12～0.20 秒 |
| 精英破盾 | 0.18 | 0.15 秒 |
| Boss 落地 | 0.25～0.35 | 0.25 秒 |
| Boss 死亡 | 0.35～0.5 | 分段 0.4～0.8 秒 |

- 同时发生的震动按能量预算合并，不直接相加。
- 连续震动有 0.1～0.2 秒衰减。
- 玩家可将镜头震动调为 100%、50%或关闭。

### 18.5 镜头特殊演出

- 升级：背景轻微虚化/压暗，不移动主镜头位置。
- 精英入场：只显示屏幕边缘箭头和短提示，避免反复抢镜。
- Boss 入场：镜头拉远 5%～10%，短暂聚焦 Boss 后立即归还控制。
- 终极技能：最多 0.15 秒轻推近或 FOV 变化，不使用频繁长时间特写。
- 胜利：镜头拉近英雄，Boss 掉落保持在画面中。

## 19. 伤害跳字完整规范

### 19.1 跳字目标

跳字用于回答四个问题：

1. 是否命中？
2. 伤害是否高于平常？
3. 是什么伤害或状态？
4. 玩家获得了什么恢复或资源？

跳字不是展示所有后台计算。高频技能全部逐次显示会遮挡战场并造成性能问题。

### 19.2 跳字类型

| 类型 | 颜色 | 字号/权重 | 示例 |
| --- | --- | --- | --- |
| 普通物理伤害 | 白/浅黄 | 小 | 128 |
| 元素伤害 | 对应元素色 | 小 | 96 |
| 暴击 | 金黄，轻描边 | 中大 | 368! |
| 弱点伤害 | 金白 + 准星符号 | 大 | 弱点 520 |
| 持续伤害 | 较暗元素色 | 小 | 24 |
| 玩家承伤 | 红色 | 中 | -156 |
| 护盾吸收 | 青蓝 | 中 | 护盾 -80 |
| 治疗 | 绿色 | 中 | +120 |
| 闪避/格挡 | 灰白/蓝白 | 文字 | 闪避、格挡 |
| 免疫 | 紫灰 | 文字 | 免疫 |
| 状态 | 状态色 + 图标 | 小文字 | 燃烧、冻结 |
| 经验/资源 | 资源色 | 靠近资源栏 | 木材 +3 |

### 19.3 跳字位置

- 敌人受伤：从命中点或头顶偏移出现。
- 玩家受伤：从角色头顶偏左出现，避免与治疗重叠。
- 治疗/护盾：从角色头顶偏右上浮。
- Boss 高频伤害可在 Boss 身体多个预设锚点轮换，避免所有数字叠在中心。
- 世界位置转屏幕位置后要限制在安全区内，不能跑到刘海或底部操作区。

### 19.4 动画轨迹

#### 普通伤害

- 0.00 秒：缩放 0.75 → 1.0。
- 0.00～0.18 秒：向上移动 18～30 px。
- 0.18～0.55 秒：继续轻微上浮并渐隐。

#### 暴击

- 0.00 秒：缩放 0.6 → 1.25，轻微水平抖动。
- 0.08 秒：回弹到 1.0。
- 0.10～0.65 秒：上浮并渐隐。

#### 治疗

- 柔和弹出，稳定向上，不抖动。
- 可伴随小型十字或叶片图标。

#### 闪避/免疫

- 横向偏移后快速淡出，持续 0.4～0.6 秒。

### 19.5 数字聚合

- 同一目标、同一技能、同一伤害类型在 0.15～0.30 秒内的伤害合并。
- 合并数字更新总值并轻微再次弹跳，不重复创建新对象。
- 持续伤害默认每 0.5 秒最多显示一次聚合数字。
- 同一帧多个穿透命中不同目标仍分别显示，但屏幕达到上限时只保留高伤和关键目标。
- 伤害统计后台记录完整原始值，不受跳字聚合影响。

### 19.6 跳字优先级

```text
玩家濒死承伤 > Boss弱点/破防 > 玩家治疗与护盾
> 暴击 > 普通伤害 > 持续伤害 > 普通资源
```

- 同屏普通数字建议上限 20～28。
- 关键数字额外保留 6～8 个槽位。
- 超过上限时不排队补播，直接舍弃低优先表现。
- 屏幕外单位不生成跳字。

### 19.7 字体与可读性

- 使用粗体数字字体，外描边 2～4 px，根据分辨率缩放。
- 元素颜色同时配合小图标或描边变化。
- 不使用过细、过长阴影。
- 数值缩写：9999以内完整显示；1万以上使用 1.2万/12.5万；设置中可切换完整数字。
- 语言本地化时，“暴击、免疫、闪避”等使用独立文本表。

### 19.8 跳字设置档位

- 详细：显示普通、暴击、元素、状态、治疗。
- 精简：只显示暴击、玩家承伤、治疗、Boss 伤害。
- 关闭：保留玩家承伤、关键状态与 Boss 阶段提示。

## 20. HUD 与战斗 UI

### 20.1 竖屏区域划分

```text
顶部安全区：关卡、计时、Boss条、暂停
中上区域：战斗主视野与前进方向
中央区域：英雄、敌人、预警、拾取物
下部区域：移动触控区
右下角：终极技能与道具
```

### 20.2 顶部 HUD

- 左上：英雄头像、生命条、护盾条、永久战斗等级。
- 头像旁：最多显示 4 个关键 Buff，其余折叠。
- 顶中：关卡时间、波次或目标进度。
- 右上：暂停、网络/性能异常提示。
- Boss 出现后：Boss 血条占据顶部中部，显示名称、阶段、韧性条和状态图标。

### 20.3 经验条

- 放在顶部英雄信息下方或屏幕顶部横向铺开。
- 拾取经验时有流光朝经验条汇聚。
- 接近升级时颜色和音高逐步增强。
- 升满后先锁定数值并触发升级，不让条在后台继续反复跳动。
- 多级排队时显示“+2级待选择”。

### 20.4 世界空间 HUD

- 普通小怪默认不显示常驻血条。
- 受到伤害后显示 1.5 秒，脱战后淡出。
- 精英常驻小型血条、名称或精英图标。
- Boss 使用屏幕顶部血条，不在头顶再重复显示完整血条。
- 状态图标不超过 3 个，重要控制优先；普通 DOT 以特效表达。

### 20.5 危险指示

- 屏幕外精英/Boss 使用边缘箭头。
- 即将从屏幕外冲锋的敌人显示方向和倒计时。
- 箭头颜色与危险等级对应，同时显示形状变化。
- 多个同方向威胁合并为一个箭头并显示数量。

### 20.6 终极技能按钮

状态：未充能、充能中、可释放、释放中、禁用。

- 充能中：环形填充。
- 可释放：图标亮起、一次弹性缩放、低频光圈。
- 释放中：按住态或短暂锁定，防止重复点击。
- 禁用：灰化并显示原因图标，如沉默、剧情限制。

### 20.7 升级三选一界面

- 背景战场压暗 55%～70%，保留角色和危险轮廓。
- 三张卡纵向屏幕可采用“一张主卡 + 左右/上下滑动”，但首选三张同时可见。
- 卡面包含图标、名称、品质、当前等级、升级后数值和组合标签。
- 新技能、进化、互斥路线使用明显角标。
- 刷新按钮显示免费次数或消耗。
- 点击卡牌先展开详情；再次点击确认，或使用独立选择按钮。

## 21. 音效、音乐与震动

### 21.1 音频分组

- BGM。
- 玩家攻击与技能。
- 敌人攻击与技能。
- 命中与死亡。
- UI、升级和奖励。
- 环境。
- 语音。

各组独立音量，设置页至少提供总音量、音乐、战斗、UI 四项。

### 21.2 音效优先级

```text
Boss预警/玩家受重伤/升级
> 玩家终极技能/精英技能
> 玩家核心攻击
> 普通敌人攻击
> 高频命中/普通死亡/拾取
```

### 21.3 高频音效限制

- 同类普通命中每 0.05～0.10 秒最多播放一次聚合音。
- 多个敌人同时死亡时按数量提高音量和层次，不播放几十个相同音源。
- 拾取经验使用音阶，短时间连续拾取提高音高，停止后重置。
- 同屏 AudioSource 数量设置上限，超出时丢弃低优先音效。

### 21.4 关键声音

- 升级经验满：上扬提示音。
- 永久卡确认：厚重落印声，区别于普通临时奖励。
- Boss 入场：低频冲击 + 专属主题层。
- 高伤预警：独立频段，不能被玩家技能淹没。
- 低血：低频心跳，限制频率。
- 胜利：Boss 音乐停止后进入短胜利段，不与爆炸混为一团。

### 21.5 震动

- 轻震：按钮、普通暴击、拾取高级物品。
- 中震：玩家重技能、受重伤、精英破盾。
- 强震：Boss 落地、阶段转换、死亡。
- 高频攻击不得逐发震动。
- 支持关闭，并遵循设备平台能力。

## 22. 首发英雄战斗表现样例

### 22.1 剑客·凌锋

#### 普通飞剑

- 操作：自动选择高威胁目标。
- 动画：上半身抬手指向目标，下半身保持移动。
- 特效：背后飞剑亮起，短距离加速射出，带青白拖尾。
- 命中：小型剑痕、目标闪白、轻金属声。
- 卡牌变化：数量增加时飞剑从扇形依次发射；穿透后拖尾加亮；回旋剑使用返回弧线。

#### 万剑流

- 飞剑数量多但单剑特效缩小，避免铺满屏幕。
- 多把飞剑分批发射，不在同一帧全部生成。
- 同一目标的高频伤害跳字按 0.2 秒聚合。
- 进化“剑阵领域”在英雄周围形成清晰圆环，轨道在地面危险预警之上但透明度较低。

#### 七剑归一

- 旧飞剑向英雄头顶汇聚，形成一把大型巨剑。
- 普通攻击频率下降，起手更重，命中带 L2/L3 反馈。
- 暴击时出现竖向剑痕和轻微镜头震动。

#### 终极技能·万剑阵

1. 点击后 0.1 秒进入霸体，移速降为 40%。
2. 0.35 秒内多把飞剑在背后展开。
3. 屏幕中敌人出现短暂剑印，但不遮挡危险区。
4. 2.5 秒内分批攻击高威胁目标。
5. 最后一轮巨剑落下，造成范围伤害和较强反馈。
6. 释放期间可以缓慢移动，避免因自动演出吃到 Boss 必杀。

### 22.2 火枪游侠·洛娜

#### 普通射击

- 动画：抬枪、枪口后坐、肩部轻微回弹。
- 弹体：速度快，使用 Sweep 判定；轨迹短而亮。
- 枪口火焰按攻速聚合，高攻速时不逐帧闪烁。
- 音效使用 3～5 个轻微随机变体。

#### 装填

- 弹仓为空时进入装填，按钮/角色旁显示短进度环。
- 装填不停止移动，移速默认降至 85%。
- 最后一发卡牌在弹药条上使用金色标记。
- 装填完成播放明确机械声，下一发输入不延迟。

#### 散射燃烧流

- 多枚弹体按扇形发射。
- 燃烧命中使用小型橙色附着，不让每个敌人持续大火。
- 连锁爆炸按由近到远的 0.05～0.1 秒延迟传播，形成可读的连爆。

#### 狙击暴击流

- 瞄准时出现短准线，但不要求玩家手动瞄准。
- 子弹命中有更长拖尾、弱点符号、较大暴击数字。
- Boss 弱点命中使用独立清脆音，不与普通暴击完全相同。

## 23. 城市援助在战斗中的表现

### 23.1 箭塔齐射

- 触发前屏幕下方出现城市方向提示。
- 多支箭从下方向上方扇形射入。
- 优先攻击敌人密集区域，不追踪单个小怪。
- 箭塔等级影响数量、伤害和穿透，不无限放大特效。

### 23.2 铁匠铺炸弹

- 目标区出现铁砧形小标记和落点圈。
- 炸弹从屏幕下方抛入，落地造成范围击退。
- 高等级附加燃烧或破甲。

### 23.3 医馆补给

- 信鸽、医疗包或治疗法阵从城市方向进入。
- 补给落点尽量在玩家前方安全区域，而不是敌群中心。
- 玩家靠近后触发治疗；低血时吸附范围扩大。

### 23.4 城墙防守模式

- 城墙拥有独立公共生命条。
- 敌人进入城门攻击区后可切换目标攻击城墙。
- 玩家攻击、箭塔火力和城墙受击信息必须区分。
- 城墙受击不使用大量屏幕红晕，使用建筑震动、碎石和顶部耐久条。

## 24. Unity 技术架构建议

### 24.1 模块划分

- BattleFlowController：战前、战中、暂停、胜负和结算。
- UnitController：单位生命周期和状态。
- CharacterMotor：移动、碰撞、技能位移和安全点。
- TargetingSystem：空间查询、目标过滤和威胁评分。
- SkillSystem：技能实例、时间轴、冷却和技能模板。
- DamageSystem：命中上下文、伤害、护盾、死亡归属。
- BuffSystem：状态、叠层、Tick、驱散和触发器。
- WaveDirector：预算、生成、精英、事件和 Boss。
- DropSystem：掉落、合并、吸附和结算缓存。
- CombatPresentation：动画、特效、音效、镜头和跳字事件。
- CombatHUD：生命、经验、Boss、按钮、提示和三选一。
- CombatSaveTransaction：永久经验和永久卡牌事务。

### 24.2 逻辑与表现事件

逻辑层发送只读事件：

- SkillStarted、SkillActive、ProjectileSpawned。
- HitConfirmed、DamageApplied、ShieldBroken。
- BuffAdded、BuffStackChanged、BuffRemoved。
- UnitStaggered、UnitDied、BossPhaseChanged。
- ExpPicked、LevelUpRequested、CardApplied。
- BattleWon、BattleLost。

表现层订阅事件并播放动画、特效、音效和跳字，不反向修改伤害结果。

### 24.3 对象池

必须池化：

- 普通敌人和常用精英。
- 投射物、持续范围、召唤物。
- 命中、死亡、预警和常用特效。
- 经验、金币、材料。
- 血条、状态图标、伤害跳字。
- 高频 AudioSource。

池对象回收时必须重置：事件订阅、Buff、目标、速度、材质参数、Trail、粒子、Animator、异步任务和计时器。

### 24.4 时间系统

- 战斗逻辑使用统一 BattleTime。
- UI 动画使用 UnscaledTime。
- 暂停将 BattleTimeScale 设为 0，而不是散落地停用各对象。
- Hit Stop 可使用局部时间倍率或分组时间倍率。
- 永久卡选择、复活和教学不得让 Buff/冷却偷偷流逝。

### 24.5 空间查询

- 使用网格、四叉树或 Spatial Hash 管理单位。
- 近战、范围、索敌、分离均通过统一空间服务查询。
- 查询返回候选后再按阵营、状态、标签过滤。
- 不在每个技能中使用 FindObjectsOfType 或全列表遍历。

### 24.6 确定性与随机

- 关卡波次、卡牌候选、掉落使用可记录随机种子。
- 关键永久升级候选在显示前保存。
- 战斗不必做到完整锁步确定性，但同一事务恢复必须返回相同卡牌结果。
- 随机暴击和掉落与纯表现随机分离，防止特效随机消耗逻辑随机序列。

## 26. 性能预算与优化

### 26.1 参考预算

| 项目 | 中高端 | 低端档 |
| --- | ---: | ---: |
| 同屏普通敌人 | 100～120 | 50～80 |
| 同屏精英 | 3～5 | 2～3 |
| 活跃投射物 | 200～250 | 100～160 |
| 活跃经验/掉落 | 100，超出合并 | 60，超出合并 |
| 普通跳字 | 24 | 12～16 |
| 同时音源 | 24～32 | 12～18 |
| 主要粒子实例 | 60～90 | 30～50 |

实际预算以目标平台真机测试为准。

### 26.2 CPU 优化

- AI 决策分帧，远处敌人降低决策频率。
- 空间查询替代全场遍历。
- 持续伤害固定 Tick，不按帧结算。
- 合并经验、跳字、音效和高频命中事件。
- Animator 对远处普通怪使用 Culling 或降频。
- 不在 Update 中产生 GC，列表和上下文对象复用。

### 26.3 GPU 优化

- 材质合批、图集、GPU Instancing。
- 限制透明粒子重叠和全屏 Overdraw。
- 普通敌人不使用大量实时光源。
- 影子按距离和质量档位关闭或简化。
- 低端档减少拖尾段数、粒子数量、扭曲和后处理。

### 26.4 动态降级顺序

1. 减少装饰粒子。
2. 降低普通敌人动画更新频率。
3. 合并更多跳字与经验。
4. 降低远处特效与拖尾。
5. 限制新生普通敌人数量。

绝不能先关闭危险预警、Boss 技能提示或玩家核心技能表现。

## 28. 战斗验收标准

### 28.1 操作

- [ ] 竖屏单手移动无明显死区、漂移或输入丢失。
- [ ] 普通攻击不会频繁抢夺移动控制。
- [ ] 终极技能点击后 0.1 秒内得到视觉反馈。
- [ ] 手指位于屏幕边缘时仍能稳定移动。
- [ ] 左右手布局和安全区适配正确。

### 28.2 逻辑

- [ ] 技能 Active 时刻与判定一致，不依赖单一动画事件。
- [ ] 伤害计算顺序稳定，日志可追踪。
- [ ] 玩家受击无敌和接触伤害间隔正确。
- [ ] 暂停时 AI、冷却、Buff、投射物和关卡时间全部冻结。
- [ ] 永久升级失败、退出或断线不会丢失或重刷候选。
- [ ] 击杀、吸血、掉落和任务读取同一死亡归属。

### 28.3 动画与打击感

- [ ] 每次攻击的起手、判定、命中和收势能够对应。
- [ ] 高频轻伤不会让敌人持续僵直抽搐。
- [ ] 重击、暴击、破盾和死亡具有不同反馈等级。
- [ ] 攻速提高后动画、弹体和判定不穿帮。
- [ ] 冲锋与位移结束不会进入墙体或非法区域。

### 28.4 特效与预警

- [ ] 所有高伤攻击都有足够预警。
- [ ] 预警结束与伤害生效误差不超过目标帧预算。
- [ ] 玩家特效不会遮住敌方危险区。
- [ ] 低端画质仍保留预警、玩家核心技能和 Boss 表现。
- [ ] 元素、治疗、护盾和敌方危险可以快速区分。

### 28.5 跳字与 HUD

- [ ] 高频攻击不会生成无法阅读的数字墙。
- [ ] 暴击、玩家承伤、治疗和护盾有明确差异。
- [ ] 跳字不会遮挡顶部 Boss 条和底部操作区。
- [ ] 普通小怪血条按规则出现和回收。
- [ ] 屏幕外高威胁攻击有方向提示。

### 28.6 敌人和 Boss

- [ ] 每类敌人的行为职责可以仅凭动作和轮廓辨认。
- [ ] 冲锋、自爆、远程攻击都有可反应窗口。
- [ ] 敌群不会把玩家永久卡死。
- [ ] Boss 不连续使用两个无安全区高压技能。
- [ ] Boss 阶段转换、破防和死亡均有完整演出。

### 28.7 性能

- [ ] 目标设备同屏 80 个敌人时保持目标帧率。
- [ ] 高密度掉落会合并，不出现长期堆积。
- [ ] 对象池回收无残留 Trail、Buff、事件或目标。
- [ ] 战斗 10 分钟以上内存不持续增长。
- [ ] 低端动态降级不影响伤害判定与危险预警。

## 30. 最终制作结论

这套战斗的核心不是单纯增加同屏敌人，而是让玩家在低操作门槛下持续获得三层反馈：

1. **即时反馈**：移动顺滑、自动攻击准确、受击原因清楚、清怪有打击感。
2. **单场反馈**：敌群逐步增压、技能发生形态变化、Boss 有完整阶段和破绽。
3. **长期反馈**：本场获得的经验和卡牌永久成为英雄的一部分，并推动下一次战斗与城市建设。

制作时应优先保证判定清楚、预警可靠、操作不被动画夺走，再逐步增加粒子、震屏和复杂演出。动画、特效、音效和跳字全部围绕逻辑事件组织，使战斗在数值、卡牌和装备持续扩展后仍然可维护、可调试、可降级。
