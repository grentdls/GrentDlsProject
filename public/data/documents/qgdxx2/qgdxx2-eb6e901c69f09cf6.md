# 竖版城市幸存者 UI 资源职责审计

审计日期：2026-08-10

## 资源职责规则

- 加载图和页面场景图只表现世界、角色或环境，不烘焙按钮、文字、页签、弹窗和其他页面框体。
- 按钮与页签底图只保留底板和边缘装饰，图标与中文文字全部由运行时独立叠加。
- 卡片与面板只提供可缩放容器，不烘焙头像、物品、技能、进度条、购买底座、标题图标或水印。
- 头像框与物品框必须保持中心透明，角色和装备图由数据驱动层单独渲染。
- 可变尺寸容器必须设置九宫格边界；固定比例插画使用 `preserveAspect`，不能用拉伸代替裁切策略。
- 仅首次进入游戏和真正进入战斗关卡时使用加载图，普通挑战入口不铺加载背景。

## 战斗顶部 HUD 排版契约

- 第一行：左侧英雄与生命/护盾/经验信息，右侧威胁与击杀统计，最右侧暂停按钮；三者横向互不覆盖。

## 三选一永久强化排版契约

- 头部只放“永久强化”、英雄名副标题与悟性等级；关卡/战斗状态不再挤入标题行。
- 卡牌按“左 28% 图标 / 中 52% 中文信息 / 右 20% 等级与选择提示”分栏，所有可变文字由运行时独立渲染。
- `RankBadge` 明确显示 `强化预览` 与 `N级 → N+1级`；路线核心单独使用 `RouteHint` 显示“再次点击确认”，普通卡显示“点击选择”。
- 稀有度颜色使用高对比文字色配深色卡底，描述字号保持在 19 以上，底部说明使用独立留白行，避免自动缩小到不可读。
