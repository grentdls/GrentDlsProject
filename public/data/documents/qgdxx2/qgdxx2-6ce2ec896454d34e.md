# 竖版城市幸存者——英雄装备、随机词条、强化进阶与套装完整方案

> 所属项目：《英雄城：永夜守望》（暂定名）  
> 文档版本：V1.0  
> 对应总案：《竖版城市建造 × 永久成长幸存者小游戏完整制作方案》  
> 对应建筑文档：《竖版城市幸存者——建筑玩法、预制体、HUD 与 UI 完整方案》  
> 对应 UI 文档：《竖版城市幸存者——全界面 UI 视觉、图文布局与 UX 动效完整规范》  
> 系统目标：建立六槽位差异明确、随机词条可构筑、成长可继承、套装可组合、长期可扩展的英雄装备体系

## 1. 装备系统定位

### 1.1 装备在总成长中的职责

装备负责英雄约 20%～30%的总战斗能力，并承担以下体验：

- 战斗后稳定获得可检查、可比较的战利品。
- 通过随机词条形成英雄构筑差异。
- 用套装效果把装备与永久卡牌路线连接起来。
- 通过铁匠铺制造、强化、重铸和升品，反向强化城市价值。
- 让新英雄可以继承账号已有资源，减少重复培养。

### 1.2 设计原则

- 六个槽位的主属性和词条职责必须不同。
- 装备强化不能阻止玩家更换更好的装备。
- 随机词条要提供构筑选择，不只是堆攻击和生命。
- 套装效果优先强化技能标签，不绑定唯一英雄。
- 高品质装备可以定向获得，不能完全依赖极低概率随机掉落。
- 装备成长没有失败、降级或永久损毁。
- 一件装备的强弱必须可以解释，战力数字只作辅助。

### 1.3 装备核心循环

```text
战斗/制造获得装备
→ 查看主属性、随机词条、套装
→ 与当前装备对比
→ 装备或分解
→ 升级装备等级
→ 强化对应槽位
→ 使用重复装备/精华进阶
→ 重铸不合适词条
→ 集齐2件/4件套装
→ 形成与英雄卡牌联动的构筑
```

## 2. 装备对象的完整结构

每件装备由以下层级组成：

| 层级 | 内容 | 是否随机 |
| --- | --- | --- |
| 装备模板 | 名称、槽位、外观、基础属性、允许英雄 | 否 |
| 装备等级 | Lv.1～Lv.80，提升基础属性 | 玩家培养 |
| 稀有度 | 普通、优秀、稀有、史诗、传说 | 掉落/升品 |
| 进阶星级 | 当前稀有度内 0～4 星 | 玩家培养 |
| 随机词条 | 数量、类型、档位、具体数值 | 是 |
| 固有特效 | 史诗/传说模板特效 | 模板固定 |
| 套装归属 | 套装 ID、2件/4件效果 | 模板固定或定向制造 |
| 强化槽位 | 对应部位的账号强化等级 | 独立于物品 |

### 2.1 装备名称组成

```text
[品质/特色前缀] + [模板名称] + [构筑后缀，可选]
```

示例：

- 锋利的猎风长弓。
- 灼热的赤焰护手。
- 守望者胸甲·壁垒。

UI 主名称不建议被过长随机前后缀占满。列表只显示模板名，详情页显示完整名称和词条来源。

### 2.2 装备标签

- 槽位标签：Weapon、Helmet、Armor、Gloves、Boots、Accessory。
- 战斗标签：Projectile、Melee、Fire、Lightning、Shield、Summon 等。
- 职业标签：Sword、Ranged、Magic、Guardian 等。
- 套装标签：HunterSet、EmberSet 等。
- 来源标签：Crafted、BossDrop、Trial、Shop 等。

卡牌、装备和技能统一读取战斗标签，避免为每个英雄硬编码专属词条。

## 3. 六个装备槽位的差异

### 3.1 槽位定位总表

| 槽位 | 固定主属性 | 核心职责 | 专属词条方向 | 战力占比建议 |
| --- | --- | --- | --- | ---: |
| 武器 | 攻击 | 输出核心、技能形态 | 技能伤害、元素、穿透、斩杀 | 28% |
| 头盔 | 生命 | 预警、经验、控制防护 | 经验、拾取、抗控、低血保护 | 14% |
| 护甲 | 防御 + 生命 | 直接生存、护盾和恢复 | 减伤、护盾、治疗、受击触发 | 18% |
| 手套 | 攻击 + 攻速 | 命中频率、暴击、触发 | 暴击、攻速、命中、击杀 | 16% |
| 鞋子 | 移速 + 少量生命 | 走位、闪避、场地适应 | 移速、闪避、冲锋、地面抗性 | 10% |
| 饰品 | 技能威力/能量 | 构筑联动、冷却、终极技能 | 元素、冷却、终极、召唤、资源 | 14% |

### 3.2 固定槽位特性

每个槽位除主属性外，再提供一个不可随机删除的槽位特性：

| 槽位 | 固定特性示例 |
| --- | --- |
| 武器 | 普通攻击与英雄主技能伤害提高 |
| 头盔 | 受到控制的持续时间降低 |
| 护甲 | 提高来自装备的生命/护盾效率 |
| 手套 | 攻击速度或触发概率小幅提高 |
| 鞋子 | 基础移动速度提高 |
| 饰品 | 终极技能充能或自动技能威力提高 |

固定特性随装备等级和稀有度成长，用于保证槽位差异，即使随机词条较差也有明确用途。

### 3.3 武器兼容

武器具有职业适配标签：

- 剑士类：Sword、Blade。
- 远程类：Bow、Gun。
- 法术类：Staff、Focus。
- 防御类：Shield、Hammer。

英雄可以装备主标签匹配的武器；少数英雄拥有两个兼容标签。其余五个槽位通用。

为了避免大量无用武器：

- 掉落时提高当前英雄和已解锁英雄可用武器的权重。
- 铁匠铺可以定向选择武器类别。
- 不兼容武器仍可分解、制造其他类别或用于升品。

## 4. 四条装备成长线

### 4.1 成长线职责

| 成长线 | 作用对象 | 主要提升 | 是否继承 |
| --- | --- | --- | --- |
| 装备升级 | 单件装备 | 基础主属性 | 可免费转移/重置 |
| 部位强化 | 六个装备槽 | 槽位固定倍率和里程碑 | 永久保留、自动生效 |
| 装备进阶 | 单件装备当前品质 | 星级、词条数值、特效节点 | 跟随该装备 |
| 稀有度/升品 | 单件装备 | 基础倍率、词条数量、固有特效 | 保留等级和词条 |

### 4.2 为什么必须拆开

- 装备升级提供频繁、可预期的小成长。
- 部位强化保证换装没有沉没成本。
- 进阶让重复装备和装备精华长期有用。
- 稀有度决定物品价值和掉落兴奋度。

四条成长线在 UI 中使用不同图标和入口，不能都叫“升级”。

## 5. 装备稀有度

### 5.1 稀有度总表

| 稀有度 | 颜色 | 基础倍率 | 随机词条数 | 固有特效 | 套装能力 |
| --- | --- | ---: | ---: | --- | --- |
| 普通 | 灰蓝 | 1.00 | 0 | 无 | 无 |
| 优秀 | 绿色 | 1.15 | 1 | 无 | 可计入2件套，但数值偏低 |
| 稀有 | 蓝色 | 1.35 | 2 | 小型固有效果概率 | 正常激活2件套 |
| 史诗 | 紫色 | 1.60 | 3 | 1条史诗特效 | 激活2件/4件套 |
| 传说 | 金橙 | 1.90 | 4 | 强化固有特效 | 强化4件套或传说共鸣 |

### 5.2 稀有度的价值

高稀有度同时提供：

- 更高基础属性倍率。
- 更多随机词条槽。
- 更高可出现词条档位。
- 固有特效。
- 更强的进阶上限。
- 套装完整能力。

不能只用颜色和基础数值区分品质。

### 5.3 稀有度掉落节奏

- 第 1 章：普通/优秀为主，教学稀有。
- 第 2～3 章：稀有成为主力，首次史诗保底。
- 中期：稳定制造稀有，精英/Boss 产史诗。
- 后期：史诗为主力，传说通过图纸、升品和长期保底获得。

### 5.4 传说品质控制

- 传说不能完全靠极低概率世界掉落。
- 第一次传说应来自明确长期目标。
- 传说词条仍可能需要调整，但至少保证 1～2 条与模板方向相符。
- 不允许普通随机词条组合反而全面碾压所有传说特效。

## 6. 装备等级

### 6.1 基础规则

- 每件装备拥有 Lv.1～Lv.80。
- 上限受英雄等级、铁匠铺等级或章节阶段限制。
- 升级消耗金币和装备经验材料。
- 装备等级只提高基础主属性和固定槽位特性，不直接提高随机词条。
- 升级没有失败概率。

### 6.2 等级区间

| 阶段 | 等级 | 主要来源 |
| --- | --- | --- |
| 初期 | 1～20 | 普通矿石、金币 |
| 中期 | 21～40 | 精炼矿石、金币 |
| 高级 | 41～60 | 高级锻造材料 |
| 后期 | 61～80 | Boss材料、传说锻造材料 |

### 6.3 升级公式

```text
装备基础属性 = 模板基础值
             × 稀有度倍率
             × [1 + 0.06 × (装备等级 - 1)]
             × [1 + 0.08 × 当前进阶星级]
```

具体系数按槽位和总战力目标校准。高级阶段可以降低单级比例，避免指数过快。

### 6.4 经验与升级消耗

- 装备经验材料按普通、精良、稀有三档。
- 低品质装备也可作为经验材料，但建议分解优先，避免误吃有价值装备。
- 一键升级可选择目标等级、当前上限或资源可达等级。
- 升级前预览攻击/生命/防御变化和战力变化。

### 6.5 等级继承

玩家换装时提供：

- 免费将旧装备等级转移给新装备。
- 或者装备重置，返还 100%装备经验和大部分金币。
- 等级转移不改变随机词条、进阶星级和稀有度。
- 已锁定装备不会被自动作为继承材料。

推荐默认弹出“一键继承”，避免新装备因为暂时等级低而显示战力下降。

## 7. 部位强化

### 7.1 定位

部位强化属于账号的六个装备槽，而不是某件物品。只要对应槽位装备了物品，强化效果自动生效。

### 7.2 强化规则

- 武器、头盔、护甲、手套、鞋子、饰品分别强化。
- 强化等级建议 +0～+30，后续可扩展。
- 消耗金币和铁矿，不消耗具体装备。
- 强化 100%成功，不爆装、不掉级。
- 更换装备不影响强化等级。
- 所有英雄共享基础部位强化，或由英雄装备页读取同一账号强化值。

共享强化可以让新英雄快速追赶，也减少六槽位 × 多英雄的重复肝度。

### 7.3 强化效果

```text
最终槽位属性 = 装备提供属性 × (1 + 1.5% × 部位强化等级)
```

里程碑：

| 强化等级 | 额外效果 |
| ---: | --- |
| +5 | 对应槽位固定特性 +3% |
| +10 | 解锁强化纹章一阶 |
| +15 | 对应主属性额外 +5% |
| +20 | 强化纹章二阶 |
| +25 | 专属词条效果 +5% |
| +30 | 槽位外观边框和终极里程碑 |

### 7.4 强化平衡

- 武器/手套强化更偏输出。
- 头盔/护甲强化更偏生命、防御。
- 鞋子强化不能无限提高移速，超过安全上限后转换为闪避/减速抗性。
- 饰品强化提高技能威力或充能，不直接同时提高所有属性。

## 8. 装备进阶

### 8.1 进阶星级

每个稀有度拥有 0～4 星：

- 0 星：当前品质基础状态。
- 1 星：基础属性提高。
- 2 星：随机词条数值提高。
- 3 星：固有特效增强或解锁次级节点。
- 4 星：达到升品条件。

### 8.2 进阶材料

优先级：

1. 同名装备。
2. 同槽位同品质装备。
3. 通用装备精华。
4. 套装精华或 Boss 核心，用于高阶节点。

同名装备效率最高，但不强制玩家只能依赖同名掉落。

### 8.3 进阶收益

| 星级 | 基础属性 | 词条 | 特效 |
| ---: | ---: | --- | --- |
| 1星 | +8% | 无 | 无 |
| 2星 | 再+8% | 全词条数值 +5% | 无 |
| 3星 | 再+8% | 最高一条词条提高半档 | 固有特效增强 |
| 4星 | 再+8% | 全词条数值再+5% | 可升品 |

数值为初始建议，最终以装备总贡献占比校准。

### 8.4 进阶不会发生的事情

- 不会失败。
- 不会随机降星。
- 不会重置装备等级。
- 不会重置随机词条。
- 不会改变套装归属。

## 9. 装备升品

### 9.1 升品条件

- 当前品质达到 4 星。
- 铁匠铺达到对应等级。
- 消耗同槽位装备、装备精华、金币和指定图纸。
- 史诗升传说需要 Boss 核心或传说图纸。

### 9.2 升品结果

- 稀有度提高一级。
- 进阶星级回到新品质 0 星。
- 装备等级完整保留。
- 原有随机词条完整保留，并根据新品质解锁一个新词条槽。
- 新词条在符合槽位和模板方向的池中生成。
- 固有特效按新品质解锁/升级。
- 套装归属保留。

星级回到 0 代表进入更高品质的新阶段，不返还已消耗材料；所有星级收益已转化为新品质基础倍率。

### 9.3 新词条保护

- 升品新增词条至少与装备模板的主标签匹配。
- 史诗和传说升品允许玩家在 3 个候选词条方向中选 1 个，再随机具体值。
- 不出现当前装备已经拥有的同组重复词条。

### 9.4 升品表现

- 装备图标进入铁匠炉/魔法阵。
- 原品质边框碎裂并转化为新颜色。
- 新词条以独立效果卡展开。
- 新品质名称、基础倍率和特效同步展示。
- 重复升品演出可跳过。

## 10. 随机词条系统总规则

### 10.1 词条组成

每条词条包含：

- AffixId。
- 显示名称和图标。
- 槽位限制。
- 标签限制。
- 词条组与互斥组。
- 档位 Tier。
- 数值最小/最大范围。
- 权重。
- 是否可重铸。
- 是否为 Boss/套装专属。
- 触发条件和内部冷却。

### 10.2 词条档位

建议使用 T1～T6：

| 档位 | 主要来源 | 显示 |
| --- | --- | --- |
| T1 | 初期普通/优秀 | 灰点或不显示档位 |
| T2 | 稀有装备 | 1枚强化标记 |
| T3 | 中期稀有/史诗 | 2枚标记 |
| T4 | 高级史诗 | 3枚标记 |
| T5 | 传说/高阶Boss | 4枚标记 |
| T6 | 顶级定向制造/赛季终局 | 特殊纹章 |

UI 不一定直接写 T3，可用条目颜色、菱形数量和数值范围表达，并在详情中显示档位。

### 10.3 词条数值

- 先确定档位，再在该档范围内随机具体值。
- 同档最低与最高差建议不超过 20%～30%。
- 高档位最低值应高于低档位最高值，保证升级有感。
- 百分比词条和绝对值词条分别配置。

### 10.4 词条组

| 词条组 | 示例 | 同装备规则 |
| --- | --- | --- |
| CoreDamage | 攻击%、技能伤害% | 最多1～2条 |
| Crit | 暴击率、暴击伤害 | 可同时出现但受上限 |
| Speed | 攻速、移速、冷却 | 按槽位限制 |
| Element | 火、雷、冰、毒 | 可混合，但套装方向权重更高 |
| Sustain | 吸血、击杀恢复、治疗增强 | 最多2条 |
| Defense | 防御、减伤、护盾 | 防具为主 |
| Trigger | 命中、击杀、受击、低血 | 同触发类别数量受控 |
| Economy | 金币、材料、经验 | 不与高强战斗词条同池无限叠加 |

### 10.5 互斥规则

- 同名词条不可重复。
- “近战伤害”和“远程伤害”可共存但生成权重降低，不推荐制造同时出现。
- “低生命增伤”和“满生命增伤”允许共存，但套装评分不视为最佳组合。
- 同一装备最多 1 条斩杀类词条。
- 复活、无敌、免死类词条严格限制来源和数量。
- 经济词条不能在所有槽位大量出现，避免战斗与收益同时无成本最大化。

## 11. 随机生成流程

### 11.1 装备生成算法

```text
确定装备模板和槽位
→ 确定物品强度ItemPower
→ 确定稀有度
→ 计算基础属性
→ 确定随机词条数量
→ 根据槽位、模板标签、来源过滤词条池
→ 按权重抽取词条组
→ 检查重复和互斥
→ 按ItemPower确定可出现档位
→ 在档位范围内随机数值
→ 生成套装/固有特效
→ 保存随机种子与结果
```

### 11.2 模板方向保护

史诗以上装备至少满足：

- 1 条词条与装备模板主标签一致。
- 1 条词条与槽位核心职责一致。
- 其余词条可以随机，形成混合构筑。

例如“赤焰长弓”至少带 1 条火焰/燃烧相关方向和 1 条武器输出词条。

### 11.3 来源影响

- 普通主线：通用词条池。
- 元素 Boss：对应元素词条权重提高。
- 矿洞：基础属性和强化材料相关。
- 英雄试炼：当前英雄标签匹配率提高。
- 铁匠铺定向制造：玩家选择槽位、模板或套装方向。
- 世界 Boss：专属词条与高档位概率。

### 11.4 防极端垃圾组合

- 史诗/传说不会全部生成经济词条。
- 武器不会出现纯防御四词条。
- 护甲不会出现完全无法影响生存的四攻击词条。
- 同一件装备至少 50%词条属于槽位核心池或模板池。
- 允许“非完美”装备存在，但不生成明显无意义组合。

## 18. 触发型词条规则

### 18.1 统一触发器

- OnHit：命中。
- OnCritical：暴击。
- OnKill：击杀。
- OnTakeDamage：受击。
- OnShieldGain/Break：获得/破裂护盾。
- OnDodge：闪避。
- OnMoveDistance：移动距离。
- OnUltimateStart/End：终极技能开始/结束。
- OnBuffApplied：状态施加。

### 18.2 内部冷却

所有高频触发词条必须配置 Internal Cooldown：

- 命中爆炸：0.3～1.0 秒。
- 受击恢复：1～3 秒。
- 击杀回血：可无单次冷却，但设置每秒恢复上限。
- 闪避护盾：3～8 秒。
- 重置技能：10～30 秒。

### 18.3 触发归属

- 召唤物命中是否触发主人词条由标签配置。
- 持续伤害默认不触发高频 OnHit，除非词条明确允许。
- 环境击杀继承最近有效玩家来源。
- 套装触发与装备词条共用 CombatEvent，避免重复判断。

### 18.4 防无限循环

- 触发生成的伤害默认不能再次触发同类伤害词条。
- 击杀爆炸造成的击杀可触发资源掉落，但不再次触发无限爆炸；特殊套装可允许有限层数。
- 护盾破裂触发的新护盾不能立即再次触发破裂特效。
- 所有连锁效果有最大传播次数和同目标命中限制。

## 19. 固有特效与传说特效

### 19.1 固有特效规则

- 固有特效属于装备模板，不占随机词条槽。
- 史诗解锁基础版本，传说解锁强化版本。
- 固有特效改变玩法或循环，不单纯增加大额攻击。
- UI 使用独立特效卡和装备专属图标。

### 19.2 各槽位传说特效示例

| 槽位 | 特效 | 作用 |
| --- | --- | --- |
| 武器 | 裂空回响 | 首次穿透后生成一道较弱回响投射物 |
| 头盔 | 预知危机 | 高伤预警出现时获得短移速和一次减伤 |
| 护甲 | 不灭壁垒 | 护盾破裂时获得短暂伤害免疫，有长CD |
| 手套 | 完美连击 | 每第N次命中必定暴击并触发额外效果 |
| 鞋子 | 幻影步 | 闪避后留下残影吸引普通敌人 |
| 饰品 | 时之回环 | 使用终极后重置一个核心自动技能 |

### 19.3 特效强度

- 单件传说特效约等于 1～1.5 条高档随机词条的价值。
- 特效与套装产生协同，但不能组合成无限无敌或无限终极。
- 对 Boss 和普通怪需要分别配置系数时必须写在说明中。

## 20. 套装系统

### 20.1 套装结构

- 六个槽位均可属于套装。
- 主要激活 2 件套和 4 件套。
- 六槽位允许 `4+2`、`2+2+2` 或完整 6 件同套装。
- 首版不强制 6 件套，避免构筑被完全锁死。
- 传说品质可增加“套装共鸣”，但不新增必须的第 6 件效果。

### 20.2 套装激活

- 优秀装备可以计入 2 件套但只提供 80%效果，稀有以上提供完整效果。
- 4 件套至少需要所有计数装备达到稀有品质。
- 不同品质同名套装可以混合计数。
- 同一装备只能属于一个套装。

### 20.3 套装设计原则

- 2 件套提供稳定方向，适合混搭。
- 4 件套提供玩法核心或明显联动。
- 套装优先强化标签，不写死英雄名称。
- 4 件套不应成为没有就无法使用某个英雄的必需品。
- 套装触发必须有清晰图标、特效和内部冷却。

### 20.4 套装 UI

- 装备详情显示 `2/4`、`4/4`进度。
- 已激活效果实色，未激活灰色。
- 点击套装名进入套装图鉴，显示六个部位和来源。
- 英雄装备页显示当前套装组合徽章，如 `猎风4 + 时轮2`。

## 23. 装备掉落与产出

### 23.1 来源分工

| 来源 | 主要产出 |
| --- | --- |
| 普通主线 | 普通/优秀装备、升级材料 |
| 精英关 | 稀有装备、较高档词条 |
| 章节Boss | 套装装备、图纸、史诗保底进度 |
| 矿洞试炼 | 铁矿、强化材料、基础装备 |
| 英雄试炼 | 当前英雄适配标签装备 |
| 城市防守 | 防御套装、建筑/装备材料 |
| 世界Boss | 史诗/传说、专属词条、套装精华 |
| 铁匠铺 | 定向槽位、模板、套装制造 |
| 市场/商店 | 追赶装备和材料，不直接售卖唯一最强词条 |

### 23.2 智能掉落

建议权重：

- 50%～65%：当前英雄可用装备或当前追踪槽位。
- 15%～25%：已解锁英雄可用装备。
- 10%～20%：当前追踪套装。
- 剩余：全局随机。

智能掉落只提高权重，不保证每次都掉目标物，保留探索感。

### 23.3 目标追踪

- 玩家可追踪一个槽位或一套套装。
- 关卡详情显示目标装备的掉落提高状态。
- 追踪不改变高品质总概率，只改变同品质内分布。
- 更换追踪目标有短冷却或仅战斗前生效，防止结算前切换利用。

### 23.4 保底

- 精英/Boss 累积史诗保底进度。
- 铁匠铺高阶制造有品质保底。
- 长期未获得当前最低战力槽位装备时，提高该槽位权重。
- 保底进度在 UI 明确显示，不做隐藏黑箱。

## 24. 铁匠铺制造

### 24.1 制造层级

- 基础制造：选择槽位，随机模板与词条。
- 定向制造：选择槽位 + 武器类别/装备模板。
- 套装制造：选择已解锁套装和槽位。
- 图纸制造：固定模板、最低品质和固有特效。
- 升品：培养已有装备。

### 24.2 制造材料

- 金币：通用费用。
- 铁矿：主要装备材料。
- 锻造精华：提高品质或定向程度。
- 装备图纸：解锁模板/套装。
- Boss 核心：史诗/传说制造与升品。

### 24.3 制造预览

必须显示：

- 可能装备模板。
- 最低/最高品质与概率。
- 随机词条数量。
- 可出现词条池入口。
- 保底进度。
- 制造时间和资源消耗。

### 24.4 定向成本

定向越精确，消耗越高：

```text
随机装备 < 指定槽位 < 指定模板 < 指定套装槽位 < 传说图纸制造
```

玩家可以通过时间或资源换取确定性，但高阶结果仍保留词条调整空间。

## 25. 重铸与词条调整

### 25.1 普通重铸

- 选择 1 条随机词条。
- 消耗金币和重铸石。
- 生成同槽位合法的新词条与数值。
- 新旧词条并列，玩家选择保留哪一条。
- 费用随同一装备连续重铸次数上升，每日或成功更换后部分回落。

### 25.2 定向重铸

- 玩家选择词条大类，如暴击、火焰、护盾。
- 系统在该类中随机具体词条和档位。
- 消耗更高阶材料。
- 不允许直接选择最高档精确数值，保留长期追求。

### 25.3 锁定词条

- 普通重铸天然只改一条，其余词条不动。
- 若后续开放整件重铸，允许锁 1～2 条，但成本显著增加。
- 传说装备首次重铸提供一次低成本保护。

### 25.4 词条升阶

- 消耗词条精华把某条从 T2 升至 T3。
- 最高档受装备稀有度和物品强度限制。
- 升阶时数值在新档位内按原百分位映射，不重新随机成最低。
- 词条升阶是后期精修系统，MVP 可暂不开放。

### 25.5 重铸保底

- 连续多次未出现所选大类时提高对应权重。
- 达到明确次数后至少出现该大类。
- 保底只保证类别，不保证最高档。

## 26. 分解、回收与保护

### 26.1 分解返还

- 装备升级材料：返还 100%或通过重置先返还。
- 强化材料：部位强化不在装备上，无需返还。
- 进阶材料：返还 60%～80%通用装备精华。
- 基础装备价值：返还铁矿和锻造精华。
- 高品质/套装：额外返还套装精华或高阶材料。

### 26.2 自动保护

以下装备默认不可批量分解：

- 已装备。
- 已锁定。
- 史诗及以上。
- 当前唯一套装部件。
- 拥有 T5/T6 词条。
- 已投入大量进阶材料。

玩家可以在设置中调整保护品质，但传说仍需二次确认。

### 26.3 批量分解

- 支持品质、槽位、等级、是否套装筛选。
- 底部显示返还材料图标和总数。
- 高价值装备单独列在警告区域。
- 分解完成后保留筛选状态并显示资源飞入铁匠铺/背包。

### 26.4 装备锁定

- 装备详情和长按快捷菜单可锁定。
- 锁定状态在物品卡右上角显示锁图标。
- 锁定装备不能分解、作为经验、进阶材料或升品消耗。

## 27. 背包与装备方案

### 27.1 背包容量

- 初始容量足以容纳正常 1～2 天掉落。
- 容量不足时优先提示分解和整理，不立即强制付费扩容。
- 普通装备过多可开启自动分解规则。
- 材料和装备分开计数，材料不占装备格。

### 27.2 自动分解

可设置：

- 普通品质自动分解。
- 优秀品质且无高档词条自动分解。
- 指定槽位/模板保留。
- 套装装备永远保留。

自动分解规则在战斗结算前显示一次汇总，并允许撤回最近一批。

### 27.3 装备方案预设

- 每名英雄保存 3 套装备方案。
- 方案记录六件装备和构筑名称。
- 同一件装备可以被多个方案引用，但同时出战规则按实际玩法处理。
- 若装备被分解/用于升品，方案中显示缺失并推荐替代。

### 27.4 一键装备

提供三种推荐：

- 最高战力。
- 当前卡牌路线匹配。
- 生存优先。

系统只给推荐并展示变化，玩家确认后更换；不自动覆盖锁定装备和套装方案。

## 28. 英雄与装备的联动

### 28.1 标签匹配

英雄永久卡牌产生标签权重：

- 万剑路线：Projectile、MultiHit、FlyingSword。
- 火枪燃烧：Projectile、Fire、OnHit、Explosion。
- 链雷：Lightning、Bounce、Control。
- 坚守骑士：Shield、Defense、Retaliation。

装备评分和推荐根据这些标签计算，不只比较战力。

### 28.2 推荐分数

```text
推荐分 = 基础战力
       + 当前路线标签匹配
       + 套装激活收益
       + 关键触发协同
       - 属性上限溢出
       - 无效/不兼容词条
```

UI 同时显示“战力更高”和“更适合燃烧路线”等原因。

### 28.3 换英雄复用

- 五个通用槽位可在英雄之间转移。
- 武器需符合兼容标签。
- 部位强化账号共享。
- 装备等级可以一键转移。
- 新英雄通过已有套装和装备快速形成基础构筑。

## 29. 装备数值框架

### 29.1 装备内部贡献

| 部分 | 装备系统内部战力占比建议 |
| --- | ---: |
| 基础属性与等级 | 40%～45% |
| 部位强化 | 15%～20% |
| 随机词条 | 20%～25% |
| 套装效果 | 10%～15% |
| 固有/传说特效 | 5%～10% |

### 29.2 最终属性计算顺序

```text
模板基础属性
→ 稀有度倍率
→ 装备等级倍率
→ 进阶星级倍率
→ 部位强化倍率
→ 固定属性词条
→ 百分比词条
→ 套装与条件效果
```

### 29.3 属性上限

建议软/硬上限：

| 属性 | 建议 |
| --- | --- |
| 暴击率 | 常规上限75% |
| 冷却缩减 | 软上限50% |
| 闪避率 | 常规上限35%～45% |
| 通用减伤 | 与防御综合后上限70% |
| 移速 | 保证动画、地图和操作仍可控 |
| 吸血/击杀恢复 | 设置每秒生命恢复上限 |
| 控制时间降低 | 不达到永久免控，特殊技能除外 |

### 29.4 装备评分

ItemPower 只用于掉落、比较和推荐：

```text
ItemPower = 基础属性评分
          + 稀有度评分
          + 装备等级评分
          + 进阶评分
          + 词条档位评分
          + 固有特效评分
          + 套装潜力评分
```

套装潜力不能全部计入单件即时战力，否则未激活套装也会虚高。

## 30. 资源经济与成长节奏

### 30.1 资源分工

| 资源 | 用途 |
| --- | --- |
| 金币 | 升级、强化、制造、重铸通用费用 |
| 铁矿 | 部位强化、制造 |
| 装备经验 | 单件装备升级 |
| 装备精华 | 进阶、升品 |
| 重铸石 | 随机词条调整 |
| 词条精华 | 后期词条升阶 |
| 装备图纸 | 定向模板/套装制造 |
| Boss核心 | 史诗/传说升品 |

### 30.2 前期节奏

- 第一场：获得第一把优秀武器，教学装备。
- 10 分钟：获得六个槽位的基础装备。
- 20～30 分钟：第一次稀有装备和随机词条对比。
- 首日：完成一次升级、部位强化、进阶和 2 件套。
- 第 3～7 天：出现史诗装备、4 件套和重铸。
- 长期：传说、定向制造、词条升阶和多套方案。

### 30.3 防资源堵塞

- 金币为通用资源，但不能同时成为所有系统唯一瓶颈。
- 铁矿主要来自矿场和矿洞，形成明确来源。
- 重铸石有每日稳定产出，不完全依赖付费。
- 进阶可使用同槽位装备或通用精华，避免卡单一同名掉落。
- 升级/重置高返还，降低试错成本。

## 31. 装备 UI 与 UX

### 31.1 英雄装备页

- 上半屏显示英雄半身模型/立绘。
- 六个装备槽分列两侧或围绕英雄：武器、头盔、护甲、手套、鞋子、饰品。
- 每个槽显示装备图标、品质框、等级、进阶星和强化等级。
- 中部显示套装徽章，如 `猎风4 + 时轮2`。
- 点击槽位后下半屏自动筛选该槽位背包。

### 31.2 物品卡信息

卡片常显：

- 品质框。
- 装备图标。
- `Lv.35`。
- 进阶星级。
- 套装小标。
- 锁定/已装备角标。

强化等级属于槽位，不重复写在每件背包物品卡上；只在已装备槽位和强化页显示。

### 31.3 装备详情

视觉头部：

- 装备大图。
- 品质、名称、槽位、武器兼容标签。
- 装备等级和进阶星。
- 当前装备英雄头像。

内容分区：

- 基础属性卡。
- 固定槽位特性。
- 随机词条卡，每条显示图标、档位和数值。
- 固有特效卡。
- 套装效果卡。
- 获取来源卡。
- 底部操作：装备、升级、进阶、重铸、锁定。

### 31.4 装备对比

- 当前装备与新装备相同字段逐行对齐。
- 绿色上箭头、红色下箭头、新增金色标识。
- 显示基础战力变化和路线匹配变化。
- 套装变化单独显示：`猎风4→猎风2`，必须警告将失去的4件效果。
- 主按钮写“装备并继承等级”。

### 31.5 升级页

- 装备大图和当前等级。
- 经验条与目标等级滑杆。
- 基础属性当前值 → 新值。
- 金币、装备经验图标 + 库存/消耗。
- 一键升级到上限。
- 成功后等级滚动、属性值上浮，不重复弹确认。

### 31.6 强化页

- 六个槽位以环形/两列显示。
- 选中槽位显示当前 +N、下一级倍率和里程碑。
- 材料为金币和铁矿图标。
- 强调“强化属于部位，更换装备自动保留”。
- 一键强化可选择单槽位或均衡强化。

### 31.7 进阶与升品页

- 当前装备品质框和星轨。
- 4 个星节点显示每星收益。
- 材料区显示同名装备、同槽位装备、精华三种可选材料。
- 升品时预览新品质、新词条槽和固有特效。
- 高价值材料自动锁定，玩家确认消耗。

### 31.8 重铸页

- 左侧/上方装备大图。
- 中部词条列表，点击选择一条。
- 下方显示可能池、消耗和保底进度。
- 重铸后新旧词条并列，玩家选择保留。
- 返回前若未选择，默认保留旧词条，不丢失结果或材料状态。

### 31.9 套装图鉴

- 套装横幅、主题插图和构筑标签。
- 六个槽位图标，已获得实色、未获得剪影。
- 2件/4件效果分框显示。
- 下方显示掉落关卡、Boss、制造图纸和追踪按钮。

## 32. 装备表现与反馈

### 32.1 掉落表现

- 普通/优秀装备直接进入战利品流。
- 稀有装备使用蓝色光柱和短音效。
- 史诗装备使用紫色光柱、图标放大和独立卡片。
- 传说装备使用金橙演出，但时长可跳过。
- 套装装备在品质效果外增加套装纹章。

### 32.2 装备成功

- 装备图标从背包卡飞向英雄槽位。
- 槽位框发光一次。
- 战力数字滚动。
- 套装激活时套装徽章点亮，并显示 2件/4件效果。

### 32.3 强化/进阶

- 升级：装备图标柔光、等级数字滚动。
- 强化：铁砧锤击、槽位纹章亮起。
- 进阶：星节点逐个点亮。
- 升品：品质框转换、新词条展开。
- 重铸：旧词条溶解为符文，新词条卡出现。

### 32.4 音效

- 武器、金属防具、布甲、饰品可有不同装备音。
- 强化使用金属锤击，技能饰品使用符文音。
- 高档词条和套装激活使用独立重音。
- 批量升级不逐级重复完整音效。

## 34. 逻辑模块与事务

### 34.1 系统模块

- EquipmentInventory：装备实例、容量、筛选、锁定。
- EquipmentGenerator：模板、稀有度、词条、档位生成。
- EquipmentLoadout：英雄六槽位和方案预设。
- EquipmentLevelSystem：装备升级、经验与继承。
- SlotEnhancementSystem：六槽位账号强化。
- EquipmentAdvanceSystem：星级与升品。
- AffixSystem：随机词条、触发、上限和数值。
- ReforgeSystem：重铸、定向、保底。
- SetBonusSystem：套装计数、激活和战斗效果。
- EquipmentCraftSystem：铁匠铺制造、图纸和保底。
- EquipmentSalvageSystem：分解、返还和保护。

### 34.2 装备更换流程

```text
验证英雄和武器兼容
→ 计算更换前属性/套装
→ 预览等级继承和套装损失
→ 玩家确认
→ 保存装备关系
→ 应用部位强化
→ 重算属性和套装
→ 刷新技能标签/触发器
→ 播放装备和战力变化
```

### 34.3 高价值事务

以下操作使用事务 ID 并防重复提交：

- 升品。
- 进阶消耗高品质装备。
- 重铸提交和新旧词条选择。
- 传说装备分解。
- 图纸制造。
- 付费购买装备/材料。

### 34.4 重铸恢复

- 重铸生成新词条后立即保存候选结果。
- 玩家未选择退出时，重新进入继续显示同一新旧对比。
- 不能通过强退反复免费刷新。
- 材料在生成候选时扣除，不在选择时二次扣除。

## 36. 平衡风险与解决方案

### 风险 1：成长线太多

解决：前期按顺序开放。先装备和升级，再部位强化，再进阶，最后重铸和升品；界面始终只推荐当前最有效的一步。

### 风险 2：换装沉没成本过高

解决：部位强化永久保留，装备等级免费继承/高返还，重铸与进阶材料部分返还。

### 风险 3：随机词条生成垃圾

解决：槽位核心池、模板方向保护、史诗以上至少两条有效方向、定向重铸和保底。

### 风险 4：套装压制散件

解决：2件套稳定、4件套机制化但数值受控；高档散件词条可以与2+2混搭竞争。

### 风险 5：暴击、冷却、闪避失控

解决：软/硬上限、内部冷却、档位预算和边际收益衰减。

### 风险 6：新英雄没有装备

解决：五槽位通用、部位强化账号共享、等级一键继承、武器智能掉落和训练场追赶装备。

### 风险 7：经济词条成为强制

解决：限制出现槽位和数量，经济收益设上限，不进入纯战斗模式，战斗强度与收益形成明确取舍。

### 风险 8：触发效果造成性能或无限循环

解决：统一 CombatEvent、内部冷却、每秒上限、传播次数和“触发伤害不可再次触发同类”规则。

## 37. 验收清单

### 37.1 槽位与属性

- [ ] 六个槽位主属性和词条方向明显不同。
- [ ] 武器兼容标签工作正确。
- [ ] 固定槽位特性不会被随机词条覆盖。
- [ ] 属性上限和边际收益按规则生效。

### 37.2 成长

- [ ] 装备升级只提升基础属性。
- [ ] 部位强化更换装备后完整保留。
- [ ] 进阶不会重置等级、词条或套装。
- [ ] 升品保留等级和原词条，并正确增加词条槽。
- [ ] 所有培养都没有失败、爆装或降级。

### 37.3 词条

- [ ] 词条符合槽位、标签、档位和互斥规则。
- [ ] 史诗以上满足模板方向保护。
- [ ] 高频触发有内部冷却和每秒上限。
- [ ] 持续伤害、召唤物、触发伤害的归属正确。
- [ ] 重铸退出后可以恢复同一候选结果。

### 37.4 套装

- [ ] 2件/4件计数和品质要求正确。
- [ ] 换装导致套装失效时对比页明确提示。
- [ ] 触发型套装有特效、状态图标和冷却。
- [ ] `4+2`、`2+2+2`组合均可正确计算。
- [ ] 套装不会产生无限连锁或无限无敌。

### 37.5 产出与经济

- [ ] 普通、精英、Boss、试炼和制造的产出定位不同。
- [ ] 智能掉落只调整权重，不修改总品质概率。
- [ ] 保底进度可见且不会异常重置。
- [ ] 分解和重置返还准确。
- [ ] 高价值装备自动保护和二次确认有效。

### 37.6 UI/UX

- [ ] 装备卡显示品质、等级、星级、套装和状态。
- [ ] 详情按基础属性、词条、特效、套装、来源分框。
- [ ] 对比显示路线匹配和套装变化，不只显示战力。
- [ ] 材料不足可以直接跳转来源并返回原界面。
- [ ] 升级、强化、进阶、升品使用不同名称、图标和动效。

### 37.7 存档与技术

- [ ] 装备实例 ID 唯一。
- [ ] 制造和掉落随机种子可追踪。
- [ ] 升品、重铸、分解等事务防重复提交。
- [ ] 装备更换后属性、触发器和套装完整刷新。
- [ ] 大量装备列表使用虚拟化，无明显卡顿。

## 38. 最终设计结论

本系统推荐使用以下清晰结构：

```text
稀有度决定装备价值上限
装备等级提供频繁基础成长
部位强化保证换装继承
进阶星级消耗重复装备并强化特效
随机词条形成构筑差异
套装效果连接英雄永久卡牌路线
铁匠铺提供定向制造和重铸确定性
```

六个槽位必须持续保持职责差异：武器负责技能输出，头盔负责经验和抗控，护甲负责护盾与承伤，手套负责攻速暴击和触发，鞋子负责走位与位移，饰品负责冷却、终极和元素联动。玩家看到一件装备时，应能立刻判断它属于哪个槽位、强化什么玩法、是否适合当前英雄路线，以及替换后会失去或获得什么套装效果。

装备随机性应该制造“可能更适合我的构筑”的期待，而不是制造不可控制的垃圾。通过智能掉落、模板方向保护、定向制造、单词条重铸、可见保底和高返还继承，玩家既能享受掉落惊喜，也能通过稳定投入完成目标装备。
