# 主界面与首页系统设计文档

> 项目类型：2D 俯视角开放世界轻 ARPG  
> 当前章节：主界面、标题界面、首页入口、开始游戏流程、存档选择、设置入口、版本信息、主界面动效与适配规则  
> 前置章节：战斗 HUD、后台菜单、商店与交互界面  
> 目标：定义玩家从启动游戏到进入存档/新游戏/设置/退出的完整主界面体验，保证界面清晰、轻量、可爱、低操作成本，并和游戏整体 UI 风格统一。

---

## 1. 主界面设计目标

主界面是玩家第一次进入游戏时看到的界面，承担 6 个核心作用：

```text
1. 建立游戏第一印象
2. 让玩家快速进入最近存档
3. 让新玩家能直接开始新游戏
4. 让老玩家能读取指定存档
5. 让玩家能进入设置调整画面、音量、按键
6. 让玩家明确当前版本、账号/本地存档状态和退出入口
```

主界面设计关键词：

```text
清楚
轻快
可爱
少层级
低打扰
有冒险感
有角色氛围
进入游戏足够快
```

主界面不应该做得像重度 MMO 大厅，也不应该放太多活动入口。  
本项目是轻量单机开放世界 ARPG，所以主界面要偏：

```text
标题页 + 存档入口 + 设置入口
```

而不是：

```text
充值大厅 + 活动大厅 + 公告大厅 + 复杂运营入口
```

## 2. 主界面整体结构

### 2.1 主界面一级入口

主界面一级按钮建议：

```text
继续游戏
新游戏
读取游戏
设置
制作人员
退出游戏
```

移动端可以去掉“退出游戏”：

```text
继续游戏
新游戏
读取游戏
设置
制作人员
```

正式版可增加：

```text
挑战模式，通关后解锁
新游戏+，通关后解锁
图鉴，进入游戏后也可看
云存档，可选
语言切换
```

### 2.2 主界面基础布局

推荐横屏布局：

```text
┌──────────────────────────────────────────┐
│ 左上：游戏 Logo / 标题                    │
│ 右上：设置小按钮 / 版本号 / 账号，可选      │
│                                          │
│             背景场景 + 主角动画            │
│                                          │
│ 左下：版权 / 版本号                       │
│ 右下：主菜单按钮组                         │
│      [继续游戏]                           │
│      [新游戏]                             │
│      [读取游戏]                           │
│      [设置]                               │
│      [制作人员]                           │
│      [退出游戏] PC                        │
└──────────────────────────────────────────┘
```

移动端也可以采用底部居中按钮组：

```text
Logo 顶部
角色场景中间
按钮组底部
```

### 2.3 主界面推荐布局

本项目推荐：

```text
左侧：Logo + 副标题 + 当前存档摘要
右侧：纵向主按钮组
背景：动态游戏场景
底部：版本号、版权、本地存档状态
```

原因：

```text
右侧按钮方便移动端右手点击
左侧用于营造气氛
中间保留角色和背景展示
整体不拥挤
```

## 3. 主界面视觉内容

### 3.1 背景场景

主界面背景建议使用游戏内第一个城镇或草原场景的美术化版本。

可选方案：

#### 方案 A：草原村入口

```text
柔和草地
远处小村庄
飘动云朵
主角站在路牌旁
偶尔眨眼 / 挥手
背景有小动物经过
```

适合：

```text
轻松、可爱、冒险开始
```

#### 方案 B：世界地图俯视角

```text
一小块地图桌游式展示
主角站在地图中央
远处有洞穴、城镇、森林轮廓
```

适合：

```text
突出开放世界探索
```

#### 方案 C：篝火营地

```text
夜晚营火
主角坐在营火旁
装备放在旁边
远处怪物影子
```

适合：

```text
更有冒险故事感
```

推荐 MVP 使用：

```text
草原村入口
```

原因：

```text
美术成本低
主题明确
和新手区衔接自然
不需要复杂动态
```

### 3.2 主角展示

主角在主界面中必须有轻动画：

```text
待机呼吸
眨眼
耳朵 / 尾巴轻动
偶尔挥手
脚下小尘土 / 小草晃动
```

如果是小熊 / 狗狗 / 狐狸主角，可以做：

```text
小熊背着剑站在路牌旁
狗狗骑士拿着木剑做准备动作
狐狸法师翻开魔法书
```

### 3.3 背景动态元素

背景可加入轻量循环动画：

```text
云朵缓慢移动
草叶摇动
蝴蝶飞过
传送点轻微发光
远处水面波纹
村庄烟囱冒烟
Logo 周围星光闪烁
```

注意：

```text
动态不能影响按钮可读性
不能太花
不能像广告活动页一样抢视觉
```

### 3.4 Logo 设计规则

Logo 包含：

```text
游戏中文名
英文副标题，可选
小图标，如剑、爪印、地图、星星
```

Logo 风格：

```text
圆润
明亮
轻描边
有一点冒险感
适合移动端小屏识别
```

Logo 不要：

```text
过重金属
暗黑风
复杂纹理
难读的艺术字
```

## 4. 主界面按钮系统

### 4.1 主按钮列表

| 按钮 | 功能 | 显示条件 |
|---|---|---|
| 继续游戏 | 读取最近存档 | 有有效存档 |
| 新游戏 | 创建新存档并进入开场 | 始终显示 |
| 读取游戏 | 打开存档槽界面 | 有存档或始终显示 |
| 设置 | 打开设置界面 | 始终显示 |
| 制作人员 | 打开制作人员界面 | 始终显示 |
| 退出游戏 | 关闭游戏 | PC 显示，移动端可隐藏 |

### 4.2 按钮视觉

主按钮样式：

```text
大圆角按钮
浅色底
软阴影
图标 + 文字
选中时按钮放大
按下时缩小
禁用时灰色
```

按钮尺寸建议：

| 平台 | 按钮宽 | 按钮高 |
|---|---:|---:|
| 手机横屏 | 260~340 px | 62~76 px |
| 平板 | 320~420 px | 72~88 px |
| PC | 300~420 px | 60~76 px |

按钮间距：

```text
12~18 px
```

### 4.3 按钮状态

| 状态 | 表现 |
|---|---|
| Normal | 正常亮度 |
| Hover / Focus | 放大 1.05，边框亮 |
| Pressed | 缩放 0.94 |
| Disabled | 灰色，透明度 50% |
| Recommended | 外圈轻微流光 |
| New | 小红点 / 星点 |
| Warning | 橙色边框 |

### 4.4 默认焦点

PC / 手柄模式：

```text
如果有存档，默认焦点在“继续游戏”
如果没有存档，默认焦点在“新游戏”
```

移动端：

```text
不需要焦点，但继续游戏按钮可更突出
```

### 4.5 继续游戏按钮规则

如果有有效存档：

```text
按钮可用
显示最近存档摘要
```

示例：

```text
继续游戏
Lv12 绿叶森林  03:24
```

如果没有存档：

```text
按钮隐藏或置灰
```

推荐：

```text
没有存档时隐藏继续游戏
新游戏作为第一个按钮
```

### 4.6 新游戏按钮规则

点击新游戏：

```text
如果没有任何存档：
    直接进入新游戏开场 / 新手流程

如果存在存档：
    打开存档槽选择界面
    让玩家选择空槽或覆盖旧槽
```

不建议点击新游戏后直接覆盖旧存档。

### 4.7 读取游戏按钮规则

点击读取游戏：

```text
打开存档槽界面
显示自动存档和手动存档
玩家选择后读取
```

如果没有存档：

```text
显示空存档槽
读取按钮置灰
提示：暂无存档
```

### 4.8 设置按钮规则

点击设置：

```text
打开设置界面
默认显示音效或画面设置
返回后回到主界面
```

主界面设置可修改：

```text
画面
音效
操作
按键
语言
辅助
```

不应显示需要进游戏才有意义的设置：

```text
角色属性
装备
技能
任务
```

## 5. 主界面启动流程

### 5.1 游戏启动流程

```text
启动应用
→ 显示厂商 / 引擎 Logo，可跳过
→ 加载本地设置
→ 加载存档索引
→ 进入标题界面
→ 检查是否有最近存档
→ 更新主按钮状态
```

### 5.2 首次启动流程

首次启动没有设置和存档时：

```text
加载默认设置
语言跟随系统，或默认中文
继续游戏按钮隐藏
新游戏按钮高亮
显示新手欢迎提示，可选
```

### 5.3 非首次启动流程

```text
读取本地设置
读取最近存档摘要
继续游戏按钮可用
显示最近角色等级、地点和时间
```

### 5.4 快速继续流程

点击继续游戏：

```text
按钮按下反馈
屏幕淡出
显示加载界面
读取最近存档
进入对应地图和位置
屏幕淡入
```

### 5.5 加载失败

如果存档损坏或读取失败：

```text
显示错误弹窗
允许返回主界面
允许选择其他存档
```

提示：

```text
读取存档失败。
该存档可能已损坏。

[返回] [选择其他存档]
```

不要直接崩溃或卡死。

## 6. 标题界面与主界面关系

### 6.1 是否需要“点击开始”标题页

可以有两种方案：

#### 方案 A：直接主菜单

```text
启动后直接显示按钮组
```

优点：

```text
进入快
适合移动端
```

#### 方案 B：标题页 → 点击开始 → 主菜单

```text
先显示 Logo 和“点击开始”
点击后展开主按钮
```

优点：

```text
仪式感更强
适合 PC / 主机
```

推荐：

```text
移动端：直接主菜单
PC / 主机：可保留“按任意键开始”
```

MVP 推荐直接主菜单，减少层级。

### 6.2 标题页内容

如果做标题页：

```text
游戏 Logo
动态背景
按任意键开始 / 点击屏幕开始
版本号
语言切换小按钮，可选
```

点击后：

```text
Logo 上移
主按钮组淡入
角色动画切换
```

## 7. 存档槽选择界面

### 7.1 入口

```text
主界面 → 读取游戏
主界面 → 新游戏且已有存档
主界面 → 继续游戏失败后选择其他存档
```

### 7.2 存档槽组成

推荐：

```text
自动存档槽 x1
手动存档槽 x3
```

也可以：

```text
存档槽 1
存档槽 2
存档槽 3
```

MVP 推荐 3 个槽：

```text
存档 1
存档 2
存档 3
```

自动存档作为每个槽内最近自动记录，不单独暴露也可以。

### 7.3 存档槽界面布局

```text
┌──────────────────────────────────────────┐
│ 读取游戏                                  │
├──────────────────────────────────────────┤
│ [存档 1] Lv12 绿叶森林 03:24              │
│ 主线：寻找森林神殿                         │
│ 保存时间：2026/05/13 20:30                │
│                                          │
│ [存档 2] 空                               │
│                                          │
│ [存档 3] Lv5 草原村 00:48                 │
├──────────────────────────────────────────┤
│ [返回]       [删除]       [读取]           │
└──────────────────────────────────────────┘
```

### 7.4 存档槽显示字段

每个存档槽显示：

```text
槽位名称
角色等级
当前区域
游戏时长
主线进度
金币，可选
保存时间
缩略图，可选
是否自动存档 / 手动存档
```

空槽显示：

```text
空存档
点击开始新游戏
```

### 7.5 读取存档规则

点击已有存档：

```text
选中存档槽
显示读取按钮
点击读取
弹出确认，可选
加载存档
```

读取确认：

```text
是否读取该存档？
当前未保存进度可能会丢失。

[取消] [读取]
```

主界面读取时没有当前进度，可不弹确认。  
游戏内读取必须弹确认。

### 7.6 新游戏选择存档槽规则

点击新游戏后：

```text
打开存档槽选择界面
空槽显示“开始”
已有存档显示“覆盖”
```

选择空槽：

```text
直接开始新游戏
```

选择已有槽：

```text
弹出覆盖确认
```

覆盖确认：

```text
该存档已有进度。
覆盖后无法恢复。

[取消] [覆盖并开始]
```

### 7.7 删除存档规则

删除操作必须强确认。

流程：

```text
选择存档
点击删除
弹出确认
长按删除按钮 1.5s
删除成功
```

确认文案：

```text
确定要删除该存档吗？
此操作无法撤销。
```

移动端推荐长按确认，防止误触。

## 8. 新游戏流程

### 8.1 新游戏入口

```text
主界面 → 新游戏
```

### 8.2 新游戏流程结构

MVP 简化：

```text
点击新游戏
→ 选择存档槽
→ 创建新存档
→ 加载新手地图
→ 播放开场对话 / 教学
```

正式版可增加：

```text
选择角色外观
输入名字
选择难度
观看开场动画
```

### 8.3 是否需要角色创建

如果项目是固定主角冒险，不建议早期做复杂角色创建。

MVP：

```text
固定主角
固定名字或默认名字
无需创建角色
```

正式版可加：

```text
选择主角颜色
选择初始外观
输入名字
```

### 8.4 难度选择

MVP 不建议做难度选择。  
正式版可提供：

```text
轻松
标准
挑战
```

难度影响：

```text
敌人伤害
敌人血量
药水恢复
死亡惩罚
```

默认：

```text
标准
```

如果做难度选择，必须允许后续修改，或提示不可修改。

### 8.5 开场跳过规则

如果有开场剧情：

```text
首次进入默认播放
长按跳过
跳过需要确认
```

提示：

```text
是否跳过开场？
你可以在图鉴中重新观看，可选。
```

MVP 可以不用开场动画，直接做游戏内对话教学。

## 9. 设置界面入口与主界面设置

### 9.1 主界面设置内容

主界面设置只显示系统类设置：

```text
画面
音效
操作
按键
语言
辅助
```

```text
存档管理，可从读取游戏进入
```

```text
→ 设置面板弹出
```

```text
设置数据独立保存
```

```text
需要应用按钮

```

移动端画质类：

```text
立即生效
```

```text
退出游戏
```

## 12. 主界面公告与版本信息

### 12.1 是否需要公告

如果是单机小项目，MVP 不建议做联网公告。  
可以做本地版本提示：

```text
版本号
更新内容按钮
```

如果后续上线移动端，可加入：

```text
公告
活动
更新说明
隐私政策
用户协议
```

但不要在 MVP 阶段占用过多主界面空间。

### 12.2 版本号显示

位置：

```text
左下角或右下角
```

内容：

```text
v0.1.0
Build 2026.05.13
```

### 12.3 网络状态，可选

如果后期有云存档：

```text
本地模式
云存档已同步
```

## 20. 主界面与存档系统关系

```text

SaveTime

IsCorrupted
```

```text
读取最近有效存档
```

```text
保存时间最新
不是损坏
不是被删除
```


显示：

```text
存档损坏
```


## 30. 设计关键点总结

主界面最重要的是：

```text
1. 有存档时，玩家一眼能继续游戏
2. 无存档时，玩家一眼能开始新游戏
3. 读取和覆盖存档必须安全
4. 设置入口要明显，但不抢主入口
5. 背景要有游戏气质，但不能干扰按钮
6. 按钮要大，移动端要好点
7. PC / 手柄要有清晰焦点
8. 主界面不要塞太多运营入口
9. 错误状态要有处理
10. 进入游戏流程要快
```

最终目标：

```text
玩家打开游戏后 3 秒内知道点哪里；
老玩家 1 次点击继续冒险；
新玩家 1 次点击开始新游戏；
任何存档风险操作都不会误触。
```
