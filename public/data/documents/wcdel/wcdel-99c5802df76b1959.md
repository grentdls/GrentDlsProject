# 角色基础操作系统设计文档

> 项目类型：2D 俯视角开放世界轻 ARPG  
> 参考方向：可爱动物勇者 / 轻量开放世界 / 即时战斗 / 短任务 / 短副本  
> 当前章节：人物基础操作  
> 目标：定义玩家角色从“能动、能打、能躲、能交互、能反馈”的完整操作层设计。

---

## 1. 设计目标

角色基础操作是整个游戏的手感核心。这一层不追求复杂连招，而是追求：

1. **移动清楚**：玩家能准确控制角色在大地图、城镇、副本中移动。
2. **攻击直接**：按下普攻后立刻有动作、有音效、有打击反馈。
3. **翻滚可靠**：翻滚必须能明确躲避红圈攻击，不能拖泥带水。
4. **技能易懂**：技能按钮和释放范围清晰，玩家不需要复杂学习。
5. **交互轻量**：靠近 NPC、宝箱、洞口时自动出现交互按钮。
6. **反馈密集**：动画、音效、特效、震屏、伤害数字都要让玩家感到“爽”。
7. **移动端友好**：操作不能像重度动作游戏一样复杂，核心按钮保持少而清晰。

## 3. 角色基础状态

角色不是任何时候都能执行所有操作，需要用状态机管理。

### 3.1 状态列表

| 状态 ID | 状态名 | 是否可移动 | 是否可普攻 | 是否可翻滚 | 是否可放技能 | 是否可交互 |
|---|---|---:|---:|---:|---:|---:|
| Idle | 待机 | 是 | 是 | 是 | 是 | 是 |
| Move | 移动 | 是 | 是 | 是 | 是 | 是 |
| Attack | 普攻 | 限制 | 否 | 可配置 | 否 | 否 |
| Roll | 翻滚 | 否，由翻滚逻辑控制 | 否 | 否 | 否 | 否 |
| Cast | 施法 | 限制 | 否 | 可配置 | 否 | 否 |
| Hit | 受击 | 否 | 否 | 否 | 否 | 否 |
| Knockback | 击退 | 否，由击退逻辑控制 | 否 | 否 | 否 | 否 |
| Interact | 交互 | 否 | 否 | 否 | 否 | 否 |
| Dead | 死亡 | 否 | 否 | 否 | 否 | 否 |
| Revive | 复活 | 否 | 否 | 否 | 否 | 否 |

### 3.2 状态优先级

优先级从高到低：

```text
Dead
> Revive
> Knockback
> Hit
> Roll
> Cast
> Attack
> Interact
> Move
> Idle
```

说明：

- 死亡最高，死亡后所有操作无效。
- 击退和受击会打断普攻、施法、交互。
- 翻滚优先级高于普攻，玩家可以通过翻滚规避危险。
- 普通交互优先级最低，避免玩家在战斗中误触 NPC / 宝箱。

## 4. 移动系统

### 4.1 移动设计目标

移动必须满足：

1. 摇杆 / WASD 操作灵敏。
2. 松手后角色马上停下。
3. 角色朝向和移动方向一致。
4. 不使用复杂惯性，避免移动端失控。
5. 在大地图、城镇、洞穴中手感一致。
6. 在水面、草地、雪地等地形上可以更换脚步特效和音效，但基础速度不建议频繁改变。

### 4.2 移动参数

| 参数 | 推荐值 | 说明 |
|---|---:|---|
| MoveSpeed | 4.2 | 基础移动速度 |
| Acceleration | 50 | 加速度，数值高代表快速到达目标速度 |
| Deceleration | 60 | 减速度，松手后快速停下 |
| DirectionSnapAngle | 22.5° | 用于 8 方向动画切换 |
| MinInputThreshold | 0.15 | 摇杆输入低于该值视为无输入 |
| TurnSmoothTime | 0.05s | 转向平滑时间，可选 |
| CollisionRadius | 0.35 | 玩家碰撞半径 |
| InteractionRadius | 1.2 | 交互检测半径 |

### 4.3 移动规则

```text
玩家输入方向
→ 归一化移动向量
→ 检查是否被状态机禁止移动
→ 检查碰撞
→ 应用速度
→ 更新朝向
→ 播放移动动画
→ 根据地表播放脚步音效和脚步特效
```

### 4.4 朝向规则

角色采用 4 方向或 8 方向表现。

#### 方案 A：4 方向

```text
Up
Down
Left
Right
```

优点：动画量少。  
缺点：移动表现略僵硬。

#### 方案 B：8 方向

```text
Up
Down
Left
Right
UpLeft
UpRight
DownLeft
DownRight
```

优点：表现更顺。  
缺点：动画量翻倍。

推荐：MVP 阶段使用 **4 方向移动 + 左右翻转**。正式版使用 **8 方向待机 / 移动 / 攻击 / 受击**。

### 4.5 移动动画播放

| 动画名 | 触发条件 | 循环 | 备注 |
|---|---|---:|---|
| Idle_Down | 无输入，朝下 | 是 | 默认待机 |
| Idle_Up | 无输入，朝上 | 是 |  |
| Idle_Left | 无输入，朝左 | 是 |  |
| Idle_Right | 无输入，朝右 | 是 | 可由 Left 翻转 |
| Walk_Down | 有输入，方向下 | 是 |  |
| Walk_Up | 有输入，方向上 | 是 |  |
| Walk_Left | 有输入，方向左 | 是 |  |
| Walk_Right | 有输入，方向右 | 是 | 可由 Left 翻转 |

移动动画切换规则：

```text
输入强度 <= 0.15 → Idle
输入强度 > 0.15 → Walk
根据最后有效输入方向选择动画方向
```

角色停下后，仍然保持最后一次移动方向的待机动画。例如玩家向右移动后松手，角色播放 Idle_Right。

### 4.6 移动音效

| 音效 | 触发条件 | 频率 |
|---|---|---|
| Footstep_Grass_01~04 | 草地移动 | 每 0.28s 一次 |
| Footstep_Stone_01~04 | 石路移动 | 每 0.28s 一次 |
| Footstep_Wood_01~04 | 木地板移动 | 每 0.28s 一次 |
| Footstep_Water_01~04 | 浅水移动 | 每 0.32s 一次 |
| Footstep_Snow_01~04 | 雪地移动 | 每 0.34s 一次 |

脚步音效规则：

```text
角色处于 Move 状态
且速度 > 角色最大速度的 30%
且不是 Roll / Knockback / Hit
→ 按脚步间隔播放当前地表脚步音效
```

### 4.7 移动特效

| 特效 | 触发条件 | 表现 |
|---|---|---|
| StepDust | 草地 / 土地移动 | 小尘土粒子 |
| StepGrass | 草地移动 | 小草叶飞起 |
| StepWaterRipple | 浅水移动 | 水波纹 |
| StepSnow | 雪地移动 | 白色粉尘 |
| StopDust | 高速移动后停下 | 轻微停步尘土 |

特效要求：

```text
使用 2D Sprite 粒子
生命周期 0.2~0.5s
SortingLayer 低于角色脚部
不遮挡角色身体
```

## 5. 普攻系统

### 5.1 普攻设计目标

普攻是最常用动作，需要：

1. 按下后反馈快。
2. 范围清楚。
3. 可以打断轻微移动，但不能完全让角色滑行。
4. 对小怪有稳定打击感。
5. 不做复杂连招也要有爽感。
6. 后续可以扩展成 2~3 段连击。

### 5.2 普攻基础规则

```text
按下普攻
→ 检查当前状态是否允许攻击
→ 角色面向输入方向 / 最近敌人方向
→ 进入 Attack 状态
→ 播放攻击动画
→ 在命中帧开启攻击判定
→ 命中敌人
→ 播放命中特效和音效
→ 造成伤害
→ 攻击后摇结束
→ 回到 Idle / Move
```

### 5.3 攻击方向规则

攻击方向优先级：

```text
1. 当前移动输入方向
2. 最近一次有效移动方向
3. 最近敌人方向，可选
4. 默认朝下
```

移动端推荐：

- 玩家正在推动摇杆时，按普攻则朝摇杆方向攻击。
- 玩家没有推动摇杆时，普攻朝最后朝向攻击。
- 可选自动辅助：如果近距离有敌人，轻微修正攻击方向。

### 5.4 普攻参数

| 参数 | 推荐值 | 说明 |
|---|---:|---|
| AttackCooldown | 0.45s | 普攻间隔 |
| AttackMoveLockTime | 0.18s | 攻击期间锁移动时间 |
| AttackTotalTime | 0.38s | 单次攻击总时长 |
| HitFrameStart | 0.12s | 命中判定开始 |
| HitFrameEnd | 0.20s | 命中判定结束 |
| AttackRange | 1.1 | 攻击距离 |
| AttackAngle | 100° | 扇形攻击角度 |
| KnockbackForce | 1.2 | 小怪击退力度 |
| ManaGainOnHit | 3 | 普攻命中回蓝，可选 |

### 5.5 普攻动画

| 动画名 | 时长 | 命中帧 | 说明 |
|---|---:|---:|---|
| Attack_Down_01 | 0.38s | 第 4~6 帧 | 向下挥砍 |
| Attack_Up_01 | 0.38s | 第 4~6 帧 | 向上挥砍 |
| Attack_Left_01 | 0.38s | 第 4~6 帧 | 向左挥砍 |
| Attack_Right_01 | 0.38s | 第 4~6 帧 | 向右挥砍 |

若使用 8 方向，则增加：

```text
Attack_UpLeft_01
Attack_UpRight_01
Attack_DownLeft_01
Attack_DownRight_01
```

### 5.6 普攻动画事件

攻击动画需要配置事件：

| 时间点 | 事件 | 说明 |
|---:|---|---|
| 0.00s | OnAttackStart | 进入攻击状态，锁定方向 |
| 0.05s | PlaySwingSFX | 播放挥砍音效 |
| 0.08s | SpawnSlashVFX | 生成刀光 / 爪痕特效 |
| 0.12s | EnableHitbox | 开启命中判定 |
| 0.20s | DisableHitbox | 关闭命中判定 |
| 0.28s | CanBufferNextAction | 允许缓存下一次操作 |
| 0.38s | OnAttackEnd | 退出攻击状态 |

### 5.7 普攻音效

| 音效 | 触发点 | 说明 |
|---|---|---|
| Attack_Swing_Light_01~04 | 攻击前摇 | 轻快挥砍声 |
| Attack_Hit_Flesh_01~04 | 命中普通怪 | 肉感命中 |
| Attack_Hit_Armor_01~04 | 命中护甲怪 | 金属感 |
| Attack_Hit_Shield_01~03 | 命中格挡敌人 | 清脆反弹 |
| Attack_Crit_01~03 | 暴击 | 更尖锐、更响 |
| Attack_Miss_Whoosh_01~03 | 未命中，可选 | 不建议频繁播放，容易吵 |

音效规则：

```text
挥砍音效每次攻击必播
命中音效每个敌人最多 0.08s 内播放一次
如果一次攻击命中多个敌人，只播放 1 次主命中音效 + 多个小命中特效
```

### 5.8 普攻特效

| 特效 | 表现 | 触发 |
|---|---|---|
| SlashArc | 扇形刀光 / 爪痕 | 普攻前摇 |
| HitSpark | 命中火花 | 命中敌人 |
| HitFlash | 敌人白闪 | 命中敌人 |
| SmallKnockDust | 敌人被击退脚底尘土 | 敌人击退 |
| CritBurst | 暴击爆点 | 暴击时 |
| DamageNumber | 伤害数字 | 命中后 |

SlashArc 要求：

```text
方向跟随攻击方向
生命周期 0.15~0.25s
颜色根据武器类型变化
普通攻击不要过亮，避免和技能混淆
```

## 6. 翻滚系统

### 6.1 翻滚设计目标

翻滚是躲避红圈攻击的核心操作。它必须做到：

1. 按下立即响应。
2. 距离固定且可预期。
3. 期间拥有短暂无敌帧。
4. 可以穿过敌人攻击范围，但不能穿墙。
5. 翻滚结束后快速恢复操作。
6. 音效和特效要明显。

### 6.2 翻滚基础流程

```text
按下翻滚
→ 检查冷却
→ 检查耐力 / 资源，可选
→ 获取翻滚方向
→ 进入 Roll 状态
→ 开启无敌帧
→ 播放翻滚动画
→ 位移角色
→ 生成尘土 / 残影特效
→ 关闭无敌帧
→ 翻滚结束
→ 回到 Idle / Move
```

### 6.3 翻滚方向规则

优先级：

```text
1. 当前移动输入方向
2. 当前角色朝向
3. 最近敌人相反方向，可选，不建议默认启用
```

推荐：

- 玩家有移动输入时：朝输入方向翻滚。
- 玩家无输入时：朝当前面向方向翻滚。
- 不做自动躲避，否则动作游戏判断感会变差。

### 6.4 翻滚参数

| 参数 | 推荐值 | 说明 |
|---|---:|---|
| RollDistance | 2.2 | 翻滚距离 |
| RollDuration | 0.32s | 翻滚总时长 |
| RollCooldown | 0.65s | 冷却 |
| InvincibleStart | 0.04s | 无敌开始 |
| InvincibleEnd | 0.24s | 无敌结束 |
| RollCancelTime | 0.28s | 可提前接移动的时间 |
| RollCollisionRadiusScale | 0.8 | 翻滚时碰撞半径缩小 |
| RollStaminaCost | 0 | MVP 不建议加耐力消耗 |

### 6.5 翻滚动画

| 动画名 | 时长 | 说明 |
|---|---:|---|
| Roll_Down | 0.32s | 向下翻滚 |
| Roll_Up | 0.32s | 向上翻滚 |
| Roll_Left | 0.32s | 向左翻滚 |
| Roll_Right | 0.32s | 向右翻滚 |

如果角色是可爱动物，可以不做真实滚翻，而做：

```text
小跳步
冲刺滑步
团成球滚一下
快速扑跃
```

推荐表现：**小动物团成球向前滚一下**。辨识度高，也适合可爱风格。

### 6.6 翻滚动画事件

| 时间点 | 事件 | 说明 |
|---:|---|---|
| 0.00s | OnRollStart | 进入翻滚状态 |
| 0.02s | PlayRollSFX | 播放翻滚音效 |
| 0.04s | InvincibleOn | 开启无敌 |
| 0.05s | SpawnRollDust | 生成起步尘土 |
| 0.10s | SpawnAfterImage | 生成残影 |
| 0.24s | InvincibleOff | 关闭无敌 |
| 0.28s | CanMove | 允许移动衔接 |
| 0.32s | OnRollEnd | 退出翻滚状态 |

### 6.7 翻滚音效

| 音效 | 触发点 | 表现 |
|---|---|---|
| Roll_Start_01~04 | 翻滚开始 | 轻快“嗖” |
| Roll_Dust_01~03 | 接触地面 | 小尘土 |
| Roll_Water_01~03 | 水面翻滚 | 水花 |
| Roll_End_01~03 | 翻滚结束，可选 | 轻微落地 |

音效规则：

```text
翻滚开始音效必须播放
地面材质音效根据当前地形替换
连续翻滚时音效随机选择，避免重复感
```

### 6.8 翻滚特效

| 特效 | 触发 | 表现 |
|---|---|---|
| RollDust_Start | 翻滚开始 | 地面尘土爆开 |
| RollTrail | 翻滚期间 | 短拖尾 |
| RollAfterImage | 翻滚中段 | 半透明残影 |
| RollDust_End | 翻滚结束 | 小尘土 |
| InvincibleBlink | 无敌帧期间，可选 | 角色轻微闪烁 |

特效规则：

```text
RollTrail 不要过长，最多 0.25s
AfterImage 透明度 30%~50%
无敌闪烁不能太强，避免像受击
```

## 7. 技能释放基础操作

本章节只定义基础操作规则，具体技能系统在后续章节细写。

### 7.1 技能按钮

| 技能槽 | 移动端 | PC | 手柄 |
|---|---|---|---|
| SkillSlot_1 | 技能按钮 1 | Q / 1 | LT + X |
| SkillSlot_2 | 技能按钮 2 | E / 2 | LT + Y |
| SkillSlot_3 | 技能按钮 3 | R / 3 | LT + B |
| SkillSlot_4 | 技能按钮 4 | F / 4 | LT + A |

### 7.2 技能释放流程

```text
按下技能按钮
→ 检查技能是否解锁
→ 检查蓝量
→ 检查冷却
→ 确定释放方向 / 目标点
→ 进入 Cast 状态
→ 播放施法动画
→ 播放施法音效
→ 生成预施法特效
→ 在技能生效帧创建技能效果
→ 扣除蓝量
→ 进入冷却
→ 回到 Idle / Move
```

### 7.3 技能方向规则

根据技能类型决定：

| 技能类型 | 方向 / 目标规则 |
|---|---|
| 自身圆形技能 | 以玩家为中心 |
| 前方扇形技能 | 朝玩家当前朝向 |
| 前方直线技能 | 朝摇杆方向 / 当前朝向 |
| 指定区域技能 | 朝最近敌人位置 / 摇杆方向一定距离 |
| 治疗技能 | 直接对自己释放 |
| 陷阱技能 | 在玩家前方 1.5 米处释放 |

移动端不建议做复杂拖拽瞄准。推荐默认自动朝向当前输入方向，必要时轻微辅助瞄准最近敌人。

### 7.4 施法参数

| 参数 | 推荐值 | 说明 |
|---|---:|---|
| CastInputBuffer | 0.15s | 技能输入缓存 |
| CastMoveSpeedScale | 0.2~0.5 | 施法期间移动速度倍率 |
| CastTurnAllowed | true | 是否允许施法前转向 |
| SkillGlobalCooldown | 0.1s | 防止多个技能同帧释放 |
| ManaCheckTiming | CastStart | 按下时检查蓝量 |
| ManaCostTiming | SkillFireFrame | 技能生效帧扣蓝 |

### 7.5 施法动画

| 动画名 | 时长 | 说明 |
|---|---:|---|
| Cast_Down | 0.45s | 向下施法 |
| Cast_Up | 0.45s | 向上施法 |
| Cast_Left | 0.45s | 向左施法 |
| Cast_Right | 0.45s | 向右施法 |

施法动画可以分强弱：

```text
Cast_Small：普通技能，0.35~0.45s
Cast_Medium：中型技能，0.5~0.7s
Cast_Large：大招，0.8~1.2s
```

### 7.6 技能音效

| 音效 | 触发 |
|---|---|
| Skill_Cast_Start | 施法开始 |
| Skill_Fire | 技能生效 |
| Skill_Hit | 技能命中 |

| Skill_NoMana | 蓝量不足 |
| Skill_Locked | 技能未解锁 |

### 7.7 技能特效

基础技能特效分 4 层：

```text
1. 施法起手特效：角色脚下法阵 / 光点
2. 飞行或扩散特效：火球、雷线、冰环

```

## 11. 操作输入缓存

### 11.1 为什么需要输入缓存

轻 ARPG 中，如果玩家在攻击后摇快结束时按翻滚，系统应该记住这个输入。否则玩家会觉得按键“不灵”。

### 11.2 输入缓存规则

| 输入 | 缓存时间 |
|---|---:|
| 普攻 | 0.15s |
| 翻滚 | 0.18s |
| 技能 | 0.15s |
| 交互 | 0.1s |

### 11.3 缓存释放优先级

```text
翻滚
> 技能
> 普攻
> 交互
```

翻滚优先级最高，因为它经常用于保命。

## 12. 操作打断规则

### 12.1 玩家主动打断

| 当前动作 | 可被移动打断 | 可被普攻打断 | 可被翻滚打断 | 可被技能打断 |
|---|---:|---:|---:|---:|
| Idle | 是 | 是 | 是 | 是 |
| Move | 是 | 是 | 是 | 是 |
| Attack 前摇 | 否 | 否 | 可选 | 否 |
| Attack 命中帧 | 否 | 否 | 否 | 否 |
| Attack 后摇 | 是 | 否 | 是 | 可选 |
| Cast 前摇 | 否 | 否 | 可选 | 否 |
| Cast 生效帧 | 否 | 否 | 否 | 否 |
| Cast 后摇 | 是 | 否 | 是 | 否 |
| Roll | 否 | 否 | 否 | 否 |
| Hit | 否 | 否 | 否 | 否 |

推荐 MVP：

```text
普攻后摇可以被翻滚打断
技能后摇可以被翻滚打断
翻滚不能被任何主动操作打断
受击不能被主动操作打断
```

### 12.2 敌人打断玩家

| 玩家状态 | 是否可被普通伤害打断 |
|---|---:|

| Move | 是 |

| Cast | 是 |
| Roll 无敌帧 | 否 |
| Roll 非无敌帧 | 是 |

## 17. 反馈强度分级

为了让游戏有商业化手感，反馈不能平均用力。不同操作需要不同强度。

| 操作 | 动画反馈 | 音效反馈 | 特效反馈 | 震屏 |
|---|---|---|---|---|
| 移动 | 低 | 低 | 低 | 无 |
| 普攻未命中 | 中 | 中 | 低 | 无 |
| 普攻命中 | 中 | 中 | 中 | 轻微 |
| 暴击 | 高 | 高 | 高 | 轻微 |
| 翻滚 | 中 | 中 | 中 | 无 |
| 小技能 | 中 | 中 | 中 | 轻微 |
| 大技能 | 高 | 高 | 高 | 中 |
| 受击 | 中 | 中 | 中 | 轻微 |
| 死亡 | 高 | 高 | 高 | 中 |
| 升级 | 高 | 高 | 高 | 轻微 |
| 获得稀有装备 | 高 | 高 | 高 | 轻微 |

### 17.1 震屏参数

| 事件 | 强度 | 时长 |
|---|---:|---:|
| 普攻命中 | 0.05 | 0.05s |
| 暴击 | 0.12 | 0.08s |
| 小技能命中 | 0.08 | 0.08s |
| 大技能命中 | 0.2 | 0.15s |
| 玩家受击 | 0.1 | 0.08s |
| Boss 重击 | 0.25 | 0.2s |

移动端震屏要克制，避免眩晕。

## 19. Unity 实现建议

### 19.1 推荐组件拆分

```text
PlayerRoot
├── PlayerController：读取输入，驱动移动
├── PlayerStateMachine：状态管理
├── PlayerCombat：普攻、受击、伤害
├── PlayerRoll：翻滚
├── PlayerSkillController：技能释放
├── PlayerInteraction：交互检测
├── PlayerAnimationController：动画播放
├── PlayerSFXController：音效播放
├── PlayerVFXController：特效生成
├── PlayerStats：属性数据
├── Rigidbody2D
├── Collider2D
├── SpriteRenderer / Animator
└── ShadowSprite
```

### 19.2 输入层

建议使用 Unity Input System，统一支持：

```text
移动端虚拟摇杆
PC 键鼠
手柄
```

输入层只负责发出意图：

```text
MoveInput
AttackPressed
RollPressed
SkillPressed
InteractPressed
MenuPressed
```

不要在输入层里直接执行战斗逻辑。

### 19.3 动画层

```text
当前状态
当前朝向
当前速度
```


## 20. 验收标准

### 20.1 移动验收

- 玩家推动摇杆后，角色立即移动。
- 松开摇杆后，角色能快速停下。
- 角色朝向和移动方向一致。
- 不会卡在普通墙角。
- 不会因为动画切换导致移动方向错误。
- 不同地表能播放不同脚步音效和特效。

### 20.2 普攻验收

- 普攻按下后 0.1s 内必须看到动画反馈。
- 攻击判定和刀光方向一致。
- 命中敌人有白闪、命中特效、音效、伤害数字。
- 未命中时也有挥砍音效和刀光。
- 攻击后摇可以顺畅接移动或翻滚。
- 连续点击不会出现动画卡死。

### 20.3 翻滚验收

- 翻滚按下后立即响应。
- 翻滚期间能躲避红圈攻击。
- 翻滚不能穿墙。
- 翻滚结束后能快速继续移动。
- 翻滚方向符合摇杆方向。
- 无敌帧时间可通过配置调整。

### 20.4 技能基础验收

- 技能未解锁时按钮显示锁定。
- 蓝量不足时不能释放，并播放提示。
- 冷却中不能释放，并显示 CD。
- 技能释放方向正确。
- 技能释放时动画、音效、特效同步。
- 技能不会和普攻、翻滚产生状态冲突。

### 20.5 交互验收

- 靠近 NPC / 宝箱 / 洞口时出现交互按钮。
- 离开范围后按钮消失。
- 多个对象重叠时按优先级选择正确对象。
- 交互期间不能乱动。
- 战斗状态下不会误触普通交互。

## 23. 设计关键点总结

人物基础操作不是“能动就行”，而是决定整个游戏是否好玩的第一层。

最重要的 6 个点：

```text
1. 移动要轻快，不要重惯性
2. 普攻要快，命中反馈要强
3. 翻滚要可靠，必须能躲红圈
4. 动画优先级必须清楚，不能互相抢
5. 音效和特效要按事件帧同步
6. 移动端按钮要少，但每个按钮作用明确
```

MVP 只要把下面这 5 件事做好，就能形成最小战斗手感：

```text
移动
普攻
命中反馈
翻滚
受击死亡
```
