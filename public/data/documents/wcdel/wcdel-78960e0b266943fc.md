# 3D 判定版角色配置工具规则说明

> 项目方向：固定视角 3D 场景 + 2D 序列帧角色资源  
> 战斗类型：DNF 式横版清版动作  
> 核心修正：游戏不是 2D 物理判定，而是 **3D 世界里的 2D 美术表现**。角色、怪物、技能、碰撞、伤害框全部按 3D 坐标和 3D 体积计算。

---

## 1. 核心结论

之前“2D 横版角色配置工具”的问题在于：把角色移动、攻击范围、受击框都当成了 2D 平面框。

现在需要统一成：

```text
游戏运行逻辑：3D
角色表现资源：2D 序列帧
地图空间：3D
碰撞判定：3D
技能伤害范围：3D
镜头：固定角度跟随
角色动画：Sprite / 序列帧 / Billboard
```

玩家操作：

```text
A / D 控制 X 轴横向移动
W / S 控制 Z 轴纵向移动，也就是场景深度方向
跳跃控制 Y 轴高度
```

---

## 2. 统一坐标轴命名

### 2.1 Unity 世界轴

| 轴 | 名称 | 用途 |
|---|---|---|
| X 轴 | 横向轴 | 左右移动 |
| Y 轴 | 高度轴 | 跳跃、击飞、浮空、高低差 |
| Z 轴 | 纵深轴 | 前后 / 上下走位 / 场景深度 |

必须统一说法：

```text
横移 = X 轴移动
纵向移动 = Z 轴移动
高度变化 = Y 轴移动
跳跃 = Y 轴运动
击飞 = Y 轴 + X/Z 位移
```

禁止再混用：

```text
2D Y 轴
屏幕上下
平面上下
```

如果说“上下走位”，必须说明是：

```text
屏幕视觉上的上下走位，对应 Unity 世界的 Z 轴移动。
```

---

### 2.2 玩家输入与世界轴关系

| 输入 | 世界轴 | 行为 |
|---|---|---|
| A | X 负方向 | 向左移动 |
| D | X 正方向 | 向右移动 |
| W | Z 正方向 | 向场景上方 / 远处移动 |
| S | Z 负方向 | 向场景下方 / 近处移动 |
| 跳跃键 | Y 正方向 | 起跳 |
| 重力 | Y 负方向 | 下落 |

示例：

```text
按 D：角色 Position.x 增加
按 A：角色 Position.x 减少
按 W：角色 Position.z 增加
按 S：角色 Position.z 减少
按跳跃：角色 Position.y 上升
```

---

### 2.3 战斗平面

角色默认站在地面上：

```text
地面平面：X-Z 平面
高度方向：Y 轴
```

可以理解为：

```text
角色的脚底坐标 = (X, GroundY, Z)
角色跳起来时 = (X, GroundY + JumpHeight, Z)
```

如果地图有高低差：

```text
GroundY 来自地形高度采样
角色 Y = GroundY + JumpOffset
```

---

## 3. 固定视角与 2D 角色表现

### 3.1 摄像机规则

游戏使用固定角度镜头：

```text
Camera 跟随角色
Camera 角度固定
Camera 不允许玩家自由旋转
Camera 可以轻微缩放、震屏、跟随、镜头反馈
```

推荐镜头：

```text
正交相机 Orthographic 或低透视 Perspective
朝向固定
略微俯视地面
能看到 X-Z 平面上的角色走位
```

---

### 3.2 2D 角色资源放在 3D 世界

角色资源可以用：

```text
SpriteRenderer
Mesh Quad + 材质
Animator 播放 Sprite 序列帧
```

角色根节点在 3D 世界中：

```text
CharacterRoot.position = (x, y, z)
```

推荐结构：

```text
CharacterRoot
├── VisualRoot
│   ├── SpriteRenderer
│   └── VFXAttachPoints
├── ShadowRoot
├── ColliderRoot
├── HitBoxRoot
├── HurtBoxRoot
├── HUDAnchor
└── AudioRoot
```

---

### 3.3 角色 Sprite 朝向

角色只需要制作右向序列帧：

```text
Right 动画
Left = Right 镜像 FlipX
```

朝向规则：

```text
按 D / X 正方向：Facing = Right
按 A / X 负方向：Facing = Left
只按 W / S：保持上一次 Facing
```

因为这是 DNF 式横版清版：

```text
攻击朝向主要看 X 轴左右
Z 轴移动只是调整站位
```

---

### 3.4 Sprite 是否跟随镜头

推荐：

```text
Sprite 始终面向 Camera，或使用固定角度 Billboard。
```

但不要影响逻辑：

```text
Sprite 怎么转，是表现层
HitBox / HurtBox / BodyCollider 仍然在 3D 世界里按 X/Y/Z 判定
```

---

## 4. 角色根节点、脚底点与高度

### 4.1 角色逻辑根节点

角色位置以脚底中心为准：

```text
CharacterRoot.position = 脚底中心点
```

不要以 Sprite 中心点作为角色位置。

原因：

```text
攻击范围从脚底点计算更稳定
地面贴合更准确
HUD 和阴影更好定位
跳跃高度更容易计算
```

---

### 4.2 关键挂点

每个角色配置需要这些挂点：

```text
FootPoint        脚底点
BodyCenter       身体中心
HeadPoint        头顶点
WeaponPoint      武器点
CastPoint        施法点
ProjectilePoint  投射物出生点
HUDPoint         头顶 HUD 点
ShadowPoint      阴影点
```

在 2D Sprite 中，可以用相对角色根节点的 3D 偏移配置：

```text
OffsetX
OffsetY
OffsetZ
```

示例：

```text
HUDPoint = (0, 2.2, 0)
WeaponPoint = (0.6, 1.0, 0)
ProjectilePoint = (0.8, 1.1, 0)
```

---

### 4.3 角色高度参数

角色必须配置真实逻辑高度：

```text
HeightY
BodyWidthX
BodyDepthZ
```

示例：

```text
狗侠客：
WidthX = 0.8
DepthZ = 0.5
HeightY = 1.6
```

老鼠小弟：

```text
WidthX = 0.55
DepthZ = 0.35
HeightY = 1.1
```

Boss：

```text
WidthX = 2.8
DepthZ = 1.6
HeightY = 3.2
```

这些数值用于：

```text
身体碰撞
受击框
技能命中
跳跃命中高度
头顶 HUD
阴影大小
```

---

## 5. 移动系统规则

### 5.1 移动是 3D 位移

移动最终改变的是：

```text
Position.x
Position.z
```

跳跃和击飞改变：

```text
Position.y
```

移动输入：

```text
Vector3 move = new Vector3(inputX, 0, inputZ)
```

斜向移动需要归一化：

```text
if move.magnitude > 1:
    move.Normalize()
```

---

### 5.2 横向与纵向速度

DNF 式清版里，Z 轴纵向移动通常比 X 轴横向移动慢一点。

推荐：

```text
MoveSpeedX = 4.5
MoveSpeedZ = 3.6
```

实际移动：

```text
Velocity.x = inputX * MoveSpeedX
Velocity.z = inputZ * MoveSpeedZ
```

---

### 5.3 朝向与移动分离

角色朝向不等于移动方向。

```text
A / D 改变朝向
W / S 不改变朝向
技能和普攻使用 Facing 决定攻击方向
```

示例：

```text
角色朝右
玩家按 W
角色向 Z 正方向移动
但仍然面向右
普攻仍然打右边
```

---

## 6. 跳跃系统规则

### 6.1 跳跃是 Y 轴高度变化

跳跃不再是 2D 动画里的“上移”，而是：

```text
CharacterRoot.position.y 增加
```

跳跃参数：

```text
JumpHeightY
JumpDuration
GravityY
AirMoveRateX
AirMoveRateZ
```

---

### 6.2 跳跃状态

```text
Grounded
JumpStart
Rising
Airborne
Falling
Landing
```

实际位置：

```text
Position.y = GroundY + JumpOffsetY
```

当：

```text
JumpOffsetY <= 0
```

落地。

---

### 6.3 跳跃中的命中高度

每个攻击需要配置高度层：

```text
Low
Middle
High
Air
All
```

目标受击框也有高度区间：

```text
MinY
MaxY
```

判断时用 3D 体积重叠：

```text
HitBoxVolume intersects HurtBoxVolume
```

跳起来后，角色 HurtBox 的 Y 范围会上移。

---

### 6.4 低段攻击躲避

低段攻击的 HitBox 高度通常是：

```text
MinY = 0
MaxY = 0.45
```

角色跳跃后：

```text
HurtBox MinY > 0.45
```

则低段攻击打不到。

这不是写死“跳跃无敌”，而是通过 Y 轴空间自然判定。

---

## 7. 碰撞判定总规则

### 7.1 所有碰撞都是 3D 体积

游戏中所有判定都不能再只用二维矩形。

必须使用 3D 体积：

```text
Box3D
Sphere
Capsule
Cylinder
Sector3D
ProjectileVolume
```

第一版推荐：

```text
Box3D
Capsule
Sphere
Cylinder
```

---

### 7.2 3D 判定包含三个维度

每个判定框必须有：

```text
WidthX   宽度，左右范围
HeightY  高度，上下范围
DepthZ   深度，前后范围
OffsetX
OffsetY
OffsetZ
```

也就是：

```text
长宽高 + 三轴偏移
```

---

### 7.3 常见框类型

| 框 | 用途 |
|---|---|
| BodyBox3D | 身体阻挡框 |
| HurtBox3D | 受击框 |
| HitBox3D | 伤害框 |
| InteractBox3D | 交互框 |
| PickupBox3D | 拾取范围 |
| GroundBox3D | 地面接触 |
| SensorBox3D | AI 感知范围 |

---

## 8. BodyBox 角色阻挡框

### 8.1 BodyBox 用途

BodyBox 用于：

```text
角色与地图墙体阻挡
角色与敌人挤压
Boss 阻挡
防止单位完全重叠
```

BodyBox 是 3D 框：

```text
Center = CharacterRoot.position + Offset
Size = (WidthX, HeightY, DepthZ)
```

---

### 8.2 BodyBox 配置字段

```text
Shape: Box / Capsule
OffsetX
OffsetY
OffsetZ
WidthX
HeightY
DepthZ
Radius
CanPushOthers
CanBePushed
PushPriority
BlockMap
BlockUnit
```

---

## 9. HurtBox 受击框

### 9.1 HurtBox 是 3D 体积

受击框必须包含高度。

示例：

```text
HurtBox:
OffsetX = 0
OffsetY = 0.9
OffsetZ = 0
WidthX = 0.8
HeightY = 1.6
DepthZ = 0.45
```

它覆盖角色从脚到头的受击范围。

---

### 9.2 多段 HurtBox

为了支持跳跃、倒地、头部判定，可以分多个：

```text
BodyHurtBox
HeadHurtBox
LowHurtBox
AirHurtBox
DownHurtBox
```

第一版可以先做：

```text
MainHurtBox
```

但数据结构必须支持多个。

---

### 9.3 每帧 HurtBox

不同动画帧可以使用不同受击框：

```text
Idle：正常站立受击框
Move：正常受击框
Jump：受击框整体上移
Dash：部分帧关闭或缩小
Attack：身体前倾，受击框向前偏一点
Down：受击框变低，HeightY 降低
```

---

## 10. HitBox 伤害框

### 10.1 HitBox 是 3D 伤害体积

普攻、技能、投射物都用 3D HitBox。

普攻横斩示例：

```text
Shape = Box
OffsetX = 0.9
OffsetY = 0.8
OffsetZ = 0
WidthX = 1.4
HeightY = 1.0
DepthZ = 0.7
```

意思：

```text
向右前方打 1.4 宽
覆盖 1.0 高度
覆盖前后深度 0.7
```

---

### 10.2 HitBox 跟随朝向

右向：

```text
OffsetX = +0.9
```

左向自动镜像：

```text
OffsetX = -0.9
```

Z 轴不镜像：

```text
OffsetZ 保持不变
```

除非技能本身是斜向或指定方向。

---

### 10.3 技能范围也必须有深度

例如剑气不是一条 2D 线，而是一个 3D 碰撞体：

```text
LengthX = 5.0
HeightY = 1.2
DepthZ = 0.8
```

火圈技能：

```text
RadiusXZ = 2.0
HeightY = 1.4
```

地面陷阱：

```text
RadiusXZ = 1.5
HeightY = 0.5
```

对空技能：

```text
HeightY = 3.0
```

---

## 12. 伤害帧配置规则

### 12.1 伤害帧仍然按序列帧时间

虽然判定是 3D，但动画还是 Sprite 序列帧。

一个动作配置：

```text
Animation Frames
Damage Events
HitBox3D Events
SFX Events
VFX Events
Cancel Windows
Movement Events
```

---

### 12.2 DamageEvent 结构

```text
DamageEventID
StartFrame
EndFrame
HitBox3DGroup
DamageType
ElementType
DamageRate
FixedDamage
HitHeight
CanHitGround
CanHitAir
CanHitDown
HitStun
KnockbackVector
LaunchVector
HitStop
CameraShake
```

重点：

```text
KnockbackVector 是 3D 向量
LaunchVector 包含 Y 轴
```

示例：

```text
KnockbackVector = (1.5, 0.2, 0)
LaunchVector = (0.8, 2.0, 0)
```

## 13. 击退、击飞、浮空规则

### 13.1 击退是 X/Z 平面的位移

普通击退：

```text
沿攻击方向 X 轴击退
可附带少量 Z 轴偏移
```

例如角色朝右攻击：

```text
Knockback = (1.2, 0, 0)
```

如果是爆炸：

```text
Knockback = 从爆炸中心指向目标的 XZ 方向
```

---

### 13.2 击飞包含 Y 轴

击飞必须有 Y 分量：

```text
LaunchVelocity = (X, Y, Z)
```

示例：

```text
向右上击飞：
(1.2, 4.5, 0)

原地挑飞：
(0.3, 5.2, 0)

斜向击飞：
(1.0, 4.0, 0.5)
```

---

### 13.3 倒地

倒地时角色仍然有 3D 位置：

```text
X/Z 可能滑动
Y 回到 GroundY
HurtBox 高度降低
```

倒地 HurtBox：

```text
HeightY = 0.4
OffsetY = 0.2
WidthX = 1.0
DepthZ = 0.6
```

部分攻击可以打倒地：

```text
CanHitDown = true
```

---

## 14. 投射物 3D 规则

### 14.1 投射物也是 3D 对象

投射物有：

```text
Position: Vector3
Direction: Vector3
Speed
HitBox3D
HeightY
DepthZ
```

剑气虽然看起来是 2D 图，但判定是：

```text
一个沿 X 轴飞行的 3D Box
```

---

### 14.2 投射物高度

不同投射物高度不同：

地面飞刀：

```text
Y = 0.8
HeightY = 0.5
```

中段剑气：

```text
Y = 1.0
HeightY = 1.2
```

对空法球：

```text
Y = 1.8
HeightY = 1.0
```

地面冲击波：

```text
Y = 0.2
HeightY = 0.4
```

## 15. 红圈 / 预警范围

### 15.1 预警显示在地面 XZ 平面

敌人技能预警要投影到地面：

```text
WarningDecal 放在 XZ 平面
Y = GroundY + 0.02
```

但真正技能伤害是 3D：

```text
WarningArea = XZ 显示范围
HitBox3D = X/Z 范围 + Y 高度
```

---

### 15.2 预警形状

```text
矩形预警：Box3D 的 XZ 投影
圆形预警：Cylinder 的 XZ 投影
扇形预警：Sector3D 的 XZ 投影
直线预警：长 Box 的 XZ 投影
```

---

### 15.3 跳跃躲预警

如果预警是低段地面攻击：

```text
HitBox HeightY 低
玩家跳起后 HurtBox 高于 HitBox
可以躲开
```

如果是全高度爆炸：

```text
HeightY 高
跳跃也会被命中
```

```text

```

## 17. 3D HitBox 编辑器规则

### 17.1 编辑方式

在编辑器里选择某一帧后，可以编辑：

```text
HitBox 的中心点
HitBox 的 X 宽度
HitBox 的 Y 高度
HitBox 的 Z 深度
```

支持：

```text
拖拽移动
拖拽缩放
数值输入
复制上一帧
复制到多帧
镜像预览
套用模板
```

---

### 17.2 颜色规则

```text
HitBox：红色半透明
HurtBox：绿色半透明
```

## 25. 常见错误规则

### 25.1 错误：只配 X/Y 伤害框

不允许。

必须有：

```text
SizeX
SizeY
SizeZ
```

---

### 25.2 错误：把 W/S 当成 Y 轴

不允许。

正确：

```text
W/S = Z 轴移动
Jump = Y 轴移动
```

---

### 25.3 错误：跳跃只是播放动画

不允许。

正确：

```text
跳跃必须改变角色逻辑 Y 高度
否则无法实现低段攻击躲避
```

---

### 25.4 错误：红圈就是真实判定

不完整。

正确：

```text
红圈是 XZ 地面投影
真实判定还需要 Y 高度
```

---

### 25.5 错误：Sprite 缩放等于角色碰撞

不允许。

正确：

```text
Sprite 是表现
Collider3D 是逻辑
二者可以不同，但必须配置对齐关系
```

## 32. 最终标准

这套系统的最终标准是：

```text
看起来像 2D 角色
玩起来像 DNF 式横版动作
底层是 Unity 3D 运动和 3D 碰撞
```

所有配置必须围绕：

```text
X = 横向
Z = 纵向 / 深度
Y = 高度
```

所有攻击必须围绕：

```text
伤害框有宽度 X
伤害框有高度 Y
伤害框有深度 Z
```

所有跳跃必须围绕：

```text
跳跃改变 Y
低段攻击靠 Y 高度躲避
全高度攻击不能靠跳跃躲避
```

一句话：

```text
这是 3D 游戏逻辑，不是 2D 游戏逻辑；只是角色和特效资源用 2D 序列帧表现。
```
