# 角色多段投射物配置规则

## 目标

角色配置工具中的技能投射物统一使用多段投射物列表。每个技能可以配置多个投射物段，每段可以单独决定生成帧、数量、布局、目标选取、飞行方式、碰撞、爆炸、伤害和表现。

## 数据入口

- 唯一入口：`CharacterSkillEntryDefinition.Projectiles`
- `CharacterSkillEntryDefinition.Projectile` 旧单段入口已删除，运行时、工具、校验和导出不再读取旧字段。
- 每段投射物需要勾选 `Enabled` 才会参与运行时发射。

## 单段投射物规则

- 基础：`ProjectileId`、`DisplayName`、`Prefab`、`Sprite`。
- 生成：`SpawnFrame`、`DelayFrames`、`RepeatCount`、`RepeatIntervalFrames`、`SpawnAttachPoint`、`SpawnAttachPointId`、`SpawnOffsetX/Y/Z`。
- 目标：角色前方、目标方向、最近敌人、锁定目标、输入方向、鼠标点、固定世界方向。
- 数量布局：单发、扇形、并列、纵列、圆形、随机散射。
- 飞行：直线、抛物线、追踪、加速、减速、静止。
- 碰撞：命中半径、逻辑高度、穿透敌人、命中销毁、碰墙销毁、最大距离销毁、重复命中同一目标。
- 爆炸：命中爆炸、到期爆炸、碰墙爆炸、爆炸半径、爆炸伤害倍率。
- 伤害：使用技能基础伤害、固定伤害、伤害倍率、伤害类型、元素类型、攻击/法术倍率。
- 冲击：每段投射物有独立 `Impact`，可以配置硬直、击退、击飞、方向和击杀倍率。
- 表现：`ImpactVfx` 和 `ExplosionVfx` 使用统一 `CharacterVfxDefinition`，支持 Prefab 或序列帧；旧 `ImpactVfxPrefab` / `ExplosionVfxPrefab` 保留兼容。

## 运行时规则

- 玩家技能释放命中帧时，`PlayerSkillController` 调用 `CharacterProjectileEmitter2D`。
- `CharacterProjectileEmitter2D` 读取当前技能条目的所有启用投射物段。
- 投射物数量会叠加角色属性 `ProjectileCountBonus`。
- 投射物速度会乘角色属性 `ProjectileSpeedMultiplier`。
- 投射物基础伤害会乘角色属性 `SkillDamageMultiplier`。
- 投射物碰撞仍使用 3D 逻辑体积判定，XZ 为地面平面，Y 为高度。
- `Projectile2D` 命中时播放 `ImpactVfx`，爆炸时播放 `ExplosionVfx`；新字段为空时回退旧 Prefab 字段。

## 编辑器规则

- 角色配置工具的技能页显示“投射物配置”。
- 新内容必须添加到“多段投射物配置”。
- 旧单段投射物配置面板已移除。
- 校验器会提示负数、无资源、穿透与命中销毁冲突、追踪目标模式不合理、爆炸半径为 0、固定伤害缺失等问题。
- 投射物编辑面板必须按当前选项条件显示字段，避免把所有高级参数一次性铺开。
- 目标为固定世界方向时才显示固定 XZ 方向；目标需要锁定/搜索时才显示锁定目标和搜索半径。
- 旧方向兼容字段只在“角色前方”目标模式下显示；自定义角度只在兼容方向选择自定义角度时显示。
- 投射物数量大于 1 时才显示散布布局参数；扇形只显示角度，并列只显示间距，纵列只显示纵列间距，圆形只显示半径，随机散射只显示散射角。
- 静止投射物不显示速度和最大距离；加速/减速才显示加速度；抛物线才显示抛物线高度；追踪才显示追踪强度、转向速度和重新选目标间隔。
- 勾选穿透敌人后才显示穿透数量；未穿透时显示命中销毁。
- 勾选重复命中后才显示同目标命中间隔。
- 任意爆炸开关开启后才显示爆炸半径和爆炸伤害倍率。
- 使用技能基础伤害时隐藏固定伤害，避免策划误以为两套基础伤害会同时生效。

## 后续注意

- `SpawnFrame`、`DelayFrames` 和重复间隔字段已经进入数据结构；当前 MVP 在技能释放点统一发射，后续如果要完全逐帧触发，应接入动作帧事件调度。
- 墙壁碰撞销毁字段已进入配置；当前投射物主要完成敌人命中、穿透、爆炸和距离/时间销毁，墙体阻挡需要继续接入地形阻挡层。

## 投射物 3D 命中修正

- `Projectile2D` 在源单位使用真实 3D 根节点移动时，投射物移动、最大距离、爆炸中心和命中扫描统一使用 XZ 逻辑平面，不再把世界 Y 当成地面坐标。
- 投射物命中仍保留旧 `Physics2D.OverlapCircle` 兼容路径，同时追加 `CombatHitVolume3DUtility.CollectDamageablesInPlanarCircle` 逻辑扫描，最终命中必须通过 `SphereHitsTarget` 的 3D 体积校验。
- 最近目标 / 锁定目标搜索增加逻辑平面兜底扫描，避免敌人根节点、血量组件、碰撞体不在同一层级或旧 2D 查询平面不一致时找不到目标。
- 命中层过滤兼容目标自身、父节点和直接子节点层级，但仍会排除来源对象及其父子层级，避免打到自己。
- 投射物命中后可以通过每段投射物的 `ApplyBuffsOnHit` 给敌人施加 Buff，爆炸伤害继续走范围伤害入口。
