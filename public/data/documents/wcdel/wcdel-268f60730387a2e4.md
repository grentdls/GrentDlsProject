# Chinese Default Localization And Language Toggle

## Goal

让项目当前的主界面、战斗内界面、后台菜单、交互提示和主要工具入口统一改为中文默认，并提供最小可运行的中英切换能力。

## Scope

- 新增轻量运行时本地化服务：
  - `Assets/Game/Runtime/Localization/GameLanguage.cs`
  - `Assets/Game/Runtime/Localization/LocalizationService.cs`
- 默认语言改为简体中文，并通过 `PlayerPrefs` 保存语言设置。
- 支持切换为英文。
- 主界面 `MainMenuCanvasPresenter` 接入本地化，并在设置页支持语言切换。
- 后台菜单 `BackendMenuCanvasPresenter` 接入本地化，并在设置页提供语言切换入口。
- 战斗 HUD、交互弹窗、传送、Boss 入口、宝箱/NPC/采集等核心运行时文本切换为中文默认出口。
- 存档默认命名切换为中文。
- UI 预制体生成器默认标签切换为中文。
- 常用编辑器菜单、弹窗、校验窗口、角色配置工具入口切换为中文。
- 第一章内容生成器与角色配置样例的主要显示名、描述、动作名、技能名切换为中文。

## Current Behavior

- 启动后默认显示简体中文。
- 后台菜单设置页可直接切换为英文，切换后立即刷新界面文本。
- 主界面设置页也可以直接切换语言。
- 即使旧 prefab 还没重建，主界面、后台菜单和部分 HUD 也会在运行时强制刷新成当前语言文本。
- 重新生成 UI prefab 后，按钮、页签、默认页标题等资产默认文本会直接使用中文。

## Boundaries

- 当前是轻量字典式本地化，不是完整表驱动、多语言资源包方案。
- 英文文本目前主要依赖原有 fallback 文案，覆盖重点是主界面、后台菜单和核心交互。
- 不是所有编辑器工具内部的深层说明都已全部翻译，本轮优先处理常用入口、标题、按钮和弹窗。
- 已经存在的旧 ScriptableObject / prefab 资产，如带有旧英文默认值，需要重新执行生成器或在 Unity 中保存资源后，才能把资产内容完整刷新为中文。
