# 装备、武器、首饰内容与套装逻辑设计文档
> 项目类型：固定视角 3D 世界 + 2D 序列帧角色表现  
> 战斗类型：DNF 式横版清版动作 RPG  
> 当前目标：建立第一批大量装备内容，包含部位定位、属性规则、套装逻辑、单件装备和每个部位 20 个配置内容。
---

## 1. 装备系统设计目标

装备系统要服务于成长、流派构筑、掉落追求和关卡推进。装备不能只是简单堆数值，而要让玩家能形成攻速连击、暴击爆发、技能范围、元素伤害、异常伤害、破甲重击、生存护盾、探索收益等不同玩法。
```text
1. 每个部位有明确属性定位。
2. 套装改变玩法，不只是加攻击。
3. 单件装备也要有独立价值，方便混搭。
4. 同一套装跨多个部位出现，玩家可以自由搭配。
5. 神话/专属装备数量少，主要作为后期目标。
6. 触发类效果必须有内置冷却，避免无限循环。
```

## 4. 完整套装逻辑

### 4.1 套装件数规则

```text
套装由任意部位组成。
玩家穿戴同一 SetID 的不同部位时，激活 2 / 4 / 6 件效果。
主角专属套可以额外做 8 件效果。
同一部位只能贡献 1 件套装计数。
重复同名装备不重复计数。
```

### 4.2 套装计算顺序

```text
1. 统计已装备部位。
2. 按 SetID 聚合同套装数量。
3. 激活小于等于当前数量的所有阈值效果。
4. 先计算装备基础属性。
5. 再计算百分比属性。
6. 最后注册触发类效果。
```

### 4.3 套装叠加规则

```text
同一套装 2/4/6 件效果同时生效。
不同套装效果可以共存。
同类型百分比加成默认加算。
特殊触发效果必须配置内置冷却 ICD。
异常爆发、雷云、燃爆、幻影等自动触发效果不能相互无限触发。
```

### 4.4 混搭示例

```text
4 件赤焰 + 2 件影牙：火伤核心 + 暴击补强。
2 件破甲 + 2 件雷鸣 + 2 件疾风：穿甲、攻速、连击兼顾。
4 件玄铁 + 2 件寒月：生存与冷却。
6 件异常伤害：多异常持续伤害流。
```

## 10. 平衡规则

```text
同等级同品质装备总价值接近。
输出装备牺牲生存。
生存装备牺牲爆发。
技能范围装备不能同时给过高伤害。
攻速、冷却、暴击、移速必须设置软上限。
触发类效果必须有内置冷却。
套装 6 件效果要明显改变流派，但不能完全碾压 4+2 混搭。
```

## 12. 总结

这批装备内容的核心逻辑是：

```text
武器决定输出方向。
防具决定生存和操作手感。
首饰决定技能、元素和特殊机制。
套装决定核心流派。
单件装备提供混搭价值。
```

后续新增装备时，只要遵守部位定位和套装逻辑，就不会出现属性混乱、装备无差异、套装没有目标的问题。
