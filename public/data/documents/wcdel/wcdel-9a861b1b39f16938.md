# Combat System Foundation Sync

## 目标

将当前原型中的简化战斗逻辑，同步到《战斗系统详细设计文档》的 MVP 骨架上。

本次重点是补“统一战斗底层”，不是一次性实现全部表现层。

## 本次范围

### 统一战斗数据

- 战斗阵营
- 伤害事件
- 基础战斗属性
- 伤害解析器

### 统一伤害链

- 区分物理 / 魔法 / 环境等伤害类型
- 支持元素类型
- 支持暴击
- 支持护甲减伤
- 支持轻量等级修正

### 原型敌人

- 加入攻击预警时间窗口
- 攻击通过统一伤害链打到玩家

## 本次不做

- 完整状态效果系统
- 掉落系统
- 伤害数字
- 暂停帧与震屏
- Boss 阶段系统

## 下一步建议

1. 接受击击退与硬直
2. 接伤害数字与简单战斗反馈
3. 接状态效果骨架
4. 接掉落与拾取
