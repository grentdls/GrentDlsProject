# Enemy Animation Prompt Pack And Production Matrix

## Goal

Turn the previously defined enemy animation rules into two directly usable deliverables:

- a ready-to-use AI prompt pack for the current enemy roster
- a full production matrix for all enemy animation sets

This document is meant to reduce prompt rewriting and help the team batch-produce action strips in a predictable order.

## Current Enemy Roster

Core chapter enemies:

- `MeadowSlime`
- `CaveBat`
- `PoisonBee`
- `BeeCaptain`
- `HiveGuardian`

Internal combat-style references:

- `MouseBandit`
- `JackalEnemy`

## Shared Generation Preset

Use this preset before every action prompt.

### Universal Generation Rules

- generate one horizontal strip for one action only
- transparent background
- same character, same facing direction, same silhouette, same costume, same scars, same ornaments, same palette
- consistent bottom-center anchor
- no environment, no text, no labels, no UI
- no extra props beyond the character's own weapon or gear
- painterly 2D game sprite style
- readable contour at gameplay scale
- strong pose clarity, one dominant action read per frame

### Default Canvas Recommendation

- `MeadowSlime`: `256x256`
- `CaveBat`: `256x256`
- `PoisonBee`: `256x256`
- `BeeCaptain`: `256x256`
- `HiveGuardian`: `512x512`
- future wolf / jackal humanoid elites: `512x512`

### Current Project Frame Counts

Base pack:

- `spawn`: 5 frames
- `idle`: 6 frames
- `move`: 8 frames
- `jump`: 4 frames
- `dash`: 4 frames
- `attack_01`: 6 frames
- `hit`: 3 frames
- `dead`: 5 frames

Advanced pack:

- `skill_leaf`: 6 frames

## Prompt Structure Rule

Every prompt should use four blocks in this order:

1. identity lock
2. output format
3. action name and frame count
4. motion rhythm

Recommended sentence structure:

```text
Generate one horizontal sprite strip for the same [enemy name], facing right, transparent background, [frame count] frames, each frame [size], consistent bottom-center anchor, same [identity features]. Painterly 2D game sprite style, no background, no text, no extra props. Action: [action name]. Motion rhythm: [frame-by-frame beats].
```

## Batch Production Order

Recommended order for the current project:

1. `PoisonBee`
2. `BeeCaptain`
3. `HiveGuardian`
4. `CaveBat`
5. `MeadowSlime`

Reason:

- `PoisonBee / BeeCaptain / HiveGuardian` benefit most from prompt standardization because they already use the advanced pack shape in runtime placeholders.
- `CaveBat` and `MeadowSlime` are easier follow-up conversions once the pipeline is stable.

## Suggested Next Step

When actual generation begins, use this process:

1. approve one seed frame per enemy
2. generate `idle`
3. generate `move`
4. generate `attack_01`
5. generate `hit`
6. generate `dead`
7. generate `spawn`
8. generate mobility actions
9. generate skill strips last

This sequence catches identity drift early and avoids wasting time on full packs before the character feels right.
