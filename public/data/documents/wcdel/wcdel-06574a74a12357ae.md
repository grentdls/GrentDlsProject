# Combat HUD MVP Sync

## 目标

把战斗界面从单纯的调试文本面板，升级到更接近正式 ARPG HUD 结构的最小可用层。

## 本次范围

### 屏幕 HUD

- 新增 `CombatHudPresenter`
- 拆出玩家左上状态卡、右下战斗技能簇、右上任务追踪和中央警告提示
- 保持低遮挡原则，不覆盖战斗中心与敌人红圈预警

### HUD 数据接口

- 新增 `CombatHudDataSource`
- 承接玩家血量、战斗状态、技能状态、翻滚状态和基础战斗属性
- 扩展 `PlayerSkillController`，暴露全局冷却与技能可用状态查询

### 世界空间血条

- 新增 `CombatWorldSpaceBar2D`
- 为玩家、训练假人、近战敌人和远程敌人提供轻量世界空间生命条
- 根据阵营和等级差异切换基础颜色，满足普通敌人与精英占位表现差异

### 原型场景验证

- 扩展 `Setup Starter Test Slice`
- 自动为玩家和战斗单位挂接 HUD 数据源与世界空间血条
- 自动启用新的 `CombatHUD`，同时隐藏旧的 `PrototypeHUD`

## 本次不做

- 正式 Canvas 预制体和图片资源
- 世界空间蓝条、Boss 顶部血条、Buff/Debuff 图标
- 技能升级、高亮锁定、蓝量不足等完整资源表现
- 正式移动端虚拟按键和手柄专用交互动效

## 后续建议

1. 把当前 IMGUI 原型 HUD 过渡到正式 Canvas 层，并拆成 `PlayerStatusCard`、`SkillCluster`、`QuestTracker` 等独立组件。
2. 为 `CombatWorldSpaceBar2D` 扩展蓝条、护盾层和 Boss 顶部血条占位。
3. 把 Buff/Debuff、低血提示、升级提示和奖励提示接入统一战斗 UI 事件派发层。
