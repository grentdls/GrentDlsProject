# 项目总览

## 项目定位

`WCDEL` 是一个使用 Unity 6 与 URP 2D 制作的 2D 俯视角轻量开放世界 ARPG。

当前参考方向不是直接复刻《猫咪斗恶龙 3》的内容，而是学习其设计节奏与系统结构，做一款原创、低压力、高反馈、适合 PC 与移动端的冒险游戏。当前默认原创题材示例为《小熊勇者大陆》。

## 当前开发目标

现阶段目标是完成项目基础搭建，给后续以下系统提供稳定骨架：

- 玩家移动、普攻、翻滚、交互、技能输入
- 战斗与敌人数据结构
- 地图区域、洞穴、任务、经济与存档的数据入口
- 主菜单、HUD、后台菜单的后续接入点
- Unity 工程目录、程序集与文档基线

## 核心设计支柱

- 地图上持续可见目标，鼓励短程探索
- 战斗强调可读性、翻滚规避与技能反馈
- 3 分钟内形成一次完整小循环
- 成长系统保持轻量，但允许装备与技能组合
- 失败惩罚低，鼓励持续推进

## 平台与输入

- 首发验证平台：PC
- 目标适配平台：移动端、手柄
- 输入系统：Unity Input System
- 渲染管线：Universal Render Pipeline 2D

## 当前工程状态

- Unity 版本：`6000.0.61f1`
- 已启用：`URP`、`2D`、`Input System`
- 当前仓库以 `docs/` 为规则文档目录
- 当前主要任务是从空白模板工程进入“可持续开发”的基础阶段

- 基础模块边界
- 通用数据定义
- 启动入口
- 玩家控制骨架
- 配置与后续扩展方式
- 文档与任务记录机制
