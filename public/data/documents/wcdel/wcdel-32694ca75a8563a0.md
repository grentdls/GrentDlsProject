# 屏幕抖动与镜头反馈系统设计文档

> 项目类型：2D 横版清版动作 RPG / DNF 式战斗  
> 模块范围：受击震屏、命中震屏、技能释放屏幕效果、Boss 强力技能屏幕效果  
> 使用目标：增强打击感、危险感、技能重量感，同时保证画面可读性，不影响玩家操作判断。

---

## 1. 设计目标

屏幕抖动不是“越大越爽”，而是要让玩家看懂战斗反馈。

本系统要解决 4 件事：

```text
1. 玩家被打时，立刻感受到危险和受击重量。
2. 玩家打中敌人时，感受到命中反馈和技能力度。
3. 技能释放时，通过镜头、闪光、慢动作、冲击波强化表现。
4. Boss 强力技能释放时，让玩家提前感到压迫，但不能遮挡红圈预警和操作信息。
```

核心原则：

```text
普通攻击小抖
重击明显抖
暴击和破甲有方向性冲击
玩家受击比敌人受击更明显
Boss 技能有预警镜头效果
绝技可以组合震屏、慢动作、色差、闪白、暗角
所有效果必须可调强度，必须支持关闭或降低
```

## 2. 镜头反馈分类

本项目屏幕效果分为 8 类：

| 类型 | 用途 | 示例 |
|---|---|---|
| ScreenShake | 屏幕抖动 | 普攻命中、玩家受击、Boss 砸地 |
| HitStop | 命中停顿 | 普攻命中、重击命中、暴击 |
| ScreenFlash | 屏幕闪光 | 暴击、爆炸、雷击 |
| ChromaticAberration | 色差冲击 | 绝技、Boss 大招、强力爆炸 |
| ZoomPulse | 镜头缩放脉冲 | Boss 登场、绝技释放 |
| SlowMotion | 短慢动作 | 斩杀、Boss 破防、绝技命中 |
| DirectionalImpulse | 方向性冲击 | 从左打到右、被击退 |
| Vignette / Darken | 暗角 / 压迫感 | Boss 蓄力、大招预警、低血 |

## 3. 屏幕抖动基础参数

每一次震屏由一组参数控制：

| 参数 | 说明 |
|---|---|
| ShakeID | 震屏配置 ID |
| Intensity | 抖动强度 |
| Duration | 持续时间 |
| Frequency | 抖动频率 |
| DirectionMode | 方向模式 |
| Direction | 抖动方向 |
| DecayCurve | 衰减曲线 |
| RotationalShake | 是否有旋转抖动 |
| ZoomShake | 是否有缩放抖动 |
| Priority | 优先级 |
| StackMode | 叠加方式 |
| MaxOffset | 最大位移限制 |
| IgnoreUserSetting | 是否无视玩家设置，默认否 |

### 3.1 强度分级

| 等级 | Intensity | 用途 |
|---|---:|---|
| Tiny | 0.05~0.10 | 小 DoT、轻微命中 |
| Small | 0.12~0.22 | 普攻命中、小怪受击 |
| Medium | 0.25~0.45 | 重击、玩家受击、技能命中 |
| Heavy | 0.50~0.80 | 暴击、破甲、Boss 小技能 |
| Massive | 0.90~1.30 | Boss 大招、绝技爆发 |
| Extreme | 1.40+ | 剧情级冲击，慎用 |

### 3.2 持续时间分级

| 类型 | Duration |
|---|---:|
| 极短 | 0.04~0.08s |
| 短 | 0.10~0.18s |
| 中 | 0.20~0.35s |
| 长 | 0.40~0.70s |
| 超长 | 0.80s+，仅 Boss / 剧情使用 |

### 3.3 方向模式

```text
Random      随机抖动，适合爆炸和通用震动
Horizontal  水平抖动，适合横向斩击和击退
Vertical    垂直抖动，适合砸地、落地、震荡波
Directional 按攻击方向抖动，适合被击退和突进命中
Radial      从爆炸中心向外冲击，适合范围爆炸
```

### 3.4 衰减曲线

```text
InstantDecay    瞬间强，快速消失，适合普攻
EaseOut         前强后弱，通用
Punch           先猛冲一下再回弹，适合重击
Rumble          持续震动，适合 Boss 蓄力和地震
Wave            波浪式强弱变化，适合魔法技能
```

## 4. 屏幕抖动优先级与叠加规则

### 4.1 优先级

从高到低：

```text
Boss 大招 > 玩家受重击 > 绝技命中 > 玩家死亡 > Boss 登场 > 暴击/破甲 > 普通技能命中 > 普攻命中 > DoT
```

### 4.2 叠加规则

不能无限叠加，否则镜头会疯。

```text
低强度震屏可以被高强度覆盖。
同一时间最多允许 2 个震屏源叠加。
如果新震屏强度低于当前震屏 50%，则忽略。
Boss 大招震屏会覆盖普通命中震屏。
玩家受击震屏优先于玩家命中震屏。
```

### 4.3 冷却规则

防止多段技能让屏幕一直抖：

```text
普通命中震屏：同一攻击者 0.08s 内只触发一次
DoT 震屏：默认不触发，或 0.5s 触发一次极小震动
多段技能：只在关键段触发中强度震屏，其余段用小震动
Boss 地震类技能：允许持续震动，但强度必须可控
```

## 5. 命中震屏规则

命中震屏是玩家打中敌人时的反馈。

### 5.1 普攻命中

| 攻击 | 震屏 | 命中停顿 | 说明 |
|---|---:|---:|---|
| 普攻 1 | Small 0.12 / 0.06s | 0.025s | 轻快 |
| 普攻 2 | Small 0.18 / 0.08s | 0.035s | 稍重 |
| 普攻 3 | Medium 0.32 / 0.12s | 0.05s | 收尾重击 |

表现规则：

```text
普攻 1 只做轻微水平抖动。
普攻 2 水平抖动略强。
普攻 3 使用 Punch 衰减，带轻微垂直回弹。
如果普攻打空，不触发震屏，只播放挥空音效。
```

### 5.2 暴击命中

```text
震屏强度：Medium~Heavy
持续时间：0.12~0.20s
方向：按攻击方向 Directional
附加：短暂红金闪光，可选
命中停顿：普通命中的 1.3~1.6 倍
```

暴击震屏不能每一段都很大：

```text
小段多段暴击：只放大跳字，不加强震屏
单次高伤暴击：加强震屏
普攻 3 暴击：明显震屏
技能终段暴击：明显震屏
```

### 5.3 穿甲 / 破甲命中

```text
震屏强度：Medium
持续时间：0.14s
方向：水平 + 轻微旋转
附加：屏幕边缘短暂银橙裂纹闪
命中停顿：0.05~0.08s
```

视觉重点：

```text
不是爆炸感，而是“硬东西被打碎”的脆裂感。
震屏应短、锐、带一点横向切割。
```

### 5.4 弱点命中

```text
震屏强度：Heavy
持续时间：0.18~0.25s
附加：金色弱点闪光 + 轻微 ZoomPulse
命中停顿：0.08~0.12s
```

### 5.5 斩杀 / 终结命中

```text
震屏强度：Heavy~Massive
持续时间：0.25~0.4s
附加：短慢动作 0.08~0.15s
附加：屏幕暗角后回亮
附加：大跳字和音效
```

普通小怪斩杀不要太夸张。精英和 Boss 斩杀才用完整效果。

## 6. 玩家受击震屏规则

玩家受击的屏幕反馈比敌人受击更重要，因为它承担危险提示。

### 6.1 轻受击

```text
强度：Small 0.18~0.25
时长：0.10~0.15s
方向：来自攻击方向的反向冲击
附加：轻微红色边缘闪
```

用途：

```text
小怪普攻
低伤投射物
轻微碰撞伤害
```

### 6.2 重受击

```text
强度：Medium 0.35~0.55
时长：0.18~0.28s
方向：Directional
附加：红色屏幕边缘闪
附加：短 HitStop 0.03~0.06s
附加：手柄震动，可选
```

用途：

```text
精英怪重击
Boss 普通技能
被击飞前的重打击
```

### 6.3 被击飞 / 倒地

```text
击飞瞬间：Medium 震屏 0.18s
落地瞬间：Medium~Heavy 垂直震屏 0.18s
倒地：屏幕轻微下沉感
起身：不震屏，只给白色保护闪
```

### 6.4 玩家低血受击

当玩家 HP < 30%：

```text
受击屏幕红闪更明显
暗角加重
心跳音效可触发
震屏强度不额外加太大，避免影响操作
```

低血时不要持续强抖，容易让玩家看不清。

### 6.5 玩家死亡

```text
震屏：Heavy 0.4s
慢动作：0.2~0.35s
屏幕暗角：逐渐加深
颜色：轻微降饱和
音效：低沉冲击
```

## 7. 技能释放屏幕效果

技能释放不能都震很大，要按技能类型分。

### 7.1 小技能

适合：小剑气、小火球、小位移斩。

```text
释放时：不震或 Tiny 0.05
命中时：Small~Medium
屏幕闪光：无或局部特效
Zoom：无
```

### 7.2 中技能

适合：范围斩、冲锋、爆炸、旋风。

```text
释放瞬间：Small 0.1s
命中关键帧：Medium 0.15~0.25s
如果是爆炸：Radial 震屏
如果是斩击：Directional 震屏
```

### 7.3 大技能

适合：职业核心技能、大范围法术、蓄力重击。

```text
蓄力开始：轻微暗角 / 聚焦
释放瞬间：Medium~Heavy 震屏
命中瞬间：Heavy 震屏
附加：短 ScreenFlash
附加：轻微 ChromaticAberration
附加：命中停顿 0.08~0.12s
```

### 7.4 绝技

绝技可以组合多个屏幕效果，但要分阶段：

```text
1. 起手阶段：镜头轻微拉近，暗角，时间微慢
2. 蓄力阶段：低频 Rumble，能量聚集
3. 释放瞬间：强 ScreenFlash + Heavy 震屏
4. 命中阶段：HitStop + Massive 震屏 + 色差
5. 收尾阶段：镜头回正，暗角消失
```

绝技参数建议：

```text
起手 ZoomPulse：1.00 → 0.94 → 1.00，0.25s
蓄力震动：Intensity 0.12，持续 0.5~1.0s
释放震动：Intensity 0.8~1.1，持续 0.25s
命中停顿：0.08~0.15s
色差：0.1~0.2s
闪白：0.04~0.08s
```

## 8. 技能类型对应镜头反馈

### 8.1 斩击类

```text
方向：跟随斩击方向
抖动：横向或斜向
时间：短而锐
效果：刀光可比震屏更明显
```

示例：

```text
一字斩：Directional 0.25 / 0.10s
三连斩终段：Directional 0.4 / 0.14s
巨大剑气命中：Directional 0.55 / 0.18s + 色差 0.08s
```

### 8.2 砸地类

```text
方向：Vertical
抖动：上下强烈
时间：中等
效果：地面裂纹、尘土、血条抖动
```

示例：

```text
小砸地：Vertical 0.35 / 0.15s
重砸地：Vertical 0.65 / 0.25s
Boss 砸地：Vertical 1.0 / 0.45s + 持续余震
```

### 8.3 爆炸类

```text
方向：Radial / Random
抖动：强，但衰减快
效果：闪光、色差、冲击波
```

示例：

```text
小爆炸：0.35 / 0.16s
中爆炸：0.6 / 0.25s
大爆炸：1.0 / 0.4s + ScreenFlash
```

### 8.4 雷电类

```text
抖动：短促、高频
效果：瞬间闪白 / 黄闪 / 色差
```

```text
雷击：0.45 / 0.12s，Frequency 高
雷暴：0.75 / 0.28s，多段短抖
```

### 8.5 冰霜类

冰技能不适合强烈震屏，重点在冻结和慢感。

```text
抖动：小
效果：轻微蓝闪、屏幕边缘结霜、短暂停顿
```

```text
冰冻命中：0.2 / 0.10s + 0.05s HitStop
大冰爆：0.5 / 0.2s + 蓝白闪
```

### 8.6 毒 / 暗影类

毒不适合震屏，暗影可以做脉冲。

```text
毒：无震屏或 Tiny
暗影爆发：低频 Rumble + 暗角
```

### 8.7 治疗 / 护盾类

治疗不震屏，护盾破碎可震。

```text
治疗：无震屏，使用柔和亮光
护盾生成：轻微 ZoomPulse
护盾破碎：Medium 0.18s + 蓝白碎裂
```

## 9. Boss 技能屏幕效果

Boss 屏幕效果要服务于“危险预警”。不能把红圈、预警线和 Boss 动作盖住。

### 9.1 Boss 普通攻击

```text
普通爪击 / 横扫：Small~Medium
命中玩家：Medium
打空：不震或 Tiny
```

### 9.2 Boss 蓄力技能

蓄力阶段：

```text
镜头轻微拉近
屏幕暗角加深
低频小震 0.08~0.15
地面预警必须保持最高可读性
Boss 身上特效增强
```

释放阶段：

```text
强震屏
屏幕闪光
短色差
音效重击
```

### 9.3 Boss 砸地大招

```text
蓄力 1：暗角 0.3s
蓄力 2：低频 Rumble 0.4~1.0s
落地瞬间：Vertical Massive 1.0~1.3 / 0.45s
余震：小幅 Rumble 0.4s
地面冲击波：视觉主导
```

### 9.4 Boss 全屏大招

```text
预警阶段：镜头拉远一点，保证玩家看到安全区
蓄力阶段：低频震动 + 暗角
释放阶段：强闪光 + Massive 震屏
命中玩家：重受击震屏叠加，但限制最大强度
收尾阶段：镜头恢复，余震衰减
```

注意：

```text
全屏大招预警期间，不允许强色差和强闪白遮挡安全区。
预警图形优先级最高。
```

### 9.5 Boss 登场

```text
镜头轻微拉近 Boss
屏幕暗角
低频震动 0.3s
Boss 名称出现时可加一次 Punch 震屏
```

### 9.6 Boss 进入二阶段

```text
短慢动作 0.15s
Boss 怒吼震屏 Heavy 0.35s
血条阶段锁变化
屏幕边缘出现对应元素色
```

### 9.7 Boss 破防

```text
镜头快速 Punch
震屏 Medium~Heavy
Boss 身上破防特效
短 HitStop
玩家获得输出窗口，不要让震屏太久
```

## 10. 屏幕效果组合规则

### 10.1 组合上限

同一时间最多允许：

```text
1 个主震屏
1 个副震屏
1 个 ScreenFlash
1 个 ColorEffect
1 个 ZoomPulse
1 个 SlowMotion
```

如果 Boss 大招和玩家暴击同时触发：

```text
Boss 大招震屏优先
玩家暴击跳字保留
玩家暴击震屏降低或取消
```

### 10.2 最大位移限制

防止画面抖出边：

```text
普通最大偏移：8 px
中等最大偏移：16 px
强震最大偏移：28 px
Boss / 绝技最大偏移：36 px
极限不超过 48 px
```

移动端建议整体降低 20%。

### 10.3 红圈预警保护

当场上有危险预警时：

```text
不允许强闪白盖住预警超过 0.06s
不允许强暗角降低预警辨识度
不允许色差让预警边界模糊
不允许长时间强震影响玩家躲避
```

## 11. 命中停顿 HitStop 规则

HitStop 是提升打击感的关键，和震屏分开配置。

### 11.1 HitStop 类型

```text
AttackerOnly     只停攻击者
TargetOnly       只停目标
Both             攻击者和目标都停
World            小范围时间停顿，慎用
```

### 11.2 推荐数值

| 行为 | HitStop |
|---|---:|
| 普攻 1 命中 | 0.025s |
| 普攻 2 命中 | 0.035s |
| 普攻 3 命中 | 0.05s |
| 小技能命中 | 0.04s |
| 中技能命中 | 0.06s |
| 大技能命中 | 0.08s |
| 绝技关键命中 | 0.10~0.15s |
| Boss 重击命中玩家 | 0.06~0.10s |

### 11.3 多段技能 HitStop 限制

```text
多段技能不能每段都停很久。
普通多段每段最多 0.015~0.025s。
只在最后一段给重 HitStop。
```

## 12. 慢动作 SlowMotion 规则

慢动作只给关键时刻：

```text
Boss 登场
Boss 破防
Boss 二阶段
玩家绝技
玩家斩杀精英 / Boss
剧情攻击
```

### 12.1 参数

```text
TimeScale: 0.15~0.5
Duration: 0.08~0.35s
EaseIn: 0.02~0.05s
EaseOut: 0.05~0.12s
AffectUI: false
AffectInput: false 或 true，按需求
```

建议：

```text
UI 冷却不受慢动作影响，或单独处理。
玩家输入可以缓存，不要因为慢动作吞输入。
```

## 13. 屏幕闪光 ScreenFlash 规则

### 13.1 闪光类型

| 类型 | 用途 |
|---|---|
| WhiteFlash | 爆炸、绝技、强命中 |
| RedFlash | 玩家受伤、低血 |
| GoldFlash | 暴击、弱点、斩杀 |
| BlueFlash | 冰、护盾 |
| YellowFlash | 雷击 |
| DarkFlash | 暗影技能、Boss 压迫 |

### 13.2 闪光限制

```text
普通技能闪光透明度不超过 0.25
Boss 大招闪光透明度不超过 0.45
闪白持续不超过 0.08s
不能连续频繁闪白，保护视觉舒适
移动端默认降低闪光强度
```

---

## 14. 色差与后处理规则

色差适合强冲击，但不能滥用。

### 14.1 使用场景

```text
绝技释放
Boss 大招
大型爆炸
雷暴技能
空间撕裂类技能
```

### 14.2 参数建议

```text
普通技能：不用
中技能：0.05~0.08 强度，0.08s
大技能：0.10~0.18 强度，0.15s
```

### 15.1 使用场景


### 15.2 缩放方式

横版 2D 推荐用 Camera Orthographic Size：

```text
数值变小 = 镜头拉近
数值变大 = 镜头拉远
```

参数：

```text
轻微拉近：原尺寸 x 0.96
明显拉近：原尺寸 x 0.92
Boss 大招预警拉远：原尺寸 x 1.05~1.12
恢复时间：0.15~0.35s
```

### 15.3 注意

```text
战斗中不要频繁缩放。
Boss 全屏技能预警时优先拉远，保证安全区可见。
```

## 19. 运行时流程

### 19.1 玩家命中敌人

```text
攻击命中
→ DamageResult 生成
→ 判断是否暴击 / 穿甲 / 弱点
→ 触发对应 HitStop
→ 触发对应 ScreenShake
→ 触发跳字
→ 触发血条扣血表现
```

### 19.2 玩家被击中

```text
玩家 HurtBox 被命中
→ 计算伤害
→ 播放玩家受击动画
→ 触发 Player_Hit_Shake
→ 触发 RedFlash / 暗角
→ 更新玩家血条
→ 如果低血，触发低血 HUD 反馈
```

### 19.3 Boss 强技能

```text
Boss 进入蓄力动作
→ 触发 ChargeEffect：暗角 + 低频轻震 + 镜头拉远/拉近
→ 红圈预警显示，强制保持可读性
→ Boss 释放
→ 触发 Boss ImpactShake
→ 触发闪光 / 色差 / 震屏
→ 如果玩家被命中，再叠加玩家受击反馈，但限制最大强度
```

## 24. 验收标准

### 24.1 命中震屏验收

```text
普攻 1/2/3 的震屏力度有层次
普攻打空不震屏
暴击明显强于普通命中
穿甲有短促锐利感
多段技能不会抖到看不清
```

### 24.2 玩家受击验收

```text
玩家轻重受击震屏区别明显
玩家重击受伤有红闪和方向冲击
击飞落地有垂直震屏
低血时反馈明显但不影响操作
死亡有完整镜头反馈
```

### 24.3 技能验收

```text
小技能不过度震屏
中技能命中有明显反馈
大技能释放和命中分阶段表现
绝技有拉近、蓄力、冲击、收尾
技能慢动作不吞输入
```

### 24.4 Boss 验收

```text
Boss 蓄力阶段有压迫感
Boss 大招释放震屏足够强
全屏技能预警不被遮挡
Boss 二阶段和破防有镜头反馈
Boss 效果不会和普通命中震屏互相打架
```

### 24.5 可访问性验收

```text
关闭屏幕震动后不再抖动
降低闪光后不会强闪白
色差可以关闭
移动端性能稳定
玩家仍能通过音效、特效、预警判断危险
```

## 26. 总结

屏幕抖动系统的核心不是“抖”，而是让不同战斗事件拥有不同重量：

```text
打中敌人：爽
被敌人打中：危险
技能释放：有力量
Boss 蓄力：有压迫
Boss 大招：有毁灭感
绝技命中：有终结感
```

最终玩家应该不用看日志，只通过镜头反馈就能感受到：

```text
这是普通攻击。
这是重击。
这是暴击。
这是我被打疼了。
这是 Boss 要放大招了。
这是我的绝技命中了。
```
