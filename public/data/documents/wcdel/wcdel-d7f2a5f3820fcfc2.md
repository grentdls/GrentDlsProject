# 后台界面与菜单系统设计文档

> 项目类型：2D 俯视角开放世界轻 ARPG  
> 当前章节：后台界面、装备界面、技能更换界面、人物信息界面、设置界面、存档界面、系统菜单与其他非战斗界面  
> 前置章节：人物基础操作系统、战斗系统、地图交互系统、战斗 HUD 系统  
> 目标：定义玩家在非战斗状态下进行成长管理、装备调整、技能配置、系统设置、存档读取、返回退出等所有“后台操作”的 UI 结构与规则。

---

## 1. 后台界面设计目标

后台界面不是战斗 HUD，而是玩家整理成长、调整配置、查看目标、管理资源的地方。

本项目后台界面的核心目标：

```text
1. 操作简单，不做复杂 MMO 菜单
2. 界面层级浅，玩家 2~3 次点击内完成主要操作
3. 装备、技能、属性变化必须即时反馈
4. 背包和装备要适合移动端触控
5. 技能更换要清楚显示当前装配、冷却、消耗、效果
6. 设置界面要完整，但不压迫普通玩家
7. 存档、返回、退出等高风险操作必须二次确认
8. 战斗中打开菜单的规则要清楚
9. 所有界面都支持 PC、移动端、手柄
10. 美术风格保持轻量、圆润、可爱、低压力
```

后台界面的整体风格：

```text
浅色半透明面板
圆角
软阴影
大按钮
清晰图标
低文本密度
重点信息用颜色和图标表达
```

## 3. 后台界面打开规则

### 3.1 可打开状态

| 玩家状态 | 是否可打开后台 |
|---|---:|
| 大地图探索 | 是 |
| 城镇 | 是 |
| 洞穴普通区域 | 是 |
| 普通战斗中 | 可配置 |
| Boss 战中 | 建议限制 |
| 剧情中 | 否 |
| 对话中 | 否，或先关闭对话 |
| 死亡界面 | 否 |
| 结算界面 | 否 |
| 加载中 | 否 |

### 3.2 战斗中打开规则

推荐单机移动端：

```text
普通战斗中可以打开暂停菜单
打开后游戏暂停
可以查看角色、装备、技能
但不允许更换装备和技能，防止战斗中临时换装
```

Boss 战：

```text
可以打开暂停菜单
只能查看信息和设置
不能更换装备
不能更换技能
不能传送
不能保存
```

### 3.3 后台界面暂停规则

| 场景 | 打开后台后是否暂停 |
|---|---:|
| 单机大地图 | 是 |
| 单机洞穴 | 是 |
| 单机 Boss | 是 |
| 联机模式 | 否，仅打开个人菜单 |
| 城镇 | 可暂停或不暂停 |
| 主菜单 | 无需暂停 |

本项目如果先做单机，统一：

```text
打开后台菜单后游戏暂停
关闭后恢复
```

### 3.4 禁止操作提示

当某功能当前不可用时，不要隐藏到玩家完全找不到。  
可以置灰并提示原因。

例子：

```text
战斗中无法更换技能
Boss 战中无法保存
当前区域无法传送
剧情中无法打开菜单
```

## 4. 后台界面美术与交互规范

### 4.1 总体布局

推荐横屏 16:9 后台界面：

```text
┌──────────────────────────────────────────┐
│ 顶部：标题 / 当前金币 / 关闭按钮          │
├──────────────┬───────────────────────────┤
│ 左侧：功能页签 │ 右侧：当前页面内容          │
│ 角色         │                           │
│ 装备         │                           │
│ 技能         │                           │
│ 背包         │                           │
│ 任务         │                           │
│ 地图         │                           │
│ 设置         │                           │
└──────────────┴───────────────────────────┘
```

移动端可采用：

```text
顶部页签 + 主内容区
```

因为移动端左侧竖向页签可能占空间较大。

### 4.2 推荐后台布局

```text
顶部栏：
- 当前界面标题
- 玩家等级
- 金币
- 返回按钮
- 关闭按钮

左侧栏：
- 角色
- 装备
- 技能
- 背包
- 任务
- 地图
- 设置

内容区：
- 根据当前页显示具体内容

底部栏：
- 操作提示
- 快捷按钮
- 确认 / 取消
```

### 4.3 UI 风格

```text
大圆角面板
浅色背景
半透明浮层
彩色功能图标
按钮有轻微软塑料质感
选中页签有明显高亮
不可用项灰色但保持可读
重要变化用绿色/红色箭头提示
```

### 4.4 通用按钮状态

| 状态 | 表现 |
|---|---|
| Normal | 正常亮度 |
| Hover | 轻微放大 / 边框发光 |
| Pressed | 缩放 0.94 |
| Selected | 高亮底色 + 外圈 |
| Disabled | 灰色 + 降低透明 |
| New | 红点 / 星点 |
| Warning | 橙色边框 |
| Danger | 红色边框 |

### 4.5 关闭与返回

所有后台界面必须有：

```text
右上角 X 关闭
左上或底部返回
Esc / B 键返回
点击半透明背景不可直接关闭重要界面，可配置
```

导航规则：

```text
当前有二级弹窗 → 返回关闭弹窗
当前在二级页面 → 返回上一级
当前在一级菜单 → 返回游戏
```

## 5. 角色数值分栏

### 5.1 入口

```text
暂停菜单 → 装备 → 左侧下方“角色数值”
快捷键 C 直接打开装备页
左上状态卡点击，可选，建议也跳转到装备页
```

### 5.2 角色数值分栏目标

角色数值不再单独做一页，统一合并到装备界面下方，避免后台菜单层级过多。
该分栏用于让玩家在换装时同步了解：

```text
当前等级
当前经验
生命 / 魔法
攻击 / 魔法 / 护甲
暴击等战斗属性
当前装备带来的加成
当前 Buff / 永久能力
下一等级成长
```

### 5.3 页面结构

```text
装备页左侧上方：角色名 / 等级 / 战力
装备页左侧中间：角色形象与环绕装备槽
装备页左侧下方：角色数值分栏
装备页右侧：背包列表与详情对比
```

示意：

```text
┌─────────────────────────────────────────┐
│ 装备                             金币    │
├───────────────┬─────────────────────────┤
│ 角色立绘/模型   │ Lv 12 小熊勇者          │
│ 当前装备外观    │ 装备背包 / 详情 / 对比    │
│ 装备槽环绕      │                         │
│ 角色数值        │ ❤ 生命 340/340          │
│                │ ◆ 攻击 45   ✦ 法强 38    │
└───────────────┴─────────────────────────┘
```

### 5.4 基础属性

| 属性 | 显示规则 |
|---|---|
| 等级 | 大号显示 |
| 经验 | 进度条 + 当前 / 需求 |
| 生命 | 当前值 / 最大值 |
| 魔法 | 当前值 / 最大值 |
| 金币 | 顶部常显 |
| 当前区域等级 | 可选 |
| 当前主线进度 | 可选 |

### 5.5 战斗属性

| 属性 | 说明 |
|---|---|
| 攻击 | 影响普攻和物理技能 |
| 魔法 | 影响法术技能和治疗 |
| 护甲 | 减少受到的伤害 |
| 暴击率 | 触发暴击概率 |
| 暴击伤害 | 暴击倍率 |
| 移动速度 | 地图移动与战斗走位 |
| 技能冷却 | 冷却缩减 |
| 元素加成 | 对应元素伤害提高 |
| 状态抗性 | 减少负面效果 |
| 回血加成 | 治疗效果提升 |

MVP 建议只显示：

```text
生命
魔法
攻击
魔法强度
护甲
暴击率
移动速度
```

高级属性放到“详细属性”按钮里。

### 5.6 属性变化颜色

装备切换预览时：

```text
增加属性：绿色 + ↑
减少属性：红色 + ↓
不变属性：白色 / 灰色
```

例子：

```text
攻击 45 → 52  ↑ +7
护甲 20 → 15  ↓ -5
```

### 5.7 当前能力显示

显示已解锁的地图能力：

```text
水上移动
飞跃裂隙
火焰净化
破除封印
传送
二段翻滚，可选
```

每个能力显示：

```text
图标
名称
简短描述
解锁来源
```

### 5.8 角色数值表现规则

```text
每个数值前方必须有属性图标
MVP 阶段图标可使用色块占位
换装后属性必须立即刷新
属性区只承载查看，不再放跳转按钮
```

## 6. 装备界面

### 6.1 装备界面目标

装备界面用于：

```text
查看当前穿戴
查看背包装备
更换装备
比较属性
查看装备品质
查看装备来源
强化装备入口
分解 / 出售装备，可选
锁定装备，可选
```

### 6.2 装备槽位

MVP 装备槽位：

```text
武器
头部
身体
```

正式版可扩展：

```text
饰品 1
饰品 2
符文
宠物
外观
```

### 6.3 装备页面布局

推荐布局：

```text
┌──────────────────────────────────────────┐
│ 装备                              金币    │
├──────────────┬──────────────┬────────────┤
│ 当前穿戴      │ 装备背包      │ 装备详情    │
│ 武器          │ 筛选/排序      │ 名称        │
│ 头部          │ 装备列表      │ 品质        │
│ 身体          │              │ 属性        │
│ 饰品          │              │ 对比        │
│ 角色数值      │              │             │
└──────────────┴──────────────┴────────────┘
```

移动端可做左右滑页：

```text
左：当前穿戴
中：背包装备
右：详情对比
```

### 6.4 当前穿戴区

显示：

```text
角色形象
装备槽位
角色数值分栏
装备图标
装备等级
装备品质边框
装备是否可强化提示
```

角色数值分栏显示：

```text
生命 / 法力
攻击 / 法强 / 防御
暴击 / 暴伤 / 移速
技能范围 / 技能半径 / 技能威力
投射物数量与速度
```

每个属性前方显示一个属性图标。MVP 阶段允许使用不同颜色的小图块占位，正式版替换为资源图标。

槽位表现：

```text
武器槽：剑 / 法杖图标
头部槽：帽子图标
身体槽：护甲图标
饰品槽：戒指图标
```

空槽显示：

```text
未装备
灰色虚线边框
```

### 6.5 装备背包区

装备列表显示：

```text
装备图标
装备名称
装备等级
品质颜色
是否已穿戴
是否新获得
是否可强化
是否锁定
```

列表支持：

```text
按槽位筛选
按品质筛选
按等级排序
按获得时间排序
按攻击 / 魔法 / 护甲排序
```

MVP 筛选：

```text
全部
武器
头部
身体
```

### 6.6 装备详情区

装备详情显示：

```text
装备名称
装备品质
装备等级
装备槽位
主属性
副属性
装备描述
获取来源
强化按钮
装备按钮
锁定按钮，可选
出售 / 分解按钮，可选
```

示例：

```text
森林短剑 +3
稀有 / 武器

攻击 +18
暴击率 +4%

一把带有森林祝福的小剑。

[装备] [强化]
```

### 6.7 装备对比规则

当选择背包装备时，自动与同槽位当前装备对比。

显示：

```text
当前装备属性
新装备属性
变化值
```

示例：

```text
攻击：32 → 45  +13
魔法：12 → 8   -4
护甲：0 → 0
生命：20 → 0   -20
```

### 6.8 装备按钮状态

| 状态 | 表现 |
|---|---|
| 可装备 | 按钮亮 |
| 已装备 | 显示“已装备”，按钮不可点 |
| 等级不足 | 按钮灰，提示等级不足 |
| 职业不符，可选 | 按钮灰 |
| 战斗中不可换装 | 按钮灰，提示战斗中无法更换 |
| Boss 战不可换装 | 按钮灰 |

### 6.9 装备更换流程

```text
玩家选择背包装备
→ 详情区显示属性对比
→ 点击装备
→ 检查条件
→ 替换同槽位装备
→ 更新角色属性
→ 播放装备音效
→ 装备槽位闪光
→ 保存装备状态
```

### 6.10 装备卸下规则

可选设计：

```text
武器不可卸下，必须始终有武器
头部 / 身体可卸下
```

MVP 推荐：

```text
所有槽位都可以为空，但新手默认给基础装备
```

卸下后：

```text
装备回到背包
属性立即变化
角色外观变化，可选
```

### 6.11 装备强化入口

装备详情中显示：

```text
强化等级
下一级属性变化
强化消耗
强化按钮
```

如果强化系统在铁匠铺中完成：

```text
野外装备界面只显示“前往铁匠强化”
在铁匠铺界面才可强化
```

推荐规则：

```text
城镇 / 铁匠铺内可强化
野外只能查看
```

### 6.12 装备出售 / 分解规则

如果有出售：

```text
普通装备可出售
已装备不能出售
锁定装备不能出售
高品质装备出售需二次确认
```

如果有分解：

```text
分解获得强化材料
品质越高材料越多
已装备 / 锁定不可分解
史诗以上分解二次确认
```

MVP 可先不做出售和分解，减少复杂度。

### 6.13 装备锁定规则

正式版建议做装备锁定。

```text
点击锁图标
锁定装备
锁定后不能出售、分解、作为强化材料
再次点击解锁
```

## 7. 技能更换界面

### 7.1 技能界面目标

技能界面用于：

```text
查看已解锁技能
查看技能等级
查看技能效果
配置 4 个技能槽
升级技能
查看技能消耗和冷却
查看技能元素和类型
```

### 7.2 技能槽

玩家最多装备 4 个主动技能：

```text
技能槽 1
技能槽 2
技能槽 3
技能槽 4
```

每个槽对应：

```text
移动端技能按钮
PC 快捷键 Q/E/R/F 或 1/2/3/4
手柄 LT + 对应按键
```

### 7.3 技能界面布局

```text
┌──────────────────────────────────────────┐
│ 技能                              金币    │
├──────────────┬──────────────┬────────────┤
│ 当前技能槽    │ 技能列表      │ 技能详情    │
│ Slot 1        │ 火系          │ 名称        │
│ Slot 2        │ 雷系          │ 等级        │
│ Slot 3        │ 治疗          │ 消耗        │
│ Slot 4        │ 陷阱          │ 冷却        │
└──────────────┴──────────────┴────────────┘
```

移动端建议：

```text
顶部：当前 4 个技能槽
中间：技能列表
底部：技能详情 + 装配按钮
```

### 7.4 当前技能槽显示

每个技能槽显示：

```text
槽位编号
```




## 31. 设计关键点总结

后台界面最重要的是：

```text
1. 装备和技能是成长核心，必须好用
2. 属性变化必须即时、清楚、可信
3. 技能更换要和战斗 HUD 完全同步
4. 设置要完整，但默认值要足够好
5. 存档、删除、退出必须保护玩家
6. 战斗中哪些事能做、哪些不能做要规则清楚
7. 移动端按钮和列表必须大，不要做 PC 小字密集界面
8. 页面层级不要深，玩家不要迷路
9. 所有不可用状态都要告诉玩家原因
10. MVP 先完成角色、装备、技能、设置、存档，不要急着做图鉴和成就
```
