# 游戏内商店、交互与其他功能界面设计文档

> 项目类型：2D 俯视角开放世界轻 ARPG  
> 当前章节：商店界面、交互界面、NPC 对话、宝箱奖励、洞穴入口、传送点、神殿、铁匠铺、技能店、任务弹窗等游戏内相关界面  
> 前置章节：后台界面与菜单系统、地图地形结构与场景交互系统、战斗 HUD 系统  
> 目标：定义玩家在探索世界时触发的所有“场景内界面”和“功能弹窗”的交互规则、UI 布局、状态逻辑、数据联动与验收标准。

---

## 1. 本章节界面范围

本章节覆盖的界面不是主菜单、装备菜单、技能菜单那种完整后台页，而是玩家在游戏世界中靠近对象、点击对象、进入建筑或完成事件时触发的轻量界面。

包含：

```text
1. NPC 对话界面
2. 任务接取界面
3. 任务完成界面
4. 普通商店界面
5. 药水商店界面
6. 技能商店界面
7. 铁匠铺界面
8. 旅店 / 营地恢复界面
9. 神殿 / 祭坛界面
10. 传送点界面
11. 洞穴入口界面
12. Boss 入口确认界面
13. 宝箱奖励界面
14. 获得装备弹窗
15. 采集界面
16. 机关交互界面
17. 告示牌 / 读物界面
18. 快速交互提示
19. 错误提示 / 条件不足提示
20. 通用确认弹窗
21. 地图发现 / 区域发现提示
22. 解锁能力提示
23. 商店购买确认和出售确认
24. 对话选项界面
25. 特殊事件弹窗
```

这些界面的共同特点：

```text
出现频率高
停留时间短
信息量适中
要快速完成操作
不能让玩家迷路
不能破坏探索节奏
```

## 2. 游戏内交互界面设计目标

设计目标：

```text
1. 玩家靠近对象时立刻知道能不能交互
2. 交互按钮和对象反馈必须清楚
3. 轻量交互不进入复杂后台页面
4. 购买、强化、传送、进入洞穴等操作需要确认与条件检查
5. NPC 对话和任务信息要短，不要像小说面板
6. 商店界面要清楚显示价格、拥有数量、属性变化
7. 所有不可用操作必须说明原因
8. 交互界面必须支持移动端、PC、手柄
9. 战斗中禁用大部分非战斗交互
10. 界面风格与后台界面统一：圆角、明亮、轻量、可爱
```

核心体验：

```text
看到对象
→ 靠近出现提示
→ 点击交互
→ 出现轻量弹窗 / 功能界面
→ 完成操作
→ 返回游戏
```

## 3. 通用交互系统 UI

### 3.1 交互提示组成

玩家靠近可交互对象时，显示：

```text
世界空间图标
对象名称
交互动作
操作按钮提示
条件不足提示，可选
```

示例：

```text
[!] 村长
点击对话

[宝箱] 普通宝箱
点击打开

[洞穴] 绿叶洞穴 Lv8
点击进入

[锁] 被藤蔓挡住
需要火焰能力
```

### 3.2 交互提示位置

有两种显示方式：

#### 方案 A：对象头顶提示

```text
图标和文字显示在对象上方
优点：对象关系清楚
缺点：多个对象靠近时可能拥挤
```

#### 方案 B：屏幕固定交互按钮

```text
移动端右侧出现交互按钮
对象头顶只显示图标
优点：触控方便
缺点：需要明确当前交互目标
```

推荐组合：

```text
对象头顶显示图标
屏幕右侧显示交互按钮
交互按钮上显示当前目标名称和动作
```

### 3.3 移动端交互按钮

位置：

```text
右侧中下区域
靠近普攻按钮上方
不与技能按钮重叠
```

按钮内容：

```text
交互图标
动作文字
目标名称，可选
```

示例：

```text
[手掌] 对话
[宝箱] 打开
[门] 进入
[齿轮] 启动
```

### 3.4 PC 交互提示

显示：

```text
[E] 对话
[E] 打开宝箱
[E] 进入洞穴
[E] 启动机关
```

如果鼠标点击交互：

```text
鼠标悬停对象时高亮
左键点击执行交互
```

### 3.5 手柄交互提示

显示：

```text
[Y] 对话
[Y] 打开
[Y] 进入
```

### 3.6 交互目标选择规则

多个交互物同时进入范围时：

```text
1. 可完成任务 NPC
2. 主线任务 NPC
3. 当前追踪任务目标
4. 任务物品
5. 宝箱
6. 洞穴入口
7. 机关
8. 传送点
9. 商店建筑 / 商人
10. 告示牌
11. 普通 NPC
```

如果优先级相同：

```text
距离玩家最近
玩家面向方向更接近者优先
```

### 3.7 交互提示状态

| 状态 | 表现 |
|---|---|
| 可交互 | 图标正常亮，按钮可点 |
| 条件不足 | 图标带锁，按钮灰，显示原因 |
| 战斗中禁用 | 图标隐藏或灰，提示战斗中无法交互 |
| 已完成 | 图标弱化或打勾 |
| 新发现 | 图标有轻微闪光 |
| 任务相关 | 感叹号 / 问号高亮 |

## 4. NPC 对话界面

### 4.1 触发条件

```text
玩家进入 NPC 交互范围
→ 当前状态允许交互
→ 按下交互
→ NPC 面向玩家
→ 玩家进入 Interact 状态
→ 打开对话界面
```

### 4.2 对话界面布局

推荐底部对话框：

```text
┌──────────────────────────────────────────┐
│                                          │
│              游戏世界背景                 │
│                                          │
├──────────────────────────────────────────┤
│ NPC头像  NPC名称                         │
│ 对话文本逐字显示……                       │
│                              [继续]      │
└──────────────────────────────────────────┘
```

也可用于移动端：

```text
底部 30% 高度对话框
上方仍然能看到角色和 NPC
```

### 4.3 对话框内容

```text
NPC 名称
NPC 头像 / 小立绘
对话文本
继续按钮
跳过按钮，可选
任务按钮，可选
对话选项，可选
```

### 4.4 对话显示规则

```text
文本逐字出现
点击一次：立刻显示完整当前句
再点击一次：进入下一句
所有句子结束：进入任务按钮 / 关闭对话
```

参数：

```text
TextSpeed = 每秒 20~35 字
AutoClose = false
ClickToFinishLine = true
```

### 4.5 对话期间操作限制

```text
玩家不能移动
不能攻击
不能释放技能
不能打开后台菜单，或 Esc 先关闭对话
敌人 AI 暂停，若在安全区
战斗区对话不建议触发
```

### 4.6 对话选项

有选项时显示在对话框右侧或底部：

```text
1. 接受任务
2. 稍后再说
3. 打开商店
4. 关于这里
5. 再见
```

移动端：

```text
大按钮纵向排列
按钮高度 52~64 px
```

### 4.7 对话选项规则

```text
选项最多 4 个
选项文本不超过 12 个字
主线关键选项突出显示
取消/离开选项放最后
```

### 4.8 NPC 情绪表现

NPC 头像可有情绪状态：

```text
普通
开心
担心
惊讶
愤怒
悲伤
神秘
```

对话数据中配置：

```text
SpeakerID
Emotion
Text
NextLine
```

## 5. 任务接取界面

### 5.1 任务接取触发

```text
NPC 对话结束
→ 如果有可接任务
→ 弹出任务接取卡
```

或：

```text
点击 NPC 头顶感叹号
→ 直接进入任务介绍
```

### 5.2 任务接取卡布局

```text
┌──────────────────────────────┐
│ 任务：森林里的怪声             │
│ 类型：支线   推荐等级：Lv8      │
├──────────────────────────────┤
│ 任务描述：                    │
│ 村民说森林深处传来奇怪声音……   │
│                              │
│ 目标：前往绿叶森林调查          │
│                              │
│ 奖励：                        │
│ EXP +120   金币 +80            │
│ 森林帽子 x1                    │
├──────────────────────────────┤
│ [稍后]             [接受]       │
└──────────────────────────────┘
```

### 5.3 任务接取信息

必须显示：

```text
任务名称
任务类型
推荐等级
任务描述
当前目标
奖励
接受按钮
拒绝 / 稍后按钮
```

可选显示：

```text
任务链标记
区域名称
预计难度
前置任务
```

### 5.4 主线任务规则

主线任务建议：

```text
自动接受
不显示拒绝按钮
只显示“继续”或“接受”
```

### 5.5 支线任务规则

支线任务：

```text
可以接受
可以稍后
未接受时 NPC 保持感叹号
```

### 5.6 接受后反馈

```text
任务加入任务列表
HUD 右上显示当前追踪
NPC 头顶标记变化
地图目标点出现
播放任务接受音效
屏幕提示：已接受任务
```

## 6. 任务完成界面

### 6.1 任务完成触发

```text
玩家达到任务目标
→ 返回 NPC
→ NPC 头顶显示问号
→ 与 NPC 对话
→ 弹出任务完成界面
```

也可有自动完成任务：

```text
击败 Boss 后直接完成
收集物达到数量后自动完成
```

### 6.2 任务完成界面布局

```text
┌──────────────────────────────┐
│ 任务完成！                    │
│ 森林里的怪声                  │
├──────────────────────────────┤
│ 你解决了森林中的异常。          │
│                              │
│ 获得奖励：                    │
│ EXP +120                      │
│ 金币 +80                      │
│ 森林帽子 x1                   │
├──────────────────────────────┤
│                 [领取奖励]     │
└──────────────────────────────┘
```

### 6.3 奖励领取规则

点击领取：

```text
发放经验
发放金币
发放装备 / 物品
更新任务状态为完成
触发后续任务
更新 NPC 状态
更新地图状态
```

如果奖励包含装备且背包满，可选：

```text
提示背包空间不足
允许发送到临时邮箱，可选
MVP 不做背包容量，避免这个问题
```

### 6.4 连锁任务

完成任务后如果有下一个任务：

```text
领取奖励后
→ 显示新任务提示
→ NPC 头顶重新出现感叹号
```

或自动弹出下一个任务。

## 7. 普通商店界面

### 7.1 商店触发

```text
靠近商人 / 商店建筑
→ 显示交互提示：商店
→ 点击交互
→ 打开商店界面
```

### 7.2 商店基础布局

```text
┌──────────────────────────────────────────┐
│ 商店：村庄杂货铺                 金币 520 │
├───────────────┬──────────────────────────┤
│ 商品列表        │ 商品详情                 │
│ [药水]          │ 小型生命药水              │
│ [魔法药水]      │ 价格：50                  │
│ [回城卷轴]      │ 拥有：3                   │
│                │ 效果：恢复 100 生命        │
│                │                          │
│                │ 数量：[-] 1 [+]           │
│                │ 总价：50                  │
│                │ [购买]                    │
└───────────────┴──────────────────────────┘
```

### 7.3 商店页签

普通商店可分：

```text
推荐
消耗品
材料
装备
特殊
出售，可选
```

MVP：

```text
购买
出售，可选
```

如果不做出售：

```text
只做购买页
```

### 7.4 商品列表显示

每个商品格子显示：

```text
商品图标
商品名称
价格
拥有数量
品质边框
限购标记
售罄标记
解锁条件锁
```

### 7.5 商品详情显示

```text
商品名称
商品类型
品质
描述
价格
玩家拥有数量
购买数量
总价
购买按钮
```

装备商品还需要显示：

```text
槽位
属性
与当前装备对比
等级要求
```

### 7.6 购买规则

购买前检查：

```text
金币是否足够
是否达到购买等级
是否满足任务解锁
是否售罄
是否限购次数已满
背包是否有空间，如有容量系统
```

购买成功：

```text
扣除金币
物品进入背包
商品数量减少，如有限购
播放购买音效
显示获得提示
刷新金币显示
```

购买失败：

```text
按钮抖动
显示失败原因
播放错误音
```

失败原因：

```text
金币不足
等级不足
尚未解锁
已售罄
背包已满
```

### 7.7 数量选择

可堆叠商品允许购买多个：

```text
[-] 数量 [+]
最大
```

数量限制：

```text
不能超过玩家金币可购买数量
不能超过商品库存
不能超过背包上限
```

快捷按钮：

```text
-1
+1
最大
```

### 7.8 购买确认

普通低价物品不需要二次确认。  
高价 / 稀有物品需要确认。

触发确认条件：

```text
单价超过玩家当前金币 50%
品质为史诗及以上
限购特殊商品
任务关键商品
```

确认弹窗：

```text
是否花费 1200 金币购买“古代钥匙”？
[取消] [购买]
```

## 8. 出售界面

### 8.1 是否做出售

MVP 可以暂缓出售。  
如果装备和物品数量增长快，正式版建议加入出售。

### 8.2 出售列表

显示：

```text
背包物品
装备
材料
消耗品
```

不可出售：

```text
任务物品
关键道具
已装备物品
锁定装备
活动道具，可选
```

### 8.3 出售详情

```text
物品名称
拥有数量
单价
出售数量
总获得金币
出售按钮
```

### 8.4 出售确认

以下情况需要二次确认：

```text
稀有及以上装备
数量超过 10 的批量出售
材料类高价值物品
```

弹窗：

```text
是否出售“稀有森林帽”？
此操作无法撤销。
[取消] [出售]
```

## 9. 药水商店界面

### 9.1 药水商店定位

药水商店是普通商店的子类型，专门出售：

```text
生命药水
魔法药水
短时 Buff 药水
解除状态药水
```

### 9.2 药水商品信息

必须显示：

```text
恢复量
冷却时间
是否战斗中可用
拥有数量
价格
```

示例：

```text
小型生命药水
恢复 100 HP
使用冷却：10 秒
战斗中可用
价格：50
```

### 9.3 限制规则

```text
药水可堆叠
可设置最大携带数量
商店可无限供应或有限库存
高级药水需要区域解锁
```

```text
靠近技能神殿 / 魔法导师
```

```text
购买新技能
升级已拥有技能
查看技能效果
查看解锁条件
```

### 10.3 技能商店布局

```text
┌──────────────────────────────────────────┐
```

### 10.5 学习技能规则

```text
金币足够
玩家等级足够
前置任务完成
技能未学习
技能商店已解锁
```

```text
扣金币
技能加入玩家技能列表
播放学习特效
提示：学会了火环术
可立即装备到技能槽
```

```text
是否装备到技能槽？
[Slot1] [Slot2] [Slot3] [Slot4] [稍后]
```

```text
技能已学习
未满级
金币足够
满足等级要求
```

```text
技能等级 +1
刷新伤害 / 冷却 / 消耗 / 范围
播放升级音效
显示属性变化
```

技能升级对比：

```text
伤害：80 → 96
冷却：3.0s → 2.8s
范围：2.2 → 2.3
```

### 10.7 技能满级

显示：

```text
已满级
最高等级 Lv10
```

按钮：

```text
满级
灰色不可点
```

## 11. 铁匠铺界面

```text
│                │ 材料：铁矿 x2              │
│                │ [强化]                    │
└───────────────┴──────────────────────────┘
```

### 11.3 可强化装备列表


### 11.4 强化详情

显示：

```text

强化后等级
属性变化
金币消耗
材料消耗
成功率，如有
强化按钮
```

本项目推荐：

```text
强化 100% 成功
无失败
无降级
```

理由：

```text
轻量 ARPG 不适合做高挫败强化系统
```

### 11.5 强化消耗规则

```text
强化等级越高，金币越贵
品质越高，金币越贵
高级装备需要材料
```

示例公式：

```text
CostGold = BaseCost * (CurrentLevel + 1)^2 * QualityMultiplier
```

品质倍率：

```text
普通 1.0
优秀 1.3
稀有 1.8
史诗 2.5
传说 4.0
```

### 11.6 强化按钮状态

| 状态 | 表现 |
|---|---|
| 可强化 | 按钮亮 |
| 金币不足 | 按钮灰，金币红 |
| 材料不足 | 按钮灰，材料红 |
| 已满级 | 显示满级 |
| 战斗中不可强化 | 不会打开铁匠铺 |
| 装备锁定 | 可以强化，锁定不影响强化 |

### 11.7 强化成功表现

```text
装备卡片发光
强化等级数字弹出
属性增加值上飘
播放铁锤音效
播放星光特效
```

提示：

```text
强化成功！森林短剑 +3
```

```text
→ ShopUI.ShowDetail()
→ Player clicks Buy
→ ShopManager.CheckPurchase()
→ InventoryManager.AddItem()
→ CurrencyManager.SpendGold()
→ ToastManager.ShowReward()
→ ShopUI.Refresh()
```

## 37. 设计关键点总结

游戏内交互界面最重要的是：

```text
1. 靠近对象就知道能做什么
2. 交互按钮要清楚，不能和战斗按钮打架
3. NPC 对话要短，任务信息要清楚
4. 商店必须让玩家看懂价格、拥有数量、购买结果
5. 技能商店要显示学习、升级、装配的完整链路
6. 铁匠铺要显示强化前后属性，不要让玩家盲强化
7. 洞穴和 Boss 入口必须提示等级和风险
8. 传送点要明确激活状态和不可传送原因
9. 奖励提示要爽，但不能频繁打断战斗
10. 所有失败操作都要告诉玩家原因
```

最终目标：

```text
玩家在地图中看到任何东西，都能自然完成：
靠近 → 看提示 → 点交互 → 看结果 → 继续冒险。
```
