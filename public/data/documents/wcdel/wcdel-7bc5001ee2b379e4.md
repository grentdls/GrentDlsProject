# 游戏设置界面设计文档

## 一、设置界面整体定位

本设置界面用于《猫咪斗恶龙》类型的动作冒险游戏，参考：

- **DNF**：分页清晰、设置项列表化、快捷键配置完整。
- **猫咪斗恶龙**：界面轻量、卡通、操作简单。
- 本项目风格：兽族幻想、无人物、轻松喜感、移动 + 跳跃 + 闪避 + 技能栏 + 物品栏。

设置界面需要补齐：

- 画质设置
- 音效设置
- 操作设置
- 快捷键设置
- 存储记录
- 读取记录
- 游戏性设置
- 系统设置

---

## 2. 推荐分页顺序

```text
画质
音效
操作
快捷键
存档
游戏性
系统
```

理由：

1. 画质、音效是玩家最常用设置。
2. 操作和快捷键是动作游戏核心。
3. 存档属于重要系统功能。
4. 游戏性辅助和系统设置放后面。

# 十、快捷键修改规则

## 1. 修改流程

玩家点击某个按键按钮后：

```text
弹窗：请按下新的按键
倒计时：5 秒
按钮：取消
```

按下新键后：

- 如果没有冲突，直接绑定。
- 如果有冲突，弹出冲突提示。
- 如果是系统禁止键，拒绝绑定。
- 如果超时，保持原按键。

---

## 2. 允许共用的按键

| 情况 | 是否允许 |
|---|---|
| UI 确认 和 跳跃共用 Space | 允许 |
| 交互 和 拾取共用 E | 允许 |
| 鼠标滚轮切物品 和 UI 滚动 | 允许 |
| Esc 作为取消和暂停 | 允许 |

---

## 3. 不允许共用的按键

| 情况 | 原因 |
|---|---|
| 移动键和技能键冲突 | 影响战斗 |
| 跳跃和闪避冲突 | 核心动作冲突 |
| 普攻和交互冲突 | 战斗误触 |
| 快速读取和快速存档冲突 | 高风险 |
| 系统返回和技能释放冲突 | 操作混乱 |

---

## 4. 禁止绑定按键

| 按键 | 原因 |
|---|---|
| Alt + F4 | 系统关闭 |
| Ctrl + Alt + Del | 系统组合 |
| PrintScreen | 系统截图占用 |
| Windows 键 | 系统键 |
| Alt + Tab | 切窗口 |
| Esc 单独绑定到普通技能 | 会影响退出 |

---

## 5. 冲突提示文案

```text
该按键已绑定到【闪避】。
是否将【闪避】清空，并绑定到【技能 1】？
```

按钮：

```text
取消
清空原绑定
交换两个按键
```

# 十八、关键交互规则

## 1. 快捷键必须支持冲突检测

重点检测：

- WASD
- 跳跃
- 闪避
- 普攻
- 技能
- 物品
- 交互
- 存档读取

不能让玩家改出无法操作的配置。

---

## 2. 存档必须有缩略图

存档列表建议显示：

```text
缩略图 + 章节 + 地点 + 时间 + 游戏时长
```

这样比只显示文字更直观。

---

## 3. 画质修改需要确认倒计时

分辨率、窗口模式改动后弹窗：

```text
是否保留当前显示设置？
15 秒后自动还原。
```

按钮：

```text
保留设置
还原
```

---

## 4. 音效设置要实时预览

滑条拖动时：

- UI 音效立即变化。
- 音乐音量立即变化。
- 战斗音效可点击按钮试听。
- 环境音可点击按钮试听。

---

## 5. 存档操作必须二次确认

以下操作必须二次确认：

- 覆盖存档
- 删除存档
- 读取存档
- 返回标题界面
- 退出游戏

# 二十、一句话总结

设置界面的核心不是堆选项，而是：

> 画质能调性能，音效能分层，操作能适配手感，快捷键能安全改，存档能清楚管理，所有高风险操作都有二次确认。
