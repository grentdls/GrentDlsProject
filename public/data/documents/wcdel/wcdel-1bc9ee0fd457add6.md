# 装备槽位占位图标与测试补给入口同步说明

## 目标

本次同步用于解决后台背包装备页中装备槽位识别混乱、点击无反馈、运行时缺少测试内容的问题。

## 装备槽位

- 装备页继续使用 `UIRoot_BackendMenuHUD` 下的后台菜单预制体结构。
- 12 个装备槽位统一放在 `EquipmentSlotRing` 内，按武器、头部、上装、下装、鞋子、项链、戒指1、戒指2、手镯、腰带、护符、特殊顺序生成。
- 每个槽位包含 `Img_EmptySlotIcon`，用于显示未装备时的部位占位图。
- 每个槽位包含 `Txt_EmptySlotIcon`，作为占位图缺失时的中文兜底识别字。
- 占位图资源路径为 `Assets/Game/Art/Icons/Equipment/Slots`。

## 运行时交互

- 点击任意装备槽位会切换当前选中槽位。
- 如果当前处于消耗品、材料或任务分页，点击装备槽后会自动切回装备筛选。
- 空槽会在详情面板显示对应部位说明和候选装备数量提示。
- 装备槽、背包物品格按钮会在 UI 结构补齐后重新缓存并绑定，避免旧预制体出现“可见但无点击响应”的情况。

## 测试补给按钮

- 装备页左侧快捷按钮组新增临时按钮 `Btn_DebugGrantTestContent`，界面文字为“测试补给”。
- 点击后会运行时添加测试金币、经验、全槽位装备、技能、消耗品、材料、宠物道具和已拥有宠物。
- 空装备槽会优先自动装备测试装备，方便快速验证属性、装备详情、技能栏和宠物页。
- 该按钮仅用于开发验收，后续正式经济、掉落、商店和任务奖励接入后可以隐藏或移除。

## 生成入口

- 后台 UI 生成器：`Assets/Game/Editor/UiPrefabFactory.cs`
- 生成态后台 UI 菜单：`Tools/WCDEL/界面/按分组重建生成态界面/后台`
- 全部生成态 UI 菜单：`Tools/WCDEL/界面/按分组重建生成态界面/全部`

## 后续注意

- 如果项目中存在后台 UI 覆盖预制体，生成态预制体重建不会覆盖 `Assets/Game/UI/Prefabs/Overrides` 下的同名覆盖体，需要同步检查覆盖体是否包含新按钮和新槽位子节点。
- 编辑器工具在加载后台菜单预制体时会检查覆盖体结构；如果覆盖体仍是旧结构，会临时回退使用生成态后台预制体，避免场景继续实例化旧 UI。
- 正式美术资源接入时，优先替换同名 PNG，不需要改运行时代码。
