# Texture Background Cutout Tool

## Goal

提供一个项目内 Unity Editor 抠图工具，方便把素材图的纯色或近似背景扣成透明 PNG，同时保留特效贴图原有的半透明 alpha 通道。

## Scope

- 新增菜单入口：
  - `Tools/WCDEL/Art/Texture Background Cutout`
- 支持从当前选中的 `Texture2D` 自动带入源图。
- 支持两种背景取样方式：
  - 四角自动取样
  - 手动指定背景颜色
- 支持两种抠图模式：
  - `ConnectedEdgeBackground`：只抠除与图片边缘连通的背景色区域，适合保留主体内部近似背景色细节。
  - `FullImageColorKey`：全图按背景色距离抠除，适合纯色底特效图。
- 输出时使用 `原始 alpha * 抠图 mask alpha`，避免把特效、光晕、烟雾这类半透明像素打平成硬边。
- 新增边缘优化参数：
  - `Remove Color Fringe`：清理半透明边缘里残留的白底、黑底或纯色底 RGB。
  - `Fringe Strength`：控制去底色强度。
  - `Edge Contract`：向内收缩背景 mask，减少误删主体边缘。
  - `Ignore Transparent Pixels`：跳过源图里已经接近透明的像素，避免二次污染特效 alpha。

## Output

- 默认输出目录：
  - `Assets/Game/Art/Cutouts`
- 输出格式：
  - PNG
- 输出导入设置：
  - `Texture Type = Sprite`
  - `Sprite Mode = Single`
  - `Alpha Is Transparency = true`
  - `Mipmap Enabled = false`
  - `Wrap Mode = Clamp`

## Usage

1. 在 Project 窗口选中一张纹理。
2. 打开 `Tools/WCDEL/Art/Texture Background Cutout`。
3. 根据素材选择背景取样方式和抠图模式。
4. 调整 `Tolerance` 与 `Soft Edge`。
5. 如果边缘有白边或黑边，开启 `Remove Color Fringe` 并调整 `Fringe Strength`。
6. 如果主体边缘被误扣，增加 `Edge Contract` 或降低 `Tolerance`。
7. 点击 `Preview` 预览结果。
8. 点击 `Export PNG` 输出正式透明图。

## Notes

- 角色立绘、道具、场景物件：优先 `ConnectedEdgeBackground`，`Tolerance` 从 `0.05 ~ 0.12` 试起。
- 纯色底特效、烟雾、光晕：可用 `FullImageColorKey`，`Tolerance` 从 `0.02 ~ 0.08` 试起。
- 明显白边或黑边：开启 `Remove Color Fringe`，`Fringe Strength` 从 `0.6 ~ 0.9` 试起。
- 主体边缘被吃掉：把 `Edge Contract` 调到 `1 ~ 2`，并降低 `Tolerance`。
- 源图已经有透明 alpha：保留 `Ignore Transparent Pixels` 开启。
