# 背包界面 UI 预制体布局结构说明

> 适用项目：2D 横版动作 RPG / DNF 式角色养成界面  
> 目标：重做背包界面，让角色展示、装备槽位、背包物品列表、物品详情和操作按钮都有清晰层级。  
> 推荐预制体名：`UI_InventoryPanel.prefab`

---

# 1. 界面设计目标

背包界面分成两个主要区域：

```text
左侧：角色展示 + 当前装备槽位
右侧：背包物品列表 + 分类筛选 + 物品操作
```

核心体验：

```text
玩家一打开背包，先看到自己的角色当前形象。
角色周围围绕装备槽位，能直接看出哪些部位穿了装备，哪些部位为空。
右侧是背包列表，所有物品以图标格子的形式显示。
点击装备槽或背包物品后，弹出对应物品详情和操作按钮。
```

界面不要做成全屏杂乱列表，也不要把装备槽位堆在一边。  
装备槽位要围绕角色，背包列表要规整、可滚动、可筛选。

# 2. 总体布局

## 2.1 推荐分辨率

以 1920 × 1080 为 UI 设计基准。

```text
Canvas Scaler：Scale With Screen Size
Reference Resolution：1920 x 1080
Match：0.5
```

## 2.2 主界面区域

```text
Root
└── SafeArea
    └── InventoryWindow
        ├── TopBar
        ├── Left_CharacterEquipPanel
        ├── Right_BagPanel
        ├── Bottom_TipsBar
        └── Floating_ItemDetailPanel
```

## 2.3 视觉占比

| 区域 | 建议宽度 | 功能 |
|---|---:|---|
| 左侧角色装备区 | 38% ~ 42% | 角色展示、装备槽位、战力信息 |
| 右侧背包区 | 54% ~ 58% | 背包物品图标列表、分类、排序 |
| 中间间隔 | 2% ~ 4% | 视觉分隔 |

推荐主窗口尺寸：

```text
InventoryWindow：1680 x 900
Left_CharacterEquipPanel：650 x 820
Right_BagPanel：920 x 820
TopBar：1680 x 80
Bottom_TipsBar：1680 x 50
```

布局示意：

```text
┌──────────────────────────────────────────────────────────────┐

├───────────────────────┬──────────────────────────────────────┤

│                       │ 排序 / 整理 / 出售 / 使用 / 装备       │
├───────────────────────┴──────────────────────────────────────┤
│ 底部提示：左键选择 / 右键快捷使用 / 长按查看详情                │

```

# 4. 左侧角色装备区设计

## 4.1 左侧区域定位

左侧主要展示：

```text
角色当前样子
当前装备槽位
角色基础战力
快捷装备操作
```

它不是背包列表，不应该塞太多文字。

---

## 4.2 CharacterPreviewArea

角色展示区放在左侧中间。

推荐尺寸：

```text
CharacterPreviewArea：420 x 520
位置：Left_CharacterEquipPanel 中心偏下
```

包含：

```text
角色当前 Sprite / Spine / 2D 动画
脚底阴影
简单背景光圈
装备外观层，可选
```

角色展示规则：

```text
默认播放 Idle 动画
换装备后实时刷新角色外观
鼠标悬停角色时可播放展示动作
点击角色可切换待机动作，可选
不要让角色被装备槽位挡住脸和身体主体
```

---

## 4.3 装备槽位围绕角色布局

装备槽位不要做成一列死板列表，而是围绕角色形成环形 / 半环形布局。

推荐槽位数量：

```text
武器
头部
衣服
裤子
鞋子
项链
戒指 1
戒指 2
手镯
腰带
护符
特殊法宝
```

如果第一版不想做太多，MVP 可以先做：

```text
武器
头部
衣服
鞋子
项链
戒指
护符
```

---

## 4.4 装备槽位推荐位置

以角色展示区中心为参考点：

```text
角色中心点：PreviewCenter
```

| 槽位 | 推荐位置 | 说明 |
|---|---|---|
| Slot_Head | 角色头顶上方 | 头盔、发饰 |
| Slot_Weapon | 角色左侧中部 | 武器，最重要，按钮稍大 |
| Slot_Chest | 角色右侧中部 | 上衣 / 护甲 |
| Slot_Pants | 角色右下 | 裤子 |

# 5. 装备槽位按钮结构

每个装备槽位都是一个按钮预制体。

推荐预制体：

```text
UI_EquipmentSlot.prefab
```

层级：

```text
UI_EquipmentSlot
├── Btn_Slot
├── Img_SlotBg
├── Img_EmptySlotIcon
├── Img_EquippedIcon
├── Img_RarityFrame
├── Img_SelectedOutline
├── Img_HoverGlow
├── Img_LockedMask
├── Img_RedDot
├── Img_CompareArrow
├── Txt_EnhanceLevel
└── Txt_SlotName，可选
```

---

## 5.1 装备槽位尺寸

推荐：

```text
普通槽位：72 x 72
武器槽位：86 x 86
特殊装备槽位：78 x 78
```

移动端可以放大：

```text
普通槽位：86 x 86
武器槽位：96 x 96
```

---

## 5.2 装备槽位状态

每个槽位至少支持这些状态：

```text
Empty       未装备
Equipped    已装备
Selected    当前选中
Hover       鼠标悬停
Locked      未解锁
Disabled    当前不可操作
CanUpgrade  可强化 / 可升级
CanReplace  背包中有更强装备
```

---

## 5.3 未装备状态

未装备时显示：

```text
槽位底框
淡色槽位图标
槽位类型小图标
可选文字：未装备
```

不要空白。  
空白会让玩家不知道这里能装什么。

示例：

```text
武器槽未装备：显示灰色小剑图标
头部槽未装备：显示灰色头盔图标
衣服槽未装备：显示灰色衣甲图标
鞋子槽未装备：显示灰色鞋子图标
戒指槽未装备：显示灰色戒指图标
```

---

## 5.4 已装备状态

已装备时显示：

```text
装备图标
稀有度框体
强化等级
锁定状态
可替换提示
```

显示优先级：

```text
装备图标 > 稀有度框 > 强化等级 > 锁定 > 红点/替换箭头
```

---

## 5.5 稀有度框体

稀有度不靠文字显示，而是靠框体颜色和边框样式。

| 稀有度 | 框体表现 |
|---|---|
| 普通 | 灰白细边框 |
| 优秀 | 绿色边框 |
| 精良 | 蓝色边框 |
| 史诗 | 紫色边框 |
| 传说 | 橙色边框 |
| 神话 | 红金边框 + 微光 |

# 6. 右侧背包列表设计

## 6.1 右侧区域定位

右侧是背包的核心操作区。

必须包含：

```text
分类标签
排序和整理
背包图标列表
操作按钮
容量显示
```

---

## 6.2 背包列表采用 ScrollRect + GridLayoutGroup

虽然叫背包列表，但物品应该以图标格子的方式排列。  
不要做成长文本列表，否则空间浪费太大。

推荐结构：

```text
BagScrollView
├── Viewport
│   └── Content
│       ├── ItemCell
│       ├── ItemCell
│       ├── ItemCell
│       └── ...
└── Scrollbar_Vertical
```

组件：

```text
ScrollRect
Mask / RectMask2D
GridLayoutGroup
Scrollbar
```

---

## 6.3 背包格子布局参数

1920 × 1080 下推荐：

```text
Cell Size：82 x 82
Spacing：10 x 10
Padding：16, 16, 16, 16
Constraint：Fixed Column Count
Column Count：8
```

如果右侧区域较窄：

```text
Column Count：7
Cell Size：78 x 78
Spacing：8 x 8
```

移动端：

```text
Column Count：5 或 6
Cell Size：88 x 88
Spacing：10 x 10
```

---

## 6.4 物品格子预制体

推荐预制体：

```text
UI_BagItemCell.prefab
```

层级：

```text
UI_BagItemCell
├── Btn_Item
├── Img_CellBg
├── Img_ItemIcon
├── Img_RarityFrame
├── Img_SelectedOutline
├── Img_HoverGlow
├── Img_NewTag
├── Img_LockIcon
├── Img_EquippedTag
├── Img_CooldownMask，可选
├── Txt_StackCount
├── Txt_EnhanceLevel
└── Img_TypeCornerIcon，可选
```

---

## 6.5 物品格子显示规则

每个背包物品格子只显示核心信息：

```text
物品图标
稀有度框体
堆叠数量
强化等级
锁定图标
已装备标记
新物品标记
```

不要在格子里显示长名字。  
名字放在详情面板里。

---

## 6.6 空背包格子

如果是固定容量背包，可以显示空格子。

空格子状态：

```text
空底框
无图标
低透明度
不可点击或点击无反馈
```

如果是无限列表背包，可以不显示空格子，只显示已有物品。

推荐第一版：

```text
固定容量显示空格子
这样玩家能清楚看到背包容量
```

# 11. 点击与拖拽交互

## 11.1 点击背包物品

流程：

```text
点击物品格子
→ 选中格子
→ 显示详情面板
→ 高亮可装备槽位，如果是装备
→ 刷新操作按钮
```

---

## 11.2 双击背包物品

推荐规则：

```text
装备：直接装备
消耗品：直接使用
材料：打开详情
任务物品：打开详情
```

移动端不做双击，使用按钮操作。

---

## 11.3 点击装备槽位

流程：

```text
点击已装备槽位
→ 显示当前装备详情
→ 背包列表筛选同部位可替换装备，可选
→ 显示卸下按钮
```

点击未装备槽位：

```text
显示该槽位可装备物品列表
如果背包没有对应装备，显示空提示
```

---

## 11.4 拖拽装备

PC 可以支持拖拽：

```text
从背包拖装备到对应槽位 = 装备
从装备槽拖到背包 = 卸下
不同部位拖入错误槽位 = 禁止并提示
```

第一版可以先不做拖拽，优先做好点击和按钮。

# 23. 推荐最终布局总结

最终背包界面应该是：

```text
左边像角色装备展示页：角色在中间，装备槽围绕角色。
右边像物品仓库：分类清楚，物品图标整齐排列，可以滚动。
点装备，左边对应槽位发光。
点槽位，右边自动筛出可装备物品。
点物品，弹出详情和操作按钮。
```

最重要的改动是：

```text
不要把装备槽位和背包物品混在一起。
不要让角色展示被挤到角落。
不要用长文本物品列表占空间。
装备槽位必须是按钮，并且有未装备状态表现。
背包物品必须是规整图标格子列表。
```

# 24. 快捷道具栏规则

## 24.1 功能定位

背包界面需要显示 6 格快捷道具栏，用于配置战斗内可使用的消耗品。

```text
快捷栏槽位：1 / 2 / 3 / 4 / 5 / 6
战斗快捷键：键盘数字 1 / 2 / 3 / 4 / 5 / 6
显示位置：背包页右侧物品列表下方；战斗 HUD 技能栏上方
```

## 24.2 配置规则

```text
只允许放入消耗品
物品必须 Usable = true
战斗中使用必须 UseInCombat = true
数量为 0 时按钮置灰，不消耗
未配置时显示“空 / 未配置”
```

背包内交互规则：

```text
选中可使用消耗品 -> 点击快捷栏槽位 = 绑定该物品
未选中可配置消耗品 -> 点击已配置槽位 = 清空该槽位
选中材料、任务物品、技能书、货币、钥匙、特殊道具 -> 禁止放入并给中文提示
```

## 24.3 使用规则

```text
战斗内按 1~6 使用对应快捷栏物品
战斗 HUD 点击快捷栏按钮也可使用
所有使用入口统一走 InventoryItemUseService
只有实际生效后才扣除数量
使用成功后触发 UseItem 类型任务进度
```

## 24.4 数据与刷新

快捷栏配置存放在玩家数据：

```text
PlayerRuntimeData.QuickItemSlotItemIds
固定 6 格，不由 UI 临时保存
旧存档读取时自动补齐 6 格
```

刷新规则：

```text
背包打开、选中物品、配置槽位、使用/丢弃物品后刷新快捷栏
战斗 HUD 可实时刷新数量，但不要反复重建 UI 节点
后续一键生成 UI 时必须保留 QuickItemBar / QuickItemHotbar 语义节点
```
