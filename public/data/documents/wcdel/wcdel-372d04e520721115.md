## 资源分类

- `BGM`：探索、战斗、Boss、胜利短句。
- `Ambience`：村庄白天、荒原风、枯井臭气、龙渠回忆、封印平台压迫、随机风声。
- `UI`：点击、确认、取消、错误、打开/关闭页面、标签切换、购买、装备、接取任务、完成任务、获得物品。
- `SFX/Movement`：草地、泥地、石地、浅水、干土、黑土脚步，跳跃、轻落地、重落地、冲刺。
- `SFX/Combat`：轻重挥空、技能施放、技能命中、绝技、普通/重击/暴击/穿甲/弱点/斩杀/元素命中、玩家受击/死亡、敌人受击/死亡、Boss 受击/破防。
- `SFX/Enemy`：大鹅、枯骨鼠、干蝇、毒芽、黑草、枯根的警觉、攻击、死亡。
- `SFX/Boss`：神龙睁眼、低语、叹息吸气、叹息爆发、叹息尾音、封印锁链、封印发光。
- `SFX/Cutscene`：被吹飞连续喜剧撞击、鸡窝坠落、鸡叫、夜晚篝火。
- `SFX/Interact`：通用交互、对话、宝箱、稀有宝箱、机关、传送点、神龛、商店、任务板、阻挡、枯井、龙纹石、告示牌、防龙铃、拾取。
- `Voice`：玩家攻击、技能、绝技、受击、死亡，NPC 短语，Boss 大招，第一章神龙/小猫/村民剧情短句。

## 运行时接入

- UI 和后台菜单通过 `GameAudioEventIds.Ui*` 播放真实音频。
- 玩家跳跃、落地、冲刺、普攻、技能和绝技会播放对应事件。
- 伤害反馈会根据暴击、穿甲、弱点、斩杀、元素和 Boss 状态选择命中音效。
- 世界交互物默认使用 `WorldInteractableBase2D.ResolveInteractionAudioEventId()`，宝箱、传送点、任务板、商店、NPC 对话已有专用事件。
- `CharacterFootstepAudioController` 读取 `SurfaceAudioRule`，按地表类型切换脚步、落地和冲刺音效。
- `SceneAudioController` 读取场景规则或 Inspector 覆盖值，负责场景默认 BGM 和环境音。

## 重新生成流程

1. 打开 Unity。
2. 点击 `Tools/WCDEL/音频/生成第一章音频库`。
3. 工具会同步 `Assets/Game/Audio/Resources/GameAudioLibrary.asset`。
4. 如果需要命令行，可在没有其他 Unity 实例打开本项目时执行 `WCDEL.Game.Editor.Chapter01AudioLibraryBuilder.BuildChapter01AudioLibraryForAutomation`。
5. 若替换为正式音频，只要保持事件 ID 和 ClipGroup ID 不变，运行时调用无需改代码。

## 后续注意事项

- 当前 WAV 为程序化占位音色，能用于玩法反馈和配置验证，但正式版本建议替换为人工设计或专业音频资源。
- 第二次 Unity batchmode 验证时检测到本项目已有 Unity 实例打开，因此不要并行打开同一个项目执行自动化。
- 后续如果增加第一章区域切换触发器，应优先通过 `SceneAudioController` 或 `GameAudioEventPlayer` 播放 `Ch01AmbWasteland`、`Ch01AmbDryWell`、`Ch01AmbSealPlatform` 等事件。
