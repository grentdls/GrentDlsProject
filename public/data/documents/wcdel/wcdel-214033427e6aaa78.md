# Chapter01 Route Unlock Sync

## Goal

Convert the Chapter01 post-boss “route unlocked” message into a real saved world-state change so the forest road can actually open after the boss reward sequence.

## Scope

- Extended `MapRuntimeData` with a lightweight `UnlockedAbilityIds` list.
- Extended `GameSession` with `IsAbilityUnlocked(...)` and `UnlockAbility(...)` accessors.
- Extended save/load restore in `GameBootstrapper` so unlocked Chapter01 abilities survive slot reload.
- Extended `CollectibleInteractable2D` with an optional `_unlockAbilityId` field.
- Added `AbilityLockedGate2D` as a small runtime gate controller that hides itself and activates linked targets once the required ability is unlocked.
- Updated `FoundationAssetUtility` so:
  - `Purified Hive Ember` unlocks `ability_ch01_fire_purification`
  - a new `ForestRoadGate` blocks the Chapter01 exit until that unlock happens
  - a new `ForestRoadBeacon` appears after the gate opens to make the route change visible in the prototype slice

## Current Behavior

- Defeating the Hive Guardian still unlocks the boss reward flow first.
- Picking up `Purified Hive Ember` now does two things:
  - advances the related quest path
  - permanently unlocks the Chapter01 fire-purification ability in runtime map data
- Once that ability is present, the forest road gate disappears and the forest-road marker becomes available.
- The unlock state can persist through the current save-slot pipeline because it now lives in `MapRuntimeData`.

## Boundaries

- This is a lightweight ability-unlock flag, not a full ability system with icons, upgrade levels, or reusable gameplay verbs.
- The forest road still opens through scene-object visibility toggles, not through a formal world streaming or tilemap mutation pipeline.
- The route beacon is only a prototype visibility aid and not yet a dedicated chapter-exit interaction or transition scene.

## Next Suggestions

1. Promote the unlocked ability into a visible player progression entry in UI or backend menu.
2. Reuse the same unlock-flag path for later chapter blockers like vine walls, traversal upgrades, or shrine blessings.
3. Replace the prototype beacon with a formal chapter-exit gate or transition trigger once Chapter02 bootstrap work begins.
