# Inventory UI Prefab Sync

## Goal

根据 `Docs/inventory_ui_prefab_layout_design.md`，将后台菜单中的装备页升级为真正的背包界面预制体结构，做到：

- 左侧角色展示区
- 环绕式装备槽位
- 右侧背包格子列表
- 详情面板
- 顶部分类与排序工具栏
- 底部快捷操作栏
- 运行时只负责数据绑定与状态刷新，不在逻辑里写布局尺寸

## Scope

- 扩展 `UiPrefabFactory`，让 `EquipmentPage` 不再是简单的 `PageTitle + PageBody` 文本页，而是生成完整的 `InventoryLayoutRoot` 结构。
- 在 `BackendMenuCanvasPresenter` 中补充背包页的控件缓存、装备槽按钮绑定、背包格子按钮绑定、详情面板刷新和操作按钮可用状态。
- 保留当前后台菜单的大框架和页面切换逻辑，不新起第二套菜单系统。

## Current Behavior

- 后台菜单的“装备”页现在会生成为完整背包页布局。
- 左侧角色区包含角色名、等级、战力、角色预览占位、环绕装备槽、角色数值分栏、快捷按钮。
- 独立“角色信息”页已经合并到装备页下方的 `CharacterStatsPanel`，顶部标签不再显示“角色”页。
- 角色数值分栏使用两列属性卡，每行包含一个属性图标色块、中文属性名和当前数值。
- 当前显示属性包括生命、法力、攻击、法强、防御、暴击、暴伤、移速、技能范围、技能半径、技能威力、投射物数量/速度。
- 右侧包含分类标签、工具栏、物品网格、详情面板、底部操作栏和提示栏。
- 当前真实运行时绑定的装备槽仍然以现有系统支持的四类为主：
  - 武器
  - 上装
  - 头部
  - 饰品
- 其它槽位先作为中文占位和后续扩展接口保留在预制体结构中。
- 背包格子会显示当前选中槽位的候选装备列表，并支持点击选中、详情刷新和装备应用。
- 背包候选来源已收紧为“玩家当前真正持有的装备”，不再直接显示全部定义。
- 已补上第一批真实按钮逻辑：
  - 分类切换
  - 装备
  - 卸下当前槽位
  - 全部卸下
  - 出售
  - 丢弃
  - 锁定 / 收藏
- `收藏` 分类当前复用锁定集合做最小闭环验证。

## Boundaries

- 当前是背包界面第一版可运行预制体，不等于最终美术版。
- 物品拖拽、双击、长按、批量整理、更多类型物品来源仍未完成。
- 当前角色展示和物品图标仍是占位图块，方便后续直接在 Unity 里替换资源。
- 运行时装备系统仍只有四类真实可写回槽位，若要完整覆盖文档中的更多装备部位，需要先扩展 `PlayerRuntimeData` 和 `GameSession` 的装备槽数据结构。
- 消耗品、材料、任务道具分类当前主要作为 UI 和筛选入口保留，尚未接入独立数据源。
