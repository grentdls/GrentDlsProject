# 宠物系统、宠物蛋孵化与宠物界面完整设计文档

> 项目类型：固定视角 3D 世界 + 2D 序列帧角色表现  
> 战斗类型：DNF 式横版清版动作 RPG  
> 当前模块：宠物玩法、抓取宠物、宠物蛋孵化、宠物升级、宠物技能、宠物攻击、宠物界面、宠物配置  
> 核心目标：玩家可以携带 1 只宠物参与冒险，宠物能跟随、战斗、成长、学习技能，并通过抓取和孵化获得更多宠物。

---

# 1. 宠物系统定位

## 1.1 宠物玩法目标

宠物系统不是单纯装饰，而是一个轻量战斗成长系统。

宠物应该承担：

```text
1. 跟随玩家探索
2. 协助玩家攻击敌人
3. 提供被动属性加成
4. 释放宠物技能
5. 通过升级变强
6. 通过技能学习形成差异
7. 通过抓取和孵化丰富收集体验
8. 通过界面配置出战宠物和技能
```

玩家感受应该是：

```text
宠物能陪我跑图
宠物能帮我打怪
宠物能成长
宠物有不同类型
宠物不是必须强制肝，但养了会明显更舒服
```

---

## 1.2 宠物在战斗中的定位

宠物不应该抢玩家主角操作的风头。  
宠物主要作为：

```text
辅助输出
控制补充
异常状态补充
生存辅助
探索辅助
```

宠物不建议做成：

```text
宠物输出远高于玩家
宠物自动清全图
玩家只挂机看宠物打
宠物技能过多导致画面混乱
```

推荐战斗占比：

```text
玩家输出：70%~85%
宠物输出：10%~25%
宠物辅助：5%~15%
```

---

## 1.3 出战数量

第一版规则：

```text
玩家一次只能携带 1 只出战宠物
```

后续可扩展：

```text
主宠 1 只
备用宠 2 只
羁绊宠 3 只，只提供被动加成
```

MVP 不建议一开始做多宠同时出战，避免：

```text
画面混乱
AI 复杂
性能压力
战斗数值失控
```

# 2. 宠物类型划分

## 2.1 宠物大类

宠物按战斗功能分为 6 类：

| 类型 | 定位 | 例子 |
|---|---|---|
| 攻击型 | 提供持续输出 | 小狼、小鹰、火狐 |
| 防御型 | 护盾、嘲讽、减伤 | 石龟、小熊、甲虫 |
| 治疗型 | 回血、净化、续航 | 灵鹿、药鼠、月兔 |
| 控制型 | 减速、眩晕、冰冻 | 冰狐、藤妖、雷鸟 |
| 异常型 | 中毒、灼烧、流血 | 毒蛇、火蜥、血蝠 |
| 探索型 | 寻宝、采集、发现隐藏 | 小鼠、灵犬、寻宝鼹鼠 |

---

## 2.2 宠物元素属性

宠物可以拥有元素属性：

```text
无属性
火
冰
雷
毒
风
土
光
暗
```

元素影响：

```text
宠物技能伤害类型
宠物攻击附加状态
宠物外观特效
宠物抗性
宠物克制关系
```

---

## 2.3 宠物品质

宠物品质用于区分成长和稀有度。

| 品质 | 颜色 | 成长 | 技能槽 | 获取难度 |
|---|---|---:|---:|---|
| 普通 | 白 / 灰 | 低 | 1 | 常见 |
| 优秀 | 绿 | 中低 | 1~2 | 较常见 |
| 稀有 | 蓝 | 中 | 2 | 较少 |
| 史诗 | 紫 | 高 | 2~3 | 稀有 |
| 传说 | 橙 | 很高 | 3 | 极稀有 |

MVP 推荐只开放：

```text
普通
优秀
稀有
史诗
```

传说宠物后续版本再开放。

# 4. 抓取宠物系统

## 4.1 可抓取对象

不是所有怪物都能抓。  
怪物配置中需要字段：

```text
CanCapture
CapturePetID
CaptureDifficulty
CaptureCondition
CaptureItemRequired
```

可抓取对象类型：

```text
野生宠物
特殊幼兽
部分小怪变种
任务指定宠物
稀有地图事件宠物
```

不可抓取：

```text
Boss
主线关键敌人
剧情 NPC
人形敌人
召唤物
机关怪
临时生成怪
```

---

## 4.2 抓取条件

抓取必须满足：

```text
目标允许抓取
目标处于低血状态
玩家拥有捕捉道具
玩家未处于受击、倒地、死亡、剧情状态
目标没有处于无敌 / 死亡 / 消失状态
目标与玩家距离足够近
```

推荐低血条件：

```text
目标 HP <= 30%
```

稀有宠物：

```text
目标 HP <= 20%
```

胆小宠物可以特殊：

```text
HP <= 40%，但会逃跑
```

---

## 4.3 抓取道具

抓宠需要宠物绳 / 捕兽符 / 灵兽铃等道具。

| 道具 | 用途 | 成功率修正 |
|---|---|---:|
| 普通捕兽绳 | 抓普通宠 | +0% |
| 精制捕兽绳 | 抓优秀 / 稀有宠 | +10% |
| 灵兽铃 | 抓稀有宠 | +20% |
| 安抚果 | 抓取前使用，降低宠物逃跑 | +15% |
| 高级灵契符 | 抓史诗宠 | +30% |

---

## 4.4 抓取流程

```text
玩家发现可抓取目标
→ 目标血量降低到抓取阈值
→ 目标头顶出现“可抓取”图标
→ 玩家靠近或锁定目标
→ 点击抓取按钮 / 使用捕捉道具
→ 进入短暂抓取演出
→ 计算成功率
→ 成功：宠物加入宠物仓库
→ 失败：道具消耗，目标短暂逃跑 / 狂暴 / 继续战斗
```

---

## 4.5 抓取成功率公式

基础公式：

```text
成功率 = 基础成功率
       + 低血加成
       + 道具加成
       + 玩家捕宠加成
       - 宠物难度修正
       - 宠物等级差修正
```

推荐：

```text
最低成功率：5%
最高成功率：95%
```

示例：

```text
基础成功率：35%
目标血量 20% 以下：+20%
精制捕兽绳：+10%
宠物难度：-15%
最终成功率：50%
```

---

## 4.6 低血加成

| 目标剩余 HP | 成功率加成 |
|---:|---:|
| 30%~21% | +10% |
| 20%~11% | +20% |
| 10% 以下 | +30% |

风险：

```text
目标血太低可能被误杀
```

这样鼓励玩家控制伤害。

---

## 4.7 抓取失败结果

抓取失败可以触发：

```text
目标后撤
目标短暂无敌 1 秒
目标进入惊慌状态
目标逃跑
目标狂暴
召唤同伴
```

不同宠物性格不同。

例如：

```text
胆小宠物：失败后逃跑
凶猛宠物：失败后狂暴
稀有宠物：失败后直接消失
普通宠物：失败后继续战斗
```

---

## 4.8 抓取 UI 表现

目标可抓取时：

```text
目标头顶出现宠物爪印图标
血条下方显示“可抓取”小标签
抓取按钮出现在右侧交互按钮位置
```

抓取按钮：

```text
图标：绳索 / 铃铛
文字：抓取
显示当前道具数量
```

抓取中：

```text
目标身上出现灵契圈
进度条 1.2 秒
玩家不可移动或降低移动速度
成功时播放星光
失败时灵契圈破碎
```

# 5. 宠物蛋系统

## 5.1 宠物蛋来源

宠物蛋可以来自：

```text
野外宝箱
Boss 掉落
任务奖励
宠物巢穴
商店购买
活动兑换
抓宠失败后概率掉落，特殊规则
```

---

## 5.2 宠物蛋类型

| 蛋类型 | 可能孵化 | 特点 |
|---|---|---|
| 普通兽蛋 | 普通 / 优秀宠物 | 基础蛋 |
| 草原兽蛋 | 草原系宠物 | 第一章可得 |
| 火纹兽蛋 | 火系宠物 | 火山区域 |
| 冰晶兽蛋 | 冰系宠物 | 雪地区域 |
| 雷鸣兽蛋 | 雷系宠物 | 雷泽区域 |
| 毒沼兽蛋 | 毒系宠物 | 沼泽区域 |
| 古妖兽蛋 | 稀有 / 史诗宠物 | 高级蛋 |
| 神秘兽蛋 | 随机宠物 | 奖励蛋 |

---

## 5.3 孵化条件

宠物蛋孵化需要：

```text
孵化槽位
孵化时间
可选孵化材料
可选金币费用
可选区域条件
```

MVP 推荐：

```text
1 个默认孵化槽
孵化需要时间或战斗次数
可用金币加速
```

---

## 5.4 孵化方式

孵化可以有 3 种方式：

### 方式 A：时间孵化

```text
放入宠物蛋
等待现实时间 / 游戏时间
时间到后领取宠物
```

适合手游，但会有养成等待感。

### 方式 B：战斗孵化

```text
放入宠物蛋
完成战斗 / 击杀怪物 / 获得经验
孵化进度增加
```

更适合单机体验。

### 方式 C：材料孵化

```text
放入宠物蛋
消耗指定材料
立即孵化或增加进度
```

推荐组合：

```text
战斗孵化为主
金币 / 材料加速为辅
```

---

## 5.5 孵化进度

孵化进度字段：

```text
EggID
CurrentProgress
RequiredProgress
StartTime
HatchMethod
BonusMaterial
```

示例：

```text
草原兽蛋
需要孵化值：100
普通战斗胜利 +8
精英战斗胜利 +20
Boss 胜利 +50
喂养草原果 +10
```

---

## 5.6 孵化结果

孵化结果由蛋配置决定。

```text
宠物种类池
品质概率
初始技能概率
性格概率
资质范围
```

示例：草原兽蛋

| 宠物 | 概率 |
|---|---:|
| 草原小犬 | 35% |
| 小草鼠 | 25% |
| 风耳兔 | 20% |
| 草叶蜥 | 15% |
| 稀有灵鹿 | 5% |

品质概率：

```text
普通 55%
优秀 30%
稀有 13%
史诗 2%
```

---

## 5.7 孵化界面表现

宠物蛋界面需要显示：

```text
宠物蛋图标
蛋名称
可能属性
孵化进度
剩余孵化值 / 时间
放入材料按钮
加速按钮
领取按钮
可能孵化预览，可选
```

孵化完成：

```text

光效
宠物出现
显示宠物名字、品质、类型、技能
按钮：出战 / 放入仓库
```

# 6. 宠物成长系统

## 6.1 宠物等级

宠物有独立等级：

```text
PetLevel
PetExp
MaxPetLevel
```

宠物等级不建议超过玩家太多：

```text
宠物等级上限 = 玩家等级 + 2
```

如果宠物等级超过玩家：

```text
可以保留等级，但属性按玩家等级上限临时压制
```

---

## 6.2 宠物经验来源

宠物经验来自：

```text
随玩家击杀怪物获得
完成任务获得
使用宠物经验道具
孵化时继承少量经验，特殊蛋
训练场培养
```

推荐：

```text
出战宠物获得 100% 宠物经验
未出战宠物获得 10%~20% 备用经验，可选
```

MVP：

```text
只有出战宠物获得经验
```

---

## 6.3 宠物属性成长

宠物有基础属性：

```text
HP
Attack
MagicAttack
Defense
MoveSpeed
CritRate
ElementPower
SkillCooldown
```

成长由 3 个部分决定：

```text
基础种族成长
品质倍率
资质随机值
```

公式：

```text
最终属性 = 基础属性 + 等级成长 × 品质倍率 × 资质倍率
```

品质倍率：

| 品质 | 成长倍率 |
|---|---:|
| 普通 | 1.00 |
| 优秀 | 1.12 |
| 稀有 | 1.28 |
| 史诗 | 1.50 |
| 传说 | 1.80 |

---

## 6.4 宠物资质

资质用于同种宠物差异。

```text
攻击资质
生命资质
防御资质
速度资质
技能资质
```

显示方式：

```text
C / B / A / S / SS
```

MVP 可以简化为：

```text
综合资质评分
```

---

## 6.5 宠物升星 / 进阶，可选

后续版本可以增加：

```text
宠物碎片
同名宠物材料
升星
外观变化
技能增强
```

MVP 不建议先做升星，避免系统过重。

# 7. 宠物技能系统

## 7.1 宠物技能分类

宠物技能分为：

```text
普通攻击
主动技能
被动技能
支援技能
探索技能
终结技，可选
```

每只宠物至少有：

```text
1 个普通攻击
1 个主动技能
1 个被动效果，可选
```

---

## 7.2 宠物技能槽

不同品质技能槽不同：

| 品质 | 主动技能槽 | 被动技能槽 |
|---|---:|---:|
| 普通 | 1 | 0 |
| 优秀 | 1 | 1 |
| 稀有 | 2 | 1 |
| 史诗 | 2 | 2 |
| 传说 | 3 | 2 |

MVP 推荐：

```text
普通攻击固定
主动技能最多 2 个
被动技能最多 1 个
```

---

## 7.3 技能学习方式

宠物技能可以通过：

```text
升级自动学习
技能书学习
宠物训练师学习
吞噬同类宠物，可选
宠物蛋孵化自带
任务解锁
```

---

## 7.4 技能替换规则

当技能槽满时：

```text
学习新技能需要选择替换旧技能
```

提示：

```text
是否用“火苗喷吐”替换“爪击强化”？
[取消] [替换]
```

不可替换技能：

```text
宠物普通攻击
种族核心技能
剧情绑定技能
```

---

## 7.5 宠物技能升级

技能升级方式：

```text
宠物等级达到要求自动升级
消耗宠物技能书升级
消耗金币和材料升级
```

推荐 MVP：

```text
宠物等级达到指定等级自动升级
```

示例：

```text
火苗喷吐 Lv1：宠物 Lv1
火苗喷吐 Lv2：宠物 Lv8
火苗喷吐 Lv3：宠物 Lv16
```

# 8. 宠物攻击与 AI 规则

## 8.1 宠物跟随规则

宠物跟随玩家，但不能卡住玩家。

宠物站位：

```text
玩家后方偏左 / 偏右
距离玩家 1.2~2.0 米
跟随目标位置在 XZ 平面上
Y 轴跟随地面高度
```

跟随时：

```text
如果距离玩家太远，快速追上
如果超过传送距离，直接瞬移到玩家附近
如果玩家进入副本 / 场景切换，宠物随玩家传送
```

参数：

```text
FollowDistance = 1.5
FollowStopDistance = 1.0
CatchUpDistance = 4.0
TeleportDistance = 10.0
```

---

## 8.2 宠物攻击目标选择

优先级：

```text
1. 玩家当前攻击目标
2. 正在攻击玩家的敌人
3. 距离玩家最近的敌人
4. 血量最低的敌人，攻击型宠物可选
5. 任务目标敌人
```

宠物不主动攻击：

```text
非战斗状态下太远的怪
玩家未拉仇恨的中立怪
剧情保护目标
```

---

## 8.3 宠物攻击频率

宠物攻击不能过密。

推荐：

```text
普通攻击间隔：1.2~2.0 秒
主动技能间隔：6~15 秒
辅助技能间隔：10~20 秒
治疗技能检测间隔：2 秒
```

---

## 8.4 宠物攻击范围

宠物也使用 3D 判定：

```text
X = 横向
Z = 纵深
Y = 高度
```

宠物技能 HitBox 必须有：

```text
SizeX
SizeY
SizeZ
OffsetX
OffsetY
OffsetZ
```

比如小狼扑咬：

```text
Box3D
SizeX = 0.9
SizeY = 0.7
SizeZ = 0.5
OffsetX = 0.6
OffsetY = 0.5
OffsetZ = 0
```

---

## 8.5 宠物不会干扰玩家操作

宠物需要遵守：

```text
不挡玩家移动
不挡玩家普攻
不挡玩家技能
不遮挡玩家角色太久
不挤开玩家
```

宠物 BodyBox 可以设置：

```text
SoftCollision = true
CanPushPlayer = false
CanBlockPlayer = false
```

但对敌人可以：

```text
CanBlockEnemy = false 或 true，按宠物类型
```

第一版推荐：

```text
宠物不阻挡任何单位，只作为视觉和攻击体存在
```

---

## 8.6 宠物受击规则

有两种方案：

### 方案 A：宠物不会被攻击

```text
宠物没有 HP
敌人不攻击宠物
宠物不会死亡
```

优点：

```text
简单
不增加治疗负担
玩家体验轻松
```

缺点：

```text
宠物真实感弱
防御型宠物玩法少
```

### 方案 B：宠物可受伤但不会永久死亡

```text
宠物有 HP
可以被敌人攻击
HP 归零后进入倒地 / 休眠
战斗结束后自动恢复
或一段时间后复活
```

推荐正式版采用方案 B。

MVP 推荐：

```text
方案 A，宠物不被攻击
```

# 30. 验收标准

## 30.1 宠物跟随验收

```text
宠物能稳定跟随玩家
宠物不会卡住玩家
宠物距离过远会追上或传送
场景切换后宠物仍然存在
```

## 30.2 宠物战斗验收

```text
宠物会选择合理目标
宠物会自动攻击
宠物技能有冷却
宠物攻击有伤害跳字
宠物技能不会遮挡玩家主要技能
宠物不会抢走玩家全部输出
```

## 30.3 抓取验收

```text
可抓取目标低血后显示图标
抓取按钮正确出现
使用抓取道具后计算成功率
成功后加入宠物仓库
失败后触发失败行为
道具数量正确扣除
```

## 30.4 孵化验收

```text
宠物蛋能放入孵化槽
战斗后孵化进度增加
材料加速有效
孵化完成能领取宠物
宠物加入仓库
孵化数据能存档
```

## 30.5 界面验收

```text
宠物列表清楚
宠物详情信息完整
出战按钮明确
技能信息可读
孵化界面能看懂进度
抓取结果弹窗清楚
```

# 32. 总结

宠物系统的核心闭环是：

```text
发现宠物 / 获得宠物蛋
→ 抓取 / 孵化
→ 加入宠物仓库
→ 选择 1 只出战
→ 跟随玩家战斗
→ 获得经验升级
→ 学习技能
→ 提供战斗和探索帮助
→ 收集更多宠物
```

第一版不要做得太重。  
先保证：

```text
能抓
能孵
能出战
能跟随
能打
能升级
能看界面
```

后续再扩展：

```text
升星
性格
羁绊
图鉴
宠物装备
多宠阵容
```
