# Combat Feedback Layer Sync

## 目标

在已有统一伤害链路基础上，补齐最小可玩的战斗反馈层，让当前原型具备：

- 受击硬直
- 基础击退
- 场景内敌人攻击预警占位表现
- 伤害数字跳字

## 本次范围

### 受击反馈

- `DamageRequest` 扩展受击硬直和击退参数
- 玩家与敌人通过统一受击消息接入反馈
- 角色移动在击退期间暂停，避免输入与受击位移互相抢占

### 攻击预警

- 为近战敌人补充运行时红圈预警占位
- 预警随蓄力进度增强透明度与颜色
- 先保证可读性，不引入正式美术资源依赖

### 伤害数字

- 所有主要受击对象接入最小伤害数字系统
- 暴击与玩家受伤使用不同颜色/缩放
- 采用运行时文本方案，方便后续替换为正式 UI/特效

## 本次不做

- 暂停帧
- 震屏
- 正式命中特效池
- Boss 多段预警图形
- 状态异常系统

## 后续建议

1. 将击退抗性和硬直抗性正式纳入 `CombatStats` 或敌人定义
2. 把预警从圆形占位扩展到扇形、矩形和跟踪预警
3. 将伤害数字改为对象池 + 世界空间 UI
4. 补正式受击闪白、命中特效和音效派发器
