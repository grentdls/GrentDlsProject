# Player Control System Sync

## 目标

将当前已搭建的玩家控制原型，与《角色基础操作系统设计文档》同步到同一套工程骨架中。

本次重点不是补完所有功能，而是把控制系统的“结构”先对齐：

- 明确玩家动作状态
- 拆分输入、状态、移动、攻击、翻滚、交互
- 补齐后续动画事件、技能、拾取的接入点

## 本次同步范围

### 结构对齐

- 新增明确的玩家动作状态枚举
- 新增玩家状态控制器
- 新增玩家普攻控制器
- 新增玩家交互控制器
- 让总控只负责协调输入和组件

### 规则对齐

- 普攻不再是按键即瞬发，而是带基础时序
- 翻滚加入无敌帧概念入口
- 受击加入短暂无敌时间入口
- 控制优先级开始向文档中的状态优先级靠拢

### 后续预留

- 动画事件接口
- 技能槽输入与施法状态
- 拾取系统
- 受击/死亡状态细化

## 本次不做

- 完整动画状态机
- 正式技能系统
- 自动拾取
- 震屏、完整音效、完整 2D 特效
- 精确到帧的美术联动

## 同步后的推荐下一步

1. 接技能 1~4 输入语义
2. 接玩家受击、死亡、复活状态
3. 接拾取系统与金币掉落
4. 接动画驱动层与事件帧
