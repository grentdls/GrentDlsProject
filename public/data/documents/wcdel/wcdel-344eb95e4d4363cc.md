# Starter Playable Slice

## 目标

本阶段在基础工程之上继续推进“首个可测试玩法切片”，目标是在 Unity 中尽快得到一个能直接验证核心手感的原型。

## 本次范围

### 玩家侧

- 玩家移动
- 普攻输入
- 普攻命中判定
- 交互输入

### 场景对象侧

- 可交互对象接口
- 可受击对象接口
- 简单测试木桩 / 训练假人

### 编辑器侧

- 一键创建测试启动对象
- 一键向当前场景注入玩家、相机、测试目标、交互点

## 切片完成标准

进入场景后应至少满足：

1. 玩家可用 WASD 移动
2. 玩家可按攻击键触发近战命中
3. 训练假人可掉血并在血量归零后销毁
4. 玩家靠近交互物后可触发交互
5. 当前场景可通过工具快速搭出最小测试环境

## 暂不包含

- 正式敌人 AI
- 正式技能释放
- 正式翻滚无敌帧
- 正式动画状态机
- HUD 与伤害数字
- 掉落物与奖励结算

## 后续顺序

在本切片跑通后，下一步建议接：

1. 翻滚与冷却
2. 伤害数字与受击反馈
3. 简单敌人追击和攻击
4. 交互点与任务目标联动
5. 首个草原测试场景布局
