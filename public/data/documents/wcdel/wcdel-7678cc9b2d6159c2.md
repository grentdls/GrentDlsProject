## 1. Unity Scene 基本信息

| 项目 | 配置 |
|---|---|
| Scene 名称 | `CH01_FirstSigh.unity` |
| 中文名 | `第一章_一声叹息` |
| 场景类型 | 单场景连续地图 + 区域分组 + 数据驱动刷点 |
| 坐标原点 | 狗尾草村中心广场 `(0,0,0)` |
| 推荐范围 | `X -60~430 / Z -60~170 / Y 0~12` |
| 主推进方向 | 狗尾草村 → 村口坡地 → 荒原边缘 → 龙渠 → 荒原入口 → 荒原外围 → 神龙平台 |
| 镜头方案 | Cinemachine 跟随 + 区域镜头触发 + Timeline 演出 |

## 3. Terrain 搭建结构

### 3.1 Terrain 参数建议

| 参数 | 建议值 |
|---|---:|
| Terrain Size X | 500 |
| Terrain Size Z | 260 |
| Terrain Height | 40 |
| Heightmap Resolution | 513 或 1025 |
| Control Texture Resolution | 1024 |
| Base Texture Resolution | 1024 |
| Detail Resolution | 1024 |
| Detail Density | 中低 |
| Tree Density | 低 |

### 3.2 区域高度

| 区域 | 高度范围 | 说明 |
|---|---:|---|
| A 狗尾草村 | Y 0~1 | 基本平坦 |
| B 村口坡地 | Y 0~3 | 缓坡，新手教学 |
| C 荒原边缘 | Y 1~2 | 轻微起伏 |
| D 枯井区 | Y -1~0 | 小凹地 |
| E 黑草坡 | Y 2~6 | 北侧斜坡 |
| F 小妖兽营地 | Y 1 | 背风凹地 |
| G 断裂龙渠 | Y -1~1 | 渠底下沉 |
| H 荒原入口 | Y 0~2 | 石柱夹道 |
| I 荒原外围 | Y 2~6 | 起伏明显 |
| J 神龙平台 | Y 8~10 | 高台演出区 |

### 敌人刷新规则

| 区域 | 规则 |
|---|---|
| 村庄 | 不刷常规敌人 |
