# 奖励资源图标化显示同步

## 目标

- 宝箱开启、任务奖励等资源奖励不再依赖纯文字描述。
- 奖励主体统一显示为图标 + 数量。
- 金币、经验、物品、装备、技能都可以使用同一套奖励图标行。
- 临时阶段允许程序化占位 ICON，后续可替换为正式美术资源。

## 运行时规则

- `QuestRewardEntry` 增加可选 `Icon` 字段，优先使用奖励自身图标。
- `RewardIconDisplayUtility` 负责生成奖励行 UI。
- 有真实图标时使用配置图标。
- 没有真实图标时运行时生成兜底图标，避免回退成纯文字奖励。
- 奖励行只显示资源图标和 `x数量`，名称不作为主显示内容。

## 接入位置

- 宝箱开启结果弹窗使用 `WorldInteractionOverlayPresenter.ShowRewardResult`。
- 战斗 HUD 任务奖励弹窗使用 `RewardRows` 图标行。
- 后台任务详情奖励区使用 `RewardRows` 图标行。
- 旧文字奖励字段只保留为无结构化奖励时的兜底说明。

## 临时 ICON 生成

Unity 菜单：

```text
Tools/WCDEL/资源图标/生成并绑定全部临时资源图标
```

生成目录：

```text
Assets/Game/Art/Icons/TempResources
```

工具会批量处理：

- `InventoryItemDefinition`
- `EquipmentDefinition`
- `SkillDefinition`
- 内置金币 / 经验占位图标

生成后会自动写入：

- `GameDefinition._icon`
- 道具 / 装备的 `_smallIcon`

## 后续注意

- 正式美术接入时可以直接替换对应定义资源的图标引用。
- 后续商店价格、任务需求、强化消耗也应复用这套图标 + 数量表现，不要新增纯文字资源列表。
