# 人物基础操作系统设计文档

> 参考方向：DNF 式横版清版动作游戏  
> 项目适配：2D 妖兽大陆动作 RPG  
> 角色表现：Q 版兽人角色 / 横版战斗 / 快节奏连招 / 技能释放 / 小范围位移  
> 文档目标：定义玩家角色的基础操作、输入规则、状态切换、动画播放、音效、特效、碰撞与手感标准。

---

## 1. 操作系统定位

### 1.1 玩法视角

本项目人物基础操作采用：

```text
横版清版动作游戏操作
```

核心参考：

```text
DNF 式横版战斗
```

也就是角色不是纯平台跳跃，也不是俯视角移动，而是：

```text
角色主要在横向场景内战斗
可以左右移动
可以上下小范围走位
可以跳跃
可以普攻连击
可以释放技能
可以被击飞、倒地、起身
可以通过技能取消和连招形成战斗节奏
```

### 1.2 移动平面

场景使用伪 2.5D 横版平面：

```text
X 轴：左右移动
Y 轴：上下走位，也就是画面深度方向
Z 轴：跳跃高度，只用于视觉和碰撞判定
```

可以理解为：

```text
玩家在一个横向房间中移动
左右是主要推进方向
上下是躲避、对位和调整攻击范围
跳跃是短时间离地状态
```

### 1.3 操作目标

人物操作必须满足：

```text
移动灵活
攻击响应快
跳跃有明确起落
技能释放清楚
受击反馈强
连招输入不丢
状态切换不乱
动画和判定一致
```

玩家感觉应该是：

```text
按下就动
攻击能接上
技能能打中
被打有反馈
起身能继续操作
```

## 3. 输入读取规则

### 3.1 输入优先级

同一帧出现多个输入时，优先级如下：

```text
死亡 / 强控状态 > 受击硬直 > 绝技 > 技能 > 闪避 > 跳跃 > 普攻 > 移动 > 待机
```

说明：

```text
角色死亡时不能操作
被强控时不能操作
受击硬直期间大部分操作无效
绝技优先级最高
技能优先级高于普攻
闪避可以打断部分普通动作
跳跃可以从地面状态触发
移动优先级最低
```

### 3.2 输入缓存

为了避免玩家按得太快导致输入丢失，需要输入缓存。

推荐规则：

```text
普攻输入缓存：0.25 秒
跳跃输入缓存：0.15 秒
闪避输入缓存：0.12 秒
技能输入缓存：0.25 秒
绝技输入缓存：0.3 秒
```

例子：

```text
玩家在普攻第 1 段后摇期间按下普攻
如果处于可连段窗口前 0.25 秒内
系统记录输入
进入可连段窗口后自动接第 2 段
```

### 3.3 输入缓冲只保留最后一次

为了防止乱连：

```text
每个动作类型只保留最后一次有效输入
```

例如：

```text
玩家连续按 J J J
系统可以按连段窗口依次触发
但不能在同一窗口内堆叠 3 次输入
```

### 3.4 输入取消条件

以下状态清空输入缓存：

```text
角色被击飞
角色倒地
角色死亡
角色进入剧情
角色进入地图切换
角色进入菜单
技能被打断
```

## 4. 角色状态机

### 4.1 一级状态

```text
Idle        待机
Move        移动
Jump        跳跃
Fall        下落
Land        落地
Dash        冲刺 / 闪避
Attack      普攻
Skill       技能
Ultimate    绝技
Hit         受击
Knockback   击退
Launch      浮空
Down        倒地
GetUp       起身
Interact    交互
Dead        死亡
```

### 4.2 状态切换总规则

```text
Idle 可以进入 Move / Jump / Dash / Attack / Skill / Interact
Move 可以进入 Idle / Jump / Dash / Attack / Skill / Interact
Jump 可以进入 Fall / AirAttack / AirSkill
Fall 可以进入 Land / Hit
Land 可以进入 Idle / Move / Attack
Dash 可以进入 Idle / Move / Attack / Skill
Attack 可以进入 AttackNext / SkillCancel / DashCancel / Idle
Skill 可以进入 SkillFollow / Idle / Move
Hit 可以进入 Knockback / Launch / Down / Idle
Down 可以进入 GetUp
GetUp 可以进入 Idle
Dead 不可切换
```

### 4.3 状态优先级

| 状态 | 是否可移动 | 是否可攻击 | 是否可受击 | 是否可被打断 |
|---|---:|---:|---:|---:|
| Idle | 是 | 是 | 是 | 是 |
| Move | 是 | 是 | 是 | 是 |
| Jump | 部分 | 部分 | 是 | 是 |
| Dash | 否 / 自动位移 | 否 | 部分 | 否 / 短暂无敌 |
| Attack | 否 / 微位移 | 否 | 是 | 部分 |
| Skill | 视技能 | 否 | 是 | 视技能 |
| Ultimate | 否 | 否 | 否 / 霸体 | 否 |
| Hit | 否 | 否 | 是 | 否 |
| Down | 否 | 否 | 部分 | 否 |
| GetUp | 否 | 否 | 否 / 起身无敌 | 否 |
| Dead | 否 | 否 | 否 | 否 |

## 5. 移动系统

### 5.1 基础移动

角色可以进行 8 方向输入，但实际表现为横版清版移动：

```text
左右移动影响角色朝向
上下移动用于站位调整
斜向移动会归一化速度
```

基础参数：

```text
基础移动速度：4.5 单位 / 秒
横向移动速度：100%
纵向移动速度：85%
斜向移动速度：归一化后 100%
加速度：20
减速度：25
```

### 5.2 移动方向

角色朝向以最后一次横向输入为准：

```text
按 D / 右：朝右
按 A / 左：朝左
只按 W / S：保持上一朝向
```

原因：

```text
横版战斗中攻击方向主要看左右
上下走位不能频繁改变角色朝向
```

### 5.3 移动动画

移动动画只分：

```text
Move_Right
Move_Left
```

其中：

```text
Move_Left 可以由 Move_Right 镜像
```

上下走位不需要单独动画，保留当前左右朝向播放移动动画。

### 5.4 移动判定

移动时角色有：

```text
身体碰撞框
脚底站位框
攻击受击框
```

推荐：

```text
身体碰撞框：角色宽度 45%，高度 70%
脚底站位框：角色底部椭圆区域
受击框：覆盖身体和头部
```

### 5.5 移动边界

角色不能穿过：

```text
地图边界
墙体
门
大型障碍物
不可通行地形
敌人实体，可根据设计选择是否软碰撞
```

推荐敌人碰撞：

```text
玩家和普通敌人轻微互斥
玩家和 Boss 强互斥
玩家不能完全穿过大型敌人
```

## 6. 跳跃系统

### 6.1 跳跃定位

跳跃不是平台跳跃，而是 DNF 式战斗跳跃：

```text
短距离离地
可以躲避部分地面攻击
可以进行空中攻击
落地后有短暂硬直
```

### 6.2 跳跃基础参数

```text
跳跃高度：1.5~2.0 单位
跳跃总时长：0.55~0.75 秒
起跳前摇：0.06 秒
上升时间：0.25 秒
下落时间：0.3 秒
落地硬直：0.08~0.12 秒
空中水平速度：地面速度的 80%
空中纵向速度：地面速度的 70%
```

### 6.3 跳跃阶段

```text
JumpStart 起跳
JumpRise 上升
JumpPeak 最高点
JumpFall 下落
Land 落地
```

### 6.4 跳跃期间允许操作

| 操作 | 是否允许 | 说明 |
|---|---:|---|
| 左右移动 | 是 | 空中可微调 |
| 上下移动 | 是 | 幅度较小 |
| 普攻 | 是 | 空中普攻 |
| 技能 | 部分 | 只有空中可用技能 |
| 冲刺 | 可选 | 空中闪避，默认不开 |
| 交互 | 否 | 空中不能交互 |
| 拾取 | 否 | 落地后拾取 |

### 6.5 地面攻击躲避规则

跳跃期间角色处于离地状态：

```text
Z 高度 > 0.4 时，可以躲避地面低段攻击
Z 高度 <= 0.4 时，仍可能被地面攻击命中
```

攻击类型需要标记高度：

```text
LowGroundAttack     地面低段
MidAttack           中段
HighAttack          高段 / 对空
AllHeightAttack     全高度
```

跳跃躲避关系：

| 攻击类型 | 跳跃是否可躲 |
|---|---:|
| 地面低段 | 是 |
| 中段 | 部分 |
| 高段 | 否 |
| 全高度 | 否 |

### 6.6 跳跃动画

需要动画：

```text
Jump_Start
Jump_Rise
Jump_Peak
Jump_Fall
Land
Air_Attack
```

动画帧数建议：

```text
Jump_Start：3 帧
Jump_Rise：3 帧
Jump_Peak：2 帧
Jump_Fall：3 帧
Land：3 帧
Air_Attack：5~6 帧
```

### 6.7 跳跃音效

```text
SFX_Jump_Start：起跳
SFX_Jump_Wind：空中轻风，可选
SFX_Land_Light：轻落地
SFX_Land_Heavy：高处落地或重击落地
```

### 6.8 跳跃特效

```text
起跳脚底小尘土
落地小尘土
空中攻击刀光
落地冲击圈，可选
```

## 7. 冲刺 / 闪避系统

### 7.1 冲刺定位

冲刺用于：

```text
快速接近敌人
躲避攻击
调整站位
取消部分后摇
```

### 7.2 基础参数

```text
冲刺距离：2.6 单位
冲刺时长：0.22 秒
冷却时间：0.65 秒
无敌时间：0.12 秒
后摇：0.08 秒
消耗：可选，默认不消耗
```

### 7.3 冲刺方向

优先使用当前移动输入方向：

```text
有方向输入：向输入方向冲刺
无方向输入：向当前朝向冲刺
```

横版建议：

```text
只要有左右输入，优先横向冲刺
只有上下输入时，进行短距离上下闪避
```

### 7.4 冲刺期间判定

```text
前 0.04 秒：启动，可被打
中间 0.12 秒：无敌
最后 0.06 秒：恢复，可被打
```

### 7.5 冲刺取消

允许冲刺取消：

```text
普攻后摇后半段
部分小技能后摇
受击起身后的移动恢复
```

禁止冲刺取消：

```text
技能前摇
绝技
被击飞
倒地
死亡
强控
```

### 7.6 冲刺动画

动画帧数建议：

```text
Dash_Start：2 帧
Dash_Move：3 帧
Dash_End：2 帧
总计 7 帧
```

视觉要求：

```text
身体前倾
脚步拖影
围巾向后拉长
尾巴被惯性甩后
地面有短尘土
```

## 8. 普通攻击系统

### 8.1 普攻定位

普攻是最基础输出方式：

```text
不消耗资源
可以三段连击
用于补伤害、打断小怪、接技能
```

### 8.2 三段普攻结构

```text
Attack_01：快速横斩
Attack_02：反向横斩
Attack_03：重劈 / 前冲斩
```

### 8.3 普攻输入

默认按键：

```text
J
```

输入规则：

```text
连续按 J 可以接下一段
每段攻击都有连段窗口
没有在窗口内输入则回到 Idle
```

### 8.4 普攻参数总表

| 攻击 | 前摇 | 命中帧 | 后摇 | 连段窗口 | 位移 | 伤害倍率 |
|---|---:|---:|---:|---:|---:|---:|
| 普攻 1 | 0.08s | 0.10~0.16s | 0.18s | 0.12~0.28s | 0.25 | 1.0 |
| 普攻 2 | 0.10s | 0.13~0.20s | 0.20s | 0.15~0.32s | 0.30 | 1.15 |
| 普攻 3 | 0.14s | 0.18~0.28s | 0.34s | 无 | 0.45 | 1.45 |

### 8.5 普攻 1：快速横斩

动作：

```text
身体小幅前倾
武器从后向前横扫
攻击范围中等
出手最快
```

判定：

```text
范围：前方 1.3 单位
宽度：0.8 单位
高度：中段
可命中：地面 / 中段敌人
```

反馈：

```text
轻命中特效
轻打击音
小硬直
```

### 8.6 普攻 2：反向横斩

动作：

```text
身体向另一侧扭转
武器反向扫回
范围略大于第一段
```

判定：

```text
范围：前方 1.4 单位
宽度：0.9 单位
高度：中段
```

反馈：

```text
中等刀光
中等打击音
敌人轻击退
```

### 8.7 普攻 3：重劈 / 前冲斩

动作：

```text
短暂蓄力
身体前冲
武器重击
打完后有明显收招
```

判定：

```text
范围：前方 1.7 单位
宽度：1.0 单位
高度：中段
击退：中
浮空：轻微，可选
```

反馈：

```text
较大刀光
重打击音
屏幕轻震
命中停顿 0.05 秒
```

### 8.8 普攻方向

普攻方向取角色当前朝向：

```text
朝右 → 攻击右侧
朝左 → 攻击左侧
```

普攻过程中：

```text
默认不能转向
如果攻击前 0.06 秒内输入反方向，可在出手前转向
出手后不能转向
```

### 8.9 普攻取消

可取消关系：

| 当前动作 | 可取消到 |
|---|---|
| 普攻 1 命中后 | 普攻 2 / 小技能 / 闪避 |
| 普攻 2 命中后 | 普攻 3 / 小技能 / 闪避 |
| 普攻 3 命中后 | 小技能 / 闪避，后摇后半段 |
| 普攻未命中 | 只能接下一段或等后摇 |

设计目的：

```text
命中后更流畅
打空有风险
鼓励玩家控制距离
```

## 9. 空中攻击

### 9.1 空中普攻

跳跃中按 J 触发：

```text
Air_Attack
```

动作：

```text
角色在空中向前挥砍
落地后有短暂硬直
```

参数：

```text
前摇：0.08s
命中：0.10~0.22s
落地硬直：0.15s
伤害倍率：1.1
击退：小
```

### 9.2 空中攻击落地规则

```text
如果攻击动画未播完但角色落地，转入 AirAttack_Land
如果攻击命中，可减少落地硬直 0.05s
如果攻击打空，完整落地硬直
```

## 10. 技能基础操作

### 10.1 技能分类

技能分为：

```text
小技能
中技能
大技能
绝技
被动技能
```

基础操作只定义释放规则，不定义具体技能数值。

### 10.2 技能按键

```text
U：技能 1
I：技能 2
O：技能 3
H：技能 4
Space：绝技
```

### 10.3 技能释放条件

必须满足：

```text
技能已解锁
技能已装配
冷却完成
资源足够
角色当前状态允许释放
没有被控制
目标方向有效
```

### 10.4 技能释放阶段

每个技能拆为：

```text
Start 前摇
Active 生效
Recovery 后摇
End 结束
```

部分技能增加：

```text
Charge 蓄力
Hold 持续
FollowUp 派生
```

### 10.5 技能取消规则

技能可从以下状态触发：

```text
Idle
Move
普攻命中后
部分跳跃状态
闪避结束后
```

不可触发：

```text
被击飞
倒地
硬控
死亡
剧情
地图切换
```

### 10.6 技能转向

技能出手前可以转向：

```text
前摇前 50% 时间允许根据输入转向
进入 Active 后锁定方向
```

### 10.7 技能打断

技能打断分 3 类：

```text
普通技能：可被重击打断
霸体技能：不会被普通攻击打断，但会受伤
无敌技能：不受伤，不被打断
```

### 10.8 技能 UI 反馈

技能按钮必须显示：

```text
技能图标

释放成功闪光
```

## 11. 绝技操作

### 11.1 绝技定位

绝技是角色大招：

```text
消耗怒气 / 能量
伤害高
表现强
短时间锁定角色状态
通常带霸体或无敌
```

### 11.2 释放条件

```text
能量满
角色非受击状态
角色非倒地状态
角色非死亡状态
没有处于剧情限制
```

### 11.3 绝技流程

```text
按下 Space
→ 角色进入 Ultimate_Start
→ 暂停普通输入
→ 镜头轻微聚焦
→ 播放大招动画
→ 造成伤害
→ 播放收招
→ 回到 Idle / Move
```

### 11.4 绝技保护

推荐：

```text
全程霸体
关键释放段无敌
不能被小怪打断
Boss 强控制可以打断，视设计
```

### 11.5 绝技输入缓冲

```text
按下后如果当前普攻即将进入可取消窗口
可缓存 0.3 秒
进入窗口后自动释放
```

参数：


## 28. 验收标准

### 28.1 移动验收

```text
按键后 1 帧内角色响应
左右转向明确
上下走位不改变左右朝向
斜向移动不会更快
碰撞不会穿墙
```

### 28.2 跳跃验收

```text
跳跃有起跳、上升、下落、落地
跳跃能躲避低段攻击
空中可进行一次普通攻击
落地硬直不拖沓
```

```text
三段普攻能稳定连上
每段攻击动作不同
命中帧和刀光一致

命中后可取消更流畅
```

```text
闪避距离明确

```

```text
轻重受击反馈不同

起身有保护

```

```text
技能按下有反馈
```

## 30. 总结

本操作系统的核心是：

```text
横版清版移动
左右朝向战斗
上下走位调整
跳跃躲地面攻击
三段普攻形成基础输出
闪避保证生存
技能提供爆发和连招变化
受击、击飞、倒地、起身形成完整动作反馈
```

玩家最基础的一套体验应该是：

```text
移动靠近敌人
上下走位避开攻击
跳跃躲地面技能
普攻三连打伤害
用闪避取消危险
释放技能补爆发
能量满后放绝技
被打倒后起身继续战斗
```
