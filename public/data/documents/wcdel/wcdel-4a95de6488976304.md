# First Skill And Revive Loop

## 目标

在当前人物基础操作原型上，补出两个真正可测试的 MVP 闭环：

- `Skill1` 的第一个真实技能
- 玩家死亡后的基础复活流程

## 本次范围

### 技能

- 使用 `SkillDefinition` 驱动第一个技能
- 技能槽 1 触发真实效果
- 技能效果选择“以玩家为中心的小范围火环”
- 可命中敌人和训练假人

### 死亡与复活

- 玩家血量归零进入死亡状态
- 提供基础复活入口
- MVP 采用“延迟后原地复活并回满生命”的低复杂度方案

### 编辑器

- 自动生成一个测试技能定义资产
- 自动把测试技能配置给当前玩家

## 验收目标

1. 按 `Skill1` 对应输入能触发火环技能
2. 技能命中周围敌人和训练假人
3. 玩家死亡后会进入死亡状态
4. 达到延迟后玩家自动恢复生命并回到可操作状态

## 本次不做

- 蓝量系统
- 技能图标与正式 HUD
- 技能冷却 UI
- 死亡回城 / 复活点
- 正式掉落和奖励
