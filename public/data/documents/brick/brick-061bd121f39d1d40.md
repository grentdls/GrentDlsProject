# BrickSurvivor UI Art Generation Prompts

The ChatGPT style-GPT link is account/session gated, so generate from your logged-in browser and save the results here:

`Assets/Art/BrickSurvivor/UIRaw`

After downloading images, run:

`Tools/BrickSurvivor/process_ui_assets.bat`

Processed transparent PNG sprites will be written to:

`Assets/Resources/BrickSurvivor/UI/Generated`

## Global Prompt Suffix

Append this to every generation request:

```text
PNG format. Transparent background. Background completely transparent. No background color. No white background. No scene. No sky, ground, shadow, reflection, floor, vignette, gradient, or decorative backdrop. Only isolated UI asset subjects. Clean alpha edges. High resolution. Game UI slicing ready. Keep every UI element separated with generous transparent spacing. Do not merge elements. Do not include text unless explicitly requested. Do not include watermark. Independent game/UI asset style.
```

## Atlas Layout Prompt

Use this when asking for multiple assets in one image:

```text
Create one transparent PNG atlas sheet containing separate isolated UI assets arranged in a clean grid. Each asset must be visually separated by transparent empty space so it can be cut into individual PNGs. No background. Do not use shadows outside the asset shape. Keep alpha edges clean.
```

## Download And Process

1. Download each generated image as PNG if possible.
2. Put every downloaded image into `Assets/Art/BrickSurvivor/UIRaw`.
3. Run `Tools/BrickSurvivor/process_ui_assets.bat`.
4. Check `Assets/Resources/BrickSurvivor/UI/Generated/generated_ui_manifest.json`.
5. If an atlas does not split well, rerun with a forced category:

```bat
Tools\BrickSurvivor\process_ui_assets.bat --category Buttons
Tools\BrickSurvivor\process_ui_assets.bat --category Frames
Tools\BrickSurvivor\process_ui_assets.bat --category Icons
```
