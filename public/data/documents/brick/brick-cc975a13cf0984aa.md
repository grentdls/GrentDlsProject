# 太空3D积木飞船幸存者：100种积木改造BD列表

版本：V0.1  
用途：局内升级三选一 BD 池、事件奖励池、稀有部件掉落池、积木背包配置参考

---

## 1. 设计目标

本列表用于扩充游戏中的“积木改造块”系统。每一种改造块都可以作为局内 BD 奖励出现，玩家选择后可以直接安装到飞船上，或者进入积木背包等待后续安装。

积木改造块的核心设计目标：

1. **每个改造块都是真实可安装的积木部件**，而不是单纯数值被动。
2. **每个改造块都有尺寸、方向、连接规则和战斗价值**。
3. **BD 选择后要改变飞船结构、外观和打法**。
4. **不同改造块之间可以形成流派组合**，例如正面火力、侧翼扫射、重甲堡垒、自动索敌、冲撞碾压、巨舰扩展、事件收益流。
5. **列表可直接作为后续配置表基础**，方便拆分成 ScriptableObject / DataTable / JSON。

---

## 2. 改造块通用字段

每个改造块建议配置以下字段：

| 字段 | 说明 |
|---|---|
| ID | 唯一编号 |
| 名称 | BD 卡与背包中的显示名称 |
| 分类 | 链接 / 防御 / 攻击 / 辅助 / 特殊规则 |
| 稀有度 | 普通 / 优秀 / 稀有 / 史诗 / 传奇 |
| 尺寸 | 必须以 1 立方米为基础单位，例如 1×1×1、3×1×1 |
| 安装方向 | 是否需要朝向，是否影响效果 |
| 连接规则 | 哪些面可以连接，哪些区域不能连接 |
| 主效果 | 安装后提供的主要能力 |
| 适合流派 | 推荐构筑方向 |
| UI提示 | BD 卡、背包、安装预览中的提示内容 |

---

## 3. 稀有度建议

| 稀有度 | 颜色建议 | 设计定位 |
|---|---|---|
| 普通 | 白色 / 灰色 | 基础扩展，数值稳定 |
| 优秀 | 蓝色 | 明确强化某一方向 |
| 稀有 | 紫色 | 开始形成流派核心 |
| 史诗 | 橙色 | 强规则改变，明显影响构筑 |
| 传奇 | 金色 | 核心流派组件，改变战斗方式 |

# 7. UI表现建议

## 7.1 BD卡牌表现

每张改造块 BD 卡应显示：

1. 改造块名称。
2. 稀有度边框。
3. 3D小模型或图标。
4. 分类标签：链接 / 防御 / 攻击 / 辅助 / 特殊。
5. 尺寸标识，例如 `3×1×1`。
6. 是否需要安装方向。
7. 主要效果描述。
8. 推荐流派标签。

示例：

```text
星核歼灭炮
传奇 / 攻击 / 3×2×1
朝安装方向周期性发射超高伤害能量束。
击杀敌人后缩短冷却。
推荐：正面火力 / 巨舰主炮
```

---

## 7.2 积木背包表现

背包中每个改造块显示：

| UI元素 | 说明 |
|---|---|
| 部件图标 | 按分类和稀有度显示 |
| 尺寸角标 | 例如 1×1×1、2×2×1 |
| 安装方向箭头 | 对攻击、防御方向块很重要 |
| 分类颜色条 | 链接灰、防御黄、攻击红、辅助蓝、特殊紫 |
| 可安装提示 | 当前有合法位置时显示绿色边框 |
| 不可安装原因 | 无连接点 / 空间不足 / 与部件重叠 |

---

## 7.3 安装预览提示

安装时应显示：

1. 绿色高亮：可安装区域。
2. 红色高亮：非法区域。
3. 黄色高亮：推荐安装区域。
4. 蓝色范围圈：辅助影响范围。
5. 红色射线：攻击方向。
6. 黄色护盾面：防御覆盖方向。
7. 白色连接线：新部件与飞船核心的连接路径。
