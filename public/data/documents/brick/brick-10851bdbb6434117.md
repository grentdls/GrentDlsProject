# 太空3D积木飞船幸存者：积木搭建交互与完整UI预制体方案

版本：V0.2  
定位：3D太空幸存者 / 积木飞船构筑 / 局内BD三选一 / 可视化模块成长  
文档重点：积木搭建方案、可搭建提示、积木背包、BD列表、战斗HUD、伤害跳字、全UI预制体结构

---

# 1. 本版设计目标

本版主要解决三个问题：

1. **玩家知道哪里可以搭建**
   - 飞船上必须有清晰的可搭建高亮。
   - 选中部件后，合法连接点、非法连接点、推荐连接点都要有不同提示。
   - 不允许玩家靠猜来搭建。

2. **玩家知道为什么不能搭建**
   - 不能只显示红色。
   - 必须显示具体原因，例如：
     - 没有连接到基础块。
     - 攻击块不能参与连接。
     - 与已有部件重叠。
     - 超出飞船体积限制。
     - 连接后无法追溯到核心。
     - 方向错误，武器炮口被遮挡。

3. **整个UI用预制体结构搭建**
   - 战斗HUD、BD三选一、积木背包、安装界面、跳字、提示、结算等全部预制体化。
   - 每个UI模块都能单独替换、隐藏、扩展。
   - 方便程序、美术、策划共同维护。

---

# 2. 积木搭建核心方案

## 2.1 搭建基础逻辑

玩家飞船由多个部件组成，每个部件以 `1m × 1m × 1m` 为最小单位。

部件分为：

| 类型 | 主要功能 | 是否可提供连接 | 说明 |
|---|---|---|---|
| 核心部件 | 飞船核心，死亡则失败 | 是 | 初始部件 |
| 链接部件 | 扩展船体结构 | 是 | 搭建其他部件的主要基础 |
| 防御部件基础块 | 承载防御块 | 是 | 只有基础块可连接 |
| 防御块 | 减伤、免伤、护盾 | 否 | 不能连接其他部件 |
| 攻击部件基础块 | 承载攻击块 | 是 | 只有基础块可连接 |
| 攻击块 | 发射子弹、激光、导弹等 | 否 | 不能连接其他部件 |
| 辅助部件基础块 | 承载辅助块 | 是 | 只有基础块可连接 |
| 辅助块 | 增益全局或区域 | 否 | 不能连接其他部件 |

---

## 2.2 部件组成规则

### 链接部件

```text
[链接块]
```

特点：

- 整个部件都可以作为连接结构。
- 适合扩展飞船长度、宽度、高度。
- 可提供多个连接面。
- 没有额外上层模块。

---

### 防御部件

```text
[防御块]
[基础块]
```

规则：

- 基础块可以连接其他基础块或链接部件。
- 防御块不能连接其他部件。
- 敌人攻击命中防御块覆盖区域时，触发减伤或免伤。
- 防御块被遮挡时仍然可以提供生命，但无法作为有效受击防御面。

---

### 攻击部件

```text
[攻击块]
[基础块]
```

规则：

- 基础块可以连接。
- 攻击块不能连接。
- 攻击块需要朝向。
- 如果炮口方向被其他部件遮挡，则该武器进入“受阻”状态。
- 受阻状态下不会开火，或者只保留部分攻击能力。

---

### 辅助部件

```text
[辅助块]
[基础块]
```

规则：

- 基础块可以连接。
- 辅助块不能连接。
- 部分辅助块提供全局效果。
- 部分辅助块提供区域效果。
- 区域效果需要在搭建界面中显示影响范围。

# 3. 可搭建点提示系统

## 3.1 搭建点分类

飞船上所有可搭建点都应被系统扫描，并分成不同状态。

| 状态 | 颜色建议 | 表现 | 含义 |
|---|---|---|---|
| 可搭建 | 绿色 | 半透明方框 + 呼吸光 | 当前部件可以安装 |
| 推荐搭建 | 金色 | 绿色框外加金色箭头 | 安装后收益较高 |
| 不可搭建 | 红色 | 红色方框 + 禁止图标 | 当前部件不能安装 |
| 方向受阻 | 橙色 | 炮口前方显示阻挡线 | 能安装，但武器会被遮挡 |
| 连接风险 | 黄色 | 闪烁连接线 | 该处被打断后容易脱落 |
| 辅助增益区 | 蓝色 | 范围网格/半透明罩 | 可被辅助部件强化 |
| 防御覆盖区 | 青色 | 护甲投影区域 | 安装后保护的方向 |

---

## 3.2 搭建高亮表现

当玩家进入安装模式时：

1. 飞船整体稍微变暗。
2. 可搭建基础块边缘发光。
3. 当前选中部件显示半透明预览。
4. 合法位置显示绿色投影。
5. 非法位置显示红色投影。
6. 推荐位置额外显示金色箭头。
7. 当前连接路径显示发光线，能追溯到核心。

### 推荐画面结构

```text
当前飞船：正常颜色，透明度 80%
可连接点：绿色小方框
推荐连接点：金色边框 + 小箭头
非法区域：红色网格
当前预览部件：半透明模型
连接到核心路径：蓝色发光线
```

---

## 3.3 连接点显示规则

每个基础块最多有六个连接方向：

```text
上、下、左、右、前、后
```

### 连接面UI

每个连接面都可以显示一个小型连接面提示：

| UI元素 | 说明 |
|---|---|
| FaceSlot_Green | 该面可以连接 |
| FaceSlot_Red | 该面不能连接 |
| FaceSlot_Yellow | 可连接但风险较高 |
| FaceSlot_Gold | 推荐连接 |
| FaceSlot_Locked | 当前规则下未解锁 |
| FaceSlot_BlockIcon | 被其他部件阻挡 |

---

## 3.4 安装失败原因提示

当玩家指向非法位置时，必须显示具体原因。

### 失败原因列表

| 失败原因 | UI提示文本 |
|---|---|
| 没有连接到飞船 | 需要连接到已有基础块 |
| 连接到非基础块 | 攻击块/防御块/辅助块不能作为连接点 |
| 与已有部件重叠 | 当前部件与已有结构重叠 |
| 超出体积限制 | 飞船当前最大尺寸不足 |
| 连接路径无效 | 该部件无法连接回核心 |
| 炮口被遮挡 | 武器方向被阻挡，无法正常开火 |
| 辅助块被遮挡 | 辅助模块区域被阻挡 |
| 防御面朝向错误 | 该方向无法有效承受攻击 |
| 部件数量上限 | 当前飞船部件数量已满 |
| 质量超限 | 当前推进能力不足以承载该部件 |
| 特殊部件限制 | 该部件只能安装在指定方向或区域 |

### 提示表现

```text
红色提示条：
无法安装：当前部件没有连接到基础块

橙色提示条：
可安装，但炮口被遮挡，武器无法开火

黄色提示条：
可安装，但该连接点距离核心较远，容易被打断
```

# 4. 推荐搭建系统

## 4.1 推荐逻辑目标

推荐搭建不是替玩家做决定，而是帮助玩家理解当前部件适合装在哪里。

系统根据部件类型给出不同推荐。

---

## 4.2 攻击部件推荐规则

### 固定方向武器

推荐位置：

1. 船头前方。
2. 左右侧翼外侧。
3. 船尾后方。
4. 没有遮挡的外边缘。
5. 能被攻击辅助模块覆盖的位置。

不推荐位置：

1. 炮口前方被挡住。
2. 装在飞船内部。
3. 装在容易断裂的单点连接末端。
4. 装在防御块后方导致无法开火。

### UI提示示例

```text
推荐：该位置炮口无遮挡，可攻击前方敌人
推荐：该位置处于武器增幅器范围内，伤害 +20%
警告：该武器安装后只能攻击后方
警告：炮口前方被装甲遮挡，无法开火
```

---

## 4.3 防御部件推荐规则

推荐位置：

1. 核心前方。
2. 飞船外边缘。
3. 经常受撞击的船头。
4. 关键连接梁外侧。
5. 高价值武器前方或侧方。

不推荐位置：

1. 飞船内部。
2. 防御面朝内。
3. 防御块被其他部件遮挡。
4. 远离核心且连接脆弱的位置。

### UI提示示例

```text
推荐：该位置可以保护核心正面
推荐：该位置可以保护侧翼武器
警告：防御面朝向内部，保护效果较低
警告：该装甲被其他部件遮挡，受击概率较低
```

---

## 4.4 辅助部件推荐规则

推荐位置：

1. 多个攻击部件中间。
2. 核心附近。
3. 防御部件密集区域。
4. 同类武器集群附近。
5. 不容易被撞掉的位置。

### 区域辅助高亮

选中辅助部件时，需要显示：

```text
蓝色半透明范围
被影响部件描边发光
右侧列表显示受影响部件数量
```

### UI提示示例

```text
该位置可强化 4 个攻击部件
该位置可覆盖 2 个防御部件
该辅助模块距离核心较近，较安全
该位置只影响 1 个部件，收益较低
```

---

## 4.5 链接部件推荐规则

推荐位置：

1. 核心周围。
2. 武器扩展方向。
3. 防御缺口方向。
4. 能形成多点连接的位置。
5. 能增加未来可搭建空间的位置。

### UI提示示例

```text
推荐：该连接块可以新增 4 个可安装点
推荐：该位置可形成双连接，结构更稳定
警告：该部件只有单点连接，断裂风险较高
警告：继续向该方向扩展会导致飞船过宽
```

# 5. 积木安装操作流程

## 5.1 局内升级安装流程

```text
玩家升级
→ 弹出BD三选一
→ 玩家选择“获得新部件”
→ 进入积木安装模式
→ 飞船周围显示可搭建高亮
→ 玩家移动预览部件
→ 系统实时显示合法/非法/推荐提示
→ 玩家旋转部件方向
→ UI实时显示属性变化
→ 玩家确认安装
→ 播放积木咔哒安装表现
→ 回到战斗
```

---

## 5.2 背包安装流程

```text
玩家打开积木背包
→ 选择已有未安装部件
→ 点击安装
→ 进入安装模式
→ 选择连接点与方向
→ 确认安装
→ 背包数量减少
→ 飞船结构刷新
```

---

## 5.3 快速安装模式

为了避免幸存者玩法节奏被打断太久，需要提供快速安装。

### 快速安装规则

当玩家选择部件后，系统自动给出 3 个推荐安装位。

| 推荐位 | 逻辑 |
|---|---|
| 推荐位1 | 当前收益最高 |
| 推荐位2 | 最安全 |
| 推荐位3 | 最适合当前流派 |

玩家可以：

```text
直接点击推荐位安装
或点击“手动调整”进入完整安装模式
```

---

## 5.4 安装模式时间控制

为了保持战斗节奏，安装模式建议有三种方案。

### 方案A：完全暂停

适合新手、普通难度。

```text
进入安装模式时，战斗完全暂停。
```

优点：理解成本低。  
缺点：节奏会被频繁打断。

### 方案B：子弹时间

适合默认模式。

```text
进入安装模式时，战斗速度降低到 10%-20%。
```

优点：保留紧张感。  
缺点：操作压力略高。

### 方案C：限时安装

适合高难度或无尽模式。

```text
玩家需要在 10 秒内完成安装。
超时后自动安装到推荐位置，或转化为碎块。
```

# 6. 积木背包界面

## 6.1 背包定位

积木背包用于管理玩家当前拥有但未安装的部件。

玩家可能通过以下方式获得未安装部件：

1. BD选择奖励。
2. 精英掉落。
3. 小星球事件。
4. 商店购买。
5. 部件残片合成。
6. 拆除飞船部件回收。

---

## 6.2 背包打开方式

| 输入 | 效果 |
|---|---|
| Tab | 打开/关闭积木背包 |
| B | 打开背包 |
| 升级后选择新部件 | 自动打开安装界面 |
| 点击HUD中的积木图标 | 打开背包 |
| 战斗暂停菜单 | 可进入背包查看 |

# 7. BD列表界面

## 7.1 BD系统界面目标

BD列表不是简单记录，而是让玩家知道当前流派已经成型到什么程度。

BD列表需要显示：

1. 已获得BD。
2. 当前流派倾向。
3. 各流派加成汇总。
4. 已经强化过哪些部件。
5. 可与当前部件形成联动的BD。

# 10. 伤害跳字系统

## 10.1 跳字设计目标

伤害跳字要做到：

1. 清楚反馈攻击是否有效。
2. 不遮挡主要战斗画面。
3. 能区分伤害类型。
4. 大量伤害时自动合并，避免满屏数字。
5. Boss和精英伤害显示更明显。
6. 玩家受伤和敌人受伤要明显不同。

---

## 10.2 跳字类型

| 类型 | 显示内容 | 颜色建议 | 表现 |
|---|---|---|---|
| 普通伤害 | `12` | 白色 | 小幅上浮 |
| 暴击伤害 | `CRIT 36` | 黄色/橙色 | 放大弹出 |
| 激光伤害 | `8` | 蓝白 | 连续细小跳字 |
| 导弹爆炸 | `52` | 橙红 | 震动弹出 |
| 闪电伤害 | `18` | 紫蓝 | 抖动跳跃 |
| 穿透伤害 | `14` | 青色 | 斜向飘出 |
| 冲撞伤害 | `撞击 80` | 红橙 | 大字震屏 |
| 护盾吸收 | `护盾 -20` | 蓝色 | 出现在护盾处 |
| 减伤 | `减免 15` | 灰蓝 | 小字 |
| 免疫 | `免疫` | 灰白 | 固定短显 |
| 修复 | `+12` | 绿色 | 向上飘 |
| 玩家受伤 | `-25` | 红色 | 屏幕边缘红闪 |

---

## 10.3 跳字分层

### 敌人跳字

显示在敌人头顶或命中点附近。

普通小怪跳字可合并。

```text
同一敌人在0.3秒内受到多次小伤害
→ 合并为一个累计跳字
```

例如：

```text
5、6、4、5
→ 显示为 20
```

---

### Boss跳字

Boss跳字需要更加克制。

建议显示：

1. 关键暴击。
2. 高额爆炸。
3. 阶段伤害。
4. 每秒累计伤害。

Boss普通持续伤害可以合并成小型DPS数字。

---

### 玩家受伤跳字

玩家受到伤害时，跳字不应该只在飞船上显示，还需要HUD反馈。

表现：

1. 被打中的部件弹出红色伤害数字。
2. 中下方飞船完整度震动。
3. 核心受击时屏幕轻微红闪。
4. 防御部件减伤时显示“减免”。

---

## 10.4 跳字动画规则

| 阶段 | 时间 | 表现 |
|---|---:|---|
| 出现 | 0-0.1s | 从小到大弹出 |
| 停留 | 0.1-0.4s | 保持可读 |
| 漂移 | 0.4-0.8s | 向上或侧上方移动 |
| 消失 | 0.8-1.0s | 透明度降低 |

暴击跳字：

```text
出现瞬间放大到 140%
然后回弹到 100%
再向上飘走
```

冲撞跳字：

```text
大幅弹出
左右震动
短暂残影
```

# 16. 新手引导方案

## 16.1 第一次升级引导

当玩家第一次升级时：

```text
弹出BD三选一

玩家选择后进入安装模式
高亮核心周围可安装点
显示提示：绿色区域可以安装积木
玩家确认安装
```

## 16.2 第一次非法安装提示

当玩家第一次尝试非法安装：

```text
暂停操作
弹出说明：
红色区域表示无法安装。
当前原因：攻击块不能连接其他部件。
请将基础块对准绿色连接点。
```

```text
显示蓝色范围

该辅助部件可以强化范围内的攻击模块。
安装在多个武器中间收益更高。
```

```text
连接梁被摧毁，外侧部件失去核心连接并脱落。
可以使用更多链接块形成稳定结构。
```

# 18. 程序实现建议

## 18.1 搭建检测数据结构

每个部件需要配置：

```text

SizeY
SizeZ
Mass
HP
BaseCells
TopCells
ConnectableFaces
BlockedFaces
AttackDirection
DefenseDirection
SupportRange

Rarity
Tags
```

---

## 18.2 安装检测流程

```text
1. 获取当前预览位置
2. 检测是否与已有格子重叠
3. 检测基础块是否接触已有可连接面
4. 检测接触对象是否为可连接基础块
5. 检测是否能追溯到核心
6. 检测是否超出飞船尺寸和质量限制
7. 检测攻击/防御/辅助块是否被遮挡
8. 生成安装评分
9. 返回状态：合法/非法/推荐/风险
10. UI根据状态刷新高亮和提示
```

---

## 18.3 推荐安装评分

```text
安装评分 =
连接稳定性评分
+ 部件收益评分
+ 安全性评分
+ 当前流派匹配评分
+ 遮挡惩罚
+ 断裂风险惩罚
+ 质量惩罚
```

### 示例

攻击部件评分：

```text
攻击评分 =
炮口无遮挡 +30
处于辅助范围 +20
朝向当前敌群主要方向 +15
距离核心较近 +10
连接点稳定 +10
炮口被遮挡 -50
单点远端连接 -20
```

防御部件评分：

```text
防御评分 =
保护核心 +30
位于受击高频方向 +25
保护高价值武器 +15
外侧覆盖 +10
防御面朝内 -40
被其他部件遮挡 -20
```

# 20. 最终效果目标

玩家在搭建时应该形成这样的体验：

```text
我选中了一个新炮塔。
飞船上马上亮起绿色和金色的可安装点。
我移动到船头，系统提示“推荐：炮口无遮挡，可攻击前方敌人”。
我移动到飞船内部，系统显示红色，并提示“炮口被遮挡，无法开火”。
我把炮塔装到侧翼，右侧属性预览显示“侧翼火力 +18”。
确认后，炮塔咔哒一声拼到飞船上，回到战斗后立刻朝侧面开火。
```

玩家在战斗时应该形成这样的体验：

```text
我能清楚看到核心血量、飞船完整度、当前经验和升级进度。
敌人从屏幕外靠近时有方向提示。
我的炮弹打中敌人会有清晰跳字。
装甲减伤、护盾吸收、暴击、冲撞都有不同反馈。
当某个连接梁快断时，HUD和飞船本体都会警告我。
```

整个UI的目标不是堆信息，而是帮助玩家理解：

```text
哪里可以搭
为什么不能搭
怎么搭收益更高
当前飞船哪里强
当前飞船哪里弱
下一次升级应该往什么流派走
```

只要这些信息表达清楚，积木飞船构筑玩法就会变得直观、爽快、有深度。
