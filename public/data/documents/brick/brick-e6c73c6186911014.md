# 太空3D积木飞船幸存者：50种敌人与战斗节奏、UI表现完整方案

版本：V0.1  
定位：3D太空幸存者 / 积木飞船构筑 / 敌潮推进 / 精英与Boss节奏 / 战斗HUD方案  
用途：用于策划配置、程序实现、UI预制体搭建、怪物预制体制作、数值表拆分。

---

# 1. 设计目标

当前战斗如果只是持续刷普通怪，会产生以下问题：

1. 玩家只需要围绕敌潮移动，目标感不足。
2. 每局节奏变化不明显，缺少高潮。
3. 精英、Boss、事件任务没有明确预告，玩家容易突然暴毙。
4. 飞船积木构筑虽然有深度，但战斗压力没有逼迫玩家调整结构。
5. UI没有把“下一波敌潮”“Boss即将出现”“当前阶段目标”传达给玩家。

本方案的目标是：

```text
普通刷怪维持压力
→ 定时敌潮制造高潮
→ 精英怪改变玩家走位和构筑需求
→ Boss作为阶段大目标
→ 顶部进度条清晰预告整局节奏
→ 全局HUD让玩家知道下一步要面对什么
```

# 2. 战斗节奏总框架

## 2.1 单局标准时长

标准单局时长建议：20分钟。

也可以扩展为：

| 模式 | 时长 | 说明 |
|---|---:|---|
| 快速模式 | 10分钟 | 适合Demo和移动端碎片时间 |
| 标准模式 | 20分钟 | 正式主模式 |
| 无尽模式 | 无限 | 20分钟后循环高压阶段 |

本文档以 **20分钟标准局** 为基准设计。

---

## 2.2 战斗节奏结构

一局战斗由以下节奏组成：

```text
持续小怪刷新
+ 每60秒一次小规模敌潮
+ 每180秒一次精英刷新
+ 每300秒一次大型特殊事件或Boss前压迫
+ 第10分钟中Boss
+ 第20分钟最终Boss
```

### 节奏层级

| 节奏层级 | 触发频率 | 作用 |
|---|---:|---|
| 基础刷新 | 每2-6秒 | 保持持续战斗压力 |
| 小敌潮 | 每60秒 | 制造短时间密度提升 |
| 大敌潮 | 每120秒 | 逼迫玩家使用机动和范围输出 |
| 精英怪 | 每180秒 | 引入特殊机制和奖励 |
| 危险事件 | 每240-300秒 | 改变场地或目标 |
| 中Boss | 第10分钟 | 检验中期构筑成型度 |
| 最终Boss | 第20分钟 | 单局终局目标 |

# 3. 顶部战斗进度条设计

## 3.1 UI定位

顶部战斗进度条是整局节奏的核心提示UI。

它需要告诉玩家：

1. 当前已经坚持了多久。
2. 下一次敌潮还有多久。
3. 下一只精英还有多久。
4. Boss会在什么时候出现。
5. 当前阶段的危险等级。
6. 是否有正在进行的占领、保护、采矿等任务。

---

## 3.2 顶部进度条布局

```text
┌─────────────────────────────────────────────┐
│ 00:00        05:00        10:00        20:00 │
│ ━━━━━●━━━━▲━━━━★━━━━▲━━━━●━━━━☠━━━━━━ │
│ 当前时间：07:35       下一精英：25秒后       │
└─────────────────────────────────────────────┘
```

### 图标含义

| 图标 | 含义 | 颜色建议 |
|---|---|---|
| 小圆点 | 小敌潮 | 黄色 |
| 双箭头 | 大敌潮 | 橙色 |
| 菱形 | 精英怪 | 紫色 |
| 星形 | 战斗事件 | 蓝色 |
| 骷髅 | Boss | 红色 |
| 闪电 | 危险区域变化 | 青色 |
| 宝箱 | 奖励事件 | 金色 |

---

## 3.3 进度条状态表现

### 平时状态

- 进度条细线显示。
- 当前时间点有发光游标。
- 即将到来的事件图标轻微呼吸。

### 事件即将发生，10秒倒计时

- 对应图标放大。
- 顶部出现倒计时。
- 屏幕边缘出现方向提示。
- 音效播放低频预警。

表现示例：

```text
敌潮即将来袭：10
敌潮即将来袭：9
敌潮即将来袭：8
```

### Boss即将出现，30秒倒计时

Boss提示必须比普通事件更强。

表现：

1. 顶部Boss图标变大并变红。
2. 屏幕四周出现红色扫描线。
3. 背景音乐进入Boss前奏。
4. 中央出现巨大警告文字。
5. 小地图上出现Boss接近方向。
6. 远处空间出现红色裂缝或巨型传送门。

UI文字：

```text
警告：高能反应正在接近
Boss将在30秒后进入战场
```

# 5. 刷怪导演系统

## 5.1 核心概念

刷怪不应该只是固定数量，而应该使用“威胁预算”。

每个敌人有一个威胁值，系统根据当前时间、玩家等级、飞船强度生成敌人组合。

```text
当前可用威胁预算 = 时间基础预算 + 玩家等级预算 + 阶段事件预算
```

---

## 5.2 威胁预算示例

| 时间段 | 基础预算/10秒 | 小敌潮预算 | 大敌潮预算 | 精英预算 |
|---|---:|---:|---:|---:|
| 0-3分钟 | 20 | 60 | 100 | 120 |
| 3-7分钟 | 35 | 100 | 160 | 220 |
| 7-10分钟 | 55 | 160 | 260 | 350 |
| 10-15分钟 | 80 | 240 | 380 | 500 |
| 15-20分钟 | 120 | 360 | 560 | 750 |

---

## 5.3 敌人威胁值

| 敌人级别 | 威胁值范围 | 示例 |
|---|---:|---|
| 小怪 | 3-10 | 蜂群无人机、小追撞机 |
| 普通怪 | 10-25 | 炮艇、自爆水雷 |
| 中型怪 | 25-60 | 重型冲撞舰、护盾艇 |
| 特殊怪 | 60-120 | 干扰舰、修复舰、召唤舰 |
| 精英怪 | 150-500 | 精英冲撞舰、精英炮台舰 |
| Boss | 独立预算 | 中Boss、最终Boss |

| 方向 | 作用 | 常见敌人 |
|---|---|---|
| 正前方 | 主压力来源 | 冲撞舰、护盾舰、Boss |

# 7. 敌人详细设计

## 7.1 E001 小型追撞机

### 定位

最基础的冲撞怪，负责让玩家熟悉移动和自动攻击。

### 行为逻辑

```text
生成在玩家前方或侧前方
→ 锁定玩家核心方向
→ 直线靠近
→ 接触任意飞船部件后造成碰撞伤害
→ 自身损毁或弹开
```

### 表现

- 三角形积木结构。
- 尾部有小喷口。
- 冲刺时前端发红。

### UI提示

普通小怪不需要中央提示，只在小地图显示白色小点。

---

## 7.2 E002 蜂群无人机

### 定位

数量压迫单位，用于制造“被包围”的感觉。

### 行为逻辑

```text
以5-15只为一组刷新
→ 分散成小扇形
→ 朝玩家不同部位靠近
→ 优先撞击外侧部件
```

### 表现

- 由2-3个小积木块组成。
- 群体飞行时有蜂群音效。
- 死亡后掉落小碎块。

### UI提示

小敌潮中出现时，顶部进度条显示黄色小圆点。

---

## 7.3 E005 自爆水雷

### 定位

## 7.4 E009 重型冲撞舰

### 定位

第一个真正威胁玩家结构的中型敌人。

### 行为逻辑

```text
缓慢靠近
→ 进入冲刺距离
→ 停顿蓄力0.8秒
→ 舰首发红
→ 朝玩家当前方向高速冲撞
→ 冲撞后短暂硬直
```

### 克制方式

1. 横移躲避。
2. 正面装甲硬抗。
3. 高伤害武器提前打断。
4. 冲撞流玩家可以反撞。

### UI提示

- 敌人蓄力时头顶出现红色感叹号。
- 冲刺路径显示红色直线预警。

# 8. Boss设计

## 8.1 Boss UI总规则

Boss出现时必须有全局级提示。

### Boss出现流程

```text
Boss倒计时30秒
→ 背景音乐切换前奏
→ 顶部进度条Boss图标发红
→ 屏幕出现红色警戒边框
→ 远处出现Boss入场特效
→ 中央Boss标题横幅
→ Boss全局血条展开
→ 战斗开始
```

---

## 8.2 Boss全局血条

Boss血条显示在屏幕顶部进度条下方。

```text
┌──────────────────────────────────────┐
│ 积木吞星母舰                         │
│ ████████████████████  100%           │
│ 阶段一：炮翼压制                     │
└──────────────────────────────────────┘
```

### 血条信息

| 信息 | 说明 |
|---|---|
| Boss名称 | 当前Boss名称 |
| 总血量百分比 | 主要血条 |
| 阶段分隔点 | 70%、40%、15%等阶段线 |
| 当前阶段名 | 告诉玩家机制变化 |
| 弱点状态 | 弱点暴露时高亮 |
| 护盾层 | 有护盾时在血条外加蓝色层 |

## 10.5 Boss提示HUD

Boss提示分为三个层级。

### 30秒预告

```text

```

表现：

- 中央红色警告框。
- 背景音乐切换。
- 顶部Boss图标开始脉冲。

### 10秒倒计时

```text
Boss接近：10

Boss接近：8
```

表现：

- 屏幕边缘出现红色警戒框。
- 远处出现Boss剪影。
- 小地图显示巨大红点。

### Boss入场

```text
积木吞星母舰
正在进入战场
```

表现：

- 屏幕短暂拉远。
- Boss从远处折跃或撕裂空间进入。
- 中央出现Boss名称横幅。
- 展开Boss全局血条。

# 17. 关键体验规则

## 17.1 不要让玩家无预警暴毙

高伤敌人必须有明显预警。

| 高危行为 | 必须预警 |
|---|---|
| 重型冲撞 | 冲刺红线 |
| 激光狙击 | 预瞄线 |
| 导弹锁定 | 锁定框 |
| Boss大招 | 大范围红区 |
| 自爆水雷 | 爆炸范围圈 |
| 隐身突刺 | 显形闪烁 |

---

## 17.2 敌人必须逼迫不同构筑

| 构筑问题 | 对应敌人 |
|---|---|
| 只堆前方炮 | 后方追击机、虚空隐猎者 |
| 没有侧翼防御 | 侧翼切割机、斜翼冲锋机 |
| 没有范围清怪 | 蜂群、爆裂寄生虫 |
| 没有穿透武器 | 盾墙舰、护盾先锋艇 |
| 没有远程输出 | 激光狙击舰、导弹舰 |
| 不保护核心 | 隐猎者、吸附虫 |
| 不拾取经验 | 星尘吞噬兽 |
| 飞船过大太笨 | 自爆水雷、激光狙击、引力水母 |

---

## 17.3 战斗节奏要有呼吸感

不能一直高压。

建议结构：

```text
45秒普通战斗
→ 15秒敌潮爆发
→ 20秒碎块回收
→ 40秒普通战斗
→ 精英预告
→ 精英战斗
→ 奖励和恢复
```

Boss之后必须给短暂恢复期。

例如第10分钟Boss死亡后，第11分钟降低刷新密度，让玩家拾取碎块和重新搭建。

# 19. 总结

本方案的核心是把原本单调的幸存者刷怪，改造成有明确节奏的太空战斗：

```text
小怪持续压力
+ 定时敌潮高潮
+ 精英改变规则
+ Boss检验构筑
+ 顶部进度条提前预告
+ HUD清晰表达危险和目标
```

玩家应该始终知道：

1. 当前正在发生什么。
2. 下一波危险什么时候来。
3. 哪个敌人是优先击杀目标。
4. Boss还有多少血。
5. 自己的飞船哪个部件正在受威胁。
6. 击败高危敌人后会获得什么奖励。

这样战斗才不会只是“自动开火刷怪”，而会变成一场持续变化、目标明确、构筑有意义的太空积木飞船生存战。
