# 《太空3D积木飞船幸存者》首页、设置、图鉴 UI 完整设计文档

版本：V1.0  
用途：用于规范游戏首页、继续游戏、设置系统、图鉴系统的 UI 排版、交互逻辑、预制体层级、模型查看器与数据展示方式。  
适用：Unity / UE / 其他 3D 游戏引擎 UI 搭建。

---

# 1. 整体设计目标

本游戏的首页不是普通按钮菜单，而应该像一个 **太空飞船整备舱 / 星舰控制台 / 积木飞船仓库**。

首页需要承载：

1. 开始新游戏
2. 继续游戏
3. 设置
4. 图鉴
5. 退出游戏
6. 当前飞船展示
7. 当前存档信息
8. 新解锁提示
9. 最近一次战斗数据概览

界面核心风格：

```text
太空科幻 + 积木拼装 + 飞船控制台 + 模块化UI + 清晰可读
```

# 5. 继续游戏设计

## 5.1 功能定位

“继续游戏”用于读取最近一次未完成的战斗局内存档。

不是读取永久蓝图，而是继续上一局战斗进度。

## 5.2 有存档时

按钮显示为高亮状态。

右侧信息栏显示：

```text
最近存档
地图：小行星墓场
当前时间：08:35
当前等级：12
飞船部件：42
当前事件：保护维修卫星
存档时间：2026-06-13 13:20
```

点击后：

```text
打开确认弹窗
→ 显示存档概要
→ 确认继续
→ 加载战斗场景
```

## 5.3 无存档时

按钮置灰，并显示提示：

```text
暂无可继续的战斗存档
```

## 5.4 存档覆盖逻辑

当玩家点击开始新游戏时，如果存在未完成存档，需要提示：

```text
当前存在未完成战斗存档，开始新游戏会覆盖该进度。
是否继续？
```

按钮：
- 取消
- 覆盖并开始

# 7. 音效设置页面

## 7.1 页面目标

允许玩家分别控制不同音频通道，避免战斗中声音太吵。

## 7.2 音量分类

| 设置项 | 默认值 | 范围 | 说明 |
|---|---:|---:|---|
| 总音量 | 100 | 0-100 | 控制所有声音总输出 |
| BGM音量 | 70 | 0-100 | 背景音乐 |
| 玩家音效 | 85 | 0-100 | 玩家武器、推进、受击、搭建 |
| UI音效 | 80 | 0-100 | 按钮、弹窗、选择BD |
| 敌人音效 | 85 | 0-100 | 敌人攻击、死亡、冲撞 |
| 背景音效 | 65 | 0-100 | 太空风声、机械环境音、星域噪声 |

## 7.3 推荐附加选项

| 设置项 | 默认 | 说明 |
|---|---|---|
| 静音全部 | 关 | 一键关闭全部音频 |
| 战斗低血警报 | 开 | 核心低血量时播放警报 |
| Boss音乐增强 | 开 | Boss出现时切换高强度音乐 |
| UI点击音 | 开 | 开关按钮点击反馈 |
| 后台静音 | 开 | 游戏失焦后是否静音 |

## 7.4 音效设置 UI 元件

每一项使用：

```text
设置名称 + 数值百分比 + 横向滑条 + 测试听按钮
```

示例：

```text
总音量   [==============------] 75%   [测试]
BGM      [==========----------] 50%   [测试]
玩家音效 [================----] 80%   [测试]
```

## 7.5 测试听逻辑

点击测试按钮后：

| 音频类型 | 测试音 |
|---|---|
| BGM | 播放 3 秒短音乐片段 |
| 玩家 | 播放机炮 + 推进器短音 |
| UI | 播放按钮确认音 |
| 敌人 | 播放敌人爆炸/冲撞音 |
| 背景 | 播放太空环境音 |

# 8. 画面设置页面

## 8.1 页面目标

允许玩家根据电脑性能调整画面，保证 3D 太空幸存者在大量敌人和弹幕时仍能稳定运行。

## 8.2 基础显示设置

| 设置项 | 类型 | 推荐选项 |
|---|---|---|
| 显示模式 | 下拉框 | 全屏 / 无边框窗口 / 窗口 |
| 分辨率 | 下拉框 | 1920×1080 / 2560×1440 / 3840×2160 等 |
| 刷新率 | 下拉框 | 60 / 120 / 144 / 165 |
| 垂直同步 | 开关 | 开 / 关 |
| 帧率上限 | 下拉框 | 30 / 60 / 90 / 120 / 144 / 不限制 |
| 亮度 | 滑条 | 0-100 |
| UI缩放 | 滑条 | 80%-130% |

## 8.3 画质精细度设置

| 设置项 | 类型 | 选项 |
|---|---|---|
| 总体画质 | 下拉框 | 低 / 中 / 高 / 极高 / 自定义 |
| 模型精细度 | 下拉框 | 低 / 中 / 高 |
| 贴图质量 | 下拉框 | 低 / 中 / 高 / 极高 |
| 特效质量 | 下拉框 | 低 / 中 / 高 |
| 粒子数量 | 下拉框 | 少 / 中 / 多 / 极多 |
| 后处理效果 | 开关 | 开 / 关 |
| 抗锯齿 | 下拉框 | 关闭 / FXAA / TAA / MSAA |

## 8.4 光影设置

| 设置项 | 类型 | 说明 |
|---|---|---|
| 动态光照 | 开关 | 是否启用动态灯光 |
| 阴影质量 | 下拉框 | 关闭 / 低 / 中 / 高 |
| 飞船自阴影 | 开关 | 飞船部件之间是否投影 |
| 爆炸光照 | 开关 | 爆炸是否产生短暂光源 |
| 屏幕泛光 | 开关 | 激光、护盾、稀有物体发光 |
| 体积光 | 开关 | 星云和Boss区域光柱 |

## 8.5 性能辅助选项

| 设置项 | 默认 | 说明 |
|---|---|---|
| 战斗中降低远景特效 | 开 | 大量敌人时减少远处粒子 |
| 低性能模式 | 关 | 自动降低粒子、阴影、后处理 |
| 弹幕简化显示 | 关 | 大量子弹时用简化材质 |
| 敌人残骸数量 | 中 | 控制场景残骸保留数量 |
| 伤害数字数量限制 | 开 | 避免跳字太多影响性能 |

## 8.6 应用逻辑

画面设置分为两类：

### 即时生效
- 亮度
- UI缩放
- 后处理
- 阴影质量
- 特效质量

### 需要确认生效
- 分辨率
- 显示模式
- 刷新率

当修改分辨率后：

```text
是否保留当前显示设置？
15 秒后自动恢复。
```

按钮：
- 保留
- 恢复

# 9. 按键操控页面

## 9.1 页面目标

让玩家能自由配置飞船操控、搭建界面、战斗快捷键和鼠标灵敏度。

## 9.2 基础操控设置

| 功能 | 默认按键 | 说明 |
|---|---|---|
| 加速 | W | 飞船向前加速 |
| 减速 | S | 飞船减速 |
| 左横移 | A | 左侧推进 |
| 右横移 | D | 右侧推进 |
| 短促推进/闪避 | Space | 可选动作 |
| 打开搭建界面 | B | 局内手动搭建 |
| 打开小地图 | M | 地图预览 |
| 暂停 | Esc | 暂停菜单 |
| 交互/确认 | E | 事件/拾取/确认 |
| 切换锁定目标 | Tab | 可选 |

## 9.3 搭建界面快捷键

| 功能 | 默认按键 | 说明 |
|---|---|---|
| 旋转部件 | R | 顺时针旋转当前部件 |
| 反向旋转 | Shift + R | 逆时针旋转 |
| 拆除部件 | Delete | 拆除选中部件 |
| 取消拖拽 | 鼠标右键 / Esc | 当前部件回到原位 |
| 聚焦核心 | F | 镜头回到飞船核心 |
| 撤销 | Ctrl + Z | 撤销上一步搭建 |
| 重做 | Ctrl + Y | 恢复撤销操作 |
| 继续游戏 | Enter | 退出搭建界面返回战斗 |

## 9.4 鼠标设置

| 设置项 | 默认值 | 范围 | 说明 |
|---|---:|---:|---|
| 鼠标灵敏度 | 50 | 1-100 | 控制屏幕偏航/视角移动 |
| 搭建界面旋转灵敏度 | 50 | 1-100 | 模型查看与飞船搭建镜头 |
| 鼠标平滑 | 开 | 开/关 | 减少移动抖动 |
| 反转X轴 | 关 | 开/关 | 左右反转 |
| 反转Y轴 | 关 | 开/关 | 上下反转 |
| 鼠标滚轮缩放速度 | 50 | 1-100 | 图鉴/搭建界面的缩放速度 |

## 9.5 按键修改交互

点击某个按键框后：

```text
等待输入新按键...
按 Esc 取消
```

如果按键冲突：

```text
该按键已绑定到“打开搭建界面”。
是否替换？
```

按钮：
- 取消
- 替换

# 20. 总结

首页、设置和图鉴三个系统承担的是游戏的“外壳体验”。

首页要让玩家一进来就知道：

```text
这是一款太空积木飞船构筑游戏。
```

设置要足够完整，尤其是：

```text
音效分类清楚
画面性能可控
按键能完全自定义
鼠标灵敏度能调
```

图鉴要让玩家愿意反复打开：

```text
能看模型
能看数值
能旋转缩放
能研究敌人和部件
能看到未解锁目标
```

这三套系统完成后，游戏会从“只有战斗玩法”变成更完整的正式游戏框架。
