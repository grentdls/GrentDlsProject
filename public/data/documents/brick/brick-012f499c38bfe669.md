# 《星空掠夺者》部件信息界面可视化优化与 UI 布局完整设计文档

版本：v1.0  
适用项目：Unity2D 桌面挂机飞船建造游戏《星空掠夺者》  
适用界面：三选一界面、奖励界面、部件改造界面、图鉴界面、部件详情界面  
核心目标：提高信息可视性、降低阅读压力、强化不同部件类型与玩法字段的识别度。

---

## 1. 当前问题总结

当前这些界面存在的问题主要不是内容不足，而是**信息没有分层**，导致玩家看起来乱、累、难判断价值。

### 1.1 主要问题

| 问题 | 表现 | 造成的结果 |
|---|---|---|
| 部件类型不明显 | 攻击、防御、生产、生存等部件只靠文字区分 | 玩家扫一眼不知道是什么类型 |
| 字段密度高 | 属性、词条、描述混在一起 | 玩家需要逐字阅读，桌面小窗里尤其累 |
| 玩法标签不突出 | 闪电、弹射、吸血、护盾等内容没有独立标识 | 强流派部件没有吸引力 |
| 背景板缺少差异 | 不同类型卡片外观太接近 | 三选一、奖励选择时辨识度差 |
| 描述区域固定高度 | 长描述被挤压，短描述留空 | 阅读体验差，UI 不稳定 |
| 稀有度和价值不够直观 | 只显示文字或颜色 | 玩家不容易判断奖励价值 |
| 对比信息不足 | 改造界面无法快速看到改造前后变化 | 选择成本高 |
| 图鉴信息堆叠 | 部件太多时，玩家无法按类型、流派、稀有度快速筛选 | 查找成本高 |

---

## 2. 优化总原则

### 2.1 一眼识别原则

玩家看到一个部件卡片时，必须在 1 秒内知道：

```text
这是什么类型？
它稀有不稀有？
它适合什么玩法？
它是立即变强，还是长期收益？
```

所以每个部件必须同时拥有：

```text
类型图标 + 类型底板 + 稀有度框 + 玩法标签 + 核心属性摘要
```

不能只靠文字说明。

---

### 2.2 图标 + 文字 + 背景板三重表达

所有关键字段都必须采用三重表达：

| 信息 | 表达方式 |
|---|---|
| 部件类型 | 图标 + 类型文字 + 类型底板 |
| 稀有度 | 边框颜色 + 星级/角标 + 稀有度文字 |
| 流派玩法 | 彩色标签 + 小图标 + 关键词 |
| 数值变化 | 箭头 + 颜色 + 数字 |
| 负面效果 | 警示图标 + 红色字段 + 说明 |
| 解锁条件 | 锁图标 + 条件文字 + 灰色遮罩 |

示例：

```text
[攻击图标] 攻击模块     [稀有：史诗 ★★★★]
[闪电] [弹射] [击中增伤]
攻击 +35    攻速 +12%    暴击 +6%
```

---

### 2.3 桌面弹窗适配原则

《星空掠夺者》是桌面游戏，所以这些界面不能按照手游全屏大面板设计。

所有界面都应遵守：

```text
1. 弹窗化显示。
2. 支持拖拽。
3. 支持折叠。
4. 支持最小化。
5. 不遮挡主飞船太久。
6. 重要信息优先显示，详情可以展开。
7. 鼠标悬停显示补充说明。
8. 可以固定在屏幕边缘。
```

推荐弹窗尺寸：

| 界面 | 默认尺寸 | 最小尺寸 | 最大尺寸 |
|---|---:|---:|---:|
| 三选一界面 | 820 × 520 | 720 × 460 | 1100 × 680 |
| 奖励界面 | 760 × 560 | 680 × 440 | 1080 × 720 |
| 部件改造界面 | 980 × 640 | 860 × 540 | 1280 × 800 |
| 图鉴界面 | 1040 × 680 | 900 × 560 | 1360 × 860 |
| 部件详情界面 | 520 × 动态高度 | 460 × 360 | 680 × 900 |

## 3. 部件类型视觉规范

### 3.1 部件大类划分

部件类型必须用图标和底板明确区分。

| 生产模块 | 齿轮 / 工厂 | 橙黄 / 铜色 | 工业铆钉底板 | 资源产出、制造速度 |

| 防御模块 | 盾牌 | 蓝灰 / 银色 | 厚重装甲底板 | 护盾、护甲、抗性 |

| 辅助模块 | 雷达 / 磁环 | 紫蓝 / 青蓝 | 科技环形底板 | 探测、拾取、增益 |
| 舰载模块 | 停机坪 / 小飞机 | 深蓝 / 白色 | 甲板底板 | 舰载机、无人机、出击 |

---

### 3.2 类型底板规则

每种部件类型都要有一张专属底板，不能只换文字。

#### 攻击模块底板

表现：

```text
深色金属板 + 红色能量纹 + 尖角边框 + 炮口纹理
```

适合显示：

```text
炮台、激光、导弹、闪电、弹射、爆炸、击杀类词条
```

#### 防御模块底板

表现：

```text
厚重装甲板 + 蓝色护盾纹 + 圆弧边缘 + 护甲层叠结构
```

适合显示：

```text
护盾、护甲、减伤、反弹、撞击、护盾恢复
```

#### 生产模块底板

表现：

```text
铜色机械板 + 齿轮纹 + 管线纹 + 小型警示条
```

适合显示：

```text
矿物产出、制造速度、材料转化、自动生产
```

#### 生存模块底板

表现：

```text
绿色生命板 + 氧气泡纹 + 植物纹理 + 软质边缘
```

适合显示：

```text
氧气、食物、恢复、医疗、船员生存
```

#### 科研模块底板

表现：

```text
紫色玻璃板 + 晶片纹路 + 数据线 + 实验容器剪影
```

适合显示：

```text
科研速度、解锁、蓝图、词条升级
```

#### 特殊模块底板

表现：

```text
不规则黑紫底板 + 裂隙光边 + 轻微扭曲图案
```

适合显示：

```text
虚空、幽灵、诅咒、规则改变、特殊事件
```

## 4. 部件结构风格视觉规范

除了功能类型，部件还应该有结构风格，比如机械结构、植物结构、虚空结构等。功能类型决定“它做什么”，结构风格决定“它看起来是什么文明/材料”。

### 4.1 结构风格列表

| 结构风格 | 图标 | 外观表现 | UI 纹理 | 常见词条倾向 |
|---|---|---|---|---|
| 机械结构 | 齿轮 | 金属、螺栓、管线、涡轮 | 铁灰、黄黑警示条 | 攻速、远程、生产、稳定 |
| 植物结构 | 叶片 | 藤蔓、花苞、孢子、根系 | 绿色纹理、软边 | 治疗、中毒、缠绕、再生 |
| 虫巢结构 | 虫卵 | 甲壳、触须、巢腔、粘液 | 暗红、褐色、蜂窝 | 召唤、腐蚀、寄生、数量 |
| 晶体结构 | 水晶 | 晶簇、折射、棱角 | 透明蓝紫、棱镜纹 | 法伤、折射、暴击、储能 |
| 虚空结构 | 裂隙 | 黑洞、裂纹、漂浮碎片 | 黑紫、蓝边、扭曲 | 闪现、裂解、异常、规则改变 |
| 幽灵结构 | 魂火 | 半透明、灵火、雾气 | 灰蓝、半透明边 | 闪避、穿透、诅咒、复活 |
| 外星结构 | 眼球 | 异星符号、流线外壳 | 青紫、奇异几何 | 控制、探测、精神、护盾 |
| 废土结构 | 破铁 | 拼接铁板、链条、废料 | 锈红、污渍、破边 | 低成本、爆炸、过热、暴击 |
| 生体结构 | 心脏 | 肌肉、血管、囊泡 | 深红、肉质纹 | 吸血、成长、再生、感染 |
| 神秘结构 | 星纹 | 符文、法阵、星轨 | 金紫、星点 | 增幅、祝福、稀有规则 |

---

### 4.2 类型和结构的组合表达

一个部件必须同时显示：

```text
功能类型：攻击模块
结构风格：植物结构
```

示例：

```text
[攻击图标] 攻击模块
[植物图标] 植物结构
名称：毒藤脉冲炮
玩法标签：[中毒] [缠绕] [持续伤害]
```

这样玩家能立即知道：

```text
它是攻击模块，但不是普通炮，而是植物系毒伤玩法。
```

## 5. 字段颜色与字段标识系统

### 5.1 玩法字段必须标签化

不要把玩法写成一整段描述：

```text
攻击时有概率发射闪电并弹射到附近敌人
```

应该拆成标签：

```text
[闪电] [弹射] [击中触发]
```

然后描述再补充具体规则。

---

### 5.2 字段颜色规范

| 字段类型 | 标签颜色 | 图标建议 | 示例 |
|---|---|---|---|
| 物理攻击 | 红色 | 剑 / 炮弹 | [物理] 攻击 +25 |
| 能量攻击 | 蓝色 | 能量球 | [能量] 伤害 +18% |
| 闪电 | 电蓝色 | 闪电 | [闪电] 命中后弹射 2 次 |
| 火焰 | 橙红色 | 火苗 | [燃烧] 每秒造成伤害 |
| 毒素 | 绿色 | 毒瓶 | [中毒] 持续掉血 |
| 冰霜 | 冰蓝色 | 雪花 | [减速] 降低移速 |
| 虚空 | 紫黑色 | 裂隙 | [裂解] 降低抗性 |
| 弹射 | 青色 | 分叉箭头 | [弹射] 额外命中目标 |
| 爆炸 | 橙色 | 爆炸云 | [爆炸] 范围伤害 |
| 击杀触发 | 金红色 | 骷髅 | [击杀] 击杀后触发 |
| 击中触发 | 黄色 | 准星 | [击中] 命中时触发 |
| 护盾 | 蓝白色 | 盾牌 | [护盾] 增加护盾值 |
| 治疗 | 绿色 | 十字 | [治疗] 恢复生命 |
| 召唤 | 紫色 | 传送门 | [召唤] 生成单位 |
| 生产 | 铜色 | 齿轮 | [生产] 矿物 +10/min |
| 探测 | 青蓝色 | 雷达 | [探测] 发现隐藏事件 |
| 负面代价 | 红黑色 | 警告 | [代价] 热量 +20 |

---

### 5.3 字段标识格式

所有玩法描述必须拆成三层：

```text
第一层：玩法标签
第二层：核心数值
第三层：详细说明
```

示例：

```text
[闪电] [弹射] [击中]
闪电伤害 +35%，弹射次数 +2
攻击命中后，有 22% 概率释放闪电，闪电会优先弹射到最近的敌舰模块。
```

---

### 5.4 数值字段颜色

| 数值变化 | 显示方式 |
|---|---|
| 正向提升 | 绿色数字 + 上箭头 |
| 负向降低 | 红色数字 + 下箭头 |
| 中性变化 | 白色 / 灰色数字 |
| 新增能力 | 金色“NEW”角标 |
| 条件触发 | 黄色条件标识 |
| 未激活 | 灰色锁定 |
| 套装激活 | 金色发光边框 |
| 蓝图未解锁 | 蓝灰色剪影 |

示例：

```text
攻击力  120 → 148  ▲ +28
热量    35 → 48    ▼ +13
新增词条：[击杀爆炸] NEW
```

注意：热量增加虽然是数值上升，但属于负面变化，所以用红色。

## 7. 动态描述区域规则

### 7.1 为什么需要动态高度

部件说明有长有短，如果固定高度，会出现两种问题：

```text
长描述：被截断，需要滚动，玩家懒得看。
短描述：大片空白，卡片显得松散。
```

所以描述区域应该根据内容长度动态拉伸。

---

### 7.2 动态高度规则

| 描述长度 | 显示方式 |
|---|---|
| 1 行以内 | 单行说明，高度最小 |
| 2-3 行 | 正常展示，不滚动 |
| 4-6 行 | 描述区域自动拉长 |
| 7 行以上 | 显示前 6 行，提供“展开详情” |
| 超过 12 行 | 自动拆成“简述 + 详细机制”两个区域 |

---

### 7.3 描述内容拆分规则

一个部件的描述不应该是一整段，而应该拆成：

```text
1. 一句话简述
2. 核心效果
3. 触发条件
4. 限制条件
5. 适配流派
6. 来源说明
```

示例：

```text
一句话简述：
适合闪电弹射流的中距离攻击模块。

核心效果：
攻击命中时，有 22% 概率释放闪电。

触发条件：
仅在主武器命中敌舰模块时触发。

限制条件：
每 1.2 秒最多触发一次。

适配流派：
闪电流、击中流、攻速流。
```

## 8. 三选一界面优化

### 8.1 界面目标

三选一界面的核心不是展示全部信息，而是帮助玩家快速做选择。

玩家需要快速判断：

```text
哪个更强？
哪个更适合当前流派？
哪个更稀有？
哪个是长期收益？
```

---

### 8.2 布局结构

```text
┌────────────────────────────────────────────────────────────┐
│ 标题：选择一个飞船部件                                      │
│ 副标题：本次奖励受到星球稀有度和敌舰等级影响                │
├────────────────────────────────────────────────────────────┤
│ 当前流派提示：[闪电流] [攻速流] [护盾撞击流]                 │
├────────────────────────────────────────────────────────────┤
│ ┌────────────┐ ┌────────────┐ ┌────────────┐               │
│ │ 选项 A      │ │ 选项 B      │ │ 选项 C      │               │
│ │ 攻击底板    │ │ 防御底板    │ │ 生产底板    │               │
│ │ 部件大图    │ │ 部件大图    │ │ 部件大图    │               │
│ │ 标签+数值   │ │ 标签+数值   │ │ 标签+数值   │               │
│ │ 推荐原因    │ │ 推荐原因    │ │ 推荐原因    │               │
│ │ [选择]      │ │ [选择]      │ │ [选择]      │               │
│ └────────────┘ └────────────┘ └────────────┘               │
├────────────────────────────────────────────────────────────┤
│ 底部：刷新 / 跳过转资源 / 查看当前飞船流派                  │
└────────────────────────────────────────────────────────────┘
```

---

### 8.3 三选一卡片信息层级

每张卡片从上到下固定为：

```text
1. 稀有度角标
2. 部件类型图标 + 名称
3. 结构风格图标
4. 部件大图
5. 玩法标签
6. 三条核心属性
7. 一句话推荐原因
8. 选择按钮
```

不要在三选一卡片中显示全部长描述。

长描述放到：

```text
鼠标悬停详情
右键查看详情
点击卡片右上角详情按钮
```

### 10.3 改造方式分页

改造方式不能全堆在一个界面，需要分页：

同时显示保底规则：

```text
连续 10 次未出现稀有词条，下次稀有词条概率提升。
```

### 10.6 改造风险提示

如果改造可能带来负面效果，要独立显示红色警示条。

示例：


风险不应该藏在描述文本里。

### 18.2 显示模式配置

## 20. 推荐界面文案规则

### 20.1 短描述规则

短描述最多 24 个中文字符。

示例：

```text
适合闪电弹射流的攻击模块。
提高护盾并强化撞击伤害。
长期提升矿物生产效率。
```

---

### 20.2 长描述规则

长描述必须拆成机制句，不要写成小说文本。

错误：

```text
这门古老的电弧炮来自机械文明的深处，它蕴含着强大的能量，能够在战场上造成毁灭性的打击。
```

正确：

```text
攻击命中敌舰模块时，有 22% 概率释放电弧。
电弧会在 3 格范围内弹射 2 次。
每次弹射造成 60% 闪电伤害。
```

---

### 20.3 字段命名统一

| 不推荐 | 推荐 |
|---|---|
| 触电 | 闪电 |
| 连锁 | 弹射 |
| 爆开 | 爆炸 |
| 打中 | 击中 |
| 杀死 | 击杀 |
| 回血 | 治疗 / 吸血 |
| 加盾 | 护盾 |
| 变快 | 攻速 |
| 变热 | 热量 |

## 24. 最终效果目标

优化后，玩家在任何界面看到部件时，都应该能快速判断：

```text
这是攻击、防御、生产还是特殊部件。
它属于机械、植物、虚空还是其他结构。
它的稀有度和价值如何。
它适合闪电、弹射、击杀、护盾还是生产流派。
它的核心数值是提升还是代价。
它从哪里来，能不能改造，适合不适合当前飞船。
```

最终 UI 方向：

```text
少堆文字。
多用图标。
多用底板。
多用标签。
多做分层。
长文本动态拉长。
关键字段用颜色和标识强调。
桌面弹窗保持紧凑但信息清楚。
```
