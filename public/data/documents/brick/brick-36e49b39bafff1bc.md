# 《太空3D积木飞船幸存者》UI悬停点击反馈优化完整文档

版本：V1.0  
用途：统一所有 UI 交互反馈，包括鼠标悬停、点击、选中、禁用、拖拽、错误、成功、稀有度强化反馈。  
目标：让游戏 UI 从“能用”提升到“有手感、有反馈、有品质感”的正式商业级表现。

---

# 1. 设计目标

当前 UI 需要重点优化鼠标交互表现，尤其是：

1. 鼠标悬停在 UI 框体、按钮、BD 卡、背包格子、图鉴条目上时，要有明确反馈。
2. 可点击组件需要有明显的“我可以点”的表现。
3. 点击瞬间要有按压、发光、变色、音效反馈。
4. 选中状态要和悬停状态区分开。
5. BD 三选一、积木搭建、背包、图鉴、设置等核心界面都需要统一交互规范。
6. 所有可交互 UI 尽量复用同一套基础交互预制体组件，避免每个按钮单独写逻辑。

本项目 UI 风格是：

```text
太空科幻 + 积木拼装 + 飞船控制台 + 模块化机械面板 + 蓝青色发光
```

因此交互反馈也要偏向：

```text
机械卡扣感、能量激活感、全息高亮感、科技边框脉冲感
```

---

# 2. UI交互反馈总原则

## 2.1 所有可交互元素必须有 5 种基础状态

所有按钮、卡牌、列表条目、背包格子、页签、设置项、图鉴卡、部件槽位都必须支持：

| 状态 | 说明 |
|---|---|
| Normal 默认 | 没有鼠标悬停，没有被选中 |
| Hover 悬停 | 鼠标移动到该 UI 上 |
| Pressed 按下 | 鼠标左键按下瞬间 |
| Selected 选中 | 当前被玩家选中或激活 |
| Disabled 禁用 | 当前不可点击 |

可扩展状态：

| 状态 | 说明 |
|---|---|
| Dragging 拖拽中 | 正在被拖动 |
| DropValid 可放置 | 拖拽到合法目标区域 |
| DropInvalid 不可放置 | 拖拽到非法目标区域 |
| New 新内容 | 新获得或未查看 |
| Warning 警告 | 操作有风险 |
| Success 成功 | 操作完成 |
| Error 错误 | 操作失败 |

---

## 2.2 所有反馈都要遵循“三段式”

### 第一段：视觉变化
例如：
- 放大
- 外发光
- 边框变亮
- 背景变色
- 图标变亮
- 阴影增强

### 第二段：动态变化
例如：
- 0.1 秒快速放大
- 边框能量流动
- 发光呼吸
- 点击时轻微缩小再回弹
- 卡牌轻微上浮

### 第三段：声音反馈
例如：
- 悬停轻提示音
- 点击确认音
- 错误低频音
- 选中能量启动音
- 稀有卡高品质音效

---

## 2.3 交互反馈不能影响布局

UI 放大时不能挤动其他 UI。

正确做法：

```text
UI_Item_Root
├─ LayoutSlot            负责布局，不缩放
└─ VisualRoot            负责缩放、发光、动画
```

鼠标悬停时，只缩放 `VisualRoot`，不要缩放 `LayoutSlot`。

避免出现：
- 列表条目放大后把其他条目顶开
- 卡牌放大后布局抖动
- 背包格子悬停后整个网格错位

# 3. 全局交互数值规范

## 3.1 悬停 Hover 数值

| 项目 | 推荐值 |
|---|---:|
| 放大比例 | 1.04 ~ 1.08 |
| 普通按钮放大 | 1.04 |
| 重要按钮放大 | 1.06 |
| BD卡牌放大 | 1.08 |
| 背包格子放大 | 1.06 |
| 动画时长 | 0.10 ~ 0.16 秒 |
| 外发光透明度 | 40% ~ 70% |
| 边框亮度提升 | 20% ~ 40% |

建议默认：

```text
HoverScale = 1.05
HoverDuration = 0.12s
HoverGlowAlpha = 0.6
```

---

## 3.2 点击 Pressed 数值

| 项目 | 推荐值 |
|---|---:|
| 按下缩小比例 | 0.94 ~ 0.97 |
| 回弹比例 | 1.03 |
| 总时长 | 0.12 ~ 0.18 秒 |
| 点击闪光时长 | 0.08 ~ 0.12 秒 |
| 颜色变化 | 蓝青 → 白蓝 / 橙黄 |

推荐点击流程：

```text
鼠标按下：Scale 1.05 → 0.96
鼠标松开：Scale 0.96 → 1.03 → 1.00
同时边框闪一次亮光
```

---

## 3.3 选中 Selected 数值

| 项目 | 推荐表现 |
|---|---|
| 放大 | 1.03 |
| 外发光 | 持续存在 |
| 边框 | 明显高亮 |
| 背景 | 略微变亮 |
| 动效 | 低频呼吸光 |

选中状态不是点击一瞬间，而是持续状态。

例如：
- 当前选中的 BD 卡
- 当前选中的背包部件
- 当前设置页签
- 当前图鉴分类
- 当前已搭建积木条目

---

## 3.4 禁用 Disabled 数值

禁用状态必须明显，不要让玩家误以为能点。

| 项目 | 推荐表现 |
|---|---|
| 透明度 | 35% ~ 55% |
| 饱和度 | 降低 60% |
| 发光 | 关闭 |
| 鼠标悬停 | 不放大，或仅显示原因提示 |
| 点击 | 无按压反馈，播放轻微错误音可选 |

禁用时可显示 Tooltip：

```text
需要完成上一关卡后解锁
当前没有可继续的存档
该部件当前无法安装
```

# 4. 通用交互状态机

所有可点击 UI 推荐使用统一状态机。

```text
Normal
  ↓ 鼠标进入
Hover
  ↓ 鼠标按下
Pressed
  ↓ 鼠标松开且仍在区域内
Click / Selected
  ↓ 鼠标离开
Normal 或 Selected
```

禁用状态优先级最高：

```text
Disabled 状态下忽略 Hover / Pressed / Click
```

拖拽状态优先级高于 Hover：

```text
Dragging 状态下，只显示拖拽反馈，不显示普通悬停反馈
```

---

# 5. 统一视觉反馈组件设计

建议所有可交互 UI 都使用一个基础组件：

```text
UIInteractiveFeedback
```

## 5.1 组件控制对象

```text
UI_InteractiveItem
├─ LayoutRoot
└─ VisualRoot
   ├─ Bg
   ├─ Frame
   ├─ Icon
   ├─ TextGroup
   ├─ Glow_Hover
   ├─ Glow_Selected
   ├─ Flash_Click
   ├─ Outline_Error
   └─ Particles_Optional
```

## 5.2 组件需要控制的属性

| 属性 | 作用 |
|---|---|
| Scale | 控制整体缩放 |
| GlowAlpha | 控制外发光透明度 |
| FrameColor | 控制边框颜色 |
| BgColor | 控制底板颜色 |
| IconColor | 控制图标亮度 |
| TextColor | 控制文字颜色 |
| ShadowStrength | 控制阴影强弱 |
| ParticlePlay | 播放点击粒子 |
| SoundPlay | 播放交互音效 |

# 6. 通用按钮交互规范

## 6.1 默认按钮 Normal

表现：
- 深灰金属底
- 蓝青弱发光边
- 图标/文字正常亮度

---

## 6.2 悬停 Hover

鼠标进入按钮范围后：

1. 按钮整体放大到 1.04。
2. 外发光从 0 渐变到 60%。
3. 边框颜色从暗蓝变为亮青。
4. 背景轻微提亮。
5. 播放轻微悬停音效。
6. 鼠标指针变为可点击样式。

表现文案：

```text
按钮像被飞船控制台识别到一样，边框能量亮起。
```

---

## 6.3 点击 Pressed

鼠标按下时：

1. 按钮从 1.04 缩小到 0.96。
2. 中央出现一次短促蓝白闪光。
3. 边框颜色瞬间变为白蓝或橙黄。
4. 松开后回弹到 1.00。
5. 播放确认点击音效。

---

## 6.4 主按钮强化表现

主按钮包括：
- 开始游戏
- 继续游戏
- 继续战斗
- 确认安装
- 选择 BD
- 保存设置

主按钮 Hover 时应该更明显：

| 反馈 | 数值 |
|---|---:|
| 放大 | 1.06 |
| 外发光 | 80% |
| 边框亮度 | +50% |
| 能量流动 | 开启 |
| 点击闪光 | 更强 |

主按钮点击时可以有轻微屏幕 UI 震动，但不要影响战斗视野。

# 7. BD选择卡交互规范

BD 三选一是游戏中最重要的 UI 之一，必须有强反馈。

## 7.1 BD卡默认状态

每张卡显示：
- 稀有度边框
- 图标区
- 名称区
- 描述区
- 流派标签
- 底部提示

默认状态下三张卡平铺。

---

## 7.2 鼠标悬停 BD 卡

Hover 表现：

1. 卡牌整体放大到 1.08。
2. 卡牌向上浮动 8 ~ 16 像素。
3. 外发光增强。
4. 稀有度边框发光。
5. 卡牌背景出现细微能量纹路。
6. 卡牌图标亮度提高。
7. 卡牌下方出现提示：`点击选择此改造`
8. 播放轻微卡牌悬停音效。

不同稀有度的悬停发光颜色：

| 稀有度 | Hover发光颜色 |
|---|---|
| 普通 | 白蓝 |
| 优秀 | 蓝色 |
| 稀有 | 紫色 |
| 史诗 | 橙色 |
| 传奇 | 金色 |

---

## 7.3 点击 BD 卡

点击流程：

```text
鼠标按下
→ 卡牌快速缩小到 0.96
→ 松开后放大到 1.12
→ 稀有度边框爆发一次光圈
→ 其余两张卡变暗
→ 当前卡进入 Selected 状态
→ 0.3秒后执行选择结果
```

点击后表现：

1. 被选择卡牌居中或略微前置。
2. 外发光增强。
3. 播放稀有度对应音效。
4. 若是传奇 BD，可加短暂全屏金色光效。

---

## 7.4 BD卡确认防误触

两种方案：

### 方案 A：单击直接选择
适合快节奏。

### 方案 B：单击选中，二次点击确认
适合稀有 BD 或关键选择。

建议：
- 普通升级：单击直接选择
- 传奇 BD / Boss 奖励：点击后出现确认按钮

---

# 8. 积木背包格子交互规范

用于：
- 未搭建部件列表
- 已搭建部件列表
- 背包格子
- 图鉴部件条目
- 奖励展示格子

## 8.1 格子 Hover

表现：

1. 格子整体放大到 1.06。
2. 边框蓝青发光。
3. 部件图标轻微上浮。
4. 显示 Tooltip。
5. 如果可拖拽，鼠标指针变为抓取样式。

Tooltip 内容：

```text
部件名称
类型：攻击 / 防御 / 辅助 / 链接
尺寸：2×1×1
主要效果：向前发射双联子弹
操作：拖拽到飞船上安装
```

---

## 8.2 格子点击

点击后：

1. 格子缩小到 0.95 再回弹。
2. 进入 Selected 状态。
3. 右侧详情面板刷新。
4. 中央模型预览更新。
5. 播放点击音效。

---

## 8.3 格子拖拽

拖拽开始：

1. 原格子变半透明。
2. 鼠标上显示部件模型缩略图。
3. 飞船搭建区域显示可安装高亮。
4. 格子边框进入 Dragging 状态。

拖拽结束：

- 合法安装：绿色闪光 + 咔哒音效
- 非法安装：红色闪烁 + 错误音效
- 取消拖拽：格子恢复正常

---

# 9. 已搭建部件列表交互规范

用于积木搭建界面右侧“已搭建部件列表”。

## 9.1 悬停条目

表现：

1. 条目底板横向放大或高亮，不改变列表布局。
2. 对应飞船上的 3D 部件同步描边。
3. 条目右侧显示快捷按钮：
   - 聚焦
   - 重排
   - 拆除
4. 播放轻微悬停音。

---

## 9.2 点击条目

点击后：

1. 条目进入 Selected 状态。
2. 飞船模型中对应部件出现持续蓝色描边。
3. 详情面板显示该部件属性。
4. 镜头可选择是否自动轻微对准该部件。

---

## 9.3 拆除按钮 Hover / Click

拆除属于危险操作，颜色要区别。

Hover：
- 红橙色边框
- 外发光较弱
- Tooltip：`拆除此部件`

Click：
- 红色闪光
- 弹出确认框
- 若会导致断链，需要显示影响部件数量

# 11. 设置界面控件交互规范

设置界面包含大量控件，必须清晰、稳定、易操作。

---

## 11.1 滑条 Slider

用于：
- 总音量
- BGM音量
- 玩家音效
- UI音效
- 敌人音效
- 背景音效
- 鼠标灵敏度
- 镜头灵敏度
- 亮度

### Hover
当鼠标悬停在滑条上：

1. 滑条轨道发光。
2. 滑块放大到 1.15。
3. 当前数值气泡显示。
4. 播放轻微悬停音。

### Drag
拖动时：

1. 填充条实时变化。
2. 数值气泡跟随滑块。
3. 滑块发光增强。
4. 可每隔固定间隔播放轻微滑动声，不要太吵。

### Release
松开时：

1. 滑块回到正常大小。
2. 播放确认音。
3. 自动保存或等待点击应用。

---

## 11.2 下拉框 Dropdown

用于：
- 分辨率
- 画质精细度
- 抗锯齿
- 阴影质量
- 语言

### Hover
- 外框发光
- 箭头图标亮起

### Click
- 下拉列表展开
- 当前项高亮
- 其他区域变暗一点

### Hover选项
- 当前选项底板发光
- 鼠标经过时轻微横向位移 4px

### Select
- 选项闪光
- 下拉框收起
- 当前值更新

---

## 11.3 开关 Toggle

用于：
- 全屏
- 垂直同步
- 显示伤害数字
- 屏幕震动
- 自动拾取
- 自动瞄准辅助

### Hover
- 开关外框发光
- 当前状态颜色增强

### Click
- 开关滑块快速移动
- 背景颜色变化
- 播放机械开关音

颜色建议：

| 状态 | 颜色 |
|---|---|
| 开 | 青蓝 / 绿色 |
| 关 | 暗灰 / 红灰 |

---

## 11.4 快捷键绑定项

用于按键操控页面。

### Hover
- 条目高亮
- 右侧按键框发光

### Click
- 进入等待输入状态
- 按键框变为橙黄色闪烁
- 显示：`请按下新的按键`

### 输入成功
- 按键框绿色闪光
- 更新按键文本
- 播放确认音

### 输入冲突
- 按键框红色闪烁
- 弹出提示：`该按键已被使用`
- 可选择：
  - 覆盖绑定
  - 取消

图鉴包含：
- 角色部件
- 敌机
- Boss

核心功能是查看模型、数值、旋转缩放。

---

## 12.1 图鉴列表条目 Hover

表现：

1. 条目放大 1.03。
2. 外框蓝青发光。
3. 对应模型预览窗口中出现轻微轮廓光。
4. 未解锁条目只显示暗色悬停，不显示完整信息。

点击后：

1. 条目进入 Selected。

3. 数值面板刷新。
4. 模型播放入场旋转动画。
5. 播放信息打开音效。

---

## 12.3 模型查看器交互

### 鼠标悬停在模型区域
显示操作提示：

```text
左键拖动：旋转模型
滚轮：缩放模型
右键拖动：平移视角
双击：重置视角
```

### 拖动旋转
- 模型跟随鼠标旋转
- 模型底部全息圆环亮起
- 鼠标松开后保留当前角度

### 滚轮缩放
- 缩放时显示缩放百分比
- 超过最大/最小距离时轻微阻尼反馈

### 双击重置
- 模型平滑转回默认角度
- 播放轻确认音

# 15. Tooltip 悬浮提示规范

```text

位置从鼠标旁边轻微上浮 6px
```

```text
标题
类型 / 稀有度

操作提示
```

# 16. 错误与成功反馈规范

## 16.1 成功反馈

用于：
- 设置保存成功
- 部件安装成功
- BD选择成功
- 图鉴解锁
- 快捷键绑定成功

表现：

1. 绿色或蓝绿色闪光。
2. 简短成功音效。
3. Toast 提示从顶部或右侧滑入。
4. 1.5 秒后自动消失。

示例文案：

```text

部件安装成功
快捷键绑定完成
新图鉴已解锁
```

用于：
- 无法安装
- 按键冲突
- 无存档
- 无法保存
- 资源不足

表现：

1. 红色边框闪烁 2 次。
2. 低频错误音。
3. 小幅左右抖动。
4. 显示错误文案。

示例文案：

```text
当前位置无法搭建
```

# 27. 最终验收标准

完成后，UI 交互应满足：

1. 玩家鼠标移动到任何可交互 UI 上，都能立刻知道它可以操作。
2. 玩家点击任何按钮，都有明确的按压和确认反馈。
3. 玩家选择 BD 时，有强烈的“做出选择”的仪式感。
4. 玩家拖拽积木时，能清楚知道哪里能放、哪里不能放。
5. 玩家查看图鉴时，模型和列表交互清楚、舒服。
6. 设置界面所有控件都有现代游戏级反馈。
7. 禁用、错误、成功状态都清楚不混淆。
8. 所有反馈不破坏布局，不遮挡重要信息。
9. 整套 UI 交互风格统一，形成完整品质感。

# 28. 总结

这套 UI 优化的核心不是单纯“放大一点”或“加个光”，而是建立完整的交互反馈语言。

玩家看到一个 UI 元素时，应该自然理解：

```text
能不能点
点了会发生什么
当前是否选中
操作是否成功
哪里出了问题
```

对于《太空3D积木飞船幸存者》来说，最适合的 UI 反馈气质是：

```text
鼠标靠近 → 飞船控制台识别目标
鼠标悬停 → 能量边框启动
鼠标点击 → 机械卡扣确认
操作成功 → 模块接入系统
操作失败 → 控制台警告报错
```

只要所有按钮、卡牌、背包格子、列表条目、设置控件都遵循这套反馈规范，整体 UI 质感会明显提升，玩家也会觉得界面更灵敏、更高级、更像正式游戏成品。
