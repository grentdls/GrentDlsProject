## 1. 文档目标

本文件用于统一《太空3D积木飞船幸存者》项目中所有 UI 美术资源的 AI 生成方案。

主要目标：

1. 统一整套 UI 的美术风格。
2. 将每个 UI 界面拆成可切图、可复用、可做预制体的独立部件。
3. 提供通用提示词、负面提示词、尺寸建议和命名规范。
4. 覆盖主界面、战斗 HUD、积木搭建界面、BD 三选一、背包、事件、Boss、设置、图鉴、结算等完整 UI。
5. 让后续 AI 出图、UI 切图、程序搭建预制体都有统一依据。

## 2. 整体 UI 美术风格

### 2.1 核心风格定位

本项目 UI 建议采用：

- 太空科幻
- 积木拼装
- 模块化机械
- 3D 手游 UI 质感
- 飞船控制台风格
- 清晰、轻量、中度科幻
- 蓝青色发光科技线条
- 深灰金属底板
- 结构分区明确
- 适合长时间战斗阅读

整体不要做成过于硬核的军事 HUD，也不要做成过度霓虹的赛博朋克。UI 需要有科幻感，但必须保持清晰、干净、可读。

## 3. 全局生成规范

### 3.1 所有 UI 图通用要求

所有 UI 素材都建议按以下标准生成：

1. PNG 格式。
2. 透明背景。
3. 单独素材，不要场景。
4. 不要人物。
5. 不要飞船完整场景，除非是展示框装饰。
6. 不要写死文字。
7. 不要写死数字。
8. 边缘干净，方便抠图和切图。
9. 结构清晰，分区明确。
10. 适合 9-slice 九宫格拉伸。
11. 所有按钮、卡牌、进度条、面板都要拆分。

---

### 3.2 推荐尺寸

| UI 类型 | 推荐尺寸 |
|---|---:|
| 大面板底板 | 2048×1024 / 2048×2048 |
| 中型弹窗 | 1024×1024 |
| 小提示框 | 512×256 / 1024×512 |
| 按钮 | 512×256 / 512×512 |
| 图标 | 256×256 / 512×512 |
| 卡牌 | 768×1024 |
| 战斗顶部条 | 2048×512 |
| Boss 血条 | 2048×256 |
| 普通进度条 | 1024×256 |
| 背包格子 | 256×256 / 512×512 |
| 小地图边框 | 512×512 |

## 9. 伤害跳字生成方案

### 9.1 跳字类型

| 类型 | 颜色 | 表现 |
|---|---|---|
| 普通伤害 | 白色 / 浅黄 | 常规跳出 |
| 暴击伤害 | 橙红 / 金黄 | 更大、更亮、震动 |
| 持续伤害 | 紫色 / 红色 | 较小，连续跳出 |
| 护盾吸收 | 蓝色 | 带护盾图标感 |
| 治疗回复 | 绿色 | 向上漂浮 |
| 免伤 | 灰白 / 蓝白 | 显示抵挡感 |
| Miss | 灰色 | 轻微飘走 |
| 经验获得 | 青蓝色 | 吸收感 |
| 稀有奖励 | 紫色 / 金色 | 强发光 |

## 25. 美术落地要求总结

1. 所有 UI 素材优先透明背景。
2. 所有面板、按钮、卡牌、进度条必须拆分生成。
3. 所有文字和数字由程序实现，不要烘焙在图片中。
4. 战斗 HUD 必须清晰，不能遮挡战斗主体。
5. 积木搭建界面必须强化“可安装位置”“不可安装位置”“推荐位置”的视觉反馈。
6. Boss 出现必须有强提示：警告横幅、屏幕边缘红光、全局 Boss 血条。
7. BD 三选一卡牌要有明显稀有度和流派标签区域。
8. 图标必须小尺寸可读，不能细节过碎。
9. 所有通用部件尽量可九宫格拉伸。
10. 先生成通用件，再生成专属件，最后生成图标。
