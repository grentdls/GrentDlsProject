# 《积木星舰幸存者》完整玩法设计文档 V0.1

## 1. 游戏定位

### 1.1 游戏类型

3D 太空幸存者 / 飞船构筑 / 积木组装成长 / 随机地图探索。

玩家驾驶一艘由积木部件拼装而成的飞船，在随机生成的太空区域中持续飞行、战斗、拾取碎块、升级，并通过每次升级弹出的 BD 三选一不断扩展飞船结构和战斗能力。

### 1.2 核心卖点

1. **飞船不是固定模型，而是由积木实时搭建出来。**
   - 玩家每局的飞船外形都会随着选择的部件而变化。
   - 飞船成长不是单纯数值提升，而是“真的长出新的部件”。

2. **部件安装位置会影响实际战斗表现。**
   - 炮口朝向决定子弹发射方向。
   - 防御部件装在哪里，就保护哪里。
   - 辅助部件影响周围区域或全局属性。
   - 链接部件决定飞船最终结构和可扩展方向。

3. **太空 3D 幸存者玩法。**
   - 玩家自动朝屏幕深处飞行。
   - W 加速，S 减速，A / D 横向推进。
   - 鼠标或摇杆控制屏幕转向，带动飞船偏航移动。
   - 怪物持续刷新，大部分敌人以冲撞为主要攻击方式。

4. **敌人和玩家都由积木组成。**
   - 敌方飞行舰队、宇宙怪物、残骸单位都可以由积木结构组成。
   - 击杀敌人后掉落积木碎块。
   - 玩家拾取碎块获得经验并升级。

---

## 2. 核心循环

### 2.1 单局基础循环

```text
进入随机太空区域
→ 自动向屏幕深处飞行
→ 怪物从前方、侧方、后方刷新
→ 玩家依靠飞船部件自动攻击 / 定向攻击
→ 击杀敌人掉落积木碎块
→ 拾取碎块获得经验
→ 升级后弹出 BD 三选一
→ 获得新部件 / 强化已有部件 / 改变飞船结构
→ 飞船越来越大，火力越来越强
→ 敌人强度和密度提升
→ 遭遇精英、事件、小行星区、Boss
→ 坚持到目标时间或击败最终 Boss
```

### 2.2 核心体验目标

| 阶段 | 玩家感受 | 设计重点 |
|---|---|---|
| 开局 0-3 分钟 | 飞船很小，操作灵活，火力有限 | 快速建立积木拼装感 |
| 中期 3-10 分钟 | 飞船开始变大，方向性火力明显 | 让安装方向、结构布局产生策略 |
| 后期 10-20 分钟 | 飞船像移动堡垒，屏幕中大量弹幕和碎块 | 强化爽感和构筑成就感 |
| 终局 | 飞船结构庞大，但笨重，面对 Boss 和精英潮 | 考验结构规划和生存能力 |

## 3. 飞船基础规则

### 3.1 飞船本体

玩家初始飞船由一个核心部件组成。

初始结构：

```text
[核心驾驶舱]
```

初始核心属性：

| 属性 | 默认值 | 说明 |
|---|---:|---|
| 核心生命值 | 100 | 核心被摧毁则游戏失败 |
| 基础速度 | 12 m/s | 不按 W / S 时的默认飞行速度 |
| 最大速度 | 24 m/s | 按 W 后可达到 |
| 最低速度 | 5 m/s | 按 S 后可降低到 |
| 横向推进速度 | 8 m/s | A / D 横向移动 |
| 基础拾取范围 | 4 m | 自动吸取碎块范围 |
| 基础转向灵敏度 | 1.0 | 屏幕转向和偏航移动速度 |
| 初始连接点 | 6 个 | 上、下、左、右、前、后 |

---

### 3.2 积木基础单位

所有部件都必须以 **1 立方米** 为最小单位。

允许的部件尺寸示例：

| 尺寸 | 类型示例 |
|---|---|
| 1×1×1 | 小型基础方块 |
| 2×1×1 | 小型连接条 |
| 3×1×1 | 长条连接件 |
| 2×2×1 | 平面装甲板 |
| 2×2×2 | 大型立方体模块 |
| 1×3×1 | 纵向武器架 |
| 3×3×1 | 大型平台块 |
| 4×1×1 | 长梁 |
| 1×1×2 | 竖向连接柱 |

禁止出现非整数尺寸，例如：

```text
1.5×1×1
2.3×2×1
0.5×1×1
```

---

### 3.3 部件连接规则

1. 新部件必须连接到飞船已有部件上。
2. 每个部件至少有一个有效连接面。
3. 只有部件的“基础块部分”可以进行连接。
4. 防御块、攻击块、辅助块不能作为连接点。
5. 如果某个部件与核心失去连接，则该部件脱落。
6. 脱落部件可变成场景残骸，也可被敌人撞碎。

有效连接示例：

```text
[链接部件] - [攻击部件基础块]
```

无效连接示例：

```text
[链接部件] - [攻击部件上方炮塔]
```

---

### 3.4 部件方向规则

每个部件都有朝向。

方向分为：

```text
前、后、左、右、上、下
```

朝向影响：

| 部件类型 | 是否受朝向影响 | 示例 |
|---|---|---|
| 链接部件 | 部分影响 | 决定可扩展方向 |
| 防御部件 | 是 | 正面装甲只保护正面区域 |
| 攻击部件 | 强影响 | 炮口朝左则向左开火 |
| 辅助部件 | 部分影响 | 锥形增幅器只强化前方区域 |

---

### 3.5 飞船整体属性

飞船总属性由所有部件叠加计算。

| 属性 | 来源 |
|---|---|
| 核心生命 | 核心、辅助部件、BD 强化 |
| 部件生命 | 每个部件独立计算 |
| 飞行速度 | 核心速度 - 总质量影响 + 推进类辅助 |
| 转向速度 | 核心转向 - 飞船体积影响 + 控制类辅助 |
| 横移速度 | 横向推进基础值 + 推进类辅助 |
| 拾取范围 | 核心拾取范围 + 磁吸辅助 |
| 火力强度 | 攻击部件数量、等级、辅助加成 |
| 防御能力 | 防御部件位置、等级、护盾覆盖 |
| 结构稳定性 | 链接部件数量和连接质量 |

## 4. 部件系统

### 4.1 部件总分类

部件分为四大类：

```text
链接部件
防御部件
攻击部件
辅助部件
```

---

### 4.2 链接部件

#### 4.2.1 定位

链接部件是飞船结构扩展的基础。

它们通常体积较大，主要用于：

1. 拓展飞船长度、宽度、高度。
2. 提供更多安装点。
3. 改变飞船外形。
4. 承担部分伤害。
5. 让攻击、防御、辅助模块可以安装在更合理的位置。

#### 4.2.2 链接部件特点

| 特点 | 说明 |
|---|---|
| 体积较大 | 经常是 2×1×1、3×1×1、2×2×1 |
| 连接点多 | 可以连接多个方向 |
| 战斗能力弱 | 通常不主动攻击 |
| 结构价值高 | 被摧毁可能导致外侧部件脱落 |
| 质量中等 | 过多会降低机动性 |

#### 4.2.3 链接部件示例

| 名称 | 尺寸 | 连接点 | 效果 |
|---|---|---|---|
| 小型连接块 | 1×1×1 | 六面 | 基础连接件 |
| 长条梁 | 3×1×1 | 前后左右 | 快速向一个方向延展 |
| 十字连接架 | 3×3×1 | 四向 | 适合搭建横向武器平台 |
| T 型连接架 | 3×2×1 | 三向 | 适合单侧扩展 |
| 厚重骨架块 | 2×2×1 | 六面 | 生命较高，但质量较大 |
| 环形连接座 | 3×3×1 | 外圈连接 | 适合作为大型武器平台 |
| 转接斜梁 | 2×2×1 | 斜向扩展 | 用于改变飞船轮廓 |
| 中央脊柱梁 | 4×1×1 | 前后主连接 | 适合构筑长船体 |

#### 4.2.4 链接部件玩法价值

链接部件不是单纯“垫块”，它决定：

1. 玩家能把炮装在哪里。
2. 防御是否能覆盖关键区域。
3. 辅助模块能影响多少攻击模块。
4. 飞船变大后是否容易被撞断。
5. 玩家飞船最终外观是否有个人特色。

---

### 4.3 防御部件

#### 4.3.1 定位

防御部件主要用于吸收、降低或免疫来自特定区域的伤害。

防御部件结构为：

```text
基础块 + 防御块
```

其中：

1. 基础块可以参与连接。
2. 防御块位于基础块上方或外侧。
3. 防御块不能参与连接。
4. 伤害打到防御块覆盖区域时，获得减伤或免伤效果。

#### 4.3.2 防御部件结构示意

```text
    [防御块]
    [基础块]
```

基础块连接飞船，防御块负责承受攻击。

#### 4.3.3 防御判定规则

当敌人攻击命中飞船时，系统判断命中点所在部件。

如果命中的是防御部件：

```text
最终伤害 = 原始伤害 × 防御部件伤害倍率
```

防御类型：

| 防御类型 | 伤害倍率 | 说明 |
|---|---:|---|
| 普通装甲 | 50% | 常规减伤 |
| 厚重装甲 | 30% | 高减伤，高质量 |
| 能量护盾 | 0% - 70% | 先消耗护盾值 |
| 反冲装甲 | 60% | 受到冲撞时反弹敌人 |
| 免伤盾面 | 0% | 有冷却，短时间免伤 |
| 陶瓷隔热板 | 40% | 对激光和火焰减伤更高 |

#### 4.3.4 防御部件示例

| 名称 | 尺寸 | 效果 | 缺点 |
|---|---|---|---|
| 小型装甲板 | 1×1×1 | 受到伤害降低 40% | 覆盖面积小 |
| 厚重装甲板 | 2×1×1 | 受到伤害降低 60% | 增加质量 |
| 冲撞缓冲块 | 1×1×1 | 冲撞伤害降低 70% | 对远程攻击效果弱 |
| 反弹装甲 | 1×1×1 | 被撞时弹开敌人 | 有冷却 |
| 能量盾发生器 | 2×2×1 | 生成局部护盾 | 护盾破裂后需恢复 |
| 正面舰首盾 | 3×1×1 | 正面冲撞免伤一次 | 冷却较长 |
| 侧翼护板 | 2×1×1 | 侧向伤害降低 | 只保护对应侧面 |
| 爆炸隔离板 | 1×1×1 | 降低范围爆炸伤害 | 生命较低 |

#### 4.3.5 防御部件设计重点

防御不是全局无脑叠数值，而是强调“装在哪里就保护哪里”。

例如：

1. 玩家经常被正面撞击，可以把重甲装在船头。
2. 玩家喜欢侧向飞行，可以强化左右护板。
3. 玩家船体很宽，需要在边缘安装防御。
4. 核心周围应优先安装防御，防止核心被直接击穿。

---

### 4.4 攻击部件

#### 4.4.1 定位

攻击部件是玩家主要输出来源。

攻击部件结构为：

```text
基础块 + 攻击块
```

其中：

1. 基础块参与连接。
2. 攻击块负责开火。
3. 攻击块不能用于连接。
4. 部分攻击部件强烈依赖安装方向。

#### 4.4.2 攻击方向规则

攻击部件分为三类：

| 类型 | 说明 |
|---|---|
| 固定方向武器 | 只朝安装方向开火 |
| 自动索敌武器 | 在一定范围内自动转向敌人 |
| 范围释放武器 | 不看方向，以自身为中心释放 |

固定方向武器示例：

```text
炮口朝前 → 只向前方发射子弹
炮口朝左 → 只向左侧发射子弹
炮口朝后 → 只向后方发射子弹
```

自动索敌武器示例：

```text
前方 90° 自动索敌
左侧 120° 自动索敌
全向 360° 自动索敌
```

全向自动索敌武器通常伤害较低，或冷却较长。

#### 4.4.3 攻击部件示例

| 名称 | 尺寸 | 类型 | 效果 |
|---|---|---|---|
| 单管机炮 | 1×1×1 | 固定方向 | 朝安装方向连续射击 |
| 双联机炮 | 2×1×1 | 固定方向 | 两条弹道，射速较快 |
| 散射炮 | 1×1×1 | 固定方向 | 扇形发射多发子弹 |
| 穿透激光器 | 2×1×1 | 固定方向 | 发射直线激光，穿透敌人 |
| 导弹发射仓 | 2×2×1 | 自动索敌 | 发射追踪导弹 |
| 闪电链模块 | 1×1×1 | 自动索敌 | 命中后弹射多个目标 |
| 等离子喷口 | 1×1×1 | 固定方向 | 近距离高伤害喷射 |
| 浮游炮接口 | 2×1×1 | 自动索敌 | 召唤浮游炮环绕攻击 |
| 磁轨炮 | 3×1×1 | 固定方向 | 低射速，高穿透 |
| 脉冲爆发器 | 2×2×1 | 范围释放 | 周期性释放范围冲击波 |
| 后置尾炮 | 1×1×1 | 固定方向 | 专门攻击身后追击敌人 |
| 侧翼切割激光 | 2×1×1 | 固定方向 | 适合装在左右侧翼 |

#### 4.4.4 攻击部件数值维度

每个攻击部件至少包含以下数值：

| 数值 | 说明 |
|---|---|
| 伤害 | 单次命中造成的基础伤害 |
| 射速 | 每秒攻击次数 |
| 弹速 | 子弹飞行速度 |
| 射程 | 最大攻击距离 |
| 穿透 | 可穿透敌人数量 |
| 弹体大小 | 命中体积 |
| 暴击率 | 触发高额伤害概率 |
| 暴击伤害 | 暴击倍率 |
| 冷却时间 | 技能型武器的间隔 |
| 朝向限制 | 是否只向安装方向攻击 |
| 索敌角度 | 自动瞄准范围 |
| 能耗 | 后续可扩展为能量系统 |

#### 4.4.5 攻击玩法策略

玩家需要考虑：

1. 船头装正面火力，适合主动冲杀。
2. 两侧装侧翼炮，适合横移扫射。
3. 船尾装后置炮，适合处理追击敌人。
4. 核心周围装范围攻击，适合清理近身敌人。
5. 远端链接梁上装武器，火力覆盖广，但容易被撞断。
6. 高伤害武器需要保护，否则被打掉会损失大量输出。

### 4.5 辅助部件

#### 4.5.1 定位

辅助部件提供全局属性，或增强某一区域的部件。

辅助部件结构为：

```text
基础块 + 辅助块
```

其中：

1. 基础块参与连接。
2. 辅助块提供增益效果。
3. 辅助块不能用于连接。

#### 4.5.2 辅助类型

辅助部件分为两类：

```text
全局辅助
区域辅助
```

全局辅助示例：

| 辅助效果 | 说明 |
|---|---|
| 飞船最大速度 +10% | 增强移动 |
| 拾取范围 +2m | 更容易吸收碎块 |
| 所有武器射速 +5% | 全局输出提升 |
| 所有防御部件生命 +10% | 提高生存能力 |
| 核心生命 +20 | 提高容错 |
| 碰撞伤害降低 10% | 适合冲撞压力大的局 |

区域辅助示例：

| 辅助效果 | 范围 |
|---|---|
| 周围 2 格攻击部件伤害 +20% | 曼哈顿距离 2 |
| 同一连接分支上的激光武器射程 +25% | 分支范围 |
| 前方 3 格武器射速 +15% | 锥形范围 |
| 左右相邻防御部件减伤 +10% | 相邻范围 |
| 周围部件每 5 秒恢复 3 点生命 | 小范围修复 |

#### 4.5.3 辅助部件示例

| 名称 | 尺寸 | 类型 | 效果 |
|---|---|---|---|
| 小型能源核心 | 1×1×1 | 全局 | 所有攻击部件伤害 +5% |
| 武器增幅器 | 1×1×1 | 区域 | 周围 2 格武器伤害 +20% |
| 冷却散热片 | 2×1×1 | 区域 | 周围武器射速 +15% |
| 磁吸收集器 | 1×1×1 | 全局 | 拾取范围 +3m |
| 纳米维修仓 | 2×1×1 | 区域 | 周围部件缓慢回血 |
| 推进稳定器 | 1×1×1 | 全局 | 横向推进速度 +10% |
| 偏航控制器 | 1×1×1 | 全局 | 转向灵敏度 +15% |
| 护盾共鸣器 | 2×2×1 | 区域 | 周围防御部件护盾恢复速度 +20% |
| 弹道计算机 | 1×1×1 | 全局 | 子弹类武器弹速 +20% |
| 导弹制导器 | 1×1×1 | 全局 | 导弹锁定速度 +25% |

## 5. 飞船搭建界面与升级选择

### 5.1 升级触发

玩家拾取积木碎块获得经验。

经验满后：

```text
游戏暂停或子弹时间减速
→ 弹出 BD 三选一界面
→ 玩家选择一项奖励
→ 如果奖励是新部件，进入快速安装界面
→ 安装完成后继续战斗
```

---

### 5.2 BD 三选一类型

每次升级出现 3 个选项。

选项类型包括：

```text
获得新部件
强化已有部件
获得全局被动
改变某类部件规则
获得一次性修复
扩展连接空间
```

### 5.3 BD 选项示例

#### 新部件类

| 名称 | 效果 |
|---|---|
| 获得单管机炮 | 可安装一个 1×1×1 单管机炮 |

### 5.4 新部件安装界面

当玩家选择新部件时，进入安装模式。

安装界面规则：

1. 战斗暂停或减速到 10%。
2. 摄像机拉近飞船。
3. 显示当前飞船的可连接位置。
4. 玩家选择一个可用连接点。
5. 玩家可旋转部件方向。
6. 合法位置显示绿色。
7. 非法位置显示红色。
8. 确认后部件安装到飞船上。
9. 安装完成后回到战斗。

安装合法性判断必须同时满足：

```text
部件基础块至少有一面连接已有部件
不与已有部件重叠
不超出当前飞船最大尺寸限制
攻击块 / 防御块 / 辅助块没有被其他部件占用
连接后能追溯到核心
```

## 6. 飞船损伤与断裂系统

### 6.1 部件独立生命

每个部件拥有独立生命值。

攻击命中哪个部件，就优先扣除哪个部件的生命。

```text
部件生命 <= 0 → 部件损毁
```

### 6.2 断裂规则

如果某个部件损毁后，导致外侧部件无法连接到核心，则外侧部件全部脱落。

示例：

```text
核心 - 长梁 - 炮塔
```

如果长梁被摧毁：

```text
核心    炮塔脱落
```

炮塔不会继续工作。

### 6.3 核心暴露风险

如果玩家只追求外扩火力，不保护核心，敌人可能直接撞击核心。

核心受到伤害时：

1. 屏幕出现红色警告。
2. 飞船驾驶舱闪烁。
3. UI 显示核心受损提示。
4. 核心生命归零后游戏失败。

### 6.4 修复机制

| 来源 | 效果 |
|---|---|
| BD 选择 | 立即修复部分部件 |
| 纳米维修仓 | 周期性修复周围部件 |
| 碎块修复事件 | 拾取特殊绿色碎块恢复生命 |
| 关卡事件 | 废弃维修站提供修复 |
| 被动技能 | 每隔一段时间修复最低生命部件 |

## 7. 操控系统

### 7.1 基础操控

飞船自动朝屏幕深处飞行。

| 输入 | 效果 |
|---|---|
| W | 加速 |
| S | 减速 |
| A | 左横向推进 |
| D | 右横向推进 |
| 鼠标移动 / 右摇杆 | 控制屏幕转向，飞船偏航 |
| 鼠标左键 / 自动 | 可选：手动主武器开火 |
| Space | 可选：短促推进 / 闪避 |
| Tab | 打开飞船结构查看界面 |

### 7.2 飞行表现

飞船一直向屏幕深处飞行，玩家主要控制：

1. 横向躲避。
2. 加减速。
3. 屏幕方向。
4. 飞船偏航角。

偏航移动表现：

```text
玩家向右转屏幕
→ 飞船船头逐渐偏向右侧
→ 飞行轨迹向右弯曲
→ 船身产生轻微倾斜
```

### 7.3 惯性与质量影响

飞船越大，质量越高。

| 影响项 | 说明 |
|---|---|
| 加速速度降低 | 大飞船提速慢 |
| 减速速度降低 | 大飞船刹车慢 |
| 横向推进降低 | 大飞船躲避困难 |
| 转向速度降低 | 大飞船偏航笨重 |
| 冲撞敌人伤害提高 | 大质量飞船撞击更强 |
| 被敌人撞击时更稳定 | 不容易被小怪撞偏 |

### 7.4 操控成长方向

| 成长方向 | 适合玩法 |
|---|---|
| 高速度小船 | 靠机动躲避，火力集中 |
| 重甲巨舰 | 扛伤害，正面碾压 |
| 横向火力船 | 依靠 A / D 横移扫射 |
| 后置炮船 | 处理大量追兵 |
| 自动索敌船 | 操作压力低，靠构筑输出 |
| 冲撞流飞船 | 船头重甲，主动撞怪 |

## 8. 战斗系统

### 8.1 战斗基本规则

敌人会不断从地图不同位置刷新。

大部分敌人以冲撞为主要攻击手段。

玩家依靠：

```text
飞船移动
武器自动攻击
安装方向规划
防御部件保护
辅助模块强化
```

来生存。

### 8.2 武器开火规则

默认情况下，所有攻击部件自动开火。

不同武器有不同索敌逻辑：

| 武器类型 | 索敌方式 |
|---|---|
| 固定炮 | 不索敌，朝安装方向开火 |
| 自动炮塔 | 搜索范围内最近敌人 |
| 导弹 | 搜索范围内血量最高或最近敌人 |
| 闪电链 | 搜索最近敌人，命中后跳跃 |
| 激光 | 朝安装方向持续或间歇照射 |
| 范围脉冲 | 不索敌，周期性释放 |

### 8.3 子弹命中规则

每个子弹拥有：

```text
飞行方向
飞行速度
伤害
穿透数量
生命周期
命中特效
击退强度
```

命中敌人后：

```text
敌人受到伤害
播放受击特效
如果子弹有穿透，则继续飞行
否则销毁
```

### 8.4 激光命中规则

激光类武器使用射线或持续判定。

特点：

1. 命中稳定。
2. 适合清理直线敌人。
3. 对高速敌人效果好。
4. 可被 BD 强化为灼烧、穿透、折射。

### 8.5 导弹命中规则

```text
发射导弹
→ 寻找目标
→ 调整飞行方向
→ 接近目标
→ 命中或到达最大时间
→ 产生爆炸
→ 范围内敌人受到伤害
```

### 8.6 闪电链规则

```text
第 1 个目标：100% 伤害
第 2 个目标：80% 伤害
第 3 个目标：60% 伤害
第 4 个目标：40% 伤害
```

可通过 BD 增加跳跃次数。

### 8.7 冲撞判定

冲撞是本游戏核心伤害来源之一。

冲撞伤害公式：

```text
冲撞伤害 = 相对速度 × 撞击方质量 × 撞击倍率
```

影响冲撞的因素：

| 因素 | 影响 |
|---|---|
| 相对速度 | 越快伤害越高 |
| 质量 | 越重撞击越强 |
| 防御部件 | 可大幅降低伤害 |
| 冲撞角度 | 正面撞击伤害最高 |
| 护盾 | 可吸收冲撞伤害 |
| 特殊 BD | 可让玩家主动撞怪 |

### 8.8 敌人死亡与掉落

敌人死亡后：

1. 积木身体碎裂。
2. 播放爆炸或解体特效。
3. 掉落积木碎块。
4. 特殊敌人掉落稀有碎块或临时道具。
5. 大型敌人可能掉落完整部件选项。

### 9.3 怪物刷新规则

#### 9.3.1 刷新导演系统

游戏使用“威胁值”控制刷怪。

```text
当前时间越久 → 威胁值越高
玩家等级越高 → 威胁值越高

```

威胁值公式示例：


#### 9.3.2 刷新区域

|---|---|
| 屏幕前方远处 | 主要敌人来源 |

| 破败星球附近 | 事件或精英刷新 |
| 地图边界外 | 大型敌人从远处进入 |

#### 9.3.3 刷新波次示例

第 0-3 分钟：


第 3-7 分钟：

第 7-12 分钟：

第 12-18 分钟：

```text

混合远程单位

```

```text
Boss 刷新
```

| 名称 | 效果 |
|---|---|
| 模块化扩展 | 每次获得链接部件时额外获得一个小连接块 |
| 巨舰协议 | 飞船部件数量越多，所有武器伤害越高 |
| 结构冗余 | 部件断裂时有概率保留连接 |
| 大型平台 | 获得一个 3×3×1 大型连接平台 |

## 12. 随机地图系统

### 12.1 地图基础结构

地图是一个有边界的太空区域。

```text
中心安全区
→ 普通战斗区
→ 小行星密集区
→ 破败小星球区域
→ 危险边界区
```

### 12.2 区域限制

当玩家接近地图边界时：

1. 远处出现能量屏障。
2. UI 出现“接近危险边界”提示。
3. 飞船受到轻微推回。
4. 超出边界时间过长会持续受伤。
5. 敌人可以从边界外刷新进入。

### 12.3 随机地标

| 地标 | 作用 |
|---|---|
| 破败小星球 | 作为场景视觉中心，可刷新事件 |
| 小行星带 | 阻挡移动，提供碰撞风险 |
| 残骸带 | 可击碎获得碎块 |
| 废弃空间站 | 提供修复或商店事件 |
| 能量风暴区 | 进入后速度提高但持续受伤 |
| 引力异常区 | 改变飞船移动方向 |
| 太空矿脉 | 击碎后掉落大量碎块 |
| 虫巢陨石 | 持续刷新宇宙怪物 |
| 古代传送门 | 触发精英战或奖励事件 |

### 12.4 破败小星球设计

表现：

1. 表面破裂。
2. 有残骸环绕。
3. 部分建筑漂浮在轨道上。
4. 星球附近有小行星碎片。
5. 可能有敌方巢穴或舰队驻守。

玩法：

| 类型 | 效果 |
|---|---|
| 废弃矿星 | 击碎矿物获得碎块 |
| 战争残星 | 刷新敌方舰队 |
| 虫巢星 | 持续生成宇宙怪物 |
| 维修卫星星 | 附近有修复事件 |
| 能源星核 | 击破后获得强力 BD |
| 黑市小行星 | 可消耗碎块购买部件 |

### 12.5 地图生成规则

每局生成时：

```text

随机生成中心点
随机分布小星球
随机布置小行星带
```

### 13.2 Boss 设计示例：积木吞星母舰

#### Boss 外观

由大量黑色、红色、紫色积木拼接而成的巨型太空母舰。

结构包括：

```text
核心舱
左右炮翼
前方撞角
导弹仓
召唤舱
护盾发生器
```

#### 阶段一：远程压制

Boss 保持距离，发射弹幕和导弹。

| 技能 | 表现 |
|---|---|
| 三联激光 | 三条红色激光横扫 |

| 召唤无人机 | 释放小型积木舰队 |

Boss 血量低于 60%。

表现：

1. 左右炮翼部分损毁。
2. 掉落大量碎块。
3. 移动速度提高。
4. 开始冲撞玩家。

| 技能 | 表现 |
|---|---|
| 巨舰冲锋 | 蓄力后直线撞向玩家 |
| 残骸散射 | 抛出积木残骸形成弹幕 |
| 护盾重启 | 短时间减伤 |

#### 阶段三：核心暴露

Boss 血量低于 25%。

表现：

1. 外壳破裂。
2. 核心发光。
3. 周围持续刷新小怪。
4. Boss 攻击频率大幅提高。

| 技能 | 表现 |
|---|---|
| 核心脉冲 | 大范围冲击波 |
| 末日吸引 | 将碎块和玩家缓慢吸向核心 |
| 自毁倒计时 | 限时击杀，否则全屏爆炸 |

## 21. 推荐核心设计原则

1. **飞船成长必须可视化。**
   - 每次升级最好能看到飞船真的变大或变强。

2. **安装位置必须有意义。**
   - 炮装前面、侧面、后面，战斗体验要明显不同。

3. **防御必须是局部防御。**
   - 不要只做全局减伤，否则积木拼装价值会降低。

4. **辅助要鼓励布局规划。**
   - 区域辅助能让玩家思考“把哪些武器集中到一起”。

5. **敌人要逼迫玩家全方向构筑。**
   - 如果敌人只从前方来，玩家只会堆前方火力。
   - 后方追兵、侧面冲撞、范围爆炸都要存在。

6. **飞船越大越强，但也越笨重。**
   - 大船不能只是无脑变强。
   - 质量、转向、断裂风险要形成代价。

7. **掉落碎块要有吸引力。**
   - 玩家应该有“想冲过去吃经验”的冲动。
   - 但冲过去可能撞进怪群，形成风险收益。

8. **BD 应该能形成明显流派。**
   - 正面火力、侧翼扫射、重甲堡垒、自动索敌、冲撞碾压、巨舰扩展都应能玩出差异。

## 22. 一局游戏示例流程

### 22.1 开局

玩家只有核心驾驶舱和一个单管机炮。

```text
飞船很小，速度快。
敌人主要是小型追撞机。
玩家通过横移和加速躲避。
```

### 22.2 第一次升级

出现 BD 三选一：

```text
1. 获得长条梁
2. 获得小型装甲板
3. 机炮伤害 +15%
```

玩家选择长条梁，安装到核心左侧，为后续侧翼火力做准备。

### 22.3 中期

玩家已经拥有：

```text
核心
左右连接梁
前方装甲
左侧散射炮
右侧激光器
后方尾炮
磁吸收集器
```

战斗风格变成：

```text
左右横移扫射
后置尾炮处理追兵
正面装甲抵挡冲撞
```

### 22.4 后期

玩家获得多个 BD：

```text
侧翼武器伤害 +20%
横移时侧翼武器射速 +30%
辅助范围 +1
所有防御部件生命 +30%
```

飞船逐渐成型为侧翼扫射巨舰。

### 22.5 Boss 战

Boss 从前方出现，召唤小怪并发射导弹。

玩家需要：

1. 横向移动躲激光。
2. 用侧翼火力持续输出。
3. 保护核心不被召唤物撞到。
4. 拾取 Boss 掉落碎块继续升级。
5. 最终击破 Boss 核心。

## 24. 总结

本游戏的核心不是传统幸存者的“角色升级”，而是“飞船结构成长”。

玩家每一次升级都应该带来三个层面的变化：

```text
数值变强
结构改变
战斗方式改变
```

最理想的体验是：

```text
开局是一艘小飞船
中期变成有明显战术方向的模块舰
后期成长为玩家亲手拼出来的太空巨舰
```

只要部件安装位置、防御覆盖、攻击方向、辅助范围和飞船质量这些规则成立，游戏就会自然形成非常强的构筑深度和重复游玩价值。
