# 《太空3D积木飞船幸存者》积木搭建界面优化与操作流程完整文档

版本：V1.0  
用途：用于规范玩家在局内/局外进行飞船积木搭建、拖拽安装、重排调整时的完整 UI、交互、HUD 提示、预制体结构与逻辑表现。  
目标：让“搭建飞船”真正成为核心乐趣，而不是简单的选项弹窗。

---

# 1. 设计目标

当前搭建界面需要从“纯选项式安装”升级为“半编辑器式可视搭建模式”。

本次优化重点：

1. 增加 **未搭建部件列表** 与 **已搭建部件列表**。
2. 玩家需要从未搭建列表中 **点击/拖拽部件** 到主飞船上进行安装。
3. 鼠标拿起部件后，显示该部件的 **3D 预览模型**。
4. 当鼠标靠近飞船时，要显示：
   - 预搭建区域高亮
   - 能否安装
   - 安装后占用范围
   - 连接是否合法
5. 鼠标松开后，若合法，才真正安装。
6. 玩家可以点击已经搭建的部件，再次拖动，进行 **重新调整位置**。
7. 搭建界面不会因为一次搭建完成而关闭。
8. 玩家必须点击 **“继续游戏”** 按钮，才退出搭建模式并返回战斗。
9. 整个界面需支持 **预制体化搭建**，便于程序拆分实现。

---

# 2. 界面定位

该界面本质上是：

- 战斗中的暂停式搭建界面
- 局内实时飞船编辑器
- 积木背包 + 飞船结构管理界面
- 半 RTS / 半生存玩法中的模块构筑 UI

在玩家升级、获得部件、事件奖励、拾取特殊模块时，都可以进入该界面。

---

# 3. 进入搭建界面的触发方式

## 3.1 进入来源

可通过以下方式进入：

1. 升级后选择“获得新部件”
2. 拾取稀有完整积木部件
3. 完成事件奖励获得可安装模块
4. 手动点击战斗 HUD 上的“搭建”按钮
5. 局外蓝图编辑模式

## 3.2 进入时的游戏状态

建议采用“强暂停模式”或“超低速模式”。

### 方案 A：完全暂停
- 敌人停止运动
- 子弹暂停
- 粒子可缓慢播放
- 适合纯操作构筑

### 方案 B：低速暂停
- 全局时间缩放到 0.05 ~ 0.1
- 背景环境继续缓慢运动
- 突出“战斗中快速维修搭建”的紧张感

建议：
- 普通搭建使用完全暂停
- 特殊玩法可做“危险搭建模式”作为后续扩展

# 5. 核心操作流程设计

# 5.1 从未搭建列表安装部件

标准流程：

```text
玩家打开搭建界面
→ 查看左侧未搭建部件列表
→ 点击某个部件
→ 鼠标上出现该部件的半透明3D模型
→ 飞船上可连接位置开始高亮
→ 鼠标移动到某个位置时显示占用预览
→ 系统判断合法/非法
→ 若合法，显示绿色高亮和属性预览
→ 玩家松开鼠标
→ 部件安装成功
→ 部件从未搭建列表移除，加入已搭建列表
→ 界面仍保持打开
```

---

# 5.2 已搭建部件重新调整位置

标准流程：

```text
玩家点击飞船上某个已安装部件
→ 部件出现选中描边
→ 右侧已搭建列表同步高亮
→ 再次按住拖动该部件
→ 进入“重定位模式”
→ 原位置显示残影
→ 鼠标携带部件预览模型移动
→ 移动到新位置后判断是否合法
→ 松开鼠标后，若合法则重新安装
→ 若非法则返回原位或等待重新摆放
```

### 推荐细节
- 已搭建部件被拖动时，原位置可以显示“虚位占坑框”
- 若松手位置非法，默认不丢失部件，返回手上待放置状态
- 玩家按 ESC 或右键取消，恢复到原位置

---

# 5.3 拆除已搭建部件

可通过两种方式：

### 方式 A：选中后点击底部“拆除”按钮
### 方式 B：右键快捷菜单选择“拆除”

处理结果：
- 被拆除部件从飞船上移除
- 回到左侧未搭建部件列表
- 如果拆除后导致一串外接部件失去连接：
  - 方案 1：一并拆下，全部进入未搭建列表
  - 方案 2：提示玩家“将导致 4 个部件脱落，是否确认”

推荐：采用确认提示，避免误操作。

---

# 5.4 继续游戏流程

这是整个界面的核心退出逻辑。

```text
玩家完成若干次安装/调整/拆除
→ 点击“继续游戏”
→ 系统检查当前结构是否有效
→ 若结构合法，保存当前飞船状态
→ 关闭搭建UI
→ 恢复战斗时间流逝
→ 返回战斗
```

### 点击继续游戏前的校验
必须校验：
1. 核心存在
2. 所有已搭建部件都连通到核心
3. 没有重叠占用
4. 没有非法悬空部件
5. 没有未完成拖拽中的部件

如果不合法：
- 弹出红色提示：`当前飞船结构无效，无法继续游戏`
- 镜头自动聚焦非法位置

# 6. 搭建合法性判定规则

# 6.1 基础规则

部件可被安装，必须满足：

1. 至少一个基础连接面连接到已有飞船结构
2. 不与现有部件重叠
3. 不超出飞船最大搭建范围（如有限制）
4. 攻击块/防御块/辅助块不与其他部件冲突
5. 连接后最终可追溯到核心

---

# 6.2 预搭建显示规则

玩家拖动部件到飞船附近时，应显示：

### 合法时
- 预览模型显示为 **半透明绿色/蓝色**
- 占用格点显示绿色框
- 连接边显示绿色线
- 右侧显示属性变化预览
- 底部提示：`松开鼠标安装`

### 非法时
- 预览模型显示为 **半透明红色**
- 冲突格点红框闪烁
- 非法原因提示
- 底部提示：`当前位置无法搭建`

---

# 6.3 非法原因提示文案

建议支持以下原因：

1. `未连接到主结构`
2. `与其他部件重叠`
3. `超出搭建范围`
4. `功能块区域冲突`
5. `该方向无法连接`
6. `会导致核心断链`
7. `此位置被锁定`

这些提示应同时在：
- 中央预览区浮动提示
- 顶部状态条提示
- 右侧详情区红字提示

---

# 7. 高亮与反馈表现设计

# 7.1 飞船上的高亮类型

建议至少做以下 6 类：

1. **可连接位置高亮**：浅蓝或绿色
2. **推荐位置高亮**：金色或更亮的青色
3. **非法位置高亮**：红色
4. **当前选中部件描边**：亮蓝描边
5. **拖拽目标占用区**：网格化透明面
6. **断链风险提示**：橙红色闪烁

---

# 7.2 视觉反馈时机

| 场景 | 表现 |
|---|---|
| 鼠标选中未搭建部件 | 鼠标出现 3D 预览模型 |
| 鼠标进入飞船编辑区 | 飞船可搭建位高亮 |
| 预放置到合法位置 | 绿色占位框 + 属性变化 |
| 预放置到非法位置 | 红色占位框 + 失败原因 |
| 松开鼠标成功搭建 | 咔哒拼装动画 + 音效 |
| 松开鼠标失败 | 错误提示音 + 红框闪烁 |
| 选中已搭建部件 | 部件描边 + 右侧详情更新 |
| 拖动已搭建部件 | 原位置残影 + 目标位预览 |
| 拆除部件 | 解构粒子 + 列表回收动画 |

---

# 7.3 音效建议

| 行为 | 音效 |
|---|---|
| 拿起部件 | 轻机械拾取声 |
| 进入合法区域 | 清脆确认提示音 |
| 进入非法区域 | 低频错误提示音 |
| 成功安装 | “咔哒”拼装声 + 轻微能量启动音 |
| 拆除部件 | 机械解锁声 |
| 旋转部件 | 轻齿轮切换音 |
| 点击继续游戏 | 控制台确认音 |
| 无法继续游戏 | 警告蜂鸣 |

# 8. 未搭建部件列表详细设计

# 8.1 显示模式建议

建议支持两种切换：

## 网格模式（默认）
适合快速选择

每格显示：
- 图标
- 数量
- 稀有度边框
- 尺寸

## 列表模式
适合查看详细属性

每行显示：
- 图标
- 名称
- 类型
- 尺寸
- 数量
- 简要属性
- 小型拖拽按钮

---

# 8.2 条目状态

每个条目需支持以下视觉状态：

1. 默认
2. 悬停
3. 选中
4. 不可用（如当前条件下无法安装）

---

# 8.3 未搭建列表的辅助功能

建议加入：

1. **筛选**
   - 仅显示攻击部件

2. **排序**
   - 按类型
   - 按稀有度
   - 按尺寸
   - 按获得时间
3. **快速定位推荐**
   - 点击按钮后，系统自动高亮适合该部件的推荐位

# 11. 属性变化预览设计

在玩家预放置部件时，应实时显示“安装后变化”。

## 11.1 位置建议

可放在中央区域右上角的悬浮信息框，或右侧详情区上方。

## 11.2 显示字段

例如：

```text
安装后变化：
总火力：120 → 138  (+18)
总耐久：540 → 560  (+20)
机动性：78 → 74   (-4)
拾取范围：12 → 12  (0)
结构评分：A → A+
```

## 11.3 颜色规则
- 正提升：绿色
- 负变化：红色
- 无变化：灰色

# 12. 拖拽交互细节规范

# 12.1 鼠标状态变化

## 普通状态
- 标准鼠标

## 选中未搭建部件时
- 鼠标旁跟随一个小部件图标
- 中央编辑区中显示完整半透明 3D 预览模型

## 拖拽已搭建部件时
- 鼠标旁出现“移动”标记
- 原位置出现虚影

## 非法放置时
- 鼠标图标变红或显示禁止符号

---

# 12.2 拖拽吸附规则

推荐使用 **格点吸附**：

1. 鼠标靠近飞船某格点时自动吸附
2. 预览模型对齐到格点
3. 若部件尺寸大于 1×1×1，则显示完整占用体积
4. 旋转后重新计算占用范围

这样能大幅降低误操作。

---

# 12.3 拖拽取消规则

以下操作可以取消当前拖拽：
- 右键
- ESC
- 把部件拖回左侧未搭建列表
- 点取消按钮

取消结果：
- 未搭建部件：回到未搭建列表
- 已搭建部件：恢复原位置

# 13. 继续游戏按钮设计重点

# 13.1 为什么必须单独保留“继续游戏”按钮

因为本界面是“构筑操作模式”，不应该像普通三选一那样选完立即退出。

这样设计有几个好处：

1. 玩家可以连续安装多个新部件
2. 玩家可以顺手重排旧部件
3. 玩家可以检查整体结构是否合理
4. 玩家可以对比火力和防御变化
5. 玩家能更强烈地感受到“我在真正造飞船”

---

# 13.2 按钮视觉要求

`继续游戏` 按钮要：
- 颜色更亮（蓝绿或橙蓝）
- 尺寸更大
- 位于底部最显眼位置
- 和其他操作按钮拉开层级
- 支持快捷键 Enter

---

# 13.3 点击后的状态提示

### 成功
- 播放确认音
- UI 淡出
- 飞船周围高亮消失
- 恢复战斗

### 失败
- 弹出红色提示条：`当前结构无效，无法继续战斗`
- 自动聚焦冲突位置
- 非法区域闪烁 1.5 秒

# 16. 推荐的实现逻辑顺序

2. 中央飞船预览
3. 拖拽安装

5. 继续游戏按钮

## 第二阶段：体验增强版
1. 右侧已搭建列表
2. 已搭建部件重排
3. 属性预览
4. 拆除确认
5. 撤销/重做

## 第三阶段：高级版
1. 树状连接视图
2. 自动整理
3. 保存蓝图
4. 推荐安装位
5. 风险提示（断链/火力覆盖/防御空缺）

# 17. 推荐的交互细节补充

## 17.1 新获得部件突出显示
左侧未搭建列表中，新获得部件应带：
- “NEW”角标
- 发光边框
- 列表自动滚动定位到该项

## 17.2 推荐位置功能
如果玩家选中一个部件后停顿 0.5 秒：
- 系统自动高亮 1~3 个推荐位置
- 优先考虑该部件类型最适合的位置

例如：
- 防御块推荐到船头或侧翼外层
- 攻击块推荐到有火力覆盖价值的位置
- 辅助块推荐到武器簇或核心附近

## 17.3 结构风险检查
点击继续游戏前，可自动分析：
- 核心防护薄弱
- 船尾火力不足
- 左侧结构断链风险高

以非强制提示方式显示在顶部或右侧。

# 18. 示例操作流程（完整）

## 场景示例
玩家在战斗中升级，获得 3 个新部件：
- 长条连接梁
- 双联机炮
- 小型装甲板

### 步骤 1：进入界面
- 游戏暂停
- 打开搭建界面
- 左侧显示 3 个新部件带高亮角标

### 步骤 2：安装连接梁
- 玩家从左侧拖出“长条连接梁”
- 鼠标携带部件模型
- 飞船核心左侧出现可连接高亮
- 玩家拖到左侧，绿色预览显示合法
- 松开鼠标，安装成功
- 左侧数量减 1，右侧已搭建列表新增条目

### 步骤 3：安装双联机炮
- 玩家拖出“双联机炮”
- 鼠标移到新连接梁外侧
- 系统提示合法，显示火力 +18
- 松开鼠标安装

### 步骤 4：调整旧装甲板
- 玩家点击飞船前方旧装甲板
- 中央部件高亮、右侧条目高亮
- 再次拖动，将其移动到左侧更外层
- 松开鼠标后成功重排

### 步骤 5：检查后继续游戏
- 玩家确认结构合理
- 点击右下“继续游戏”
- 界面关闭，战斗恢复

# 19. 总结

本次优化后的搭建界面，应当达到以下体验目标：

1. **像真的在拼飞船，而不是点卡片加属性**
2. **未搭建与已搭建分离，管理更清晰**
3. **拖拽预览、合法性判断、高亮反馈完整**
4. **支持重排与拆除，增强构筑深度**
5. **不自动退出，允许玩家连续调整结构**
6. **通过“继续游戏”形成明确的搭建闭环**
7. **整个界面结构清楚，方便做成预制体系统**

如果后续继续扩展，本界面还可以继续加入：
- 飞船蓝图保存
- 套装提示
- 火力覆盖热力图
- 防御覆盖热力图
- 自动最佳安装推荐
- 局外高级编辑模式

这将使《太空3D积木飞船幸存者》的“积木搭建”真正成为区别于普通幸存者游戏的核心竞争力。
