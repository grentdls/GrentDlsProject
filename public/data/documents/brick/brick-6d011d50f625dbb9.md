# 09 UI 信息字段、颜色、标签、图标、品质表现规范

## 1. 文档目标

本文档用于统一 UI 中的字段命名、颜色含义、标签样式、图标规则、品质表现。后续策划、程序、美术、UI 制作统一按本文档沟通。

如果每个界面都自己定义“红色代表什么”“蓝色代表什么”“标签怎么写”，玩家会越来越难理解。

---

## 2. 字段命名规则

### 2.1 字段必须短、准、统一

推荐：

```text
攻击力
生命值
防御力
攻击间隔
暴击率
暴击伤害
移动速度
技能冷却
能量消耗
击中概率
击杀触发
```

不推荐：

```text
造成伤害的能力
每次攻击之间的等待时间
角色可以承受的总伤害
```

长解释应该放在 Tooltip，不放字段名。

### 2.2 字段显示优先级

| 优先级 | 字段类型 | 示例 |
|---|---|---|
| P0 | 核心战斗字段 | 攻击力、生命值、防御力、攻击间隔 |
| P1 | 流派关键字段 | 闪电伤害、弹射次数、召唤数量 |
| P2 | 成长字段 | 等级、经验、升星、强化等级 |
| P3 | 限制字段 | 职业限制、槽位限制、等级限制 |
| P4 | 来源字段 | 掉落来源、商店来源、图鉴来源 |

详情面板默认显示 P0/P1，P2/P3/P4 根据界面需要显示。

## 3. 数值显示规则

### 3.1 正负号规则

| 类型 | 显示 |
|---|---|
| 增加攻击 | `+12 攻击力` |
| 减少冷却 | `-1.5s 冷却`，这是正向，颜色用正向色 |
| 增加受到伤害 | `+10% 受到伤害`，这是负向，颜色用负向色 |
| 减少攻击间隔 | `-0.15s 攻击间隔`，这是正向，颜色用正向色 |

颜色不能只看正负号，要看对玩家是否有利。

### 3.2 对比显示规则

升级、替换、改造时必须显示变化。

```text
攻击力      12 → 18
冷却        8s → 6s
暴击率      5% → 8%
```

颜色：

- 提升：目标值高亮。
- 降低：目标值警告。
- 不变：弱化。

### 3.3 单位规则

| 字段 | 单位 |
|---|---|
| 攻击力 | 纯数字 |
| 生命值 | 纯数字 |
| 暴击率 | % |
| 冷却 | 秒 / s |
| 攻击间隔 | 秒 / s |
| 移动速度 | % 或 m/s，项目内统一一种 |
| 范围 | 米 / 格 / 像素单位，项目内统一 |
| 持续时间 | 秒 / s |

同一个项目内不要一会写“秒”，一会写“s”。

## 4. 颜色含义规范

### 4.1 基础颜色语义

| 语义 | 用途 |
|---|---|
| Text_Normal | 普通正文 |
| Text_Weak | 次要说明 |
| Text_Title | 标题 |
| Text_Positive | 有利变化 |
| Text_Negative | 不利变化 |
| Text_Warning | 警告、资源不足 |
| Text_Disabled | 不可用 |
| Text_Highlight | 当前重点 |

### 4.2 玩法字段颜色

| 字段 | 用途 | 建议表现 |
|---|---|---|
| 物理 | 普通攻击、撞击 | 中性暖色/白色 |
| 火焰 | 灼烧、爆炸 | 红橙 |
| 冰霜 | 减速、冻结 | 冰蓝 |
| 闪电 | 连锁、电击 | 蓝紫/亮青 |
| 毒素 | 中毒、持续伤害 | 绿色 |
| 护盾 | 防御、减伤 | 蓝色/银色 |
| 治疗 | 回血、恢复 | 绿色/青绿 |
| 暴击 | 爆发、倍率 | 金色/橙色 |
| 召唤 | 召唤物、随从 | 紫色/青色 |
| 异常 | 混乱、诅咒、虚空 | 紫黑 |

注意：颜色需要和项目整体风格适配，不是必须使用固定色值。但语义必须稳定。

## 5. 品质表现规范

### 5.1 品质等级

推荐品质：

```text
普通 Common
优秀 Uncommon
稀有 Rare
史诗 Epic
传说 Legendary
神话 Mythic，可选
```

### 5.2 品质表现组成

品质不能只靠文字颜色，应该组合表现：

```text
QualityVisual
├── 品质边框 QualityFrame
├── 品质底纹 QualityBg
├── 品质文字 QualityText
├── 品质光效 QualityGlow，可选
└── 品质粒子 QualityParticle，稀有以上可选
```

### 5.3 品质使用场景

| UI 元素 | 品质表现 |
|---|---|
| 物品格 | 边框 + 角标 |
| 详情面板 Header | 边框 + 标签 + 名字颜色 |
| 奖励弹窗 | 大光效 + 背景装饰 |
| 商店商品 | 边框 + 价格区域弱强调 |
| 图鉴条目 | 边框 + 稀有度标签 |

### 5.4 禁止事项

- 不要让传说品质全屏乱闪，影响文字阅读。
- 不要只用颜色区分品质，色弱玩家可能看不清。
- 不要同一品质在不同界面颜色不同。

## 6. 标签 Tag 规范

### 6.1 标签类型

| 标签类型 | 例子 | 用途 |
|---|---|---|
| 品质标签 | 传说、稀有 | 表示稀有度 |
| 类型标签 | 武器、部件、消耗品 | 表示对象类别 |
| 流派标签 | 闪电、弹射、护盾 | 表示玩法构筑方向 |
| 状态标签 | 已装备、锁定、已拥有 | 表示当前状态 |
| 条件标签 | Lv.5、职业限定 | 表示限制条件 |

### 6.2 标签结构

```text
TagChip
├── Bg_9Slice
├── Icon_Tag 可选
└── Txt_TagName
```

### 6.3 标签尺寸

| 标签类型 | 高度 | 字号 |
|---|---:|---:|
| 小标签 | 24-28 | 14-18 |
| 普通标签 | 30-36 | 18-22 |
| 大标签 | 40-48 | 22-28 |

### 6.4 标签排列

```text
TagRow
├── HorizontalLayoutGroup
├── ContentSizeFitter
└── TagChip[]
```

如果需要自动换行，使用自定义 `FlowLayoutGroup`。

规则：

- Header 标签最多 2 行。
- Card 内标签最多 1 行。
- 完整标签列表放详情 Body。

## 7. 图标规范

### 7.1 图标分类

| 图标类型 | 用途 | 推荐尺寸 |
|---|---|---:|
| 主对象图标 | 物品、技能、角色 | 80-160 |
| 字段图标 | 攻击、生命、冷却 | 24-36 |
| 货币图标 | 金币、钻石、材料 | 24-40 |
| 状态图标 | Buff、Debuff | 32-48 |
| 按钮图标 | 设置、关闭、返回 | 32-64 |
| 角标图标 | 锁定、新、已装备 | 20-32 |

### 7.2 图标清晰度规则

- 小图标必须轮廓清晰，不能有太多碎细节。
- 字段图标只表达一个概念。
- 不同字段图标轮廓要明显不同。
- 图标颜色不能和背景融在一起。

### 7.3 图标和文字组合

推荐：

```text
[攻击图标] 攻击力 +12
[金币图标] 1200
```

不推荐：

```text
攻击力 [攻击图标] +12
1200 [金币图标]
```

除非项目有明确从右到左阅读需求。

## 8. 状态表现规范

### 8.1 可点击状态

```text
ButtonState
├── Normal
├── Hover / Focus
├── Pressed
├── Selected
├── Disabled
└── Loading 可选
```

表现规则：

- Hover：轻微变亮或描边。
- Pressed：轻微缩小或下压。
- Selected：持续描边/高亮。
- Disabled：置灰、降低透明、禁止点击。
- Loading：显示转圈或进度。

### 8.2 物品格状态

```text
ItemSlotState
├── Empty
├── Normal
├── Hover
├── Selected
├── Equipped
├── Locked
├── New
├── CanUpgrade
└── Disabled
```

不要用同一种角标表示多个状态。

例如：

- `New` 用红点。
- `Equipped` 用绿色/蓝色小标。
- `Locked` 用锁图标。
- `CanUpgrade` 用上箭头。

## 9. 字段颜色和标签颜色的关系

字段颜色用于正文中的关键词，标签颜色用于块状识别。

示例：

```text
标签：[闪电]
正文：造成 120% 攻击力的 闪电伤害。
```

这里 `[闪电]` 的标签背景和正文中的“闪电伤害”可以使用同一语义色，但亮度不同。

规则：

- 标签背景颜色更深，文字更亮。
- 正文关键词颜色更亮，但不要加太多描边。
- 同一字段在不同界面保持一致。

## 10. 配置表建议

建议建立 UI 字段配置表。

### 10.1 FieldConfig

| 字段 | 类型 | 说明 |
|---|---|---|
| FieldId | string | 字段 ID，例如 Attack |
| DisplayName | string | 显示名，例如 攻击力 |
| Icon | Sprite | 字段图标 |
| ColorKey | string | 颜色键 |
| Unit | string | 单位 |
| IsPositiveHigher | bool | 数值越高是否越好 |
| Tooltip | string | 字段解释 |

### 10.2 KeywordConfig

| 字段 | 类型 | 说明 |
|---|---|---|
| KeywordId | string | 词条 ID，例如 Lightning |
| DisplayName | string | 显示名，例如 闪电 |
| Icon | Sprite | 词条图标 |
| ColorKey | string | 颜色键 |
| ShortDesc | string | 简短解释 |
| FullDesc | string | 完整解释 |

### 10.3 QualityConfig

| 字段 | 类型 | 说明 |
|---|---|---|
| QualityId | string | 品质 ID |
| DisplayName | string | 显示名 |
| ColorKey | string | 主颜色 |
| FrameSprite | Sprite | 品质边框 |
| BgSprite | Sprite | 品质底纹 |
| GlowPrefab | Prefab | 品质光效，可选 |

## 11. 美观与信息统一检查清单

- [ ] 同一字段在所有界面是否叫同一个名字？
- [ ] 同一品质是否颜色一致？
- [ ] 同一词条是否图标一致？
- [ ] 正向/负向变化是否按“对玩家是否有利”判断？
- [ ] 标签数量是否受控？
- [ ] 小图标是否清晰？
- [ ] 物品格状态是否不会混淆？
- [ ] 不可点击状态是否足够明显？
- [ ] 颜色是否没有承担多个互相冲突的含义？
- [ ] 是否为色弱玩家提供了形状/文字辅助？
