# 太空3D积木飞船幸存者：战斗事件玩法与HUD提示完整方案

版本：V0.1  
定位：在原有“自动刷怪 + 击杀拾取碎块 + 升级三选一BD + 积木飞船成长”的核心框架上，增加局内随机战斗任务、场地事件、目标保护、占领、防守、追逐、风险收益选择，让单局过程不再只是重复清怪。

---

## 1. 设计目标

### 1.1 当前问题

原有战斗循环偏单一：

```text
怪物刷新 → 玩家自动攻击 → 击杀掉碎块 → 拾取升级 → 继续刷怪
```

这个循环虽然具备幸存者玩法基础，但中后期容易出现以下问题：

1. 玩家只需要绕圈、躲怪、吃经验，目标感不足。
2. 地图随机生成的破败小星球、残骸、小行星带没有足够玩法意义。
3. 飞船搭建流派虽然有深度，但战斗过程缺少阶段性变化。
4. 玩家升级之外缺少短期目标，局内节奏容易平。
5. 稀有BD只靠升级随机出，缺少主动争取稀有奖励的机会。

### 1.2 新增事件玩法目标

新增局内随机任务后，需要达到以下效果：

1. **让地图变得有用**：破败小星球、空间站、矿区、虫巢、残骸带都能生成不同玩法。
2. **让玩家主动改变路线**：不是一直朝一个方向飞，而是被事件目标吸引。
3. **增加风险收益选择**：高奖励任务通常伴随更高怪物压力。
4. **让不同飞船流派有不同优势**：重甲适合防守，机动流适合追逐，火力流适合清剿。
5. **让HUD承担明确引导功能**：玩家要一眼知道任务在哪、做什么、剩多久、奖励是什么。
6. **让战斗节奏有波峰波谷**：普通刷怪、事件任务、精英干扰、奖励爆发交替出现。

---

## 2. 局内战斗事件系统总览

### 2.1 事件类型分类

局内事件分为 8 大类：

| 类型 | 核心玩法 | 主要奖励 | 风险点 |
|---|---|---|---|
| 占领任务 | 进入区域并坚持一定时间 | 大量积木经验 | 被怪物逼出区域会中断 |
| 保护目标 | 保护目标存活到倒计时结束 | 稀有BD / 稀有部件 | 目标被敌人集火 |
| 护送任务 | 跟随目标移动到指定区域 | 部件奖励 / 高级碎块 | 玩家需要边走边防御 |
| 清剿巢穴 | 摧毁持续刷怪的巢穴 | 大量掉落 / BD刷新次数 | 敌人密度高 |
| 采矿钻探 | 在矿点附近防守钻机 | 大量碎块 / 修复资源 | 钻机被打爆会失败 |
| 追击补给舰 | 追上并击毁高速目标 | 稀有攻击部件 | 需要高机动和爆发 |
| 关闭裂隙 | 破坏多个裂隙节点 | 降低怪潮压力 / 特殊BD | 地图多点跑动 |
| 临时挑战 | 限时完成特殊目标 | 强力临时Buff / 星尘 | 条件苛刻 |

## 3. 事件刷新导演系统

### 3.1 事件刷新频率

事件不应过于频繁，否则会打断幸存者核心节奏。

推荐规则：

| 单局时间 | 事件刷新建议 |
|---|---|
| 0:00 - 2:00 | 不刷新事件，专注基础成长 |
| 2:00 - 5:00 | 刷新 1 个简单事件 |
| 5:00 - 10:00 | 每 2-3 分钟刷新 1 个事件 |
| 10:00 - 15:00 | 每 2 分钟刷新 1 个事件，可能叠加精英干扰 |
| 15:00 后 | 高价值事件与高风险事件为主 |

### 3.2 同屏事件数量限制

为避免玩家迷路和压力过大：

```text
普通难度：同一时间最多存在 1 个事件
高难度：同一时间最多存在 2 个事件
无尽模式：最多存在 3 个事件，但HUD要清楚分层
```

### 3.3 事件生成位置

事件生成点必须遵守：

1. 不生成在玩家正前方极近距离，避免突然撞上。
2. 不生成在地图边界外。
3. 不生成在过密小行星内部。
4. 需要保证玩家在合理时间内能到达。
5. 高价值事件可以生成得更远，用距离制造取舍。

推荐距离：

| 事件价值 | 生成距离 |
|---|---|
| 普通事件 | 玩家前方 80m - 150m |
| 稀有事件 | 玩家侧前方 120m - 220m |
| 高危事件 | 玩家远处 180m - 300m |
| Boss前事件 | 地图中心附近或大型地标附近 |

## 4. 事件通用流程

所有事件使用统一状态机，便于程序和UI制作。

```text
预告状态
→ 出现状态
→ 引导状态
→ 激活状态
→ 进行中状态
→ 成功 / 失败状态
→ 奖励结算状态
→ 清理状态
```

### 4.1 预告状态

事件即将出现时，屏幕边缘出现提示。

表现：

```text
侦测到异常信号
前方出现可占领区域
破败空间站请求支援
发现高速补给舰
```

HUD表现：

1. 屏幕上方出现短提示条。
2. 小地图上出现事件图标。
3. 事件方向出现箭头。
4. 远处空间中出现光柱或信标。

### 4.2 出现状态

事件正式生成。

表现：

1. 场地中出现任务目标。
2. 目标上方显示 3D 图标。
3. HUD左侧加入事件任务条。
4. 播放任务出现音效。

### 4.3 引导状态

玩家还没有进入事件范围。

HUD显示：

```text
占领信标：距离 132m
奖励：大量积木经验
危险：敌人会被吸引
```

如果玩家远离事件，任务条逐渐半透明，但不会立刻消失。

### 4.4 激活状态

玩家进入事件范围，事件正式开始。

表现：

1. 屏幕中央出现任务标题。
2. 音效明显变化。
3. 场地内范围圈亮起。
4. 任务倒计时或进度条开始。
5. 敌人刷新逻辑切换为事件专属模式。

### 4.5 进行中状态

事件根据玩法类型持续进行。

HUD必须显示：

1. 当前目标。
2. 剩余时间。
3. 进度条。
4. 目标生命值。
5. 奖励预览。
6. 是否处于有效范围内。

### 4.6 成功状态

事件完成后：

1. 播放成功音效。
2. 目标发光或爆开奖励。
3. 屏幕出现“任务完成”。
4. 奖励直接掉落或弹出奖励选择。
5. 小地图图标移除。

### 4.7 失败状态

事件失败后：

1. 播放失败音效。
2. 目标爆炸或裂隙扩大。
3. 屏幕出现“任务失败”。
4. 可根据事件类型触发惩罚。
5. 事件清理。

失败惩罚不宜过重，避免玩家放弃事件后体验太差。建议大多数事件失败只是失去奖励，少数高危事件才触发负面效果。

## 5. 玩法一：占领任务

## 5.1 玩法定位

占领任务是最基础、最直观的局内事件。

玩家需要进入一个指定空间区域，并在区域内累计占领进度。占领成功后获得大量积木经验或直接升级。

适合解决的问题：

1. 让玩家有理由停留在危险区域。
2. 逼迫玩家从单纯逃跑变成阵地防守。
3. 让防御部件、范围武器、自动索敌武器更有价值。

---

## 5.2 场地表现

占领区域是一个立体球形或圆柱形空间圈。

推荐表现：

```text
中心是一个漂浮信标
外围是半透明蓝色能量圈
地面/空间中有环形扫描线
区域边缘有向内流动的粒子
```

如果在太空中没有地面，可以用：

1. 半透明球形范围。
2. 环形光圈。
3. 中心信标。
4. 四周漂浮小型定位器。

---

## 5.3 占领逻辑

### 进入区域

玩家核心进入占领区域后，开始占领。

```text
玩家核心在区域内 → 占领进度增加
玩家核心离开区域 → 占领进度停止或缓慢下降
敌人进入区域 → 占领速度降低
精英敌人进入区域 → 占领暂停
```

### 推荐数值

| 项目 | 数值 |
|---|---:|
| 基础占领时间 | 25 秒 |
| 简单事件占领时间 | 15 秒 |
| 高级事件占领时间 | 35 秒 |
| 离开后进度衰减 | 每秒 -3% |
| 敌人在圈内时 | 占领速度 -50% |
| 精英在圈内时 | 占领暂停 |

---

## 5.4 占领事件变体

### 5.4.1 普通信标占领

目标：在圈内坚持 20 秒。

奖励：大量普通碎块。

适合前期出现。

### 5.4.2 双点占领

目标：先后占领 A 点和 B 点。

奖励：积木经验 + 额外BD刷新次数。

逻辑：

```text
占领A点成功
→ B点亮起
→ 玩家需要在60秒内到达B点
→ 占领B点成功后获得奖励
```

### 5.4.3 高危占领

目标：在敌潮围攻中占领信标。

奖励：稀有BD三选一。

特殊规则：

1. 占领期间敌人刷新速度 +50%。
2. 每 10 秒刷出一只重型冲撞舰。
3. 如果离开区域超过 8 秒，任务失败。

### 5.4.4 移动占领圈

目标：跟随缓慢移动的占领圈。

奖励：移动类辅助部件或推进BD。

玩法价值：

1. 让玩家边移动边战斗。
2. 适合考验飞船操控。
3. 大飞船会更难完成。

---

## 5.5 占领任务HUD表现

### 任务条

屏幕左侧显示：

```text
【占领信标】
占领进度：67%
剩余时间：无限 / 00:18
奖励：大量积木经验
状态：占领中
```

### 场内提示

1. 玩家在圈内：范围圈变蓝，进度条上升。
2. 玩家离开圈：范围圈变灰，提示“返回占领区”。
3. 敌人进入圈：范围圈边缘变红，提示“清除区域内敌人”。
4. 精英进入圈：进度条锁住，显示“精英干扰中”。

### 屏幕中央提示

| 状态 | 提示文字 |
|---|---|
| 接近事件 | 发现占领信标 |
| 进入区域 | 开始占领 |
| 离开区域 | 离开占领区域，进度正在衰减 |
| 敌人干扰 | 敌人正在干扰占领 |
| 成功 | 占领完成，获得大量积木经验 |
| 失败 | 占领失败 |

---

## 6. 玩法二：保护目标任务

## 6.1 玩法定位

保护任务要求玩家在限定时间内保护一个目标不被敌人摧毁。

成功后给予高价值奖励，例如：

1. 稀有BD。
2. 稀有辅助部件。
3. 免费修复飞船。
4. 部件进化机会。

这个玩法适合让玩家从“只保自己”变成“保护场景目标”。

---

## 6.2 保护目标类型

| 目标 | 表现 | 奖励倾向 |
|---|---|---|
| 维修无人机 | 小型蓝色无人机 | 修复、护盾、防御BD |
| 破败空间站核心 | 固定大型目标 | 稀有BD、部件奖励 |
| 逃生舱 | 小型脆弱目标 | 星尘、局外资源 |
| 矿业钻机 | 固定设备 | 大量碎块 |
| 古代数据库 | 发光遗迹装置 | 规则改变类BD |
| 友军运输舰 | 缓慢移动目标 | 稀有部件、商店折扣 |

---

## 6.3 基础逻辑

保护任务生成后，目标会出现在地图中。

玩家靠近后任务开始。

```text
任务开始
→ 目标出现生命条
→ 敌人优先攻击目标
→ 玩家需要清理敌人
→ 倒计时结束且目标存活
→ 任务成功
```

### 目标受击规则

敌人会根据自身类型选择目标：

| 敌人类型 | 行为 |
|---|---|
| 小型追撞机 | 优先撞保护目标 |
| 蜂群无人机 | 分散攻击玩家和目标 |
| 重型冲撞舰 | 从远处冲击目标 |
| 炮击无人艇 | 远程射击目标 |
| 自爆水雷 | 接近目标后爆炸 |

---

## 6.4 推荐数值

| 项目 | 普通保护 | 稀有保护 | 高危保护 |
|---|---:|---:|---:|
| 保护时间 | 30秒 | 45秒 | 60秒 |
| 目标生命 | 300 | 500 | 800 |
| 敌人刷新倍率 | 1.2 | 1.5 | 2.0 |
| 精英刷新 | 无 | 1只 | 2-3只 |
| 奖励 | 经验 | 稀有BD | 史诗BD / 稀有部件 |

---

## 6.5 保护任务变体

### 6.5.1 保护维修无人机

表现：

```text
一台蓝色维修无人机正在尝试修复破败信标。
敌人会从四周出现并攻击它。
```

成功奖励：

1. 飞船所有部件恢复 20% 生命。
2. 额外弹出一个防御类BD三选一。

### 6.5.2 保护数据库上传

表现：

```text
古代数据库正在上传资料。
上传期间敌人会试图摧毁数据库核心。
```

成功奖励：

1. 规则改变类BD三选一。
2. 例如“子弹穿透+1”“辅助范围+1”“装甲破裂爆炸”。

### 6.5.3 保护友军运输舰

表现：

```text
一艘小型友军运输舰跃迁失败，需要玩家掩护它重新启动引擎。
```

成功奖励：

1. 稀有部件背包补给。
2. 可在 3 个部件中选择 1 个直接加入积木背包。

### 6.5.4 保护矿业钻机

表现：

```text
钻机正在开采太空矿脉。
开采完成后喷出大量积木碎块。
```

成功奖励：

1. 大量普通碎块。
2. 一定概率掉落稀有碎块。

---

## 6.6 保护任务HUD表现

### 左侧任务卡

```text
【保护目标】维修无人机
目标生命：72%
剩余时间：00:28
奖励：稀有防御BD
状态：敌人接近中
```

### 目标头顶UI

保护目标上方显示：

1. 目标名称。
2. 生命条。
3. 剩余保护时间。
4. 被攻击时闪红。
5. 低血量时显示感叹号。

### 屏幕边缘提示

如果保护目标不在屏幕内：

```text
目标方向箭头 + 距离
目标受击时箭头变红并震动
```

### 危险提示

| 状态 | 提示 |
|---|---|
| 目标血量低于 50% | 目标受损严重 |
| 目标血量低于 25% | 目标即将被摧毁 |
| 自爆敌人接近 | 自爆单位正在接近目标 |
| 精英锁定目标 | 精英敌人正在攻击目标 |

## 7. 玩法三：护送任务

## 7.1 玩法定位

护送任务让玩家跟随一个移动目标，从起点护送到终点。

它可以让玩家不再固定在一个区域，而是在太空中边移动边战斗。

---

## 7.2 基础逻辑

```text
玩家靠近护送目标
→ 护送目标启动
→ 目标沿路线移动
→ 敌人从路线两侧刷新
→ 玩家需要保护目标并跟上路线
→ 到达终点后成功
```

### 护送目标移动规则

1. 玩家距离目标太远时，目标减速或停止。
2. 玩家在目标附近时，目标正常移动。
3. 目标受到攻击时短暂停顿。
4. 目标血量过低时会进入求救状态。

---

## 7.3 护送任务变体

### 7.3.1 护送逃生舱

目标：将逃生舱护送到跃迁点。

奖励：局外星尘 + 稀有碎块。

### 7.3.2 护送运输舰

目标：保护运输舰穿越小行星带。

奖励：从 3 个部件中选择 1 个。

### 7.3.3 护送能量核心

目标：护送不稳定能量核心到封印装置。

特殊规则：

1. 能量核心会周期性释放脉冲，击退敌人。
2. 但如果被摧毁，会产生大爆炸。
3. 爆炸会伤害玩家飞船和敌人。

奖励：强力辅助BD。

---

## 7.4 护送HUD表现

```text
【护送任务】运输舰
目标生命：65%
路线进度：42%
玩家距离：18m
奖励：稀有部件
```

场内表现：

1. 路线用虚线光带显示。
2. 终点有大型跃迁门或光柱。
3. 护送目标周围有护航范围圈。
4. 玩家离太远时，屏幕提示“返回护送范围”。

---

## 8. 玩法四：清剿巢穴任务

## 8.1 玩法定位

清剿巢穴是高压进攻型任务。

地图上生成一个持续刷怪的巢穴或敌方母舰残骸。玩家需要在怪潮中摧毁它。

适合火力流、爆发流、穿透流玩家。

---

## 8.2 基础逻辑

```text
巢穴出现
→ 持续刷新敌人
→ 玩家靠近后巢穴激活
→ 巢穴拥有护盾和生命
→ 玩家摧毁护盾后攻击本体
→ 摧毁成功后掉落大量奖励
```

### 巢穴阶段

| 阶段 | 逻辑 |
|---|---|
| 未激活 | 只在地图中显示，不大量刷怪 |
| 激活 | 玩家靠近后开始刷怪 |
| 护盾阶段 | 巢穴减伤，需要清理周围护盾节点 |
| 暴露阶段 | 本体可被直接攻击 |
| 崩溃阶段 | 死亡前爆发最后一波敌人 |

---

## 8.3 巢穴类型

| 类型 | 特点 | 奖励 |

## 9. 玩法五：采矿钻探任务

## 9.1 玩法定位

采矿钻探任务是一种资源型事件。

玩家启动矿点附近的钻机，钻机在一定时间内持续产出碎块，但敌人会不断攻击钻机。

玩法重点是：

```text
玩家是否愿意为了大量经验承担防守压力
```

---

## 9.2 基础流程

```text
发现太空矿脉
→ 玩家靠近启动钻机
→ 钻机开始工作
→ 每隔数秒喷出碎块
→ 敌人被噪音吸引
→ 钻探完成后喷出大量奖励
```

---

## 9.3 钻机产出规则

| 钻探阶段 | 产出 |
|---|---|
| 25% | 少量普通碎块 |
| 50% | 中量普通碎块 + 修复碎块 |
| 75% | 大量普通碎块 + 稀有碎块概率 |
| 100% | 大爆发奖励，有概率部件残片 |

如果钻机中途被摧毁：

1. 已经喷出的碎块保留。
2. 最终奖励消失。
3. 钻机爆炸，击退周围单位。

---

## 9.4 钻探HUD表现

```text
【采矿钻探】富矿点
钻机生命：58%
钻探进度：73%
下一次喷发：00:04
最终奖励：大量积木碎块
```

场内表现：

1. 矿脉发光。
2. 钻机发出光束打入矿脉。
3. 进度越高，矿脉裂缝越亮。
4. 每次喷发时碎块向四周弹出。
5. 100% 完成时产生大型碎块喷泉。

## 10. 玩法六：追击补给舰

## 10.1 玩法定位

追击补给舰是机动型事件。

一艘携带稀有部件的高速补给舰出现在地图中，玩家需要在限定时间内追上并击毁。

适合让高速小船、远程武器、导弹流有发挥空间。

---

## 10.2 基础逻辑

```text
补给舰出现
→ 向远处逃离
→ 玩家需要追击

→ 超时后补给舰跃迁逃走
```

## 10.3 补给舰行为

| 行为 | 说明 |
|---|---|

| 侧向闪避 | 被攻击时短暂偏移 |
| 释放诱饵 | 生成小型假目标吸引导弹 |
| 释放地雷 | 在身后留下自爆水雷 |
| 短距离跃迁 | 血量低时瞬移一小段距离 |

---

## 10.4 追击HUD表现

```text

逃离倒计时：00:22
距离：96m
奖励：稀有攻击部件
```

场内表现：

2. 屏幕边缘始终显示方向箭头。
3. 超出射程时提示“距离过远”。
4. 即将逃走时出现倒计时警报。
5. 成功击毁时掉落一个大型奖励箱。

## 11. 玩法七：关闭空间裂隙

## 11.1 玩法定位

裂隙是地图危机型事件。

如果玩家不处理，裂隙会持续增强敌人刷新。如果成功关闭，玩家获得奖励，同时降低一段时间的怪潮压力。

---

## 11.2 基础逻辑

```text
空间裂隙出现
→ 裂隙周期性刷怪
→ 地图上出现多个裂隙节点
→ 玩家需要摧毁所有节点
→ 节点全部摧毁后裂隙关闭
```

---

## 11.3 裂隙危害

| 裂隙等级 | 效果 |
|---|---|
| 1级 | 周期性刷小怪 |
| 2级 | 敌人移动速度 +10% |
| 3级 | 周围出现精英敌人 |
| 4级 | 敌人获得护盾 |
| 5级 | 形成Boss前置事件 |

如果玩家长时间不处理，裂隙会升级。

---

## 11.4 关闭裂隙HUD表现

```text
【空间裂隙】不稳定裂缝
裂隙等级：2
剩余节点：2 / 4
升级倒计时：00:36
奖励：降低敌潮压力 + 特殊BD
```

场内表现：

1. 裂隙是紫色撕裂空间效果。
2. 裂隙节点用紫色连线连接到主裂隙。
3. 节点被摧毁后连线断开。
4. 主裂隙关闭时向内坍缩。
5. 成功后短时间内敌人刷新减少。

## 15. 事件奖励系统

## 15.1 奖励分层

事件奖励分为 5 档。

| 奖励档位 | 奖励内容 | 对应事件 |
|---|---|---|
| 小奖励 | 少量碎块、修复碎块 | 简单占领、普通空投 |
| 中奖励 | 大量经验、普通BD | 采矿、防守 |
| 高奖励 | 稀有BD、稀有部件 | 保护目标、清剿巢穴 |
| 极高奖励 | 史诗BD、规则改变BD | 高危裂隙、高危保护 |

## 15.2 奖励发放方式

奖励不能全都直接加到玩家身上，应根据类型变化。

| 奖励方式 | 适用内容 |
|---|---|
| 直接喷出碎块 | 占领、采矿、清剿 |
| 弹出BD三选一 | 保护、挑战、裂隙 |
| 弹出部件三选一 | 空投、运输舰、补给舰 |
| 直接修复 | 维修无人机、维修站 |
| 掉落奖励箱 | 追击、精英、Boss前事件 |
| 增加BD刷新次数 | 高难挑战 |

## 15.3 奖励预览UI

所有事件在玩家接近前都要显示奖励预览。

示例：

```text
事件：保护古代数据库

危险：敌人会优先攻击目标
```

奖励预览让玩家可以判断是否值得参与。

## 16. 事件与飞船流派的关系

不同事件应让不同流派都有优势，避免只奖励一种玩法。

| 冲撞碾压流 | 连续击杀、清理蜂群 | 近战清场强 |
| 巨舰扩展流 | 长时间防守、Boss前事件 | 后期综合强 |
| 高机动小船 | 追击、裂隙多点关闭 | 跑图能力强 |

## 17. 事件难度调节

### 17.1 难度影响因素

事件难度由以下参数控制：

```text
事件等级
当前局内时间
玩家等级
玩家飞船部件数量
玩家当前生命状态
事件奖励稀有度
地图危险区域
```

### 17.2 动态补偿

为了避免玩家状态差时事件完全做不了，可以加入轻度补偿。

| 玩家状态 | 调整 |
|---|---|
| 核心生命低于 30% | 暂不刷新高危事件 |
| 飞船完整度低于 40% | 保护任务目标生命提高 20% |
| 玩家等级落后时间进度 | 经验类事件权重提高 |
| 玩家火力极高 | 清剿类事件护盾提高 |
| 玩家速度很低 | 追击类事件出现权重降低 |

注意：补偿不能太明显，避免削弱构筑选择的意义。

## 20. 伤害跳字与任务跳字

## 20.1 伤害跳字基础规则

伤害跳字需要服务于战斗爽感和信息识别。

### 跳字类型

| 类型 | 表现 |
|---|---|
| 普通伤害 | 小号白色数字，快速上飘 |
| 暴击伤害 | 大号黄色数字，弹跳放大 |
| 激光伤害 | 连续小数字，沿命中点快速跳出 |
| 导弹爆炸 | 多个数字从爆炸中心散开 |
| 闪电链 | 数字带电弧连线 |
| 冲撞伤害 | 粗体数字，带冲击波 |
| 护盾吸收 | 蓝色“吸收”数字 |
| 防御减伤 | 灰色小数字，显示“减免” |
| 核心受伤 | 红色大数字，屏幕轻震 |

---

## 20.2 事件相关跳字

事件目标也需要跳字，但不能和敌人伤害混乱。

| 场景 | 跳字 |
|---|---|
| 占领进度增加 | `+3% 占领` |
| 占领被干扰 | `占领暂停` |
| 保护目标受伤 | `目标 -24` |
| 钻机产出碎块 | `+经验碎块` |
| 裂隙节点破坏 | `节点破坏 1/4` |
| 空投打开进度 | `解锁 +10%` |
| 护送路线推进 | `护送 +5%` |
| 挑战击杀计数 | `击杀 +1` |

---

## 20.3 跳字层级控制

为了避免后期满屏数字遮挡，需要跳字合并规则。

### 合并规则

1. 同一敌人在 0.2 秒内受到多段小伤害，合并为一个数字。
2. 激光持续伤害每 0.5 秒显示一次总伤害。
3. 蜂群小怪死亡时，可以只显示击杀爆点，不显示全部伤害。
4. 暴击、核心受伤、任务目标受伤永远优先显示。
5. 屏幕内跳字超过上限时，低优先级数字缩小或隐藏。

## 28. 结论

这套事件系统的核心价值是：

```text
把单纯刷怪幸存者，变成有局内目标选择的太空战场。
```

玩家不再只是被动等怪，而是不断做选择：

```text
要不要去占领？
要不要保护目标？
要不要冒险进入风暴区？
要不要追补给舰？
要不要先关裂隙？
要不要放弃事件继续发育？
```

每个事件都应该同时具备三点：

1. **清晰目标**：玩家一眼知道要做什么。
2. **明确风险**：玩家知道失败原因和危险来源。
3. **强奖励吸引**：玩家愿意主动改变飞行路线去参与。

只要事件HUD、场内光柱、任务卡、奖励预览和失败/成功反馈做清楚，战斗节奏会从“重复刷怪”变成“不断出现短期目标的动态战场”。
