# UI Rules

## Prefab 优先

- 可见 UI 的固定结构、锚点、位置、大小、图片、颜色、字体和静态初始文字放在 Prefab 内。
- 代码只写动态文本、数值、显隐、事件和必要动画。
- 模块根默认保留 Prefab 布局和样式。

## 禁止模板文字

Prefab 可见 Text 不得出现：

- `GenericPanel`
- `WorldHudItem`
- `世界HUD`
- `类型：`
- `用途：`
- `Prefab模板`
- `可绑定数据`

说明文字写入文档或 Inspector，不写进运行时 UI。

## HUD 射线

- HUD 总根和透明 Layer 不得拦截战场点击。
- 只有按钮、Toggle、Slider、ScrollRect、打开状态面板、Tooltip 触发区、小地图内容区域等真实交互对象可以接收射线。

## 世界坐标 UI

- 单位/建筑头顶 HUD、伤害跳字、技能喊名冒泡可以由代码驱动屏幕位置和动画。
- 条目的可见结构和基础样式必须 Prefab 化。
