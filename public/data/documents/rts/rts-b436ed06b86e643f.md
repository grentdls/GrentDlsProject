# Building Visual Replacement Guide

## Goal

Use real building art prefabs to replace the generated 25-level placeholder visuals without editing each `BuildingVisualProgression.asset` by hand.

This pipeline keeps gameplay prefabs stable and only swaps the visual child content at runtime.

## Runtime chain

1. `BuildingData.asset`
2. `visualProgression`
3. `BuildingVisualProgressionData.asset`
4. one visual prefab per level
5. `BuildingVisualProgressionController` instantiates that visual under `VisualRoot`

## Generated data locations

- Progression assets:
  `Assets/Resources/Data/BuildingVisualProgression`
- Generated placeholder prefabs:
  `Assets/Generated/BuildingProgressionVisuals`
- Recommended real art replacement root:
  `Assets/Art/Buildings/Progression`

## Real art folder rule

For each building, create one folder with the same generated asset key.

Examples:

- `Assets/Art/Buildings/Progression/egypt_sun_tower_BuildingData`
- `Assets/Art/Buildings/Progression/Greek_民居_BuildingData`
- `Assets/Art/Buildings/Progression/Huaxia_民居_BuildingData`

Inside each folder, place level prefabs named exactly:

- `Lv01_Visual.prefab`
- `Lv02_Visual.prefab`
- ...
- `Lv25_Visual.prefab`

You do not have to provide all 25 levels at once.
Only the levels that exist will be rebound. Missing levels keep using the current placeholder or previously assigned prefab.

## Recommended prefab content

Each level visual prefab should contain:

- mesh renderers only, or visual-only helper children
- no gameplay scripts
- no colliders unless the art team explicitly needs them for visuals
- root transform authored at local zero
- forward facing the same way as the gameplay building root

## Binding workflow

1. Drop real visual prefabs into the replacement folders.
2. In Unity run:
   `Tools/RTS/Generate Real Building Progression Folder Skeleton`
3. If needed, review the scaffolded folders under `Assets/Art/Buildings/Progression`.
4. Then run:
   `Tools/RTS/Bind Real Building Progression Prefabs`
5. The tool scans the replacement folders and writes matching prefabs into the corresponding `BuildingVisualProgression.asset`.
6. Enter play mode or open the scene and verify building levels swap visuals correctly.

## Missing prefab report

You can generate a gap report at any time:

- `Tools/RTS/Report Missing Building Progression Prefabs`

This writes:

- `Docs/BuildingVisualReplacementMissingReport.md`

The report lists each building that is still missing one or more `LvXX_Visual.prefab` files.

## Real art coverage report

You can also generate a real-art adoption report:

- `Tools/RTS/Report Real Building Art Coverage`
- `Tools/RTS/Building Visual Coverage Dashboard`

This writes:

- `Docs/BuildingVisualReplacementCoverageReport.md`

The report separates every level into three states:

- `RealArtLevels`
  real prefabs already replaced by art and no longer carrying the generated template marker
- `TemplateLevels`
  still using generated starter prefabs and should be replaced later
- `MissingLevels`
  no prefab exists for that level in the replacement folder

Imported replacement prefabs are also inspected automatically.
If a prefab under `Assets/Art/Buildings/Progression` still has a generated template marker but now contains external mesh/material/prefab references, the importer treats it as replaced art and removes the marker automatically.

Recommended use:

1. art replaces some `LvXX_Visual.prefab` files with final prefabs
2. if those prefabs were copied from generated templates, run:
   `Tools/RTS/Mark Selected Replacement Prefabs As Real Art`
3. run `Tools/RTS/Bind Real Building Progression Prefabs`
4. run `Tools/RTS/Report Real Building Art Coverage`
   or inspect the live dashboard
5. review overall replacement percentage and per-building level coverage

## Marking real art replacements

Generated replacement prefabs carry a `GeneratedBuildingVisualTemplateMarker`.
That marker is what makes the coverage report classify a level as template art.

After art replaces a prefab with a final version, remove the marker by using:

- `Tools/RTS/Mark Selected Replacement Prefabs As Real Art`

This command works with:

- selected replacement prefabs
- selected replacement folders under `Assets/Art/Buildings/Progression`

In the dashboard each building row also provides:

- `Select Folder`
- `Mark Folder Real`
- per-era mini progress bars
- grouped summaries by faction, era, or building type
- grouped CSV export

Use `Mark Folder Real` only after the building's visible prefabs have really been replaced by final art.

## One-click full refresh workflow

If you changed generation rules and want to rebuild placeholders plus progression assets:

1. Run:
   `Tools/RTS/Generate Building Era Pipeline`
2. Then run:
   `Tools/RTS/Generate Real Building Progression Folder Skeleton`
3. Then run:
   `Tools/RTS/Bind Real Building Progression Prefabs`
4. Optionally run:
   `Tools/RTS/Report Missing Building Progression Prefabs`

The first step maintains the structure.
The second step ensures every building has a valid replacement folder.
The third step reapplies your real art replacements.
The final step tells you what is still missing.
You can then run the real-art coverage report to see how much of the library is still template-based.

## Duplicate building names

If two factions share the same file name, the generator automatically prefixes the parent folder name.

Example:

- `Greek_民居_BuildingData`
- `Huaxia_民居_BuildingData`

Use those exact folder names in `Assets/Art/Buildings/Progression`.

## Suggested artist handoff checklist

- confirm building key folder name
- provide `Lv01` to `Lv25` prefabs using the required naming
- keep prefab root clean and centered
- avoid gameplay scripts
- verify silhouette growth across 5 eras
- keep footprint visually compatible with the gameplay building size
