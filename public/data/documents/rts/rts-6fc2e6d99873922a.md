# 建造页面UI预制体分类栏补充说明

## 2026-05-19

### 本轮目标
- 继续收口“单位选中后的建造页”分类栏。
- 让分类页签的选中态和空分类态优先落到 prefab 固定节点，而不是继续只靠运行时代码硬写背景色和字体样式。

### 适用范围
- `SelectionPanel` 中的 `PcBuildCategory_*`
- `ProductionCategoryTab_Prefab`
- HUD 内嵌建造页 `SelectionBuildingProductionPage_Prefab/BuildCategoryTabsContent`

### 固定节点
- `ProductionCategoryTab_Prefab` 现在固定包含：
  - `Label`
  - `Image_SelectedLine`
  - `Image_NewDot`

### 运行时职责边界
- `SelectionPanel` 运行时只负责：
  - 写入分类文案
  - 切换当前选中分类
  - 根据当前 builder 的可建列表决定分类是否可交互
  - 控制 `Image_SelectedLine` 的显隐
  - 预留 `Image_NewDot` 的显隐入口
- 如果分类页签或其父层级挂有 `UiPrefabSlot`：
  - 代码不再强制覆盖背景色
  - 代码不再强制覆盖文字颜色
  - 代码不再强制覆盖字重
  - 代码不再强制覆盖选中线颜色

### 空分类规则
- 某个分类当前没有任何可显示建筑时：
  - 按钮允许被置为 `interactable = false`
  - 灰态背景、文字和其它静态视觉优先由 prefab 自己表现
- 当当前选中的分类在新目标上已无内容时：
  - 运行时自动回退到 `All`
  - 避免出现“分类栏高亮停在空分类，但列表为空”的错位状态

### 建造卡状态层补充
- `BuildButton_Prefab` 的 `State_Overlay`、`Image_DarkMask`、`Image_LockIcon`、`Image_WarningIcon`、`Text_StateReason`、`Image_SelectedBorder`、`Image_RecommendGlow` 继续视为固定 prefab 节点。
- 若建造卡挂有 `UiPrefabSlot`，`SelectionPanel.ConfigurePcCatalogStateVisual(...)` 只做：
  - 显隐切换
  - 原因文本写入
  - 推荐/选中状态切换
- 上述节点的静态色值、描边、底图透明度优先在 prefab 中调，不再默认由代码覆盖。

### 验证建议
- 在 Unity 中检查 `ProductionCategoryTab_Prefab`：
  - `Image_SelectedLine` 是否位于页签底部
  - `Image_NewDot` 是否位于右上角
- 运行时检查：
  - 切换不同 builder 时，空分类是否自动禁用
  - 当前分类失效时是否自动回退 `All`
  - prefab 已保留样式时，代码是否不再刷回旧配色
