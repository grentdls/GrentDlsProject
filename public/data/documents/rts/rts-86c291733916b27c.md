# 华夏阵营：建筑、单位、科技树完整方案

版本目标：统一整理华夏阵营当前确定的规则，包括资源体系、建筑建造关系、生产建筑与单位关系、单位克制、科技树、UI显示与程序实现要点。

---

## 1. 阵营核心定位

华夏阵营定位为：

```text
正规军制 + 主城等级推进 + 单一兵种生产线 + 科技解锁高级兵 + 士兵战斗升星
```

华夏阵营和其他阵营的区别：

| 阵营 | 建筑成长 | 单位成长 | 核心体验 |
|---|---|---|---|
| 华夏 | 主城等级驱动建筑升级 | 士兵/英雄升星 | 正规军制、稳步推进、兵种克制 |
| 妖族 | 建筑献祭进入圣祭形态 | 单位吞噬强化 | 牺牲、吞噬、血肉成长 |
| 机械 | 建筑/单位部件改造 | 单位部件改造 | 模块化、科技改装、电力体系 |
| 自然 | 建筑相邻五行共鸣 | 单位融合 | 建筑摆阵、五行融合、生态防御 |

华夏阵营设计重点：

```text
1. 建筑功能必须单一。
2. 一个生产建筑只负责一条兵种线。
3. 高级兵种通过科技解锁，但仍在原生产建筑中生产。
4. 科技不是单纯加数值，而是改变单位玩法、强化克制、增加战术选择。
5. 单位必须有明确克制对象和被克制对象。
6. 士兵不升级，只通过战斗经验升星，最高5星。
7. 英雄最高5星，升星解锁或强化技能。
```

## 2. 资源体系

当前华夏阵营只使用 4 种基础资源 + 人口：

```text
木材
黄金
石料
金属
人口
```

删除：

```text
粮食
粮仓
粮食上限
粮食消耗
```

删除原因：

```text
1. 粮食会增加额外资源管理复杂度。
2. 当前玩法中粮食和造兵、科技、建筑关系不强。
3. 补给、治疗、恢复可以交给辎重营和后勤单位。
4. 人口由主城和民房提供即可。
```

### 2.1 资源定位

| 资源 | 核心用途 | 设计定位 |
|---|---|---|
| 木材 | 基础建筑、远程单位、船只、攻城器械、箭塔 | 扩张和基础军备资源 |
| 黄金 | 造兵、科技、英雄、军令、特殊单位 | 通用核心资源 |
| 石料 | 主城升级、防御建筑、城墙、城门、塔、防御科技 | 防御和城市发展资源 |
| 金属 | 高级兵、重甲、弩、骑兵甲胄、飞行武装、攻城器械 | 高级军备资源 |
| 人口 | 限制单位规模 | 由主城和民房提供 |

### 2.2 资源建筑

| 资源 | 建筑 | 功能 |
|---|---|---|

## 3. 主城等级与建筑升级规则

### 3.1 主城等级

华夏主城是建筑体系的核心。

| 主城等级 | 名称 | 建筑等级上限 | 战略阶段 |
|---|---|---:|---|
| Lv.1 | 天阙营城 | 1 | 基础陆战、防御、资源 |
| Lv.2 | 天阙都城 | 2 | 机动、空军、水军、英雄、阵法 |
| Lv.3 | 昊天帝阙 | 3 | 攻城、精锐、终局科技 |

### 3.2 建筑升级规则

```text
1. 华夏建筑最大3级。
2. 其他建筑等级不能超过主城等级。
3. 主城 Lv.1 时，其他建筑最高 Lv.1。
4. 主城 Lv.2 时，其他建筑最高 Lv.2。
5. 主城 Lv.3 时，其他建筑最高 Lv.3。
6. 建筑升级需要消耗资源和时间。
7. 建筑升级必须带来明确功能变化，不能只是数值提升。
```

### 3.3 生产建筑升级效果

| 等级 | 效果 |
|---|---|
| Lv.1 | 基础生产 |
| Lv.2 | 对应兵种训练速度 +15%，队列容量 +1 |
| Lv.3 | 新训练单位初始经验 +20，高级单位训练时间 -10% |

### 3.4 科技建筑升级效果

| 等级 | 效果 |
|---|---|
| Lv.1 | 可研究基础科技 |
| Lv.2 | 解锁中级科技，研究速度 +15% |
| Lv.3 | 解锁高级科技，研究速度 +25% |

## 7. 单位克制关系

### 7.1 核心克制逻辑

```text
军犬 → 克制工程师、轻甲步兵
工程师 → 占领建筑，但自身极脆
枪兵 → 克制骑兵、大型冲锋单位
弓手 → 克制轻甲步兵、军犬、低甲飞行单位
刀盾兵 → 克制弓手、抗远程推进
防空弩兵 → 专门克制飞行单位
神臂弩手 → 克制重甲、英雄、重骑兵
轻骑兵 → 克制远程、后勤、攻城器械
重骑兵 → 克制散兵、弓手、后勤
玄甲重骑 → 克制普通步兵和轻防线，但怕枪兵和破甲
飞羽骑 → 克制地面后排、攻城器械、后勤
破甲鹰弩 → 克制重甲、英雄、楼船
轻舟 → 克制运兵舟和水面骚扰目标
弩舟 → 克制轻舟和岸边轻甲
楼船 → 水上重型主力，怕火箭舟和破甲鹰弩
火箭舟 → 克制建筑、楼船、密集单位
攻城器械 → 克制建筑，但怕骑兵和飞行单位
```

## 9. 科技树总览

```text
1. 步兵科技
2. 射击科技
```

科技类型分为：

| 科技类型 | 作用 |
|---|---|
| 解锁科技 | 解锁新单位、新建筑、新技能 |
| 强化科技 | 强化单位原有职责 |
| 模式科技 | 改变单位玩法，例如箭矢模式 |
| 克制科技 | 增强针对某类敌人的能力 |
| 战略科技 | 侦察、机动、经济、后勤、视野、军令 |

## 23. 最终硬规则

```text
1. 当前资源只有木材、黄金、石料、金属和人口。
2. 删除粮食和粮仓。
3. 人口由主城和民房提供。
4. 补给、治疗、修理交给辎重营和后勤单位。
5. 一个生产建筑只负责一条兵种线。
6. 高级单位通过科技解锁，但仍在对应生产建筑生产。
7. 科技建筑只研究科技，不生产普通单位。
8. 步兵营生产全部步兵线单位。
9. 骑兵营生产全部骑兵线单位。
10. 飞羽营生产全部飞行单位。
11. 水师营生产全部水上单位。
12. 工械坊生产全部攻城器械。
13. 辎重营生产全部后勤单位。
14. 演武台负责陆军、射击、骑兵、攻城科技。
15. 天机楼负责空军科技。
16. 水军府负责水军科技。
17. 军阵坛负责阵法科技。
18. 辎重营负责后勤科技。
19. 主城等级决定建筑等级上限。
20. 建筑最大3级。
21. 士兵没有等级，只有星级，最高5星。
22. 英雄最高5星，升星解锁/强化技能。
23. 每个单位必须有明确克制对象和被克制对象。
24. 箭矢类科技可以全部研究，但同一单位只能启用一种箭矢模式。
25. 迅捷步伐提供短时间移速提升，但结束后有减速 Debuff。
26. 科技必须服务单位差异化，不能只堆数值。
27. 单位 Tips 必须显示定位、擅长、害怕、当前模式和已生效关键科技。
28. 科技 Tips 必须显示影响单位、解锁内容、代价、克制方向。
29. 资源不足 UI 必须明确显示缺少哪种资源和数量。
30. 华夏整体体验必须是：正规军制、清晰生产线、科技驱动克制网络、士兵战斗升星。
```

## 24. 总结

华夏阵营最终结构：

```text
建筑：主城等级推进 + 单一功能建筑
单位：按生产线分类 + 明确克制关系
科技：解锁高级兵 + 改变玩法 + 强化克制方向
资源：木材、黄金、石料、金属 + 人口
成长：士兵和英雄通过战斗升星
```

```text
华夏阵营是“主城统筹建筑体系，生产建筑各司其职，科技解锁高级兵种，士兵通过战斗升星成精锐”的正规军 RTS 阵营。
```
