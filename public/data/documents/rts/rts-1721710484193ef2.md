# 08 常见界面布局模板规范：背包、商店、奖励、图鉴、设置

## 1. 文档目标

本文档给出常见游戏 UI 界面的标准布局模板。后续制作新界面时，不要从空白开始设计，而是从这里选择一个模板再改。

包含：

- 背包界面
- 物品详情弹窗
- 商店界面
- 奖励界面
- 三选一界面
- 图鉴界面
- 设置界面
- 部件改造界面
- 技能选择界面
- 战斗 HUD 信息层

---

## 2. 通用页面结构

全屏页面推荐：

```text
ScreenRoot
├── BgLayer                 背景层
├── Header                  顶部标题/资源/关闭
├── Main                    主内容区
│   ├── LeftPanel           左侧区域，可选
│   ├── CenterPanel         中央区域
│   └── RightPanel          右侧详情，可选
├── Footer                  底部按钮/提示
└── FloatingLayer           Tooltip/弹出提示/拖拽图标
```

弹窗页面推荐：

```text
PopupRoot
├── DimLayer
├── PanelRoot
│   ├── Header
│   ├── Body
│   └── Footer
└── FloatingLayer
```

## 3. 背包界面布局规范

### 3.1 适用场景

- 道具背包
- 装备背包
- 部件仓库
- 技能库存
- 材料仓库

### 3.2 推荐布局：左网格，右详情

```text
┌──────────────────────────────────────────────┐
│ 背包                  金币 12345     [关闭] │
├──────────────────────────────────────────────┤
│ [全部][装备][材料][消耗品][部件]             │
├──────────────────────────┬───────────────────┤
│                          │                   │
│  物品网格                 │  当前选中详情      │
│  [ ][ ][ ][ ][ ]          │  Icon + 名字       │
│  [ ][ ][ ][ ][ ]          │  属性 / 效果       │
│  [ ][ ][ ][ ][ ]          │  操作按钮          │
│                          │                   │
├──────────────────────────┴───────────────────┤
│ 排序：品质优先 / 类型优先       容量 36/80    │
└──────────────────────────────────────────────┘
```

### 3.3 层级结构

```text
BackpackPanel
├── Header
│   ├── Txt_Title
│   ├── CurrencyGroup
│   └── Btn_Close
├── CategoryTabs
│   ├── Tab_All
│   ├── Tab_Equip
│   ├── Tab_Material
│   └── Tab_Module
├── Main
│   ├── Left_ItemGridPanel
│   │   ├── SortBar
│   │   └── Scroll_ItemGrid
│   │       └── Content_Grid
│   │           └── ItemSlot[]
│   └── Right_DetailPanel
│       └── ItemDetailPanelBase
└── Footer
    ├── Txt_Capacity
    ├── Btn_Sort
    └── Btn_AutoArrange
```

### 3.4 美观规则

- 左侧网格是操作区，右侧详情是阅读区。
- 选中物品时，右侧详情立即更新。
- 右侧详情不要覆盖背包格，避免玩家失去上下文。
- 物品格尺寸统一，品质差异通过边框、底纹、角标表现。
- 空格子可以弱显示，但不要比已有物品更亮。

## 4. 商店界面布局规范

### 4.1 推荐布局

```text
┌──────────────────────────────────────────────┐
│ 商店              金币 12345 钻石 88 [关闭] │
├──────────────────────────────────────────────┤
│ [推荐] [武器] [部件] [材料] [限时]            │
├──────────────────────────┬───────────────────┤
│ 商品列表                  │ 商品详情           │
│ [商品卡][商品卡][商品卡]  │ Icon + 名字        │
│ [商品卡][商品卡][商品卡]  │ 价格 / 效果        │
│                          │ [购买]             │
└──────────────────────────┴───────────────────┘
```

### 4.2 商品卡结构

```text
ShopItemCard
├── Bg_Card
├── IconBlock
├── Txt_Name
├── PriceRow
│   ├── Icon_Currency
│   └── Txt_Price
├── Badge_Discount 可选
├── Badge_Limit 可选
└── StateOverlay_SoldOut 可选
```

### 4.3 美观规则

- 价格必须靠近购买按钮或商品卡底部。
- 折扣、限购、已售罄用角标，不要塞进名字里。
- 当前货币放 Header 右侧，玩家买东西时随时能看见。
- 商品详情和背包详情共用 `DetailPanelBase`。

## 5. 奖励界面布局规范

### 5.1 适用场景

- 战斗胜利奖励
- 宝箱开启
- 任务完成
- 关卡结算
- 每日奖励

### 5.2 低密度奖励弹窗

```text
┌──────────────────────────────┐
│          获得奖励             │
│                              │
│      [大图标 / 稀有光效]      │
│          雷霆核心             │
│        传说 · 攻击部件        │
│                              │
│   金币 +1200   经验 +300      │
│                              │
│          [确认]              │
└──────────────────────────────┘
```

### 5.3 多奖励列表

```text
┌────────────────────────────────┐
│           战斗奖励              │
├────────────────────────────────┤
│ [奖励卡] [奖励卡] [奖励卡]       │
│ [奖励卡] [奖励卡] [奖励卡]       │
├────────────────────────────────┤
│         [全部领取]              │
└────────────────────────────────┘
```

### 5.4 美观规则

- 奖励界面允许更强动效和光效。
- 稀有奖励要比普通奖励更突出。
- 但文字说明仍然不能被光效压住。
- 多奖励时用网格，不要竖向无限堆。
- 领取按钮固定底部。

## 6. 三选一界面布局规范

### 6.1 推荐布局

```text
┌────────────────────────────────────────────┐
│              选择一个强化                  │
│        本次选择会影响后续战斗流派           │
├────────────────────────────────────────────┤
│                                            │
│   ┌────────┐   ┌────────┐   ┌────────┐    │
│   │ 卡牌 A │   │ 卡牌 B │   │ 卡牌 C │    │
│   │ Icon   │   │ Icon   │   │ Icon   │    │
│   │ 效果   │   │ 效果   │   │ 效果   │    │
│   └────────┘   └────────┘   └────────┘    │
│                                            │
├────────────────────────────────────────────┤
│             [刷新]          [跳过]          │
└────────────────────────────────────────────┘
```

### 6.2 卡牌结构

```text
ChoiceCard
├── Bg_Card_Quality
├── Header
│   ├── Txt_Name
│   └── Tag_Quality
├── IconBlock
├── EffectText
├── KeywordRow
└── HoverGlow / SelectedFrame
```

### 6.3 美观规则

- 三张卡必须等宽等高。
- 当前悬停/选中卡要有明显浮起或描边。
- 卡牌内容不要超过卡牌底部，超长效果进入 Tooltip。
- 三选一界面不建议放太多其他按钮，避免干扰选择。

## 7. 图鉴界面布局规范

### 7.1 推荐布局：左分类，中列表，右详情

```text
┌──────────────────────────────────────────────┐
│ 图鉴                                      [X] │
├──────────┬────────────────┬──────────────────┤
│ 分类      │ 条目列表         │ 详情展示          │
│ [角色]    │ [头像][头像]     │ 大模型/大图        │
│ [敌人]    │ [头像][头像]     │ 名字/描述/属性     │
│ [部件]    │ [头像][头像]     │ 获取来源           │
│ [事件]    │ [头像][头像]     │                  │
└──────────┴────────────────┴──────────────────┘
```

### 7.2 美观规则

- 分类永远在左侧或顶部，保持稳定。
- 条目列表只负责选择，不展示太多详情。
- 右侧详情负责放大展示。
- 未解锁条目用剪影、问号、灰色遮罩。
- 已解锁进度放 Header 或 Footer。

## 8. 设置界面布局规范

### 8.1 推荐布局：左分类，右设置项

```text
┌──────────────────────────────────────────────┐
│ 设置                                      [X] │
├──────────┬───────────────────────────────────┤
│ [音效]    │ 总音量       [Slider]             │
│ [画面]    │ BGM音量      [Slider]             │
│ [按键]    │ UI音效       [Slider]             │
│ [语言]    │ 敌人音效     [Slider]             │
│          │ 背景音效     [Slider]             │
└──────────┴───────────────────────────────────┘
```

### 8.2 设置项结构

```text
SettingRow
├── Txt_Label
├── Txt_Desc 可选
└── ControlArea
    ├── Slider / Toggle / Dropdown / KeyBindButton
    └── Txt_Value 可选
```

### 8.3 美观规则

- 设置项必须按组分区。
- Label 左对齐，控件右对齐。
- 说明文字弱化，不能和标题一样强。
- 按键绑定项要显示当前按键和冲突状态。
- 危险操作，例如清除存档，要放到最下方，使用警告样式。

## 9. 部件改造界面布局规范

适合积木飞船、装备改造、模块升级。

### 9.1 推荐布局

```text
┌──────────────────────────────────────────────┐
│ 部件改造                                [X] │
├───────────────┬──────────────────────────────┤
│ 当前部件       │ 改造选项                      │
│ [大Icon]       │ [词条卡][词条卡][词条卡]       │
│ 名字/品质      │                              │
│ 当前属性       │ 消耗材料                      │
│ 当前效果       │ [材料][材料][金币]             │
├───────────────┴──────────────────────────────┤
│              [确认改造] [取消]               │
└──────────────────────────────────────────────┘
```

### 9.2 美观规则

- 左侧放当前对象，右侧放将要变化的内容。
- 属性变化必须用对比箭头：`12 → 18`。
- 提升用绿色，降低用红色，中性变化用白色/黄色。
- 消耗材料靠近确认按钮。
- 如果材料不足，材料项和按钮都要提示原因。

## 10. 技能选择界面布局规范

### 10.1 推荐布局

```text
┌──────────────────────────────────────────────┐
│ 技能配置                                [X] │
├──────────────────────┬───────────────────────┤
│ 已装备技能栏           │ 技能库                 │
│ [槽][槽][槽][槽]       │ [技能][技能][技能]      │
│                      │ [技能][技能][技能]      │
├──────────────────────┴───────────────────────┤
│ 技能详情 / 替换说明                           │
└──────────────────────────────────────────────┘
```

### 10.2 美观规则

- 已装备技能和可选技能必须视觉区分。
- 技能槽要显示空槽、锁定槽、已装备槽。
- 点击技能时，底部或右侧显示详情。
- 拖拽更换时，鼠标/手指下显示半透明图标。

## 11. 战斗 HUD 信息层布局规范

### 11.1 原则

战斗 HUD 的核心是“不挡战斗区域”。

优先级：

```text
角色状态 > 技能按钮 > 战斗提示 > 小地图/任务 > 装饰
```

### 11.2 推荐结构

```text
BattleHUD
├── TopLayer
│   ├── WaveInfo
│   ├── Timer
│   └── PauseButton
├── CenterFloatingLayer
│   ├── DamageText
│   ├── BuffTips
│   └── ObjectiveHint
├── BottomLeft
│   └── Joystick
├── BottomRight
│   ├── MainAttackButton
│   ├── DodgeButton
│   ├── JumpButton
│   ├── SkillRing
│   └── ItemRing
└── CharacterWorldUI
    ├── HPBar
    ├── EnergyBar
    └── BuffList
```

### 11.3 美观规则

- 技能按钮集中，不要散落全屏。
- 重要按钮大，低频按钮小。
- Buff 不要堆太多，超过数量折叠。
- 伤害数字颜色根据类型统一。
- 角色头顶血条不能太大，避免遮挡角色。

## 12. UI 模板选择规则

| 界面类型 | 推荐模板 |
|---|---|
| 物品/技能详情 | Header + BodyScroll + Footer |
| 背包/仓库 | 左网格 + 右详情 |
| 商店 | 左商品 + 右详情 + 顶部货币 |
| 图鉴 | 左分类 + 中列表 + 右详情 |
| 设置 | 左分类 + 右设置项 |
| 三选一 | 三卡并排 + 底部操作 |
| 奖励 | 中央焦点 + 底部确认 |
| 部件改造 | 左当前 + 右变化 + 底部确认 |
| 技能配置 | 已装备槽 + 技能库 + 详情 |
| 战斗 HUD | 四角分区 + 中央少干扰 |

---

## 13. 通用检查清单

- [ ] 当前界面是否有明确焦点？
- [ ] 操作区和阅读区是否分开？
- [ ] 列表是否只是列表，详情是否集中在详情区？
- [ ] 按钮是否固定在玩家预期位置？
- [ ] 内容多时是否滚动或分页？
- [ ] 内容少时是否隐藏空模块？
- [ ] 当前选中对象是否有明显选中态？
- [ ] 货币/资源是否在购买界面持续可见？
- [ ] 关闭按钮是否固定右上角？
- [ ] 重要信息是否没有被装饰遮挡？
