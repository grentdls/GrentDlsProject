# 建筑选中后的造兵页面 UI 详细规则文档

## 运行时绑定补充规则（2026-05-18）

- HUD 内嵌造兵页继续使用 `SelectionBuildingProductionPage_Prefab`，不再允许脚本重新摆放其固定子节点位置。
- `SelectionPanel` 对造兵页的职责只保留：
  - 读取固定节点
  - 生成训练卡条目
  - 绑定“当前生产 / 等待队列 / 集结点”数据
  - 控制显隐、点击、可用状态
- `SelectionPanel` 不再负责：
  - 重新设置造兵页内部固定标题、队列区、集结点区的位置
  - 重新设置 prefab 内固定文本的字体、对齐、尺寸
  - 把整个生产队列继续当成一条旧的纯横向列表来重建

### 单位列表滚动内容规则（2026-05-19）

- `ProductionGridViewport` / `ProductionGridContent` 继续由 `SelectionBuildingProductionPage_Prefab` 提供固定结构。
- `ProductionGridContent`、`BuildCategoryTabsContent`、`ProductionQueueContent` 作为横向滚动内容根时必须使用左上基准：

```text
anchorMin = (0, 1)
anchorMax = (0, 1)
pivot = (0, 1)
anchoredPosition = (0, 0)
```

- `SelectionPanel` 运行时只允许根据实际训练卡数量更新 `ProductionGridContent.sizeDelta`，确保横向滚动内容宽度覆盖所有 `PcQuickTrain_*` 卡片。
- `ProductionGridViewport` 本体的位置、大小和视觉样式仍由 prefab 维护；代码只保证它在存在可训练单位时处于 active，并把 `ScrollRect.content` 指回 `ProductionGridContent`。
- 如果造兵页显示了队列但单位卡列表为空，优先检查：
  - `ProductionCatalogUtility.ResolveTrainableUnits(building)` 是否返回单位
  - `ProductionGridContent` 的 pivot 是否仍为 `(0, 1)`
  - 训练卡是否被重新挂回 `ProductionGridContent`
  - `ScrollRect.content` 是否指向 `ProductionGridContent`

### 队列区固定节点

`ProductionQueueContent` 下优先使用以下推荐固定节点：

```text
ProductionQueueContent
  CurrentProduction
  WaitingQueueViewport
    WaitingQueueContent
  EmptyLabel
```

- `CurrentProduction`：当前正在生产的条目容器，只显示队列第 0 项
- `WaitingQueueViewport`：等待队列专用滚动槽，固定在当前生产槽右侧
- `WaitingQueueContent`：等待中的队列内容容器，只显示第 1 项及以后；若仍直接挂在 `ProductionQueueContent` 下，运行时按旧兼容结构处理
- `EmptyLabel`：空队列提示

兼容旧结构：

```text
ProductionQueueContent
  CurrentProduction
  WaitingQueueContent
  EmptyLabel
```

### 兼容规则

- 如果上述新节点尚未补到 prefab，运行时仍会降级回旧的 `ProductionQueueContent` 横向列表，保证不崩。
- 一旦 prefab 补齐 `CurrentProduction` 或 `WaitingQueueContent`，运行时就切换到新结构，不再对 `ProductionQueueContent` 本体套旧横向布局。
- 推荐结构是 `CurrentProduction + WaitingQueueViewport/WaitingQueueContent + EmptyLabel`，这样当前生产槽固定在左侧，等待队列只在右侧区域横向滚动。

### 当前生产条目规则

- 当前生产条目显示完整单位名
- `ProgressLabel` 显示：`百分比 + 剩余秒数`
- `ProgressFill` 显示当前训练进度
- 取消按钮仍直接取消队列第 0 项

### 等待队列条目规则

- 等待条目显示短名称
- `ProgressLabel` 固定显示 `等待中`
- `ProgressFill` 保持 0
- 每个等待项右上角取消按钮取消对应排队项

### 集结点按钮规则

- `RallyPointFloatingButton` 的位置和大小必须由 prefab 维护
- 代码只更新：
  - 文案
  - 按钮可点击状态
  - 点击事件
- 若 prefab 已声明保留样式，代码不再覆盖其文字字号和对齐

### 独立造兵窗口补充规则（2026-05-18）

- 除 HUD 内嵌造兵页外，独立大造兵窗口 `UnitProductionPanel_Prefab` 也必须遵守同一套 prefab 优先规则。
- 独立窗口里的以下节点，后续一律直接在 prefab 内调：
  - `CategoryTabs` 下各分类页签
  - `UnitButtons` 下每个 `UnitProductionCard_Prefab`
  - `QueueEntries` / `WaitingQueueContent` 下每个 `ProductionQueueEntry_Prefab`
- 代码不再负责这些节点的静态样式：
  - 分类标签字号、best-fit、对齐
  - 造兵卡按钮过渡色、底色、默认描边
  - 队列条目进度条类型、方向、默认底图
  - 角标底图与默认文本配色
- 代码仍然负责：
  - 可训练单位列表的生成顺序
  - 队列当前项 / 等待项的数据填充
  - 训练可用性、队列状态、选中状态对应的动态数据
  - 点击训练、取消队列、查看详情
- 如果后续发现“改了 prefab 但独立造兵窗口没变化”，优先检查：
  - 当前节点或父节点是否漏挂 `UiPrefabSlot`
  - 当前运行时是否仍然走到了非可见逻辑宿主
  - 是否实例化了错误的旧 prefab 资源

## 一、设计目标

当玩家点击拥有造兵功能的建筑后，需要显示造兵页面。

该页面用于快速创建单位、查看单位消耗、查看生产队列、设置集结点，并通过悬停 / 长按查看单位详情。

当前优化目标：

```text
1. 造兵页面显示单位图片。
2. 单位图片下方显示资源消耗：ICON + 数字。
3. 单位列表横向排布，可横向拖动。
4. 下方单独显示制造队列：制造中、等待制造。
5. 点击造兵建筑时，如果建筑有造兵功能，旁边必须有集结点按钮。
6. 鼠标悬停 / 手机长按单位卡显示单位造兵详情页。
7. PC 和手机都要清楚、好点、好拖、低误触。
8. 主页面简洁，复杂信息放入详情页。
```

最终体验：

```text
玩家点击兵营 / 兽巢 / 机场 / 船厂 / 元素建筑后，
界面弹出横向单位创建列表，
每个单位卡显示单位图 + 名称 + 消耗，
下方显示当前生产队列，
旁边有集结点按钮，
点击单位即可加入生产队列，
悬停 / 长按可查看完整详情。
```

# 二、造兵页面出现条件

## 2.1 哪些建筑显示造兵页面

建筑满足以下条件时，选中后显示造兵页面：

```text
建筑拥有生产单位功能
建筑已建造完成
建筑未被摧毁
建筑未处于瘫痪状态
建筑未处于断供导致完全停产状态
当前玩家拥有该建筑控制权
当前模式允许生产单位
```

示例建筑：

| 阵营 | 造兵建筑 |
|---|---|
| 华夏 | 步兵营、骑兵营、水军营、飞行营、神机工坊 |
| 妖族 | 虫巢、凶兽巢、温兽巢、飞兽巢、水巢 |
| 机械 | 机场、重装工厂、机动机械场、船厂 |
| 自然 | 水灵源池、炽火灵炉、厚土灵坛、金魄铸庭、灵木育场 |
| 融合阵营 | 镇妖兽栏、化形兽坛、灵能装配场、血肉机巢等 |

---

## 2.2 建筑无造兵功能

如果建筑没有造兵功能：

```text
不显示造兵页面。
显示建筑信息面板和建筑操作按钮。
```

例如：

```text
防御塔
资源建筑
纯科技建筑
治疗建筑
电力建筑
```

---

## 2.3 建筑有多个功能

如果建筑同时拥有：

```text
造兵
科技
升级
改造
技能
```

优先显示规则：

```text
造兵列表显示在建筑操作区域上方。
科技列表可以作为同级横向列表或切换页。
按钮操作放在右侧操作区。
```

推荐结构：

```text
上方：单位创建列表
中间：制造队列
右侧：建筑操作按钮，包括集结点、升级、停止、详情
```

# 三、造兵页面整体布局

## 3.1 手机端布局

手机端推荐显示在屏幕右侧或底部偏右区域。

原则：

```text
不遮挡顶部资源栏
不遮挡小地图
不遮挡技能按钮
不遮挡建筑血条/战场关键区域
```

推荐布局：

```text
┌──────────────────────────────┐
│ 单位创建列表                  │
│ [单位卡][单位卡][单位卡] →拖动 │
├──────────────────────────────┤
│ 制造队列                      │

      [集结点按钮]
```

手机端尺寸建议：

| 项目 | 建议 |

| 面板高度 | 245~300 px |

| 集结点按钮 | 54~64 px |

# 四、页面展开与隐藏

## 4.1 展开规则

点击造兵建筑后：

```text
建筑信息面板打开
造兵页面从底部或右侧滑出
单位创建列表自动显示
制造队列自动显示
集结点按钮显示
```

推荐动效：

```text
0.18秒滑入
透明度 0 → 100%
缩放 96% → 100%
```

---

## 4.2 隐藏规则

以下情况隐藏造兵页面：

```text
取消选择建筑
选中其他非造兵建筑
打开全屏UI
建筑被摧毁
建筑失去控制权
玩家按返回键
手机系统返回键
```

---

## 4.3 返回键规则

手机端：

```text
按系统返回键：
如果单位详情页打开 → 关闭详情页
如果正在设置集结点 → 取消集结点设置
如果造兵页面打开 → 关闭造兵页面
如果没有打开UI → 不处理或打开暂停菜单
```

PC端：

```text
ESC：
优先关闭详情卡
再取消集结点设置
再关闭造兵页面
```

# 五、单位创建列表设计

## 5.1 列表基础规则

单位创建列表横向排布。

```text
[单位卡][单位卡][单位卡][单位卡] →
```

列表必须支持横向拖动。

适用原因：

```text
建筑可生产单位较多时，不挤压UI。
手机端可直接滑动选择。
PC端可滚轮或拖拽切换。
```

---

## 5.2 单位卡片结构

每个单位卡片显示：

```text
单位图片
单位名称
资源消耗
训练时间，可选
状态角标
```

推荐结构：

```text
┌──────────────┐
│   单位图片    │
│              │
├──────────────┤
│ 单位名称      │
│ 🪵60  🪙90    │
│ 👥2   ⏱18s   │
└──────────────┘
```

---

## 5.3 单位图片

单位图片要求：

```text
使用单位头像、半身像或小渲染图
透明背景
主体清楚
剪影明确
和战场模型风格一致
```

尺寸：

| 平台 | 图片尺寸 |
|---|---:|
| 手机 | 72~82 px |
| PC | 78~88 px |

图片底板：

```text
圆角方形底
阵营主题边框
轻微阴影
```

---

## 5.4 单位名称

显示规则：

```text
最多 5 个汉字
超过则缩略
完整名进入详情页
```

示例：

```text
盾兵
长枪兵
麒麟骑兵
机械狗
冰灵
火魔树
```

字体：

```text
12~14号
加粗
居中
```

---

## 5.5 资源消耗列表

单位卡下方显示消耗。

格式：

```text
ICON + 数字
```

推荐最多显示：

```text
3种资源 + 人口
```

如果资源超过4项：

```text
显示主要3项 + 人口
完整消耗进入详情页
```

示例：

```text
🪵60  🪙90
👥2   ⏱18
```

机械单位：

```text
🪙180 ⚙100
⚡5   👥3
```

融合单位：

```text
🪙460 ⚙180
👥6   🌀5
```

其中：

```text
👥 = 普通人口
🌀 = 融合人口
⚡ = 电力/能耗
```

---

## 5.6 训练时间显示

训练时间建议显示在单位卡右下角：

```text
⏱18s
```

如果卡片空间不足：

```text
训练时间可以只在详情页显示。
```

推荐：

```text
普通造兵卡显示训练时间。
手机超小屏可以隐藏训练时间。
```

# 六、单位卡片状态表现

## 6.1 状态类型

| 状态 | 表现 |
|---|---|
| 可训练 | 正常亮度，阵营色描边 |
| 资源不足 | 缺少资源数字红色，卡片轻微变暗 |
| 人口不足 | 人口数字红色，显示人口警告 |
| 科技未解锁 | 灰色遮罩，锁图标 |
| 建筑等级不足 | 锁图标 + 等级条件 |
| 建筑停电 | 蓝色电力警告 |
| 建筑断供 | 灰色断供标记 |
| 队列已满 | 卡片灰显，显示队列满 |
| 单位数量上限 | 显示 0/3，满后灰显 |
| 新解锁 | 右上角“新”角标 |
| 推荐生产 | 柔和脉冲描边 |

---

## 6.2 资源不足

如果某项资源不足：

```text
对应资源数字变红。
卡片整体透明度降低到 70%。
点击时不加入队列。
播放轻微错误音。
弹出小提示：黄金不足。
```

---

## 6.3 人口不足

普通人口不足：

```text
👥 数字变红。
底部显示：人口不足。
```

融合人口不足：

```text
🌀 数字变紫红。
底部显示：融合人口不足。
```

机械能耗不足：

```text
⚡ 数字变红。
底部显示：能耗不足。
```

---

## 6.4 科技未解锁

未解锁单位显示：

```text
灰色遮罩
锁图标
名称可见
条件简写
```

示例：

```text
[锁] 麒麟骑兵
需要：麒麟军阵
```

点击未解锁单位：

```text
不加入队列。
打开详情页并定位到条件区。
```

---

## 6.5 队列已满

如果建筑生产队列达到上限：

```text
所有可训练单位卡底部显示：队列满。
点击无法加入。
队列栏轻微闪烁。
```

# 七、横向拖动规则

## 7.1 手机端拖动

手机端单位列表拖动规则：

```text
手指左右滑动 → 横向滚动
移动超过 12px → 判定为拖动
拖动中不触发点击
快速滑动 → 惯性滚动
长按 0.35秒 → 显示详情页
长按后移动超过20px → 关闭详情并进入拖动
```

防误触优先级：

```text
拖动 > 长按 > 点击
```

---

## 7.2 PC端拖动

PC端支持：

```text
鼠标滚轮横向滚动
Shift + 滚轮快速滚动
鼠标拖拽列表滚动
左右箭头按钮翻页
鼠标悬停单位卡显示详情
```

推荐：

```text
鼠标在单位列表上时，滚轮控制单位列表。
鼠标离开列表时，滚轮恢复默认镜头缩放。
```

---

## 7.3 列表边缘提示

如果还能向右滚：

```text
右侧显示渐隐遮罩。
```

如果还能向左滚：

```text
左侧显示渐隐遮罩。
```

底部可显示进度条：

```text
━━━━━━━──
```

# 八、点击单位卡后的生产规则

## 8.1 点击加入队列

点击可训练单位卡：

```text
立即加入制造队列。
消耗资源。
队列栏新增该单位图标。
播放点击音和加入队列动效。
```

建议：

```text
资源在加入队列时扣除。
取消队列时返还100%资源。
```

如果后续需要更硬核：

```text
可配置取消返还比例。
```

---

## 8.2 连续点击

连续点击同一单位卡：

```text
每次点击加入一个单位。
```

PC端快捷：

```text
Shift + 点击：加入5个。
Ctrl + 点击：加入队列最大数量。
右键点击队列项：取消一个。
```

手机端快捷：

```text
双击单位卡：加入2个，可选。
长按单位卡：显示详情，不用于连续生产。
```

建议手机端不要做双击造兵，避免误触。更推荐：

```text
点击一次加入一个。
队列旁边提供 + / - 按钮，可选。
```

# 九、制造队列栏设计

```text
5个
```

可通过科技或建筑升级提高：

```text
队列扩展 I：+2
队列扩展 II：+3
```

建议最大：

```text
10个
```

每个队列项显示：

```text
单位头像
状态
进度条
```

第一个队列项是制造中。

显示：

```text
更大的头像

剩余时间
“制造中”标签
```

示例：

```text
[盾兵头像]
```

# 十、制造进度规则

## 10.1 单位生产时间

每个单位拥有：

```text
BaseTrainTime
```

最终制造时间受以下影响：

```text
建筑等级
科技加成
电力状态
断供状态
阵营特殊机制
Buff/Debuff
```

示例：

```text
最终时间 = 基础时间 / 生产速度倍率
```

---

## 10.2 制造速度影响

| 状态 | 效果 |
|---|---|
| 正常 | 100% |
| 华夏建筑升级 | 生产速度 +10% / +20% |
| 机械过载 | 生产速度 +30%~40% |
| 机械缺电 | 生产速度 -50% |
| 机械断电 | 生产暂停 |
| 妖族圣祭建筑 | 生产速度 +15% |
| 自然优势相邻强化 | 生产速度 +5%~15%，如果配置 |
| 融合建筑断供 | 生产暂停 |

---

## 10.3 暂停生产

以下情况会暂停生产：

```text
建筑断电
建筑断供
建筑被控制
建筑被暂停
建筑被摧毁
资源系统特殊锁定，可选
```

暂停时：

```text
制造中进度保留。
队列不消失。
队列栏显示暂停状态。
```

---

## 10.4 暂停表现

队列栏显示：

```text
暂停
```

进度环变灰。

暂停原因显示：

```text
断电
断供
建筑被控制
建筑已停产
```

示例：

```text
制造暂停：电力不足
```

# 十一、集结点按钮规则

## 11.1 出现条件

```text
集结点按钮
```

即使当前队列为空，也要显示。

## 11.2 集结点按钮位置

### 手机端

推荐位置：

```text
造兵页面右侧
靠近单位列表，但不混入单位卡
```

结构：

```text
┌──────────────┐
│ 造兵页面      │ [集结点]
└──────────────┘
```

按钮尺寸：

```text
54~64 px
```

### PC端

推荐位置：

```text
造兵面板右侧
或建筑操作按钮区最上方
```

按钮尺寸：

```text
48~56 px
```

---

## 11.3 集结点按钮图标

图标建议：

```text
旗帜 + 箭头
或 旗帜 + 地面标记
```

不同阵营风格：

| 阵营 | 图标风格 |
|---|---|
| 华夏 | 军旗 |
| 妖族 | 骨旗 / 妖血旗 |
| 机械 | 信标 / 定位塔 |
| 自然 | 灵旗 / 光点种子 |
| 融合 | 双阵营混合旗 |

---

## 11.4 设置集结点流程

点击集结点按钮：

```text
进入设置集结点模式
鼠标/手指点击地图位置
建筑保存该位置为集结点
后续生产单位自动前往该位置
```

PC端：

```text
点击集结点按钮
→ 鼠标变为旗帜光标
→ 左键点击地面设置
→ 右键取消
```

手机端：

```text
点击集结点按钮
→ 屏幕中心出现集结点预览旗
→ 拖动地图选择位置
→ 点击确认设置
→ 点击取消退出
```

为了和建筑放置逻辑统一，手机端建议使用中心点确认：

```text
集结点旗帜虚影显示在屏幕中心地面
右上确认
左上取消
```

---

## 11.5 集结点表现

设置成功后：

```text
建筑到集结点之间短暂显示虚线
集结点位置出现阵营旗帜
旗帜停留1.5秒后淡化
建筑面板集结点按钮高亮
```

当建筑被选中时：

```text
显示当前集结点旗帜
显示建筑到集结点的细线
```

未选中时：

```text
隐藏旗帜或只显示很淡的标记
```

---

## 11.6 集结点类型

基础集结点：

```text
地面点
```

高级集结点可支持：

```text
指定单位
指定建筑
资源点
水域点
空中巡逻点
```

建议第一版支持：

```text
地面点
水域点，船厂用
机场空中等待点，可选
```

---

## 11.7 不同建筑集结点规则

| 建筑类型 | 集结点规则 |
|---|---|
| 地面兵营 | 地面可通行点 |
| 飞行单位建筑 | 地面/空中点都可，单位飞过去 |
| 船厂 | 必须是水域可航行点 |
| 水系建筑 | 水域点优先，水系单位可上岸则允许陆地 |
| 机械机场 | 空中单位起飞后前往集结点 |
| 运输单位建筑 | 可设置装载等待点 |

---

## 11.8 集结点非法位置

如果玩家点击非法位置：

```text
集结点旗帜变红
提示原因
不保存
```

提示示例：

```text
地面单位无法到达
船厂单位需要水域集结点
该位置被阻挡
超出地图范围
```

---

## 11.9 集结点清除

长按/右键集结点按钮：

```text
清除集结点
```

清除后：

```text
单位生产完成后停留在建筑出口附近。
```

按钮状态：

```text
无集结点：灰色旗帜
已设置：阵营色高亮旗帜
设置中：闪烁旗帜
```

# 二十、最终硬规则

```text
1. 造兵页面必须显示单位图片。
2. 单位图片下方必须显示消耗资源：ICON + 数字。
3. 单位列表必须横向排布。
4. 单位列表必须支持横向拖动。
5. 造兵页面下方必须有制造队列栏。
6. 制造队列必须区分制造中和等待制造。
7. 制造中必须显示进度和剩余时间。
8. 等待制造必须显示顺序。
9. 点击单位卡加入制造队列。
10. PC端悬停单位卡显示单位详情。
11. 手机端长按单位卡显示单位详情。
12. 建筑有造兵功能时，旁边必须显示集结点按钮。
13. 集结点按钮必须能进入设置集结点模式。
14. 资源不足、人口不足、科技未解锁、队列满必须有明确状态。
15. 造兵页面和建筑操作按钮必须分区，不能堆叠。
16. 手机端必须避免点击、长按、拖动误触。
17. 不同阵营单位卡和队列进度必须有阵营主题。
```

---

# 二十一、一句话总结

```text
建筑造兵页面的主界面负责快速生产：单位图 + 名称 + 消耗；下方队列负责显示制造中和等待制造；集结点按钮负责生产后的行动方向；复杂单位说明通过悬停/长按详情页展示，保证可视性、操控性和战斗节奏都清楚。
```
