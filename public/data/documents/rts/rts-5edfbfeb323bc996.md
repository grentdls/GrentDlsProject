# 二、自然阵营新增系统总览

| 系统 | 核心作用 | 关联对象 |
|---|---|---|
| 元素属性系统 | 给建筑、单位、技能标记元素类型 | 所有自然单位、建筑、技能 |
| 五行克制系统 | 形成明确强弱关系 | 水、火、土、金、木 |
| 地形强化系统 | 元素单位在对应地形上获得强化 | 水面、火地、岩地、矿脉、森林 |
| 水系特殊系统 | 水系单位水面强、陆地弱 | 水灵源池、水系单位 |
| 建筑放置系统 | 水建筑只能建在水面/水岸 | 水灵源池 |
| 融合系统 | 两个单位融合为新单位 | 元素融合坛、所有元素单位 |
| 天象系统 | 全局/区域天气改变战场 | 天象祭台 |
| 治疗净化系统 | 回复、解除负面状态 | 灵泉之环、治愈莲灵 |
| 元素防御系统 | 自然阵营防御塔可元素化 | 根须守卫 |

# 三、元素属性系统需求

## 3.1 元素类型

所有自然阵营单位、建筑、技能必须拥有元素类型字段。

```text
Water 水
Fire 火
Earth 土
Metal 金
Wood 木
Hybrid 混合
Neutral 无属性
```

## 3.2 单位元素字段

每个单位配置：

```text
主元素
副元素，可为空
是否融合单位
是否纯属性融合
是否双属性融合
是否三段融合
优势地形
劣势地形
克制目标
被克制目标
```

示例：

```text
单位：火魔树
主元素：火
副元素：木
融合类型：双属性融合
优势地形：燃烧地表、森林，燃烧森林特殊加成
被克制：水
克制：木、金、密集单位
```

## 3.3 技能元素字段

每个技能配置：

```text
技能元素
伤害元素
是否造成元素状态
是否触发克制加成
是否受天气影响
是否受地形影响
```

示例：

```text
技能：爆裂火果
技能元素：火+木
伤害元素：火
附加状态：燃烧藤蔓
受雨天影响：伤害 -20%
受烈日影响：燃烧持续 +2秒
```

# 四、五行克制系统需求

## 4.1 基础克制关系

| 元素 | 强克制 | 被克制 |
|---|---|---|
| 水 | 火 | 土、木控制 |
| 火 | 木、金 | 水 |
| 土 | 水、冲锋单位 | 木、金穿甲 |
| 金 | 木、重甲、建筑 | 火 |
| 木 | 土、慢速重型 | 火、金 |

## 4.2 克制数值

基础克制：

```text
攻击克制目标：伤害 +25%
被克制目标攻击：受到伤害 +20%
```

科技强化后：

```text
强克制科技：额外伤害 +10%
高级强克制科技：附加状态触发概率 +15%
```

## 4.3 混合单位克制规则

双属性融合单位拥有主副元素。

伤害计算规则：

```text
优先使用技能元素判断克制。
普通攻击使用主元素判断克制。
部分技能可使用双元素反应伤害。
```

示例：

```text
火魔树普通攻击：主元素火，克制木/金。
火魔树技能爆裂火果：火+木反应，主要造成火伤，附带藤蔓区域。
```

## 4.4 克制UI表现

攻击触发克制时：

```text
伤害数字带元素颜色
目标头顶闪现“克制”小图标
血条旁出现被克制标识，持续1秒
```

被克制提示：

```text
单位面板显示：当前受到水系克制
鼠标悬停/长按显示原因
```

# 五、地形强化系统需求

## 5.1 地形类型

| 地形 | 强化元素 | 表现 |
|---|---|---|
| 水面/浅水/河流 | 水 | 水波、蓝色底光 |
| 燃烧地表/熔岩 | 火 | 火焰、红色热浪 |
| 岩地/山地/高坡 | 土 | 岩纹、土黄色光脉 |
| 矿脉/金属地表 | 金 | 金属光点、白金线条 |
| 森林/草地/藤蔓地 | 木 | 绿光、藤蔓、叶片 |

## 5.2 地形强化基础数值

| 元素 | 优势地形效果 |
|---|---|
| 水 | 攻击 +25%，移速 +30%，减伤20%，回血1.5%/s |
| 火 | 燃烧持续 +1秒，攻击 +12%，技能范围 +10% |
| 土 | 护甲 +2，受到击退 -30%，生命回复 +5/s |
| 金 | 命中 +15%，破甲效果 +1，攻击 +8% |
| 木 | 脱战回复 +12/s，控制持续 +0.5秒，召唤物生命 +10% |

## 5.3 地形识别需求

程序需要支持单位当前位置查询：

```text
当前地形类型
是否处于优势地形
是否处于劣势地形
是否处于临时元素地形
临时地形剩余时间
```

## 5.4 地形状态UI

单位面板显示：

```text
当前地形：水面
元素状态：水面强化中
效果：攻击 +25%，移速 +30%，减伤20%，回血1.5%/s
```

战场HUD：

```text
单位脚下出现元素颜色小圆环。
水系水面强化为蓝色水波环。
火系燃烧地表强化为红色火焰环。
```

# 六、水系特殊系统需求

## 6.1 水灵源池放置规则

水灵源池只能建在：

```text
水面
浅水
湖泊
河流
水岸建造点
```

不能建在：

```text
纯陆地
山地
森林
矿脉
敌方建筑范围内
不可通行深渊
```

## 6.2 建造预览表现

可建造：

```text
水面出现蓝色圆形建造范围
建筑虚影半透明蓝色
水面出现旋涡效果
```

不可建造：

```text
建筑虚影变红
地面显示“不在水域”提示
确认按钮灰显
```

## 6.3 水系单位移动规则

水系单位分三类：

```text
水行：水面强，陆地弱
冰行：水面中等，陆地可用，控制强
雨行：支援型，陆地惩罚较小
```

### 水行单位

```text
水面：满强化
陆地：攻击 -25%，移速 -35%
```

### 冰行单位

```text
水面：移速 +15%，冻结触发更快
陆地：无明显攻击惩罚，但移速 -10%
```

### 雨行单位

```text
水面：治疗/雨区效果 +20%
陆地：无攻击惩罚，但自身移速 -10%
```

## 6.4 非水系单位水面规则

默认：

```text
火、土、金、木基础单位不能进入水面。
```

例外：

```text
融合后获得两栖能力的单位可以进入水面。
飞行单位无视水面限制。
部分科技可让木系生成莲叶桥，短时间让陆地单位通过浅水。
```

## 6.5 水面强化表现

水系单位在水面：

```text
脚下持续水波
身体材质更亮
攻击带水花拖尾
回血时出现蓝色上升粒子
```

上岸削弱：

```text
身体水光变暗
脚下水迹变小
单位头顶显示“离水削弱”图标
```

# 七、元素融合系统需求

## 7.1 融合入口

融合只能在元素融合坛执行。

单位面板提供：

```text
[融合]
```

点击后进入融合选择模式。

## 7.2 融合操作流程

```text
选择单位A
点击【融合】
系统高亮可融合单位B
点击单位B
弹出融合预览
确认后两个单位前往元素融合坛
进入融合进度
完成后生成融合单位
```

## 7.3 可融合判定

可融合条件：

```text
双方都是自然阵营单位
双方不是英雄/Boss/召唤临时单位
双方不在战斗中
双方生命高于50%
元素融合坛可用
资源足够
融合配方存在
```

不可融合提示：

| 原因 | 提示 |
|---|---|
| 战斗中 | 单位正在战斗，无法融合 |
| 生命过低 | 生命低于50%，无法融合 |
| 无配方 | 当前组合没有融合结果 |
| 资源不足 | 显示缺少资源 |
| 融合坛忙碌 | 元素融合坛正在进行融合 |

## 7.4 融合预览UI

融合弹窗必须显示：

```text
单位A头像
单位B头像
融合结果模型/图标
融合后名称
融合后定位
融合后属性变化
融合技能
融合消耗
融合时间
克制与弱点
```

示例：

```text
火灵 + 木灵 = 火魔树
定位：爆炸投掷 / 燃烧召唤
克制：密集远程、建筑、木系
害怕：水系、远程穿甲、空中单位
技能：爆裂火果、燃根召唤
```

## 7.5 融合表现

融合开始：

```text
两个单位进入融合坛左右两侧
元素光球从单位身上抽离
中央形成五色旋转球
```

融合中：

```text
进度条显示
两种元素特效围绕中央旋转
火+木显示火焰和藤蔓缠绕
水+金显示冰晶和金属碎片旋转
```

融合完成：

```text
爆发一道元素光柱
新单位从中央出现
播放融合完成音效
弹出提示：融合成功：火魔树
```

融合失败，特殊模式可选：

```text
普通模式不允许失败。
高级不稳定融合科技可加入失败概率，但不建议早期加入。
```

# 九、天象天气系统需求

## 9.1 天象祭台功能

天象祭台提供全局或区域天气技能。

天气不是永久状态，而是：

```text
大范围持续效果
有冷却
可被敌方注意和反制
```

## 9.2 天象技能列表

# 十、灵泉治疗与净化系统需求

## 10.1 灵泉之环功能

灵泉之环只负责：

```text
治疗
净化
解除燃烧/中毒/减速/破甲
提高自然单位续航
```

不生产单位。

## 10.2 治疗规则

治疗对象：

```text
自然单位
融合单位
友方生物单位，可选
```

不能治疗：

```text
机械单位
建筑，除非科技解锁自然修复
敌方单位
```

## 10.3 净化优先级

净化负面状态优先级：

```text
燃烧
中毒
冻结/减速
破甲
沉默/禁技
其他持续伤害
```

## 10.4 灵泉技能

| 技能 | 效果 |
|---|---|
| 灵泉涌动 | 范围持续治疗 |
| 净化水环 | 清除范围友军1个负面状态 |
| 生命涌泉 | 单体大量治疗 |
| 自然修复 | 科技解锁，可缓慢修复自然建筑 |

## 10.5 表现

治疗：

```text
绿色和蓝色粒子上升
被治疗单位血条旁显示绿色十字/叶子图标
```

净化：

```text
负面状态图标破碎
单位身上出现水波冲刷效果
```

# 十一、根须守卫防御系统需求

## 11.1 根须守卫基础职责

根须守卫是自然阵营基础防御建筑。

可通过科技选择元素化防御模式。

## 11.2 防御模式

| 模式 | 效果 | 克制 |
|---|---|---|
| 木刺守卫 | 普通穿刺攻击 | 轻甲、采集单位 |
| 缠绕守卫 | 攻击有概率减速 | 骑兵、迅捷单位 |
| 火果守卫 | 攻击小范围爆炸 | 密集单位、木系 |
| 水雾守卫 | 降低敌人命中 | 远程阵地 |
| 岩根守卫 | 高生命阻挡 | 正面推进 |
| 金刺守卫 | 破甲射击 | 重甲、建筑单位 |

## 11.3 互斥规则

```text
同一座根须守卫只能启用一种防御模式。
切换模式需要科技和时间。
```

## 11.4 表现

```text
木刺：绿色尖刺
缠绕：藤蔓缠住目标脚下
火果：燃烧果实爆炸
水雾：白蓝雾气环绕
岩根：粗大岩根外壳
金刺：金属化藤刺
```

# 十五、验收标准

## 15.1 元素克制验收

```text
水攻击火时伤害明显提高。
火攻击水时表现为被压制。
UI能显示克制和被克制提示。
技能Tips能说明克制关系。
```

## 15.2 水系地形验收

```text
水系单位在水面攻击、移速、减伤、回血全部生效。
水系单位上岸后出现削弱图标。
陆地惩罚数值正确。
非水系基础单位无法进入水面。
```

## 15.3 融合系统验收

```text
能选择两个单位进行融合。
融合前能预览结果。
融合后两个原单位消失。
生成正确融合单位。
融合单位技能正确。
资源消耗和融合时间正确。
```

## 15.4 天象系统验收

```text
天象能影响指定区域或全局。
天象能正确强化/削弱对应元素。
UI显示当前天象和剩余时间。
特效和音效明显。
```

## 15.5 灵泉净化验收

```text
灵泉能治疗友军。
净化能按优先级移除负面状态。
被净化状态图标会消失。
机械单位不会被治疗。
```

## 15.6 防御模式验收

```text
根须守卫可以切换/选择元素防御模式。
同一座守卫只能启用一种模式。
不同模式有不同攻击表现和克制方向。
```

# 十六、最终硬规则

```text
1. 所有新增技能必须绑定元素属性。
2. 所有元素技能必须能参与克制计算。
3. 地形强化必须有UI提示和战场表现。
4. 水系水面强化和陆地削弱必须非常明显。
5. 融合前必须有结果预览。
6. 融合单位必须拥有新模型、新技能、新定位。
7. 天象必须影响技能、地形或元素状态，不能只是视觉效果。
8. 灵泉治疗和净化必须有明确优先级。
9. 根须守卫的元素模式必须互斥。
10. 所有Buff/Debuff必须有图标、Tips、持续时间显示。
11. 手机端长按显示详情，PC端鼠标悬停显示详情。
12. 所有高影响操作，如融合、天象释放，手机端需要确认或明显预览。
```
