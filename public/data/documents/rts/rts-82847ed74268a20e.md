# 1. 基础规则

## 1.1 阵营规则

华夏阵营采用以下成长结构：

| 系统 | 规则 |
|---|---|
| 建筑成长 | 建筑可升级，最高 Lv.3 |
| 建筑等级限制 | 其他建筑等级不能超过主城等级 |
| 主城升级 | 等同阵营阶段推进，解锁新建筑与高级科技 |
| 单位成长 | 士兵不升级，只升星，最高 5 星 |
| 英雄成长 | 英雄最高 5 星，升星解锁/强化技能 |
| 高级兵解锁 | 高级兵不换建筑生产，通过科技解锁 |
| 资源 | 木材、黄金、石料、金属、人口 |
| 删除内容 | 不使用粮食，不使用粮仓 |

---

## 1.2 建筑等级通用规则

| 主城等级 | 其他建筑最高等级 | 阶段定位 |
|---|---:|---|
| 主城 Lv.1 | Lv.1 | 基础陆战、基础经济、防御初建 |
| 主城 Lv.2 | Lv.2 | 骑兵、空军、水军、英雄、战术体系 |
| 主城 Lv.3 | Lv.3 | 攻城器械、精锐兵种、终局科技 |

---

## 1.3 生产建筑通用升级效果

| 建筑等级 | 通用效果 |
|---|---|
| Lv.1 | 基础生产，队列 3 格 |
| Lv.2 | 对应单位生产速度 +15%，队列 +1 |
| Lv.3 | 新生产单位初始经验 +20，高级单位训练时间 -10%，队列 +1 |

> 飞行单位和水上单位 Lv.3 初始经验为 +30，因为它们生产成本更高、节奏更慢。

# 4. 建筑升级数值

## 4.1 建筑通用字段说明

| 字段 | 含义 |
|---|---|
| HP | 建筑生命值 |
| 护甲 | 固定减伤或参与护甲公式 |
| 建造时间 | 工兵建造所需时间，多个工兵可加速 |
| 升级时间 | 从当前等级升级到下一级的时间 |
| 视野 | 建筑提供视野 |
| 占地 | 格子大小，供建造系统使用 |

# 13. 最终硬规则

```text
1. 华夏建筑最高 Lv.3。
2. 其他建筑等级不能超过主城等级。
3. 生产建筑只生产单位，不研究科技。
4. 科技建筑只研究科技，不生产普通单位。
5. 高级兵通过科技解锁，仍在对应生产建筑生产。
6. 步兵营生产全部步兵线。
7. 骑兵营生产全部骑兵线。
8. 飞羽营生产全部飞行线。
9. 水师营生产全部水军线。
10. 工械坊生产全部攻城线。
11. 辎重营生产全部后勤线。
12. 单位不升级，只升星，最高5星。
13. 英雄最高5星，升星解锁/强化技能。
14. 删除粮食与粮仓。
15. 资源只使用木材、黄金、石料、金属、人口。
16. 箭矢科技可以都研究，但同一单位只能启用一种箭矢。
17. 迅捷步伐提升移速后必须附带疲惫减速。
18. 单位必须有明确克制和被克制关系。
19. 高级单位必须有价格、速度、弱点上的代价。
20. UI必须清楚显示资源、前置、锁定原因、克制关系和当前科技模式。
```

# 14. 总结

华夏阵营最终结构：

```text
建筑：主城等级推进 + 单一功能建筑体系
单位：明确克制关系 + 战斗升星
科技：解锁高级兵 + 改变玩法模式 + 强化克制方向
资源：木材、黄金、石料、金属 + 人口
```

一句话：

```text
华夏阵营是一个依靠正规建筑体系、清晰兵种线、科技战术选择和士兵升星成长组成的标准 RTS 阵营。
```
