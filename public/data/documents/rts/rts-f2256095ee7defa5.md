# 战斗伤害跳字系统完整设计方案

## 一、设计目标

当前跳字问题：

```text
1. 普通伤害、暴击、治疗、穿甲、元素伤害表现差异不明显。
2. 数字跳出动画缺少强弱层级。
3. 元素伤害没有明确识别。
4. 高伤害没有爽感。
5. 多种伤害效果叠加时缺少统一规则。
6. 玩家很难从跳字判断当前攻击是否有效、是否克制、是否暴击、是否穿甲。
```

本方案目标：

```text
1. 让玩家一眼看出伤害类型。
2. 让玩家一眼看出伤害强度。
3. 让暴击、大伤害、克制伤害有明显爽感。
4. 让元素伤害、治疗、护盾、穿甲、真实伤害有独立识别。
5. 支持多个效果叠加，但不让画面乱。
6. 手机端也能看清楚，不堆满屏幕。
```

最终效果：

```text
普通伤害清楚。
暴击伤害爽。
元素伤害有辨识度。
治疗跳字柔和。
穿甲跳字锋利。
克制伤害有反馈。
高伤害有冲击。
低伤害不抢视觉。
```

# 二、游戏内伤害规则总览

## 2.1 基础伤害流程

每次攻击或技能造成伤害时，推荐按以下流程结算：

```text
基础伤害
→ 攻击类型修正
→ 护甲减免
→ 穿甲 / 破甲修正
→ 元素克制修正
→ 暴击修正
→ 技能倍率修正
→ Buff / Debuff 修正
→ 最终伤害
→ 触发跳字表现
```

---

## 2.2 伤害来源类型

| 来源类型 | 说明 | 示例 |
|---|---|---|
| 普通攻击 | 单位基础攻击 | 士兵砍击、弓箭、机枪 |
| 技能伤害 | 主动技能造成伤害 | 麒麟踏阵、火球、炮击 |
| 持续伤害 | 持续掉血 | 燃烧、中毒、腐蚀 |
| 范围伤害 | AOE伤害 | 爆炸、地震波、熔岩重踏 |
| 反弹伤害 | 受到攻击后反击 | 金甲反震 |
| 自爆伤害 | 单位死亡或主动引爆 | 爆浆虫、机械自毁 |
| 建筑伤害 | 防御建筑攻击 | 箭塔、炮台、根须守卫 |
| 环境伤害 | 地形或天气伤害 | 熔岩、天象、毒雾 |
| 召唤物伤害 | 召唤单位造成伤害 | 燃烧树根、无人机 |
| 真实伤害 | 不受护甲减免 | 终局技能、特殊斩杀 |

---

# 三、伤害结果类型

一次伤害可以被标记为多个结果。

例如：

```text
火焰暴击穿甲克制伤害
```

需要拆成：

```text
基础属性：火焰
强度等级：高伤害
特殊结果：暴击
附加结果：穿甲
关系结果：克制
```

---

# 四、伤害强度分级

## 4.1 强度计算

推荐用“最终伤害占目标最大生命百分比”来决定跳字强度。

```text
伤害占比 = 最终伤害 / 目标最大生命
```

同时考虑绝对伤害值，避免打小兵时全是巨额表现。

---

## 4.2 强度分级表

| 强度等级 | 判定 | 表现定位 |
|---|---|---|
| 微弱伤害 | < 1%最大生命 | 小、轻、快速消失 |
| 普通伤害 | 1%~5% | 标准跳字 |
| 有效伤害 | 5%~12% | 稍大、有弹性 |
| 高伤害 | 12%~25% | 大号、强跳动 |
| 巨额伤害 | 25%~45% | 大号、冲击波 |
| 致命伤害 | >45% 或直接击杀 | 最大、震动、击杀反馈 |

---

## 4.3 强度动画差异

| 强度 | 字号 | 动画 | 停留时间 | 额外表现 |
|---|---:|---|---:|---|
| 微弱 | 18 | 轻微上飘 | 0.45秒 | 无 |
| 普通 | 22 | 上飘+淡出 | 0.65秒 | 无 |
| 有效 | 26 | 上弹+上飘 | 0.8秒 | 小缩放 |
| 高伤害 | 32 | 强弹出+抖动 | 1.0秒 | 小冲击 |
| 巨额 | 40 | 爆弹+慢停留 | 1.2秒 | 冲击圈 |
| 致命 | 46 | 爆裂+震屏轻微 | 1.4秒 | 击杀闪光 |

---

## 4.4 强度表现规则

```text
低伤害不能抢视觉。
高伤害必须明显大于普通伤害。
巨额伤害允许短暂停留。
致命伤害可以带击杀图标。
同一目标同时多个小伤害时应合并显示。
```

# 五、基础跳字类型设计

## 5.1 普通物理伤害

用途：

```text
没有元素、没有暴击、没有穿甲的基础伤害。
```

表现：

```text
白色数字
浅灰描边
标准上飘
无图标
```

示例：

```text
128
```

---

## 5.2 低效伤害

触发：

```text
伤害被护甲大幅减免
打到被克制目标失败
攻击无效目标
```

表现：

```text
灰色数字
缩小字号
上飘距离短
带“削弱”小标签或向下箭头
```

示例：

```text
↓ 24
```

---

## 5.3 有效伤害

触发：

```text
对克制目标造成伤害
技能命中主要目标
伤害占比较高但非暴击
```

表现：

```text
数字略大
颜色更亮
弹性更明显
可出现“有效”小闪光
```

示例：

```text
256
```

---

## 5.4 暴击伤害

触发：

```text
Critical = true
```

表现：

```text
红色数字
深色粗描边
字体更大
弹出更强烈
短暂抖动
```

示例：

```text
暴 864
```

UI规则：

```text
暴击文字可显示“暴”图标，不建议长写“暴击”。
暴击动画优先级高于普通元素动画。
暴击可以叠加元素图标。
```

---

## 5.5 超暴击 / 致命暴击

触发：

```text
暴击 + 高伤害
或特殊技能触发超暴击
```

表现：

```text
红金渐变数字
黑红粗描边
更大字号
爆裂缩放
轻微屏幕震动
```

示例：

```text
暴! 2400
```

限制：

```text
同屏同时最多显示3个超暴击特效。
防止画面爆炸。
```

---

## 5.6 穿甲伤害

触发：

```text
ArmorPierce = true
```

表现：

```text
银白数字
金属蓝描边
数字前加穿甲图标
动画为斜向切入
带金属划痕
```

示例：

```text
[穿甲图标] 420
```

动画：

```text
数字从右下向左上斜切弹出
0.1秒后向上飘
```

---

## 5.7 破甲伤害

触发：

```text
ArmorBreak = true
```

表现：

```text
银红数字
数字旁出现破盾/裂甲图标
目标身上出现护甲裂纹
```

示例：

```text
[裂甲] 330
护甲 -2
```

规则：

```text
伤害数字和破甲状态可以分两行显示。
第一行显示伤害。
第二行显示护甲降低。
```

---

## 5.8 真实伤害

触发：

```text
TrueDamage = true
```

表现：

```text
纯白或紫白数字
强描边
数字垂直弹出
无护甲减免提示
```

示例：

```text
真 560
```

规则：

```text
真实伤害不受护甲颜色影响。
如果暴击，红色暴击优先，但保留真实伤害图标。
```

---

## 5.9 治疗跳字

触发：

```text
Heal = true
```

表现：

```text
绿色数字
前面加 + 号
柔和上升
无强烈弹跳
带叶子/十字/水滴小图标
```

示例：

```text
+120
```

持续治疗：

```text
小号绿色数字
上飘更轻
可合并显示
```

示例：

```text
+24
+24
+24
```

建议：

```text
持续治疗频率高时，每0.5秒合并一次。
```

---

## 5.10 护盾吸收

触发：

```text
DamageToShield = true
```

表现：

```text
蓝色数字
前面加护盾图标
数字不显示红色伤害感
动画更硬，像被挡住
```

示例：

```text
[盾] 180
```

护盾破裂：

```text
[破盾] 320
```

表现：

```text
蓝白裂纹
目标护盾罩碎裂
跳字有破碎动画
```

---

## 5.11 闪避 / 未命中 / 格挡 / 免疫

这些不是数字，而是文字跳字。

| 类型 | 文本 | 颜色 | 动画 |
|---|---|---|---|
| 闪避 | 闪避 | 青色 | 左右偏移 |
| 未命中 | Miss | 灰白 | 上飘淡出 |
| 格挡 | 格挡 | 蓝灰 | 小震动 |
| 免疫 | 免疫 | 紫白 | 原地闪现 |
| 吸收 | 吸收 | 蓝紫 | 向内收缩 |

规则：

```text
这类文本不能太大。
不应盖过真实伤害和暴击。
```

# 六、元素伤害跳字设计

## 6.1 元素跳字通用规则

元素伤害统一规则：

```text
数字前方显示元素图标。
数字颜色使用元素主色。
数字描边使用深色或元素暗色。
动画可叠加元素粒子。
```

结构：

```text
[元素图标] 数字
```

示例：

```text
🔥 320
💧 280
❄ 190
🌿 240
```

# 七、叠加表现规则

## 7.1 叠加优先级

一次伤害可能同时拥有多个标签。

显示优先级：

```text
致命击杀
> 超暴击
> 暴击
> 元素克制
> 穿甲/破甲
> 元素属性
> 普通伤害
> 低效伤害
```

---

## 7.2 颜色优先级

颜色优先规则：

```text
暴击优先红色。
元素伤害保留元素图标。
穿甲保留穿甲图标。
克制保留“克”小标。
```

例如：

火焰暴击：

```text
🔥 暴 920
```

水系克制火系暴击：

```text
💧 克 暴 1280
```

金系穿甲暴击：

```text
⚔ 穿 暴 1500
```

真实暴击：

```text
真 暴 1800
```

---

## 7.3 图标叠加规则

最多显示 2 个前置图标。

优先级：

```text
元素图标
特殊图标，暴击/穿甲/破甲/真实/治疗
```

如果超过2个，用文字小标代替。

示例：

```text
🔥 暴 920
⚔ 穿 680
💧 克 420
```

不推荐：

```text
🔥⚔🛡💥暴击克制穿甲 920
```

---

## 7.4 文本标签规则

|---|---|---|

| PopUp | 有效伤害 | 放大弹出 |
| HeavyPop | 高伤害 | 强弹出+抖动 |
| BurstPop | 巨额伤害 | 爆裂弹出 |
| CriticalSmash | 暴击 | 大缩放+震动 |
| SlashOut | 穿甲/金系 | 斜切出现 |
| SplashRise | 水系 | 水泡式上浮 |
| FlameBurst | 火系 | 火花爆开 |
| FrostCrack | 冰系 | 冻结停顿+碎裂 |
| StoneImpact | 土系 | 下砸震动 |
| VineGrow | 木系 | 生长弹出 |
| ElectricJitter | 电系 | 快速抖动 |
| HealRise | 治疗 | 柔和上升 |
| ShieldBlock | 护盾 | 原地弹开 |
| TextFade | 免疫/闪避 | 文字淡出 |

---

## 8.2 普通伤害动画

```text
0.00s：数字出现，缩放 80%
0.08s：放大到 110%
0.15s：回落到 100%
0.15s~0.65s：向上飘 35px
0.65s：透明度归零
```

---

## 8.3 暴击动画

```text
0.00s：数字从 60% 缩放出现
0.06s：放大到 145%
0.12s：回落到 115%
0.12s~0.25s：左右抖动
0.25s~1.1s：缓慢上飘 50px
0.9s~1.1s：淡出
```

额外：

```text
高伤害暴击触发小冲击圈。
致命暴击触发轻微屏幕震动。
```

---

## 8.4 穿甲动画

```text
0.00s：数字从右下斜向切入
0.08s：出现刀光线
0.12s：数字停顿
0.12s~0.8s：向左上飘
0.8s：淡出
```

---

## 8.5 治疗动画

```text
0.00s：数字透明度从0到100
0.10s：轻微放大到105%
0.10s~0.9s：柔和上升 45px
0.9s：淡出
```

治疗不能抖动，避免像伤害。

---

## 8.6 护盾动画

```text
0.00s：数字出现
0.05s：横向轻微弹开
0.10s：护盾小图标闪烁
0.10s~0.6s：上飘
```

护盾破裂：

```text
数字出现时有碎片向两侧飞出。
```

# 九、跳字布局规则

## 9.1 出现位置

默认：

```text
单位头顶血条上方
```

特殊：

```text
大型单位：在受击点附近显示
建筑：在建筑中心偏上显示
AOE：多个目标各自显示，不在地面中心显示
治疗：单位头顶偏右
护盾：血条上方偏左
```

---

## 9.2 多个跳字防重叠

同一单位短时间多个跳字时：

```text
第1个：正上方
第2个：左上方
第3个：右上方
第4个：更高位置
第5个以后：合并或延迟
```

偏移规则：

```text
随机水平偏移 -18px 到 +18px
高伤害不随机太多，保持居中
```

---

## 9.3 跳字合并规则

持续伤害和持续治疗需要合并。

合并窗口：

```text
0.35秒
```

同一单位、同一伤害类型、同一来源可合并。

示例：

```text
毒伤害 18 + 18 + 18
显示为：☠ 54
```

燃烧同理。

---

## 9.4 同屏数量限制

为了手机端清楚：

| 类型 | 同屏上限 |
|---|---:|
| 普通伤害 | 30 |
| 持续小伤害 | 15 |
| 治疗 | 15 |
| 暴击 | 10 |
| 巨额伤害 | 5 |
| 致命伤害 | 3 |
| 免疫/闪避文本 | 10 |

超出后处理：

```text
低优先级跳字合并或隐藏。
高优先级永远显示。
```

# 十、特殊战斗效果跳字

## 10.1 克制伤害

触发：

```text
攻击元素克制目标
兵种克制目标
技能专门克制目标
```

表现：

```text
数字前加“克”小标
颜色更亮
弹出更有力
```

示例：

```text
💧 克 420
```

如果暴击：

```text
💧 克 暴 1280
```

---

## 10.2 被克制 / 低效伤害

触发：

```text
攻击被目标抗性克制
打到高护甲但没有穿甲
水系上岸削弱后输出
火系打水系
```

表现：

```text
灰色或暗元素色
数字更小
向下轻微坠落后消失
```

示例：

```text
↓ 38
抵抗
```

---

## 10.3 破甲状态

破甲分两种显示：

### 造成伤害时

```text
[裂甲] 330
```

### 状态附加时

```text
护甲 -2
```

状态文字颜色：

```text
银红色
```

动画：

```text
文字轻微裂开
```

---

## 10.4 吸血

吸血建议分成两段：

```text
伤害数字
吸血治疗数字
```

示例：

```text
暴 860
+吸 120
```

吸血治疗显示在攻击者头顶，不显示在受害者头顶。

---

## 10.5 斩杀

触发：

```text
技能直接击杀低生命目标
化形饕餮吞军化血
特殊处决技能
```

表现：

```text
斩 字样 + 伤害数字或直接“斩杀”
深红金色
大字号
强烈下劈动画
```

示例：

```text
斩杀
```

或：

```text
斩 2400
```

---

## 10.6 自爆伤害

表现：

```text
爆炸图标
橙黄数字
数字向外散开
高伤害时带冲击圈
```

示例：

```text
💥 780
```

多个单位被同一爆炸伤害：

```text
每个单位显示数字，但小兵低伤害可合并。
```

---

## 10.7 友军伤害

如果开启友伤：

```text
数字使用黄色或橙灰
前面加“友”小标
```

示例：

```text
友 120
```

默认不建议强调太强。

# 十五、程序实现建议

## 15.1 跳字生成流程

```text
战斗系统计算最终伤害
→ 生成 DamageResult
→ DamagePopupSystem 读取 DamageResult
→ 判断跳字类型
→ 判断强度等级
→ 判断颜色和图标
→ 判断是否合并
→ 从对象池取 PopupItem
→ 播放对应动画
→ 动画结束回收
```

---

## 15.2 对象池

跳字必须使用对象池。

建议池数量：

```text
普通跳字：80
高优先级跳字：30
状态文字：40
治疗跳字：30
```

如果池不足：

```text
优先回收低优先级跳字
不能覆盖暴击/致命跳字
```

---

## 15.3 合并逻辑

可合并条件：

```text
同目标
同来源
同元素
同PopupType
同0.35秒窗口
不是暴击
不是致命
不是斩杀
```

不可合并：

```text
暴击
致命伤害
破盾
斩杀
重要技能命中
```

# 十六、验收标准

## 16.1 基础识别

```text
普通伤害是白色。
暴击伤害是红色，且动画明显更强。
治疗是绿色，并且动画柔和。
护盾伤害是蓝色。
穿甲伤害是银白/金属蓝，并有穿甲图标。
破甲伤害有裂甲图标和护甲降低提示。
真实伤害有“真”标记。
```

---

## 16.2 元素识别

```text
火伤害有火焰图标和橙红数字。
水伤害有水滴图标和蓝色数字。
冰伤害有雪花图标和冰蓝数字。
土伤害有岩石图标和土黄数字。
金伤害有金刃图标和金白数字。
木伤害有叶子图标和绿色数字。
毒伤害有紫绿色小数字。
电击伤害有电蓝数字和抖动动画。
```

---

## 16.3 强度识别

```text
微弱伤害明显小。
普通伤害标准。
高伤害明显更大。
巨额伤害有冲击圈。
致命伤害有击杀反馈。
同一个单位受到不同强度伤害时，玩家能明显区分。
```

---

## 16.4 叠加识别

```text
火焰暴击显示火图标 + 暴击表现。
水系克制火系显示水图标 + 克制标记。
穿甲暴击显示穿甲图标 + 暴击红色。
治疗暴击如果存在，应显示大号绿色治疗，不显示红色。
护盾破裂有破盾表现。
```

---

## 16.5 性能与清晰度

```text
大量持续伤害时不会满屏小数字。
持续伤害可以正确合并。
手机端不会遮挡大部分战斗画面。
高优先级跳字不会被低优先级挤掉。
跳字动画结束后正确回收。
```

---

# 十七、最终硬规则

```text
1. 跳字必须区分伤害类型。
2. 跳字必须区分伤害强度。
3. 暴击必须是红色、大号、强动画、带描边。
4. 元素伤害必须在数字前显示元素图标。
5. 治疗必须绿色，动画柔和，不像伤害。
6. 穿甲必须有金属感和穿甲图标。
7. 破甲必须显示护甲降低提示。
8. 持续伤害必须合并，不能刷屏。
9. 多效果叠加最多显示2个前置图标。
10. 致命、暴击、巨额伤害优先级最高。
11. 手机端必须减少跳字密度。
12. 玩家必须能通过跳字判断当前攻击是否有效。
```

---

# 十八、一句话总结

```text
伤害跳字不是单纯显示数字，而是战斗反馈系统。普通伤害负责清楚，元素伤害负责辨识，暴击和高伤害负责爽感，治疗和护盾负责状态反馈，穿甲和克制负责策略反馈。
```
