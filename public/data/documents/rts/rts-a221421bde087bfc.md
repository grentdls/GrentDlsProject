# Unity UI 美观性布局规范扩展包

本文档包是《Unity UI 控件制作规则文档》的扩展，专门解决“控件做出来了，但界面不好看、不清晰、不好维护”的问题。

## 文档列表

| 文件 | 作用 |
|---|---|
| `05_UI美观性布局总规则_视觉层级_间距_对齐.md` | 定义整体审美规则、视觉层级、间距、对齐、信息密度、颜色使用规则。 |
| `06_详情面板布局规范_物品_技能_角色_词条.md` | 重点说明物品详情、技能详情、角色详情、词条说明等面板怎么排版。 |
| `07_内容自适应_动态高度_滚动区域_防溢出规则.md` | 说明内容多/少时，背景框、ScrollRect、LayoutGroup、文字换行如何处理。 |
| `08_常见界面布局模板规范_背包_商店_奖励_图鉴_设置.md` | 给出背包、商店、三选一、奖励、图鉴、设置、部件改造等界面模板。 |
| `09_UI信息字段_颜色_标签_图标_品质表现规范.md` | 统一字段名词、颜色、标签、图标、品质框、状态表现，方便后续统一调用。 |

## 推荐使用方式

1. 先看 `05`，确定整个项目 UI 的审美底层规则。
2. 做任意详情弹窗前，先按 `06` 的结构搭预制体。
3. 文字长度、词条数量不固定的界面，必须按 `07` 处理自适应。
4. 做具体功能界面时，从 `08` 选择模板。
5. 所有字段颜色、品质框、图标含义，统一走 `09`，不要各界面自己随便定。

## 核心原则

UI 的美观不只是“画得漂亮”，更重要的是：

- 玩家一眼知道重点在哪里。
- 玩家知道哪个区域能点，哪个区域只是信息。
- 内容多时不乱，内容少时不空。
- 不同界面的布局语言统一，玩家不需要重新学习。
- 后续改数值、改文字、加词条、换图标时，不需要重做整个界面。
